## FL・SL と階高

各階の FL は床上端の基準標高、SL は代表的な梁の中心が来る構造基準標高です。
どちらも同じモデル座標原点からの mm 値です。各階に FL と上向きを正とする差分 ΔSL を入力し、SL は FL + ΔSL で求めます。
差分の負・0・正を指定できます。−500 mm は例であり固定値ではありません。明示した 0 mm は FL と SL が同じことを表します。

| 値 | 定義 |
| --- | --- |
| 建築階高（FL間） | 上階 FL − 下階 FL。既存計算へ渡す階高 |
| 構造階高（SL間） | 上階 SL − 下階 SL |

例えば下階 FL=3500 mm・ΔSL=−500 mm、上階 FL=7000 mm・ΔSL=−600 mm なら、SL は 3000／6400 mm、建築階高は 3500 mm、構造階高は 3400 mm です。
FL を固定して差分だけを変えても建築階高は変わりません。FL・差分・SL・隣接階差は有限で、FL 列と SL 列はそれぞれ下から上へ厳密な正順が必要です。
重複・逆転を微小階高や別の階順へ置き換えることはしません。

「① 準備計算」の階定義で、階名・FL・ΔSL を編集します。SL・FL間・SL間は導出表示です。
FL と ΔSL の空欄は未設定として保持します。階追加では両方を明示し、「階を追加」で採用します。
既存階の FL が未設定・不正で追加位置を確定できない場合は、階 ID・FL の診断を表示して追加を拒否します。既存の階順・ID・原階・参照・節点座標は変更しません。既存 FL を補ってから追加してください。追加フォームには FL=0 mm、ΔSL=0 mm を表示し、追加後の次の FL 候補は直前の FL + 3500 mm とします。
階編集と追加は undo/redo と OViKA 保存・再読込に対応し、計算入力の変更で既存結果は失効します。
既存節点の座標は FL・差分の編集では動きません。変更後の構造レベルに必要な所属・剛床が成立しなければ、診断を確認してモデルを修正してください。

最下階の FL はモデル座標原点・GL・構造節点の最小 Z と別の情報です。最下層にも指定した上下 FL を使います。
構造最下端を理由に最下階 FL を変更したり、基部の階を自動追加したりしません。
FL・差分が不足するモデルは編集・保存できますが、階を必要とする準備計算・解析・後続算定を開始できません。
節点 Z から FL／SL を推測したり、未設定差分を 0／−500 mm で補ったりしません。

## 階と層

**階は床の基準で、層は指定した隣接 2 階の間です**。階を N 個定義すると層は N−1 個です。
層の名前は下端階、重量・所属節点・階種別・主要構造種別は上端階から採ります。
最下階に配分した重量は最下層の層重量には算入しません。
階名の既定は下から 1F・2F…です。最上階を自動的に屋根と判定せず、必要に応じて RF 等へ編集します。
階名の重複は整合性チェックで確認してください。

STB 元階の FL・階名・種別・明示所属は、現在編集する階情報と分けて保持します。
取込みで取得できた FL を保持し、ΔSL は未設定です。入力後も元の節点座標・元属性を変更しません。
解析用階と元階の対応は FL 編集後も維持され、元属性の高さ一致や階名で付け替えません。
「STB明示所属と解析用推定」で入力不整合と所属の相違を確認し、原階の節点 ID を入力して「所属を適用」で明示所属を編集できます。
未知節点・多重所属・従属先の欠落や循環は診断されます。空の元階一覧へ自動で解析階を追加しません。

## 階と剛床

階所属と剛床は別の概念です。通常の架構では SL を代表解析レベルとして使います。

| 対象 | 自動判定 |
| --- | --- |
| 階所属 | 直下階 SL を超え、当該階 SL 以下の区間 |
| 最下階の所属 | 構造節点の最下端以上、最下階 SL 以下の区間 |
| 剛床候補 | 当該階 SL から 1 mm 以内の面 |

中間高さの節点は階に属しても、SL 面から外れれば新規の剛床に加えません。
SL に節点がない階には剛床・代表節点を自動生成しません。入力済みの明示所属・利用者剛床は維持し、自動生成した所属・剛床は再評価します。
必要な所属や拘束が成立しない場合は計算を停止し、元の節点や明示拘束を勝手に移動・解除しません。
1 階に複数の剛床がある場合の水平力は剛床重量比で分配します。
現在の重量・質量の準備計算では、利用者剛床のスレーブも所属階 SL から 1 mm 以内にあることが必要です。
SL 外の別レベルに明示した拘束は入力として保持しますが、この準備計算で有効な別レベル剛床として自動的に受理・補正しません。

最下階の自動剛床代表節点は、構造部材が接続する床面節点の水平自由度が全て拘束されている場合、水平並進・面内回転を拘束します。
支点ばねで水平移動できる場合は自由として質量を連成させます。部材が接続しない床境界・小梁支持点はこの判定に数えません。

## 層間変形角への高さと評価点の供給

層間変形角に供給する分母は上下階の FL 間高さです。上下の評価点には、上下階 SL にある解析節点の加力方向水平変位を使い、その差の絶対値を FL 間高さで除します。
FL 位置の変位や、SL 節点変位を FL へ補間・換算した変位は使いません。対象層の柱の上下端も SL を基準に判定します。
例えば FL が 3500／7000 mm、SL が 3000／6400 mm なら、Z=3000／6400 mm の解析節点の変位差と分母 3500 mm を対応させます。
ここで整備した階情報・参照先を使う具体的な変位差の算定・集計・表示は、層間変形角機能の対応範囲に従います。

## 階の定義と自動算定の分担

階名・FL・ΔSL・階種別・地震用重量の手入力は利用者が定め、準備計算は保持します。
所属節点・自動剛床・地震用重量の算定値・主要構造種別は準備計算で更新します。
階の削除は節点・部材を残し、その階の所属と剛床を解除します。最下階の削除はできませんが、FL・差分の編集はできます。

## 一覧の列

一覧の 1 行は 1 つの**層**です。

| 列 | 内容 |
| --- | --- |
| 床レベル | 層の上端階 FL [mm]（モデル座標） |
| 階高 | 上端階 FL − 下端階 FL [mm] |
| 節点数 | 上端の階に属する節点の数 |
| 剛床数 | 上端の階に定義された剛床（ダイアフラム）の数 |
| 地震用重量 \\( W\_i \\) | 層の地震用重量 [kN]（固定荷重＋地震用積載） |
| 累積 \\( \Sigma W\_j \\) | 当該層以上の地震用重量の合計 [kN] |
| 構造・種別 | 層の主要構造種別（RC / S / SRC）と階種別（一般 / PH / 地下） |

剛床数が 0 の層、地震用重量が 0 の層は強調表示します。剛床のない階にも水平力は載りますが、
載荷先が剛床代表節点ではなく階の各節点になる（[地震力](../calc_basis/01_荷重/01_地震力.md)）
ため、意図した床面のモデル化になっているかを確認してください。
剛床のない階は[モデル整合性チェック](./README.md#モデル整合性チェック)にも警告として並びます。
解析は止まりませんので、意図した入力であればそのまま進めてかまいません。

支点数には、階の生成が作る剛床代表節点（面外拘束を持つ仮想節点）は含めません。

主要構造種別は、その層に属する柱・梁の構造種別
（[構造種別の判定](../calc_basis/02_材料/05_構造種別の判定.md)）を集計して決めます。
RC を RC、S を S、鉄骨とコンクリートが一体で働く SRC・CFT を SRC とし、層に属する部材で
もっとも多い種別を採ります。部材の所属は、材端節点のうちもっとも高い節点の所属階を上端と
する層とします（層 \\( i \\) の階高区間にある柱は上端が層 \\( i \\) の上端の階に取り付き、
その階のレベルにある梁も層 \\( i \\) に属します）。種別ごとの本数が同数の場合、および断面も
材料も割り当てられていない部材だけの層は RC とします。主要構造種別は略算周期の鉄骨造高さ比
\\( \alpha \\)（[地震力](../calc_basis/01_荷重/01_地震力.md)）にのみ効き、S の層が増えるほど
設計用固有周期 \\( T \\) が長く \\( R\_t \\) が小さくなるため、判定が割れた場合に S を採らないことが
安全側になります。
