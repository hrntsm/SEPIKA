# 仕口パネル

準備計算が生成した**仕口パネル要素**を一覧します。

仕口パネル要素は、柱梁接合部のせん断変形を解析モデルへ組み込む要素です。既定で S 造（CFT を除く）の
柱梁接合部に生成されます。生成の有無は右パネル「① 準備計算」の「部材のモデル化」にあるチェックボックス
**「仕口パネルをモデル化（柱梁接合部）」**（既定 ON）で建物一律に切り替えます。OFF にすると仕口パネル要素は
生成されないため、この一覧は空になります。

| 列 | 内容 |
| --- | --- |
| 節点 | 接合部の節点 ID |
| dc [mm] | 柱せい方向の仕口パネル要素の寸法 |
| db [mm] | 梁フランジ板厚中心間距離（取り付く梁のうち最大） |
| tp [mm] | 仕口パネル要素の板厚 |
| Ve [mm³] | 仕口パネル要素の実効体積 |
| Kxp=Kyp [kN·m/rad] | 仕口パネル要素のせん断剛性 |

<div class="impl-ref">

**実装参照**：仕口パネル要素の生成・除去は `sepika_element::springs::panel_gen::apply_auto_panel_zones`（`crates/sepika-element/src/springs/panel_gen.rs`）が行います。

</div>

## 仕口パネル要素の生成

仕口パネル要素は、S 造（CFT を除く）の柱梁接合部に生成されます。生成された仕口パネル要素の寸法・実効体積・
せん断剛性は、この一覧で確認できます。

一覧が空になる場合は、対象となる S 造の柱梁接合部がない、接合部に CFT 柱を 1 本でも含む、または柱・梁の断面が
未割当である可能性があります。「断面性能」タブで断面の割り当てを確認してください。CFT の柱梁接合部は
仕口パネル要素を生成しませんが、柱梁接合部の断面算定の対象です。

梁の寸法はH梁の形状外寸 `D − tf`、組立H梁の `D − (tf上 + tf下)/2` から求めます。表示用の断面せいが異なっていても、形状寸法を用います。非H梁、形状未定義、不正寸法の梁を含む接合部は生成せず、接合部ID・梁ID・形状・梁材軸・不足条件付きの通知を表示します。非H梁のせいの直接入力は式適用の確認にはなりません。

対象梁は材軸水平・直交化したせい方向±Zに限定します。横倒し、斜め断面回転、勾配梁、鉛直Girderは理由付き未対応です。−Zを向く組立Hは上下板厚を全体座標の上下へ対応させます。

相対する梁の上下フランジ板厚中心位置を面ごとに比較し、両位置が局所数値公差1×10⁻⁶ mm以内で一致する標準形式だけを適用します。片側梁は保持し、直交梁を左右の比較相手にしません。150 mmの梁せい差による許容判定はありません。現行の入力には梁端鉛直偏心がなく、梁天端へ自動的に揃えません。

段違い・未対応面を含む接合部は標準パネル要素を生成せず、節点・検討面・梁ID・両db・上下位置差を通知します。通知はせん断変形をモデル化できない制限であり、剛接合の妥当性を確認した結果ではありません。パネル不生成時はパネル分のオフセットを残しません。フェイス応力評価位置・手動剛域は個別の設定条件を保持します。古い/明示パネルも同じ幾何制限を受け、未対応接合を剛パネルへ置き換えて解析成功にはしません。

保存成果の読込時にも、共通resolverで現在の標準形式の適用条件を確認します。対象外面が旧成功結果になっている、または現在の共通理由を記録した未算定面がない場合、その解析・検定成果を利用不可にして再解析を要求し、面と位置差を含む理由を残します。全体解析の応力は接合部剛性と連成するため、旧成功成果の直交面だけを再認証しません。対応標準形式の成果と、現在の共通理由を記録した未算定面＋別標準面の保存成果は保持します。モデル編集後の古い解析を対象外形状の再検定へ流用する入口も拒否します。一般の算法版管理は[#587](https://github.com/hrntsm/SEPIKA/issues/587)で別途扱います。

解析成果や旧Sパネルの成功結果を含まない空の結果容器・床板だけの直接設計は、旧架構成果の利用制限では停止しません。床板の自重・材料条件はその直接設計入口で検証します。静的/組合せ・固有値・増分/保有耐力・立体/質点系時刻歴などの解析成果、保存内力/パネル需要、または旧Sパネル成功結果を持つ場合は、従来どおり共通幾何による利用不可判定を受けます。

断面検定は面別に「検定不能」を表示し、直交する標準形式の面は検定を保持します。未算定を含む節点の検定比図は「未算定」を表示し、適合色にはしません。MCPの全適合判定とCSV帳票でも未算定面・理由を保持します。段違い耐力・剛性の正式対応と非0配置入力からの伝播は未対応であり、解除条件は[標準形式の適用範囲](../calc_basis/04_要素剛性/06_パネルゾーン.md)を参照してください。

生成条件と構造種別の判定は、[構造種別の判定](../calc_basis/02_材料/05_構造種別の判定.md)・
[仕口パネル要素](../calc_basis/04_要素剛性/06_パネルゾーン.md)を参照してください。

<div class="impl-ref">

**実装参照**：生成条件と諸元の解決は `sepika_core::panel_zone::resolve_panel_joint`（`crates/sepika-core/src/panel_zone.rs`）が行い、CFT 柱の除外は `sepika_element::springs::panel_gen::apply_auto_panel_zones` が担います。

## モデル化の影響

仕口パネル要素は、柱梁接合部のせん断変形を解析へ組み込みます。仕口パネル要素の寸法に対応するオフセットと
部材端の剛域は、準備計算の「剛域」表と結果タブ「モデル化」のモデル化ビューで確認できます。

せん断変形・剛域・オフセットの算定と解析モデルへの反映は、[仕口パネル要素](../calc_basis/04_要素剛性/06_パネルゾーン.md)・
[ティモシェンコ梁要素](../calc_basis/04_要素剛性/01_ティモシェンコ梁要素.md)を参照してください。

## 断面・材料の割当と表示上の扱い

仕口パネル要素は**断面を割り当てない要素**です。
せん断剛性は取り付く柱・梁の断面から求めた実効体積 Ve によるため、仕口パネル要素自身が
断面を参照する必要がありません。材料は断面が持つため、断面を割り当てない仕口パネル要素は材料も
持ちません。節点バネ・免震支承材・制振ダンパーも同じく、断面ではなく専用の特性値から
剛性を作るため、これらにも断面を割り当てません。

このため、断面・材料の割当を見る次の機能は、いずれも仕口パネル要素を対象から除きます。

| 機能 | 仕口パネル要素の扱い |
| --- | --- |
| 下ドック「診断」タブの断面未割当の警告 | 対象外 |
| 解析前の入力チェック（断面・材料の未割当エラー） | 対象外 |
| ナビゲータの部材グループ（鋼材部材 / RC部材） | 対象外（材種で分類しない） |
| 3D ビューの選択ハイライト | 描かない |

3D ビューでハイライトしないのは、仕口パネル要素の節点列が「接合部の節点 ＋ 取り付く部材の他端」であり、
材軸も輪郭も持たないためです。先頭 2 節点を結ぶ線は取り付く柱・梁そのものと同じ線分になるので、そこへ
ハイライトを描くと、選択していない柱・梁が選択されているように見えてしまいます。同じ理由でクリックによる
選択・ホバーの対象からも外れているため、仕口パネル要素の寸法とせん断剛性は、この準備計算「仕口パネル」タブの
一覧で確認してください。

仕口パネル要素は部材タブの部材一覧には種別 `PanelZone` の要素として並び、断面の欄と（断面から引く）材料の欄は
どちらも空欄（`―`）が正しい状態です。ナビゲータの部材グループは仕口パネル要素を数えないため、鋼材部材と
RC部材の合計は部材一覧の行数とは一致しません。

<div class="impl-ref">

**実装参照**：仕口パネル要素を断面必須としない扱いは `sepika_core::model::ElementKind::requires_section_and_material`（`crates/sepika-core/src/model/element.rs`）が定め、3D ビューの描画・選択からの除外は `sepika_app::viewer::scene::element_draw_shape`（`crates/sepika-app/src/viewer/scene.rs`）が担います。

</div>

## 断面算定との関係

柱梁接合部の断面算定は、仕口パネル要素のモデル化の有無によらず行います。CFT の柱梁接合部も断面算定の対象です。
検定結果は結果タブ「設計」の「接合部・耐震壁の検定」表と、3D の検定比図（節点上のひし形マーカー）で確認できます。

算定式・係数・対象条件は、一次設計の[RC 断面検定](../calc_basis/06_一次設計/02_RC_断面検定.md)・
[鋼構造 断面検定](../calc_basis/06_一次設計/03_鋼構造_断面検定.md)・
[SRC / CFT 断面検定](../calc_basis/06_一次設計/04_SRC_CFT_断面検定.md)を参照してください。
