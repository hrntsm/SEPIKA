# 仕口パネル

準備計算を実行し、下ドック「準備計算」の「仕口パネル」を選んで確認します。

準備計算が生成した**仕口パネル要素**を一覧します。

仕口パネル要素は、柱梁接合部のせん断変形を解析モデルへ組み込む要素です。既定で S 造（CFT を除く）の
柱梁接合部に生成されます。生成の有無は右パネル「① 準備計算」の「部材のモデル化」にあるチェックボックス
**「仕口パネルをモデル化（柱梁接合部）」**（既定 ON）で建物一律に切り替えます。OFF にすると仕口パネル要素は
生成されないため、この一覧は空になります。

| 列 | 内容 |
| --- | --- |
| 節点 | 接合部の節点 ID |
| 方向 | 採用柱の強軸・弱軸 |
| dc [mm] | 表示方向の仕口パネル要素の寸法 |
| db [mm] | 表示方向の梁フランジ板厚中心間距離 |
| tp [mm] | 表示方向の仕口パネル要素の板厚 |
| Ve [mm³] | 表示方向の仕口パネル要素の実効体積 |
| K [kN·m/rad] | 表示方向の仕口パネル要素のせん断剛性 |

接合部ごとに強軸・弱軸の2行を表示します。箇所数は接合部の数です。柱断面の既存の向きから2方向を定め、梁方向ごとの仮想の仕口パネルは設けません。追加の2自由度は、全体 X・Y の基底を柱材軸の直交面へ投影した基底の係数で、鉛直柱の場合に全体 X・Y 軸まわりの回転方向と一致します。変形とモーメントの対応は[柱主軸と全体座標の変換](../calc_basis/04_要素剛性/06_パネルゾーン.md)を参照してください。

## 仕口パネル要素の生成

仕口パネル要素は、S 造（CFT を除く）の柱梁接合部に生成されます。生成された仕口パネル要素の寸法・実効体積・
せん断剛性は、この一覧で確認できます。

一覧が空になる場合は、対象となる S 造の柱梁接合部がない、または接合部に CFT 柱を 1 本でも含む可能性があります。CFT の柱梁接合部は
仕口パネル要素を生成しませんが、柱梁接合部の断面算定の対象です。

柱由来の寸法・材料・実効体積は、接合部の物理的な下側柱から求めます。下側柱が存在しない場合だけ上側柱を使います。上下の実効体積の大小・同値、部材の並び順や端点の登録順では選びません。解析・断面検定の柱情報と軸力も同じ採用柱を参照します。

算定対象で採用柱を一意に特定できない場合や、採用柱の断面・材料・寸法・断面積・軸剛性など必要な情報が欠落・不正の場合は、接合部と理由を示すエラーになります。「断面性能」タブなどで割り当てを確認してください。不正な下側柱を不在とみなして上側柱へ切り替えたり、既定値や正常な剛パネルで補ったりしません。

せん断弾性係数は採用柱の材料の明示値を優先し、未指定の場合だけヤング係数とポアソン比から求めます。採用値と実効体積との積は有限の正値が必要で、0も入力不備として扱います。不正な明示値から導出値への切替えや、剛パネル・微小値・既定材料による補完は行いません。仕口パネルをモデル化する自動生成・準備計算と、明示パネルを使う直接解析のいずれでも、条件を満たさない場合は正常結果を返さず、接合部・採用柱と理由を示します。式と適用条件は[仕口パネル要素の剛性](../calc_basis/04_要素剛性/06_パネルゾーン.md)を参照してください。

梁の寸法はH梁の形状外寸 `D − tf`、組立H梁の `D − (tf上 + tf下)/2` から求めます。表示用の断面せいが異なっていても、形状寸法を用います。非H梁、形状未定義、不正寸法の梁を含む接合部では、仕口パネルを自動生成せず、接合部ID・梁ID・形状・梁材軸・不足条件を示す通知を表示します。非H梁のせいの直接入力は式適用の確認にはなりません。

対象梁は材軸水平・直交化したせい方向±Zに限定します。横倒し、斜め断面回転、勾配梁、鉛直に配置した梁は理由付き未対応です。−Zを向く組立Hは上下板厚を全体座標の上下へ対応させます。

相対する梁の上下フランジ板厚中心位置を面ごとに比較し、両位置が局所数値公差1×10⁻⁶ mm以内で一致する標準形式だけを適用します。片側梁は保持し、直交梁を左右の比較相手にしません。150 mmの梁せい差による許容判定はありません。梁の一律鉛直偏心を含む実材軸端の高さで比較します。未指定偏心を0へ補わず、同じ断面でも異なる偏心によりフランジがずれれば段違いとして拒否します。端別偏心の入力や梁天端への自動調整は行いません。

段違い・未対応面を含む接合部は、標準パネル要素を自動生成せず、節点・検討面・梁ID・両db・上下位置差を通知します。自動生成しない場合はパネル分のオフセットを残しません。これはせん断変形をモデル化できない制限であり、剛接合の妥当性を確認した結果ではありません。フェイス応力評価位置・手動剛域は個別の設定条件を保持します。古い/明示パネルも同じ幾何制限を受け、条件を満たさない場合は理由付きエラーで解析を停止します。未対応接合を剛パネルへ置き換えて解析成功にはしません。

保存結果を開いた際も標準形式の適用条件を確認します。対象外の面を算定済みとしている結果や、未算定理由を確認できない結果は利用できません。画面の案内で対象面・位置差などの理由を確認し、必要な入力を修正して解析・検定を再実行してください。対応する標準形式の結果と、未算定方向・理由を正しく記録した結果は保持します。モデル編集後の古い応力を、現在の接合部の再検定へ流用できません。

架構の解析成果や仕口パネルの算定済み結果を使わない床板だけの直接検定は、この制限の対象外です。床板の自重・材料など、直接検定に必要な入力は別途確認します。

断面検定は元の梁構面の標準形式を確認し、柱の強軸・弱軸へ需要を集約します。同じ主軸へ寄与する構面間の上下フランジ位置が一致しない方向は「検定不能」とし、独立する整列直交方向の標準形式検定は保持します。解析のパネルモーメントを用いる場合、解析の共通最大dbと検定方向の高さが異なる方向も、その方向は未算定です。未算定を含む節点の検定比図は「未算定」を表示し、適合色にはしません。CSV帳票でも未算定方向・理由を保持します。詳しい適用条件は[S 造柱梁接合部](../calc_basis/06_一次設計/03_鋼構造_断面検定.md#s-造柱梁接合部)、段違い形式の解除条件は[標準形式の適用範囲](../calc_basis/04_要素剛性/06_パネルゾーン.md)を参照してください。

生成条件と構造種別の判定は、[構造種別の判定](../calc_basis/02_材料/05_構造種別の判定.md)・
[仕口パネル要素](../calc_basis/04_要素剛性/06_パネルゾーン.md)を参照してください。

## モデル化の影響

仕口パネル要素は、柱梁接合部のせん断変形を解析へ組み込みます。仕口パネル要素の寸法に対応するオフセットと
部材端の剛域は、準備計算の「剛域」表と結果タブ「モデル化」のモデル化ビューで確認できます。

せん断変形・剛域・オフセットの算定と解析モデルへの反映は、[仕口パネル要素](../calc_basis/04_要素剛性/06_パネルゾーン.md)・
[ティモシェンコ梁要素](../calc_basis/04_要素剛性/01_ティモシェンコ梁要素.md)を参照してください。

梁端のオフセットは、採用柱の実断面と向き、梁方向から求める接合面までの距離です。非正方柱や柱断面回転を反映し、円形・角形鋼管およびH形柱の外フランジ広面内部へ交わる斜交も、既存入力から面が一意に決まる範囲で扱います。H形柱の弱軸側・フランジ端への接合、交点距離に影響する角Rが未知の角形鋼管などは、対象柱・梁・接合部と理由を示して準備計算・解析を停止します。面距離を推測して続行しません。具体的な面定義・適用条件は[部材端の接合面とオフセット](../calc_basis/04_要素剛性/06_パネルゾーン.md#部材端の接合面とオフセット)を参照してください。

再準備では接合面距離を更新し、モデル化解除・既存の対象外では仕口パネル分の距離を消します。手動剛域長と危険断面位置は独立して保持します。保存距離が現在の形状・向きと一致しない場合は、直接解析を止めて再準備を要求します。

## 断面・材料の割当と表示上の扱い

仕口パネル要素は**断面を割り当てない要素**です。
せん断剛性は取り付く柱・梁の断面から求めた実効体積 Ve によるため、仕口パネル要素自身が
断面を参照する必要がありません。材料は断面が持つため、断面を割り当てない仕口パネル要素は材料も
持ちません。節点バネ・免震支承材・制振ダンパーも同じく、断面ではなく専用の特性値から
剛性を作るため、これらにも断面を割り当てません。

このため、断面・材料の割当を見る次の機能は、いずれも仕口パネル要素を対象から除きます。

| 機能 | 仕口パネル要素の扱い |
| --- | --- |
| 下ドック「診断」タブの断面未割当の警告 | 対象外 |
| 解析前の入力チェック（断面・材料の未割当エラー） | 対象外 |
| ナビゲータの部材グループ（鋼材部材 / RC部材） | 対象外（材種で分類しない） |
| 3D ビューの選択ハイライト | 描かない |

仕口パネル要素は3Dビューの部材線として選択・ホバーできません。寸法とせん断剛性は、準備計算「仕口パネル」タブの一覧で確認してください。

仕口パネル要素は部材タブの部材一覧には種別 `PanelZone` の要素として並び、断面の欄と（断面から引く）材料の欄は
どちらも空欄（`―`）が正しい状態です。ナビゲータの部材グループは仕口パネル要素を数えないため、鋼材部材と
RC部材の合計は部材一覧の行数とは一致しません。

## 断面算定との関係

柱梁接合部の断面算定は、仕口パネル要素のモデル化の有無によらず行います。CFT の柱梁接合部も断面算定の対象です。
検定結果は「設計」タブの「接合部・耐震壁の検定」表と、3D の検定比図（節点上のひし形マーカー）で確認できます。

算定式・係数・対象条件は、一次設計の[RC 断面検定](../calc_basis/06_一次設計/02_RC_断面検定.md)・
[鋼構造 断面検定](../calc_basis/06_一次設計/03_鋼構造_断面検定.md)・
[SRC / CFT 断面検定](../calc_basis/06_一次設計/04_SRC_CFT_断面検定.md)を参照してください。
