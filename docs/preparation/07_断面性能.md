# 断面性能

断面ごとに、符号・階・形状種別・使用部材数・せい D × 幅 B・断面積 \\( A \\)・断面二次モーメント
\\( I\_y \\)・\\( I\_z \\)・ねじり定数 \\( J \\)・せん断有効断面積 \\( A\_{sy} \\)・\\( A\_{sz} \\)・断面二次半径
\\( i\_y = \sqrt{I\_y/A} \\)・\\( i\_z \\)・材料名とヤング係数 \\( E \\) を示します。値は解析に用いる断面諸量
そのもの（形状定義から生成された値、またはカタログ数値の直入力）であり、この表では
再計算しません。表示は cm 系（\\( A \\): cm²、\\( I \\)・\\( J \\): cm⁴）です。

形状定義を持たない断面（数値の直入力）は「数値直入力」と表示します。この断面は
幅厚比・部材ランクの判定、終局耐力の算定、スラブ協力幅による剛性増大の対象外に
なるため、意図した入力かどうかを確認してください。どの部材・床にも割り当てられていない
断面は、使用部材数 0 として淡色で表示します。

材料欄には、断面に割り当てた主材料の名前を示します。
材料は断面が持つため、1 つの断面が複数の材料で使われることはありません。
違う材料を割り当てるなら、それは別の断面になります。

断面は符号と階の組で識別します。
同じ符号の断面が階ごとに並ぶことがあるため、符号だけでなく階も併記しています。
階を持たない断面の階欄は `—` と表示します。
詳細は[断面の符号と階](../model_edit/02_断面の符号と階.md)を参照してください。

算定根拠は [断面諸量（弾性）](../calc_basis/03_断面性能/02_断面諸量.md)・
[せん断有効断面積 As](../calc_basis/03_断面性能/03_せん断有効断面積_As.md)を参照してください。

## 単一リップ溝形の寸法と総断面性能

単一・直角・一様厚のリップ溝形は、外寸のせい H、幅 B、端から測るリップ外寸 C、板厚 t（いずれも mm）を入力します。
H/B/C/t は有限な正値で、**t < C < H/2、t < B/2** が必要です。寸法の許容差による救済は行いません。

角Rを持たない総断面は、次の重複しない5矩形で表します。ここでの y はせい方向、z は幅方向の矩形区間用の補助座標であり、部材局部軸と区別します。

| 部分 | y 区間 [mm] | z 区間 [mm] |
|---|---|---|
| ウェブ | 0～H | 0～t |
| 下フランジ | 0～t | t～B |
| 上フランジ | H−t～H | t～B |
| 下リップ | t～C | B−t～B |
| 上リップ | H−C～H−t | B−t～B |

上下リップ間の開口は H−2C です。C > H/2 では上下リップが重複し、C = H/2 では接触するため拒否します。
B ≤ 2t のウェブとリップの接触・重複、C ≤ t の不成立寸法も拒否します。
この接触拒否は本アプリが対応する単一開断面の範囲であり、規準の寸法上限を示すものではありません。
C の切詰め、微小隙間の補完、閉断面のねじり定数への読み替え、0質量化は行いません。
寸法が有限でも、算定する総断面性能や途中の計算が非有限となる入力は拒否します。

正常寸法の総A/I/Jは従来の直角矩形モデルで算定します。総性能の成立は有効断面・耐力・部材検定の成立を意味しません。
角R、傾斜リップ、孔、有効断面、座屈、接触部の結合はこのモデルの対象外です。
[検討対象と未検定](../calc_basis/06_一次設計/03_鋼構造_断面検定.md#単一リップ溝形材の検討対象と未検定)を参照してください。

形状定義を持つ断面では、性能をすべて直接入力しても不成立寸法を拒否します。形状なしの正常な数値直入力は引き続き使用できます。
断面フォームには寸法と理由を表示し、追加・適用が拒否された場合はモデルや編集履歴を更新しません。
