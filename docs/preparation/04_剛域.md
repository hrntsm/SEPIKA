# 剛域

準備計算を実行し、下ドック「準備計算」の「剛域」を選んで確認します。

剛域長 \\( \lambda \\)、仕口パネル要素のオフセット、または柱フェース距離を持つ梁要素を一覧します。

| 列 | 内容 |
| --- | --- |
| 材長 \\( L \\) | 節点間距離 [mm] |
| \\( \lambda\_i \\) / \\( \lambda\_j \\) | 各端の剛域長 [mm]。括弧内は出所（自動／手動） |
| パネル i/j [mm] | 各端の仕口パネル要素分のオフセット [mm]。仕口パネル要素がない端は 0 |
| 可とう長 \\( L\' \\) | 採用する剛体アーム長を両端から控除した部材中間の長さ [mm] |
| フェース \\( i/j \\) | 柱フェース距離 [mm]（断面算定の危険断面位置の基準） |
| 剛域比 | 剛体アーム長の合計を材長で除した値 |

剛域長 \\( \lambda \\) と仕口パネル要素分のオフセットは別々に表示しますが、「剛域を考慮する」がONなら可とう長と剛域比は両者の大きい方から定まる剛体アーム長に基づきます。OFFでは剛域長を採用せず、仕口パネル分の偏心だけを反映します。フェース距離は断面算定の危険断面位置に用いる別の量です。
構造種別による剛域の条件、壁寸法・耐震スリットの扱い、算定式は
[ティモシェンコ梁要素の剛域](../calc_basis/04_要素剛性/01_ティモシェンコ梁要素.md#剛域)を参照してください。
剛域比が 0.5 を超える部材、可とう長が 0 以下になる部材は、直交部材せいの入力を
確認するため強調表示します。

準備計算の「剛域を考慮する」は建物共通の設定で、既定はONです。ONでは自動・手動の剛域長を剛性と荷重応答に反映します。OFFでは保存済みの剛域長を保持したまま、その力学的効果だけを抑止します。危険断面のフェース位置と仕口パネルの偏心はどちらの設定でも保持します。設定はプロジェクトへ保存され、変更後の旧解析結果は利用できません。

剛域内の部材荷重は、可撓区間の荷重と分けて、当該端節点の力・モーメントへ一度だけ伝達します。剛域内の荷重を捨てる選択肢はありません。OFFでは全長を用いた梁の荷重応答となります。ただし、別設定の仕口パネルがある場合はその接続偏心を反映します。

剛域長には、既定で**取り付く壁**を考慮します。準備計算の「剛域の算定で壁を考慮する」で
原断面のみに切り替えられます。フェース距離には壁を含めないため、この設定を切り替えても
値は変わりません。

部材端の剛域を含む立体形状は、モデル化ビュー（結果タブ「モデル化」）でも確認できます
（[モデル化の表示](../result_view/07_モデル化の表示.md)）。

算定根拠は [ティモシェンコ梁要素](../calc_basis/04_要素剛性/01_ティモシェンコ梁要素.md)を参照してください。
