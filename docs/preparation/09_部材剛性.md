# 部材剛性

準備計算を実行し、下ドック「準備計算」の「部材剛性」を選んで確認します。

断面性能の表（断面単位）では表せない、**部材ごとに決まる**剛性の割増しと SRC/CFT の
等価断面性能を一覧します。H形鋼大梁は、床板の合成剛性を算入しない場合も表示します。

画面の \\( I\_y \\)・\\( I\_z \\) は断面性能表の呼称です。局所曲げ面・変位・回転・断面力との対応と、強軸側・弱軸側という基準呼称の意味は、[断面性能表と要素局所軸の対応](../calc_basis/04_要素剛性/01_ティモシェンコ梁要素.md#保存断面性能と要素局所軸の対応)を参照してください。

| 列 | 内容 |
| --- | --- |
| スラブ | スラブ協力幅（RC 矩形梁の T 形断面）または合成梁（H 形鋼梁）による**強軸曲げ**剛性の増大率 |
| 床板合成の判定 | H形鋼大梁の床板を算入したかどうかと理由。未算定の詳細はカーソルを重ねて確認 |
| 壁上下梁 | 壁エレメントモデルの上下大梁の剛性倍率（軸・曲げ・ねじり・せん断に一律） |
| 元 \\( I\_y \\) | 断面が持つ強軸側の断面二次モーメント |
| 実効 \\( I\_y \\) | 等価換算・上記の割増しをすべて適用した、解析に入る強軸側の曲げ剛性用の値 |
| 総増大率 | 実効 \\( I\_y \\) / 元 \\( I\_y \\) |

断面名に「（等価換算）」が付く部材は SRC/CFT の等価断面性能を用います。行にカーソルを
合わせると、等価断面の \\( A\_{ax} \\)・\\( I\_y \\)・\\( I\_z \\)・\\( J \\)・\\( A\_{sy} \\)・\\( A\_{sz} \\) を確認できます。

実効剛性には、SRC/CFT の等価換算、スラブ協力幅・合成梁、壁エレメント上下大梁の補正が
反映されます。フレーム内雑壁は単一倍率で表せないため、この表の実効 \\( I\_y \\) には含めません。

スラブ協力幅・合成梁の適用結果は「スラブ」列と実効 \\( I\_y \\) に反映され、等価換算の適用結果は
断面名とカーソルで確認できます。

H形鋼大梁にRC床板が接する場合は、モデル編集の「部材」表で「床板合成」を指定します。
頭付きスタッド等による一体化と、梁上端との接触、梁全長にわたる取付き、床の材種と配置を設計者が確認し、
現行の近似を採用できる場合に「現行近似の適用確認済み」を選びます。設計上、合成剛性を採用しない大梁は「非合成」を選びます。
既定は「未確認」です。接合条件や床の材種・配置が変わった場合は指定を見直してください。

鋼床板のみ、床板なし、非合成指定では、それぞれの理由を表示し、スラブ増大率を1とします。
RC床板が接する大梁で接合条件が未確認の場合、該当部材のスラブ増大率・実効剛性は理由付きで未算定となり、解析を保留します。
材料や適用形状を解決できない場合も、未算定理由を確認できます。固定荷重と物理質量の床板算定は、床板合成の指定と独立です。節点集中質量だけの行列組立では接合確認を要しません。採用曲げ剛性を使う整合質量行列の組立や動的解析には、剛性の確定が必要です。
適用条件と平均剛性の詳細は[S造合成梁の強軸曲げ剛性](../calc_basis/04_要素剛性/01_ティモシェンコ梁要素.md#s造合成梁の強軸曲げ剛性)を参照してください。

矩形RC梁の床板協力剛性は、上端を揃えて梁全長を覆う囲まれた床板群の実厚を、左右別に取付長で加重平均して反映します。
この厚さ平均は剛性過大・変形過小となり得る近似です。
版なしは倍率1、床板割当や実配置の未解決、不正寸法、同側重複、全長欠落・版なし混在・幅変化・段差などの適用範囲外は
対象と理由を通知します。入力を修正して準備計算・解析を再実行してください。算定根拠・適用条件は[梁の剛性計算上の付加](../calc_basis/04_要素剛性/01_ティモシェンコ梁要素.md#剛性計算上の付加協力幅壁エレメント上下梁雑壁)を参照してください。

SRC の材料未割当、Fc・Ec・νc の不正、等価性能・必要剛性の非有限値などは理由付きエラーです。準備計算は成功結果を公開せず、解析も停止します。断面形状だけから生成した比15の暫定性能は解析に使いません。材料を修正して再実行してください。

CFT は鋼管とコアの初期弾性性能を累加します。ねじりには供給値を優先した鋼管 Js と、同じ内形のコア Jc を用い、実際の鋼管 Gs による GsJs+GcJc を反映します。
鋼管 G の直接入力は、ねじり・せん断双方の換算に用います。
材料不正、角Rが未知・不正、内法消失、必要な鋼管 J の未算定、コア数値 J の品質未達・資源上限到達は理由付き算定エラーです。
鋼管のみの性能に置き換えて成功表示せず、準備計算の成功結果を公開しません。

断面単位で J だけが未算定の場合、成立する A・Iy・Iz は保持し、J とその理由を分けて示します。
準備計算の「断面性能」表で、J欄の「未算定」にポインタを重ねると理由を確認できます。未算定を0や入力欄に残る数値と読み替えないでください。
J が未算定でも、J を必要としない重量・幾何性能は別に算定できます。
SRC・CFT の入力が成立することは、付着・ひび割れ等を含むモデル精度や安全側の保証とは別です。

算定根拠は [ティモシェンコ梁要素](../calc_basis/04_要素剛性/01_ティモシェンコ梁要素.md)・
[SRC / CFT の等価断面性能](../calc_basis/03_断面性能/06_SRC_CFT_の等価断面性能.md)を参照してください。
