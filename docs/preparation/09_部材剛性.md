# 部材剛性

断面性能の表（断面単位）では表せない、**部材ごとに決まる**剛性の割増しと SRC/CFT の
等価断面性能を一覧します。割増しも等価換算もない部材は、表に載りません。

| 列 | 内容 |
| --- | --- |
| スラブ | スラブ協力幅（RC 矩形梁の T 形断面）または合成梁（H 形鋼梁）による**強軸曲げ**剛性の増大率 |
| 壁上下梁 | 壁エレメントモデルの上下大梁の剛性倍率（軸・曲げ・ねじり・せん断に一律） |
| 元 \\( I\_y \\) | 断面が持つ強軸の断面二次モーメント |
| 実効 \\( I\_y \\) | 等価換算・上記の割増しをすべて適用した、解析に入る強軸曲げ剛性用の値 |
| 総増大率 | 実効 \\( I\_y \\) / 元 \\( I\_y \\) |

断面名に「（等価換算）」が付く部材は SRC/CFT の等価断面性能を用います。行にカーソルを
合わせると、等価断面の \\( A\_{ax} \\)・\\( I\_y \\)・\\( I\_z \\)・\\( J \\)・\\( A\_{sy} \\)・\\( A\_{sz} \\) を確認できます。

実効剛性には、SRC/CFT の等価換算、スラブ協力幅・合成梁、壁エレメント上下大梁の補正が
反映されます。フレーム内雑壁は単一倍率で表せないため、この表の実効 \\( I\_y \\) には含めません。

スラブ協力幅・合成梁の適用結果は「スラブ」列と実効 \\( I\_y \\) に反映され、等価換算の適用結果は
断面名とカーソルで確認できます。

矩形RC梁の床板協力剛性は、上端を揃えて梁全長を覆う囲まれた床板群の実厚を、左右別に取付長で加重平均して反映します。
この厚さ平均は剛性過大・変形過小となり得る近似です。
版なしは倍率1、床板割当や実配置の未解決、不正寸法、同側重複、全長欠落・版なし混在・幅変化・段差などの適用範囲外は
対象と理由を返します。算定根拠・適用条件は[梁の剛性計算上の付加](../calc_basis/04_要素剛性/01_ティモシェンコ梁要素.md#剛性計算上の付加協力幅壁エレメント上下梁雑壁)を参照してください。

SRC の材料未割当、Fc・Ec・νc の不正、等価性能・必要剛性の非有限値などは理由付きエラーです。準備計算は成功結果を公開せず、解析も停止します。断面形状だけから生成した比15の暫定性能は解析に使いません。材料を修正して再実行してください。

CFT は鋼管とコアの初期弾性性能を累加します。ねじりには供給値を優先した鋼管 Js と、同じ内形のコア Jc を用い、実際の鋼管 Gs による GsJs+GcJc を反映します。
鋼管 G の直接入力は、ねじり・せん断双方の換算に用います。
材料不正、角Rが未知・不正、内法消失、必要な鋼管 J の未算定、コア数値 J の品質未達・資源上限到達は理由付き算定エラーです。
鋼管のみの性能に置き換えて成功表示せず、準備計算の成功結果を公開しません。

断面単位で J だけが未算定の場合、成立する A・Iy・Iz は保持し、J とその理由を分けて示します。
公開 JSON の J は `null` とし、未算定理由を返します。0 や保存欄に残る数値で補完しません。
J を必要としない重量・幾何性能の算定には、CFT コアのねじり求解を持ち込みません。
SRC・CFT の入力が成立することは、付着・ひび割れ等を含むモデル精度や安全側の保証とは別です。

算定根拠は [ティモシェンコ梁要素](../calc_basis/04_要素剛性/01_ティモシェンコ梁要素.md)・
[SRC / CFT の等価断面性能](../calc_basis/03_断面性能/06_SRC_CFT_の等価断面性能.md)を参照してください。
