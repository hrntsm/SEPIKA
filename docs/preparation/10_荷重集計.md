# 荷重集計

準備計算を実行し、下ドック「準備計算」の「荷重集計」を選んで確認します。

荷重ケースごとの節点荷重数・部材荷重数と、全体座標系での外力の合計
\\( \Sigma F\_x \\)・\\( \Sigma F\_y \\)・\\( \Sigma F\_z \\) [kN] を示します。部材荷重は、集中荷重はその大きさ、
分布荷重は線荷重を載荷区間で積分した合力を作用方向へ投影して積算します。
これは等価節点力へ置換する前の外力の総和であり、支点反力と釣り合います。

区間の始点・終点を \\(a,b\\) [mm]、両端の線荷重強度を \\(w_1,w_2\\) [N/mm] とすると、線形分布の合力は荷重図の台形面積です。

\\[
w(x)=w_1+\frac{w_2-w_1}{b-a}(x-a),\qquad a\le x\le b
\\]

\\[
W=\int_a^b w(x)\\,dx=\frac{w_1+w_2}{2}(b-a)\quad[\mathrm{N}]
\\]

合力は作用方向の全体座標成分へ投影し、NからkNへ換算（1000で除す）して表示します。
鉛直下向きが負のため、重力系の荷重ケースでは \\(\Sigma F_z\\) が負値になります。
床の面荷重 \\(q\\) [N/mm²] から負担面積 \\(A_e\\) [mm²] を介して得られる辺荷重も、
\\(W_e=qA_e=\int w_e(x)\\,dx\\) [N] として同じ集計へつながります。
面積から線荷重への換算、合力・反力・固定端力の算定の正本は
[床荷重の分配](../calc_basis/01_荷重/03_床荷重の分配.md#分配方法と算定式)を参照してください。

荷重が定義されていない荷重ケースは淡色で表示します。

算定根拠は [積載荷重](../calc_basis/01_荷重/02_積載荷重.md)・
[床荷重の分配](../calc_basis/01_荷重/03_床荷重の分配.md)・
[自重の長期応力解析への接続](../calc_basis/01_荷重/06_自重の長期応力解析への接続.md)・
[床の断面と自重](../calc_basis/01_荷重/08_床の断面と自重.md)を参照してください。
