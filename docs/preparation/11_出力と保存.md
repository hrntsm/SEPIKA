# CSV 出力・プロジェクトファイルへの保存

## CSV 出力

「📋 CSV をコピー」で、建物概要・階の分布・地震力（Ai 分布）・剛域・断面性能・
幅厚比・部材剛性・荷重集計の各セクションを CSV 形式でクリップボードへコピーできます。

準備計算タブで閲覧できる「ねじり解放」「仕口パネル」は、現状 CSV には含まれません。
列構成が他セクションと異なるため、画面上での確認専用としています。

レポートタブの CSV 出力（解析結果を含むレポート）には、未設定の床板・壁版割当領域があるとき
「[未設定の割当領域]」セクションとして未設定件数と対象 ID を床板・壁版別に記載します。
未設定は荷重・剛性を過小評価し得るため、結果を見る前に気づけるようにするためです
（[準備計算](./README.md#未設定の割当領域の扱い)）。

レポートCSVの「検定荷重状態」「検定荷重項」は、選択した単独ケース/保存組合せの対象キー・名称、係数とケース種別、長期/短期/未判定、作用と判定理由を記録します。モデル編集後の結果には要再計算を表示し、法的全条件は未確認です。「小梁・床検定範囲」は固定＋用途別積載の独立した長期略算と、選択短期・積雪・風・地震・任意組合せの未検定範囲を示します。選択した荷重組合せを小梁・床へ適用した検定結果ではありません。

レポートCSVには、[壁版ごとの検定状態](../result_view/06_検定比の表示.md#壁版ごとの検定状態)の壁版・生成要素・荷重ケース・種別・判定・理由と、壁枚数／検定種別ごとの集計を含めます。未検定の検定比および空集合の最大検定比は空欄です。PDF／Excel形式の帳票出力入口は現在ありません。

## プロジェクトファイルへの保存

準備結果・本案の解析と検定・解析設定・検討の保持計算は、種類ごとの条件で保存・復元します。
本案の現在有効な結果と計算時入力付きの履歴は区別し、検討の全保持計算は本案結果の最新性と独立して保存します。
保存できる条件、動的ケースの扱い、再実行が必要な条件は
[OVIKAの保存対象と再読込](../model_io/01_プロジェクト形式_ovika.md#保存対象と再読込)を正本とします。
