# 外部AI連携（MCP）

開いているGUIの検討へ外部AIクライアントを接続し、計算根拠の確認や断面の比較案作成を依頼できます。接続にはModel Context Protocol（MCP）に対応したクライアントと `sepika-mcp.exe` を使います。GUIへのローカル接続はWindowsで利用できます。

まず[接続と承認](01_ビルドと起動.md)で依頼を保存し、[クライアント設定例](02_クライアント設定例.md)に従って接続します。許可する前に、[共有範囲と制約](05_制約・注意点.md)を確認してください。

| 接続方式 | 対象と用途 |
| --- | --- |
| GUI接続 | GUIで許可した検討の基準案・比較案を共有し、人が権限と採否を確認します。本章の操作手順はこちらです |
| 独立サーバ | 起動時に指定したOVIKAのモデル、または空モデルを別に扱います。GUIの検討・モデル・保持結果とは共有しません |

独立サーバのビルド・起動・設定・公開ツールとAPI契約は[開発者向け仕様](https://github.com/hrntsm/SEPIKA/blob/main/dev_docs/mcp_server.md)を参照してください。独立サーバの「起動時のみモデルを読み込む」「モデル保存ツールがない」「一部の解析結果しか永続化しない」という制約はGUI接続の保存・操作には適用しません。
