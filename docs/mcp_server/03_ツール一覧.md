# 依頼できる操作

## 開いているGUIへの接続

許可した検討の根拠確認と、固定した鉄骨大梁の断面比較を依頼できます。接続許可と依頼の両方で認められた範囲だけを操作します。

| 依頼・確認 | 利用できる内容 |
| --- | --- |
| 入力と条件の確認 | 検討、基準案・比較案、固定対象、解析・検定条件、全体モデルと有効候補断面 |
| 根拠の閲覧 | 保持計算の一覧、計算時の入力、変位・内力・検定の数値と図表参照、詳細検定 |
| 比較案の作成・編集 | 基準案から比較案を作成し、固定した鉄骨大梁へ既存の有効断面を割り当てる |
| 計算 | 固定条件で既存計算を実行し、進行や確認待ちを照会する |
| 差と数量の確認 | 断面変更、固定対象の鋼材数量とその根拠、全体数量の未算定理由 |
| 成果提出 | 対象入力、計算結果の根拠、説明と未確認事項を提出する。説明・数量だけの提出も可能 |
| 通信の受理確認 | 応答を失った要求について、受理された内容と結果を確認する |

確認のみの依頼は比較案を作らず、根拠の閲覧と説明の提出で完了できます。編集・計算の許可を与えても、本案更新や採用を外部AIへ委ねることはできません。[対応範囲](05_制約・注意点.md)を参照してください。

一覧や数値は分割して取得します。省略されたページだけで全件を確認したと扱わず、対象・計算条件・単位・省略の有無を確認してください。過去の計算済み記録が一覧にあることと、その数値が現在利用可能であることは別です。

依頼の作成と成果からの採否操作は[断面案の検討](../section_study/01_断面案の検討.md#外部aiからの参照比較)、計算と根拠の判断は[計算と成果の確認](04_解析ジョブと結果取得.md)を参照してください。
