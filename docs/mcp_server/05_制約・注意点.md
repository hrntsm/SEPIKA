# 制約・注意点

## GUI接続の共有と許可

GUIで許可した検討の基準・比較案の全体モデル、条件、有効候補断面、保持結果を読み取れます。固定対象以外の節点・部材・材料等も含まれ、「選択部材だけの共有」ではありません。編集は比較案の固定鉄骨大梁への既存有効断面の割当だけです。本案更新、最終採用、任意ファイル操作、任意コード実行、警告の承諾、計算取消は公開しません。

ローカル通信でも、外部クライアントがクラウドAIを利用すれば取得した情報が外部送信され得ます。クライアント側の保存・送信はSEPIKAの管理範囲外です。

確認のみで開始した依頼に対する作成・編集・計算は拒否します。別案、古い入力版、無効対象、許可範囲外の更新も理由付きで拒否し、現在選択へ読み替えません。保存済み旧版の閲覧はGUIで許可され、保存入力版を明示した場合に限ります。数値は条件・単位・対象範囲とともに取得し、省略されたページを全件の根拠にしないでください。全体集計はSEPIKAが保持する全対象から生成した値です。確認済みNGと未検定は併存し、未計算・欠落・不正を0や合格へ置き換えません。

計算の続行確認が必要な場合はGUIで確認待ちになり、AIは承諾できません。接続解除・GUI終了・モデル差替後は新規要求を受け付けません。切断しても受理済み計算は停止しません。再読込で接続許可を復活させず、未完了計算を自動再開しません。

応答を失った場合は受理結果を推定せず、再接続・GUI再承認後に要求IDを照会してください。同じ受理済みID・同じ内容の再送は元の受理結果を返し、同じIDの内容違いは拒否します。成果と受理台帳は検討とともに保存されます。接続許可は保存されません。

- **モデルの読み込みは起動時引数のみ**。`.ovika` ファイルパスをコマンドライン引数として渡す方法しかなく、実行中にモデルを差し替えたり読み込んだりする `model.load` のような MCP ツールは存在しません。ST-Bridge ファイルを直接渡すことはできないため、GUI で ST-Bridge を読み込み、`.ovika` として保存してから、そのファイルパスを MCP サーバに渡してください。保存（`model.save`）と計算書出力（`report.export`）も未公開です。
- **編集は `model_edit` で壁版・床板・床領域・壁領域・二次部材（未割当を含む）に限る**。壁版 9 コマンド、床板 10 コマンド（囲まれた床板は任意境界ではなく床板割当領域 `region` への割当で作る）、床領域 2 コマンド、二次部材 4 コマンド（配置・移動・削除・端部支持条件）、壁領域 1 コマンド、未割当 4 コマンドを GUI と同じ Undo 経路で適用します。節点・部材・荷重など他の編集コマンド、および実行中のモデル差し替えは公開していません。存在しない対象など通常の参照不成立は `applied: false`（Noop）になります。割当境界の衝突・版の重複割当・未確認の旧版除去は、モデル・履歴が未更新であることと理由を返します（[二次部材の編集確認](03_ツール一覧.md#二次部材の配置移動削除3)）。未対応のコマンド名や必須キーの欠落はエラーになります。
- **主架構線材は異なる2節点のみ対応**。`Beam`・`Fiber`・`MultiSpring`・`Brace` の0・1・3節点以上と同一NodeId二重指定は、`quantity_takeoff` で `status=unavailable`・`totals=null`、`analysis_run` で入力不正の失敗となります。ElemId・kind・実節点数・期待2・入力NodeId列を含む同じ診断を返します。床接触や断面割当の有無によらず拒否し、先頭2節点の採用・自動分割はしません。起動時OVIKA読込も同じ条件です。
- 質点系解析は GUI の右バーからのみ実行できます。`analysis_run` の `kind` には含まれません。
- `Pushover`・`TimeHistory`・`UltimateCheck` ジョブは結果ストアへ書き込みません。対応する結果スキーマがない、あるいはスキーマが要求する粒度（全節点×全ステップ）のデータを持たないため、結果は `analysis_status` の `result_ref`（サマリ JSON）としてのみ得られます。
- `DesignCheck`の検定結果（OK/NG・検定比）はサマリのみです。単独ケースの`MemberForce`は結果ストアへ保存します。保存組合せ・自動G+P+Kは`case: null`・`store.persisted: false`で、組合せ内力もサマリのみです。`analysis_status`の`status.Done.result_ref`をJSON文字列として解析し、`member_forces`と`load_target`を取得してください。内力は最大10,000行（`truncated`/`total_rows`で省略を確認）、サーバープロセス中だけ保持し、`result_get`/永続化/ページ取得は未対応です。
- 未設定の床板・壁版割当領域は、前処理の注意事項（`notices`）に件数と対象 ID を記します。矩形RC/SRC大梁が支持する床板の割当が未設定の場合は、[実重複控除](../calc_basis/01_荷重/06_自重の長期応力解析への接続.md#矩形rcsrc大梁と床板の実重複控除)を確定できないため停止します。それ以外の未設定は警告を添えて続行しますが、床荷重・躯体自重と壁の剛性が解析に入らず応力・変形を過小評価し得るため、解消後に採用してください（GUI では計算前に続行確認を挟みます）。

DesignCheckの`load_target`は、保存組合せ・自動G+P合成・単独ケースを区別します。未判定の継続時間は`term: null`、必要応力の解析失敗は入力不備となり、部分成功で合格を返しません。`legal_conditions_verified: false`は地域指定・風時実況等の法的適用条件を自動確認していないことを示します。小梁・床の長期略算はGUIで別計算し、MCPの主架構サマリには含めません。
