# 共有範囲と制約

## GUI接続の共有と許可

GUIで許可した検討の基準案・比較案の全体モデル、条件、有効候補断面、保持結果を読み取れます。固定対象以外の節点・部材・材料等も含むため、「選択部材だけの共有」ではありません。

ローカル通信でも、外部クライアントがクラウドAIを利用すれば取得した情報が外部送信され得ます。クライアント側の保存・送信はSEPIKAの管理範囲外です。

| 操作 | GUI接続の範囲 |
| --- | --- |
| 確認のみ | 許可した入力・根拠の閲覧と説明提出。比較案の作成・編集・計算は拒否 |
| 比較案の編集 | 許可した比較案の固定鉄骨大梁へ既存有効断面を割り当てる。別案・古い入力・無効対象・範囲外の更新は拒否 |
| 保存旧版の閲覧 | 接続ごとにGUIで別途許可し、対象の保存入力を明示した場合のみ。現在選択への読み替えや旧版の編集は行わない |
| 計算の続行確認 | GUIで人が判断。AIによる警告の承諾は不可 |
| 本案更新・最終採用 | 人がGUIで実行。外部AIへ公開しない |
| その他 | 任意ファイル操作、任意コード実行、計算取消は公開しない |

計算と提出の利用条件、固定数量と全体数量の違いは[計算と成果の確認](04_解析ジョブと結果取得.md)を参照してください。接続を許可しても、未検定を合格と認定したり、法的適用条件を自動確認したりするものではありません。

## 通信が途切れたとき

応答を失った場合は受理結果を推定せず、GUIで再有効化して新しい接続先へ接続し、新規承認後に元の要求IDの受理内容を照会してください。応答のIDが要求と一致しない場合も、成功扱いせず接続を終了します。

同じ受理済みIDで同じ内容を再送すると最初の受理結果を返し、内容を変えた再送は拒否します。最新の計算状態を確認する場合はクライアントから新しい要求IDで照会します。過去の変更を再送する代わりに、その変更の受理記録を照会してください。

保存応答の再送・受理照会でも、現在の権限と元の根拠の有効性を確認します。再接続時に旧版閲覧を許可しなければ、以前許可した旧版の保存応答も返しません。元の計算根拠が失効した応答を利用可能な結果として返すこともありません。確認のみ接続から変更要求を再送することもできません。

承認後は参照や状態照会も要求・応答を記録するため、取得回数と応答量に応じて検討を含むOVIKAの容量が増えます。受理記録は自動で間引きません。数量だけの提出で保持した固定数量の根拠も、その元の案を削除できない保持根拠になります。

## 計算上の不足と未対応

外部AIから依頼しても、元のGUI計算の適用範囲や近似・未対応は変わりません。数値は対象範囲・単位・条件をそろえて確認し、省略されたページを全件の根拠にしないでください。全体集計はSEPIKAが保持する全対象から生成します。

未設定の床板・壁版割当領域は、床荷重・躯体自重や壁の剛性が解析に入らず、応力・変形を過小評価し得ます。GUIの続行確認を承諾しても不足が解消するわけではありません。矩形RC/SRC大梁が支持する床板割当が未設定の場合は[実重複控除](../calc_basis/01_荷重/06_自重の長期応力解析への接続.md#矩形rcsrc大梁と床板の実重複控除)を確定できず停止します。それ以外の未設定で続行できても、解消後の結果を採用してください。

比較の検定集計は既存検定の算定済み範囲です。床板・二次部材の設計、未実行ケース、動的・終局・保有耐力は集計外であり、設計全体の確認完了ではありません。詳細は[全体への影響と未評価範囲](../section_study/01_断面案の検討.md#全体への影響と未評価範囲)を参照してください。

## 独立サーバ固有の制約

独立サーバは起動時のOVIKAまたは空モデルを扱い、実行中のモデル差替え、モデル保存、計算書出力を公開しません。編集範囲・解析の既定条件・サマリと永続化の対応範囲は[独立起動のモデル入力制約](https://github.com/hrntsm/SEPIKA/blob/main/dev_docs/mcp_server.md#独立起動のモデル入力制約)と[ツール契約](https://github.com/hrntsm/SEPIKA/blob/main/dev_docs/mcp_server.md#独立起動ツール契約)を参照してください。独立サーバの時刻歴はサンプル波、プッシュオーバーには固定の載荷条件があるため、GUIで指定した波形・設定と同じ計算とみなさないでください。
