# 接続と承認

## 開いているGUIの検討への接続

1. WindowsのGUIで「検討・設計案」を開き、検討を作成します。「図・表・結果からAIへ依頼」で目的、対象、計算条件を確認し、未開始の依頼を保存して依頼文をコピーします。根拠だけの確認では「根拠の確認のみ」を選びます。対象を固定する操作は[断面案の検討](../section_study/01_断面案の検討.md#外部aiからの参照比較)を参照してください。
2. 「外部AIへのローカル接続」を開き、「ローカル接続を有効化」を選びます。「MCP起動引数をコピー」で表示中の接続先を取得します。
3. 外部MCPクライアントへ `sepika-mcp.exe` とコピーした起動引数を設定します。[設定例](02_クライアント設定例.md)を参照してください。GUIと同じWindowsログオンから起動します。

```powershell
sepika-mcp.exe --gui-pipe \\.\pipe\sepika-gui-表示された識別
```

4. 外部クライアントから接続確認を行います。GUIの承認待ちクライアント、対象検討、編集・計算の許可、保存旧版の閲覧許可を確認し、「このクライアントと対象検討を確認して許可」を選びます。有効化しただけでは検討を操作できません。
5. コピーした依頼文をクライアントへ渡します。接続確認・依頼開始・計算・成果提出は別の操作です。「AIへの依頼一覧・成果」で実際の受理と進行を確認してください。

「比較案の作成・断面割当・既存計算を許可」を選ばない接続は確認のみです。依頼自体が確認のみの場合も、比較案の作成・編集・計算は行えません。保存旧版の明示閲覧は別の許可であり、旧版の編集を許可するものではありません。[共有範囲と制約](05_制約・注意点.md)を確認してください。

## 終了と再接続

GUIの「接続を解除」、クライアント切断、GUI終了、モデル差替後は、新規要求を受け付けません。切断しても受理済み計算は停止しません。

再接続はGUIで「ローカル接続を有効化」を選び直し、新しく表示された起動引数でクライアントを起動し、再承認します。以前の接続先・許可は再使用できません。再読込でも接続許可を復活させず、未完了計算を自動再開しません。

応答が途切れた場合は、変更が失敗・成功したと推定せず、再承認後に元の要求IDの受理内容をクライアントから照会してください。同じ要求の再送と、新しい状態の照会の違いは[共有範囲と制約](05_制約・注意点.md#通信が途切れたとき)を参照してください。

## 実行ファイルを用意する場合

ソースからビルドする場合は次のコマンドを使います。Windowsの生成先は `target/debug/sepika-mcp.exe`（`--release` 付きでは `target/release/sepika-mcp.exe`）です。

```bash
cargo build -p sepika-mcp --features mcp
```

`mcp` は非デフォルトの機能です。`sepika-mcp` 以外へ指定したり、省略して起動バイナリを作ろうとすると実行できません。独立したモデルを起動する場合は[開発者向けのビルドと独立起動](https://github.com/hrntsm/SEPIKA/blob/main/dev_docs/mcp_server.md#ビルドと独立起動)を参照してください。GUI接続ではモデルファイルや結果保存先を指定しません。
