# ビルドと起動

## 開いているGUIの検討への接続

Windowsで利用できます。GUIの「検討・設計案」で検討を作り、「外部AIへのローカル接続」を開きます。「ローカル接続を有効化」を選び、表示される起動引数を外部クライアントへ渡してください。

```powershell
sepika-mcp.exe --gui-pipe \\.\pipe\sepika-gui-表示された識別
```

GUIと同じWindowsログオンから起動します。外部クライアントで接続確認を行うと、GUIに承認待ちクライアントが表示されます。対象検討、確認のみ／比較案の作成・編集・計算、保存旧版の閲覧許可を確認し、「このクライアントと対象検討を確認して許可」を選びます。接続先を有効化しただけでは検討を操作できません。

クライアントを切断すると、その接続先と許可を終了します。再接続する場合はGUIで再び「ローカル接続を有効化」を選び、新しく表示された起動引数でMCPブリッジを起動し、新規承認してください。以前の接続先・許可は再使用できません。受理済み計算は切断で停止しません。

この方式は開いているGUIが保持する検討を操作します。モデルファイルや結果ストアの指定は不要です。起動ファイルを別に読み込む独立起動のモデルとは共有しません。接続確認、依頼開始、計算、成果提出は別の操作です。確認のみの依頼は、比較案を作らず根拠の閲覧と説明提出で完了できます。

## 独立したモデルでの起動

```bash
# ビルドのみ（バイナリは target/debug/sepika-mcp に生成される。
# --release 付きなら target/release/sepika-mcp）
cargo build -p sepika-mcp --features mcp

# モデルファイルを指定して起動
cargo run -p sepika-mcp --features mcp -- model.ovika

# 引数を省略すると空モデルで起動する
cargo run -p sepika-mcp --features mcp
```

- 起動時の第 1 引数がモデルの読み込み元になり、省略時は空モデルで起動します。
- 解析結果ストアのディレクトリは環境変数 `SEPIKA_RESULT_DIR` で指定でき、未設定の場合は OS 一時ディレクトリ配下の `sepika-mcp-results` を使います。

```bash
SEPIKA_RESULT_DIR=/path/to/results cargo run -p sepika-mcp --features mcp -- model.ovika
```

> **注意**: stdout は MCP の JSON-RPC トランスポートそのものです。ログや診断出力を stdout に書くと、クライアントは壊れたフレームとして接続を切断します。

よくあるエラー:

| 状況 | 結果 |
|---|---|
| `--features mcp` を `sepika-mcp` 以外のクレート（例: `-p sepika-app`）に付けて実行する | そのクレートに `mcp` という機能フラグがないためビルドエラーになります |
| `sepika-mcp` を `--features mcp` なしでビルド/実行しようとする | 起動バイナリ自体が `required-features = ["mcp"]` でゲートされているため、バイナリが存在せず実行できません |

モデル入力の形式と制約は[制約・注意点](./05_制約・注意点.md)を参照してください。
