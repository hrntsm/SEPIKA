# 計算と成果の確認

## GUIでの計算と確認待ち

外部AIが計算を依頼すると、対象案と入力を固定して既存の計算を実行します。「AIへの依頼一覧・成果」で実行中・確認待ち・失敗等の状態を確認します。警告の続行確認が必要な場合はGUIで人が確認し、AIは承諾できません。受理済み計算の取消には対応していません。

計算中の案にはAIから断面を割り当てられません。他の比較案は操作できます。計算が完了すると、開始した案と入力に結果を保持します。計算の実行と失敗原因の確認は[準備・解析の実行・結果の確認](../workflow/README.md)、比較案の操作は[断面案の検討](../section_study/01_断面案の検討.md#計算と結果の確認)を参照してください。

## 提出された根拠を確認する

1. 「AIへの依頼一覧・成果」で、対象案・固定対象・入力・計算条件、AIの説明、未確認事項を確認します。接続や依頼文のコピーだけでは依頼開始・成果提出になりません。
2. 計算結果を添えた提出では、選択した一つの保持計算と、その計算の根拠を確認します。同じ入力の別計算が後から終わっても、提出時の状態や検定集計を置き換えません。説明・数量だけの提出には、計算結果や検定集計を自動で補いません。
3. 根拠から計算時入力、対象の部材・位置・ケース、条件・単位を確認します。変位はmm、固定鋼材の体積はm³、検定比は無次元です。内力・詳細の値は各応答の単位表示を確認してください。図表の読み方は[数値から計算時の根拠を確認する](../result_view/README.md#数値から計算時の根拠を確認する)を参照してください。
4. 未計算・未検定・不正・欠落を0や合格に置き換えず、変更外の部材や未評価範囲への影響も確認します。[比較と採否](../section_study/01_断面案の検討.md#変更と計算結果の比較)に従い、人が採否を判断します。

成果提出、計算成功、検定結果、人による採用は別です。AIの説明に「完了」「合格」とあっても計算・検定状態は変わりません。必要な検定根拠が取得不能なら全範囲の件数も取得不能です。「部分集計」は取得できた根拠だけの件数であり、部材本数とは異なります。確認済みNGと未検定は併存します。

固定したS造部材の鋼材数量は、固定入力の実断面積と節点間材長から集計します。他部材の型枠等が未確定なら全体数量の未算定理由を併記します。固定鋼材の取得・提出が成功しても、全体数量の算定成功ではありません。不正・欠落した対象の数量を0で補いません。

## 保持結果の閲覧と保存

保存後の新しい接続でも、許可した案の保持計算から計算時入力と根拠を確認できます。旧版閲覧を許可しない接続は現在入力に対応する計算だけ、許可した接続は明示した保存旧版も閲覧できます。計算済みの記録が残っていても、現在利用可能な数値や検定合格・採用を保証しません。

現在のモデル・計算条件・計算版に対応しない結果は、現在入力の設計根拠として採用せず、対象の解析・検定を再実行してください。保存し直し、Undo、表示切替、別種別の再計算だけで過去結果の入力・版・欠落を補完しません。

検討の成果と受理記録は検討とともにOVIKAへ保存します。検討の各案・全保持計算は本案結果の保存条件とは分けて扱います。接続許可は保存しません。保存対象・履歴と現在結果の区別は[プロジェクト形式](../model_io/01_プロジェクト形式_ovika.md)、検討の操作は[保存](../section_study/01_断面案の検討.md#保存)を参照してください。完了済みの保持結果を保存・再読込しても「中断・結果なし」へ置き換えません。未完了計算は再読込で自動再開せず、実行処理の失敗は理由付き失敗として区別します。

## 独立サーバの結果取得

独立サーバでは計算の非同期実行、状態照会、対応する明細の取得を行います。保存可能な明細、サマリだけで得られる結果、行数制限、生成条件・版・保存ファイルの検査は[ジョブと結果取得](https://github.com/hrntsm/SEPIKA/blob/main/dev_docs/mcp_server.md#ジョブと結果取得)を参照してください。GUIの保持計算と同じ保存先や取得方法ではありません。
