# クライアント設定例

## 開いているGUIへ接続する場合

MCPクライアントのサーバ設定へ実行ファイルと起動引数を登録します。接続先は有効化するたびに変わるため、GUIからコピーした値で置き換えます。JSON内ではバックスラッシュをエスケープします。

```json
{
  "mcpServers": {
    "sepika-gui": {
      "command": "C:\\path\\sepika-mcp.exe",
      "args": ["--gui-pipe", "\\\\.\\pipe\\sepika-gui-表示された識別"]
    }
  }
}
```

Claude Codeのコマンドで登録する場合の例です。既存の登録を更新する場合も、GUIの現在の接続先に合わせます。

```powershell
claude mcp add sepika-gui -- C:\path\sepika-mcp.exe --gui-pipe \\.\pipe\sepika-gui-表示された識別
```

Claude Codeではプロジェクトの `.mcp.json`、Claude Desktopでは `claude_desktop_config.json` の `mcpServers` に上記のGUI接続設定を記載します。実行ファイルのパスは手元の配置へ置き換えてください。

接続後はGUIの[承認手順](01_ビルドと起動.md#開いているguiの検討への接続)へ戻り、対象検討と権限を確認して依頼文を渡します。再接続の際も接続先の更新と再承認が必要です。

## 独立サーバを利用する場合

モデルファイルを引数にする設定はGUI接続とは異なります。独立サーバ用のClaude Code・Claude Desktopの設定と `SEPIKA_RESULT_DIR` は[独立起動クライアント設定](https://github.com/hrntsm/SEPIKA/blob/main/dev_docs/mcp_server.md#独立起動クライアント設定)を参照してください。
