# クライアント設定例

## 開いているGUIへ接続する場合

GUIの接続案内を使い、クライアントの起動引数を次のように指定します。接続先は有効化するたびに変わるため、GUIに表示された値で置き換えます。

```json
{
  "mcpServers": {
    "sepika-gui": {
      "command": "C:\\path\\sepika-mcp.exe",
      "args": ["--gui-pipe", "\\\\.\\pipe\\sepika-gui-表示された識別"]
    }
  }
}
```

クライアントの接続確認後、GUIで対象検討と権限を許可してください。以下のファイル指定例は独立起動の設定です。

## Claude Code

```bash
claude mcp add sepika -- /path/to/sepika-mcp model.ovika
```

もしくはプロジェクトの `.mcp.json` に登録します。

```json
{
  "mcpServers": {
    "sepika": {
      "command": "/path/to/sepika-mcp",
      "args": ["model.ovika"]
    }
  }
}
```

## Claude Desktop

`claude_desktop_config.json` に以下のエントリを追加します。

```json
{
  "mcpServers": {
    "sepika": {
      "command": "/path/to/sepika-mcp",
      "args": ["model.ovika"],
      "env": {
        "SEPIKA_RESULT_DIR": "/path/to/results"
      }
    }
  }
}
```
