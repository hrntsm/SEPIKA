# モデル入出力（ファイル形式）

構造モデルの保存・読込には OVIKA（`.ovika`）を使います。GUI のファイルメニューから操作できます。読込に失敗した場合は、現在のモデルを保持します。

<div class="impl-ref">

**実装参照**：`.ovika` は `sepika_io::ovika`（`save_ovika` / `load_ovika`、`crates/sepika-io/src/ovika.rs`）が入出力を担います。

</div>

本案の有効な結果・過去履歴・検討の保持計算は保存条件が異なります。[OVIKAの保存対象と再読込](01_プロジェクト形式_ovika.md#保存対象と再読込)を確認してください。外部波形は別途管理します。
