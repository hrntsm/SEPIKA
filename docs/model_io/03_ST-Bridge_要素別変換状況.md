# ST-Bridge 要素別 変換状況一覧

ST-Bridge の主要要素ごとの変換状況です。
凡例: **✅ 対応** ／ **⚠️ 一部・近似** ／ **❌ 非対応**。
「読込」「書出」は対応の有無、「再読込」は読込→書出→再読込で残る情報・失われる情報を示します。最後の列は保持条件や解析で使う際の制限です。✅は要素内の全属性・全形状への対応を意味しません。

**保存可能と解析・検定可能は別です。** 配筋・強度・壁版などは保存できても、解析前チェックや検定で停止する場合があります。解析適用は各節の制限と、リンク先の計算条件で確認してください。

対応範囲の考え方と非対応項目の扱いは [ST-Bridge 形式（.stb / .xml）](./02_ST-Bridge_形式.md)を参照してください。
本表は要素の単位でまとめたものです。
属性の単位では、取り込んだファイルに存在した属性の扱いを
すべて取り込み時に報告します（[属性の扱いの報告](./02_ST-Bridge_形式.md#属性の扱いの報告)）。

書き出しは開発中で、一部の形状・属性・断面性能を正しく出力できない場合があります。
出力内容は利用先で確認してください。モデルの保存にはOVIKAを使用してください。
「ファイル」メニューの「ST-Bridge 書出（開発中）…」の直下にも、この説明を表示します。

書き出しは ST-Bridge 2.0.2 の標準要素を用いる 1 形式で、断面の表現を選ぶモードはありません。
全体のスキーマ適合は未完了です。対応範囲と制限は上記の ST-Bridge 形式を参照してください。
標準要素で表せない断面だけが、物性を直接持つ拡張要素 `StbSecRaw` へ落ちます。`StbSecRaw` は取り込み対象ではなく、この出力の再読込は保証しません。
原階・節点は標準の元 ID/GUID を保持して再出力します。断面・部材の番号や符号の完全な保存を意味しません。

<div class="impl-ref">

**実装参照**：書き出しは `sepika_io::stbridge::export_stbridge`（`crates/sepika-io/src/stbridge/export.rs`）が担います。表現限界による近似・切り捨ての警告は `export_stbridge_with_report` が返します。取り込みは節ごとに入口を示します。

</div>

## 部材

### 断面参照の系列対応

取り込み時は、部材要素と `kind_structure` から次の具体的な断面系列を選び、同じ系列の数値IDへ結びます。
柱と間柱、大梁と小梁はそれぞれ系列を共有します。

| 部材要素 | `kind_structure` | 要求する断面系列 |
|---|---|---|
| `StbColumn` / `StbPost` | RC / S / SRC / CFT | `StbSecColumn_RC` / `StbSecColumn_S` / `StbSecColumn_SRC` / `StbSecColumn_CFT` |
| `StbGirder` / `StbBeam` | RC / S / SRC | `StbSecBeam_RC` / `StbSecBeam_S` / `StbSecBeam_SRC` |
| 上記の柱・間柱・大梁・小梁 | UNDEFINED | `StbSecUndefined`（未対応） |
| `StbBrace` | S | `StbSecBrace_S` |
| `StbSlab` | RC / DECK / PRECAST | `StbSecSlab_RC` / `StbSecSlabDeck` / `StbSecSlabPrecast`（PRECASTは未対応） |
| `StbWall` | RC | `StbSecWall_RC` |

系列の選択と、形状・用途の対応可否は別です。例えばCFTの系列が存在しても、二次部材への使用は下表の用途制限に従います。
ブレースのRC/SRCは対応系列を創作せず、未対応の構造種別として拒否します。
UNDEFINEDやPRECASTは、要求系列の定義がなければ参照先欠落、定義があれば未対応として診断します。未対応形状を別系列の同IDへ読み替えません。
同系列の重複IDは、その形状が未対応でも拒否します。
名前空間と数値IDの制約、参照不正時の扱いは[断面系列と数値ID](02_ST-Bridge_形式.md#断面系列と数値id)を参照してください。

| ST-Bridge 要素 | 読込 | 書出 | 再読込での保持・欠落・近似 | 保持条件・解析への適用と確認 |
|---|:--:|:--:|---|---|
| `StbColumn`（柱） | ✅ | ✅ | 用途・回転・接合条件を保持。偏心は欠落 | `StbSecColumn_*` を参照する。角度によらず柱用途として扱い、`rotate`・`condition_bottom`/`_top` を読む。端部の偏心 `offset_*` は対象外 |
| `StbGirder`（大梁） | ✅ | ✅ | 用途・回転・接合条件を保持。偏心は欠落 | `StbSecBeam_*` を参照する。角度によらず大梁用途として扱い、`rotate`・`condition_start`/`_end` を読む。端部の偏心 `offset_*` は対象外 |
| `StbBeam`（小梁） | ✅ | ✅ | 端点一致等の出力条件を満たす範囲 | `StbSecBeam_*` を参照する二次部材。床荷重・自重を支持先へ伝達する。支持条件・確認先は[小梁の支持と荷重伝達](#小梁の支持と荷重伝達) |
| `StbPost`（間柱） | ✅ | ✅ | 端点一致等の出力条件を満たす範囲。端部負担率は欠落 | `StbSecColumn_*` を参照する二次部材。節点は標準の `id_node_bottom`/`id_node_top`。端点がモデル節点に一致しない場合の書き出し制限は小梁と同じ |
| `StbBrace`（ブレース） | ✅ | ✅ | 対応断面の範囲。引張専用等の条件を確認 | 標準断面は `StbSecBrace_*` を参照する。書き出しで標準要素に表せない断面は `StbSecRaw` へフォールバックするが、その再読込は保証しない。`feature_brace` を読み、`TENSIONANDCOMPRESSION` 以外は引張専用とする。両端ピンで取り込む |
| `StbSlab`（スラブ） | ✅ | ⚠️ | 再構築後の囲まれた版のみ。元形状・荷重・用途は保持しない | 境界節点ループ＋断面参照。仕上げ・積載・用途は読まず、分配法は三角形・台形分配。再構築条件と補う入力は[床の形状と荷重](#床の形状と荷重) |
| `StbWall`（壁） | ✅ | ✅ | 囲まれた版のみ。取付き・開口・面荷重・負担率は欠落 | 境界節点ループ＋断面参照。解析要素の有無と自重伝達は別に確認する。[壁の形状と荷重伝達](#壁の形状と荷重伝達)を参照 |
| 部材の符号（`name`） | ⚠️ | ⚠️ | 主架構の元符号は欠落。自動命名 | 取り込みで符号を保つのは二次部材（小梁・間柱）のみ。書き出しは `C1`・`G1`・`BR1` のような自動命名になるため、符号は往復しない |
| `StbFooting` / `StbPile` / `StbFoundationColumn` / `StbStripFooting`（基礎系） | ❌ | ❌ | 保持しない | 取り込み時に警告 |
| `StbParapet` / `StbOpen`（パラペット・開口） | ❌ | ❌ | 保持しない | 取り込み時に警告 |

### 小梁の支持と荷重伝達

小梁は二次部材として取り込みます。全体解析の線材要素にはせず、床荷重と自重を支持先へ伝え、最終的に大梁への集中荷重（CMQ）として扱います。
取り込み後は「床」タブの小梁（二次部材）一覧に表示され、端部支持条件を設定できる（実部材化済みは除く）。幾何的に支持のない端（節点が実部材に接続せず、大梁の材軸上にも他の二次部材の内法にもない端。許容差 10 mm）は自由端（片持ち小梁）として取り込み、件数と対象を取り込み報告に出す。他の二次部材の端点と一致する端は、自分の反対側の端が主架構に載り、かつ相手の材軸が連続していないときだけ自由端にする。断面検定は [小梁の検定](../calc_basis/06_一次設計/05_小梁・床の断面検定.md#小梁の検定)（二次部材経路。床板分配の線荷重を単純梁または片持ち梁として重ね合わせる）。

支持先を解決できない二次部材は、件数を取込時の通知に出し、端点座標・重量・材軸長を保持します。解析前チェックでエラーにして解析を停止するため、支持部材や端部支持条件を確認・修正してください。

材軸中間へアンカーした二次部材（両端のいずれかが一致するモデル節点を持たない小梁・間柱）は、ST-Bridge が
材端を節点 ID で表すため書き出せません。件数と対象 ID を含むエラーにして書き出し全体を
失敗させ、黙って部材を落としません（ST-Bridge は二次部材の材軸途中の取付きを表現できない）。

### 床の形状と荷重

境界節点ループは `StbNodeIdOrder` のテキスト・CDATA・子要素 `StbNodeId` のいずれも読み取ります。
大梁・小梁から床板割当領域を再構築し、元スラブとの交差面積が正の領域ごとに床板を1枚作ります。
断面と標準強度指定は元スラブから引き継ぎます。同一領域へ異なる断面・元部材強度指定をまとめることはできません。
1辺が大梁に全長載り、自由端が1〜2点の床は、割当領域との交差がない場合に取り付く床板へ変換します。
割当領域に入らない面積が許容差を超えて残り、取り付く床板へも変換できない場合は、未帰属面積と境界節点を含むエラーで取り込み全体を拒否します。

**仕上げ荷重・積載荷重・室用途は元ファイルから取り込みません。** 取り込んだ床板は仕上げ等の面荷重が空、室用途が未指定です。
元ファイルに荷重値があっても、面積比で保持・平均化されるとは扱わないでください。
`kind_slab` と元の分配法も読まず、分配法は三角形・台形分配になります。
躯体自重は荷重の取込とは別に、採用した断面の板厚と材料から算定します
（[床の断面と自重](../calc_basis/01_荷重/08_床の断面と自重.md)）。

取込後は「床」タブで断面・仕上げ等の面荷重・室用途と積載荷重・分配法を照合し、不足分を入力してください。
基準階と鉛直偏心も未入力なので、[床板の鉛直配置](../model_edit/12_床板の入力.md#床板の鉛直配置)を設定します。
[床荷重の分配](../calc_basis/01_荷重/03_床荷重の分配.md)と[積載荷重](../calc_basis/01_荷重/02_積載荷重.md)を確認し、準備計算で重量と荷重伝達先を確認してください。
荷重が不足したままでは、応力・変形・地震用重量を過小評価し得ます。

書き出しは囲まれかつ版がある床板だけで、`kind_slab` は `NORMAL` 固定です。
仕上げ荷重・用途（積載）・分配法・取り付き・版なしは出力せず、元スラブ形状への再結合もしません。これらの保存にはOVIKAを使用します。
床領域の付け直しで、どの床領域にも載らない版・所属の付かない小梁・面積照合できなかった旧床領域があるときも、件数を警告へ出します。

### 壁の形状と荷重伝達

境界節点ループと断面参照（厚さ）を読み、標準強度指定から材料を解決します。
柱・梁・間柱から再構築した壁版割当領域のうち、境界が一致する領域へ壁版を割り当てます。
境界が一致しない壁は取り付く壁版へ自動変換できる場合だけ取り込み、それ以外は境界節点を含むエラーで全体を拒否します。
間柱で分割された複数領域への面積按分は行いません。

解析要素になる条件は[壁エレメントモデル](../calc_basis/04_要素剛性/05_壁エレメントモデル.md)に従います。
解析要素にならない壁版も、自重を分配して地震用重量・「DL」・数量拾いへ算入します
（[地震用重量・層データの生成](../calc_basis/01_荷重/05_地震用重量_層データの生成.md)）。
開口（`StbOpen`）と仕上げ・増打ちの面荷重は取り込まず、面荷重は空になります。
書き出しは囲まれた壁版が対象で、4節点以外も往復しますが、取り付く壁版は往復しません。

囲まれた壁版の自重支持辺の負担率と間柱の端部負担率は、ST-Bridge では取り込み・書き出しを行いません。
取り込んだ間柱の端部負担率は未指定になるため、鉛直な間柱では解析前チェックでエラーになり得ます。
ST-Bridge 取込後は、モデルタブの「壁版」一覧で、解析要素にならない壁版の自重支持辺の負担率と、
「間柱の自重・重力荷重の伝達先」の端部負担率を画面から指定してください
（[壁の断面と自重](../calc_basis/01_荷重/09_壁の断面と自重.md)、[自重の長期応力解析への接続](../calc_basis/01_荷重/06_自重の長期応力解析への接続.md)）。値の保持には `.ovika` を使用します。

壁領域の付け直しでは、主架構だけの壁領域へ所属しない囲まれた壁版と、所属の付かない間柱の件数を警告へ出します。両端支持の二次部材を含む有効な割当領域のある壁版は、所属先がなくても囲まれた壁版とその仕様を保持します。割当領域に一致しない壁を取り込み時に取付き変換する経路とは別です。取付き変換の支持候補は同一レベルの通常の2節点線材に限り、ファイバー要素・マルチスプリング要素は含めません（[変換条件](../calc_basis/01_荷重/09_壁の断面と自重.md#取り付く壁版への自動変換)）。
断面未割当の壁版は、取り込み時に警告します（板厚と材料が決まらず自重を算定できません）。

### 床・壁の境界参照

境界節点の参照先が存在しないスラブ・壁は、取り込み全体を拒否します。頂点が3つに満たないスラブ・壁は、取り込まず警告へ出します。指定された断面参照が存在しない場合も全体を拒否し、断面参照を省略した壁の既存の未割当処理とは区別します。

<div class="impl-ref">

**実装参照**：取り込みは `sepika_io::stbridge::import::assemble::{build_members, build_secondaries, build_slabs, assign_imported_slabs, build_walls}`（`crates/sepika-io/src/stbridge/import/assemble.rs`）、二次部材の支持先解決は `Model::anchorize_secondary_members`（`crates/sepika-core/src/model/secondary.rs`）が担います。

</div>

## 断面 — 共通

断面の階は `floor` 属性として書き出します。階を持たない断面は属性ごと省きます。
ST-Bridge 2.0 の `floor` は省略可能な `xs:string` なので、未設定を空文字列で書き出すと取り込み側で
「階なし」と「階が空文字列」を区別できなくなるためです。属性を省くことで、往復しても符号＋階の
組が保たれます。
部材種別ごとの断面要素は、Girder（大梁）と Beam（小梁）が `StbSecBeam_*`、Column（柱）と
Post（間柱）が `StbSecColumn_*`、Brace（ブレース）が `StbSecBrace_*` です。ここでいう Beam（小梁）は標準部材要素 `StbBeam` の用途分類です。

柱・梁で共有していた断面は、書き出し時に柱用（`StbSecColumn_*`）と梁用（`StbSecBeam_*`）へ
分割されます。二次部材は、同じ断面を参照する場合でも、小梁は梁用、間柱は柱用を参照します。
取り込みでは、柱用と梁用の別系列の断面は、符号・階・形状が同じでも符号を改名して別々に保持します。
異なる数値IDの定義を1件へ統合するのは、同一具体系列・同一符号/階で、断面性能・形状・材料・強度と配筋の元指定がすべて一致する場合に限ります。同系列の同数値ID重複は統合せず拒否します
（[断面の符号と階（取り込み）](./02_ST-Bridge_形式.md#断面の符号と階取り込み)を参照）。

## 断面 — 鋼（形鋼ライブラリ `StbSecSteel`）

形状を保持できても、必要な断面性能が未算定なら解析・検定には使用できません。特に未知半径の被覆外周、組立BOX異厚のねじり・せん断性能などは下記と[断面諸量](../calc_basis/03_断面性能/02_断面諸量.md)を確認してください。

`StbSecColumn_S` / `StbSecBeam_S` / `StbSecBrace_S` が形鋼図形を参照します。
書き出しでは、Column（柱）の鋼断面が `StbSecColumn_S`、Girder（大梁）と Beam（小梁）の鋼断面が
`StbSecBeam_S`、Brace（ブレース）の鋼断面が `StbSecBrace_S` になります。
二次部材（小梁・間柱）だけが使う断面は、それぞれ梁用・柱用として書き出します。

鋼ブレースの一様断面は、`StbSecBrace_S` → `StbSecSteelFigureBrace_S` →
`StbSecSteelBrace_S_Same` の要素で表し、形鋼参照 `shape` と材料名 `strength_main` を保持します。

|---|:--:|:--:|---|---|
| `StbSecRoll-H` | ✅ | ✅ | 半径が既知の正値なら保持 | 圧延H形鋼のルート半径 `r` を保持。書き出しには既知の正半径が必要 |
| `StbSecBuild-H` | ✅ | ✅ | 対称断面の範囲で保持 | 対称断面も組立H形鋼の板組輪郭として保持 |
| `StbSecBuild-H`（上下フランジ相違） | ❌ | ✅ | 非対称の保存は保証しない | 入力の標準属性は `A`/`B`/`t1`/`t2`。独自の `B2`/`t2_lower` は読まない。現行出力ではこれらの方言属性を持つが、再読込による非対称形状の保存は保証しない |
| `StbSecRoll-BOX` | ⚠️ | ⚠️ | 正半径がある範囲で保持 | 外角半径 `r` を保持し、`t` を一様板厚に採る。欠落半径は未知のまま保持する。書出には既知の正半径が必要 |

| `StbSecLipC` | ❌ | ⚠️ | 独自タグ出力を読み取れない | 正式タグの取込接続は未対応。標準の `H` と `A` は別寸法。現行出力は独自の `StbSecRoll-LipC` で、再読込できない |
| 組立断面（2L・2C・十字）・リップ Z・その他軽量形鋼 | ❌ | ❌ | 対応なし | 必要な形鋼参照を解決できなければ、取り込み全体を拒否する |

H と Box の圧延断面で `r` 属性が欠落した場合は、モデルを取り込んで半径を未知のまま保持します。
被覆の実外周が必要になった時点で算定エラーとなるため、欠落を直角として黙って読み替えません。
Box を角形 CFT へ変換する経路でも、既知・未知の半径を引き継ぎます。

ST-Bridge 2.0.2 の圧延 H・Box は正の `r` が必須です。
未知または明示した 0 はこの形式で表せないため、書き出しをエラーにします。
フランジ厚・板厚を便宜半径にせず、出力の都合で製法を組立へ変更することもありません。
不正半径も出力エラーとし、同寸法で半径だけ異なる図形は参照名を分けて保持します。
未知と 0 を含む完全な保存には OVIKA を使用してください。

カタログの H・Box は名称でなく CSV の `r` 列から半径を保持します。
カタログの A・I・J 等は表値を維持し、半径保持を理由に再計算値へ置き換えません。

鋼断面の図形参照（`StbSecSteelColumn_S_Same`・`StbSecSteelBeam_S_Straight` など）は、
標準の `shape` から形鋼名を読みます。独自の `shape_start`・`shape_center`・`shape_main` を代替には使いません。

| 図形参照 | 読込 | 書出 | 再読込での保持・欠落・近似 | 保持条件・解析への適用と確認 |
|---|:--:|:--:|---|---|
| 一様断面（`*_Same` / `*_Straight`） | ✅ | ✅ | 対応する形鋼寸法の範囲で保持 | 書き出しはこの形だけを使う |
| テーパ・継手（`*_Taper` / `*_Joint` ほか始端を持つ図形） | ⚠️ | ❌ | 始端一様断面へ近似。変断面は欠落 | 始端の形鋼を採り、材長方向に一様な断面として近似する。中間・終端の形鋼は取り込まない |
| 形鋼参照 `shape` を解決できない図形 | ❌ | ❌ | 読込拒否 | 必要な形鋼参照を解決できず、取り込み全体を拒否する |

## 断面 — RC・SRC・CFT

| ST-Bridge 要素 | 読込 | 書出 | 再読込での保持・欠落・近似 | 保持条件・解析への適用と確認 |
|---|:--:|:--:|---|---|
| `StbSecColumn_RC`（`_Rect` / `_Circle`） | ✅ | ✅ | 対応する形状・配筋の範囲 | RC 矩形柱・円形柱＋配筋 |
| `StbSecBeam_RC`（`_Straight`） | ✅ | ✅ | 矩形梁と対応配筋の範囲 | RC 矩形梁＋配筋。大梁・小梁専用。RC 柱型の梁利用と円形 RC 梁は非対応で、主架構線材・小梁・間柱の用途不整合は入出力時に拒否する |
| `StbSecBarArrangement*`（配筋） | ✅ | ⚠️ | 元部位・pos・属性省略を保持。編集後は出力検査 | RC/SRC梁・柱の元部位・pos・標準属性・省略を保存。現行の計算で表現できない配置は計算不可。新規・編集済み配筋の標準出力は必須値と段数を検査する |
| `StbSecColumn_CFT`（＋充填鋼管） | ✅ | ⚠️ | 柱用途・鋼管の出力条件を満たす範囲 | CFT 角形・円形。**主架構の柱用途だけ**に使用でき、床板・壁版・`StbBeam` 等の二次部材には使用しない。用途不一致の既存参照や未参照断面は解析前チェックで ID・件数を示してエラーにする。書き出しで不正用途の部材が参照する場合は `StbSecRaw` へ |
| `StbSecColumn_SRC` / `StbSecBeam_SRC` | ✅ | ✅ | 矩形・内蔵H形鋼・対応配筋の範囲 | SRC矩形＋内蔵H形鋼＋配筋。鋼材強度は標準の鋼材図形子の `strength_main` を読む。断面親の独自 `strength_steel`/`strength_main_S` は読まない |
| `StbSecRaw`（物性直持ちの拡張要素） | ❌ | ✅ | 読み取れない | 入力対象外。現行出力のフォールバックは残るが、そこへの断面参照を入力時に救済しない |
| RC・SRC のテーパ・ハンチ等（矩形・円形以外の図形） | ❌ | ❌ | 対応なし | 図形を認識できず、断面を取り込めなかったものとして警告する |

配筋の保存と解析採用は別です。標準の配筋コンテナと各部位を、属性の省略を含めてOVIKAへ保存し、同じ標準系列へ再出力します。XML順序ではなく `pos` を対応させ、重複・不足する位置や必須値欠落、明示0本、ピッチ0を拒否します。

| 入力 | 保存する意味 | 現解析への対応 |
|---|---|---|
| 梁 `N_main_top/bottom_1st/2nd/3rd` | 上端・下端の主筋段 | 主筋中心・段間位置を解決できる範囲。段間未解決は不可 |
| `D_2nd_main` / `N_2nd_main_*` | 別径・材料の副主筋。2段筋とは別 | 保存・出力可、解析不可 |
| `D_stirrup` / `N_stirrup` / `pitch_stirrup` | あばら筋 | 主筋・腹筋・巾止筋へ合算しない |
| `D_web` / `N_web` | 腹筋 | 適用条件があるときだけ適用。現解析は不可 |
| `D_bar_spacing` / `N_bar_spacing*` / `pitch_bar_spacing` | 巾止筋 | 適用条件があるときだけ適用。現解析は不可 |
| 柱 `N_main_X/Y_1st/2nd` / `N_main_total` | X=左右垂直列、Y=上下水平列と段別配筋。総本数は確認済み共有位相だけで検査 | 既存実鉄筋座標で表現できない配置は不可 |
| `D_axial` / `N_axial` | 軸筋。主筋総本数へ加えない | 保存・出力可、解析不可 |
| Same / StartEnd / ThreeTypes / RectNotSame | 同一またはSTART/CENTER/END、BASE/TOPの各部位 | 位置別の新しい解析モデルは未対応 |
| `kind_corner` | NONE/DIR_X/DIR_Y/DIR_XYの位置意味と省略を保持（段数・追加本数ではない） | 寄せ配置は未対応。NONEへ平滑化しない |
| 配筋コンテナの `depth_cover_*` / `center_*` | 外周補強筋までのあきと第一段主筋重心を別保存 | Apply適用時はcenter優先。単一かぶりへ表現できる範囲で採用し、面別値・未解決位置は診断する。配筋子に置かれた同名属性は採用しない |

`StbApplyConditionsList` の対象要素がない項目は非適用です。元属性は保存しても解析用入力には混ぜません。対象要素の `set_default=false` は共通省略値を供給せず、`true` は書かれた属性だけ供給します。個別指定を優先し、部分既定値の未指定項目に値を追加しません。

円形帯筋の `N_band` は必須です。SEPIKAで入力した閉鎖帯筋は現モデルの2脚を明示し、標準入力の2脚以外は原保存して計算を拒否します。共通Apply既定の腹筋・巾止筋は実効本数と径で役割・強度を解決し、個別属性の省略は元入力に保持します。未確定の隅筋共有位相は保存できますが計算できません。未証明の一般本数式だけで有効な標準入力を拒否しません。

柱の主筋総本数は、X・Y方向の段別本数の和を2倍し、隅筋の共有本数を控除します。共有本数を確認しているのは、隅筋指定NONEで各方向1段・各段2本以上の場合の4本、NONEまたはDIR_XYでX・Yとも段別本数が[7, 2]の場合の12本（各隅のL字形3本を4組）、NONEでXが[7, 7]・Yが[7, 6]の場合の16本（各隅の2×2本を4組）です。後二者は仕様書本文124–125頁・127頁の配置に対応し、軸筋は別扱いです。これら以外の配置や副主筋を含む配置では、この総本数検査から適否を推定しません。

径名 `D22` などは元の文字列を保存します。主筋・副主筋・軸筋・帯筋・あばら筋・腹筋・巾止筋それぞれの元部位・posを、[標準強度の解決](02_ST-Bridge_形式.md#標準強度の解決と編集)へ結びます。呼び名の保存はJIS公称断面積の全対応を意味しません。

原配筋付き断面を形状編集した場合は、新しい配筋をSEPIKAで編集した入力として扱い、古い原配筋を再適用しません。Undoは原配筋と強度指定をともに復元します。新規・編集後の配筋は、必須本数・径・ピッチの不足、梁4段以上・矩形柱3段以上を対象断面付きで出力不可にします。任意の0本段は標準属性を省略し、後段を前段へ詰めません。

保存できても解析できない標準入力は、準備計算・解析・該当架構検定で理由を示します。未使用断面や架構配筋を消費しない床板単独検定まで一律に禁止しません。完全保存はOVIKAを使用してください。

出典：buildingSMART Japan『ST-Bridge XMLファイル仕様書（ver.2.0）Revision 2』採用2.0.2、[2022-06-15版](https://www.building-smart.or.jp/wp-content/uploads/2022/06/ST-Bridge_XML%E4%BB%95%E6%A7%98%E8%AA%AC%E6%98%8E%E6%9B%B8%EF%BC%88ver.2.0.2%EF%BC%89_20220615.pdf)、本文12、22–29、122–127、192–198頁。[公式2.0.2 XSD](https://www.building-smart.or.jp/wp-content/uploads/2026/04/ST-Bridge_v202.zip)の同名要素・attributeGroupに照合しています。

**実装参照**：`StbRebarArrangement` / `Model::stb_rebar_diagnostics`（`crates/sepika-core/src/model/stb_rebar.rs`）、`StrengthInputs`（`crates/sepika-io/src/stbridge/import/strength.rs`）、`strength_export::section`（`crates/sepika-io/src/stbridge/strength_export.rs`）。

## 断面 — スラブ・壁

| ST-Bridge 要素 | 読込 | 書出 | 再読込での保持・欠落・近似 | 保持条件・解析への適用と確認 |
|---|:--:|:--:|---|---|
| `StbSecSlab_RC`（厚さ・符号・階・コンクリート） | ✅ | ✅ | 出力対象の版が参照する断面のみ | 厚さ（`depth`）は図形要素（`StbSecFigureSlab_RC` > `StbSecSlab_RC_Straight`）から取る。符号 `name`・階 `floor`・`strength_concrete` も断面として取り込む。書き出すのは `StbSlab` を出した領域が参照する断面だけ（版なし・取り付きの孤立断面は出さない） |
| `StbSecSlabDeck`（デッキ合成） | ✅ | ⚠️ | RC床へ近似。デッキ形式は欠落 | 図形（`StbSecSlabDeckStraight`）からコンクリート部せいを厚さとして取る。書き出しは `StbSecSlab_RC` 相当 |
| `StbSecWall_RC`（厚さ） | ⚠️ | ✅ | 厚さ・強度指定を保持。符号は自動命名 | 厚さは `StbSecFigureWall_RC` 内の `StbSecWall_RC_Straight` の `t` を読む。標準の強度指定を保持・解決する。書き出しは壁版ごとに1件、符号は `W1` のような自動命名 |
| `StbSecSlab_S`（鋼スラブ） | ❌ | ❌ | 保持しない | 取り込み時に警告 |

スラブの入力参照は、RCとDECKを含む具体的な系列と元の数値IDで区別します。同じ断面を参照する複数の床には、その断面の厚さと強度指定を結びます。
床の自重は面荷重へ焼き込まず、断面の板厚とコンクリート材料から使うたびに算定します
（[床の断面と自重](../calc_basis/01_荷重/08_床の断面と自重.md)）。

壁の入力参照は `StbSecWall_RC` と元の数値IDで解決します。取り込み後の断面符号は `Wall t180` のように厚さから決めますが、同厚であることだけを理由に異なる強度指定を取り違えません。
壁の材料は、部材・断面・原階・共通の標準 `strength_concrete` とその優先順位から解決します。独自の `id_material` へは接続しません。

**実装参照**：取り込みは `sepika_io::stbridge::import::assemble::{build_slabs, push_slab_section, build_walls}`（`crates/sepika-io/src/stbridge/import/assemble.rs`）が担います。

</div>

| 拘束条件（支点） | ❌ | ❌ | 元支点を保持しない。再読込で自動設定 | ST-Bridge の幾何スコープ外。支点を持たないモデルは取り込み時に自動設定する（下記） |
| 質量 | ❌ | ❌ | 保持しない | ST-Bridge の幾何スコープ外 |
| `StbCommon` | ✅ | ✅ | 対応する情報を保持 | プロジェクト・アプリ情報、共通Fc・径別鉄筋強度・適用条件を保持する。新規モデルの書き出し情報は既定値を用いる |
| `StbJoints` | ❌ | ✅ | 接合部の情報は保持しない（空出力） | 接合部は扱わないため、書き出しでは空要素だけを出す |

<div class="impl-ref">

**実装参照**：取り込みは `sepika_io::stbridge::import::assemble::{build_load_cases, build_axes}`（`crates/sepika-io/src/stbridge/import/assemble.rs`）が担います。

</div>

### 節点荷重の単位と方向

`StbLoadCase` と `StbNodalLoad` は、本製品が受理する荷重の形式です。
公開されているST-Bridge 2.0.2の躯体情報の仕様書には、これらの要素と荷重単位の定義がありません。同仕様書は荷重・設計条件・解析モデルの詳細を別途「計算編」の範囲としています。
以下は標準の荷重単位の規定ではなく、SEPIKAで採用される読込値の意味です。

| 入力属性 | 入力に必要な単位 | 採用単位 | 全体座標での正方向 | 取込時の換算 |
|---|---|---|---|---|
| `fx` | N | N | +X方向 | なし |
| `fy` | N | N | +Y方向 | なし |
| `fz` | N | N | +Z方向（上向き） | なし |
| `mx` | N·mm | N·mm | +X軸まわりの右ねじ方向 | なし |
| `my` | N·mm | N·mm | +Y軸まわりの右ねじ方向 | なし |
| `mz` | N·mm | N·mm | +Z軸まわりの右ねじ方向 | なし |

力・モーメントとも部材の局所軸や通り芯方向へ回転せず、入力した符号をそのまま採用します。
右ねじ方向とは、右手の親指を各軸の正方向へ向けたときに、他の指が曲がる向きです。
下向き10 kNなら `fz="-10000"`、+Z軸まわり2 kN·mなら `mz="2000000"` が必要です。
kNの値は1,000倍、kN·mの値は1,000,000倍してから入力します。ファイルの単位指定による自動換算はありません。

欠けた成分は0です。`id_node` で参照する節点がなければ、その節点荷重を破棄して件数を警告します。
取込後は[荷重の入力](../model_edit/11_荷重の入力.md)でケース名・対象節点・6成分の値と符号を元入力と照合してください。
[節点荷重の計算条件](../calc_basis/01_荷重/07_荷重の入力.md#節点荷重)に従って同一節点の荷重は加算されます。
ST-Bridgeへは書き出さないため、保存にはOVIKAを使用します。

出典：buildingSMART Japan『ST-Bridge XMLファイル仕様書（ver.2.0）Revision 2』採用2.0.2、[公開仕様書](https://www.building-smart.or.jp/wp-content/uploads/2022/06/ST-Bridge_XML%E4%BB%95%E6%A7%98%E8%AA%AC%E6%98%8E%E6%9B%B8%EF%BC%88ver.2.0.2%EF%BC%89_20220615.pdf)、本文1頁（荷重等の対象範囲）。

<div class="impl-ref">

**実装参照**：読込成分は `StbParser::start_load`（`crates/sepika-io/src/stbridge/import/parser.rs`）、節点参照と採用値は `build_load_cases`（`crates/sepika-io/src/stbridge/import/assemble.rs`）、全体自由度への加算は `assemble_global_f`（`crates/sepika-solver/src/common/assemble.rs`）が扱います。

</div>

## 取り込み時の既定値

ファイルに属性がないときの扱いをまとめます。
支点の自動設定は、採用内容を取り込み報告の通知でも知らせます。

- 部材端の接合条件（`condition_*`）がない場合は剛接合（`FIX`）とする
- 断面の回転角（`rotate`）がない場合は 0 とする
- ブレースの `feature_brace` がない場合は引張専用とする
- 柱・大梁・ブレース・小梁・間柱は断面参照（`id_section`）の未指定・参照先欠落で取り込み全体を拒否する。床・壁の断面参照省略は既存の未割当処理を維持する。存在する `-1`・小数・範囲外・非数値は不正IDとして取り込み全体を拒否する。主架構部材・ブレース・小梁・間柱の断面未割当は、必須の断面参照を出力できないため書き出し全体を拒否する。診断に示された部材へ適切な実在断面を明示的に割り当てて再出力する。未割当を `-1` や属性省略で出力せず、ダミー部材・架空の断面や材料を生成しない
- 配筋要素がないRC・SRC断面は未入力として保持する。標準の必須配筋属性の欠落を本数・径・ピッチ0で補って出力しない
- 形鋼参照を解決できない鋼・CFT・SRC断面は、理由を示して取り込み全体を拒否する
- 支点を 1 つも持たないモデルは、最下レベルで柱脚が付く節点をピン支点にする
  （[支点の自動設定](./02_ST-Bridge_形式.md#支点の自動設定取り込み時)）

<div class="impl-ref">

**実装参照**：既定値の適用は `sepika_io::stbridge::import`（`crates/sepika-io/src/stbridge/import/{parser.rs, assemble.rs}`）が担い、支点の自動設定は `sepika_io::stbridge::import::assemble::auto_assign_supports` が行います。

</div>

標準配筋の未対応診断は部材だけでなく、配筋を使うRC/SRC接合部・PCa水平接合面・耐震壁側柱でも理由付きで検定を止めます。実際に使う断面だけを対象にし、未使用断面や鋼材だけのパネルへ広げません。

標準配筋では数値や真偽値の前後のXML空白を解釈しても、元の記述は保存します。未知の選択値を既定値へ置き換えません。

実効 `depth_cover_*` と `center_*` を併記した場合は `center_*` を優先します。既知の主筋・外周補強筋径から採用あきを算出し、指定したあきと異なる場合は、断面・面・両指定値・採用値を注意として通知します。この注意だけでは計算を停止しません。取込時の注意と準備計算で両指定値と採用値を確認し、意図した配筋へ修正してください。未知径や未指定値は推測せず、解析・検定の停止理由として示します。
