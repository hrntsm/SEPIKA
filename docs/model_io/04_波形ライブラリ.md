# 波形ライブラリ

時刻歴応答解析の入力波形（CSV）を、プロジェクト（`.ovika`）をまたいで使い回すための置き場です。

<div class="impl-ref">

**実装参照**：`sepika_io::wave_library::{wave_library_dir, list_wave_library, register_wave, wave_sha256}`（`crates/sepika-io/src/wave_library.rs`）が保管先の解決・一覧・登録・ハッシュ算定を担います。

</div>

## 位置づけ

`.ovika` にはモデル・解析結果・解析タブの設定値（時刻歴の波形パラメータ・減衰モデル等）を保存しますが、時刻歴の入力波形（CSV）そのものは含めません。波形ライブラリは、OS 標準のユーザーデータディレクトリ配下の専用フォルダに波形 CSV をコピーして保管し、全プロジェクトから共通の置き場として参照します。立体時刻歴と質点系は、同じライブラリから独立した選択を持ちます。

- ディレクトリ: OS 標準のユーザーデータディレクトリ配下の `sepika/waves`（Windows は `%APPDATA%\sepika\waves`、macOS は `~/Library/Application Support/sepika/waves`、Linux は `~/.local/share/sepika/waves` 相当）。
- 対応拡張子: `.csv` / `.txt` / `.dat`。

**注意（機械ローカル）**: ライブラリはこのマシンのユーザーデータディレクトリに置かれます。別のマシンで `.ovika` を開いた場合や、プロジェクトファイルを他者へ渡した場合、そのマシンのライブラリに同名の波形がなければ波形を解決できません。

<div class="impl-ref">

**実装参照**：保存先は `sepika_io::wave_library::wave_library_dir`、一覧は同 `list_wave_library`（`crates/sepika-io/src/wave_library.rs`）が持ち、一覧とファイル選択ダイアログは `.csv`・`.txt`・`.dat` の拡張子でフィルタします。

</div>

## GUI からの操作

### 波形の登録

ファイルメニューの「🌊 波形を保存…」から、波形 CSV を選んでライブラリへコピーします（この操作では解析は実行しません）。ライブラリに同名の波形が既にある場合は、上書き確認ダイアログを表示します。

<div class="impl-ref">

**実装参照**：`sepika_app::app::App::{register_wave_to_library_dialog, confirm_register_wave}`（`crates/sepika-app/src/app/actions/wave_library.rs`）が受け付け、コピーは `sepika_io::wave_library::register_wave` が行います。

</div>

### 波形を選んで実行

工程タブ「解析」を開き、右のアイコン列から「時刻歴応答」パネルを出すと、「波形ライブラリ」のドロップダウンがあります。登録済みの波形ファイル名を一覧表示します（他のプロジェクトで登録したものも同じ一覧に表示されます）。選んで「▶ 選択した波形で実行」を押すと、時刻歴応答解析をジョブ実行します。方向（X/Y/X+Y）・dt の解釈は「📂 波形CSVを開いて実行…」（一回限りのファイル選択）と同じです。

右バー「質点系」にも同じドロップダウンがあります。ここでの選択は立体時刻歴とは独立で、`.ovika` にも別々に保存します。質点系パネルから波形 CSV を直接開いて実行する操作はありません。

<div class="impl-ref">

**実装参照**：ドロップダウンは `sepika_app` の解析パネル（`crates/sepika-app/src/app/panels/analysis.rs`）が表示し、実行は `sepika_app::app::App::run_time_history_from_library` と `App::start_lumped_mass_library_th_job`（`crates/sepika-app/src/app/actions/`）が担います。

</div>

実行結果のケースは、選択中の名前ではなく、実際に解析した波形と計算条件に対応します。
実行開始後にライブラリの表示選択を変えても、完了結果の所属先は変わりません。
同名のファイルを上書きして波形の加速度列や時間刻みが変わった場合は、再実行で別ケースになります。
ケースの再実行と表示は[ナビゲータの解析結果ツリー](../result_view/14_ナビゲータの解析結果ツリー.md#ケース名)を参照してください。

## CSV入力仕様

外部 CSV とライブラリ内の CSV は、同じ列選択・単位換算で読み込みます。実行前に、入力方向・加速度の単位・列配置・GUI の時間刻み dt [s] を確認してください。

### 入力方向と加速度列

| 波形の選択元 | X | Y | X+Y |
| --- | --- | --- | --- |
| サンプル波 | 生成した波形を X へ入力 | 生成した波形を Y へ入力 | 同一の生成波形を X・Y へ入力 |
| 外部 CSV（「📂 波形CSVを開いて実行…」） | 最後の列を X へ入力 | 最後の列を Y へ入力 | 第1列を X、第2列を Y へ入力 |
| 波形ライブラリ | 最後の列を X へ入力 | 最後の列を Y へ入力 | 第1列を X、第2列を Y へ入力 |

この表の X+Y は立体時刻歴の選択肢です。質点系は X または Y を選び、ライブラリの最後の列をその方向へ入力します。質点系から外部 CSV を直接選択する操作はありません。

CSV の加速度は **gal（cm/s²）** で指定します。内部の加速度単位 mm/s² へは **10 倍**して換算します。たとえば CSV の `100` は 100 gal = 1000 mm/s² です。mm/s² の値をそのまま CSV に記入すると、意図した加速度の 10 倍になります。

1方向入力の最小例です。X を選ぶと X 方向、Y を選ぶと Y 方向に、1000, −1000 mm/s² を入力します。

```csv
100
-100
```

2方向入力の最小例です。X+Y を選ぶと X に 1000, −1000 mm/s²、Y に 500, −250 mm/s² を入力します。外部 CSV とライブラリでは、このように異なる2列の波形を同時入力できます。

```csv
100,50
-100,-25
```

同じ2列のファイルで X または Y を選ぶと、採用されるのは最後の列（50, −25 gal）だけです。X を選んでも第1列が選ばれるわけではありません。

### 区切り・ヘッダ・無効行

各行をカンマで区切り、採用する欄の前後の空白を除いて数値として読みます。列名による選択や単位の自動判別は行いません。

| 行・列の状態 | X / Y | X+Y |
| --- | --- | --- |
| ヘッダなど数値化できない欄 | 最後の欄を数値化できなければ行全体を無視 | 第1・第2欄のいずれかを数値化できなければ行全体を無視 |
| 空行 | 無視 | 無視 |
| 非空行が1列だけ | その値を採用（数値化できなければ無視） | エラー。1列だけのヘッダも使用不可 |
| 追加列 | 最後の列だけを採用し、それ以前は無視 | 第3列以降を無視 |

たとえば `acc_gal` は X/Y のヘッダ、`x_gal,y_gal` は X+Y のヘッダとして無視されます。無効行は欠測時刻として残らず、残った有効行を連続した dt 間隔に並べます。欠測のある波形は入力前に整えてください。

### 時間刻みと時間列

時間刻みは実行するパネルの GUI 指定 dt [s] を使用します。立体時刻歴では「時刻歴応答」、質点系では「質点系」の時間刻みが採用されます。**CSV の時間列を時刻として読み取ったり、行間の時間差から dt を求めたりしません。**

たとえば、次の「時刻 [s], 加速度 [gal]」の2列 CSV は、X/Y なら最後の加速度列だけを採用します。GUI の dt を 0.02 s にすれば、入力時刻は 0, 0.02 s です。

```csv
0.00,100
0.02,-100
```

このファイルを X+Y で使うと、時刻として意図した第1列の 0.00, 0.02 が **X 方向の加速度 [gal]** として採用されます。X+Y には時間列を除いた「X 加速度, Y 加速度」の2列を用意してください。`時刻,X,Y` の3列でも、第1列が X、第2列が Y となり、本来の Y 列は無視されます。

<div class="impl-ref">

**実装参照**：CSV の列選択・換算と時間刻みは `sepika_app::app::{parse_wave_csv, ground_motion_from_wave_content}`（`crates/sepika-app/src/app/mod.rs`）、サンプル波の方向割当は `sepika_job::sample_wave::build_ground_motion`（`crates/sepika-job/src/sample_wave.rs`）が実装します。

</div>

## 入力波形の時間軸

GUI で実行する CSV は、無効行を除いた有効なデータが 2 点以上必要です。N 点を時刻 0, dt, …, (N−1)dt の瞬時値として扱い、
立体・質点系とも N−1 区間を積分します。先頭は積分前の初期状態、末端は最後の入力時刻に対応する応答です。
上の最小例はいずれも N=2 なので、dt=0.02 s なら 0〜0.02 s の1区間を積分します。
詳細は [入力時刻と初期状態](../calc_basis/05_構造解析/05_時刻歴応答解析.md#入力時刻と初期状態) を参照してください。

## `.ovika` との連携

保存対象と可搬性は[OVIKAの外部波形と可搬性](01_プロジェクト形式_ovika.md#外部波形と可搬性)を正本とします。一回限りの「📂 波形CSVを開いて実行…」はライブラリ参照を保存しません。

「▶ 選択した波形で実行」で実行した波形のファイル名と、実行時点のファイル内容の SHA-256 は、解析タブの設定値に同梱して保存します。プロジェクトを開き直すと、ライブラリに同名のファイルが存在する限り、この選択を自動的に復元します。

- ライブラリにファイルが見つからない場合（削除された等）は、通知したうえで選択を解除します。
- ファイルは見つかるが内容（SHA-256）が保存時と異なる場合（ライブラリ側で上書きされた等）は、選択は維持したうえで内容が変わっている旨を通知します。

<div class="impl-ref">

**実装参照**：保存・復元は `sepika_app::app::App::save_project_to_opts` と `App::{restore_wave_library_selection, restore_lumped_wave_library_selection}`（`crates/sepika-app/src/app/actions/wave_library.rs`）が行います。

</div>
