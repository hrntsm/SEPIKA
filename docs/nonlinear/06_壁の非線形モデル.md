# 壁の非線形モデル

壁の幾何・弾性剛性と[目的別の適用範囲](../calc_basis/04_要素剛性/05_壁エレメントモデル.md#目的別の適用範囲)、[壁脚内力と初期耐力](../calc_basis/08_部材終局耐力/08_RC壁の壁脚内力と初期耐力.md)を併せて確認してください。

## 側柱の非線形接続と適用範囲


RC・SRC置換壁の側柱は、軸剛性・軸力、面外曲げ・せん断、物理質量を保持します。増分解析のファイバー・MS側柱は、軸・二軸曲げの材料履歴を持ち、軸降伏・除荷・再載荷を評価します。解放回転を各試行状態で釣り合わせ、同じ収束状態の内力と接線を用います。局所収束だけでは履歴を確定せず、全体未収束時は材料と内部回転を一体で巻き戻します。特異・非有限・局所不収束は失敗として扱います。

保持自由度を \\(u_a\\)、内部の解放回転を \\(u_b\\) とし、部材荷重を含む局所残差 \\(r_b(u_a,u_b)=0\\) を各試行状態で解きます。部材荷重がなければ、解放方向の材端モーメントは零です。同じ収束状態の保持側内力 \\(f_a\\) を返し、同じ状態の微分による接線ブロックについて、\\(K_{bb}\\) が可逆な場合に次を用います。

\\[
K_{\mathrm{cond}}=K_{aa}-K_{ab}\,\operatorname{solve}(K_{bb},K_{ba})
\\]

非線形内力を \\(K_{\mathrm{cond}}u_a\\) で代用しません。局所残差の評価と接線には同じ荷重・材料履歴を用い、特異・非有限・局所不収束を零剛性や弾性への置換で隠しません。これは準静的な数値縮約の条件であり、全状態での解の一意性や動的適用を保証しません。

部材荷重がある側柱では、元の節点間全長に対する荷重を可撓部と剛域に分けます。可撓部の等価荷重を断面材料と回転接続の両方の釣合いへ含め、剛域分は実合力と腕長による節点荷重として扱います。出力する材端力は同じ収束状態の荷重込みの力とし、固定端力をさらに加算しません。元の端部条件・剛域の変換と物理質量を保持し、荷重のない側柱へだけ有効なモーメント零条件を、部材荷重のある側柱へ無条件には当てはめません。

局所釣合いと整合接線の数理原理は、Lowes, Mitra, Altoontash, *A Beam-Column Joint Model for Simulating the Earthquake Response of Reinforced Concrete Frames*, PEER Report 2003/10（扉February 2004）、[§3.3.2 本文15–17頁／PDF21–23頁、式(3.3)・(3.4)、§3.3.3 本文17–18頁／PDF23–24頁、式(3.5)–(3.8)](https://peer.berkeley.edu/sites/default/files/0310_l._lowes_n._mitra_a._altoontash.pdf#page=21)を参照します。原著の対象は13成分・4内部自由度の平面RC接合部です。この原理の採用だけでは、本壁側柱モデルの材料履歴・実壁挙動の検証を完了したことにはなりません。

| 解析・指定 | RC・SRC置換壁の側柱接続 |
| --- | --- |
| 線形静的、梁・ファイバー・MSの入力表現 | 共通の弾性回転解放を適用 |
| 単一平面・準静的の増分解析、ファイバー・MS | 材料履歴を保持した回転解放を適用。梁の自動選択でファイバーとなる柱も同じ扱い |
| 増分解析で側柱を材端集中ばねに指定 | 解放との連成が未定式化のため、対象部材・壁・解析種別と理由を示して適用外 |
| 非線形時刻歴の側柱接続 | 従属回転の慣性との連成が未定式化のため理由付き適用外 |
| P–Δを有効にした側柱接続 | 幾何剛性との連成が未成立のため、実際の指定に従って理由付き適用外 |
| 固有値・線形時刻歴で部材の整合質量を使う接続 | 初期弾性接続による実際の整合質量を構成できる条件に限る。特異な内部回転や、慣性を持つ共通ねじり回転を静的に固定しなければならない条件は理由付き適用外 |
| 要素質量を使わない質点のみ方式 | 上記の部材整合質量の構成条件は課さない。非線形時刻歴・P–Δ等の接続制限は別に適用 |

側柱の幾何判定は材軸単位ベクトルの鉛直成分が \\( |e\_z| > 0.707 \\) となる鉛直卓越材を対象とします。これは[壁脚内力と初期耐力](../calc_basis/08_部材終局耐力/08_RC壁の壁脚内力と初期耐力.md#適用範囲と未算定)の矩形鉛直壁への限定とは別の条件です。側柱として認識されても、傾斜壁の参考骨格や初期耐力が求められるとは限りません。

複数壁が側柱を共有する場合、平行・反転した法線は同じ解放面として扱います。採用可能な壁どうしが非平行となる共有柱は、独立した定式化が未成立のため適用外です。最初に登録した壁だけで解放方向を決めません。

診断とモデル化表示は、同じ部材の物理的役割と解析種別に対応した理由を示します。解析入口では、実際のP–Δ指定と質量方式の適用条件も検査します。停止条件は対象部材・壁・解析種別とともに示し、有効な鋼板耐震壁の注意通知と区別します。壁との節点・断面・材料用途の対応が矛盾する場合も、側柱なしとして継続しません。純鋼板・壁なし骨組・剛性算入なしの壁版へ、RC側柱接続の制限を一律には適用しません。

**面内せん断の非線形性**

[目的別の適用範囲](../calc_basis/04_要素剛性/05_壁エレメントモデル.md#目的別の適用範囲)を満たして実行する非線形解析では、壁の面内せん断を**終局せん断強度 \\( Q\_u \\) で頭打ちとする弾完全塑性骨格**の復元力ばねとして扱います（[耐震壁（せん断非線形トリリニア）](05_RC_部材_非線形復元力特性.md)）。せん断モード（上辺 2 節点の壁面内水平並進）に沿う塑性すべり \\( \gamma\_p \\) を導入し、変形測度 \\( D = \gamma\_p + Q/k\_{s0} \\)（\\( k\_{s0} = p^{\mathsf T} K\_{el}\\, p \\) は弾性モード剛性）に対する履歴ばね \\( Q = M(D) \\) と壁の伝達水平力が一致するよう \\( \gamma\_p \\) を定めます。接線剛性はせん断モードの剛性を保持し、非線形は内力側のすべり補正のみで表現します（初期剛性法。曲げ機構の形成後にせん断が \\( Q\_u \\) から除荷へ向かう角点で、剛性を除去した整合接線では大域反復が特異化するため）。

ばねの骨格は弾完全塑性（初期剛性 \\( k\_{s0} \\)、耐力 \\( Q\_u \\)。トリリニアのひび割れ点は弾性線上 \\( Q\_u/3 \\) に置きバイリニア相当、終局点は降伏変形の \\( 10^4 \\) 倍で降伏後フラット）とし、**除荷・再載荷則は履歴則の設定（[履歴則の設定（増分用・時刻歴用）](02_部材履歴則.md#履歴則の設定増分用時刻歴用)）から解決します。既定は最大点指向型**（増分・時刻歴共通。壁の面内せん断はひび割れのスリップ性状が強く、除荷開始剛性が初期剛性のままの移動硬化型ではループの吸収エネルギーを過大評価するため）です。逆行型・標準型・原点指向型・武田型も選択できます。

**軸・曲げの非線形性（ファイバー壁柱）**

保有水平耐力計算（増分解析）では、壁柱の**軸・曲げを既定でファイバー断面の弾塑性評価**とします（柱の Fiber 既定と同じ扱い）。壁柱は「全長弾性梁＋端部塑性増分ヒンジ」のファイバー要素（[ファイバーモデル](04_非線形梁要素のモデル化.md)）とし、断面は次で構成します。

- コンクリート: 幅 \\( t \\) × せい \\( l\_w \\) の格子ファイバー（幅 4 × せい 20 分割。Fc≤60 は材料から解決した E を初期接線へ反映した NewRC、\\( f\_c > 60 \\) は NewRC 固有 Ec の暫定外挿）。除荷則は部材ごとに増分用・時刻歴用を選択でき（[履歴則の設定（増分用・時刻歴用）](02_部材履歴則.md#履歴則の設定増分用時刻歴用)）、自動（未指定）の既定は増分解析=**原点指向型**、時刻歴応答解析=**Karsan–Jirsa 型**です。明示指定は自動既定より優先します。ただし時刻歴の既定は定義のみで、現行のRC側柱付き壁の非線形時刻歴は未対応です。既定や指定を変更しても、側柱接続の適用制限は解消しません（[側柱の回転解放と適用範囲](#側柱の非線形接続と適用範囲)）。
- 縦筋: 明示壁縦筋比 pwv_ratio を各せい方向層へ等価分散した鋼材ファイバーとします。縦筋材料の公称fyを用い、増分解析では所有する材料の強度倍率を一度適用します。縦筋比・材料の不足は補完せず拒否します。

非線形壁柱の弾性基準となる軸・面内曲げの鉄筋剛性係数は、[線形解析用の共通筋比](../calc_basis/04_要素剛性/05_壁エレメントモデル.md#弾性壁柱の剛性)に代えて明示した縦筋比を用います。鉄筋のヤング係数は205000 N/mm²です。せん断の断面評価と開口低減は弾性壁柱と共通です。塑性化域長は \\( 0.5 \\, l\_w \\)（可撓長の 45% までにクランプ）とします。これにより細長壁の曲げ降伏・N–M 相関（軸力変動による曲げ耐力の変化）が表現されます。せん断の \\( Q\_u \\) 頭打ちは上記のとおり併用し（すべりを差し引いた変位を壁柱へ与える直列構成）、曲げ・せん断のうち先に到達した方で耐力が頭打ちになります。

許容応力度計算（弾性解析）では、軸・曲げ・せん断とも線形弾性として扱います。

終局せん断耐力の引張主筋量は、引張側最端の付帯柱1本の全主筋量です。初期耐力の対応条件は[壁脚内力と初期耐力の適用範囲](../calc_basis/08_部材終局耐力/08_RC壁の壁脚内力と初期耐力.md#適用範囲と未算定)によります。ファイバー壁柱や履歴則を構成できることだけでは、増分解析・非線形時刻歴解析の実行条件を満たしません。

壁横筋の降伏強度は断面の「せん断補強筋」材料のfyを用い、割増しません。明示横筋比pwh_ratioとその材料が必要で、未割当・非有限・非正fyは入力不備として拒否します。

正負の終局耐力を別々に求め、壁ばねにも別々に設定します。正方向は下辺aからbへ向かう上辺の移動で、a側を引張側・b側を圧縮側とします。負方向はこれを入れ替えます。全長Dは左右柱の外面間距離、圧縮側柱せいDcはその柱の壁長方向の実投影寸法です。等価壁厚は、重複控除した同じ断面の面積Aを使い、te=min(A/D, 1.5t)とします。引張側柱の主筋量は方向別の主筋セットの面積を合算した全主筋量です。側柱を左右平均した寸法や、多い側の主筋量では代用しません。関連する寸法・面積の定義は[建築研究資料第204号・第4章](https://www.kenken.go.jp/japanese/contents/publications/data/204/5.pdf)を参照してください。

正負それぞれの降伏変位はQu/Ks0です。初期剛性Ks0は共通とし、反対側の最大経験点・未経験時の降伏点は、載荷方向に対応する包絡線から求めます。弾完全塑性リターンマッピング、履歴ばね、ファイバー壁柱との連成のいずれでも、その方向の耐力を使います。モデル化表示には正負両方のQuを表示します。採用runがない場合や入力が一致しない場合は未解決と表示します。表示のために初期耐力を再計算しません。

**設定不備による停止**

次の設定不備がある耐震壁は、保有水平耐力計算・非線形時刻歴応答解析を**エラーで停止**します（代替値で補わず、弾性としても扱いません。耐力が定まらない壁は際限なく水平力を負担し保有水平耐力を過大評価するためです。[増分解析](../calc_basis/05_構造解析/07_プッシュオーバー解析.md)「解析前の入力チェック」）。

- 壁エレメントとして構築できない（4 節点の指定がない、節点座標が退化している）
- 断面が設定されていない、または壁厚が \\( \le 0 \\)
- 材料が設定されていない

RC 壁では、これに加えて次を検出します。

- 材料にコンクリート強度 \\( F\_c \\) が設定されていない、または \\( F\_c \le 0 \\)
- 付帯柱があるのに、その断面から主筋量を取得できない（断面形状が RC 矩形でない、主筋の本数・径が 0）
- 明示方向配筋・材料・対応側柱・同じfaceの必要応答が不足する
- 静的一次参照または正負の初期Quが未解決・不正となる

鋼板耐震壁では、次を検出します。

- 材料に降伏強度 \\( F \\) が設定されていない、または \\( F \le 0 \\)
- \\( Q\_y \\) の算定結果が \\( \le 0 \\) となる


鋼板の降伏せん断耐力とせん断座屈未考慮の制限は[鋼板耐震壁のせん断耐力](../calc_basis/08_部材終局耐力/09_鋼板耐震壁のせん断耐力.md)を参照してください。
