# 非線形モデル・復元力

材料の応力–ひずみ関係、部材の履歴則、非線形要素の骨格と適用条件を扱います。解析の反復・収束・実行方法は[構造解析の方法](../calc_basis/05_構造解析/README.md)、耐力の算定は[部材終局耐力](../calc_basis/08_部材終局耐力/README.md)を参照してください。

ファイバー梁の採用モデル・主要な既定値・評価範囲は、[ファイバーモデルの概要](04_非線形梁要素のモデル化.md#ファイバーモデル)で確認できます。

| 確認したい内容 | 参照先と扱う内容 |
| --- | --- |
| 梁・柱の非線形モデルを選ぶ | [非線形梁要素](04_非線形梁要素のモデル化.md)：材端集中・ファイバー・MSの選択と接続条件 |
| RC梁の集中ばね骨格を設定する | [RC部材骨格](05_RC_部材_非線形復元力特性.md)：基準指定・採用式・総角と追加角 |
| 増分／時刻歴の履歴則を設定する | [部材履歴則](02_部材履歴則.md)：指定優先順位・自動既定・除荷再載荷 |
| 材料から断面応答までを確認する | [一軸材料構成則](01_一軸材料構成則.md)で応力–ひずみ関係と既定値を確認し、[ファイバー断面](03_ファイバー断面.md)で平面保持・断面積分・分割精度・参考M–φ／M–θを確認 |
| 解析を実行して結果を読む | [構造解析](../calc_basis/05_構造解析/README.md)：解析条件・収束・実行・結果 |

壁の実解析モデルは[壁の非線形モデル](06_壁の非線形モデル.md)、断面検定の参考骨格は[RC部材の耐震壁骨格](05_RC_部材_非線形復元力特性.md#耐震壁せん断非線形トリリニア)を正とし、両者を区別します。[仕口パネル](07_仕口パネルの復元力.md)と[免震・制振ばね](08_免震制振ばねの復元力.md)は各部の復元力を扱います。GUIの支承・ダンパー入力は[免震・制振](../calc_basis/09_免震制振/README.md)を参照してください。
