# 免震・制振ばねの復元力

各特性にはバイリニア・摩擦・マクスウェル要素の力学モデルを採用し、製品別に設定した係数と入力条件を用います。製品固有の係数は対応する製品の適用条件に限り、他製品へ一般化しません。

免震支承（積層ゴム）は各方向独立バイリニアとし、摩擦支承は \\( Q\_{\max} = \mu \cdot N \\)（長期軸力）を 2 次元摩擦で射影します。歪依存は次式によります。

\\[ Q\_d(\gamma) = Q\_{d0} \cdot C\_{Qd}(\gamma) \\]

\\[ K\_2(\gamma) = K\_{2,0} \cdot C\_{Kd}(\gamma) \\]

マクスウェルダンパーはバネ Kd と粘性ダッシュポットの直列（後退 Euler、線形 \\( \alpha = 1 \\) かつリリーフなしは閉形式、それ以外はスカラー Newton）とします。時間刻み \\( \Delta t \le 0 \\)（静的・線形解析）では不活性（力・剛性 0）とします。ダッシュポット力は、リリーフ速度 \\( V\_r \\) を指定しない場合は次式です。

\\[ F\_c = C\_0 \cdot \operatorname{sign}(V) \cdot |V|^\alpha \\]

リリーフ速度 \\( V\_r \\)（オイルダンパーのバイパス弁による頭打ち特性）を指定した場合、
リリーフ後の減衰係数比 \\( C\_2/C\_1 \\) による折れ線とします。

\\[
F\_c =
\begin{cases}
C\_0 \cdot \operatorname{sign}(V) \cdot |V|^\alpha & (|V| \le V\_r) \\
\operatorname{sign}(V) \cdot \left( C\_0 \cdot V\_r^\alpha + C\_2 \cdot (|V| - V\_r) \right) & (|V| > V\_r)
\end{cases}
\\]

ここで \\( C\_1 = C\_0 \cdot \alpha \cdot V\_r^{\alpha-1} \\)（リリーフ速度における接線減衰係数）、
\\( C\_2 = (C\_2/C\_1) \cdot C\_1 \\) です。リリーフ点で力は連続（\\( C\_0 \cdot V\_r^\alpha \\) に一致）、
勾配は \\( C\_1 \\) から \\( C\_2 \\) へ不連続に低下します。

免震支承の回転自由度は \\( 10^{12} \\) N·mm/rad の剛でモーメントを伝達します。摩擦ばねの滑り後の残留せん断剛性比は \\( 10^{-4} \\) とします。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( Q\_d(\gamma) \\) | 免震支承の切片荷重（ひずみ依存） | N |
| \\( Q\_{d0} \\) | 基準（ひずみ 0 相当）の切片荷重 | N |
| \\( K\_2(\gamma) \\) | 免震支承の降伏後剛性（ひずみ依存） | N/mm |
| \\( K\_{2,0} \\) | 基準（ひずみ 0 相当）の降伏後剛性 | N/mm |
| \\( C\_{Qd}(\gamma),\ C\_{Kd}(\gamma) \\) | 切片荷重・降伏後剛性のひずみ依存係数 | - |
| \\( \gamma \\) | 免震支承のせん断ひずみ | - |
| \\( Q\_{\max} \\) | 摩擦支承の最大水平力 | N |
| \\( \mu \\) | 摩擦係数 | - |
| \\( N \\) | 長期軸力（圧縮正） | N |
| \\( F\_c \\) | マクスウェルダンパーのダッシュポット力 | N |
| \\( C\_0 \\) | 基準の粘性減衰係数 | N·(s/mm)^α |
| \\( V \\) | ダンパーの相対速度 | mm/s |
| \\( \alpha \\) | 速度の指数 | - |
| \\( V\_r \\) | リリーフ速度 | mm/s |
| \\( C\_1,\\ C\_2 \\) | リリーフ前後の接線減衰係数 | N·s/mm |
