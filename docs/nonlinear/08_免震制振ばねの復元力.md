# 免震・制振ばねの復元力

各特性にはバイリニア・摩擦・マクスウェル要素の力学モデルを採用し、製品別に設定した係数と入力条件を用います。製品固有の係数は対応する製品の適用条件に限り、他製品へ一般化しません。

## ゴム系支承のひずみ依存

GUIの選択肢・入力・既定値は[免震アイソレータ](../calc_basis/09_免震制振/01_免震アイソレータ.md)を正とします。天然ゴム・LRB・HDRは共通の二方向独立バイリニアで、ひずみ依存を有効にすると水平二方向の相対変位uy、uz [mm]の合成量とゴム総厚H [mm]から

\\[ \gamma=\frac{\sqrt{u_y^2+u_z^2}}{H},\qquad C(\gamma)=\max(0,c_0+c_1\gamma+c_2\gamma^2) \\]

を求めます。CKdとCQdそれぞれに係数を入力し、次式で特性耐力と二次剛性を更新します。

\\[ Q_d(\gamma)=Q_{d0}C_{Qd}(\gamma),\qquad K_2(\gamma)=K_{2,0}C_{Kd}(\gamma) \\]

QdはGUIの「特性耐力」で、降伏しきい値として用います。ライブラリ専用LRB式の切片荷重とは区別してください。更新後の特性耐力には下限10⁻⁹ N、二次剛性には0〜0.999K1の制限があります。初期剛性K1にも下限10⁻⁹ N/mmを設けます。これらの数値処理を製品特性の保証とは扱いません。

## 水平二方向の滑り条件

弾性すべり支承は入力した長期圧縮軸力N [N]と摩擦係数μから限界合力を求めます。

\\[ Q_{\max}=\max(\mu,0)\max(N,0) \\]

直前までの塑性すべりを控除した相対変位にK1を乗じた弾性予測力をFy、Fz [N]とすると、合力 \\(\sqrt{F_y^2+F_z^2}\\) がQmax以下なら滑りません。限界を超える場合は、同じ方向を保って水平力ベクトルをQmaxの円へ射影します。一方向ごとにμNを負担させる矩形の滑り条件ではありません。合力が10⁻¹² N未満のときは弾性側として扱います。

滑り後の残留せん断接線剛性比は10⁻⁴です。力は摩擦限界への射影値であり、この比を力の上限超過や追加耐力として解釈しません。接線は各方向の対角成分で近似し、射影の二方向連成微分をすべて表す整合接線ではありません。一般の二方向応答の精度・安全側は未確認です。

免震支承の回転自由度は \\(10^{12}\\) N·mm/rad の剛性でモーメントを伝達します。

## 制振ダンパー

種類・入力・既定値とマクスウェル／履歴型の採用式は[制振ダンパー](../calc_basis/09_免震制振/02_制振ダンパー.md)を正とします。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( Q\_d(\gamma) \\) | 免震支承の特性耐力（ひずみ依存） | N |
| \\( Q\_{d0} \\) | 基準（ひずみ 0 相当）の特性耐力 | N |
| \\( K\_2(\gamma) \\) | 免震支承の降伏後剛性（ひずみ依存） | N/mm |
| \\( K\_{2,0} \\) | 基準（ひずみ 0 相当）の降伏後剛性 | N/mm |
| \\( C\_{Qd}(\gamma),\ C\_{Kd}(\gamma) \\) | 特性耐力・降伏後剛性のひずみ依存係数 | - |
| \\( \gamma \\) | 免震支承のせん断ひずみ | - |
| \\( Q\_{\max} \\) | 摩擦支承の最大水平力 | N |
| \\( \mu \\) | 摩擦係数 | - |
| \\( N \\) | 長期軸力（圧縮正） | N |
