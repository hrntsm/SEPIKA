# 免震・制振

本章では、免震支承材（積層ゴム、鉛プラグ入り、高減衰、すべり、転がり、球面すべり）、制振ダンパー（オイル／マクスウェル型、履歴型）、座屈拘束ブレース（BRB）の力学モデルと係数の採用条件を示します。
バイリニア・摩擦・マクスウェル要素等の力学モデルを採用します。製品別の係数・認定値はCategory Bとして扱い、各モデルに対応する製品と入力条件に限って用います。同じ構造形式の製品全般への適用を保証するものではありません。

要素剛性としての組込みは[ばね要素](../04_要素剛性/07_ばね要素.md#ばね要素免震制振節点ばね支点ばね)に示し、設計計算は `sepika_design_jp::{isolator, brb}` が担当します。
