# 免震・制振

本章では、免震支承材（積層ゴム、鉛プラグ入り、高減衰、すべり、転がり、球面すべり）、制振ダンパー（オイル／マクスウェル型、履歴型）の力学モデルと係数の採用条件を示します。
バイリニア・摩擦・マクスウェル要素等の力学モデルを採用します。製品別の係数・認定値はCategory Bとして扱い、各モデルに対応する製品と入力条件に限って用います。同じ構造形式の製品全般への適用を保証するものではありません。

要素の復元力と速度依存性は[免震・制振ばねの復元力](../../nonlinear/08_免震制振ばねの復元力.md)、座屈拘束ブレースの許容軸力・限界長さは[BRBの断面検定](../06_一次設計/06_座屈拘束ブレース.md)を参照してください。
