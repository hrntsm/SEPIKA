# 免震・制振

GUIで選べる免震支承（天然ゴム、LRB、HDR、弾性すべり）と制振ダンパー（マクスウェル型、履歴型）の入力・既定値・採用モデルを示します。製品別係数は対象製品の適用条件に限って用います。

免震のひずみ依存と二方向滑りは[免震・制振ばねの復元力](../../nonlinear/08_免震制振ばねの復元力.md)、ダンパーの速度依存とリリーフは[制振ダンパー](02_制振ダンパー.md)を正とします。座屈拘束ブレースの許容軸力・限界長さは[BRBの断面検定](../06_一次設計/06_座屈拘束ブレース.md)を参照してください。
