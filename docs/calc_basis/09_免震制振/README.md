# 制振

[制振ダンパー](02_制振ダンパー.md)では、マクスウェル型と履歴型の入力、既定値、復元力の算定方法を説明します。

座屈拘束ブレースの許容軸力・限界長さは[BRBの断面検定](../06_一次設計/06_座屈拘束ブレース.md)を参照してください。

## 免震支承の対応終了

天然ゴム系積層ゴム、鉛プラグ入り積層ゴム（LRB）、高減衰ゴム系積層ゴム（HDR）、弾性すべり支承の対応は終了しました。これらを含む旧プロジェクトは[読込時にエラーになります](../../model_io/01_プロジェクト形式_ovika.md#gui-からの操作)。

## 確認したい内容から選ぶ

- ダンパーを選び、速度依存・履歴特性を指定する：[制振ダンパー](02_制振ダンパー.md)
