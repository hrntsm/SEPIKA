# 制振ダンパー

制振ダンパーの復元力特性を、標準的な力学モデル（マクスウェル要素・弾塑性バイリニア）で算定します。

## 選択・入力と既定値

「制振要素（ダンパー定義プリセット）」で種類と諸元を登録し、「部材」でダンパーを追加するときに定義を選べます。部材一覧では割り当て済み諸元を個別に変更できます。

| 種類 | 入力（GUI表示単位） | 新規入力の既定値 |
| --- | --- | --- |
| マクスウェル（速度依存） | Kd [kN/mm]、C0 [kN·(s/mm)^α]、速度指数α | Kd=100、C0=1、α=1 |
| 履歴型バイリニア（鋼材系） | Kd=k1 [kN/mm]、降伏軸力Qy [kN]、第2剛性比k2/k1 | Kd=100、Qy=50、k2/k1=0.02 |

初期種別はマクスウェルです。プリセット編集の「リリーフ特性を有効化」は既定で無効で、有効化時はVr=200 mm/s、C2/C1=0.1から入力します。既定値は製品の推奨値ではありません。

## 諸元の複写と編集の反映範囲

プリセットを部材へ割り当てると、その時点の諸元を複写します。プリセットの更新・削除は、割り当て済み部材へ自動追随しません。既存部材を変更するには、部材一覧で個別編集するか、「一覧の全ダンパーへ一括適用」で定義を選び「この一覧の全ダンパーへ適用」を押します。適用時に一覧へ表示されている全ダンパーの諸元を複写し直します。

リリーフ条件はプリセット編集で設定します。部材一覧の個別編集は種類・Kd・C0・α・Qy・k2/k1が対象で、リリーフの入力欄はありません。プリセット更新後にリリーフ条件を既存部材へ反映する場合も、明示的な再適用が必要です。

## 採用式と解析への適用

マクスウェル型は正の時間刻みを与える時刻歴で作用し、時間刻みを与えない静的・線形解析では不活性です。履歴型は静的・動的の両方で作用します。

### マクスウェル型の直列適合条件

ばねと粘性ダッシュポットを直列接続します。下図の区間ごとに伸びを定義し、装置全体の伸びを \\(u\\)、ばね部を \\(u_s\\)、ダッシュポット部を \\(u_d\\) とします。いずれも伸びを正とし、共通の軸力 \\(F\\) は引張を正とします。

```text
i o---[ Kd ]---o---[ Fc(vd) ]---o j
  |<-- us --->|<----- ud ----->|
  |<----------- u ----------->|
```

図の i・j は装置の両端、中央の○はばねとダッシュポットの接続点です。

変形の適合条件と軸力の釣合いは次式です。

\\[ u=u_s+u_d \\]

\\[ F=K_d u_s=F_c(v_d), \qquad v_d=\dot{u}_d \\]

力則に用いる速度 \\(v_d\\) は**ダッシュポット部の変形速度**です。装置全体の相対速度 \\(\dot{u}=\dot{u}_s+v_d\\) と区別します。

### ダッシュポットの力則とリリーフ特性

リリーフなしでは、正の粘性係数 \\(C_0\\) と速度指数 \\(\alpha>0\\) を用います。理論式では \\(F_c(0)=0\\) です。

\\[ F_c(v_d)=C_0\\,\mathrm{sign}(v_d)\\,|v_d|^\alpha \\]

リリーフを有効にするときは、正のリリーフ速度 \\(V_r\\) と減衰係数比 \\(r=C_2/C_1\\)（GUI入力範囲 \\(0\le r\le1\\)）を指定します。折点の力 \\(F_r\\) と接線減衰係数は次式で定義します。

\\[
F_r=C_0V_r^\alpha,\qquad
C_1=C_0\alpha V_r^{\alpha-1},\qquad C_2=rC_1
\\]

\\[
F_c(v_d)=
\begin{cases}
C_0\\,\mathrm{sign}(v_d)\\,|v_d|^\alpha & (|v_d|\le V_r),\\\\
\mathrm{sign}(v_d)\left(F_r+C_2(|v_d|-V_r)\right) & (|v_d|>V_r).
\end{cases}
\\]

折点 \\(v_d=\pm V_r\\) で力は \\(\pm F_r\\) に連続し、折点直前の接線勾配 \\(C_1\\) から直後の \\(C_2\\) に変わります。以下は \\(\alpha=1\\)、\\(0<r<1\\) の正速度側の模式図です。負速度側は原点対称です。\\(\alpha\ne1\\) ではリリーフ前がべき乗曲線となり、\\(C_1\\) はその折点での接線勾配です。

リリーフ無効時は全速度域でリリーフなしの力則を用います。\\(r=0\\) はリリーフ後の力が一定となり、\\(r=1\\) は折点前後の接線勾配が等しくなります。\\(V_r=0\\) は有効なリリーフ速度として扱わず、リリーフなしとなります。

### 後退Eulerによる時間更新

時間刻み \\(\Delta t=t_{n+1}-t_n>0\\) に対し、前ステップで確定した \\(u_{d,n}\\) と今回の装置全体の伸び \\(u_{n+1}\\) から、今回の \\(u_{d,n+1}\\) を求めます。

\\[ v_{d,n+1}=\frac{u_{d,n+1}-u_{d,n}}{\Delta t} \\]

\\[
K_d(u_{n+1}-u_{d,n+1})
-F_c\left(\frac{u_{d,n+1}-u_{d,n}}{\Delta t}\right)=0
\\]

求めた変形から \\(u_{s,n+1}=u_{n+1}-u_{d,n+1}\\)、\\(F_{n+1}=K_du_{s,n+1}\\) を評価します。釣合いが確定したら \\(u_{d,n+1}\\) を次ステップへ引き継ぎます。

\\(\alpha=1\\) かつリリーフなしの場合、上の離散釣合い式は次の閉形式になります。これは**後退Eulerの離散式の解**であり、連続時間の厳密解ではありません。

\\[
u_{d,n+1}=\frac{C_0u_{d,n}+\Delta t K_du_{n+1}}{C_0+\Delta t K_d}
\\]

それ以外はスカラーNewton反復で評価します。マクスウェル型は時刻歴解析の正の時間刻みで作用し、時間刻みを与えない静的・線形解析（\\(\Delta t\le0\\)）では不活性（力・剛性0）です。

零速度近傍では、力則と速度に関する接線係数の評価に用いる速度の絶対値に \\(10^{-12}\\,\mathrm{mm/s}\\) の下限を設けます。特に \\(0<\alpha<1\\) で接線係数が発散することを避ける数値処理であり、装置の物理的な不感帯ではありません。この下限によって、力則の数値評価は零速度を含む下限未満の領域で理論式と一致しない場合があります。

### 1ステップの計算例

\\(\alpha=1\\)、リリーフなしとして、GUI表示単位で次の値を与えます。

| 量 | 値 |
| --- | --- |
| ばね剛性 \\(K_d\\) | 100 kN/mm |
| 粘性係数 \\(C_0\\) | 1 kN·s/mm |
| 時間刻み \\(\Delta t\\) | 0.01 s |
| 前ステップのダッシュポット部の伸び \\(u_{d,n}\\) | 0 mm |
| 今回の装置全体の伸び \\(u_{n+1}\\) | 1 mm |

上の離散閉形式に代入します（分子の単位は kN·s、分母は kN·s/mm）。

\\[
u_{d,n+1}=\frac{1\times0+0.01\times100\times1}{1+0.01\times100}
=0.5\\,\mathrm{mm}
\\]

\\[
u_{s,n+1}=1-0.5=0.5\\,\mathrm{mm},\qquad
v_{d,n+1}=\frac{0.5-0}{0.01}=50\\,\mathrm{mm/s}
\\]

ばね力と粘性力の双方が同じ引張力となり、変形の和も装置全体の伸びに一致します。

\\[
K_du_{s,n+1}=100\\,\mathrm{kN/mm}\times0.5\\,\mathrm{mm}=50\\,\mathrm{kN}
\\]

\\[
F_c(v_{d,n+1})=1\\,\mathrm{kN\cdot s/mm}\times50\\,\mathrm{mm/s}=50\\,\mathrm{kN}
\\]

### 記号・単位

GUIでは力をkN系で表示し、内部計算ではN系を用います。変位mm、時間s、速度mm/sは共通です。\\(K_d\\) と \\(C_0\\) のGUI入力値をそれぞれ1000倍して内部値とするため、上例は \\(K_d=100000\\,\mathrm{N/mm}\\)、\\(C_0=1000\\,\mathrm{N\cdot s/mm}\\)、\\(F=50000\\,\mathrm{N}=50\\,\mathrm{kN}\\) です。

| 記号 | 意味 | GUI表示単位 | 内部計算単位 |
| --- | --- | --- | --- |
| \\(u,u_s,u_d\\) | 装置全体・ばね部・ダッシュポット部の伸び（伸び正） | mm | mm |
| \\(F,F_c,F_r\\) | 共通軸力・ダッシュポット力・正側折点の力（引張正） | kN | N |
| \\(K_d\\) | 直列ばね剛性 | kN/mm | N/mm |
| \\(C_0\\) | 基準の粘性減衰係数 | kN·(s/mm)^α | N·(s/mm)^α |
| \\(v_d\\) | ダッシュポット部の変形速度 | mm/s | mm/s |
| \\(\alpha\\) | 速度の指数 | - | - |
| \\(V_r\\) | リリーフ速度 | mm/s | mm/s |
| \\(C_1,C_2\\) | 折点直前・リリーフ後の接線減衰係数 | kN·s/mm | N·s/mm |
| \\(r=C_2/C_1\\) | リリーフ後の減衰係数比 | - | - |
| \\(\Delta t\\) | 時間刻み | s | s |

### 履歴型

初期軸剛性k1=Kd、降伏軸力Qy、二次剛性k2=(k2/k1)Kdの移動硬化バイリニア軸ばねです。静的・動的の両方で作用します。鋼材系／鉛／U形などの入力諸元を、この共通モデルで扱います。
