# 免震アイソレータ

## GUIで選べる支承と入力

「境界条件」の「免震支承の配置」、または「部材」の免震支承追加で次の4種を選びます。配置済みの種別・剛性・特性耐力・摩擦係数は「部材」の免震支承一覧で変更できます。摩擦力算定用の長期軸力は新規配置時に入力します。一覧でゴム系から弾性すべり支承へ種別を変更しても、保存済みの長期軸力を引き継ぎます。

| 支承種別 | 局所x軸に直交する面の復元力 | 解析に用いる入力 |
| --- | --- | --- |
| 天然ゴム系積層ゴム | 二方向独立の移動硬化バイリニア | K1、K2、Qd、Kv、任意のHとひずみ依存係数 |
| 鉛プラグ入り積層ゴム(LRB) | 同上 | 同上 |
| 高減衰ゴム系積層ゴム(HDR) | 同上 | 同上 |
| 弾性すべり支承 | 二方向の合力による摩擦 | すべり前剛性K1、μ、長期圧縮軸力N、Kv |

種別の切替えだけでは製品別の剛性・耐力・摩擦係数やひずみ依存係数を設定しません。対象製品の適用条件に対応する諸元を入力してください。LRBとHDRも、入力したバイリニア特性を用います。

| 入力 | 意味・単位（GUI表示） | 新規入力の既定値 |
| --- | --- | --- |
| K1 | 局所y・z方向の初期剛性／すべり前剛性 [kN/mm] | 1 |
| K2 | 局所y・z方向の二次剛性 [kN/mm]（ゴム系） | 0.1 |
| Qd | 特性耐力 [kN]（ゴム系の降伏しきい値） | 50 |
| Kv | 局所x方向の弾性剛性 [kN/mm] | 2000 |
| μ | 摩擦係数（すべり支承） | 0.1 |
| N | 摩擦力算定用の長期軸力 [kN]、圧縮正 | 0 |
| n | マルチシアスプリング本数、表示・低減率照合用 | 8 |
| H | ゴム総厚 [mm] | 0（ひずみ依存なし） |
| CKd、CQdのc0、c1、c2 | ひずみ依存の二次多項式係数、無次元 | ともに [1, 0, 0] |

初期種別は天然ゴム系積層ゴムです。ゴム系のK1、K2、Qdには局所y・z各軸の諸元を入力します。既定値は製品の推奨値や設計値ではありません。

本数nは低減率の参考表示に使います。GUIは1本や奇数本でも低減率を表示します。係数を照合した範囲は、等角度に配置した2本以上の偶数本ばねを基準方向の一軸特性に合わせる場合です。解析では本数や表示の係数による剛性・耐力の補正は行いません。

## 解析で採用する復元力

零長の支点配置では局所x軸を全体鉛直方向に取ります。長さのある部材では、2節点を結ぶ方向が局所x軸です。Kvは局所x軸に沿い、二方向の復元力は局所y・z軸が張る直交面で働きます。以下の「鉛直」「水平」は、零長の支点配置または2節点を鉛直に揃えた部材に対応します。

以下の降伏・滑りを評価するのは増分解析と非線形時刻歴応答解析です。線形解析は初期接線剛性を用います。

ゴム系3種は共通のバイリニアモデルで、局所水平二軸それぞれに塑性変形履歴を持ちます。弾性範囲では同じ初期剛性を両軸に使います。降伏後は同じ変位の大きさでも方向によって水平復元力が異なります。二方向載荷時に支承の連成降伏特性が必要な場合は、このモデルをその評価に用いず、対象支承の試験結果と使用するモデルの適用性を別途確認してください。ひずみ依存を指定した場合は、水平変位の合成量から求めた共通の係数を両軸に適用します。

Hを正値にすると「歪依存係数（任意・詳細）」でCKdとCQdを編集できます。実際の採用式は[免震・制振ばねの復元力](../../nonlinear/08_免震制振ばねの復元力.md)の二次多項式です。Hが0以下、または両係数が既定 [1, 0, 0] の場合はひずみ依存なしです。

弾性すべり支承では、水平二方向の合力に対して[摩擦限界と滑り条件](../../nonlinear/08_免震制振ばねの復元力.md#水平二方向の滑り条件)を適用します。対象のすべり面が圧縮接触を保ち、固定した長期圧縮軸力と一定の摩擦係数で対象応答を評価できることを、支承の認定資料・試験条件および荷重条件に照らして確認してください。長期軸力は手入力で、解析で得た鉛直反力による更新はありません。長期軸力が既定の0のままでは摩擦限界も0です。

鉛直方向ではKvの弾性ばねが圧縮・引張の両側で作用し、回転方向では \\(10^{12}\\) N·mm/rad の剛性でモーメントを伝達します。地震・積載荷重などの変動で摩擦力が有意に変わる場合や、引張・浮上り・再接触が生じる場合の応答評価には適用できません。認定資料に定める面圧・速度などの条件と使用する摩擦係数の対応を確認してください。

## 自動適用しない製品式・補正

LRB統一型の区分冪乗式、20℃基準の温度補正はGUI配置に接続していません。GUIでLRB・HDRを選んでもこれらを自動適用せず、温度から係数を補完しません。これらはライブラリ専用計算であり、GUIの二次多項式と同じ式ではありません。

製品固有の係数の原典照合と適用条件の確認には未確認事項があり、入力できることは実験的精度や安全側の保証を意味しません。配置操作は[免震支承の配置](../../model_edit/14_免震支承の配置.md)を参照してください。
