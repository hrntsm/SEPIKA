# 免震アイソレータ

## GUIで選べる支承と入力

「境界条件」の「免震支承の配置」、または「部材」の免震支承追加で次の4種を選びます。配置済みの諸元は「部材」の免震支承一覧で変更します。

| 支承種別 | 水平復元力 | 必要な入力 |
| --- | --- | --- |
| 天然ゴム系積層ゴム | 二方向独立の移動硬化バイリニア | K1、K2、Qd、Kv、n、任意のHとひずみ依存係数 |
| 鉛プラグ入り積層ゴム(LRB) | 同上 | 同上 |
| 高減衰ゴム系積層ゴム(HDR) | 同上 | 同上 |
| 弾性すべり支承 | 水平二方向の合力による摩擦 | すべり前剛性K1、μ、長期圧縮軸力N、Kv |

種別の切替えだけでは製品別の剛性・耐力・摩擦係数やひずみ依存係数を設定しません。対象製品の適用条件に対応する諸元を入力してください。LRBとHDRも、入力したバイリニア特性を用います。

| 入力 | 意味・単位（GUI表示） | 新規入力の既定値 |
| --- | --- | --- |
| K1 | 水平初期剛性／すべり前剛性 [kN/mm] | 1 |
| K2 | 水平二次剛性 [kN/mm]（ゴム系） | 0.1 |
| Qd | 特性耐力 [kN]（ゴム系の降伏しきい値） | 50 |
| Kv | 鉛直弾性剛性 [kN/mm] | 2000 |
| μ | 摩擦係数（すべり支承） | 0.1 |
| N | 摩擦力算定用の長期軸力 [kN]、圧縮正 | 0 |
| n | マルチシアスプリング本数、表示・低減率照合用 | 8 |
| H | ゴム総厚 [mm] | 0（ひずみ依存なし） |
| CKd、CQdのc0、c1、c2 | ひずみ依存の二次多項式係数、無次元 | ともに [1, 0, 0] |

初期種別は天然ゴム系積層ゴムです。本数nは入力値を保持しますが、解析では水平二方向のばねを用い、本数による剛性・耐力の低減率を自動適用しません。既定値は製品の推奨値や設計値ではありません。

## 解析で採用する復元力

ゴム系3種は共通のバイリニアモデルで、水平方向ごとに塑性変形履歴を持ちます。ひずみ依存を指定した場合は水平変位の合成量から共通の係数を求めるため、二方向がその係数を介して連動します。二方向の連成降伏面を持つモデルではありません。

Hを正値にすると「歪依存係数（任意・詳細）」でCKdとCQdを編集できます。実際の採用式は[免震・制振ばねの復元力](../../nonlinear/08_免震制振ばねの復元力.md)の二次多項式です。Hが0以下、または両係数が既定 [1, 0, 0] の場合はひずみ依存なしです。

すべり支承の摩擦限界は \\(Q_{\max}=\mu\max(N,0)\\) です。Nは入力した長期軸力を固定して用い、解析中の変動軸力へ追随しません。Nの既定0では摩擦限界も0です。滑りの判定は各方向別ではなく水平二方向の合力によります。[滑り条件と残留接線](../../nonlinear/08_免震制振ばねの復元力.md#水平二方向の滑り条件)を参照してください。

鉛直方向はKvの弾性ばね、回転方向は \\(10^{12}\\) N·mm/rad の剛性でモーメントを伝達します。浮上り・引張時の支承特性や軸力変動による摩擦変化を自動評価するモデルではありません。

## 自動適用しない製品式・補正

LRB統一型の区分冪乗式、20℃基準の温度補正、転がり支承・球面すべり支承の摩擦式、製品別HDRのひずみ多項式はGUI配置に接続していません。GUIでLRB・HDRを選んでもこれらを自動適用せず、温度・面圧・速度から係数を補完しません。これらはライブラリ専用計算であり、GUIの二次多項式と同じ式ではありません。

製品固有の係数の原典照合と適用条件の確認には未確認事項があり、入力できることは実験的精度や安全側の保証を意味しません。配置操作は[免震支承の配置](../../model_edit/14_免震支承の配置.md)を参照してください。
