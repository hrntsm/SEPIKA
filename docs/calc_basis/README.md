# 計算根拠の読み方

このセクションは、SEPIKA が行う各計算について、どの基準や法令のどの式で算定しているかを体系的に示します。

構造計算一貫プログラムは、応力や変形、検定比、保有水平耐力といった出力を、法令や規準に定められた根拠に基づいて算定したものだと説明できなければなりません。
このセクションは「なぜその値になるのか」、すなわち法令、規準、力学の根拠を扱います。

## この章で確認できる内容

- 各計算が依拠する法令・告示の条項と、学会規準・指針の式
- 画面に表示するときの単位（換算表）
- 共通の主な記号と、各ページの主要な記号・単位
- 各計算に対応する実装コードへの参照（実装参照）

## 法令・規準との関係

### 法的根拠の全体像

日本の建築構造計算は次の階層で規定されるため、SEPIKA はこの体系に沿って計算を構成しています。

```
建築基準法 20条（構造耐力）
   └ 建築基準法施行令 第3章第8節（構造計算）
        ├ 第82条〜第82条の4 … 保有水平耐力計算
        │   ├ 第82条       … 保有水平耐力計算
        │   ├ 第82条の2    … 層間変形角（法令上の上限。画面は設定値との参考比較）
        │   ├ 第82条の3    … 保有水平耐力（Qu ≧ Qun = Ds·Fes·Qud）
        │   └ 第82条の4    … 屋根ふき材等の構造計算
        ├ 第82条の5         … 限界耐力計算
        ├ 第82条の6         … 許容応力度等計算
        │   └ 第1号で第82条各号・第82条の2・第82条の4を参照
        ├ 令85〜86条        … 積載荷重・積雪荷重
        ├ 令88条            … 地震力（C0・Ci・Z・Rt・Ai）
        ├ 令89〜94条        … 材料の許容応力度・材料強度（鋼・コンクリート・鉄筋等）
        ├ 令96・98条        … 溶接・材料強度
   └ 告示
        ├ 昭55建告1793号    … Z（地域係数）・Rt（振動特性係数）・Ai（高さ方向分布）
        ├ 昭55建告1792号    … Ds（構造特性係数）・Fes（形状係数 Fs・Fe）
        ├ 平12建告1455号    … 積雪（区域・単位荷重・多雪区域）
        └ 平12建告1458号    … 保有水平耐力に関する基準 等
```

### 学会規準・指針

法令が直接には数値を与えない部材耐力式などは、次の学会規準や指針を根拠とします。

**RC 規準**：日本建築学会『鉄筋コンクリート構造計算規準・同解説』。

**鋼構造規準**：日本建築学会『鋼構造設計規準』および『鋼構造許容応力度設計規準』。

**塑性設計指針**：日本建築学会『鋼構造塑性設計指針』。

**靭性保証型指針**：日本建築学会『鉄筋コンクリート造建物の靭性保証型耐震設計指針・同解説』。

**終局強度型指針**：日本建築学会『鉄筋コンクリート造建物の終局強度型耐震設計指針・同解説』。

**技術基準解説書**：『建築物の構造関係技術基準解説書』（国土交通省住宅局建築指導課ほか監修）。

**SRC 規準**：日本建築学会『鉄骨鉄筋コンクリート構造計算規準』。

**CFT 指針**：『コンクリート充填鋼管（CFT）構造設計・施工指針』。

### 出典の分類（Category A / B）

本ソフトが用いる数値や式は、次のように区分します。

**Category A（法令・告示の公開値）**：誰でも原典（法令や告示）で照合できる値を指すため、このセクションはこれらを条番号や式番号まで明示します。

**Category B（学会規準・私的規準の係数）**：学会規準や指針に基づく部材耐力式の係数などを指すため、出典の文献名とページを併記し、利用組織がライセンスや実測で確定すべき旨を明記します。

**力学の閉形式**：ティモシェンコ梁剛性、CMQ、Newmark 更新式のような教科書的な力学式を指すため、原典照合ではなく、理論解と一致するかどうかを検証します。

このほか、規準・指針が式を直接与えない実務的取扱い（床荷重の分配、壁エレメント置換、剛床への荷重按分など）は「実務慣用」と明記します。
製品固有の係数（免震・制振部材のアイソレータ・ダンパー・座屈拘束ブレース等）はCategory Bとして扱い、対応する製品別の採用値・認定値と適用条件を用います。同じ構造形式という理由だけで別製品へ一般化しません。

## 単位系

各ページの記号・単位表および算定式は、**法令・告示・学会規準が用いる単位**で記載します。
法令が m で定める建物高さ・地下階の深さなども、原典どおり m で書きます。
荒川式のように工学単位系（kgf/cm²）で導出された実験式は、単位換算（1 kgf/cm² = 0.0980665 N/mm²、1 kgf = 9.80665 N）を施してから評価します。

**画面に表示する単位**は、量ごとに実務の慣例へ合わせて換算します。

| 量 | 画面に表示する単位 |
|---|---|
| 力（軸力・せん断力・重量） | kN |
| モーメント | kN·m |
| 単位幅あたりモーメント | kN·m/m |
| 階高・建物高さ・スパン | m |
| 断面寸法・鉄筋径・変位 | mm |
| 応力度・材料強度 | N/mm² |
| 面荷重（床・雑壁） | kN/m² |
| 断面積 A・せん断有効断面積 As | cm² |
| 断面二次モーメント I・ねじり定数 J | cm⁴ |
| 断面係数 Z（弾性・塑性） | cm³ |
| 断面二次半径 i | cm |
| バネ定数・線剛性 | kN/mm |
| 粘性係数 C0（マクスウェル） | kN·(s/mm)^α |

断面性能を cm 系で示すのは、JIS 形鋼表の慣例に合わせるためです。
同じ量は、どの画面でも同じ単位で表示します。
該当する箇所は各ページで明記します。

## 記号の扱い

主な記号は次のとおりです。

| 記号 | 意味 | 記号 | 意味 |
|------|------|------|------|
| `F` | 鋼材の基準強度（F 値） | `Fc` | コンクリート設計基準強度 |
| `σy` / `σwy` | 主筋／せん断補強筋の降伏強度 | `pt` / `pw` | 引張鉄筋比／せん断補強筋比 |
| `E` / `G` | ヤング係数／せん断弾性係数 | `A` / `I` / `Z` / `Zp` | 断面積／断面二次モーメント／断面係数／塑性断面係数 |
| `M` / `Q` / `N` | 曲げ／せん断力／軸力 | `Mu` / `Qmu` / `Qsu` | 終局曲げ耐力／曲げ終局時せん断力／終局せん断耐力 |
| `Ci` | i 層の地震層せん断力係数 | `Qud` | 地震時の設計用層せん断力 |
| `Ds` | 構造特性係数 | `Fes` | 形状係数（Fs·Fe） |

各ページには、そのページの式を読むために必要な主要な記号と単位の表も置きます。
各ページの記号・単位表および算定式は、法令・告示・学会規準が用いる単位で記載します。
画面に表示する単位は、上記「単位系」の換算表で対応を示します。

## 実装参照の読み方

このセクションの各ページには、その説明に対応する実装箇所を示す `<div class="impl-ref">` の表示が入ります。中には、次のように関数・モジュール名とソースファイルを書きます。

```
**実装参照**：`sepika_xxx::module::item`（`crates/...`）が…します。
```

この表示は警告やエラーではありません。計算を実装しているコードへたどるための入口を示すものです。
行番号は、コードの変更で陳腐化するため書きません。コードを確認するときは、示された関数名やファイルパスをコード検索でたどってください。

このドキュメントは実装が依拠する根拠を説明するものであり、個々の建築物の設計における式の適用可否（適用範囲や前提条件）の判断は、設計者（構造設計一級建築士等）の責任に属します。
