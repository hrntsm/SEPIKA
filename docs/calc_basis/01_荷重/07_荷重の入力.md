# 入力荷重の計算条件

節点荷重と部材荷重の計算時の条件を示します。[入力操作](../../model_edit/11_荷重の入力.md)と[等価節点力・固定端内力](../04_要素剛性/03_部材荷重.md)も参照してください。

## 節点荷重

節点荷重は、節点に作用する力とモーメントを全体座標系の 6 成分で与えます。
単位は力（Fx・Fy・Fz）が N、モーメント（Mx・My・Mz）が N·mm です。

**1 つの節点に何件でも定義できます。**
たとえば同じ柱頭に載る機器の重量と吊り物の重量を別々の荷重として入力し、それぞれに名称を
付けておくと、あとからどちらがどれだけを占めていたかをたどれます。
解析では、同じ節点に載る荷重をすべて加算した値を外力とします。

<div class="impl-ref">

**実装参照**：`sepika_core::model::NodalLoad`（`crates/sepika-core/src/model/load.rs`）が 6 成分と名称を保持し、同一節点の荷重の加算は `sepika_solver::common::assemble::assemble_global_f`（`crates/sepika-solver/src/common/assemble.rs`）が行います。

</div>


## 部材荷重の計算条件

### 作用方向の計算条件

集中・分布のどちらも、作用方向は内部で単位方向へ正規化してから強度と組み合わせます。[0,0,-1] と [0,0,-2] は同じ下向き荷重です。入力した方向成分は書き換えません。

計算には、方向の全成分が有限で、成分の平方和の平方根として計算したノルムが有限かつ 1e-12 以上であることを要求します。全荷重ケースの部材荷重を対象に確認し、不成立なら荷重ケース・荷重の添字と名称・対象部材・理由を示して計算を拒否します。強度が 0 の荷重も方向の検査対象です。

ゼロ方向、ノルムが 1e-12 未満の方向、平方和がオーバーフローする巨大な方向、非有限成分を含む方向は計算できません。この境界は既存の数値正規化の適用条件であり、構造規準の許容値や荷重を省略してよい基準ではありません。方向全体が条件を満たせば、微小な成分を含む任意方向や非単位方向も使えます。正規化の詳細は[部材荷重の作用方向](../04_要素剛性/03_部材荷重.md#作用方向)を参照してください。

方向の全成分が有限であれば、ゼロ方向など計算条件を満たさない入力も、そのまま編集・保存・再読込できます。参照先や位置・区間など、他の入力条件は引き続き適用します。計算時に既定方向へ置換したり、荷重を削除したり、強度を 0 に直したりしません。方向が成立した強度 0 の荷重、荷重のないケース、等大反対荷重の相殺、検討軸への直交による成分 0 は、方向不備とは区別します。合力 0 の分布でもモーメントが残ることがあります。

<div class="impl-ref">

**実装参照**：`sepika_core::model::Model::validate_member_load_directions`（`crates/sepika-core/src/model/load.rs`）が共通の方向条件を検査します。

</div>

### 作用位置と区間

載荷対象の材長 L は有限で 1e-9 mm より大きい必要があります。固定距離の集中荷重は有限な位置 a で 0≤a≤L、区間分布は有限な位置 a・b で 0≤a<b≤L としてください。両端の集中荷重、短い正の区間、符号付き・ゼロの強度は入力できます。

範囲外・非有限の位置、長さが 0 以下の分布区間は、追加・更新・保存・読み込み・解析前の確認で、荷重ケース・荷重の添字・対象部材と理由を示して拒否します。材長を 0.5 mm だけ超える場合も同じです。区間の切り詰めや全長追従への読み替えは行いません。これは本アプリの入力条件であり、構造規準の寸法許容値ではありません。

<div class="impl-ref">

**実装参照**：`sepika_core::model::{MemberLoad, MemberLoadKind}`（`crates/sepika-core/src/model/load.rs`）が種別・作用方向・諸元を保持し、入力 UI の既定（等分布・鉛直下向き）は `sepika_app::load_editor::MemberDraft`（`crates/sepika-app/src/load_editor.rs`）が持ちます。

</div>

### 節点の座標編集と作用区間

新規の全長等分布は**全長追従**です。全長追従では a=0、b=現在材長 L [mm]、w1=w2=w [N/mm] とし、節点編集後も強度 w、対象部材、荷重ケース、名称、全体座標の作用方向を保持します。部材が回転しても重力方向は回転しません。

合力は wL です。L=6000 mm、w=10 N/mm、方向 [0,0,-1] なら鉛直下向き 60000 N、L=8000 mm へ延長すると 80000 N、重心は新しい部材中点です。同長の平行移動では 60000 N を保ち、重心だけが移動します。総荷重を一定に保つために強度を変える扱いはしません。

集中荷重と区間分布は**固定距離**で、i 端からの位置・区間を保持します。例えば [1000,3000] mm、w1=w2=10 N/mm は延長後も同じ区間と 20000 N の合力を保持します。全長と数値が一致する固定区間も全長追従へ読み替えません。追従属性がない入力は固定距離として扱います。

固定位置・区間が材長を越える短縮や、荷重の対象部材がゼロ長になる座標編集は、荷重ケース・部材荷重の添字・対象部材・理由を示して編集全体を拒否します。区間を切り詰めたり荷重を消したりしません。複数節点の貼り付けは全座標を反映した最終形状で判断します。

更新は編集節点を共有する部材の利用者入力だけが対象で、自動生成・片持ちスラブ先端荷重は既存の準備計算で再生成します。座標と全長追従の区間は 1 回の取り消し・やり直しで一緒に戻り、保存・読み込みでも追従区分を保持します。

節点編集時の追従・強度保持・全体方向保持・不正編集の拒否はSEPIKAの採用条件です。

<div class="impl-ref">

**実装参照**：`sepika_core::model::{MemberLoadExtent, MemberLoad}`（`crates/sepika-core/src/model/load.rs`）と `sepika_edit::SetNodeCoord`（`crates/sepika-edit/src/node_member.rs`）が区分と座標編集を扱います。

</div>

### 荷重を載せられる部材

部材荷重を載せられるのは、**2 節点の線材**です。
具体的には梁・柱・ブレースと、非線形解析用の梁要素（ファイバー梁・マルチスプリング梁）が
対象になります。3D ビューでこれら以外をクリックしても選択されません。

壁・スラブのような面要素を対象から外しているのは、材軸方向という概念を持たない要素に部材
荷重を紐付けると、先頭の 2 節点を材端とみなして荷重が誤って配られるためです。
床に載る荷重は、スラブの床荷重として入力してください
（[床荷重の分配](./03_床荷重の分配.md)）。

<div class="impl-ref">

**実装参照**：対象の判定は `sepika_app::viewer::pick::member_load_pickable`（`crates/sepika-app/src/viewer/pick.rs`）と `sepika_solver::common::assemble::is_member_load_target`（`crates/sepika-solver/src/common/assemble.rs`）が同じ集合（2 節点の梁・ファイバー梁・マルチスプリング梁・ブレース）で行います。

</div>

### ブレースに載せる荷重

ブレースは軸剛性のみを持つトラス要素としてモデル化するため、材軸に直交する方向の荷重を
部材として負担できません。そこで、ブレースを対象に選んだ場合は**新規荷重の作用方向を材軸方向に
限定します**。既存荷重を編集するときは「保存済み方向」が既定で、部材回転後も保存された全体方向をそのまま保持します。「現在の材軸方向」を明示選択したときだけ、現在の部材軸へ変更します。

材軸に直交する成分は、材端モーメントを生じない静定分配で両端の節点へ配ります。
配り方は単純梁の反力と同じで、合力と作用位置が保存されるため、建物の総重量や支点反力は
この扱いによって変わりません（[部材荷重](../04_要素剛性/03_部材荷重.md)）。

<div class="impl-ref">

**実装参照**：`sepika_app::load_editor::LoadEditor::set_picked_member`（`crates/sepika-app/src/load_editor.rs`）が新規ブレース荷重の作用方向を材軸方向へ設定し、材軸直交成分は `sepika_element::frame::member_load`（`member_load.rs`）が `SpanLoadTransfer::StaticallyEquivalent` で両端の節点へ配ります。

</div>
