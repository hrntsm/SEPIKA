# 自重の長期応力解析への接続（DL 荷重ケース）

部材自重・壁自重・ダンパー自重を、固定荷重（`LoadCaseKind::Dead`）の標準荷重ケース「DL」の内容として自動生成し（スラブ固定荷重の分配と合算）、長期応力解析・荷重組合せへ接続します。
**床（スラブ）の自重はここには含まず**、床の断面の板厚と材料から算定して床荷重の分配へ乗せます（[床の断面と自重](./08_床の断面と自重.md)）。自重の算定対象を部材・壁・ダンパーに限ることで、床の重量が両方から二重に載るのを防いでいます。
梁・ブレースは等分布荷重、柱は既存の節点自重を載せます。壁版は解析Wall生成有無によらず共通総量を支持部材へ一度伝達します。階帯集計はDL支持比や反力から独立です。シェルは既存の頂点節点荷重を維持します。

RC/SRC 柱の仕上げ重量も、[階共通条件と断面形状の規則](05_地震用重量_層データの生成.md#rcsrc-柱の仕上げ重量)で DL と地震用重量を共通算定します。
未設定は 0 N/mm² とし、もっとも高い材端節点の所属階の値を柱全体へ適用します。
傾斜・水平配置・複数階にまたがる Column も同じ規則とし、所属階未解決はエラーにします。
柱自重の節点荷重・部材荷重への伝達方法は、上記の既存規則のままです。

鋼の物理単位重量が固定設計値78.5 kN/m³を超える材料を参照する場合、DLの生成と
設計荷重を必要とする解析を理由付きで停止します。旧自動荷重を最新の結果として使えません。
判定単位・対象・割増前の検査は[カスタム鋼材の密度と計算可否](../02_材料/04_標準材料一覧.md#カスタム鋼材の密度と計算可否)によります。

## 矩形RC/SRC大梁と床板の実重複控除

矩形 RC/SRC の主架構大梁は、囲まれた床板との実重複体積を梁本体から控除します。
大梁の用途で対象を決め、柱・ブレース・S/CFT・二次小梁へは適用しません。
梁は個別の鉛直偏心を含む実配置、床板は基準階の FL と個別の鉛直偏心、および床断面の実板厚を使います。
剛性へ算入するかにかかわらず、支持関係から実在する床板を解決します。建物共通のスラブ厚は控除量・上限・既定値に使いません。

同じ平面位置で、梁の上端・下端を \\(z_{b,t},z_{b,b}\\)、床板の上面・下面を \\(z_{s,t},z_{s,b}\\) として、重複高さを

\\[h_s=\max\{0,\min(z_{b,t},z_{s,t})-\max(z_{b,b},z_{s,b})\}\\]

とします。片側だけに床板が実在する場合は全梁幅 \\(b\\)、両側に実在する場合は各 \\(b/2\\) を割り当てます。
片側の重複高さが 0 でも、床板が存在する限り反対側を全幅へ広げません。
床領域だけがあり床板なしを明示している側は、床板なしとして扱います。未設定・参照切れは床板なしへ読み替えず停止します。
同じ側の同じ床板の支持区間を統合し、正長の区間で別の床板候補が重なる場合は停止します。
梁の左右が別の閉領域なら、それぞれ別の床板です。同じ床板を複数の割当領域へ共有する不正な参照は停止します。

水平・一定断面では控除面積は片側のみなら \\(b h_s\\)、両側なら \\(b(h_L+h_R)/2\\) です。
上端一致で板厚 \\(0<t\le D\\) の場合は、控除後断面積が \\(b(D-t)\\) に一致します。
板厚が梁せいを超える場合も上下範囲の交差を使い、板厚を梁せいへ丸めません。離れている床板は控除 0 です。

斜梁は有限な梁の端面を含む実上下範囲を使い、控除体積を水平投影長について積分します。

\\[V_{ded}=\int\sum_s b_s h_s\,dl_{plan},\qquad dl_{plan}=\cos\theta\,ds\\]

鉛直重複高さを断面せい \\(D\\) で制限しません。梁本体の体積は \\(bD L\\) とし、既存の柱面間の自重算定区間を保ちます。
控除重量は除去する梁本体と同じ設計単位重量 \\(\gamma_b\\) を使い、控除後自重は \\(\gamma_b(bD L-V_{ded})\\) です。
床板本体は既存の床荷重分配で一度だけ計上します。動的解析の物理質量はこの設計重量の控除で変更しません。

適用範囲は、各側の囲まれた床板群の支持区間和集合が、梁の自重算定区間全長を隙間なく覆う場合です。
同側に別の床板が隣接する場合は、支持区間の境界ごとに左右の床板を一意に解決し、その区間の実板厚・実高さで厳密に積分します。
床板群の和集合に隙間がある場合や、途中の版なしにより正長の部分被覆となる場合は停止し、全長へ推定したり平均厚に置き換えたりしません。
断面の幅方向は水平であることを要し、幅方向にも鉛直位置が変化する材軸回りの回転を与えた矩形断面は未対応として停止します。
部分取付き・取り付く床板による控除、床板下面までの嵩上げ重量の加算、偏心接続による応力変換は未対応です。
対象大梁に取り付く床板がある場合は、未対応であることを示して停止します。
必要な位置・断面・材料・支持参照が欠ける場合、寸法や採用長さが有限な正値でない場合、体積・重量が非有限または控除体積が梁本体を超える場合は、対象と理由を示して停止します。
準備計算の荷重集計と CSV には梁本体・床板重複控除・控除後の内訳を示します。仕上げ・付加重量・嵩上げはこの内訳に含めません。

## 小梁自重の作用区間

S 柱・CFT 柱・S 大梁・S 小梁の耐火被覆は、[階共通耐火被覆の重量](05_地震用重量_層データの生成.md#階共通耐火被覆の重量) と同じ条件・式で DL へ加算します。
被覆分には鉄骨重量割増を重ねず、既存の自重算定長と伝達方式を維持します。

二次部材小梁の自重は、芯々の材軸座標で表したフェース間区間 `[a, b]` に元の単位長荷重を載せます。
総重量だけを減らして全長へ再配分しないため、支持幅が異なる場合の非対称反力も保持できます。
設計自重算定長の規則は [地震用重量・層データの生成](05_地震用重量_層データの生成.md) と共通です。
鉛直柱支持では[小梁を支持する鉛直柱のフェース](05_地震用重量_層データの生成.md#小梁を支持する鉛直柱のフェース)の最外側面交点と有限柱閉区間を使います。
未算定の支持を0控除へ置換せず、理由と支持材を示してDL生成を停止します。

たとえば芯々長 3000 mm、矩形支持材の始端幅 300 mm・終端幅 200 mm の直交取付きなら、作用区間は `[150, 2900]` mm です。
単位長荷重を w N/mm とすると、総重量は 2750w N、載荷重心は始端から 1525 mm です。
反力は芯々の支持位置で求めるため、始端が `2750w × 1475/3000` N、終端が `2750w × 1525/3000` N になります。
片持ちでは支持端のフェースから自由端まで載荷し、全量を支持端へ伝えます。
小梁の材軸・支持位置・検定スパンは芯々のままで、間柱の自重作用区間も変更しません。
自重総量・DL への反力伝達・地震用重量は同じ区間を使うため、控除長さの食い違いは生じません。
物理密度による質量相当の逐次伝達も同じフェース間区間へ載せますが、単位長荷重は設計自重から独立に求めます。
断面質量特性と芯々長から求める量、転送量と階動的質量の関係は[地震用重量・層データの生成](05_地震用重量_層データの生成.md)の「動的解析用の質点質量の設定」を参照してください。
主架構大梁の DL は従来の総重量を芯々長で割った等分布として載せ、二次部材小梁の部分区間載荷とは区別します。

<div class="impl-ref">

**実装参照**：`sepika_load::cascade::solve_with_basis`（`crates/sepika-load/src/cascade.rs`）が自重区間へ荷重を載せ、芯々スパン上で反力を逐次伝達します。
設計重量と物理質量相当の単位長荷重は `beam_self_weight_udl`・`beam_mass_equiv_udl`（`crates/sepika-load/src/floor/beam_design.rs`）から独立に求めます。

## 解析要素にならない壁版の自重

生成Wallと壁エレメントにならない壁版は共通総量とDL方式を使います。実領域・対象・入力・未算定の対照表は[壁の断面と自重](09_壁の断面と自重.md)、独立階帯は[地震用重量・層データの生成](05_地震用重量_層データの生成.md)を参照してください。

| DL方式 | 実支持材へ伝える量 |
|---|---|
| 下梁全量 | 共通総量全量 |
| 上梁全量 | 共通総量全量 |
| 高さ中央の実体積切断 | 内法実領域の上下端中央で切断した交差量。位置付き開口を反映 |
| 任意辺率 | 境界辺順の非負率、総和1（許容差1e-9）。DL専用 |

3方式と任意辺率の同時適用はエラーです。方式は支持条件・スリットと別に明示選択します。左右下完全スリット・上接続は先に判定して上梁全量です。上下梁せいが異なれば実高さ中央と階レベル中央は一致しません。DL変更で総量・階重量は変わりません。

スリットがない囲まれた壁は、梁中間の間柱端など境界頂点に節点がない場合も、実支持部材の材軸部分区間へDLを載せます。スリットを指定した場合は辺への対応が必要で、対応を解決できなければ未算定を診断します。

小梁上の壁は下小梁へ全量を載せ、逐次反力伝達で主架構へ運びます。柱・間柱支持は指定区間へ分布荷重を載せ、間柱端部率は別に必要です。未設定・不正率・支持欠落・循環・切れた辺は振り替えず診断します。

Attachedの腰壁・垂れ壁・パラペット・部分区間は線アンカー、柱伝達指定は柱へ集中、床領域自立壁は既存床伝達です。3方式を無条件適用しません。支持や床領域が解決できなければ解析前診断で停止します。

壁版フォームで方式を選び適用し、準備計算後にDL表示と階重量を確認します。編集Undo・再生成も現在形状から同期します。自動壁荷重と手入力荷重を識別し、同期2回で増分を生じません。手入力重力ケースを壁自重として再解釈しません。

<div class="impl-ref">

**実装参照**：`dl_ratios`・`distribute_enclosed_wall_plates`（`crates/sepika-load/src/wall_plate_load.rs`）、`compute_gravity_auto_load_cases`・`apply_auto_load_cases`（`crates/sepika-job/src/auto_loads.rs`）を参照してください。

</div>

## 任意辺指定と間柱の取付条件

各辺の支持部材と材軸区間は、壁版割当領域の境界を正本としてそのまま使います（ADR 0020）。壁版割当領域は柱・梁・間柱を構面ごとに面走査して分割した閉領域で、境界の 1 辺は 1 つの支持部材の材軸区間に対応します。同じ種類どうし（主架構どうし・間柱どうし）の重なりは解析前チェックのエラーであり、異種の重なりは主架構を優先します。同種の重なりを自動で一意化しないため、再構築でどの支持部材が残るかは要素順に依存します。辺の全長を覆うかは領域の構成から決まり、節点座標からの支持先の再推定はしません。境界が参照する支持部材が実在し、種別（柱・梁・間柱）が適合し、材軸を解決できることは `Model::validate` が確認します。境界の頂点にモデル節点が無くても（間柱の端が梁の材軸中間にある場合など）支持先と荷重を取り落としません。

実際に梁で受ける壁の自重を柱へ指定すると、その梁の曲げを過小評価する危険側のモデルとなります。境界辺の存在だけで荷重の伝達を判断せず、実際の納まりに応じて指定してください。間柱を支持辺にする場合は、その間柱が壁版の境界となるよう壁版を分割します。


柱が受け持つ分は、その柱の材軸方向の分布荷重として載せます。軸力は、節点変位による内力に、切断位置までの部材荷重を含む固定端内力を重ね合わせて求めます。引張を正とし、下端固定・上端自由の鉛直柱に下向き等分布荷重 w が作用する場合、下端からの距離 x における軸力は N(x) = −w(L−x) です。下端は柱が受け持つ全重量を圧縮軸力として負担し、上端の軸力は 0 となります。上下端とも拘束される場合の負担は、架構の変形適合条件と釣合いから決まります。

間柱が受け持った荷重は、二次部材の反力の逐次伝達が主架構へ運びます（[床荷重の分配](03_床荷重の分配.md)）。鉛直な間柱では、壁から間柱への負担率とは別に、**間柱の上下端への負担率も明示入力が必要**です。既定は未指定で、解析前エラーとなります。間柱自身の自重にも同じ端部負担率を適用します。

**指定した支持辺に荷重を流せない壁版は、解析前チェックがエラーで止めます。** 自重の行き先が決まらないためです。行き先のない荷重を節点荷重として残すと、要素が接続しない節点への節点荷重は解析の自由度から外れるので、荷重の一覧には見えるのに解析からは消えます。


間柱の端部支持条件で自由端とした端には、端部負担率0を指定してください。自由端への正の負担率は入力エラーで、反対側へ自動振替しません。
