# 構造特性係数 Ds

昭和55年建設省告示第1792号に基づき定める各階の構造特性係数 Ds は、次の 3 つの軸で決まります。

1. **柱及びはりの部材群としての種別**（A〜D）
2. **耐力壁（RC）／筋かい（S）の部材群としての種別**（RCはA〜D、SはA〜C）
3. **\\( \beta\_u \\)** — 耐力壁・筋かいの水平耐力の和を保有水平耐力で除した数値

部材群としての種別は、各部材の種別（RC は FA〜FD・WA〜WD、S は幅厚比区分 FA〜FD と筋かいの BA〜BC、SRC は判定比 \\( N/N\_0 \\)・\\( {}\_sM\_0/M\_0 \\) による FA〜FD と耐震壁の WA/WC）を耐力比 \\( \gamma\_A, \gamma\_C \\) で集計して定めます。個々の部材種別の判定条件は[部材の分類](03_部材ランク.md)、群集計とDsの値表は本ページに示します。

SRC柱・壁の部材種別の算定は、SRC用Ds表を採用できることを意味しません。現在のRC/S選択とSRCへの制限は[SRC造の計算ルートと適用範囲](01_保有水平耐力の判定.md#src造の計算ルートと適用範囲)を参照してください。

Ds 用の部材応力・機構・βu は、同じ目的別確定評価点から採ります。保有耐力比較用の Qu や他 step の壁力を混合しません。群の耐力重みは同時点の負担力と区別します。採用点と釣合い診断は [保有水平耐力の判定](01_保有水平耐力の判定.md) を参照してください。

本対応域のRC壁のせん断耐力には、その増分runで実際に採用した正負Quを使います。[壁脚内力と初期耐力](../08_部材終局耐力/08_RC壁の壁脚内力と初期耐力.md)の入力一致・不足診断を適用し、現在のモデルだけから耐力を再計算しません。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( \beta\_u \\) | 耐力壁・筋かいの水平耐力の和を保有水平耐力で除した数値 | - |
| \\( \gamma\_A \\) | 種別 A の部材（筋かい BA・柱 FA）の耐力の和を全耐力で除した耐力比 | - |
| \\( \gamma\_C \\) | 種別 C の部材（筋かい BC・柱 FC）についての耐力比 | - |
| \\( N/N\_0 \\) | SRC 柱の軸力比 | - |
| \\( {}\_sM\_0/M\_0 \\) | SRC 柱の鉄骨曲げ耐力比 | - |

## 部材群としての種別

層の Ds は個々の部材ではなく、**部材群としての種別**で定めます。下表は耐力比によるA・B・Cの分類です。Ds表にはDの列・行もあり、この耐力比の表だけでD部材の取扱いや全適用条件が確定するものではありません。

| | 部材の耐力の場合 | 部材群としての種別 |
|---|---|---|
| (一) | \\( \gamma\_A \ge 0.5 \\) かつ \\( \gamma\_C \le 0.2 \\) | A |
| (二) | \\( \gamma\_C < 0.5 \\)（部材群としての種別が A の場合を除く） | B |
| (三) | \\( \gamma\_C \ge 0.5 \\) | C |

- \\( \gamma\_A \\): 筋かいの部材群の種別を定める場合は、種別 BA である筋かいの耐力の和をすべての筋かいの水平耐力の和で除した数値。柱及びはりの部材群の種別を定める場合は、種別 FA である柱の耐力の和を種別 FD である柱を除くすべての柱の水平耐力の和で除した数値。
- \\( \gamma\_C \\): 同様に、種別 BC である筋かい／種別 FC である柱について求めた数値。

## 各階の構造特性係数 Ds（RC 造）

\\( \beta\_u \\) は耐力壁の水平耐力の和を保有水平耐力の数値で除した数値です。

| 耐力壁の部材群としての種別 | 条件 | 柱及びはりの部材群としての種別 A | B | C | D |
|---|---|---|---|---|---|
| A | \\( 0 < \beta\_u \le 0.3 \\) | 0.3 | 0.35 | 0.4 | 0.45 |
| A | \\( 0.3 < \beta\_u \le 0.7 \\) | 0.35 | 0.4 | 0.45 | 0.5 |
| A | \\( \beta\_u > 0.7 \\) | 0.4 | 0.45 | 0.45 | 0.55 |
| B | \\( 0 < \beta\_u \le 0.3 \\) | 0.35 | 0.35 | 0.4 | 0.45 |
| B | \\( 0.3 < \beta\_u \le 0.7 \\) | 0.4 | 0.4 | 0.45 | 0.5 |
| B | \\( \beta\_u > 0.7 \\) | 0.45 | 0.45 | 0.5 | 0.55 |
| C | \\( 0 < \beta\_u \le 0.3 \\) | 0.35 | 0.35 | 0.4 | 0.45 |
| C | \\( 0.3 < \beta\_u \le 0.7 \\) | 0.4 | 0.45 | 0.45 | 0.5 |
| C | \\( \beta\_u > 0.7 \\) | 0.5 | 0.5 | 0.5 | 0.55 |
| D | \\( 0 < \beta\_u \le 0.3 \\) | 0.4 | 0.4 | 0.45 | 0.45 |
| D | \\( 0.3 < \beta\_u \le 0.7 \\) | 0.45 | 0.5 | 0.5 | 0.5 |
| D | \\( \beta\_u > 0.7 \\) | 0.55 | 0.55 | 0.55 | 0.55 |

耐力壁がない（\\( \beta\_u = 0 \\)）純ラーメンの場合は 0.3 / 0.35 / 0.4 / 0.45 とします。

## 各階の構造特性係数 Ds（S 造）

\\( \beta\_u \\) は筋かい（耐力壁を含む）の水平耐力の和を保有水平耐力で除した数値です。

| 筋かいの部材群としての種別 | 条件 | 柱及びはりの部材群としての種別 A | B | C | D |
|---|---|---|---|---|---|
| A 又は \\( \beta\_u = 0 \\) | — | 0.25 | 0.3 | 0.35 | 0.4 |
| B | \\( 0 < \beta\_u \le 0.3 \\) | 0.25 | 0.3 | 0.35 | 0.4 |
| B | \\( 0.3 < \beta\_u \le 0.7 \\) | 0.3 | 0.3 | 0.35 | 0.45 |
| B | \\( \beta\_u > 0.7 \\) | 0.35 | 0.35 | 0.4 | 0.5 |
| C | \\( 0 < \beta\_u \le 0.3 \\) | 0.3 | 0.3 | 0.35 | 0.4 |
| C | \\( 0.3 < \beta\_u \le 0.5 \\) | 0.35 | 0.35 | 0.4 | 0.45 |
| C | \\( \beta\_u > 0.5 \\) | 0.4 | 0.4 | 0.45 | 0.5 |

## 本プログラムでの部材群種別・βu の算定

βu は [保有水平耐力の判定](01_保有水平耐力の判定.md#符号付き層切断面力と釣合い)に示す、Ds 判定用確定点の符号付き負担力比を使います。部材群の種別を決める耐力重みは、同時点の実負担力とは別の量です。自動ランクを使用する場合は設計タブで各部材の正の耐力重み [N] を明示入力してください。壁系の側柱は壁系へ一度分類し、柱梁系へ再計上しません。

耐力重み・ランク・確定応力が欠ける場合は自動判定を停止します。壁・筋かい群が存在しない純ラーメンではその群を仮にランク A とせず、βu=0 の純ラーメンの表を用います。柱梁群を持たない構造の自動 Ds 判定は未対応として明示し、手動設計入力を求めます。実負担力を耐力と読み替えることや、欠損をランク A・選択ランクで埋めることはありません。自動判定を使用しない場合の手動ランクは設計者の明示入力です。

目的別集計の釣合い確認は、群種別のD部材取扱い・柱梁群の範囲やDs適用条件の成立を保証しません。破壊形式・非ヒンジ柱・接合部・柱脚の確認不足は、[崩壊機構に関する適用条件と確認範囲](#崩壊機構に関する適用条件と確認範囲)の制限に従い自動・手動とも理由付きで保留します。

群の耐力比の背景資料は、国土交通省公開の住指発第96号（昭和56年5月1日）別記3付則(2)2)v)表3-5です（HTML、頁なし）。[原文](https://www.mlit.go.jp/notice/noticedata/sgml/099/81000085/81000085.html)。歴史的通知として参照し、現行法の全要件の代替には用いません。

## 崩壊機構の反映

解析上の全体崩壊・層崩壊・機構未形成の分類だけでは、Dsの適用条件を確定しません。層崩壊の層を一律に一段階悪化する補正は適用しません。

現在はRCの崩壊時破壊形式、非ヒンジ柱の該当性と接続梁種別、接合部で塑性ヒンジ又は脆性破壊を生じる部材の種別、S柱脚の形式・伸び能力・保有耐力接合を確定する入力が不足しています。対象の柱・梁・接合節点と不足条件を示し、**Ds判定を保留して必要保有水平耐力・合否を算定不能**とします。自動ランクと手動ランクのどちらでも同じ制限を適用し、FDの手動指定でも保証条件の確認に代用しません。設計画面・増分結果画面・CSVに不足理由を表示します。一般のRC/Sラーメンもこの制限の対象です。

接続梁の確認対象は加力方向ごとに示し、計算方向に直交する梁を除きます。接合部の表示部材は確認対象候補であり、全てがヒンジ・脆性部材であるとの判定ではありません。S柱は柱脚の有無・形式から未確認とし、露出柱脚と決め付けません。S柱とRC梁を含む架構では層外のRC梁も確認対象とし、基礎梁用途や限定換算の適用条件を未確認として示します。

ここでの「部分崩壊形」は機構未形成を表すプログラム上の分類です。特定階が崩壊形に達した状態を指す告示上の部分崩壊形とは区別してください。機構分類、解析終了、評価点の選択だけでは規準上の採用状態の成立を確認できません。Ds・Quの採用状態の確認も別途必要です。

## 崩壊機構に関する適用条件と確認範囲

確認根拠は『2025年版 建築物の構造関係技術基準解説書』第2版（2026年2月11日）、6.3.4(2) pp.397–400・403、付録1-2.6 付図1.2-25 p.670、6.4.4(2) pp.420・422–427 です。以下は条件の要約です。現在はこれらを自動で成立と判定する情報がなく、対象条件を理由付きで保留します。

| 対象 | 規準上の条件と取扱い | 現在の利用上の制約 |
| --- | --- | --- |
| 通常RCの層崩壊 | Dsを算定する階の崩壊時応力と破壊形式で部材種別を定めます。非ヒンジ柱は取り付く梁（計算方向と直交する方向に取り付く梁を除く）の種別を用います。異種別接合は、接合部で接合される部材のうち、崩壊時に塑性ヒンジ又は脆性破壊を生じる部材に限って最低種別を用います | 機構分類から層全体を一段階悪化する方式では代替できません。非ヒンジ柱・接合部・脆性破壊の個別確認が必要です |
| Sの非ヒンジ柱 | 接続梁及び塑性ヒンジを形成する接合部材の種別に応じて柱種別を修正します | RC基礎梁の換算や露出柱脚の措置とは別の確認です |
| 塑性化する露出柱脚 | アンカーボルトに伸び能力があり、保有耐力接合を満たさない場合は、履歴のスリップ化を考慮して1階Dsを0.05程度割増すなどの措置が必要です。保有耐力接合を満たす場合は柱ヒンジを仮定し、Dsは上部構造で決定します | 柱脚形式・伸び能力・保有耐力接合の成立を機構分類だけで確認できません。柱梁群Dの場合は付図の割増対象外です |
| 伸び能力のないアンカーボルトの露出柱脚 | 保有耐力接合を満たす設計が基本です。満たさない場合は柱梁群Dに対応するDsで1階Quを確認します | 一段階悪化や一律0.05加算へ置換できません。認定柱脚は認定条件の確認も必要です |
| S造のRC基礎梁に塑性ヒンジが生じる場合 | 同書6.9.4 p.484はヒンジ部材の構造とランクに重点を置く取扱いを示します | RC種別をS種別へ一段階下げて換算する直接規定は、今回確認した同書の範囲では未確認です。限定した地域取扱いを一般条件として採用せず、適用条件とFDの扱いを別途確認してください |

柱脚・接合部・基礎梁や破壊形式の情報不足を、一律補正・無補正・手動ランクで埋めません。保留は規準不適合の確定とも区別してください。
