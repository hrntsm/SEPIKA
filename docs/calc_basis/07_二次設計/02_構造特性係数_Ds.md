# 構造特性係数 Ds

昭和55年建設省告示第1792号に基づき定める各階の構造特性係数 Ds は、次の 3 つの軸で決まります。

1. **柱及びはりの部材群としての種別**（A〜D）
2. **耐力壁（RC）／筋かい（S）の部材群としての種別**（A〜C）
3. **\\( \beta\_u \\)** — 耐力壁・筋かいの水平耐力の和を保有水平耐力で除した数値

部材群としての種別は、各部材の種別（RC は FA〜FD・WA〜WD、S は幅厚比区分 FA〜FD と筋かいの BA〜BC、SRC は判定比 \\( N/N\_0 \\)・\\( {}\_sM\_0/M\_0 \\) による FA〜FD と耐震壁の WA/WC）を耐力比 \\( \gamma\_A, \gamma\_C \\) で集計して定めます。個々の部材種別の判定条件、部材群としての種別の判定式、および Ds の値表は [部材ランク](03_部材ランク.md) に示します。

Ds 用の部材応力・機構・βu は、同じ目的別確定評価点から採ります。保有耐力比較用の Qu や他 step の壁力を混合しません。群の耐力重みは同時点の負担力と区別します。採用点と釣合い診断は [保有水平耐力の判定](01_保有水平耐力の判定.md) を参照してください。

本対応域のRC壁のせん断耐力には、その増分runで実際に採用した正負Quを使います。[壁脚内力と初期耐力](../04_要素剛性/10_RC壁の壁脚内力と初期耐力.md)の入力一致・不足診断を適用し、Modelだけから耐力を再計算しません。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( \beta\_u \\) | 耐力壁・筋かいの水平耐力の和を保有水平耐力で除した数値 | - |
| \\( \gamma\_A \\) | 種別 A の部材（筋かい BA・柱 FA）の耐力の和を全耐力で除した耐力比 | - |
| \\( \gamma\_C \\) | 種別 C の部材（筋かい BC・柱 FC）についての耐力比 | - |
| \\( N/N\_0 \\) | SRC 柱の軸力比 | - |
| \\( {}\_sM\_0/M\_0 \\) | SRC 柱の鉄骨曲げ耐力比 | - |

**代表値（耐力壁・筋かいがない純ラーメンの場合）**

| 柱及びはりの部材群としての種別 | A | B | C | D |
|---|---|---|---|---|
| RC 造 | 0.30 | 0.35 | 0.40 | 0.45 |
| S 造 | 0.25 | 0.30 | 0.35 | 0.40 |

耐力壁・筋かいを有する架構では \\( \beta\_u \\) と壁・筋かいの部材群種別に応じて Ds が増大します（[各階の構造特性係数 Ds（RC 造）](03_部材ランク.md#各階の構造特性係数-dsrc-造)・[各階の構造特性係数 Ds（S 造）](03_部材ランク.md#各階の構造特性係数-dss-造) の表）。

**崩壊機構の反映**

現在の計算では、プッシュオーバーの機構分類を層別に次のように反映します。

- 全体崩壊形: Ds 表をそのまま適用する。
- 層崩壊形: 崩壊が生じる層の柱及びはりの部材群としての種別を 1 段階不利側（A→B→C→D、D は据え置き）へ移す。
- 崩壊機構が未形成（部分崩壊形）: 機構が確定していないため補正は行わず、Ds・必要保有水平耐力が暫定値である旨を表示する（崩壊機構の確定が必要保有水平耐力算定の前提となる）。

層崩壊形に対する一律の 1 段階補正は、告示に基づく適用条件を確認できていません。補正による Ds の増大だけで、破壊形式や非崩壊部分の評価が適切であるとは判断できません。S 造の柱脚や塑性ヒンジが生じる RC 基礎梁について、必要な個別条件を満たす補正としても利用できません。

ここでの「部分崩壊形」は機構未形成を表すプログラム上の分類です。特定階が崩壊形に達した状態を指す告示上の部分崩壊形とは区別してください。機構分類、解析終了、評価点の選択だけでは規準上の採用状態の成立を確認できません。Ds・Qu の採用根拠は設計者による別途確認が必要です。
