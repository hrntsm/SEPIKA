# 部材の分類（FA〜FD・WA〜WD・BA〜BC）

昭和55年建設省告示第1792号と学会規準（RC 靭性、S 幅厚比）に基づき、部材ランク FA〜FD を、RC は応力度比・形状・配筋と破壊形式、S は幅厚比や筋かいの有効細長比、SRC は耐力比と破壊モードで分類します。

ここでは個々の部材の分類を扱います。部材群への集計とDsの値表は[構造特性係数 Ds](02_構造特性係数_Ds.md#部材群としての種別)を参照してください。候補種別の算定と、Dsの適用条件が確認できたことは別です。

**算定式**
- RC 部材種別: 下記の[RC 部材の種別](#rc-部材の種別)の多変数表（\\( h\_0/D \\)・\\( \sigma\_0/F\_c \\)・\\( p\_t \\)・\\( \tau\_u/F\_c \\)）で判定する。
- S 部材種別: 下記の[鋼材の幅厚比種別](#鋼材の幅厚比種別)の幅厚比限界値表（部材種別・断面・部位・鋼種別）で判定する。
- SRC 部材種別: 下記の[SRC 部材の種別](#src-部材の種別)の判定比（\\( N/N\_0 \\)・\\( {}\_sM\_0/M\_0 \\)）と破壊モードの表で判定する。

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( h\_0/D \\) | 柱の内法高さと断面せいの比 | - |
| \\( \sigma\_0/F\_c \\) | 柱の軸方向応力度とコンクリート設計基準強度の比 | - |
| \\( p\_t \\) | 引張鉄筋比 | % |
| \\( \tau\_u/F\_c \\) | 平均せん断応力度とコンクリート設計基準強度の比 | - |
| \\( N/N\_0 \\) | SRC 柱の軸力比 | - |
| \\( {}\_sM\_0/M\_0 \\) | SRC 柱の鉄骨曲げ耐力比 | - |
| \\( Q\_{su}, Q\_{mu} \\) | 終局せん断耐力・曲げ終局時せん断力 | N |

| \\( Q\_u \\) | 耐震壁の終局せん断強度 | N |

## RC 部材の種別

### 柱及びはりの種別

いずれも「せん断破壊、付着割裂破壊及び圧縮破壊その他の構造耐力上支障のある急激な耐力の低下のおそれのある破壊を生じないこと」を満たすことが前提で、これを満たさない場合は FD とします。

| 種別 | 柱 \\( h\_0/D \\) | 柱 \\( \sigma\_0/F\_c \\) | 柱 \\( p\_t \\) | 柱 \\( \tau\_u/F\_c \\) | はり \\( \tau\_u/F\_c \\) |
|---|---|---|---|---|---|
| FA | 2.5 以上 | 0.35 以下 | 0.8 以下 | 0.1 以下 | 0.15 以下 |
| FB | 2.0 以上 | 0.45 以下 | 1.0 以下 | 0.125 以下 | 0.2 以下 |
| FC | — | 0.55 以下 | — | 0.15 以下 | — |
| FD | FA, FB 又は FC のいずれにも該当しない場合 | | | | |

- \\( h\_0 \\): 柱の内法高さ、\\( D \\): 加力方向の柱の断面せい
- \\( \sigma\_0 \\): Ds 算定時に柱の断面に生じる軸方向応力度
- \\( p\_t \\): 引張鉄筋比 [%]
- \\( F\_c \\): コンクリートの設計基準強度
- \\( \tau\_u \\): Ds 算定時に柱、梁の断面に生じる平均せん断応力度

本プログラムは \\( \sigma\_0, \tau\_u \\) を Ds 判定用に明示採用した確定 step の部材応答から算定し、急激な耐力低下のおそれのある破壊はせん断先行（\\( Q\_{su} < Q\_{mu} \\)）で判定します。評価点の指定だけでは崩壊機構の成立を保証しません。採用点における機構を確認します。

#### 表の選択順序

急激な耐力低下のおそれがある場合はまずFDとし、それ以外はFA、FB、FCの順に、その行の全条件を満たす最初の種別を採ります。したがってFAの条件も満たす部材をFBへ重複分類しません。各「以下」「以上」は等号を含みます。柱でどの行も満たさない場合はFDです。梁のFC行の「—」は、せん断応力度比による上限なしを示し、非脆性の梁で\\(\tau_u/F_c>0.2\\)ならFCです。

例えば矩形梁で\\(B=400\\) mm、\\(D=600\\) mm、\\(F_c=24\\) N/mm²、\\(Q_y=864000\\) Nなら\\(\tau_u=3.6\\) N/mm²、比は0.15です。上下側ともせん断先行でないことを別途満たせば、等号を含むFAです。この数値例だけでは付着割裂・圧縮破壊などの確認やDsの採用可否まで保証しません。

#### 応答の位置・方向・符号

以下は現在のRC矩形柱・円形柱・矩形梁の自動候補の入力定義です。矩形柱のせん断応力度には後述の単位不整合があり、表の入力がすべて成立しているとは扱えません。T形梁などへこれらの式を拡張しません。

同じDs評価点の部材両端節点における内力を用います。i→jの局所材軸をx、断面せい方向をy、幅方向をzとします。局所y方向せん断が強軸側、局所z方向せん断が弱軸側です。強弱は断面の基準呼称であり、断面性能の大小による並べ替えではありません。全体X/Y加力のそれぞれの解析応答について、柱は局所二方向の候補の不利な方を採用します。梁は局所強軸側を対象とします。

\\[
N_{Ds}=\max(N_i,-N_j,0),\qquad
Q_y=\max(|V_{y,i}|,|V_{y,j}|),\qquad
Q_z=\max(|V_{z,i}|,|V_{z,j}|)
\\]

\\(N_i,N_j\\) は各節点端力の局所x方向成分、\\(V_{y,i},V_{y,j},V_{z,i},V_{z,j}\\) は局所せん断成分で、いずれもNです。\\(N_{Ds}\\) は圧縮を正とした両端の大きい値で、両端とも引張なら0です。引張軸力の絶対値は用いません。\\(Q_y,Q_z\\) は非負で、同じ断面位置で軸力とせん断力が最大となることは要求しません。部材中央・剛域フェースのせん断、履歴全体の最大値、別の評価点の値には置換しません。

以下の寸法はmm、面積はmm²、\\(F_c,\sigma_0,\tau_u\\) はN/mm²、応力度比は無次元です。内法高さ\\(h_0\\)と梁の内法長さは節点間長さから両端のフェース距離を差し引きます。差が正にならない場合の現在の候補計算は節点間長さを用いるため、その場合は実内法として成立しているか別途確認が必要です。

#### 矩形柱の軸応力度と引張鉄筋比

幅を\\(B\\)、全せいを\\(D\\)とします。軸応力度の分母はコンクリートの全断面積であり、主筋を控除せず、換算断面積・せん断有効断面積も用いません。

\\[
A=BD,\qquad \sigma_0=\frac{N_{Ds}}{BD},\qquad
\frac{\sigma_0}{F_c}=\frac{N_{Ds}}{BD F_c}
\\]

方向別の幅・せい・主筋列を次のように選びます。\\(c\\)はかぶり、\\(\phi_w\\)は帯筋径、\\(\phi_m\\)は主筋径です。

| 局所検討方向 | 幅 \\(b_k\\) | 全せい \\(D_k\\) | 引張主筋として数える列 |
| --- | --- | --- | --- |
| y（強軸側） | \\(B\\) | \\(D\\) | X方向配筋の最外段1列（上側） |
| z（弱軸側） | \\(D\\) | \\(B\\) | Y方向配筋の最外段1列（左側） |

\\[
d_t=c+\phi_w+\frac{\phi_m}{2},\qquad
d_{e,k}=D_k-d_t,\qquad
a_{t,k}=n_{k,1}a_m,\qquad
p_{t,k}=100\frac{a_{t,k}}{b_k d_{e,k}}\quad[\%]
\\]

\\(n_{k,1}\\)は上表の最外段の本数、\\(a_m\\)は主筋1本の断面積です。内側の段・反対面・直交方向の全主筋量を足しません。矩形柱では多段配筋でも最外段を使い、全段の重心へ置き換えません。方向別の\\(h_0/D\\)には\\(h_0/D_k\\)を用います。\\(p_t=0.8\\)は0.8 %であり、小数の0.008を表に入力しません。剛性低下率用の全せいを分母とする鉄筋比とは区別します。終局せん断耐力の式に同形の鉄筋比があっても、その値を転用せず、ここで指定する列と方向から求めます。

#### 矩形柱のせん断応力度に関する制約

現在、矩形柱で表の\\(\tau_u/F_c\\)へ渡す数値は、各方向について次式になっています。

\\[
\text{現在の矩形柱の表入力値}=\frac{Q_k}{b_k F_c}
\\]

分母にせいがなく、この量の単位はmmで、無次元の応力度比ではありません。したがって、この入力を平均せん断応力度比として正当化することはできず、矩形柱の自動ランク候補を本表の成立確認に用いることはできません。例えば\\(B=400\\) mm、\\(D=600\\) mm、\\(F_c=24\\) N/mm²、\\(Q_y=240000\\) Nでは、現在の入力値は25 mmです。参考に全断面で除した\\(Q_y/(BD F_c)\\)は0.0416667ですが、これを修正後の採用式と決めるものではありません。必要な面積定義の確認と計算の訂正は[矩形柱のせん断応力度比の訂正課題](https://github.com/hrntsm/SEPIKA/issues/1268)で扱います。安全側・危険側の判断も未確定です。

#### 円形柱と矩形梁

円形柱は直径\\(D_c\\)、全主筋面積\\(a_g\\)から、等面積正方形の辺\\(s\\)と引張主筋量を定める現在の近似を用います。

\\[
s=\sqrt{\frac{\pi D_c^2}{4}},\qquad
a_t=\frac{a_g}{4},\qquad d_e=\max(s-d_t,0)
\\]

\\[
\sigma_0=\frac{N_{Ds}}{s^2},\qquad
\tau_{u,k}=\frac{Q_k}{s^2},\qquad
p_t=100\frac{a_g/4}{s d_e}\quad[\%]
\\]

\\(d_t\\)は矩形柱と同じかぶり・帯筋径・主筋半径の和です。応力度比はそれぞれを\\(F_c\\)で除します。\\(h_0/D\\)だけは等価辺長ではなく実直径を使い、\\(h_0/D_c\\)とします。二方向で同じ面積・配筋量を使い、せん断力だけを切り替えます。この近似の記載は原典上の適用性や安全側であることの確認ではありません。

矩形梁では幅\\(B\\)と全せい\\(D\\)を用います。

\\[
\tau_u=\frac{Q_y}{BD},\qquad
\frac{\tau_u}{F_c}=\frac{Q_y}{BD F_c}
\\]

梁の種別表には\\(\sigma_0/F_c\\)と\\(p_t\\)の列はなく、これらの上限で梁ランクを判定しません。破壊形式の確認に用いる終局耐力は上端引張・下端引張を別々に評価して不利な候補を採ります。各側の全段の主筋面積と段別本数による重心から有効せいを求め、全段を用いる梁と最外段1列を用いる矩形柱を区別します。耐力算定で用いる\\(N_{Ds}/(BD)\\)や引張鉄筋比を、梁の種別表にない判定項目として追加しません。

### 耐力壁の種別

本節の自動判定の対象は次のとおりです。

自動判定は、無開口・矩形・同一鉛直面で、両側に非共有のRC柱を持つ単独RC壁を対象とします。壁版と壁単体応答の負担範囲、実支持材、左右の柱断面・材料を一意に確認できることが必要です。袖壁・開口付き壁、連スパンや直交する壁との共有側柱を含む壁群は対象外です。壁版の分割や支持材の分割等で対応が不明な場合も推定で受理しません。

壁厚・柱心間距離・内法寸法・柱断面・材料強度は正の有限値、応答Qは符号付き有限値を要求します。未対応・不明・不正のときは対象IDと理由を示して自動判定を停止し、0・WA・合格・指定ランクで補いません。手動判定を利用者が明示選択した場合に限り、設計タブの指定ランクを使用します。

「せん断破壊、その他の構造耐力上支障のある急激な耐力の低下のおそれのある破壊を生じないこと」が前提です。

| 種別 | 壁式構造以外の構造の耐力壁 \\( \tau\_u/F\_c \\) | 壁式構造の耐力壁 \\( \tau\_u/F\_c \\) |
|---|---|---|
| WA | 0.20 以下 | 0.1 以下 |
| WB | 0.25 以下 | 0.125 以下 |
| WC | — | 0.15 以下 |
| WD | WA, WB, WC のいずれにも該当しない場合 | |

#### Ds 判定時の平均せん断応力度

Ds 判定用に明示採用した確定 step の壁単体局所面内せん断力を \\(Q_{Ds}\\) として、次式を用います。

\\[ \tau_u = \frac{|Q_{Ds}|}{t\cdot l_{cc}}, \qquad \frac{\tau_u}{F_c}=\frac{|Q_{Ds}|}{t\cdot l_{cc}\cdot F_c} \\]

| 記号 | 意味 | 単位 |
| --- | --- | --- |
| \\(Q_{Ds}\\) | 同じ Ds 評価点の壁単体局所面内せん断力（符号付き） | N |
| \\(t\\) | 壁板の実厚 | mm |
| \\(l_{cc}\\) | 左右の側柱の中心間距離 | mm |
| \\(F_c\\) | 壁コンクリートの設計基準強度 | N/mm² |
| \\(\tau_u\\) | Ds 判定時の平均せん断応力度 | N/mm² |

\\(l_{cc}\\) は壁板の内法長さと区別します。分母は壁厚と側柱中心間距離の積であり、側柱の全断面積や耐力用開口低減率 \\(r_2\\) を加えません。係数1.2も用いません。保有耐力比較用の \\(Q_u\\) や別 step の最大せん断力を \\(Q_{Ds}\\) に代用しません。

#### 両側柱の寸法と適用表

壁板の実内法長さを \\(l_{clear}\\)、実内法高さを \\(h_{clear}\\) とし、\\(s=\min(l_{clear},h_{clear})\\) [mm] とします。左右それぞれの側柱について、実断面積 \\(A_c\\) [mm²] と最小径 \\(d_{min}\\) [mm] が次のすべてを満たす場合を寸法上の適格とします。

\\[ A_c\ge\frac{st}{2},\qquad d_{min}\ge\sqrt{\frac{st}{3}},\qquad d_{min}\ge 2t \\]

**いずれか一方の側柱でも不足する場合**は、上表の「壁式構造」の列を用います。不足の判定は厳密な「未満」であり、等号は適格です。設計タブの「壁式構造」チェックを入れた場合も壁式構造の列を用います。チェックの既定はオフですが、オフだけでは通常の列に決まりません。両側の寸法条件を満たす場合に通常の列を用います。階の構造種別からの自動切替は行いません。表の切替によって上式の \\(\tau_u\\) は変わりません。

矩形RC柱は実幅と実せいの積を \\(A_c\\)、小さい方を最小径とします。円形RC柱は実径から断面積と最小径を求めます。内法寸法は周辺の実支持材のフェース間から求め、柱心間距離や解析用剛域長で置換しません。

例えば、柱心間3000 mm、壁厚200 mm、内法2600×1500 mm、左右400 mm角、\\(F_c=24\\) N/mm²では、\\(s=1500\\) mm、各柱の断面積160000 mm²は必要150000 mm²以上、最小径400 mmは必要316.227766… mm以上で、\\(2t=400\\) mmの等号も満たします。非せん断破壊で \\(Q_{Ds}=3.0\times10^6\\) Nなら、\\(\tau_u=5\\) N/mm²、\\(\tau_u/F_c=5/24=0.208333333\ldots\\) となり通常表のWBです。内法高さだけを2400 mmにすると面積条件が不足し、同じ応力度比のまま壁式表を用います。

#### 適用範囲と出典

出典は日本建築防災協会『令和5年度 構造設計者向け留意事項作成等事業 報告書』（2024年3月）、[本文44頁／PDF46頁](https://www.kenchiku-bosai.or.jp/files/2025/04/r5houkoku20250417.pdf#page=46)の、2015年版『建築物の構造関係技術基準解説書』393頁「②鉄筋コンクリート造耐力壁の靱性と破壊形式 c)」の公開引用です。平均せん断応力度の壁厚・側柱中心間距離による定義と、側柱断面積・最小径による表切替条件を採用します。この引用頁の確認は原書全体の照合や2020／2025年版との同一性を意味しません。別資料の \\(1.2|Q|/\Sigma A\\) による比較方式は本判定に用いません。

壁応答には、壁単体の局所面内せん断力 \\(Q_w\\) と加力方向への符号付き寄与 \\(Q_{dir}\\) を別々に記録します。定義・合成基準点・入力表と一次資料は[壁単体の確定ステップ応答](../../result_view/16_壁の確定ステップ応答.md#壁単体の確定ステップ応答)を参照してください。局所正負別 \\(Q_u[+,-]\\) の選択には \\(Q_w\\) の符号を用います。下辺a/bの反転では局所符号と耐力の張力側対応が一緒に反転します。

局所壁ランクの自動判定には、Ds 判定用に明示採用した同じ確定 step の \\(|Q_w|\\) を既存式へ渡します。層の βu は、その Ds 評価点での符号付き層切断面力から算定します。壁系の分子は面内壁パネルと切断面をまたぐ鉛直側柱の寄与、分母は同じ層・方向・run・入力世代・step の全体系の寄与です。共有側柱は壁系全体へ一度だけ計上し、柱梁側へ二重計上しません。境界梁を無条件に足すことも、局所 \\(|Q_{dir}|\\) を壁の層負担力として加算することもありません。局所壁応力の判定と、壁系全体の層力・βu の評価を区別します。層外力との釣合い、反転、開口・共有側柱などの独立回帰を検証していますが、多層をまたぐ壁や斜め壁など一般配置の網羅的 Validation は未完了です。

目的別に保持した解析条件と現在のモデル・材料・実荷重から確認した入力識別が一致しない結果、壁専用の確定履歴が未記録の結果、壁幾何の適用外、非有限な内力、上下力・モーメントの釣合い不成立は自動判定を拒否します。材料せん断ひずみと壁の線材用イベントは未提供であり、イベントなしを「塑性化なし」と読むことはできません。実測・原典例題による壁ランクのValidationは未完了です。

増分解析の壁要素は、面内せん断を終局せん断強度 \\( Q\_u \\) で頭打ちにする弾完全塑性としてモデル化します。
Ds 判定用に明示採用した確定 step の局所面内せん断力の絶対値が \\( Q\_u \\) の 99 % 以上（\\( |Q_w| \ge 0.99\\, Q\_u \\)）に達したときは、せん断が頭打ちに達したとみなし、種別を WD とします。
数値誤差を見込んで 100 % ではなく 99 % で切るため、頭打ちの直前で WA〜WC に残ることを避けます。
\\( Q\_u \\) が0以下・非有限で算定できないときは、自動判定をエラーとします。未対応や不正な耐力を0として判定しません。
終局せん断強度 \\(Q_u\\) の算定で用いる開口低減率 \\(r_2\\) は、Ds 平均せん断応力度の分母とは別です（[壁エレメントモデル](../04_要素剛性/05_壁エレメントモデル.md)）。

**実装参照**：`sepika_design_jp::secondary::ds_group`（`crates/sepika-design-jp/src/secondary/ds_group.rs`）の `rc_wall_tau_over_fc`・`rc_wall_side_column_eligible`・`rc_wall_type` と、`App::compute_holding_capacity`（`crates/sepika-app/src/app/actions/design/holding.rs`）。

## 鋼材の幅厚比種別

鉄骨部材の種別は、板要素の幅厚比を限界値と比較して定めます（技術基準解説書「鋼材の幅厚比種別等」）。

### 幅厚比の計算方法

| 断面 | 部位 | 幅厚比 |
|---|---|---|
| H 形鋼 | フランジ | \\( b/t\_f \\)（\\( b \\) はフランジ半幅 \\( = B/2 \\)） |
| H 形鋼 | ウェブ | \\( (D - 2t\_f)/t\_w \\)（内法せい） |
| 角形鋼管 | （径厚比） | \\( B/t \\)（**全せい**。内法ではない） |
| 円形鋼管 | （径厚比） | \\( D/t \\)（外径） |

### 柱及びはりの種別

\\( F \\) は平成12年建設省告示第2464号第1に規定する基準強度 [N/mm²] です。

| 部材 | 断面 | 部位 | FA | FB | FC | FD |
|---|---|---|---|---|---|---|
| 柱 | H 形断面 | フランジ | \\( 9.5\sqrt{235/F} \\) | \\( 12\sqrt{235/F} \\) | \\( 15.5\sqrt{235/F} \\) | 左記以外 |
| 柱 | H 形断面 | ウェブ | \\( 43\sqrt{235/F} \\) | \\( 45\sqrt{235/F} \\) | \\( 48\sqrt{235/F} \\) | 左記以外 |
| 柱 | 角形断面 | — | \\( 33\sqrt{235/F} \\) | \\( 37\sqrt{235/F} \\) | \\( 48\sqrt{235/F} \\) | 左記以外 |
| 柱 | 円形断面 | — | \\( 50(235/F) \\) | \\( 70(235/F) \\) | \\( 100(235/F) \\) | 左記以外 |
| はり | H 形断面 | フランジ | \\( 9\sqrt{235/F} \\) | \\( 11\sqrt{235/F} \\) | \\( 15.5\sqrt{235/F} \\) | 左記以外 |
| はり | H 形断面 | ウェブ | \\( 60\sqrt{235/F} \\) | \\( 65\sqrt{235/F} \\) | \\( 71\sqrt{235/F} \\) | 左記以外 |

**備考**
1. この表の規定は、基準強度が 205 N/mm² 以上で 375 N/mm² 以下である鋼材に限る。
2. 基準強度が 235 N/mm² 及び 325 N/mm² 以外の炭素鋼にあっては、H 形断面及び角形断面では \\( \sqrt{235/F} \\) を、円形断面では \\( 235/F \\) を、400N 級鋼の幅厚比に乗じた値とする。

H 形断面はフランジ・ウェブの両方を判定し、**不利な方（FD 寄り）** を部材の種別として採用します。
角形鋼管・円形鋼管は同表に「はり」の行がないため、柱の行を準用します。

幅厚比表に行のない形状（溝形・T形・山形等）は、規範的根拠のない仮のしきい値で
自動判定することを避けるため**自動判定の対象外**とし、当該部材はランク未判定とします。層切断面の必須構成員のランクが未判定なら自動判定を停止し、手動ランクへ暗黙に切り替えません。利用者が手動判定を明示選択する必要があります。

準備計算に表示する代表幅厚比は形状寸法からの簡易値であり、角形鋼管は内法寸法を用い、円形鋼管は対象外です。部材種別判定に使う上表の幅厚比とは区別してください。

### 角形鋼管の鋼種別限界値

冷間成形角形鋼管（BCR・BCP）及び一般構造用角形鋼管（STKR）は、鋼種ごとの限界値を用います。

| 鋼種 | FA | FB | FC | FD |
|---|---|---|---|---|
| STKR400 / BCP235 | 33 | 37 | 48 | 左記以外 |
| STKR490 / BCP325 | 27 | 32 | 41 | 左記以外 |
| BCR295 | 30 | 34 | 43 | 左記以外 |

### 筋かいの種別

筋かいの種別判定に用いるFも、通常鋼部材と同じ[材種・実板厚の選択規則](../06_一次設計/01_材料の許容応力度.md#鋼材のf値と入力条件)に従います。既知材種の表のFを保存された降伏応力で上書きせず、材料・必要厚・直接入力強度の不備を既定値で補いません。

| | 有効細長比 \\( \lambda \\) | 筋かいの種別 |
|---|---|---|
| (一) | \\( \lambda \le 495/\sqrt{F} \\) | BA |
| (二) | \\( 495/\sqrt{F} < \lambda \le 890/\sqrt{F} \\) 又は \\( 1980/\sqrt{F} \le \lambda \\) | BB |
| (三) | \\( 890/\sqrt{F} < \lambda < 1980/\sqrt{F} \\) | BC |

## SRC 部材の種別

### SRC 柱の種別

鉄骨鉄筋コンクリート造の柱は、軸力比 \\( N/N\_0 \\)・鉄骨曲げ耐力比 \\( {}\_sM\_0/M\_0 \\) と破壊モードで種別を定めます（2025年版技術基準解説書、第2版第1刷、6.5.4(2) p.442、告示第1792号第5一）。

**既定値**：内蔵鉄骨の基準強度 \\( {}\_sF \\) は断面の内蔵鉄骨材料の名称から板厚区分（フランジ厚）込みで解決し、解決できない場合は 235 N/mm²（400N 級鋼相当）とします。主筋の降伏強度 \\( \sigma\_y \\) は断面の主筋材料の \\( f\_y \\) から解決します。判定対象は SRC 矩形断面の柱で、SRC 梁は表に規定がないため自動ランク判定の対象外とします。層切断面の必須構成員が未判定なら自動判定を停止し、手動判定の指定ランクへ暗黙に切り替えません。SRC 矩形柱で Fc 未設定または 0 以下・増分解析応答なし・主筋降伏強度を解決できない・ランク判定比を算定できない場合はフォールバックせず部材 ID 付きエラーとします。

柱の分類表は、柱・はりの大部分がSRC造の階を対象とします。靭性を期待する柱の内蔵鉄骨は充腹形又はラチス形とし、格子形を用いません。非埋込み柱脚に曲げ降伏が生じる柱はRC柱としてDsを定める必要があります（同書6.5.4(2) p.444）。本プログラムはこれらの適用成立や柱脚条件によるRC扱いを自動確認しません。

#### 現在の候補計算の耐力と記号

以下は現在の矩形SRC柱の略算累加による候補値です。表の記号との対応を示すもので、原典が要求する耐力定義の採用可否を確定するものではありません。寸法はmm、面積はmm²、強度はN/mm²とします。

\\[
N_0={}_cA_c F_c+{}_sA\,{}_sF+a_r\sigma_y\quad[\mathrm{N}]
\\]

\\[
{}_sM_0={}_sZ_p\,{}_sF\quad[\mathrm{N\,mm}]
\\]

\\[
M_0={}_sM_0+{}_rM_0,\qquad {}_rM_0=0.9a_t\sigma_y d_e
\quad[\mathrm{N\,mm}]
\\]

内蔵H形鋼の寸法を高さ\\(H_s\\)、幅\\(B_s\\)、フランジ厚\\(t_f\\)、ウェブ厚\\(t_w\\)、SRC外形を\\(B\times D\\)とします。

\\[
{}_sA=2B_s t_f+(H_s-2t_f)t_w,\qquad
{}_cA_c=\max(BD-{}_sA-a_r,0)
\\]

\\[
{}_sZ_p=B_s t_f(H_s-t_f)+\frac{t_w(H_s-2t_f)^2}{4}
\quad[\mathrm{mm}^3]
\\]

| 記号 | 現在の候補計算で用いる量 |
| --- | --- |
| \\(N_0\\) | コンクリート正味断面・内蔵鉄骨・全主筋の圧縮耐力の和 |
| \\({}_cA_c\\)、\\(a_r\\) | 鉄骨・全主筋を控除したコンクリート面積、全主筋面積 |
| \\({}_sF\\)、\\(\sigma_y\\) | 内蔵鉄骨の基準強度、主筋の降伏強度 |
| \\({}_sM_0\\) | 内蔵H形鋼の強軸全塑性曲げ耐力 |
| \\(M_0\\) | 軸力0におけるSRC曲げ耐力の候補値（鉄骨とRC部分の略算値の和） |
| \\(a_t\\)、\\(d_e\\) | X方向配筋の上側最外段1列の主筋面積、対向縁から同列までの有効せい |

\\(a_t\\)は最外段の本数分で、内側の段は足しません。\\(d_e=\max(D-d_t,0)\\)、\\(d_t=c+\phi_w+\phi_m/2\\)で、\\(c,\phi_w,\phi_m\\)はかぶり・帯筋径・主筋径です。多段全体の重心を使う梁の定義とは区別します。現在の候補計算は内蔵鉄骨の強軸とこの主筋列を用い、加力方向に応じた弱軸耐力比への切替は行いません。

#### 無次元比から種別を読む

\\[
\eta_N=\frac{N}{N_0},\qquad \eta_M=\frac{{}_sM_0}{M_0}
\\]

いずれも無次元で、\\(N_0,M_0>0\\)が必要です。\\(N\\)は上記RCと同じDs確定stepの両端圧縮力最大値で、両端引張なら0です。力やモーメントは分子・分母で単位をそろえます。

| 軸力比 \\(\eta_N\\) | 鉄骨曲げ耐力比 \\(\eta_M\\) | 曲げ破壊 | せん断破壊 |
| --- | --- | --- | --- |
| \\(0\le\eta_N\le0.3\\) | \\(\eta_M\ge0.4\\) | FA | FB |
| \\(0\le\eta_N\le0.3\\) | \\(\eta_M<0.4\\) | FB | FC |
| \\(0.3<\eta_N\le0.4\\) | \\(\eta_M\ge0.4\\) | FB | FC |
| \\(0.3<\eta_N\le0.4\\) | \\(\eta_M<0.4\\) | FC | FD |
| \\(\eta_N>0.4\\) | 比によらない | FD | FD |

\\(\eta_N=0.3\\)は上側2行、0.4は中段2行、\\(\eta_M=0.4\\)は「以上」の行です。有効な非負の軸力比と有限の曲げ耐力比について行は重複・欠落しません。例えば\\(N=1.2\times10^6\\) N、\\(N_0=4.0\times10^6\\) N、\\({}_sM_0=2.0\times10^8\\) N·mm、\\(M_0=5.0\times10^8\\) N·mmが確認できたとすれば、比は0.3と0.4であり、曲げ破壊ならFA、せん断破壊ならFBです。これは表の境界を読む例であり、当該耐力値を採用できる断面の例ではありません。

候補計算の破壊モードは、採用stepまでにせん断降伏イベントが記録された部材をせん断破壊、それ以外を曲げ破壊とします。イベントがないことだけでは原典の破壊状況や崩壊機構の成立を保証しません。

原典の\\(N_0\\)が求める圧縮耐力の定義、\\(M_0\\)の軸力0での評価方法、鉄骨の強軸比を用いる条件、軸力分担・破壊モードとの対応は[既存の原典調査課題](https://github.com/hrntsm/SEPIKA/issues/953)で未確認です。同書付録の終局N–M関係にも\\(N_0,M_0\\)という記号がありますが、ここでの部材種別用の同名量とは定義が異なり、その式を転用しません。現行略算の適用性・安全側／危険側は未確定であり、上記の式や表との一致で確認を代替しません。

### SRC 耐震壁の種別

側柱（壁と両端の節点を共有する鉛直部材）に SRC 造の柱がある耐震壁は、\\( \tau\_u/F\_c \\) の表によらず破壊モードで種別を定めます。

| 破壊モード | 種別 |
|---|---|
| せん断破壊 | WC |
| それ以外 | WA |

破壊モードは、Ds 判定用に明示採用した確定 step に記録された壁専用応答の局所面内せん断力 \\( Q_w \\) と、その符号に対応する正負別終局せん断耐力 \\( Q_u \\) を用い、\\( |Q_w| \ge 0.99 Q_u \\) をせん断破壊と判定します。加力方向への射影値 \\( Q_{dir} \\) はこの局所判定に用いません。評価点の指定だけでは崩壊機構の成立を保証しません。採用点における機構を確認します。この0.99倍による同定だけでは、原典が求める崩壊形時の実際の破壊状況を確認したことにはなりません。閾値未到達だけで非せん断破壊と判断しないでください。壁専用応答・生成入力の識別が未記録または不正な場合や、対応する \\( Q_u \\) が未算定・非有限・0 以下の場合は、層の選択ランクへフォールバックせずエラーとします。
