# 部材ランク（FA〜FD）

昭和55年建設省告示第1792号と学会規準（RC 靭性、S 幅厚比）に基づき、部材ランク FA〜FD を、RC はせん断余裕度で、S は幅厚比で判定します。

**算定式**
- RC 部材種別: 下記の[RC 部材の種別](#rc-部材の種別)の多変数表（\\( h\_0/D \\)・\\( \sigma\_0/F\_c \\)・\\( p\_t \\)・\\( \tau\_u/F\_c \\)）で判定する。
- S 部材種別: 下記の[鋼材の幅厚比種別](#鋼材の幅厚比種別)の幅厚比限界値表（部材種別・断面・部位・鋼種別）で判定する。
- SRC 部材種別: 下記の[SRC 部材の種別](#src-部材の種別)の判定比（\\( N/N\_0 \\)・\\( {}\_sM\_0/M\_0 \\)）と破壊モードの表で判定する。

**実装参照**：`sepika_design_jp::secondary::ds_group` が告示表による部材種別・部材群種別・Ds を、`sepika_design_jp::secondary::width_thickness` が幅厚比を算定します。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( h\_0/D \\) | 柱の内法高さと断面せいの比 | - |
| \\( \sigma\_0/F\_c \\) | 柱の軸方向応力度とコンクリート設計基準強度の比 | - |
| \\( p\_t \\) | 引張鉄筋比 | % |
| \\( \tau\_u/F\_c \\) | 平均せん断応力度とコンクリート設計基準強度の比 | - |
| \\( N/N\_0 \\) | SRC 柱の軸力比 | - |
| \\( {}\_sM\_0/M\_0 \\) | SRC 柱の鉄骨曲げ耐力比 | - |
| \\( Q\_{su}, Q\_{mu} \\) | 終局せん断耐力・曲げ終局時せん断力 | N |

| \\( r\_2 \\) | 耐力用の開口低減率 | - |
| \\( Q\_u \\) | 耐震壁の終局せん断強度 | N |

## RC 部材の種別

### 柱及びはりの種別

いずれも「せん断破壊、付着割裂破壊及び圧縮破壊その他の構造耐力上支障のある急激な耐力の低下のおそれのある破壊を生じないこと」を満たすことが前提で、これを満たさない場合は FD とします。

| 種別 | 柱 \\( h\_0/D \\) | 柱 \\( \sigma\_0/F\_c \\) | 柱 \\( p\_t \\) | 柱 \\( \tau\_u/F\_c \\) | はり \\( \tau\_u/F\_c \\) |
|---|---|---|---|---|---|
| FA | 2.5 以上 | 0.35 以下 | 0.8 以下 | 0.1 以下 | 0.15 以下 |
| FB | 2.0 以上 | 0.45 以下 | 1.0 以下 | 0.125 以下 | 0.2 以下 |
| FC | — | 0.55 以下 | — | 0.15 以下 | — |
| FD | FA, FB 又は FC のいずれにも該当しない場合 | | | | |

- \\( h\_0 \\): 柱の内法高さ、\\( D \\): 加力方向の柱の断面せい
- \\( \sigma\_0 \\): Ds 算定時に柱の断面に生じる軸方向応力度
- \\( p\_t \\): 引張鉄筋比 [%]
- \\( F\_c \\): コンクリートの設計基準強度
- \\( \tau\_u \\): Ds 算定時に柱、梁の断面に生じる平均せん断応力度

本プログラムは \\( \sigma\_0, \tau\_u \\) を Ds 判定用に明示採用した確定 step の部材応答から算定し、急激な耐力低下のおそれのある破壊はせん断先行（\\( Q\_{su} < Q\_{mu} \\)）で判定します。評価点の指定だけでは崩壊機構の成立を保証しません。採用点における機構を確認します。

### 耐力壁の種別

「せん断破壊、その他の構造耐力上支障のある急激な耐力の低下のおそれのある破壊を生じないこと」が前提です。

| 種別 | 壁式構造以外の構造の耐力壁 \\( \tau\_u/F\_c \\) | 壁式構造の耐力壁 \\( \tau\_u/F\_c \\) |
|---|---|---|
| WA | 0.20 以下 | 0.1 以下 |
| WB | 0.25 以下 | 0.125 以下 |
| WC | — | 0.15 以下 |
| WD | WA, WB, WC のいずれにも該当しない場合 | |

本プログラムでの耐力壁の種別は、告示の表に加えて、開口低減とせん断頭打ちの到達を見て決めます。

\\( \tau\_u \\) は、Ds 判定用に明示採用した確定 step の壁単体局所面内せん断力の絶対値 \\( |Q_w| \\) を有効断面 \\( t \cdot l\_w \cdot r\_2 \\) で除して算定します。
開口があると壁板の有効断面が減るため、分母には耐力用開口低減率 \\( r\_2 \\) を乗じます。
たとえば \\( r\_2 = 0.5 \\) なら有効断面は半分になり、\\( \tau\_u \\) は 2 倍になります。
\\( r\_2 \\) は次の式です。

\\[ r\_2 = 1 - \max\left(r\_0,\; l\_0/l\_w,\; h\_0/h\right) \\]

\\[ r\_0 = \sqrt{h\_0 l\_0 / (h l\_w)} \\]

開口が複数あるときは、面積等価の 1 開口へまとめてから上式へ入れます。
等価開口の幅は \\( l\_0 = \sum l\_i \\)、高さは \\( h\_0 = \sum(l\_i h\_i)/l\_0 \\) です。
複数開口のまとめ方は、包絡／面積等価／自動のうち、建物一律の設定に従います。
既定のまとめ方は面積等価です。
個別の開口寸法が未入力のときは低減しないため、\\( r\_2 = 1 \\) とします。
\\( r\_2 = 0 \\) になると有効断面が0で平均せん断応力度を算定できないため、自動判定をエラーとします。
自動判定で必要な層のランクを 1 本も算定できない場合は、理由を示して判定を停止します。手動判定を利用者が明示選択した場合に限り、設計タブの指定ランクを使用します。自動判定の欠損を指定ランクや既定 FA で補いません。

壁応答には、壁単体の局所面内せん断力 \\(Q_w\\) と加力方向への符号付き寄与 \\(Q_{dir}\\) を別々に記録します。定義・合成基準点・入力表と一次資料は[壁単体の確定ステップ応答](../04_要素剛性/05_壁エレメントモデル.md#壁単体の確定ステップ応答)を参照してください。局所正負別 \\(Q_u[+,-]\\) の選択には \\(Q_w\\) の符号を用います。下辺a/bの反転では局所符号と耐力の張力側対応が一緒に反転します。

局所壁ランクの自動判定には、Ds 判定用に明示採用した同じ確定 step の \\(|Q_w|\\) を既存式へ渡します。層の βu は、その Ds 評価点での符号付き層切断面力から算定します。壁系の分子は面内壁パネルと切断面をまたぐ鉛直側柱の寄与、分母は同じ層・方向・run・入力世代・step の全体系の寄与です。共有側柱は壁系全体へ一度だけ計上し、柱梁側へ二重計上しません。境界梁を無条件に足すことも、局所 \\(|Q_{dir}|\\) を壁の層負担力として加算することもありません。局所壁応力の判定と、壁系全体の層力・βu の評価を区別します。層外力との釣合い、反転、開口・共有側柱などの独立回帰を検証していますが、多層をまたぐ壁や斜め壁など一般配置の網羅的 Validation は未完了です。

目的別に保持した解析条件と現在のモデル・材料・実荷重から確認した入力識別が一致しない結果、壁専用の確定履歴が未記録の結果、壁幾何の適用外、非有限な内力、上下力・モーメントの釣合い不成立は自動判定を拒否します。材料せん断ひずみと壁の線材用イベントは未提供であり、イベントなしを「塑性化なし」と読むことはできません。実測・原典例題による壁ランクのValidationは未完了です。

「壁式構造」の列へ切り替えるかどうかは、設計タブの「壁式構造」チェックで決めます。
既定ではチェックを外した状態で、壁式構造以外の列を使います。
見るのは設計タブのチェックだけなので、階の構造種別からは自動では切り替えません。

増分解析の壁要素は、面内せん断を終局せん断強度 \\( Q\_u \\) で頭打ちにする弾完全塑性としてモデル化します。
Ds 判定用に明示採用した確定 step の局所面内せん断力の絶対値が \\( Q\_u \\) の 99 % 以上（\\( |Q_w| \ge 0.99\\, Q\_u \\)）に達したときは、せん断が頭打ちに達したとみなし、種別を WD とします。
数値誤差を見込んで 100 % ではなく 99 % で切るため、頭打ちの直前で WA〜WC に残ることを避けます。
\\( Q\_u \\) が0以下・非有限で算定できないときは、自動判定をエラーとします。未対応や不正な耐力を0として判定しません。
\\( Q\_u \\) の算定にも、同じ \\( r\_2 \\) を反映します（[壁エレメントモデル](../04_要素剛性/05_壁エレメントモデル.md)）。

## 鋼材の幅厚比種別

鉄骨部材の種別は、板要素の幅厚比を限界値と比較して定めます（技術基準解説書「鋼材の幅厚比種別等」）。

### 幅厚比の計算方法

| 断面 | 部位 | 幅厚比 |
|---|---|---|
| H 形鋼 | フランジ | \\( b/t\_f \\)（\\( b \\) はフランジ半幅 \\( = B/2 \\)） |
| H 形鋼 | ウェブ | \\( (D - 2t\_f)/t\_w \\)（内法せい） |
| 角形鋼管 | （径厚比） | \\( B/t \\)（**全せい**。内法ではない） |
| 円形鋼管 | （径厚比） | \\( D/t \\)（外径） |

### 柱及びはりの種別

\\( F \\) は平成12年建設省告示第2464号第1に規定する基準強度 [N/mm²] です。

| 部材 | 断面 | 部位 | FA | FB | FC | FD |
|---|---|---|---|---|---|---|
| 柱 | H 形断面 | フランジ | \\( 9.5\sqrt{235/F} \\) | \\( 12\sqrt{235/F} \\) | \\( 15.5\sqrt{235/F} \\) | 左記以外 |
| 柱 | H 形断面 | ウェブ | \\( 43\sqrt{235/F} \\) | \\( 45\sqrt{235/F} \\) | \\( 48\sqrt{235/F} \\) | 左記以外 |
| 柱 | 角形断面 | — | \\( 33\sqrt{235/F} \\) | \\( 37\sqrt{235/F} \\) | \\( 48\sqrt{235/F} \\) | 左記以外 |
| 柱 | 円形断面 | — | \\( 50(235/F) \\) | \\( 70(235/F) \\) | \\( 100(235/F) \\) | 左記以外 |
| はり | H 形断面 | フランジ | \\( 9\sqrt{235/F} \\) | \\( 11\sqrt{235/F} \\) | \\( 15.5\sqrt{235/F} \\) | 左記以外 |
| はり | H 形断面 | ウェブ | \\( 60\sqrt{235/F} \\) | \\( 65\sqrt{235/F} \\) | \\( 71\sqrt{235/F} \\) | 左記以外 |

**備考**
1. この表の規定は、基準強度が 205 N/mm² 以上で 375 N/mm² 以下である鋼材に限る。
2. 基準強度が 235 N/mm² 及び 325 N/mm² 以外の炭素鋼にあっては、H 形断面及び角形断面では \\( \sqrt{235/F} \\) を、円形断面では \\( 235/F \\) を、400N 級鋼の幅厚比に乗じた値とする。

H 形断面はフランジ・ウェブの両方を判定し、**不利な方（FD 寄り）** を部材の種別として採用します。
角形鋼管・円形鋼管は同表に「はり」の行がないため、柱の行を準用します。

幅厚比表に行のない形状（溝形・T形・山形等）は、規範的根拠のない仮のしきい値で
自動判定することを避けるため**自動判定の対象外**とし、当該部材はランク未判定とします。層切断面の必須構成員のランクが未判定なら自動判定を停止し、手動ランクへ暗黙に切り替えません。利用者が手動判定を明示選択する必要があります。

| STKR490 / BCP325 | 27 | 32 | 41 | 左記以外 |

|---|---|---|
| (一) | \\( \lambda \le 495/\sqrt{F} \\) | BA |

## SRC 部材の種別

### SRC 柱の種別

鉄骨鉄筋コンクリート造の柱は、軸力比 \\( N/N\_0 \\)・鉄骨曲げ耐力比 \\( {}\_sM\_0/M\_0 \\) と破壊モードで種別を定めます（技術基準解説書 表 2.6.6-5）。

| 破壊モード | \\( N/N\_0 \le 0.3 \\) かつ \\( {}\_sM\_0/M\_0 \ge 0.4 \\) | \\( N/N\_0 \le 0.3 \\) かつ \\( {}\_sM\_0/M\_0 < 0.4 \\) | \\( 0.3 < N/N\_0 \le 0.4 \\) かつ \\( {}\_sM\_0/M\_0 \ge 0.4 \\) | \\( 0.3 < N/N\_0 \le 0.4 \\) かつ \\( {}\_sM\_0/M\_0 < 0.4 \\) | \\( N/N\_0 > 0.4 \\) |
|---|---|---|---|---|---|
| 曲げ破壊 | FA | FB | FB | FC | FD |
| せん断破壊 | FB | FC | FC | FD | FD |

- \\( N \\): Ds 判定用に明示採用した確定 step に柱に生じる軸方向力（圧縮を正とし、引張の場合は 0 として扱う）
- \\( N\_0 \\): SRC 断面の圧縮耐力
- \\( {}\_sM\_0 \\): 内蔵鉄骨の曲げ耐力
- \\( M\_0 \\): 軸力 0 とした SRC 断面の曲げ耐力
- 破壊モード: 増分解析でせん断降伏イベントが記録された部材をせん断破壊、それ以外を曲げ破壊とする

評価点の指定だけでは崩壊機構の成立を保証しません。採用点における機構を確認します。耐力は SRC 規準の累加強度の考え方に基づく略算で評価します。

- \\( N\_0 = {}\_cA\_c \cdot F\_c + {}\_sA \cdot {}\_sF + a\_r \cdot \sigma\_y \\)（コンクリートは鉄骨・主筋を控除した正味断面積 \\( {}\_cA\_c \\)、\\( a\_r \\) は主筋全断面積）
- \\( {}\_sM\_0 = {}\_sZ\_p \cdot {}\_sF \\)（内蔵 H 形鋼の強軸全塑性断面係数 \\( {}\_sZ\_p = B \cdot t\_f (H - t\_f) + t\_w (H - 2t\_f)^2 / 4 \\)）
- \\( M\_0 = {}\_sM\_0 + {}\_rM\_0 \\)（\\( {}\_rM\_0 = 0.9 \\, a\_t \\, \sigma\_y \\, d\_e \\)。\\( a\_t \\) は引張側主筋量、\\( d\_e = D - d\_t \\) は有効せい）

引張縁から主筋群重心までの距離 \\( d\_t \\) は、1 段配筋では \\( \text{かぶり} + \text{せん断補強筋径} + \text{主筋径}/2 \\) です。段数・段別本数で与える配筋の多段配筋（2 段以上）では、段間のあき（主筋径の 1.5 倍と 25 mm の大きい方）を考慮した多段重心位置とし、RC 断面検定の引張有効せいと同じ規則によります。断面中心対称な実配筋では引張側最外段の \\( \text{かぶり} + \text{帯筋径} + \text{主筋径}/2 \\) を \\( d\_t \\) とし、\\( a\_t \\) は同最外段の本数分の主筋量とします。

**既定値**：内蔵鉄骨の基準強度 \\( {}\_sF \\) は断面の内蔵鉄骨材料の名称から板厚区分（フランジ厚）込みで解決し、解決できない場合は 235 N/mm²（400N 級鋼相当）とします。主筋の降伏強度 \\( \sigma\_y \\) は断面の主筋材料の \\( f\_y \\) から解決します。判定対象は SRC 矩形断面の柱で、SRC 梁は表に規定がないため自動ランク判定の対象外とします。層切断面の必須構成員が未判定なら自動判定を停止し、手動判定の指定ランクへ暗黙に切り替えません。SRC 矩形柱で Fc 未設定または 0 以下・増分解析応答なし・主筋降伏強度を解決できない・ランク判定比を算定できない場合はフォールバックせず部材 ID 付きエラーとします。

### SRC 耐震壁の種別

側柱（壁と両端の節点を共有する鉛直部材）に SRC 造の柱がある耐震壁は、\\( \tau\_u/F\_c \\) の表によらず破壊モードで種別を定めます。

| 破壊モード | 種別 |
|---|---|
| せん断破壊 | WC |
| それ以外 | WA |

破壊モードは、Ds 判定用に明示採用した確定 step に記録された壁専用応答の局所面内せん断力 \\( Q_w \\) と、その符号に対応する正負別終局せん断耐力 \\( Q_u \\) を用い、\\( |Q_w| \ge 0.99 Q_u \\) をせん断破壊と判定します。加力方向への射影値 \\( Q_{dir} \\) はこの局所判定に用いません。評価点の指定だけでは崩壊機構の成立を保証しません。採用点における機構を確認します。壁専用応答・生成入力の識別が未記録または不正な場合や、対応する \\( Q_u \\) が未算定・非有限・0 以下の場合は、層の選択ランクへフォールバックせずエラーとします。

## 部材群としての種別

層の Ds は個々の部材ではなく、**部材群としての種別**（A・B・C）で定めます。

| | 部材の耐力の場合 | 部材群としての種別 |
|---|---|---|
| (一) | \\( \gamma\_A \ge 0.5 \\) かつ \\( \gamma\_C \le 0.2 \\) | A |
| (二) | \\( \gamma\_C < 0.5 \\)（部材群としての種別が A の場合を除く） | B |
| (三) | \\( \gamma\_C \ge 0.5 \\) | C |

- \\( \gamma\_A \\): 筋かいの部材群の種別を定める場合は、種別 BA である筋かいの耐力の和をすべての筋かいの水平耐力の和で除した数値。柱及びはりの部材群の種別を定める場合は、種別 FA である柱の耐力の和を種別 FD である柱を除くすべての柱の水平耐力の和で除した数値。
- \\( \gamma\_C \\): 同様に、種別 BC である筋かい／種別 FC である柱について求めた数値。

<div class="impl-ref">

**実装参照**：`sepika_design_jp::secondary::ds_group::member_group` が耐力比 \\( \gamma\_A, \gamma\_C \\) から判定します。

</div>

\\( \beta\_u \\) は耐力壁の水平耐力の和を保有水平耐力の数値で除した数値です。

| 耐力壁の部材群としての種別 | 条件 | 柱及びはりの部材群としての種別 A | B | C | D |
|---|---|---|---|---|---|
| A | \\( 0 < \beta\_u \le 0.3 \\) | 0.3 | 0.35 | 0.4 | 0.45 |
| A | \\( 0.3 < \beta\_u \le 0.7 \\) | 0.35 | 0.4 | 0.45 | 0.5 |
| A | \\( \beta\_u > 0.7 \\) | 0.4 | 0.45 | 0.45 | 0.55 |
| B | \\( 0 < \beta\_u \le 0.3 \\) | 0.35 | 0.35 | 0.4 | 0.45 |
| B | \\( 0.3 < \beta\_u \le 0.7 \\) | 0.4 | 0.4 | 0.45 | 0.5 |
| B | \\( \beta\_u > 0.7 \\) | 0.45 | 0.45 | 0.5 | 0.55 |
| C | \\( 0 < \beta\_u \le 0.3 \\) | 0.35 | 0.35 | 0.4 | 0.45 |
| C | \\( 0.3 < \beta\_u \le 0.7 \\) | 0.4 | 0.45 | 0.45 | 0.5 |

### 本プログラムでの部材群種別・βu の算定

βu は [保有水平耐力の判定](01_保有水平耐力の判定.md#符号付き層切断面力と釣合い)に示す、Ds 判定用確定点の符号付き負担力比を使います。部材群の種別を決める耐力重みは、同時点の実負担力とは別の量です。自動ランクを使用する場合は設計タブで各部材の正の耐力重み [N] を明示入力してください。壁系の側柱は壁系へ一度分類し、柱梁系へ再計上しません。

耐力重み・ランク・確定応力が欠ける場合は自動判定を停止します。壁・筋かい群が存在しない純ラーメンではその群を仮にランク A とせず、βu=0 の純ラーメンの表を用います。柱梁群を持たない構造の自動 Ds 判定は未対応として明示し、手動設計入力を求めます。実負担力を耐力と読み替えることや、欠損をランク A・選択ランクで埋めることはありません。自動判定を使用しない場合の手動ランクは設計者の明示入力です。

現行の群種別の D 部材取扱い、柱梁群の範囲、層崩壊時の一段階補正は簡易規則です。目的別集計の釣合い確認は、これらの現行法適合や Ds 表の独立原典照合を保証しません。

**実装参照**：`sepika_app::app::App::compute_holding_capacity`（`crates/sepika-app/src/app/actions/design/holding.rs`）。

</div>
