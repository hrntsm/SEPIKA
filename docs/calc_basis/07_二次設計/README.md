# 建物全体の耐震評価

層間変形角、保有水平耐力、構造特性係数、部材ランク、形状係数、主軸を扱います。層間変形角の確認は、保有水平耐力の評価とは独立した計算項目です。法令上の計算項目と告示の対応は、次のように分けて示します。

| 計算項目 | 参照 |
|---|---|
| 層間変形角 | 令第82条の2 |
| 保有水平耐力 Qu・必要保有水平耐力 Qun | 令第82条の3 |
| Ds・Fes | 令第82条の3第2号、昭55建告第1792号 |
| Z・Rt・Ai を参照する計算 | 昭55建告第1793号 |

令第82条の3は必要保有水平耐力を \\( Q\_{un} = D\_s \times F\_{es} \times Q\_{ud} \\) として規定し、昭55建告第1792号は Ds / Fes の算出方法を定めます。
このため、条文が規定する保有水平耐力の判定と、告示が定める係数の算出方法を分けて記載します。

層間変形角の上限比較は設定値との参考比較であり、法令適合や1/120の緩和資格を自動判定しません。算定対象と表示の制約は[層間変形角](./05_層間変形角.md)を参照してください。

## この章の読み方

| 目的 | 入力・確認する結果 | 詳細 |
| --- | --- | --- |
| 一次地震解析による建物指標 | X／Y地震静的結果から最大柱角、重心位置の変形によるRs、解析剛性と重心によるReを確認 | [層間変形角](05_層間変形角.md)、[剛性率 Rs・偏心率 Re と形状係数 Fes](04_形状係数_Fes.md) |
| 弾性応答の主軸 | X・Yに共通の荷重分布を作用させた結果からレポートの角度を読む | [主軸の計算](06_主軸の計算.md) |
| 部材の分類 | Ds判定用の採用点の応力・破壊形式、断面・配筋等から個別の候補種別を求める | [部材の分類](03_部材ランク.md) |
| 部材群の分類とDs | 部材種別と耐力重みから群を集計し、同じDs点の壁・筋かい負担率βuから係数を求める | [構造特性係数 Ds](02_構造特性係数_Ds.md) |
| 必要耐力と保有耐力の比較 | 地震力Qud、Ds、FesによるQunと、比較用に明示採用した増分解析点のQuを扱う | [保有水平耐力の判定](01_保有水平耐力の判定.md) |

層間変形角は最大の柱変位差、Rsは重心位置の代表変位差を使います。n倍法を有効にするとRsだけは付加剛性を組み込んだ評価用再解析の変位を用い、元の応力と最大層間変形角は置き換えません。増分解析の最終ステップも、Ds用・Qu用の採用評価点へ自動で読み替えません。

## 表示の意味と判定の限界

| 表示・状態 | 意味 |
| --- | --- |
| 層間変形角の参考比較 | 利用者が設定した分母（既定200）との比較。法令適合や緩和資格の確認ではありません |
| Rs・Re・Fesの数値 | 必要な解析結果から算定した個別指標。建物全体の法適合を確定するものではありません |
| 未計算・未算定・算定不能 | 結果の不足や適用外、不正入力等により値を得られない状態。0や前回値で補いません |
| Ds・合否の保留 | 採用状態・破壊形式・部材や接合部等の確認証拠が不足する状態。不適合の確定とも、確認済みとも異なります |
| 層間変形角の対象なし | 対象の上下階を結ぶ柱がない状態。変形角0や合格を意味しません |

現在は一般のRC／Sラーメンを含め、Ds及び保有耐力比較の必要条件の確認情報が不足するため、理由を付して保留します。手動ランクでも解除されません。表示可能な弾性指標や候補部材種別があっても、建物全体の判定完了とは扱わないでください。
