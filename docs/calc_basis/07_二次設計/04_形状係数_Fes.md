# 剛性率 Rs・偏心率 Re と形状係数 Fes

## 算定方法と適用範囲

形状係数Fesは、建物の高さ方向・平面内の剛性の偏りに応じて必要保有水平耐力を割り増す係数です。
各階について、剛性率RsによるFsと偏心率ReによるFeの積で求めます。
建築基準法施行令第82条の3第二号と昭和55年建設省告示第1792号第7の通常式を用います。

Rs・Reの算定には、部材の剛性を適切に評価する必要があります。
Rs≧0.6・Re≦0.15ではそれぞれの係数が1となります。この境界を外れる場合は、以下の式による割増しを行います。

### 個別評価を行う場合

通常式と異なるFesを用いる場合は、告示第7ただし書に基づき、各階の剛性率・偏心率と形状特性の関係を個別に評価する必要があります。
剛性の高い下層部があることだけで、上層階の割増しを一律に除外することはできません。

本機能が算定するのは通常式によるFesです。個別評価による割増しの除外・別値の採用や、その適用可否、法規上の設計ルートは判定しません。
個別評価が必要な案件では、別途その検討を行ってください。

## 形状係数 Fes

形状係数 Fes は、剛性率による Fs と偏心率による Fe の積として算定します。
表2では Re≦0.15 で Fe=1.0、0.15＜Re＜0.30 で直線補間、Re≧0.30 で Fe=1.5 です。
Re=0.15、0.225、0.30 に対して Fe=1.0、1.25、1.5 です。Rs=0.15、Re=0.225 なら Fes=2.1875 です。

**算定式**

\\[ F\_{es} = F\_s \cdot F\_e \\]


## 剛性率 Rs と係数 Fs

告示第1792号第7表1に対応する次式で、剛性率 Rs から Fs を算定します。

**算定式**

\\[ K\_s = h/\delta \\]

\\[ R\_s = K\_s/\mathrm{mean}(K\_s) \\]

\\[ F\_s = \begin{cases} 1.0 & (R\_s \ge 0.6) \\\\ 2.0 - R\_s/0.6 & (R\_s < 0.6) \end{cases} \\]

表1の境界 Rs=0.6 では Fs=1.0 です。Fs に 1.5 の上限は設けません。例えば Rs=0.60、0.30、0.15 に対して Fs=1.0、1.5、1.75 です。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( R\_s \\) | 層の剛性率 | - |
| \\( K\_s \\) | 相対剛性（層間変形角の逆数＝階高 / 層間変位） | - |
| \\( h \\) | 階高 | mm |
| \\( \delta \\) | 重心位置の層間変位 | mm |
| \\( F\_s \\) | 剛性率による形状係数 | - |

自立壁のn倍法を使用する場合は、一次解析結果から求めた壁の付加剛性を壁の位置・方向に応じて上下階へ組み込み、Rs評価用の再解析を行います。同じ地震荷重に対する評価用変位から重心位置の層間変位を求め、床の並進・回転の連成を考慮します。元の応力と[最大層間変形角](05_層間変形角.md)は一次解析結果から求めます。

剛性率に使う層間変位は、柱の最大変位ではなく、重心位置の水平変位差です。上下階それぞれのSL上の節点変位を質量で重み付けして平均し、その差の絶対値を用います。中間節点は床レベルにないため平均に入れません。質量未設定の節点の重みは0、床レベル上の全質量が0なら節点変位の単純平均を用います。階高 h は上下階FL間高さです。

## 偏心率 Re と係数 Fe

告示第1792号第7表2に対応する次式で、偏心率 Re から Fe を算定します。
計算結果の偏心率には、X・Y 両方向の地震時弾性応力解析結果が必要です。方向別の柱剛性を使用できる架構では、柱の負担水平力と変位差から剛心を求めます。層の並進に方向間連成がある場合は、偏心率を保留します。[方向間連成と剛床の剛心・ねじり剛性](#方向間連成と剛床の剛心ねじり剛性)
片方向の結果が欠ける場合、D 値法の略算へ切り替えず、偏心率を算定不能とします。
剛心・偏心率の算定で柱の局所軸を使う場合、その柱の断面参照方向から単位直交基底を構成できなければ、部材と理由を示して算定を停止します。この算定に使わない梁の参照方向は対象に含めません。

**算定式**

柱 i の方向別水平剛性は、X加力結果のX成分、Y加力結果のY成分から別々に求めます。

\\[ \delta_{i,d}=|u_{\mathrm{top},i,d}-u_{\mathrm{bottom},i,d}|,\qquad k_{i,d}=\frac{|Q_{i,d}|}{\delta_{i,d}}\quad(d=X,Y) \\]

上下階SLの節点の水平変位差を用い、中間節点で分割された柱は上下階を結ぶ連なりを1本とします。柱位置は柱頭の平面位置です。

同じ上階SLの節点に複数の柱が接続していても、それぞれの接続から下階SLへ独立した区間が定まれば、一つずつ柱の負担水平力と変位差を評価します。下階SLに達した時点で区間を区切るため、下階SLの節点を共有する場合も各柱を評価できます。

通常の梁要素でモデル化した柱の負担水平力は、最上部材が上階SLに接続する節点の高さで、対象層に入った直後の断面から求めます。引張を正とする材軸力 N と局所せん断力 Qy・Qz は、i端側から部材内へ作用する力にそろえると局所成分が (−N, Qy, Qz) です。上端がi端ならこの符号を使い、上端がj端なら3成分とも反転します。これを全体座標へ変換した水平成分が負担水平力です。i/jの指定順を反転しても同じ物理断面を評価します。方向別剛性の算定で絶対値を取ります。

切断位置と同じ端点に作用する集中部材荷重は、上端側の力の釣合いに含めます。層内の部材荷重は節点変位と端力の算定に反映され、層側にある荷重はこの上端側切片の外力には含めません。剛域がある場合も同じ高さを使います。水平の材端偏心がある場合、同じ高さの剛体オフセットを介して並進力が伝わるため、実材軸端の力を使います。

上端の実材軸端とSL接続節点の高さが異なる場合、最上部材の実材軸が上端から層側へ伸びない場合、又は別の分割材の実材軸が最上部材の上端高さに達する場合は、対象柱と切断位置を特定できない理由を示し、その層の偏心率を算定不能とします。

上下階SLを結ぶ連なりに、上階または下階で同じSLと判定される別の節点どうしを結ぶ柱材があると、変位と断面力に使う区間を一意に特定できません。この場合は該当する柱材と上階・下階の別を示し、その層の偏心率を両方向とも算定不能とします。SLとの距離による選択や変位の補間は行いません。長期軸力による重心と自立壁のn倍法にも同じ柱の区間を使います。

上下階SLの両方に接続する連なりで、中間節点に枝が付く場合や、節点の高さが順に下がる経路を特定できない場合は、部材と中間節点を示してその層の偏心率と形状係数を算定不能とします。中間節点に付く行き止まりや層外へ出る枝も分岐に含めます。上階SLだけを共有する行き止まりや階跨ぎの枝、別の上階SL節点で終わる経路は、その層の下階SLに達しないため算定の対象外です。別の上階SL節点に独立して接続する柱は、その節点から区間を確認します。

最上部材がファイバー柱の場合は、地震時弾性応力解析の始端断面力と上下階SLの節点変位から評価します。これらの柱を含む連なりでは、各分割材の実材軸が鉛直で、実材軸の両端と接続節点の平面位置が一致することが適用条件です。通常柱とこれらの柱が同じ層にある場合も、それぞれの柱を集計します。

方向別の柱剛性を使うときは、対象柱の区間、負担水平力、上下階SLの節点変位のいずれかを確認できないと、対象柱と理由が表示され、その層の偏心率・形状係数・必要保有水平耐力は算定不能になります。自立壁のn倍法で同じ柱の区間が必要な場合は、壁の付加剛性とそれを使う剛性率も算定不能になります。

地震層せん断力の合力点に対する略算として、長期の常時G+P組合せ結果のうち先頭のものを用い、柱頭のSL接続節点の平面位置を各柱の材軸圧縮力で重み付けします。略算の出典は『2025年版 建築物の構造関係技術基準解説書』第2版第1刷 6.2.3(3) p.359 式(6.2-2)です。端の指定にかかわらず、最上部材の上階SL接続節点の高さから層側に入った直後の断面で軸力を評価します。ファイバー柱を含む連なりにも、前述の適用条件の下でこの切断位置を使います。

切断位置、端点の集中部材荷重、剛域、水平の材端偏心の扱いは、通常柱の負担水平力の評価と共通です。傾斜柱も実材軸方向の力を使用します。全体鉛直方向への投影や局所せん断力の鉛直成分の加算は行いません。引張軸力は重みに入れません。

\\[ X_g=\frac{\sum_i N_{c,i}x_i}{\sum_i N_{c,i}},\qquad Y_g=\frac{\sum_i N_{c,i}y_i}{\sum_i N_{c,i}} \\]

長期結果がない場合又は全柱の圧縮軸力合計が0の場合は節点の質量重心を用い、全質量が0なら節点座標の幾何重心を用います。存在する長期結果が不正な場合は、この代用を行わず算定不能とします。

柱の方向別剛性に、使用を指定した自立壁のn倍法の方向別剛性を加えた各位置の剛性を以下の \\(D_x,D_y\\) とします。n倍法を使わない場合は柱の \\(k_{i,X},k_{i,Y}\\) です。Dはここでは方向別剛性を表し、D値略算法による値ではありません。

\\[ X_s=\frac{\sum D_y x}{\sum D_y},\qquad Y_s=\frac{\sum D_x y}{\sum D_x} \\]

\\[ e_x=|X_g-X_s|,\qquad e_y=|Y_g-Y_s| \\]

\\[ K_R=\sum D_x(y-Y_s)^2+\sum D_y(x-X_s)^2 \\]

\\[ r_{ex}=\sqrt{K_R/\sum D_x},\qquad r_{ey}=\sqrt{K_R/\sum D_y} \\]

X加力時は直交するY方向の偏心距離、Y加力時はX方向の偏心距離を用います。
階別・方向別の重心、剛心、ねじり剛性、弾力半径および偏心率の定義は、『2025年版 建築物の構造関係技術基準解説書』6.2.3(3) pp.358–360 を参照してください。[刊行元の書誌](https://www2.icba.or.jp/products/detail.php?product_id=606)

上式は、各位置の水平力をX・Y独立の方向別剛性で表せること、並進に対して求めた剛性で回転時の水平力も表せること、ねじりモーメントを水平力と腕の積で評価できることを前提とします。各構面の力と変形の関係、部材端から伝わる曲げや材軸ねじりの寄与を確認してください。並進架構を原則とする評価条件と直交グリッドを外れる架構での扱いは、同書6.2.3(5) p.362を参照してください。
方向間連成の兆候がない直交構面では、この方向別集計を使用します。各柱の材軸ねじりが回転モーメントに寄与する場合は、層の並進剛性が対角であっても、この集計の \\(K_R\\) と剛床の純ねじり応答から求める剛性は異なります。

\\[ R_{eX}=e_y/r_{ex},\qquad R_{eY}=e_x/r_{ey} \\]

偏心率と Fe:

\\[ R\_e = e/r\_e \\]

\\[ F\_e = \begin{cases} 1.0 & (R\_e \le 0.15) \\\\ \min(1.0 + 0.5(R\_e - 0.15)/0.15, 1.5) & (R\_e > 0.15) \end{cases} \\]

**記号・単位**

| 記号 | 意味 | 単位 |
| --- | --- | --- |
| \\(R_e,F_e\\) | 偏心率・偏心率による形状係数 | - |
| \\(Q_{i,d},N_{c,i}\\) | 柱の方向別水平力・圧縮長期軸力の大きさ | N |
| \\(\delta_{i,d}\\) | 柱の上下階SL間の方向別水平変位差の絶対値 | mm |
| \\(k_{i,d},D_x,D_y\\) | 柱の方向別剛性・壁を含む各位置の方向別剛性 | N/mm |
| \\(x_i,y_i,X_g,Y_g,X_s,Y_s\\) | 柱位置・重心・剛心の平面座標 | mm |
| \\(e_x,e_y,r_{ex},r_{ey}\\) | 偏心距離・方向別弾力半径 | mm |
| \\(K_R\\) | 剛心まわりのねじり剛性 | N·mm/rad |

### 方向間連成と剛床の剛心・ねじり剛性

剛心は、水平力を通すと剛床がねじれずに並進する点です。剛心まわりのねじり剛性は、その点まわりに単位回転を生じさせるモーメントです。部材の材軸がX・Yの両方に傾く場合、傾斜材と直交側の構面材が自由な節点を介して変位を伝える場合、方向別の剛性を持つ断面の軸が全体軸から回転している場合、端部偏心や付加ばねがある場合などでは、回転を除いた並進にも方向間連成が生じ得ます。

直交構面でも、X方向の梁曲げとY方向の梁曲げや壁の変形が、自由な鉛直変位を介してつながると方向間連成を生じ得ます。片方向に傾くブレースの軸変形や鉛直材の片方向の端部偏心も、鉛直変位を通じて他方の構面と連成する場合があります。非剛床でも、直交梁が自由な鉛直軸まわりの節点回転を共有すると水平変位を伝達し得ます。このような入力で層の剛性を同定できない場合も、対象層と変位を伝える部材・自由度を示して保留します。

部材軸が全体軸から回転しているときは、解析に採用する曲げ・せん断剛性と壁側柱の曲げ解放を確認します。断面入力上の剛性が両方向で同じでも、材料の換算や周辺壁の算入で一方向の剛性が変わる場合があります。採用する剛性を確認できない場合は、層と部材を示して保留します。

単層で上端の構造節点が単一の剛床に従い、下端の面内移動と回転が拘束された線形弾性架構では、地震静的解析と同じ剛性で独立したX・Y・ねじりの単位荷重に対する応答を求めます。正の有限な剛性を持つ独立した3自由度が必要です。連成の可能性がある架構で同定条件を満たせない場合は、層と理由を付けて保留します。非剛床・複数剛床・複数層、活動する支持ばね等の付加ばね、加力で活動状態が変わる引張専用ブレース、n倍法の外付け自立壁を含む架構は、この同定の対象外です。
上下端の節点は、剛床への帰属と同じSLの許容範囲を用いて確認します。

全成分が0の節点ばねは連成の判定に含めません。節点ばねの端で活動する自由度がX・Y移動に限られ、全体座標で両方向にまたがる剛性がない場合も、当該ばねは連成の理由になりません。

座標 \\((x_0,y_0)\\) [mm] で純ねじりモーメント \\(M_z\\) [N·mm] を作用させたときの面内変位を \\((u_x,u_y)\\) [mm]、回転を \\(\theta\\) [rad] とします。変位が0となる点と、純ねじりのモーメントを回転で除した値を用います。

\\[ X_s=x_0-u_y/\theta,\qquad Y_s=y_0+u_x/\theta,\qquad K_R=M_z/\theta \\]

X・Y単位荷重の応答から純ねじり応答を重ね合わせて回転を除き、残った並進柔性を逆行列にして \\(K_{xx},K_{xy},K_{yy}\\) [N/mm] を求めます。並進剛性の非対角項が生じると、直交方向の変位を拘束する場合と、直交方向の外力を0にする場合で弾力半径が異なります。同書6.2.3(5) p.362は斜め構面での剛心・ねじり剛性を定義に合わせることを求めています。連成層の弾力半径に用いる拘束条件は定めていないため、剛心とねじり剛性を同定できても、Re・Fes・必要保有水平耐力は算定を保留します。[刊行元の書誌](https://www2.icba.or.jp/products/detail.php?product_id=606)

各部材の方向間連成が層全体の並進剛性では相殺されても、各位置の力が生むモーメントは相殺されるとは限りません。この場合は剛床応答による剛心・ねじり剛性を用い、層の並進剛性の対角項から弾力半径を求めます。偏心率に採用するには、上下階SL間を結ぶ対象柱があり、各柱の区間と上端切断位置を確認できる必要があります。剛床応答を用いる評価で参照するのは柱区間・切断位置と層全体の応答であり、柱ごとの負担水平力や節点変位の比を要しません。結果画面での偏心率の精算には現行モデルのEX・EY両方の地震静的解析結果が必要です。

片方向の鉛直面内だけに傾く部材でも、剛床の鉛直軸まわりの回転が部材の曲げ回転となり、剛心やKRに寄与することがあります。対象層の剛床応答を同定できる場合は、X/Y並進が独立でも、この曲げの寄与を含む剛心・ねじり剛性を採用します。

## 自立壁の剛性（n 倍法）

柱・梁に囲まれていない壁も、階と階をつないでいれば層の剛性に効き、剛心を偏らせます。
これを等価な剛性要素としてRs・Reへ算入する方法が n 倍法です。
**対象は無開口RC自立壁（床領域に取り付く壁版）だけです。**
非RC壁、有開口壁、スリット付き壁は算入しません。主材料を確認できない壁をRC壁として扱いません。
腰壁・垂れ壁・パラペットは、フロア間で壁がつながっていないため層剛性に影響しません。
これらが周辺の柱梁へ及ぼす剛性は、袖壁・腰壁として部材の断面性能へ算入する経路
（[ティモシェンコ梁要素](../04_要素剛性/01_ティモシェンコ梁要素.md)）が受け持つので、
ここで等価剛性要素としても数えると二重に計上することになります。

自立壁も同じ基準で切り分け、**立ち上がりが直上の階レベルに達している壁だけ**を対象とします。
床の上に立つ腰高のパーティションは階と階をつないでいないため、対象にしません。
考慮を指定した対象壁の断面・主材料・構造厚を確認できない場合は算定を停止します。
帰属する層は、壁の下端からその階の階高の半分だけ上がった高さがどの層に入るかで決めます。

### 指定する操作と入力条件

**既定値**は \\( n \\) が未設定で、そのときは雑壁の剛性を考慮しません。
準備計算の「計算条件」で「自立壁の剛性をn倍法で考慮する」を有効にし、係数nと算定方式を指定します。代表内柱方式では各層の柱を選択します。設定を変更した場合は、地震静的解析を再実行してください。
考慮する場合の係数nは**1以上の有限値**に限ります。1未満・非有限値は入力・保存・読込・算定で拒否し、1や「考慮しない」への読み替えは行いません。範囲外の係数を含むプロジェクトファイルは読み込めません。
柱の剛性と面積は、同じ層・同じ柱集合から集計します。各柱の断面積とヤング係数には正の有限値が必要です。必要な変位・内力の欠落、柱の層間変位が0、面積・方向別剛性の不正、集計・演算結果の非有限では、対象と理由を示して算定を停止します。正の層間変位に対してせん断力が0となる正常な剛性0とは区別します。正の微小変位を一律に剛性0へ置き換えません。

### 算定方式と基準柱

基準にする柱の剛性と断面積は、次の二方式から建物全体で共通の方式を選びます。初期選択は層内柱合算方式です。

| 方式 | 基準にする柱 | 壁1枚の等価水平剛性 |
| --- | --- | --- |
| 層内柱合算方式 | 当該層の柱全体 | \\( K\_w' = n A\_w' \sum K\_c / \sum A\_c \\) |
| 代表内柱方式 | 各層で指定した代表的な内柱1本 | \\( K\_w' = n A\_w' K\_c / A\_c \\) |

代表内柱は各層で1本指定し、同じ柱のX・Y方向それぞれの剛性を使います。柱の剛性は、壁の付加剛性を加える前の一次解析結果の \\( |Q\_c|/|\delta\_c| \\) から求めます。方式によって評価結果は異なります。

通常の梁要素でモデル化した斜め柱を基準に含める場合も、偏心率の算定と同じ負担水平力を使います。切断位置や必要な水平力を確認できない場合は、対象柱と理由を示し、壁の付加剛性とそれを用いる剛性率Rsを算定不能とします。[斜め柱の水平力の扱い](#偏心率-re-と係数-fe)
付加剛性を求める層で[剛床のねじれによる柱の層間変位の相殺](#算定できない場合)を検出した場合も、壁の付加剛性と剛性率Rsを算定不能とします。Rsの平均には全層が必要です。

適用範囲は、基準に使う各柱が層内で同一断面となる場合に限ります。層内柱合算方式では集計する全柱、代表内柱方式では指定柱が対象です。中間節点で分割された柱も、一本の連なりを構成する各部材が同一断面である必要があります。異なる柱どうしの断面を揃える必要はありません。
層内で断面が変わる対象柱がある場合は、対象柱と理由を示してn倍法による付加剛性の算定を停止します。異断面柱を集計から外したり、最上部・平均などの代表断面で代用したりしません。この制限はn倍法に関するもので、モデル全体の解析を一律に禁止するものではありません。

\\( A\_w\' \\) は壁の平面長さ × 構造厚です。
構造厚は断面の板厚で、仕上げ・増打ちの面荷重（[壁の断面と自重](../01_荷重/09_壁の断面と自重.md)）は
重さの入力であって厚さではないため含めません。
方向別に求めた \\( K\_{wx}' \\)・\\( K\_{wy}' \\) を壁面内方向の方向余弦 \\( (c\_x, c\_y) \\) で投影し、壁面内方向の単一ばねを壁の平面中点に置きます。

\\[ k\_w = K\_{wx}' c\_x^2 + K\_{wy}' c\_y^2 \\]

\\[ \boldsymbol{K}\_w = k\_w \begin{bmatrix} c\_x^2 & c\_x c\_y \\\\ c\_x c\_y & c\_y^2 \end{bmatrix} \\]

Rs評価用再解析にはこのばねのXY連成と位置による回転連成を反映します。直交配置の方向別評価で使う成分は \\( D\_x=k\_w c\_x^2 \\)、\\( D\_y=k\_w c\_y^2 \\) です。n倍法の自立壁がX・Yの両方向に傾く場合は、付加剛性の連成を含む剛床応答を同定できないためReを保留します。
層内柱合算方式では柱総面積が0の層を算定できません。代表内柱方式では対象層の有効な柱の指定が必要です。

支持条件・配置等によって危険側の評価にならない係数nと代表内柱を選定してください。下限1は一律の推奨値ではありません。両方式とも一次解析から求めた水平剛性を使い、D値による略算とは区別します。
係数を大きくすると付加剛性は比例して増えますが、壁位置によって剛心とねじり剛性が変わるため、剛性率・偏心率・形状係数・必要耐力が一律に安全側へ変わるとは限りません。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( K\_w\' \\) | 雑壁 1 枚の等価水平剛性 | N/mm |
| \\( n \\) | 雑壁の剛性を柱に換算する係数（n 倍法） | - |
| \\( A\_w\' \\) | 壁の平面長さ × 構造厚 | mm² |
| \\( K\_c \\) | 基準にする柱の方向別剛性 | N/mm |
| \\( A\_c \\) | 基準にする柱の断面積 | mm² |
| \\( D\_x, D\_y \\) | 壁の X・Y 方向の層剛性 | N/mm |
| \\( c\_x, c\_y \\) | 壁面内方向の方向余弦 | - |

## 算定できない場合

設計画面とレポート CSV では、Rs は選択方向の地震静的結果、Re は X・Y 両方向の地震静的結果について、現在のモデル・関連計算条件と解析時の入力および計算契約の対応を確認します。
Re の重心に長期結果を用いる場合は、保存された常時 G+P の長期組合せ結果のうち先頭のものも確認します。
必要な結果の欠落、入力不一致、入力識別情報の欠落、計算契約の不一致・欠落があれば、対象の方向・組合せと理由を表示します。
選択方向以外の地震結果又は長期結果だけが無効な場合、Rs と層間変形角の表示は継続し、Re と Fes を算定不能とします。
長期結果が存在しても入力の対応を確認できない場合は、長期結果なしとして質量重心へ切り替えません。
増分解析の刻み・目標変位、表示方向、層間変形角の参考比較分母の変更だけでは、地震静的結果を無効にしません。

階高と重心位置の層間変位は、全層について対応する正の有限値が必要です。
全層の変位が 0 の場合も、一部の層だけが 0 の場合も、相対剛性を定義できないため Rs を算定しません。
ゼロ変位の層を平均から除いたり、Rs=1 や他層の最大値で代用したりしません。
床レベル上の必要節点の変位が欠ける場合、階・方向の対応が取れない場合、非有限値や演算不能がある場合も算定不能です。
自立壁のn倍法を使用する場合、Rs評価用再解析の結果がない場合や再解析できない場合も算定不能です。壁の上下端で接続先の剛床を一意に特定できない場合は、対象と理由を示します。固定支持へ接続する端部を除き、別の床や近くの節点へ置き換えません。
質量が未設定又は全節点の質量が 0 の階では、床レベル上の節点変位の単純平均を重心位置変位として用います。

Re には有限な偏心距離と正の有限な弾力半径が必要です。半径が 0 の場合は、偏心距離も 0 であっても Re を定義できません。
必要な柱の地震時変位・内力が欠ける場合や不正な場合、上下端の変位差を有限値として求められない場合も算定しません。
柱の水平剛性を求める変位差が0の場合は、せん断力も0であっても比を定義できないため算定不能です。変位差が0でない場合も、非有限な商や、以下のねじれによる相殺を検出した場合は算定を保留します。

ねじれ回転による変位が並進による変位を打ち消し、柱の層間変位が0に近づく場合、水平力と変位の比は過大な剛性を与えることがあります。上階が単一の剛床で全評価柱の上端が加力方向に剛床と一体で動き、下階も同様に全評価柱の下端が単一の剛床と一体で動くか、全柱下端が加力方向に固定され応答の変位が0である層で、相殺を確認します。

上階の評価柱上端の平面図心を、上下階に共通の基準位置とします。各床の回転角と基準位置から各柱端までの距離から、加力方向の回転変位を求めます。その上下端の差を柱の回転による層間変位、解析の層間変位から回転による層間変位を引いた値を並進による層間変位とします。これは同じ載荷時の変位の分解です。両成分が逆符号で、解析の層間変位の絶対値が両成分それぞれの絶対値より小さい柱があれば、対象の層・加力方向・柱を示し、その層の両方向の偏心率と形状係数を算定不能とします。判定は力と変位を同じ割合で小さくしても変わりません。

この保留条件は、原典が指定する数値基準ではありません。非剛床、多剛床、剛床から独立に水平移動できる柱などでは、層を共通の並進・回転で表せないため、この相殺判定を行わず、比による評価の適否を設計者が確認します。全評価柱の下端が固定され、上端の加力直交方向の座標がすべて等しい場合は、平面図心からの回転の腕がすべて0となるため、この方法では回転変位を分離できません。検出されない場合も、表示値を採用する前に各構面の水平変形を確認してください。ねじれで柱の層間変位が0に近づく場合は、各階がねじれず構面の水平変形がそろう並進架構等を用いて別途偏心率を評価します。『2025年版 建築物の構造関係技術基準解説書』第2版第1刷 6.2.3 p.362 (5) によります。

長期解析結果を用いて重心を求める場合、必要な柱の上階SL直下の切断位置を一意に特定できない場合や、その材軸力が欠損・非有限の場合は、柱と理由を示して偏心率を算定不能とします。組合せを構成する非零係数の荷重ケースの応答が欠ける場合も、同様に算定不能とします。
長期結果がない場合又は全柱の圧縮軸力の合計が 0 の場合は、質量重心を用います。
質量重心に使う節点質量は未設定を 0 と扱い、全質量が 0 なら節点座標の幾何重心を用います。
長期軸力又は質量から重心を求める際、必要な位置・質量の不正、軸力・質量・位置一次モーメントの集計不能、重心座標の除算不能がある場合も算定不能です。
剛心・ねじり剛性・弾力半径についても、方向別剛性や位置一次モーメントの集計・除算を有限値で行えない場合は算定不能とします。
方向別剛性の合計が 0 の場合、対応する剛心座標は 0 と扱いますが、弾力半径が 0 の Re を正常値で代用しません。
偏心距離が 0 で弾力半径が正なら Re=0 は正常です。有効な全層の相対剛性が等しい場合の Rs=1 も正常です。

結果画面とレポート CSV は、該当する層・加力方向と理由を付けて「算定不能」と表示し、剛性率・偏心率の判定を「判定なし」とします。
Rs 又は Re を算定できなければ Fes と、それに依存する必要保有水平耐力・合否の算定を止めます。
増分解析は引き続き実行でき、保有水平耐力 Qu の評価に用いる層せん断力は増分解析結果に残ります。必要保有水平耐力 Qun と合否を含む保有耐力比較表は保留します。
再計算や保存後の再読込みでも、欠ける入力を既定値や前回の値で補いません。
