# 剛性率 Rs・偏心率 Re と形状係数 Fes

## 算定方法と適用範囲

形状係数Fesは、建物の高さ方向・平面内の剛性の偏りに応じて必要保有水平耐力を割り増す係数です。
各階について、剛性率RsによるFsと偏心率ReによるFeの積で求めます。
建築基準法施行令第82条の3第二号と昭和55年建設省告示第1792号第7の通常式を用います。

Rs・Reの算定には、部材の剛性を適切に評価する必要があります。
Rs≧0.6・Re≦0.15ではそれぞれの係数が1となります。この境界を外れる場合は、以下の式による割増しを行います。

### 個別評価を行う場合

通常式と異なるFesを用いる場合は、告示第7ただし書に基づき、各階の剛性率・偏心率と形状特性の関係を個別に評価する必要があります。
剛性の高い下層部があることだけで、上層階の割増しを一律に除外することはできません。

本機能が算定するのは通常式によるFesです。個別評価による割増しの除外・別値の採用や、その適用可否、法規上の設計ルートは判定しません。
個別評価が必要な案件では、別途その検討を行ってください。

## 剛性率 Rs と係数 Fs

告示第1792号第7表1に対応する次式で、剛性率 Rs から Fs を算定します。

**算定式**

\\[ K\_s = h/\delta \\]

\\[ R\_s = K\_s/\mathrm{mean}(K\_s) \\]

\\[ F\_s = \begin{cases} 1.0 & (R\_s \ge 0.6) \\\\ 2.0 - R\_s/0.6 & (R\_s < 0.6) \end{cases} \\]

表1の境界 Rs=0.6 では Fs=1.0 です。Fs に 1.5 の上限は設けません。例えば Rs=0.60、0.30、0.15 に対して Fs=1.0、1.5、1.75 です。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( R\_s \\) | 層の剛性率 | - |
| \\( K\_s \\) | 相対剛性（層間変形角の逆数＝階高 / 層間変位） | - |
| \\( h \\) | 階高 | mm |
| \\( \delta \\) | 重心位置の層間変位 | mm |
| \\( F\_s \\) | 剛性率による形状係数 | - |

自立壁のn倍法を使用する場合は、一次解析結果から求めた壁の付加剛性を壁の位置・方向に応じて上下階へ組み込み、Rs評価用の再解析を行います。同じ地震荷重に対する評価用変位から重心位置の層間変位を求め、床の並進・回転の連成を考慮します。元の応力と[最大層間変形角](05_層間変形角.md)は一次解析結果から求めます。

剛性率に使う層間変位は、柱の最大変位ではなく、重心位置の水平変位差です。上下階それぞれのSL上の節点変位を質量で重み付けして平均し、その差の絶対値を用います。中間節点は床レベルにないため平均に入れません。質量未設定の節点の重みは0、床レベル上の全質量が0なら節点変位の単純平均を用います。階高 h は上下階FL間高さです。

## 偏心率 Re と係数 Fe

告示第1792号第7表2に対応する次式で、偏心率 Re から Fe を算定します。
計算結果の偏心率は、X・Y 両方向の地震時弾性応力解析結果による柱の水平剛性から剛心を求めて算定します。
片方向の結果が欠ける場合、D 値法の略算へ切り替えず、偏心率を算定不能とします。
剛心・偏心率の算定で柱の局所軸を使う場合、その柱の断面参照方向から単位直交基底を構成できなければ、部材と理由を示して算定を停止します。この算定に使わない梁の参照方向は対象に含めません。

**算定式**

柱 i の方向別水平剛性は、X加力結果のX成分、Y加力結果のY成分から別々に求めます。

\\[ \delta_{i,d}=|u_{\mathrm{top},i,d}-u_{\mathrm{bottom},i,d}|,\qquad k_{i,d}=\frac{|Q_{i,d}|}{\delta_{i,d}}\quad(d=X,Y) \\]

上下階SLの節点の水平変位差を用い、中間節点で分割された柱は上下階を結ぶ連なりを1本とします。せん断力は最上部の分割材の始端断面力を全体座標へ変換した加力方向成分を用い、柱位置は柱頭の平面位置とします。分割材単体の変位差や材長で剛性を求めません。上下階SLを結ぶ柱を対象とし、複数層をまたぎ途中階SLに節点を持たない柱を、変位の補間によって追加することはありません。

重心は、長期の常時G+P組合せ結果のうち先頭のものを用い、各柱の圧縮軸力の大きさで重み付けします。分割柱は同じ最上部材の始端軸力を用います。引張軸力は重みに入れません。

\\[ X_g=\frac{\sum_i N_{c,i}x_i}{\sum_i N_{c,i}},\qquad Y_g=\frac{\sum_i N_{c,i}y_i}{\sum_i N_{c,i}} \\]

長期結果がない場合又は全柱の圧縮軸力合計が0の場合は節点の質量重心を用い、全質量が0なら節点座標の幾何重心を用います。存在する長期結果が不正な場合は、この代用を行わず算定不能とします。

柱の方向別剛性に、使用を指定した自立壁のn倍法の方向別剛性を加えた各位置の剛性を以下の \\(D_x,D_y\\) とします。n倍法を使わない場合は柱の \\(k_{i,X},k_{i,Y}\\) です。Dはここでは方向別剛性を表し、D値略算法による値ではありません。

\\[ X_s=\frac{\sum D_y x}{\sum D_y},\qquad Y_s=\frac{\sum D_x y}{\sum D_x} \\]

\\[ e_x=|X_g-X_s|,\qquad e_y=|Y_g-Y_s| \\]

\\[ K_R=\sum D_x(y-Y_s)^2+\sum D_y(x-X_s)^2 \\]

\\[ r_{ex}=\sqrt{K_R/\sum D_x},\qquad r_{ey}=\sqrt{K_R/\sum D_y} \\]

X加力時は直交するY方向の偏心距離、Y加力時はX方向の偏心距離を用います。

\\[ R_{eX}=e_y/r_{ex},\qquad R_{eY}=e_x/r_{ey} \\]

偏心率と Fe:

\\[ R\_e = e/r\_e \\]

\\[ F\_e = \begin{cases} 1.0 & (R\_e \le 0.15) \\\\ \min(1.0 + 0.5(R\_e - 0.15)/0.15, 1.5) & (R\_e > 0.15) \end{cases} \\]

**記号・単位**

| 記号 | 意味 | 単位 |
| --- | --- | --- |
| \\(R_e,F_e\\) | 偏心率・偏心率による形状係数 | - |
| \\(Q_{i,d},N_{c,i}\\) | 柱の方向別水平力・圧縮長期軸力の大きさ | N |
| \\(\delta_{i,d}\\) | 柱の上下階SL間の方向別水平変位差の絶対値 | mm |
| \\(k_{i,d},D_x,D_y\\) | 柱の方向別剛性・壁を含む各位置の方向別剛性 | N/mm |
| \\(x_i,y_i,X_g,Y_g,X_s,Y_s\\) | 柱位置・重心・剛心の平面座標 | mm |
| \\(e_x,e_y,r_{ex},r_{ey}\\) | 偏心距離・方向別弾力半径 | mm |
| \\(K_R\\) | 剛心まわりのねじり剛性 | N·mm |

## 自立壁の剛性（n 倍法）

柱・梁に囲まれていない壁も、階と階をつないでいれば層の剛性に効き、剛心を偏らせます。
これを等価な剛性要素としてRs・Reへ算入する方法が n 倍法です。
基準にする柱の剛性と断面積は、次の二方式から建物全体で共通の方式を選びます。初期選択は層内柱合算方式です。

| 方式 | 基準にする柱 | 壁1枚の等価水平剛性 |
| --- | --- | --- |
| 層内柱合算方式 | 当該層の柱全体 | \\( K\_w' = n A\_w' \sum K\_c / \sum A\_c \\) |
| 代表内柱方式 | 各層で指定した代表的な内柱1本 | \\( K\_w' = n A\_w' K\_c / A\_c \\) |

代表内柱は各層で1本指定し、同じ柱のX・Y方向それぞれの剛性を使います。柱の剛性は、壁の付加剛性を加える前の一次解析結果の \\( |Q\_c|/|\delta\_c| \\) から求めます。方式によって評価結果は異なります。

適用範囲は、基準に使う各柱が層内で同一断面となる場合に限ります。層内柱合算方式では集計する全柱、代表内柱方式では指定柱が対象です。中間節点で分割された柱も、一本の連なりを構成する各部材が同一断面である必要があります。異なる柱どうしの断面を揃える必要はありません。
層内で断面が変わる対象柱がある場合は、対象柱と理由を示してn倍法による付加剛性の算定を停止します。異断面柱を集計から外したり、最上部・平均などの代表断面で代用したりしません。この制限はn倍法に関するもので、モデル全体の解析を一律に禁止するものではありません。

\\( A\_w\' \\) は壁の平面長さ × 構造厚です。
構造厚は断面の板厚で、仕上げ・増打ちの面荷重（[壁の断面と自重](../01_荷重/09_壁の断面と自重.md)）は
重さの入力であって厚さではないため含めません。
方向別に求めた \\( K\_{wx}' \\)・\\( K\_{wy}' \\) を壁面内方向の方向余弦 \\( (c\_x, c\_y) \\) で投影し、壁面内方向の単一ばねを壁の平面中点に置きます。

\\[ k\_w = K\_{wx}' c\_x^2 + K\_{wy}' c\_y^2 \\]

\\[ \boldsymbol{K}\_w = k\_w \begin{bmatrix} c\_x^2 & c\_x c\_y \\\\ c\_x c\_y & c\_y^2 \end{bmatrix} \\]

Rs評価用再解析にはこのばねのXY連成と位置による回転連成を反映します。Reには同じばねの方向別成分 \\( D\_x=k\_w c\_x^2 \\)、\\( D\_y=k\_w c\_y^2 \\) を用います。
層内柱合算方式では柱総面積が0の層を算定できません。代表内柱方式では対象層の有効な柱の指定が必要です。

**対象は無開口RC自立壁（床領域に取り付く壁版）だけです。**
非RC壁、有開口壁、スリット付き壁は算入しません。主材料を確認できない壁をRC壁として扱いません。
腰壁・垂れ壁・パラペットは、フロア間で壁がつながっていないため層剛性に影響しません。
これらが周辺の柱梁へ及ぼす剛性は、袖壁・腰壁として部材の断面性能へ算入する経路
（[ティモシェンコ梁要素](../04_要素剛性/01_ティモシェンコ梁要素.md)）が受け持つので、
ここで等価剛性要素としても数えると二重に計上することになります。

自立壁も同じ基準で切り分け、**立ち上がりが直上の階レベルに達している壁だけ**を対象とします。
床の上に立つ腰高のパーティションは階と階をつないでいないため、対象にしません。
考慮を指定した対象壁の断面・主材料・構造厚を確認できない場合は算定を停止します。
帰属する層は、壁の下端からその階の階高の半分だけ上がった高さがどの層に入るかで決めます。

**既定値**は \\( n \\) が未設定で、そのときは雑壁の剛性を考慮しません。
準備計算の「計算条件」で「自立壁の剛性をn倍法で考慮する」を有効にし、係数nと算定方式を指定します。代表内柱方式では各層の柱を選択します。設定を変更した場合は、地震静的解析を再実行してください。
考慮する場合の係数nは**1以上の有限値**に限ります。1未満・非有限値は入力・保存・読込・算定で拒否し、1や「考慮しない」への読み替えは行いません。範囲外の係数を含むプロジェクトファイルは読み込めません。
柱の剛性と面積は、同じ層・同じ柱集合から集計します。各柱の断面積とヤング係数には正の有限値が必要です。必要な変位・内力の欠落、柱の層間変位が0、面積・方向別剛性の不正、集計・演算結果の非有限では、対象と理由を示して算定を停止します。正の層間変位に対してせん断力が0となる正常な剛性0とは区別します。正の微小変位を一律に剛性0へ置き換えません。

支持条件・配置等によって危険側の評価にならない係数nと代表内柱を選定してください。下限1は一律の推奨値ではありません。両方式とも一次解析から求めた水平剛性を使い、D値による略算とは区別します。
係数を大きくすると付加剛性は比例して増えますが、壁位置によって剛心とねじり剛性が変わるため、剛性率・偏心率・形状係数・必要耐力が一律に安全側へ変わるとは限りません。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( K\_w\' \\) | 雑壁 1 枚の等価水平剛性 | N/mm |
| \\( n \\) | 雑壁の剛性を柱に換算する係数（n 倍法） | - |
| \\( A\_w\' \\) | 壁の平面長さ × 構造厚 | mm² |
| \\( K\_c \\) | 基準にする柱の方向別剛性 | N/mm |
| \\( A\_c \\) | 基準にする柱の断面積 | mm² |
| \\( D\_x, D\_y \\) | 壁の X・Y 方向の層剛性 | N/mm |
| \\( c\_x, c\_y \\) | 壁面内方向の方向余弦 | - |

## 算定できない場合

設計画面とレポート CSV では、Rs は選択方向の地震静的結果、Re は X・Y 両方向の地震静的結果について、現在のモデル・関連計算条件と解析時の入力および計算契約の対応を確認します。
Re の重心に長期結果を用いる場合は、保存された常時 G+P の長期組合せ結果のうち先頭のものも確認します。
必要な結果の欠落、入力不一致、入力識別情報の欠落、計算契約の不一致・欠落があれば、対象の方向・組合せと理由を表示します。
選択方向以外の地震結果又は長期結果だけが無効な場合、Rs と層間変形角の表示は継続し、Re と Fes を算定不能とします。
長期結果が存在しても入力の対応を確認できない場合は、長期結果なしとして質量重心へ切り替えません。
増分解析の刻み・目標変位、表示方向、層間変形角の参考比較分母の変更だけでは、地震静的結果を無効にしません。

階高と重心位置の層間変位は、全層について対応する正の有限値が必要です。
全層の変位が 0 の場合も、一部の層だけが 0 の場合も、相対剛性を定義できないため Rs を算定しません。
ゼロ変位の層を平均から除いたり、Rs=1 や他層の最大値で代用したりしません。
床レベル上の必要節点の変位が欠ける場合、階・方向の対応が取れない場合、非有限値や演算不能がある場合も算定不能です。
自立壁のn倍法を使用する場合、Rs評価用再解析の結果がない場合や再解析できない場合も算定不能です。壁の上下端で接続先の剛床を一意に特定できない場合は、対象と理由を示します。固定支持へ接続する端部を除き、別の床や近くの節点へ置き換えません。
質量が未設定又は全節点の質量が 0 の階では、床レベル上の節点変位の単純平均を重心位置変位として用います。

Re には有限な偏心距離と正の有限な弾力半径が必要です。半径が 0 の場合は、偏心距離も 0 であっても Re を定義できません。
必要な柱の地震時変位・内力が欠ける場合や不正な場合、上下端の変位差を有限値として求められない場合も算定しません。
柱の水平剛性を求める変位差が0の場合は、せん断力も0であっても比を定義できないため算定不能です。正の変位差では大きさによらず比を求め、非有限な商は算定不能とします。
長期解析結果を用いて重心を求める場合、その必要柱の軸力が欠ける場合や非有限の場合も算定不能です。
長期結果がない場合又は全柱の圧縮軸力の合計が 0 の場合は、質量重心を用います。
質量重心に使う節点質量は未設定を 0 と扱い、全質量が 0 なら節点座標の幾何重心を用います。
長期軸力又は質量から重心を求める際、必要な位置・質量の不正、軸力・質量・位置一次モーメントの集計不能、重心座標の除算不能がある場合も算定不能です。
剛心・ねじり剛性・弾力半径についても、方向別剛性や位置一次モーメントの集計・除算を有限値で行えない場合は算定不能とします。
方向別剛性の合計が 0 の場合、対応する剛心座標は 0 と扱いますが、弾力半径が 0 の Re を正常値で代用しません。
偏心距離が 0 で弾力半径が正なら Re=0 は正常です。有効な全層の相対剛性が等しい場合の Rs=1 も正常です。

結果画面とレポート CSV は、該当する層・加力方向と理由を付けて「算定不能」と表示し、剛性率・偏心率の判定を「判定なし」とします。
Rs 又は Re を算定できなければ Fes と、それに依存する必要保有水平耐力・合否の算定を止めます。
再計算や保存後の再読込みでも、欠ける入力を既定値や前回の値で補いません。

## 形状係数 Fes

形状係数 Fes は、剛性率による Fs と偏心率による Fe の積として算定します。
表2では Re≦0.15 で Fe=1.0、0.15＜Re＜0.30 で直線補間、Re≧0.30 で Fe=1.5 です。
Re=0.15、0.225、0.30 に対して Fe=1.0、1.25、1.5 です。Rs=0.15、Re=0.225 なら Fes=2.1875 です。

**算定式**

\\[ F\_{es} = F\_s \cdot F\_e \\]
