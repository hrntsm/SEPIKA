# 形状係数 Fes（剛性率 Fs・偏心率 Fe）

## 算定の対象と根拠の確認範囲

本ページで採用する通常計算は、下記の Fs・Fe の積による Fes です。
Fs・Fe の折線は、建築研究所・小山信「[『新耐震基準』から40年を振り返る](https://www.kenken.go.jp/japanese/research/lecture/r03/pdf/T07_Koyama.pdf)」（2021年、PDF4頁・図5）の改訂後の折線に対応します。
告示ただし書による個別評価、例外の適用可否及び法規上の設計ルートは判定しません。
通常計算の結果が得られることだけでは、個別の建築物への法規上の適用が確認されたことにはなりません。

正式な根拠法令は、建築基準法施行令第82条の3第二号と、昭和55年11月27日建設省告示第1792号「Ds及びFesを算出する方法を定める件」です。
ただし、同告示第7の本文・表1/2・ただし書を公布済みの公的原文で一体として照合する作業は未完了です。
採用する告示の版・施行時点、通常式の法規上の適用条件及びただし書の個別評価との境界は、確認済みとは扱いません。
告示の公布・改正の沿革は[国立国会図書館「日本法令索引」](https://hourei.ndl.go.jp/simple/detail?current=-1&lawId=0000069125)で確認できますが、本文・表の照合の代わりにはなりません。

## 剛性率 Rs・Fs

建築基準法施行令 第82条の6 と告示第1792号に基づき、剛性率 Rs（規定は \\( R\_s \ge 0.6 \\)）から Fs を算定します。

**算定式**

\\[ K\_s = h/\delta \\]

\\[ R\_s = K\_s/\mathrm{mean}(K\_s) \\]

\\[ F\_s = \begin{cases} 1.0 & (R\_s \ge 0.6) \\\\ 2.0 - R\_s/0.6 & (R\_s < 0.6) \end{cases} \\]

Fs に 1.5 の上限は設けません。例えば Rs=0.60、0.30、0.15 に対して Fs=1.0、1.5、1.75 です。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( R\_s \\) | 層の剛性率 | - |
| \\( K\_s \\) | 層の剛性（階高 / 層間変位） | - |
| \\( h \\) | 階高 | mm |
| \\( \delta \\) | 重心位置の層間変位 | mm |
| \\( F\_s \\) | 剛性率による形状係数 | - |

<div class="impl-ref">

**実装参照**：`sepika_design_jp::secondary::holding_capacity::{stiffness_ratios, fs}` が算定し、δg は `sepika_design_jp::secondary::stiffness_ratio::cog_story_drifts` です。
剛性率に使う層間変位は、柱の最大変位ではなく、重心位置の水平変位 δg です。
各層の δg は、上端の床レベル上の節点と下端の床レベル上の節点について、重心位置の水平変位の差として求めます。
δg は柱の層間変位とは別の量であり、中間節点は床レベルにないため平均には入れません。

</div>

## 偏心率 Re・Fe

建築基準法施行令第 82 条の 6 と告示第 1792 号に基づき、偏心率 Re から Fe を算定します。
規定は \\( R\_e \le 0.15 \\) です。
計算結果の偏心率は、X・Y 両方向の地震時弾性応力解析結果による柱の水平剛性から剛心を求めて算定します。
片方向の結果が欠ける場合、D 値法の略算へ切り替えず、偏心率を算定不能とします。
剛心・偏心率の算定で柱の局所軸を使う場合、その柱の断面参照方向から単位直交基底を構成できなければ、部材と理由を示して算定を停止します。この算定に使わない梁の参照方向は対象に含めません。

**算定式**

D 値（一般階）:

\\[ D = a \cdot K\_{c0} \\]

\\[ K\_{c0} = 12EI\_c/h^3 \\]

\\[ a = \bar{k}/(2+\bar{k}) \\]

剛心と偏心距離:

\\[ X\_s = \sum(D\_y \cdot x)/\sum D\_y \\]

\\[ e\_x = |X\_g - X\_s| \\]

弾力半径:

\\[ r\_{ex} = \sqrt{K\_R/\sum D\_x} \\]

\\[ K\_R = \sum(D\_x \cdot \bar{y}^2) + \sum(D\_y \cdot \bar{x}^2) \\]

偏心率と Fe:

\\[ R\_e = e/r\_e \\]

\\[ F\_e = \begin{cases} 1.0 & (R\_e \le 0.15) \\\\ \min(1.0 + 0.5(R\_e - 0.15)/0.15, 1.5) & (R\_e > 0.15) \end{cases} \\]

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( R\_e \\) | 層の偏心率 | - |
| \\( F\_e \\) | 偏心率による形状係数 | - |
| \\( D \\) | 柱の水平剛性（D 値） | N/mm |
| \\( a \\) | D 値の係数（\\( \bar{k}/(2+\bar{k}) \\)） | - |
| \\( K\_{c0} \\) | 柱の標準剛性 | N/mm |
| \\( E \\) | ヤング係数 | N/mm² |
| \\( I\_c \\) | 柱の断面二次モーメント | mm⁴ |
| \\( X\_g, X\_s \\) | 重心位置・剛心位置 | mm |
| \\( e\_x \\) | X 方向の偏心距離 | mm |
| \\( r\_{ex} \\) | X 方向の弾力半径 | mm |
| \\( K\_R \\) | 層のねじり剛性 | N·mm |
| \\( D\_x, D\_y \\) | X・Y 方向の層剛性 | N/mm |
| \\( \bar{x}, \bar{y} \\) | 剛心から各柱までの距離 | mm |

<div class="impl-ref">

**実装参照**：`sepika_design_jp::secondary::holding_capacity::fe` が Fe を算定します。
地震時の応力解析結果があるときは、柱の水平剛性を \\( k\_i = Q\_i/\delta\_i \\) として剛心を求めます。
ここでの \\( \delta\_i \\) は、その柱の上下階SL節点の水平変位差です。各柱の剛性算定と、層間変形角の最大値の集計は別に行います。
中間節点で柱を分割するとセグメント単体の変位差は層高より短くなるため、連なりを 1 本の柱とみなします。
重心は、鉛直荷重を支持する柱の長期軸力を重みにして求めます。
引張の柱は鉛直荷重を支持しないため、重みに入れません。
この精算は `sepika_design_jp::secondary::eccentricity_analysis`（`crates/sepika-design-jp/src/secondary/eccentricity_analysis.rs`）です。
武藤 D 値法の略算は `sepika_design_jp::secondary::eccentricity` です。計算結果の偏心率表示で不足する解析結果を補うものではありません。
略算でも中間節点で分割された鉛直材は連なりを 1 本の柱とみなし、層の上下端の高さを \\( h \\) として D 値を求めます。
セグメントの材長を \\( h \\) にすると \\( 12EI/h^3 \\) が過大になるためです。

</div>

**雑壁の剛性（n 倍法）**

柱・梁に囲まれていない壁も、階と階をつないでいれば層の剛性に効き、剛心を偏らせます。
これを等価な剛性要素として剛心とねじり剛性へ算入する方法が n 倍法です。
壁 1 枚の等価水平剛性 \\( K\_w\' \\) は、当該層の柱の剛性と断面積の比から求めます。
適用範囲は、集計対象の各柱が層内で同一断面となる場合に限ります。中間節点で分割された柱も、一本の連なりを構成する各部材が同一断面である必要があります。異なる柱どうしの断面を揃える必要はありません。
層内で断面が変わる対象柱がある場合は、対象柱と理由を示してn倍法による付加剛性の算定を停止します。異断面柱を集計から外したり、最上部・平均などの代表断面で代用したりしません。この制限はn倍法に関するもので、モデル全体の解析を一律に禁止するものではありません。

\\[ K\_w\' = n \cdot A\_w\' \cdot \sum K\_c / \sum A\_c \\]

\\( A\_w\' \\) は壁の平面長さ × 構造厚です。
構造厚は断面の板厚で、仕上げ・増打ちの面荷重（[壁の断面と自重](../01_荷重/09_壁の断面と自重.md)）は
重さの入力であって厚さではないため含めません。
方向別に \\( K\_{wx}\' \\)・\\( K\_{wy}\' \\) を求め、壁面内方向の方向余弦 \\( (c\_x, c\_y) \\) で
\\( D\_x = K\_{wx}\' c\_x^2 \\)、\\( D\_y = K\_{wy}\' c\_y^2 \\) として、壁の平面中点に置きます。
柱総面積が0の層では算定できません。

**対象は無開口RC自立壁（床領域に取り付く壁版）だけです。**
非RC壁、有開口壁、スリット付き壁は算入しません。主材料を確認できない壁をRC壁として扱いません。
腰壁・垂れ壁・パラペットは、フロア間で壁がつながっていないため層剛性に影響しません。
これらが周辺の柱梁へ及ぼす剛性は、袖壁・腰壁として部材の断面性能へ算入する経路
（[ティモシェンコ梁要素](../04_要素剛性/01_ティモシェンコ梁要素.md)）が受け持つので、
ここで等価剛性要素としても数えると二重に計上することになります。

自立壁も同じ基準で切り分け、**立ち上がりが直上の階レベルに達している壁だけ**を対象とします。
床の上に立つ腰高のパーティションは階と階をつないでいないため、対象にしません。
考慮を指定した対象壁の断面・主材料・構造厚を確認できない場合は算定を停止します。
帰属する層は、壁の下端からその階の階高の半分だけ上がった高さがどの層に入るかで決めます。

**既定値**は \\( n \\) が未設定で、そのときは雑壁の剛性を考慮しません。
考慮する場合の係数nは正の有限値に限ります。0・負値・非有限値は拒否し、「考慮しない」への読み替えは行いません。
柱の剛性と面積は、同じ層・同じ柱集合から集計します。各柱の断面積とヤング係数には正の有限値が必要です。必要な変位・内力の欠落、面積・方向別剛性の不正、集計・演算結果の非有限では、対象と理由を示して算定を停止します。正常な応答から算定された剛性0とは区別します。

この層内合算方式の確認範囲は、公開された計算式と適用条件に限ります。2020年版・2025年版『建築物の構造関係技術基準解説書』原書との照合は未実施であり、各版への適合確認済みとは扱いません。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( K\_w\' \\) | 雑壁 1 枚の等価水平剛性 | N/mm |
| \\( n \\) | 雑壁の剛性を柱に換算する係数（n 倍法） | - |
| \\( A\_w\' \\) | 壁の平面長さ × 構造厚 | mm² |
| \\( K\_c \\) | 層の柱の剛性 | N/mm |
| \\( A\_c \\) | 層の柱の断面積 | mm² |
| \\( D\_x, D\_y \\) | 壁の X・Y 方向の層剛性 | N/mm |
| \\( c\_x, c\_y \\) | 壁面内方向の方向余弦 | - |

**実装参照**：`sepika_design_jp::secondary::eccentricity::{misc_wall_stiffness, append_misc_wall_stiffnesses}`（`crates/sepika-design-jp/src/secondary/eccentricity/misc_wall.rs`）が算定します。

## 算定できない場合

設計画面とレポート CSV では、Rs は選択方向の地震静的結果、Re は X・Y 両方向の地震静的結果について、現在のモデル・関連計算条件と解析時の入力および計算契約の対応を確認します。
Re の重心に長期結果を用いる場合は、保存された常時 G+P の長期組合せ結果のうち先頭のものも確認します。
必要な結果の欠落、入力不一致、入力識別情報の欠落、計算契約の不一致・欠落があれば、対象の方向・組合せと理由を表示します。
選択方向以外の地震結果又は長期結果だけが無効な場合、Rs と層間変形角の表示は継続し、Re と Fes を算定不能とします。
長期結果が存在しても入力の対応を確認できない場合は、長期結果なしとして質量重心へ切り替えません。
増分解析の刻み・目標変位、表示方向、層間変形角の参考比較分母の変更だけでは、地震静的結果を無効にしません。

階高と重心位置の層間変位は、全層について対応する正の有限値が必要です。
全層の変位が 0 の場合も、一部の層だけが 0 の場合も、相対剛性を定義できないため Rs を算定しません。
ゼロ変位の層を平均から除いたり、Rs=1 や他層の最大値で代用したりしません。
床レベル上の必要節点の変位が欠ける場合、階・方向の対応が取れない場合、非有限値や演算不能がある場合も算定不能です。
質量が未設定又は全節点の質量が 0 の階では、床レベル上の節点変位の単純平均を重心位置変位として用います。

Re には有限な偏心距離と正の有限な弾力半径が必要です。半径が 0 の場合は、偏心距離も 0 であっても Re を定義できません。
必要な柱の地震時変位・内力が欠ける場合や不正な場合、上下端の変位差を有限値として求められない場合も算定しません。
長期解析結果を用いて重心を求める場合、その必要柱の軸力が欠ける場合や非有限の場合も算定不能です。
長期結果がない場合又は全柱の圧縮軸力の合計が 0 の場合は、質量重心を用います。
質量重心に使う節点質量は未設定を 0 と扱い、全質量が 0 なら節点座標の幾何重心を用います。
長期軸力又は質量から重心を求める際、必要な位置・質量の不正、軸力・質量・位置一次モーメントの集計不能、重心座標の除算不能がある場合も算定不能です。
剛心・ねじり剛性・弾力半径についても、方向別剛性や位置一次モーメントの集計・除算を有限値で行えない場合は算定不能とします。
方向別剛性の合計が 0 の場合、対応する剛心座標は 0 と扱いますが、弾力半径が 0 の Re を正常値で代用しません。
偏心距離が 0 で弾力半径が正なら Re=0 は正常です。有効な全層の相対剛性が等しい場合の Rs=1 も正常です。

結果画面とレポート CSV は、該当する層・加力方向と理由を付けて「算定不能」と表示し、剛性率・偏心率の判定を「判定なし」とします。
Rs 又は Re を算定できなければ Fes と、それに依存する必要保有水平耐力・合否の算定を止めます。
再計算や保存後の再読込みでも、欠ける入力を既定値や前回の値で補いません。

## 形状係数 Fes

形状係数 Fes は、剛性率による Fs と偏心率による Fe の積として算定します。
Re=0.15、0.225、0.30 に対して Fe=1.0、1.25、1.5 です。Rs=0.15、Re=0.225 なら Fes=2.1875 です。

**算定式**

\\[ F\_{es} = F\_s \cdot F\_e \\]

**実装参照**：`sepika_design_jp::secondary::holding_capacity::fes` が算定します。
