# 保有水平耐力の判定

建築基準法施行令 第82条の3 に基づき、各層の保有水平耐力 Qu が必要保有水平耐力 Qun を上回るか（\\( Q\_u \ge Q\_{un} = D\_s \cdot F\_{es} \cdot Q\_{ud} \\)）を判定します。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( Q\_u \\) | 各層の保有水平耐力 | N |
| \\( Q\_{un} \\) | 各層の必要保有水平耐力 | N |
| \\( Q\_{ud} \\) | 設計用地震層せん断力 | N |
| \\( D\_s \\) | 構造特性係数 | - |
| \\( F\_{es} \\) | 形状係数（\\( F\_s \cdot F\_e \\)） | - |
| \\( C\_0 \\) | 標準せん断力係数 | - |

**算定式**

必要保有水平耐力:

\\[ Q\_{un} = D\_s \cdot F\_{es} \cdot Q\_{ud} \\]

- 保有水平耐力 `Qu` は、保有耐力比較用に明示採用した確定評価点での層切断面力の大きさです。各層のピーク時刻を寄せ集めず、同じ方向・run・step の状態を全層で用います。
- 設計用地震層せん断力 `Qud` は標準せん断力係数 1.0 の Ai 分布層せん断力です。
- 層間変形角は保有耐力比較用の同じ評価点の層間変位から求めます。

## 目的別の確定評価点

Ds 判定用と保有耐力比較用に、方向、解析実行（run）、入力世代、確定 step、選定理由を指定します。両目的の載荷条件・終了目標・採用 step は異なって構いません。一つの目的の内部では、壁・筋かい・柱梁の負担力、分母の層全体力、ランク判定の応力と機構を同じ状態から採ります。Ds の βu に比較用 Qu を流用しません。評価点未指定のまま、最終点や法定停止点を自動採用することはありません。

設計タブで各目的の step と理由を入力し、「目的にこのrun・stepを採用して保持」で採用します。続く別条件の解析は保持した目的別結果を上書きしません。X／Y 各方向の 2 目的分をプロジェクトに保存し、復元後も同じ点を使います。画面と帳票で、目的、方向、run、入力世代の識別値、解析条件、外力分布の各層累積値、選定理由、解析終了理由を確認できます。選定理由は設計者が確認した条件を記載してください。選択操作だけで法適合や機構形成を保証するものではありません。

## 符号付き層切断面力と釣合い

層の中間高さで構造を切り、上側自由体へ伝わる各物理要素の加力方向成分を一度ずつ合算します。同じ確定状態の内力を用い、絶対値の端力和や、最終変位による弾性応力再計算は使いません。

\\[ Q_i = Q_{wall,i}+Q_{brace,i}+Q_{frame,i},\quad
\beta_{u,i}=\frac{Q_{wall,i}+Q_{brace,i}}{Q_i} \\]

壁面内方向に作用する壁系は壁パネルと鉛直側柱の和です。隣接壁の共有側柱は壁系全体へ一度含め、柱梁系との二重計上や、根拠のない個別壁への按分をしません。直交方向の側柱力は柱梁系です。開口の影響は解析で確定した実内力に含まれるため、合算時に低減係数を再適用しません。仕口パネルの柱節点参照は軸力追従用であり、独立した層水平力として加算しません。

上側の節点へ作用する外力を累積します。支持ばねの内力は上側自由体の外部作用として差し引きます。荷重倍率を λ、参照外力を q、固定外力を f0、支持ばね内力を s とすると、釣合い診断は次式です。

\\[ E_i=\sum_{z>z_{cut,i}}(\lambda q+f_0-s),\quad r_i=Q_i-E_i \\]

残差の許容差は Newton 求解の相対許容差（10⁻⁶）に、実外力ベクトルのノルム（下限 1 N）と節点数の平方根を掛けた値です。基準外力、支持ばね内力、実外力、残差と許容差を層別に表示します。例えば下階 100 kN、上階 50 kN の外力なら切断面力は下層 150 kN、上層 50 kN です。壁系が 90／30 kN を負担すれば、各層 βu は 0.6 です。反転載荷では各力の符号が反転しても同方向の比率は変わりません。

非有限値、内力・履歴欠損、二重計上、識別不一致、釣合い残差超過、ゼロ分母、全体力と反対の群寄与、βu が 0〜1 の範囲外の場合は理由を示して判定を停止します。値をゼロや上下限へ置換しません。切断面上の支持拘束反力を取得できないモデルや、節点力と自由度の対応を確定できない要素は集計対象の適用外です。多層をまたぐ壁・斜め壁など一般配置の網羅的検証は未完了です。

構造特性係数 \\( D\_s \\) は部材ランクと崩壊機構から層別に定めます（[構造特性係数 Ds](02_構造特性係数_Ds.md)）。形状係数 \\( F\_{es} = F\_s \cdot F\_e \\) は剛性率・偏心率から求めます（いずれも加力方向の地震時弾性層間変位に基づきます）。

## 解析結果の有効性

目的別に保持した増分解析は、現在モデルと各目的の保存済み解析条件に生成入力が一致する結果だけを採用します。自動地震荷重はその目的の条件で照合し、手入力荷重の変更は無効化します。現在の解析条件が別目的へ変わったことだけでは保持した点を無効にしません。地震静的（EX／EY）は現在のモデル・関連する設定と生成入力が一致する結果を採用します。画面で別の静的荷重ケースを選択していても、判定には対象方向の地震静的結果を使います。X 方向の判定へ Y 方向の増分結果を代用することはありません。

材料強度・配筋・断面・壁属性・荷重と組合せ・階・計算設定を変更した場合は、必要な解析を再実行してください。静的解析や時刻歴だけを再実行しても、残っている旧増分結果は利用できません。X／Y の片方向だけの再解析でも、他方向の旧結果は有効になりません。剛性・偏心率の精算で使用する地震静的と長期組合せ、周期として使用する固有値結果にも同じ照合を行います。使用する結果の不一致や入力識別情報の欠落、方向別結果の不足がある場合は、旧合否を無効にし、理由と再解析対象を表示します。

精算周期を選択している場合は、地震力生成に採用した周期も結果ごとに照合します。剛性を変更した後、旧固有値結果から地震静的・増分解析を行い、最後に固有値だけを更新しても判定は有効になりません。更新した周期で EX／EY と増分解析を再実行してください。この地震力の再生成だけを理由に、固有値を繰り返し実行する必要はありません。略算周期を用いる解析結果には、この固有値更新による再解析要求はありません。

解析実行中にモデル・計算設定が変わった場合、変更前の入力から届いた結果は破棄します。入力識別情報がない保存結果も、再解析するまで判定には利用できません。表示ステップ・カメラ・ハイライト・通り芯の表示専用変更や、判定に無関係な時刻歴の記録間隔変更は再解析を必要としません。
