# 保有水平耐力の判定

建築基準法施行令 第82条の3 に基づき、各層の保有水平耐力 Qu が必要保有水平耐力 Qun を上回るか（\\( Q\_u \ge Q\_{un} = D\_s \cdot F\_{es} \cdot Q\_{ud} \\)）を判定します。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( Q\_u \\) | 各層の保有水平耐力 | N |
| \\( Q\_{un} \\) | 各層の必要保有水平耐力 | N |
| \\( Q\_{ud} \\) | 設計用地震層せん断力 | N |
| \\( D\_s \\) | 構造特性係数 | - |
| \\( F\_{es} \\) | 形状係数（\\( F\_s \cdot F\_e \\)） | - |
| \\( C\_0 \\) | 標準せん断力係数 | - |

**算定式**

必要保有水平耐力:

\\[ Q\_{un} = D\_s \cdot F\_{es} \cdot Q\_{ud} \\]

- 保有水平耐力 `Qu` = 各層について、プッシュオーバー性能曲線上の**層別ピーク層せん断力**（崩壊機構形成時の耐力）。単調載荷では機構形成後に頭打ち・劣化するため、最終点ではなく曲線全体のピークを採ります。
- 設計用地震層せん断力 `Qud` = \\( C\_0 = 1.0 \\) の標準地震層せん断力。[地震力](../01_荷重/01_地震力.md)の地上部 Ai 分布と地下部の直上せん断力加算を共通に用います。地下震度 K は C0 に比例しないため、通常荷重全体を5倍する計算ではありません。
- 層間変形角の算定に用いる層間変位は、終局状態（性能曲線最終点＝最大変位時）から採ります。

**実装参照**：`sepika_design_jp::secondary::holding_capacity`（`crates/sepika-design-jp/src/secondary/holding_capacity.rs`）が判定を行い、Qu にはプッシュオーバー（[増分解析（プッシュオーバー解析）](../05_構造解析/07_プッシュオーバー解析.md#増分解析プッシュオーバー解析)）の層せん断を用います。

構造特性係数 \\( D\_s \\) は部材ランクと崩壊機構から層別に定めます（[構造特性係数 Ds](02_構造特性係数_Ds.md)）。形状係数 \\( F\_{es} = F\_s \cdot F\_e \\) は剛性率・偏心率から求めます（いずれも加力方向の地震時弾性層間変位に基づきます）。

## Qud の入力と適用範囲

令88条3項の必要保有水平耐力用地震力の C0 下限は1.0であり、SEPIKA は1.0を採用します。周期は解析条件で選択した略算式を用い、参考固有値の存在によって周期を変更しません。地域係数・地盤種別は解析条件から採用し、地域根拠と地盤の適用は設計者が確認してください。出典・版・条項・適用条件は[地震力の出典](../01_荷重/01_地震力.md#出典と確認範囲)に示します。

精算周期、PH 指定震度、指定 Ci の副剛床を含む Qud は、必要な適用条件が未検証なので理由付きで未対応とします。指定 Ci の副剛床重量を除いた主系統のせん断力だけで、層全体の必要耐力が満たされるとは判定しません。固有値解析と参考周期の取得は利用できます。

## 解析結果の有効性

判定方向の増分解析と地震静的（EX／EY）は、現在のモデル・関連する計算設定と生成時の入力が一致する結果だけを採用します。画面で別の静的荷重ケースを選択していても、判定には対象方向の地震静的結果を使います。X 方向の判定へ Y 方向の増分結果を代用することはありません。

材料強度・配筋・断面・壁属性・荷重と組合せ・階・計算設定を変更した場合は、必要な解析を再実行してください。静的解析や時刻歴だけを再実行しても、残っている旧増分結果は利用できません。X／Y の片方向だけの再解析でも、他方向の旧結果は有効になりません。剛性・偏心率の精算で使用する地震静的と長期組合せ、対象の結果にも同じ照合を行います。使用する結果の不一致や入力識別情報の欠落、方向別結果の不足がある場合は、旧合否を無効にし、理由と再解析対象を表示します。

略算周期を用いる標準結果は、参考固有値の更新だけでは再解析を必要としません。精算周期を選択している場合は、上記の適用制限により標準 Qud を算定できません。

解析実行中にモデル・計算設定が変わった場合、変更前の入力から届いた結果は破棄します。入力識別情報がない保存結果も、再解析するまで判定には利用できません。表示ステップ・カメラ・ハイライト・通り芯の表示専用変更や、判定に無関係な時刻歴の記録間隔変更は再解析を必要としません。

設計タブには採用方向と部材応答・変形の採用ステップを表示し、層別 Qu の欄にカーソルを置くと最大耐力の採用ステップを確認できます。これは結果の追跡のための表示で、最大耐力と最終応答を採る計算規則は上記のとおりです。
