# 部材荷重（等価節点力・固定端内力）

部材に作用する分布荷重を節点力へ変換し、固定端内力を算定します。
根拠は力学で、Hermite 形状関数による等価節点力（consistent load）と両端固定梁の固定端内力に基づきます。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( Q \\) | 分布荷重を形状関数で節点へ変換した等価節点力 | N |
| \\( N \\) | 形状関数（軸は線形、曲げは Hermite 3 次） | - |
| \\( w \\) | 部材に作用する分布荷重（線荷重） | N/mm |
| \\( P \\) | 部材に作用する集中荷重 | N |
| \\( f\_{FEF} \\) | 固定端内力（等価節点力の符号反転） | N |
| \\( N\_{FEF}(x) \\) | 固定端のスパン軸力（引張正） | N |
| \\( R \\) | 分布荷重の合力 | N |
| \\( R\_i,\\ R\_j \\) | 分布荷重の i 端・j 端の分担反力 | N |
| \\( L \\) | 部材長 | mm |
| \\( a \\) | 集中荷重の i 端からの距離 | mm |

## 作用方向

作用方向は全体座標系のベクトル \\( d=(d_x,d_y,d_z) \\) で与え、次のノルムで正規化した単位方向へ集中強度 P [N] または分布強度 w [N/mm] を作用させます。

\\[ n = \sqrt{d_x^2+d_y^2+d_z^2}, \qquad \hat d = d/n \\]

各成分が有限で、浮動小数点の平方和・平方根により求めた n が有限かつ 1e-12 以上であることを計算条件とします。これは数値正規化の適用条件であり、構造規準の許容値ではありません。数学的に有限・非ゼロの方向でも、平方和のアンダーフローやオーバーフローにより条件を満たさない場合があります。

条件を満たす非単位方向は単位方向と同じ荷重を与えます。全荷重ケースの集中・分布荷重を強度によらず検査し、不成立なら対象と理由を示して計算を拒否します。入力の方向は保持し、重力方向への置換・荷重削除・ゼロ強度化は行いません。編集・保存との関係は[荷重の入力](../01_荷重/07_荷重の入力.md#作用方向の計算条件)を参照してください。

局所軸へ射影した方向成分の絶対値が 1e-15 未満なら、その軸への成分を与えません。この成分別の数値処理と、方向ベクトル全体の成立条件は別です。軸力だけが生じる荷重や、あるせん断軸と直交して別の軸へ作用する荷重を、無荷重とはみなしません。

## 算定式

等価節点力（軸は線形形状関数、曲げは Hermite 形状関数、分布荷重は 3 点 Gauss 積分）:

\\[ Q = \int N^T \cdot w~dx \\]

固定端内力（等価節点力の符号反転）:

\\[ f\_{FEF} = -Q \\]

節点変位による断面内力に、固定端のスパン内力を重畳します。軸力は引張を正とし、局所 x 軸正方向の荷重を正として、固定端のスパン軸力を次式で求めます。

\\[ N\_{FEF}(x) = -f\_{FEF,i,x} - \int\_0^x w\_x(s)\\,ds - \sum\_{a\_k<x}P\_{x,k} \\]

集中荷重位置では i 端側の極限値を返します。等分布軸荷重では軸力は線形、線形に変化する分布軸荷重では二次式となります。梁・ブレースとも軸力には同じ釣合い式を用います。

**ブレースの扱い**

ブレースは軸剛性のみを持つトラス要素のため、曲げ・せん断・ねじりの剛性がありません。
Hermite 形状関数による等価節点力は材端モーメントを含みますが、ブレースはこれを負担できず、
節点へ外力として撒かれるだけになります。そこでブレースに限り、材軸に直交する成分を
**材端モーメントを生じない静定分配**（単純梁の反力と同じ配分）で両端へ配ります。

区間 [a, b] に載る分布荷重では、合力 \\( R \\) と i 端まわりの 1 次モーメントから両端の分担を
決めます。集中荷重 \\( P \\) が i 端から距離 \\( a \\) にある場合は、てこの原理そのものです。

\\[ R\_j = \frac{1}{L}\int\_a^b w(s)\\,s~ds, \qquad R\_i = R - R\_j \\]

\\[ R\_j = P\frac{a}{L}, \qquad R\_i = P\left(1 - \frac{a}{L}\right) \\]

符号付き線形分布の合力・一次モーメントは[床の単純梁反力](../01_荷重/03_床荷重の分配.md#符号付き単純梁反力)と同じつり合い式です。合力ゼロでも反力対を保持し、反力比を制限しません。これは任意の荷重を地震重量へ採用する規則ではありません。
静定分配では部材長の下限を1e−9 mm、点位置比を0〜1とし、分布は終了位置が開始位置以下なら無視、それ以外は原区間で積分します。解析へ入力する分布荷重は、有限で支間内の正の幅を持つことが必要です。

## 線形分布の合力と部分切断

始端 a [mm]、終端 b [mm] の強度をそれぞれ w₁、w₂ [N/mm] とし、b > a とします。切断によって残る区間 [u, v] の端部強度を wᵤ、wᵥ とすると、幅 h=v−u [mm]、合力 R [N]、i 端まわり一次モーメント S [N·mm] は次式です。

\\[
w(s)=w_1\frac{b-s}{b-a}+w_2\frac{s-a}{b-a},\qquad
w_u=w(u),\quad w_v=w(v)
\\]

\\[
R=\frac{h}{2}(w_u+w_v),\qquad
S=uR+\frac{h^2}{6}(w_u+2w_v)
\\]

位置 x [mm] まわりの荷重モーメントは xR−S [N·mm] です。切断区間は元の荷重区間との共通部分とし、空なら合力・モーメントはゼロです。符号付きの端部強度をそのまま用いるため、合力がゼロでも一次モーメントが残る場合があります。

浮動小数点で区別できる正の幅は、微小であっても元の線形分布として扱います。幅を理由に始端強度一定へ置き換えたり、荷重を省略したりしません。端部近傍も同じ扱いです。ただし、座標・強度の表現精度や演算のオーバーフロー・アンダーフローを含む、任意の極小・極大入力での数学的精度保証ではありません。

この合力と一次モーメントをブレースの静定分配および断面の荷重釣合いへ用います。曲げを負担する部材への等価節点力は、引き続き形状関数による算定です。

## ブレースの内力回復

合力と作用位置の 1 次モーメントがともに保存されるため、建物の総重量・支点反力はこの扱いに
よって変わりません。材軸方向の成分は形状関数が線形で静定分配と一致するので、配り方を
変える必要がありません。内力回復でも、ブレースには軸力以外の固定端内力を与えません
（材軸直交成分は荷重ベクトル側で両端へ流し切っているためです）。
