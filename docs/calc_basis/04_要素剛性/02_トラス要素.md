# トラス（ブレース）要素

軸剛性のみをもつブレースを次式で算定します（トラス要素の力学）。

\\[ K\_B = E \cdot A/L \\]

軸剛性のみを持ち、曲げ・せん断・ねじりはゼロとします。E はヤング係数 [N/mm²]、A は断面積 [mm²]、L は正の材長 [mm]、軸ばね剛性は N/mm です。局所 x 軸を i 端から j 端とし、軸伸び δ [mm] と軸力 N [N] は引張を正に取ります。節点並進を材軸へ射影した相対変位から δ を求め、回転自由度には剛性を与えません。

## 引張専用ブレースの扱い

引張専用ブレースも、弾性時の基準は一般ブレースと同じ軸剛性 \\( E\\,A/L \\) のトラス要素として扱います。圧縮側の無効化は線形応力解析の active-set 反復で実現し、計算条件で切り替えます。

- **反復なし（既定）**：引張専用という指定だけでは軸剛性を低減せず、1回の求解で圧縮側も軸力を負担します。長期軸力無効化による低減は別に適用します。
- **active-set 反復**：各反復で圧縮側（軸伸び δ < 0）に入った引張専用ブレースの軸剛性を残留比 1e-6 まで縮小して無効化します。無効化ブレースの節点変位から求めた軸伸びが引張へ転じれば再び active に戻します。active 集合が前反復と一致した時点で収束とみなします。反復上限50回で集合が一致しなければ未収束エラーとして停止し、未収束解を正常な成果として保存しません。軸伸び0は有効です。

採用する軸剛性と、その剛性で回復する軸力を次式で表します。反復ありの場合は収束後の軸伸びを用います。

\\[ K = \beta s K\_B = \beta s \frac{EA}{L}, \qquad N = K\delta \\]

ここで \\( K\_B \\) は冒頭の基準軸剛性、\\( K \\) は採用軸剛性（ともに N/mm）です。\\( \beta \\) は長期軸力無効化による長期係数、\\( s \\) は引張専用反復の圧縮側残留比で、いずれも無次元です。\\( \beta \\) は圧縮側の残留比ではなく、長期低減の対象なら引張側にも適用します。

長期係数は、ブレースの長期軸力無効化を指定した対象長期ケースで \\( \beta = 10^{-6} \\)、それ以外で \\( \beta = 1 \\) とします。対象ケースと設定の正本は[長期軸力無効化と引張専用](../05_構造解析/02_線形静解析.md#長期軸力無効化と引張専用)です。残留比は、反復なしでは引張・圧縮とも \\( s = 1 \\)、反復ありでは \\( \delta \ge 0 \\) で \\( s = 1 \\)、\\( \delta < 0 \\) で \\( s = 10^{-6} \\) です。

| 長期低減 | 引張専用反復 | 軸伸び | 長期係数 \\( \beta \\) | 残留比 \\( s \\) | 採用軸剛性の倍率 \\( \beta s \\) |
| --- | --- | --- | --- | --- | --- |
| 対象外・指定なし | なし | 引張・圧縮とも | 1 | 1 | 1 |
| 対象外・指定なし | あり | \\( \delta \ge 0 \\)（有効） | 1 | 1 | 1 |
| 対象外・指定なし | あり | \\( \delta < 0 \\)（無効化） | 1 | \\( 10^{-6} \\) | \\( 10^{-6} \\) |
| 対象長期ケースで指定あり | なし | 引張・圧縮とも | \\( 10^{-6} \\) | 1 | \\( 10^{-6} \\) |
| 対象長期ケースで指定あり | あり | \\( \delta \ge 0 \\)（有効） | \\( 10^{-6} \\) | 1 | \\( 10^{-6} \\) |
| 対象長期ケースで指定あり | あり | \\( \delta < 0 \\)（無効化） | \\( 10^{-6} \\) | \\( 10^{-6} \\) | \\( 10^{-12} \\) |

例えば、反復あり・長期低減なしの引張側では \\( N = (EA/L)\delta \\)、長期低減を併用した引張側では \\( N = 10^{-6}(EA/L)\delta \\) です。圧縮側では、それぞれ \\( N = 10^{-6}(EA/L)\delta \\)、\\( N = 10^{-12}(EA/L)\delta \\) となり、圧縮軸力は厳密なゼロにはしません。

表の倍率は軸剛性に対するものです。軸伸びも採用剛性に応じて変わるため、低減前の軸力にこの倍率を乗じた値になるとは限りません。代替の荷重伝達経路がない場合は、低減した部材が荷重を負担し続けるため、軸力と変形を確認してください。
