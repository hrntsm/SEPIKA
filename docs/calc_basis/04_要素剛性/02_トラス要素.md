# トラス（ブレース）要素

軸剛性のみをもつブレースを次式で算定します（トラス要素の力学）。

\\[ K\_B = E \cdot A/L \\]

軸剛性のみを持ち、曲げ・せん断・ねじりはゼロとします。E はヤング係数 [N/mm²]、A は断面積 [mm²]、L は正の材長 [mm]、軸ばね剛性は N/mm です。局所 x 軸を i 端から j 端とし、軸伸び δ [mm] と軸力 N [N] は引張を正に取ります。節点並進を材軸へ射影した相対変位から δ を求め、回転自由度には剛性を与えません。

**実装参照**：`sepika_element::frame::truss`（`crates/sepika-element/src/frame/truss.rs`）が算定します。

</div>

## 引張専用ブレースの扱い

引張専用ブレースも、弾性時の基準は一般ブレースと同じ軸剛性 \\( E\\,A/L \\) のトラス要素として扱います。圧縮側の無効化は線形応力解析の active-set 反復で実現し、計算条件で切り替えます。

- **反復なし（既定）**：引張専用という指定だけでは軸剛性を低減せず、1回の求解で圧縮側も軸力を負担します。
- **active-set 反復**：各反復で圧縮側（軸伸び δ < 0）に入った引張専用ブレースの軸剛性を残留比 1e-6 まで縮小して無効化します。無効化ブレースの節点変位から求めた軸伸びが引張へ転じれば再び active に戻します。active 集合が前反復と一致した時点で収束とみなします。反復上限50回で集合が一致しなければ未収束エラーとして停止し、未収束解を正常な成果として保存しません。長期軸力無効化を併用すると、長期係数と残留比の積を採用します。軸伸び0は有効です。収束後は active な引張ブレースのみが \\( N = \beta E\\,A/L \cdot \delta \\) を負担し、圧縮ブレースの軸力はほぼ 0 となります。

<div class="impl-ref">

**実装参照**：圧縮側の判定と反復は `sepika_solver::statics::linear::solve_tension_only_iterative`（`crates/sepika-solver/src/statics/linear/mod.rs`）です。

</div>
