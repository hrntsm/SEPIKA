# 数量積算

本章では、建物モデルから部位別（柱・大梁・小梁・基礎梁・床・壁・ブレース）に
コンクリート体積・型枠面積・鉄筋重量・鉄骨重量・鉄筋継手個所数を概算集計する
数量積算の算定根拠を、構造計算プログラムで慣用される概算数量の拾い出し規則として
示します。

構造計算モデルを唯一の入力とする**概算数量**であり、施工数量（鉄筋のフック・余長・
継手長さ、開口補強筋、接合部プレート等の詳細）は対象外とします。

設計タブの「数量積算」で確認し、CSVへ出力できます。

数量積算は**解析結果に依存しない**ため、応力解析の前後を問わず参照でき、モデルを編集する
たびに再集計されます（準備計算・応力解析の要再計算とは別に扱います）。GUI では
部位別・階別・構造別・明細・鉄骨種類別・鉄筋径別に集計を切り替えられます。
壁筋は明示横筋比・縦筋比で方向別に概算し、不足する方向は理由付き未算定とします。
未算定を含む鉄筋重量は不完全小計です。壁筋仮定径・定着係数はパネルで編集し、Undo／Redoと保存に対応します。
詳しい入力、完全性、解析質量との境界は[算定式](./01_数量積算の算定式.md)を参照してください。
二次部材は端点にモデル節点がなくても実長で集計し、階だけ不明な数量は「-」の行へ保持します。
明細の識別と数量全体が未算定になる条件は[二次部材の数量](./01_数量積算の算定式.md#二次部材の実長階明細)を参照してください。

積算した鉄筋重量は解析質量へ加算しません。係数設定の変更でも自重・解析質量・解析応答は変わりません。
