# SRC梁・柱の許容曲げ検定

SRC梁ではRC部と鉄骨部を累加し、SRC柱では設計軸力に応じて各部の分担を求めます。

## SRC部材の許容曲げと累加

断面寸法・配筋から[有効せい・応力中心距離と許容応力度](04_01_SRCの部材検定.md#配筋から求める有効せい応力中心距離)を求めます。検定方向と材料の適用条件は[SRCの部材検定](04_01_SRCの部材検定.md)を参照してください。

### SRC梁の強軸曲げ

梁はSRC規準第6版第3刷16条の式(16.1)・(16.2)・(16.4)によって鉄骨部とRC部の許容曲げを単純累加します。軸力と弱軸曲げがともにゼロで、軸力と両軸の曲げが有限な位置を対象とします。矩形梁の引張鉄筋比が式(16.7)の釣合鉄筋比以下のときにRC部の略算値を採用します。鉄骨断面にはボルト孔による欠損がないことを前提とします。

梁・柱とも、内蔵鉄骨に欠損がある場合は有効断面を用いて別途照査してください。継手やスカラップの欠損を入力した部材は、この断面検定の適用範囲外です。

### SRC柱の軸力と一軸曲げ

長期・短期とも、設計軸力が非有限（NaNまたは正負の無限大）の位置を理由付きで未算定とします。

柱は鉄骨フランジの食い込みに対する次の低減を両軸に共通して適用します。

\\[ {}\_sp\_c=\frac{b\_ft\_f}{BD},\qquad f\_c^{\prime}=\max\\{f\_c(1-15\\,{}\_sp\_c),0\\} \\]

spcの分母は鉄骨・主筋を控除しない矩形総面積です。RC部の許容N–M計算は[RC柱の線形応力分布・合力・補間](02_03_RC柱の軸力_二軸曲げ検定.md#柱の許容nm境界)を基本とし、コンクリートのfcをfc′に置き換えます。SRCではxn/Ddir=0.02〜10の対数等間隔300点と純圧縮・純引張の両端点を用います。nは低減前のFcから求めます。

全主筋面積As、主筋の許容応力度ftによりRC部の軸力限界を求め、設計軸力Ndは圧縮を正とします。

\\[ A\_e=BD+(n-1)A\_s,\qquad {}\_rN\_c=\max\\{\min(A\_ef\_c^{\prime},A\_ef\_t/n),0\\},\qquad {}\_rN\_t=-A\_sf\_t \\]

\\[ M\_A(N\_d)=\begin{cases} {}\_sM\_o+{}\_rM\_A(N\_d)&({}\_rN\_t\le N\_d\le{}\_rN\_c)\\\\ \max[{}\_sZ\\{{}\_sf\_c-(N\_d-{}\_rN\_c)/{}\_sA\\},0]&(N\_d>{}\_rN\_c)\\\\ \max[{}\_sZ\\{{}\_sf\_t-|N\_d-{}\_rN\_t|/{}\_sA\\},0]&(N\_d<{}\_rN\_t)\end{cases} \\]

RC部の軸力範囲内はRC部が全軸力を分担し、鉄骨の軸力を0として曲げを加えます。圧縮・引張限界を超えるとRC部はその限界を分担し、超過軸力を鉄骨に負担させた鉄骨曲げだけを用います。共通ひずみの合成断面計算ではありません。鉄骨の許容圧縮応力度はsfc=sftとし、内蔵鉄骨の座屈低減は行いません。曲げは作用する軸の|M|/MAで検定します。軸力では鉄骨とRCの軸耐力の合計を確認し、地震時圧縮では式(17.30)の圧縮力上限も確認します。純引張端ではRC曲げが0へ収束します。

座屈長さが各方向の断面せいの12倍以下の短柱を対象とします。強軸・弱軸ごとに「S造検定属性」の直接指定を優先し、空欄の軸は節点間距離の1.2倍を用います。既定値の根拠と適用上の注意は[座屈長さ](03_06_鋼部材の座屈長さ_有効細長比.md#通常s主架構部材の座屈長さ)を参照してください。二軸同時の曲げと長柱は別途照査してください。

地震荷重組合せの柱には、SRC規準17条6項の上限 \\( N\_l=BD F\_c/3+2{}\_sA{}\_sf\_c/3 \\) を適用します（p.19）。\\( B,D \\) は矩形断面の全幅・全せい、\\( F\_c \\) はコンクリートの設計基準強度、\\( {}\_sA \\) は内蔵鉄骨の断面積、\\( {}\_sf\_c \\) は表14.1の短期圧縮許容応力度です。二軸同時曲げまたは長柱で曲げが適用範囲外の場合も、圧縮力がこの上限を超えると、軸力の不適合と曲げの未算定理由を併記します。
- SRC 柱の RC 部分の中立軸圧縮側鉄骨面積は軸に依らない一つの値を用いる。
