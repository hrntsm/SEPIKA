# 座屈拘束ブレース（BRB）

座屈拘束ブレースの断面検定は、入力した許容軸力・限界長さに対する比を表示します。製品・型式・接合形式に対応する設計資料で、入力値と長さの測定位置が一致することを確認してください。製品の設計条件全体と建築基準法施行令第65条への適合は別途確認が必要です。

## 入力・対象と結果

BRBの製品検定は、断面用途がブレースで、BRBの検定属性が設定されたブレース要素に適用します。短期許容軸力Na [N]、限界長さLc [mm]、端部の低減距離L1 [mm]を用います。GUIで製品を選んで値を入力する専用画面はありません。属性を含むモデルを開く場合に、設定済みの製品条件と部材の対応を確認してください。属性がない部材は、形状や材料名にかかわらず通常の検定経路に進みます。

NaとLcには有限の正値を、L1には有限の非負値を明示します。控除が不要な製品条件では、L1に0を指定します。

選択した長期又は短期の解析軸力と、部材の実材軸長さL [mm]（偏心0では節点間長さ）を用います。剛体腕長はLに加えません。L1は両端の低減距離の平均で、2L1が両端分の控除です。Lは有限の正値で、控除後の長さも正値であることが必要です。控除後の長さが、採用する製品資料でLcと比較する長さに対応する場合に利用できます。通常鋼の曲げ座屈長さlk_y/lk_zや等間隔横補剛本数による長さは使いません。

解析で内力を得られた場合、BRB属性の参照先が柱や梁であれば、部材の不一致を理由とする未検定になります。製品値が未入力または範囲外の部材や、控除後の長さが正値でない部材も理由付きの未検定です。解析ねじりモーメントMxが非零または非有限の位置も理由付きの未検定です。

実材軸が成立しない場合、通常のGUI・MCPの処理は解析前の入力診断で停止し、内力が生成されません。内力を直接受け取る共通検定では、実材軸長さの不備を対象部材の理由付き未検定行に記録します。

**算定式**

- 軸力検定比 \\( |N| / N\_a \\)（Na = 短期許容軸力、長期はNa/1.5）
- 座屈長さ検定比 \\( L\_k / \text{限界長さ} \\)（\\( L\_k = L - 2L\_1 \\)）
- 総合 \\( \text{ratio} = \max(\text{軸力比}, \text{座屈長さ比}) \\)

軸力は引張・圧縮とも絶対値で評価します。許容軸力と長さの入力が妥当で、採用製品の設計条件と対応する場合、総合検定比1以下はこの2項目が入力した限度内であることを示します。詳細には軸力比と長さ比の内訳を小数第4位まで表示します。丸めによって、超過した比が1.0000と表示される場合があります。長期のNa/1.5は本機能の採用式です。長期許容値の根拠と、引張・圧縮に共通のNaを用いられる条件は、製品資料で確認してください。曲げ・せん断、端部接合と端部突出部、構面外安定、繰返し変形性能の検討が別途必要です。

有限の入力から検定比を求める演算が数値表現の上限に達した場合も、入力した限度の超過と判定します。詳細に演算の上限到達を示し、総合検定比に表現可能な最大値を用います。

未検定の部材は検定表と検定比図に理由を表示し、MCP集計では未検定件数に含めます。保存・再読込した検定結果は、計算契約版と生成入力が一致するときに理由を再表示します。

許容軸力・限界長さの検定とは独立に、履歴復元力を設定します。履歴復元力の入力は[辻・山田モデル](../../nonlinear/02_部材履歴則.md#辻山田モデル混合硬化)を参照してください。

## 製品資料で確認する条件

- JFEシビルの二重鋼管座屈補剛ブレースの標準部材表では、ピン接合タイプの製品限界長さはピン間、高力ボルト接合タイプではスプライスプレート端間です。同じ表の軸力欄は降伏軸力です。標準部材表の値を用いる前に、設計上の許容軸力と、現行検定が比較する長さへの対応を確認してください。[二重鋼管座屈補剛ブレースのカタログ、PDF p.4](https://www.jfe-civil.com/pdf/catalog/double_steel_pipe.pdf)
- 日鉄エンジニアリングの建築用アンボンドブレースは、接合詳細や構面外拘束を考慮して座屈長さを定めます。設計軸力は耐震タイプでは芯材の降伏軸力、制振タイプでは芯材の最大降伏軸力です。どちらのタイプでも、拘束鋼管の座屈耐力が設計軸力の1.5倍を上回るように設計します。構面外安定の判定は別に定めています。[アンボンドブレースのカタログ、2024.12版、pp.14–15・18–19](https://www.eng.nipponsteel.com/steelstructures/wp/wp-content/uploads/2025/09/UBB_202509.pdf)

標準表の長さを超える場合や表にない組合せは、採用製品の設計資料とメーカー確認に基づいて判断してください。一般評定や構成材料の大臣認定を使う場合は、その対象と条件を確認してください。

## 令第65条の有効細長比

令第65条は、該当する構造耐力上主要な鋼圧縮材について、柱以外は有効細長比250以下と定めます。建築物に適用する規定は令第36条・第63条等と、対象部材の荷重負担に基づいて確認してください。適用する場合は、圧縮を負担する評価対象と区間を特定し、各主軸の有効座屈長さを対応する断面二次半径で除した値の最大を評価します。BRBの評価対象・区間・軸ごとの入力は製品や使用条件と照合する必要があります。[建築基準法施行令](https://laws.e-gov.go.jp/law/325CO0000000338)

現行のBRB検定には令第65条の結果欄がありません。GUI・保存して再表示した検定結果・MCP集計では入力した製品値に対する検定を確認できます。令第65条への適合は別途確認してください。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( N \\) | ブレースに生じる軸力 | N |
| \\( N\_a \\) | 短期許容軸力（長期は 1/1.5） | N |
| \\( L\_k \\) | 座屈長さ（部材長から端部低減を除いた長さ） | mm |
| \\( \text{ratio} \\) | 総合検定比（軸力比と座屈長さ比の大きい方） | - |
