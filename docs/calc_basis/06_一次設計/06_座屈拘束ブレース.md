# 座屈拘束ブレース（BRB）

座屈拘束ブレースの断面検定は、製品別に設定した許容軸力・限界長さ・端部低減を用い、軸力と座屈長さの検定比から算定します。認定値を用いる場合も、その製品の適用条件を満たす必要があります。
製品は JFE シビル二重鋼管座屈補剛ブレースおよび日鉄エンジニアリングアンボンドブレースを対象とし、メーカー許容値を直接使用します（座屈拘束により全断面降伏まで座屈しない製品特性のため、座屈考慮 fc は用いません）。同じ構造形式の製品全般に適用できることを保証するものではありません。

## 入力・対象と結果

BRBの検定属性が設定された部材では、通常鋼ブレースの許容応力度式の代わりに、製品の短期許容軸力Na [N]、限界座屈長さLc [mm]、端部の低減距離L1 [mm]を用います。GUIには製品を選んでこれらの認定値を自動入力する専用画面はありません。属性を含むモデルを開く場合に、設定済みの製品条件と部材の対応を確認してください。属性がない部材を、形状・材料名だけからBRBと判定しません。

選択した長期又は短期の解析軸力と、部材の節点間長さL [mm]を用います。Lは芯材全長として式に渡す長さであり、実製品の芯材全長と一致することを利用者が確認する必要があります。低減距離L1は両端それぞれの低減距離の平均で、2L1が両端分の控除です。通常鋼の曲げ座屈長さlk_y/lk_zや等間隔横補剛本数による長さは使いません。

**算定式**

- 軸力検定比 \\( |N| / N\_a \\)（Na = 短期許容軸力、長期はNa/1.5）
- 座屈長さ検定比 \\( L\_k / \text{限界長さ} \\)（\\( L\_k = \max(L - 2L\_1,0) \\)）
- 総合 \\( \text{ratio} = \max(\text{軸力比}, \text{座屈長さ比}) \\)

軸力は引張・圧縮とも絶対値で評価し、総合検定比が1以下ならこの2項目について適合です。長期のNa/1.5は本機能の採用条件であり、製品の認定・設計条件との適合を別途確認してください。せん断・曲げ・端部接合・繰返し変形性能はこの比に含めません。

有効な許容値と限界長さを正値で与える必要があります。現在の計算はL−2L1が負なら0とし、Na又はLcの絶対値が10⁻⁹以下の場合は分母を10⁻⁹へ置き換えます。これらを理由付き未検定にする入力検査はなく、不適切な入力でも数値を返し得ます。検定比だけで製品入力の妥当性を判断しないでください。

履歴復元力の降伏軸力・剛性・混合硬化等を定める[辻・山田モデル](../../nonlinear/02_部材履歴則.md#辻山田モデル混合硬化)とは別の検定です。履歴モデルの設定や解析収束は、許容軸力・限界長の適合を意味しません。製品条件と令第65条の有効細長比の対応も未確認です。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( N \\) | ブレースに生じる軸力 | N |
| \\( N\_a \\) | 短期許容軸力（長期は 1/1.5） | N |
| \\( L\_k \\) | 座屈長さ（部材長から端部低減を除いた長さ） | mm |
| \\( \text{ratio} \\) | 総合検定比（軸力比と座屈長さ比の大きい方） | - |
