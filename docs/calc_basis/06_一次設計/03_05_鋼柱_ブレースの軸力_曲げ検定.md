# 鋼柱・ブレースの軸力・曲げ検定

鋼柱を軸力と二軸曲げ、ブレースを設計用軸力で検定します。対応する柱のせん断と合成応力は別の検定項目です。

## 算定式（柱・ブレース）

次節の上下非対称組立H形鋼柱の圧縮・強軸曲げを除き、柱の圧縮時は座屈を考慮した \\( f\_c \\) を用います。

\\[ \sigma\_c/f\_c + \sigma\_{by}/f\_b + \sigma\_{bz}/f\_t \le 1.0 \\]

柱の引張時は、軸力項 \\( \sigma\_c/f\_c \\) を \\( \sigma\_t/f\_t \\) に置き換え、曲げ項は同じ許容値を用います。
円形鋼管柱は、梁と同じ合成曲げ応力度 \\( \sigma\_b=\sqrt{M\_z^2+M\_y^2}/Z\_{\mathrm{strong}} \\) による \\( \sigma\_b/f\_b \\) で二つの曲げ項を置き換えます。

- ブレース: 圧縮 \\( \sigma\_c/f\_c \\)、引張 \\( \sigma\_t/f\_t \\)

柱の \\( f\_b \\)（H 形強軸）も、梁と同じ許容曲げ応力度 fb の算定式（2019年版、横座屈修正係数 C の直接入力を含む）によりますが、lb には柱の部材長（節点間長さ）を用います。

## 上下非対称組立H形鋼柱の圧縮と強軸曲げ

上下フランジの幅または板厚が異なる充腹形の組立H形鋼柱に圧縮軸力と強軸曲げが作用する場合、曲げで圧縮される縁と引張を受ける縁を照査します。ウェブと両フランジの寸法を持ち、断面積・断面二次モーメントがその形状に基づく無欠損の断面が対象です。孔欠損やスカラップを控除した断面係数は未算定です。軸力なしの曲げおよび引張軸力の照査は、この節の適用外です。 [軸力なしの強軸曲げ](https://github.com/hrntsm/SEPIKA/issues/1540)・[引張軸力](https://github.com/hrntsm/SEPIKA/issues/1484)

局所 \\( y \\) の正側を上、負側を下とします。 \\( I\_y \\) は本書の鋼断面表記で強軸断面二次モーメント [mm⁴]、\\( y\_{\mathrm{上}}, y\_{\mathrm{下}} \\) は図心から各外縁までの正の距離 [mm] です。強軸曲げ \\( M\_z>0 \\) のときは上縁が曲げ圧縮、下縁が曲げ引張となり、\\( M\_z<0 \\) のときは逆です。全断面積 \\( A \\) [mm²] から平均圧縮応力度 \\( \sigma\_c \\) [N/mm²] を求めます。

\\[
 Z\_{\mathrm{上}}=\frac{I\_y}{y\_{\mathrm{上}}},\qquad
 Z\_{\mathrm{下}}=\frac{I\_y}{y\_{\mathrm{下}}},\qquad
 \sigma\_c=\frac{-N}{A}.
\\]

圧縮側・引張側の断面係数 \\( Z\_c,Z\_t \\) [mm³] を曲げ符号に従って選び、圧縮側と引張側の比 \\( R\_c,R\_t \\) の大きい方を軸曲げ検定比とします。

\\[
 R\_c=\frac{\sigma\_c}{f\_c}+\frac{|M\_z|}{Z\_c f\_b}\le 1,\qquad
 R\_t=\frac{|M\_z|/Z\_t-\sigma\_c}{f\_t}\le 1.
\\]

両式を満たすとき適合と判定できるのは、材長と指定された有効座屈長さ・横座屈長さがすべて0の断面単独照査で、弱軸曲げ・せん断・ねじりが作用しない場合です。この境界では \\( f\_c=f\_b=f\_t \\) とし、長期は \\( F/1.5 \\)、短期は \\( F \\) [N/mm²] を用います。

材長またはいずれかの座屈長さが正のときは、上下非対称断面の横座屈・曲げねじり座屈を含む照査が未算定です。弱軸曲げが加わる場合も、断面内の二軸曲げの組合せが未確定のため未算定です。強軸せん断が加わる場合はウェブ内同一点の組合せ、弱軸せん断が加わる場合はフランジ内同一点の組合せが未算定です。ねじりが作用する場合は[ねじりの検定条件](03_03_鋼梁_柱のせん断検定.md#材軸ねじりが作用する場合)を適用します。 [有限長・座屈](https://github.com/hrntsm/SEPIKA/issues/1541)・[強軸せん断](https://github.com/hrntsm/SEPIKA/issues/1542)・[弱軸せん断が加わる場合](03_04_鋼梁_柱の組合せ応力検定.md#h形鋼柱で圧縮または軸力なしの場合の強軸曲げと弱軸せん断)

座屈・弱軸曲げ・せん断を含む照査が未算定でも、圧縮側の \\( f\_c,f\_b \\) に上限 \\( f\_t \\) を使って得た比、または引張側の比が1を上回るときは、不適合と比の下限を未算定理由とともに表示します。各フランジの幅中央では弱軸曲げの曲げ応力度が0なので、軸力と強軸曲げだけで不適合を確認できます。両比が1以下であっても未算定理由がある位置は検定不能と表示します。

[有効細長比の法定上限](03_06_鋼部材の座屈長さ_有効細長比.md#圧縮材の有効細長比上限)を超える場合は、その不適合を先に表示します。このときも、断面欠損や座屈照査など、判明している未算定理由を併記します。

根拠は日本建築学会『鋼構造許容応力度設計規準』2019年版の11.9(1)(4)（p.27、解説 p.97）、10.1(1)（p.22）、6.1 式(6.1)・(6.2)（p.15、解説 p.61）です。許容応力度の上限は5.1(1)(3)(4)（pp.9–12）と5.6（p.14、解説 p.60）によります。 [規準の書誌](https://ndlsearch.ndl.go.jp/books/R100000002-I030037737)

## ブレースの設計用軸力

設計用軸力は実材軸に沿う部材内の軸力を用い、引張には既存の軸力検定を適用します。元の節点へ伝える剛体腕の移送モーメントはブレースの曲げ耐力や曲げ検定へ含めません。接合部・剛体腕の耐力や接合部の局部曲げは本検定の対象外です。[座屈拘束ブレース](06_座屈拘束ブレース.md)は既存の製品別軸力・限界長さ検定を用い、一般圧縮材の座屈長さを追加しません。
