# 鋼部材の方向・記号・単位

## 対応断面の検定式

鋼部材の検定式は、[梁の曲げ・横座屈](03_02_鋼梁の曲げ_横座屈検定.md)、[梁・柱のせん断](03_03_鋼梁_柱のせん断検定.md)、[梁・柱の組合せ応力](03_04_鋼梁_柱の組合せ応力検定.md)、[柱・ブレースの軸力・曲げ](03_05_鋼柱_ブレースの軸力_曲げ検定.md)を参照してください。S/CFT接合部は[鋼構造の柱梁接合部](07_鋼構造の柱梁接合部.md)に示します。

**局所軸と強軸・弱軸の対応**

局所xは始端から終端への材軸、局所yは断面せい方向、局所zは右手系の幅方向です。
強軸・弱軸は断面形状の基準呼称であり、断面性能の大小で並べ替えません。
本ページの断面性能の添字はSEPIKAの保存規約に従い、回転軸の添字とは区別します。

| 曲げの基準呼称 | 変位・せん断の局所方向 | 曲げの回転軸 | 断面力 | 断面性能・二次半径 | 座屈長さ |
|---|---|---|---|---|---|
| 強軸側 | y（せい方向） | 局所z軸 | \\( M\_z, Q\_y \\) | \\( I\_y, i\_y=\sqrt{I\_y/A} \\) | \\( l\_{ky} \\) |
| 弱軸側 | z（幅方向） | 局所y軸 | \\( M\_y, Q\_z \\) | \\( I\_z, i\_z=\sqrt{I\_z/A} \\) | \\( l\_{kz} \\) |

座屈長さ・二次半径の添字y/zも、この表の強軸側／弱軸側を指します。
局所回転軸y/zと同一視しません。断面係数の添字strong/weakも同じ区別です。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( \sigma\_{ax} \\) | 軸力による応力度 | N/mm² |
| \\( \sigma\_{by}, \sigma\_{bz} \\) | 強軸・弱軸まわりの曲げ応力度 | N/mm² |
| \\( N \\) | 軸力 | N |
| \\( M\_z, M\_y \\) | 強軸・弱軸まわりの曲げモーメント | N·mm |
| \\( M\_x \\) | 材軸まわりのねじりモーメント | N·mm |
| \\( A \\) | 断面積 | mm² |
| \\( Z \\) | 断面係数 | mm³ |
| \\( I\_y, I\_z \\) | 強軸側・弱軸側の断面二次モーメント（上表の規約） | mm⁴ |
| \\( f\_c \\) | 座屈を考慮した許容圧縮応力度 | N/mm² |
| \\( f\_b \\) | 許容曲げ応力度 | N/mm² |
| \\( f\_t \\) | 許容引張応力度 | N/mm² |
| \\( F \\) | 鋼材の基準強度（F 値） | N/mm² |
| \\( \lambda \\) | 座屈長さと断面二次半径から求める細長比 | - |
| \\( l\_{ky}, l\_{kz} \\) | 強軸・弱軸まわりの座屈長さ | mm |
| \\( i\_y, i\_z \\) | 強軸・弱軸まわりの断面二次半径 | mm |
| \\( C \\) | 横座屈修正係数 | - |
| \\( l\_b \\) | 圧縮フランジの支点間距離（横座屈長さ） | mm |
