# 小梁端部の高力ボルト接合

小梁端部の反力を需要とし、高力ボルトによるせん断伝達を長期荷重で検定します。

## 小梁端部の高力ボルトによるせん断伝達

鋼小梁の断面符号ごとに、高力ボルトの種類・呼び径・摩擦面数・本数と適用条件を設定します。本数は**片側接合部の正の整数**です。同じ符号を使うすべての小梁に、階が異なっても同じ設定を適用します。同寸法でも符号が異なれば別設定です。両端支持では両端各同本数、片持ちでは支持端に適用し、個別小梁や端部ごとの上書きはありません。符号を変更すると変更先の設定を使います。設定はプロジェクトへ保存され、編集後は再検定が必要です。

断面作成画面で対象断面を選び、「小梁端部の高力ボルト」を開きます。新規モデルでは接合条件は未設定です。設定を開始したときの初期選択はF10T・M20・1面摩擦、本数0（未設定）、二つの適用条件は未確認です。初期選択だけでは接合部を検定しません。種類を変更すると摩擦面条件の確認が解除されるため、新しい種類の処理条件を確認し直してください。

種類はF10Tと**F8T（溶融亜鉛めっき）**、摩擦面数は「1面摩擦」「2面摩擦」から選びます。対応呼び径はF10TがM12・M16・M20・M22・M24・M27・M30、F8TがM16・M20・M22・M24・M27・M30です。

### 端部需要と総合判定

各端部の設計用せん断力Qは、その小梁用荷重から求めた**当該端部の反力**です。左右で反力が異なる場合にも平均や最大せん断力で置き換えません。

\\[ Q\_a=nq\_a,\qquad R\_{Q,i}=\frac{|Q\_i|}{Q\_a},\qquad R\_Q=\max\_i R\_{Q,i},\qquad R=\max(R\_M,R\_\delta,R\_Q) \\]

nは断面符号に設定した片側の本数です。各端のRQが1以下なら、適用条件内の高力ボルトによるせん断伝達について適合です。必要な3項目がすべて検定できた場合に限り、総合比Rが1以下で総合適合とします。

### ボルト種類ごとの許容値

長期の摩擦接合許容値を用い、ボルト軸のせん断破断耐力とは区別します。F10TはJIS B 1186の所定セットを用い、施行令第92条の2第1項、平成12年建設省告示第2466号の基準張力500 N/mm²によります。

\\[ q\_a=m\\,0.3T\_0\frac{\pi d^2}{4},\qquad T\_0=500\ \mathrm{N/mm^2} \\]

ここでmは摩擦面数、dは呼び径[mm]です。鋼板間のすべり係数0.45以上を確保する所定の摩擦面処理と締付けを前提とします。

F8Tは溶融亜鉛めっき高力ボルトの公開技術資料に示す、すべり係数0.4の長期許容せん断力を採用します。国土交通大臣認定を受け、下表の許容値と所定の施工条件を適用できるセットであることを確認してください。接合する鋼板同士の摩擦面にはブラスト処理とりん酸塩処理を施し、ブラスト面は表面粗さ50 μmRz以上とします。亜鉛合金層を残す軽いブラストとし、処理範囲は添接板の外に出さず、所定の施工・締付け条件を満たしてください。めっきのままの無処理面へ適用しません。

| F8Tの呼び径 | 1面摩擦のqa [kN/本] | 2面摩擦のqa [kN/本] |
| --- | ---: | ---: |
| M16 | 22.7 | 45.4 |
| M20 | 35.4 | 70.8 |
| M22 | 44.0 | 88.0 |
| M24 | 51.2 | 102 |
| M27 | 66.6 | 133 |
| M30 | 81.3 | 163 |

F8Tの1面・2面は、それぞれの公表長期値を用います。丸められた1面値を2倍した値で置き換えません。採用資料は日本製鉄「建設用資材ハンドブック」2025年9月改訂版「溶融亜鉛めっき高力ボルト（GHボルト・GHボルト-FR）」です。

### 適用条件と未検定

本数倍の評価は、ボルト群が直接せん断を均等に伝達し、外力によるボルト引張と偏心による付加力を必要としない接合に限ります。所定の摩擦面処理と、この接合条件の確認を入力してください。設定なし、0本、未対応径、確認不足、不正な端部需要は理由付きの「未検定」です。未検定を検定比0や総合合格へ置き換えず、算定済みの曲げ・たわみを併記します。

片持ち支持端は曲げ伝達も必要です。支持端せん断について参考値を示しても、曲げ伝達を含めた適否を算定しないため総合は未検定とします。外力引張や偏心付加力が必要な接合へ、無低減のQaを適用できません。

結果では断面符号、適用本数、各端部の種類・径・摩擦面数・Q [kN]・Qa [kN]・検定比・判定を確認できます。**せん断伝達の適合は接合部全体の安全性を意味しません。** ガセットプレート・小梁ウェブの支圧や破断、溶接、配置・縁端距離、接合部の曲げ・引張は別途検討してください。短期・終局検定、径・本数の自動選定は対象外です。
