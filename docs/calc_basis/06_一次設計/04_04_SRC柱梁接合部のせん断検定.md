# SRC柱梁接合部のせん断検定

接合部の形状係数・有効寸法と材料値から許容せん断を求め、需要と比較します。

## 短期せん断検定用の帯筋入力

「モデル」→「SRC接合部帯筋」で節点・接続柱・接続梁を確認し、対象構面の「帯筋を編集」から、有効脚本数、呼び径、間隔 [mm]、対象幅 [mm]、帯筋材種を登録します。同じ節点で接続梁の方向が異なる場合は、構面ごとに登録します。「帯筋を解除」で指定を取り消せます。現在の構面軸や接続する柱・梁の組合せが登録時と異なる場合は、その構面で帯筋を確認して再登録してください。配筋詳細や断面寸法を変更したときは、有効脚本数や対象幅などの登録値を確認し、必要に応じて更新してください。

有効脚本数には、対象構面の接合部で有効と確認した脚だけを数えます。対象幅には、帯筋比の分母に用いる幅を設計者が確認して入力します。帯筋比は有効脚本数 \\( n_w \\)、呼び径の公称断面積 \\( a_w \\) [mm²]、対象幅 \\( b \\) [mm]、間隔 \\( s \\) [mm] から求める無次元量です。

\\[ p_w = \frac{n_w a_w}{b s} \\]

短期検定の入力には、帯筋比が0より大きく1未満の有限値となる組合せを受け付けます。範囲外の場合は構面と理由を表示します。

日本建築学会『鉄骨鉄筋コンクリート構造計算規準・同解説』第6版第3刷の7条2項(3) 式(7.1)（p.5）が示す帯筋比の定義を使います。計算例10（pp.319–321）の2-D13@425では、付図1.7の検討構面に直交する柱幅800 mmとD13の公称断面積126.7 mm²を使うと帯筋比は0.0007452941となり、掲載値0.00075に対応します。

短期せん断補強用の許容引張応力度は同規準の表14.5（p.12）の短期・せん断補強の欄によります。

| 入力材種 | 短期許容引張応力度 [N/mm²] |
| --- | --- |
| SD295・SD295A・SD295B | 295 |
| SD345 | 345 |
| SD390 | 390 |
| SD490 | 490 |

SD295はSD295系の表記として扱います。材種は対応する異形棒鋼から選びます。材料表の任意名や降伏点からの換算、丸鋼・溶接金網、柱断面の帯筋や他構面の帯筋の流用は扱いません。未登録・無効・重複・対象が変わった指定には理由が付きます。

一覧の帯筋比と許容引張応力度は検定用の入力値です。配筋詳細、配筋細則、接合部の耐力および適合は個別に確認してください。現行の接合部検定結果は次節の式で求めています。

## SRC 柱梁接合部

矩形SRC柱を含む柱梁接合部について、検定根拠に「SRC規準 柱梁接合部（パネル）せん断検定」と表示します。**この結果は設計上の適合判定に使えません。** 日本建築学会『鉄骨鉄筋コンクリート構造計算規準・同解説』第6版（2014年）20条 pp.22–23 の長期式(20.1)は全形状で係数3を使い、短期式(20.2)はコンクリートの有効体積、形状係数、帯筋、鉄骨ウェブの許容せん断を用います。現行の計算は長期・短期とも下記の全体積と本数区分の係数を使います。設計には、検討方向の部材・内力と接合部の諸元を確定し、20条の長期・短期式で別途確認してください。

\\[ M\_A={}\_cV \cdot j\delta \cdot f\_s(1+\beta),\qquad M\_D=(h\'/h)\sum |{}\_BM|,\qquad R=|M\_D|/M\_A \\]

\\[ {}\_cV=C\_b \cdot m\_{Bd} \cdot m\_{Cd},\qquad \beta=\frac{nJ\_{tw}s\_{Cd}}{C\_bm\_{Cd}} \\]

S梁の場合は、体積の式のmBdを鉄骨フランジ重心間距離sBdへ置き換えます。接合部検定表の判定欄は、有限の検定比が1以下なら「OK」、1を超えるなら「NG」と表示します。許容値が0以下の場合、内部の検定比は無限大となり、検定比欄に「-」、判定欄に「検定不能」と表示します。Cb mCdの絶対値が10⁻⁹ mm²以下の場合はβ=0として扱います。

| 記号 | 意味・現在の採用条件 | 単位 |
| --- | --- | --- |
| Cb | 採用SRC柱の幅 | mm |
| mBd | 代表RC/SRC梁の上下主筋の重心間距離 | mm |
| mCd | 柱幅から両側の主筋中心までの距離を控除した、柱左右主筋間距離 | mm |
| sBd | 代表S梁のフランジ重心間距離。H形はせい−フランジ厚、その他はせいの0.9倍 | mm |
| Jtw、sCd | 柱内蔵鉄骨のウェブ厚、フランジ重心間距離 | mm |
| n | Fc≤27で15、27超36以下で13、36超48以下で11、48超60以下で9、60超で7（FcはN/mm²）。軸力比ではない | — |
| jδ | 接続柱2本以上かつ梁2本以上は3、柱又は梁の一方だけ2本以上は2、いずれも1本は1 | — |
| fs | 採用柱コンクリートの長期又は短期許容せん断応力度。軽量の採用低減も適用 | N/mm² |
| h′/h | 内法階高／階高の係数。GUIの接合部検定は1.0を採用し、実内法高さから算定しない | — |
| Σ\|BM\| | 接続する各梁の接合部端の強軸解析モーメントの絶対値和。降伏モーメント和ではない | N·mm |
| cV | 接合部の全体積。有効体積への置換をしない | mm³ |
| MA、MD | 許容値・設計値 | N·mm |

柱寸法は接続する矩形SRC柱1本、梁寸法は接続梁1本で代表します。接続本数には直交梁も含まれ、検討方向や梁段差を確認せずに区分します。梁の材端内力が欠けると、設計値が小さくなって比0で「OK」と表示されたり、接合部の結果行自体が出なかったりする場合があります。

非0偏心の柱を含む接合部では、接続梁が1本以上検定候補に残る場合に理由付きの未算定となります。一部の未対応配筋も理由付きの未算定です。主筋間距離を取得できない梁断面には、梁せいに一定割合を乗じる場合があります。20条1項・3〜6項の柱梁端の軸力・曲げ・せん断の伝達、鉄骨部分の曲げ耐力比による検討省略条件、局部応力・スチフナや定着などの接合詳細は別途検討してください。
