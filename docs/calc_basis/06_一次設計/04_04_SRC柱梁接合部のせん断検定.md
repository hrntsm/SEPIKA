# SRC柱梁接合部のせん断検定

日本建築学会『鉄骨鉄筋コンクリート構造計算規準・同解説』第6版（2014年）20条に基づき、SRC柱梁接合部のパネルに生じるせん断の設計値と許容値を曲げモーメント換算で比較します。接合部検定表には構面ごとに種別、検定比、採用式または未算定理由を表示します。パネルせん断の許容内判定に加え、柱梁端間の応力伝達を別途確認してください。

## 短期せん断検定用の帯筋入力

「モデル」→「SRC接合部帯筋」で節点・接続柱・接続梁を確認し、対象構面の「帯筋を編集」から、有効脚本数、呼び径、間隔 [mm]、対象幅 [mm]、帯筋材種を登録します。同じ節点で接続梁の方向が異なる場合は、構面ごとに登録します。「帯筋を解除」で指定を取り消せます。短期検定の後で帯筋を変更・解除した場合は、保持された解析結果を使って「検定を再実行」してください。現在の構面軸や接続する柱・梁の組合せが登録時と異なる場合は、その構面で帯筋を確認して再登録してください。配筋詳細や断面寸法を変更したときは、有効脚本数や対象幅などの登録値を確認し、必要に応じて更新してください。

有効脚本数には、対象構面の接合部で有効と確認した脚だけを数えます。対象幅には、帯筋比の分母に用いる幅を設計者が確認して入力します。帯筋比は有効脚本数 \\( n_w \\)、呼び径の公称断面積 \\( a_w \\) [mm²]、対象幅 \\( b \\) [mm]、間隔 \\( s \\) [mm] から求める無次元量です。

\\[ p_w = \frac{n_w a_w}{b s} \\]

短期検定の入力には、帯筋比が0より大きく1未満の有限値となる組合せを受け付けます。範囲外の場合は構面と理由を表示します。

日本建築学会『鉄骨鉄筋コンクリート構造計算規準・同解説』第6版第3刷の7条2項(3) 式(7.1)（p.5）が示す帯筋比の定義を使います。計算例10（pp.319–321）の2-D13@425では、付図1.7の検討構面に直交する柱幅800 mmとD13の公称断面積126.7 mm²を使うと帯筋比は0.0007452941となり、掲載値0.00075に対応します。

短期せん断補強用の許容引張応力度は同規準の表14.5（p.12）の短期・せん断補強の欄によります。

| 入力材種 | 短期許容引張応力度 [N/mm²] |
| --- | --- |
| SD295・SD295A・SD295B | 295 |
| SD345 | 345 |
| SD390 | 390 |
| SD490 | 490 |

SD295はSD295系の表記として扱います。材種は対応する異形棒鋼から選びます。材料表の任意名や降伏点からの換算、丸鋼・溶接金網、柱断面の帯筋や他構面の帯筋の流用は扱いません。未登録・無効・重複・対象が変わった指定には理由が付きます。

一覧の帯筋比と許容引張応力度は検定用の入力値です。配筋詳細、配筋細則、接合部の耐力および適合は個別に確認してください。現行の接合部検定結果は次節の式で求めています。

## 長期・短期に共通の適用条件

対象は普通コンクリートの矩形SRC柱に、矩形SRC梁・矩形RC梁・H形鋼梁が取り付く、水平梁と鉛直柱の同一構面の十字形・T字形・ト字形・L字形です。形状は同じ構面の上下柱と左右の梁から決めます。中心軸が直交する水平梁は別の構面として扱います。斜交・勾配・水平偏心で構面を独立に扱えない接合部は未算定です。

- 柱内蔵H形鋼のウェブが平行な構面を対象とします。同じ断面・材料の上下柱に連続する通常のウェブを前提とし、接合部だけの板厚変更・貫通孔・補強による抵抗は扱いません。断面弱軸側や斜め方向は未算定です。内蔵H形鋼の材種・板厚・形状は[SRC部材の適用条件](04_01_SRCの部材検定.md#内蔵h形鋼の材種と実板厚)を満たす必要があります。
- 同じ構面の柱・梁は固定接合とします。偏心・材軸と節点のずれ・勾配梁・横倒し・継手やハンチの指定・片側の複数部材・段違い・異断面の接合は対象外です。
- 柱の接続する隣階に同じ構面・同じせいの水平梁がある場合に、階高と柱の内法高さを各階の梁面から確定します。上下両側に柱があれば、両層で階高と内法高さがそれぞれ一致することを確認します。隣階の構面にかかわる梁の用途・材軸・梁面を解決できない場合は未算定です。
- 各梁の[実柱面の断面力](../04_要素剛性/01_ティモシェンコ梁要素.md#大梁の実柱面の断面力)に有限な曲げが必要です。梁がモデルにあって柱面の断面力が得られない場合は、その構面に理由を表示します。
- 断面または断面用途が未設定の主架構線材が取り付く場合は、構面の形状が未確定です。ブレースが同じ節点に取り付く場合は、接合部内でのブレース力の伝達経路が未確認となります。いずれも理由付きで未算定とします。

## 式と諸元

柱面で各梁が接合部に及ぼす曲げを、同じ全体座標方向の回転を正として符号付きで加えます。その和に内法高さと階高の比を乗じ、絶対値を設計値とします。長期の許容値は全形状に共通の式(20.1)によります。\\( f\_{s,L} \\) は普通コンクリートの長期許容せん断応力度です。

\\[ M\_D=\left|({}\_BM\_1+{}\_BM\_2)\frac{h^{\prime}}{h}\right|,\qquad
M\_{A,L}={}\_cV\cdot3f\_{s,L}(1+\beta),\qquad R=\frac{M\_D}{M\_A} \\]

\\[ \beta=\frac{nJ\_{tw}s\_{Cd}}{C\_bm\_{Cd}},\qquad
f\_{s,L}=\min\left(\frac{F\_c}{30},\\,0.49+\frac{F\_c}{100}\right) \\]

| 記号 | 意味 | 単位 |
| --- | --- | --- |
| \\( {}\_BM\_1,{}\_BM\_2 \\) | 各側の梁の柱面における、接合部への曲げモーメント。梁の取り付かない側の項は省く | N·mm |
| \\( h,h^{\prime} \\) | 隣り合う梁の高さの差と、両梁面間の柱内法高さ | mm |
| \\( C\_b,B\_b \\) | 構面に直交する柱・梁の幅 | mm |
| \\( m\_{Bd},m\_{Cd} \\) | 梁上下の主筋群、柱の検討方向両側の主筋群の重心間距離 | mm |
| \\( s\_{Bd},s\_{Cd} \\) | 梁・柱の鉄骨フランジ重心間距離 | mm |
| \\( J\_{tw} \\) | 接合部で構面に平行な鉄骨ウェブの実板厚 | mm |
| \\( n \\) | 柱の内蔵鉄骨とコンクリートのヤング係数比 \\( E\_s/E\_c \\)。割当材料のヤング係数から求める | — |
| \\( F\_c \\) | 柱コンクリートの設計基準強度 | N/mm² |

主筋群の重心は配筋位置から求めます。検討方向両側のいずれに含めるか確定できない柱中央の主筋がある場合や配筋を解決できない場合は、構面を未算定とします。体積 \\( {}\_cV,{}\_cV\_e,{}\_sV \\) の単位は mm³ です。

| 梁 | コンクリート体積 \\( {}\_cV \\) | コンクリート有効体積 \\( {}\_cV\_e \\) |
| --- | --- | --- |
| SRC・RC | \\( C\_bm\_{Bd}m\_{Cd} \\) | \\( (C\_b+B\_b)m\_{Bd}m\_{Cd}/2 \\) |
| S | \\( C\_bs\_{Bd}m\_{Cd} \\) | \\( C\_bs\_{Bd}m\_{Cd}/2 \\) |

出典は20条本文(20.1)・表20.1（pp.22–23）、表14.6、および解説の解20.4–7（pp.156–157）です。解20.7は柱の長期せん断設計と同様の\\( \beta \\) を用います。柱の長期せん断では鋼とコンクリートのせん断弾性係数比をヤング係数比で近似します（解18.13–14、p.147）。

## 短期の許容値

20条の短期式(20.2)は、コンクリート有効体積と接合部帯筋、接合部鉄骨ウェブの抵抗を用います。SRC梁・S梁には、[対象構面に登録した接合部帯筋](#短期せん断検定用の帯筋入力)と、柱内蔵鉄骨のウェブの実板厚で求めた基準強度を用います。帯筋の登録が欠ける場合や登録値が無効な場合は、その構面を理由付きで未算定とします。帯筋を省略できる接合詳細は適用範囲外です。RC梁の短期は、表20.1で梁鉄骨のフランジ重心間距離に相当する有効高さと、梁から鉄骨ウェブへの応力伝達を確定できないため未算定です。

\\[ M\_{A,S}={}\_cV\_e(2f\_{s,S}\\,{}\_j\delta+{}\_wp\\,{}\_wf\_t)+{}\_sV\\,{}\_sf\_s,\qquad
{}\_sV=J\_{tw}s\_{Bd}s\_{Cd} \\]

| 記号 | 意味 |
| --- | --- |
| \\( {}\_j\delta \\) | 形状係数。十字形3、T字形・ト字形2、L字形1 |
| \\( {}\_wp \\) | 接合部帯筋比（小数） |
| \\( f\_{s,S} \\) | 普通コンクリートの短期許容せん断応力度。長期の1.5倍 [N/mm²] |
| \\( {}\_wf\_t \\) | 接合部帯筋のせん断補強用短期許容引張応力度 [N/mm²] |
| \\( {}\_sf\_s \\) | 接合部ウェブ鋼材の短期許容せん断応力度 \\( F/\sqrt{3} \\) [N/mm²] |

SRC柱とS梁の組合せで、\\( {}\_cV\_e[{}\_j\delta(F\_c/10)+{}\_wp\\,{}\_wf\_t]<{}\_cV(F\_c/10) \\) の場合は、解20.12の \\( M\_{A,S}={}\_cV\cdot2f\_{s,S}+{}\_sV\\,{}\_sf\_s \\) を用います。出典は20条本文(20.2)・表20.1・表20.2（pp.22–23）および解20.9–12（pp.157–159）です。

例えば原典の計算例10で、SRC柱・SRC梁の十字形に対する柱面の作用曲げが1200と800 kN·m、階高4000 mm、内法3150 mmの場合、設計値は1575 kN·mです。有効体積約2.63×10⁸ mm³、鉄骨体積約2.82×10⁶ mm³、帯筋比0.00075、帯筋の許容引張応力度295 N/mm²、ウェブの許容せん断応力度187.6 N/mm²などの掲載諸元から許容値は約2315 kN·mになります。規準の例は直交する2本の内蔵H形鋼を持つ柱です。ここでは原典の掲載諸元を用いて式の値を示しています。帯筋をモデルに登録する場合は、公称断面積により求めた丸め前の帯筋比を使います。出典は付1の計算例10と付図1.7（pp.319–321）です。

## 検定結果と応力伝達の読み方

パネルせん断の検定比が1以下なら、その構面のパネルせん断は「OK」、1を超えると「NG」です。適用条件や必要な諸元・応力を確認できない場合は、検定比欄に「-」、判定欄に「検定不能」、根拠欄に理由を表示します。確認済みの応力から設計値が0になった場合の検定比は0です。

20条1項に基づき、柱・梁の鉄筋コンクリート部分と鉄骨部分が負担する軸力・曲げ・せん断を端部で伝達できることを別途確認してください。鉄骨部分間の応力伝達の安全性検討には、次の省略条件があります。

- SRC柱とSRC梁・S梁の場合、柱側の鉄骨部分の曲げ耐力和を梁側の和で除した比が0.4以上2.5以下なら、鉄骨部分間の応力伝達の安全性検討を省略できます。原典の計算例10では約0.74です。
- SRC柱とRC梁の場合、柱側のRC部分の曲げ耐力和を梁側の和で除した比が0.4以上なら、解20.13による鉄骨部分の応力伝達の安全性検討を省略できます。短期パネルせん断の未算定は別途確認してください。
- 架構モデルでは柱・梁の部分曲げ耐力和を確定できないため、構面が未確定の場合も含め、「応力伝達」行に省略条件を判定できない理由と、別途確認が必要なことを表示します。20条4〜6項のスチフナ、貫通孔、異種構造接合などは詳細設計で確認してください。

出典は20条1項・3〜6項（pp.22–23）と解20.13（p.159）です。
