# 鋼部材の座屈長さ・有効細長比

通常S部材の軸別座屈長さを選び、許容圧縮応力度と圧縮材の有効細長比上限の判定に用います。

## 柱の座屈長さ係数 K

### 通常S主架構部材の座屈長さ

通常S部材・SRC柱は、「S造検定属性」に入力した座屈長さ [mm] を軸ごとに優先します。空欄の軸は材端節点の座標間距離に、柱は1.2、梁・ブレースは1.0を乗じます。採用値は有限な正値とし、通常検定と時刻歴簡易検定に表示します。材端偏心、剛域、一本部材の合成長は、座屈長さの既定値の基準距離に含めません。
小梁・間柱の[二次部材検定](05_小梁・床の断面検定.md)は個別の適用条件に従います。
一般H形鋼柱の強軸許容曲げ応力度に使う横座屈長さについては[一般H形鋼柱の横座屈長さ](03_05_鋼柱_ブレースの軸力_曲げ検定.md#一般h形鋼柱の横座屈長さ)を参照してください。

### 柱の支持条件と座屈長さ

節点の柱梁剛度比だけでは、骨組全体の支持・接合条件と層内の座屈条件を確定できないため、通常S柱の自動Kは設計検定に採用しません。

| 確認が必要な条件 | 自動採用しない理由 |
| --- | --- |
| 理想ピン柱脚、柱端解放、有効梁のない方向・端 | G=10は回転抵抗が残るピン柱脚の便宜値です。方向ごとに実際の支持・接合による回転拘束を確認します |
| 支点の回転拘束・ばね | 節点の支持条件と剛度比境界の対応が未確定 |
| 梁の節点側・遠端の結合、半剛接 | 遠端回転と接合ばねを含む有効拘束を確認していない。半剛接を剛接へ置換しない |
| 層の水平移動拘束、各柱の軸力分布・同時座屈 | 水平移動の拘束条件で使用する式・図表が変わります。各柱の軸力分布に応じて座屈モードも変わります |
| 当該柱・接続柱の非0XYZ偏心 | 剛体接続の並進・回転連成に対する係数法の適用が未確認 |

日本建築学会『鋼構造許容応力度設計規準』第1版（2019年）§11.5（本文p.25、解説pp.91–92）では、
水平移動に対して剛な骨組と剛な床組で連結され、節点の水平移動を拘束できる場合に、精算を省いて拘束節点間距離を採れます。
上記の水平移動拘束の条件に該当しないラーメンの柱は、節点間距離を超える座屈長さを解析で定めます。
均等ラーメンの係数図表には全柱同時座屈などの仮定があります。
『鋼構造塑性設計指針』第4版（2026年）§6.2.3（pp.106–109）は骨組の座屈解析を基本とし、係数図表を用いる場合は水平移動と梁遠端の条件に応じて梁の剛度を補正します。
[許容応力度設計規準の書誌](https://ndlsearch.ndl.go.jp/books/R100000002-I030037737)・[塑性設計指針の書誌](https://ci.nii.ac.jp/ncid/BD21038834)

既定倍率が安全側となるかは支持条件によります。節点間距離3000 mmの水平移動非拘束の理想ピン門形架構では、梁と柱の剛度比が1の例で、弾性座屈から強軸の座屈長さ6983.63 mmを得ます。弱軸を3000 mmとし、柱に長期の圧縮軸力2215.2 kNが作用するとき、強軸の既定値3600 mmで比0.934、独立解の直接入力で比1.015となります。各方向の支持・接合条件から求めた長さが既定値を上回る場合は、その軸の長さを直接指定してください。

[CFT柱の座屈長さ](04_08_CFT柱の座屈長さと適用条件.md#cft柱の座屈長さ)は両軸に有限な正値の直接指定が必要です。

## 圧縮材の有効細長比上限

構造耐力上主要な圧縮材には、令第65条の有効細長比上限（柱200以下、柱以外250以下）が適用されます。
通常の鋼柱・大梁・筋かいでは、長期・短期とも検定位置の軸力が圧縮（引張正の軸力が負）の場合に、この上限を判定します。強軸・弱軸それぞれの有効座屈長さを断面二次半径で除した値の最大を用い、上限ちょうどは許容します。引張のみ、軸力0・曲げのみの位置には適用しません。SRC・CFTの内蔵鉄骨や鋼管単体へこの通常鋼の判定を流用しません。

判定位置は通常の断面検定と同じ柱フェース両端・中央・追加指定位置です。各荷重ケース・組合せの評価位置ごとの軸力で判定し、同じ部材の他の位置が引張または軸力0でも、圧縮位置の上限超過を打ち消しません。

超過は「構造規定」のNGとして、細長比・法定上限とその比率を示します。超過時の軸力・曲げの応力度検定は省きます。座屈長さの不足や細長比上限の超過があっても、[対称H形鋼の強軸ウェブせん断](03_03_鋼梁_柱のせん断検定.md#せん断の検定)で独立に確定した不適合は併記します。検定比図で曲げ等の項目を選択しても、超過した構造規定は不適合として残ります。通常S部材の有効細長比と許容圧縮応力度には、同じ[軸別の採用座屈長さ](#柱の座屈長さ係数-k)を用います。

山形鋼の[断面二次モーメント](../03_断面性能/02_断面諸量.md#塑性断面係数-zp-の算定範囲)は、図心を通り脚に平行な幾何軸まわりの値です。圧縮材を検定するには、断面の主軸と、その軸まわりの座屈に対応する有効座屈長さが必要です。端部や途中の拘束が主軸方向と異なる場合は、主軸まわりの曲げが連成することがあります。また、片脚接合では接合の偏心や回転拘束が圧縮耐力に影響します。

山形鋼形状を設定した柱・大梁・筋かいの圧縮位置は、軸別の長さを直接指定しても、法定上限を含む部材検定を理由付き未検定とします。主軸に対応する座屈長さの算定や、片脚接合したトラスの単一山形鋼ウェブ材に対する規準の限定的な算定には未対応です。引張・軸力0の位置は既存の検定範囲で扱います。形状を指定していない一般断面は、名称だけではこの未検定の対象になりません。

判定の根拠は、2025年版『建築物の構造関係技術基準解説書』第2版 p.175 §3.6.3 と、日本建築学会『鋼構造許容応力度設計規準』2019年制定 §§11.1–11.5、pp.23–25、解説 pp.86–92 です。 [令第65条](https://laws.e-gov.go.jp/law/325CO0000000338#Mp-At_65)・[規準の書誌](https://ndlsearch.ndl.go.jp/books/R100000002-I030037737)

検定比図では、同じ部材に未検定位置と検定済み位置が混在する場合も、検定済み位置の適合値だけで部材を着色しません。選択した項目で確認済みのNGがなければグレーの「未検定」とし、NGがあればそのNGと「未検定あり」を表示します。検定表とホバー内訳には、各位置の未検定理由を保持します。荷重組合せを切り替えた場合も、選択した組合せの検定結果で表示します。
