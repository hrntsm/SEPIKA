# RC梁の許容曲げ

強軸曲げを検定します。長期・短期の材料値を使い、正負曲げに対応する引張筋と中立軸から許容値を求めます。

RC 梁の曲げ・せん断・付着を、日本建築学会 RC規準 13条（2010年版）に基づいて検定します。

材料の短期倍率・軽量コンクリートの適用条件には[材料の許容応力度](01_01_コンクリートの許容応力度.md#コンクリート)に示す未確認範囲があります。本ページの部材式と材料値の組合せだけで、規準の全適用条件を満たすと判断しないでください。付着の方式・版は[付着・定着](02_07_RC梁の付着_定着検定.md#付着定着rc規準19991991)で区別します。

### 梁の許容曲げと中立軸

矩形RC梁は平面保持と線形応力分布を仮定し、ひび割れ後のコンクリート引張応力を無視します。梁は軸力との相関を考慮せず、強軸の \\( M\_z \\) に対して \\( |M\_z|/M\_A \\) を検定します。

正曲げ（\\( M\_z>0 \\)）は下端筋、負曲げは上端筋を引張側とし、引張側の全段の面積を \\( a\_t \\)、反対側を \\( a\_c \\) とします。引張縁から引張筋重心までを \\( d\_t \\)、圧縮縁から圧縮筋重心までを \\( d\_c \\)、全せいをD、有効せいを \\( d=D-d\_t \\) とします。多段筋の重心は面積加重平均です。

矩形の曲げ許容値を算定する条件は次のとおりです。

- 引張側に主筋があり、圧縮側にも主筋がある場合は上下の縁からそれぞれの主筋重心までの距離が一致する。段数や本数が異なる場合も、縁からの重心距離が等しければこの条件を満たす。
- 圧縮側の全段の中心が中立軸より圧縮縁側、引張側の全段の中心が中立軸より引張縁側にある。段中心が中立軸に一致する場合は適用範囲外とする。

2024年版RC規準p.18の13条5(2)は、主要な梁を全スパンで複筋梁とする構造規定を設けています。軽量コンクリートでは圧縮鉄筋量を所要引張鉄筋面積の0.4倍以上とする条件があります。この構造規定への適合は自動判定の対象外です。

非零曲げで条件を満たさない位置は、理由付きで**検定不能**となります。その位置で検定比や適合は表示されません。例えばFc24・SD345の矩形250×350 mm、D19で上端3本×2段・下端3本×1段、かぶり40 mm・あばら筋径10 mmでは、上下の縁からの重心距離が83.25 mmと59.5 mmです。長期の45 kN·mの正曲げは検定不能になります。強軸曲げ需要がゼロの位置では曲げ許容値の算定を省き、せん断や付着の検討を続けます。中央・スラブ付き正曲げは[正負曲げとスラブの扱い](#正負曲げとスラブの扱い)によります。

断面設計用のヤング係数比 \\( n \\) は鉄筋をコンクリートに換算する無次元比です。初期弾性解析の材料定数から直接求める \\( E\_s/E\_c \\) とは区別し、Fc区分と確認範囲は[断面設計用ヤング係数比](../02_材料/03_材料強度.md#断面設計用ヤング係数比の確認範囲)によります。[地震時設計用せん断の割増係数n](02_05_RC梁_柱の許容せん断の共通式.md#地震時設計用せん断)とは別です。許容応力度 \\( f\_c,f\_t \\) は[材料の許容応力度](01_材料の許容応力度.md)から長期／短期と主筋径に応じて選びます。

#### 断面の釣合いから中立軸を求める

主筋の各段が上記の適用条件を満たす断面で、コンクリート換算応力の勾配を \\( s \\) とすると、圧縮側は \\( \sigma\_c(y)=s(x\_n-y) \\)、鉄筋は \\( \sigma\_s(y)=ns(x\_n-y) \\) です（圧縮正）。圧縮域に含まれる鉄筋位置では、既に数えたコンクリート分を除くため換算面積を \\( (n-1)a\_c \\) とします。圧縮側に主筋がない断面では \\( a\_c=0 \\) とし、圧縮筋の項を省きます。軸力0の釣合いは次式です。

\\[ \frac{b x\_n^2}{2}+(n-1)a\_c(x\_n-d\_c)-na\_t(d-x\_n)=0 \\]

\\[ B=(n-1)a\_c+na\_t,\qquad C=(n-1)a\_c d\_c+na\_t d,\qquad x\_n=\frac{-B+\sqrt{B^2+2bC}}{b} \\]

中立軸まわりのコンクリート換算ひび割れ断面二次モーメントは、圧縮コンクリートと、各側の重心に集約した鉄筋の寄与を加えます。各段が中立軸の想定側にあれば、各側で換算係数が一定のため、各段を個別に扱う場合と重心集約の中立軸は一致します。重心集約では各段の重心まわりの分散に対応する正の寄与が省かれるので、同じ仮定で各段位置を用いた場合に比べてコンクリート圧縮縁で決まる許容値は同じか小さくなります。

\\[ I\_{cr}=\frac{b x\_n^3}{3}+(n-1)a\_c(x\_n-d\_c)^2+na\_t(d-x\_n)^2 \\]

この線形応力分布では \\( M=sI\_{cr} \\) となり、圧縮縁コンクリートの \\( sx\_n\le f\_c \\) から \\( M\_{Ac} \\) を得ます。一方、SEPIKAの引張鉄筋側の許容値は、中立軸から導く応力中心距離を使わず、**略算の \\( j=7d/8 \\)** を用いて次のように組み合わせます。

\\[ M\_A = \min(M\_{At}, M\_{Ac}) \\]

\\[ M\_{At} = a\_t \cdot f\_t \cdot j \\]

\\[ M\_{Ac} = f\_c \cdot I\_{cr}/x\_n \\]

同じ線形応力分布だけで引張鉄筋の制限 \\( ns(d-x\_n)\le f\_t \\) を表せば、許容値は \\( f\_t I\_{cr}/\\{n(d-x\_n)\\} \\)、対応する応力中心距離は \\( I\_{cr}/\\{na\_t(d-x\_n)\\} \\) です。これは上記の採用値 \\( a\_t f\_t(7d/8) \\) と一般には一致しません。接合部・せん断・付着で用いるjも7d/8の略算ですが、検討目的と参照する配筋・断面は各節の条件によります。梁の中立軸から求めた厳密値として転用しません。梁の採用許容式は圧縮鉄筋の許容応力による独立した上限を加えていません。

#### 対称複筋梁の代表例（長期・スラブ補正なし）

普通コンクリートFc=24 N/mm²、SD345主筋D20を上下各4本1段、b=300 mm、D=600 mm、かぶり40 mm、あばら筋径10 mmとします。主筋1本の面積を \\( \pi20^2/4 \\) として、 \\( a\_t=a\_c=1256.637 \\) mm²、 \\( d\_t=d\_c=40+10+20/2=60 \\) mm、d=540 mmです。材料値はn=15、fc=8 N/mm²、ft=215 N/mm²です。

| 計算段階 | 結果 |
| --- | --- |
| 釣合い | \\( 150x\_n^2+36442.475x\_n-11234335.329=0 \\)（各項mm³） |
| 中立軸 | \\( x\_n=177.944 \\) mm（60 < xn < 540） |
| 換算断面二次モーメント | \\( I\_{cr}=3.279060\times10^9 \\) mm⁴ |
| 採用する応力中心距離 | \\( j=7\times540/8=472.500 \\) mm |
| 引張側の許容値 | \\( M\_{At}=1256.637\times215\times472.5=127.659\times10^6 \\) N·mm |
| 圧縮縁の許容値 | \\( M\_{Ac}=8I\_{cr}/177.944=147.420\times10^6 \\) N·mm |
| 採用許容曲げ | \\( M\_A=127.659 \\) kN·m、引張側の許容式が支配 |

比較のため、同じxn・Icrから導く線形応力分布の応力中心距離は480.477 mmです。採用MAでこの分布を評価すると、コンクリート圧縮縁6.928 N/mm²、引張筋211.431 N/mm²となります。jの略算を含むため、支配側の応力度がちょうど215になるとは限りません。1 kN·m = \\( 10^6 \\) N·mmです。この例は採用式の計算確認であり、全荷重組合せを含む設計適合例ではありません。

| 記号 | 意味 | 単位 |
| --- | --- | --- |
| \\( D,d\_t,d\_c,y \\) | 全せい、引張縁から引張筋重心、圧縮縁から圧縮側筋の算定位置、圧縮縁からの座標 | mm |
| \\( a\_c \\) | 圧縮側主筋の断面積 | mm² |
| \\( n \\) | 断面設計用ヤング係数比 | − |
| \\( s \\) | コンクリート換算応力の勾配 | N/mm³ |
| \\( f\_c \\) | コンクリート許容圧縮応力度 | N/mm² |

日本建築学会『鉄筋コンクリート構造計算規準・同解説』2024年版pp.132–133の解13.2・解13.3および解13.5・解13.8・解13.9で、矩形断面の圧縮合力に実圧縮筋重心の位置を用いることと、引張・圧縮の応力分布を照合しました。圧縮コンクリートとの重複を除く換算係数は本文解説のn−1によります。材料値、略算jとの組合せを含めた規準の全適用条件には未照合範囲があります。

#### 正負曲げとスラブの扱い

部材中央（正規化位置 0.5）かつ梁にスラブが取り付く場合では、正曲げの許容を次のように扱います。
「スラブが取り付く」は版がある床板に対して判定します（版 = 断面が割り当たり板厚が正）。
囲まれた床板は、その床板が属する床領域の外周（大梁の区画。小梁による細分によらず常に区画
全体を表す。床領域内のどれか 1 枚でも版があればよい）に両端節点が含まれること、どの床領域にも
属さない床板は自身の境界節点に両端が含まれることです。取り付く床板は取付き線の両端が梁の
両端と一致すること（順不同）です。点取り付きと版なしは対象外です。
正曲げは部材座標系の \\( m\_z > 0 \\) とし、床スラブ側が圧縮となる向きです。
このときは T 形断面の引張支配略算として \\( M\_A = M\_{At} = a\_t \cdot f\_t \cdot j \\) のみを用います。
負曲げでは引張側のスラブを無視し、矩形断面の適用条件を満たす場合に \\( \min(M\_{At}, M\_{Ac}) \\) を用います。
中央のスラブ付き正曲げは矩形の許容曲げ \\( M\_{Ac} \\) を算定・表示せず、スラブ有効幅・フランジ厚による圧縮縁応力度や、釣合鉄筋比の条件も自動では確認しません。日本建築学会『鉄筋コンクリート構造計算規準・同解説』2024年版p.18の13条3・4は、T形断面の圧縮縁の評価とjの略算を使う条件を規定しています。この略算を使う梁では、圧縮側と引張鉄筋比の条件を別途確認してください。

床スラブ自体の一方向検定（版のある床板の \\( M \\)・許容値）は、この梁の T 形断面略算とは
別の検定です。[床（スラブ）の一方向検定](05_03_床板の一方向検定.md#床スラブの一方向検定)を参照してください。
