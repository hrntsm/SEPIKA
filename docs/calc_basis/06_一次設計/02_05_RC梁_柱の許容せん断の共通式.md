# RC梁・柱の許容せん断の共通式

RC梁・柱について、長期、短期の損傷制御、短期の安全確保に使う許容せん断耐力と、地震時を含む設計用せん断力を求めます。材料、配筋、断面の「主架構用途」などは[RCの部材検定に共通する入力条件](02_RC_断面検定.md)を確認してください。

## 梁・柱のせん断需要と許容耐力

以下は現在採用する梁・柱のせん断式です。RC規準13条・14条に対応する検討ですが、材料値と部材式の組合せには[コンクリートの短期倍率・軽量低減の原典未確認範囲](01_01_コンクリートの許容応力度.md)が残ります。式の対応を示すことは、その適用根拠を確認済みとするものではありません。

設計タブの「RC短期せん断: 損傷制御」は、ON（既定）で損傷制御、OFFで安全確保の式を選びます。長期ではこの選択によらず長期式を使います。需要の「min(QD1,QD2)」（既定）／「QD1」／「QD2」は別の選択で、許容耐力の式を切り替えません。

| 部材・期間・検討目的 | 採用材料値 | 許容耐力 | 検定比 |
| --- | --- | --- | --- |
| 梁・長期 | 長期値 | \\( Q\_{AL}^{B} \\) | \\( Q\_L/Q\_{AL}^{B} \\) |
| 梁・短期・損傷制御 | 短期値、補強筋390上限 | \\( Q\_{AS,d}^{B} \\) | \\( Q\_{\mathrm{dem}}/Q\_{AS,d}^{B} \\) |
| 梁・短期・安全確保 | 短期値 | \\( Q\_{AS,s}^{B} \\) | \\( Q\_{\mathrm{dem}}/Q\_{AS,s}^{B} \\) |
| 柱・長期 | 長期値（補強筋項なし） | \\( Q\_{AL}^{C} \\) | \\( Q\_L/Q\_{AL}^{C} \\) |
| 柱・短期・損傷制御 | 短期値、補強筋390上限 | \\( Q\_{AS,d}^{C} \\) | \\( Q\_{\mathrm{dem}}/Q\_{AS,d}^{C} \\) |
| 柱・短期・安全確保 | 短期値 | \\( Q\_{AS,s}^{C} \\) | \\( Q\_{\mathrm{dem}}/Q\_{AS,s}^{C} \\) |

柱は強軸側（Mz・Qy）と弱軸側（My・Qz）のそれぞれの断面諸量・需要で検定し、大きい検定比をせん断の結果に表示します。梁は強軸側（Mz・Qy）を検定します。

最後に、選択した部材・期間・目的の許容耐力で、次の需要を除します。材料の短期倍率を長期の許容耐力全体へ掛ける換算はできません。

| 荷重状態・需要方式 | 検定に用いる需要 \\( Q\_{\mathrm{dem}} \\) |
| --- | --- |
| 長期の保存組合せ・梁 | 検定位置の重力せん断力の絶対値 \\( Q\_L \\) |
| 長期の保存組合せ・柱 | [両材端フェース間の方向別最大せん断力](02_04_RC柱のせん断検定.md#長期せん断の検定位置) |
| 地震を含まない短期の保存組合せ（積雪・風） | 選択組合せの解析せん断力の絶対値 \\( \lvert Q\rvert \\) |
| 地震時短期・min(QD1,QD2) | \\( \min(Q\_{D1},Q\_{D2}) \\) |
| 地震時短期・QD1 | \\( Q\_{D1} \\) |
| 地震時短期・QD2 | \\( Q\_{D2} \\) |

地震時は損傷制御／安全確保のどちらでも、選択した需要方式を用います。必要な重力参照が揃うことが前提です。内法長が正でないか降伏モーメント和が正でなくQD1を算定できない場合、QD1／min方式もQD2を採用します。これは、[地震時設計用せん断の重力参照](#地震時設計用せん断)の不足を補完する規則ではありません。単独の荷重ケースでは主架構の組合せ検定を実施しないこと、組合せの選択・未検定の意味は[本章の入口](README.md)に従います。

### 材料値・補強筋比・αの適用

まず[材料の許容応力度](01_材料の許容応力度.md)から長期／短期のコンクリート値 \\( f\_{s,L},f\_{s,S} \\) と補強筋値 \\( {}\_w f\_{t,L},{}\_w f\_{t,S} \\) を選びます。コンクリートの軽量低減も材料値に含めます。その後、短期・損傷制御だけ補強筋値を390 N/mm²で制限し、長短期別の補強筋比上限と組み合わせ、下式の補強筋項を算定します。

\\[ p\_{w,L}=\min(p\_w,0.006),\qquad p\_{w,S}=\min(p\_w,0.012) \\]

\\[ {}\_w f\_{t,S,d}=\min({}\_w f\_{t,S},390\\,\mathrm{N/mm^2}) \\]

\\[ R\_L=0.5\\,{}\_w f\_{t,L}\max(p\_{w,L}-0.002,0) \\]

\\[ R\_{S,d}=0.5\\,{}\_w f\_{t,S,d}\max(p\_{w,S}-0.002,0),\qquad R\_{S,s}=0.5\\,{}\_w f\_{t,S}\max(p\_{w,S}-0.002,0) \\]

補強筋比が0.002未満でも負の負担にはせず0とします。現在対応する普通強度せん断補強筋はSR235・SR295・SD295・SD345・SD390・SD490です。高強度せん断補強筋は未対応です。

\\[ \alpha=\min\left(\alpha\_{\max},\max\left(1,\frac{4}{|M|/(|Q|d)+1}\right)\right),\qquad \alpha\_{\max}=2.0\quad (\text{梁}),\quad 1.5\quad (\text{柱}) \\]

矩形・円形RC柱の通常の長期保存組合せには[長期許容せん断力の割増係数](02_04_RC柱のせん断検定.md#長期許容せん断力の割増係数)の二段階の照査を用います。通常の組合せ検定のその他の条件でαを求める場合は、検討方向ごとに、曲げモーメントの絶対値が最大となる解析評価断面（節点芯を含む）の \\( (|M|,|Q|) \\) を使います。強軸は \\( |M\_z|\_{\max} \\) とその位置の \\( |Q\_y| \\)、弱軸は \\( |M\_y|\_{\max} \\) とその位置の \\( |Q\_z| \\) です。地震時設計用の \\( Q\_D \\) をαの \\( |Q| \\) に置き換えません。
退化時の規約: \\( Q\approx0 \\)（\\( |Q|<10^{-9}\\,\mathrm{N} \\)）かつ \\( |M|>0 \\) はせん断スパン比が無限大となる下限α=1.0を採用します。MもQも0（無応力）または \\( d\le0 \\) の場合もα=1.0とします。この規約はRC・SRCで共通です。

### 採用許容式

梁の長期・短期安全確保は同じ形の式ですが、材料値と補強筋比上限を切り替えます。短期損傷制御ではコンクリート項に2/3を掛ける式へ変わります。

\\[ Q\_{AL}^{B}=bj(\alpha f\_{s,L}+R\_L) \\]

\\[ Q\_{AS,d}^{B}=bj\left(\frac{2}{3}\alpha f\_{s,S}+R\_{S,d}\right) \\]

\\[ Q\_{AS,s}^{B}=bj(\alpha f\_{s,S}+R\_{S,s}) \\]

柱は長期に補強筋項を加えず、短期損傷制御は梁と同形、短期安全確保はコンクリート項にαを含めません。

\\[ Q\_{AL}^{C}=bj\alpha f\_{s,L} \\]

\\[ Q\_{AS,d}^{C}=bj\left(\frac{2}{3}\alpha f\_{s,S}+R\_{S,d}\right) \\]

\\[ Q\_{AS,s}^{C}=bj(f\_{s,S}+R\_{S,s}) \\]

### 地震時設計用せん断

\\[ Q\_D=\min(Q\_{D1},Q\_{D2})\quad (\text{min方式}),\qquad Q\_D=Q\_{D1}\quad (\text{QD1方式}),\qquad Q\_D=Q\_{D2}\quad (\text{QD2方式}) \\]

\\[ Q\_{D1}^{B}=Q\_0+n\_{\mathrm{mech}}\frac{\sum {}\_B M\_y}{l^{\prime}},\qquad Q\_{D1}^{C}=n\_{\mathrm{mech}}\frac{\sum M\_y}{h^{\prime}} \\]

\\[ Q\_{D2}=Q\_L+n Q\_E,\qquad Q\_L=|q\_L|,\quad Q\_E=|q-q\_L| \\]

ここで \\( q \\) は選択組合せ、\\( q\_L \\) は同じ位置・方向の重力参照の**符号付き**解析せん断力です。成分を差し引いてから絶対値を取ります。\\( n=1.5 \\)、\\( n\_{\mathrm{mech}}=1.0 \\) を採用します。梁の \\( \sum {}\_B M\_y \\) は検定位置断面の略算降伏モーメントの2倍を用います。柱の和は[柱頭・柱脚の崩壊メカニズム](02_04_RC柱のせん断検定.md#柱頭柱脚の崩壊メカニズム)によります。

ここで記号の意味を分けます。

- \\( Q\_L \\)：選択した組合せに含まれる固定・積載・積雪荷重ケースの組合せ係数を保持したFEM重力せん断力（積載は架構用）
- \\( Q\_E \\)：選択した組合せに含まれる地震荷重ケースの寄与（組合せ内力から上記重力参照を差し引いた成分。0.35Sを含めない）
- \\( Q\_0 \\)：両端支持とした単純梁の長期せん断力（部材荷重から算定。重力ケース集合は \\( Q\_L \\) と同じ）

\\( Q\_0 \\) は選択した組合せに含まれる固定・積載・積雪荷重ケースの部材荷重から、[RC梁の単純梁せん断Q0](02_02_RC梁のせん断検定.md#rc梁の単純梁せん断q0)で算定します。地震重量用積載は流用しません。
RC梁でQD1を含む方式を選びQ0が不足する場合は理由付き未検定とし、FEMのQLでは代替しません。SRC梁は[SRC梁の地震時設計用せん断と重力参照](04_03_SRC梁_柱の許容せん断検定.md#src-梁の地震時設計用せん断と重力参照)に従います。
\\( n\_{\mathrm{mech}} \\) はメカニズム側の割増で、既定は 1.0 です。
本ソフトでは QD1 をメカニズム側、QD2 を割増 QE 側と呼びます。

### 長期・短期の代表例（採用式の数値確認）

普通コンクリートFc=24 N/mm²、SD490補強筋、検討方向の幅b=300 mm、有効せいd=560 mm、j=7d/8=490 mm、実補強筋比0.008とします。長期の最大モーメント位置で \\( (|M|,|Q|)=(56\times10^6\\,\mathrm{N\\,mm},100000\\,\mathrm{N}) \\)、短期では \\( (140\times10^6\\,\mathrm{N\\,mm},250000\\,\mathrm{N}) \\) とすると、いずれも \\( |M|/(|Q|d)=1 \\)。梁は長期・短期ともα=2.0、柱の短期損傷制御はα=1.5です。柱は一方向分の例で、長期需要100 kNをα=1の許容値107.310 kNが満たします。

材料値は \\( f\_{s,L}=0.49+24/100=0.73 \\)、\\( f\_{s,S}=1.5\times0.73=1.095 \\) N/mm²。補強筋値は長期195、短期490、損傷制御用短期はmin(490,390)=390 N/mm²です。長期の補強筋比はmin(0.008,0.006)=0.006、短期はmin(0.008,0.012)=0.008となります。

\\[ R\_L=0.5\times195\times(0.006-0.002)=0.390\\,\mathrm{N/mm^2} \\]

\\[ R\_{S,d}=0.5\times390\times(0.008-0.002)=1.170\\,\mathrm{N/mm^2},\quad R\_{S,s}=1.470\\,\mathrm{N/mm^2} \\]

長期需要は100 kN。地震時短期では符号付きq=250 kN、qL=100 kNよりQE=150 kN、QD2=100+1.5×150=325 kNとします。梁はQ0=120 kN、降伏モーメント和1200 kN·m、内法6000 mmでQD1=120+1200/6=320 kN。柱は降伏モーメント和900 kN·m、内法3000 mmでQD1=900/3=300 kNです。min方式を選ぶと梁320 kN、柱300 kNを需要に使います。

| 検討 | 許容耐力の途中値（N） | 許容耐力（kN） | 需要／許容耐力 |
| --- | --- | --- | --- |
| 梁・長期 | 300×490×(2×0.73+0.390) | 271.950 | 100/271.950 ≈ 0.368 |
| 梁・短期・損傷制御 | 300×490×((2/3)×2×1.095+1.170) | 386.610 | 320/386.610 ≈ 0.828 |
| 梁・短期・安全確保 | 300×490×(2×1.095+1.470) | 538.020 | 320/538.020 ≈ 0.595 |
| 柱・長期 | 300×490×1×0.73 | 107.310 | 100/107.310 ≈ 0.932 |
| 柱・短期・損傷制御 | 300×490×((2/3)×1.5×1.095+1.170) | 332.955 | 300/332.955 ≈ 0.901 |
| 柱・短期・安全確保 | 300×490×(1.095+1.470) | 377.055 | 300/377.055 ≈ 0.796 |

数値例は採用計算の確認であり、実配筋・全荷重組合せ・適用規準への適合を保証する設計例ではありません。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( M\_{At} \\) | 引張鉄筋の引張力で決まる許容曲げモーメント | N·mm |
| \\( M\_{Ac} \\) | コンクリートの圧縮応力度で決まる許容曲げモーメント | N·mm |
| \\( a\_t \\) | 引張鉄筋断面積 | mm² |
| \\( f\_t \\) | 鉄筋の許容引張応力度 | N/mm² |
| \\( j \\) | 応力中心距離（有効せいdの7/8、j=7d/8） | mm |
| \\( I\_{cr} \\) | ひび割れ断面二次モーメント | mm⁴ |
| \\( x\_n \\) | 圧縮縁から中立軸までの距離 | mm |
| \\( \alpha \\) | せん断スパン比 \\( M/(Q \cdot d) \\) による割増係数 | - |
| \\( Q\_{AL} \\) | 長期許容せん断力 | N |
| \\( {}\_w f\_t \\) | せん断補強筋の許容引張応力度 | N/mm² |
| \\( p\_w \\) | せん断補強筋比 | - |
| \\( Q\_D \\) | 地震時の設計用せん断力 | N |
| \\( b,d \\) | 検討方向の幅、有効せい（円形柱の幅は等価正方形の辺長） | mm |
| \\( f\_{s,L},f\_{s,S} \\) | コンクリートの長期・短期許容せん断応力度 | N/mm² |

| \\( Q\_{AS,d},Q\_{AS,s} \\) | 短期損傷制御・短期安全確保の許容せん断力（上添字Bは梁、Cは柱） | N |

| \\( l^{\prime},h^{\prime} \\) | 梁の内法スパン、柱の内法高さ | mm |
| \\( \sum {}\_B M\_y,\sum M\_y \\) | 梁・柱のQD1に用いる降伏モーメント和 | N·mm |
