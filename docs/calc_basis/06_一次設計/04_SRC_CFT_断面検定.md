# SRC / CFT 断面検定

SRC は SRC規準1987の累加強度式・併用せん断式を採用します。以下の対応範囲と制約に従って部材の検定比を確認してください。検定比の適合は、SRC造の構造細則・柱脚・接合詳細を含む全条件の適合を意味しません。CFT の採用方式・適用範囲は各節に示します。

## SRC の対応範囲と別途確認

矩形のRC部に中心H形鉄骨を内蔵した梁・柱を対象とします。梁は強軸曲げと対応するせん断、柱は軸力・二軸曲げ・二方向せん断を検定します。梁の軸力・弱軸曲げ・弱軸方向せん断は評価しません。これらが作用する梁では、この検定比だけで安全を判断せず、別途その影響を検討してください。

鉄骨のコンクリートかぶりは、令79条の3による原則50 mm以上と例外の適用条件を別途確認してください。形状や配筋入力の受理は、この法定かぶりの適合判定ではありません。令79条の4で準用される規定の適用・除外、柱脚の引張抵抗、継手・定着、構造切替階の応力伝達、接合部の帯筋配置も自動確認しません。部材・接合部の耐力比は、これらの詳細確認を代替しません。

## CFT の適用条件と別途確認

CFTは柱を対象とし、鋼管と充填コンクリートへ別々の材料を割り当てます。[平成14年国土交通省告示第464号](https://www.mlit.go.jp/notice/noticedata/pdf/201703/00006524.pdf)第三2に基づき、充填コンクリートの設計基準強度Fcは24 N/mm²以上を必要とします。Fcが24 N/mm²未満の場合は許容応力度検定を行わず、下限未満である理由を付けて検定不能として表示します。24 N/mm²ちょうどを含む、それ以上の有限値は既存の検定の対象です。入力Fcを24 N/mm²へ補完せず、別認定による例外も扱いません。第十・第十一による適用条件の違いを、第三2の下限の除外として扱いません。

告示464号の充填・養生・接合の施工順序、蒸気抜き孔、仕口補強の条件は別途確認してください。柱の座屈長さと小径の比、板厚、径厚比・幅厚比の仕様条件と、保有水平耐力計算等による適用除外の条件も自動判定しません。長柱の耐力を計算できることや、拘束による強度割増しを採らないことだけで、適用除外の成立を意味しません。

許容耐力は以下に示す累加・鋼管せん断の採用モデルによります。検定比の適合は、これらの法定適用条件・施工条件の適合や、全ての断面・材料に対するモデル精度を保証しません。

## 角形 CFT の暫定適用範囲

許容曲げは内角Rが 0 の場合に限り、矩形コアの既存式を用います。
0<角R≤板厚では内角Rが 0 となりますが、鋼管の A・Iy・Iz・弾性断面係数・細長比には角Rを反映します。
内角Rが正の場合は許容曲げを未対応とし、その検定位置全体を理由付きの「未算定」とします。
需要が 0 でも、未対応の耐力を 0 や適合へ読み替えません。

終局 N–M が必要な設計用せん断 QD1/min は、角Rが正の場合に未算定となります。
内角Rが 0 でも鋼管が角丸なら対象となり、QD2 へ自動切替しません。
利用者が QD2 を明示しても、内角Rが正なら許容曲げが未対応のため位置全体は未算定です。
GUI は未算定理由を表示し、MCP は `member_skipped` に位置と理由を返します。
NG が 0 件であっても、未算定を含む結果は「全適合」ではありません。

正の角Rに対する規準設計への対応には、上記の制約があります。
ファイバー積分を規準式の無条件な代替として採用していません。
明示した角R=0 の既存設計式と、円形 CFT の適用は維持します。

## 記号・単位と算定式

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( M\_A \\) | SRC 断面の許容曲げモーメント（鉄骨と RC の累加） | N·mm |
| \\( {}\_s M\_o \\) | 鉄骨部の許容曲げモーメント | N·mm |
| \\( {}\_r M\_A \\) | RC 部の許容曲げモーメント | N·mm |
| \\( {}\_s Q\_A \\) | 鉄骨部の許容せん断力 | N |
| \\( {}\_r Q\_A \\) | RC 部の許容せん断力 | N |
| \\( Q\_A \\) | SRC 柱の許容せん断力（併用式） | N |
| \\( {}\_s Z \\) | 鉄骨の断面係数 | mm³ |
| \\( a\_t \\) | 引張鉄筋断面積 | mm² |
| \\( f\_t, f\_s \\) | 鉄筋の許容引張応力度・コンクリートの許容せん断応力度 | N/mm² |
| \\( {}\_s f\_t, {}\_s f\_s \\) | 鉄骨の許容引張応力度・許容せん断応力度 | N/mm² |
| \\( {}\_w f\_t \\) | せん断補強筋の許容引張応力度 | N/mm² |
| \\( p\_w \\) | せん断補強筋比 | - |
| \\( \beta \\) | 鉄骨ウェブの形式と寸法による係数 | - |
| \\( {}\_r \alpha \\) | せん断スパン比による RC 部の割増係数 | - |
| \\( \sum {}\_c M\_y \\) | 柱頭・柱脚の終局曲げ耐力の和 | N·mm |
| \\( Q\_D \\) | 地震時の設計用せん断力 | N |

**算定式**

SRC 梁 曲げ（鉄骨と RC の累加）:

\\[ M\_A = {}\_s M\_o + {}\_r M\_A \\]

鉄骨部:

\\[ {}\_s M\_o = {}\_s Z \cdot {}\_s f\_t \\]

RC 部:

\\[ {}\_r M\_A = a\_t \cdot f\_t \cdot j \\]

SRC 梁 せん断は、鉄骨部と RC 部を弾性分担（または地震時短期の構造規定方式 sQD/rQD）と比較します。

鉄骨部:

\\[ {}\_s Q\_A = t\_w \cdot d\_w \cdot {}\_s f\_s \\]

RC 部（pw は 0.6% 上限）:

\\[ {}\_r Q\_A = \min(b \cdot {}\_r j \cdot ({}\_r \alpha \cdot f\_s + 0.5 \cdot p\_w \cdot {}\_w f\_t), b \cdot {}\_r j \cdot (2(b\'/b) \cdot f\_s + p\_w \cdot {}\_w f\_t)) \\]

- SRC 柱 N-M 相関を累加強度式で構築する（コンクリート許容応力度は鉄骨フランジ食い込み低減後 \\( f\_c\' = f\_c(1 - 15 \cdot {}\_s p\_c) \\)）、二軸曲げは線形和。RC 部 N-M 曲線は引張側アンカー \\( ({}\_r N\_t, 0) \\) を持ち、純引張耐力近傍で \\( {}\_r M \to 0 \\) に収束する。
SRC 柱 せん断の長期は、併用式を全せん断力と比較します。

\\[ Q\_A = (1+\beta) \cdot b \cdot {}\_r j \cdot a\' \cdot f\_s \\]

ここで \\( a\' = {}\_r \alpha \\)（\\( b\'/b \ge {}\_r \alpha/3 \\)）または \\( 3b\'/b \\)、\\( 1 \le {}\_r \alpha \le 2 \\)、β は鉄骨ウェブの形式と寸法による係数とします。

せん断スパン比による割増係数 \\( {}\_r \alpha = 4/(M/(Q \cdot d)+1) \\) の算定（\\( Q \approx 0 \\) の退化時は下限 1.0 を採用する規約を含む）は RC 断面検定（[梁（RC規準13条）](02_RC_断面検定.md#梁rc規準13条)）と共通です。

短期は鉄骨部 `sQA`（強軸 \\( d\_w \cdot t\_w \cdot {}\_s f\_s \\)／弱軸 \\( (4/3) \cdot b\_f \cdot t\_f \cdot {}\_s f\_s \\)）と RC 部を分担 sQD/rQD と比較します。

\\[ {}\_r Q\_{AS1} = b \cdot {}\_r j \cdot (f\_s + 0.5 \cdot p\_w \cdot {}\_w f\_t) \\]

（α を含まない）

\\[ {}\_r Q\_{AS2} = b \cdot {}\_r j \cdot (2(b\'/b) \cdot f\_s + p\_w \cdot {}\_w f\_t) \\]
- CFT 柱は SRC 規準の累加モデルを CFT 断面に準用し、相互拘束効果の強度割増しを考慮しません。許容せん断耐力は鋼管部分だけで評価します。角形のせん断有効断面積は方向別（\\( 2t(H-2t) \\)／\\( 2t(B-2t) \\)）とし、二方向のせん断検定比の最大を用います。円形は鋼管全断面積の1/2をせん断有効断面積とし、二方向のせん断力の合力 \\( \sqrt{Q_y^2+Q_z^2} \\) を許容せん断耐力と比較します。鋼管部分の許容圧縮応力度の細長比は、充填コンクリートの剛性を算入せず鋼管単体の断面二次半径で評価します。これら個々の低減の採用だけで、累加モデル全体や適用条件を含む安全側を認定するものではありません。鋼管部分の許容圧縮応力度には鋼管専用材料のヤング係数を用います。コンクリート強度未設定の断面は検定不能です。鋼管材料の不備は下記の条件に従い拒否します。
- CFT 柱の充填コンクリート部分の \\( (c\_N, c\_M) \\) は、縁応力一定・線形分布（コンクリート引張無視）の弾性三角形応力分布で求める（矩形は中立軸位置・充填断面幅せいの閉形式、円形は同仮定の数値積分）。中立軸が断面外（\\( X\_n > c\_D \\)）の分枝の \\( c\_M \\) 式は、\\( X\_r = 1 \\) での連続性と全断面一様圧縮での 0 収束を満たす形を用いる。
- CFT の鋼管材料は鋼管専用の材料割当を参照し、既知材種は実板厚による表のF、未知名称は正の有限値の降伏応力を用います。既知材種の適用範囲外を直接指定値で補いません。未設定・不正・解決不能な場合は解析前エラーとし、F=235 の補完は行いません。

CFTの鋼管専用材料は、GUIの断面表の「内蔵鉄骨・鋼管」欄で指定・変更します。主材料には充填コンクリートを割り当て、鋼管材料と分けます。

## CFT鋼管のヤング係数と許容圧縮

鋼管の許容圧縮応力度は、[材料の許容応力度](01_材料の許容応力度.md#鋼材f-値許容応力度座屈)の式へ、鋼管専用材料に登録したヤング係数Eをそのまま用いて求めます。
正の有限値を入力範囲とし、標準値205000 N/mm²と異なる値も許します。充填コンクリートのEを鋼管側へ用いません。
Eが0以下・非有限の場合、または中間値や許容応力度が数値の表現範囲外になる場合は、対象位置全体を理由付き未算定とします。固定値で補完しません。

鋼管専用材料の種別が「鋼材」であれば、大臣認定による特別な鋼材も同じ許容圧縮応力度式を適用します。材料定数・使用条件はその認定内容に従って指定します。
限界細長比の内側係数と外側係数0.277の丸めによる小さな段差は保持します。Eの増減を全領域で厳密に単調な耐力変化とは扱いません。

## SRC 梁の地震時設計用せん断と重力参照

地震時短期には構造規定方式を用います。QL は、検定対象と同じ選択重力荷重・係数による FEM のせん断力です。
単純梁の部材荷重から求める Q0 とは異なり、SRC 梁のこの方式では Q0 を算定に使いません。
RC 梁の Q0 に対する符号付き端反力の合成方法を SRC 梁へ適用するものではありません。

評価位置ごとに、鉄骨の断面係数 \\( {}\_s Z \\)、引張鉄筋断面積 \\( a\_t \\)、RC 部の応力中心間距離 \\( {}\_r j \\) から分担率を求めます。
曲げの引張側に対応する鉄筋を用い、曲げが 0 の場合は上下の引張鉄筋量の小さい側を採ります。

\\[ \eta\_s = \frac{{}\_s Z}{{}\_s Z+a\_t\,{}\_r j},\qquad {}\_s Q\_L=\eta\_s|Q\_L|,\qquad {}\_r Q\_L=(1-\eta\_s)|Q\_L| \\]

\\[ {}\_s Q\_D={}\_s Q\_L+\frac{2\,{}\_s Z\,{}\_s f\_t}{l'},\qquad {}\_r Q\_{D1}={}\_r Q\_L+\frac{2\,{}\_r M\_u}{l'} \\]

\\[ {}\_r Q\_{D2}=\max\{0,\ n(|Q|-{}\_s Q\_D)\} \\]

ここで Q は検定対象の地震組合せ後の全せん断力 [N]、l′ は内法スパン [mm]、n は割増係数、
鉄骨の短期許容引張応力度は N/mm²、RC 部の終局曲げ耐力は N·mm です。
Qd1 は RC 部に rQD1、Qd2 は rQD2、Min は両者の小さい値を用い、鉄骨部の sQD は共通です。
既存の退化時の扱いとして、内法スパンが正でない場合は鉄骨部の曲げ項を加算せず、
RC 部の QD1 が求まらない場合は QD2 を用います。これは長期参照不足の代替規則ではありません。

検定は i 端・中央・j 端の既存評価位置で行い、端部フェースがある場合は端の評価位置をフェースへ移します。
各位置の QL は同じ位置から採り、正規化位置の差が 10⁻⁶ 未満の行を一致とします。
Qd1・Qd2・Min のいずれもこの長期参照を必要とします。
要求した長期参照に当該部材がない場合、または同位置の QL が欠落・非有限の場合や評価位置が非有限の場合は、
該当する検定位置全体を理由付き未検定とします。弾性分担・0・近傍位置・補間値で補いません。
定義済みで有限な QL=0 は不足に含めません。通常の長期・地震割増を用いない短期は既存の弾性分担で検定します。

QLを用いる構造規定方式と、単純梁Q0を用いる方式は参照する応力状態が異なります。SEPIKAは本文に示すQL分担とsQD/rQDを採用し、QLをQ0で置き換えません。
『2007年版 建築物の構造関係技術基準解説書』p.664–665への適合は未確認です。

両端同一断面の仮定と絶対値による合成を含むため、正負地震・異断面等の一般的な安全性や規準適合を保証するものではありません。

## CFT 柱の地震時設計用せん断

\\[ Q\_D = \min(Q\_{D1}, Q\_{D2}) \\]

\\[ Q\_{D1} = \sum {}\_c M\_y/h\' \\]

ここで cMy には [CFT 柱の終局 N–M 相互作用](../08_部材終局耐力/06_CFT_柱_終局耐力.md#正方形角r0-の長柱-case2)による終局曲げ耐力 Mu(N)（柱分類対応）を用い、柱頭・柱脚同一断面の仮定で \\( \sum {}\_c M\_y = 2 \cdot M\_u(N) \\) とします。

\\[ Q\_{D2} = Q\_L + n \cdot Q\_E \\]

QD1 または min を選択した場合、各検討軸の座屈長さによる Mu(N) を用います。
正方形・角R=0 の長柱で圧縮軸力がコンクリート座屈耐力を超える Case2 は、リンク先の適用域・有効域に従います。
この Case2 で曲げ耐力が下がると、QD1 と min の要求せん断力も下がり得ます。曲げの耐力低下だけで設計全体を安全側とは判定しません。
純圧縮端の Mu=0 や軸終局限界超過を、QD2 への自動切替で適合に読み替えません。
無効な寸法・座屈荷重や適用範囲外で Mu が求められない場合は、QD1/min も理由付き未算定です。
GUI の未算定理由、MCP の `member_skipped` と、終局検定の軸 NG／Mu 未算定を区別して確認してください。

**SRC規準1987からの主な簡略化**

- 地震時短期の設計用せん断力は構造規定方式のみを実装し、選択機能は設けない。`sM1+sM2 = 2・sZ・sft` は部材両端が同一鉄骨・短期許容引張応力度に達するとみなす近似（安全側とは限らない）、`rMu1+rMu2 = 2・rMu` も両端同一断面・同一設計軸力の仮定による。
- SRC 柱の内蔵鉄骨の座屈は考慮せず `s_fc = s_ft` とする（被覆コンクリートによる拘束のため。SRC 規準の座屈検討は別途必要になり得る）。
- SRC 柱の RC 部分の中立軸圧縮側鉄骨面積は軸に依らない一つの値を用いる。
- SRC 柱のせん断は強軸・弱軸を対称的に扱い、RC 柱検定と同様の「b/D 入れ替え」近似を用いる。
- CFT 断面では、鋼管と充填コンクリートに別の材料を割り当て、F値には鋼管材料、Fc・コンクリート種別には充填材を用いる。許容圧縮応力度に用いる鋼管のヤング係数は鋼管材料の入力値とする。コンクリート強度または鋼管材料未設定の断面は検定不能とする。
- CFT の鋼管強度は鋼管専用の材料割当から、上記の材種・実板厚の条件で決める。未設定・不正・解決不能な場合は解析前エラーとし、SS400 相当（F=235）の補完は行わない。
- SRC 断面では、コンクリート強度、主筋・せん断補強筋・内蔵鉄骨の材料が必要です。内蔵鉄骨の未知鋼種名は、直接入力した降伏応力によらずF=235で検定する制約があります。235 N/mm²未満の鋼材では許容耐力を過大評価し得るため、この補完結果を採用しないでください。材種と板厚からF値を確認できる対応鋼種を使用し、未知鋼種は別途検討してください。
