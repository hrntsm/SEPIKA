# 鋼構造 断面検定

鋼構造の断面検定を、鋼構造設計規準・告示平13国交告第1024号に基づいて行いますが、幅厚比による断面性能の低減は考慮しません（幅厚比は部材ランク判定
（[部材ランク](../07_二次設計/03_部材ランク.md)）で別途評価します）。

## 単一リップ溝形材の検討対象と未検定

単一・直角・一様厚の総断面モデルは、有限な正の外寸 H/B/C/t [mm]、t < C < H/2、t < B/2 を必要とします。
5矩形の交差と開口の根拠は[単一リップ溝形の寸法と総断面性能](../../preparation/07_断面性能.md#単一リップ溝形の寸法と総断面性能)を参照してください。
上下リップの接触 C = H/2 も対応範囲外です。接触の結合や閉断面Jを推定せず、寸法・総性能が成立しても以下の未検定状態は変わりません。
この寸法条件は対応する初等幾何モデルの条件であり、国内耐力規準や製造者表の規準条文として扱いません。

一般軽量形鋼の単一リップ溝形材は、断面の幾何性能と部材検定の対応範囲を分けます。
現段階の部材検定は、柱・梁・ブレースのいずれも理由付きの「検定不能」です。
純圧縮、正負の強軸・弱軸曲げ、圧縮曲げ・組合せ、純引張、無荷重、せん断のみでも検定済みにはしません。
総断面の降伏、一般断面の許容曲げ応力度、幅厚比や断面保存の成立だけでは部材の適合を示せません。
純引張などで座屈の不適用を別途判断できても、断面欠損・接合を含む部材検定の対応完了とは別です。
現在の分類表示では不適用も判定せず、条件不明を不適用へ読み替えません。

| 検討対象 | 区別する変形 | 現在の状態 |
|---|---|---|
| 局部座屈 | ウェブ–フランジおよびフランジ–リップの接合線が移動しない板要素の局所変形 | 算定未対応 |
| ゆがみ座屈 | フランジ–リップ接合線の移動等を伴う断面形状変化 | 算定未対応 |
| 全体座屈 | 断面形状を保つ部材全体の曲げ・ねじり・曲げねじり、梁の横座屈 | 各耐力式と拘束条件の適用が未確認 |

分類は検討対象の種別を示します。形状名から実際に発生する座屈や支配モードを予測せず、
各項目を合格にしません。局部・ゆがみ・全体の連成も一つのモードへ強制分類せず、未評価とします。

入力・結果の単位と適用条件は次のとおりです。

| 情報 | 単位 | 参照・保持する内容と適用限界 |
|---|---|---|
| H/B/C/t | mm | 保存された外寸のせい・幅・リップ長・板厚を理由欄へ表示。未知の曲げ半径Rを0として設計用平板部幅へ変換しない |
| 総A、Iy/Iz/J | mm²、mm⁴ | 既存の総断面幾何性能を保持。検定対応や有効断面の値を意味しない |
| 有効A、強軸/弱軸の有効Z | mm²、mm³ | 荷重状態・圧縮側・採用式に依存する評価結果。未算定であり総A/Zや0による代替は行わない |
| N、Qy/Qz、My/Mz | N、N、N·mm | Nは負が圧縮、正が引張。強軸はMz/Qy、弱軸はMy/Qz。符号を理由欄へ保持し、非有限値を0や無荷重へ置換しない |
| 材長、lk_y/lk_z、lb | mm | 検定へ渡された材長・座屈長・横座屈長を表示。未指定は不明、非正/非有限は不正/未確定と表示。長さの値だけで拘束の適合を証明しない |
| 等間隔横補剛本数 | 本 | 入力あり（0本も含む）と未指定を区別。補剛剛性、端部・ねじり・反り拘束は未確定 |
| 材料E/F/G、リップ剛性、荷重作用点・せん断中心 | N/mm²、mm⁴、mm等 | 既存材料情報は保持するが、今回耐力式には使用しない。リップ剛性・偏心と拘束の国内耐力式適用条件は未確認 |
| 内外/中心線R、リップ角、孔、左右向き | mm、度等 | 本検定の幾何入力には表現がない。追加入力や推定補完を行わない |

GUIの部材検定表・検定比表示とCSV帳票は、検定比を数値の0ではなく未検定として扱い、
形状・各座屈の未対応・有効断面未算定・適用条件未確定の理由を保持します。
表の冒頭では検定済み位置と検定不能位置を別集計し、検定不能をOK/NG件数に含めません。
保存・再読込やST-Bridgeの形状往復後も、その形状から未対応理由を再生成します。
ST-Bridgeは荷重・補剛属性・解析結果の完全保存形式ではありません。
既存の幾何・材料入力検査は維持し、不正な入力を合格へ置換しません。

分類の公開一次根拠は以下です。ここから耐力式・安全係数は採用していません。

- 日本建築学会発行、三井和也・五十嵐規矩夫「圧縮力が作用する冷間成形溝形断面部材の弾性局部座屈耐力と座屈挙動」、構造系論文集86巻790号、2021年12月、pp.1685–1692、分類はp.1685 §1・Fig.1。[公開本文](https://www.jstage.jst.go.jp/article/aijs/86/790/86_1685/_pdf)。局部・ゆがみとその連成の区別を参照し、論文の弾性局部解を最大耐力へ流用しません。
- American Iron and Steel Institute発行、AISI S100-16 (2020)、Commentary Appendix 2 §2.2.1、本文pp.2-1–2-3（PDF434–436頁）。[公開本文](https://buildusingsteel-media.s3.amazonaws.com/wp-content/uploads/2023/06/23212326/AISI-S100-16-2020.pdf#page=434)。全体座屈の下位モード分類を参照し、海外設計モードを追加しません。

有効幅/幅厚比式の全面実装、国内の耐力式一式、ゆがみ・ねじり/曲げねじり耐力、
全域の許容曲げ応力度、圧縮曲げ相関、面材拘束による耐力上昇は未対応です。
これらの根拠・平板部と無効部分の配置・各拘束条件を確認するまで、一般リップ材の検定済み表示には進めません。

## 対応断面の検定式

S 造柱梁接合部では、検定比を \\( |{}\_p M|/{}\_p M\_y \\) とし、1.0 以下を適合とします。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( \sigma\_{ax} \\) | 軸力による応力度 | N/mm² |
| \\( \sigma\_{by}, \sigma\_{bz} \\) | 強軸・弱軸まわりの曲げ応力度 | N/mm² |
| \\( N \\) | 軸力 | N |
| \\( M\_z, M\_y \\) | 強軸・弱軸まわりの曲げモーメント | N·mm |
| \\( A \\) | 断面積 | mm² |
| \\( Z \\) | 断面係数 | mm³ |
| \\( f\_c \\) | 座屈を考慮した許容圧縮応力度 | N/mm² |
| \\( f\_b \\) | 許容曲げ応力度 | N/mm² |
| \\( f\_t \\) | 許容引張応力度 | N/mm² |
| \\( F \\) | 鋼材の基準強度（F 値） | N/mm² |
| \\( \lambda \\) | 座屈長さと断面二次半径から求める細長比 | - |
| \\( l\_{ky}, l\_{kz} \\) | 強軸・弱軸まわりの座屈長さ | mm |
| \\( i\_y, i\_z \\) | 強軸・弱軸まわりの断面二次半径 | mm |
| \\( C \\) | 横座屈修正係数 | - |
| \\( l\_b \\) | 圧縮フランジの支点間距離（横座屈長さ） | mm |

**算定式（梁）**

軸力・曲げによる応力度:

\\[ \sigma\_{ax} = |N|/A,\quad \sigma\_{by} = |M\_z|/Z,\quad \sigma\_{bz} = |M\_y|/Z\_{\text{弱軸}} \\]

円形鋼管は強軸・弱軸の曲げモーメントを合成した \\( \sigma\_b \\) で代表させます:

\\[ \sigma\_b = \sqrt{M\_z^2 + M\_y^2}/Z \\]

軸力＋二軸曲げの組合せ検定。圧縮時（\\( f\_c \\) は座屈を考慮した許容圧縮応力度）:

\\[ \sigma\_c/f\_c + \sigma\_{by}/f\_b + \sigma\_{bz}/f\_t \le 1.0 \\]

（円形鋼管は \\( \sigma\_c/f\_c + \sigma\_b/f\_b \\)）。引張時:

\\[ (\sigma\_t + \sigma\_{by} + \sigma\_{bz})/f\_t \le 1.0 \\]

（円形鋼管は \\( (\sigma\_t + \sigma\_b)/f\_t \\)）。組合せ検定とは別に、単独曲げの検定 \\( \sigma\_{by}/f\_b \\)（円形鋼管は \\( \sigma\_b/f\_b \\) で代替）・\\( \sigma\_{bz}/f\_t \\) も行い、いずれも検定比として扱います。

許容圧縮応力度 \\( f\_c \\) は、強軸・弱軸それぞれの座屈長さによる細長比のうち大きい方で算定します:

\\[ \lambda = \max(l\_{ky}/i\_y,\ l\_{kz}/i\_z),\quad i\_y = \sqrt{I\_y/A},\quad i\_z = \sqrt{I\_z/A} \\]

（\\( l\_{ky} \\): 強軸まわり座屈長さ、\\( l\_{kz} \\): 弱軸まわり座屈長さ。両者とも部材長のとき \\( \lambda = l\_k/i\_{\min} \\)、\\( i\_{\min} = \sqrt{\min(I\_y, I\_z)/A} \\) に一致します。）

\\( l\_{ky}, l\_{kz} \\) は次の優先順位で解決します: **直接入力（部材単位、`SteelDesignAttr.lk_y_direct`/`lk_z_direct`）＞ 柱の自動算定（軸別座屈長さ係数 K×部材長。[柱の座屈長さ係数 K](03_鋼構造_断面検定.md#柱の座屈長さ係数-k) 参照）＞ 部材長**。直接入力は柱に限らず梁・ブレースでも有効であり、柱の自動算定は柱のみに適用されます。

<div class="impl-ref">

**実装参照**：この優先順位による \\( l\_{ky}, l\_{kz} \\) の解決は `sepika_design_jp::member_design_check::run_member_design_checks`（`crates/sepika-design-jp/src/member_design_check.rs`）が行い、柱の自動算定は `sepika_design_jp::steel::buckling::steel_column_k_axes_with_index` を用います。

**せん断の検定**

せん断応力度は \\( \tau\_y = |Q\_y|/A\_y \\)、\\( \tau\_z = |Q\_z|/A\_z \\) とし、せん断有効断面積 \\( A\_y, A\_z \\) は梁・柱共通の単一定義として断面形状ごとに次式によります:

- 欠損なし標準H 形: \\( A\_y = t\_w(H - 2t\_f) \\)、\\( A\_z = 2Bt\_f/1.5 \\)。フィレット面積は加算しません。
- 角形鋼管（同心円弧・一様厚さ、外角R \\( r\_o\ge t \\)）: \\( A\_y = 2t(H-2r\_o) \\)、\\( A\_z = 2t(B-2r\_o) \\)。対向する直線部だけを用い、円弧面積を加算しません。
- 明示した外角R \\( r\_o=0 \\) の溶接箱: \\( A\_y = 2t(H-2t) \\)、\\( A\_z = 2t(B-2t) \\)。正の角Rを持つモデルとは別の対向板モデルです。
- 円形鋼管: \\( A\_y = A\_z = \pi t (D - t)/2 \\)
- その他の形状: 強軸Qyには断面性能as_z、弱軸Qzにはas_yを用います。各性能が正でなければ、その方向は全断面積Aを代替値として用います。一般軽量形鋼の単一リップ溝形材の未検定条件は別途適用します。

寸法H/B/tと外角Rはmm、面積Ay/Azはmm²、Qy/QzはN、τとfsはN/mm²です。
検定用の \\( (A\_y,A\_z) \\) は強軸Qy・弱軸Qzの順で、剛性用断面性能 \\( (a\_{s,y},a\_{s,z}) \\) の添字順とは異なります。
曲げについては強軸Mzが断面性能Iy、弱軸MyがIzに対応します。

角形鋼管の梁・柱では、外角Rの未知、\\( 0<r\_o<t \\)、両方向いずれかの直線長が0以下、不正寸法、非有限・非正の面積を理由付きの検定不能とします。
負値・NaN・無限大・外角Rの上限超過も拒否し、未知を0にしたり、不成立の長さを丸めたり、未検定を数値0や合格へ置き換えたりしません。
形状を持たず名称だけでBoxに分類された断面も、明示した外角R=0の溶接箱とはみなさず、寸法・外角Rの不足として扱います。
外角Rが断面外形に収まっても、\\( r\_o=\min(H,B)/2 \\) では一方向の直線長が0になるため本検定には適用できません。
この検定モデルの条件は、内角Rを \\( \max(r\_o-t,0) \\) とする断面幾何で\\( 0<r\_o<t \\)を表現することまで禁止しません。
軸力のみを扱うブレース検定は、このせん断面積の適用条件の対象外です。

角形鋼管400×300×12の検定用 \\( (A\_y,A\_z) \\) は、外角R=12で(9024,6624)、外角R=30で(8160,5760)、明示した外角R=0の溶接箱で(9024,6624) mm²です。
外角R=0と12で数値が一致しても、採用モデルの区別は維持します。

検定面積には、前述の方向別面積を採用します。
ウェブ有効率rは欠損なしで1であり、外角Rとは別の記号です。弱軸Hにはκ=1.5を用い、角形鋼管は直線部、溶接箱は対向板、円管はA/2を用います。角形鋼管の式は直線領域の幾何に基づきます。
日本建築学会の規準書本体の全文照合は未完了です。AIJ2005・冷間鋼管2003の本体は未閲覧です。

この \\( A\_y, A\_z \\) は**検定用**の有効断面積です。
要素剛性（ティモシェンコ梁の \\( GA\_s \\)）に用いる \\( a\_{s,y}, a\_{s,z} \\)（[せん断有効断面積 As](../03_断面性能/03_せん断有効断面積_As.md)）とは値が異なります。
H 形では、検定側がウェブの内法せい \\( H - 2 t\_f \\) を用い、フランジ側を 1.5 で除する点が剛性側と異なります。

H形・角形鋼管・その他の形状の柱／梁は、純せん断の方向別検定比を求め、その和で検定します。

\\[ R\_y = \frac{|Q\_y|}{A\_y f\_s},\qquad R\_z = \frac{|Q\_z|}{A\_z f\_s},\qquad R\_{\mathrm{shear}}=R\_y+R\_z \\]

von Mises合成には、各方向のせん断応力度の和を用います。

\\[ \tau\_{\mathrm{sum}}=\tau\_y+\tau\_z=\frac{|Q\_y|}{A\_y}+\frac{|Q\_z|}{A\_z} \\]

方向別比の和とτsumによる接続は、SEPIKAの採用規約です。

各方向のvon Mises比全体を足して軸力・曲げを二重算入する計算は行いません。
円形鋼管はこの加算規約の対象外で、以下に示す合成式を用います。

**von Mises 合成**

H形の梁は、次の2式の大きい方をvon Mises比とします。双方に同じτsumを用い、法線応力はそれぞれの式で評価します。

\\[ R\_{\mathrm{VM,H,beam}}=\max\left(\dfrac{\sqrt{(\sigma\_{ax}+\sigma\_b\')^2+3\tau\_{\mathrm{sum}}^2}}{f\_t},\ \dfrac{\sqrt{(\sigma\_{ax}+\sigma\_{by}+\sigma\_{bz})^2+3\tau\_{\mathrm{sum}}^2}}{f\_t}\right) \\]

ここで \\( \sigma\_{ax}=|N|/A \\)、\\( \sigma\_{by}=|M\_z|/Z\_{\mathrm{strong}} \\)、\\( \sigma\_{bz}=|M\_y|/Z\_{\mathrm{weak}} \\) です。
H梁の強軸断面係数には、設定された欠損の控除を適用します。
ウェブ端の曲げ応力度は \\( \sigma\_b\' = \sigma\_{by}\max(H-2t\_f,0)/H \\) とします。

角形鋼管とその他の形状の梁は、次式を採用します。この一般形状への適用を、任意断面での安全側の保証とはしません。

\\[ R\_{\mathrm{VM,Box/Other,beam}}=\sqrt{(\sigma\_{ax}+\sigma\_{by}+\sigma\_{bz})^2+3\tau\_{\mathrm{sum}}^2}/f\_t \\]

円形鋼管の梁は、中立軸位置の式を用います（曲げ応力度の寄与はありません）。円形鋼管の純せん断比も方向別比の最大値を用い、上記の和へ置き換えません。

\\[ \sqrt{\sigma\_{ax}^2+3(\tau\_y^2+\tau\_z^2)}/f\_t \\]

梁の検定比は、上記の組合せ検定・単独曲げ検定・せん断検定・von Mises 合成の各比のうち最大値とします。
柱の法線応力と集約式は後述の「算定式（柱・ブレース）」に示します。

日本建築学会の規準書本体への全面適合や、任意断面に対する安全性を確認済みとするものではありません。

**許容曲げ応力度 fb（横座屈、H 形の強軸のみ考慮。他形状は \\( f\_b = f\_t \\)）**

ライブラリ API 内部では、鋼構造設計規準 1973 年版（`Standard1973`）と鋼構造許容応力度設計規準 2019 年版（`Asd2019`）を指定できます。ただし、通常の App / MCP の断面検定では `SteelFbBasis::default()` により `Asd2019` を使用し、現状は UI・MCP・モデル設定から `Standard1973` を選択できません。

圧縮フランジの支点間距離（横座屈長さ）\\( l\_b \\) は、次の優先順位で解決します: **直接入力（部材単位、始端・中央・終端の区間別）＞ 等間隔横補剛本数 \\( n \\) による自動算定 \\( l\_b = L/(n+1) \\) ＞ 部材長 \\( L \\)**。区間別の直接入力は、評価位置に応じて始端側（部材軸方向の無次元位置 0.25 未満）・中央（0.25〜0.75）・終端側の値を用います。

`Standard1973`:

\\[ f\_b = \max(f\_{b1}, f\_{b2}) \le f\_t \\]

\\[ f\_{b1} = F(2/3 - (4/15)(l\_b/i)^2/(C \cdot \Lambda^2)) \\]

\\[ f\_{b2} = 89000/(l\_b \cdot h/A\_f) \\]

断面二次半径 \\( i \\) は、圧縮フランジと、せいが部材せいの 1/6 のウェブからなる T 形断面で算定します（ウェブ部の高さは \\( \max(h/6 - t\_f,\ 0) \\)）。上下フランジの形状が異なる組立 H 形（BH）は、どちらが圧縮側か特定できないため、上下フランジそれぞれで求めた T 形断面のうち \\( i \\) が小さい側を安全側として採用します。

`Asd2019`（AIJ-ASD19）:

\\[ M\_y = F \cdot Z,\quad M\_e = C\sqrt{\dfrac{\pi^4 E I\_z E I\_w}{l\_b^4} + \dfrac{\pi^2 E I\_z G J}{l\_b^2}} \\]

\\[ \lambda\_b = \sqrt{M\_y/M\_e},\quad {}\_e\lambda\_b = 1.29,\quad \nu = 3/2 + (2/3)(\lambda\_b/{}\_e\lambda\_b)^2 \\]

\\[ f\_b = \begin{cases} F/\nu & (\lambda\_b \le {}\_p\lambda\_b) \\\\ \left(1 - 0.4\dfrac{\lambda\_b - {}\_p\lambda\_b}{{}\_e\lambda\_b - {}\_p\lambda\_b}\right)F/\nu & ({}\_p\lambda\_b < \lambda\_b \le {}\_e\lambda\_b) \\\\ F/(2.17\lambda\_b^2) & ({}\_e\lambda\_b < \lambda\_b) \end{cases} \\]

長期の上限は \\( F/1.5 \\)、短期は長期の 1.5 倍（上限 \\( F \\)）とします。塑性限界細長比 \\( {}\_p\lambda\_b \\) は、横補剛区間内で曲げモーメントが最大となる場合は 0.3、区間内で単調に変化する場合は \\( 0.6+0.3(M\_2/M\_1) \\)（\\( M\_2/M\_1 \\) は複曲率で正・単曲率で負）とします。端部モーメントの情報がない場合は安全側の 0.3 とします。

曲げねじり定数 \\( I\_w \\) は、H 形で \\( I\_w = I\_z (h - t\_f)^2/4 \\)、上下フランジの形状が異なる組立 H 形（BH）で \\( I\_w = h\_f^2 \cdot I\_u I\_l/(I\_u + I\_l) \\)（\\( h\_f \\): 上下フランジ重心間距離、\\( I\_u, I\_l \\): 上下フランジ単独の弱軸まわり断面二次モーメント）とします。せん断弾性係数 \\( G \\) は材料に入力があればその値、なければ \\( E/(2(1+\nu)) \\) によります。サンブナンのねじり定数 \\( J \\) は断面性能のねじり定数を用います。

部分補剛区間で区間端部モーメントを入力・復元できない場合は、端部モーメント比によらず安全側の pλb=0.3 とします。全長区間では端部モーメントが利用できる場合に既存の M2/M1 式を用い、情報がない場合は安全側の 0.3 とします。

横座屈修正係数（両基準に共通）:

\\[ C = 1.75 + 1.05(M\_2/M\_1) + 0.3(M\_2/M\_1)^2 \le 2.3 \\]

\\( M\_1 \\) は座屈区間両端の強軸曲げモーメントの絶対値が大きい方、\\( M\_2 \\) は小さい方で、\\( M\_2/M\_1 \\) は複曲率（反曲点あり）で正・単曲率で負とします。自動算定では次の場合に安全側の値を用います:

- 座屈区間中央の曲げモーメントが両端より大きい（区間内で最大となる）場合は \\( C = 1.0 \\)。
- 横補剛により座屈区間 lb が部材の部分区間となる場合は、区間端モーメント比が不明なため自動算定の \\( C = 1.0 \\)。
- 端部モーメントの情報がない場合は \\( C = 1.0 \\)（もっとも不利な等曲げ分布相当）。

横座屈修正係数 C は、`SteelDesignAttr.c_direct` により部材単位で直接入力できます（正値。0 以下は無効入力として無視します）。入力がある場合は自動算定（上記の \\( M\_2/M\_1 \\) 式・上限 2.3・安全側の \\( C=1.0 \\) 規定）を行わず入力値をそのまま採用します。したがって部分補剛区間でも正値の `c_direct` が優先されます。

**断面欠損を考慮した断面係数 Z′（H 形の強軸曲げ）**

継手部の欠損率 \\( \beta\_f \\)（フランジ [%]）・\\( \beta\_w \\)（ウェブ [%]）、端部スカラップによるウェブ欠損率 \\( \alpha\_w \\) [%] が部材に入力されている場合、H 形の強軸曲げ応力度は欠損を考慮した断面係数 \\( Z\' \\) で算定します。全断面の強軸断面二次モーメントをフランジ寄与分 \\( I\_f = (B H^3 - B(H-2t\_f)^3)/12 \\) とウェブ寄与分 \\( I\_w = t\_w (H-2t\_f)^3/12 \\) に分解し:

\\[ I\_f\' = I\_f (1 - \beta\_f/100),\quad I\_w\' = I\_w (1 - \beta\_w/100) \\]

端部（評価位置が部材軸方向の無次元位置 0.25 以下または 0.75 以上）は、スカラップを考慮したウェブ寄与分に置き換えたうえで \\( \beta\_w \\) も乗じます:

\\[ I\_w\'\' = \frac{t\_w \{(H-2t\_f)(1-\alpha\_w/100)\}^3}{12} (1 - \beta\_w/100) \\]

\\[ Z\' = (I\_f\' + I\_w\')/(H/2) \\]

（端部は \\( I\_w\' \\) を \\( I\_w\'\' \\) に置き換えます。）

**参考情報（検定比に含めない）**

梁の検定では、次の 2 項目を検定比に含めない参考情報として併記します。

- **大梁の必要横補剛数**（保有耐力横補剛・均等配置の参考本数）:
  [大阪府『構造計算適合性判定指摘事例集』2021年版・2023年一部改正版、4.1.6-2 式(3a)(3b)](https://www.pref.osaka.lg.jp/documents/35034/05_a41kakusyukouzounosekkei_1.pdf)に掲載された、400/490ニュートン級炭素鋼の均等配置式を採用します。
  弱軸細長比 \\( \lambda\_y = L/i\_y \\)（\\( i\_y = \sqrt{I\_z/A} \\)、\\( I\_z \\): 弱軸の断面二次モーメント、\\( A \\): 断面積）に対し、
  400ニュートン級は \\( \lambda\_y \le 170 + 20n \\)、490ニュートン級は \\( \lambda\_y \le 130 + 20n \\) を満たす最小非負整数を必要本数とします。
  すなわち \\( n = \max(0,\lceil(\lambda\_y-c)/20\rceil) \\)（400ニュートン級: \\( c=170 \\)、490ニュートン級: \\( c=130 \\)）です。
  出典では \\( L \\) を柱間の内法実長（節点間距離によることも可）としています。本機能は柱間の節点間全長を採用し、内法長、横座屈長さ \\( l\_b \\)、中間節点による解析分割長では代替しません。長さの単位をmmに揃えると \\( \lambda\_y \\) は無次元です。
  対象材種は400級のSS400、SN400/SN400A/B/C、SM400/SM400A/B/Cと、490級のSS490、SN490/SN490B/C、SM490/SM490A/B/C/YA/YBです。裸のSN400/490・SM400/490はアプリ内の材種系列名で、完全なJIS種類記号ではありません。基準強度 \\( F \\) の数値から400/490級を推定せず、板厚で \\( F \\) が変わってもこの区分は変わりません。未知材種、任意の接尾辞、SM400YA/YB、BCP/BCR/TMCPや520級は対象外です。
  明示したH形鋼（SteelH）の大梁で、柱間の両外端がFixed/Fixedの場合だけ参考数を返します。断面符号からの形状推定、BuiltH、鋼管、非対称断面、片端ピン、半剛接、片持ち、用途不明は今回の対象外です。この限定は参考機能の採用範囲であり、それらの構造形式が成立しないという意味ではありません。
  単一の2節点大梁は、両端の同一節点IDへ明示した柱用途の実線材が接続する場合に柱間全長とします。一本部材指定の分割大梁は、全区間が節点で連続し、折返しがなく共線で、両外端に柱があり、内部節点に柱がないことを確認します。ID欠落や重複所属、非連続・非共線、複数柱間、外端条件の不足などがあれば、単一の分割要素へ戻さず全体を算定不能とします。
  有効な分割大梁では全区間に柱間全長を適用し、最大必要数と支配要素・断面・材種・細長比を一組で表示します。同数の場合は指定順で先の区間を採用します。一つでも未確認の区間があれば全体を算定不能とします。モデルに表現された区間断面だけを評価し、未表現の断面変化やハンチ部の断面性能は検証しません。
  断面積 \\( A \\)、弱軸 \\( I\_z \\)、柱間全長 \\( L \\)、H寸法、強度入力と途中計算の有限性・正値を確認します。既存の弱軸 \\( I\_z \\) 規約が不整合な場合に他の軸へ入れ替えません。不正入力や整数上限超過は理由付き算定不能とし、0本には置換しません。参考数の可否は曲げ・せん断の検定比や合否集計から分離され、有効な既存検定を消しません。表示が0本でも横補剛不要や適合の証明にはなりません。
  実際の補剛配置、補剛材・接合部の耐力と剛性、力の伝達は別途確認が必要です。許容曲げ応力度の横座屈長さ \\( l\_b \\) の算定・検定とも区別し、本数表示だけでは保有耐力横補剛の適合を意味しません。
- **たわみ**（長期のみ）: モーメント図を 2 次曲線分布（等分布荷重相当）と仮定し、単純梁中央モーメントを \\( M\_0 = |M\_c| + (|M\_L| + |M\_R|)/2 \\)（\\( M\_c \\): 部材中央、\\( M\_L, M\_R \\): 両端の曲げモーメント）として

\\[ S = \frac{5 M\_0 l^2}{48EI} - \frac{(M\_L + M\_R) l^2}{16EI} \\]

を算定しますが、変形制限（例: \\( l/300 \\)）による合否判定は行わず、算定値の出力のみとします。
分割された梁要素を一本の梁として扱う場合、中央モーメント \\( M\_c \\) は A 式（端部せん断と釣り合う等分布荷重の単純梁中央モーメントから端部モーメントの平均を差し引いた復元値）と B 式（グループ中央位置に最も近い評価行のモーメント）の絶対値の大きい方（符号は B 式に合わせる）とします。

**算定式（柱・ブレース）**

柱（座屈考慮 fc）:

\\[ \sigma\_c/f\_c + \sigma\_{bX}/f\_{bX} + \sigma\_{bY}/f\_{bY} \le 1.0 \\]

- ブレース: 圧縮 \\( \sigma\_c/f\_c \\)、引張 \\( \sigma\_t/f\_t \\)

柱の \\( f\_{bX} \\)（H 形強軸）も、梁と同じ許容曲げ応力度 fb の算定式（`Standard1973`・`Asd2019` の選択、横座屈修正係数 C の直接入力を含む）によりますが、lb には柱の階高（`ctx.length`）を用います。

H形・角形鋼管・その他の形状の柱も、梁と共通のAy/Azを用い、純せん断比は \\( R\_{\mathrm{shear}}=R\_y+R\_z \\)、von Misesへのせん断応力度は \\( \tau\_{\mathrm{sum}}=|Q\_y|/A\_y+|Q\_z|/A\_z \\) とします。
柱のvon Misesに用いる法線応力は、次の部材別の式です。

\\[ \sigma\_{\mathrm{H,column}}=\frac{|N|}{A}+\frac{|M\_z|}{Z\_{\mathrm{strong}}}\frac{\max(H-2t\_f,0)}{H} \\]

\\[ \sigma\_{\mathrm{Box/Other,column}}=\frac{|N|}{A}+\frac{|M\_z|}{Z\_{\mathrm{strong}}}+\frac{|M\_y|}{Z\_{\mathrm{weak}}} \\]

柱では \\( Z\_{\mathrm{strong}}=I\_y/(H/2) \\)、\\( Z\_{\mathrm{weak}}=I\_z/(B/2) \\) を用い、上記σを次式へ代入します。

\\[ R\_{\mathrm{VM,column}}=\frac{\sqrt{\sigma^2+3\tau\_{\mathrm{sum}}^2}}{f\_t},\qquad R\_{\mathrm{Shear,column}}=\max(R\_{\mathrm{VM,column}},R\_{\mathrm{shear}}) \\]

H柱のvon Mises用σはウェブ端の強軸曲げを用い、弱軸曲げを含むH梁の第2ケースとは異なります。
τsumは共通ですが、法線応力の評価式は柱と梁で異なります。軸力・二軸曲げの独立検定は別に行い、柱全体の検定比はその比と上記せん断検定比の最大値です。
H柱・H梁の法線応力と断面内評価位置の適合性は未検証です（追跡先: [#692](https://github.com/hrntsm/SEPIKA/issues/692)）。

円形鋼管の柱は合成 \\( \tau=\sqrt{Q\_y^2+Q\_z^2}/A\_y \\)（Ay=Az）と \\( \sigma=|N|/A+\sqrt{M\_z^2+M\_y^2}/Z\_{\mathrm{strong}} \\) を用い、\\( \max(\sqrt{\sigma^2+3\tau^2}/f\_t,\tau/f\_s) \\) とします。円形鋼管柱のσは、円形鋼管梁の中立軸位置の式とも異なります。

## 柱の座屈長さ係数 K

構造耐力上主要な圧縮材には、令第65条の有効細長比上限（柱200以下、柱以外250以下）が適用されます。
本機能は有効細長比による許容圧縮応力度の低下を計算しますが、この上限の適否は自動判定しません。応力度の検定比が1.0以下でも、上限を満たすことを別途確認してください。

柱の座屈長さ係数 K を、鋼構造塑性設計指針 式(6.65)〜(6.67)に基づいて算定します。
水平移動非拘束（sway）を前提とし、強軸まわり K_y・弱軸まわり K_z を個別に評価します。

**算定式**

\\[ \frac{G\_A \cdot G\_B \cdot x^2 - 36}{6(G\_A + G\_B)} = \frac{x}{\tan(x)} \\]

\\[ x = \pi/K \\]

（\\( K \ge 1 \\)）

\\[ G\_a = \sum (E \cdot I\_{\text{eff}}/L)\_{\text{柱}}/\sum (E \cdot i\_y \cdot \cos^2\theta/L)\_{\text{梁}} \\]

（\\( a \in \{y(\text{強軸}), z(\text{弱軸})\} \\)）。ピン端・取付部材なしは \\( G\_a = 10 \\) とします。

**軸別評価**

柱・梁それぞれの局所軸から、評価方向（強軸 y または弱軸 z のたわみ方向）の水平投影単位ベクトルを求め、次の重みで G を軸ごとに集計します:

- 梁: 梁材軸の水平投影と評価方向のなす角の余弦の 2 乗 \\( \cos^2\theta \\) を \\( E \cdot i\_y/L\' \\) に乗じます（面内（鉛直面）曲げは強軸 \\( i\_y \\) とする仮定を維持し、角度のみ重み付けします）。評価方向に平行な梁が節点回転をもっとも拘束し、直交する梁は寄与しません。当該節点側の梁端が \\( \text{Pinned} \\) の場合、その梁は節点回転を拘束しないため G の梁側の集計に算入しません（`SemiRigid` は剛接合とみなします）。
- 柱（評価対象の柱自身を含む）: その柱自身の強軸たわみ方向と評価方向のなす角 \\( \cos^2\beta \\) により、断面二次モーメントを \\( I\_{\text{eff}} = I\_y \cdot \cos^2\beta + I\_z \cdot (1-\cos^2\beta) \\) へ投影します（評価対象の柱自身は \\( \cos^2\beta=1 \\) となり \\( I\_y \\)（強軸側）／\\( I\_z \\)（弱軸側）にそのまま一致します）。
- 部材種別は `FrameSectionUse` から解決した `MemberKind` を用います。`Brace` は剛度比から除外し、`Girder`・`Column` は傾斜していても用途どおりに集計します。部材軸の鉛直成分は、部材種別の分類ではなく、各評価方向への水平投影の重み付けにだけ用います。
- \\( L\' \\) は柱・梁とも剛域控除後の内法長（\\( L\' = \\) 節点間長さ \\( - \\) 始端剛域長 \\( - \\) 終端剛域長。\\( L\' \le 0 \\) となる場合は節点間の幾何学的長さにフォールバックする）。

評価方向の水平投影が縮退する（部材がほぼ鉛直で水平方向が定まらない）軸は、方向を区別しない評価（\\( I\_y \\) を全部材で用いる簡略版と同じ G）にフォールバックします。方向を区別しない簡略版は、梁の結合状態（ピン接合を含む）を考慮せず、剛域による材長補正も行いません。

いずれの版も、支点（節点の境界条件）の状態・梁の遠端の結合状態は考慮しません。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( K \\) | 柱の座屈長さ係数 | - |
| \\( G\_A, G\_B \\) | 柱頭・柱脚節点における柱と梁の剛度比 | - |
| \\( E \\) | ヤング係数 | N/mm² |
| \\( I\_{eff} \\) | 評価方向へ投影した柱の有効断面二次モーメント | mm⁴ |
| \\( i\_y \\) | 梁の強軸まわりの断面二次モーメント | mm⁴ |
| \\( L, L\' \\) | 部材長・剛域控除後の内法長 | mm |

<div class="impl-ref">

**実装参照**：`sepika_design_jp::steel::buckling`（`crates/sepika-design-jp/src/steel/buckling.rs`）が算定します。方向を区別しない簡略版は `steel_column_k`／`steel_column_k_with_index` です。

</div>

**梁・ブレースの座屈長さ**

梁・ブレースは座屈長さ係数 K の自動算定を行わないため、直接入力がない場合は部材長（節点間の距離。K=1 相当）を座屈長さとします。K 係数法（水平移動非拘束の骨組の剛度比）は柱のみに適用されます。

**実装参照**：部材種別に基づく軸別の座屈長さ係数は `sepika_design_jp::steel::buckling::steel_column_k_axes_with_index`（`crates/sepika-design-jp/src/steel/buckling.rs`）が算定し、梁・ブレースの座屈長さも `sepika_design_jp::member_design_check::run_member_design_checks`（`crates/sepika-design-jp/src/member_design_check.rs`）が直接入力を優先し、直接入力がなければ部材長を座屈長さとします。

## S 造柱梁接合部

S 造柱梁接合部を、採用柱の強軸・弱軸に対応する2方向で検定します。以下の降伏耐力式を用いますが、H 形柱の弱軸側はフランジ2枚の純せん断モデルであり、曲げ等による耐力低下は含みません。原典適合・実接合部の妥当性を確認したモデルではなく、耐力を過大評価する可能性があります。[弱軸側の近似](../04_要素剛性/06_パネルゾーン.md)も確認してください。

**算定式**

\\[ {}\_p M\_y = (V\_e/\kappa) \cdot \sqrt{\max(0, 1 - n^2)} \cdot F\_y/\sqrt{3} \\]

**降伏耐力と適用根拠**

上式は降伏耐力の評価式であり、接合部の全塑性耐力・最大耐力と同一ではありません。N・A・Fの組合せ、H形・鋼管・CFT、異厚・補強・接合詳細ごとの原典適合は未確認です。せん断抵抗板の実板厚からFを選べることだけでは、そのFと柱全断面積の積を軸耐力に使えることを保証しません。

『2025年版 建築物の構造関係技術基準解説書』第2版第1刷（2026年2月11日）、§6.3.4、pp.402–403は、パネルの早期降伏を直ちに架構耐力喪失とせず、パネル降伏を無視する保有水平耐力の評価にはパネル部・近傍接合部が早期破断しない条件を示しています。この説明は上記の降伏式や全塑性相関式の定義ではなく、非線形ばね・二次勾配・変動軸力の妥当性を保証するものでもありません。同節pp.394–395の柱梁耐力比に用いる接合部の最大曲げモーメントも、上式の降伏耐力へ自動的に置換しません。

CFTについて同書§3.10.11 p.237は仕様規定の概要を示し、設計の参考文献として『コンクリート充填鋼管(CFT)造技術基準・同解説』（2012.8）と『同解説の運用及び計算例等』（2024.1）を挙げています。この節にはパネルのN・A・Fと耐力式の定義がなく、鋼管部分が鉄骨造の規定によることだけをもって、部材全軸力と鋼管のA・Fによる本検定の妥当性を確認済みとはしません。

**検定する接合部**

取り付く**柱・梁がすべて S 造**（CFT を含む）で、**下側優先で採用した柱の諸元を解決できる**柱梁接合部を検定します。構造種別は材料の区分で決まります（[構造種別の判定](../02_材料/05_構造種別の判定.md)）。RC/SRC の柱や梁が
1 本でも取り付く接合部は、S 造柱梁接合部の式が前提とする挙動から外れるため、この式では検定しません。採用柱が組立 H 形などの未対応断面の場合は理由付きエラーとし、他の解決可能な柱へ切り替えて検定成功にしません。
RC/SRC を含む接合部は RC 柱梁接合部・SRC 柱梁接合部の断面算定が担います。斜材（ブレース等）は
この判定の対象外です。

仕口パネル要素のモデル化対象は S 造（CFT を除く）で、CFT 柱を 1 本でも含む接合部はモデル化しません。一方、柱梁接合部の断面算定は S 造（CFT を含む）を対象とします。CFT の接合部は仕口パネル要素を生成せず、柱梁接合部の検定では鋼管の諸元を上記の降伏式へ代入します。充填コンクリートの耐力寄与、軸力分担、鋼管断面積と基準強度の組合せを含む式の適用根拠は未確認です（[仕口パネル要素](../04_要素剛性/06_パネルゾーン.md)）。

**諸元**

対象梁は材軸水平・直交化したせい方向±Zに限定します。横倒し、斜め断面回転、勾配梁、鉛直Girderは理由付き未対応です。−Zを向く組立Hは上下板厚を全体座標の上下へ対応させます。

梁はH形鋼・組立H形の形状寸法からフランジ板厚中心位置を解決し、元の梁構面で相対する上下両位置が一致するときに限り標準形式を適用します。片側梁は既存の対象条件を保持し、直交梁は別構面に分けます。さらに、同じ柱主軸へ幾何的に非零の寄与を持つ構面間でも、上下のフランジ中心位置がそれぞれ一致する必要があります。瞬間的な応力が0でも、この参加条件を変えません。独立した整列直交構面は方向別の高さを用いるため、梁せいが異なることだけで両方向を停止しません。位置の局所数値公差・段違いの未対応条件・解除に必要な原典と入力条件は[標準形式の適用範囲](../04_要素剛性/06_パネルゾーン.md)を参照してください。

全梁が一つの構面を構成し、一方の柱主軸へ梁曲げの寄与がない場合も、強軸・弱軸の2方向の仕口パネルを評価します。その方向の高さは唯一の梁構面から定め、標準形式が未確認のまま0需要の適合とはしません。

不正寸法・非H梁・位置不一致の構面が寄与する柱主軸は、接合部と不足条件を示す「未算定」とします。外寸やdbの一致だけで適合にせず、設計用パネルモーメントを取得しても未対応形状へ耐力式を適用しません。GUI・MCP・帳票では方向別の検定不能と理由を保持し、一方向でも未算定を含む接合部を全適合としません。上下位置が未検証のdb単独数値入力も未算定です。

複数の梁構面に入力不備がある場合は、不足条件を落とさないため補足の入力診断行を表示することがあります。これは追加の仕口パネルの耐力評価ではありません。

H 形鋼・角形鋼管・円形鋼管では、方向別の柱寸法・抵抗板・形状係数を[仕口パネル要素](../04_要素剛性/06_パネルゾーン.md)と同じ柱断面から求めます。H 形柱は強軸側のウェブ1枚、弱軸側のフランジ2枚を用い、弱軸側は `dc = フランジ幅`、`tp = フランジ1枚の厚さ`、`Ve = 2 dc db tp`、`κ = 1.5` とします。明示されたパネル板厚は抵抗板1枚あたりの有効厚です。基準強度の板厚区分は有効厚と区別し、強軸側の実ウェブ厚・弱軸側の実フランジ厚・鋼管の実壁厚から選びます。既知鋼種は鋼種と実板厚の表を優先し、適用範囲外を直接指定値で補いません。未知の材料名は、割当材料が鋼材で基準強度の直接指定値が正の有限値なら、その値を用います。材料の欠落・不正を既定強度で補いません。
柱由来の諸元・材料・軸力は、[仕口パネル要素の参照柱の規則](../04_要素剛性/06_パネルゾーン.md)に従い、物理的な下側柱を優先し、下側柱が存在しない場合だけ上側柱を採用します。実効体積や入力順では選びません。採用柱の接合部側の軸力と、その柱の断面・材料から `d_c`・`t_p`・`κ`・軸力比 `n`・基準強度 `F_y` をそろえます。採用側を一意に特定できない場合や必要情報が欠落・不正の場合は、接合部と理由を示すエラーとし、上側柱やゼロ軸力で補って検定成功にしません。仕口パネル要素を生成しない CFT では、以下のとおり柱梁接合部の断面算定専用の諸元として解決します。

**CFT 柱梁接合部の諸元**

CFT の `V_e` は、充填コンクリートを含む等価断面の体積ではなく、鋼管の断面形状から求める柱梁接合部の実効体積です。CFT 角形の強軸側は `d_c = せい − 板厚`、弱軸側は `d_c = 幅 − 板厚`、CFT 円形の両軸は `d_c = 外径 − 板厚` とし、`t_p` は入力された「パネル板厚 tp」を優先し、未入力なら鋼管の板厚を用います。`d_b` はその主軸へ寄与する構面間で上下位置が一致した梁フランジ板厚中心間距離です。H梁は形状外寸 `D − tf`、組立H梁は `D − (tf上 + tf下)/2` です。いずれも `V_e = 2 d_c d_b t_p` とします。

CFT の `κ` は鋼管の形状係数で、ここで `b_c` は評価方向と直交する外寸（強軸側は幅、弱軸側はせい）です。角形は `1/(2/3 + 2 b_c/d_c) + 1/(1 + d_c/(3 b_c))`、円形は `4/π` です。CFT の `n` は、検定対象柱の解析軸力のうち圧縮側を、鋼管の基準強度 `F_y` と CFT 断面データの鋼管断面積 `A` の積で除した柱梁接合部用の軸力比です。引張側は `n = 0` とし、`n` は 1.0 でクランプします。

CFT の `F_y` は、CFT 柱に割り当てた鋼管専用材料の鋼種名と実壁厚、または正の有限値の直接指定から解決します。未設定・不正・範囲外・解決不能の材料を既定強度で補いません。これは充填コンクリートの `F_c` や CFT の等価断面性能から求める値ではありません。

CFT 柱梁接合部の降伏耐力は、上記の算定式にこの専用諸元を代入して求めます。柱梁接合部の断面検定には降伏耐力比の下限を設けず、軸力比が1以上では降伏耐力を0、検定比を無限大とします。非線形要素の設定可能域の制限とは区別します。

**柱梁接合部の設計用モーメント**

需要は同一状態の符号を保って柱の強軸・弱軸へ集約し、集約後の絶対値を各方向の降伏耐力と比較します。梁方向ごとの仮想の仕口パネルや、近い主軸への振分けは用いません。複数構面が同じ主軸へ寄与する場合は加算・相殺を含めて合成します。

解析のパネルせん断モーメントがある場合は、[柱主軸と全体座標の変換](../04_要素剛性/06_パネルゾーン.md)の \\( \boldsymbol{MS}=\boldsymbol A^{\mathsf T}\boldsymbol m \\) から、\\( \boldsymbol m=\boldsymbol A^{-\mathsf T}\boldsymbol{MS} \\) によって柱2主軸の需要を復元します。梁高さによる需要の倍率補正は行いません。有限で非退化の逆変換が必要です。傾斜柱の \\( \boldsymbol A \\) は直交行列として扱いません。解析で用いる共通最大dbと、その検定軸へ寄与する梁のフランジ中心間距離が異なる場合は、容量の実幾何との対応が未確認のため当該方向を未算定とします。

解析のパネルせん断モーメントがない場合は、鉛直柱に限り、梁端曲げモーメントと柱端力から組み立てます。梁端モーメントは局所軸から全体座標へ変換し、要素の節点抵抗モーメント（Ku）の符号へそろえます。各梁構面の面内曲げ成分を符号付きで柱主軸へ合成した後、その方向のフランジ中心間距離dbによる柱端力の補正を一度だけ加えます。同じ柱の補正を梁構面ごとに繰り返しません。材端内部モーメントの節点側端がi端なら−1、j端なら+1を乗じます。

**解析のパネルせん断モーメントを持たない非鉛直柱の材端力組立は未対応であり、理由付き未算定とします。** 鉛直柱用の高さ方向・腕長を傾斜柱へそのまま適用した結果を、適合や安全側の評価に用いません。柱断面だけが梁方向に対して回転した鉛直柱は、この制限の対象ではありません。

**検定の実施可否はパネルのモデル化・設計用モーメントの取得の有無に依らず、最初に幾何の適用条件で判定します。** 梁・柱応力が未取得の場合も、0で補って適合にしません。

## 冷間成形角形鋼管柱の柱梁耐力比

冷間成形角形鋼管柱の柱梁耐力比を、2008年版「冷間成形角形鋼管の柱に用いる角形鋼管設計・施工マニュアル」に基づいて算定します。
