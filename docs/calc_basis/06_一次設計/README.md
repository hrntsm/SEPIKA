# 許容応力度・部材検定

本章でいう「一次設計」は、材料の許容応力度、および RC・S・SRC・CFT 部材の断面検定（曲げ・せん断・軸力・付着・接合部・座屈長さ）をまとめる実務上の章分類です。
法令上の「許容応力度等計算」は建築基準法施行令第82条の6に規定され、同条第1号は第82条各号、第82条の2および第82条の4によることを求めています。
そのため、本章では許容応力度等計算を第82条の6に対応づけつつ、荷重組合せ等の個別の説明では第82条各号等への参照を残します。部材の許容応力度は令第89〜91条・98条に、断面算定は各学会規準（RC規準・鋼構造設計規準）に依拠します。
[小梁・床の断面検定](./05_小梁・床の断面検定.md)は、固定＋用途別積載に対する独立した長期略算です。
全体FEMに含めないことは、令第1条第3号・第82条の構造安全対象からの免除を意味しません。

**荷重継続時間と検定範囲**

保存組合せの係数と荷重ケース種別から長期・短期を判定します。名称は許容値を決めません。
常時G+Pと多雪0.7Sは長期、Sと風・地震の組合せは短期です。
任意係数・その他の荷重種別・地震重量用積載の混用など一意に判定できない条件は理由付き未検定です。
荷重ケース単体は種別により継続時間を表示し、直前の選択状態を引き継ぎません。
単独の雪・風・地震表示では主架構の組合せ検定は未実施です。G+Pを含む保存組合せを選択してください。
小梁・床の表は長期略算として表示し、選択した短期等の検定済みを意味しません。

法令組合せ、部材内力の単位、積載用途別入力、多雪・風の適用条件と未確認原典は[荷重組合せ](../01_荷重/04_荷重組合せ.md)を参照してください。

## 検定に必要な入力と実行

主架構では、断面形状・寸法と材料を部材に割り当て、断面編集の「主架構用途」を柱・梁・ブレースから指定します。傾斜部材もこの用途で扱い、見た目の鉛直・水平から用途を推定しません。用途の欠落・部材との不整合は入力不備です。RC/SRCの配筋、SRC内蔵鉄骨・CFT鋼管の専用材料など、材種ごとの必須条件は各ページで確認してください。

準備計算と解析を実行し、設計タブで対象の荷重ケース又は保存組合せを選んで断面検定を実行します。地震時設計用せん断の方式と付着・定着の方式はRC/SRC/CFTの各説明に従います。選択していない組合せの包絡検定を意味しません。架構を選択せず床小梁だけを検定する場合の条件は[小梁・床](05_小梁・床の断面検定.md)を参照してください。

| 検定対象 | 需要・入力 | 得られる判定と範囲 |
| --- | --- | --- |
| RC・鋼・SRC・CFTの主架構 | 選択した状態の解析断面力、材料・断面・配筋 | 危険断面ごとの対応する応力度・耐力比。接合部・構造規定は各適用範囲による |
| 鋼小梁 | 固定＋小梁用積載、支持条件、分配荷重・断面 | 曲げ・たわみの長期略算。せん断力は表示値で、せん断耐力の合否は未判定 |
| 床板 | 固定＋床用積載、板厚・スパン | 一方向版の設計曲げ・必要鉄筋量。実配筋の合否は未判定 |
| BRB | 選択状態の軸力、製品の許容軸力・限界長・端部低減 | 軸力比と座屈長さ比。履歴特性・接合詳細は別途確認 |

## 危険断面と長さの意味

| GUIの表示・入力 | 力学的な意味と採用条件 |
| --- | --- |
| 準備計算の「材長 L [mm]」 | 部材両端の節点間距離。断面用途や剛域の設定とは別の幾何長 |
| 「フェース i/j [mm]」 | 節点芯から接合する部材の面までの距離。断面検定の端部位置を定める。未算定の端は節点芯を用いる |
| 危険断面・検定位置 | 原則はi側フェース、部材中央、j側フェース。部材詳細にハンチ端・継手等があれば追加位置も含む。i→jを0→1とする位置表示。節点芯とフェースが異なる端では芯の内力を端部検定へ流用しない |
| 内法スパンl′・内法高さh′ | 地震時設計用せん断やRC長期たわみで使う、材長から両端のフェース距離を引いた長さ。正の長さが取れない場合は節点間長さを用いる。一本部材は両外端間の長さを用いる |
| 「λi [mm]」「λj [mm]」「可とう長 L' [mm]」 | 各端の剛域長と、採用する剛体アーム長を両端で控除した表示値。剛体アーム長は各端の剛域長と「パネル i/j [mm]」のオフセットの大きい方で、「剛域を考慮する」がOFFなら剛域長を除外する。[準備計算の剛域](../../preparation/04_剛域.md)を参照。フェース間内法長とも、下記の鋼柱K算定用長さとも区別する |
| 鋼柱K算定の剛度比に用いる長さ | 材長から、保存された剛域長と仕口パネルオフセットの大きい方を各端で控除する。準備計算表と異なり「剛域を考慮する」のOFFを反映せず、控除後が1×10⁻⁶ mm以下なら材長を用いる。詳細は[柱の座屈長さ係数K](03_鋼構造_断面検定.md#柱の座屈長さ係数-k)を参照 |
| 「座屈長さ lk_y(強軸)直接入力[mm]」「lk_z(弱軸)直接入力[mm]」 | 各方向の曲げ座屈に対する有効長。柱は直接入力、軸別K×材長、材長の順に採用し、梁・通常ブレースは直接入力がなければ材長を使う |
| 「横座屈長さ lb 直接入力[mm]」の始端・中央・終端、「等間隔横補剛本数」 | 圧縮フランジの横座屈区間長を指定する鋼梁用条件。曲げ座屈長lkや内法長と同一ではない。鋼柱のlbは材長を用いる |

長さの単位はmmです。強軸側はMzとQy、弱軸側はMyとQzの組です。名称は断面の基準方向を表し、断面性能の大小による自動並べ替えではありません。内力は軸力・せん断力がN、曲げがN·mm、応力度がN/mm²です。解析断面力の軸力は引張正、RC/SRC/CFTの耐力式で圧縮正を示す箇所では符号を読み替えます。

## 結果の読み方

対応する検定比は原則1以下を適合、1超をNGとします。「構造規定」の比、数値だけの参考値、警告は応力度比と区別します。RC梁の構造規定やたわみは中央位置に一度だけ表示されます。

「検定不能」「未算定」「未」には、入力不足、方式・形状の未対応、必要な応力を取得できない等の理由があります。0需要・0検定比・適合とは読み替えません。NG件数が0でも、未検定を含む結果は全適合ではありません。検定済みの項目でも各ページに示す近似・原典未確認・未評価の接合詳細は残ります。
