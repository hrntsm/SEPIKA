RC梁・柱には、コンクリート材料、主筋・せん断補強筋材料、断面寸法と成立する実配筋、断面の「主架構用途」、選択した荷重状態の解析断面力が必要です。材料の未割当・未対応材種や配筋幾何の不整合は理由付き検定不能です。壁・接合部には各ページの条件を追加します。共通する危険断面・内法長・荷重状態と合否／未検定の読み方は[本章の入口](README.md)を参照してください。

RC・SRC梁柱の許容応力度検定では、断面タブの「主筋」に「鉄筋」区分の材料を割り当てます。異なる区分の材料が割り当てられている場合は、主筋の材料を必要とする検定を未算定とし、該当部材・材料名・区分を表示します。せん断や構造規定など、主筋材料の区分にかかわらず不適合が確定した項目は併記します。断面タブで主筋の材料割当を修正してから再検定してください。

### せん断補強筋の材料区分

断面タブの「せん断補強筋」には「鉄筋」区分の材料を割り当てます。異なる区分の材料を割り当てた位置では、その材料を前提とする検定を未算定とします。診断に部材、断面、材料名、現在の材料区分を表示します。断面タブで割り当てを修正してから再検定してください。

RC柱の長期せん断と、採用した許容せん断式の補強筋項が0になる場合は、需要を確定できれば評価できます。材料区分が異なるRC柱で地震時の設計用せん断力を用いる場合は、同じ検定位置に有効な重力参照がある方向を評価し、不足や非有限値は方向を示して表示します。

1991方式の付着は、必要な設計用せん断力を確認できれば評価できます。1999方式の付着は、長期の場合と、短期で横補強筋の間隔が0以下または断面積が0の場合に評価できます。曲げ・軸力、構造規定、長期たわみなどで独立した不適合が確定した場合は併記します。未算定を含む位置は合格になりません。

## 検定項目

| 選択・用途 | 検討するもの |
| --- | --- |
| 梁 | 強軸曲げ・対応するせん断、付着・定着、構造規定・長期たわみ |
| 柱 | 軸力と二軸曲げ、二方向せん断、構造規定 |
| 柱梁接合部 | 接合部せん断の許容式。原典適合の未確認範囲があり設計採用は保留 |
| 耐震壁 | 成立条件を満たす壁のせん断。床小梁や雑壁の検定ではない |

プレキャスト（PCa）部材は、部材種別を問わず対応対象外です。

通常の許容応力度検定では、局所x軸まわりのねじりモーメント Mx が非零または非有限の位置を理由付きで未算定とします。[RC・SRC・CFTの材軸ねじり](README.md#rcsrccftの材軸ねじり)

## RC柱の実材端面

矩形・円形RC柱の通常の長期・短期検定では、接続大梁の外面が柱軸に直交する一つの断面に定まる場合、準備画面に表示される公称フェースでなく、この実材端面で軸力・曲げなどを検定します。例えば水平な幅300 mm、せい600 mmの矩形大梁と無偏心で接続する鉛直柱では、節点芯から300 mmが端面です。梁を材軸回りに90°回転させると、その距離は150 mmになります。

矩形RC・SRC大梁の有限な実外形と柱の実材端の間に正の面積の接触があり、柱側に向かって外形を抜ける面が柱軸に直交する場合に適用します。同じ端に複数の大梁があれば、全ての面が同じ位置にあることを確認します。大梁の斜めの断面回転、異なる高さの面、線や点だけの接触、丸め誤差と正の接触面積を区別できない場合は未検定とします。接合側の大梁ハンチに幅・せいの増分がある場合や接続形状の不足、連続を確認できない接続柱、実面を確認できない仕口パネルなども、端と理由を示して未検定とします。確認した面の間に正の長さの柱区間がなければ断面検定は行いません。

端面の位置は実材軸のi端からの距離を実材軸長で除した値で表示し、材中央で切り詰めません。同じ静的解析の、荷重を含む符号付き断面力を用います。面上に集中部材荷重がある場合は柱区間側の切断力を用い、丸めと実際の離隔を区別できない場合は未検定とします。位置に対応する解析応答がなければ、節点芯・公称フェース・近傍測点の値や補間で代用しません。短期地震時に同じ位置の重力参照を要するせん断式は、その参照がない場合は該当するせん断を未算定とします。選択した地震組合せの応答を確認でき、検定用の重力応答だけが得られない場合には、このRC柱で独立に確定した軸力・曲げや構造規定の不適合を残します。通常の測点の解析応答が重複する場合も、一意の実材端面応答で確認できた不適合まで取り消しません。

材中央や追加検定位置は確認できた実材端面の内側で検定します。端面と一致するときは、実材端面として一度だけ検定します。この扱いは準備計算・剛域、時刻歴簡易検定、終局検定、短期せん断の降伏機構の算定や、[長期せん断の最大需要と割増係数](02_04_RC柱のせん断検定.md#長期せん断の検定位置)の採用条件を変更しません。

日本建築学会『鉄筋コンクリート構造計算規準・同解説』2024年版、付2の断面設計(1)（p.438）では、長期・水平荷重時の断面算定用内力をフェイス位置で求めています。剛域端のモデル化は同付2の §2.2（p.443）で別に扱われ、検定面とは一致しません。

## 構造規定・長期たわみ

配筋・寸法は[RC梁の構造規定](02_08_RC梁の構造規定.md)と[RC柱の構造規定](02_09_RC柱の構造規定.md)、たわみは[RC梁の長期たわみ](02_10_RC梁の長期たわみ.md)で説明します。

部材全体に共通する項目（構造規定・たわみ）は、原則として部材中央（正規化位置 0.5）に一度だけ表示します。RC柱の実材端面より外側に中央がある場合や中央の解析内力が不足する場合にも、断面力を必要としない確認済みの構造規定の不適合は保持します。規定に関する警告だけの場合は他の検定行に付記し、その警告だけで未検定とはしません。
