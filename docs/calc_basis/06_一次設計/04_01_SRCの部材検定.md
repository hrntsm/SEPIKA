# SRCの部材検定

矩形RC部に中心H形鉄骨を内蔵した梁・柱の検定を扱います。断面寸法、配筋、鉄骨・コンクリート・主筋・補強筋の材料が必要です。

- [SRC梁・柱の許容曲げ検定](04_02_SRC梁_柱の許容曲げ検定.md)
- [SRC梁・柱の許容せん断検定](04_03_SRC梁_柱の許容せん断検定.md)
- [SRC柱梁接合部のせん断検定](04_04_SRC柱梁接合部のせん断検定.md)

## SRC の対応範囲と別途確認

矩形のRC部に中心H形鉄骨を内蔵した梁・柱を対象とします。梁は強軸曲げと対応するせん断、柱は軸力・二軸曲げ・二方向せん断を検定します。梁の軸力・弱軸曲げ・弱軸方向せん断は評価しません。これらが作用する梁では、この検定比だけで安全を判断せず、別途その影響を検討してください。

鉄骨のコンクリートかぶりは、令79条の3による原則50 mm以上と例外の適用条件を別途確認してください。形状や配筋入力の受理は、この法定かぶりの適合判定ではありません。令79条の4で準用される規定の適用・除外、柱脚の引張抵抗、継手・定着、構造切替階の応力伝達、接合部の帯筋配置も自動確認しません。部材・接合部の耐力比は、これらの詳細確認を代替しません。

- SRC 断面では、コンクリート強度、主筋・せん断補強筋・内蔵鉄骨の材料が必要です。内蔵鉄骨は鋼材区分の材料を割り当て、対応する材種名とウェブ・フランジの実最大板厚から[鋼材のF値](01_03_鋼材の許容応力度.md#鋼材のf値と入力条件)を決めます。両方の実板厚に正の有限値が必要です。既知材種では表のFを優先し、直接入力した降伏応力の欠落・不正値でも表の適用条件が成立すれば算定します。表の適用範囲外を降伏応力で補完しません。
- 未知の材種名は、正の降伏応力を入力してもSRC規準への適用根拠が未確定のため、位置全体を理由付き未算定とします。降伏応力の欠落・0・負値・非有限値も未算定です。235 N/mm²やRC部分だけの耐力で成功に補完しません。未算定を含む結果は全適合を意味しません。

## SRC部材の断面寸法と中間量

以下は、日本建築学会『鉄骨鉄筋コンクリート構造計算規準・同解説』1987年版の累加強度式・併用せん断式として現在採用する計算モデルです。入力寸法・配筋から中間量を求める定義と現行計算との対応を示します。第6版（2014年）17条のRC先行累加と構成は対応します。対称断面の短柱を対象とする比較で、引張有効断面、二軸で共通の軸力分担、座屈長がせいの12倍を超える柱や地震時圧縮力上限を含む17条全体への適合確認には使えません。1987年版本文への照合は未完了です。柱梁接合部の形状係数・許容式、CFT中長柱の許容体系の原典照合とも別の範囲です。

中心H形鉄骨の全せいをH、フランジ幅をbf、ウェブ厚をtw、フランジ厚をtfとします。矩形RC部の幅・全せいをB・Dとし、検討方向ごとの幅b・全せいDdirを次表で選びます。寸法は全てmmです。

| 対象・検討方向 | b | Ddir | b′（左右の残り幅の和） | 鉄骨のせん断抵抗部 |
| --- | --- | --- | --- | --- |
| 梁、柱の強軸（Mz・Qy） | B | D | max(B−bf,0) | 充腹ウェブ |
| 柱の弱軸（My・Qz） | D | B | max(D−H,0) | 両フランジ |

```text
        強軸：上側を圧縮とした断面模式図（幅 B=b）
          ←──────────── B ────────────→
          ┌──────────────────────────┐  圧縮縁
          │  ●                  ●    │
          │     ┏━━━━━━━━━━━━┓       │  圧縮側フランジ：面積 bf×tf
          │     ┗━━━━━┳━━━━━━┛       │
          │           ┃ tw           │  ↑ H
          │           ┃              │  ↓
          │     ┏━━━━━┻━━━━━━┓       │
          │     ┗━━━━━━━━━━━━┛       │
          │  ●                  ●    │  引張筋重心：圧縮縁から d
          └──────────────────────────┘
          ← b′/2 →←── bf ───→← b′/2 → （中心配置）
          全せい D、ウェブ内法 dw=H−2tf

        RC部の採用する力の距離（位置は概念表示）
          ─────────────────── 圧縮縁 y=0
                    ↓ d/8
          ─────────────────── RC圧縮合力の略算位置
                    ↕ rj=7d/8
          ●─────────────────● 引張筋重心 y=d
                    ↕ dt
          ─────────────────── 引張側縁 y=Ddir
```

圧縮側鉄骨の表示は強軸曲げの向きを説明するものです。柱の低減用spcには、曲げの向き・弱軸への切替えによらず同じ1枚のフランジ面積bf tfを用います。弱軸のb′は図を90度回して左右に残る幅の和に相当します。b′は片側のあきや鉄骨のかぶり厚ではありません。

### 配筋から求める有効せい・応力中心距離

梁の引張側は曲げ符号に従い、Mz>0で下端、Mz<0で上端です。Mz=0では上下の全段主筋面積の小さい側を使い、等しい場合は下端を使います。梁のatとdtには引張側全段の主筋面積と面積加重平均の重心距離を用います。かぶりc0、補強筋径φw、主筋径φ、引張側の縁から第i段の本数Niに対し、次式で求めます。

\\[ y\_i=c\_0+\varphi\_w+\frac{\varphi}{2}+(i-1)\\{\varphi+\max(25,1.5\varphi)\\},\qquad a\_i=N\_i\frac{\pi\varphi^2}{4} \\]

\\[ a\_t=\sum\_i a\_i,\qquad d\_t=\frac{\sum\_i a\_i y\_i}{a\_t},\qquad d=D\_{\mathrm{dir}}-d\_t,\qquad {}\_rj=\frac78d \\]

柱は強軸で上下辺、弱軸で左右辺の最外段1列を両縁筋とし、dt=c0+φw+φ/2、atはその1列の主筋面積です。残余主筋の扱いは[RC柱の許容N–M境界](02_03_RC柱の軸力_二軸曲げ検定.md#柱の許容nm境界)と共通です。rjは曲げ・せん断・分担率に使う略算値であり、柱の中立軸から求める合力間距離ではありません。[RC梁の中立軸とjの違い](02_01_RC梁の許容曲げ.md#梁の許容曲げと中立軸)も参照してください。

せん断補強筋1組の検討方向の脚数をnw、間隔をsとし、梁はあばら筋の脚数、柱は強軸でX方向・弱軸でY方向の帯筋脚数を用います。

\\[ A\_w=n\_w\frac{\pi\varphi\_w^2}{4},\qquad p\_{w,\mathrm{raw}}=\frac{A\_w}{bs},\qquad p\_w=\min(p\_{w,\mathrm{raw}},0.006) \\]

入力配筋の成立条件に加え、計算上はs≤0なら補強筋比を0とします。SRCの以下の補強筋項はpwをそのまま用い、RC部材せん断式のpw−0.002へ置き換えません。

| 記号 | 意味 | 単位 |
| --- | --- | --- |
| dt、d、rj | 引張側縁から主筋重心までの距離、有効せい、RC部の略算応力中心距離 | mm |
| at、Aw | 引張主筋面積、補強筋1組の検討方向の断面積 | mm² |
| spc、pw | 低減用の圧縮側鉄骨比、上限適用後の補強筋比（0.006は0.6%） | — |
| fc、fc′、fs | コンクリートの許容圧縮応力度、その低減後、許容せん断応力度 | N/mm² |
| ft、wft | 主筋、せん断補強筋の許容引張応力度 | N/mm² |
| sft、sfc、sfs | 鉄骨の許容引張、許容圧縮、許容せん断応力度 | N/mm² |
| sZ、sA | 検討軸の鉄骨弾性断面係数、鉄骨全断面積 | mm³、mm² |
| MA、sMo、rMA、rMu | SRC、鉄骨部、RC部の許容曲げモーメント、RC部の終局曲げ耐力 | N·mm |
| As、Ae | 全主筋面積、RC部の換算断面積 | mm² |
| Nd、rNc、rNt | 設計軸力、RC部の圧縮・引張軸力限界（圧縮正） | N |
| n | 許容曲げ用ヤング係数比 | — |
| QA、sQA、rQA | 併用式、鉄骨部、RC部の許容せん断力 | N |
| sQD、rQD | 地震時構造規定方式の鉄骨部、RC部の要求せん断力 | N |
| rα、a′、βm、ηs | せん断スパン割増係数、併用式の係数、部材せん断用係数、鉄骨分担率 | — |

許容応力度には[材料の許容応力度](01_材料の許容応力度.md)による検定期間・材料の値を用います。nは同ページの[コンクリート](01_01_コンクリートの許容応力度.md#コンクリート)の許容曲げ用ヤング係数比（Fc≤27で15、27超36以下で13、36超48以下で11、48超60以下で9、60超で7）です。解析用Es/Ec、地震時せん断の割増係数nとは区別します。
