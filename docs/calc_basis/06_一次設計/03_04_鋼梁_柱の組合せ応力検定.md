# 鋼梁・柱の組合せ応力検定

軸力・二軸曲げの組合せと、せん断を含むvon Mises合成を確認します。H形鋼柱に強軸曲げと弱軸せん断が同時に作用する位置では、同一点の組合せ応力度が未算定になります。

## 算定式（梁）

軸力・曲げによる応力度:

\\[ \sigma\_{ax} = |N|/A,\quad \sigma\_{by} = |M\_z|/Z,\quad \sigma\_{bz} = |M\_y|/Z\_{\text{弱軸}} \\]

円形鋼管は強軸・弱軸の曲げモーメントを合成した \\( \sigma\_b \\) で代表させます:

\\[ \sigma\_b = \sqrt{M\_z^2 + M\_y^2}/Z \\]

軸力＋二軸曲げの組合せ検定。圧縮時（\\( f\_c \\) は座屈を考慮した許容圧縮応力度）:

\\[ \sigma\_c/f\_c + \sigma\_{by}/f\_b + \sigma\_{bz}/f\_t \le 1.0 \\]

（円形鋼管は \\( \sigma\_c/f\_c + \sigma\_b/f\_b \\)）。引張時:

\\[ (\sigma\_t + \sigma\_{by} + \sigma\_{bz})/f\_t \le 1.0 \\]

（円形鋼管は \\( (\sigma\_t + \sigma\_b)/f\_t \\)）。組合せ検定とは別に、単独曲げの検定 \\( \sigma\_{by}/f\_b \\)（円形鋼管は \\( \sigma\_b/f\_b \\) で代替）・\\( \sigma\_{bz}/f\_t \\) も行い、いずれも検定比として扱います。

許容圧縮応力度 \\( f\_c \\) は、強軸・弱軸それぞれの座屈長さによる細長比のうち大きい方で算定します:

\\[ \lambda = \max(l\_{ky}/i\_y,\ l\_{kz}/i\_z),\quad i\_y = \sqrt{I\_y/A},\quad i\_z = \sqrt{I\_z/A} \\]

（\\( l\_{ky} \\): 強軸まわり座屈長さ、\\( l\_{kz} \\): 弱軸まわり座屈長さ。両者とも部材長のとき \\( \lambda = l\_k/i\_{\min} \\)、\\( i\_{\min} = \sqrt{\min(I\_y, I\_z)/A} \\) に一致します。）

通常Sの主架構部材は、軸ごとに直接指定を優先します。未指定軸には[部材用途別の座屈長さの既定値](03_06_鋼部材の座屈長さ_有効細長比.md#柱の座屈長さ係数-k)を用います。

## von Mises 合成

H形の梁は、次の断面内評価位置に対応する候補比を別々に求め、その最大値を採用します。
双方に、[せん断の検定](03_03_鋼梁_柱のせん断検定.md#せん断の検定)で定義する同じせん断応力度τsumを用います。

- ウェブ端（フランジ内面との境界）: 強軸曲げ応力度をウェブ端のせい位置へ換算し、弱軸曲げは含めません。

\\[ \sigma\_{b,\mathrm{web}}=\sigma\_{by}\frac{\max(H-2t\_f,0)}{H} \\]

\\[ R\_{\mathrm{VM,H,web}}=\frac{\sqrt{(\sigma\_{ax}+\sigma\_{b,\mathrm{web}})^2+3\tau\_{\mathrm{sum}}^2}}{f\_t} \\]

- フランジ縁（強軸・弱軸曲げの縁応力度を加算する候補）: 軸力・二軸曲げの法線応力を加算します。

\\[ R\_{\mathrm{VM,H,flange}}=\frac{\sqrt{(\sigma\_{ax}+\sigma\_{by}+\sigma\_{bz})^2+3\tau\_{\mathrm{sum}}^2}}{f\_t} \\]

H梁のvon Mises比:

\\[ R\_{\mathrm{VM,H,beam}}=\max(R\_{\mathrm{VM,H,web}},R\_{\mathrm{VM,H,flange}}) \\]

ここで \\( \sigma\_{ax}=|N|/A \\)、\\( \sigma\_{by}=|M\_z|/Z\_{\mathrm{strong}} \\)、\\( \sigma\_{bz}=|M\_y|/Z\_{\mathrm{weak}} \\) です。
H梁の強軸断面係数には、設定された欠損の控除を適用します。
この位置名は採用している応力度式の対応を示します。法線応力とせん断応力を同じ点で評価できる条件は未確定です。 [#951](https://github.com/hrntsm/SEPIKA/issues/951)

せん断検定の適用条件を満たす角形鋼管やその他の形状の大梁では、次式を採用します。この一般形状への適用を、任意断面での安全側の保証とはしません。

\\[ R\_{\mathrm{VM,Box/Other,beam}}=\sqrt{(\sigma\_{ax}+\sigma\_{by}+\sigma\_{bz})^2+3\tau\_{\mathrm{sum}}^2}/f\_t \\]

円形鋼管の梁は、中立軸位置の式を用います（曲げ応力度の寄与はありません）。円形鋼管の純せん断比も方向別比の最大値を用い、上記の和へ置き換えません。

\\[ \sqrt{\sigma\_{ax}^2+3(\tau\_y^2+\tau\_z^2)}/f\_t \\]

梁の検定比は、上記の組合せ検定・単独曲げ検定・せん断検定・von Mises 合成の各比のうち最大値とします。
柱のvon Mises合成に用いる法線応力とせん断との組合せは、[せん断検定の適用条件を満たす柱](#せん断検定の適用条件を満たす柱)に示します。独立した軸力・二軸曲げの検定には[柱の軸力・曲げの算定式](03_05_鋼柱_ブレースの軸力_曲げ検定.md#算定式柱ブレース)を用います。

日本建築学会の規準書本体への全面適合や、任意断面に対する安全性を確認済みとするものではありません。

## H形鋼柱で引張・強軸曲げ・弱軸せん断が同時に作用する場合

**H形鋼柱で引張軸力 N > 0、強軸曲げ Mz ≠ 0、弱軸せん断 Qz ≠ 0 が同時に作用する位置は、理由付きの検定不能です。**
通常のH形鋼、組立H形鋼、形状は未指定でも断面名からH形鋼と判定される断面を対象とします。短期・長期とも、強軸せん断 Qy や弱軸曲げ My が加わる場合を含みます。弱軸せん断が0の場合は、軸力と曲げの検定を行います。

日本建築学会『鋼構造許容応力度設計規準』2019年版の5.5 式(5.24)（p.14、解説 pp.59–60）は、同一箇所の垂直応力度とせん断応力度の組合せを、5.1・5.6の許容引張応力度（長期 F/1.5、短期 F）で照査します。5.1(2)の解説（p.49、図5.1.1）が示すのは、H形断面のウェブ面内せん断と、細長い長方形断面のせん断分布です。11.9(4)（p.27、解説 p.97）が充腹柱の軸力と曲げについて参照する6.2 式(6.3)・(6.4)（p.15、解説 p.61）は、引張側フランジと部材の横座屈をそれぞれ照査します。 [規準の書誌](https://ndlsearch.ndl.go.jp/books/R100000002-I030037737)

これらの箇所から、弱軸せん断に対するフランジ内の設計用公称応力度の分布や、ウェブとフランジの取り合いにあるフィレット半径の取扱いを確定できません。同一点の組合せ応力度が最大となる位置を求められないため、その位置の鋼部材検定は未算定とします。

## H形鋼柱で圧縮または軸力なしの場合の強軸曲げと弱軸せん断

圧縮軸力または軸力なし（N ≤ 0）のH形鋼柱で、強軸曲げ Mz と弱軸せん断 Qz が同じ材軸位置でともに非零なら、同一点の組合せ応力度は理由付きで未算定です。通常のH形鋼、組立H形鋼、断面名によってH形鋼に分類される断面が対象です。短期・長期とも、強軸せん断 Qy または弱軸曲げ My の併存時にも適用します。間柱は対象外です。材軸ねじり Mx が非零または非有限のときは[ねじりの検定条件](03_03_鋼梁_柱のせん断検定.md#材軸ねじりが作用する場合)を適用します。

日本建築学会『鋼構造許容応力度設計規準』2019年版の5.5 式(5.24)（p.14、解説 pp.59–60）は、同一点の公称垂直応力度と公称せん断応力度の組合せを、5.1・5.6の許容引張応力度（長期 F/1.5、短期 F）で照査します。5.1(2)の解説（p.49、図5.1.1）は通常のH形断面のウェブ面内せん断に対してウェブ平均を示します。11.9(4)（p.27、解説 p.97）が参照する6.1 式(6.1)・(6.2)（p.15、解説 p.61）は、圧縮側と引張側の軸力・曲げの照査を扱います。これらの箇所からは、弱軸せん断によるフランジ内の公称応力度分布、フィレット半径の評価方法、組合せ応力度が最大となる点を確定できません。 [規準の書誌](https://ndlsearch.ndl.go.jp/books/R100000002-I030037737)

組合せが未算定でも、法定細長比または既存の軸力・曲げの検定で不適合を確認できた場合は、その検定比と根拠に未算定理由を併記します。従来のせん断検定比は、弱軸の代表せん断応力度を含むため、独立した不適合の根拠には用いません。既知の不適合がない位置は検定不能と表示します。

## せん断検定の適用条件を満たす柱

せん断検定の適用条件を満たすH形・角形鋼管などの柱では、大梁と共通のAy/Azを用い、純せん断比は \\( R\_{\mathrm{shear}}=R\_y+R\_z \\)、von Misesへのせん断応力度は \\( \tau\_{\mathrm{sum}}=|Q\_y|/A\_y+|Q\_z|/A\_z \\) とします。
柱のvon Misesに用いる法線応力は、次の部材別の式です。

\\[ \sigma\_{\mathrm{H,column}}=\frac{|N|}{A}+\frac{|M\_z|}{Z\_{\mathrm{strong}}}\frac{\max(H-2t\_f,0)}{H} \\]

\\[ \sigma\_{\mathrm{Box/Other,column}}=\frac{|N|}{A}+\frac{|M\_z|}{Z\_{\mathrm{strong}}}+\frac{|M\_y|}{Z\_{\mathrm{weak}}} \\]

柱では \\( Z\_{\mathrm{strong}}=I\_y/(H/2) \\)、\\( Z\_{\mathrm{weak}}=I\_z/(B/2) \\) を用い、上記σを次式へ代入します。

\\[ R\_{\mathrm{VM,column}}=\frac{\sqrt{\sigma^2+3\tau\_{\mathrm{sum}}^2}}{f\_t},\qquad R\_{\mathrm{Shear,column}}=\max(R\_{\mathrm{VM,column}},R\_{\mathrm{shear}}) \\]

H柱のvon Mises用σはウェブ端の強軸曲げを用い、弱軸曲げを含むH梁の第2ケースとは異なります。
τsumは共通ですが、法線応力の評価式は柱と梁で異なります。軸力・二軸曲げの独立検定は別に行い、柱全体の検定比はその比と上記せん断検定比の最大値です。
H柱・H梁の応力式を同じ断面点の評価に適用できる条件は未確定です。H柱に強軸曲げ・弱軸せん断が同時に作用する場合には、[引張時](#h形鋼柱で引張強軸曲げ弱軸せん断が同時に作用する場合)および[圧縮時・軸力なし](#h形鋼柱で圧縮または軸力なしの場合の強軸曲げと弱軸せん断)の適用制限があります。

円形鋼管の柱は合成 \\( \tau=\sqrt{Q\_y^2+Q\_z^2}/A\_y \\)（Ay=Az）と \\( \sigma=|N|/A+\sqrt{M\_z^2+M\_y^2}/Z\_{\mathrm{strong}} \\) を用い、\\( \max(\sqrt{\sigma^2+3\tau^2}/f\_t,\tau/f\_s) \\) とします。円形鋼管柱のσは、円形鋼管梁の中立軸位置の式とも異なります。
