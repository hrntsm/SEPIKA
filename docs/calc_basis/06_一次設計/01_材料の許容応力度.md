# 材料の許容応力度

## コンクリート

コンクリートの許容応力度には、以下の式を採用します。圧縮は建築基準法施行令 第91条の基本倍率によります。普通コンクリートの長期許容せん断応力度は同条及び平成12年建設省告示第1450号第2の値を用います。短期倍率・軽量コンクリートの低減及び付着のFc上限には以下の設計用の扱いがあり、この機能だけで全ての法令上の適合を判定することはできません。

長期・短期は荷重状態に対応する区分です。令82条では常時及び多雪区域の長期積雪を長期、積雪・暴風・地震時を短期とします。短期の損傷制御／安全確保は、同じ短期区分の中の検討目的の違いです。材料値の短期倍率を、そのまま部材耐力全体の倍率として使うことはできません。

**算定式**

付着許容応力度には Fc（36 N/mm²を上限）を用います。異形鉄筋は長期上端筋 \\(\min(F_c/15, 0.9 + (2/75)F_c)\\)、その他 \\(\min(F_c/10, 1.35 + F_c/25)\\) とし、丸鋼は上端筋 \\(\min(4F_c/100, 0.9)\\)、その他 \\(\min(6F_c/100, 1.35)\\) とします。短期は長期値の1.5倍です。異形鉄筋の長期値は、平12建告第1450号第1第一号の表によります。上端筋以外では Fc=22.5 N/mm²を境に Fc/10 と 1.35+Fc/25 が連続します。出典は『2025年版 建築物の構造関係技術基準解説書』第2版第1刷、9.3、p.585です。

告示第1第二号の短期値は長期の2倍ですが、本プログラムでは1.5倍の小さい値を採用します。Fcの上限は36 N/mm²とし、Fcがこれを超える場合は36の値を使います。これらの採用条件は、告示表そのものの規定とは区別します。

- 許容圧縮応力度 \\( f\_c \\) = 長期 \\( F\_c/3 \\)、短期 = 長期×2
- 許容せん断応力度 \\( f\_s \\) = 長期は \\(F_c \le 21\\) で \\(F_c/30\\)、\\(F_c > 21\\) で \\(0.49 + F_c/100\\)、短期 = 長期×1.5
- 付着（異形鉄筋）\\( f\_a \\) = 長期上端筋 \\( \min(F\_c/15, 0.9 + (2/75)F\_c) \\)、その他 \\( \min(F\_c/10, 1.35 + F\_c/25) \\)、短期×1.5
- 付着（丸鋼）\\( f\_a \\) = 長期上端筋 \\( \min(4F\_c/100, 0.9) \\)、その他 \\( \min(6F\_c/100, 1.35) \\)、短期×1.5
- 軽量コンクリート 1 種・2 種は許容せん断応力度のみを 0.9 倍（許容圧縮応力度は普通コンクリートと同じ。付着は対象外）

普通コンクリートの長期値は、Fc=21/24/36 N/mm²でそれぞれ0.70/0.73/0.85 N/mm²です。実験に基づく別の許容値への置換は行いません。

せん断の短期1.5倍は設計用の採用倍率です。令91条の短期表値は長期の2倍であり、採用する材料値はその75%です。軽量1種・2種の0.9倍は別の設計用低減であり、令91条・告1450第2だけからその種類別係数の根拠を確認したものではありません。これらの係数と各部材の検定式全体の適用根拠は別途確認が必要です。材料値が小さいことだけで部材・建物全体の安全性を保証しません。

このせん断材料値はRC梁・柱、RC壁、RC接合部及びSRC梁・柱・仕口パネルに適用します。RC接合部は短期値、その他は検討の長短期区分に応じた値を用います。SRCのRC部分にも同じ材料値を用い、CFT柱の鋼管のみで評価する許容せん断には用いません。

軽量1種・2種のせん断0.9倍と短期1.5倍は、材料値としての採用条件です。通常RC・SRCの各部材式と組み合わせる学会規準の適用条件は未確認であり、これらの材料値による検定結果だけで設計の適否を確定しないでください。付着についても、軽量への適用条件及び丸鋼を含む短期1.5倍・Fc上限36の規準上の根拠は未確認です。令91条の一般付着の軽量値0.6を、せん断0.9の根拠や、ここで用いる異形鉄筋・丸鋼の付着表の代わりには使いません。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( f\_c \\) | コンクリートの許容圧縮応力度 | N/mm² |
| \\( f\_s \\) | コンクリートの許容せん断応力度 | N/mm² |
| \\( f\_a \\) | 付着の許容応力度（異形鉄筋） | N/mm² |
| \\( F\_c \\) | コンクリートの設計基準強度 | N/mm² |

## 鉄筋（径区分に注意）

鉄筋の許容応力度には、以下の材種・径別の値を採用します。SD345・SD390の長期許容引張・圧縮応力度は建築基準法施行令第90条表2に、SD490は平成13年国土交通省告示第1024号第1第六号・第3第五号により、径28 mm以下／28 mm超で区分します。数値径28 mmでは215 N/mm²、28.6 mmでは195 N/mm²です。短期値とせん断補強筋の許容値は、この主筋の径区分によって変わりません。

断面編集の径選択はD10〜D41の標準呼び名から選び、呼び名の数値を保持します。D25は25、D29は29を用いるため、長期許容値はそれぞれ215／195 N/mm²です。ST-Bridgeの標準配筋でも、D25・D29表記は25・29として取り込み、数値径は小数を含めてその値を保持します。公称直径を数値で指定した25.4／28.6 mmも、同じ215／195 N/mm²の区分になります。

配筋の径は正の有限値が必要で、配置が断面内に成立することも必要です。標準呼び名以外の数値径を取り込んでも、近い呼び名やJIS公称直径へ丸めません。断面積は保持した径の円面積で求め、主筋位置や鉄筋数量も保持した径によります。呼び名の数値と公称直径を入れ替えると、許容応力度の区分が同じ場合でも面積・位置・数量は変わり得ます。

**算定式（許容引張、長期／短期）**

- SR235 = 155/235、SR295 = 155/295、SD295 = 195/295、SD345/390/490 は \\( D > 28 \to 195/ \\)、\\( D \le 28 \to 215/ \\)（短期は 345/390/490）
- USD685 = 215/685（径によらず）
- せん断補強筋: 長期は SR235 のみ 155、他は 195。短期は基準強度（SR235 = 235、
  SR295/SD295 = 295、SD345 = 345、SD390 = 390、SD490 = 490）。
- 損傷制御の短期せん断検定では、普通強度せん断補強筋（`SD*`・`SR*`）を用いる RC 梁・柱の
  許容せん断力で \\( {}_w f_t \\) を 390 N/mm² 以下に制限します（RC規準）。

鉄筋は長期上限と短期値をそれぞれ選ぶため、短期値は長期値の一律1.5倍ではありません。例えばSD345主筋は径28 mm以下で215→345、28 mm超で195→345 N/mm²です。法令表の分数値に対し、SD295主筋の径28 mm以下の長期値は196.666…に対して195、SR235せん断補強筋の長期値は156.666…に対して155 N/mm²を採用します。この小さい側の差の規準上の採用根拠は未確認です。SD490の短期材料値490と、部材の損傷制御で用いる390上限は用途が異なり、材料表の値によって部材側の上限を緩和しません。

**実装参照**：`sepika_design_jp::material_strength::{rebar_allowable_tension, rebar_allowable_shear}` が算定します。

### 鉄筋の材料はどこで指定するか

主筋・せん断補強筋の材料は、**断面の属性**として指定します（断面タブの「主筋」「せん断補強筋」欄）。
断面は 4 つの材料欄を持ち、それぞれ次の役割を担います。

| 欄 | 役割 | 使う断面 |
|------|----------|--------|
| 材料 | 主材料。コンクリート（\\( F\_c \\)）または鋼材（F 値） | すべての断面 |
| 主筋 | 主筋の材質。降伏点 \\( \sigma\_y \\) と許容応力度に用いる | RC 矩形・RC 円形・SRC 矩形・RC 壁 |
| せん断補強筋 | せん断補強筋の材質。\\( \sigma\_{wy} \\) と \\( w f\_t \\) に用いる | 同上 |
| 内蔵鉄骨 | SRC の内蔵鉄骨の鋼種。F 値に用いる | SRC 矩形 |

呼び名サイズ（`D10`〜`D41`）と本数・段数・ピッチは、材料とは別に断面の配筋欄で指定します。

材料の名称がそのままグレード名になり、そこから許容応力度の表を引きます。
降伏点 \\( \sigma\_y \\)・\\( \sigma\_{wy} \\) は材料に登録した \\( f\_y \\) をそのまま用い、
名称からの推定は行いません。

- 許容応力度の表は名称で引きます（`SD345` → 令90条表の SD345 の行）
- 主筋の \\( \sigma\_y \\)・せん断補強筋の \\( \sigma\_{wy} \\) は、割り当てた材料の \\( f\_y \\) です
- せん断補強筋の材料が未割当のとき、終局耐力の \\( \sigma\_{wy} \\) は SD295 相当
  （295 N/mm²、材料未割当時に用いる代表値）を既定とします

配筋を持つ断面で**主筋**の材料が未割当のモデルは、解析前チェックが**エラーで停止**します
（[増分解析](../05_構造解析/07_プッシュオーバー解析.md)「解析前の入力チェック」）。
**せん断補強筋**の材料が未割当のときは解析前チェックで停止せず、終局耐力の
\\( \sigma\_{wy} \\) のみ上記の既定値を用います。

許容応力度計算の断面検定は材料の名称で許容応力度表を引くため、**主筋・せん断補強筋の
いずれが未割当でも**「検定不能」として理由を返します。主筋の \\( \sigma\_y \\) を
既定値 345 N/mm² で補わないのは、SD295 の部材で耐力を過大評価するためです。

せん断補強筋として対応する材料は、普通強度の `SR235`・`SR295`・`SD295`（`SD295A`・`SD295B` を含む）・`SD345`・`SD390`・`SD490` に限ります。
普通強度鉄筋は令90条の表、SD490は平成13年国土交通省告示第1024号の高強度鉄筋の表に対応する値を採用します。高強度せん断補強筋の製品名や未知名など上記以外のグレードを割り当てた断面は、現時点で未対応のため、断面検定は「検定不能（理由付き）」、解析は解析前チェックのエラーで停止します。

対応グレードの材料を割り当てているのに \\( f\_y \\) が未設定（0 以下を含む）の場合も入力不備とし、断面検定は「検定不能（理由付き）」、解析は解析前チェックのエラーで停止します。
壁の断面検定・非線形参考骨格は別の入力契約とし、必要な材料役割の未割当・fy欠落・非有限/非正値を未検定とします。壁検定には295の既定値を用いません（[壁参考骨格](../08_部材終局耐力/04_RC_部材_非線形復元力特性.md#耐震壁せん断非線形トリリニア)）。

解析用の既存終局耐力では、材料未割当のときだけ既定 295 N/mm² を用います。対応グレードの \\( f\_y \\) を無言で 295 に補うと、`SR235`（\\( f\_y = 235 \\)）の部材で \\( \sigma\_{wy} \\) を 235 から 295 へ増やす**危険側**の評価になるためです。

<div class="impl-ref">

**実装参照**：`sepika_core::material_grade::{rebar_yield_strength, shear_rebar_yield_strength, is_supported_shear_rebar_grade, shear_rebar_material_issue}` が \\( f\_y \\) の解決と材料の不備判定を行い、検定側の材質選択は `sepika_design_jp::material_strength::{main_rebar_grade, shear_rebar_grade}` によります。

## 鋼材（F 値・許容応力度・座屈）

鋼材の F 値・許容応力度・座屈を、建築基準法施行令 第90条・98条／告示、および鋼構造設計規準 1973 に基づいて算定します。許容曲げ応力度 fb の算定式と通常の利用経路は、[鋼構造 断面検定](03_鋼構造_断面検定.md)に記載します。

**算定式**

- F 値（板厚区分）: SS400/SN400 = 235(\\( t \le 40 \\))/215、SN490/SM490 = 325/295 ほか
  （グレード別の F 値一覧は [標準材料（プリセット）一覧](../02_材料/04_標準材料一覧.md)）。
  F 値は断面に割り当てた材料の対応済み名称から解決します（`SN490B` → `SN490` 等）。
  名称の対応範囲は[鋼材名の対応範囲](../02_材料/04_標準材料一覧.md#鋼材名の対応範囲)を参照します。
  SRC の内蔵鉄骨は、断面の「内蔵鉄骨」欄の材料の名称を用います。
  通常鋼部材・鋼小梁・S/CFT柱梁接合部の材料・実板厚の選択と入力条件は、[鋼材のF値と入力条件](#鋼材のf値と入力条件)に従います。
  SRC内蔵鉄骨の条件は[SRC / CFT 断面検定](04_SRC_CFT_断面検定.md)を参照してください。
- 許容引張 \\( f\_t \\) = 長期 \\( F/1.5 \\)、短期 \\( F \\)、許容せん断 \\( f\_s \\) = 長期 \\( F/(1.5\sqrt{3}) \\)、短期 \\( F/\sqrt{3} \\)
- 圧縮（座屈考慮）:

\\[ \Lambda = \sqrt{\pi^2 E / (0.6 F)} \\]

\\[ \nu = 3/2 + (2/3)(\lambda/\Lambda)^2 \\]

\\[ \lambda \le \Lambda: f\_c = F(1 - 0.4(\lambda/\Lambda)^2)/\nu \\]

\\[ \lambda > \Lambda: f\_c = 0.277 F / (\lambda/\Lambda)^2 \\]

標準的な建築用鋼材のヤング係数は205000 N/mm²です。材料種別が「鋼材」の材料には、大臣認定による特別な鋼材も含めて、上記の許容圧縮応力度式を共通に適用します。
Eは当該鋼材に登録したヤング係数、Fは[鋼材のF値と入力条件](#鋼材のf値と入力条件)で定める基準強度を用い、短期は長期値の1.5倍です。特別な鋼材の材料定数・使用条件は、その認定内容に従って指定します。
平13国交告第1024号第1第三号ロ表1の炭素鋼の式は、限界細長比を \\(1500/\sqrt{F/1.5}\\)、長柱側の係数を \\(18/65\\) とします。
標準値と異なるEでは、この告示式より許容値が大きくなり、同じ圧縮応力度の検定比が小さくなる場合があります。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( F \\) | 鋼材の基準強度（F 値） | N/mm² |
| \\( f\_t \\) | 鋼材の許容引張応力度 | N/mm² |
| \\( f\_s \\) | 鋼材の許容せん断応力度 | N/mm² |
| \\( f\_c \\) | 座屈を考慮した許容圧縮応力度 | N/mm² |
| \\( \lambda \\) | 座屈長さと断面二次半径から求める細長比 | - |
| \\( \Lambda \\) | 限界細長比 | - |
| \\( E \\) | 鋼材のヤング係数（材料に登録した値を用い、標準的な鋼材は \\( 2.05\times10^5 \\) N/mm²） | N/mm² |
| \\( \nu \\) | 座屈係数（\\( \lambda/\Lambda \\) の関数） | - |
| \\( t \\) | 板厚（F 値の板厚区分） | mm |

<div class="impl-ref">

## 鋼材のF値と入力条件

通常の鋼部材・鋼小梁・S/CFT柱梁接合部には、次の規則を適用します。材料名の対応範囲と各板厚区分の値は[標準材料一覧](../02_材料/04_標準材料一覧.md#鋼材名の対応範囲)を参照してください。

| 材料の条件 | 採用するF |
| --- | --- |
| 材種表に対応する鋼材 | 対象部位の実板厚による表のF。材料の降伏応力が未入力でも採用でき、保存された降伏応力で上書きしない |
| 材種表に対応しない名称の、割当済み鋼材 | 材料に指定した正の有限値の降伏応力を直接採用する |
| 既知材種で表の適用範囲外 | 入力エラー。直接入力材料へ読み替えない |

| 対象 | 参照する材料 | Fを選ぶ実板厚 |
| --- | --- | --- |
| 通常鋼部材・鋼小梁 | 対象断面の鋼材 | 実断面形状の最大板厚。実形状がない場合は明示した断面板厚 |
| H形柱の強軸側パネル | 採用柱の鋼材 | ウェブの実厚 |
| H形柱の弱軸側パネル | 採用柱の鋼材 | フランジ1枚の実厚 |
| 鋼管・CFTパネル | 鋼管の鋼材。CFTは鋼管専用の材料割当 | 鋼管壁1枚の実厚 |

パネルの参照柱は物理的な下側を優先し、下側柱が存在しない場合だけ上側を採ります。補強を含む有効厚や複数の抵抗板の合計厚を、材種表に渡す一枚の製品板厚に置き換えません。柱の強軸・弱軸への需要の分担と適用条件は[鋼構造の柱梁接合部](03_鋼構造_断面検定.md)に従います。

材料未割当、参照先不明、鋼材以外の割当、必要板厚の欠落・非正値・非有限値は、対象と理由を示す入力エラーです。直接入力材料の降伏応力の欠落・0以下・非有限値も同様です。235 N/mm²や40 mmで補ったり、該当対象だけを読み飛ばしたりして検定全体を正常完了にしません。直接入力材料のFを決めるためだけの板厚区分は不要ですが、断面性能やパネル耐力の算定に必要な形状寸法は必要です。

例えばSS400の40 mmはF=235 N/mm²、50 mmはF=215 N/mm²です。50 mmの断面に降伏応力235 N/mm²が保存されていても、通常部材・鋼小梁はF=215 N/mm²を用い、小梁の長期許容曲げ応力度は215/1.5 N/mm²となります。

<div class="impl-ref">
