# RC梁の付着・定着検定

RC梁の引張主筋に異形鉄筋を使う場合は、選択した1999方式または1991方式で付着を検定します。[大地震時の付着照査](../08_部材終局耐力/02_02_RC梁_柱の大地震時の付着照査.md)は別の算定です。

<a id="付着定着rc規準19991991"></a>

## 付着・定着の算定方式

設計タブの「1999方式」（既定）は平均付着応力度による方式、「1991方式」はせん断力による方式です。日本建築学会『鉄筋コンクリート構造計算規準・同解説』第10版（2024）16条（付着・継手）および17条（定着）を参照します。16条1項(3)の式(16.1)～(16.4)（p.25）は、使用性と損傷制御の付着検討にせん断力による式と平均付着応力度による式を示しています。現行方式の地震時せん断力の選択、係数・適用条件・長さの取り方の照合は未完了です。

### 丸鋼を引張主筋に用いる場合

2024年版RC規準16条の解説（p.217）では、やむを得ず丸鋼を用いる場合、鉄筋端部にフックを設け、長期は式(16.2)、短期は式(16.4)を準用します。フックの形状は原則として17条の標準フックに従い、仕口内の定着は別に確認します。丸鋼の付着は表面状態の影響を受けるため、解説は許容耐力に十分な余裕を持たせるよう勧めています。

丸鋼（SR235・SR295）を主筋に指定すると、1999方式・1991方式とも長期・短期の付着は未算定となり、検定比や適合は表示しません。両方式では丸鋼に必要な端部フックと実際の付着長さを確認できないためです。曲げ・せん断などで確定した不適合は、付着の未算定理由と併せて表示します。丸鋼を使用する場合は、長期・短期の付着と仕口内の定着を別途確認してください。異形鉄筋は、呼び名の代わりに数値径を指定しても、数値径だけを理由に丸鋼とは扱いません。

### 1991方式との違い

強軸曲げが未算定でも、1999方式は有限な解析曲げモーメントと必要な配筋・断面諸量・材料・部材長から確定できたNGを表示します。1991方式は同じ位置の設計用せん断力が必要です。[強軸曲げを算定できないときのせん断需要](02_02_RC梁のせん断検定.md#強軸曲げを算定できないときのせん断需要)を参照してください。

短期1999方式であばら筋1組の断面積が正の場合は、横補強筋効果の算定に有限なあばら筋間隔が必要です。 [あばら筋間隔が非有限の場合](02_02_RC梁のせん断検定.md#あばら筋間隔が非有限の場合)

1991方式は必要長さを算定せず、設計用せん断力 \\( Q\_d \\) による応力度比で検定します。\\( Q\_d \\) は[梁・柱のせん断需要と許容耐力](02_05_RC梁_柱の許容せん断の共通式.md#梁柱のせん断需要と許容耐力)で用いる値です。地震時の安全確保ではQD方式による需要、損傷制御では長期・水平の合算せん断力の絶対値を使います。地震時以外は解析せん断力の絶対値です。[時刻歴の簡易検定](../../result_view/10_時刻歴アニメーションの表示.md#rc梁柱のせん断検定)で損傷制御のせん断需要を確定できない場合は、1991方式の付着も未算定です。

\\[ \sum\varphi=n\_t\varphi,\qquad \tau\_a=\frac{Q\_d}{(\sum\varphi)j},\qquad R\_b=\frac{\tau\_a}{f\_a} \\]

周長総和には引張側全段の総本数を使い、1999方式の1本の周長 \\( \varphi \\) や最外段本数 \\( n\_1 \\) と区別します。許容値 \\( f\_a \\) は[材料の許容応力度](01_01_コンクリートの許容応力度.md#コンクリート)の異形鉄筋欄だけから、上端筋／その他と長期／短期に応じた値を採ります。上端筋は両方式とも曲げで選んだ上側の主筋を指しますが、1991方式は表の上端筋欄、1999方式は \\( f\_{b0} \\) の0.8倍を使います。1991方式に1999方式の \\( W,K \\)、多段0.6倍や長さ比較を追加しません。両方式の \\( f\_a,f\_b \\) は別の式の値であり、置き換えません。

### 入力配筋と引張応力度（1999方式）

検定断面の強軸曲げモーメントが負なら上端筋、正なら下端筋を引張側に選びます。ゼロでは鉄筋断面積が小さい側を選び、同じなら下端筋とします。引張側全段の総本数を \\( n\_t \\)、最外段（かぶり側の第1段）の本数を \\( n\_1 \\)、段数を \\( r \\) とします。多段の場合も \\( n\_1 \\) を全本数や段数による平均本数に置き換えません。

主筋1本の断面積と周長は[配筋寸法と公称値](01_02_鉄筋の許容応力度.md#配筋寸法と公称値)の値を用います。引張側の主筋面積と引張応力度は次式で求めます。

\\[ a\_t=n\_t a\_s \\]

\\[ \sigma\_t=\frac{|M\_z|}{a\_t j},\qquad j=\frac{7d}{8} \\]

\\( d \\) は圧縮縁から引張側全段の鉄筋重心までの有効せいです。[梁の許容曲げと中立軸](02_01_RC梁の許容曲げ.md#梁の許容曲げと中立軸)と同じく全段の面積加重平均を使います。かぶり側から第 \\( i \\) 段の本数を \\( n\_i \\)、全せいを \\( D \\) とすると、現在の配筋の段間あき \\( \max(25,1.5d\_b) \\) mmから次式で再現できます。かぶり \\( c\_0 \\) とあばら筋径 \\( d\_w \\) は次項で定義します。

\\[ y\_i=c\_0+d\_w+\frac{d\_b}{2}+(i-1)\left(d\_b+\max(25,1.5d\_b)\right),\qquad d=D-\frac{\sum\_{i=1}^{r}n\_iy\_i}{n\_t} \\]

\\( y\_i \\) は引張側コンクリート表面から各段の主筋中心までの距離です。\\( \sigma\_t \\) は上記の略算式による値であり、鉄筋の許容引張応力度や降伏強度で頭打ちにしません。

### あき・かぶりと横補強筋効果（1999方式）

かぶり \\( c\_0 \\) はコンクリート表面からあばら筋外面まで、あばら筋径を \\( d\_w \\)、断面幅を \\( b \\) とします。最外段を幅方向に均等配置したときの主筋表面間のあき \\( a \\) と、有効長さ \\( C \\) を次式で求めます。

\\[ a=\begin{cases}\dfrac{b-2(c\_0+d\_w)-n\_1d\_b}{n\_1-1}&(n\_1>1)\\\\5d\_b&(n\_1=1)\end{cases},\qquad C=\min(a,3c\_0,5d\_b) \\]

次の寸法図は1段4本の概念図（縮尺なし）です。図の主筋は表面間のあき \\( a \\) で並びます。上下の \\( d \\) の向きは引張側によって反転します。

```text
断面幅方向（最外段、n1=4）
|<-------------------------- b -------------------------->|
|<- c0 ->|dw|<db>|<-- a -->|<db>|<-- a -->|<db>|<-- a -->|<db>|dw|<- c0 ->|
             ○                ○                ○                ○
        あばら筋内面                                      あばら筋内面

断面せい方向（上端引張の例）       材軸方向（あばら筋の間隔）
上面 ────────────────            │     │     │     │
     c0 + dw + db/2               |<-s->|<-s->|<-s->|
主筋重心 ──○──○──○──○──         各位置の脚数 m、本図の断面例では m=2
          ↕ d
下面（圧縮縁）──────────
```

あばら筋1脚の面積を \\( a\_{w1} \\) とします。あばら筋1組の脚数 \\( m \\) と1脚の面積から、横補強筋断面積 \\( A\_{st} \\) を求めます。間隔 \\( s \\) は材軸方向の入力間隔です。採用する換算長さ \\( W \\) は次式です。

\\[ A\_{st}=m a\_{w1},\qquad W=\min\left(\frac{20A\_{st}}{s n\_1},2.5d\_b\right)\quad(s>0) \\]

\\( s\le0 \\) の場合は \\( W=0 \\) とします。\\( A\_{st} \\) は1組の脚の面積の合計であり、定着区間内のあばら筋の組数を掛けません。現在は断面に入力した径・脚数・間隔を検定位置に用い、実際の定着区間ごとにあばら筋を数えたり、局所的な補強範囲・端部の配筋変更を照合したりしません。式には横補強筋の降伏強度を用いません。

\\[ K=\begin{cases}\min\left(0.3\dfrac{C}{d\_b}+0.4,2.5\right)&(\text{長期})\\\\\min\left(0.3\dfrac{C+W}{d\_b}+0.4,2.5\right)&(\text{短期})\end{cases} \\]

\\( W \\) の上限を先に適用し、続いて \\( K \\) の上限2.5を適用します。長期の \\( K \\) には \\( W \\) を加えません。

### 許容値・必要長さ・最終比較（1999方式）

まず異形鉄筋の基準値 \\( f\_{b0} \\) を求め、上端筋、短期、多段配筋の順でそれぞれ1回だけ倍率を掛けます。

\\[ f\_{b0}=F\_c/60+0.6 \\]

\\[ \eta\_{top}=\begin{cases}0.8&(\text{上端筋})\\\\1&(\text{下端筋})\end{cases},\qquad\eta\_{term}=\begin{cases}1&(\text{長期})\\\\1.5&(\text{短期})\end{cases},\qquad\eta\_{row}=\begin{cases}1&(r=1)\\\\0.6&(r\ge2)\end{cases} \\]

\\[ f\_b=f\_{b0}\eta\_{top}\eta\_{term}\eta\_{row},\qquad l\_{db}=\frac{\sigma\_t a\_s}{K f\_b\varphi} \\]

多段配筋では、引張側全段の \\( a\_t \\) と重心による共通の \\( \sigma\_t \\)、最外段の \\( n\_1 \\) による \\( C,W \\) を用い、\\( f\_b \\) 全体を0.6倍して代表検定します。各段の個別応力・あきによる比較ではなく、実際に2段目以降の必要長さが最大かどうかを照合するものでもありません。1999方式の \\( F\_c \\) は入力した設計基準強度を用い、1991方式の材料表の上限36 N/mm²は適用しません。

比較に用いる付着長さ \\( l\_d \\) は、通し筋・カットオフ無しを仮定し、部材長 \\( L \\) と有効せいから算定します。検定位置 \\( p \\) は始端を0、終端を1とする材軸位置です。

\\[ l\_d=\begin{cases}(L+d)/2&(p\le0.25\ \text{または}\ p\ge0.75:\text{端部})\\\\L/2&(0.25<p<0.75:\text{中央})\end{cases},\qquad R\_b=\frac{l\_{db}}{l\_d} \\]

通常の \\( L \\) は節点間の部材長で、連続する梁を一体として扱う設定では一体の部材長を使います。柱フェイスを控除した内法長は、この付着長さ算定には使いません。\\( l\_d \\) は図面から読み取った実際の確保定着長ではありません。柱内への埋込み、折曲げ、フック、機械式定着、主筋の切断位置を評価しないため、\\( R\_b\le1 \\) はこの通し筋モデルの長さ比較を満たすことを表し、定着詳細全体の適否は別途確認が必要です。\\( R\_b>1 \\) は必要長さの超過です。\\( L\le0 \\)、引張筋不足、\\( K\le0 \\) などで算定できない場合は付着検定を省略し、適合とは扱いません。

### 代表計算例（1999方式）

矩形梁の幅400 mm、せい600 mm、上端4本・下端4本の各1段、主筋を数値径20 mm、かぶり40 mm、あばら筋を数値径10 mm・2脚・間隔100 mm、異形鉄筋、\\( F\_c=24 \\) N/mm²とします。\\( L=6000 \\) mm、\\( p=0 \\)、短期、\\( M\_z=-100 \\) kN·mで上端引張です。途中では丸めず、表だけを丸めています。

| 段階 | 代入・結果 |
| --- | --- |
| 引張側断面 | \\( n\_t=n\_1=4,\ r=1,\ a\_s=314.159\ \mathrm{mm^2},\ a\_t=1256.637\ \mathrm{mm^2} \\) |
| 有効せい・応力 | \\( d=600-(40+10+20/2)=540\ \mathrm{mm},\ j=472.5\ \mathrm{mm},\ \sigma\_t=100\times10^6/(1256.637\times472.5)=168.418\ \mathrm{N/mm^2} \\) |
| あき・有効長さ | \\( a=(400-2(40+10)-4\times20)/3=73.333\ \mathrm{mm},\ C=\min(73.333,120,100)=73.333\ \mathrm{mm} \\) |
| 横補強筋 | \\( A\_{st}=2\pi10^2/4=157.080\ \mathrm{mm^2},\ W=\min(20\times157.080/(100\times4),50)=7.854\ \mathrm{mm} \\) |
| 係数・許容値 | \\( K=\min(0.3(73.333+7.854)/20+0.4,2.5)=1.61781,\ f\_b=(24/60+0.6)\times0.8\times1.5\times1=1.2\ \mathrm{N/mm^2} \\) |
| 必要長さ | \\( \varphi=62.832\ \mathrm{mm},\ l\_{db}=\sigma\_t a\_s/(K f\_b\varphi)=433.760\ \mathrm{mm} \\) |
| 最終比較 | \\( l\_d=(6000+540)/2=3270\ \mathrm{mm},\ R\_b=433.760/3270=0.133\le1 \\) |

この例では \\( C \\) はあきで決まり、\\( W,K \\) は上限に達しません。例えば \\( C=5d\_b,\ W=2.5d\_b \\) なら短期の上限適用前は \\( K=2.65 \\) ですが、採用値は2.5です。多段にした場合は \\( a\_t,d,n\_1 \\) を配筋に応じて求め直したうえで、\\( \eta\_{row}=0.6 \\) を1回だけ適用します。

### 記号・単位

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( l\_{db} \\) | 必要定着長さ | mm |
| \\( l\_d,L \\) | 比較用の付着長さ、算定に使う部材長 | mm |
| \\( p,R\_b \\) | 始端からの材軸位置比、付着検定比 | - |
| \\( \sigma\_t \\) | 検定断面の鉄筋引張応力度 | N/mm² |
| \\( M\_z,Q\_d \\) | 強軸曲げモーメント、設計用せん断力 | N·mm、N |
| \\( a\_t,b,d,j \\) | 引張側全段の断面積、幅、有効せい、応力中心間距離 | mm²、mm、mm、mm |
| \\( D,y\_i,n\_i \\) | 全せい、引張縁から第i段の主筋中心までの距離、第i段の本数 | mm、mm、- |
| \\( n\_t,n\_1,r,m \\) | 引張側総本数、最外段本数、引張側段数、あばら筋脚数 | - |
| \\( c\_0,d\_w,s,a \\) | かぶり、あばら筋径、材軸方向間隔、主筋のあき | mm |
| \\( A\_{st} \\) | あばら筋1組の脚の断面積合計 | mm² |
| \\( a\_s \\) | 主筋 1 本の断面積 | mm² |
| \\( K \\) | 付着割裂の検討用係数 | - |
| \\( f\_b \\) | 付着の許容応力度 | N/mm² |
| \\( \varphi \\) | 主筋 1 本の周長 | mm |
| \\( C \\) | あき・かぶり・鉄筋径から定まる付着の有効長さ | mm |
| \\( W \\) | 横補強筋効果を表す換算長さ | mm |
| \\( d\_b \\) | 主筋の呼び名の数値または数値径 | mm |
| \\( F\_c \\) | コンクリートの設計基準強度 | N/mm² |
