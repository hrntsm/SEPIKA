# 鋼大梁の長期たわみ

鋼大梁の長期の弾性曲げたわみを求めます。適用する支持・荷重条件と曲率積分はRC大梁と共通です。

## たわみ（長期のみ）

鋼大梁の長期荷重に対する鉛直の弾性曲げたわみを、中央の検定行に参考値として表示します。両端を結ぶ弦からの最大絶対たわみ \\(\delta\\) [mm]、その位置 \\(x\\) [mm]、その位置での符号付き変位 \\(v\\) [mm] と比 \\(\delta/L\\) を示します。位置は i 端からの距離、変位は下向きを正とします。中央の検定行が欠ける場合は、中央に最も近い検定行に未算定理由を付記します。たわみ参考値と未算定理由は、応力度の検定比・合否の集計から分離します。

### 鋼・RC大梁の適用条件と曲率積分

対象は、両端の鉛直並進が節点で直接拘束され、強軸曲げによる変位が鉛直となる、単一要素の水平な等断面の弾性梁です。両端のフェース距離が確認済みでゼロ、解析に用いる剛域・仕口オフセット・材端偏心もゼロの場合に、節点間長 \\(L\\) [mm] をスパンとして採用します。解析と同じ固定・積載荷重ケースと組合せ係数を用い、当該梁上の部材荷重は鉛直の全長等分布に限ります。全長等分布と材端曲げはともに上下の符号を保持し、端偶力による曲げも扱います。

\\(E\\) [N/mm²] は割当材料のヤング係数、鋼梁の \\(I\\) [mm⁴] は梁単体の強軸断面二次モーメント \\(I_y\\)（要素局所 z 軸まわり）です。[RC大梁](02_10_RC梁の長期たわみ.md#梁の長期たわみ)は長方形総断面の値を用います。採用する正の有限な一定 \\(EI\\) が解析の強軸曲げ剛性と一致することを確認します。評価する変形は曲げによる弾性変位で、せん断変形や軸力による二次効果は対象外です。

両端の断面曲げ \\(m_i,m_j\\) [N·mm] は、下側が引張となる曲げを正にそろえます。[解析断面力の符号規約](../05_構造解析/02_線形静解析.md#線形静解析)での \\(M_z\\) は局所 \\(-y\\) 側引張が正です。両端曲げと全スパンの荷重強度 \\(w\\) [N/mm]（下向き正）から曲げ図を求めます。

\\[ M(x) = \left(1-\frac{x}{L}\right)m_i+\frac{x}{L}m_j+\frac{w}{2}x(L-x) \\]

曲げ図が解析断面力と一致することを確認します。\\(EI v^{\prime\prime}=-M(x)\\) を弦上の両端で \\(v(0)=v(L)=0\\) として積分し、\\(v^{\prime}(x)=0\\) となるスパン内の全位置と両端を比較して \\(\delta=\max_{0\le x\le L}|v(x)|\\) を求めます。下向き等分布だけを受ける単純支持梁では最大たわみは中央の \\(5wL^4/(384EI)\\)、対称な両端固定梁では中央の \\(wL^4/(384EI)\\) です。

片持ち、架構で支持する梁、一本部材、フェース距離・剛域等を持つ梁、集中荷重・部分分布荷重、採用剛性が異なる合成梁など、条件を満たさない場合は理由付きで未算定とします。支持・荷重・剛性が異なる場合は実際の条件を用いて別途たわみを確認してください。日本建築学会『鋼構造許容応力度設計規準』2019年版8.1（本文 p.20、解説 p.71）の制限は通常の梁で \\(L/300\\)、片持ち梁で \\(L/250\\) です。本欄は変形制限の合否を判定しません。
