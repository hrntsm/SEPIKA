# 鋼梁・柱のせん断検定

対応する鋼梁・柱について、断面形状と検討方向ごとの有効面積でせん断を検定します。ブレースの軸力検定とは項目が異なります。

## せん断の検定

対応するH形・角形鋼管・その他の形状の柱／大梁は、純せん断の方向別検定比を求め、その和で検定します。
**断面形状を平鋼として入力した柱・大梁では、局所y・zのどちらかにせん断力があれば、その位置の鋼部材検定は理由付きの検定不能です。** 非有限のせん断力も検定不能です。検定不能の条件は形状とせん断力で決まり、剛性用せん断有効断面積に直接入力した正値や非正値を含めて適用します。圧縮時の法定細長比の判定は先に適用します。両方向のせん断力が0のときは軸力・曲げの検定を行い、ブレースは軸力を検定します。

\\[ R\_y = \frac{|Q\_y|}{A\_y f\_s},\qquad R\_z = \frac{|Q\_z|}{A\_z f\_s},\qquad R\_{\mathrm{shear}}=R\_y+R\_z \\]

von Mises合成には、各方向のせん断応力度の和を用います。

\\[ \tau\_{\mathrm{sum}}=\tau\_y+\tau\_z=\frac{|Q\_y|}{A\_y}+\frac{|Q\_z|}{A\_z} \\]

方向別比の和とτsumによる接続は、SEPIKAの採用規約です。せん断面積・二方向合成について、規準の版・形状・同時応力の適用条件との照合は未完了であり、設計での採用継続の承認は保留しています（[#951](https://github.com/hrntsm/SEPIKA/issues/951)）。
同じ点のせん断成分の絶対値の和は二乗和平方根以上ですが、代表値Q/Adが各点の応力を過小評価しない保証にはなりません。曲げ・軸力の応力度も同じ点で評価する必要があり、加算規約だけから任意断面の安全側を判定できません。
**H形鋼柱に引張軸力・強軸曲げ・弱軸せん断が同時に作用する位置は、理由付きの検定不能です。** [H形鋼柱の適用制限](03_04_鋼梁_柱の組合せ応力検定.md#h形鋼柱で引張強軸曲げ弱軸せん断が同時に作用する場合)

**現行の検定比が1以下でも、軸力が0または圧縮で強軸曲げと弱軸せん断を受けるH形鋼柱、純強軸せん断を受ける直角・一様厚BOX、せん断を受ける中実丸鋼では、同じ許容値を用いた局所弾性応力の照査で比が1を超えた例があります。** 局所応力の確認が必要な場合は、断面内の応力分布と許容値の適用条件を確認してください。 [軸力が0または圧縮のH形鋼柱](https://github.com/hrntsm/SEPIKA/issues/1483)・[直角BOX](https://github.com/hrntsm/SEPIKA/issues/1453)・[中実丸鋼](https://github.com/hrntsm/SEPIKA/issues/1452)

各方向のvon Mises比全体を足して軸力・曲げを二重算入する計算は行いません。
円形鋼管の純せん断比は方向別比の最大です。軸力とせん断の合成は[von Mises 合成](03_04_鋼梁_柱の組合せ応力検定.md#von-mises-合成)を参照してください。

せん断応力度は \\( \tau\_y = |Q\_y|/A\_y \\)、\\( \tau\_z = |Q\_z|/A\_z \\) とし、せん断有効断面積 \\( A\_y, A\_z \\) は梁・柱共通の単一定義として断面形状ごとに次式によります:

- 欠損なし標準H 形: \\( A\_y = t\_w(H - 2t\_f) \\)、\\( A\_z = 2Bt\_f/1.5 \\)。フィレット面積は加算しません。
- 角形鋼管（同心円弧・一様厚さ、外角R \\( r\_o\ge t \\)）: \\( A\_y = 2t(H-2r\_o) \\)、\\( A\_z = 2t(B-2r\_o) \\)。対向する直線部だけを用い、円弧面積を加算しません。
- 明示した外角R \\( r\_o=0 \\) の溶接箱: \\( A\_y = 2t(H-2t) \\)、\\( A\_z = 2t(B-2t) \\)。正の角Rを持つモデルとは別の対向板モデルです。
- 円形鋼管: \\( A\_y = A\_z = \pi t (D - t)/2 \\)
- 丸鋼、溝形鋼、T形鋼、山形鋼など: 各方向の正の剛性用せん断有効断面積を用い、非正なら全断面積Aを代替値とします。一般軽量形鋼の単一リップ溝形材や圧縮山形鋼の未検定条件は別途適用します。
- 断面形状を持たない一般断面: 各方向の正の供給値を用い、非正なら全断面積Aを代替値とします。断面名だけでは平鋼の形状を特定できません。

上記の剛性用面積や全断面積による代替では、局所せん断応力度の確認が必要です。丸鋼や板組断面では局所応力度の分布が異なります。

平鋼の検定を未算定とするのは、両方向のせん断応力度をどの位置で評価し、どの許容値を適用するかが確定していないためです。長期の許容せん断応力度は F/(1.5√3)、短期はその1.5倍です。日本建築学会『鋼構造許容応力度設計規準』2019年版の5.1(2) 式(5.2)（p.9）、5.6（p.14）および建築基準法施行令第90条が許容値を定めています。 [規準の書誌](https://ndlsearch.ndl.go.jp/books/R100000002-I030037737)・[建築基準法施行令第90条](https://laws.e-gov.go.jp/law/325CO0000000338#Mp-At_90)

同規準5.5 式(5.24)の組合せは同一部分の応力度を使います。梁の10.1（本文p.22、解説p.78 式(10.1.2)）における Q/(ht) は、hを梁せい、tをウェブ厚とする評価です。柱は11.9（本文p.27、解説p.97）を参照します。これらの規定から平鋼の局所最大応力度または平均応力度にどの許容値を組み合わせるかは決まりません。SEPIKAでは平鋼の剛性用面積を検定面積へ流用せず、初等梁の局所応力係数による代替検定も行いません。

寸法H/B/tと外角Rはmm、面積Ay/Azはmm²、Qy/QzはN、τとfsはN/mm²です。
検定用の \\( (A\_y,A\_z) \\) は強軸Qy・弱軸Qzの順で、剛性用断面性能 \\( (a\_{s,y},a\_{s,z}) \\) の添字順とは異なります。
曲げについては強軸Mzが断面性能Iy、弱軸MyがIzに対応します。

角形鋼管・角形CFTの断面を新たに追加・形状変更するときは、角部外半径（角R）を必ず入力します。未設定のままの確定や、設定済み半径を未設定へ戻す操作は入力エラーになります。カタログからの追加も同じ条件です。溶接組立BOXの直角は0を明示し、未知から0を補完しません。この必須入力はH形鋼のフィレット半径や、角部半径を持たない断面へは適用しません。既存データで半径が不足する場合の計算時の防御も維持します。

角形鋼管の梁・柱では、外角Rの未知、\\( 0<r\_o<t \\)、両方向いずれかの直線長が0以下、不正寸法、非有限・非正の面積を理由付きの検定不能とします。
負値・NaN・無限大・外角Rの上限超過も拒否し、未知を0にしたり、不成立の長さを丸めたり、未検定を数値0や合格へ置き換えたりしません。
形状を持たず名称だけでBoxに分類された断面も、明示した外角R=0の溶接箱とはみなさず、寸法・外角Rの不足として扱います。
外角Rが断面外形に収まっても、\\( r\_o=\min(H,B)/2 \\) では一方向の直線長が0になるため本検定には適用できません。
この検定モデルの条件は、内角Rを \\( \max(r\_o-t,0) \\) とする断面幾何で\\( 0<r\_o<t \\)を表現することまで禁止しません。
軸力のみを扱うブレース検定は、このせん断面積の適用条件の対象外です。

角形鋼管400×300×12の検定用 \\( (A\_y,A\_z) \\) は、外角R=12で(9024,6624)、外角R=30で(8160,5760)、明示した外角R=0の溶接箱で(9024,6624) mm²です。
外角R=0と12で数値が一致しても、採用モデルの区別は維持します。

検定面積には、前述の方向別面積を採用します。
ウェブ有効率rは欠損なしで1であり、外角Rとは別の記号です。弱軸Hにはκ=1.5を用い、角形鋼管は直線部、溶接箱は対向板、円管はA/2を用います。角形鋼管の式は直線領域の幾何に基づきます。
規準の版ごとのウェブせい・フランジ応力評価・フィレット、冷間成形/溶接、矩形と角Rの適用条件の照合は未完了です。既存の未算定条件を解除する根拠にはしません。
