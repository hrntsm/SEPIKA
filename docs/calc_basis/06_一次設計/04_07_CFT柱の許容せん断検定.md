# CFT柱の許容せん断検定

鋼管部分の許容せん断耐力と需要を比較します。地震時は選んだ需要方式に応じて終局曲げ耐力が必要です。

充填コンクリートの設計基準強度Fcが24 N/mm²未満の場合は検定不能です。[CFTの適用条件と別途確認事項](04_05_CFTの部材検定.md#cft-の適用条件と別途確認)を参照してください。

## 鋼管部分の許容せん断耐力

許容せん断耐力は鋼管部分だけで評価します。角形のせん断有効断面積は方向別（\\( 2t(H-2t) \\)／\\( 2t(B-2t) \\)）とし、二方向のせん断検定比の最大を用います。円形は鋼管全断面積の1/2をせん断有効断面積とし、二方向のせん断力の合力 \\( \sqrt{Q\_y^2+Q\_z^2} \\) を許容せん断耐力と比較します。

## CFT 柱の地震時設計用せん断

\\[ Q\_D = \min(Q\_{D1}, Q\_{D2}) \\]

\\[ Q\_{D1} = \sum {}\_c M\_y/h\' \\]

ここで cMy には [CFT 柱の終局 N–M 相互作用と利用条件](../08_部材終局耐力/06_CFT_柱_終局耐力.md#cft柱の終局耐力)による終局曲げ耐力 Mu(N)（柱分類対応）を用い、柱頭・柱脚同一断面の仮定で \\( \sum {}\_c M\_y = 2 \cdot M\_u(N) \\) とします。

\\[ Q\_{D2} = Q\_L + n \cdot Q\_E \\]

QD1 または min を選択した場合、角形CFTは検討軸ごとの座屈長さでMu(N)を求めます。円形CFTは両軸の座屈長さのうち長い方でMu(N)を求め、両方向に同じ値を用います。

円形CFTで設計軸力が軸終局耐力の範囲外にある場合は、表示されたMuやQD1/minの結果を設計判定に使わないでください。範囲外でも正のMuが表示される場合があります。

正方形の長柱で圧縮軸力がコンクリート座屈耐力を超える場合は、[Case2の適用域・有効域](../08_部材終局耐力/06_04_CFT正方形長柱の終局曲げ耐力_Case2.md#正方形の長柱-case2)に従います。
この Case2 で曲げ耐力が下がると、QD1 と min の要求せん断力も下がり得ます。曲げの耐力低下だけで設計全体を安全側とは判定しません。
Case2の純圧縮端でMu=0となる場合や、角形の軸終局限界を超えてMuを算定できない場合は、QD2に自動で切り替えません。
無効な寸法・座屈荷重や適用範囲外で Mu が求められない場合は、QD1/min も理由付き未算定です。
許容応力度検定の未算定理由と、終局検定の軸NG／曲げ耐力未算定を区別して確認してください。
