# RC柱の軸力・二軸曲げ検定

圧縮・純引張の軸力限界と、同じ設計軸力に対する二軸曲げの許容値を求めます。

## 柱（RC規準14条）

RC 柱の軸力＋二軸曲げ＋せん断を、RC規準 14条に基づいて検定します。

**算定式**

許容軸力:

\\[ N\_A = \min(f\_c \cdot A\_e, f\_t \cdot A\_e/n) \\]

\\[ A\_e = A + (n-1) \cdot A\_s \\]

ここでAはコンクリートの総断面積、Asは全主筋断面積です。NAは圧縮軸力単独の上限であり、曲げがある断面の許容値は次のN–M相関から読みます。n・fc・ftは[梁の許容曲げ](02_01_RC梁の許容曲げ.md#梁の許容曲げと中立軸)と同じ材料の選び方です。

### 柱の純引張

純引張ではコンクリートの引張抵抗を考慮せず、全主筋が負担する軸力と許容引張力を比較します。矩形・円形とも、全主筋断面積As [mm²] と、主筋の材種・径・荷重期間による許容引張応力度ft [N/mm²] を使います。

\\[ N\_T=A\_s f\_t \\]

これは一様引張の軸力釣合いから得られる値です。引張軸力の大きさをT [N] とすると、曲げ需要が0の場合はT/NTが1以下なら数値上適合、1を超えれば不適合です。円形柱でも純引張の全主筋面積を等価矩形の両縁筋面積へ減らしません。Fcが60 N/mm²を超える場合も純引張を算定します。設計用ヤング係数比を必要とする圧縮軸力とN–M照査は未算定です。

例えばFc24・SD345、径19 mmを8本とする対称配筋では、As=2268.229896 mm²です。長期ft=215、短期ft=345 N/mm²より、NTは長期487669.428 N、短期782539.314 Nです。T=1000000 N、曲げ0の検定比は長期2.050569、短期1.277891となり、いずれも不適合です。

この純引張上限から引張と曲げの相互作用を直線補間しません。非零曲げを伴う引張は、[柱の許容N–M境界](#柱の許容nm境界)で算定できる範囲に限ります。

### 柱の二軸曲げの合成

設計軸力 \\( N\_d \\) は圧縮正とし、引張正の解析軸力の符号を反転します。各方向の許容曲げは[柱の許容N–M境界](#柱の許容nm境界)から、この同じ \\( N\_d \\) で読み取ります。

| 記号 | 意味 | 単位・条件 |
| --- | --- | --- |
| \\( M\_z,M\_y \\) | 検定位置の強軸・弱軸の解析曲げモーメント（需要） | N·mm |
| \\( M\_{A,z}(N\_d),M\_{A,y}(N\_d) \\) | 矩形柱の指定軸力での強軸・弱軸の許容曲げ | N·mm |
| \\( M\_A(N\_d) \\) | 円形柱の指定軸力での両方向共通の許容曲げ | N·mm |
| \\( r\_z,r\_y \\) | 各方向の曲げ需要の絶対値／許容曲げ | − |
| \\( r\_M,r\_N,R\_{NM} \\) | 二軸曲げの合成比、軸力比、軸力曲げ検定比 | − |
| \\( N\_d,N\_A \\) | 設計軸力（圧縮正）、圧縮軸力単独の許容上限 | N、\\( N\_A \\) は[柱の許容軸力](#柱rc規準14条)による |

**矩形柱**：方向別の需要をそれぞれの許容曲げで除し、その比を加算します。

\\[ r\_z=\frac{|M\_z|}{M\_{A,z}(N\_d)},\qquad r\_y=\frac{|M\_y|}{M\_{A,y}(N\_d)} \\]

\\[ r\_M=r\_z+r\_y \\]

**円形柱**：等積正方形に近似し、両縁の筋面積を各全主筋の1/4、中央集約筋を0として、一つの許容N–M境界を求めます。等価幅は[円形柱のせん断補強筋比](02_04_RC柱のせん断検定.md#円形柱のせん断補強筋比)の \\( b\_e \\) と同じです。共通の許容曲げで除した比の二乗和を使います。

\\[ r\_z=\frac{|M\_z|}{M\_A(N\_d)},\qquad r\_y=\frac{|M\_y|}{M\_A(N\_d)} \\]

\\[ r\_M=r\_z^2+r\_y^2 \\]

各方向の許容曲げが正でないとき、その方向に非零の曲げ需要があれば、その位置の軸力・曲げを理由付きの「未検定」とします。理由には軸力・圧縮軸力単独上限、両方向の許容曲げと曲げ需要を表示します。

#### 曲げが未検定の位置での軸力判定

矩形・円形柱の通常の長期・短期断面検定では、同じ位置の有限な軸力の大きさが、その符号に対応する有限かつ正の許容上限（圧縮はNA、引張はNT）を超える場合、「軸」の不適合を併記します。検定比は軸力の大きさを上限で除した値です。比が有限の数値で表せる範囲を超える場合は、表現可能な最大値を検定比の下限として表示します。詳細には上限と設計軸力をN単位で表示します。上限と一致する場合は曲げの未検定理由を表示します。同じ位置で確定した[せん断の不適合](02_04_RC柱のせん断検定.md#軸力曲げが未検定の位置)も併記し、NG部材数は部材単位で数えます。未検定が残る部材は全件適合にはなりません。

日本建築学会『鉄筋コンクリート構造計算規準・同解説』2024年版12条（p.17）、14条(1)(2)（p.19）および14条解説の断面釣合い（pp.144–146）は、コンクリート引張の無視、長期・短期で共通のヤング係数比、コンクリート・鉄筋の許容応力度による断面合力の算定の根拠です。一様ひずみの軸力上限を使い、許容曲げが算定できない位置でも、独立に確認した軸力超過を示します。

#### 短期の解析内力が非有限の場合

矩形・円形柱の短期検定で、軸力が非有限の場合は軸力・曲げを理由付きで未検定とします。一方の曲げが非有限の場合は二軸の合成を未検定とし、確定した軸力超過や、有限な方向の曲げ比だけで限界を超える不適合を併記します。有限なゼロは検定に使います。せん断は、方式と方向ごとに必要な内力から判定します。 [短期の解析内力が非有限の場合のせん断検定](02_04_RC柱のせん断検定.md#短期の解析内力が非有限の場合)

軸力・曲げ・損傷制御用せん断スパンに必要な断面力が非有限の場合や、柱端の応答軸力が非有限で地震時せん断を算定できない場合も、有限な需要と正の有限な許容値から確定した軸力・曲げの不適合を併記します。その検定比が数値で表せる範囲を超えるときは、表現可能な最大値を検定比の下限として表示します。

#### 曲げ比と軸力比

許容曲げが正でない方向の需要が厳密に0なら、その方向の曲げ比は0とし、他方向の正の許容曲げに対する需要を合成します。両方向の曲げ需要が0の場合は軸力単独で判定し、圧縮軸力が許容上限と一致すれば比1で適合、上限の1.01倍なら比1.01で不適合です。正の微小な許容曲げは丸めて0とせず、その値で計算します。表示上の「0.0」だけで内部値が厳密に0とは判断できません。

軸力単独上限で非零曲げを許容できない境界は、一様圧縮の断面釣合いによります。全断面が許容圧縮応力に達した状態で非零の曲率を加えれば、圧縮側の応力が上限を超えるか、上限内に保つために軸合力を下げる必要があります。この境界の確認は円形等価近似や二軸合成式の全域精度を保証するものではありません。

両形状とも、圧縮時は圧縮許容軸力、引張時は純引張の許容上限で除した軸力比を求め、二軸曲げの合成比との大きい方を検定比とします。軸力0の軸力比は0です。

\\[ r\_N=\begin{cases}N\_d/N\_A&(N\_d>0,\ N\_A>0)\\\\(-N\_d)/N\_T&(N\_d<0)\\\\0&(\text{その他})\end{cases},\qquad R\_{NM}=\max(r\_N,r\_M) \\]

検定比は1以下を数値上の適合とします。円形の二軸曲げ比には二乗和の平方根を取りません。

ここに示した式・集約配筋・離散化は現行の採用モデルです。日本建築学会『鉄筋コンクリート構造計算規準・同解説』2024年版14条で確認できる断面釣合いに対し、現行の配筋集約・円形近似・二軸曲げの方法を全軸力域に適用できる条件と精度は未確認です。近似を一律に安全側とみなしません。

### 柱の許容N–M境界

矩形柱の各軸を別々に検討し、検討方向の幅b・せいDを使います。強軸（Mz）は上下辺、弱軸（My）は左右辺の最外段1列を両縁の筋とします。両縁の各面積をac・at、圧縮縁からの位置をそれぞれdt・D−dtとし、それ以外の全主筋を \\( a\_p=A\_s-a\_c-a\_t \\) として断面中央D/2に集約します。交点の筋は重複させません。実配筋の全位置を積分するモデルとは異なります。

次図は一方向曲げの断面と応力の符号の対応です。yは圧縮縁から下向き、Nは圧縮を正、Mの大きさは断面中心まわりで評価します。xnがDを超える場合は全断面圧縮です。

```text
      断面（幅 b）               換算応力 σc（圧縮正 →）
y=0   ┌──────────┐              │────── s xn
y=dt  │ ● ac     │              │    ／
      │          │              │  ／
y=xn  ├ 中立軸 ──┤              ● 0
y=D/2 │ ○ ap     │              │  コンクリート引張は0
      │          │              │  鉄筋応力は n s(xn−y)
y=D−dt│ ● at     │              │  （y>xnでは引張）
y=D   └──────────┘              │
```

図では \\( d\_t<x\_n<D/2 \\) の場合を示します。平面保持による線形ひずみに対応して、コンクリート換算応力の勾配sを次の許容条件で制限します。圧縮側・引張側の鉄筋許容応力度には同じftを用います。

\\[ \sigma\_c(y)=s(x\_n-y)\quad(0\le y\le x\_c),\qquad x\_c=\min(x\_n,D),\qquad \sigma\_s(y)=ns(x\_n-y) \\]

\\[ s=\min\left\\{\frac{f\_c}{x\_n},\ \frac{f\_t}{n|x\_n-d\_t|},\ \frac{f\_t}{n|x\_n-(D-d\_t)|}\right\\} \\]

面積0の筋と中立軸上の筋の項は制限から除きます。中央の集約筋は両縁筋の間にあり、同じftなのでその応力度制限を別には加えません。コンクリート引張を無視し、各筋群 \\( i\in\\{c,t,p\\} \\) の位置・面積を \\( (y\_i,a\_i) \\) とすると、鉄筋位置のコンクリートとの重複を除いた力は次式です。

\\[ k\_i=\begin{cases}n-1 & (y\_i\le x\_n)\\\\ n & (y\_i>x\_n)\end{cases},\qquad F\_i=k\_i a\_i s(x\_n-y\_i) \\]

\\[ N(x\_n)=bs\left(x\_n x\_c-\frac{x\_c^2}{2}\right)+\sum\_i F\_i \\]

\\[ M(x\_n)=\left|bs\left\\{\frac{x\_n D x\_c}{2}-\frac{(x\_n+D/2)x\_c^2}{2}+\frac{x\_c^3}{3}\right\\}+\sum\_i F\_i\left(\frac D2-y\_i\right)\right| \\]

このNとMは同じ線形応力分布の合力と断面中心まわりのモーメントです。xnを変えると、少なくとも一つの許容応力度に達する点 \\( (N(x\_n),M(x\_n)) \\) が得られます。これが採用する一軸の許容N–M境界です。終局強度の塑性応力分布による境界とは区別します。

#### 指定軸力で許容曲げを読む

現在は \\( x\_n/D=0.02\sim10 \\) の対数等間隔400点に軸力単独の点 \\( (N\_A,0) \\) を加え、軸力順に並べた隣接点の間で線形補間します。設計軸力 \\( N\_d \\) を挟む点が \\( (N\_0,M\_0),(N\_1,M\_1) \\) なら、

\\[ M\_A(N\_d)=M\_0+\frac{N\_d-N\_0}{N\_1-N\_0}(M\_1-M\_0) \\]

となります。同じ軸力の隣接点では大きいMを使います。圧縮側の範囲外は圧縮端点値を使います。引張軸力で点列の最小軸力を下回る方向は許容曲げを0として扱い、その方向に非零の曲げ需要があれば理由付き未検定とします。引張側の端点曲げを範囲外へ流用せず、純引張上限までの境界を新たに補間しません。曲げ0なら点列範囲によらず純引張の軸力比で判定します。

例えばb=D=600 mm、dt=60 mm、ac=at=1200 mm²、ap=1200 mm²、n=15、fc=8 N/mm²、ft=215 N/mm²としてxn=300 mmを選ぶと、

\\[ s=\min(8/300,\ 215/(15\times240),\ 215/(15\times240))=0.026667\\,\mathrm{N/mm^3} \\]

\\[ N\_c=720000\\,\mathrm N,\quad F\_c=107520\\,\mathrm N,\quad F\_t=-115200\\,\mathrm N,\quad F\_p=0 \\]

\\[ N=712320\\,\mathrm N=712.320\\,\mathrm{kN},\qquad M=197452800\\,\mathrm{N\\,mm}=197.453\\,\mathrm{kN\\,m} \\]

です。圧縮縁コンクリートが支配し、鉄筋応力度の大きさは両縁とも96 N/mm²です。この点は連続式の説明例であり、400点の点列に必ず含まれるとは限りません。実際の指定NでのMAは上記補間によります。

| 記号 | 意味 | 単位 |
| --- | --- | --- |
| \\( x\_c \\) | コンクリート圧縮域の深さ | mm |
| \\( a\_p \\) | 断面中央に集約する残余主筋面積 | mm² |
| \\( k\_i \\) | コンクリートとの重複を除いた鉄筋換算係数 | − |
| \\( F\_i,N,N\_d \\) | 鉄筋の換算合力、軸力、設計軸力（圧縮正） | N |
| \\( M,M\_A \\) | 断面中心まわりの曲げモーメントの大きさ、指定軸力での許容曲げ | N·mm |
