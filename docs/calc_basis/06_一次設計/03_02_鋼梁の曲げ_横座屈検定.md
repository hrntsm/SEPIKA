# 鋼梁の曲げ・横座屈検定

鋼梁の単独曲げを検定します。断面形状・補剛条件と、H形強軸の断面欠損を考慮して曲げ応力度と許容値を求めます。

強軸・弱軸の単独曲げは、各方向の曲げ応力度をその方向の許容値で除して判定します。
上下非対称組立H形鋼大梁の強軸曲げには、[上下縁それぞれの断面係数と許容値](#上下非対称組立h形鋼大梁の強軸曲げ)を用います。
その他の[曲げ応力度の算定式](03_04_鋼梁_柱の組合せ応力検定.md#算定式梁)では、円形鋼管の二方向曲げを合成して扱います。

## 上下非対称組立H形鋼大梁の強軸曲げ

上下のフランジ幅または厚さが異なる組立H形鋼の大梁では、図心から上下縁までの距離と、曲げの符号により決まる圧縮縁・引張縁を使って検定します。次の条件をすべて満たす位置が対象です。

- 強軸曲げモーメント \\( M\_z \\) が作用し、軸力 \\( N \\)、弱軸曲げ \\( M\_y \\)、せん断 \\( Q\_y,Q\_z \\)、ねじり \\( M\_x \\) がいずれも0です。
- 断面欠損の指定がなく、強軸断面二次モーメントは実形状から算定します。
- 2019年版の許容曲げ応力度を使用し、横座屈による低減を要しない条件を設計者が確認したうえで、「横座屈長さ lb 直接入力[mm]」の該当区間に0を指定します。0は断面照査における横座屈長さの理想化を表します。区間の指定値は全荷重組合せに共通のため、正負の曲げが生じる場合は両方の圧縮縁について条件を確認します。節点間距離や等間隔横補剛本数から自動算定する場合は、この適用条件を満たしません。

断面力が0かどうかは検定に渡される値で判定します。理論上の純曲げでも、解析で微小なせん断力が生じた位置は組合せの未算定になります。 [#1599](https://github.com/hrntsm/SEPIKA/issues/1599)

局所 \\( y \\) の正側を上、負側を下とします。強軸断面二次モーメントを \\( I\_y \\) [mm⁴]、図心から上縁・下縁までの距離をそれぞれ \\( c\_{\mathrm{上}},c\_{\mathrm{下}} \\) [mm] とし、上下縁の断面係数 [mm³] と応力度 [N/mm²] を求めます。

\\[ Z\_{\mathrm{上}} = \frac{I\_y}{c\_{\mathrm{上}}},\qquad Z\_{\mathrm{下}} = \frac{I\_y}{c\_{\mathrm{下}}} \\]

\\[ \sigma\_{\mathrm{上}} = -\frac{M\_z}{Z\_{\mathrm{上}}},\qquad \sigma\_{\mathrm{下}} = \frac{M\_z}{Z\_{\mathrm{下}}} \\]

\\( M\_z \\) [N·mm] が正なら上縁が圧縮、負なら下縁が圧縮です。全断面で照査するには、圧縮側フランジとウェブが次の幅厚比の限度をともに満たす必要があります。

| 板要素 | 幅厚比に使う寸法 [mm] | 局部座屈の影響を省ける条件 |
| --- | --- | --- |
| 圧縮側フランジ | フランジ全幅の半分 \\( b \\)、圧縮側フランジの板厚 \\( t\_f \\) | \\( b/t\_f \le 0.53\sqrt{E/F\_f} \\)（式(9.1)） |
| 溶接組立大梁のウェブ | 全せいから上下のフランジ厚を引いた内法せい \\( d \\)、ウェブの板厚 \\( t\_w \\) | \\( d/t\_w \le 2.4\sqrt{E/F\_w} \\)（式(9.5)） |

\\( E \\) は鋼材のヤング係数、\\( F\_f,F\_w \\) は各板厚に対応する基準強度です。いずれも N/mm² で扱います。引張側フランジの幅厚比は、この曲げの符号に対する全断面の適用条件に含めません。

条件を満たす場合は、圧縮縁には許容曲げ応力度 \\( f\_b \\)、引張縁には許容引張応力度 \\( f\_t \\) を使い、応力度の絶対値を対応する許容値で除した比の最大値を検定比とします。横座屈低減を要しない条件での \\( f\_b \\) と \\( f\_t \\) はともに長期 \\( F/1.5 \\)、短期 \\( F \\) です。この全断面の応力度照査では最大板厚に対応する共通の \\( F \\) を適用します。

幅厚比が限度を超える場合や限度を確認できない場合、有効断面による照査は未算定です。無効部分を控除すると図心が移動するため、全断面の各縁の応力度比からは有効断面の各縁の応力度比を確定できません。

図9.1.3のように、フランジは幅方向の自由縁から無効部分を控除しても、ウェブで支持された部分に板厚を保って残ります。ウェブは板の中央から無効部分を控除するため、フランジの外面位置は変わりません。上下の外縁間距離は全せい \\( h \\) [mm] のままであり、上下縁の応力度の絶対値の和は \\( |M\_z|h/I\_{y,\mathrm{eff}} \\) です。平行軸の定理により、有効断面の図心まわりの断面二次モーメント \\( I\_{y,\mathrm{eff}} \\) は全断面の \\( I\_y \\) を超えません。このとき、少なくとも一方の縁の応力度比に対する下限を次式で求めます。

\\[ \frac{|M\_z|h}{I\_y\bigl(f\_{t,\mathrm{上}}+f\_{t,\mathrm{下}}\bigr)} \\]

\\( f\_{t,\mathrm{上}}, f\_{t,\mathrm{下}} \\) は各フランジの板厚に対応する基準強度から求めた許容応力度の上限 [N/mm²] です。下限が1を超える場合は、上下いずれかの縁の不適合、曲げ比の下限、および有効断面による曲げ照査が未算定である理由を表示します。下限が1以下の場合や確認できない場合は理由付きで未算定とします。

横座屈長さが有限の正値または未指定で、他の適用条件を満たす場合は、圧縮縁の許容曲げ応力度の上限 \\( f\_t \\) と引張縁の \\( f\_t \\) を使って検定比の下限を求めます。この下限が1を超える場合は、確定した不適合と横座屈の未算定理由を表示します。下限が1以下の場合は理由付きで未算定となります。断面欠損、断面力の併存、横座屈長さの負値・非有限値など、他の適用条件を満たさない場合も、理由付きで未算定となります。正の横座屈長さに対する算定条件は調査中です。 [#1598](https://github.com/hrntsm/SEPIKA/issues/1598)

圧縮軸力があり、[有効細長比の法定上限](03_06_鋼部材の座屈長さ_有効細長比.md#圧縮材の有効細長比上限)を超える位置では、細長比の不適合と強軸曲げとの組合せが未算定である理由を併記します。

日本建築学会『鋼構造許容応力度設計規準』2019年版の式(6.1)・式(6.2)（p.15）で軸応力度を0とすると、圧縮縁は \\( f\_b \\)、引張縁は \\( f\_t \\) との比較に帰着します。許容値の根拠は同規準 5.1(1) 式(5.1)（p.9）、5.1(4)a（pp.10–11）、5.6（p.14）です。梁の曲げ応力度と幅厚比の適用は 10.1(2)(3)（p.22、解説 p.78 式(10.1.1)）、幅厚比の限度は 9.1(1)a)・(2)b)（pp.20–21）と解説の式(解9.1.3)（p.75）に基づきます。幅厚比に用いる板幅は解説の図9.1.2(b)（p.76）、無効部分の位置は 9.1(3)（p.21）と解説の図9.1.3（p.76）を参照します。

## 許容曲げ応力度と横座屈

H形鋼の強軸曲げでは、横座屈を考慮した圧縮側の許容曲げ応力度を求めます。弱軸曲げと、横座屈を考慮しない断面形状の許容曲げ応力度は、許容引張応力度と同じ値とします。上下非対称組立H形鋼大梁や一般リップ溝形材等の適用条件は先に適用します。

圧縮フランジの支点間距離（横座屈長さ）\\( l\_b \\) は、**区間別の直接入力 ＞ 等間隔横補剛本数 \\( n > 0 \\) による区間長 \\( l\_b = L/(n+1) \\) ＞ 材端節点の座標間距離**の順に採用します。補剛区間長に用いる \\( L \\) は検定対象の実材軸長で、補剛本数が0または未入力なら節点間距離を用います。直接入力は、無次元評価位置で始端側（0.25未満）、中央（0.25以上0.75未満）、終端側（0.75以上）に切り替わります。実際の有効支点間隔が節点間距離を超えると、既定値は許容曲げ応力度を過大に評価し得ます。圧縮フランジの有効支点間隔を確認して指定してください。

日本建築学会『鋼構造許容応力度設計規準』2019年制定、第1版第3刷の5.1(4)a（pp.10–11）、式(5.7)〜(5.12)に従って、長期の許容曲げ応力度を求めます。\\( F \\) は鋼材の基準強度 [N/mm²]、\\( Z \\) は強軸の弾性断面係数 [mm³] です。

\\[ M\_{\mathrm{yield}} = F \cdot Z,\quad M\_e = C\sqrt{\dfrac{\pi^4 E I\_z E I\_w}{l\_b^4} + \dfrac{\pi^2 E I\_z G J}{l\_b^2}} \\]

\\[ \lambda\_b = \sqrt{M\_{\mathrm{yield}}/M\_e},\quad {}\_e\lambda\_b = 1/\sqrt{0.6},\quad \nu\_b = 3/2 + (2/3)(\lambda\_b/{}\_e\lambda\_b)^2 \\]

\\[ f\_b = \begin{cases} F/\nu\_b & (\lambda\_b \le {}\_p\lambda\_b) \\\\ \left(1 - 0.4\dfrac{\lambda\_b - {}\_p\lambda\_b}{{}\_e\lambda\_b - {}\_p\lambda\_b}\right)F/\nu\_b & ({}\_p\lambda\_b < \lambda\_b \le {}\_e\lambda\_b) \\\\ F/(2.17\lambda\_b^2) & ({}\_e\lambda\_b < \lambda\_b) \end{cases} \\]

弾性限界細長比 \\( {}\_e\lambda\_b \\) は、式(5.12)の値を丸めずに分岐と安全率に用います。境界と等しい場合は式(5.8)（上式の第2分岐）を採用します。

長期の上限は \\( F/1.5 \\)、短期は同規準5.6（p.14）に従って長期の1.5倍（上限 \\( F \\)）とします。

### 単一補剛区間の強軸曲げ分布と最大需要

通常検定では、1解析要素の実材軸全長が一つの補剛区間と一致する上下対称H形鋼梁について、解析に使った荷重と保存断面力を照合します。同じ荷重ケースまたは荷重組合せについて、荷重が変わる位置と強軸側のせん断力がゼロになる位置の曲げから分布を確認し、全長の絶対値最大を求めます。既定の検定位置に加え、材端フェース間で曲げの絶対値が最大となる位置を探索し、その断面を検定します。最大需要に相当する位置が複数あれば各位置を検定します。集中荷重が作用する位置では、軸力やせん断力が荷重の前後で異なるため、区間内部では両側、材端フェースでは区間内側の断面力を使います。この追加照査は軸力と二軸曲げの組合せの部材全域最大を求めるものではありません。

一本部材に指定した上下対称H形鋼大梁も、複数の解析要素の実材軸全長が一つの補剛区間と一致するときに対象となります。外端だけが圧縮フランジの有効支点であることを設計者が確認し、各要素の「横座屈長さ lb 直接入力[mm]」の始端・中央・終端すべてに一本部材の実材軸全長を指定してください。分割した要素の節点間距離や合成した代表曲げでは、有効支点間隔や区間の曲げ分布を確認できません。

- 同じ無欠損断面で、接続節点を共有する共線・同方向の実材軸と局所軸が連続した梁を、始端から終端へ順に登録します。複数の一本部材に重ねて登録した要素、内部で材端フェース・剛域・端部解放がある場合、正の等間隔横補剛本数を指定した場合は、この単一補剛区間の照査の対象外です。C係数を直接入力する場合は全要素で共通の値を指定します。
- 各要素の部材荷重と保存断面力の釣合いに加え、要素の境界での断面力の連続性を確認します。境界に作用する集中部材荷重や、節点荷重・接続材の作用などによって境界の断面力が連続しない場合は対象外です。
- 全長で確認した分布から一つの補剛区間の許容値を求めます。一本部材の両外端の材端フェース間にある最大需要は、該当する解析要素の位置に表示します。単一補剛区間または以下の断面照査の条件を確認できない一本部材は、解析要素ごとの補剛区間に置き換えず、強軸曲げと横座屈を理由付きで未算定とします。独立に確認できた不適合は表示します。

塑性限界細長比 \\( {}\_p\lambda\_b \\) と横座屈修正係数 \\( C \\) は、同規準の式(5.13)〜(5.16)（p.11）に従います。符号付き強軸曲げの単調変化を確認できた場合は、両端の曲げモーメント比を使います。

\\[ {}\_p\lambda\_b=0.6+0.3(M\_2/M\_1),\qquad C = 1.75 + 1.05(M\_2/M\_1) + 0.3(M\_2/M\_1)^2 \le 2.3 \\]

\\( M\_1 \\) は両端の強軸曲げモーメントのうち絶対値が大きい方、\\( M\_2 \\) は小さい方です。比は複曲率で正、単曲率で負とします。曲げの絶対値が区間内部で最大となる場合は、中央かどうかにかかわらず \\( {}\_p\lambda\_b=0.3 \\)、\\( C=1.0 \\) を使います。

荷重と保存断面力の対応、補剛区間と実材軸全長の一致、または区間全体の分布を確認できない場合、横座屈を考慮した強軸曲げは未算定です。非単調で絶対値最大が端部にとどまる場合や、内部の孤立した極値が端部と同程度で、どちらが最大か確認できない場合も、端部比の式は使いません。未算定でも、許容曲げ応力度の上限を超えた断面など、独立に確認できた不適合は表示します。時刻歴の内力包絡や一部の断面の値では、区間内の単調変化を確認できません。

検定明細の理由が「解析断面力がありません」の場合は、確認できた曲げモーメントがゼロの場合や、横座屈の照査対象でない場合とは異なります。選択した荷重ケース・組合せの確定結果を確認してください。必要な断面力をゼロや別ケースの値で補って許容曲げ応力度を算定することはありません。

上下対称H形鋼大梁の検定では、選択した荷重ケース・組合せの保存結果と生成入力を照合します。照査する要素自身の断面力が欠けるか一致しない場合は、横座屈長さがゼロでも理由付きで未算定とします。一本部材で他の構成要素の断面力を確認できない場合は、その断面力が必要な補剛区間の照査を未算定とし、確認済み断面の独立した不適合は残します。保存結果を読み込んだ場合も同様です。参照しない部材の断面力の欠落は照査に影響しません。選択をやり直し、生成入力が確認できなければ再解析してください。

区間の最大曲げ位置以外でも、端部フェース・ハンチ端・継手などの検定位置と記録位置を照合します。集中荷重点ちょうどでは、荷重をまだ含まないi端側の断面力を使います。記録位置と検定位置の全候補が同じ切断側なら、荷重点に近くても検定します。断面力が跳ぶ荷重点を挟む場合や、検定位置が不明で近接する跳びの影響を除けない場合は、その断面を未算定とします。同じ作用点の集中荷重が完全に相殺すれば跳びはありません。近接していても異なる作用点の荷重は相殺しません。切断側を確認できた区間最大位置や他の断面の検定は残ります。

### 等間隔の中間横補剛を指定した場合

1解析要素の上下対称H形鋼梁では、「等間隔横補剛本数」を正の値で指定し、横座屈長さを直接指定しない場合に、実材軸の両端と等間隔の中間点を補剛端とします。設計者は両実材端と中間点で、各荷重組合せの圧縮側フランジに有効な横補剛が成立することを確認してください。この入力で、補剛材自体の強度・剛性や実際の配置は検定しません。

区間ごとに、両補剛端の間の符号付き強軸曲げの分布から、上記の式で許容値を求めます。需要は各区間と両材端フェース間が重なる範囲で、両端と範囲内の絶対値最大を検定します。隣接する二つの区間に共通の補剛端では、同じ位置を二つの許容値で別々に検定します。集中荷重が補剛端や材端フェースに作用するときは各需要範囲の内側、範囲内部なら集中荷重の両側の断面力を使います。通常検定の詳細に、各区間の実材軸i端からの位置を mm で表示します。検定比図の同位置マーカーには、選択した検定式のうちその位置で最も大きい検定比を表示します。各区間の比は明細で確認できます。補剛本数の通常検定の上限は10,000です。

短い横座屈長さを直接指定しただけでは、補剛端の位置を確認できません。横座屈長さの直接指定が等間隔横補剛本数より優先される場合や、一本部材を複数要素で構成し共通の中間補剛位置を確認できない場合も同様です。位置や荷重と断面力の対応が確認できないときは、区間の推定や既定断面だけでの適合判定を行わず、横座屈を考慮した強軸曲げを理由付きで未算定とします。許容応力度の上限を超える断面など、独立に確認できた不適合は表示します。横座屈長さ0の直接指定による位置別の断面照査では、横座屈による低減を行いません。

「C 係数直接入力（空欄=自動）」で有効な値を指定した場合は、許容値を算定できる区間の \\( C \\) に直接値を使い、自動算定の上限2.3は適用しません。直接指定で曲げ分布の確認や塑性限界細長比の選定を省略することはできません。

### 横座屈に用いる断面性能

曲げねじり定数 \\( I\_w \\) は、次式をH形（下記の組立H形を除く）に用います。

\\[ I\_w=I\_z(H-t\_f)^2/4 \\]

横座屈検定の適用条件を満たす組立H形（BH）では、上下フランジ重心間距離 \\( h\_f \\) と
上下フランジ単独の弱軸側断面二次モーメント \\( I\_u,I\_l \\) を用います。

\\[ I\_w=h\_f^2\frac{I\_u I\_l}{I\_u+I\_l} \\]

せん断弾性係数 \\( G \\) は材料に入力があればその値、なければ次式によります。

\\[ G=\frac{E}{2(1+\nu\_P)} \\]

サンブナンのねじり定数 \\( J \\) は断面性能のねじり定数を用います。

| 記号 | 意味 | 単位 |
|---|---|---|
| \\( M\_{\mathrm{yield}} \\) | 強軸曲げの降伏モーメント（局所y軸まわりの \\( M\_y \\) とは別） | N·mm |
| \\( M\_e \\) | 弾性横座屈モーメント | N·mm |
| \\( \nu\_b \\) | 横座屈の安全率 | - |
| \\( \nu\_P \\) | 材料のポアソン比 | - |
| \\( I\_w \\) | 曲げねじり定数 | mm⁶ |
| \\( I\_u,I\_l \\) | 上下フランジ単独の弱軸側断面二次モーメント | mm⁴ |
| \\( h\_f \\) | 上下フランジ重心間距離 | mm |
| \\( H,B,t\_f,t\_w \\) | 断面せい・幅・フランジ厚・ウェブ厚 | mm |
| \\( E,G \\) | ヤング係数・せん断弾性係数 | N/mm² |
| \\( J \\) | サンブナンのねじり定数 | mm⁴ |

採用式の降伏モーメントMy・安全率νに対し、本ページではそれぞれ \\( M\_{\mathrm{yield}} \\)、\\( \nu\_b \\) と区別します。
弱軸側断面二次モーメントは上表の保存規約に従う \\( I\_z \\) です。

### 断面欠損を考慮した断面係数 Z′（上下対称H形の強軸曲げ）

ここでフランジ寄与分 \\( I\_f \\) とウェブ寄与分 \\( I\_{\mathrm{web}} \\) はともにmm⁴です。曲げねじり定数 \\( I\_w \\) [mm⁶]とは区別します。

継手部の欠損率 \\( \beta\_f \\)（フランジ [%]）・\\( \beta\_w \\)（ウェブ [%]）、端部スカラップによるウェブ欠損率 \\( \alpha\_w \\) [%] が部材に入力されている場合、H 形の強軸曲げ応力度は欠損を考慮した断面係数 \\( Z\' \\) で算定します。全断面の強軸断面二次モーメントをフランジ寄与分 \\( I\_f = (B H^3 - B(H-2t\_f)^3)/12 \\) とウェブ寄与分 \\( I\_{\mathrm{web}} = t\_w (H-2t\_f)^3/12 \\) に分解し:

\\[ I\_f\' = I\_f (1 - \beta\_f/100),\quad I\_{\mathrm{web}}\' = I\_{\mathrm{web}} (1 - \beta\_w/100) \\]

端部（評価位置が部材軸方向の無次元位置 0.25 以下または 0.75 以上）は、スカラップを考慮したウェブ寄与分に置き換えたうえで \\( \beta\_w \\) も乗じます:

\\[ I\_{\mathrm{web}}\'\' = \frac{t\_w \left[(H-2t\_f)(1-\alpha\_w/100)\right]^3}{12} (1 - \beta\_w/100) \\]

\\[ Z\' = (I\_f\' + I\_{\mathrm{web}}\')/(H/2) \\]

（端部は \\( I\_{\mathrm{web}}\' \\) を \\( I\_{\mathrm{web}}\'\' \\) に置き換えます。）
