# 鋼梁の曲げ・横座屈検定

鋼梁の単独曲げを検定します。断面形状・補剛条件と、H形強軸の断面欠損を考慮して曲げ応力度と許容値を求めます。

強軸・弱軸の単独曲げは、各方向の曲げ応力度をその方向の許容値で除して判定します。
上下非対称組立H形鋼大梁の強軸曲げには、[上下縁それぞれの断面係数と許容値](#上下非対称組立h形鋼大梁の強軸曲げ)を用います。
その他の[曲げ応力度の算定式](03_04_鋼梁_柱の組合せ応力検定.md#算定式梁)では、円形鋼管の二方向曲げを合成して扱います。

## 上下非対称組立H形鋼大梁の強軸曲げ

上下のフランジ幅または厚さが異なる組立H形鋼の大梁では、図心から上下縁までの距離と、曲げの符号により決まる圧縮縁・引張縁を使って検定します。次の条件をすべて満たす位置が対象です。

- 強軸曲げモーメント \\( M\_z \\) が作用し、軸力 \\( N \\)、弱軸曲げ \\( M\_y \\)、せん断 \\( Q\_y,Q\_z \\)、ねじり \\( M\_x \\) がいずれも0です。
- 断面欠損の指定がなく、強軸断面二次モーメントは実形状から算定します。
- 2019年版の許容曲げ応力度を使用し、横座屈による低減を要しない条件を設計者が確認したうえで、「横座屈長さ lb 直接入力[mm]」の該当区間に0を指定します。0は断面照査における横座屈長さの理想化を表します。区間の指定値は全荷重組合せに共通のため、正負の曲げが生じる場合は両方の圧縮縁について条件を確認します。直接入力が空欄の場合や、部材長または等間隔横補剛本数から自動算定される場合は、この適用条件を満たしません。

断面力が0かどうかは検定に渡される値で判定します。理論上の純曲げでも、解析で微小なせん断力が生じた位置は組合せの未算定になります。 [#1599](https://github.com/hrntsm/SEPIKA/issues/1599)

局所 \\( y \\) の正側を上、負側を下とします。強軸断面二次モーメントを \\( I\_y \\) [mm⁴]、図心から上縁・下縁までの距離をそれぞれ \\( c\_{\mathrm{上}},c\_{\mathrm{下}} \\) [mm] とし、上下縁の断面係数 [mm³] と応力度 [N/mm²] を求めます。

\\[ Z\_{\mathrm{上}} = \frac{I\_y}{c\_{\mathrm{上}}},\qquad Z\_{\mathrm{下}} = \frac{I\_y}{c\_{\mathrm{下}}} \\]

\\[ \sigma\_{\mathrm{上}} = -\frac{M\_z}{Z\_{\mathrm{上}}},\qquad \sigma\_{\mathrm{下}} = \frac{M\_z}{Z\_{\mathrm{下}}} \\]

\\( M\_z \\) [N·mm] が正なら上縁が圧縮、負なら下縁が圧縮です。全断面で照査するには、圧縮側フランジとウェブが次の幅厚比の限度をともに満たす必要があります。

| 板要素 | 幅厚比に使う寸法 [mm] | 局部座屈の影響を省ける条件 |
| --- | --- | --- |
| 圧縮側フランジ | フランジ全幅の半分 \\( b \\)、圧縮側フランジの板厚 \\( t\_f \\) | \\( b/t\_f \le 0.53\sqrt{E/F\_f} \\)（式(9.1)） |
| 溶接組立大梁のウェブ | 全せいから上下のフランジ厚を引いた内法せい \\( d \\)、ウェブの板厚 \\( t\_w \\) | \\( d/t\_w \le 2.4\sqrt{E/F\_w} \\)（式(9.5)） |

\\( E \\) は鋼材のヤング係数、\\( F\_f,F\_w \\) は各板厚に対応する基準強度です。いずれも N/mm² で扱います。引張側フランジの幅厚比は、この曲げの符号に対する全断面の適用条件に含めません。

条件を満たす場合は、圧縮縁には許容曲げ応力度 \\( f\_b \\)、引張縁には許容引張応力度 \\( f\_t \\) を使い、応力度の絶対値を対応する許容値で除した比の最大値を検定比とします。横座屈低減を要しない条件での \\( f\_b \\) と \\( f\_t \\) はともに長期 \\( F/1.5 \\)、短期 \\( F \\) です。この全断面の応力度照査では最大板厚に対応する共通の \\( F \\) を適用します。

幅厚比が限度を超える場合や限度を確認できない場合、有効断面による照査は未算定です。無効部分を控除すると図心が移動するため、全断面の各縁の応力度比からは有効断面の各縁の応力度比を確定できません。

図9.1.3のように、フランジは幅方向の自由縁から無効部分を控除しても、ウェブで支持された部分に板厚を保って残ります。ウェブは板の中央から無効部分を控除するため、フランジの外面位置は変わりません。上下の外縁間距離は全せい \\( h \\) [mm] のままであり、上下縁の応力度の絶対値の和は \\( |M\_z|h/I\_{y,\mathrm{eff}} \\) です。平行軸の定理により、有効断面の図心まわりの断面二次モーメント \\( I\_{y,\mathrm{eff}} \\) は全断面の \\( I\_y \\) を超えません。このとき、少なくとも一方の縁の応力度比に対する下限を次式で求めます。

\\[ \frac{|M\_z|h}{I\_y\bigl(f\_{t,\mathrm{上}}+f\_{t,\mathrm{下}}\bigr)} \\]

\\( f\_{t,\mathrm{上}}, f\_{t,\mathrm{下}} \\) は各フランジの板厚に対応する基準強度から求めた許容応力度の上限 [N/mm²] です。下限が1を超える場合は、上下いずれかの縁の不適合、曲げ比の下限、および有効断面による曲げ照査が未算定である理由を表示します。下限が1以下の場合や確認できない場合は理由付きで未算定とします。

横座屈長さが有限の正値または未指定で、他の適用条件を満たす場合は、圧縮縁の許容曲げ応力度の上限 \\( f\_t \\) と引張縁の \\( f\_t \\) を使って検定比の下限を求めます。この下限が1を超える場合は、確定した不適合と横座屈の未算定理由を表示します。下限が1以下の場合は理由付きで未算定となります。断面欠損、断面力の併存、横座屈長さの負値・非有限値など、他の適用条件を満たさない場合も、理由付きで未算定となります。正の横座屈長さに対する算定条件は調査中です。 [#1598](https://github.com/hrntsm/SEPIKA/issues/1598)

圧縮軸力があり、[有効細長比の法定上限](03_06_鋼部材の座屈長さ_有効細長比.md#圧縮材の有効細長比上限)を超える位置では、細長比の不適合と強軸曲げとの組合せが未算定である理由を併記します。

日本建築学会『鋼構造許容応力度設計規準』2019年版の式(6.1)・式(6.2)（p.15）で軸応力度を0とすると、圧縮縁は \\( f\_b \\)、引張縁は \\( f\_t \\) との比較に帰着します。許容値の根拠は同規準 5.1(1) 式(5.1)（p.9）、5.1(4)a（pp.10–11）、5.6（p.14）です。梁の曲げ応力度と幅厚比の適用は 10.1(2)(3)（p.22、解説 p.78 式(10.1.1)）、幅厚比の限度は 9.1(1)a)・(2)b)（pp.20–21）と解説の式(解9.1.3)（p.75）に基づきます。幅厚比に用いる板幅は解説の図9.1.2(b)（p.76）、無効部分の位置は 9.1(3)（p.21）と解説の図9.1.3（p.76）を参照します。

## 許容曲げ応力度と横座屈

GUIの許容曲げ応力度は、鋼構造許容応力度設計規準2019年版の式を採用します。1973年版の許容曲げ式へ切り替えるGUI設定はありません。H形の強軸曲げで横座屈を考慮し、他形状の許容曲げ応力度は許容引張応力度と同じ値とします。上下非対称組立H形鋼大梁や一般リップ溝形材等の適用条件は先に適用します。

圧縮フランジの支点間距離（横座屈長さ）\\( l\_b \\) は、**直接入力（部材単位、始端・中央・終端の区間別）＞ 等間隔横補剛本数 \\( n \\) による自動算定 \\( l\_b = L/(n+1) \\) ＞ 部材長 \\( L \\)** の優先順位で決まります。区間別の直接入力は、評価位置に応じて始端側（部材軸方向の無次元位置 0.25 未満）・中央（0.25 以上 0.75 未満）・終端側（0.75 以上）の値を用います。

鋼構造許容応力度設計規準2019年版の採用式:

\\[ M\_{\mathrm{yield}} = F \cdot Z,\quad M\_e = C\sqrt{\dfrac{\pi^4 E I\_z E I\_w}{l\_b^4} + \dfrac{\pi^2 E I\_z G J}{l\_b^2}} \\]

\\[ \lambda\_b = \sqrt{M\_{\mathrm{yield}}/M\_e},\quad {}\_e\lambda\_b = 1.29,\quad \nu\_b = 3/2 + (2/3)(\lambda\_b/{}\_e\lambda\_b)^2 \\]

\\[ f\_b = \begin{cases} F/\nu\_b & (\lambda\_b \le {}\_p\lambda\_b) \\\\ \left(1 - 0.4\dfrac{\lambda\_b - {}\_p\lambda\_b}{{}\_e\lambda\_b - {}\_p\lambda\_b}\right)F/\nu\_b & ({}\_p\lambda\_b < \lambda\_b \le {}\_e\lambda\_b) \\\\ F/(2.17\lambda\_b^2) & ({}\_e\lambda\_b < \lambda\_b) \end{cases} \\]

長期の上限は \\( F/1.5 \\)、短期は長期の1.5倍（上限 \\( F \\)）とします。

塑性限界細長比 \\( {}\_p\lambda\_b \\) は次の条件ごとに定めます。
全長区間で端部モーメントを利用でき、区間中央の絶対値が両端より大きくない場合（単調変化として扱う条件）:

\\[ {}\_p\lambda\_b=0.6+0.3(M\_2/M\_1) \\]

区間中央の曲げモーメントの絶対値が両端より大きい場合、端部モーメント情報がない場合、
または部分補剛区間で区間端部モーメントを入力・復元できない場合（現在の部分区間の扱い）:

\\[ {}\_p\lambda\_b=0.3 \\]

端部モーメント比の符号は後述のCの式と共通です。両端モーメントがともに微小で上記の0.3の条件に該当しない場合は比を0とし、\\( {}\_p\lambda\_b=0.6 \\) です。

曲げねじり定数 \\( I\_w \\) は、次式をH形（下記の組立H形を除く）に用います。

\\[ I\_w=I\_z(H-t\_f)^2/4 \\]

横座屈検定の適用条件を満たす組立H形（BH）では、上下フランジ重心間距離 \\( h\_f \\) と
上下フランジ単独の弱軸側断面二次モーメント \\( I\_u,I\_l \\) を用います。

\\[ I\_w=h\_f^2\frac{I\_u I\_l}{I\_u+I\_l} \\]

せん断弾性係数 \\( G \\) は材料に入力があればその値、なければ次式によります。

\\[ G=\frac{E}{2(1+\nu\_P)} \\]

サンブナンのねじり定数 \\( J \\) は断面性能のねじり定数を用います。

| 記号 | 意味 | 単位 |
|---|---|---|
| \\( M\_{\mathrm{yield}} \\) | 強軸曲げの降伏モーメント（局所y軸まわりの \\( M\_y \\) とは別） | N·mm |
| \\( M\_e \\) | 弾性横座屈モーメント | N·mm |
| \\( \nu\_b \\) | 横座屈の安全率 | - |
| \\( \nu\_P \\) | 材料のポアソン比 | - |
| \\( I\_w \\) | 曲げねじり定数 | mm⁶ |
| \\( I\_u,I\_l \\) | 上下フランジ単独の弱軸側断面二次モーメント | mm⁴ |
| \\( h\_f \\) | 上下フランジ重心間距離 | mm |
| \\( H,B,t\_f,t\_w \\) | 断面せい・幅・フランジ厚・ウェブ厚 | mm |
| \\( E,G \\) | ヤング係数・せん断弾性係数 | N/mm² |
| \\( J \\) | サンブナンのねじり定数 | mm⁴ |

採用式の降伏モーメントMy・安全率νに対し、本ページではそれぞれ \\( M\_{\mathrm{yield}} \\)、\\( \nu\_b \\) と区別します。
弱軸側断面二次モーメントは上表の保存規約に従う \\( I\_z \\) です。

横座屈修正係数:

\\[ C = 1.75 + 1.05(M\_2/M\_1) + 0.3(M\_2/M\_1)^2 \le 2.3 \\]

\\( M\_1 \\) は座屈区間両端の強軸曲げモーメントの絶対値が大きい方、\\( M\_2 \\) は小さい方で、\\( M\_2/M\_1 \\) は複曲率（反曲点あり）で正・単曲率で負とします。自動算定では次の場合に安全側の値を用います:

- 座屈区間中央の曲げモーメントが両端より大きい（区間内で最大となる）場合は \\( C = 1.0 \\)。
- 横補剛により座屈区間 lb が部材の部分区間となる場合は、区間端モーメント比が不明なため自動算定の \\( C = 1.0 \\)。
- 端部モーメントの情報がない場合は \\( C = 1.0 \\)（もっとも不利な等曲げ分布相当）。

横座屈修正係数 C は、「C 係数直接入力（空欄=自動）」で部材単位に直接入力できます（正値。0 以下は無効入力として無視します）。入力がある場合は自動算定（上記の \\( M\_2/M\_1 \\) 式・上限 2.3・安全側の \\( C=1.0 \\) 規定）を行わず入力値をそのまま採用します。したがって部分補剛区間でも正値の直接入力 が優先されます。

### 断面欠損を考慮した断面係数 Z′（上下対称H形の強軸曲げ）

ここでフランジ寄与分 \\( I\_f \\) とウェブ寄与分 \\( I\_{\mathrm{web}} \\) はともにmm⁴です。曲げねじり定数 \\( I\_w \\) [mm⁶]とは区別します。

継手部の欠損率 \\( \beta\_f \\)（フランジ [%]）・\\( \beta\_w \\)（ウェブ [%]）、端部スカラップによるウェブ欠損率 \\( \alpha\_w \\) [%] が部材に入力されている場合、H 形の強軸曲げ応力度は欠損を考慮した断面係数 \\( Z\' \\) で算定します。全断面の強軸断面二次モーメントをフランジ寄与分 \\( I\_f = (B H^3 - B(H-2t\_f)^3)/12 \\) とウェブ寄与分 \\( I\_{\mathrm{web}} = t\_w (H-2t\_f)^3/12 \\) に分解し:

\\[ I\_f\' = I\_f (1 - \beta\_f/100),\quad I\_{\mathrm{web}}\' = I\_{\mathrm{web}} (1 - \beta\_w/100) \\]

端部（評価位置が部材軸方向の無次元位置 0.25 以下または 0.75 以上）は、スカラップを考慮したウェブ寄与分に置き換えたうえで \\( \beta\_w \\) も乗じます:

\\[ I\_{\mathrm{web}}\'\' = \frac{t\_w \left[(H-2t\_f)(1-\alpha\_w/100)\right]^3}{12} (1 - \beta\_w/100) \\]

\\[ Z\' = (I\_f\' + I\_{\mathrm{web}}\')/(H/2) \\]

（端部は \\( I\_{\mathrm{web}}\' \\) を \\( I\_{\mathrm{web}}\'\' \\) に置き換えます。）
