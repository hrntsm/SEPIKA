# 独立鋼間柱の断面検定

主架構の解析から独立して、指定した保存荷重組合せと横支持に対する軸力・二方向の曲げ、せん断、たわみを確認します。

## 鋼製間柱の独立検定

間柱の端別XYZ偏心は可視化専用です。検定用の長さ・荷重位置・強弱軸・横支持・鉛直端部負担率・需要と耐力には、偏心前の基準材軸を使います。表示偏心だけを編集しても、局部横荷重による単体の反力・検定、主架構への既存鉛直反力、自重・質量・数量は変わりません。実際の偏心による付加応力を過小評価し得るため、安全側の近似とは扱いません。適用範囲は[梁・柱の端別XYZ偏心](../../model_edit/09_梁の鉛直偏心.md)を確認してください。

壁版入力の間柱一覧にある「検定入力」を開き、荷重・設計条件を設定し、設計画面から検定します。対象は壁領域所属で支持先・材料が確定した鉛直間柱の、実寸を持つH形鋼と等厚角形鋼管です。角形鋼管は外角半径の明示が必要で、溶接箱は0とします。組立H、円形鋼管、異厚箱、他の断面形式、RC・SRC・CFTは理由付き未検定です。

横支持の初期選択は両端ピンです。「両端ピン」「始端固定・終端自由」「始端自由・終端固定」から指定します。鉛直自重等の端部負担率、強軸・弱軸の軸圧縮座屈長さ、圧縮フランジの横補剛間隔は、それぞれ独立に明示します。荷重を受け持たない鉛直端も横支持点になれます。断面の向きは、強軸曲げを生じる横力方向を全体X軸から反時計回りの角度で指定します。これに直交する方向を弱軸曲げの方向とし、間柱名や壁の向きから推定しません。明示した断面の向きは、壁版・架け側小梁の自重作用区間を求める支持面にも適用します。そのため向きの変更は主架構へ伝達される既存自重も変え得ます。既存の解析・重量・検定結果は再計算してください。

検定する保存荷重組合せと、それぞれの長期・短期を指定します。間柱検定用の局部横荷重は、ケース・全体XY平面内の方向角・始端からの位置とともに等分布（N/mm）または集中荷重（N）で入力します。位置と区間はmmです。風圧・壁面外地震力は利用者が算定してください。**局部横荷重は主架構へ自動転送されません。** 結果に表示する端部反力・固定端曲げ反力を確認し、主架構への荷重を別途扱ってください。

鉛直荷重は既存の床・壁・二次部材の伝達を荷重ケース別に取り込みます。DLには間柱自重・壁自重・架け側の二次部材反力を含み、LLには架構用の積載、地震用LLには地震用積載を取り込みます。反力として受けた荷重の元荷重を再加算しません。同種の鉛直ケースが複数ある場合は自動伝達の所属が一意でないため未検定です。雪・任意ケースから間柱へ新たな鉛直荷重を生成する機能はありません。

### 軸力と二方向の横応答

鉛直荷重と局部横荷重は別々に扱います。鉛直荷重の合計を \\( W\_g \\) [N]、始端の端部負担率を \\( \alpha\_0 \\)（無次元）、
始端からxまでの下向き鉛直荷重累計を \\( G(x) \\) [N]とすると、反力と軸力は次式です。
\\( x \\) は間柱の始端から終端への位置[mm]で、端部負担率の和は1です。

\\[ R\_{g,0}=\alpha\_0 W\_g,\qquad R\_{g,L}=(1-\alpha\_0)W\_g \\]

\\[ N(x)=\eta\left(G(x)-R\_{g,0}\right),\qquad \eta=\frac{z\_L-z\_0}{|z\_L-z\_0|} \\]

\\( z\_0,z\_L \\) は両端の高さ[mm]です。軸力は引張正で、下側へ支持する場合の圧縮は負、上側へ吊る場合の引張は正です。
途中で受ける集中荷重の左右は別の断面として評価します。軸力を横荷重に置き換えません。

局部横荷重は断面の向きへ投影し、保存組合せの係数を乗じて強軸曲げ・弱軸曲げの二方向に重ね合わせます。
各方向について、[小梁の力学関係](05_01_鋼小梁の曲げ_たわみ検定.md#荷重から反力断面力たわみまで)のW・Sから反力、Q・M、曲率、変位を求めます。
この場合の正荷重方向は各投影方向、変位vの正方向はその逆向きとします。二方向の剛性にはそれぞれ強軸のEIy、弱軸のEIzを用います。
強軸側の応力表示はMz・Qy、弱軸側はMy・Qzです。

```text
両端ピン            始端固定・終端自由    始端自由・終端固定
0 △────────○ L      0 ┃──────── 自由 L    0 自由 ────────┃ L
       q ↓↓↓                q ↓↓↓                 q ↓↓↓
```

図は鉛直間柱を横に寝かせた各横方向の単体モデルです。両端ピンでは \\( v(0)=v(L)=0,\ M(0)=M(L)=0 \\)、
始端固定では \\( v(0)=v^{\prime}(0)=0 \\)、終端固定では \\( v(L)=v^{\prime}(L)=0 \\) です。
自由端は端部集中荷重がないときQ・Mが0です。終端固定の場合は、始端からの座標のまま次式となります。

\\[ R\_0=0,\qquad R\_L=W,\qquad M(0)=0,\qquad M(L)=-(LW-S) \\]

表示する固定端曲げは、この端部断面のMの符号で示します。例えば、横一方向に全長一様荷重2 N/mm、
長さ3000 mm、E = 205000 N/mm²、当該方向のI = 8.0×10⁶ mm⁴の場合、
[小梁の代表例](05_01_鋼小梁の曲げ_たわみ検定.md#全長一様荷重の代表例)と同じ値になります。
両端ピンでは反力各3 kN・中央曲げ2.25 kN·m・最大絶対変位約1.286 mm、
片端固定では固定端反力6 kN・固定端曲げ−9 kN·m・自由端の最大絶対変位約12.348 mmです。
終端固定では最大変位の位置が始端へ移ります。これらは鉛直荷重の端部負担率や軸力の例ではありません。

応答は区間線形荷重の閉形式積分によります。荷重端・集中荷重の左右で区間を分け、断面力の零点と極値、同一位置の軸力＋二軸曲げ比・せん断比の極値を評価します。固定分点の最大値で代用しません。許容応力度と軸力＋二軸曲げ・二方向せん断の判定は鋼構造部材の断面検定で用いる既存の柱検定を共用します。強軸の横座屈には入力した横補剛間隔、軸圧縮には各軸の座屈長さを適用します。別位置や別組合せの成分最大を同時作用として合成しません。

### たわみと結果の読み方

たわみは曲げによる弾性変位です。二方向変位を \\( v\_1(x),v\_2(x) \\) [mm]として、同一位置で合成した最大値を求めます。

\\[ \delta=\max\_{0\le x\le L}\sqrt{v\_1(x)^2+v\_2(x)^2},\qquad R\_\delta=D\frac{\delta}{L} \\]

Lは間柱の全長[mm]（片端固定では固定端から自由端まで）、Dは利用者が入力したたわみ限界分母です。
表示するたわみ比は \\( \delta/L \\)、判定用の比は \\( R\_\delta \\) で、1以下を適合とします。小梁のL/250は自動採用せず、「たわみ限界 L/分母」を利用者が明示します。未指定時は変位を表示し、たわみ適否と総合合否は未検定です。

設計結果では間柱名・断面・横支持・組合せと期間・検定位置・N/My/Mz/Qy/Qz・項目別比・許容値を確認できます。数値根拠は項目別判定にカーソルを合わせて表示します。必要項目をすべて評価した場合だけ総合OK/NGとし、不足や非対応の理由を評価済みの項目と分けて表示します。横荷重未入力時には風・地震の検定済みとしません。条件と結果はプロジェクトへ保存し、断面・荷重・支持等の編集後は再検定が必要です。

全体解析の間柱剛性、層間変形追従、軸力による二次効果、非線形・終局・接合部は対象外です。MCPの主架構検定はこの独立検定を実行せず、その対象外であることを結果に示します。
