# SRC / CFT の等価断面性能

SRC の初期弾性解析には入力コンクリートの Ec と標準鋼材 Es=205000 N/mm²の比を用います。許容曲げ計算の n とは区別します。外形コンクリートに鉄骨部分を重ねて表すため、軸・曲げでは鉄骨の重複コンクリートを除く n−1 の累加を用います。

\\[ A\_n = {}\_{rc}A\_n + {}\_s A\_n \cdot (n\_s - 1) \\]

\\[ I\_e = {}\_{rc}I\_e + {}\_s I\_e \cdot (n\_s - 1) \\]

\\[ A\_s = {}\_{rc}A\_s + {}\_s A\_s \cdot (n\_{gs} - 1) \\]

\\[ J = {}\_c J + ({}\_s G/{}\_c G) \cdot {}\_s J \\]
CFT は SRC 柱に準じ、鋼基準の 1/n 換算で累加します。充填コンクリートの Ec は鋼管材料の密度やヤング係数からは算定せず、Fc とコンクリートの種類から無筋コンクリートの単位体積重量 γC を求めて算定します。

**算定式**

換算係数（SRC は νs=0.3、νc は主材料の入力値。CFT は νc=0.2）:

\\[ n\_s = E\_{\text{steel}}/E\_c \\]

\\[ n\_{gs} = n\_s \cdot \frac{1 + \nu\_c}{1 + \nu\_s} \\]

SRC 軸剛性用:

\\[ A = b \cdot d + (n\_s - 1) \cdot {}\_s a \\]

SRC 曲げ:

\\[ I\_y = \frac{b \cdot d^3}{12} + (n\_s - 1) \cdot {}\_s i\_y \\]

CFT（充填コンクリートを鋼基準へ換算）:

\\[ A = A\_{\text{steel}} + {}\_c a/n \\]

\\[ I\_y = I\_{y,\text{steel}} + {}\_c i\_y/n \\]

**記号・単位**

角形 CFT の鋼管・コアの A・Iy・Iz は、[角Rを含む材料領域](02_断面諸量.md#フィレット角rの材料領域)から算定します。
せん断換算のコア面積にも同じ値を用います。
角Rが未知・不正、または内法が消失した角形 CFT は、鋼管のみへフォールバックせず入力・算定エラーとします。
J と鋼材せん断面積の算定方法は既存式のままで、角R反映や安全側の精度を保証していません。

## 入力と計算不可の表示

SRC の主材料はコンクリートです。Ec [N/mm²] は正の有限値、νc は有限値で −1 < νc < 0.5、Fc [N/mm²] は設定済みの正の有限値を要します。この等方弾性範囲では体積弾性係数とせん断弾性係数が正になります。材料登録で決まった Ec を解析に使い、解析時に Fc から再算定しません。内蔵鋼材に登録したカスタム E は、SRC の換算比に使いません。

材料未割当・不正値、換算比または必要剛性の非有限・非正値は計算不可です。診断は理由と対象部材を示すエラーとなり、解析を停止します。準備計算も理由を表示し、成功結果を公開しません。材料を直して再実行してください。形状だけから作成する断面性能の暫定比15を、解析の代替値には使いません。

等価面積は軸剛性のための値です。実面積・実体積から算定する自重・物理質量には流用しません。例として b=300、D=600、中心 H400×200×8×12、フィレット・鉄筋・スラブなしでは、実面積180000 mm²に対して Ec=20500、ns=10 の等価面積は250272 mm²、Ie=7345337856 mm⁴です。ns=15なら289312 mm²、8426081109.333333 mm⁴となり、この差を安全側とは断定しません。

## 許容曲げ計算の n と適用限界

許容曲げ計算の n は次の強度区分によります。入力 Ec から求める解析用 ns の代用にはしません。

| Fc [N/mm²] | 許容曲げ用 n |
| --- | --- |
| Fc ≤ 27 | 15 |
| 27 < Fc ≤ 36 | 13 |
| 36 < Fc ≤ 48 | 11 |
| 48 < Fc ≤ 60 | 9 |

この表から Fc>60 の外挿は導きません。高強度用の n 定義の一次資料照合は未完了です。SRC の鉄筋・フィレット・スラブを含む断面の全換算理論、ねじり・せん断の全式の原典適合とモデル精度は未検証です。SRC の材料入力契約は、CFT の追加適用や精度保証を含みません。
