# 主要定数

| 定数 | 値 | 意味 | 根拠 |
|------|----|----|----|
| `N_S_EQ` | 15.0 | SRC の形状だけから生成する断面表示の暫定比。解析は材料由来の比を必須とし、不正時は停止する | ヤング係数比 \\( n = E\_s/E\_c \\)（式形は力学） |
| `KAPPA_RC` | 1.2 | RC のせん断形状係数 κ（\\( A\_s = A/\kappa \\)） | 力学（矩形断面の慣用値） |
| `E_STEEL` | 205000 N/mm² | 鋼材ヤング係数 | 力学（材料定数） |
| `NU_STEEL` | 0.3 | 鋼材ポアソン比 | 力学（材料定数） |
| `NU_CONCRETE` | 0.2 | コンクリートポアソン比 | 力学（材料定数） |
| `GAMMA_CONCRETE` | 23.0 kN/m³ | γC を材料から解決しない既定の Ec 算定経路で用いる値。直接入力密度の不正値を置き換えるものではない | RC規準（Ec 式の γ） |

矩形断面のせん断有効断面積は \\( \text{rect\_shear\_area}(A) = A \cdot 5/6 \\) で算定します（せん断補正係数 \\( k = 6/5 \\)）。

<div class="impl-ref">

**実装参照**：定数は `crates/sepika-core/src/section_shape/constants.rs` に定義し、`sepika_core::section_shape::{E_STEEL, KAPPA_RC, N_S_EQ}` として公開しています（`NU_STEEL`・`NU_CONCRETE`・`GAMMA_CONCRETE` はクレート内でのみ参照）。矩形断面のせん断有効断面積は `sepika_core::model::rect_shear_area`（`crates/sepika-core/src/model/section.rs`）が算定します。
