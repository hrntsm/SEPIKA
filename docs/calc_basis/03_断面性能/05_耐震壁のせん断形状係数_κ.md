# 耐震壁のせん断形状係数 κ

GUIの壁要素は、壁板と左右の側柱の実形状・材料から、面内の曲げ剛性とせん断剛性を求めます。採用する[材料別実幅による一次元モデル](#実形状と材料別幅による一次元せん断流モデル)について、材料別幅、弾性図心、曲げ剛性、せん断流、せん断剛性の順に説明します。同一材料の場合には、せん断剛性をせん断形状係数κで表せます。補助算定の既定値1.2を、GUIで材料や形状が不足した壁の代用値には用いません。

## 材料間の接合条件

鋼材・コンクリートの合成断面は完全付着とし、界面のすべりを考慮しません。界面にすべりが生じる場合には変形を過小評価しうる危険側の近似です。適用できる断面形状は[壁エレメントモデル](../04_要素剛性/05_壁エレメントモデル.md)によります。

## 実形状と材料別幅による一次元せん断流モデル

### 断面の座標と材料別幅

面内曲げでは壁長方向を断面のせい、壁厚方向を断面の幅とします。壁長方向を積分軸 \\( y \\) とし、断面の両端を \\( y\_{min}, y\_{max} \\)、全せいを \\( D=y\_{max}-y\_{min} \\) とします。幅 \\( b\_i(y) \\) は位置 \\( y \\) で断面を横切る線上にある材料 \\( i \\) の長さの合計です。同じ材料が離れて存在する場合も合計し、空洞は含めません。

次の模式図は、壁板を材料1、左右の側柱を材料2とした断面を、壁長方向が上向きになるように示したものです。材料別幅は積分軸に直交する向きに測ります。実際には左右の側柱で異なる材料や、同じ位置に複数の材料がある断面も扱います。

```text
  y（壁長方向・積分軸）       幅方向（壁厚方向）
  ↑
  │                  ←──── b_2(y_R) ────→
  │ y_max            ┌───────────────────┐  ┐
  │                  │  材料2：右側柱    │  │
  │ y_R ─────────────┤                   │  │
  │                  └──────┐     ┌──────┘  │
  │                         │材料1│         │
  │ y_W ────────────────────┤壁板 ├          │ D
  │                         │     │         │
  │                         ←─────→         │
  │                         b_1(y_W) = t    │
  │                  ┌──────┘     └──────┐  │
  │ y_L ─────────────┤  材料2：左側柱    │  │
  │                  │                   │  │
  │ y_min            └───────────────────┘  ┘
  │                  ←──── b_2(y_L) ────→
```

図の \\( y\_L,y\_W,y\_R \\) は幅を示すための代表位置であり、積分は \\( y\_{min} \\) から \\( y\_{max} \\) の全断面を対象とします。図のように一つの材料だけがある位置では、他の材料の幅は0です。

壁要素は、側柱の回転を反映した各位置 \\( y \\) の材料別実幅 \\( b\_i(y) \\) を求めます。矩形は直線、円・角丸は円弧との交差から幅を求め、外接矩形では代用しません。非対称鋼材の基準点は幾何学的図心です。壁と柱の重複部分は柱材料を優先し、同一材料の重なりを二重計上しません。SRCは内蔵H形鋼をコンクリートから控除し、CFTは外周の鋼管と内部コンクリートを区別します。中空鋼材の空洞は材料なしとして保持し、壁材料で埋めません。

### 材料定数と記号

材料定数は壁・左右柱の割当材料を個別に使用し、Gの明示値があれば優先します。SRC内蔵鋼材は断面の鉄骨材料を使用し、未指定はエラーです。CFT充填部は主材料の充填コンクリートに指定したFcとコンクリートの種類から、無筋コンクリートの単位体積重量表でγCを求めてEを算定し、ν=0.2からGを求めます。鋼管部には専用の鋼管材料のE・Gを用い、充填部には主材料のE・Gや鋼管材料の密度を流用しません。Fcの未指定・非正値・非有限値はエラーです。RC主筋をせん断剛性の材料領域には加えません。

| 記号 | 意味 | 単位・条件 |
| --- | --- | --- |
| \\( y, s \\) | 壁長方向の座標、同じ軸上の積分変数 | mm |
| \\( y\_{min}, y\_{max}, D \\) | 断面の両端の座標、全せい | mm、\\( D=y\_{max}-y\_{min}>0 \\) |
| \\( b\_i(y), t \\) | 材料iの実幅、壁厚 | mm、材料がない位置の幅は0 |
| \\( E\_i, G\_i \\) | 材料iのヤング係数、せん断弾性係数 | N/mm²、正・有限 |
| \\( B\_E(y), B\_G(y) \\) | E、Gをそれぞれ幅方向に積分した量 | N/mm |
| \\( A, y\_E \\) | 幾何学的な断面積、弾性図心の座標 | mm²、mm |
| \\( K\_b, K\_s \\) | 面内の曲げ剛性、せん断剛性 | N·mm²、N |
| \\( Q\_E(y) \\) | 弾性図心まわりのEで重み付けした断面一次モーメント（下端から位置yまで） | N·mm |
| \\( V, q(y) \\) | 断面に作用するせん断力、幅方向に積分したせん断流 | N、N/mm |
| \\( I, Q(y), A\_s, \kappa \\) | 均質断面の断面二次モーメント、断面一次モーメント、せん断有効断面積、せん断形状係数 | mm⁴、mm³、mm²、無次元 |

### 材料別幅から弾性図心へ

まず、各材料の実幅にE・Gを掛けて足し合わせます。

\\[ B\_E(y)=\sum\_i E\_i b\_i(y) \\]

\\[ B\_G(y)=\sum\_i G\_i b\_i(y) \\]

幾何学的な面積と、Eで面積を重み付けした弾性図心を求めます。異種材料の断面では、面積の図心と弾性図心は一般に一致しません。

\\[ A=\int\_{y\_{min}}^{y\_{max}}\sum\_i b\_i(y)\\,dy \\]

\\[ y\_E=\frac{\int\_{y\_{min}}^{y\_{max}}B\_E(y)y\\,dy}{\int\_{y\_{min}}^{y\_{max}}B\_E(y)\\,dy} \\]

### 弾性図心から曲げ剛性へ

完全付着・平面保持を前提に、弾性図心からの距離の二乗で重み付けします。曲げ剛性には全せいDと区別して \\( K\_b \\) を用います。

\\[ K\_b=\int\_{y\_{min}}^{y\_{max}}B\_E(y)(y-y\_E)^2\\,dy \\]

### 曲げ剛性からせん断流へ

下端から位置 \\( y \\) までの領域について、Eで重み付けした断面一次モーメントを求めます。

\\[ Q\_E(y)=\int\_{y\_{min}}^y B\_E(s)(s-y\_E)\\,ds \\]

\\( Q\_E \\) はせん断流そのものではありません。曲げ応力度の材軸方向の変化とせん断流の釣合いから、せん断力 \\( V \\) に対するせん断流は次のようになります。符号は下端側の領域について \\( q/V=Q\_E/K\_b \\) となる向きに取ります。弾性図心の定義により、両端で \\( Q\_E(y\_{min})=Q\_E(y\_{max})=0 \\) です。

\\[ q(y)=\frac{V Q\_E(y)}{K\_b} \\]

### せん断流からせん断剛性へ

幅方向のせん断ひずみを共通とする一次元モデルを用います。これは幅方向のせん断変形の分布を省略する近似で、局所的なせん断変形を過小評価しうる危険側の近似です。完全付着の条件だけから幅方向のひずみ一定が保証されるわけではありません。面外曲げとの連成を求める断面内二次元せん断解析ではありません。

このモデルでは、せん断流による単位材軸長さ当たりのひずみエネルギーと、せん断剛性 \\( K\_s \\) によるひずみエネルギーを等置します。

\\[ \frac{V^2}{2K\_s}=\frac12\int\_{y\_{min}}^{y\_{max}}\frac{q(y)^2}{B\_G(y)}\\,dy \\]

せん断流の式を代入すると、せん断剛性は次式です。

\\[ K\_s=\frac{K\_b^2}{\int\_{y\_{min}}^{y\_{max}} Q\_E(y)^2/B\_G(y)\\,dy} \\]

異種材料の断面はこの \\( K\_s \\) で評価します。同一材料のように単一のGを前提とするκへの換算は行いません。

### 均質断面でのせん断形状係数

全断面が同一のE・Gを持つ場合、\\( b(y)=\sum\_i b\_i(y) \\) とすると、\\( B\_E=Eb \\)、\\( B\_G=Gb \\) です。弾性図心は面積の図心に一致し、次式になります。

\\[ K\_b=EI,\qquad Q\_E(y)=E Q(y),\qquad Q(y)=\int\_{y\_{min}}^y b(s)(s-y\_E)\\,ds \\]

これをせん断剛性の式へ代入し、Eを消去します。

\\[ K\_s=\frac{(EI)^2}{(E^2/G)\int\_{y\_{min}}^{y\_{max}}Q(y)^2/b(y)\\,dy}
=G\frac{I^2}{\int\_{y\_{min}}^{y\_{max}}Q(y)^2/b(y)\\,dy}=G A\_s \\]

\\[ \kappa=\frac{A}{A\_s}=\frac{A}{I^2}\int\_{y\_{min}}^{y\_{max}}\frac{Q(y)^2}{b(y)}\\,dy,\qquad K\_s=\frac{GA}{\kappa} \\]

κは、均質断面のせん断剛性を総断面積AによるGAから求めるための係数であり、その逆数が低減率を表します。以下の対称I形の式ではQを上端側の領域で定義しますが、下端側と符号が逆になるだけで、Q²の積分とκは同じです。

## 材料定数が区間ごとに異なる断面の積分

各区間の幅方向が単一材料で、幅・E・Gが区分一定の場合には、前述の式の \\( B\_E(y)=E(y)b(y) \\)、\\( B\_G(y)=G(y)b(y) \\) として積分します。材料定数の既定値はなく、各区間のE・Gを別々に指定します。材料領域の重複を一度だけ数えた幅・E・Gを用いることが前提です。

各区間内で \\( Q\_E \\) は二次式、\\( Q\_E^2/(Gb) \\) は四次式なので、3点Gauss積分で評価します。面積 [mm²]、弾性図心 [mm]、曲げ剛性 \\( K\_b \\) [N·mm²]、せん断剛性 \\( K\_s \\) [N]を得ます。

## 実形状の数値積分と収束

断面形状の端・矩形頂点の投影・壁厚境界との交点で積分区間を区切ります。各区間の中点で実幅を評価し、区分一定幅の積分へ渡します。1分割から2倍ずつ最大8192分割まで細分し、面積・曲げ剛性・せん断剛性の相対変化と、全断面長で無次元化した弾性図心の変化が1e-6以下となることを連続2回確認します。収束しない場合は計算を中止します。この収束判定は一次元モデルの数値積分誤差を管理するもので、上記のモデル化の近似を解消するものではありません。

数値処理では、幅を求める座標変換の方向余弦が1e-14未満の場合は平行として扱い、投影された積分区間の境界差が1e-10 mm以下の場合は同一境界として統合します。

## 同一材料・対称I形の断面理論

**算定式**

\\[ \kappa = \frac{A}{I^2} \int \frac{Q(y)^2}{b(y)} \\, dy \\]

- \\( A \\): 断面積、\\( I \\): 断面二次モーメント
- \\( Q(y) \\): 位置 \\( y \\) より上の断面一次モーメント
- \\( b(y) \\): 位置 \\( y \\) における断面幅（ウェブ部は壁厚 \\( t \\)、フランジ部は側柱幅）

面内曲げの断面は「壁長方向を断面のせい、壁厚方向を断面の幅」とみなし、断面のせいは側柱外面間の全長 \\( D \\)、フランジは両端の側柱（沿壁方向せい \\( d\_c \\)・壁直交方向幅 \\( b\_c \\)）、ウェブは壁板（せい \\( D - 2 d\_c \\)・幅 \\( t \\)）です。

**性質**

- 一様矩形（側柱なし、側柱幅が壁厚に等しい、または中央のウェブせいが0）では \\( \kappa = 1.2 \\)。
- 係数はフランジ・ウェブの寸法比に依存します。側柱せいを増やして中央のウェブせいが0になると矩形断面となるため、側柱寸法に対して単調に増えるとは限りません。
- せん断断面積 \\( A/\kappa \\) は総断面積を超えません。

**積分の評価**

\\( c=D/2,\ a=c-d\_c,\ q\_a=b\_c d\_c(c+a)/2 \\) とすると、半断面の各区間の積分は次の多項式になります。

\\[ J\_w=\frac{a q\_a^2}{t}+\frac{2q\_a a^3}{3}+\frac{2ta^5}{15} \\]
\\[ J\_f=b\_c d\_c^3\left(\frac{c^2}{3}-\frac{c d\_c}{4}+\frac{d\_c^2}{20}\right) \\]
\\[ \kappa=\frac{2A(J\_w+J\_f)}{I^2},\qquad
I=\frac{2}{3}\left(t a^3+b\_c d\_c(c^2+ca+a^2)\right) \\]

幅が一定の各区間を3点Gauss積分で評価します。各区間のQは二次式、Q²/bは四次式であり、3点Gauss積分は五次までの多項式を厳密に積分するため、上記の多項式積分と一致します（浮動小数点の丸め誤差を除く）。幅一定の区間を細分する設定や既定分割数はありません。

同一材料で幅方向対称の断面では、連続する各区間の長さ・幅から面積 [mm²]、断面端からの図心位置 [mm]、図心まわりのI [mm⁴]、As [mm²]を求めます。非正・非有限の寸法や算定不能な性能値は有効な結果として扱いません。

対称I形を仮定する補助算定は、非有限の寸法、非正の全せい・幅、側柱なし、側柱幅が壁厚以下、算定したκが非有限または1未満の場合に1.2とします。側柱せいは0から全せいの半分に制限します。これは補助算定の範囲であり、GUIの壁要素が不正な入力を1.2で補う仕様ではありません。

側柱の断面形状は明示指定が必要です。形状未定義の側柱は解析前の入力エラーとし、面積・幅・せいだけから形状を推定しません。

壁と左右柱を矩形の和集合として扱う補助算定もありますが、GUIの壁要素には採用していません。この補助算定は同一材料で柱中心が壁厚中央にあり、各矩形の辺が壁に平行・直交する場合に限ります。左右の柱寸法を個別に扱い、壁と柱・柱同士の重複を一度だけ数え、図心を左壁端から測ります。非正・非有限の寸法や算定不能な性能値は求めません。GUIでは前述の材料別実幅を用います。
