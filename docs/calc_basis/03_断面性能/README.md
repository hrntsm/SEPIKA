# 弾性断面諸量

本章では、断面諸量（断面積 A、断面二次モーメント I、断面係数 Z、塑性断面係数 Zp、ねじり定数 J、せん断有効断面積 As）、せん断形状係数、コンクリートのヤング係数、SRC/CFT の等価断面性能の算定方法を示します。
形状から求める幾何性能、材料を基準に換算する等価性能、E・Gを掛けた剛性EA・EI・GAs・GJを区別します。SRCの形状だけによる暫定比15は表示用で、材料不足の解析補完には使いません。CFTは主材料の充填コンクリートと専用の鋼管材料を別々に指定します。

断面公式・Ec式・換算式の採用条件と、未算定・近似・適用限界は各ページに示します。数値が得られることを、全条件での原典適合や安全側の保証とは解釈しないでください。材料入力の意味と変更可否は[材料定数・強度](../02_材料/README.md)を参照してください。
