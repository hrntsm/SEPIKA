# 断面諸量（弾性）

各断面形状の A、I、Z、J は力学の閉形式（標準的な断面公式）で算定します。

## リップ溝形の総断面と有効断面

リップ溝形は、既存のH/B/C/t（外寸、mm）からウェブ・上下フランジ・上下リップの
5矩形による総断面幾何性能を保持します。総Aはmm²、Iy/Iz/Jはmm⁴です。
この幾何モデルは設計用の平板部幅や未知の曲げ半径Rを確定するものではありません。
荷重・圧縮側・採用式に依存する有効A/Zは未算定であり、総断面性能や0で代用しません。
総断面の保存・ST-Bridge往復対応は部材検定の対応を意味しません。
部材の未検定と座屈の分類は[単一リップ溝形材の検討対象と未検定](../06_一次設計/03_鋼構造_断面検定.md#単一リップ溝形材の検討対象と未検定)を参照してください。

**算定式（代表例）**

フィレット半径を明示した 0 とする H 形の断面積:

\\[ A = 2 \cdot B \cdot t\_f + (H - 2t\_f) \cdot t\_w \\]

H 形 強軸（\\( h\_w = H - 2t\_f \\)）:

\\[ I\_y = \frac{B \cdot H^3 - (B - t\_w) \cdot h\_w^3}{12} \\]

H 形 塑性断面係数:

\\[ Z\_p = B \cdot t\_f \cdot (H - t\_f) + \frac{t\_w \cdot (H - 2t\_f)^2}{4} \\]

箱形 閉断面ねじり（Bredt）:

\\[ J = \frac{4 \cdot A\_0^2 \cdot t}{\text{周長}} \\]

円形鋼管:

\\[ A = \pi (r^2 - r\_i^2) \\]

\\[ J = \frac{\pi}{2} \cdot (r^4 - r\_i^4) \\]

矩形 RC（ねじりは \\( J = \text{rect\_torsion\_j}(b, d) \\)）:

\\[ A = b \cdot d \\]

\\[ I\_y = \frac{b \cdot d^3}{12} \\]

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( A \\) | 断面積 | mm² |
| \\( I\_y \\) | 強軸まわりの断面二次モーメント | mm⁴ |
| \\( Z\_p \\) | 塑性断面係数 | mm³ |
| \\( J \\) | ねじり定数 | mm⁴ |
| \\( B \\) | フランジ幅 | mm |
| \\( H \\) | 断面せい | mm |
| \\( t\_f \\) | フランジ厚 | mm |
| \\( t\_w \\) | ウェブ厚 | mm |
| \\( h\_w \\) | ウェブ高さ（\\( H - 2t\_f \\)） | mm |
| \\( b, d \\) | 矩形断面の幅・せい | mm |
| \\( r, r\_i \\) | 円形鋼管の外半径・内半径 | mm |
| \\( A\_0 \\) | 閉断面が囲む面積 | mm² |
| \\( y\_p \\) | 等面積軸の図心からの位置 | mm |

**塑性断面係数 Zp の算定範囲**

\\( Z\_p \\) はすべての鋼断面形状について算定します。
対象は H 形・箱形・円形鋼管・組立 H 形・T 形・溝形・リップ溝形・山形・平鋼・中実丸鋼で、RC・SRC・CFT は対象外です。

H 形と箱形は、下記のフィレット・角Rを含む閉形式で求めます。
円形鋼管と中実丸鋼も閉形式で求めます。
それ以外は断面を水平な矩形帯へ分解し、**等面積軸**（断面積を上下 2 等分する水平軸）まわりに \\( Z\_p = \int |y - y\_p| \\, dA \\) を積分します。
等面積軸は弾性図心とは一般に一致しません。
とくに T 形や組立 H 形のような非対称断面では、両者の差が大きくなります。

\\( Z\_p \\) を求める軸は \\( I\_y \\) と同一です。
山形鋼の \\( I\_y \\) は図心を通る脚に平行な軸（幾何軸）まわりで、主軸まわりではありません。
\\( Z\_p \\) も同じ軸で定義しているため、形状係数 \\( Z\_p/Z\_e \\) が意味を持ちます。

<div class="impl-ref">

**実装参照**：`sepika_core::section_shape::SectionShape::{calc_area, calc_iy, calc_iz, calc_j, plastic_modulus_strong}`（`crates/sepika-core/src/section_shape/properties.rs`）が算定します。
非対称断面（山形、溝形、T 形）は図心を求めて平行軸定理で合成します。

</div>

**CFT・壁・スラブ形状の扱い**

CFT（角形・円形）の断面生成は鋼管部分のみで算定し、充填コンクリートの剛性は含めません。RC 壁・RC スラブ形状の断面性能は幅 1 m の帯としての名目値であり、要素剛性には用いません（壁は壁エレメント、スラブは荷重分配のみ）。

<div class="impl-ref">

**実装参照**：`sepika_core::section_shape::SectionShape::to_section`（`crates/sepika-core/src/section_shape/builder.rs`）が CFT の鋼管部分と RC 壁・RC スラブの帯断面を生成します。

</div>

**SRC 断面の断面レベル諸量**

SRC の断面レベル \\( I\_y \\)・\\( I\_z \\) は、コンクリート部分に鉄骨部分の \\( (n\_s - 1) \\) 累加を加えた等価値です。\\( n\_s \\) は形状だけでは決まらないため、形状から生成する暫定値として \\( n\_s = N\_S\_EQ = 15 \\) を用い、解析では材料由来の検証済み等価性能を必須とします。SRC の材料未割当・不正時は解析不可となり、この暫定値を解析へ使用しません。

算定根拠は [SRC / CFT の等価断面性能](06_SRC_CFT_の等価断面性能.md) を参照してください。

**鋼材カタログ表値の扱い**

カタログ断面の諸元は表値をそのまま用い、再計算しません。
CSV は cm 系のため面積は 100 倍、断面二次モーメント・ねじり定数は 10⁴ 倍して mm 系へ換算します。
幅厚比判定用の寸法は断面名から復元し、フィレット半径・角Rは CSV の専用列から保持します。
表値からフィレット半径・角Rを逆算することはありません。
丸鋼管の幅は外径を用います。

<div class="impl-ref">

**実装参照**：`sepika_section::catalog::to_section`（`crates/sepika-section/src/catalog.rs`）が表値を用いた断面生成を行い、CSV の mm 系換算は同モジュールの `parse_csv`、断面名からの形状復元は `parse_shape_from_name` が担います。

</div>

## フィレット・角Rの材料領域

H 形鋼は、ウェブと上下フランジの内隅 4 か所に接する円弧でフィレットを定義します。
角形鋼管・角形 CFT は、外形 H×B の角丸矩形と内形 (H−2t)×(B−2t) の角丸矩形の差を鋼管領域とします。
角Rを ro、内角Rを ri とすると、ri=max(ro−t,0) です。
角形 CFT のコアは、この鋼管内形と同じ領域です。

ro=0 は内外とも直角、0<ro<t は内側が直角となるモデルです。
独立した内角Rの入力は持ちません。
これは入力形状の定義であり、実製品の角部を安全側へ置換したとの認定ではありません。

四分正方形から四分円を除いた領域について、円中心から測る面積・一次・二次モーメントを次で表します。

\\[
a=(1-\pi/4)r^2,\qquad m=r^3/6,\qquad q=(1/3-\pi/16)r^4
\\]

角丸矩形の cH=H/2−r、cB=B/2−r に対し、断面性能は次のとおりです。

\\[
A=HB-4a,\quad
I_y=BH^3/12-4(c_H^2a+2c_Hm+q),\quad
I_z=HB^3/12-4(c_B^2a+2c_Bm+q)
\\]
\\[
Z_p=BH^2/4-4(c_Ha+m)
\\]

鋼管は外形の性能から内形の性能を差し引き、コアは内形の性能を用います。
H のフィレットは直角の板組 H に加える領域で、cH=(H−2tf)/2−r、cB=tw/2+r とします。
a、m、q を用い、A に 4a、Iy に 4(cH²a+2cHm+q)、Iz に 4(cB²a−2cBm+q)、Zp に 4(cHa+m) を加えます。

設計重量は保存 A に、物理質量と質量二次モーメントは材料領域の A・Iy・Iz に各材料の密度を掛けます。
CFT は鋼管と充填コンクリートを分けるため、コアを鋼管の密度で重複計上しません。
カタログ・直接入力の保存性能は形状算定値で上書きせず、フィレット半径・角Rが未知でも入力性能だけで成立する計算は継続します。
ただし、コアやファイバーなど未知寸法を必要とする計算は理由付きエラーとなります。

一般ブレースの Truss 要素も、物理質量はこの共通の材料領域算定を用います。
軸剛性の A はカタログ・直接入力値を保護したまま保持し、質量源の A と混同しません。
Truss の Lumped・Consistent は同じ単位長さ質量を用い、形状がない場合は直接入力性能と主材料から算定します。

J と剛性用の鋼材せん断面積の算定方法は既存式を維持し、フィレット・角Rを反映していません。
検定用の角形鋼管せん断面積にある既存の角R参照は維持し、今回の材料領域の差分を使う新しい方法へは置換しません。
この維持を安全側とは認定しておらず、J は [#416](https://github.com/hrntsm/SEPIKA/issues/416)、鋼材せん断面積は [#417](https://github.com/hrntsm/SEPIKA/issues/417) で追跡します。
CFT の既存せん断式が参照するコア面積は、角丸内形の面積を用います。

CFT の Lumped 質量も、鋼管・コアそれぞれの密度×面積の和を用います。
要素ではこの単位長さ質量を合計面積で除した等価密度を保持するため、コンクリート密度を鋼管へ流用しません。
点質量の配置方式や、地震用重量と物理質量の区別は変更しません。

階の動的質量と二次部材の物理質量相当自重も、共通の材料領域から求める単位長さ質量を用います。
CFT の鉄骨割増は、その全量から充填コンクリート質量を除いた鋼管部分だけに適用します。
解析要素の質量行列分は割増前の質量とし、補正質点は割増・付加重量を含む物理質量との差で求めます。
保存 A は設計 DL・設計地震用重量の算定で保護し、物理質量から逆算して上書きしません。
必要な材料領域や質量特性が解決できない場合、自重・階質量の生成は理由付きエラーで中断し、質量ゼロに補完しません。
未知のフィレット半径・角Rについて、A だけが直接入力され、Iy・Iz が形状未算定の断面もこの対象です。
鋼材の A・Iy・Iz がすべてカタログ・直接入力なら、それらの値で成立する共通質量算定は維持します。

<div class="impl-ref">

## 算定元と未知寸法

保存する性能には項目別の算定元を持たせ、形状算定値とカタログ・直接入力値を区別します。
フィレット半径・角Rの編集時は形状算定の A・Iy・Iz だけを再計算し、個別に直接入力した項目は維持します。
たとえば A だけを直接入力した断面では、A を維持しながら Iy・Iz が形状編集に追従します。
材料・用途・階と項目別の区分は、undo/redo と OVIKA の保存往復でも保持します。

ST-Bridge から未知寸法を取り込む場合は、未知のフィレット半径・角Rと断面形状を保持します。
このとき A・Iy・Iz は `PendingShape`（未算定）として保持し、格納欄の値を計算値として用いません。
GUI・CSV は「未算定」、公開 JSON の性能値は `null` と理由を示します。
必要な寸法が確定すると未算定の形状項目を算定し、直接入力項目を保護したまま更新します。

入力値を検証する API は `try_calc_*`、`try_to_section`、未知の入力を保持する API は `input_section` です。
非 fallible な算定 API は、算定不能時に panic するため、未知寸法を扱う呼び出し側では検証付き API を用いてください。

<div class="impl-ref">

**実装参照**：`Section::{ensure_properties_resolved, resolved_area, with_surface_radius}` と `SectionPropertyBasis`（`crates/sepika-core/src/model/section.rs`）が未算定の拒否と項目別更新を担います。
`SectionShape::input_section`（`crates/sepika-core/src/section_shape/builder.rs`）が未知の入力を保持します。

</div>

## 矩形ねじり定数

矩形断面のねじり定数 J は、Saint-Venant のねじり理論による矩形断面の級数近似式で算定します。

**算定式**：
\\[ J = \frac{b^3 h}{16} \left[ \frac{16}{3} - 3.36 \frac{b}{h} \left( 1 - \frac{1}{12} \left( \frac{b}{h} \right)^4 \right) \right] \\]
（\\( b = \text{短辺} \\)、\\( h = \text{長辺} \\)）。

<div class="impl-ref">

**実装参照**：`sepika_core::section_shape::geometry::rect_torsion_j`（`crates/sepika-core/src/section_shape/geometry.rs`）が算定します。

</div>
