# コンクリートのヤング係数 Ec

コンクリートのヤング係数 Ec は、RC 規準の Ec 式で算定します。

\\[ E\_c = 3.35 \times 10^4 \cdot (\gamma\_C/24)^2 \cdot (F\_c/60)^{1/3} \\]

RC 材料では、保存済みの質量密度 ρ [ton/mm³] から γRC = ρg×10⁶ [kN/m³] を復元し、
γC = γRC - 1.0 [kN/m³] とします。したがって、γRC=24 kN/m³ の標準材料は
γC=23 kN/m³ です。質量密度が有限な正値でない場合は、既定値 γC=23 kN/m³ を用います。
Fc≤0 の場合、Ec は 0 とします。
