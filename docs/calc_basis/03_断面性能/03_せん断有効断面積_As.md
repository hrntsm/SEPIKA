# せん断有効断面積 As

せん断有効断面積 As は、初期弾性解析のせん断剛性 \\( GA\_s \\) に用いる面積です。
RC は \\( A\_s = A/\kappa \\)（\\( \kappa = 1.2 \\)）とします。
SRC は RC 部分のせん断有効断面積 \\( {}\_{rc}A\_s = {}\_{rc}A/\kappa \\) に、材料由来の換算係数 \\( n\_{gs} \\) による鉄骨等価分 \\( {}\_s A\_s \cdot (n\_{gs} - 1) \\) を累加します。材料由来の値を算定できないときは \\( N\_S\_EQ = 15 \\) の既定値を用います（[SRC / CFT の等価断面性能](06_SRC_CFT_の等価断面性能.md)）。
S 造の H 形・角形鋼管は、以下の方向別板面積を採用します。カタログ・直接入力で供給された断面性能は、形状算定値と区別して扱います。

形状係数 \\( \kappa = A/A\_s \\) と面積乗算係数 \\( k = A\_s/A \\) は逆数です。
\\( GA/\kappa = GkA = GA\_s \\) であり、As に換算した後で再び κ で除しません。
寸法は mm、As は mm²、G は N/mm²、GAs は N、部材長 L に対するせん断ばね剛性 GAs/L は N/mm です。

**算定式（代表例）**

H 形:

\\[ a\_{s,y}\text{（弱軸）} = 2 \cdot B \cdot t\_f \\]

\\[ a\_{s,z}\text{（強軸）} = H \cdot t\_w \\]

一様厚さの角形鋼管:

\\[ a\_{s,y}\text{（弱軸）} = 2t(B-2t),\qquad a\_{s,z}\text{（強軸）} = 2t(H-2t) \\]

これらは剛性用の慣用面積で、H のフィレットや角形鋼管の角Rの円弧面積を加算しません。
H を矩形板二枚に置き換えて κ=1.2 を一律適用したり、20%の誤差があると断定したりする根拠にはなりません。

矩形 RC:

\\[ a\_s = b \cdot d/1.2 \\]

円形鋼管:

\\[ a\_s = A/2 \\]

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( A\_s \\) | せん断有効断面積（要素剛性用） | mm² |
| \\( A \\) | 断面積 | mm² |
| \\( {}\_{rc}A\_s, {}\_s A\_s \\) | RC 部分・内蔵鉄骨部分のせん断有効断面積 | mm² |
| \\( n\_{gs} \\) | せん断弾性係数比を考慮した換算係数 | - |
| \\( N\_S\_EQ \\) | 材料から換算係数を算定できないときの SRC 鉄骨の等価ヤング係数比（暫定既定） | - |
| \\( \kappa \\) | せん断形状係数 | - |
| \\( a\_{s,y} \\) | 断面性能の弱軸側せん断有効断面積 | mm² |
| \\( a\_{s,z} \\) | 断面性能の強軸側せん断有効断面積 | mm² |
| \\( B \\) | H のフランジ幅、角形鋼管の外幅 | mm |
| \\( H \\) | 断面せい | mm |
| \\( t\_f \\) | フランジ厚 | mm |
| \\( t\_w \\) | ウェブ厚 | mm |
| \\( t \\) | 角形鋼管の板厚 | mm |
| \\( b, d \\) | 矩形断面の幅・せい | mm |

**断面検定で用いる有効断面積とは別の量です**

本節の \\( A\_s \\) は**要素剛性**（ティモシェンコ梁のせん断剛性 \\( GA\_s \\)）に用いる値です。
鋼構造の許容応力度検定でせん断応力度 \\( \tau = |Q|/A\_d \\) を求めるときの検定用面積 Ad は、これとは別の定義によります（[鋼構造 断面検定](../06_一次設計/03_鋼構造_断面検定.md)「せん断の検定」）。
検定側はウェブの内法せいを用い、フランジのせん断応力分布も考慮するためです。

H 形では、本節が \\( a\_{s,z} = H t\_w \\)（ウェブ全せい）・\\( a\_{s,y} = 2 B t\_f \\) であるのに対し、検定側は \\( A\_y = t\_w(H - 2 t\_f) \\)・\\( A\_z = 2 B t\_f/1.5 \\) となります。

H400×200×8×13 は、フィレット半径が 0 mm でも 13 mm でも剛性用 \\( (a\_{s,y},a\_{s,z})=(5200,3200) \\)、検定用 \\( (A\_y,A\_z)=(2992,3466.6666666667) \\) mm²です。
角形鋼管400×300×12の剛性用面積は \\( (a\_{s,y},a\_{s,z})=(6624,9024) \\) mm²で、検定用面積の角R依存とは区別します。
H形・角形鋼管・その他の形状の柱／梁の検定では、方向別せん断比の和と、von Misesへの \\( \tau\_{\mathrm{sum}}=|Q\_y|/A\_y+|Q\_z|/A\_z \\) の接続を採用します。
実際の部材別の法線応力と合成式は[鋼構造 断面検定](../06_一次設計/03_鋼構造_断面検定.md)に示し、本節の剛性用Asへこの検定用の加算規約を流用しません。

## 力の方向と断面性能の対応

添字は断面性能と部材内力で同じ意味ではありません。強軸・弱軸は断面形状の基準軸を表し、空間内の取付方向は部材の局所座標で扱います。

| 曲げ面 | 部材内力 | 断面二次モーメント | 剛性用 As | 検定用 Ad |
| --- | --- | --- | --- | --- |
| 強軸 | Mz、Qy | Iy | as_z | Ay |
| 弱軸 | My、Qz | Iz | as_y | Az |

## エネルギー等価面積との区別

均質線形弾性断面のエネルギー等価なせん断面積は、断面内の二成分のせん断応力から定義できます。

\\[ A\_{s,\mathrm{energy}} = \frac{V^2}{\int_A(\tau_1^2+\tau_2^2)\,dA} \\]

Jourawski のせん断応力分布に限定して評価すると、次式になります。

\\[ A\_{s,J} = \frac{I^2}{\int Q(s)^2/b(s)\,ds} \\]

ここで V はせん断力 [N]、Q(s) は断面一次モーメント [mm³]、I は断面二次モーメント [mm⁴]、b(s) と s は mm です。
この剛性の定義は、許容応力度検定の Ad の定義や、上記慣用面積の物理精度を保証するものではありません。

## 出典と確認範囲

[Favataほか、2010、§2、式(8)(9)、p.5](https://arxiv.org/pdf/0912.2622#page=5)は、せん断応力のエネルギー等価による形状係数を定義しています。上記の慣用面積とは区別します。
せん断検定面積の採用方式と適用範囲は[鋼構造 断面検定](../06_一次設計/03_鋼構造_断面検定.md)を参照してください。

## As = 0 は入力エラー

線材（梁・柱・ファイバー・マルチスプリング）が参照する断面の \\( A\_{s,y} \\)・\\( A\_{s,z} \\) は正の値でなければならず、0 の断面を用いるモデルは解析前チェックでエラー停止します。\\( A\_s = 0 \\) はティモシェンコ梁の \\( \phi = 0 \\)（せん断変形なし）となるうえ、せん断降伏の判定閾値も \\( Q\_y = +\infty \\)（せん断では決して降伏しない）となり、入力不足が「せん断について無限に強い部材」として通ってしまうためです。

せん断変形を無視した検討を行う場合は、断面の \\( A\_s \\) を 0 とするのではなく、部材のモデル化として十分大きな \\( A\_s \\) を与えてください（\\( \phi \to 0 \\) でベルヌーイ梁に一致します）。
