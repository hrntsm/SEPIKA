# 並列計算

右バー「① 準備計算」の「計算条件」で解析に使うスレッド数を指定します。解析対象・荷重・収束条件は、各解析の設定で指定します。

## 設定と採用方法

| 設定値 | 意味 |
| --- | --- |
| 0（既定） | 自動。使用可能なコアを基に配分する |
| 1 | 単一スレッドで実行する |
| n（2 以上） | 指定したスレッド数を基に配分する |

行列の分解・求解、荷重ケースごとの求解、非線形解析の要素評価を並列化します。
一括解析ではケース数に応じて同時に解くケース数と行列求解のスレッド数を配分し、コアの過剰な割当を抑えます。
荷重組合せは各ケースの応答係数和であり、組合せ数だけ独立した求解を行う方式ではありません（[線形静解析](./02_線形静解析.md)）。

## 計算時間と結果の再現

所要時間とメモリは、モデル・非ゼロ配置・ケース数・反復回数・コア数・実行環境に依存します。小規模な解析ではスレッド管理の負担が増え、並列化で遅くなる場合もあります。特定の倍率やコア数に比例した高速化は保証しません。

浮動小数点の加算順序が変わると丸め差が生じます。要素評価の集約順序は固定していますが、解析全体には行列ソルバの演算も含まれます。並列の有無だけから解析全体のビット一致を保証することはできません。
再現性を確認する場合はスレッド数を 1 にし、同じ実行ファイル・依存ライブラリ・計算環境・入力・設定をそろえて比較してください。異なる版・CPU・環境まで含む無条件のビット一致保証ではありません。

丸め差が収束判定やヒンジ判定のしきい値付近で反復回数・終了点を変える可能性があります。差を一律に工学的に無視できるとは扱わず、判定値・収束・確定範囲への影響を確認してください。
