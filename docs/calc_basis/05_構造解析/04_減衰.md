# 減衰

減衰マトリクスを、質量比例、初期剛性比例、Rayleigh、モード別、接線剛性比例の各方式で、構造動力学の標準手法に準拠して構成します。

**算定式**

質量比例（\\( a\_0 = 2h\omega \\)）:

\\[ C = a\_0 \cdot M \\]

初期剛性比例（\\( a\_1 = 2h/\omega \\)）:

\\[ C = a\_1 \cdot K \\]

Rayleigh は減衰マトリクスを次とし、係数を次で定めます:

\\[ C = a\_0 \cdot M + a\_1 \cdot K \\]

\\[ \beta\_k = \frac{2(h\_2\omega\_2 - h\_1\omega\_1)}{\omega\_2^2 - \omega\_1^2} \\]

\\[ \alpha\_m = \frac{2\omega\_1\omega\_2(h\_1\omega\_2 - h\_2\omega\_1)}{\omega\_2^2 - \omega\_1^2} \\]

モード別:

\\[ C = \sum 2h\_i\omega\_i(M\varphi\_i)(M\varphi\_i)^\mathsf{T} \\]

接線剛性比例:

\\[ C = (2h/\omega) \cdot K\_t \\]

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( C \\) | 減衰マトリクス | N·s/mm |
| \\( M \\) | 質量マトリクス | t |
| \\( K \\) | 初期剛性マトリクス | N/mm |
| \\( K\_t \\) | 接線剛性マトリクス | N/mm |
| \\( h \\) | 減衰比 | - |
| \\( h\_1,\\ h\_2 \\) | Rayleigh に用いる 1 次・2 次の減衰比 | - |
| \\( \omega \\) | 基準の固有円振動数 | rad/s |
| \\( \omega\_1,\\ \omega\_2 \\) | Rayleigh に用いる 1 次・2 次の固有円振動数 | rad/s |
| \\( a\_0,\\ \alpha\_m \\) | 質量比例の係数 | 1/s |
| \\( a\_1,\\ \beta\_k \\) | 剛性比例の係数 | s |
| \\( \varphi\_i \\) | i 次の固有ベクトル（モード形状） | - |

**基準振動数の求め方**

剛性比例と接線剛性比例の基準は初期剛性の 1 次固有円振動数、Rayleigh は 1 次・2 次を用います。
モード別は 6 次から 1 次の順に試行し、得られた低次モードに一律の減衰比を与えます。

**初期剛性比例の適用**

初期剛性は、長期荷重と動的初期変位を与える前の未載荷状態で定め、初期加速度の評価から全時刻の減衰行列に用います。
長期載荷や地震応答で塑性化しても、状態確定や同じ変位での再評価によって減衰用剛性を切り替えません。
復元力と材料履歴は非線形に更新し、釣合い反復には現在の接線剛性を用います。

塑性化後も初期剛性に比例した減衰力が作用します。したがって同じ速度なら、剛性低下した接線に比例する方式より大きな減衰力となり得ます。
塑性履歴によるエネルギー消費に加えて粘性減衰を与えるため、減衰が過大となり、変位や応力の応答を過小評価する可能性があります。
初期剛性比例がすべての建物・応答について安全側になるという保証はありません。
塑性化の程度、減衰比、減衰力の大きさと応答への影響を確認し、適用する解析モデルに応じて減衰条件を選んでください。

**既定値**（解析タブ）:

時刻歴応答解析では、次の値を既定とします。

| 項目 | 既定 |
| --- | --- |
| 減衰比 | 0.02 |
| 減衰モデル | 初期剛性比例 |
| Rayleigh の 2 次モード減衰比 | 0.02（1 次は上記の減衰比） |
| 質点系の減衰比 | 0.02（初期剛性比例固定。立体時刻歴とは独立） |

立体時刻歴では Rayleigh・モード別・接線剛性比例（α1 一定、h1 一定）も選択できます。
接線剛性比例を明示的に選んだ場合は、現在の接線に応じて減衰行列が変わります。
保存した解析設定の減衰方式を再実行時にも用います。
時刻歴応答解析での使い方は [時刻歴応答解析](./05_時刻歴応答解析.md) を参照してください。
質点系の減衰は初期剛性比例のみで、減衰比は右バー「質点系」の設定を使います（既定は上表。[質点系解析](./10_質点系解析.md)）。
