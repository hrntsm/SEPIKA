# 質点系解析

本節では、各階を質点に縮約したせん断型・曲げせん断型モデルの固有値と時刻歴を扱います。
立体 FEM の固有値・時刻歴とは独立した解析です。

立体のモードは部材の曲げや局部変形を含むため、質点系の次数と並べて読むことはできません。
対応する並進モードを選び、同じ頂部変位で正規化した形状と周期を比較してください。自由度と質量行列が異なるため、同じ次数や周期の厳密一致は要求しません。
曲げせん断型は、柱軸伸縮による建物全体の弾性曲げをせん断変形から分離します。弾性曲げ要素と履歴せん断ばねの直列接続を用い、別方式の回転ばね型は提供しません。
曲げせん断型の入力不足、非有限な質量・剛性、時刻歴の未収束は理由付きの計算失敗として通知します。空の応答結果として扱いません。

実行は右バー「質点系」です。
表とグラフは結果タブ「質点系」、球とばねは 3D ビューアの「質点モード」「質点時刻歴」です。

## 前提

| 設定 | 必要な先行結果 |
| --- | --- |
| 2 次元・線形 | 加振方向の地震静的（EX または EY） |
| 3 次元・線形 | 地震静的 EX と EY の両方 |
| 2 次元・非線形 | 加振方向の増分解析と同じ水平力分布の地震静的 EX または EY |
| 3 次元・非線形 | X・Y 両方の増分解析と、ねじり剛性のための EX・EY |

表の先行結果は、現在のモデル・その先行解析の計算条件と一致する生成入力を持つ必要があります。
結果の欠落、生成入力の記録欠落、入力の不一致は、対象の方向と再解析の案内を表示して質点系解析の開始を拒否します。
せん断型では未使用方向の結果は要求しません。非線形でも、初期剛性のために対象方向の地震静的結果が必要です。
曲げせん断型は線形・非線形とも対象方向の EX/EY を必要とし、3 次元では両方向を必要とします。
非線形では、それらに加えて対象方向の増分解析も必要です。
表示の切替、質点系固有値のモード数や質点系時刻歴の時間刻みだけの変更では先行再解析は不要です。

3 次元のねじりばね（KR）は、線形・非線形のいずれでも線形ばねです。
非線形の並進だけが増分解析のトリリニアを使い、ねじりは偏心率精算の KR のままにするためです。

波形はサンプル波か波形ライブラリから選びます。
立体時刻歴にある「波形 CSV を開いて実行」は、質点系パネルにはありません。
プロジェクトファイル（`.ovika`）には設定・固有値・時刻歴結果を同梱し、波形の実体はライブラリ参照です。
質点系時刻歴は線形・非線形、平面・空間とも途中状態の保存・再開には対応しません。立体線形時刻歴との対応の違いは[解析の中断と再開](./05_時刻歴応答解析.md#解析の中断と再開)を参照してください。

サンプル波は立体時刻歴と同じ式です。

\\[ \ddot{x}\_g(t) = A \sin(\omega t)\\, e^{-0.3 t},\quad \omega = 2\pi / T \\]

\\( A \\) は振幅、\\( T \\) は周期、\\( dt \\) は刻みです。

入力 N 点は時刻 0 から (N−1)dt の瞬時値で、積分は N−1 区間です。
平面・空間とも、先頭は積分前の静止初期変位・速度に対応し、相対初期加速度は先頭地動の釣合いから求めます。
サンプル波の点数と丸上げ終時刻、外部入力の下限は [時刻歴の入力時刻と初期状態](./05_時刻歴応答解析.md#入力時刻と初期状態) と共通です。
初期釣合いと積分で扱う加速度は相対加速度で、並進の絶対加速度は同時刻の地動を加えた値です。

## 質量

各層の質量は上端階の**物理質量相当重量** \\( W\_{\text{mass}} \\) を重力加速度で割った値です（\\( m = W\_{\text{mass}}/g \\)）。
物理質量相当重量は準備計算で節点から階ごとに集計します。
質量方式（[固有値解析](./03_固有値解析.md)の質量モデル）に依らず全量を用います（串団子は部材分布質量を持たないため）。

物理質量相当重量は物理質量（鋼材は物理質量密度 7.85 t/m³）に基づき、設計地震用重量 （鋼材は 78.5 kN/m³）とは一致しません（[地震用重量・層データの生成](../01_荷重/05_地震用重量_層データの生成.md)の「動的解析用の質点質量の設定」）。
手入力の地震用重量は設計地震力のみを変え、質点系の質量は変えません。

未算定なら準備計算で階を生成する必要があり、質点系は明示エラーで止まります（設計重量での代用はしません）。

3 次元の回転慣性 \\( J \\) [t·mm²] は、同じ物理質量分布から質量重心まわりに直接算定した値です。
質点の平面位置はその質量重心 です。

\\[ J = \sum \frac{w\_{\text{mass},i}}{g} \\, \lvert r\_i - G \rvert^2 \\]

\\( r\_i \\) は節点 \\( i \\) の平面位置、\\( G \\) は質量重心です。
2 次元の 3D 表示では、剛床マスター（なければ原点）を代表点にします。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( m \\) | 層の質量 | t |
| \\( W\_{\text{mass}} \\) | 上端階の物理質量相当重量 | N |
| \\( w\_{\text{mass},i} \\) | 節点 \\( i \\) の物理質量相当重量 | N |
| \\( g \\) | 重力加速度 | mm/s² |
| \\( J \\) | 3 次元の質量重心まわりの回転慣性 | t·mm² |
| \\( r\_i \\) | 節点 \\( i \\) の平面位置 | mm |
| \\( G \\) | 階の質量重心 | mm |
| \\( Q \\) | 地震静的解析の層せん断力 | N |
| \\( \delta \\) | 層間変位 | mm |
| \\( K\_x,\\ K\_y \\) | 層の並進剛性（X・Y 方向） | N/mm |
| \\( k\_i \\) | 柱の剛性（\\( Q\_i/\delta\_i \\)） | N/mm |
| \\( K\_R \\) | 層のねじり剛性 | N·mm/rad |
| \\( r\_x,\\ r\_y \\) | 剛心の重心に対する相対位置 | mm |
| \\( \omega \\) | 固有円振動数 | rad/s |
| \\( T \\) | 固有周期 | s |
| \\( \mu\_X,\\ \mu\_Y,\\ \mu\_{45} \\) | X・Y・45° の層塑性率 | - |
| \\( d_{yx},\\ d_{yy} \\) | 各方向骨格の等価降伏変形（第2折点） | mm |

## 層並進剛性

**層 Q/δ（既定、線形時）**

地震静的 EX の層せん断 \\( Q \\) と層間変位 \\( \delta \\) から \\( K\_x = |Q|/|\delta| \\)、EY から同様に \\( K\_y \\) を算定します。
層せん断は、増分性能曲線と同じ全要素の物理節点力・支持反力から算定します。壁・ブレースの寄与も含め、柱だけの合計では代用しません。
層せん断を層間で足し直しません。

2 次元の層間変位は、階の代表節点（剛床マスター、なければ質量最大の節点）の水平変位差です。
3 次元の層間変位は、その層の剛心の平面位置における剛床変位の上下差です。
3×3 の並進ばねは剛心位置のばねなので、\\( \delta \\) も剛心で取ります。
上下とも同じ平面位置で取るため、セットバックでマスターがずれても層間になります。
上下階の重心が異なる場合も、上階はその層の剛心から上階重心への距離、下階は同じ剛心から下階重心への距離で回転変位を変換します。この変換と転置による力の変換を剛性・減衰・内力・応答へ共通に適用します。

剛心座標とねじり剛性 KR [N·mm/rad] は、偏心率の精算と同じ柱剛性 \\( k\_i = |Q\_i|/|\delta\_i| \\)（雑壁の寄与を含む）から算定します。
柱の変位差が0の場合、又は剛性の商が非有限になる場合は算定できません。正の微小変位を剛性0へ置き換えません。
保存した静的応答から層せん断・柱剛性を求めるときは、使う柱の局所軸が解決できない場合に部材と理由を示して停止します。この集計に使わない梁の参照方向は要求しません。

**柱 ki（線形時）**

\\( K\_x \\)・\\( K\_y \\)・剛心・KR をすべて柱の \\( k\_i \\) 合計（偏心率精算と同じ）から定めます。

非線形時も、同じ EX/EY の弾性静的応答から求める初期剛性を固定します。増分解析と弾性静的解析の水平力分布をそろえ、元骨格が初期弾性直線を上回る場合は、初期状態・荷重条件・代表位置を確認します。増分曲線の最初の記録点から初期剛性を取り直しません。
せん断型は \\(K_0=Q^{el}/\delta^{el}\\)、曲げせん断型は \\(K_{s0}=Q^{el}/(\delta^{el}-\delta_b^{el})\\) とします。後者の曲げ変位は全高さで回転を累積して求めます。正のせん断剛性が得られない場合は停止し、絶対値や微小正値で成立させません。

## 初期剛性固定の非線形骨格と減衰

標準骨格は、初期の剛性低下を表す第1折点と、等価降伏を表す第2折点を持つトリリニアです。復元力は最大点指向型（Clough 系）です。
元曲線は、増分解析の確定点から水平力ゼロ時の変位・層せん断力を控除した区分線形曲線です。曲げせん断型では同じ載荷状態の弾性曲げも控除し、非線形のせん断成分を近似します。

### 面積の評価上限

全層に共通の目標層間変形角 \\(R_{target}\\)（既定1/200）と、その層の建築階高 \\(h_{FL}\\) から、全層間変位の目標 \\(\delta_{target}=R_{target}h_{FL}\\) を求めます。階高3,000 mmなら15 mmです。
曲げせん断型では全層間変位がこの目標へ到達する確定ステップ間を補間し、その載荷状態の弾性曲げを控除した正のせん断変位を面積上限 \\(D_{area}\\) とします。曲げ棒には構造階高（SL間）、目標変形角の換算には建築階高（FL間）を使います。
目標未到達では面積を確定できないため、最後の記録点への置換・外挿を行いません。

### 第1・第2折点

元曲線と \\(Q=\alpha K_0d\\) の最初の原点以外の交点を補間し、その荷重 \\(Q_c\\) を初期直線へ投影して \\(d_c=Q_c/K_0\\) とします。交点の変位自体を折点にしません。割線比の既定 \\(\alpha=0.75\\) は近似設定であり、すべての構造種別に共通の物性値ではありません。
この荷重投影の考え方は、小林ほか（2002）§3.1.2・図7、p.1077に対応します。同論文の対象は梁降伏型RC架構であり、層の第1折点は最初の部材のひび割れ・降伏と同一ではありません。

降伏後直線 \\(Q=K_pd+b\\) は、採用区間 \\([a,b_{fit}]\\) の区分線形曲線に対し、変形方向に均等な重みの連続最小二乗で求めます。

\\[
\min_{K_p,b}\int_a^{b_{fit}}[Q_{original}(d)-(K_pd+b)]^2\\,dd
\\]

固定した初期剛性、第1折点、降伏後直線のもとで、次の等面積条件から等価降伏点 \\((d_y,Q_y)\\) を求めます。

\\[
\int_0^{D_{area}}Q_{tri}(d)\\,dd=\int_0^{D_{area}}Q_{original}(d)\\,dd,
\quad Q_y=K_pd_y+b,
\quad K_2=(Q_y-Q_c)/(d_y-d_c)
\\]

非負の剛性低下型 \\(K_0>K_2>K_p\ge0\\)、独立した折点 \\(0<d_c<d_y\le a\\) を識別できることを要求します。第2折点が面積上限より後にあっても、第2勾配を通じて面積から一意に識別できれば採用できます。面積上限まで初期直線上にあり、面積条件が降伏点に依存しない場合は未同定です。
耐力低下、区間不足、等面積解の不存在・非一意は区別して近似不成立又は等価降伏未同定として表示・保存し、仮折点・負勾配のゼロ置換・切詰め・無言の弾性置換を行いません。

### 降伏後区間の自動選定と任意変更

自動同定上限 \\(D_{fit}\\) は、元増分解析に保存した終了目標へ最初に到達する載荷状態を補間して定めます。頂部変位と全層最大層間変形角の両方が有効なら先着、両方無効なら荷重倍率1です。各層における実際の全層間変位又はせん断変位へ対応付けます。終了理由名や後から変更した画面条件で上限を決めません。

無次元座標 \\(d/D_{fit}\\) 上で開始点を変え、共通終点 \\(D_{fit}\\) の候補を比較します。等価降伏点が区間開始以後に出る候補を除外し、全候補で共通の範囲における規格化誤差を評価します。

\\[
e=\sqrt{\frac{\int_0^{D_{fit}}[Q_{tri}(d)-Q_{original}(d)]^2\\,dd}{D_{fit}Q_{ref}^2}},
\quad Q_{ref}=\max_{[0,D_{fit}]}|Q_{original}|
\\]

| SEPIKA独自の数値条件 | 採用値 |
| --- | --- |
| 初期探索 | 第1折点以後〜終了点の手前10%を128分割 |
| 最良候補の近傍精細化 | 初期1区間幅の両側をそれぞれ16分割 |
| 最小同定区間幅 | \\(0.1D_{fit}\\) |
| 最良候補の許容規格化RMSE | 0.05以下 |
| 同程度の競合とみなす誤差 | 最良値＋0.001以下 |
| 競合間の降伏変位差の許容値 | \\(0.05D_{fit}\\) 以下 |
| 数値的同等性の許容値 | 無次元量で \\(10^{-10}\\) |

最良でも近似不良なら採用しません。最良近傍と同程度の競合候補の降伏変位が不安定なら未同定とします。数値的に同等な候補では広い区間を決定的に採用します。
積分は区分線形曲線について行うため、同じ折れ線への記録点追加で最小二乗の重みを変えません。同定上限より先の追加データを選定に使いません。

自動探索で全候補が不成立の場合は、区間不足・等面積解なし・非一意・骨格形状不成立の候補数を理由に含めます。面積が降伏点によらず一定でも、元骨格の面積と不一致なら解なし、一致すれば非一意として区別します。

選定区間・同定上限・面積上限・降伏後剛性・等価降伏点・規格化誤差・元終了目標を結果へ表示し保存します。「降伏後直線の同定区間」で必要な層・方向だけ手動変更できます。未指定が自動選定で、変更時も同じ面積・最小幅・適合・骨格成立条件を適用します。手動区間の変更・Undo・Redoでは、元の静的・増分成果を保持して質点系の骨格・固有値・応答の表示窓口だけを無効化します。再実行するまで旧条件の折点・周期を最新の数値として表示・保存しません。階を挿入・削除した場合も、設定を元の階へ対応付け直し、削除した階の設定を別の階へ移しません。

小林ほかの原著は降伏後の2点を用いる方法です。変形方向均等の連続最小二乗、自動区間選定、競合安定性及び上表はSEPIKAで具体化した条件であり、文献でそのまま検証された手順ではありません。これらは構造応答の安全側を保証する条件でもありません。

固有値と減衰には固定した初期剛性を用います。初期剛性比例減衰は \\(C=(2h/\omega_1)K_0\\) です。
せん断型の減衰用一次振動数は、固有値分解失敗時に逆反復法の概算を用います。曲げせん断型は追加回転と物理慣性を含む固有値を必要とし、算定失敗時に概算へ切り替えません。

## 層塑性率の定義と妥当性

主指標は、層全体を集約した等価骨格に対する最大変形倍率です。同じ非線形ばねの変形 \\(d\\) と等価降伏変形 \\(d_y\\) を対応させ、\\(\mu^{eq}=\max_t|d(t)|/d_y\\) とします。
せん断型は全層間変位、曲げせん断型の「等価層塑性率（せん断成分）」はせん断ばね変形を使います。トリリニアの履歴則で降伏に用いる第2折点を分母とし、第1折点や \\(Q_y/K_0\\) で割り直しません。

初部材降伏を基準にすると、局所的な早期降伏が主指標を決める場合があります。ここでは層を集約した等価骨格の降伏を用い、初部材降伏イベントと部材の曲率・回転塑性率は補助情報として区別します。等価層塑性率は部材塑性率の最大値・平均値でもありません。Reyes-Salazarほか（2018）§3.3・式(2)のように当該層の梁又は柱の初降伏時の層間変位を基準にする定義も実在し、同論文の部材曲率塑性率（式(1)）とは別です。今回は局所的な初降伏基準を主指標へ自動採用しません。\\(\mu^{eq}<1\\) でも全ての部材が弾性とは限りません。

曲げせん断型は比較用の「等価層塑性率（全層間変位）」も保持します。

\\[
\mu_{\Delta}^{eq}=\frac{\max_t|\delta_s(t)+\delta_b(t)|}{d_y+\delta_{b,y}^{ref}},
\qquad \delta_{b,y}^{ref}=\delta_b^{el}\\,Q_y/Q^{el}
\\]

分母の曲げは、同じ静的水平力分布で当該層の等価降伏荷重に対応する弾性曲げ変位です。元曲線の同じ荷重時の全変位ではなく、等価骨格のせん断降伏変位に加えます。分子は各時刻で曲げとせん断を合成した後の最大であり、両成分の最大値を足しません。主指標と固定比で換算せず、異なるモデル形式の数値を同じ物差しとして単純比較しません。

島崎・和田（1994）p.107 §4.3・図15の説明では、高層RC架構の各層のトリリニア第2折点を層塑性率の基準にします。Appendix p.108は初期剛性を保持し、想定最大応答変形までの面積を一致させる近似を示します。同論文の耐力比・剛性比・評価変形範囲を、構造種別によらない既定値にはしていません。
初降伏と等価降伏の定義の違いはPark（1989）§4.1（p.158）・Fig.3（p.159）にも示されますが、同著者の推奨する低減剛性法と今回の固定初期剛性法は別です。
建築研究資料147（2013）第3章では、RC115m級（p.3-23・表3.3-12注）はせん断第2折点時の曲げを含む全層間変位、RC180m級（p.3-27・表3.3-16注）はせん断成分の第2折点を基点とします。資料全体で単一の統一定義を示すものではありません。

1/200は面積評価の上限であり、降伏角や塑性率1の点ではありません。同定範囲・区間・近似条件が降伏点へ影響するため、比較・判定には定義と適用条件をそろえます。等面積は単調骨格の仕事量をそろえる条件であり、繰返し履歴の消費エネルギー、部材損傷、最大地震応答の一致を保証しません。
未同定の対象方向は実際に同定できなかった方向であり、3次元の加振方向選択とは独立に保存・表示します。元増分の終了目標不足など層共通の失敗は対象方向の全層と表示します。

未同定・近似不成立時は保存した元手動区間を層・方向とともに現在の編集値と分けて表示します。対象層・方向と理由及び元条件を診断として保存し、非線形モデルと塑性率の数値を生成しません。明示選択する弾性解析とは区別します。

独立骨格例では、初期剛性・交点荷重投影・面積及び面積上限より後の等価降伏を確認し、記録点追加・同定上限外追加に対する不変性、近似不良と降伏点不安定の識別を検証しています。これらは限定した数値Verificationであり、実建物や実験によるValidationとは区別します。
限定した二層骨組では、両質点系が基準水平力分布の弾性全層間変位を再現しました。一方、対応するX並進モードの周期は全体架構と約34%異なりました。別の一層骨組の人工正弦入力では、塑性化した両質点系の最大変位が全体架構より約78%大きくなりました。この差は面積一致で動的応答まで一致しないことを示します。本例の大小関係を一般の安全側性へ拡張せず、対応モードと対象入力で縮約の差を確認してください。詳細な試験条件と未検証範囲は開発者向けV&V記録で管理します。

## せん断型の 2 次元（せん断串）

加振方向 1 本の質点列です。層間ばねはせん断型三重対角です。

**算定式**

固有値は

\\[ K x = \omega^2 M x \\]

2 次元では M は対角、K は三重対角です。せん断型の 2・3 次元とも、正の対角質量行列を用いて標準固有値問題へ変換し、対称行列の固有値分解で解きます。

\\[ A=M^{-1/2}KM^{-1/2},\qquad Ay=\omega^2 y,\qquad x=M^{-1/2}y \\]

せん断型は層質量が 0 以下の層を含む場合、固有値を算定できません。3 次元では、さらに質量重心まわりの回転慣性 \\( J\le0 \\) の階がある場合も算定できません。曲げせん断型の質量・慣性の条件は後述の[物理質量と結果の読み方](#物理質量と結果の読み方)に従います。
モード形状は最上階を 1.0 に正規化します。
刺激係数と有効質量は算定しません。
立体固有値の参加係数は M 正規化に紐づく量で、質点系は縮約モデルの周期を見る解析だからです。

時刻歴は Newmark 平均加速度と Newton 反復、減衰は初期剛性比例 \\( a\_1 = 2h/\omega\_1 \\) です。
三重対角の連立方程式は Thomas 法で解きます。収束と記録は後述の条件に従います。

## せん断型の 3 次元（Ux, Uy, θz）

各階の自由度は質量重心における並進 2 成分と鉛直軸まわり回転です。
剛心相対位置を \\( r\_x = X\_s - X\_g \\)、\\( r\_y = Y\_s - Y\_g \\) として、層の 3×3 剛性は次です。

**算定式**

\\[
K =
\begin{bmatrix}
K\_x & 0 & -K\_x r\_y \\
0 & K\_y & K\_y r\_x \\
-K\_x r\_y & K\_y r\_x & K\_x r\_y^2 + K\_y r\_x^2 + K\_R
\end{bmatrix}
\\]

\\( K\_x \\)・\\( K\_y \\) は線形なら静解析の層剛性、非線形なら増分骨格の初期剛性です。
階間は相対変位で直列につながります。
地動は加振方向（X または Y）の 1 方向です。

たとえば偏心のない 1 層では、並進の固有周期は \\( T = 2\pi\sqrt{m/K} \\)、ねじりの固有周期は \\( T = 2\pi\sqrt{J/K\_R} \\) となり、上の 3×3 を対角化した結果と一致します。

非線形時、X・Y の並進ばねは各方向のトリリニア（最大点指向型）、ねじりは KR の線形ばねのままです。
3 次元のモード形状は各階 \\( (U\_x, U\_y, \theta\_z) \\) で、頂部水平変位のノルムで正規化します。
刺激係数と有効質量は 2 次元と同じく算定しません。

## 時刻歴の収束と記録

両モデルとも Newmark 平均加速度法（β=1/4、γ=1/2）と Newton 反復を用います。時間刻みは波形に適用する刻みであり、立体時刻歴の記録間引き設定は適用しません。初期点と各積分時刻の頂部変位・各階変位を記録し、全時刻から層間変位・層せん断力・塑性率のピークを求めます。曲げせん断型は曲げ回転も記録します。

全体の Newton 反復は最大 30 回、収束は \\( \lVert r\rVert<10^{-6}r\_{\mathrm{ref}} \\) です。基準は動的外力・慣性力・減衰力のノルムと、解析中の最大力スケールの 1%、最低値 1 の最大です（[立体時刻歴の収束式](./05_時刻歴応答解析.md#非線形時刻歴newmark-β--newton-raphson)）。

| モデル | 反復上限内に収束しない場合 | 利用可能な結果 |
| --- | --- | --- |
| せん断型（2・3 次元） | その時点の試行状態を確定して続行し、結果画面へ未収束ステップ数を警告 | 記録・ピークには未収束の試行応答が含まれる。残差収束を確認できていない参考値 |
| 曲げせん断型（2・3 次元） | 時刻と理由を示して計算失敗とする。直列要素内の局所釣合い失敗も停止対象 | その実行の途中応答を正常な完了結果として返さない |

この違いは線形／非線形の選択によらずモデルごとの求解に適用します。せん断型で未収束警告が出た場合は、後続応答と最大値も試行状態の影響を受けます。正常な収束解として設計採用しないでください。
時間刻みの自動細分は行いません。刻み・骨格・減衰・先行結果を見直して再実行し、刻みを細かくした比較で応答の変化を確認してください。平均加速度法の安定性は時間刻みの精度・非線形反復の収束を保証しません。

せん断型・曲げせん断型とも、固有モードは固有値の低い順（1次から）に並べ、対応する固有周期は長い順に示します。

固有モードは、せん断型では2次元は頂部を1、3次元は頂部水平変位のノルムで正規化します。曲げせん断型も頂部の加振方向成分（2次元）又は水平ノルム（3次元）で正規化し、曲げ回転を同じ倍率で示します。頂部の正規化用成分が極小の場合はモード全体の最大絶対成分で正規化するため、頂部が1になるとは限りません。刺激係数・有効質量は算定しません。立体モードの正規化・自由度とは異なり、振幅値や同じ次数をそのまま比較しないでください。

## 時刻歴の方向別ピーク

時刻歴の層間・層せん断・塑性率は、X・Y・45°・最大の 4 欄で出します。以下の塑性率の変形は、せん断型では全層間変位、曲げせん断型ではせん断ばね変形です。曲げせん断型の層間変位表示は全層間変位のままであり、塑性率の分子と混同しないでください。
地動は X か Y の 1 方向でも、ねじりがあれば剛心位置の層間は平面内を動くためです。

層間は剛心位置の並進 \\( (\delta\_x,\ \delta\_y) \\) です。
層ばねの変形がここだからです。
層せん断は同じ位置のばね力 \\( (Q\_x,\ Q\_y) \\) です。
頂部変位のグラフは質量重心の加振方向成分です。
質点の自由度がそこだからです。

**算定式**

各時刻の値から、層ごとに時刻歴の最大絶対値を取ります。

| 欄 | 層間・層せん断 |
| --- | --- |
| X | \\( \|\delta\_x\| \\)、\\( \|Q\_x\| \\) |
| Y | \\( \|\delta\_y\| \\)、\\( \|Q\_y\| \\) |
| 45° | \\( \max(\|(\delta\_x+\delta\_y)/\sqrt{2}\|,\ \|(\delta\_x-\delta\_y)/\sqrt{2}\|) \\)（せん断も同じ） |
| 最大 | \\( \sqrt{\delta\_x^2+\delta\_y^2} \\)、\\( \sqrt{Q\_x^2+Q\_y^2} \\) |

45° は 45° と 135° の投影の大きい方です。
斜めの応答はどちらの対角にも出るためです。

塑性率は次です。
\\( d_{yx} \\)・\\( d_{yy} \\) は各方向骨格の等価降伏変形（第2折点）です。

| 欄 | 塑性率 |
| --- | --- |
| X | \\( \mu\_X = \delta\_X / d_{yx} \\) |
| Y | \\( \mu\_Y = \delta\_Y / d_{yy} \\) |
| 45° | \\( \mu\_{45} = \delta\_{45} / (\sqrt{2}\\,\min(d_{yx},d_{yy})) \\) |
| 最大 | \\( \max(\mu\_X,\ \mu\_Y) \\) |

45° の分母は、軸平行の降伏矩形 \\( |\delta\_x|=d_{yx} \\)、\\( |\delta\_y|=d_{yy} \\) に沿う斜め距離です。
最大の塑性率は並進ばねが経験した値の包絡です。
合成変位を \\( \min(d_{yx},d_{yy}) \\) で割ると、ばねが感じていない量になるため使いません。

2 次元では加振方向以外の並進は 0 です。
45° は加振方向成分の \\( 1/\sqrt{2} \\) になります。

## 曲げせん断型

### 適用範囲と自動算定

右バー「質点系」の「モデル」で「曲げせん断型」を選択します。
基部の並進・曲げ回転は固定とし、変形前形状の一次釣合いを用います。
曲げは層ごとに一定の弾性剛性とし、曲げ塑性・P–Δ効果・基礎のスウェイ／ロッキングは考慮しません。
柱軸伸縮で高さ方向の曲げを代表できる柱・梁・ブレースの骨組が対象です。壁・シェル・節点ばね・免震・制振部材等は、高さや層中央との交差にかかわらず対象外と診断します。
部材に接続する節点と、剛床・剛リンク・多点拘束に参加する節点（部材に直結しない代表節点も含む）の支持ばねのうち固定されていない自由度の非零成分も対象外です。ゼロ成分と固定自由度のばね成分は作用しないため、この制限に含めません。
基部より上の節点が解析対象の水平方向で地盤に固定される場合も対象外です。2 次元では対象方向、3 次元では X/Y 両方向を確認し、2 次元の面外拘束はこの制限に含めません。傾斜柱には鉛直変位差を軸伸縮として用いることができないため、適用外として解析を停止します。

EX・EY の水平力だけによる柱の軸力・鉛直軸変形・平面位置から算定します。
中間節点で分割された柱は上下階間の連なりを一度だけ数えます。
層を切断するすべての柱について上下階を結ぶ非分岐の連なりであることを確認し、途中階を飛ばす柱・下端階に達しない柱・中間分岐を持つ柱は、階と部材を特定して停止します。
仕口パネルの接続節点列は独立した層切断部材として重ねて数えず、その変形は骨組の全層間変位に含めます。
軸力は引張正、全体座標の上向きを正とし、X 方向加力は Y 軸回り、Y 方向加力は X 軸回りの曲げ剛性に対応します。
同一の平面基準点からの座標を使い、上下端で

\\[
M_x=\sum_k N_k(y_k-y_0),\qquad M_y=-\sum_k N_k(x_k-x_0)
\\]

を求めます。上下端平均軸力を用いた軸仕事を \\(W_a=\sum_k \bar N_k\Delta u_{z,k}\\) とすると、

\\[
\bar M_i=(M_{b,i}+M_{t,i})/2,\quad
\Delta\theta_i=W_{a,i}/\bar M_i,\quad
EI_i=h_i\bar M_i/\Delta\theta_i
\\]

です。\\(h_i\\) は上下階の構造基準レベル間の高さ [mm]、軸力は [N]、曲げモーメントは [N·mm]、曲げ剛性は [N·mm²] です。
軸仕事・有効曲げモーメントが不足する層、非有限値や正の曲げ剛性を得られない層は、階と原因を表示して停止します。
柱以外の変形を曲げ剛性に加算せず、算定不能な層を剛とみなしません。

### 全変位からせん断骨格を得る

層せん断力から頂部をゼロとして下層へ曲げモーメントを復元します。

\\[
M_{t,i}=M_{b,i+1},\qquad M_{b,i}=M_{t,i}+Q_i h_i
\\]

各層のモーメントは線形分布とし、基部回転ゼロから積分します。

\\[
\Delta\theta_i=\frac{h_i(M_{b,i}+M_{t,i})}{2EI_i},\qquad
\delta_{b,i}=h_i\theta_{b,i}+\frac{h_i^2(2M_{b,i}+M_{t,i})}{6EI_i}
\\]

上端回転は \\(\theta_{t,i}=\theta_{b,i}+\Delta\theta_i\\) とし、次層の下端回転へ引き継ぎます。
線形では全層間変位から \\(\delta_s=\delta-\delta_b\\) を求め、\\(K_s=Q/\delta_s\\) とします。
非線形では、各確定ステップの層せん断力と全層間変位から水平力ゼロ時点の値を引き、各ステップの層せん断力で曲げ変位を再計算して差し引きます。
3 次元では各確定ステップと水平力ゼロの初期載荷点の水平変位・ねじれ回転を同じ剛心位置へ変換してから差を取り、剛床の代表節点位置に依存しないせん断骨格を求めます。
増分解析と初期剛性用の EX/EY の水平力分布をそろえます。
得られたせん断骨格を固定初期剛性の等面積トリリニアへ縮約し、最大点指向型履歴を使います。
標準の自動同定では独立した2折点を必要とし、弾性や折点の縮退から仮の降伏点を生成しません。明示指定された層ばねの同一変位の折点の力は相対64ε（εは倍精度の機械精度）以内の一致を要求し、異なる力を持つ同一変位や負勾配・非有限接線を拒否します。折点値の正値補正・移動は行いません。
正のせん断剛性・有効なせん断骨格が得られない場合は、絶対値化や微小正値による補正を行わず停止します。

### 要素と自由度

各層は Euler–Bernoulli 弾性曲げとせん断ばねの直列要素です。
局所自由度を \\([u_b,\theta_b,u_t,\theta_t]\\)、\\(\phi=12EI/(K_s h^3)\\) とすると、線形剛性は

\\[
K_e=\frac{EI}{h^3(1+\phi)}
\begin{bmatrix}
12&6h&-12&6h\\
6h&(4+\phi)h^2&-6h&(2-\phi)h^2\\
-12&-6h&12&-6h\\
6h&(2-\phi)h^2&-6h&(4+\phi)h^2
\end{bmatrix}
\\]

です。基部固定 1 層に頂部水平力 \\(Q\\) を与えると、

\\[
\delta=Q\left(\frac{1}{K_s}+\frac{h^3}{3EI}\right),\qquad
\theta=\frac{Qh^2}{2EI}
\\]

となり、\\(EI\to\infty\\) でせん断型へ収束します。
非線形でも内部の直列接続点で同じせん断力を満たすよう釣合いを解き、同じせん断ばね変形に対して内力・接線・履歴を確定します。

2 次元の各階は水平変位と曲げ回転の 2 自由度、3 次元は水平 2 成分・Z 軸ねじれ・X/Y 軸曲げ回転の 5 自由度です。
X 方向の曲げ回転は \\(\theta_y\\)、Y 方向は \\(-\theta_x\\) として連続性を満たします。
3 次元の剛心とねじりばねの扱いはせん断型と同じです。

### 物理質量と結果の読み方

並進質量と同じ階の物理質量分布を用い、重心まわりの慣性を求めます。
壁版の物理質量は実領域を積分し、重心への移送も含めます。

\\[
J_x=\sum m(y-y_G)^2,\quad J_y=\sum m(x-x_G)^2,\quad
P_{xy}=\sum m(x-x_G)(y-y_G),\quad J_z=J_x+J_y
\\]

2 次元は \\(\operatorname{diag}(m,J_y)\\)（X 方向）、\\(\operatorname{diag}(m,J_x)\\)（Y 方向）です。
3 次元の回転慣性の X/Y 部分は \\(\begin{bmatrix}J_x&-P_{xy}\\-P_{xy}&J_y\end{bmatrix}\\) とし、積慣性も考慮します。
必要な質量・慣性が正でない場合や質量行列が正定値でない場合は、該当階と値を提示して停止します。
固有値解析は追加回転と慣性を含む一般化固有値問題を解きます。
時刻歴は Newmark 平均加速度法と初期剛性比例減衰を用い、地動は並進自由度に作用します。

結果の層間変位は**全層間変位**、層せん断力は**せん断ばね力**、塑性率は**せん断ばね変形**に基づきます。
結果画面にモデル種別と層別曲げ剛性を表示し、算定モデル・曲げ回転・固有値・時刻歴を保存します。
時刻歴のケース識別にはモデル種別も含むため、せん断型と同じ波形を解析しても別の結果として所属します。
