# 線形静解析

変位法（有限要素法）により、部材内力と変位を求めます。
右バーの線形静解析で荷重ケース又は荷重組合せを選び、単体実行又は一括解析を実行します。
先に準備計算で部材・材料・断面・支点・拘束・荷重を整えます。固有値解析や増分解析の結果は不要です。

## 採用モデルと求解

支点と剛床などの拘束を満たす独立変位を求め、それを全節点の変位へ復元して部材内力を計算します。
以下は微小変形・線形弾性のもとで、支点の指定変位がゼロであり、節点間の拘束が線形・同次の場合を扱います。
長期軸力無効化や引張専用の指定による剛性の扱いは、[長期軸力無効化と引張専用](#長期軸力無効化と引張専用)に従います。

**記号・単位**

| 記号 | 意味・大きさ | 単位 |
|------|------|------|
| \\( n,\\ m \\) | 拘束前の全解析自由度数、拘束後の独立自由度数（\\( m \le n \\)） | - |
| \\( u\_{\text{full}},\\ F\_{\text{full}} \\) | 全解析自由度の変位・荷重ベクトル（各 \\( n \\) 成分） | 変位は並進 mm・回転 rad、対応する荷重は力 N・モーメント N·mm |
| \\( u\_{\text{red}},\\ F\_{\text{red}} \\) | 独立自由度の変位・荷重ベクトル（各 \\( m \\) 成分） | 独立変位は mm・rad、それに仕事の意味で対応する一般化力は N・N·mm |
| \\( K\_{\text{full}},\\ K\_{\text{red}} \\) | 拘束前・縮約後の剛性行列（順に \\( n\times n,\\ m\times m \\)） | 行の一般化力／列の一般化変位 |
| \\( T \\) | 独立変位を全解析自由度へ復元する拘束変換行列（\\( n\times m \\)） | 行の変位／列の独立変位 |
| \\( u \\) | 荷重組合せで用いる復元後の節点変位 | 並進 mm・回転 rad |
| \\( N \\) | 軸力（引張正） | N |
| \\( Q\_y,\\ Q\_z \\) | せん断力 | N |
| \\( M\_x \\) | ねじりモーメント | N·mm |
| \\( M\_y,\\ M\_z \\) | 曲げモーメント | N·mm |
| \\( S,\\ S\_i \\) | 部材断面力ベクトル（荷重組合せ・荷重ケース単体） | N, N·mm |
| \\( F,\\ F\_i \\) | 荷重ベクトル（荷重組合せ・荷重ケース単体） | 並進 N・回転 N·mm |
| \\( c\_i \\) | 荷重組合せの組合せ係数 | - |

ここで「全解析自由度」は支点で変位を固定した成分と従属成分を含み、解析対象外の節点は含めません。
通常の節点の並進・回転各3成分に加え、仕口パネルをモデル化した場合はせん断変形角の追加自由度（rad）も含むため、\\( n \\) は必ずしも節点数の6倍ではありません。
節点変位の表示は復元後の並進・回転各3成分です。

**拘束の縮約・求解・復元**

独立自由度は拘束を満たす変位を表すために残した成分であり、従属成分を別の未知量として解く必要はありません。
支点の変位ゼロと剛床などの従属関係をまとめて、変位を次のように表します。

\\[ u\_{\text{full}} = T u\_{\text{red}} \\]

支点の固定成分に対応する \\( T \\) の行はゼロです。独立成分の行は対応する独立変位をそのまま取り出し、従属成分の行は拘束関係に従って独立変位を組み合わせます。
荷重には節点荷重と部材中間荷重からの等価節点荷重を含め、剛性と同じ拘束変換で独立自由度へ縮約します。

\\[ F\_{\text{red}} = T^\mathsf{T} F\_{\text{full}}, \qquad
K\_{\text{red}} = T^\mathsf{T} K\_{\text{full}} T \\]

この転置による荷重変換は仮想仕事から導けます。拘束を満たす任意の仮想変位を \\( \delta u\_{\text{full}}=T\delta u\_{\text{red}} \\) とすると、外力の仕事は

\\[ \delta u\_{\text{full}}^\mathsf{T} F\_{\text{full}}
= \delta u\_{\text{red}}^\mathsf{T} T^\mathsf{T} F\_{\text{full}}
= \delta u\_{\text{red}}^\mathsf{T} F\_{\text{red}} \\]

です。理想的な支点・節点間拘束の反力はこの仮想変位に対して仕事をしないため、内力と外力の仮想仕事の釣合いは

\\[ \delta u\_{\text{red}}^\mathsf{T}
\left(T^\mathsf{T} K\_{\text{full}} T u\_{\text{red}} - T^\mathsf{T} F\_{\text{full}}\right)=0 \\]

となります。任意の独立仮想変位について成立することから、解くべき連立一次方程式は次になります。

\\[ K\_{\text{red}} u\_{\text{red}} = F\_{\text{red}} \\]

縮約した剛性と荷重を作り、この方程式を解いて独立変位を求め、\\( u\_{\text{full}}=T u\_{\text{red}} \\) により従属変位と支点のゼロ変位を復元します。
逆行列を明示的に作るのではなく、[線形代数ソルバ](01_線形代数ソルバ.md#採用解法)の疎 Cholesky 分解と前進・後退代入で求解します。
全解析自由度上の釣合いには拘束反力も含まれるので、一般に \\( K\_{\text{full}}u\_{\text{full}}=F\_{\text{full}} \\) をそのまま解くこととは異なります。

復元した変位から、各部材の座標・材端条件に対応する変形と剛性応答を求めます。
実内力は、この剛性応答と部材中間荷重による両端固定梁のスパン内力の重ね合わせとします。
独立変位だけを節点変位として読んだり、部材中間荷重を等価節点荷重に置き換えた応答だけで部材内力としたりはできません。

線材（柱・梁・ブレース）は、剛床への所属や非線形部材モデルの指定に依らず、すべて
弾性要素（弾性ティモシェンコ梁・弾性トラス）で組みます（[モデルの自動選択](../../nonlinear/04_非線形梁要素のモデル化.md#モデルの自動選択)）。したがって線材の
部材内力は全部材について出力され、応力図・断面検定の対象になります。材端集中ばね・
ファイバーといった弾塑性の梁要素は非線形解析でのみ用います。

剛性行列は並進力／並進変位で N/mm、並進力／回転で N/rad、モーメント／並進変位で N、モーメント／回転で N·mm/rad の成分を持ちます。
拘束変換の成分 \\( T_{ij} \\) の単位は \\( [u_{\text{full},i}]/[u_{\text{red},j}] \\) です。
同種の変位間の係数は無次元、回転から並進を求める腕長の係数は mm/rad（radを無次元として扱うと mm）です。
したがって変換行列全体に単一の単位を与えるのではなく、縮約後も各一般化力と対応する変位の積が仕事（N·mm）になるように読みます。

**解析前の入力チェック**

解析の実行前に、モデルの静的な検証を行います。
次の不備は、何をすれば直るかを含むエラーとして扱い、解析を停止します。
断面や材料が未割当の要素を既定値で補って解析することはありません。

- 節点・部材の ID と配列添字の不一致、存在しない断面・材料への参照など、モデル検証で見つかる不整合
- 節点・部材・支点（拘束）が 1 つもない
- 断面・材料が必要な要素（梁・柱・ブレース・ファイバー・マルチスプリング・シェル・壁）の断面が未割当、または材料が未割当
- シェル要素の断面に板厚がない（線材用断面を割り当てた場合など）
- 線材（梁・柱・ファイバー・マルチスプリング）の断面のいずれかの方向でせん断有効断面積 As が 0 以下。As は正の有限値を必要とし、0 をせん断剛直の指定値には使えません（[せん断有効断面積 As](../03_断面性能/03_せん断有効断面積_As.md#as--0-は入力エラー)）
- 耐震壁と周辺架構の構造種別の食い違い
- 断面が未割当の床、断面の材料または板厚が定まらない床（[床の断面と自重](../01_荷重/08_床の断面と自重.md)）
- 存在しない節点への参照（ダングリング）、およびどの部材・拘束・床にも属さない孤立節点
- 基部以外の階で、剛床マスター節点が水平方向（Ux または Uy）に拘束され、かつその階の地震用重量が正のとき

仕口パネル要素・節点バネ・免震支承材・制振ダンパーは、断面や材料ではなく専用の特性値から剛性を作るため、断面と材料の未割当チェックの対象外です（[仕口パネル](../../preparation/06_仕口パネル.md)）。

基部の床では、柱脚が固定またはピンで水平拘束されているとき、剛床マスターも水平拘束になります。
これは剛床が動けるかどうかの判定結果であり、地震用重量があってもエラーにはしません。
上階で同じ状態になるのは、床面に柱や大梁が取り付いておらず、非構造節点だけが剛床のスレーブになっているときです。
その階の地震力はマスターへ載るため、水平拘束された自由度へ入ると解析結果に現れません。
地震用重量が 0 の階は、消える水平力も 0 であるため、この検査の対象外です。

この一覧は、下ドックの「診断」タブがエラーとして挙げる項目と同じで、どちらも同じ判定を呼んでいます。
判定は解析を止めない警告も返し、剛床のない階や、断面未割当の壁版などがその例です。
入力チェックはエラーだけを見て停止するため、警告では解析は止まりません。
入力チェックは最初の 1 件で解析を止めるため、不備が複数あるモデルでは、修正と再実行を繰り返すことになります。
解析の前にまとめて洗い出したい場合は、準備計算の[モデル整合性チェック](../../preparation/README.md#モデル整合性チェック)を確認してください。
こちらは不備をすべて挙げ、部材や節点ごとに 3D ビューで位置を示すため、修正の順序を立ててから解析へ進めます。

**部材内力の符号規約**

評価断面の内力 \\( [N, Q\_y, Q\_z, M\_x, M\_y, M\_z] \\) は、部材全長で連続な断面力
（切断法による断面の力の釣合いから定まる値）として出力します:

- 軸力 \\( N \\) は引張を正とする。
- せん断力とモーメントは \\( Q\_y = dM\_z/dx \\)・\\( Q\_z = -dM\_y/dx \\) を満たす。
- 曲げモーメント \\( M\_z \\) は局所 \\( -y \\) 側（重力方向の下向き荷重を受ける
  水平梁では下端）の引張を正とする。両端固定梁の等分布荷重では端部
  \\( -wL^2/12 \\)・中央 \\( +wL^2/24 \\) となる。
- 応力図は正のモーメントを引張側（局所 \\( -y \\) 方向）へ張り出して描画する。
  張り出しの実線と材軸の間の領域を塗りつぶす。塗りは単色のほか、値に応じた
  色分け（コンター表示。カラーバー凡例付き）へ切り替えられる。コンターの
  カラーマップは Viridis（既定。知覚均等で色覚多様性に配慮）・Plasma・
  Turbo・Jet・青-白-赤（発散型）から選択できる。

## 長期軸力無効化と引張専用

単発・一括・背景実行のいずれも、荷重ケースの種類と応力解析条件から同じ剛性を採用し、その剛性で部材内力を回復します。
長期軸力無効化を指定した場合、対象部材の軸剛性に係数 β = 1e-6 を乗じます。指定しない場合は β = 1 です。
長期ケースは固定・積載・雪・その他（Dead / Live / Snow / Other）です。
地震用積載・風・地震（LiveSeismic / Wind / Seismic）は長期低減の対象外です。Ai 地震力も地震ケースとして扱います。
柱の対象は柱用途の梁・ファイバー・マルチスプリング要素です。部材の傾きでは追加判定しません。ブレースの指定は柱とは独立です。

低減するのは軸剛性であり、回復軸力が必ず1e-6倍になるわけではありません。代替の荷重伝達経路がない場合は対象部材が荷重を負担し続けるため、軸力と変形を確認してください。
SRC・CFT柱では合成軸剛性を求めてから低減します。断面形状、質量、曲げ・せん断・ねじり剛性、剛域、壁側柱の解放、仕口パネルのオフセット、支持ばねは保持します。
完全にゼロにせず微小値を残すのは、浮き自由度による特異行列を避けるためです。

引張専用ブレースで反復解析を指定した場合、軸伸びが負の部材には追加の残留係数 s = 1e-6、軸伸びが0以上の部材には s = 1 を採用します。
軸剛性の係数は βs です。両設定を併用した長期圧縮側では1e-12となり、微小な圧縮軸力が残ります。
有効部材の集合が変わらなくなった場合だけ収束とします。反復上限50回で集合が一致しなければ、荷重ケース名・ID・上限を示す未収束エラーとなり、正常な解析結果として保存しません。
ほかの荷重ケースの成功応答は、そのケース自体が失敗しない限り使用できます。固有値・精算周期の基準剛性にはこれらの静的設定を適用しません。

## 荷重組合せの応答（重ね合わせ）

求解の最小単位は**荷重ケース単体**です。荷重組合せの応答は、荷重ケース単体の応答を
組合せ係数で倍して足し合わせて求めます。長期低減や引張専用反復も、各ケースで採用した応答を足し合わせます。
引張専用を含む係数和は合成荷重の active-set 解ではなく、別ケース合成の断面検定は理由付き未検定です。合成荷重による再解析は行いません。

**算定式**

荷重組合せが荷重ケース \\( L\_1, L\_2, \dots \\) を係数 \\( c\_1, c\_2, \dots \\) で参照する場合、
節点変位 \\( u \\) と部材断面力 \\( S \\)（評価断面ごとの \\( [N, Q\_y, Q\_z, M\_x, M\_y, M\_z] \\)）は

\\[ u = \sum\_i c\_i \\, u\_i, \qquad S = \sum\_i c\_i \\, S\_i \\]

とします。ここで \\( u\_i, S\_i \\) は荷重ケース \\( L\_i \\) 単体の応答です。

全ケースで同じ剛性・回復条件を採用する場合、この係数和は荷重ベクトル
\\( F = \sum\_i c\_i F\_i \\) を組み立てて同じ条件で 1 回解いた結果と理論上一致します。
長期低減を採用するケースと通常剛性の短期ケースが混在する場合は、引張専用反復がなくてもこの同値性は成立しません。
その場合も各ケースの応答係数和を維持し、合成荷重による再解析は行いません。部材中間荷重による
スパン内力（両端固定梁の内力。上式の \\( S\_i \\) に含まれます）も同じ係数で倍されるため、
等分布荷重を受ける梁の M の放物線分布は組合せでも保たれます。

参照する荷重ケースが存在しない、又はそのケースの解析結果が不足・失敗している場合は、その荷重組合せをエラーとして扱います。不足する項をゼロとして合成しません。必要なケースを修正・再実行してください。

この扱いにより、同じ荷重ケース（DL・LL・EX・EY など）を参照する荷重組合せが
何件あっても、求解は荷重ケースの数だけで済みます。GUI の「単体実行」「一括解析」は
いずれもこの経路を使い、単体実行で荷重組合せを選んだ場合は、その組合せが参照する
荷重ケースを解いてから線形和を組み立てます。
