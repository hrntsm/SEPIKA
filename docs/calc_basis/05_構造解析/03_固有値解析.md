# 固有値解析

固有値解析は、剛性・質量・拘束から、外力がなくても振動する周期（固有周期）と変形の比率（モード形状）を求めます。
弾性の微小振動を対象とし、減衰と外力を除いた自由振動を扱います。実際の地震時の応答振幅は、この解析だけでは決まりません。

## 実行条件

準備計算で剛性・拘束・物理質量を整え、右バーの固有値解析で要求モード数を指定して実行します。静解析の成功結果は前提としません。
質量の有効な独立方向が要求数に足りない場合はエラーになります。固有値の反復上限は 200 回、収束許容差は後述の式とし、未収束のモードを成功結果として採用しません。

## 質量モデル

全体質量行列 \\( M \\) の質量源は「部材密度による整合質量（Consistent）」と「節点集中質量（剛床マスターの質点等）」の 2 つで、その組合せはモデルの質量方式に従います:

- **補正質点方式（既定）**: 部材密度による分布質量に加え、剛床マスター節点へ「物理質量相当重量のうち分布質量として計上されない分」（床・仕上げ・積載・二次部材・雑壁など）を補正質点として与えます。階の生成がマスター質量を \\( m = (W\_{\text{mass}} - W\_{\text{frame}})/g \\)（水平 2 方向）、回転慣性を \\( J = \sum m\_i r\_i^2 \\)（\\( r\_i \\) は慣性力重心からの平面距離）で算定します。部材の分布質量による鉛直・局部の振動モードも保たれます。
- **質点のみ方式**: 質量は節点集中質量のみを用い、部材密度による分布質量は算入しません（水平質点系モデル化）。剛床マスターには物理質量相当重量の全量 \\( W\_{\text{mass}}/g \\) と回転慣性を与えるため、鉛直方向・局部の振動モードは表現されません。

質点のみ方式でも、立体骨組の固有値解析は部材剛性を使います。局所軸を構成できない部材は、質量が節点集中のみでも対象部材と理由を示して解析を停止します。

両方式の公称並進総動的質量は \\( \sum W\_{\text{mass},i}/g \\) で一致します。動的質量は物理質量（鋼材は物理質量密度 7.85 t/m³）に基づき、地震用重量 \\( W \\)（設計重量。鋼材は 78.5 kN/m³）とは一致しません。

質量方式は固有値解析と時刻歴応答解析で共通です。地震力の精算周期への採用は未対応です。

質点系（串団子）の層質量は、この質量行列とは別に、階生成が物理質量相当重量の全量から
算定した値を用います（[質点系解析](./10_質点系解析.md)の「質量」）。

## 自由振動から固有周期へ

以下の \\( K, M, u \\) は、支点・剛床等の拘束を反映した同じ独立自由度空間の量です。

| 記号 | 意味 | 単位・条件 |
| --- | --- | --- |
| \\( u(t) \\) | 時刻 \\( t \\) の変位ベクトル | 並進 mm、回転 rad |
| \\( K, M \\) | 剛性行列、質量行列 | 下表の一般化剛性・質量 |
| \\( t, \delta \\) | 時刻、位相 | s、rad |
| \\( \omega_i, \lambda_i \\) | 第 \\( i \\) モードの固有円振動数、固有値 | rad/s、s⁻²（\\( \lambda_i=\omega_i^2 \\)、rad は無次元） |
| \\( T_i \\) | 第 \\( i \\) モードの固有周期 | s |
| \\( \varphi_i \\) | 第 \\( i \\) モードの固有ベクトル | 正規化の規約は後述 |
| \\( A_i \\) | モード振幅の係数 | モードの尺度に依存 |

慣性力と弾性復元力が釣り合う自由振動の運動方程式は、次のとおりです。ドットは時間微分を表します。

\\[ M\ddot{u}(t)+Ku(t)=0 \\]

各自由度が同じ円振動数で振動する調和振動を仮定します。

\\[ u(t)=A_i\varphi_i\sin(\omega_i t+\delta) \\]

\\[ \ddot{u}(t)=-\omega_i^2 A_i\varphi_i\sin(\omega_i t+\delta) \\]

代入すると、振動の全時刻で釣合いを満たす非零のモード形状は、次の一般化固有値問題を満たします。

\\[ (K-\omega_i^2 M)\varphi_i=0, \qquad K\varphi_i=\lambda_i M\varphi_i \\]

正の固有値から円振動数と周期を求めます。小さい固有値ほど周期は長くなります。

\\[ \omega_i=\sqrt{\lambda_i}, \qquad T_i=\frac{2\pi}{\omega_i} \\]

モード形状は、各節点の並進・回転がどの比率で動くかを示します。同じ固有値に対して非零の定数倍も解になるため、倍率は後述の質量正規化で定めます。

### 並進・回転・連成成分の単位

剛性は一般化力を変位で、質量は一般化慣性力を加速度で割った単位を持ちます。
rad を無次元として扱う N・mm・s 系では、\\( 1\\,\mathrm{t}=1\\,\mathrm{N\\,s^2/mm} \\) です。

| 行の一般化力／列の変位 | \\( K \\) の成分単位 | \\( M \\) の成分単位 |
| --- | --- | --- |
| 並進力／並進変位 | N/mm | t |
| 並進力／回転 | N | t·mm |
| モーメント／並進変位 | N | t·mm |
| モーメント／回転 | N·mm | t·mm² |

連成項がある場合も、\\( M\ddot{u} \\) と \\( Ku \\) の各行は並進力 N 又はモーメント N·mm になります。
行列全体が一律に N/mm・t という意味ではありません。拘束変換の腕長と剛性の単位は、[線形静解析の記号・単位](./02_線形静解析.md#採用モデルと求解)も参照してください。

### 1質点の例

並進1自由度の質量 \\( m=1\\,\mathrm{t} \\)、ばね剛性 \\( k=100\\,\mathrm{N/mm} \\) とします。

\\[ m\ddot{u}+ku=0, \qquad \lambda=\frac{k}{m}=100\\,\mathrm{s^{-2}} \\]

\\[ \omega=10\\,\mathrm{rad/s}, \qquad T=\frac{2\pi}{10}\simeq0.628\\,\mathrm{s} \\]

剛性を保って質量を4倍にすると周期は2倍、質量を保って剛性を4倍にすると周期は半分になります。
これは \\( T=2\pi\sqrt{m/k} \\) によるもので、表示するモードの倍率には依存しません。

## 数値解法

部分空間反復法で低次側の固有値・モードを求め、射影した小さい一般化固有値問題を一般化 Jacobi 法で解きます。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( p\_{\text{req}} \\) | 要求モード数 | - |
| \\( n \\) | 縮約後自由度数 | - |
| \\( p \\) | 解析対象のモード数 \\( p = \min(p\_{\text{req}}, n) \\) | - |
| \\( q \\) | 部分空間サイズ | - |
| \\( y,\\ x \\) | 部分空間反復の予測・更新ベクトルの組 | 列ごとの尺度に依存 |
| \\( \bar{K},\\ \bar{M} \\) | 部分空間へ射影した剛性・質量行列 | 基底ベクトルの尺度に依存 |
| \\( V \\) | 射影固有値問題の固有ベクトル | 基底ベクトルの尺度に依存 |
| \\( \Theta \\) | 射影固有値問題の固有値 | rad²/s² |
| \\( S \\) | 対称スケーリング行列 | 射影剛性の対角成分の平方根の逆数 |
| \\( \omega \\) | 固有円振動数 | rad/s |
| \\( \text{period} \\) | 固有周期 | s |
| \\( \varphi \\) | 固有ベクトル（モード形状） | 並進成分 t⁻¹ᐟ²、回転成分 mm⁻¹·t⁻¹ᐟ² |
| \\( \beta \\) | 刺激係数（参加係数） | t¹ᐟ² |
| \\( M\_{\text{eff}} \\) | 有効質量 | t |
| \\( r \\) | 地動方向の影響ベクトル | - |
| \\( W\_{\text{mass}},\\ W\_{\text{frame}} \\) | 階の物理質量相当重量・分布質量として計上する部材重量 | N |
| \\( m,\\ g \\) | 補正質点の質量・重力加速度 | t, mm/s² |
| \\( J,\\ r\_i \\) | 階の回転慣性・慣性力重心からの平面距離 | t·mm², mm |

**算定式**

要求モード数 \\( p\_{\text{req}} \\) は縮約後自由度数 \\( n \\) で切り詰め、解析対象のモード数 \\( p \\) とします:

\\[ p = \min(p\_{\text{req}}, n) \\]

部分空間サイズ \\( q \\) は次で算定します:

\\[ q = \min(n, \max(2p, p+8)) \\]

上式は \\( p\_{\text{req}} \geq 1 \\) に適用します。要求モード数 \\( p\_{\text{req}} = 0 \\) のときは上式によらず \\( q = 0 \\) とし、部分空間を構成しません（固有値解析は行わず、空の結果を返します）。

この式は[採用解法の出典](#採用解法の出典と確認範囲)の式(19)と同じ \\( \max(p+8, 2p) \\) に、SEPIKA の条件として自由度数 \\( n \\) の上限と、要求数0の扱いを加えたものです。
原典の \\( \max \\) は反復の計算量とベクトル数の検討から提案され、Sturm 列チェックを省くための代替式ではありません。

要求モード数 \\( p\_{\text{req}} \\) が縮約後自由度数 \\( n \\) を超える場合は、自由度数まで切り詰めて \\( p = n \\) として実行します（返るモード数は要求モード数を超えません）。一方、質量を持つ方向の数（質量ランク）が解析対象のモード数 \\( p \\) に満たない場合は、要求モード数を切り詰めるのではなくエラーとして通知します（質量が有効な独立自由度が不足しているため）。

反復は次の予測から射影を作り、射影一般化固有値問題を解いて更新します:

\\[ K y = M x \\]

\\[ \bar{K} = y^\mathsf{T} K y, \bar{M} = y^\mathsf{T} M y \\]

\\[ x\_{\text{new}} = y \cdot V \\]

射影一般化固有値問題 \\( \bar{K} V = \bar{M} V \Theta \\) は、一般化 Jacobi 法（Bathe）により \\( \bar{K} \\)・\\( \bar{M} \\) を同時対角化して解きます。半正定値の \\( \bar{M} \\)（部分空間サイズが質量ランクを超える場合に必ず生じる）でも正則な合同変換のみで進むため、質量を持たない方向が混在しても数値的に安定します。求解に先立ち、両行列を \\( \bar{K} \\) の対角で対称スケーリング（\\( S = \operatorname{diag}(1/\sqrt{\bar{K}\_{ii}}) \\)、合同変換のため固有値は不変）することで、並進質量と回転慣性のように単位スケールが大きく異なる質量が混在しても、質量の有無の判定が単位系に依存しません。質量を持たない方向（対角化後の質量対角成分が相対許容誤差未満の方向）には固有振動数が存在しないため解の対象から除外し、質量を持つ方向の数（質量ランク）が解析対象のモード数 \\( p \\) に満たない場合はエラーとして通知します。

収束は \\( |\theta - \theta\_{\text{prev}}| < 10^{-10} \cdot \max(\theta, 1) \\) で判定します。数値結果の周期は、上記の \\( T_i \\) と同じく次式によります。

\\[ \text{period} = 2\pi/\sqrt{\omega^2} \\]

## 正規化と参加係数・有効質量

固有ベクトルは、質量による二次形式が1になるように M 正規化（質量正規化）します。

\\[ \varphi^\mathsf{T} M \varphi = 1 \\]

この正規化では、質量を t、長さを mm とする数値規約を使います。並進モード成分は t⁻¹ᐟ²、回転モード成分は mm⁻¹·t⁻¹ᐟ²、刺激係数は t¹ᐟ² です。モードの倍率を変更すると刺激係数はその逆数倍となり、刺激係数とモード形状の積および有効質量は変わりません。

調和振動式の \\( A_i \\) は、この質量正規化では mm·t¹ᐟ² の尺度を持ちます。実応答を得るには初期条件や外力に対するモード座標の応答が必要です。
画面で形状を見やすくする表示倍率や、固有ベクトルの符号を、地震時の変位振幅として読むことはできません。

固有ベクトル \\( \varphi \\) は拘束縮約後の独立自由度空間で求まるため、モード形状の表示・出力にあたっては縮約を逆変換して全節点の 6 成分へ展開します。剛床などの従属自由度には、マスター自由度の剛体変位関係（面内並進＋回転）に従った値が入ります。

参加係数および有効質量は、各モードについて全体 X・Y・Z の並進加振方向ごとに求めます。
\\( r \\) は対象方向の並進成分を1、他の並進・回転成分を0とする影響ベクトルです。
以下の内積では、拘束を逆変換したモード形状と、同じ自由度空間の質量行列・影響ベクトルを用います。
参加係数は一様な地動がそのモードをどれだけ励起するかを、有効質量はその方向の応答に寄与する質量を表します。

\\[ \beta = \frac{\varphi^\mathsf{T} M r}{\varphi^\mathsf{T} M \varphi} \\]

\\[ M\_{\text{eff}} = \frac{(\varphi^\mathsf{T} M r)^2}{\varphi^\mathsf{T} M \varphi} \\]

\\( \varphi^{\prime}=c\varphi \\)（\\( c\ne0 \\)）と置くと、\\( \beta^{\prime}=\beta/c \\) なので、\\( \beta^{\prime}\varphi^{\prime}=\beta\varphi \\) です。有効質量も変わりません。
1質点の例では \\( \varphi=1/\sqrt{m} \\)、\\( r=1 \\) より \\( \beta=\sqrt{m} \\)、\\( M\_{\text{eff}}=m=1\\,\mathrm{t} \\) となり、唯一のモードが全質量を担います。
多自由度では複数モードへ分かれるため、個々の有効質量を総質量や実応答変位と同一視しないでください。

固有周期は採用した剛性・質量・拘束に対する弾性振動特性です。モード形状の符号や倍率は物理的な振幅ではありません。有効質量を方向別に確認してください。Sturm 列チェックを行わないため、指定した低次モードが欠落なく得られたことを保証しません。

## 採用解法の出典と確認範囲

Klaus-Jürgen Bathe, *The subspace iteration method – Revisited*, **Computers & Structures**, 126 (2013), pp.177–183, [DOI: 10.1016/j.compstruc.2012.06.002](https://doi.org/10.1016/j.compstruc.2012.06.002) を部分空間反復の出典とします。
本文を確認できる一次公開先は[著者のMIT公開PDF](https://web.mit.edu/kjb/www/Principal_Publications/The_subspace_iteration_method_Revisited.pdf)です。このPDFは2012年の in-press 版であり、最終刊行版の巻頁とは区別します。

公開PDFの p.2、§2.1、式(1)〜(9)で一般化固有値問題・質量正規化・射影反復を、p.3、§2.2、式(19)で部分空間サイズを確認しています。
p.2、§2.1では、収束後に Sturm 列チェックで低次 \\( p \\) 組の欠落を確認し、不通過時には反復ベクトルを増やす方針が述べられています。
SEPIKA はこのチェックと、不通過を受けた部分空間の拡大を行いません。収束したことや上記のサイズ式だけで、低次モードが欠落なく得られた保証にはなりません。

公開PDFと最終刊行版の本文同一性、一般化 Jacobi 法・対角スケーリング・質量ランク判定の細部、SEPIKA の収束判定と原典式(10)の同等性は照合していません。原典のアルゴリズム全体への適合を保証するものではありません。

## 地震荷重（Ai 分布）との連携

地震力の「精算（固有値解析）」による周期採用は未対応です。固有値結果があっても、精算の適用条件・証拠とRt下限を確認する採用経路がないため地震力生成を停止します。既定の略算は告示の式 \\(T=h(0.02+0.01\alpha)\\) を用います。質点系の初期剛性は同じ略算Ai水平力分布の弾性静的応答へそろえ、固有周期の厳密一致や未実装の精算採用を条件にしません。
