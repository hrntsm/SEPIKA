# 累積損傷度（鉄骨梁端部）

鉄骨梁端部の累積損傷度を、塑性率の時系列に対するレインフロー法（ASTM E1049-85 3 点法）と Miner 則を用いて算定します。最大振幅だけから損傷度を算定する方式は提供しません。

## 必要な応答と適用限界

非線形時刻歴の完了後、結果タブ「時刻歴」の波形表示で累積損傷度を確認します。計算には各確定時刻の部材塑性率系列が必要です。線形時刻歴や質点系の層応答から梁端の損傷度を推定しません。
GUIでは疲労係数を変更する入力欄を提供していません。採用値は **C=20.0、β=0.5 の暫定既定値**です。鋼種・接合形式への適用と規準原典との照合は未確認であり、破断寿命の確定値や設計合否として利用できません。

代表応答グラフに表示するレインフローの繰返し数・最大振れ幅は、選択した節点変位・ベースシア・層間変形角の計数です。部材塑性率に基づく梁端損傷度とは異なります。
部材塑性率を取得できない要素や塑性化していない要素の D=0 は、実接合部の疲労損傷がないことを保証しません。取得した要素単位の系列による参考評価であり、各梁端接合部の局所ひずみ・破断を直接解析するものではありません。

## 採用式と結果の意味

**算定式**

破断寿命および損傷度を次とします:

\\[ N\_f = (\mu/C)^{-1/\beta} \\]

\\[ D = \sum \text{count} \cdot (\mu/C)^{1/\beta} \\]

振幅は振れ幅（peak-to-peak）としてカウントされるため、片振幅としての \\( \mu \\) は振れ幅の 1/2 とします。

Miner則では D=1 が採用した疲労曲線上の寿命到達の目安です。暫定係数の本評価では、D≥1 を実部材の破断確認、D<1 を安全の確認と扱わないでください。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( N\_f \\) | 片振幅 \\( \mu \\) に対する破断寿命（繰返し回数） | 回 |
| \\( D \\) | 累積損傷度（Miner 則） | - |
| \\( \mu \\) | 部材塑性率の片振幅（振れ幅の 1/2） | - |
| \\( C \\) | 疲労強度係数 | - |
| \\( \beta \\) | 疲労指数 | - |
| \\( \text{count} \\) | レインフローで抽出したサイクルの繰返し回数（全サイクル 1.0・半サイクル 0.5） | 回 |
