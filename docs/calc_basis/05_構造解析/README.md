# 構造解析の方法

本章では、線形静解析、荷重組合せの重ね合わせ、固有値解析、減衰、時刻歴応答（Newmark-β）、増分解析（プッシュオーバー解析）、累積損傷度、質点系解析のアルゴリズム根拠を記します。
応力解析・動的解析の手法は、変位法（マトリクス法・有限要素法）と構造動力学の標準的な数値解析法に基づきます。

## 実行条件と結果の確認

準備計算で部材・支持・荷重・階・質量を整え、右バーの解析から対象を選びます。操作の入口は[準備計算](../../preparation/README.md)です。

| 解析 | 必要な入力・先行結果 | 結果を読むときの確認 |
| --- | --- | --- |
| 線形静解析・荷重組合せ | 材料・断面・拘束・荷重ケース・組合せ係数 | ケース別の採用剛性、組合せに必要な全ケースの成功 |
| 立体固有値解析 | 剛性・拘束・物理質量・要求モード数 | 質量方式、得られたモード数、有効質量、欠落モードの可能性 |
| 立体時刻歴 | 波形・方向・時間刻み・減衰・線形／非線形の選択 | 収束、長期荷重の有無、相対／絶対応答、記録間隔 |
| 増分解析 | 非線形モデル・強度・加力方向・終了目標 | 終了理由と確定範囲、設計に採用する評価点 |
| 質点系 | 階質量、モデルと次元に応じた静的・増分結果 | せん断型／曲げせん断型、未収束時のモデル別扱い |

解析完了は、モデルの適用性や設計上の合格を意味しません。各ページの未対応条件と結果の限界を確認してください。
計算時間は自由度数だけでなく拘束・疎行列の非ゼロ配置・反復回数・実行環境にも依存します。
並列度と再現性の確認条件は[並列計算](./09_並列計算.md)に従います。
