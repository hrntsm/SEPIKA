# 時刻歴応答解析

## 実行条件とモデル

右バーの時刻歴応答で線形／非線形、波形、入力方向、時間刻み、減衰を選んで実行します。波形はサンプル波・ライブラリ・CSV読込を利用します。
準備計算で材料・断面・支点・拘束・階・質量を整えてください。減衰を定める初期固有値は実行時に求めるため、立体固有値解析の結果を先に保存する必要はありません。
非線形では復元力・強度入力と、既定で有効な長期荷重の初期釣合いも必要です。
各方式の対応と減衰の既定値は[減衰](./04_減衰.md)、質点系の先行結果・モデル別条件は[質点系解析](./10_質点系解析.md)を参照してください。

支配方程式（基盤一様加振、相対変位形式）を解きます。全体質量行列 \\( M \\) は固有値解析と同一の質量モデル（[固有値解析](./03_固有値解析.md)の質量モデル: 部材の整合質量と剛床マスター等の節点集中質量を、モデルの質量方式に従って組み合わせる）で組み立てます。

\\[ M \cdot \ddot{u} + C \cdot \dot{u} + K \cdot u = -M \cdot r \cdot \ddot{x}\_g(t) \\]

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( M \\) | 全体質量行列 | t |
| \\( C \\) | 減衰マトリクス | N·s/mm |
| \\( K \\) | 全体剛性行列 | N/mm |
| \\( u,\\ \dot{u},\\ \ddot{u} \\) | 相対変位・速度・加速度ベクトル | mm, mm/s, mm/s² |
| \\( \ddot{x}\_g(t) \\) | 地動加速度 | mm/s² |
| \\( r \\) | 地動方向の影響ベクトル | - |
| \\( \beta,\\ \gamma \\) | Newmark-β の積分パラメータ（平均加速度法は \\( 1/4,\\ 1/2 \\)） | - |
| \\( \Delta t \\) | 時間刻み | s |
| \\( \hat{K},\\ K\_{\text{eff}} \\) | Newmark・非線形時刻歴の有効剛性行列 | N/mm |
| \\( K\_t \\) | 接線剛性行列 | N/mm |
| \\( c\_1,\\ c\_2,\\ c\_3,\\ c\_4 \\) | Newmark-β の係数 | 1/s², 1/s, 1/s, - |
| \\( p\_{\text{eff}} \\) | Newmark の有効荷重ベクトル | N |
| \\( a,\\ v \\) | 加速度・速度ベクトル | mm/s², mm/s |
| \\( f\_{\text{int}} \\) | 要素の復元力ベクトル | N |
| \\( p,\\ p\_{\text{dyn}},\\ f\_0 \\) | 外力・動的外力・長期荷重の外力ベクトル | N |

表の力・変位・行列の単位は並進成分です。回転成分は回転角 [rad]、角速度 [rad/s]、角加速度 [rad/s²] と、仕事共役なモーメント [N·mm] を用います。質量行列の回転慣性成分は [t·mm²] であり、連成成分も自由度に応じた単位を持ちます。

## 入力時刻と初期状態

立体の線形・非線形時刻歴と、平面・空間の質点系時刻歴は、入力の各点をその時刻の地動加速度の瞬時値として扱います。
N 点の入力は時刻 0, dt, …, (N−1)dt に対応し、積分は T=N−1 区間です。
時刻 sdt から (s+1)dt への更新には、終点の入力加速度を使います。
記録の先頭は積分前の初期状態で、入力末端後の自由振動区間は自動追加しません。

| 入力 | 点数・積分区間数 | 解析・記録の終時刻と下限 |
| --- | --- | --- |
| サンプル波（正の有限な継続時間 D・刻み dt） | S=ceil(D/dt)、N=S+1、S 区間 | Sdt。0<D<dt でも 1 区間・2 点 |
| 外部波 N≥2 点 | N 点、T=N−1 区間 | Tdt。GUI の CSV 読込は 2 点以上が必要 |
| 空の入力 | 正常な応答として採用しない | エラーまたは空の結果となる |

サンプル波の継続時間と刻みが 0 以下または非有限の場合は、波形生成前に拒否します。
たとえば D=0.05 s、dt=0.02 s では 3 区間・4 点、終時刻 0.06 s です。
刻みは実際に解析へ適用する時間刻みであり、詳細記録の間引きによって終時刻は変わりません。

初期相対加速度は、先頭地動と初期の変位・速度を含む釣合いから求めます。
線形では次式です。静止から始める場合でも、先頭地動が非零なら相対初期加速度は一般に非零です。

\\[ M a\_0 = -M r \ddot{x}\_g(0) - C v\_0 - K u\_0 \\]

非線形では、初期復元力と長期荷重を含めて次式を用います。

\\[ M a\_0 = -M r \ddot{x}\_g(0) + f\_0 - f\_{\text{int},0} - C v\_0 \\]

質量行列が特異な立体モデルでは、任意の初期条件を扱えるわけではありません。
既存の初期加速度求解で解けず、右辺の成分を内部単位系（並進 N・回転 N·mm）で表した数値のユークリッドノルムが 10⁻⁹ 未満の場合は初期加速度をゼロとして扱い、それ以外はエラーになります。
この近零時の扱いは厳密な初期釣合いを保証しません。無質量自由度を含む一般モデルや一般 MPC の初期加速度求解への対応を意味しません。

相対変位・相対速度・相対加速度は地盤に対する応答です。
並進の絶対加速度は、同じ時刻の相対加速度に地動の寄与を加えた \\( a\_{\mathrm{abs}}=a\_{\mathrm{rel}}+r\ddot{x}\_g \\) です。
入力地動、相対加速度、階絶対加速度を同じ量として比較しないでください。

## 線形時刻歴（Newmark-β）

線形の時刻歴応答を Newmark-β 法で解きます。
パラメータは平均加速度法（\\( \beta = 1/4, \gamma = 1/2 \\)、無条件安定）と線形加速度法（\\( \beta = 1/6, \gamma = 1/2 \\)、条件付安定）を取り、**解析は常に平均加速度法で実行します**。
この無条件安定性は線形問題の積分法の性質であり、任意の時間刻みで精度が得られる保証ではありません。波形の高振動数成分や固有周期を表現できる刻みを選び、刻みを細かくした結果との比較で最大応答・位相・収束への影響を確認してください。非線形反復の収束も保証しません。
時間刻み \\( \Delta t \\) は、解析設定で指定した値が正であればそれを、指定がなければ入力波形のサンプリング間隔を使います。

**算定式**

時刻 \\( t\_n=n\Delta t \\) の変位・速度・加速度を \\( u\_n,v\_n,a\_n \\) とし、係数を定めます。

\\[ c\_1=\frac{1}{\beta\Delta t^2},\quad c\_2=\frac{\gamma}{\beta\Delta t},\quad c\_3=\frac{1}{\beta\Delta t},\quad c\_4=\frac{1}{2\beta}-1 \\]

有効剛性:

\\[ \hat{K} = K + c\_2 \cdot C + c\_1 \cdot M \\]

終点の地動外力を \\( p\_{n+1}=-Mr\ddot{x}\_g(t\_{n+1}) \\) として、有効荷重は次式です。

\\[ p\_{\text{eff}}=p\_{n+1}+M\left(\frac{u\_n}{\beta\Delta t^2}+\frac{v\_n}{\beta\Delta t}+\left(\frac{1}{2\beta}-1\right)a\_n\right)+C\left(\frac{\gamma u\_n}{\beta\Delta t}+\left(\frac{\gamma}{\beta}-1\right)v\_n+\Delta t\left(\frac{\gamma}{2\beta}-1\right)a\_n\right) \\]

次を解き、加速度と速度を更新します:

\\[ u\_{n+1} = \hat{K}^{-1} \cdot p\_{\text{eff}} \\]

\\[ a\_{n+1} = c\_1(u\_{n+1} - u\_n) - c\_3 \cdot v\_n - c\_4 \cdot a\_n \\]

\\[ v\_{n+1} = v\_n + \Delta t((1-\gamma)a\_n + \gamma \cdot a\_{n+1}) \\]

初期加速度は [入力時刻と初期状態](#入力時刻と初期状態) の釣合いから求めます。

## 非線形時刻歴（Newmark-β ＋ Newton-Raphson）

全節点が固定され、独立自由度がないモデルでも、長期部材荷重による部材応力を評価します。変位・速度・加速度はゼロですが、初期時点と各確定時点の応力を記録し、荷重の評価に失敗した場合は理由付きで停止します。節点も要素もない空モデルだけは計算せず空の結果を返します。

記録する部材応答は履歴を確定する前に検査します。荷重を含む応答の欠落・自由度数不一致・非有限値、不正な評価位置・断面力を検出した場合は、停止し、不正な応答を正常な結果として扱いません。

非線形の時刻歴応答を、Newmark-β と Newton-Raphson 反復で解きます（構造動力学の標準的な非線形時刻歴解法）。
積分パラメータと時間刻みの決め方は [線形時刻歴（Newmark-β）](05_時刻歴応答解析.md#線形時刻歴newmark-β) と同じで、平均加速度法（\\( \beta = 1/4, \gamma = 1/2 \\)）を使います。

**算定式**

各反復で釣合い用の接線剛性を更新します。既定の初期剛性比例減衰は、長期載荷前の未載荷剛性から定めた減衰行列を固定します。
接線剛性比例を選んだ場合に限り、接線に応じて減衰行列も更新します（[減衰](./04_減衰.md)）。有効剛性を次とします:

\\[ K\_{\text{eff}} = K\_t + c\_2 \cdot C + c\_1 \cdot M \\]

残差を次とします（\\( f\_{\text{int}} \\) は要素の復元力に加え、支点ばね
の内力 \\( k\_i u\_i \\) も含みます）:

\\[ r = p - f\_{\text{int}} - C \cdot v - M \cdot a \\]

収束は \\( \\|r\\| < \text{tol} \cdot r\_{\text{ref}} \\) で判定します。基準ノルム \\( r\_{\text{ref}} \\) は
**動的釣り合いの各項のノルムの最大**とし、解析中の最大値に対する下限を設けます。

\\( p\_{\text{dyn}} \\) は外力 \\( p \\) から長期荷重成分 \\( f\_0 \\) を除いた地震動由来の
動的外力（\\( p = p\_{\text{dyn}} + f\_0 \\)）です。\\( f\_0 \\) を含めないのは、長期荷重が
卓越するモデルで収束判定が過度に緩まないようにするためです。

地動加速度がゼロでも慣性力・減衰力を基準に含めます。さらに応答が小さくなった区間では、解析中の力の最大スケールの 1% を下限にします。

\\[ r\_{\text{ref}} = \max(\\|p\_{\text{dyn}}\\|,\ \\|M \cdot a\\|,\ \\|C \cdot v\\|,\ 0.01 \cdot r\_{\text{ref,max}},\ 1) \\]

この下限は収束判定のための数値条件です。小振幅応答の精度や、その影響を無視できることを保証するものではありません。残差ノルムは並進力 [N] と回転モーメント [N·mm] を内部単位系の数値として集計しており、各成分に独立した誤差上限を与える方式ではありません。

最低値の 1 は、解析を通して一度も動いていないときに 0 除算を避けるための床です。
反復の最大回数と許容誤差 tol は解析タブ「時刻歴応答」の「Newton反復」欄で指定します
（既定は最大 50 回・tol \\( 10^{-6} \\)）。

次を解いて要素状態を更新します:

\\[ \delta u = K\_{\text{eff}}^{-1} \cdot r \\]

骨組の非線形時刻歴では、反復が上限に達しても全体釣合いが収束しなかったステップは確定せず、
解析を停止します。試行応答が有限値でも続行しません。
その実行の途中応答を正常な完了結果として返しません。
応答または釣合い残差が非有限値となった場合も同じ扱いです。
エラーに示された時刻・ステップ・理由を確認し、時間刻み dt、減衰、復元力特性などの条件を見直して再実行してください。
時間刻みの自動細分は行いません。

質点系の未収束時の扱いは[質点系解析の収束と記録](./10_質点系解析.md#時刻歴の収束と記録)に従い、モデルによって異なります。

コンクリート除荷則と材端集中ばねのM–θ履歴は、[履歴則の設定（増分用・時刻歴用）](../../nonlinear/02_部材履歴則.md#履歴則の設定増分用時刻歴用)の指定優先順位・時刻歴の自動既定に従います。材料除荷則と部材ばねの履歴は別の設定対象です。

壁柱ファイバーにも時刻歴の自動既定として Karsan–Jirsa 型が定義されていますが、現行のRC側柱付き壁の非線形時刻歴は未対応です。壁法線まわりの非線形回転解放と従属回転の慣性との連成が未定式化のため、解析を開始できません（[壁の解析適用範囲](../../nonlinear/06_壁の非線形モデル.md#側柱の非線形接続と適用範囲)）。

位相差入力（ねじれ加振）に対応します。**非線形時刻歴では幾何剛性を考慮しません**。軸力に伴う P–Δ 効果を含む応答や安定限界の評価には、この結果だけを用いないでください。

**入力方向と位相差入力**

X・Y に加え、同一波形を両方向へ同時入力する X+Y を選べます。
X+Y は同一波形をそのまま両方向へ入れる簡易仕様で、位相差や方向別の波形指定には対応しません。

位相差入力では、位相遅れ時間 \\( t = (L \cdot \sin\theta)/V\_s \\) を求め、位相遅れ方向の並進波を基準波としてねじれ地動加速度を生成します。
\\( L \\) は矩形基礎長さ [m]、\\( V\_s \\) はせん断波速度 [m/s]、\\( \theta \\) は入射角 [°] です（既定は \\( L = 20 \\)、\\( V\_s = 200 \\)、\\( \theta = 30 \\)）。

Y を位相遅れ方向に選ぶ場合は Y 方向の加速度が必要です。Y 方向の加速度がない入力は理由を表示して解析を開始できません。

**長期荷重の初期化**

RC耐震壁の初期せん断耐力は、開始入力の[静的一次参照](../08_部材終局耐力/08_RC壁の壁脚内力と初期耐力.md)で正負別に確定し、時刻歴中固定します。公称強度を用い、波形ピークや瞬間応答から選びません。参照応答は時刻歴の初期変位・応力・履歴へ移さず、後述の長期載荷と区別します。限定域外や未解決の対象壁がある場合は非線形時刻歴を開始できません。

時刻歴の開始前に、長期系荷重ケース（固定・積載等）の外力を
節点荷重・部材荷重の全量を1回の静的 Newton 求解で載荷し、その変位・応力・材料履歴を時刻歴の初期条件とするオプションです（既定で有効）。
軸力に依存する部材耐力（柱の曲げ降伏 \\( M\_y \\)・せん断降伏 \\( Q\_y \\) の軸力項、ファイバー断面の
N–M 相関）を、長期軸力を含んだ状態で評価するために用います。

長期荷重ベクトル \\( f\_0 \\) は時刻歴を通じて一定の外力として毎ステップ加算し、動的な初期変位・
初期速度（波形読込フォームで指定する 初期変位／初期速度）は「長期解からの増分」として
扱います。したがって、記録される変位・部材内力は長期変位・長期応力を含む全量です。長期系荷重
ケースがないモデルでは何も行いません。このオプションは非線形時刻歴のみに適用され、線形時刻歴
（[線形時刻歴（Newmark-β）](05_時刻歴応答解析.md#線形時刻歴newmark-β)）には適用されません（地震動による応答成分のみを扱います）。
OFF にすると長期系荷重は時刻歴中に一切載荷されず、重力を無視した応答になります。

**長期荷重の初期載荷が収束しない場合**

長期系荷重は荷重係数 1.0 の固定外力として1回の静的 Newton 求解で釣り合わせ、成功した場合だけ状態を確定します。収束失敗・要素更新失敗時は全要素を載荷前の状態へ復元し、理由付きで解析全体を停止します。分割載荷・刻み半減による再試行や、長期荷重を除いた解析への切替えは行いません。地震動応答の起点となる長期状態が定まらないためです。

このエラーが出た場合は、次を確認してください。

- 長期系荷重ケースの荷重値・載荷先（固定・積載等）
- 支点・拘束の設定（剛床・剛リンク・MPC・支点ばね）。剛性がゼロになる自由度がないか
- 弾性の長期静解析（許容応力度計算の長期）は通るのにこの載荷で落ちる場合、非線形要素の接線剛性（材料の履歴則・ファイバー断面の設定）を疑う

## 質点系（串団子）非線形時刻歴

せん断型・曲げせん断型の 2 次元／3 次元モデルを扱います。必要な先行結果、トリリニア縮約式、固有値、減衰、モデル別の未収束時の扱いと利用可能な結果は、[質点系解析](./10_質点系解析.md)を正とします。立体時刻歴の停止条件をそのまま質点系へ適用しないでください。

## 層応答の集計（層せん断力・層せん断力係数・階加速度・階速度・階変位）

[線形時刻歴](#線形時刻歴newmark-β)・[非線形時刻歴](#非線形時刻歴newmark-β--newton-raphson)のいずれの経路でも、応答の詳細記録として各時刻の層応答を階（下層→上層）ごとに集計します。
X・Y 方向の両方を常に記録し、加振されていない方向のねじれ・偏心による連成応答も含めます。

**層せん断力（慣性力ベース）**

節点慣性力ベクトル \\( f\_{\text{abs}} = M \cdot \ddot{u} + \ddot{x}\_g \cdot M \cdot r \\)
（\\( \ddot{u} \\) は相対加速度ベクトル、\\( \ddot{x}\_g \\) は地動加速度、\\( M \cdot \ddot{u} \\)
は疎行列ベクトル積）の**当該方向の並進自由度成分のみ**を、当該層以上に属する節点について
集計し、符号を反転した値です。

\\[ Q\_i = -\sum\_{j \geq i} \sum\_{\text{dof} \in \text{階} j \text{ の並進自由度}} f\_{\text{abs, dof}} \\]

一貫質量行列では \\( M \\) が並進・回転自由度間の連成項を持ちますが、これは疎行列ベクトル積
\\( M \cdot \ddot{u} \\) の並進成分の中に既に正しく反映されているため、回転自由度そのものを
集計へ含める必要はありません（回転自由度の加速度に地動加速度 \\( \ddot{x}\_g \\) を直接
加算することもしません）。どの階にも属さない節点（基礎レベルの自由節点等）の並進自由度は、
Z 座標が最も近い階（階の代表 Z＝所属節点の平均 Z）に計上します。最下層の \\( Q\_1 \\) は
全並進自由度の慣性力の総和（ベースシア）に一致します。

**層せん断力係数**

全時刻を通じた層せん断力の絶対値最大値を、当該層以上の地震用重量の総和で除した値です。

\\[ C\_i = \dfrac{\max\_t |Q\_i(t)|}{\sum\_{j \geq i} W\_j} \\]

\\( W\_j \\) は階 \\( j \\) の地震用重量（[地震力](../01_荷重/01_地震力.md)と同じ設計用重量）です。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( Q\_i \\) | i 層の層せん断力（慣性力ベース） | N |
| \\( C\_i \\) | i 層の層せん断力係数（最大層せん断力／i 層以上の地震用重量） | - |
| \\( W\_j \\) | j 層の地震用重量 | N |
| \\( \bar{a}\_i \\) | i 階の質量加重平均した絶対加速度 | mm/s² |
| \\( m\_{\text{dof}} \\) | 自由度の質量 | t |

**階絶対加速度・階速度・階変位**

階に属する節点の質量加重平均です（質量が全節点ゼロの階は単純平均）。加速度は絶対加速度（相対加速度＋地動加速度）、速度・変位は相対値です。

\\[ \bar{a}\_i = \dfrac{\sum\_{\text{dof} \in \text{階} i} m\_{\text{dof}} \left( \ddot{u}\_{\text{dof}} + \ddot{x}\_g \right)}{\sum\_{\text{dof} \in \text{階} i} m\_{\text{dof}}} \\]

**層応答の最大値**

層せん断力・階絶対加速度・階速度・階変位のいずれも、全時刻を通じた絶対値最大値
（[詳細記録のフレーム間引き（record_every）](#詳細記録のフレーム間引きrecord_every)に関わらず全ステップで求めた値）を別途保持します。

**代表応答記録**

UI 描画用の代表応答（1 節点変位等）の記録方向は、入力加速度の絶対値和が大きい方向を自動選択します（Y 方向入力があり、その絶対値和が X を上回る場合のみ Y）。記録節点は最上部の当該方向自由度を持つ節点です。

## 鋼板耐震壁の既知制限の注意

非線形時刻歴応答解析では、解析へ組み込まれる鋼板耐震壁がある場合、開始時に対象の枚数・要素 ID・生成元の壁版 ID をまとめて 1 回表示し、解析を継続します。同期実行とバックグラウンド実行で通知内容は共通です。時刻ステップごとには繰り返さず、新しい起動では再通知します。準備計算の注意と計算エラーも保持します。

現行のせん断耐力は鋼板のせん断降伏 \\( Q\_y=t\,l\_w F/\sqrt{3} \\) によるもので、せん断座屈を考慮しません。幅厚比が大きく補剛のない鋼板では、耐力を過大評価し得ます。通知は座屈耐力や断面検定の合格を保証せず、未確認の幅厚比の数値しきい値は用いません。計算モデルと適用上の制限は[壁エレメントモデル](../04_要素剛性/05_壁エレメントモデル.md)を参照してください。

線形時刻歴、鋼板耐震壁がないモデル、RC 壁・SRC 内蔵鋼板、壁エレメントにならない壁版には、この非線形耐力モデルの注意を表示しません。

## 詳細記録のフレーム間引き（record_every）

[線形時刻歴](#線形時刻歴newmark-β)・[非線形時刻歴](#非線形時刻歴newmark-β--newton-raphson)いずれの経路でも、全節点変位・部材内力・層応答の時系列（[層応答の集計（層せん断力・層せん断力係数・階加速度・階速度・階変位）](05_時刻歴応答解析.md#層応答の集計層せん断力層せん断力係数階加速度階速度階変位)）は、
解析の全ステップのうち一定間隔 `record_every` ステップごとに間引いて保持します
（初期点と最終確定点は間引きに関わらず必ず含めます）。地震波は数千〜数万ステップに及ぶため、
時系列の全量をそのまま保持するとメモリ・保存容量を圧迫することへの対処です。

`record_every` を指定しない場合は、記録フレーム数がおおむね 1000 になるよう次式で自動決定します（\\( T=N-1 \\) は全積分区間数）。間引かない場合のフレーム数は初期点込みの T+1 です。

\\[ \text{record\_every} = \max\left(1, \left\lfloor T / 1000 \right\rfloor\right) \\]

たとえば T=5、record_every=3 では確定ステップ 0, 3, 5 を残します。

間引きの対象は時系列本体（各フレームの全節点変位・部材内力・層応答）のみです。
全ステップを通じた最大応答（節点変位の最大値、部材内力の包絡値、層せん断力係数 Ci、
層せん断力・階絶対加速度・階速度・階変位の絶対値最大）は間引かず、全ステップを走査して
求めます。

フレームごとの部材内力（時系列本体）は、各部材の評価断面のうち両端 2 点（材端、
最小ξ・最大ξ）のみを保持し、メモリを削減します（3D アニメーション・履歴表示は端部値の
みを用いるため）。中間の評価断面（危険断面）を含む全断面の情報は、間引かない包絡値
（部材内力の最大値）側にのみ保持されます。

解析タブ「時刻歴応答」の「記録間引き」欄で `record_every` を指定できます
（線形 Newmark-β・非線形のいずれの経路でも共通）。0 を指定すると上式による
自動決定になります。
