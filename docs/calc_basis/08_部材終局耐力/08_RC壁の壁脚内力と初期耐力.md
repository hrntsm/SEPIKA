# RC壁の壁脚内力と初期耐力

静的解析後のせん断参考骨格は、選択した荷重ケースまたは保存組合せの同じ応力状態から、壁全体の壁脚内力を求めます。非線形解析の初期耐力は、解析開始時の入力を固定した静的一次参照から求め、解析中は更新しません。この二つは目的と応力状態が異なります。

## 適用範囲と未算定

本節は静的解析後のせん断参考骨格と非線形解析用の初期Quに共通する壁・側柱の適用範囲です。線形解析・許容せん断検定・非線形解析の実行可否との区別は[目的別の適用範囲](../04_要素剛性/05_壁エレメントモデル.md#目的別の適用範囲)を参照してください。

対応するのは、同一平面の単独・無開口・矩形鉛直RC耐震壁と、対称同質の正方形RC断面を持つ両側の付帯柱です。付帯柱と上下支持梁は、梁・ファイバー梁・MSのいずれの入力表現でも同じ物理的な接続と断面を用い、この参照では線形弾性として評価します。側柱の元端部条件は両端剛接とし、断面方向は壁面内・壁面法線に平行で、壁面法線まわりの両端回転解放が成立し、下部支持梁と左右柱脚が同じ実フェイス平面を持つ必要があります。

解析種別の適用条件は[側柱の回転解放と適用範囲](../../nonlinear/06_壁の非線形モデル.md#側柱の非線形接続と適用範囲)を優先します。両側柱を持つRC壁の非線形時刻歴は、側柱の解放回転と慣性の連成が未定式化のため未対応です。初期Quを算定できることは、その解析の実行可能性を意味しません。側柱を除いた壁も本節の初期Quの対象には含めません。

終局せん断耐力の単体評価でも両側柱を必要とし、無側柱・片側柱の壁には耐力を返しません。壁板の全縦筋量を引張側柱主筋量へ代用せず、無側柱の壁に両側柱付き壁の有効せいを適用しません。

共有柱、連スパン、開口、異種・非対称側柱、成立しない端条件は未対応として対象識別番号と理由を示します。解析後の参考骨格では壁・側柱への部材荷重を含む経路も未対応です。初期耐力用の長期軸力に限り、側柱の軸方向部材荷重を柱の実接合面（フェイス）位置で評価します。生成された壁要素への直接部材荷重は拒否します。

側柱と壁の節点・断面用途・材料の対応が不正な場合は、許容せん断検定と参考骨格の双方に対象と理由を示します。一方、鉛直卓越材として側柱を認識できても、壁が傾斜して矩形鉛直壁の条件を満たさない場合は参考骨格を未算定とし、独立に成立する許容せん断検定は維持します。

必要な応答・材料・フェイス由来の不足、非有限値、水平参照のQ=0、引張軸力、平均圧縮応力度が0.4Fcを超える場合は代替耐力を補完しません。参考骨格は理由付き未算定となり、独立した正常な許容せん断検定は維持します。初期Quが必要な壁のいずれかの正負が未解決なら、その非線形解析は開始できません。壁なし、純鋼板壁、非耐震壁、線形解析にはこの初期QuのAi要件を課しません。

## 終局せん断耐力の方式と入力

右パネル「① 準備計算」の「計算条件」で「RC壁の終局せん断耐力」を荒川min／荒川meanから選びます。新規モデルの既定は荒川meanです。建物全体で共通の一方式を使い、部材・断面・階別の上書き、二方式の同時計算・比較、小さい耐力の自動採用は行いません。

壁脚フェイスの入力から \\(\lambda=|M_{フェイス}|/(|Q|D)\\)、\\(c=p_{te}^{0.23}(F_c+18)\\)、\\(s=0.85\sqrt{p_{wh,e}\sigma_{wh}}+0.1\sigma_0\\) として、次を使います。

\\[
Q_{u,min}=\left(\frac{0.053c}{\lambda+0.12}+s\right)t_ej,
\qquad
Q_{u,mean}=\left(\frac{0.068c}{\sqrt{\lambda+0.12}}+s\right)t_ej
\\]

| 記号 | 入力・意味 | 単位 |
| --- | --- | --- |
| Qu,min・Qu,mean | 選択方式による壁の終局せん断耐力 | N |
| Fc | 壁コンクリートの設計基準強度 | N/mm² |
| σwh | 明示した水平横筋材料の降伏強度 | N/mm² |
| t・te・D・d・Dc・j | 実壁厚・等価壁厚・全長・有効せい・圧縮側柱せい・応力中心距離 | mm |
| ag | 引張側柱の全主筋面積 | mm² |
| pte | 等価断面の引張鉄筋比。1%は数値1 | % |
| Pwh・Pwv・pwh,e | 実壁厚基準の横筋比・縦筋比・等価壁厚基準の横筋比 | 小数（無次元） |
| N・A・σ0 | 同じ壁脚位置の圧縮正軸力・物理断面積・平均圧縮応力度 | N, mm², N/mm² |
| Mface・Q | 同じ応力状態・壁脚位置の曲げモーメント・面内せん断力 | N·mm, N |
| λ・c・s | せん断スパン比と式の略記。c=pte^0.23(Fc+18)、sは横筋・軸力項 | 無次元, N/mm², N/mm² |

方式によってコンクリート項の係数と分母を同時に変えます。横筋・軸力項は共通であり、Qu全体を0.068/0.053倍しません。両方式の値の大小だけでは、対象壁の安全性や設計適合を判定できません。

- Dは付帯柱を含む壁全長、d=D−Dc/2、j=7d/8、Dcは圧縮側柱の壁方向せいです。
- 等価壁厚teは実壁板と付帯柱の重複を控除した面積と全長を等しくする置換幅で、1.5t以下とします。
- 引張側柱主筋agからpte=100ag/(te d)を百分率で求めます。明示横筋比Pwhと壁板の明示縦筋比Pwvは実壁厚基準の小数で、pwh,e=min(Pwh t/te, 0.012, 2Pwv)とします。横筋比だけを等価壁厚へ換算し、上限側の縦筋比は壁板の実壁厚基準を使います。最小筋比から方向別の比を推定しません。
- σ0=N/Aは圧縮正です。Aはteの上限制限前の実壁板と付帯柱の物理面積で、te Dへ置き換えません。明示N=0は有効ですが、欠落したNは0にしません。
- λは正の有限入力を1〜3へ制限します。無開口に限りr=1です。長さmm、面積mm²、強度N/mm²、MはNmm、Q・N・QuはNです。

横筋寄与は、等価壁厚基準で1.2%以下、かつ壁板の実壁厚基準の縦筋比の2倍以下に制限します。側柱主筋の有無にかかわらず、壁板の縦筋比が未知・非有限・負の場合は初期耐力を算定できません。参考骨格では縦横とも直交最小筋比以上の明示入力が必要です。構造実験による終局強度確認を入力する機能はなく、実験確認による上限の例外は適用しません。上限適用後にひび割れ耐力Qc以上のQuを得られない場合、参考骨格は理由付き未算定になります。

引張N、σ0>0.4Fc、Q=0、非有限・不足・計算時入力との不一致は理由付き未算定または解析開始拒否です。0.4Fcの制限は現在の実装域を拡張しないための条件であり、規準による適用保証ではありません。他方式への切替や0耐力による補完は行いません。

参考骨格のQc・変形角・割線剛性比βsは[RC壁の参考骨格](../../nonlinear/05_RC_部材_非線形復元力特性.md#耐力骨格点単位)を参照してください。参考骨格は解析せん断ばねへ接続しません。

参考骨格と非線形解析の正負初期Quには同じ選択を用います。非線形解析は開始時の方式を固定し、求解中の方式変更・履歴再構築・採用ステップの自動探索を行いません。モデル化表示とDsは同じ解析実行の採用Quを使います。

設定はプロジェクト全体とともに保存され、取り消し・やり直しの対象です。方式を編集すると切替前の解析・検定・実行中ジョブの結果は利用できません。別の解析を実行しても旧増分結果は復活せず、採用方式で再計算が必要です。参考骨格は成功・未算定とも方式名を示し、初期Quの未解決理由にも方式を示します。

## 同じ壁脚フェイスでの壁全体内力

壁柱の局所xを下から上、yを下辺aからb、zをx×yとします。中央壁柱の軸・曲げは壁厚t×壁長lwの断面で、独立側柱の軸・曲げを含みません。面内せん断剛性は側柱を含む和集合断面に由来します。したがって中央壁柱と側柱の全成分を一律に足し合わせません。

同じ高さ・同じ切断側へ局所軸と端順を正規化し、引張正の回収軸力をNt、圧縮正をNc=-Nt、物理断面の図心から沿壁方向の腕長をrとすると、対応経路では次を使います。

\\[
N_{comp}=N_{c,wall}+N_{c,left}+N_{c,right},\qquad Q_{wall}=Q_{y,wall}
\\]
\\[
M_{z,O}=M_{z,wall}+\sum_i r_iN_{c,i}
\\]

同じ壁脚フェイスの軸力合成では、圧縮正の各成分を \\(N_i\\)、合成値を \\(N=\sum_iN_i\\) として、\\(|N|\leq32\varepsilon\sum_i|N_i|\\) のときだけ、正負どちらの値も零へ正規化します。\\(\varepsilon=2^{-52}\\) は倍精度の機械イプシロンです。これは相殺に伴う丸め誤差を扱う数値上の判定であり、厳密な全誤差上界を保証するものではありません。絶対的な力・応力のしきい値は設けず、単独の微小軸力は保持します。有意な引張軸力は引き続き適用外とし、耐力式の応力度範囲や物性値は変更しません。

解放側柱の面内Q・Mは零となる経路で、その数値残差を確認します。側柱の軸力腕長Mは零ではありません。軸力の釣合い合成と、壁板・柱の重複を控除した物理面積Aは別の量です。例えばlw=4000、t=180、左右600×600では中央と両柱の解析軸断面積の和は1440000 mm²、物理和集合Aは1332000 mm²です。軸力を重複面積の割合で任意に減算しません。軸剛性モデル自体の妥当性確認を、この内力合成の確認で代用しません。

中央壁柱の下端応答は下梁心位置の値です。下部支持梁の形状・方向・支持関係から実フェイス距離ℓを求め、左右側柱の明示フェイスと実空間高さを照合します。剛性用剛域長をフェイス距離の代わりに使いません。別の接続梁のフェイスが支配する場合、フェイス不明・不一致、対応する位置の応答がない場合は未算定です。

現行局所断面力の符号はdMz/dx=+Qyです。梁心から上向きにℓ移す中央壁柱は、符号付きのまま一度だけ次の輸送を行います。

\\[
M_{z,face}=M_{z,center}+Q_y\ell,\qquad
\lambda=\frac{|M_{z,face}|}{|Q_{wall}|D}
\\]

側柱は既に同じフェイスで回収されたNを使い、再輸送しません。絶対値化は輸送と軸力腕長合成の後です。壁脚以外の最大N・最大Mを組み合わせず、総応力へ長期成分を再加算しません。

画面または外部連携で選択したケース／組合せを検定する場合は、その応答を生成した実荷重集合に対して未対応部材荷重を検査します。対象集合が明示されない検定では、モデル内の全荷重ケースを保守的に検査します。ケース名だけから対象集合を推定しません。

## 初期Quの静的一次参照

長期参照Gは、その解析の長期載荷設定がONなら固定・積載・雪・その他の長期種別の全荷重を係数1で合成します。負の値も保持します。OFFと、正常に解決した空の長期集合は明示無載荷N=0です。応答取得の失敗はN=0へ置き換えません。設計用組合せや雪係数をこの集合へ無断適用しません。

水平参照EX/EYは、建物高さと鋼造高さ比による略算周期を使い、方向だけX/Yに設定した既定Ai条件で生成します。壁下辺の水平単位方向e=(ex,ey)に平行な荷重Ew=ex EX+ey EYを作り、正負をそれぞれ直接解きます。GもEwも節点・部材荷重を求解前に合成し、引張専用の反復や長期軸力無効化など当該解析実行の静的設定を保ちます。引張専用材などの有効状態が変わる応答の事後重ね合わせや、一方の解の負号反転による代用は行いません。

Gは長期、Ewは非長期地震荷重として扱います。採用するN_Gは設定された静的一次参照の軸力であり、別の非線形構成則で長期載荷した後の軸力との完全一致を保証しません。保存済みのEX/EY名称や表示中の荷重ケースを初期参照に読み替えません。

Gから使うのは同じフェイスの圧縮正N_Gとσ0=N_G/Aです。軸方向分布荷重のある側柱は固定端内力を含む実フェイスのNを採り、梁心のNを一定として運びません。各水平参照から壁全体M/Qを求め、λを選択した耐力式の1〜3に制限します。中央壁柱の下側Qyと上辺伝達力Qwは逆符号なので、参照応答の局所Qwに従って正負の引張側・圧縮側へ対応付けます。

この壁方向Ai参照はSEPIKAの採用するモデル化規約です。法令・規準による唯一の方向規則とはしません。増分の加力方向、時刻歴の方向・波形ピーク・瞬間応答から初期値を選ぶ規約ではなく、実時刻歴の応力状態を再現することを意味しません。対応する増分解析では材料強度を用い、横筋fyは割増せず、縦材料の自身の倍率は一度適用します。

全壁の正負Quを有限正値として確定できることが非線形解析の開始条件です。初期耐力の参照応答は、非線形解析の初期変位・応力・履歴・外力として採用しません。非線形解析の長期載荷は別途1回だけ行い、参照応答は通常の静的解析結果とは別に扱います。モデル化表示とDs判定は同じ入力・同じ解析実行で採用したQuを使います。未解析・採用解析実行なし・旧入力・欠落耐力は未解決と表示し、表示操作で再求解しません。

参照求解の特異・不収束、Ai生成不可、局所分岐不足、材料不正も開始拒否の理由になります。失敗した計算の新しい非線形結果・履歴は公開しません。計算中に入力を変更した場合は、その開始入力と一致しない結果を採用しません。

## 計算根拠と確認限界

初期モデルには静的一次参照のM/Qと長期軸力を用います。中央壁柱も軸力を負担するため、中央と両柱を同じフェイスで合成します。ピン側柱の面内Q/Mが零でも、軸力の腕長によるモーメントは合成します。フェイスへの輸送符号は本モデルの局所符号に従い、M−Qℓを無条件に適用しません。

荒川min／meanの係数・分母と、λ、D/d、等価壁厚te・物理面積Aは本文で示す組合せを採用します。M/(Qd)とσ0=N/(te D)を使う方式は、SEPIKAのDと物理Aを使う方式と区別し、式の一部を混成しません。

[国土交通省・建築研究所 中村聡宏の公開報告](https://www.mlit.go.jp/chosahokoku/r6giken/assets/pdf/safety_and_security-2.pdf#page=47)の本文p.44／PDF47式(6)は0.068・根号分母・Dと根号外の軸力項を示します。開口新設連層壁実験の評価を、一般開口モデルへ転用しません。

『2025年版 建築物の構造関係技術基準解説書』第2版第1刷、付録1-3.1(3)⑥b)、pp.715–716、
式(付1.3-32)・(付1.3-33)は、この二方式の係数・分母、D/d、等価壁厚・鉄筋比とスパン比を示します。
p.716の横筋比上限には1.2%に加えて壁板の鉛直せん断補強筋比の2倍という条件があり、
その上限を超える場合の例外には構造実験による終局強度の確認が必要です。
横筋比にはこの二つの上限を適用します。0.4Fcの圧縮上限は同頁の壁式には明記されていません。
この上限を柱のせん断式に対する0.4Fcの規定で正当化しません。引張域の適用と高圧縮域の安全性も確認できていないため、初期Quでは現在の軸応力度制限を維持します。範囲内で計算できることだけでは、個別壁の規準適合や破壊性状を保証しません。

同頁のI形断面では、引張側柱の総主筋量と圧縮側柱せいを使います。側柱のない長方形断面にはd=0.95Dと端部の曲げ補強筋量という別の定義があり、全壁の縦筋量による代用はできません。端部圧縮領域の閉鎖型補強筋による拘束が不十分な無側柱壁では、実験値と計算値の比が小さくなる傾向も示されています。側柱なしの壁は本節の初期Quの対象外とし、端部筋・拘束条件を推定して計算しません。

壁板縦横筋によるせん断補強と端部の曲げ補強筋は区別します。p.714にある壁筋比0.45%以上・周辺柱寸法等は、終局変形角からせん断剛性低下率を設定する条件であり、Qu式の一律の配筋条件へ読み替えません。p.716のFc18〜60 N/mm²の試験調査も、任意の軸力・配筋・材料域への適用を保証するものではありません。

2007年版pp.281–282・638–639及び2020年版原典全文への適合は未確認です。実験による破壊・履歴・軸剛性・動的応答・全適用域のValidationは未確認です。
