# 終局検定の統括

RC 部材のせん断・付着・軸の余裕度と CFT 柱の軸終局検定を扱います。需要は「静的・両端ヒンジ略算」と「増分・確定総応答」を区別します。部材余裕度の成立だけで、建物全体の保有水平耐力判定が完了したことにはなりません。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( Q\_{mu} \\) | 曲げ終局時せん断力 | N |
| \\( Q\_{su}, Q\_{bu} \\) | 終局せん断耐力・付着割裂耐力 | N |
| \\( Q\_L \\) | 長期せん断力 | N |
| \\( Q\_{mx}, Q\_{my} \\) | x・y 方向の曲げ終局時せん断力 | N |
| \\( Q\_{ux}, Q\_{uy} \\) | x・y 方向の終局せん断耐力 | N |
| \\( M\_u \\) | 曲げ終局強度 | N·mm |
| \\( \text{内法} \\) | 部材の内法長さ | mm |
| \\( b\_{ai} \\) | 接合部有効幅の片側分 | mm |
| \\( b\_i \\) | 梁幅 | mm |
| \\( D \\) | 柱の断面せい | mm |

**静的・両端ヒンジ略算の余裕度**：部材別にせん断、付着、軸の余裕度を算定します。
梁の余裕率は長期せん断力 QL を分子から控除した \\( \frac{Q\_{su} - Q\_L}{Q\_{mu}} \\)・\\( \frac{Q\_{bu} - Q\_L}{Q\_{mu}} \ge 1.0 \\) とします。
ここで QL は、保存した架構用長期組合せの terms と係数で符号付き合成した FEM 重力せん断力の最大絶対値です。部材荷重から単純梁として求める Q0 とは区別します。控除後の耐力が負になる場合は 0 とします。この式は静的・両端ヒンジ略算に限り、増分・確定総応答には適用しません。
柱の 2 軸せん断余裕度は \\( 1/((Q\_{mx}/Q\_{ux})^2 + (Q\_{my}/Q\_{uy})^2)^{1/2} \\) とします。
曲げ Mu は引張鉄筋量を用いる略算式により、柱は軸力を考慮します。
せん断は塑性理論式（既定）または[靭性指針式せん断信頼強度 Vu / Vbu](02_RC_終局せん断.md#靭性指針式せん断信頼強度-vu--vbu)を切り替えます。
接合部終局の有効幅は \\( b\_{ai} = \min(b\_i/2, D/4) \\)（許容応力度検定と同じ）。
検定対象は用途別 RC 断面（RC 梁・RC 矩形柱・RC 円形柱）とします。梁の曲げ Mu は実配筋の上端・下端と曲げ符号から引張側を選んで算定します（曲げ 0 のときは引張鉄筋量の小さい側）。対応 RC 断面で Fc 未設定・Fc/断面寸法不正・材料未設定・主筋降伏強度未解決・配筋不整合・有効せい 0 以下・せん断補強筋の未対応グレードまたは fy 未設定がある場合は対象外とせず部材 ID 付きエラーとします。柱の 2 軸せん断余裕度は指定により検定します。

## 設計軸力の符号と保存結果

RC・CFT の終局検定に用いる設計軸力は圧縮正［N］です。静的解析の引張正の断面軸力は、terms の合成後、終局需要へ渡す際に一度だけ符号を反転します。増分解析の軸力は既に圧縮正のため、そのまま用います。
この符号契約は RC・CFT の静的終局検定に共通です。CFT の中柱・円形・Case1・引張・長方形の耐力式を維持することと、解析結果から渡る軸力の符号を正しく扱うことは区別します。

荷重 terms・係数・用途、材料、配筋、形状、解析条件の変更と、読込・Undo・Redo により入力が変わった場合は結果を失効させます。生成元の入力識別が現在と異なる結果の採用も拒否します。保存成果の契約版と再計算の扱いは[プロジェクト形式](../../model_io/01_プロジェクト形式_ovika.md)を参照してください。

## 静的・両端ヒンジ略算の重力参照

設計タブ「終局検定」の「長期架構用組合せを選択」から、保存した架構用長期荷重組合せを明示します。「未指定（未検定）」のままでは需要を算定しません。標準は係数 1 の固定荷重 G と架構用積載 P です。積載がゼロでも、架構用積載の空ケースを明示します。地震重量用積載による代用、名称・ケースの並び順による選択はしません。

選択 terms と係数を保持し、同じ部材・局所軸・評価位置の符号付き 6 成分を線形合成します。

\\[
\boldsymbol{F}_G(\xi)=\sum_k c_k\boldsymbol{F}_k(\xi),\qquad
\boldsymbol{F}=[N,Q_y,Q_z,M_x,M_y,M_z],\quad \xi=x/L
\\]

軸力・せん断力は N、モーメントは N·mm、位置は i 端からの無次元位置 \\(0\le\xi\le1\\) です。絶対値・最大値をケースごとに先に加算せず、符号付き合成後に抽出します。設計軸力は合成した始端値、曲げ需要は合成後の部材内最大絶対値、QL は合成後の local Qy の最大絶対値です。始端 N と最大 M・QL は必ずしも同一断面ではありません。全断面の危険位置探索や補間を行う評価ではなく、この抽出について一律の安全側は保証しません。

両端ヒンジを仮定する要求せん断力は \\(Q_{mu}=\alpha\,2M_u/l_0\\) です。α は上限強度倍率、Mu は曲げ終局強度、l0 は内法長さです。既存の上限強度倍率を用いる限定評価であり、実際の終局時総応答を取得した検定ではありません。

## 増分・確定総応答

選択方向の確定評価ステップから N・M・Q・塑性回転角 Rp を採ります。画面で閲覧しているステップと需要採用ステップは区別します。解析実行に記録した初期重力の terms・係数・入力識別・載荷有無を参照し、現在の地震重量集合から重力を再構成しません。

外力の釣合いは \\(\boldsymbol{f}_{ext}=\boldsymbol{f}_0+\lambda\boldsymbol{q}\\) です。確定内力は初期重力を含む総応答なので、Q へ QL を再加算せず、耐力から QL を再控除しません。総応答モードで追加 QL を 0 と扱うことは「総 Q に追加しない」という意味であり、重力なしや QL 不足の代用ではありません。

総応答モードでは QL の未設定を需要モードと組にして「追加なし」と表します。静的略算での QL 未設定は入力不足です。

初期対応の上限強度倍率は 1 に限ります。非 1 は重力まで増幅するため理由付き未対応とし、静的略算への自動切替は行いません。強軸のせん断・付着余裕度は次式です。

\\[
\eta_s=\frac{Q_{su}}{|Q_{total}|},\qquad
\eta_b=\frac{Q_{bu}}{|Q_{total}|}
\\]

例えば Qsu=120000 N、Qmu=80000 N、QL=12000 N のヒンジ略算は余裕度 1.35 です。同じ耐力で総 Q=92000 N の総応答は 1.304347826、逆向き総 Q=−68000 N は 1.764705882 です。これは需要モードの演算例であり、実部材の耐力式・実験的妥当性の検証ではありません。

初期重力を明示的に載荷しない解析は参考の水平載荷実験として扱い、一般建物の終局合否へ自動採用しません。非線形総応答へ別の線形重力応力を後から加えて、同じ荷重履歴の解として扱うこともしません。

## 完全性と未検定

必要な非ゼロ係数ケースが 1 件でも未解析・失敗・参照破損・世代不一致なら、取得できたケースだけで需要を成立させません。重複 terms はケース別に係数を正規化します。係数 0 の term は応力を要求しませんが、参照と係数の構文は検査します。同種別でも選択外のケースは加えません。

必要部材の欠落、空の評価位置列、重複部材 ID、不正位置、非有限の位置・内力、局所軸・結果モデルの不一致も入力不足です。評価位置は 0 と 1 の両端を含む厳密な昇順とし、ケース間で同じ位置列に完全一致する範囲だけを扱います。位置が対応しなければ、欠けた側を 0 とせず理由付きで拒否します。増分応答の空・非有限・未確定・旧世代・方向違いでも静的へ自動代用しません。静的モードは利用者が明示的に選択します。

対応する RC・CFT 対象の需要不足は対象外と区別し、部材 ID・ケースまたは term・用途・原因を伴う理由として返します。直接の部材検定でも欠落を需要 0・無限大余裕度・合格に変換しません。部分結果が得られても全体は不完全・未検定であり、全検定算定済みかつ合格とは扱いません。定義済みで有限な 0 と入力不足は区別します。材料不足などの診断も保持します。

Other、用途不明、LiveSeismic だけの代用、標準外係数の根拠不足は理由付き未対応です。長期組合せに明示した積雪係数を保持しますが、特別な終局重力組合せ、雪の地域・実況条件の自動判定、過強度需要や増分成分だけの増幅には対応しません。許容応力度用の組合せ判定を、すべての終局荷重条件の規準適合とは解釈しないでください。

MCP 固有の未指定時の先頭ケース採用と、単独ケース指定による長期総組合せ不足の扱いは修正・専用受入が未完了です。共有計算の不足診断だけで、MCP 経由の終局検定が受入済みとは扱いません。

## 根拠と確認範囲

架構応力用積載と地震重量用積載の区別は、文部科学省[「建築構造設計指針」平成21年版・平成26年訂正掲載](https://www.mext.go.jp/component/a_menu/education/detail/__icsFiles/afieldfile/2014/10/14/1293759_003.pdf#page=29) §4.2 表4.2（本文 p.22／PDF p.29）に確認できます。同指針 §6.2（本文 p.31／PDF p.38）は部材・接合部の終局強度と崩壊機構の関係を示します。文教施設を対象とするため追加係数を一般建物へ無条件に転用しません。表紙・訂正事項・適用範囲（PDF pp.1–2、8）も確認範囲です。

静的標準 G+P と保存長期 terms、総応答の倍率 1 は SEPIKA の先行対応範囲です。総応答へ重力を再加算しないことは、上記釣合いと確定内力の定義からの判断です。これらを学会規準の全終局条件として断言しません。引用学会規準・技術基準解説書の未閲覧原本、特殊条件の適用、実験 Validation は確認済みとは扱いません。
