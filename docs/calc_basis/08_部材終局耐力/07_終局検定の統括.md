# 終局検定の統括

RC 部材のせん断・付着・軸の余裕度と CFT 柱の軸終局検定を扱います。需要は「静的・両端ヒンジ略算」と「増分・確定総応答」を区別します。部材余裕度の成立だけで、建物全体の保有水平耐力判定が完了したことにはなりません。

## 検定対象と耐力の方式

曲げ Mu は引張鉄筋量を用いる略算式により、柱は軸力を考慮します。
せん断は塑性理論式（既定）または[靭性指針式せん断信頼強度 Vu / Vbu](02_RC_終局せん断.md#靭性指針式せん断信頼強度-vu--vbu)を切り替えます。
接合部のφ・有効幅bj・自動評価の制限は[RC柱梁接合部の終局耐力](03_RC_柱梁接合部_終局耐力.md)を正とします。
検定対象は用途別 RC 断面（RC 梁・RC 矩形柱・RC 円形柱）とします。梁の曲げ Mu は実配筋の上端・下端と曲げ符号から引張側を選んで算定します（曲げ 0 のときは引張鉄筋量の小さい側）。対応 RC 断面で Fc 未設定・Fc/断面寸法不正・材料未設定・主筋降伏強度未解決・配筋不整合・有効せい 0 以下・せん断補強筋の未対応グレードまたは fy 未設定がある場合は対象外とせず対象部材を示すエラーとします。柱の 2 軸せん断余裕度は指定により検定します。

静的・両端ヒンジ略算の RC 柱では、両軸の長期せん断力がゼロと確認できた場合に二軸せん断余裕度を算定します。長期せん断力がある場合や弱軸の値が欠ける場合は、確定した NG があればその判定を示し、それ以外は理由付きで「未検定」と表示します。

## 需要モードを選ぶときの比較

梁の強軸のせん断・付着余裕度について、比較する量を整理すると次のようになります。同じ \\(\eta_s,\eta_b\\) の記号でも、分母の比較需要と分子の重力分の扱いが異なります。

| 比較項目 | 静的参照（静的・両端ヒンジ略算） | 増分・確定総応答 |
| --- | --- | --- |
| 分子：比較に用いる耐力 | 終局せん断耐力・付着割裂耐力から \\(Q_L\\) を控除し、負なら 0 | 終局せん断耐力・付着割裂耐力をそのまま使用 |
| 分母：比較する需要 | 両端ヒンジを仮定した \\(Q_{mu}\\) | 採用した確定評価ステップの \\(\lvert Q_{total}\rvert\\) |
| \\(Q_L\\) の扱い | 選択した長期組合せの合成後最大絶対値を分子から控除。未設定は入力不足 | 初期重力を総応答に含むため、需要への再加算も耐力からの再控除もしない。未設定は「追加なし」 |
| 結果の意味 | 重力分を控除した耐力が、両端ヒンジの略算需要に対して持つ余裕 | 耐力が、初期重力を含む採用ステップの総需要に対して持つ余裕 |

総需要には重力による応答が既に含まれています。ここで耐力からも \\(Q_L\\) を差し引くと、同じ重力分を需要側と耐力側に二重に見込むため、静的略算の控除式を総応答へ流用しません。両方式の余裕度は、比較需要を確認せずに置き換えられる値ではありません。

**記号・単位**

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( Q\_{mu} \\) | 曲げ終局時せん断力 | N |
| \\( Q\_{su}, Q\_{bu} \\) | 終局せん断耐力・付着割裂耐力 | N |
| \\( Q\_L \\) | 長期せん断力（合成後の局所せん断力 Qy の最大絶対値） | N |
| \\( Q_{total} \\) | 採用した確定評価ステップの総せん断力（初期重力を含む） | N |
| \\( Q\_{mx}, Q\_{my} \\) | x・y 方向の曲げ終局時せん断力 | N |
| \\( Q\_{ux}, Q\_{uy} \\) | x・y 方向の終局せん断耐力 | N |
| \\( M\_u \\) | 曲げ終局強度 | N·mm |
| \\( l_0 \\) | 部材の内法長さ | mm |
| \\( \alpha \\) | 上限強度倍率 | 無次元、静的略算の既定 1.0 |
| \\( \eta_s, \eta_b \\) | せん断・付着余裕度 | 無次元 |

## 静的・両端ヒンジ略算の余裕度

部材別にせん断、付着、軸の余裕度を算定します。
梁のせん断・付着余裕度は、長期せん断力 \\(Q_L\\) を控除した耐力を、両端ヒンジを仮定する要求せん断力 \\(Q_{mu}\\) と比較します。

\\[
\eta_s=\frac{\max(Q_{su}-Q_L,0)}{Q_{mu}},\qquad
\eta_b=\frac{\max(Q_{bu}-Q_L,0)}{Q_{mu}}
\\]

いずれも 1.0 以上を満足することを確認します。控除後の耐力が負になる場合は 0 とします。
ここで \\(Q_L\\) は、選択した架構用長期荷重組合せの構成ケースと係数で符号付き合成した架構の重力せん断力の最大絶対値です。部材荷重から単純梁として求める Q0 とは区別します。採用位置は[静的・両端ヒンジ略算の重力参照](#静的両端ヒンジ略算の重力参照)に示します。この式は静的・両端ヒンジ略算に限り、増分・確定総応答には適用しません。

「柱を2軸せん断で検定」を選ぶと、強軸は長期せん断力を考慮した余裕度で確認します。静的略算の強軸で曲げ終局時せん断力が 0 でも、長期せん断力が強軸のせん断耐力を超えれば NG です。付着や二軸曲げも、選択していて NG が確定すれば部材を NG と表示します。

静的略算の二軸せん断余裕度は、強軸・弱軸の長期せん断力がともに 0 の場合に、両端ヒンジ略算の各軸需要と耐力の比を下式で合成します。長期せん断力がある場合の静的二軸合成は適用範囲外です。弱軸の耐力算定に必要な配筋・有効せいを確認できない場合も、二軸せん断余裕度は未算定です。表の「せん断余裕度」欄には算定できた軸を明記し、「未検定」にカーソルを合わせると理由を確認できます。各軸の需要・耐力の単位は N、余裕度は無次元です。

\\[
\frac{1}{\sqrt{
\left(\frac{Q_{mx}}{Q_{ux}}\right)^2+
\left(\frac{Q_{my}}{Q_{uy}}\right)^2
}}
\\]

## 設計軸力の符号と保存結果

RC・CFT の終局検定に用いる設計軸力は圧縮正［N］です。静的解析の引張正の断面軸力は、構成ケースの合成後、終局需要へ渡す際に一度だけ符号を反転します。増分解析の軸力は既に圧縮正のため、そのまま用います。
RC・CFTの静的終局検定はこの符号を共通に使います。

荷重の構成ケース・係数・用途、材料、配筋、形状、解析条件の変更と、読込・Undo・Redo により入力が変わった場合は結果を失効させます。生成元の入力条件が現在と異なる結果の採用も拒否します。保存結果の再計算の扱いは[プロジェクト形式](../../model_io/01_プロジェクト形式_ovika.md)を参照してください。

## 静的・両端ヒンジ略算の重力参照

設計タブ「終局検定」の「長期架構用組合せを選択」から、保存した架構用長期荷重組合せを明示します。「未指定（未検定）」のままでは需要を算定しません。標準は係数 1 の固定荷重 G と架構用積載 P です。積載がゼロでも、架構用積載の空ケースを明示します。選択は保存した組合せの種別と係数で確認します。

線形重ね合わせが成り立つ状態を対象とします。同じ部材・局所軸・評価位置の符号付き 6 成分を、選択した構成ケースの係数で線形合成します。ケースごとに引張専用ブレースの有効状態が変わる場合は、組合せ荷重による応答を別途照査してください。

\\[
\boldsymbol{F}_G(\xi)=\sum_k c_k\boldsymbol{F}_k(\xi),\qquad
\boldsymbol{F}=[N,Q_y,Q_z,M_x,M_y,M_z],\quad \xi=x/L
\\]

軸力・せん断力は N、モーメントは N·mm、位置は i 端からの無次元位置 \\(0\le\xi\le1\\) です。絶対値・最大値をケースごとに先に加算せず、符号付き合成後に抽出します。設計軸力は合成した始端値、曲げ需要は合成後の部材内最大絶対値、強軸・弱軸の長期せん断力はそれぞれ合成後の局所せん断力 Qy・Qz の最大絶対値です。始端 N と最大 M・QL は必ずしも同一断面ではありません。全断面の危険位置探索や補間を行う評価ではなく、この抽出について一律の安全側は保証しません。

両端ヒンジを仮定する要求せん断力は次式です。

\\[
Q_{mu}=\alpha\frac{2M_u}{l_0}
\\]

\\(M_u\\) は曲げ終局強度［N·mm］、\\(l_0\\) は内法長さ［mm］、\\(\alpha\\) は上限強度倍率（既定1.0、無次元）で、\\(Q_{mu}\\) は N です。倍率はヒンジ略算の比較需要にのみ掛かります。1 未満を入力すると、同じ耐力に対する余裕度が増えます。割増しが必要な保証設計には、この倍率の既定値や両端ヒンジの仮定だけで適用を判断できません。

## 増分・確定総応答

選択方向の確定評価ステップから N・M・Q・塑性回転角 Rp を採ります。保有水平耐力比較用に明示採用したステップが対象です。画面の閲覧ステップ、解析の最終ステップ、別途選ぶ Ds 判定用ステップからは自動選択しません。解析実行に記録した初期重力の構成ケース・係数・入力条件・載荷有無を参照し、現在の地震重量集合から重力を再構成しません。

外力の釣合いは \\(\boldsymbol{f}_{ext}=\boldsymbol{f}_0+\lambda\boldsymbol{q}\\) です。確定内力は初期重力を含む総応答なので、Q へ QL を再加算せず、耐力から QL を再控除しません。総応答モードで追加 QL を 0 と扱うことは「総 Q に追加しない」という意味であり、重力なしや QL 不足の代用ではありません。

総応答モードでは両軸の QL の未設定を需要モードと組にして「追加なし」と表します。静的略算で必要な軸の QL 未設定は入力不足です。RC 柱の二軸せん断余裕度には、初期重力を含む両軸の総せん断力の絶対値を用います。

この方式の上限強度倍率は 1 に限ります。総応答を一律に定数倍すると初期重力による内力も倍率の対象になります。地震成分のみを割り増す方法はこの検定の範囲外です。倍率 1 以外は未検定とし、静的略算への自動切替は行いません。強軸のせん断・付着余裕度は次式です。

\\[
\eta_s=\frac{Q_{su}}{|Q_{total}|},\qquad
\eta_b=\frac{Q_{bu}}{|Q_{total}|}
\\]

**せん断余裕度の演算例**：\\(Q_{su}=120000\\) N、\\(Q_{mu}=80000\\) N、\\(Q_L=12000\\) N のヒンジ略算は次の値です。

\\[
\eta_s=\frac{120000-12000}{80000}=1.35
\\]

同じ耐力で総 \\(Q_{total}=92000\\) N の確定総応答を比較すると、次の値です。

\\[
\eta_s=\frac{120000}{\lvert92000\rvert}\simeq1.304347826
\\]

局所座標で負の総せん断力 \\(Q_{total}=-68000\\) N の場合も、総応答の絶対値と比較します。この負符号は部材の局所軸に対するせん断力の向きを表します。解析全体の加力方向は、選択した加力ケースで確認してください。

\\[
\eta_s=\frac{120000}{\lvert-68000\rvert}\simeq1.764705882
\\]

これは需要モードの演算例であり、実部材の耐力式・実験的妥当性の検証ではありません。

初期重力を明示的に載荷しない解析は参考の水平載荷実験として扱い、一般建物の終局合否へ自動採用しません。非線形総応答へ別の線形重力応力を後から加えて、同じ荷重履歴の解として扱うこともしません。

## 完全性と未検定

設計タブの終局検定と、その共通需要算定の入口には、次の完全性の条件を適用します。

必要な非ゼロ係数ケースが 1 件でも未解析・失敗・参照破損・入力条件の不一致なら、取得できたケースだけで需要を成立させません。同じ荷重ケースを複数指定した場合は係数を合計します。係数0のケースには応力結果を要求しませんが、ケースの存在と係数の有効性を確認します。同種別でも選択外のケースは加えません。

必要部材の欠落、空の評価位置列、同じ部材の重複結果、不正位置、非有限の位置・内力、局所軸・結果モデルの不一致も入力不足です。評価位置は 0 と 1 の両端を含む厳密な昇順とし、ケース間で同じ位置列に完全一致する範囲だけを扱います。位置が対応しなければ、欠けた側を 0 とせず理由付きで拒否します。増分応答の空・非有限・未確定・古い入力条件・方向違いでも静的へ自動代用しません。静的モードは利用者が明示的に選択します。

対応する RC・CFT 対象の需要不足は対象外と区別し、対象部材・荷重組合せ・用途・原因を伴う理由として返します。直接の部材検定でも欠落を需要 0・無限大余裕度・合格に変換しません。部分結果が得られても全体は不完全・未検定であり、全検定算定済みかつ合格とは扱いません。定義済みで有限な 0 と入力不足は区別します。材料不足などの診断も保持します。

その他荷重、用途不明、地震重量用積載での代用、標準外係数は理由付き未対応です。

外部連携からの未指定ケースの選択や単独ケースの指定では、長期総組合せの完全性を保証できない制限があります。CFT の単独ケース結果で全項目が合格と表示されても、完全な重力条件による終局検定として採用しないでください。

## 積雪を含む長期重力の指定

長期重力には常時の G+P と、積雪荷重ケースを必要とする場合の G+P+0.7S を選べます。G・P の係数はそれぞれ 1 です。積雪を含める場合は積雪ケース S を 1 件指定し、そのケースに組合せ係数を掛ける前の短期積雪荷重を入力してください。多雪区域の長期組合せでは、この S に組合せで 0.7 を一度だけ掛けます。あらかじめ 0.7 を掛けた荷重を S に入力すると、積雪による需要を過小評価します。この範囲は[建築基準法施行令](https://laws.e-gov.go.jp/law/325CO0000000338)第82条第2号の長期組合せに対応し、0.7S は同令第86条第2項に基づく指定多雪区域の長期積雪時です。短期積雪の G+P+S と多雪区域の許容応力度計算における地震時の G+P+0.35S+K は、長期重力として選べません。増分解析では、モデルの階地震用重量から全体 +X または +Y 方向の標準地震力（地上部は Ai 分布）を求め、水平参照荷重として初期重力の後に増分載荷します。負方向の増分載荷や正負の結果の包絡が必要な場合は、別途照査してください。参照荷重の算定条件は [増分解析で採用する水平荷重](../05_構造解析/07_プッシュオーバー解析.md#採用する水平荷重) を参照してください。

積雪をモデル化するときは、建設地を管轄する特定行政庁の規則で多雪区域指定、垂直積雪量、積雪の単位荷重を確認してください。屋根の水平投影面積、勾配・雪止め・屋根形状、偏積雪を確認します。雪下ろしの慣習がある地域で垂直積雪量が 1 m を超え、雪下ろしによる低減を用いる場合は、その実況・垂直積雪量 1 m の下限・表示要件を確認します。多雪区域外でも条例等による積雪の組合せや、所定の緩勾配屋根における降雪後の降雨の割増しが必要になる場合があります。SEPIKA はこれらの適用を自動判定せず、選択した荷重ケースの内力を用います。条例等で標準形と異なる荷重組合せが必要な場合は、その組合せに対して別途照査してください。多雪区域の [Ai 地震力の階重量](../01_荷重/01_地震力.md#高さ方向分布係数-ai)への必要積雪分も別途確認・設定してください。

積雪の出典は施行令第86条、平成12年建設省告示第1455号、および『2025年版 建築物の構造関係技術基準解説書』第2版第1刷 §4.4（pp.269–271）・§5.3（pp.296–298）です。架構応力用と地震重量用の積載は施行令第85条第1項の表の別欄に対応します。同解説書 §5.2（pp.294–295）も参照してください。[平成12年建設省告示第1455号](https://www.mlit.go.jp/notice/noticedata/pdf/201703/00006501.pdf)

## 保証設計に必要な別の照査

平成19年国土交通省告示第594号第4第三号ハの表は、RC 造の保有水平耐力計算でせん断破壊を生じないものとした部材を対象とします。保証設計では部材の種類と両端ヒンジの成立に応じて設計用せん断力を求めます。梁は長期せん断力 \\(Q_0\\) を保持して地震力によるせん断力 \\(Q_M\\) に所定倍率を掛け、柱・耐力壁は告示の表に従って \\(Q_M\\) を割り増します。この照査には、同告示の適用条件、耐力式、各評価状態での地震成分、ヒンジの状態を確認する必要があります。保証設計の方法を Ds 算定時の応力で部材種別の判定に準用する場合も、保有水平耐力算定時の応力で保証設計を別途確認します。両時点で外力分布が異なる場合は、各時点に対応する分布を用います。出典は『2025年版 建築物の構造関係技術基準解説書』第2版第1刷 §6.2.4（pp.364–366）、§6.4.4（pp.427–428、431–435）および国土交通省公開資料 §6.3.5 の告示抜粋です。[告示抜粋を含む公開資料](https://www.mlit.go.jp/gobuild/content/001517906.pdf)

SEPIKA の終局検定で表示する余裕度は、選択した長期重力とヒンジ略算、または確定総応答による部材評価です。保証設計が必要な場合は、上記の地震成分・適用倍率を確認し、別途照査してください。鋼構造の塑性設計における荷重係数や限界耐力計算の極めて稀な積雪時の組合せも、この終局検定へ自動適用しません。
