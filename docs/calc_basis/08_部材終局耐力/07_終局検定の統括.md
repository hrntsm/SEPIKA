# 部材の終局検定

- <a id="静的両端ヒンジ略算の余裕度"></a><a id="静的両端ヒンジ略算の重力参照"></a>[静的・両端ヒンジ略算による終局検定](07_01_静的_両端ヒンジ略算による終局検定.md)
- <a id="増分確定総応答"></a>[増分・確定総応答による終局検定](07_02_増分_確定総応答による終局検定.md)

RC 部材のせん断・付着・軸の余裕度と CFT 柱の軸終局検定を扱います。需要は「静的・両端ヒンジ略算」と「増分・確定総応答」を区別します。部材余裕度の成立だけで、建物全体の保有水平耐力判定が完了したことにはなりません。

## 検定対象と耐力の方式

RC梁・柱のせん断には[荒川mean式](02_01_RC梁_柱の終局せん断耐力_荒川mean式.md)を使います。付着は[大地震時の付着照査](02_02_RC梁_柱の大地震時の付着照査.md)として扱います。CFTの適用条件は[CFT柱の終局耐力](06_01_CFT柱の軸終局耐力.md)を参照してください。

## RC梁・柱の内法長さ

材軸長から、算定済みの両端のフェース距離を差し引きます。内法長さは有限の正値が必要です。フェース距離や材軸長が不明、またはフェースが接触・重複する場合は、部材を理由付きで未検定とします。

## 需要モードを選ぶときの比較

静的・両端ヒンジ略算では、RC柱の参考需要 Qmu を表示します。RCのせん断耐力と余裕度は、設計用曲げとせん断の組を確認できる増分・確定総応答で算定します。強軸のせん断余裕度は Qsu を総せん断力の絶対値で除した値です。総応答は初期重力込みです。二軸せん断を指定した柱では、余裕度を算定した軸または二軸の別を表示します。

付着を有効にした場合は、設計用付着応力度、許容応力度、付着余裕度を表示対象にします。算定条件を確認できない項目は「未算定」と表示し、部材 ID にカーソルを合わせると理由を確認できます。付着をオフにしたときは「無効」と表示します。

## 設計軸力の符号と保存結果

RC・CFT の終局検定に用いる設計軸力は圧縮正［N］です。静的解析の引張正の断面軸力は、構成ケースの合成後、終局需要へ渡す際に一度だけ符号を反転します。増分解析の軸力は既に圧縮正のため、そのまま用います。
RC・CFTの静的終局検定はこの符号を共通に使います。

荷重の構成ケース・係数・用途、材料、配筋、形状、解析条件の変更と、読込・Undo・Redo により入力が変わった場合は結果を失効させます。生成元の入力条件が現在と異なる結果の採用も拒否します。保存結果の再計算の扱いは[プロジェクト形式](../../model_io/01_プロジェクト形式_ovika.md)を参照してください。

## 完全性と未検定

設計タブの終局検定と、その共通需要算定の入口には、次の完全性の条件を適用します。

必要な非ゼロ係数ケースが 1 件でも未解析・失敗・参照破損・入力条件の不一致なら、取得できたケースだけで需要を成立させません。同じ荷重ケースを複数指定した場合は係数を合計します。係数0のケースには応力結果を要求しませんが、ケースの存在と係数の有効性を確認します。同種別でも選択外のケースは加えません。

必要部材の欠落、空の評価位置列、同じ部材の重複結果、不正位置、非有限の位置・内力、局所軸・結果モデルの不一致も入力不足です。評価位置は 0 と 1 の両端を含む厳密な昇順とし、ケース間で同じ位置列に完全一致する範囲だけを扱います。位置が対応しなければ、欠けた側を 0 とせず理由付きで拒否します。増分応答の空・非有限・未確定・古い入力条件・方向違いでも静的へ自動代用しません。静的モードは利用者が明示的に選択します。

対応する RC・CFT 対象の需要不足は対象外と区別し、対象部材・荷重組合せ・用途・原因を伴う理由として返します。直接の部材検定でも欠落を需要 0・無限大余裕度・合格に変換しません。一部に未算定の項目があっても、確認済みの不適合があれば部材の判定は「NG」です。不適合が確認されず、必要な項目に未算定が残る場合は「未検定」です。定義済みで有限な 0 と入力不足は区別します。材料不足などの診断も保持します。

その他荷重、用途不明、地震重量用積載での代用、標準外係数は理由付き未対応です。

## 積雪を含む長期重力の指定

長期重力には常時の G+P と、積雪荷重ケースを必要とする場合の G+P+0.7S を選べます。G・P の係数はそれぞれ 1 です。積雪を含める場合は積雪ケース S を 1 件指定し、そのケースに組合せ係数を掛ける前の短期積雪荷重を入力してください。多雪区域の長期組合せでは、この S に組合せで 0.7 を一度だけ掛けます。あらかじめ 0.7 を掛けた荷重を S に入力すると、積雪による需要を過小評価します。この範囲は[建築基準法施行令](https://laws.e-gov.go.jp/law/325CO0000000338)第82条第2号の長期組合せに対応し、0.7S は同令第86条第2項に基づく指定多雪区域の長期積雪時です。短期積雪の G+P+S と多雪区域の許容応力度計算における地震時の G+P+0.35S+K は、長期重力として選べません。増分解析では、モデルの階地震用重量から全体 +X または +Y 方向の標準地震力（地上部は Ai 分布）を求め、水平参照荷重として初期重力の後に増分載荷します。負方向の増分載荷や正負の結果の包絡が必要な場合は、別途照査してください。参照荷重の算定条件は [増分解析で採用する水平荷重](../05_構造解析/07_プッシュオーバー解析.md#採用する水平荷重) を参照してください。

積雪をモデル化するときは、建設地を管轄する特定行政庁の規則で多雪区域指定、垂直積雪量、積雪の単位荷重を確認してください。屋根の水平投影面積、勾配・雪止め・屋根形状、偏積雪を確認します。雪下ろしの慣習がある地域で垂直積雪量が 1 m を超え、雪下ろしによる低減を用いる場合は、その実況・垂直積雪量 1 m の下限・表示要件を確認します。多雪区域外でも条例等による積雪の組合せや、所定の緩勾配屋根における降雪後の降雨の割増しが必要になる場合があります。SEPIKA はこれらの適用を自動判定せず、選択した荷重ケースの内力を用います。条例等で標準形と異なる荷重組合せが必要な場合は、その組合せに対して別途照査してください。多雪区域の [Ai 地震力の階重量](../01_荷重/01_地震力.md#高さ方向分布係数-ai)への必要積雪分も別途確認・設定してください。

積雪の出典は施行令第86条、平成12年建設省告示第1455号、および『2025年版 建築物の構造関係技術基準解説書』第2版第1刷 §4.4（pp.269–271）・§5.3（pp.296–298）です。架構応力用と地震重量用の積載は施行令第85条第1項の表の別欄に対応します。同解説書 §5.2（pp.294–295）も参照してください。[平成12年建設省告示第1455号](https://www.mlit.go.jp/notice/noticedata/pdf/201703/00006501.pdf)

## 保証設計に必要な別の照査

平成19年国土交通省告示第594号第4第三号ハの表は、RC 造の保有水平耐力計算でせん断破壊を生じないものとした部材を対象とします。保証設計では部材の種類と両端ヒンジの成立に応じて設計用せん断力を求めます。梁は長期せん断力 \\(Q_0\\) を保持して地震力によるせん断力 \\(Q_M\\) に所定倍率を掛け、柱・耐力壁は告示の表に従って \\(Q_M\\) を割り増します。この照査には、同告示の適用条件、耐力式、各評価状態での地震成分、ヒンジの状態を確認する必要があります。保証設計の方法を Ds 算定時の応力で部材種別の判定に準用する場合も、保有水平耐力算定時の応力で保証設計を別途確認します。両時点で外力分布が異なる場合は、各時点に対応する分布を用います。出典は『2025年版 建築物の構造関係技術基準解説書』第2版第1刷 §6.2.4（pp.364–366）、§6.4.4（pp.427–428、431–435）です。

SEPIKA の終局検定で表示する余裕度は、選択した長期重力とヒンジ略算、または確定総応答による部材評価です。保証設計が必要な場合は、上記の地震成分・適用倍率を確認し、別途照査してください。鋼構造の塑性設計における荷重係数や限界耐力計算の極めて稀な積雪時の組合せも、この終局検定へ自動適用しません。
