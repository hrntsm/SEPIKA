# RC壁の終局せん断耐力（荒川min・mean）

壁の同じ実フェイスでの応力状態と側柱込みの断面から、参考骨格や非線形解析の初期Quに用いるせん断耐力を求めます。

対象は、両側に対称同質の正方形RC側柱を持つ、単独・無開口・矩形鉛直RC耐震壁です。[壁と側柱の適用範囲・未算定条件](08_RC壁の壁脚内力と初期耐力.md#適用範囲と未算定)を確認してください。

[荒川min／meanの設定と再計算](08_RC壁の壁脚内力と初期耐力.md#方式の選択と再計算)、[断面・配筋と壁脚内力](08_01_RC壁の耐力算定用断面と壁脚内力.md)も確認してください。

## 終局せん断耐力の方式と入力

静的解析後の参考骨格では、選択した同じケース／組合せの \\( N=N_{comp} \\)、\\( M_{face}=M_{z,O,face} \\)、\\( Q=Q_{wall} \\) を使います。非線形解析の初期Quでは、[静的一次参照で採用した応力状態](08_02_RC壁の初期耐力に用いる静的一次参照.md#初期quの静的一次参照)を次のように使い分けます。

| 算定する量 | 初期Quに使う同じ壁脚フェイスの応答 |
| --- | --- |
| 平均圧縮応力度 \\( \sigma_0 \\) | 長期参照Gの合成軸力 \\( N_G \\) |
| 正側・負側のせん断スパン比 | それぞれ直接求解した正負水平参照の壁全体 \\( M_{face}, Q \\) |
| 引張側柱・圧縮側柱の選択 | 各水平参照の局所上辺伝達力 \\( Q_w \\) の符号 |

長期参照のM/Qと水平参照のM/Qを混合せず、水平参照の軸力を \\( N_G \\) に加えません。以下の \\( N \\) は、初期Quでは \\( N_G \\) を意味します。

### 平均圧縮応力度とせん断スパン比

物理面積 \\( A \\) を使い、平均圧縮応力度を求めます。

\\[ \sigma_0 = \frac{N}{A}, \qquad 0 \leq \sigma_0 \leq 0.4F_c \\]

\\( N \\) はN、\\( A \\) はmm²、\\( \sigma_0,F_c \\) はN/mm²です。明示N=0は有効ですが、欠落を0にしません。引張Nや \\( \sigma_0>0.4F_c \\) は未算定または解析開始拒否です。0.4Fcは現在の実装域を拡張しないための条件であり、規準による適用保証ではありません。

壁全体への合成とフェイス移送を終えてからM/Qの絶対値を取り、せん断スパン比を求めます。

\\[ \lambda_{raw} = \frac{|M_{face}|}{|Q|D} \\]

\\[ \lambda = \min\left(3,\ \max\left(1,\ \lambda_{raw}\right)\right) \\]

\\( M_{face} \\) はN·mm、\\( Q \\) はN、\\( D \\) はmm、両方の \\( \lambda \\) は無次元です。\\( Q\ne0 \\) かつ \\( \lambda_{raw} \\) が0を含む有限非負値の場合に1〜3の制限を適用します。分母を有効せい \\( d \\) へ変更しません。非有限・不足・計算時入力との不一致も理由付き未算定または解析開始拒否です。他方式への切替や0耐力で補完しません。

壁脚フェイスでM=0かつQ≠0の場合、初期Quと静的参考骨格はせん断スパン比を1として評価します。初期Quの正負は上辺伝達力の符号で対応付け、参考骨格は左右同一の柱せい・主筋量で評価します。左右の側柱の寸法と配筋が同じなので、引張側・圧縮側の呼び分けによる耐力式への入力差は生じません。

この境界で壁全体の終局せん断耐力を評価するための危険断面、引張側・圧縮側の物理的な判定、軸力や端部拘束に対応する適用範囲は未確定です。反曲点が壁脚フェイスにあるときは、部材内の曲げ分布と拘束条件を含めて設計上の適用を別途確認してください。

### 荒川min／meanの終局せん断耐力

| 記号 | 意味 | 単位・条件 |
| --- | --- | --- |
| \\( F_c \\) | 壁コンクリートの設計基準強度 | N/mm²、有限正値 |
| \\( \sigma_{wh} \\) | 明示した水平横筋材料の降伏強度 | N/mm² |
| \\( c,s \\) | コンクリート項の略記、横筋・軸力項 | 採用単位による式の値（N/mm²） |
| \\( Q_{u,min},Q_{u,mean} \\) | 選択方式による壁の終局せん断耐力 | N |

断面から求めた \\( p_{te},p_{wh,e},t_e,j \\) と、壁脚内力から求めた \\( \sigma_0,\lambda \\) をつなぎます。まず二方式に共通の中間量を求めます。

\\[ c = p_{te}^{0.23}(F_c+18) \\]

\\[ s = 0.85\sqrt{p_{wh,e}\sigma_{wh}} + 0.1\sigma_0 \\]

次に選択した方式を適用します。本節の無開口壁では開口低減率は \\( r=1 \\) です。

\\[ Q_{u,min} = \left(\frac{0.053c}{\lambda+0.12}+s\right)t_ej \\]

\\[ Q_{u,mean} = \left(\frac{0.068c}{\sqrt{\lambda+0.12}}+s\right)t_ej \\]

採用係数0.053・0.068・0.85・0.1と定数18は、強度N/mm²・寸法mm・\\( p_{te} \\) の百分率・\\( p_{wh,e} \\) の小数に対応する値です。原典の単位へ入力を戻す換算や、算定後のkgf→N換算を重ねません。

方式によってコンクリート項の係数と分母を同時に変えます。minの分母は \\( \lambda+0.12 \\)、meanの分母は \\( \sqrt{\lambda+0.12} \\) です。横筋・軸力項は共通であり、Qu全体を0.068/0.053倍しません。両方式の値の大小だけでは、対象壁の安全性や設計適合を判定できません。

QuはNで算定し、画面のkN表示では1000で除します。壁脚モーメントも式にはN·mmで渡し、kN·m表示では1000000で除します。[共通の単位系](../README.md#単位系)を参照してください。上限適用後にひび割れ耐力Qc以上のQuを得られない場合、参考骨格は理由付き未算定になります。

参考骨格のQc・変形角・割線剛性比βsは[RC壁の参考骨格](../../nonlinear/05_RC_部材_非線形復元力特性.md#耐力骨格点単位)を参照してください。参考骨格は解析せん断ばねへ接続しません。

## 計算根拠と確認限界

初期モデルには静的一次参照のM/Qと長期軸力を用います。中央壁柱も軸力を負担するため、中央と両柱を同じフェイスで合成します。ピン側柱の面内Q/Mが零でも、軸力の腕長によるモーメントは合成します。フェイスへの輸送符号は本モデルの局所符号に従い、M−Qℓを無条件に適用しません。

荒川min／meanの係数・分母と、λ、D/d、等価壁厚te・物理面積Aは本文で示す組合せを採用します。M/(Qd)とσ0=N/(te D)を使う方式は、SEPIKAのDと物理Aを使う方式と区別し、式の一部を混成しません。


『2025年版 建築物の構造関係技術基準解説書』第2版第1刷、付録1-3.1(3)⑥b)、pp.715–716、
式(付1.3-32)・(付1.3-33)は、この二方式の係数・分母、D/d、等価壁厚・鉄筋比とスパン比を示します。
両式では、せん断スパン比が1未満の場合に、式に用いる比を1とします。
同書の適用説明からは、M=0の反曲点断面を壁全体の耐力評価に用いる条件や、その断面での側柱の役割は確定できません。
日本建築学会『鉄筋コンクリート構造計算規準・同解説』2024年、第10版第1刷、19条解説3(2)、pp.313–314の式(解19.9)では、
軸応力度を等価壁厚と応力中心距離の積で除した全軸力として定義します。同解説は、純せん断応力状態や柱幅が広い場合に等価長方形化で耐力を過大評価し得ることを示しています。
p.716の横筋比上限には1.2%に加えて壁板の鉛直せん断補強筋比の2倍という条件があり、
その上限を超える場合の例外には構造実験による終局強度の確認が必要です。
横筋比にはこの二つの上限を適用します。0.4Fcの圧縮上限は同頁の壁式には明記されていません。
この上限を柱のせん断式に対する0.4Fcの規定で正当化しません。引張域の適用と高圧縮域の安全性も確認できていないため、初期Quでは現在の軸応力度制限を維持します。範囲内で計算できることだけでは、個別壁の規準適合や破壊性状を保証しません。

同頁のI形断面では、引張側柱の総主筋量と圧縮側柱せいを使います。側柱のない長方形断面にはd=0.95Dと端部の曲げ補強筋量という別の定義があり、全壁の縦筋量による代用はできません。端部圧縮領域の閉鎖型補強筋による拘束が不十分な無側柱壁では、実験値と計算値の比が小さくなる傾向も示されています。側柱なしの壁は本節の初期Quの対象外とし、端部筋・拘束条件を推定して計算しません。

壁板縦横筋によるせん断補強と端部の曲げ補強筋は区別します。p.714にある壁筋比0.45%以上・周辺柱寸法等は、終局変形角からせん断剛性低下率を設定する条件であり、Qu式の一律の配筋条件へ読み替えません。p.716のFc18〜60 N/mm²の試験調査も、任意の軸力・配筋・材料域への適用を保証するものではありません。

実験による破壊・履歴・軸剛性・動的応答と全適用域のValidationは未確認です。
