# CFT 柱 終局耐力

CFT 柱は座屈長さにより短柱（\\( l\_k \le 4D \\)）、中柱（\\( 4D < l\_k \le 12D \\)）、長柱（\\( l\_k > 12D \\)）に分類します。採用モデルでは、正方形の長柱の圧縮側 Case2 を津田ほか（1999）の式(20.3)で補足します。現行規準本文との照合は未実施です。

角形 CFT の指針上の対象は正方形です。長方形断面は既存式の準用経路を持ちますが、以下の正方形長柱 Case2 の適用対象には含めません。

終局耐力が算定できても、平14国交告第464号の構造・施工条件や適用除外資格を自動判定した結果ではありません。充填材の Fc≥24 N/mm²、通常の座屈長さ／柱小径≤12、鋼管厚12 mm以上、円形径厚比50以下・角形幅厚比34以下等を別途確認してください。保有水平耐力計算等による適用除外には鋼管の実況を考慮して拘束効果を低減した計算などの条件があり、長柱や円形拘束割増の計算結果だけで除外を認定できません。

## 角部の丸みを考慮した角形CFTの曲げ耐力

同じ板厚の正方形・長方形について、外側の角丸長方形から内側のコアを除いた鋼管領域を使います。本ページでは外角半径を \\( R\_o \\)、内角半径を \\( r\_i \\) とし、単位はともに mm です。

\\[
r\_i=\max(R\_o-t,0)
\\]

\\( R\_o=0 \\) の直角モデル、\\( 0<R\_o<t \\) の外側円弧・内側直角の意味は、[許容曲げの材料領域](../06_一次設計/04_SRC_CFT_断面検定.md#角部の丸みを考慮した角形cftの曲げ耐力)と同じです。同節および藤本ほか（2009）の外角半径 \\( R \\)・内角半径 \\( r \\) に、それぞれ本ページの \\( R\_o \\)・\\( r\_i \\) が対応します。後段の無次元の座屈低減係数 \\( \chi\_b \\) とは区別します。未知・不正半径と異厚BOXは理由付き未算定です。

短柱は鋼管に引張・圧縮降伏応力、コアの圧縮部分に一様Fcを作用させ、同じ領域から材料別のNとMを求めます。中立軸が角部やコア外を横切る場合も鋼管全領域で積分し、全引張・全圧縮まで設計軸力との釣合いを求めます。中柱・長柱は同じ領域のA・同一検討軸のI・塑性断面係数を既採用の柱耐力式へ渡します。

藤本利昭ほか「断面形状を考慮した角形CFT柱の設計式」（日本建築学会技術報告集15巻31号、2009、pp.757–760）§3.2の式(23)–(26)は、本ページの記号で \\( r\_i\le x\_n\le{}\_cD-r\_i \\) を明記します。同心等厚の \\( R\_o\ge t \\) でその重複域を照合し、角部内・コア外の中立軸と \\( 0<R\_o<t \\) は同じ応力ブロックの領域積分で補います。式(22)(27)は中長柱のコア曲げ基準値・鋼管塑性断面係数へ接続します。

正の外角半径 \\( R\_o \\) を持つ中柱・長柱は \\( F\_c\le58.8399 \\) N/mm²、\\( l\_k/D\le30 \\) を計算範囲とし、これを超える場合は理由付き未算定です。短柱と既存の \\( R\_o=0 \\)・円形の範囲は各採用式に従います。\\( 0<R\_o<t \\) と長方形の中長柱は実輪郭と既採用柱曲線の準用モデルです。正方形の指針適用と同じ保証を与えず、面外・横座屈を別途確認してください。外角半径を変えた幾何・耐力の連続性、数値積分との一致、規準適合性、実験的妥当性は別々の確認事項です。円弧を厳密積分しても、座屈曲線や中柱補間などの経験近似まで厳密にはなりません。

軸終局の判定と曲げの算定状態は別です。条件不足・適用域外・数値不成立をMu=0や全項目適合へ補完しません。GUIと既存出力はMu又は未算定理由を示し、軸OKだけで曲げを含む全適合とは扱いません。半径・断面・材料の編集後は再計算してください。

## 記号・単位と算定式

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( l\_k \\) | 座屈長さ | mm |
| \\( D \\) | 鋼管の断面せい | mm |
| \\( N\_{cu1} \\) | 短柱の軸終局耐力 | N |
| \\( {}\_c A, {}\_s A \\) | 充填コンクリート・鋼管の断面積 | mm² |
| \\( F\_c \\) | コンクリートの設計基準強度 | N/mm² |
| \\( F\_y \\) | 鋼管の基準強度（降伏強度） | N/mm² |
| \\( \xi \\) | 円形 CFT の拘束効果による強度割増係数（角形 0） | - |
| \\( {}\_c \sigma\_{cr} \\) | 充填コンクリートの座屈応力 | N/mm² |
| \\( {}\_c \lambda\_1 \\) | 充填コンクリートの規準化細長比 | - |
| \\( R\_o, r\_i \\) | 角形の外角半径・内角半径 | mm |
| \\( \chi\_b \\) | 中柱・長柱の座屈低減係数 | 無次元 |
| \\( M\_u \\) | N-M 相互作用による終局曲げ耐力 | N·mm |
| \\( {}\_s N\_{cr} \\) | 鋼管の座屈耐力 | N |
| \\( {}\_s \lambda\_1 \\) | 鋼管の規準化細長比 | - |
| \\( \beta\_t \\) | 軸引張終局耐力の引張低減係数（1.0） | 無次元 |
| \\( \beta\_{c1},\beta\_{c2} \\) | 円形短柱の鋼管応力係数（順に 0.89、−1.08） | 無次元 |
| \\( N,N\_{cu},N\_{tu} \\) | 圧縮正の設計軸力、圧縮耐力、引張耐力の大きさ | N |
| \\( N\_k,{}\_sN\_E \\) | 合成断面の座屈補助軸力、鋼管単体のオイラー荷重 | N |
| \\( {}\_cI,{}\_sI \\) | コア・鋼管の断面二次モーメント | mm⁴ |
| \\( {}\_cZ\_p,{}\_sZ\_p \\) | コア・鋼管の塑性断面係数 | mm³ |

軸引張係数 \\( \beta\_t \\) は軸引張式での \\( \beta\_2 \\)、円形応力係数 \\( \beta\_{c1},\beta\_{c2} \\) は円形短柱式での \\( \beta\_1,\beta\_2 \\) に対応するよう、用途を添字で区別します。原典の採用値・適用条件の確認範囲は各節の記述に従います。

**算定式**:

- 短柱軸終局は次式によります。

\\[
N\_{cu1}={}\_cAF\_c+(1+\xi){}\_sAF\_y,\qquad
\xi=\begin{cases}0.27&\text{円形}\\\\0&\text{角形}\end{cases}
\\]

- コンクリート座屈応力 \\( {}\_c \sigma\_{cr} \\)（規準化細長比 \\( {}\_c \lambda\_1 \\) の 2 分岐、\\( {}\_c \lambda\_1 = 1 \\) で連続）
- N-M 相互作用（角形・円形の耐力曲面）を用います。中柱・長柱は座屈の影響を考慮し、正方形長柱の Case2 は[該当節](#正方形の長柱-case2)の式によります。角形短柱の鋼管曲げ耐力の第 2 項は、[短柱のN–M](#短柱のnm)に示す、中立軸におけるウェブ 2 枚の全塑性モーメントです。
- 鋼管の座屈耐力 \\( {}\_sN\_{cr} \\) の分岐条件は鋼管細長比 \\( {}\_s\lambda\_1 \\) で評価します。軸引張係数は角形・円形とも \\( \beta\_t=1.0 \\)（鋼管全断面降伏）です。円形の拘束割増 \\( \xi=0.27 \\)、短柱N–Mの鋼管応力係数 \\( \beta\_{c1}=0.89,\ \beta\_{c2}=-1.08 \\)、充填材割増係数 0.78 はそれぞれ別の係数であり、相互に置換しません。これら円形モデル全体および中柱・Case1・長方形準用の規準適用条件の確認は完了していません。

## 材料・寸法と軸終局耐力の選択

充填コンクリートのFcと鋼管材料のFyを別に指定します。鋼管のFyは鋼種名と板厚または有効な入力強度から採用し、欠落・不正な材料はエラーとします。
座屈長さlkは部材の幾何長（K=1相当）、鋼管ヤング係数sEは205000 N/mm²です。柱分類の代表Dは角形では幅とせいの小さい方、円形では外径です。軸終局のcI・sIは各材料の2軸の小さい断面二次モーメントを用います。

圧縮正の軸力Nに対し、圧縮耐力Ncuと引張耐力の大きさNtuを次により算定します。

\\[
N\_{cu}=\begin{cases}
N\_{cu1}&l\_k/D\le4\\\\
\max\\{N\_{cu1}-0.125(N\_{cu1}-N\_{cu3}|\_{l\_k=12D})(l\_k/D-4),0\\}&4<l\_k/D\le12\\\\
N\_{cu3}={}\_cN\_{cr}+{}\_sN\_{cr}&l\_k/D>12
\end{cases},\qquad N\_{tu}=\beta\_t{}\_sAF\_y,\quad\beta\_t=1.0
\\]

中柱の補間に使うNcu3は実長でなくlk=12Dで再評価します。cNcr・sNcrの全分岐は後段の[長柱Case2](#正方形の長柱-case2)と同じです。軸余裕度は圧縮時Ncu/N、引張時Ntu/|N|、N=0では上限なしです。これは軸のみの判定です。

## 短柱のN–M

以下は採用中の耐力曲線であり、現行規準の全適用条件の確認は未完了です。曲げ面の鋼管せい \\( D \\)・幅 \\( B \\)・板厚 \\( t \\)、コアせい \\( {}\_cD=D-2t \\)・幅 \\( {}\_cB=B-2t \\) を mm で用います。曲げ面を変える場合は幅とせいを交換します。柱分類の代表せいは前節のままとし、曲げ用の断面二次モーメントと座屈荷重は同じ検討軸・座屈長さを用います。

直角の角形で中立軸がコア内にある場合は、コア圧縮縁からの中立軸深さxn [mm]に対し次のNとMの和へ一致します。

\\[
{}\_cN=x\_n{}\_cBF\_c,\qquad {}\_cM=\tfrac12x\_n{}\_cB({}\_cD-x\_n)F\_c
\\]
\\[
{}\_sN=2t(2x\_n-{}\_cD)F\_y,\qquad
{}\_sM=Bt(D-t)F\_y+2tx\_n({}\_cD-x\_n)F\_y,\qquad
N={}\_cN+{}\_sN,\quad M={}\_cM+{}\_sM
\\]

円形はパラメータ角 \\( 0\le\theta\le\pi \\) [rad] を用います。コア半径 \\( r\_1 \\)・鋼管板厚中心の半径 \\( r\_2 \\) [mm] と、コア圧縮応力度 \\( \sigma\_c \\) [N/mm²] を先に定めます。

\\[
r\_1=\frac{{}\_cD}{2},\qquad r\_2=\frac{D-t}{2},\qquad
\sigma\_c=F\_c+0.78\frac{2t}{D-2t}F\_y
\\]

\\[
{}\_cN=r\_1^2(\theta-\sin\theta\cos\theta)\sigma\_c,\qquad
{}\_cM=\tfrac23r\_1^3\sin^3\theta\\,\sigma\_c
\\]
\\[
{}\_sN=2r\_2t\\{\beta\_{c1}\theta-\beta\_{c2}(\theta-\pi)\\}F\_y,\qquad
{}\_sM=2r\_2^2t(\beta\_{c1}-\beta\_{c2})\sin\theta\\,F\_y
\\]

\\[
\beta\_{c1}=0.89,\qquad\beta\_{c2}=-1.08
\\]

角部を含む角形は図心から正側への座標zと中立軸zₙを用います。圧縮側の切断面積をA⁺、一次モーメントをQ⁺とすると、材料別の力は次式です。

\\[
{}\_cN=F\_c{}\_cA^+,\quad {}\_cM=F\_c{}\_cQ^+,\qquad
{}\_sN=F\_y(2{}\_sA^+-{}\_sA),\quad {}\_sM=2F\_y{}\_sQ^+
\\]

コアは圧縮だけ、鋼管は中立軸の両側で±Fyです。円弧境界で分けた解析積分を使い、軸力釣合いから中立軸を探索します。全引張N=−sAFy、全圧縮N=cAFc+sAFyではMu=0となります。全鋼管領域を評価するためコア外の中立軸も連続に扱います。角形の当該柱分類の軸限界を超える需要は軸NGで、Muも理由付き未算定とします。

NはN、MはN·mmです。円形は従来のθ曲線と、その端点から(Ncu1,0)又は(−Ntu,0)への直線補間を用います。いずれも軸限界超過を許容するものではありません。

## 中柱・長柱のN–M（Case2以外）

正方形長柱かつ \\( N>{}\_cN\_{cr} \\) の場合は、[正方形の長柱 Case2](#正方形の長柱-case2)を優先します。同節の計算範囲・有効域を満たさない場合は理由付き未算定とし、以下の補間式へ切り替えません。

以下はそれ以外の中柱・長柱に用いる採用式です。正の外角半径 \\( R\_o \\) を持つ角形は、\\( F\_c\le58.8399 \\) N/mm²、\\( l\_k/D\le30 \\) の計算範囲を超えると理由付き未算定です。長方形は準用モデルであり、円形拘束係数や中柱・Case1・長方形準用の規準適用条件は未確認です。正方形長柱 Case2 の限定的な根拠確認を、これらの式へ拡張しないでください。

### 共通の中間量

座屈低減係数を \\( \chi\_b \\)、鋼管単体の全塑性曲げ耐力を \\( {}\_sM\_{u0} \\) とします。\\( \chi\_b \\) は座屈低減式の \\( R \\) に対応します。\\( N\_k,{}\_c\lambda\_1,{}\_cN\_{cr} \\) は[次節の座屈荷重・細長比の式](#正方形の長柱-case2)で、同じ検討軸・実際の座屈長さを用いて求めます。

\\[
\chi\_b=\max\left\\{1-\frac{{}\_cN\_{cr}}{N\_k},0\right\\}
\\]

\\( N\_k \\) が正の有限値として得られない場合は \\( \chi\_b=1 \\) とします。この数値処理は、座屈の影響がないことを確認した結果ではありません。正方形長柱 Case2 にはこの補完を適用しません。

\\[
{}\_sM\_{u0}=\begin{cases}
{}\_sZ\_p F\_y&\text{角形}\\\\
4r\_2^2tF\_y&\text{円形}
\end{cases}
\\]

\\[
C\_b=0.923-0.0045F\_c,\quad
{}\_cM\_{max}=\frac{C\_b}{C\_b+{}\_c\lambda\_1^2}{}\_cM\_{max0},\quad
{}\_cM\_{max0}=\begin{cases}F\_c{}\_cZ\_p/2&\text{角形}\\\\F\_c({}\_cD)^3/12&\text{円形}\end{cases}
\\]

\\( C\_b \\) は無次元、\\( {}\_cM\_{max},{}\_cM\_{max0} \\) は N·mm です。分母 \\( C\_b+{}\_c\lambda\_1^2\le0 \\) なら \\( {}\_cM\_{max}=0 \\) とします。角形の \\( {}\_sZ\_p,{}\_cZ\_p \\) は同じ検討軸の材料領域の塑性断面係数です。直角コアでは次式となり、長方形でも幅を反映します。

\\[
{}\_cM\_{max0}=\frac{F\_c{}\_cB({}\_cD)^2}{8}
\\]

\\[
{}\_cM(N)=\max\left\\{4\frac{N}{0.9{}\_cN\_{cr}}\left(1-\frac{N}{0.9{}\_cN\_{cr}}\right){}\_cM\_{max},0\right\\}
\\]

\\( {}\_cN\_{cr}=0 \\) なら \\( {}\_cM(N)=0 \\) とします。以下の各式は \\( M\_u \\) [N·mm] を求め、負の曲げ耐力は 0 に制限します。不正な断面寸法・材料強度・設計軸力、又は有限値として求まらない曲げ耐力は理由付き未算定です。

### 引張側：中柱・長柱、N < 0

\\[
M\_u=\chi\_b{}\_sM\_{u0}\max\left\\{\frac{N+N\_{tu}}{N\_{tu}},0\right\\},\qquad N<0
\\]

分母 \\( N\_{tu}=0 \\) の場合は \\( M\_u=0 \\) とします。\\( N\_{tu} \\) は[軸終局耐力の式](#材料寸法と軸終局耐力の選択)による正の大きさであり、引張軸力そのものの符号とは区別します。

### Case1：中柱・長柱、0 ≤ N ≤ cNcr

\\[
M\_u=\max\\{{}\_cM(N)+\chi\_b{}\_sM\_{u0},0\\},\qquad 0\le N\le{}\_cN\_{cr}
\\]

\\( N={}\_cN\_{cr} \\) は本分岐に含み、正方形長柱でも Case2 へは進みません。

### 圧縮側：円形長柱、N > cNcr

円形長柱では、板厚中心の半径 \\( r\_2=(D-t)/2 \\) [mm] を用い、パラメータ角 \\( \theta \\) [rad] を次式で求めます。短柱の軸力釣合いで定める角度とは別の算定式です。

\\[
\theta=\min\left\\{\frac{\pi}{2}+\frac{N-{}\_cN\_{cr}}{4r\_2tF\_y},\pi\right\\}
\\]

\\[
M\_u=\max\\{4r\_2^2tF\_y\chi\_b\sin\theta,0\\},\qquad
N>{}\_cN\_{cr},\quad l\_k/D>12\quad(\text{円形})
\\]

角度式の分母 \\( 4r\_2tF\_y\le0 \\) の場合は \\( M\_u=0 \\) とする数値処理があります。寸法・強度の不正による未算定を、この 0 で補完するものではありません。

### 圧縮側：中柱・長方形長柱、N > cNcr

中柱は角形・円形とも次式を用います。長柱で本分岐を用いるのは長方形だけであり、正方形長柱には Case2、円形長柱には直前の式を用います。

\\[
M\_u=\chi\_b{}\_sM\_{u0}\max\left\\{1-\frac{N-{}\_cN\_{cr}}{N\_{cu}-{}\_cN\_{cr}},0\right\\},\qquad N>{}\_cN\_{cr}
\\]

\\( N\_{cu} \\) は[当該柱分類の軸圧縮終局耐力](#材料寸法と軸終局耐力の選択)です。分母 \\( N\_{cu}-{}\_cN\_{cr}\le0 \\) なら理由付き未算定です。中柱の軸耐力で用いる \\( l\_k=12D \\) での補間端点と、本節の実長による中間量を混同しないでください。

## 正方形の長柱 Case2

対象は既存の材料・幅厚比の適用域内にある正方形の断面で、\\( F\_c \le 58.8399 \\) N/mm²、\\( 12 < l\_k/D \le 30 \\) とします。圧縮を正とし、\\( N > {}\_cN\_{cr} \\) のとき、\\( {}\_cN\_{cu}={}\_cN\_{cr} \\)、\\( \Delta N=N-{}\_cN\_{cr} \\) を用いて算定します。

\\[
C\_M M\_u =
\left(1-\frac{\Delta N}{{}\_sN\_{cr}}\right)
\left(1-\frac{\Delta N}{{}\_sN\_E}\right)
\left(1-\frac{{}\_cN\_{cr}}{N\_k}\right){}\_sM\_{u0},
\qquad {}\_sM\_{u0}={}\_sZ\_pF\_y
\\]

鋼管単体の降伏軸力・オイラー荷重と座屈耐力は次のとおりです。終局耐力用の鋼管ヤング係数は 205000 N/mm² を用います。

\\[
{}\_sN\_y={}\_sAF\_y,\qquad
{}\_sN\_E=\frac{\pi^2{}\_sE{}\_sI}{l\_k^2},\qquad
{}\_s\lambda\_1=\sqrt{\frac{{}\_sN\_y}{{}\_sN\_E}}
\\]

\\[
{}\_sN\_{cr}=\begin{cases}
{}\_sN\_y & {}\_s\lambda\_1<0.3\\\\
\\{1-0.545({}\_s\lambda\_1-0.3)\\}{}\_sN\_y & 0.3\le{}\_s\lambda\_1<1.3\\\\
{}\_sN\_E/1.3 & 1.3\le{}\_s\lambda\_1
\end{cases}
\\]

境界 1.3 の左右に生じる微小差は補間しません。分岐にはコンクリートの規準化細長比 \\( {}\_c\lambda\_1 \\) を用いません。

\\[
N\_k=\frac{\pi^2({}\_cE^{\prime}{}\_cI/5+{}\_sE{}\_sI)}{l\_k^2},\qquad
{}\_cE^{\prime}=(3.32\sqrt{F\_c}+6.90)\times10^3\ \mathrm{N/mm^2},\qquad C\_M=1
\\]

\\( C\_M=1 \\) は節点移動がある場合の採用条件です。\\( 1/C\_M \\) は乗算係数です。
\\( {}\_cE^{\prime} \\) は解析用コンクリートのヤング係数と別の値で、コンクリート剛性には 1/5 を乗じます。合成断面の \\( N\_k \\) を鋼管単体の \\( {}\_sN\_E \\) に代用しません。

コンクリートの座屈耐力は、同じ検討軸・座屈長さ・断面を用い、次式により求めます。

\\[
{}\_cN\_{cr}={}\_c\sigma\_{cr}{}\_cA,\quad
{}\_c\lambda\_1=\frac{l\_k}{\pi\sqrt{{}\_cI/{}\_cA}}\sqrt{\varepsilon\_u},\quad
\varepsilon\_u=0.93F\_c^{1/4}\times10^{-3},\quad C\_c=0.568+0.00612F\_c
\\]

\\[
\frac{{}\_c\sigma\_{cr}}{F\_c}=\begin{cases}
2/(1+\sqrt{{}\_c\lambda\_1^4+1}) & {}\_c\lambda\_1\le1\\\\
2(\sqrt2-1)\exp\\{C\_c(1-{}\_c\lambda\_1)\\} & {}\_c\lambda\_1>1
\end{cases}
\\]

軸力・座屈荷重は N、面積は mm²、断面二次モーメントは mm⁴、塑性断面係数は mm³、長さは mm、強度とヤング係数は N/mm²、曲げ耐力は N·mm です。\\( C\_M,{}\_c\lambda\_1,{}\_s\lambda\_1 \\) は無次元です。

### 有効域と結果の読み方

\\( 0<\Delta N\le{}\_sN\_{cr}\le{}\_sN\_E \\)、\\( {}\_cN\_{cr}<N\_k \\)、\\( C\_M>0 \\) を同じ検討軸・座屈長さで満たす場合に用います。
純圧縮限界 \\( N={}\_cN\_{cr}+{}\_sN\_{cr} \\) では \\( M\_u=0 \\) です。限界超過は軸 NG とし、負の二因子の積や切り詰め処理で正の曲げ耐力を復活させません。
無効寸法・非有限値・無効な座屈荷重・上記適用範囲外は理由付き未算定とし、既知の軸 NG と算定条件を満たさない状態を区別します。

中柱・円形・Case1・引張と長方形の算定範囲はこの Case2 式の対象外です。角部形状を含む適用条件は前述の材料領域・準用範囲に従います。
これらの耐力式の維持と、静的解析の軸力を圧縮正の設計軸力へ変換する共通契約は別です。[設計軸力と保存結果](07_終局検定の統括.md#設計軸力の符号と保存結果)に従い、RC・CFT の静的終局需要へは符号を一度だけ変換し、既に圧縮正の増分軸力は反転しません。
曲げ耐力が小さくなると、それを用いる QD1/min の要求せん断力も小さくなり得るため、曲げ耐力だけで安全側とは判定できません（[一次設計への適用](../06_一次設計/04_SRC_CFT_断面検定.md#cft-柱の地震時設計用せん断)）。
