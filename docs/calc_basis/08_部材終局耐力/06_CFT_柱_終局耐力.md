# CFT 柱 終局耐力

CFT 柱は座屈長さにより短柱（\\( l_k \le 4D \\)）、中柱（\\( 4D < l_k \le 12D \\)）、長柱（\\( l_k > 12D \\)）に分類します。採用モデルでは、正方形・角R=0 の長柱の圧縮側 Case2 を津田ほか（1999）の式(20.3)で補足します。現行規準本文との照合は未実施です。

角形 CFT の指針上の対象は正方形です。長方形断面は既存式の準用経路を持ちますが、以下の正方形長柱 Case2 の適用対象には含めません。

終局耐力が算定できても、平14国交告第464号の構造・施工条件や適用除外資格を自動判定した結果ではありません。充填材の Fc≥24 N/mm²、通常の座屈長さ／柱小径≤12、鋼管厚12 mm以上、円形径厚比50以下・角形幅厚比34以下等を別途確認してください。保有水平耐力計算等による適用除外には鋼管の実況を考慮して拘束効果を低減した計算などの条件があり、長柱や円形拘束割増の計算結果だけで除外を認定できません。

## 角Rが正の角形 CFT

軸終局耐力は、鋼管とコアそれぞれの実形状の面積と断面二次モーメントで算定します。
終局 N–M は角Rが正の場合に未対応とし、Mu を理由付き未算定とします。
内角Rが 0 の場合も、鋼管に角Rがあればこのゲートの対象です。
軸終局の判定と曲げの算定状態は別に保持し、軸が OK であることを曲げを含む全適合として表示しません。

曲げ耐力Muは「未算定」と理由を表示します。軸終局の判定と曲げ耐力の算定状態を分け、軸の満足を曲げを含む全適合として扱いません。
角Rが未知・不正で軸終局用の材料領域も求められない場合はエラーとなります。未対応をMu=0として補完しません。
角形のN–M式は鋼管・コアとも直角形状で、一様板厚を前提とします。異厚BOXの曲げ終局耐力も未対応です。

## 記号・単位と算定式

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( l\_k \\) | 座屈長さ | mm |
| \\( D \\) | 鋼管の断面せい | mm |
| \\( N\_{cu1} \\) | 短柱の軸終局耐力 | N |
| \\( {}\_c A, {}\_s A \\) | 充填コンクリート・鋼管の断面積 | mm² |
| \\( F\_c \\) | コンクリートの設計基準強度 | N/mm² |
| \\( F\_y \\) | 鋼管の基準強度（降伏強度） | N/mm² |
| \\( \xi \\) | 円形 CFT の拘束効果による強度割増係数（角形 0） | - |
| \\( {}\_c \sigma\_{cr} \\) | 充填コンクリートの座屈応力 | N/mm² |
| \\( {}\_c \lambda\_1 \\) | 充填コンクリートの規準化細長比 | - |
| \\( R \\) | 中柱・長柱の座屈低減係数 | - |
| \\( M\_u \\) | N-M 相互作用による終局曲げ耐力 | N·mm |
| \\( {}\_s N\_{cr} \\) | 鋼管の座屈耐力 | N |
| \\( {}\_s \lambda\_1 \\) | 鋼管の規準化細長比 | - |
| \\( \beta\_2 \\) | 軸引張終局耐力の引張低減係数（1.0） | - |

**算定式**:

- 短柱軸終局 \\( N\_{cu1} = {}\_c A \cdot F\_c + (1+\xi) \cdot {}\_s A \cdot F\_y \\)（ξ = 円形0.27/角形0）
- コンクリート座屈応力 \\( {}\_c \sigma\_{cr} \\)（規準化細長比 \\( {}\_c \lambda\_1 \\) の 2 分岐、\\( {}\_c \lambda\_1 = 1 \\) で連続）
- N-M 相互作用（角形・円形の (Nu, Mu) 曲面）を用いる。中柱・長柱は座屈の影響を考慮し、正方形長柱の Case2 は次節の式による。角形の鋼管曲げ耐力 `sMu` の第 2 項は、中立軸におけるウェブ 2 枚の全塑性モーメント `2t·xn·(cD−xn)·Fy` とする。
- 鋼管の座屈耐力 `sNcr` の分岐条件は鋼管細長比 `sλ1` で評価する。軸引張終局耐力の引張低減係数は角形・円形とも `β2 = 1.0`（鋼管全断面降伏）とする。円形の拘束割増 ξ=0.27 と、短柱N–Mの鋼管応力係数 β1=0.89・β2=−1.08、充填材割増係数0.78はそれぞれ別の係数であり、相互に置換しない。これら円形モデル全体および中柱・Case1・長方形準用の規準適用条件の確認は完了していません。

## 材料・寸法と軸終局耐力の選択

充填コンクリートのFcと鋼管材料のFyを別に指定します。鋼管のFyは鋼種名と板厚または有効な入力強度から採用し、欠落・不正な材料はエラーとします。
座屈長さlkは部材の幾何長（K=1相当）、鋼管ヤング係数sEは205000 N/mm²です。柱分類の代表Dは角形では幅とせいの小さい方、円形では外径です。軸終局のcI・sIは各材料の2軸の小さい断面二次モーメントを用います。

圧縮正の軸力Nに対し、圧縮耐力Ncuと引張耐力の大きさNtuを次により算定します。

\\[
N_{cu}=\begin{cases}
N_{cu1}&l_k/D\le4\\\\
\max\\{N_{cu1}-0.125(N_{cu1}-N_{cu3}|_{l_k=12D})(l_k/D-4),0\\}&4<l_k/D\le12\\\\
N_{cu3}={}_cN_{cr}+{}_sN_{cr}&l_k/D>12
\end{cases},\qquad N_{tu}={}_sAF_y
\\]

中柱の補間に使うNcu3は実長でなくlk=12Dで再評価します。cNcr・sNcrの全分岐は後段の[長柱Case2](#正方形角r0-の長柱-case2)と同じです。軸余裕度は圧縮時Ncu/N、引張時Ntu/|N|、N=0では上限なしです。これは軸のみの判定です。

## 短柱のN–M

以下は採用中の耐力曲線であり、現行規準の全適用条件の確認は未完了です。曲げ面の鋼管せいD・幅B・板厚t、コアせいcD=D−2t・幅cB=B−2tをmmで用います。曲げ面を変える場合は幅とせいを交換しますが、柱分類と座屈の代表性能は前節のままという近似です。

角形は圧縮縁からの中立軸深さxn [mm]を0〜cDとして、次のNとMの和を使います。

\\[
{}_cN=x_n{}_cBF_c,\qquad {}_cM=\tfrac12x_n{}_cB({}_cD-x_n)F_c
\\]
\\[
{}_sN=2t(2x_n-{}_cD)F_y,\qquad
{}_sM=Bt(D-t)F_y+2tx_n({}_cD-x_n)F_y,\qquad
N={}_cN+{}_sN,\quad M={}_cM+{}_sM
\\]

円形はθ [rad]を0〜πとして次を用います。r1=cD/2、r2=(D−t)/2 [mm]、σc=Fc+0.78{2t/(D−2t)}Fy [N/mm²]です。

\\[
{}_cN=r_1^2(\theta-\sin\theta\cos\theta)\sigma_c,\qquad
{}_cM=\tfrac23r_1^3\sin^3\theta\\,\sigma_c
\\]
\\[
{}_sN=2r_2t\\{\beta_1\theta-\beta_2(\theta-\pi)\\}F_y,\qquad
{}_sM=2r_2^2t(\beta_1-\beta_2)\sin\theta\\,F_y,\quad
\beta_1=0.89,\quad\beta_2=-1.08
\\]

NはN、MはN·mmです。設計軸力に対応する中立軸またはθからMuを求めます。曲線の軸力区間外は各端点と(Ncu1,0)または(−Ntu,0)を直線補間し、負の曲げ耐力を0とします。端点と軸限界の間に補間区間が成立しなければ0です。この切り詰めで軸限界超過を許容するものではありません。

## 中柱・長柱のN–M（Case2以外）

正方形長柱かつN>cNcrの場合は次節のCase2を優先し、ここで示す補間式を用いません。
その他の中柱・長柱は、R=max(1−cNcr/Nk,0)と、鋼管単体の全塑性曲げ耐力sMu0を使います。

\\[
{}_sM_{u0}=\begin{cases}
Bt(D-t)F_y+t({}_cD)^2F_y/2&\text{角形}\\\\
4r_2^2tF_y&\text{円形}
\end{cases}
\\]

\\[
C_b=0.923-0.0045F_c,\quad
{}_cM_{max}=\frac{C_b}{C_b+{}_c\lambda_1^2}{}_cM_{max0},\quad
{}_cM_{max0}=\begin{cases}F_c({}_cD)^3/8&\text{角形}\\\\F_c({}_cD)^3/12&\text{円形}\end{cases}
\\]

Cbは無次元、cMmax・cMmax0はN·mmです。Cb+cλ1²が0以下ならcMmax=0とします。角形のcMmax0は長方形でもcDの3乗を用いる現在の準用式であり、全長方形断面への適合を保証しません。

\\[
{}_cM(N)=\max\left\\{4\frac{N}{0.9{}_cN_{cr}}\left(1-\frac{N}{0.9{}_cN_{cr}}\right){}_cM_{max},0\right\\}
\\]

cNcrが0ならcM(N)=0です。採用分岐は次のとおりです（曲げ耐力の負値は0）。

| 軸力・形状の条件 | Mu [N·mm] |
| --- | --- |
| N<0 | R sMu0 max{(N+Ntu)/Ntu,0}。Ntu=0なら0 |
| 0≤N≤cNcr（Case1） | cM(N)+R sMu0 |
| N>cNcr、円形長柱 | max{4r2²tFy R sinθ,0}、θ=min{π/2+(N−cNcr)/(4r2tFy),π} |
| N>cNcr、その他の中柱・長方形長柱 | R sMu0 max{1−(N−cNcr)/(Ncu−cNcr),0}。Ncu≤cNcrなら0 |

Nk・cλ1・cNcrの定義は次節に示します。Nkが正の有限値として得られない場合のR=1という数値処理も、座屈の影響がないことを確認した結果ではありません。
円形拘束係数や中柱・Case1・長方形準用の規準適用条件は未確認です。正方形長柱Case2の限定的な根拠確認を、これらの式へ拡張しないでください。

## 正方形・角R=0 の長柱 Case2

対象は既存の材料・幅厚比の適用域内にある正方形・角R=0 の断面で、\\( F\_c \le 58.8399 \\) N/mm²、\\( 12 < l\_k/D \le 30 \\) とします。圧縮を正とし、\\( N > {}\_cN\_{cr} \\) のとき、\\( {}\_cN\_{cu}={}\_cN\_{cr} \\)、\\( \Delta N=N-{}\_cN\_{cr} \\) を用いて算定します。

\\[
C\_M M\_u =
\left(1-\frac{\Delta N}{{}\_sN\_{cr}}\right)
\left(1-\frac{\Delta N}{{}\_sN\_E}\right)
\left(1-\frac{{}\_cN\_{cr}}{N\_k}\right){}\_sM\_{u0},
\qquad {}\_sM\_{u0}={}\_sZ\_pF\_y
\\]

鋼管単体の降伏軸力・オイラー荷重と座屈耐力は次のとおりです。終局耐力用の鋼管ヤング係数は 205000 N/mm² を用います。

\\[
{}\_sN\_y={}\_sAF\_y,\qquad
{}\_sN\_E=\frac{\pi^2{}\_sE{}\_sI}{l\_k^2},\qquad
{}\_s\lambda\_1=\sqrt{\frac{{}\_sN\_y}{{}\_sN\_E}}
\\]

\\[
{}\_sN\_{cr}=\begin{cases}
{}\_sN\_y & {}\_s\lambda\_1<0.3\\\\
\\{1-0.545({}\_s\lambda\_1-0.3)\\}{}\_sN\_y & 0.3\le{}\_s\lambda\_1<1.3\\\\
{}\_sN\_E/1.3 & 1.3\le{}\_s\lambda\_1
\end{cases}
\\]

境界 1.3 の左右に生じる微小差は補間しません。分岐にはコンクリートの規準化細長比 \\( {}\_c\lambda\_1 \\) を用いません。

\\[
N\_k=\frac{\pi^2({}\_cE^{\prime}{}\_cI/5+{}\_sE{}\_sI)}{l\_k^2},\qquad
{}\_cE^{\prime}=(3.32\sqrt{F\_c}+6.90)\times10^3\ \mathrm{N/mm^2},\qquad C\_M=1
\\]

\\( C\_M=1 \\) は節点移動がある場合の採用条件です。\\( 1/C\_M \\) は乗算係数です。
\\( {}\_cE^{\prime} \\) は解析用コンクリートのヤング係数と別の値で、コンクリート剛性には 1/5 を乗じます。合成断面の \\( N\_k \\) を鋼管単体の \\( {}\_sN\_E \\) に代用しません。

コンクリートの座屈耐力は、同じ検討軸・座屈長さ・断面を用い、次式により求めます。

\\[
{}\_cN\_{cr}={}\_c\sigma\_{cr}{}\_cA,\quad
{}\_c\lambda\_1=\frac{l\_k}{\pi\sqrt{{}\_cI/{}\_cA}}\sqrt{\varepsilon\_u},\quad
\varepsilon\_u=0.93F\_c^{1/4}\times10^{-3},\quad C\_c=0.568+0.00612F\_c
\\]

\\[
\frac{{}\_c\sigma\_{cr}}{F\_c}=\begin{cases}
2/(1+\sqrt{{}\_c\lambda\_1^4+1}) & {}\_c\lambda\_1\le1\\\\
2(\sqrt2-1)\exp\\{C\_c(1-{}\_c\lambda\_1)\\} & {}\_c\lambda\_1>1
\end{cases}
\\]

軸力・座屈荷重は N、面積は mm²、断面二次モーメントは mm⁴、塑性断面係数は mm³、長さは mm、強度とヤング係数は N/mm²、曲げ耐力は N·mm です。\\( C\_M,{}\_c\lambda\_1,{}\_s\lambda\_1 \\) は無次元です。

### 有効域と結果の読み方

\\( 0<\Delta N\le{}\_sN\_{cr}\le{}\_sN\_E \\)、\\( {}\_cN\_{cr}<N\_k \\)、\\( C\_M>0 \\) を同じ検討軸・座屈長さで満たす場合に用います。
純圧縮限界 \\( N={}\_cN\_{cr}+{}\_sN\_{cr} \\) では \\( M\_u=0 \\) です。限界超過は軸 NG とし、負の二因子の積や切り詰め処理で正の曲げ耐力を復活させません。
無効寸法・非有限値・無効な座屈荷重・上記適用範囲外は理由付き未算定とし、既知の軸 NG と算定条件を満たさない状態を区別します。

中柱・円形・Case1・引張と長方形の算定範囲はこの Case2 式の対象外です。正の角Rは前述の未対応条件に従います。
これらの耐力式の維持と、静的解析の軸力を圧縮正の設計軸力へ変換する共通契約は別です。[設計軸力と保存結果](07_終局検定の統括.md#設計軸力の符号と保存結果)に従い、RC・CFT の静的終局需要へは符号を一度だけ変換し、既に圧縮正の増分軸力は反転しません。
曲げ耐力が小さくなると、それを用いる QD1/min の要求せん断力も小さくなり得るため、曲げ耐力だけで安全側とは判定できません（[一次設計への適用](../06_一次設計/04_SRC_CFT_断面検定.md#cft-柱の地震時設計用せん断)）。
