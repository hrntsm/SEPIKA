# 部材終局耐力

本章は、保有水平耐力計算、終局検定、非線形解析で用いる部材終局耐力の算定式と出典をまとめます。
対象は、曲げ Mu、曲げ終局時せん断 Qmu、終局せん断 Qsu、付着割裂 Qbu、軸終局 Nu、接合部終局、壁の初期耐力、CFT 終局です。

採用式・材料強度・適用条件は各頁で示します。規準原本の未照合範囲や近似が残るため、数値が得られることだけでは対象部材の規準適合・設計への採用を保証しません。SRC/SRRCの部材せん断終局検定は未対応です。

| 結果の用途 | 読み方・正本 |
| --- | --- |
| 部材耐力 | 本章の式で材料・形状・軸力等から算定する抵抗値 |
| 骨格・履歴 | [非線形モデル・復元力](../../nonlinear/README.md)で耐力と変形を対応付ける。参考骨格と解析骨格を区別する |
| 作用応力 | [構造解析](../05_構造解析/README.md)で荷重条件から得る応答。部材耐力と同義ではない |
| 部材の終局検定 | [終局検定の統括](07_終局検定の統括.md)で採用需要と耐力を比較する |
| 建物の保有水平耐力 | [二次設計](../07_二次設計/README.md)の採用状態と層力で判定する。部材検定の満足だけでは完了しない |

> **単位系の注意:** 工学単位系の式は \\( 1\ \mathrm{kgf/cm^2} = 0.0980665\ \mathrm{N/mm^2} \\)、\\( 1\ \mathrm{kgf} = 9.80665\ \mathrm{N} \\) で換算して評価します。
> 無開口壁のQcはFc [N/mm²]と柱心間距離×実壁厚 [mm²]から直接Nで算定し、kgf換算を重ねません。
> βsは強度比が無次元です。式ごとの単位と面積は[RC部材の非線形復元力特性](../../nonlinear/05_RC_部材_非線形復元力特性.md#耐力骨格点単位)を参照してください。
