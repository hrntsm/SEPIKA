# CFT中柱・長柱の終局曲げ耐力

CFT中柱・長柱について座屈を考慮し、設計軸力と断面形状に応じて終局曲げ耐力を求めます。

通常の終局検定では、充填コンクリートのFcが24 N/mm²未満の場合、軸・曲げとも未検定です。[柱分類・材料と角部形状の条件](06_CFT_柱_終局耐力.md)を確認してください。

[共通の記号・単位](06_01_CFT柱の軸終局耐力.md#記号単位と算定式)に従います。

## 中柱・長柱のN–M（Case2以外）

正方形長柱かつ \\( N>{}\_cN\_{cr} \\) の場合は、[正方形の長柱 Case2](06_04_CFT正方形長柱の終局曲げ耐力_Case2.md#正方形の長柱-case2)を優先します。同節の計算範囲・有効域を満たさない場合は理由付き未算定とし、以下の補間式へ切り替えません。

以下はそれ以外の中柱・長柱に用いる採用式です。正の外角半径 \\( R\_o \\) を持つ角形は、\\( F\_c\le58.8399 \\) N/mm²、\\( l\_k/D\le30 \\) の計算範囲を超えると理由付き未算定です。長方形は準用モデルであり、円形拘束係数や中柱・Case1・長方形準用の規準適用条件は未確認です。[藤永・孫（2009）](06_04_CFT正方形長柱の終局曲げ耐力_Case2.md#出典と照合範囲)が掲載する中柱式は、低圧縮側の鋼管項を設計軸力で低減します。以下の採用式はコンクリート座屈力に基づく共通係数を用い、N=0でも鋼管項の低減が生じます。

### 共通の中間量

座屈低減係数を \\( \chi\_b \\)、鋼管単体の全塑性曲げ耐力を \\( {}\_sM\_{u0} \\) とします。\\( \chi\_b \\) は座屈低減式の \\( R \\) に対応します。\\( N\_k,{}\_c\lambda\_1,{}\_cN\_{cr} \\) は[合成断面の座屈補助軸力の式](06_04_CFT正方形長柱の終局曲げ耐力_Case2.md#case2の採用式と座屈荷重)と[コンクリートの細長比・座屈耐力の式](06_01_CFT柱の軸終局耐力.md#鋼管とコンクリートの座屈耐力)で、同じ検討軸・実際の座屈長さを用いて求めます。

\\[
\chi\_b=\max\left\\{1-\frac{{}\_cN\_{cr}}{N\_k},0\right\\}
\\]

\\( N\_k \\) が正の有限値として得られない場合は \\( \chi\_b=1 \\) とします。この数値処理は、座屈の影響がないことを確認した結果ではありません。正方形長柱 Case2 にはこの補完を適用しません。

\\[
{}\_sM\_{u0}=\begin{cases}
{}\_sZ\_p F\_y&\text{角形}\\\\
4r\_2^2tF\_y&\text{円形}
\end{cases}
\\]

\\[
C\_b=0.923-0.0045F\_c,\quad
{}\_cM\_{max}=\frac{C\_b}{C\_b+{}\_c\lambda\_1^2}{}\_cM\_{max0},\quad
{}\_cM\_{max0}=\begin{cases}F\_c{}\_cZ\_p/2&\text{角形}\\\\F\_c({}\_cD)^3/12&\text{円形}\end{cases}
\\]

\\( C\_b \\) は無次元、\\( {}\_cM\_{max},{}\_cM\_{max0} \\) は N·mm です。分母 \\( C\_b+{}\_c\lambda\_1^2\le0 \\) なら \\( {}\_cM\_{max}=0 \\) とします。角形の \\( {}\_sZ\_p,{}\_cZ\_p \\) は同じ検討軸の材料領域の塑性断面係数です。直角コアでは次式となり、長方形でも幅を反映します。

\\[
{}\_cM\_{max0}=\frac{F\_c{}\_cB({}\_cD)^2}{8}
\\]

\\[
{}\_cM(N)=\max\left\\{4\frac{N}{0.9{}\_cN\_{cr}}\left(1-\frac{N}{0.9{}\_cN\_{cr}}\right){}\_cM\_{max},0\right\\}
\\]

\\( {}\_cN\_{cr}=0 \\) なら \\( {}\_cM(N)=0 \\) とします。以下の各式は \\( M\_u \\) [N·mm] を求め、負の曲げ耐力は 0 に制限します。不正な断面寸法・材料強度・設計軸力、又は有限値として求まらない曲げ耐力は理由付き未算定です。

### 引張側：中柱・長柱、N < 0

\\[
M\_u=\chi\_b{}\_sM\_{u0}\max\left\\{\frac{N+N\_{tu}}{N\_{tu}},0\right\\},\qquad N<0
\\]

分母 \\( N\_{tu}=0 \\) の場合は \\( M\_u=0 \\) とします。\\( N\_{tu} \\) は[軸終局耐力の式](06_01_CFT柱の軸終局耐力.md#材料寸法と軸終局耐力の選択)による正の大きさであり、引張軸力そのものの符号とは区別します。円形中柱・長柱の純引張限界は、この直線の端点でMu=0です。

### Case1：中柱・長柱、0 ≤ N ≤ cNcr

\\[
M\_u=\max\\{{}\_cM(N)+\chi\_b{}\_sM\_{u0},0\\},\qquad 0\le N\le{}\_cN\_{cr}
\\]

\\( N={}\_cN\_{cr} \\) は本分岐に含み、正方形長柱でも Case2 へは進みません。

### 圧縮側：円形長柱、N > cNcr

円形長柱では、板厚中心の半径 \\( r\_2=(D-t)/2 \\) [mm] を用い、パラメータ角 \\( \theta \\) [rad] を次式で求めます。短柱の軸力釣合いで定める角度とは別の算定式です。

\\[
\theta=\min\left\\{\frac{\pi}{2}+\frac{N-{}\_cN\_{cr}}{4r\_2tF\_y},\pi\right\\}
\\]

\\[
M\_u=\max\\{4r\_2^2tF\_y\chi\_b\sin\theta,0\\},\qquad
N>{}\_cN\_{cr},\quad l\_k/D>12\quad(\text{円形})
\\]

角度式の分母 \\( 4r\_2tF\_y\le0 \\) の場合は \\( M\_u=0 \\) とする数値処理があります。寸法・強度の不正による未算定を、この 0 で補完するものではありません。

純圧縮限界では鋼管の残余軸力に相当する項が鋼管の座屈軸耐力になります。この軸耐力は断面や座屈長さに依存し、対応する角度がπに達せず曲げが残る場合があります。軸圧縮終局耐力への接続を確認できていないため、円形長柱の純圧縮限界のMuは未算定です。

### 圧縮側：中柱・長方形長柱、N > cNcr

中柱は角形・円形とも次式を用います。長柱で本分岐を用いるのは長方形だけであり、正方形長柱には Case2、円形長柱には直前の式を用います。

\\[
M\_u=\chi\_b{}\_sM\_{u0}\max\left\\{1-\frac{N-{}\_cN\_{cr}}{N\_{cu}-{}\_cN\_{cr}},0\right\\},\qquad N>{}\_cN\_{cr}
\\]

\\( N\_{cu} \\) は[当該柱分類の軸圧縮終局耐力](06_01_CFT柱の軸終局耐力.md#材料寸法と軸終局耐力の選択)です。分母 \\( N\_{cu}-{}\_cN\_{cr}\le0 \\) なら理由付き未算定です。中柱の軸耐力で用いる \\( l\_k=12D \\) での補間端点と、本節の実長による中間量を混同しないでください。円形中柱の純圧縮限界は、この圧縮側の直線に達する場合にMu=0です。Ncuが実長のコンクリート座屈軸耐力以下の場合は、Case1からの接続を確認できないため純圧縮限界のMuは未算定です。
