# RC部材の略算終局耐力

- <a id="曲げ終局モーメント梁"></a><a id="曲げ終局時せん断力梁"></a>[RC梁の曲げ終局耐力と曲げ終局時せん断力](01_01_RC梁の曲げ終局耐力と曲げ終局時せん断力.md)
- <a id="柱の軸力考慮終局曲げ"></a>[RC柱の軸力を考慮した終局曲げ耐力](01_02_RC柱の軸力を考慮した終局曲げ耐力.md)
- <a id="終局せん断耐力荒川-mean-式系"></a>[RC梁・柱の終局せん断耐力（荒川mean式系）](01_03_RC梁_柱の終局せん断耐力_荒川mean式系.md)

Muは断面の略算曲げ耐力、Qmuは両端曲げ降伏を仮定したせん断力、Qsuはせん断耐力です。骨格の降伏点・表示判定・終局検定で同じ値を使う場合でも、各用途の判定が成立したことを相互に代用しません。
材料強度の割増の有無は用途で異なり、[増分解析の強度基準](../05_構造解析/07_プッシュオーバー解析.md)を参照してください。

略算式の鉄筋比は、用途ごとに分母と単位が異なります。断面タブの梁幅・全せいと実配筋から算定するため、百分率の表示値を小数の入力へ読み替えないでください。耐力式の係数と適用条件には原典未照合の項目が残ります。

| 記号 | 意味 | 単位 |
|------|------|------|
| \\( M\_u \\) | 曲げ終局モーメント | N·mm |
| \\( Q\_{mu} \\) | 曲げ終局時のせん断力 | N |
| \\( Q\_{su} \\) | 終局せん断耐力 | N |
| \\( a\_t \\) | 引張鉄筋断面積 | mm² |
| \\( \sigma\_y \\) | 主筋の降伏強度 | N/mm² |
| \\( d, d\_e \\) | 有効せい | mm |

原典表記と採用単位の区別、MuのN·mmからkN·m、Qmu・QsuのNからkNへの換算は、[共通の単位系と算定例](../README.md#単位系)を参照してください。

## 鉄筋比の分母・単位と引張方向

本ページでは、終局せん断用を \\(p_{t,s}\\)、降伏時剛性低下率用を \\(p_{t,\alpha}\\) と表記します。
添字は用途を区別するためのもので、以下の出典で使われる引張鉄筋比の記号ptに対応します。
荒川式のptには \\(p_{t,s}\\) の百分率の数値を、採用する剛性低下率式のptには \\(p_{t,\alpha}\\) の小数を代入します。
原典のptという記号だけから、分母・単位が同じとは判断しないでください。

全せい D と有効せい d は区別します。有効せいは圧縮縁から引張主筋の重心までの距離です。
梁の上下の配筋が異なる場合、引張側の主筋面積と重心を各方向で求めます。
多段配筋は入力した各段の面積による重心から有効せいを算定します。

| 用途・方向 | 定義 | 数値の単位 |
| --- | --- | --- |
| 矩形梁の降伏時剛性低下率 | \\(p_{t,\alpha}=a_t/(bD)\\) | 小数（1% は 0.01） |
| T形梁の下端引張、スラブ圧縮 | at/(BD)、B はスラブ協力幅を含む有効幅 | 小数 |
| T形梁の上端引張、スラブ引張 | (at + 協力幅内のスラブ引張筋面積)/(bD) | 小数 |
| 終局せん断耐力（荒川mean式系） | \\(p_{t,s}=100a_t/(bd)\\)、梁幅 b と有効せい d を使う | 百分率（1% は 1.0） |
| せん断補強筋比 | aw/(b・ピッチ)、aw は検討方向の1組の総面積 | 小数（0.2% は 0.002） |

b=300 mm、D=600 mm、d=540 mm、at=1800 mm² のとき、降伏時剛性低下率用は 0.010、
終局せん断用は 1.111111…% です。同じ配筋でも分母が異なるため単純な100倍変換はできません。
矩形梁で同じ引張主筋面積を使う場合の対応は \\(p_{t,s}=100(D/d)p_{t,\alpha}\\) です。
T形の B=1500 mm なら下端引張用は 0.002、上端引張でスラブ筋600 mm²を加える場合は
0.013333…です。この変更で梁のせん断用鉄筋比を有効幅 B に置き換えません。

T形の上端引張では、この鉄筋比で得た剛性低下率に矩形断面とT形断面の断面二次モーメント比
I0/IT を一度だけ乗じます。下端引張へ同じ補正を一律に適用しません。
鉄筋比の生成自体にはこの補正を含めません。

### 利用できる範囲と入力の確認

材端集中ばねへ採用剛性低下率を接続する入力・基準・適用条件は、[RC部材の非線形復元力特性の指定と制限](../../nonlinear/05_RC_部材_非線形復元力特性.md#guiでの指定と制限)を正とします。一様な矩形RC梁・上下同一配筋等の条件に加え、逆対称・同一半部材の基準の明示選択が必要で、未指定のまま可撓長さの半分をせん断スパンへ自動採用しません。
主筋ヤング係数Esは割り当てた主筋材料、Ecはコンクリート材料のヤング係数で、比n=Es/Ecは無次元です。

**スラブ協力付きRC梁の材端集中ばねは未対応です。** 現在の床板には協力幅内の引張筋面積を設定できず、
集中ばねも正負別のT形骨格を設定できません。この条件の非線形解析は入力診断で停止します。
矩形断面や既定剛性低下率による代用として解析を継続しません。入力を修正するまで解析要素を生成しません。
弾性剛性のスラブ協力と、T形の降伏時骨格が対応することは同義ではありません。
ファイバー骨格のスラブ筋・T形断面の妥当性を保証するものでもありません。

梁幅・全せい・有効せい・引張筋面積は正の有限値、有効せいは全せい以下が必要です。
RC矩形梁の非線形解析には、上端・下端の両側の主筋入力が必要です。両側未入力や片側欠落は入力診断で停止し、主筋材料の割当だけでは耐力・骨格を算定しません。骨格表示も未算定とします。
T形の計算には引張方向、有効幅（梁幅以上）、上端引張時の協力スラブ筋面積（非負の有限値）を明示します。
この情報の欠落を、矩形への置換で補いません。

### 定義の出典と未確認事項

日本建築学会『鉄筋コンクリート構造計算規準・同解説』第10版（2024）の8条解説は、T形梁の引張方向による剛性低下率の補正を示しています。『2025年版 建築物の構造関係技術基準解説書』第2版第1刷、付録1-3.1のpp.697–699・704は、梁の降伏時剛性低下率と梁・柱の終局せん断耐力の略算式を示しています。

現行のT形補正、段別主筋の扱い、荒川mean式で用いる鉄筋比の分母と強度・配筋の適用範囲には、未照合の部分があります。梁・柱の曲げ式と適用条件は[梁の曲げ終局](01_01_RC梁の曲げ終局耐力と曲げ終局時せん断力.md#曲げ終局モーメント梁)・[柱の終局曲げ](01_02_RC柱の軸力を考慮した終局曲げ耐力.md#柱の軸力考慮終局曲げ)を参照してください。実験による妥当性確認は未実施です。

## 円形柱の等価正方形

『2025年版 建築物の構造関係技術基準解説書』のp.704、付図1.3-2は、円形柱の曲げ終局強度を略算するときに、等面積の正方形へ置き換える方法を示します。正方形の辺長は実直径 \\(D_c\\) に対して \\(\sqrt{\pi D_c^2/4}\\) です。

現行の線材の曲げ・せん断ヒンジ判定はこの正方形を使い、引張鉄筋面積を全主筋面積の1/4、有効せいを辺長からかぶり・帯筋径・主筋半径を引いた値として算定します。せん断降伏判定の円形帯筋は検討方向あたり2本の閉鎖フープとして扱います。軸終局耐力は等面積と全主筋面積を用います。換算の全適用域での妥当性は未確認です。
