# 静的・両端ヒンジ略算による終局検定

選択した長期架構用組合せの重力せん断を差し引いた耐力を、両端ヒンジを想定した略算需要と比較します。RC矩形梁は[両端の曲げ伝達と降伏の確認](#rc矩形梁の引張側と評価範囲)が必要です。

[対象と耐力の方式](07_終局検定の統括.md#検定対象と耐力の方式)、[需要モード別の記号・単位](07_終局検定の統括.md#需要モードを選ぶときの比較)、[入力不足による未検定の扱い](07_終局検定の統括.md#完全性と未検定)を確認します。

## 静的・両端ヒンジ略算の余裕度

部材別にせん断、付着、軸の余裕度を算定します。
梁・柱の単軸せん断と、有効にした付着割裂の照査では、長期せん断力 \\(Q_L\\) を控除した耐力を、両端ヒンジを仮定する要求せん断力 \\(Q_{mu}\\) と比較します。
\\(Q_{mu}>0\\) のとき、余裕度は次式で求めます。

\\[
\eta_s=\frac{\max(Q_{su}-Q_L,0)}{Q_{mu}},\qquad
\eta_b=\frac{\max(Q_{bu}-Q_L,0)}{Q_{mu}}
\\]

いずれも 1.0 以上を満足することを確認します。控除後の耐力が負になる場合は 0 とします。
ここで \\(Q_L\\) は、選択した架構用長期荷重組合せの構成ケースと係数で符号付き合成した架構の重力せん断力の最大絶対値です。部材荷重から単純梁として求める Q0 とは区別します。採用位置は[静的・両端ヒンジ略算の重力参照](#静的両端ヒンジ略算の重力参照)に示します。この式は静的・両端ヒンジ略算に限り、増分・確定総応答には適用しません。

\\(Q_{mu}=0\\) のときは、\\(Q_L\\) をせん断耐力と、有効にした付着割裂耐力のそれぞれと直接比較します。\\(Q_L\\) がその耐力を超えれば、該当する余裕度は 0 となり、部材を「NG」と表示します。\\(Q_L\\) がその耐力以下の場合は、その照査は成立し、余裕度を無限大（`inf`）と表示します。

「柱を2軸せん断で検定」を選んだ場合も、強軸に対して同じ比較を行います。強軸せん断・付着割裂・二軸曲げのいずれかで NG が確定すれば、部材を「NG」と表示します。

静的略算の二軸せん断余裕度は、強軸・弱軸の長期せん断力がともに 0 の場合に、両端ヒンジ略算の各軸需要と耐力の比を下式で合成します。長期せん断力がある場合の静的二軸合成は適用範囲外です。弱軸の耐力算定に必要な配筋・有効せいを確認できない場合も、二軸せん断余裕度は未算定です。表の「せん断余裕度」欄には算定できた軸を明記し、「未検定」にカーソルを合わせると理由を確認できます。各軸の需要・耐力の単位は N、余裕度は無次元です。

\\[
\frac{1}{\sqrt{
\left(\frac{Q_{mx}}{Q_{ux}}\right)^2+
\left(\frac{Q_{my}}{Q_{uy}}\right)^2
}}
\\]

## 静的・両端ヒンジ略算の重力参照

軸力は[設計軸力の符号](07_終局検定の統括.md#設計軸力の符号と保存結果)、積雪時は[積雪を含む長期重力の指定](07_終局検定の統括.md#積雪を含む長期重力の指定)を確認してください。

設計タブ「終局検定」の「長期架構用組合せを選択」から、保存した架構用長期荷重組合せを明示します。「未指定（未検定）」のままでは需要を算定しません。標準は係数 1 の固定荷重 G と架構用積載 P です。積載がゼロでも、架構用積載の空ケースを明示します。選択は保存した組合せの種別と係数で確認します。

線形重ね合わせが成り立つ状態を対象とします。同じ部材・局所軸・評価位置の符号付き 6 成分を、選択した構成ケースの係数で線形合成します。

引張専用ブレースを含む架構で引張専用反復を有効にすると、各ケースの静的解析が収束しても、ブレースの有効状態はケース間で異なることがあります。この設定では、長期架構用組合せ荷重に対する需要を確認できないため、GUI の「終局検定」で RC 部材・CFT 柱ともに「未検定」と表示します。「需要由来」に表示する理由と、長期架構用組合せの構成ケース・係数を確認してください。

\\[
\boldsymbol{F}_G(\xi)=\sum_k c_k\boldsymbol{F}_k(\xi),\qquad
\boldsymbol{F}=[N,Q_y,Q_z,M_x,M_y,M_z],\quad \xi=x/L
\\]

軸力・せん断力は N、モーメントは N·mm、位置は i 端からの無次元位置 \\(0\le\xi\le1\\) です。絶対値・最大値をケースごとに先に加算せず、符号付き合成後に抽出します。設計軸力は合成した始端値、柱の曲げ需要は合成後の部材内最大絶対値、強軸・弱軸の長期せん断力はそれぞれ合成後の局所せん断力 Qy・Qz の最大絶対値です。始端 N と最大 M・QL は必ずしも同一断面ではありません。

### RC矩形梁の引張側と評価範囲

静的略算を適用するには、梁の両端が強軸曲げを支持先へ伝達でき、対象の載荷方向で上端引張と下端引張が異なる端に生じて、両端が曲げ降伏に達することを確認します。自由端と強軸曲げの解放端は適用外です。支持・接合による曲げ伝達や両端の曲げ降伏を確認できない場合は、確認できない条件を示します。『2025年版 建築物の構造関係技術基準解説書』第2版第1刷、p.416 §6.4.3 (1) 2) i) は、当該梁の両端に曲げ降伏が生じたときのせん断力を `Qy` と定義しています。

共通検定でこの略算を使えるのは、3方向の回転を直接固定した節点に両端を剛接し、上下の主筋配置が対称で、対象の載荷方向における梁端ごとの曲げ降伏が確認済みの場合です。曲げ伝達の判定では節点の並進拘束を条件としません。接合部の耐力・定着と、想定する降伏を妨げる別の破壊の先行も確認してください。端部の拘束や長期曲げの符号だけでは、両端の降伏を確認できません。

設計タブの「終局検定」には曲げ降伏の確認を入力する欄がないため、静的参照ではRC矩形梁を「未検定」と表示します。判定欄で該当する端の適用外または確認できない条件を示し、比較需要と余裕度は「-」と表示します。合成長期応力の全評価位置のうち、非ゼロの強軸曲げが一方向だけなら、その向きの断面耐力を参考値として表示します。負曲げでは上端筋、正曲げでは下端筋を引張鉄筋とします。正負混在・ゼロ・符号不明や、対応する引張主筋がない場合は参考値も未算定です。

両端ヒンジを仮定する要求せん断力は次式です。

\\[
Q_{mu}=\alpha\frac{2M_u}{l_0}
\\]

\\(M_u\\) は曲げ終局強度［N·mm］、\\(l_0\\) は内法長さ［mm］、\\(\alpha\\) は上限強度倍率（既定1.0、無次元）で、\\(Q_{mu}\\) は N です。倍率はヒンジ略算の比較需要にのみ掛かります。倍率には有限の正の値が必要です。ゼロは比較需要を消し、負値は符号を反転させ、非有限値では比較に必要な需要を算定できないため、いずれも入力エラーとなります。1 未満を入力すると、同じ耐力に対する余裕度が増えます。告示の割増しは地震力によるせん断力に適用します。[保証設計に必要な別の照査](07_終局検定の統括.md#保証設計に必要な別の照査)を確認してください。

上下の主筋配置が対称なRC矩形梁では、両端が逆符号で曲げ降伏するときの \\(M_u\\) の大きさが等しく、梁区間の端部曲げによるせん断力を上式で表せます。曲げ耐力の算定式は[RC梁の曲げ終局耐力](01_01_RC梁の曲げ終局耐力と曲げ終局時せん断力.md#曲げ終局モーメント梁)を参照してください。長期せん断力は架構の合成応力から求めます。片持ち梁や、一端または支間内の降伏が支配する梁は、その機構に応じた需要を別途求めてください。

上下の主筋配置が対称な場合は、両端で同じせん断耐力を用います。上端筋と下端筋の付着条件は異なるため、付着割裂を照査する場合は、確認した機構のi端の引張側を照査し、それを満たせばj端の引張側でも同じ比較需要を満たすことを確認します。j端で満たさない場合は理由付きで未検定とし、比較需要と余裕度は未算定とします。有限の正の倍率を指定しても丸めで \\(Q_{mu}=0\\) となる場合があり、その場合は長期せん断力を耐力と直接比較します。長期せん断力が耐力と等しければ照査は成立します。

終局時の両端における各主筋の応力度差、段別配筋、カットオフ筋や定着は別途確認してください。両端ヒンジ形成後の付着割裂が、部材種別や保有水平耐力に無視できない影響を与える場合は、RC規準（2024）16条の大地震動に対する検討が必要です。根拠は『2025年版 建築物の構造関係技術基準解説書』第2版第1刷、付録1-3.1(2)⑥d)、pp.707–708、式(付1.3-20)～(付1.3-22)です。
