# 増分・確定総応答による終局検定

増分解析の採用ステップで確定した、初期重力を含む内力を耐力と比較します。

[対象と耐力の方式](07_終局検定の統括.md#検定対象と耐力の方式)、[需要モード別の記号・単位](07_終局検定の統括.md#需要モードを選ぶときの比較)、[入力不足による未検定の扱い](07_終局検定の統括.md#完全性と未検定)を確認します。

## 増分・確定総応答

選択方向の確定評価ステップから N・M・Q を採ります。保有水平耐力比較用に明示採用したステップが対象です。画面の閲覧ステップ、解析の最終ステップ、別途選ぶ Ds 判定用ステップからは自動選択しません。解析実行に記録した初期重力の構成ケース・係数・入力条件・載荷有無を参照し、現在の地震重量集合から重力を再構成しません。

外力の釣合いは \\(\boldsymbol{f}_{ext}=\boldsymbol{f}_0+\lambda\boldsymbol{q}\\) です。確定内力は初期重力を含む総応答なので、Q へ QL を再加算せず、耐力から QL を再控除しません。総応答モードで追加 QL を 0 と扱うことは「総 Q に追加しない」という意味であり、重力なしや QL 不足の代用ではありません。

総応答モードでは両軸の QL の未設定を需要モードと組にして「追加なし」と表します。静的略算で必要な軸の QL 未設定は入力不足です。RC 柱の二軸せん断余裕度には、初期重力を含む両軸の総せん断力の絶対値を用います。

RC矩形梁の比較需要には、採用した確定ステップの総せん断力を用います。表の合否は有効にしたせん断・付着の比較を表します。梁の Mu 欄は応答曲げの引張側に対する参考曲げ略算で、適用を確認できない理由は Mu 欄の詳細に表示します。強軸曲げがゼロの場合は引張鉄筋量の小さい側を参照します。参考値を算定できない場合も、必要な需要とせん断・付着耐力が揃えば比較を行います。[RC梁の参考曲げ略算](01_01_RC梁の曲げ終局耐力と曲げ終局時せん断力.md#終局検定の参考曲げ略算)

この方式の上限強度倍率は 1 に限ります。総応答を一律に定数倍すると初期重力による内力も倍率の対象になります。地震成分のみを割り増す方法はこの検定の範囲外です。倍率 1 以外は未検定とし、静的略算への自動切替は行いません。強軸のせん断余裕度は Qsu を総せん断力の絶対値で除した値です。終局せん断耐力が120 kN、総せん断力の絶対値が80 kN の場合、強軸のせん断余裕度は 1.50 です。[付着](02_02_RC梁_柱の大地震時の付着照査.md)は設計用付着応力度に対して別に照査します。

初期重力を明示的に載荷しない解析は参考の水平載荷実験として扱い、一般建物の終局合否へ自動採用しません。非線形総応答へ別の線形重力応力を後から加えて、同じ荷重履歴の解として扱うこともしません。
