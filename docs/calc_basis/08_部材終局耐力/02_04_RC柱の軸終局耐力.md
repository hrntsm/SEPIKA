# RC柱の軸終局耐力

RC柱の純圧縮・純引張に対する軸終局耐力を求めます。

## 柱の軸終局耐力

検討方向の断面幅b・全せいD [mm]、コンクリート強度Fcと主筋降伏強度σy [N/mm²]、全主筋面積ag [mm²]を使います。円形柱は[共通の断面寸法の扱い](01_RC_部材_略算終局耐力.md#円形柱の等価正方形)に従い等積正方形で扱います。圧縮正、引張負として、耐力をNで求めます。

\\[ N_{uc}=bDF_c,\qquad N_{ut}=-a_g\sigma_y \\]

圧縮側に主筋寄与を加えない軸耐力です。[柱の軸力考慮終局曲げ](01_02_RC柱の軸力を考慮した終局曲げ耐力.md#柱の軸力考慮終局曲げ)で用いるNmax=bDFc+agσyとは用途を区別します。
