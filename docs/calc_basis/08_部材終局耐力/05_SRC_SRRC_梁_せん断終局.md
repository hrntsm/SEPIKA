# SRC / SRRC 梁 せん断終局（充腹・非充腹）

SRC/SRRC 梁のせん断終局耐力について、充腹の累加式および非充腹の格子材・ラチス材の算定には対応していません。
これらの方式によるせん断終局耐力の検定結果は出力しません。

SRC柱についても、鉄骨とRC部分のせん断終局耐力を累加する部材終局検定は出力しません。
矩形RC柱・梁の終局検定結果にSRC部材は含まれません。結果の件数が0でも、SRCの終局耐力を満足したという意味にはなりません。
非充腹の格子材・ラチス材は、矩形RC部と中心H形鉄骨からなる対応断面へ読み替えず、別途検討してください。

SRC柱梁接合部のパネル検定は許容応力度による検定です。終局パネルモーメント、終局強度式の有効体積、帯筋の終局寄与による検定には対応していません。
許容パネルの検定比や、解析でのパネル降伏を、SRC接合部の終局検定結果として用いることはできません。
接合部帯筋の最小比0.1%と配置・定着の適合は、耐力比とは別に確認してください。

現在のSRC梁・柱の許容応力度検定の算定方法と適用範囲は、
[SRC・CFT 断面検定](../06_一次設計/04_SRC_CFT_断面検定.md)を参照してください。

## 計算根拠と適用の区別

『2025年版 建築物の構造関係技術基準解説書』第2版第1刷（2026年2月11日）、付録1-4.2 pp.764–770は、
曲げ累加、充腹・非充腹のせん断終局強度、接合部の終局パネルモーメントの算定例を示しています。
これらの終局算定例と、SEPIKAが採用する許容応力度検定は分けて扱います。
同書付録1-4.1 pp.758–759の設計用せん断力を用いる靭性確認も、部材のせん断終局耐力そのものの算定とは異なります。
