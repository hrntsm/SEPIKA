# 結果の表示（3D ビューア）

この章では、解析結果を画面に出すときの仕様をまとめます。
3D ビューアでの変形・応力などの表示計算と、左ドックのナビゲータから結果を切り替える
操作の両方を扱います。
ここでの計算はいずれも**画面表示のための処理**であり、解析結果（節点変位・部材応力）
そのものには影響しません。

## 数値から計算時の根拠を確認する

結果タブの「表示結果の計算元・変位の根拠」で、計算元の案、入力世代、入力識別、荷重ケース・
組合せの係数と計算状態を確認します。計算時の案名称を記録していない成果は、名称を現在の値で
補わず案の識別を示します。図で節点を選び、全体座標 X・Y・Z の変位 [mm] の「根拠」を押すと、
計算時の節点番号・座標・方向・荷重状態を確認できます。現行入力と計算元の入力版が異なる場合、
現在の図の選択は使わず、この欄で計算時入力の節点・部材を選びます。
計算時節点や変位の記録が欠落していれば取得不能と表示します。

検定表の検定比または断面名を押すと、部材番号、材軸位置 ξ（始端0・終端1）、無次元の検定比、
OK／NG または未検定の理由、保存された式名と既存の数値詳細を開きます。
「保持された検定結果の位置・根拠（履歴を含む）」からも位置を選べます。図で部材を選択した場合は、
結果タブの根拠欄にその計算時部材番号の検定位置が並びます。
主架構検定は選択した一つのケース・組合せの応力によるため、比較ケース集合は1件です。
その1件を支配ケースとして表示し、複数ケース間の包絡比較や、同じ部材内の最大位置の選択とは区別します。
未検定では採用応力源だけを示し、支配ケースは未確定と表示します。
記録のない式や詳細を推定しません。荷重期間・検定方式と、その検定が採用した応力生成時の条件は
「計算時の入力を見る」で確認します。

「計算時の入力を見る（読み取り専用）」は記録された入力だけを開き、現在のモデルで補完しません。
部材の節点・割当断面、断面形状と配筋、材料、荷重ケース・組合せ、記録された計算条件を確認できます。
部材の材料は主材料・主筋・せん断補強筋・内蔵鉄骨／鋼管の役割別に、実際に解決された材料番号・名称・強度を示します。
断面の明示割当と、取込時の共通指定・径別指定などから実際に解決された材料が異なる場合も区別できます。
未割当・解決不能はそのまま示し、現在の材料で補完しません。
閲覧ではモデルやUndo、結果の有効性を変更しません。入力窓を閉じると元の根拠に戻り、根拠窓を閉じると
元の図表に戻ります。「現在の断面入力を編集」「現在の材料入力を編集」は、表示された現在本案の案・
入力世代を確認してから選びます。過去の番号から現在の対象を自動選択せず、現在の入力表で対象を選びます。
移動後は根拠窓の「元の結果へ戻る」で元の工程に戻れます。入力窓の「現在の本案の入力表へ移動（計算時入力の閲覧は保持）」
も、現在本案へ移る明示操作です。この入力窓を閉じると元の工程に戻ります。

生成入力が一致することと個々の検定のOKは別です。解析入力の変更では依存する解析・検定が利用不可に
なり、検定条件だけの変更では検定の再実行が必要になります。保持している古い結果の詳細は履歴として
閲覧できますが、現行入力の最新結果にはしません。保存・再読込時に既存の失効規則で除外された成果は
取得不能・要再計算となります。未計算、入力不備、計算失敗、未検定、未対応、欠落を0やOKで補いません。
AIの説明は補足であり、計算値や検定の保証を置き換えません。
根拠窓を開いた後に編集や再計算をした場合も、有効性の表示は更新します。別の実行結果へ置き換わった場合は、
窓の数値が開いた時点の記録であることを示し、新しい結果の値へ差し替えません。

数量積算は、図の選択や階・通りの絞込みによらないモデル全体の随時計算です。
「体積・数量の対象と集計時入力を見る」で、各明細の対象と、その操作時点に固定した入力を確認できます。
数量の保存結果の履歴とは別です。鋼材体積 [m³] は鉄骨数量（S・SRC・CFT・ブレース）の重量 [t] を
数量用単位重量7.85 t/m³で換算し、鉄筋を含みません。コンクリート体積 [m³] とともに明細対象を確認でき、
鉄筋の不完全小計や未算定の理由はそのまま示します。
数量の根拠参照には固定した入力・モデル全体という対象範囲・集計契約を含み、同じ参照から同じ根拠を開きます。
現在の入力が変わった後も元の数量を再確認でき、別プロジェクトや不整合な参照、異なる集計契約は拒否します。
数量の読み取り専用入力では、壁筋仮定径・定着係数に加え、小梁主筋比・小梁スターラップ比・床と片持ち床の鉄筋比を
確認できます。「数量対象の配置・支持範囲」には床板・壁版の割当断面、支持境界座標と支持部材の区間、床・壁領域、
二次部材の支持位置と両端座標を示します。これらも固定した入力から表示し、現在の配置や数量設定で補完しません。
線材の種別・フェース距離・鉛直偏心・局所軸方向・ハンチ、断面の用途・幅・せい・実板厚・断面積の採用元、
材料種別、節点の所属階と階のFL・ΔSL、壁・シェルの開口入力も確認できます。フェース距離の未算定は0に置き換えません。
二次部材も主材料・主筋・せん断補強筋・内蔵鉄骨／鋼管の実解決材料を示します。
床板は支持境界に加え、固定入力から解決した実上面・下面・実厚・上面境界を表示します。解決不能なら理由を示します。
検定表と履歴入口の断面名も計算時入力の名前を使い、現在の断面名で代用しません。

## 図の操作

ビュー上部の主操作行には、左から表示モードの選択欄、表示範囲の選択欄、
「全体に合わせる」、前／次の通り・階（◀／▶）、「断面表示」「床壁・二次部材」「表示設定」が並びます。
表示モードの選択欄で現在のモードを確認し、一覧から切り替えます。
時刻歴は詳細記録がある場合、質点モード・質点時刻歴は質点系の結果がある場合に選べます。
表示範囲は「全体（3D）」、通り（軸組図）、階（伏図）から選びます。
通り・階のない模型では「全体（3D）」だけを選べます。

応力成分、CMQ の成分と軸、検定式、モード次数、モデル化の解析種別、変形倍率、
時刻歴の再生など、現在の表示モードに対応する操作と結果の案内は、主操作行の下に表示します。
「支点」「剛床代表点」「通り芯グリッド」などの補助表示は「表示設定」にまとめています。
利用できる項目は模型と表示モードによって異なります。

幅が足りなくなると、まず「全体に合わせる」と前／次の通り・階、次に「断面表示」「床壁・二次部材」が
「表示設定」へ移ります。幅を戻すと元の位置に戻り、設定値は引き継ぎます。
主操作行は折り返しません。長い選択名は省略し、ポインタを重ねるか選択一覧を開くと
全文を確認できます。さらに狭い幅では主操作行を横スクロールして操作します。

「表示設定」末尾の「操作案内」では、現在の表示範囲に合う操作を確認できます。
全体（3D）は左ドラッグで回転、右ドラッグで移動、構面は左ドラッグで移動します。
いずれも描画領域上でスクロールまたはピンチすると、ポインタ位置を保ったまま拡大・縮小します。
画面を移動した後や、部材のない空白上でも同じ操作ができます。倍率の限界では画面は移動しません。
ピンチでポインタ位置を取得できない場合は、現在の投影中心を基準に拡大・縮小します。
ViewCube 上や手前のウィンドウ・ポップアップへのズーム操作は、背後の模型には適用しません。
ViewCube は全体（3D）の描画領域の右上に表示し、
面や角をクリックすると視点を切り替えます。

拡大・移動した後は「全体に合わせる」を押すと、現在の視点方向を保ったまま、
画面移動を解除して全体表示の倍率へ戻ります。構面では選択した通り・階への正対を保ちます。
ウィンドウのサイズ変更やパネルの開閉後も、その時点の描画領域に合わせます。
表示モード、部材の選択、結果ケース、変形倍率などの設定は変わりません。

全体表示の基準は、全体（3D）では模型の全節点、構面では対象要素の節点の未変形座標です。
構面の対象要素から有効な節点を得られない場合は、構面の選択と視点方向を保ち、模型全体の節点範囲を使います。
部材などの表示・非表示や選択状態によって、この基準は変わりません。
断面外形、変形図・応力図の張り出し、注記・グリッドなどを含む、すべての描画物が収まる操作ではありません。

## 部材のホバーと選択表示

3D・構面ビューは淡い灰色の背景に模型を表示し、通り芯グリッドは部材より細い灰色の線で示します。
通常部材へポインタを重ねると青い補助線が一時的に現れ、部材から外すと消えます。
選択した部材は、より太い紫の補助線で示します。ポインタを外しても残り、選択中の部材へ
ポインタを重ねても同じ選択表示を維持します。複数選択では各部材に適用します。
表示範囲外の部材は強調せず、選択は保持します。

線材表示では部材線に沿って、断面表示では中心線などに沿って状態を示します。
断面全体を塗り替えないため、H形の凹部や空隙は残ります。
応力図・検定比・モデル化・ヒンジの色は結果や凡例の意味を表し、青・紫の補助線は操作状態を表します。
結果の線色・塗り・数値はそのまま読み取れます。作成・割当・荷重対象指定中は、それぞれの専用プレビューを使います。

<div class="impl-ref">

**実装参照**：`sepika_app::viewer::viewer_panel`（`crates/sepika-app/src/viewer/mod.rs`）が通常部材の状態表示を、`sepika_app::theme`（`crates/sepika-app/src/theme.rs`）が配色を定義します。

## CMQ 図（表示モード）

3D ビューアには、大梁の C（端部固定値）・M（荷重込み曲げモーメント）・
Q（荷重込みせん断力）を表示する **CMQ 図**モードがあります。節点変位を0とし、建物共通の「剛域を考慮する」設定、局所軸、材端解放に従って算定します。単純梁の参考値ではありません。建物全体の変位による応力を含む解析結果は応力図で確認します。
解析の実行を必要とせず、モデル・荷重ケースの入力内容だけから毎フレーム描きます。梁の実材軸上に表示し、部材長と局所軸も実材軸から評価します。
CMQ 図表示中は床・二次部材の変形追従メッシュを描きません
（[床・二次部材の変形追従](./04_床・二次部材の変形追従.md)）。

**ソースはナビゲータ／荷重タブで選択中の荷重ケース（`nav.focus_load_case`）の部材荷重
（`LoadCase.member`）そのものです。** 床荷重の分配（自立壁を床へ上乗せした等価面荷重を
含む）・梁自重・取り付く壁版の線アンカー分布・手入力の部材荷重のいずれも、そのケースに
載っていれば同じ図に重ねて表示します。柱への節点集中荷重（取り付く壁版を両端の柱へ集中させた場合等）は梁に載る
荷重ではないため表示されません。荷重ケースが未選択の場合は先頭の荷重ケースを表示します
（静解析の対象決定と同じ規約）。

「DL」「LL(架構用)」「LL(地震用)」の内容は準備計算（またはいずれかの解析実行。
どちらも内部で同じ同期処理を通ります）が書き込みます。モデルを読み込んだ直後や
スラブを編集した直後で準備計算をまだ一度も実行していない場合、これらのケースの
CMQ図は空（部材荷重なし）のまま表示されることがあります。準備計算タブで実行すると
最新化されます（「EX」「EY」はこの制約の対象外です。水平力は常に節点荷重のみで
表され、準備計算の有無にかかわらず CMQ 図には元々何も表示されません）。

「成分:」で C/M/Q を、「軸:」で強軸（ey）・弱軸（ez）を切り替えられます（既定は強軸のみ）。
部材の局所軸が傾いている場合（斜め柱、ひねりのある断面等）、鉛直荷重でも強軸・弱軸の
両方に成分が生じうるため、荷重の作用方向を各部材の局所軸へ投影してから C/M/Q を計算します。
両軸を同時表示するときは同一スケールで重ねて描き、弱軸（ez）は強軸（ey）より半透明に
描きます（構面ビューでは強軸・弱軸の張り出し方向が同一直線上に重なるため、色だけでは
区別できないことがあります。透明度で見分けられるようにしています）。

選択中の軸に有意な荷重成分がない場合（例: 直交グリッドの部材で弱軸のみを選択した場合、
鉛直荷重はほとんど強軸側にしか投影されません）、CMQ図は空欄になり、その旨の案内を
表示します。

準備計算 CSV の出力項目は、[CSV 出力・プロジェクトファイルへの保存](../preparation/11_出力と保存.md)を参照してください。

<div class="impl-ref">

**実装参照**：CMQ 図は `sepika_app::viewer::cmq::draw_cmq_diagram`（`crates/sepika-app/src/viewer/cmq.rs`）が選択中の荷重ケース（`nav.focus_load_case`）の部材荷重から C・M・Q を求めて描き、表示モードは `sepika_app::viewer::ViewMode::Cmq`（`crates/sepika-app/src/viewer/mod.rs`）で、成分と軸（既定は強軸のみ）を切り替えます。`ViewMode::Cmq` では床・二次部材の変形追従メッシュを描きません（同ファイル）。

</div>
