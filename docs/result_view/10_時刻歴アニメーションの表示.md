# 時刻歴アニメーションの表示

表示モード「時刻歴」では、時刻歴応答解析の詳細記録（間引きされたフレーム
ごとの全節点変位・部材内力）を 3D ビュー上でアニメーション再生します。
地震応答の時々刻々の変形の様子を確認できます。

時刻歴応答解析の実行が前提です。詳細記録がない場合（保存時に詳細記録を除外した場合など）は、
表示モードの選択肢自体に「時刻歴」が現れません。

詳細記録はプロジェクトファイル（.ovika）に保存され、読み込み直後から
アニメーション・部材履歴を確認できます。詳細記録はデータ量が大きい
（実建物規模の解析では数百 MB 級になり得る）ため、解析結果の保存サイズが
512 MB を超える場合は、保存時に「時刻歴の詳細記録を保存に含めますか？」の
確認が表示されます。除外して保存した場合も、層応答の集計値・ピーク値などは
別に保存され、詳細記録は時刻歴応答解析の再実行で復元できます。

## フレームと変形表示

詳細記録は、解析の全ステップのうち指定した記録間隔
で間引いた時刻のみを保持します。ビューには次のフレーム制御を表示します。

初期点と最終確定点は必ず含めます。先頭の時刻 0 は積分前の初期状態で、N 点の入力に対する終時刻は (N−1)dt です。
フレーム番号は積分回数とは異なります。[入力時刻と初期状態](../calc_basis/05_構造解析/05_時刻歴応答解析.md#入力時刻と初期状態) と [記録間引き](../calc_basis/05_構造解析/05_時刻歴応答解析.md#詳細記録のフレーム間引きrecord_every) も参照してください。

- **フレームスライダー**: 0 から最終フレームまでの範囲で現在フレームを選択
  します。ラベルには現在時刻 \\( t \\) [s] と総時間を表示します。
- **再生／一時停止ボタン**（▶／⏸）: 再生中は実時間の経過に再生速度を掛けた
  だけフレーム時刻を進め、最終フレームに達すると先頭へ周回します。
- **再生速度**: ×0.25／×0.5／×1／×2 から選択します。

現在フレームの全節点変位は、変形図（表示モード「変形」）と同じ方式で表示します。変形倍率スライダー・内部たわみ（梁の Hermite 曲線）表示の
切り替えも変形図と共通です。ただし自動倍率は、現在フレームではなく
**解析全体を通じた最大変位**（全ステップの絶対値最大、間引きの影響を受け
ません）から 1 回だけ算定した固定値を使います。フレームを切り替えても
倍率自体は変わらないため、振幅の小さい時刻でも表示が消えたり、逆に
過大な倍率になったりしません。

モデルを編集すると、再解析するまで時刻歴モードの変形アニメーション・
部材クリックは無効化され、「モデルが編集されています。解析を再実行して
ください」と案内します。開いている部材の履歴・検定ウィンドウ
がある場合も同様に、プロット・検定を隠して同じ案内を表示します。

## 部材の履歴・検定ウィンドウ

時刻歴モードで部材をクリックすると、「時刻歴詳細: 部材 #N」ウィンドウ
（開閉・リサイズ可能）が開きます。ウィンドウは他の表示モードへ切り替えても、
閉じるまで表示されたままです。

### 荷重変形関係の履歴ループ

部材の種別に応じて、次のいずれかのループ図（横軸・縦軸とも解析全フレームの
値を結んだ折れ線）を表示します。現在フレームの位置はループ上にマーカーで
示し、フレームスライダーと連動します。

- **軸力系（ブレース・ダンパー・免震・節点ばね要素）**: 軸力 N [kN]（引張を
  正）と軸方向相対変位 \\( \delta \\) [mm] の関係。\\( \delta \\) は部材両端
  の変位差（並進成分）を、未変形時の材軸方向（i端→j端の単位ベクトル）へ
  射影した値です。

  免震支承・節点ばねのように部材長がほぼ 0 の要素は材軸方向が定まらない
  ため、代わりに要素ローカル軸の成分（軸／せん断y／せん断z）を切り替えて
  表示します。免震支承は水平方向のせん断力とせん断変位の関係（局所 y 軸）
  を既定表示にします（免震の応答確認では水平ループが主な関心事のため）。
  局所軸は免震支承が軸＝鉛直・せん断＝水平、それ以外（節点ばね等）は
  全体座標系と同じ向きです。
- **梁・柱**: 材端モーメント M [kN・m] と材端回転角 \\( \theta \\) [rad]
  （弦からのたわみ角）の関係。強軸（Mz・θz）／弱軸（My・θy）を切り替え
  られ、i端・j端をそれぞれ色分けして重ねて表示します。

  \\( \theta \\) は、部材端の節点回転から「弦回転」（両端の並進変位差を
  部材長で除した値）を差し引いた回転角です。弦回転は部材全体の剛体的な
  傾き（層間変形相当）を表すため、これを差し引くことで材端そのものの
  曲げ変形（たわみ角）だけを取り出します。

要素の内力が記録されていない場合（免震・ダンパー要素など、内力分布を
持たない要素定式化の場合）は、ループの代わりに記録がない旨を案内します。

### 最大応力に対する検定

上下非対称組立H形鋼柱では「抽出時刻の簡易検定（短期）」に[極値が生じた確定時刻の断面力](#上下非対称組立h形鋼柱)による照査を表示します。
それ以外の対象部材では、全ステップを通じた部材内力の包絡値（各成分の絶対値最大値。符号は極値の
符号を保持）を用いて、短期の断面検定を行います。断面・材料の種別に応じて
鉄筋コンクリート・鋼・SRC・CFT のいずれかの検定式を適用し、検定位置ごとに
検定比・判定（OK／NG）・検定式別の内訳を表示します。判定色は検定比図
（[検定比の表示](./06_検定比の表示.md)）と同じ配色（緑＝良好／黄＝注意／
赤＝超過）です。

各検定位置で引張・圧縮が生じた場合は、「軸力極値が生じた確定ステップ」に
それぞれの軸力の絶対値が最大となった時刻と検定結果を表示します。
せん断力・ねじりモーメント・曲げモーメントには、その軸力と同じ確定ステップの値を使います。
軸力が同値なら最初の時刻を採用します。包絡と軸力極値の集計はいずれも初期状態を
含む全確定ステップが対象で、アニメーションの記録間引きには左右されません。
軸力が極値に達していない時刻の組合せでも検定比が大きくなる場合があります。
旧結果で引張側・圧縮側の記録がない場合は、解析を再実行すると表示できます。

次の部材・要素は検定対象外とし、その旨を案内します。

- 断面または材料が未設定の部材（免震・ダンパー・節点ばね要素など、
  断面検定という概念自体が当てはまらない要素を含む）。
- 壁・シェル・仕口パネル要素（断面検定の部材種別（梁・柱・ブレース）に
  当てはまらない要素）。

通常S部材の座屈長さは[通常検定と同じ軸別の選択](../calc_basis/06_一次設計/03_06_鋼部材の座屈長さ_有効細長比.md#通常s主架構部材の座屈長さ)に従い、採用値を mm で表示します。
各軸の直接指定を優先し、未指定軸には柱1.2L、大梁・一般ブレース1.0Lを使います。L は端部偏心を反映した個々の部材の実材軸長です。
支持条件から求まる長さが既定値を超える方向は、その長さを直接指定してください。指定値に0・負値・非有限値があれば、その軸を示して未検定とします。
CFT柱は[両軸の直接座屈長さ](../calc_basis/06_一次設計/04_08_CFT柱の座屈長さと適用条件.md#cft柱の座屈長さ)を用います。片軸でも未指定か不正なら未検定です。
座屈拘束ブレースの属性は、断面用途がブレースのブレース要素に割り当てます。柱・梁など、条件を満たさない部材に属性が付いている場合は、部材 ID と理由を表示して未検定とします。
本画面は座屈拘束ブレースの製品別検定に対応していません。製品固有の軸力・限界長さは[通常検定](../calc_basis/06_一次設計/06_座屈拘束ブレース.md)で確認してください。
鋼継手・スカラップの欠損による断面性能の低減、一本部材指定による応力合成は簡易検定の対象外です。上下非対称組立H形鋼柱では、欠損を指定した位置の[圧縮時の強軸曲げ](../calc_basis/06_一次設計/03_05_鋼柱_ブレースの軸力_曲げ検定.md#上下非対称組立h形鋼柱の圧縮と強軸曲げ)および[軸力ゼロ時の強軸曲げ](../calc_basis/06_一次設計/03_05_鋼柱_ブレースの軸力_曲げ検定.md#上下非対称組立h形鋼柱の軸力ゼロの強軸曲げ)の応力度照査を未算定とします。

非線形時刻歴で長期荷重を初期状態に含めたSRC柱では、地震時の設計用せん断力の評価に保存済みの重力参照内力が必要です。
重力組合せの保存結果や対象柱の内力がない場合、同じ位置の重力参照せん断力 QL（Qy・Qz）が欠けているか非有限の場合、または設計用せん断力の適用条件を確認できない場合は、「内力包絡」と「軸力極値が生じた確定ステップ」の該当位置に「検定不能」と理由を表示します。
その位置の検定比と判定の表示は、独立に確定した軸力・曲げの不適合（NG）に限られます。検定に必要な入力の不足やねじりによる未算定もあるときは、その理由も併記します。 [SRC柱の地震時の設計用せん断力](../calc_basis/06_一次設計/04_03_SRC梁_柱の許容せん断検定.md#src柱の地震時設計用せん断の適用範囲)

「内力包絡」では各成分（軸力・せん断力・
ねじりモーメント・曲げモーメント）の最大値はそれぞれ全ステップを通じた絶対値最大（包絡値）
であり、同一時刻に生じたとは限りません。実際には同時に生じない組合せを
検定している可能性があるため、応力の組合せが過大になる場合があります。ただし、各成分の符号や相関を含む検定について、この包絡だけで必ず安全側になるとは限りません。

鋼部材の応力度検定では、ねじりモーメントMxが非零または非有限の位置を理由付きで未算定とします。[材軸ねじりが作用する場合](../calc_basis/06_一次設計/03_03_鋼梁_柱のせん断検定.md#材軸ねじりが作用する場合)

RC・SRC・CFT部材では、「内力包絡」と「軸力極値が生じた確定ステップ」のそれぞれで、各検定位置の材軸ねじりモーメント Mx を確認します。
Mx が厳密に 0 なら通常の検定条件を適用します。微小値を含む非零または非有限の Mx では、「検定不能」と理由を表示します。
独立に確定した不適合があればその検定比と NG を併記します。 [RC・SRC・CFTの材軸ねじり](../calc_basis/06_一次設計/README.md#rcsrccftの材軸ねじり)

線形の時刻歴応答解析では、地震動による応答成分のみを検定しており、長期
荷重（固定・積載等）との重ね合わせは含みません。非線形の時刻歴応答解析
では、長期荷重を初期状態として考慮する設定にしていた場合はその旨、
していない場合は水平力のみの結果である旨を、検定結果の上に注記します。

#### 上下非対称組立H形鋼柱

上下フランジの幅または厚さが異なる組立H形鋼のS柱では、各検定位置で非零の引張・圧縮軸力 N と正・負の局所強軸曲げ Mz のそれぞれの極値を探します。同値は最初の時刻を採用します。各行は、該当する確定時刻の同じ断面位置における軸力・せん断力・ねじり・曲げの全成分を用いた短期照査です。線形・非線形ともに、初期状態を含む全確定ステップから、アニメーションの記録間引きに関わらず抽出します。

圧縮時または軸力ゼロ時に強軸曲げが作用する有限長の柱では、横座屈・曲げねじり座屈が未算定です。法定細長比、軸曲げ比の下限、曲げ比の下限から独立に不適合が確定した場合は NG と表示します。NG と併記される未算定理由と照査根拠は、検定比にポインターを合わせると確認できます。検定不能の理由は該当行に表示します。個々の N・Mz が極値に達していない時刻や、せん断力など他成分が厳しい時刻が抽出されない場合があるため、全時刻の適否は未判定と表示します。異なる時刻の成分を合わせた「内力包絡」はこの柱の簡易検定に使用しません。

プロジェクトに時刻歴の詳細記録を含めると、再読込後も同じ時刻を照査できます。正負の強軸曲げ極値の記録がない保存結果では、利用できる軸力極値で照査し、曲げ極値を確認するには再解析が必要なことを案内します。
