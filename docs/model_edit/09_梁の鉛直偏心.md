# 梁の鉛直偏心

大梁・小梁には、両端を結ぶ基準材軸から梁全体を上下へ移動する一律鉛直偏心を指定できます。
単位は mm、上向き（全体座標 +Z）を正とします。大梁は大梁用途の断面を割り当てた主架構線材、小梁は支持アンカーを持つ二次部材が対象です。柱・ブレース・間柱・床板は対象に含みません。

## 入力と確認

大梁は部材表、小梁は床の小梁一覧にある「梁の一律鉛直偏心 [mm]（上向き＋）」を開きます。
数値を入力して入力欄からフォーカスを外すと確定します。「0を指定」は基準材軸と実材軸を一致させ、「未指定」は入力を解除します。
空欄・未指定と明示した 0 は区別します。新規に画面で作成する梁は 0 を指定して作成します。ST-Bridge から取り込んだ梁は未指定とし、偏心値を推測しません。
偏心はプロジェクト保存・再読込、元に戻す・やり直すの対象です。

各行には実材軸の両端 Z と、中央の平面位置での上端・下端 Z を表示します。形状モードの材軸線・断面表示は実配置を使います。
偏心・支持アンカー・節点・実断面形状が未指定、不正または非有限なら、対象と理由を表示し、実位置を使う判定を行いません。未指定を 0 や節点位置から補いません。

## 基準材軸と実材軸

大梁の基準両端位置は両端節点、小梁の基準両端位置は指定済み支持アンカーから求めます。
基準位置を \\(N_i,N_j\\)、偏心を \\(e_b\\) とすると、実材軸端は次の位置です。

\\[
P_i=N_i+(0,0,e_b),\qquad P_j=N_j+(0,0,e_b)
\\]

両端の XY、傾斜、材軸長、部材と支持先の識別は変わりません。傾斜は節点座標で指定し、端別の偏心は指定しません。
SL は階の代表梁節点を生成する基準であり、個別梁の偏心基準ではありません。既存節点を動かさず SL だけを編集した場合、実材軸は移動しません。
基準節点を移動すれば、偏心を保ったまま実材軸が追従します。個別梁の偏心は FL 間高さを変更しません。
小梁は支持梁の実位置と上下に離れていても指定した支持先を保持し、支持先の偏心を重ねて加算しません。

## 上端・下端と幅

実断面を局所軸の向きに配置し、実材軸の両端面で切った有限な立体を使います。
上端・下端 Z は、対象 XY を通る鉛直線と材料領域の最も上・下の交点です。端面や一点接触も含み、交差がなければ上端・下端はありません。
水平幅は対象の高さを通り、材軸の水平投影に直交する水平線で切った材料領域の最外交点間の距離です。空洞を含む断面でも、外側の距離を表します。
上下非対称断面・断面回転・空洞を実形状から扱い、一律にせいの半分を加減しません。

例えば両端節点 Z が −500 mm、せい 600 mm の水平矩形梁では次の位置になります。

| 偏心 [mm] | 実材軸 Z [mm] | 上端 Z [mm] | 下端 Z [mm] |
| ---: | ---: | ---: | ---: |
| 0 | −500 | −200 | −800 |
| +100 | −400 | −100 | −700 |
| −100 | −600 | −300 | −900 |

ねじれがなく、水平から 30 度傾く矩形梁の内部では、同じ XY における材軸と上面の鉛直差は \\(D/(2\cos30^\circ)\\) です。
せい 600 mm なら約 346.410 mm となります。材軸直交断面の上端を鉛直投影した約 259.808 mm とは異なります。梁端では有限な端面による制限も適用します。

## 解析・重量計算との関係

実配置の編集は準備計算と既存の計算結果を陳腐化させます。節点や断面の編集も実配置へ反映されます。
解析節点の座標・自由度・部材の接続条件は保持します。解析結果を表示する変形図・応力図等は解析配置を参照します。
矩形RC/SRC大梁では、偏心を含む実配置から[床板との自重重複控除](../calc_basis/01_荷重/06_自重の長期応力解析への接続.md#矩形rcsrc大梁と床板の実重複控除)を算定します。
現時点では、この偏心による剛性・内力・反力の変換と、床板下端までの嵩上げ重量の追加は行いません。
