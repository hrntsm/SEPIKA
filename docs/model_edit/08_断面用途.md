# 主架構線材の断面用途

主架構線材の設計上の用途は、断面に指定する `FrameSectionUse` で決まります。`Girder`、`Column`、`Brace` のいずれかを明示し、断面符号や部材の角度から推定しません。

`ElementKind::Beam` は柱・大梁を含む曲げフレーム要素の解析定式化です。`ElementKind::Brace` はトラス定式化と `tension_only` を表し、Brace 用途の断面だけを割り当てられます。Beam 要素には Girder または Column 用途を、Brace 要素には Brace 用途を割り当てます。不整合や用途未設定は拒否します。

床・壁・二次部材の断面に主架構用途は要求しません。二次部材は `SecondaryMemberKind::{Beam, Post}` が正であり、断面の `frame_use` は `None` でも構いません。二次部材の断面用途は主架構の用途整合とは別に扱い、`frame_use` の値だけを理由に二次部材を拒否しません。

断面の同一性は断面符号と階の組で決まり、用途違いを暗黙の使い回しで解決しません。形状編集と複製では用途を保持します。幾何判定は局所座標・接続関係・式の適用条件の確認に限り、用途を変更しません。仕口パネルも用途で柱梁候補を抽出し、適用可否は別の幾何条件で判断します。

SCZ は用途を保存します。ST-Bridge の `StbColumn`、`StbGirder`、`StbBrace` の主架構部材文脈を用途へ写し、`StbBeam`・`StbPost` は用途を決めません。同一断面を大梁と小梁、または柱と間柱が共有する場合も内部断面は複製しません。主架構用途の競合は入力エラーとします。旧形式からの移行や用途復元の fallback はありません。

この用途は RC・S・SRC・CFT の柱梁検定、`ForceRegime::Auto`、`no_long_axial_column`、数量積算でも共通して参照されます。

CFT（`CftBox`・`CftPipe`）は `FrameSectionUse::Column` 専用です。用途は部材角度ではなく `FrameSectionUse` を正とし、`Girder`・`Brace`・`None` の断面作成・割当は拒否し、既存データは解析前チェックでエラーにします。二次部材への CFT 割当も同じく拒否します。Column 用途の主架構部材は水平・傾斜を含めて材軸角度だけでは停止しません。
