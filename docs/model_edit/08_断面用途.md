# 主架構線材の断面用途

主架構線材の設計上の用途は、断面に指定する `FrameSectionUse` で決まります。`Beam`、`Column`、`Brace` のいずれかを明示し、断面符号や部材の角度から推定しません。傾斜した Column は柱、勾配のある Beam は梁として扱います。

`ElementKind::Beam` は柱を含む曲げフレーム要素の解析定式化です。`ElementKind::Brace` はトラス定式化と `tension_only` を表し、Brace 用途の断面だけを割り当てられます。Beam 要素には Beam または Column 用途を、Brace 要素には Brace 用途を割り当てます。不整合や用途未設定は拒否します。

床・壁の断面に主架構用途は要求しません。二次部材は `SecondaryMemberKind` が正であり、小梁（Joist）は Beam 用途、間柱（Post）は Column 用途を使います。Brace 用途は二次部材へ割り当てられません。

断面の同一性は断面符号と階の組で決まり、用途違いを暗黙の使い回しで解決しません。形状編集と複製では用途を保持します。幾何判定は局所座標・接続関係・式の適用条件の確認に限り、用途を変更しません。仕口パネルも用途で柱梁候補を抽出し、適用可否は別の幾何条件で判断します。

SCZ は用途を必須情報として保存します。ST-Bridge の Column、Beam/Girder、Brace の文脈を用途へ写し、二次部材は Joist/Post の規則を使います。用途競合は角度で解決せず、入力エラーとします。旧形式からの移行や用途復元の fallback はありません。

この用途は RC・S・SRC・CFT の柱梁検定、`ForceRegime::Auto`、`no_long_axial_column`、数量積算でも共通して参照されます。
