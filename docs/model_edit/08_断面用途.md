# 主架構線材の断面用途

断面作成パネルの「主架構用途」で、柱・大梁・ブレースのどれに使う断面かを指定します。
画面の「梁」は大梁を表します。用途は断面符号や部材の傾きから自動判定しません。
例えば柱を傾けても柱用途のままです。用途は柱梁の検定、長期軸力の扱い、
仕口パネルの対象選定、数量積算に影響します。

## 用途を選んで割り当てる

1. 下ドックの「モデル」→「断面」で、断面作成パネルを開きます。
2. 形状・寸法・配筋と「主架構用途」を選び、符号と階を指定して追加します。
3. 断面一覧で必要な材料を割り当て、対象の部材へ断面を割り当てます。
4. 部材と断面を選んで形状・材料・用途を確認し、準備計算の診断を確認します。

通常の柱・大梁のほか、断面をファイバーや多数のばねで表す柱・大梁でも用途の指定が必要です。
柱・大梁には対応する柱または梁用途、ブレースにはブレース用途の断面を使います。
用途が未設定または不一致なら、理由を示して割当や計算を拒否します。
ブレースは軸力で抵抗する部材であり、用途を変えるだけで柱梁の曲げ部材にはなりません。

断面の符号と階が同じなら同じ断面です。用途の異なる断面を使う場合は、別の符号と階の組で作成してください。
形状の編集・断面の複製では元の用途を引き継ぎます。形状や角度を変えた後も、意図する用途か確認してください。

## 形状と割当先の対応

RC の梁型・柱型と CFT は、次の範囲に限ります。

| 断面形状 | 主架構で選ぶ用途 | 二次部材での使用 | 床板・壁版 |
| --- | --- | --- | --- |
| RC 矩形梁 | 梁（大梁） | 小梁 | 使用不可 |
| RC 矩形柱 | 柱 | 間柱 | 使用不可 |
| RC 円形柱 | 柱 | 間柱 | 使用不可 |
| CFT 角形・円形 | 柱のみ | 使用不可 | 使用不可 |

RC 梁型を柱・間柱へ、RC 柱型を大梁・小梁へ割り当てることはできません。
円形 RC 梁と RC ブレースは非対応です。大梁と小梁、柱と間柱は、それぞれ同じ対応形状の断面を共有できます。
未使用または二次部材だけに使う RC 断面では主架構用途が未設定でも構いませんが、
用途を指定する場合は表の対応に従います。

小梁・間柱は、配置時に選んだ二次部材の種別で区別します。
断面用途を指定しても、二次部材を主架構へ変更することにはなりません。
CFT は本製品では主架構柱専用です。柱用途を指定しても、小梁・間柱には使用できません。
領域内に配置した二次部材と、所属領域が未割当の二次部材に同じ条件を適用します。

RC 梁型・柱型は、主架構用途を未設定にしたり板厚を別途指定したりしても板用には使えません。
床板・壁版には板用断面、または各機能の適用条件に合う板厚・材料を指定した数値入力断面を使ってください。
[床の断面と自重](../calc_basis/01_荷重/08_床の断面と自重.md)と
[壁の断面と自重](../calc_basis/01_荷重/09_壁の断面と自重.md)で必要な入力を確認できます。

既に使用中の断面を変更するときも、使用先との対応を確認します。不一致の変更は適用せず、
元のモデルと Undo/Redo 履歴を保ちます。配筋・部材・版を削除したり、別の形状に置き換えたりして適用することはありません。
不整合なモデルは保存・読込・数量積算・解析でも拒否します。保存を拒否した場合は既存ファイルを上書きしません。
断面が未割当のまま編集・保存できることと、荷重・数量・解析を計算できることは別です。

鋼・SRC 断面も割当先の主架構用途と必要な材料を確認してください。
CFT は「材料」に充填コンクリート、「内蔵鉄骨・鋼管」に鋼管材料が必要です。
材料欄と形状表示の読み方は[断面の符号と階](02_断面の符号と階.md)を参照してください。

## 取り込んだモデルの確認

ST-Bridge の柱・大梁・ブレースは、それぞれの部材種別から主架構用途を設定します。
小梁・間柱だけから主架構用途は決めません。同じ断面を大梁と小梁、柱と間柱で共有できますが、
柱と大梁など主架構用途が競合する断面は入力エラーになります。
取り込み後も、断面一覧と部材の詳細で用途・形状・材料を確認してください。

## 線材の両端

主架構の柱・大梁・ブレースは、異なる二つの節点を両端に指定します。
断面未割当の床境界線にも同じ条件を適用します。節点が不足する場合、三つ以上指定した場合、
同じ節点を両端に指定した場合は、対象部材と入力内容を示して拒否します。
先頭の二点だけを使ったり、自動分割したりしません。拒否された追加では、
モデル・版割当・計算結果の有効性・Undo/Redo 履歴は変わりません。
小梁・間柱は、節点の直接指定ではなく支持部材と取付き位置を指定します
（[立体グリッドとスナップ](04_立体グリッドとスナップ.md#小梁間柱を領域内へ配置する)）。
