# 文字と状態表示

数値や文章を読む内容面・入力面は白、周囲はごく淡い青灰色を基調とします。
ツールバーとグループ見出しは明るい青、ステータスバーは淡い青紫です。
主要操作は淡い青のボタンと濃い文字で示します。

ツリー、選択対象の属性、荷重・解析条件、表、結果、検討、ダイアログは、
控えめな太細とかすれのある青灰色の枠でまとまりを示します。
表の内部は細い罫線で区切り、行や数値の密度を保ちます。
枠の質感はモデル形状・寸法線・応力図・グラフのデータ線には適用しません。

名称が長い場合の確認方法は
[名称と属性の確認](06_画面構成と工程タブ.md#名称と属性の確認)、
表の範囲選択と入力先は[テーブル編集とグリッド操作](07_テーブル編集とグリッド操作.md)を参照してください。

## 選択・入力先・検定状態の見分け方

| 表示 | 意味・確認方法 |
| --- | --- |
| 一覧や主領域の淡青背景と「▸」 | 選択している対象を示します |
| 白い面の一時的な淡青表示 | ポインタを重ねている操作欄を示します |
| 入力操作欄の輪郭 | キーボード操作の対象を示します。表のアクティブセルは別途識別されます |
| 「良好」「注意」「超過」 | 検定比の状態を文字と色で示します。色だけで判断せず、検定値と内訳を確認してください |
| 白い入力欄と参照値 | 入力できる値と、属性・結果として読む値を区別します |
| 無効な数値欄 | ポインタを重ねると、その項目を編集できない理由を確認できます |

結果文字の状態色と、応力・検定比のコンターやヒンジ図の色は別です。
図の意味は凡例と[結果の表示](../result_view/README.md)で確認してください。
表示が変わったことだけでは、計算結果の更新や検定の適合を意味しません。
