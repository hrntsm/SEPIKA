# 断面案の検討

ナビゲータの「検討」から「検討・設計案を開く」を選ぶと、本案を変更せずに鉄骨大梁の断面を比較できます。図で比較したい既存の鉄骨大梁を選択し、「選択した鉄骨大梁・全ケース・全組合せで検討作成」を押します。目的と注記は検討内で編集できます。選択した部材は固定され、作成後の図の選択では変わりません。対象を選ばず、基準案だけを確認する検討も作成できます。

## 案の編集と表示

検討には開始時の本案全体と解析・検定条件を保持する基準案があります。基準案は読取専用です。「基準案から比較案を作成」で独立した案を追加し、名前を付けて「表示」で切り替えます。通常の図と部材表で編集できるのは、固定した鉄骨大梁への既存の有効な大梁断面の割当だけです。材料・断面定義・支点・入力荷重・対象外の部材は変更できません。

本案と各比較案はそれぞれ Undo / Redo を持ちます。案ごとの表のドラフトや保留した断面割当を分離して保持します。案の切替などで既存のセル確定・検証が行われる場合は、その規則に従います。不正な途中値を確定できないときは値と理由を表示し、モデルには反映しません。すべての途中文字列が切替後もそのまま残ることを保証するものではありません。本案に戻ると通常の編集ができます。結果を保持した案は、その根拠が失われるため削除できません。結果のない比較案は削除できます。

## 計算と結果の確認

作成時の全荷重ケース・全荷重組合せを指定し、解析・検定条件を固定します。任意の部分集合や、検討内で計算条件を変更する操作には対応していません。条件を変えて比較する場合は、本案で条件を設定して新しい検討を作成してください。

各案の「計算」は、基準案も含め、モデル全体の準備計算、線形静的解析と対応する検定、数量積算を行います。部材断面に応じて自重・質量・自動荷重などを再算定します。入力荷重の固定は、これらの派生値の固定を意味しません。準備計算に必要な標準荷重ケースも同じ条件で生成します。基準案そのものは準備計算で上書きされません。

計算はアプリ内で一件ずつ実行します。別の計算を要求すると、実行中であることを表示します。未設定の床板・壁版割当領域が残るときは、その対象と過小評価し得る影響を確認してから「続行して計算」を選びます。準備開始から完了までのすべての通知と診断は、保持した計算の「注意・診断」と、計算時入力を表示したときの通常のログ・診断パネルで確認できます。直近の通知が更新されても、以前の警告本文は残ります。

計算中も案の表示や編集を続けられます。完了結果は開始時の案・入力・条件の履歴になります。編集後の案の最新結果に読み替えません。「計算開始時入力を表示」で前処理前の入力を、「準備後入力・結果を表示」で派生値を反映した入力と結果を、通常の図・表から読取専用で確認してください。検定・数量の表示も、この入力に基づきます。保存済み結果の参照からも、対応する計算時入力を表示できます。

保持した計算も、通常の保存結果と同じ計算契約・生成入力・標準パネルの適用条件を確認して表示します。契約版が欠落・旧版・未来版の結果や、生成入力が欠落・不一致の結果、標準パネルについて保存結果の利用条件を満たさない結果は、有効な図表として利用できません。表示される理由を確認して再計算してください。検討に保存した入力・結果の原本を、失効判定で書き換えることはありません。

本案を検討開始時から変更した場合は、その旨を検討内に表示します。保持した履歴の閲覧と、現在の本案へ採用できるかの判断は別です。本案への採用は、次の確認操作で行います。

## 変更と計算結果の比較

検討の「変更・結果を比較」で、基準案とすべての比較案の指標、断面変更、未評価範囲を表示します。左右の案選択では任意の2案を図に並べられます。比較案数に3案等の上限はありません。

断面変更表は表示している計算の開始時入力と基準案を比べ、部材番号、部材符号（基準案の断面名）、階、変更前後の断面、対象数を示します。独立した部材符号の入力欄はなく、固定した基準案の断面名と部材番号を併記します。行の部材番号を選ぶと両図で対応部材を選択します。案を再編集しても、保持した計算時の断面へ現在の変更を混ぜません。比較画面を開いた時点の計算を固定し、ケースの切替や通常結果への移動も、その固定した計算の中で行います。別の案編集や再計算の後にケースを切り替えても、新しい計算を混ぜません。「再表示」だけが、その時点の案と最新の保持計算へ変更表・数量・変位・検定・図をまとめて更新します。

図は読取専用です。荷重状態は上部の共通ケース／組合せ指定に揃え、図内では変更しません。図は表示された単一ケースの結果であり、指標表の「同ケース集合内の最大」と区別します。左図で方向・構面・図倍率を選び、「左の方向・構面・図倍率を両図へ揃える」で右図にも適用します。変形は既定で共通の絶対表示倍率100倍を使用し、共通欄で変更できます。共通を解除すると、各図の自動倍率と手動係数を使います。応力コンターは図ごとの自動範囲、検定比の色は共通の0〜1と1超のNG色です。個別範囲の色だけから大小を判定しないでください。

### 指標と差

すべての差は **案−基準案** です。左右に選んだ図の差ではありません。単位・対象・入力条件・ケース定義・範囲の一致を確認できないときは差や悪化を判定しません。自動順位、総合点、改善率、最適案の決定は行いません。

| 指標 | 対象と定義 |
| --- | --- |
| 対象鋼材体積 [m³] | 検討作成時に固定した鉄骨大梁の集合を、既存の数量積算の明細から集計します。鉄骨重量を数量用単位重量7.85 t/m³で換算し、鉄筋は含めません。建物全体の数量ではありません。固定対象なしや明細欠落は状態を表示します。数量の集計元が未計算の入力か、保持計算の準備後入力かを区別します。 |
| 指定変位 [mm] | 同じ節点、全体座標X/Y/Z成分、指定荷重ケースまたは組合せの符号付き値を比較します。正負・ゼロを保持し、大小から改善を判断しません。 |
| 最大検定比 [無次元] | 同じ対象集合・項目・長短期等の検定条件とケース定義集合について、算定済み範囲の最大を示します。「同ケース集合内の最大」と「指定ケースのみ」を切り替えます。支配部材・位置・ケースは各案で異なり得ます。集合・定義が同じまま支配ケースだけが変わった場合は、その旨を表示します。 |

検定比は、検討の固定対象集合だけの算定済み最大・基準との差・支配部材／位置／項目／ケースを先に表示し、今回実行した主架構検定全体の最大・件数を別に表示します。固定対象外の柱等が全体を支配しても、固定対象大梁の結果は独立して確認できます。

数値の「根拠」から、固定した対象・値・計算時入力と通常結果へ戻れます。AIの説明や注記は計算値に混ぜません。

### 全体への影響と未評価範囲

変更対象の詳細に加え、今回実行した既存主架構検定の行を集計します。粒度は部材×検定位置×ケース、接合部種別×節点×ケース、耐震壁項目×ケースです。同じ部材が複数ケースでNGなら複数行として数えます。検定比1超をNG、算定不能を未検定として分けます。空の検定成分や不正な数値も有効な0にはしません。

位置別の「変更外の悪化」は、同条件で部材内位置と検定項目集合が完全一致する行で案の比が増えた場合です。検定位置が移動した場合、位置の順番から同一位置を推定せず、基準・案それぞれの未比較位置数を表示します。

別に、変更外の部材×ケースごとに、その計算で算定済みの全位置の最大比を集計します。各案の実際の支配位置・項目と基準／案の未検定数を示します。断面変更でフェイス等の位置が動いても、同じ部材とケースの全位置最大という範囲で比較できます。ただし、軸力と構造規定等の検定項目集合が異なる場合や、未検定・欠落により評価範囲を比較できない場合は、両方の値・状態と理由を示し、差・悪化・新規NGを判定しません。位置移動と検定項目の不一致は区別します。両案それぞれの根拠ボタンから、対象図と対応する計算根拠へ移動します。

「新規NG」は、比較可能な評価位置・項目集合で、基準の比が1以下から案で1を超えたと確認できた場合です。基準側の未検定・欠落・位置集合差がある部材包絡は新規NGと確定せず、「案側NG・基準未評価／未比較あり」として区別します。算定済み範囲の最大や差を、未評価位置の合格へ読み替えません。

未検定を含む場合の最大は算定済み範囲の最大であり、全対象の安全確認ではありません。固定対象・全体の最大値の差は、実際に算定済みか未検定かを位置・項目ごとに照合します。未検定件数が同じでも、基準と案で未検定の位置や項目が異なれば差と支配ケース変化を判定しません。部材×ケースの全位置が両案で算定済みなら、支配位置の移動を許して最大値を比較できます。空・非有限・負の検定成分は、比較表・共通の根拠・通常の検定比図と表で一貫して未評価とし、0やOKへ置き換えません。正常位置と不正・未検定位置が混在しても、算定できた正常位置だけで部材や節点を合格色にしません。全位置が未評価なら未検定表示を残し、確認済みNGと未評価が併存する場合は両方を示します。未評価を含む節点の適合値は凡例の最大・合格色へ集約しません。凡例の最大は算定済み範囲であり、壁の凡例と通常表でも不正成分を未検定の項目数へ含めます。計算時に保持した部材・検定位置・接合部・壁の対象と検定項目の範囲を、保存結果と照合します。部材結果全体、空の検定位置、一部の検定項目の欠落も未評価にします。この照合情報自体がない履歴は現在入力から補わず、再計算してください。比較図、保持した通常結果、共通根拠でも同じ範囲照合を行い、欠落を除いた低い比へ読み替えません。範囲を取得できないケースは行数も未確定であり、未検定0行として件数へ補完しません。

ケース結果やケース別検定根拠が欠落している場合は、両案で同じケースが欠けていても完全な集合比較として扱いません。未計算、計算失敗、古い結果、未対応、欠落を0や合格で補いません。床板・二次部材の設計、未実行ケース、動的・終局・保有耐力はこの集計の対象外です。

条件の照合は計算開始時の支点・拘束、ユーザー入力荷重、解析／検定設定、ケース・組合せの実定義と対象で行います。名前や番号の一致だけで認定しません。断面変更に応じて準備計算で再算定した自重・自動荷重・質量は派生差として区別し、各案の準備後入力と通常結果で確認できます。

検定のNG件数と未検定件数は、同じ行が両方へ入る場合があります。耐震壁の検定件数は原本の対象内行数であり、対象外行やNG・未評価の併記による表示行を分母へ加えません。同じ位置の有効な検定項目がNGで、別項目が欠落・非有限・負の場合は、確認済みNG値と未評価を併記します。この行は完全算定とせず、差・改善・新規NGの判定には使用しません。有効な成分がない場合に検定比0を補いません。

この確認済みNGの表示は、生成時の対象・位置・項目構造、計算入力、実行の共通確認を通る根拠に適用します。構造や生成情報が欠落して根拠全体を利用できない場合は、残存数値を再認証せず、集計不可・欠落理由・範囲未確認を表示します。

取得できた検定行がない場合、件数欄は「集計不可・範囲未確認」です。一部のケースや対象のみ取得できた場合は、件数欄自体に「部分集計（取得済み範囲のみ）」と表示します。固定対象集合が空の場合は「対象なし」と表示し、NG0や未検定0とは区別します。

## 確認した変更の採否

「変更・結果を比較」で、比較案の「結果と断面変更を確認して採否へ」を選びます。変更表の部材・前後の断面・対象数、固定条件、対象鋼材体積と指定変位、固定対象と主架構全体の検定、変更外の悪化、未検定・未対応・既存警告を確認してください。未計算・古い結果・失敗の場合は、案の「計算」や保持計算の注意・診断へ戻ります。人が作成した案も、外部から作成された案も同じ確認操作を使います。

理由は任意です。「確認済みの変更一式を本案へ採用」で、固定した鉄骨大梁の断面割当変更だけを一括で反映します。「不採用として判断を記録」は本案を編集せず、確認した入力・条件・結果と理由を残します。採用は計算完了や検定OKを意味しません。NG・未検定・未対応は採用後も別の状態です。

確定時には本案の入力・計算設定が基準案と一致すること、比較案が確認した時点から変わっていないこと、対象と断面が有効であることを再確認します。本案が異なるときは「本案を表示して新しい基準の検討へ」から本案へ戻り、対象の鉄骨大梁を選び直して新しい検討を作成してください。表示の変更や保存再読込だけでは不一致にしません。表示する応力の長期・短期が切り替わっても、荷重ケース・組合せの定義を変えなければ本案の入力変更とは扱いません。Undoで入力と設定が基準と完全に一致する状態へ戻れば採用できます。比較案を編集・再計算した場合は「再表示」で変更と結果を更新し、確認し直します。未確認の新しい結果へ自動で置き換えません。

変更がない場合や反映済みの変更は重複して適用しません。一部の変更だけを採用する操作はありません。必要なら比較案を修正し、再計算・再確認してください。一部を適用できない場合は変更一式を適用しません。

採用直後は一度のUndoで断面割当を戻せます。後続編集がある場合は通常のUndo順です。Redoは採用時の断面割当を再適用し、その後に比較案を再編集しても内容は変わりません。本案の結果は要再計算となり、比較案の結果は本案へ移植しません。

検討の「判断」には採否・理由・判断時入力と結果への入口を残します。「採用をUndoで取消」と、採用後に現在の本案が採用時入力から変わった状態を分けて表示します。採用履歴があることを現在の本案の適合確認へ読み替えないでください。判断時の根拠は比較案の再編集でも変わらず、保存再読込後も確認できます。過去セッションのUndo／Redoは復元しません。

## 外部AIからの参照・比較

「図・表・結果からAIへ依頼」で短い目的を入力し、「根拠の確認のみ」または「断面の比較案を作成」を選びます。確認のみでは節点・RC部材等の選択も使え、比較案の作成や入力変更を求めません。比較作成の対象は既存の鉄骨大梁です。

数値の確認を依頼する場合は、結果の方向・成分の「根拠」を開き、「この根拠からAIへの依頼を作る」を選びます。そのケース・方向・成分を含む参照を固定します。形状図や表の選択だけから、未指定の結果や成分を依頼対象へ追加しません。根拠と現在表示の入力版が異なる場合は、元の保持結果・図表を明示表示してから依頼を確認してください。

数量の根拠から確認のみの依頼を作る場合は、その根拠の「モデル全体」または「固定した部材集合」を数量の固定範囲とします。画面で別の部材を選んでも範囲は変わらず、部材選択がないことを「対象なし」にはしません。コピーする情報には数量の元入力・範囲・識別を含め、モデル全体は含めません。数量入力が異なる場合は依頼を作成せず、一覧の「依頼時の固定入力を表示（読取専用）」等で元の保存入力を明示表示してから再確認してください。数量範囲を比較案の編集対象へ変えることはできません。

入力途中の値は元の表・フォームで適用します。「未確定入力を取消して対象を確認」は、入力ドラフト・編集中のセル・保留割当を取り消して、確定済みの入力を依頼対象にします。案名・固定対象数・階／通り・計算条件・変更範囲を確認し、「この対象・条件で未開始の依頼を保存」を押します。作成後の選択変更では対象は変わりません。確認から保存の間や開始前に元入力が変わった場合は、対象を再確認してください。保存入力の確認は、元の読取専用入力を明示した依頼と、接続時の旧版閲覧許可が必要です。

「依頼時の固定入力」は依頼元の案のその時点の入力であり、検討の基準案とは別です。変更済みの比較案から依頼した場合も、依頼時の断面を表示します。本案からの依頼は実際の本案の入力版と照合し、保存した確認用コピーが一致するだけでは現行版としません。本案を後から変更した場合は開始前に再確認し、以前の成果は古い版・要再計算と表示します。依頼時の入力と根拠は引き続き読取専用で確認できます。

一覧の「依頼時の対象を図表で確認」は、選んだ依頼の固定入力を読取専用で開きます。同じ入力・対象の依頼が複数あっても、選んだ依頼の目的を表示します。

一覧の固定入力から新たな確認依頼を作る場合も、保存旧版の閲覧許可が必要です。再接続時にその許可を外すと、以前の要求の再照会や保存済み応答からも入力・根拠を取得できません。過去の許可を自動的に引き継ぐことはありません。

「AIへの依頼一覧・成果」の「依頼文と識別情報をコピー」で、目的・検討と依頼の識別・対象参照・条件を外部クライアントへ渡します。全体モデルをクリップボードへ出力しません。コピーや接続だけでは依頼は未開始のままです。

「検討・設計案」の「外部AIへのローカル接続」で有効化し、外部クライアントの接続確認後に対象検討と権限を許可します。読取範囲は基準・比較案の全体モデルと条件・候補断面・保持結果で、編集範囲は固定鉄骨大梁の比較案への断面割当です。読み取りと編集の範囲を別々に表示します。

確認のみの依頼は根拠の閲覧と説明提出だけを行い、比較案の作成・編集・計算を拒否します。比較依頼でも本案更新・最終採用は人が行います。外部AIの操作は現在の表示案・選択を切り替えません。計算時の確認待ちはGUIに残り、AIが警告を承諾することはできません。

ローカル接続でも外部クライアントからクラウドAIへ情報が送られる可能性があります。クライアント側の保存・送信はSEPIKAの管理範囲外です。クライアント切断で接続先と許可を終了します。再接続は人が再有効化し、新しい接続先と新規承認を使います。解除・切断は計算停止とは別で、再読込時に以前の許可を復活させません。実際の起動手順は[MCPのビルドと起動](../mcp_server/01_ビルドと起動.md)を参照してください。

依頼文を保存・コピーした後、ローカル接続を有効化し、「MCP起動引数をコピー」の内容を外部MCPクライアントへ設定します。クライアントの接続後、対象検討・確認のみか比較編集か・旧版閲覧をGUIで確認して許可し、コピーした依頼文をクライアントへ渡します。

| 依頼の状態 | 確認できた内容 |
| --- | --- |
| 未開始 | 依頼を保存したが開始を受理していない |
| 作業中 | 外部クライアントの明示開始を受理した。AI内部の処理は未観測 |
| 計算中／人の確認待ち | SEPIKAの実計算ジョブ／続行確認待ち |
| 成果提出済み | 説明・未確認事項・根拠参照の提出を受信した。計算成功・検定合格・採用とは別 |
| 失敗／接続中断・継続未確認 | 実計算の失敗と理由、または接続終了や再読込後の継続未確認 |

一覧には最終確認操作・UTC日時・経過時間を表示します。AI内部の思考や未計測の進捗率は表示しません。接続を解除しても受理済み計算は継続し、計算停止には対応していません。再読込で以前の作業が継続・成功したとは扱いません。

説明は「AI由来の補足説明」として表示し、未確認点、元入力が現行版か古い版か、提出時の計算・検定状態、根拠の取得可否を別々に確認します。古い版は要再計算です。利用者が一覧のボタンを押したときだけ、元の固定入力・根拠図表・変更と比較表を開きます。AI通知では視点・選択・画面を変更しません。

依頼時の対象を開く操作は、節点・部材等は図、断面・材料・荷重ケース・荷重組合せは表、振動ケースは詳細を表示します。図を持たない対象に図表示を要求せず、いずれも依頼時の保存入力を読取専用で確認します。

比較案の最新計算を確認した後は、通常の「確認した変更の採否」へ進みます。未接続・切断・失敗後も「手作業で表示」から案を編集・計算・比較でき、AI専用の編集ロックはありません。「人による補足・判断理由」は提出された説明とは別に編集できます。この本文だけの変更も未保存になります。依頼の目的・固定対象・説明・根拠・状態は検討に保存されます。

## 保存

通常の保存は、表示している案にかかわらず、本案の解析・検定設定を含め、本案とすべての検討を一つの OVIKA ファイルに保存します。検討・案・注記・保持した結果の変更も未保存の印に反映されます。

検討には、開始時の本案、固定対象、各案の現在入力と条件、保持した計算の開始時入力と準備後入力、結果、数量、警告、生成日時とアプリ版を保存します。案を再編集しても保持した計算時入力は変更されません。計算履歴の入力を表示中に作成した固定対象・結果参照も保存します。案を切り替えても、開始時入力と準備後結果のそれぞれのビューで保持され、保存参照から対応する入力を再表示できます。結果の表示対象を切り替えて検定が再生成された場合も、参照として保存した検定はその入力・条件・応力の根拠とともに保持します。参照しない閲覧時の再検定をすべて保存するものではありません。

数量の「体積・数量の対象と集計時入力を見る」で固定数量根拠を開き、「この固定数量根拠を検討に保存」を選ぶと、その時点の案・入力版・全体の数量入力を検討に保持します。未計算の基準案や比較案でも利用でき、比較案ゼロの検討にも保存できます。本案を表示中は保存先が未指定のため、保存先の検討で元の基準案・比較案または計算履歴を表示してください。保存した根拠は検討の「固定数量根拠」から再表示できます。閲覧だけでは新しい注記を作成しません。固定数量根拠を持つ案も削除できません。

結果・数量の根拠窓から「本案の断面入力を編集」「本案の材料入力を編集」を選ぶと、本案へ移って通常の入力表を開きます。比較案の材料・断面定義を編集する操作ではありません。「元の結果へ戻る」で元の案または読取専用の計算時ビューと図表配置へ戻ります。計算時入力の窓から本案の入力表へ移った場合も、閲覧を閉じると元の表示へ戻ります。

再読込後は外部接続や AI がなくても履歴を閲覧し、基準案や比較案を再計算できます。Undo 履歴とすべての編集版は保存しません。検討を含む保存では、本案の動的ケースの定義も保持します。対応する計算結果を保存していない場合は、ケース定義があっても結果を確認済みとは扱いません。

実行中の計算を保存済みの成功結果にはしません。再読込時に計算を自動再開しません。保存後に計算が完了すると、新たな結果は未保存になります。
