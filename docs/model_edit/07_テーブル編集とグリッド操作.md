# テーブル編集とグリッド操作

下ドックの各テーブル（節点・部材・荷重など）は、セル単位の入力に加えて、スプレッドシートに
近い操作で編集できます。Excel で座標表や荷重表を組み立ててからまとめて貼り付ける流れを
想定したもので、矩形選択・コピー＆ペースト（Excel と相互に TSV）・キーボード移動・
Undo/Redo を備えます。

対象は節点テーブルの座標3列と、材料タブの「材料定数のグリッド編集」です。
材料一覧の名称・区分・Fc/Fyなどの単一編集は一覧で行い、TSVの矩形選択はその下の数値グリッドで行います。

| 表 | TSVの列順 | 単位 | 編集条件 |
| --- | --- | --- | --- |
| 節点 | X・Y・Z | mm | 末尾行の追加に対応 |
| 材料定数 | E・ν・ρ・強度割増係数 | N/mm²・無次元・t/mm³・無次元 | 標準普通コンクリートのEは編集不可。行追加は不可 |

材料のID・名称・区分・Fc・FyはTSV編集対象外です。Fc/Fyは材料一覧で単一編集できます。
材料グリッドの空の割増セルは自動設定を表し、貼り付け時の空欄はその設定を維持します。
材料グリッドのセル操作は、3Dの幾何選択や材料一覧で開いている対象を変えません。

**実装参照**：操作レイヤは `sepika_app::grid`（`crates/sepika-app/src/grid/`）に置き、節点テーブルへの適用は `sepika_app::app::node_grid::NodeGridAdapter`（`crates/sepika-app/src/app/node_grid.rs`）が担います。材料定数は `sepika_app::app::material_grid::MaterialGridAdapter`（`crates/sepika-app/src/app/material_grid.rs`）が扱います。描画は `sepika_app::grid::GridWidget`（`crates/sepika-app/src/grid/widget.rs`）です。

## 選択

- セルをクリックすると単一選択、ドラッグすると矩形選択になります。
- **Shift+クリック・Shift+矢印**では、選択の起点（アクティブセル）を動かさずに選択端だけを
  広げます。
- 行ヘッダで行全体、列ヘッダで列全体、左上コーナーまたは Ctrl+A で全選択します。
- 表の外をクリックするか Esc を押すと選択を解除します。

アクティブセルは選択の起点に留まります。移動の基準にもなります。

グリッドのセル・列・矩形選択と、3D に表示する節点・部材の幾何選択は独立しています。
座標セルの選択・編集・コピー・貼り付け、Ctrl+A、Esc や表外クリックによるグリッド選択解除では
幾何選択は変わりません。ただし、座標編集による生成壁の ID 付け替わりへの対処は下記のとおりです。
節点表の**行ヘッダ**をクリック、Shift+クリック、ドラッグしたときだけ、
実在する行の節点が幾何選択にも反映されます。複数行の場合は行選択の起点が個別表示の対象です。
末尾の「＋」まで Shift+クリックやドラッグで広げた場合も、「＋」は節点ではないため実在する行だけを幾何選択します。
「＋」を起点に実在行へ広げた場合は、節点を幾何選択しますが個別表示の対象は指定しません。
「＋」だけの選択や空の節点表での行ヘッダ操作では、幾何選択を変えません。
節点行を削除した場合や Undo/Redo では、ID の付け替わりによる誤選択を避けるため幾何選択と境界条件の編集対象を解除します。
準備計算の壁領域再構築で節点が削除された場合も、後続節点の ID が詰められるため同様に解除します。
部材表から支点の免震支承材を撤去した場合も、生成された地盤節点の削除で後続節点の ID が詰められるため、幾何選択と境界条件の編集対象を解除します。
境界条件フォームは、別の節点を幾何選択した場合はその節点を編集対象にします。幾何選択がないときの先頭節点表示はフォーム内だけの既定値で、フォームで明示的に節点を選んだときだけ幾何選択へ反映されます。セル操作では幾何選択を変えません。
壁版の断面変更で解析用の壁要素が増減する場合も、生成壁の選択は解除します。後続の壁要素の ID が付け替わるためです。
生成の可否が変わらない断面の差し替えでは、同じ壁・他の壁のどちらを選択していても幾何選択と個別表示の対象を保持します。
存在しない断面など、適用されなかった断面指定でも選択は解除しません。
壁版割当領域への割当・版なし・未設定への変更時は幾何選択を解除します。壁要素の生成・削除で ID が付け替わる場合があるためです。
3D・テーブルで二次部材を配置した場合と、テーブルで支持端を変更・二次部材を削除した場合は、操作が成功したときだけ生成壁を含む部材選択を解除します。
割当領域の再構築で壁版が取り除かれると、別の壁が以前の生成 ID を再利用する場合があるためです。
通常の主架構部材だけの選択と節点の選択は保持します。
節点表の座標編集・貼り付け・クリアでも、割当領域の再構築で生成壁の ID が付け替わる場合があるため、生成壁を含む部材選択は解除します。
この場合も、通常の主架構部材だけの選択と節点の選択は保持します。

幾何選択は節点と部材を同時には保持しません。3D や部材表などで個別の部材を選ぶと、
それまでの節点選択と個別表示は消えます。部材グループや断面の「使用部材を3Dハイライト」は
対象の部材全体を選びますが、個別表示の対象は指定しません。インスペクタは選択件数を表示し、
個別の対象がない複数選択では以前の詳細を表示しません。3D の背景クリックでは幾何選択を解除します。
断面・材料・荷重ケースなど各機能で開いている対象は、幾何選択とは独立して保持します。
材料・断面の一覧で開いている対象は、それより前の行を削除して ID が変わっても同じ実体のままです。
開いている対象自身を削除した場合は解除します。後の行を削除した場合や、参照中などの理由で削除できなかった場合は変わりません。
同じ操作で複数行を削除する場合も、残った同じ実体を開き続けます。
Undo/Redo でも残存する表示対象を維持し、削除後に別の実体を開いた場合はその実体を維持します。
削除によって解除された対象は、Undo で復元しても自動では開きません。材料の操作で断面の表示対象は変わらず、その逆も同じです。
部材断面の複製や階への複製で追加した断面を Undo で取り除く場合も、取り除かれた表示対象を解除します。
設計結果行の断面をクリックして断面一覧へ移動するときは、その行の部材を単一選択して個別表示し、開く断面もその行の断面に切り替えます。
生成壁を選択した場合もインスペクタに部材・断面を表示し、断面の使用部材数と「使用部材を3Dハイライト」には表示中の生成壁を含めます。

## キーボード

| キー | 選択モード | 編集モード |
| --- | --- | --- |
| 矢印 | セル移動（Shift で選択拡張） | カーソル移動 |
| Tab / Shift+Tab | 右 / 左へ移動 | 確定して右へ |
| Enter / Shift+Enter | 下 / 上へ移動 | 確定して下へ |
| F2 | アクティブセルを編集 | — |
| 文字キー | その文字を初期値に編集開始 | 文字入力 |
| Esc | 選択解除 | 編集キャンセル |
| Delete | 選択範囲をクリア | 文字削除 |
| Backspace | アクティブセルを空にして編集開始 | 文字削除 |
| Ctrl+C | 選択範囲を TSV コピー | 文字列コピー |
| Ctrl+V | TSV ペースト | 文字列貼り付け |
| Ctrl+A | 全選択 | 文字列全選択 |
| Ctrl+Delete | 行削除 | — |

Delete は**セル値のクリア**で、行そのものは消えません。行削除は右クリックメニューまたは
Ctrl+Delete です。Backspace は範囲クリアではなく、アクティブセルを空にして編集を始めます。

## 2 モード式の編集

セルには**選択モード**と**編集モード**があります。ダブルクリック・F2・文字キー・Backspace の
いずれかで編集モードに入り、そのセルの現在値を初期値として入力します。Enter や Tab で確定して
次のセルへ移り、Esc で編集を取り消します。

確定した値が不正（数値列に数値でない入力など）のときは変更せず、理由をイベントログに出し、
対象セルを赤くフラッシュします。空文字のまま確定した場合は「変更なし」として扱います。

<div class="impl-ref">

**実装参照**：セル確定は `sepika_app::grid::commit_cell_text`（`crates/sepika-app/src/grid/core.rs`）が検証し、失敗のフラッシュとログは `GridWidget`（`crates/sepika-app/src/grid/widget.rs`）が扱います。

</div>

## コピー・貼り付け（Excel 相互 TSV）

- **Ctrl+C** は選択範囲をタブ区切り（TSV）でクリップボードへコピーします。セルの文字列は
  内部値の正準文字列を使い、表示用に丸めた値は使いません。
- **Ctrl+V** は TSV を貼り付けます。**空セルは「変更なし」**として既存値を維持します。
- ヘッダーなしのタブ区切りを用います。LF・CRLFと末尾改行を受け付け、短い行の不足列は変更しません。
  指数表記は使用できます。単位文字列、式、桁区切りカンマの自動評価は行いません。NaN・無限大・数値範囲を超える指数表記は拒否します。
- 明示した0は0に変更します。空セルと区別してください。
- 1 セルでも不正（有限の数値として解釈できない値、編集不可のセル、貼り付け先が列をはみ出す）があれば
  **貼り付け全体を適用しません**。ブロック内の行・列と対象IDをイベントログに示します。空白だけの余分な列も拒否します。
- 選択範囲がコピー元ブロックの整数倍のときは、ブロックを繰り返して選択範囲へ広げます
  （タイル展開。フィルハンドルは未対応です）。
- 節点の貼り付けが末尾行を超える場合、確認なしで行を自動追加します。追加は貼り付けと
  あわせて 1 つの複合コマンドになるため、**Undo 1 回で行追加ごと戻ります**。
- 材料は末尾行を超えたブロック全体を拒否します。空白だけの超過行も含み、切り捨ては行いません。
- 一度に貼り付けられるのは、空セルを含む矩形で100,000セルまでです。タイル展開後も同じ上限です。
- 全空白ブロックは値やUndo/Redo履歴を変更しません。拒否された貼り付けも、モデル・履歴・結果の状態を変えません。
  成功した数値編集では解析結果・設計結果・準備計算・診断が古い状態となり、再計算が必要です。

SEPIKA内のTSV往復ではf64の正準文字列を用います。Excelの数値セルは有効桁数が15桁のため、
17桁の数値の厳密な往復は保証しません。必要な桁がコピー文字列へ出るセル書式と十分な列幅を用い、
「表示桁数で計算する」はOFFにしてください。たとえば15桁の数値には `0.00000000000000E+00` を使用できます。
正準文字列の全桁をExcel経由で保持するときは、貼り付け前にセルを文字列型とし、数値変換・計算を行わず戻してください。

出典：Microsoft Support「[Change formula recalculation, iteration, or precision in Excel](https://support.microsoft.com/en-us/excel/change-formula-recalculation-iteration-or-precision-in-excel)」、
Microsoft 365・Excel 2024・2021等のWeb版説明（版番号・頁なし）、Precision / Change the precision of calculations節。

<div class="impl-ref">

**実装参照**：TSV 変換は `sepika_app::grid::{rect_to_tsv, parse_tsv, tile_block}`、貼り付け検証は `sepika_app::grid::plan_paste`（`crates/sepika-app/src/grid/core.rs`）が担います。

## 新規行と行削除

- **新規行プレースホルダ**：行追加に対応するテーブルの最下部に、常設の空行を 1 行表示します
  （行ヘッダは「＋」）。まだデータではない行で、選択・貼り付けの起点・直接入力の受け口に
  なります。ここで入力すると 1 行追加され、空のテーブルへも貼り付けで一括投入できます。
- **行削除**：右クリックメニューまたは Ctrl+Delete で、選択が跨ぐ実データ行を削除します。
  参照されている節点を含む場合は、**1 行でも削除できないときは何も消さず**、理由を
  イベントログに列挙します。削除も Undo 1 回で元の位置へ戻ります。

<div class="impl-ref">

**実装参照**：行追加・削除の可否と適用は `sepika_app::grid::GridAdapter`（`crates/sepika-app/src/grid/core.rs`）の実装である `sepika_app::app::node_grid::NodeGridAdapter`（`crates/sepika-app/src/app/node_grid.rs`）が担い、節点の参照中判定は `sepika_core::model::Model::node_in_use` によります。

</div>

## Undo/Redo

セルの変更はすべて編集トランザクション（`sepika_edit` の編集コマンド）として適用します。
複数セルの貼り付け・範囲クリア・行追加・行削除は 1 つの複合コマンドにまとめるため、
**Undo 1 回で操作のまとまりごと戻ります**。上部ツールバーの Undo/Redo と共通です。

## 見た目

テーブルは Excel に近いスプレッドシート様式で、白地に共有罫線（隣接セルと
1 本の線を共有）を引きます。選択範囲は外周を青の太枠で囲い、内側を青の半透明で塗り、
アクティブセルだけは白抜きにして入力先を示します。選択に含まれる行・列のヘッダは薄い青で
ハイライトします。新規行プレースホルダのセルは淡いグレー地です。

不正・注意のフィードバックは、イベントログだけでなく対象の範囲を約 1 秒フラッシュして
示します。**赤は「何も適用されていない」**（貼り付けの全体拒否、編集の失敗、行削除の
全体拒否など）、**黄は「適用されたが確認が必要」**（コピー元と選択範囲のサイズが一致しない
貼り付けなど）です。

## 現状の制約

- フィルハンドル（ドラッグでの連続値埋め）・切り取り（Ctrl+X）・行挿入ペーストは未対応です。
- 列のソート・行の並び替えは未対応です。
- 選択ドラッグの表外への自動スクロールは未対応です。
- 文字列列の IME 入力は未対応です。現状の適用先は数値列のため実害はありません。
