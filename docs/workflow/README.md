# 準備・解析の実行・結果の確認

入力を確認して準備計算を実行し、解析結果を読む流れを扱います。

1. [準備計算](../preparation/README.md)で階・断面・剛性・荷重を確認します。
2. 解析種別と計算条件を選んで実行します。解析方式の適用条件と収束の扱いは[構造解析の方法](../calc_basis/05_構造解析/README.md)を参照してください。
3. [結果の表示](../result_view/README.md)で変形・応力・ヒンジ・検定結果を確認します。
4. 建物全体の判定に採用する応答は[建物全体の耐震評価](../calc_basis/07_二次設計/README.md)で確認します。
