# 構造解析の内部実装と旧性能記録

Issue #1023で製品本文から分離した開発補助情報。現在の実行条件・計算根拠・既定・適用範囲は[構造解析の方法](../docs/calc_basis/05_構造解析/README.md)を正とする。以下のAPI・旧測定値はGUIの利用契約や現行性能の保証ではない。

## 疎行列と分解の再利用

要素のTripletをCSCへ集約し、同一位置を加算する。疎Choleskyの記号解析と数値分解を分離し、同じ非ゼロパターン・剛性を使う複数右辺の求解で再利用する。実装入口は `sepika_math::solver`、`cholesky`、`lu`、`sparse`（`crates/sepika-math/src/`）。

スカイライン格納の帯内演算の目安は自由度数n・平均バンド幅bに対して O(nb²)。疎分解の資源量は因子のフィルインに依存し、入力順序から独立に一定になるわけではない。固有値の射影は疎行列積と部分空間積に分け、反復の目安は O(nnz·q+nq²)。qは要求モード数に伴って増えるため、自由度数だけに比例した性能とは解釈しない。

固定剛性は採用条件ごとに分解を共有する。基準固有値は長期軸低減や引張専用の最終剛性と分ける。線形Newmarkは有効剛性を再利用し、非線形の接線更新では数値分解をやり直す。再分解失敗後の以前の因子を再利用しない内部契約は `crates/sepika-math/src/cholesky.rs` と `lu.rs` を参照する。

## 非線形の試行状態

立体時刻歴は確定状態を基点に反復し、失敗した時刻の試行状態を取り消す。材料履歴だけでなく部材荷重・内部変形・応答も復元対象とする。記録の検査を終えてから履歴を確定する。入口は `crates/sepika-solver/src/dynamic/timehistory/nonlinear.rs`。利用者が確認する停止・結果の採否は製品本文に置く。

## GUI未接続の線形時刻歴再開API

`linear_time_history_from_state`（`crates/sepika-solver/src/dynamic/timehistory/linear.rs`）へ渡すステップsは、時刻sdtの確定状態を意味する。変位・速度・相対加速度を引き継ぎ、初期加速度を再計算しない。全積分区間数Tに対し残りはT−s区間、s=Tなら更新なし、s>Tは拒否する。

再開記録は開始点s、絶対ステップ番号の間引き格子、末端Tを残す。T=5、record_every=3、s=2なら2,3,5となる。GUIの途中状態ファイル保存・再開機能とは区別する。

## 並列処理の内部配分

設定総枠に対して、ケース並列数 outer=min(ケース数,総枠)、行列求解側 inner=max(1,floor(総枠/outer)) と配分する。バッチ終了後は設定値へ戻す。入口は `crates/sepika-solver/src/statics/analysis/mod.rs` と `crates/sepika-math/src/parallelism.rs`。

非線形の要素評価は独立に計算し、集約を要素順で行う。この集約手順だけの加算順序の一致を、行列ソルバまで含む解析全体のビット一致保証に拡張しない。
