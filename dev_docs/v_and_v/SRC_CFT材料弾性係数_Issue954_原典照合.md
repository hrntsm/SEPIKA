# SRC・CFT解析用材料E・Gと換算比の原典照合（Issue #954）

## 判定と範囲

2026-11-18、[Issue #954](https://github.com/hrntsm/SEPIKA/issues/954)の初期弾性解析用の材料定数を調査した。照合時の製品コードは `8c7e2669`。SRCの標準Es、Ecの式および曲げ剛性の累加に根拠を確認した。SRCには採用Gの不一致があり、表10.1と製品の既定Gの差、および明示Gによる鋼項の変動を確認した。純充填CFTは専用指針の本文照合が残る。現行の解析方式を維持し、採用条件と制約を[等価断面性能](../../docs/calc_basis/03_断面性能/06_SRC_CFT_の等価断面性能.md#出典と確認範囲)と[コンクリートのヤング係数](../../docs/calc_basis/03_断面性能/04_コンクリートのヤング係数_Ec.md#出典と確認済みの範囲)に記載する。

## 独立有限例と是正候補

弾性梁の公開入口 `BeamElement::try_new` と局所剛性行列を、3000 mmの部材に対して観測した。断面と材料値を固定して、SRCの基準GとCFTの鋼管Gの指定だけを変えた。SRCには中心H形鋼・鉄筋なし・スラブなしの矩形300×600 mmとH400×200×8×12 mm、CFTには外径400 mm・厚12 mmの円形鋼管を使用。両例のFcは60 N/mm²。以下の条件で再現できる。

- 節点を (0, 0, 0)・(3000, 0, 0) mmとし、始端を6自由度固定、終端を自由にする。部材の両端に回転解放を設定せず、局所軸の参照ベクトルは (0, 0, 1)。剛域、端部オフセット、柱梁接合パネル、付加荷重・部材を設定しない。
- 主材料は普通コンクリートで、初期カードをνc=0.2、密度2.4×10⁻⁹ t/mm³、G省略とする。SRCではカードE=33500、CFTではE=23000 N/mm²。CFTの専用鋼管材料はEs=205000 N/mm²、νs=0.3、Fy=295 N/mm²、密度7.85×10⁻⁹ t/mm³、形状からJsを求める設定とする。CFTの充填Ec=33500 N/mm²の期待値はFc60・γ=24から求める。
- 要素生成後に E×A、E×局所z軸まわりI、G×局所y方向As、G×Jを取得し、ねじりは局所剛性行列の終端材軸回転対角項に長さ3000 mmを乗じた値でも確認する。CFTの材料カード編集は鋼管Gの省略・明示ごとに同じ未編集モデルから開始する。

| --- | ---: | ---: | ---: | ---: |
| SRC Ec=33500、νc=0.2、G省略 | 7.369072000e9 | 2.179694936e14 | 2.301391026e9 | 5.177876287e13 |
| SRC 同じEc・νc、明示Gc=14400 | 7.369072000e9 | 2.179694936e14 | 2.374211160e9 | 5.341713567e13 |

SRCのEA・EIは、外形矩形と内蔵鉄骨の断面積・断面二次モーメントから独立に算定した。鉄骨は上下フランジとウェブの三矩形を足し合わせ、強軸はフランジ各図心の平行軸項を加える。コンクリートは外形矩形から内蔵鉄骨の断面量を引き、各材料のEを乗じて加算した。強軸せん断の同じ幾何モデルでは、単位変形当たりの二材料の抵抗はそれぞれ `20000 × (150000−3200)` と `78846.153846 × 3200` Nで、和は3188307692.308 N。ここで150000 mm²は外形のせん断有効面積、3200 mm²は鋼ウェブの有効面積。観測との差は109207807.118 N。明示Gcを倍率に使い、換算分母にはEcとνcから復元した13958.333を使うため、固定の内蔵鉄骨Gsが実効112973.594 N/mm²に変わる。ねじりでも鋼項に同じ倍率が掛かる。係数を表のGs/Gcに置き換えるだけでは、明示Gの扱いは揃わない。指定可能なGの組み合わせを定義し、基準Gと換算分母を一致させて鋼寄与を独立に保つか、使えない組み合わせを入力時に明示する必要がある。単一条件の差から架構全体の安全側を判定しない。

CFTでは鋼管の環とコア円を別に積分し、軸面積、曲げ・極二次モーメント、現行のせん断有効面積を材料ごとに計算して各剛性を加算した。明示Gs=61000の独立値はEA=6718308456.072 N、EI=89348847077839.47 N·mm²、GA=1737701115.966 N、GJ=61002862246807.22 N·mm²。実経路と表示精度で一致した。主材料カードをE=7000、ν=0.44、G=2300 N/mm²、密度1.4×10⁻⁹ t/mm³に同時編集しても、Fcと種類が同じなので四つの剛性は変わらなかった。円形の理論とコードの有限例であり、実部材の付着・変形と任意形状の精度を検証する実験ではない。

明示Gの不一致は[#712](https://github.com/hrntsm/SEPIKA/issues/712)の正・有限値検査と異なり、正の有限値で再現する。SRCのG・ポアソン比・せん断剛性・鋼寄与の既存課題検索で同一の是正を確認できなかった。是正対象はこの1件で、[#1424](https://github.com/hrntsm/SEPIKA/issues/1424)で追跡する。標準Gの規準表との差、CFTの軽量γ・実測値の採用条件は適用確認が残るため、数値差だけによる一律修正は提案しない。

## 採用Gcの是正後の検証（Issue #1424）

2026-11-19、[#1424](https://github.com/hrntsm/SEPIKA/issues/1424)の対象を上記のSRC矩形と同じ形状で確認した。SRC規準第6版第3刷の表10.1（p.9）は標準材料定数、解説11条（p.99）は平面保持によるSRC梁の曲げ剛性および累加、解説12条（p.100）は内蔵鉄骨の影響が小さい矩形部材のせん断変形の概算に対応する。表10.1のGの既定値採否、既存の両方向As・Jの形状式の一般適用、実測値の採用条件と実験Validationは未確認。[製品の算定条件](../../docs/calc_basis/03_断面性能/06_SRC_CFT_の等価断面性能.md#srcのコンクリート基準への換算)

独立計算では、強・弱軸のコンクリート有効面積をそれぞれ146800・145200 mm²、鋼を3200・4800 mm²とし、各材料の抵抗を加算した。ねじりは矩形の近似J=3707859375 mm⁴と三枚の鋼板の薄板近似J=883712/3 mm⁴に各Gを乗じて加算した。両方のGc条件で固定鋼項は252307692.308 N、378461538.462 N、23225764102.564 N·mm²。EAと強・弱軸EIはコンクリートと鋼の非重複領域から算定し、それぞれ7369072000 N、217969493589333.33・47971751317333.33 N·mm²となる。

変更前の公開梁試験では、明示Gc=20000 N/mm²のGJが74190466206773.83 N·mm²となり、独立期待との差で失敗した。ST-Bridgeの部材別強度に対する軸・曲げのEの選択は[#1522](https://github.com/hrntsm/SEPIKA/issues/1522)で追跡する。

数値表現の境界試験 `src_weak_axis_steel_shear_survives_large_concrete_g` では矩形300×600 mm、H550×300×8×250 mmを用いた。弱軸の外形と鉄骨の有効面積はともに150000 mm²で、弱軸GAは鋼の分担11826923076.923 Nに一致する。修正前の公開等価断面算定では、換算比から1を引く順序の桁落ちにより、Gc=10²¹ N/mm²で29103830456.734 Nを返し、Gc=10²² N/mm²では等価Asが0となって算定に失敗した。面積差と換算鋼項を別々に算定し、両条件で鋼の分担を確認した。Gcは丸めの影響を確認するための数値入力である。
