# 地震力標準式と適用診断（Issue #486）

## 対象と参照解

令88条・昭和55年建設省告示1793号第1～第3の標準経路と、その入力・適用診断の Verification。標準式は既存実装を維持し、実装出力でなく独立手計算を期待値とした。実測 Validation、全自治体の地域適合、特殊な調査・研究による例外の実装検証は含まない。重量の鮮度・再生成は #439、層間変形角は #490、Ds/Fes/Qud全体は #489 の範囲。

## 対象・入力・単位・適用条件の対照

| 対象 | 入力 | 単位 | 適用条件・診断 |
| --- | --- | --- | --- |
| 地上部 Ci/Qi（令88条1項、1793号第1～第3） | Z、Rt、Ai、C0、地上部累積重量 | 係数は無次元、重量・Qi/Piは N（表示kN） | 固定＋地震用積載、条件に応じ積雪。地下重量をαiへ含めない。全0/欠落/負/非有限重量、一般層αi=0を標準入口で拒否 |
| Z（告示第1の表） | 利用者指定のZと敷地の地方区分根拠 | 無次元 | 数値は有限の正数。入力値の形式検証は地域適合証明ではない。全自治体マスター・自動照合は未対応 |
| Rt/T/Tc（告示第2） | T、地盤I/II/III、Tc=.4/.6/.8 | s | T>0かつ有限。T<Tc、Tc<=T<2Tc、2Tc<=Tの分岐。地盤の実態条件を利用者が確認 |
| 略算T（告示第2） | h、α | h:m（内部mm）、α:無次元 | T=h(.02+.01α)。木造又は鉄骨階の高さ比が原文。製品は木造対象外、S造一般階の高さ比。GL・PH除外等の特殊な法令高さ適用を全面検証したとはしない |
| Ai（告示第3） | 地上部累積重量比αi、同じT | 無次元 | 通常式を使用。特別な調査・研究によるAi例外未対応 |
| 通常C0（令88条2項） | C0 | 無次元 | 有限かつ.2以上。一定の木造＋指定軟弱区域の.3は製品対象外。地盤IIIと行政の区域指定は異なる |
| 必要耐力用C0（令88条3項） | 二次設計採用値 | 無次元 | 法令下限1.0、製品採用1.0。Qud全体は#489。通常係数の.2ゲートと目的を区別 |
| 地下（令88条4項、住指96第三二(二)） | H、Z、当該層重量、直上Qi | H:m（入力mm）、重量/Qi:N | H有限非負、20m上限。K=.1(1−min(H,20)/40)Z。地下Qi=直上Qi+Kwi。動的性状による震度例外未対応 |
| PH指定震度の参考経路 | k、PH累積重量 | 無次元、N | kへZを再乗算しない。既存純数値経路を維持。通常Ai階と突出部局部法の適用証拠がないため標準入口では未検証として拒否 |
| Rtただし書 | 精算方法、初期剛性、境界条件、有効高さ、T、略算/精算/採用Rt | T:s、Rt無次元 | 弾性域（RCひび割れ前）、地盤/杭の変形を除外。必要証拠保存と適用検証が未実装なのでSemiPrecise標準荷重は理由付き未対応。数値Tだけは証拠でない |
| 荷重生成 | 階順、階/節点ID、剛床重量、指定Ci、水平質量、Piと分配先 | mm、N、質量は内部単位 | 階レベル昇順、種別地下→一般→PH。欠落/重複ID、負/非有限分配入力、副剛床重量超過、負Pi、非有限結果、合力不一致を拒否。K組立不要 |
| 任意Qi/Ci/T指定 | 層別直接指定 | N、無次元、s | 専用モード未対応。副剛床Ci指定とMCP参考周期を一般層の直接指定と同一視しない |

## 独立期待値と直接入口

許容差は係数/周期1e-12、荷重1e-8 N（丸め前期待値）とした。

| ケース | 独立期待値 | テスト |
| --- | --- | --- |
| Rt、地盤3種、境界両側 | T/Tc=.5,1,1.5,2,4 → 1,1,.95,.8,.4。Tcと2Tcの左右連続 | load `standard_formula_independent_values_and_boundaries` |
| h=30m、α=0/.5/1 | T=.60/.75/.90s | 同上 |
| 地上2層、各100kN、T=.5/Tc=.6/Z1/C0.2 | Q1=40kN、Q2=27.31370849898476kN、P1=12.68629150101524kN、P2=27.31370849898476kN、ΣP=40kN | load上記、solver `seismic_two_layer_entry_matches_hand_values_and_rejects_negative_pi`（分布と実荷重生成） |
| 地下H=0/20/25m、Z1 | K=.10/.05/.05、Qi=直上20kN+K×100kN | load `basement_and_specified_penthouse_independent_values`、solver `seismic_basement_entry_adds_above_shear_at_depth_boundaries`（分布とY荷重生成） |
| PH100kN、Z.8、k1 | 純数値参考Qi=100kN（Z再乗算なし）。K=Zの80kNとは別 | 同上＋solver `seismic_standard_entry_rejects_invalid_inputs_and_unsupported_routes` が標準入口の未検証拒否 |
| Rt精算下限の理論独立例 | max(.5,.75×.8)=.6、max(.7,.75×.8)=.7 | 手計算。実装例外は未対応なので実装済みとしてテストしない |
| 異常入力・適用不足 | 不正T/Z/C0、欠落/負/NaN/∞/0重量、地下深さ、PH/SemiPreciseはErr。C0=1では単層100kN→Qi100kN | solver `seismic_standard_entry_rejects_invalid_inputs_and_unsupported_routes` |
| αi=0/負Pi/分配欠落 | 一般層αi=0はErr。下層主重量0・全体100kN、上層主100kNで上Qi>下Qiとなる入力は負Pi Err。載荷先0は合力不一致Err | solver上記、`seismic_two_layer_entry_matches_hand_values_and_rejects_negative_pi`、`seismic_load_case_preserves_independent_resultant_and_rejects_missing_destination` |
| ID/階種別破損 | 階ID99、node99/重複、master99、一般→地下の順はErr | solver `seismic_entry_rejects_reference_corruption_and_wrong_kind_order` |
| GUI準備表・周期 | 不正C0はseismic=NoneとC0理由。固有値実行後も参考周期は取得可、標準表は未対応でNone | app `preparation_seismic_invalid_coefficient_is_not_a_zero_result`、`test_preparation_semiprecise_without_eigen_reports_note` |
| GUI旧結果 | 固有値再計算でも未対応精算の標準地震結果を有効にしない | app `精算周期は固有値を再解析しても標準地震結果として採用しない` |
| MCP実ジョブ | 旧Auto EXありでもC0=.1/SemiPrecise＋T=.5のLinearStaticはFailed | mcp `seismic_mcp_rejects_invalid_c0_and_unsupported_refined_period` |

loadの純数値APIは退化αi=0の0処理と負Piクランプを保持するが、適用検証を行わない参考計算とRustdocに明記した。solver/GUI/MCPの標準入口はその返値を合格・0荷重として採用しない。
