# 鋼断面形状とコンクリート主材料の曲げヒンジ表示の確認（#1290）

2026-11-19。基点 `c84ee862`、重量置換の追加確認は `4c6c0746`。[#1203](https://github.com/hrntsm/SEPIKA/issues/1203) の表示閾値選択表を追加した [PR #1291](https://github.com/hrntsm/SEPIKA/pull/1291) を起点に、組合せの到達性と式を確認した。状態は🔶。鋼断面形状にコンクリート主材料を割り当てた線材は、編集・保存読込で保持できる。通常の断面自重を求める解析準備と許容応力度検定は材料区分の不一致で拒否する。ダンパー総重量で自重を置き換える場合、正のFyがあると増分解析で曲げヒンジが記録される有限例を確認した。

## 現行の計算と製品入口

- [構造種別の分類](../../crates/sepika-core/src/structure_kind.rs) では、複合断面を除き主材料がコンクリートならRCになる。[共通My算定](../../crates/sepika-core/src/flexural_strength.rs) はRC専用の配筋形状、塑性断面係数を持つ形状、弾性断面係数を使う残りの順に選ぶ。鋼形状なら材料区分によらず、主材料のfy（なければ235 N/mm²）に鋼材用の強度係数を乗じ、強軸側Zpと掛ける。SRC・CFT専用形状にはこのZpがなく、主材料のfyまたは同じ代表値と、保存断面の弾性断面係数Zeの積を簡易値に使う。鋼管・内蔵鉄骨の強度や断面内の軸力分担は、この簡易値に入らない。
- [増分のヒンジ記録](../../crates/sepika-solver/src/nonlinear/pushover/hinge.rs) はSの形状付き断面でMc=Myとし、配筋形状等ではFcがある場合に Mc = min(My, 0.56√Fc Ze) を用いる。ここでのZeは max(Iy, Iz) を max(幅, せい)/2 で除した値。MyとMcは確定ステップの軸力で更新せず、各材端の二方向曲げの絶対値の大きい方を比較する。同じモデルを下位算定へ直接渡した場合、鋼形状とコンクリート主材料では、S以外の分岐でこのMcとZpを使うMyが併存する。
- [非線形要素の骨格](../../crates/sepika-element/src/factory/springs.rs) では、材端集中ばねの一部も共通Myを使う。材端集中ばねの応答は履歴則と初期剛性に基づき、履歴則によってはN–M相関を適用する。骨格上の降伏点と表示閾値が一致するかは、採用した骨格と解析条件に依存する。ファイバーとマルチスプリングでは断面を分割した材料応答から曲げ応答を求める。[ヒンジ詳細](../../crates/sepika-app/src/viewer/hinge.rs) の骨格・曲面の背景描画は、増分結果・当該部材のヒンジ記録・応答履歴を持つ場合に下位の [骨格取得](../../crates/sepika-element/src/factory/hinge_view.rs) を呼ぶ。

通常の断面自重の確認には、片持ちの長さ3,000 mmの水平梁1本を用いた。材端集中ばねを明示し、材料はFc24 N/mm²・E=25,000 N/mm²・ν=0.2・密度2.4×10⁻⁹ t/mm³のコンクリート区分。形状なしに変更し、断面諸量と主材料を維持した対照は、準備と下位非線形入力診断の両方を通過した。H形にSS400（Fy=235 N/mm²）を割り当てた対照も両方を通過した。MCPは公開ライブラリ関数を直接実行し、GUIはコード経路を確認した。

[材料属性による構造種別判定の申し送り](../handoff/構造種別判定の材料属性化_申し送り.md#35-非線形解析の入力チェックが-2-つ増えた) の §3.5 には、鋼形状にコンクリートを割り当てる組合せを当時は入力誤りとしなかった経緯がある。[階の分類の既存試験](../../crates/sepika-load/src/story_gen/tests.rs) の `test_generate_story_structure_follows_material_not_shape` は、同じ組合せで自重ありの階生成が失敗し、自重を省く下位の階生成ならRCに分類されることを確認する。今回の観測は履歴上の方針の見直しや、任意のコンクリート断面形状の新規対応の採否を決めるものではない。現行の重量条件ごとの受理・拒否を記録した。

## ダンパー総重量で置き換えた場合の増分解析と検定

[GUIの荷重設定](../../crates/sepika-app/src/tables/load_cfg.rs) では柱・梁にも「ダンパー総重量（断面・付加重量を置換）」を指定できる。この指定がある部材は、[自重の列挙](../../crates/sepika-load/src/story_gen/self_weight_calc.rs) が入力総重量を採用して次の部材に進む。このため、通常は断面自重・要素質量の算定で行う主材料区分の検査を通らない。荷重設定を含むモデルをOVIKAに保存・読込し、MCPの公開ジョブ入口で確認した。

同じ材端集中ばねのH 400×200（ウェブ8、フランジ12、フィレット半径0 mm）とFc24を用いて、高さ3,000 mmの鉛直片持ち柱を作った。柱脚固定・柱頭自由、全体X方向への加力で局所z軸まわりに強軸曲げが生じる。B階FL=0、R階FL=3,000 mm、両階ともΔSL=0とし、固定荷重DLと内容が空の架構用積載ケースを係数1で足す重力組合せを保存した。ダンパー総重量20 kNで置き換えた結果、DLには柱の両端に10 kNずつ載る。総重量指定だけを外した対照では、Fy=100 N/mm²でも準備で鋼材区分の不一致を返した。

| 入口 | Fy未入力・ダンパー総重量20 kN | Fy=100 N/mm²・ダンパー総重量20 kN |
| --- | --- | --- |
| 解析準備 | 成功 | 成功 |
| MCP線形静的解析（DL） | 成功。最大変位0.153689 mm、柱脚断面力の軸力成分−10 kN、断面力3行 | 同じ |
| MCP許容応力度検定 | 部材0の鋼材区分が不一致として拒否 | 同じ |
| MCP終局検定 | ジョブ結果を返す。RC・CFTとも検定0件で、全検定の算定・適合を表す `all_checks_calculated_and_ok` は false | 同じ |
| MCP増分解析 | 部材0のFy未設定で停止 | 目標変位100 mm、150 mmの両方に到達 |

DLによる柱頭10 kNの圧縮に対し、断面積は 2×200×12 + 376×8 = 7,808 mm²。変位の独立値は NL/(EA) = 10,000×3,000/(25,000×7,808) = 0.1536885246 mm で、線形静的解析と一致した。ここで確認したのは入力した断面積とEによる弾性軸変形である。

Fy=100 N/mm²、増分24指定の増分解析は、どちらの目標でも初期点を含む確定応答26点を返した。100 mmでは最大ベースシア38.635686 kN、機構分類は「部分崩壊形」。150 mmでは40.494923 kN、「全体崩壊形」だった。同じ準備済みモデルをGUIと共通の計算APIに渡した150 mmの試行では、柱脚にステップ1で「ひび割れ」、25で「降伏」（μ=1.0007378）が初出した。最終の強軸曲げは121.48477 kN·m、軸力は圧縮10 kNだった。

H形の強軸Zpは下記の独立算術から1,213,952 mm³なので、主材料のFy=100 N/mm²を用いる表示Myは121.3952 kN·mとなる。幾何学的なZe=1,080,743.253 mm³をFc24に用いるMcは2.96494 kN·m。どちらも確定時の軸力で更新しない。150 mm試行の最終曲げと降伏記録はこの表示閾値と整合した。結果の取得は鋼断面形状とコンクリート主材料の組合せの設計妥当性を示さない。重量方法に依存した線形静的・増分の入力診断は [#1462](https://github.com/hrntsm/SEPIKA/issues/1462) で追跡する。

## 鋼断面の独立算術と観測値

軸力零、均質な鋼、各形状の対称軸まわりの一方向曲げ、全断面が降伏応力度235 N/mm²に達した状態を仮定した。H形の座標は断面中心からせい方向を測り、Zpを両側の断面一次モーメントの和として評価した。箱形では外矩形と内空洞の一次モーメントを引き、円形鋼管では半円の断面一次モーメント `2R³/3` を外円と内円について引き、2倍した。1 kN·m = 10⁶ N·mm。

| 断面寸法 [mm] | 独立 Zp [mm³] | 独立 鋼Mp [kN·m] | 現行の共通My APIにFc24・Fy未入力を直接入力 [kN·m] |
| --- | ---: | ---: | ---: |
| H 400×200、ウェブ8・フランジ12・フィレット半径0 | 2 × (200×12×194 + 8×188×94) = 1,213,952 | 285.27872 | 285.27872 |
| 角形鋼管 300×300、板厚10・角R0 | (300×300² − 280×280²)/4 = 1,262,000 | 296.57000 | 296.57000 |
| 円形鋼管 外径300、板厚10 | 4 × (150³ − 140³)/3 = 841,333.333… | 197.71333… | 197.71333… |

表の一致で確認したのは鋼の断面算術と、下位の共通Myがコンクリート区分でも鋼と同じ235を使う挙動。H形の正のFyを100 N/mm²と入力したとき、共通Myは121.3952 kN·mとなり、N=0の材端集中ばねの骨格取得でも第1折点は追加回転0.011232566 rad・モーメント121.3952 kN·mだった。Fy未入力時は骨格が得られず、Fyを求める診断が返った。参考に同寸法の均質鋼の強軸弾性断面係数は1,080,743.253 mm³で、縁の初降伏は253.97466 kN·m。全塑性と初降伏はこの単純な対照でも異なる。

コンクリート主材料付き鋼形状に鋼と同じ数値が出る理由は、形状のZpと代表値の積である。RC・SRC・CFTとしての物理耐力、また一律の安全側・危険側の大小関係は、この値から確定できない。重量置換で増分解析が完了した場合も、表示されたヒンジ・機構分類から実部材の降伏や耐力の成立は判断できない。専用複合断面の参考表示を複合断面の終局耐力へ置き換える採用判断、二軸曲げ・座屈・軸力を含む鋼曲げの全適用条件、実験Validationは今回の確認範囲外。
