# 方向間で連成する層の偏心率（Issue #1685）

[Issue #1685](https://github.com/hrntsm/SEPIKA/issues/1685)の調査。状態🔶。方向間で連成する層では、剛心とねじり剛性を定義どおり求めても、弾力半径の分母に用いる水平剛性は評価条件に依存する。照合した原典から連成層に一律に適用できる境界条件や主軸への置換条件を特定できず、設計用Re・Fes・必要保有水平耐力は引き続き算定を保留する。

建築行政情報センターの研修Q&Aは、不整形な建物ではX・Y以外の加力方向を検討する必要があること、評定物件等では剛心載荷の剛性主軸を調べて加力する例があることを説明している。主軸の検討を加える実務上の根拠であり、元の設計方向を省略できる条件は示していない。斜めに交わる構面について部材の二方向のせん断力・変位から連成項を求める研究例もある。対象とした単層モデルの技術検討であり、一般の採用手順には照合が残る。[建築確認実践研修Q&A 質疑2](https://www.icba.or.jp/info/pdf/20180122qa.pdf)・[吉村「構面が斜めに交わる不整形立体架構における剛心・偏心率の計算方法に関する研究」§2–6](https://www.rs.kagu.tus.ac.jp/kurita/PDF/2010/B-yoshimura.pdf)

## 力学上の比較条件

線形弾性の単層剛床を用い、原点での層剛性を並進の2×2対称正定値行列 H [N/mm]、並進と回転の連成列 b [N/rad]、回転剛性 c [N·mm/rad] のブロックで表す。b と c は原点に依存する。原点で並進外力をゼロとして単位回転を与えたときの並進は u = −H⁻¹b。剛心 C [mm] は (−u_y, u_x)、剛心回りのねじり剛性 KR は c − bᵀH⁻¹b。C に座標原点を移すと H は同じで、並進と回転は層応答で分離する。

検討方向の単位ベクトルを d、その反時計回り90°の単位ベクトルを n、重心 G と剛心 C の距離のうち検討方向に直交する成分を e = |nᵀ(G − C)| [mm] とする。いずれも同じ H、C、KR を用い、剛床の回転をゼロとしたときの方向別水平剛性 k [N/mm] を比較する。

| 比較条件 | k の算定 | 境界条件の成立 |
| --- | --- | --- |
| 直交変位ゼロ | dᵀHd | 変位は d に平行。一般には直交拘束反力が必要で、検討方向への単独載荷と同じ応答になるのは、対象方向が並進主軸となるなど、その反力を要しない場合。 |
| 直交外力ゼロ | 1/(dᵀH⁻¹d) = dᵀHd − (nᵀHd)²/(nᵀHn) | 剛心を通る d 方向の水平力だけを与え、直交方向の変位を許す。重心で同じ力を作用させて回転も自由にすると、偏心によるねじれが加わる。 |
| 層の並進主軸 | H の固有値 | H を対角化する二方向に実際に加力方向を変える。各軸で二つの境界条件が同じ値になる。e は各主軸に直交する距離として取り直す。 |

各比較の弾力半径は re = √(KR/k) [mm]、偏心率は Re = e/re とした。同じ方向・e・正の KR に対し、正定値 H では直交変位ゼロの k は直交外力ゼロの k 以上となる。したがって Re は拘束時の方が大きいか等しく、通常式の Fe も非減少である。Fs・Ds・Qud を固定した比較では Fes と Qun にも同じ大小関係が成り立つ。これは同じ条件間の算術上の上限で、直交拘束が実際の部材応力・変形・ねじれや崩壊形を包絡する根拠にはならない。

重心載荷で剛床が自由に回転する場合、G における並進柔度は H⁻¹ + ttᵀ/KR となる。t = (−(G − C)_y, (G − C)_x) は偏心によるモーメントの腕を表す。この柔度の二つの固有方向が、同一の荷重分布を各方位に回転して加えたときの仕事の極値となる方向である。偏心による回転の寄与があるため、[仕事の極値による主軸（#1204）](../../docs/calc_basis/07_二次設計/06_主軸の計算.md)と層の H の主軸が一致するとは限らない。重心位置では、加力方向のねじれによる変位と剛心の並進による変位との比が (e²/KR)/(dᵀH⁻¹d) となり、直交外力ゼロの比較Reの二乗に一致する。この比は指定した剛床モデルの力学的な意味を与える。重心位置の変位から求める剛性には既にねじれの影響が入る。本比較の弾力半径では回転を除いた k と KR を使い、仕事の主軸は比較する加力方向の候補とする。

## 独立計算と結果

二例とも1層とし Rs = 1、従って Fs = 1。方向間で異なる Re の影響を抽出するため Ds = 0.30、Qud = 1,000 kN を全行で例示値として固定した。Qun は各行の Fes に300 kNを掛けた値。個別架構の地震荷重、部材種別・崩壊形、Qu は算定していない。

## 設計採用と後続条件

- **直交・非連成の通常評価**。検討方向と直交方向が力学的に独立し、各位置の方向別水平剛性と腕で剛心・ねじり剛性を表せる架構には、直交配置の算定式を適用できる。層の非対角項が相殺されても、各部材の直交応力が位置に応じてねじり剛性に寄与する場合は、剛心とねじり剛性の定義に基づく検証が必要。[ADR 0136](../adr/0136-coupled-story-rigidity.md)
- **方向間連成の保留**。同定できる層では、同じ線形系の二方向の並進と純ねじりの応答から H、C、KR を求められる。直交変位ゼロは拘束を含む並進実験、直交外力ゼロは剛心を通る単独載荷の剛性を表す。設計値を採用するには、対象の境界条件・外力分布・ねじれ自由度・剛性の評価状態を一次設計用地震力の解析と対応付け、告示・解説・個別の調査研究等に照らして当該水平剛性を弾力半径に用いる妥当性を示す必要がある。根拠を特定できない層、剛床・剛心・KRを同定できない層、水平剛性の正定値性やKRの有限かつ正の値を確認できない層は理由とともに算定を保留する。
- **主軸での評価**。座標を回すだけなら元の設計方向の外力と偏心モーメントも同じ座標に変換して扱う。主軸方向への単独加力は別の地震力条件となる。主軸に元の設計方向が一致する場合、又は必要な設計方向の全層・正負の応答、部材応力、層間変形、ねじれ及び終局の耐力・崩壊形を同等以上に扱うことを適用規定や個別の検証で示せる場合に限り、主軸の二方向だけで元の方向を代替できる。各階で主軸が異なる場合は同じ建物全体の載荷方向として扱えるかも確認する。代替根拠が得られなければ、主軸は追加の検討方向に用いる。
- **必要保有水平耐力**。設計採用時は方向と符号を対応付ける。Rs・Re は一次設計用地震力の応答に対応する剛性評価から求め、Fes を算定する。Qud は令第88条に基づき、標準せん断力係数 C0 を1.0以上とする地震力から求める。終局状態の部材の耐力分担・崩壊形に基づき Ds を求め、同じ方向と符号の載荷に対応する Qu を Qun と比較する。弾性域で H を対角化できることから、塑性化後の耐力、Ds 又は層間変形の分布が同じとは判断できない。
- **後続の検証**。一般の連成層について一律の算定方式を製品仕様へ追加する根拠は得られなかった。追加調査では、まず採用する荷重と境界条件および設計方向を明示する公開原典、又は適用ルートに沿った個別評価の根拠を特定する。次に独立立体解析で直交変位・反力・ねじれ、方向と符号を変えた部材応力・崩壊形、設計方向ごとの Rs・Re・Fes・Qun を照合する。複数層、非剛床、剛性低下・支持条件の変化に適用する場合は、それぞれ検証する。実際の設計載荷に基づく調査を [#1698](https://github.com/hrntsm/SEPIKA/issues/1698) で追跡する。[現行の算定条件](../../docs/calc_basis/07_二次設計/04_形状係数_Fes.md#方向間連成と剛床の剛心ねじり剛性)
