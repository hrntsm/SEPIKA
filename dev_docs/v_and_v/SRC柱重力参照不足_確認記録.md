# SRC柱の構造規定方式と重力参照不足（#1274）

状態🔶。2026-11-18、基点 `9066d546` で公開 `SrcDesign::check` を実行し、同位置参照の欠落による弾性分担への切替えと、非有限値を与えた場合の有限成功を確認した。要求済み方式の入力不足を理由付き未算定に是正する。構造規定方式の需要式そのものの採用根拠・一般的安全性・規準適合の再承認ではない。

## 変更前の公開入口再現

柱500×700 mm、主筋径22 mm、各辺3本、かぶり40 mm、帯筋径10 mm・間隔100 mm・各方向2本、内蔵H500×200×9×14、Fc24、SD345、SN400B。評価位置0、N=My=Mz=0、Qy=110 kN、Qz=50 kN、内法長6000 mm、n=1.5。同位置の重力Qy=100 kN、Qz=30 kNとする。以下の値はせん断成分の検定比。

| 重力参照 | Qd1 | Qd2 / Min | 変更前の表示・有限性 |
| --- | ---: | ---: | --- |
| 正常 | 0.347593221267219 | 0.347593221267219 | 両軸「構造規定方式」、有限 |
| 同位置なし | 0.137389378932607 | 0.137389378932607 | 両軸「弾性分担」、有限 |
| QyのみNaN | 0.195223232838794 | 0.105130423231214 | 両軸「構造規定方式」、有限 |
| QzのみNaN | 0.347593221267219 | 0.347593221267219 | 両軸「構造規定方式」、有限 |
| Qy・QzともNaN | 0.160485108041192 | 0 | 両軸「構造規定方式」、有限 |
| Qyが+∞、又はQzが−∞ | +∞ | +∞ | 両軸「構造規定方式」、非有限 |

静的読取りの「同位置なしは弾性分担」を公開入口で再現した。非有限値は同位置検索で拒否されず、NaNを含む演算が `f64::min/max` で有限値へ消える。NaNの事象は弾性分担への切替えとは異なる。この例の欠落時・NaN時には正常参照より検定比が小さくなるため、不足を成功へ補完してよいとはいえない。任意の入力で切替えが常に危険側になるという結論ではない。

## 独立算術による代表値

矩形差の断面二次モーメントと縁距離から、強軸の鉄骨断面係数は `(200×500³−191×472³)/(12×250)` = 1,638,525.61066667 mm³。主筋の円面積は `3π22²/4` = 1140.3981332531 mm²、有効せいは `700−40−10−11` = 639 mm、応力中心間距離は559.125 mm。これより鉄骨分担率は0.719866922029908。

鉄骨部の需要は `0.719866922029908×100000 + 2×1638525.61066667×235/6000` = 200337.865038546 N、許容値は `9×472×235/√3` = 576357.22672662 Nで、比は0.347593221267219。通常短期の鉄骨分担は `0.719866922029908×110000` = 79185.36142329 Nで、比は0.137389378932607。実装の断面性能・分担・需要計算関数を期待値計算に呼ばない独立算術である。

弱軸は `((2×14×200³+472×9³)/12)/100` = 186953.406666667 mm³、応力中心間距離384.125 mm、分担率0.299121220086365。鉄骨部の需要23618.3201248132 N、許容値506528.636169032 Nの比0.046627808258666。RC部はN=0の採用式 `rMu=0.8atσyD` より強軸220324919.344498 N·mm、弱軸157374942.388927 N·mm。rQD1は各101454.947578509 N、73484.6775270514 N、公開入口の許容値表示457622.8 N、376413.6 Nとの比は約0.22170、0.19522で、鉄骨強軸の0.34759が支配する。Qd2・MinではRC部需要は強軸0、弱軸39572.5198127802 Nとなる。RC許容値の式全体の独立導出までを本確認の証拠に含めず、鉄骨需要・許容値の独立算術と公開入口の両方向の表示を照合する。これらは採用済み式のVerificationであり、規準式のValidationではない。

## 入力契約と変更要否

期待契約は[製品仕様](../../docs/calc_basis/06_一次設計/04_SRC_CFT_断面検定.md#src部材の許容せん断と要求せん断力)の構造規定方式と通常短期の区別による。方式を要求した場合は、同位置の有限なQy・Qzがそろわなければ、軸力・曲げを含む評価位置全体を理由付きSkippedにする。片方向の成功だけを全体の成功としない。有限な0と負値は有効、位置差10⁻⁶未満の既存一致条件は維持する。

`seismic_qd=None` の通常短期は弾性分担、通常長期は併用式を維持する。公開バッチでは `long_member_forces=None` と `Some(empty)` を区別し、要求参照に当該SRC柱そのものがない場合も未算定とする。新しい近似や需要式を追加しない。検定契約版を52から53へ更新し、旧保存検定結果を現行結果として再利用しない。解析契約版70は維持する。

## 上位入口の到達性

GUIの `App::run_design_check` とMCPのDesignCheckジョブは、選択した地震組合せの重力termsを解析し、`sepika_job::complete_design_gravity_forces` による合成後、共通公開バッチへ渡す。重力ケースの欠落、空内力、非有限位置・内力、ケース間の部材・位置不一致はこの準備で拒否する。MCPは入力エラー、GUIは検定理由へ伝える。これらは静的読取りで確認した拒否である。

通常の実行確認は、GUI側の `src_ql_acceptance_tests::src912_material_edit_preparation_design_save_preserve_beam_and_column_skips` がSRC柱へ断面・方向・階入力を変え、実解析と正常検定、編集後の未算定、保存往復を実行する。MCP側は `src_column_mcp_saved_seismic_combination_supplies_both_gravity_directions` が保存地震組合せの実解析を実行する。通常の荷重ありと重力部材荷重なしを区別する。正常な重力0は欠落ではない。

一方、共通公開バッチへ人工的に `Some(empty)`・別部材だけ・同位置なしを与える経路は実行再現できる。直接 `SrcDesign::check` へのNaN・∞も再現できる。通常GUI/MCP操作でこれらの不正参照を入力できたことは示していない。また、重力準備は地震組合せ側の評価位置集合と比較しないため、将来や別呼出側で異なる位置が渡されても検定側で拒否する必要がある。
