# RC梁の方向別両端降伏の設計入力（#1914）

状態は🔶。原典、独立した断面・梁の釣合い、現行の解析記録と公開検定の入口を照合した。設計タブは左右同一ステップの応答を確認する手掛かりと、実フェース・重力の入力候補を得られるが、通常結果だけで両端の強軸曲げ降伏の先行、定着・曲げ伝達、曲げ耐力上限までは確認できない。次の実装では、確認済みの条件を方向別に明示入力し、不足時は未算定を維持する。実建物での機構同定・適用性、設計タブへの接続や保存は未検証。

## 原典と適用範囲

『2025年版 建築物の構造関係技術基準解説書』第2版第1刷（2026年2月11日）の該当頁を原画像で確認した。本文・画像は転載しない。[編集元の公開書誌](https://www2.icba.or.jp/products/detail.php?product_id=606)

- p.416 §6.4.3 (1) 2) i) のルート2では、梁の両端曲げ降伏枝 QD2 は、単純支持の常時せん断 Q0 と当該梁の両端曲げ降伏によるせん断 Qy の和。剛節架構の常時せん断と割増地震せん断を用いる QD1 は別枝であり、今回の入力で二枝の選定をしない。短期許容検定の QD1 とも別。
- pp.433–434 §6.4.4 (3) の保証設計例は、梁の Q0 に Ds 算定時などの所定の地震せん断成分の割増値を加える。外力分布が異なると保有水平耐力時の応力状態が変わり得る。以下の部材自由体の結果を、別の解析ステップの応答やルート3保証設計の判定に代用しない。
- pp.698–699 付録1-3.1 の式(付1.3-5)は、引張主筋の降伏が圧縮コンクリートの破壊より先行する矩形梁の曲げ終局強度の略算。これは上限を保証する式ではない。同所はスラブ付き梁でスラブ筋の寄与と定着の確認も扱う。今回の対象は、両端に接続柱を持つ単独の矩形RC大梁に限る。

## 代表例と不成立例

梁の局所 x は i→j、局所 y は上向きとする。単独の矩形梁で軸力 0、幅 350 mm、せい 600 mm、上下とも材縁から 50 mm に集約した主筋を仮定した。i の上・下の断面積を 1500・900 mm²、j は 1800・1200 mm² とする。鋼材は弾完全塑性（ヤング係数 200000、降伏応力度 345 N/mm²）、平面保持、コンクリート引張無視とし、圧縮縁ひずみ 0.003 で、仮定した等価圧縮ブロックを深さ 0.8c、応力度 25 N/mm² とした。これは部材の実耐力や材料強度の上限を求める方法ではなく、引張側の違いと略算の上限性を独立に点検する比較用断面モデル。

圧縮縁からの中立軸深さを c とし、圧縮縁側の鉄筋応力度をひずみ適合で求め、ブロック内なら置換したコンクリート応力度 25 N/mm² を引く。ブロック圧縮力とこの鉄筋力の和が反対側の引張力 Aₜ×345 と等しくなる c を求め、引張鉄筋まわりの圧縮力のモーメントを合計した。各場合の引張ひずみは 0.0216〜0.0311 で降伏ひずみ 0.001725 より大きい。以下の曲げは絶対値で、(付1.3-5) の比較値は同じ Aₜ、345 N/mm²、有効せい 550 mm を使った。

| 地震方向 | 実支持フェース・引張側 | c [mm] | 断面の釣合い [kN·m] | (付1.3-5) [kN·m] |
| --- | --- | ---: | ---: | ---: |
| 正 | i 上端 | 60.520 | 269.677 | 256.163 |
| 正 | j 下端 | 52.315 | 217.647 | 204.930 |
| 負 | i 下端 | 48.455 | 165.635 | 153.698 |
| 負 | j 上端 | 66.954 | 321.382 | 307.395 |

強軸断面曲げは下端引張を正とする。上の曲げ値を仮に実支持フェースの逆符号の作用として与え、地震時の内法間に別の横荷重がないとすると、内法 4.0 m の自由体の釣合いから Qy は正方向で +121.831 kN、負方向で −121.754 kN。左右を同じ耐力と置かず、地震の正負と断面曲げの符号を分ける。比較断面モデルの数値も公称略算値も、そのまま公開検定の耐力上限には渡さない。

同じ実フェース間を単純支持として i から 3.0 m に下向きの常時荷重 120 kN を作用させると、自由体の釣合いから i と j の鉛直反力は 30、90 kN、端別断面せん断 Q0 は +30、−90 kN。区間内も符号付きの端範囲に収まる。正方向では j 面で一部が相殺され、負方向では j 面で加算される。上限値を代入した符号付き端値と、相殺も考慮した方向別の絶対包絡上限は区別する。[公開検定の計算根拠](../../docs/calc_basis/08_部材終局耐力/07_01_静的_両端ヒンジ略算による終局検定.md#方向別の両端降伏枝)

以下は照合条件のための仮想記録であり、通常の解析が表の降伏状態を出力したという意味ではない。各方向で、同じ run の選択済み確定ステップの組だけを比較する。

| 記録例 | 断面・自由体との照合 |
| --- | --- |
| 正で同一ステップに i 上端・j 下端、負の別 run の同一ステップに i 下端・j 上端 | 方向ごとに符号・位置が整合する候補。両端の先行降伏、支持、内法せん断の釣合いを別途確認する。 |
| 正の選択ステップで i だけが降伏し、j は弾性 | j の作用に耐力上限を代入すると選択ステップの応力状態ではなくなる。両端降伏枝は未算定。 |
| 正の選択ステップ n では i だけが降伏、別ステップ n+1 では j だけが降伏 | 発生履歴を合算した両端の偶力はどの荷重状態にも存在しない。異なる run・地震符号を組み合わせても同様に未算定。 |
| 同一ステップに端別の閾値超過があるが、同符号、弱軸支配または実柱面不一致 | 両端の逆符号の強軸曲げとはいえない。包絡値や剛域フェイスを用いた置換で成立扱いしない。 |
| i・j とも降伏しても、せん断破壊・接合部破壊等が先行、あるいは地震時の横荷重が内法間に残る | 両端曲げ降伏が先行し曲げ差だけで Qy が一定になる条件を満たさない。 |

## 現行結果から取得できる範囲

| 条件 | モデル・通常解析から確認できること | 設計者の確認が必要なこと |
| --- | --- | --- |
| 荷重状態 | 設計タブの確定総応答は、選択軸・run・入力世代・確定ステップ・採用目的・初期重力の組合せを照合する。解析記録には載荷符号もあるが、通常のRC終局の入口は選択軸の一つの結果を読むもので、正負両方の根拠を揃える経路ではない。静的結果はケース別の内力であり、降伏履歴ではない。 | 各地震方向に採用する荷重状態を明示する。正負を反転計算で補わない。[設計タブの取得処理](../../crates/sepika-app/src/app/actions/design/ultimate.rs)・[確定応答](../../crates/sepika-solver/src/nonlinear/pushover/story_response.rs) |
| 同一ステップの両端曲げ | 確定総応答の強軸曲げは両端の最大絶対値。ヒンジ一覧は同一ステップに絞れるが、局所両軸の絶対値の大きい方と部材用閾値から作るため、軸・符号も端別の実配筋による降伏も証明しない。ヒンジ等の詳細履歴に同一ステップの i/j の符号付き強軸の材端力成分がある場合は候補の照合に使えるが、f32 の記録で、剛域フェイスを用い、取得できない場合に材端力へ戻る経路もある。端面ごとの作用から共通の断面力符号に変換せずに生データの正負を比較しない。 | 両端の実柱面における強軸曲げの符号と引張側が逆で、他の破壊より両端曲げ降伏が先行し、地震時の内法内の強軸せん断が両端曲げのみで釣り合うことを、同一状態の資料で確認する。[ヒンジ記録](../../crates/sepika-solver/src/nonlinear/pushover/hinge.rs)・[履歴への収録](../../crates/sepika-solver/src/nonlinear/pushover/member_response.rs)・[履歴型](../../crates/sepika-solver/src/nonlinear/pushover/types.rs) |
| 実支持面・曲げ伝達 | 実材軸・局所軸・接続柱から候補の実柱面と正の内法を取得できる。公開検定は左右の実柱面、梁・接続柱の曲げ伝達条件、接合節点または接続柱遠端の該当する直接支持を照合する。剛域・節点反力だけから実柱面や曲げ伝達は確定しない。 | 実際の納まり、接合部と定着、端別の曲げ上限まで強軸曲げを伝達できることを確認する。モデルの支持照合に失敗した場合は手入力でも上書きしない。[公開入口の入力・適用判定](../../crates/sepika-design-jp/src/ultimate/rc_beam_hinge_shear.rs) |
| 端別曲げ耐力 | モデルから配筋・材料の名目情報を確認できるが、両端の実配筋・有効せい・定着・実強度等を反映した曲げ耐力の上限は通常結果にない。長期曲げ符号、公称略算やヒンジ閾値を上限の代わりにしない。 | i/j 端かつ正負方向別の引張側と、実配筋・定着、材料条件（実降伏強度等）および係数の出典を確認し、実際の強度を下回らない端別の正の上限値を示す。 |
| 単純支持常時せん断 Q0 | 採用した長期架構用組合せと梁・荷重のモデル情報は取得できる。通常の解析の内力・反力はその支持条件での応答で、実柱面間を単純支持とした Q0 ではない。 | 同じ重力組合せを用い、実柱面間に伝わる常時荷重、局所 Qy の符号、単純支持の i/j の断面せん断および内法内の符号付き包絡を確認する。逆向きの荷重が混じると端で絶対値最大でも符号付き包絡は成立しない。 |

ヒンジ詳細図の `MemberHistory` はヒンジまたはせん断降伏が記録された部材だけを保持し、`records` は確定ステップ `steps` と同順・同数。ヒンジ記録は `Crack` を含むため、曲げひび割れの閾値に達しただけでも履歴が収録され得る。片端のイベントによって部材履歴があっても他端の降伏を証明せず、履歴がないことも実柱面の非降伏を証明しない。[履歴型](../../crates/sepika-solver/src/nonlinear/pushover/types.rs)・[ヒンジ記録](../../crates/sepika-solver/src/nonlinear/pushover/hinge.rs)

確定ステップの履歴材端力は全変位の状態に基づき、初期重力を載荷した run では重力込みとなるため、地震成分 Qy や単純支持常時せん断 Q0 に転用せず、Q0 を重複加算しない。[確定ステップの記録](../../crates/sepika-solver/src/nonlinear/pushover/step_record.rs)

公開入口は確認済みの i/j の実支持フェース位置を、それぞれモデルから取得した実柱面の位置と厳密に一致させる。内法長だけの一致では足りない。実支持フェースを構成する接続柱にハンチがある場合は実柱面を確認できないため未算定とする。[公開入口の適用判定](../../crates/sepika-design-jp/src/ultimate/rc_beam_hinge_shear.rs)

内法内に部材荷重がないなどの条件を満たす場合、通常の確定応答には既存のRC終局せん断検定用のフェース間の軸力範囲と曲げ・せん断の絶対値の最大もある。ただし i/j の値と符号を対で保持せず、方向別両端降伏の証拠にはならない。[確定応答への収録](../../crates/sepika-solver/src/nonlinear/pushover/member_response.rs)

## 設計タブへの接続と確認の鮮度

初期実装の対象は、現行公開入口の範囲内でモデルから実支持フェースと直接支持の条件を照合し、重力の端別 Q0・符号付き包絡と、方向別の降伏先行・引張側・耐力上限・支持伝達の確認を、設計者の根拠とともに入力する経路。通常応答の取得は同一状態の照合の補助に限る。確認根拠が別途の設計検討であるときも、採用した状態そのものを記録し、別ステップの証拠で穴埋めしない。確定総応答や付着照査の判定とは区別し、片方向が未確認ならその理由を返し、独立に成立する他方向と既知の不適合を失わない。

結果は正負別に、算定できる場合は符号付き端別 Q0、端別の曲げ耐力上限を代入した符号付き Qy と端別 QD2、およびそれらと別の量である方向別絶対包絡上限を区別して表示する。算定できなければ該当方向に未算定理由を表示する。これらは従来の終局せん断耐力・余裕度の適否判定に用いない。[設計タブへの入力・表示の後続 Issue #1973](https://github.com/hrntsm/SEPIKA/issues/1973)

既存の公開検定では、同じ載荷軸・地震方向に非降伏梁としての付着照査入力と両端曲げ降伏入力が同時にある場合、矛盾としてその方向の両端降伏せん断需要を未算定とし、非降伏を根拠とする付着応力度とその適合判定も採用しない。同方向でも独立に確認した必要延長不足は保持し、別方向の結果には波及させない。後続でもこの契約を維持し、付着入力を新たに取得しない。[両端降伏せん断側](../../crates/sepika-design-jp/src/ultimate/rc_beam_hinge_shear.rs)・[付着照査側](../../crates/sepika-design-jp/src/ultimate/rc_check.rs)・[方向別検証](../../crates/sepika-design-jp/tests/rc_ultimate_beam_bond_direction.rs)

保存は現行公開入口の範囲外。後続で保存する場合の鮮度条件は次のとおり。

- 確認を部材 ID だけにひも付けない。実フェースの i/j 順序と位置、局所軸、断面・端別配筋・材料、支点・柱・接合条件、長期架構用組合せ（ケース・係数）、該当する荷重と入力世代を照合する。
- 解析を使う根拠は採用目的、軸と載荷符号、run・入力世代・確定ステップを方向ごとに照合する。別途設計検討の資料も識別と改訂を保存し、対象モデル・断面・荷重状態との対応が切れないようにする。現行の確定総応答の照合は解析の鮮度の土台であって、手入力した実際の納まり・強度の根拠の鮮度までは保証しない。
- 変更や読込後の再照合で確認根拠が欠落、旧形式、または不一致なら、その根拠を使う枝は再確認まで未算定。正負共通の重力・支持面が変われば両方向に影響し、一方向の解析を取り替えた場合は少なくともその方向の確認が失効する。部材番号やステップ番号が偶然同じでも再利用しない。

複数要素の梁、スラブ付き・ハンチ付き、実柱面や直接支持が確認できない場合（他層・剛リンク等をたどる必要がある場合を含む）には、手入力でも適用を拡張しない。自動での強軸曲げ降伏・機構判定、単純支持重力の自動算定、ルート3保証設計、付着照査の条件取得は後続の手入力・結果表示の範囲外。

## 照合の限界

[既存の方向別公開検定の検証](RC梁の方向別両端降伏せん断_Issue1582_検証.md)の独立自由体と自動テストは、確認済みの入力に対する出力を検証する。本調査の独立断面・仮想記録は、通常結果のどの情報が不足するかを示すもので、実建物の定着・破壊順序、解析モデルによる実柱面の降伏再現、手入力の保存・鮮度チェックを実証するものではない。
