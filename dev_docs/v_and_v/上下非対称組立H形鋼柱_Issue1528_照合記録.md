# 上下非対称組立H形鋼柱の軸力・強軸曲げ（#1528）

[Issue #1528](https://github.com/hrntsm/SEPIKA/issues/1528) の再現断面を、独立した断面算術、公開断面検定、線形静的解析から共通部材検定への経路で照合した。現行の適用範囲と規準の条項は[計算根拠](../../docs/calc_basis/06_一次設計/03_05_鋼柱_ブレースの軸力_曲げ検定.md#上下非対称組立h形鋼柱の圧縮と強軸曲げ)を正本とする。

## 再現断面と独立期待値

短期、基準強度235 N/mm²、全せい400 mm、上フランジ80×12 mm、下フランジ180×20 mm、ウェブ厚8 mm、圧縮軸力77 kNとした。3枚の矩形から、全断面積7504 mm²、図心の下縁からの距離135.236673774 mm、強軸断面二次モーメント168019265.000711 mm⁴を平行軸の定理で求めた。上下の断面係数は順に634601.730518 mm³と1242409.032342 mm³、平均圧縮応力度は10.261194030 N/mm²。曲げ応力度は引張正とする。

材長0の公開検定で両方向の支配比・応力度の内訳を確認した。長期は両比とも短期の1.5倍、短期の−150 kN·mは適合だった。従来式に図心をせい中央と仮定した断面係数を入れると、±160 kN·mとも約0.8541となる。

## 解析から共通部材検定まで

高さ3,000 mmの鉛直片持ち柱を用いた。局所y軸を全体Xに向けて柱頭の全体Y軸まわりに+160 kN·mを作用させた場合と、局所y軸を全体Yに向けて柱頭の全体X軸まわりに+160 kN·mを作用させた場合を比較した。後者では局所z軸が全体−Xとなる。両モデルで圧縮軸力−77 kNと局所 Mz の正負をすべての出力位置で照合し、共通検定の3位置で同じ符号に対応する軸曲げの下限比、不適合、座屈の未算定理由を確認した。後者の曲げを150 kN·mに下げると、3位置とも理由付きの未算定となった。

局所 Mz が+160 kN·mの柱にフランジ欠損5%を指定すると、同じ解析内力に対する共通検定の3位置とも欠損を理由とする未算定となった。

## 要素と検証

| 照合した項目 | 検証 |
|---|---|
| 上下縁の断面係数、圧縮側・引張側の照査、長短期 | 6.1と11.9、3矩形の独立算術、10.1(1)に基づく無欠損境界、公開 `SteelDesign::check` |
| 局所 Mz 符号と有限材長での不適合保持 | 公開 `linear_static_once` から `run_member_design_checks` に接続した片持ち柱3例 |
| 未算定条件と対象外の境界 | 弱軸曲げ、強軸・弱軸せん断、座屈長さ指定、欠損、供給断面性能、非有限断面力、および軸力なし・引張軸力・強軸曲げなし・対称組立Hの対照 |
| H形鋼柱の弱軸せん断と法定細長比 | 同一点の未算定理由と独立軸曲げ不適合を検証。材長20,000 mmの上下非対称組立H形鋼柱では、法定細長比の不適合に欠損・座屈の未算定理由が併記され、ねじりがある場合はその理由も保持された。既存の `steel_h_column_combined` 5件、`steel_slenderness` 11件、`steel_torsional_moment` 3件も通過 |
| 時刻歴簡易検定での欠損境界 | `asymmetric_built_h_peak_check_respects_section_loss_without_using_direct_c`。eguiの描画ラベルを比較し、欠損指定による未算定と、軸力なしの既存表示が欠損またはCの直接指定に影響されないことを検証 |

`cargo test -p sepika-design-jp --locked --test steel_asymmetric_h_column` は6件通過。有限材長・座屈の評価は [#1541](https://github.com/hrntsm/SEPIKA/issues/1541)、軸力なしの曲げは [#1540](https://github.com/hrntsm/SEPIKA/issues/1540)、強軸せん断は [#1542](https://github.com/hrntsm/SEPIKA/issues/1542) で追跡する。対象範囲の規準照合と有限例のVerificationであり、部材実験によるValidation・座屈耐力の算定は未検証。
