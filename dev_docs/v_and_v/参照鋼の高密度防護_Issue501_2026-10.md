# 参照鋼の高密度防護（Issue #501）

対象コードは `c7f9d41f43351c49e77f1abcf156b3f4570baa7b`、基準mainは
`eb992c0ced0d81d47ba193a9ef794fe5230a41c9`。固定設計単位重量による過小評価の拒否を
Verificationする。材料実験や構造応答のValidationを行った記録ではない。

製品仕様は[カスタム鋼材の密度と計算可否](../../docs/calc_basis/02_材料/04_標準材料一覧.md#カスタム鋼材の密度と計算可否)を正とする。

## 参照経路と検査位置

| 設計用途 | 材料の解決 | 防護位置 | 物理側 |
|---|---|---|---|
| 主架構Beam/Fiber/MultiSpring/Brace・ShellのDL/地震重量 | 既存`element_material`、CFTのみ`element_steel_material` | `story_gen::self_weight_calc::enumerate_self_weight`の設計単位重量利用直前 | `element_mass_properties`は許可 |
| 二次Beam/PostのDL/地震重量・小梁設計 | 既存`secondary_material`、CFT鋼管は断面`steel_material` | `floor::beam_design::beam_self_weight_udl`、cascadeのDesignが利用 | `beam_mass_equiv_udl`とcascadeのMassEquivは許可 |
| 囲み鋼壁のDL支持 | 既存`wall_plate_material` | `wall_plate_load::distribute_enclosed_wall_plates_with_basis`のDesign | MassEquiv分配は許可 |
| 取付き鋼壁のDL（線/床領域/補助節点集計） | 既存`wall_plate_material` | `wall_attached`の設計専用入口 | 物理節点集計は許可 |
| 壁の幾何による地震重量 | 既存`wall_plate_material` | `story_gen::generate_stories_impl` | 共通`wall_weight`のphysical/matrixは許可 |
| GUI/MCP共通準備・DL自動生成 | 上記既存経路を再利用 | `job::auto_loads::compute_gravity_auto_load_cases`、`job::prepare` | 独立した物理算定は許可 |

共通比較はcoreの`Material::validate_design_self_weight`。登録全材料の検査にせず、
固定設計自重へ参照される材料と部材ID・目的を渡す。鉄筋・SRC主材料・CFT充填材を
鋼材と誤認しない。負・非有限の診断は高密度の過小評価診断とは別に返す。
壁の共通総量APIを一律にエラーへ変更せず、設計消費入口だけから検査する。

## 独立期待値と直接試験

重力は9806.65 mm/s²、体積1 m³は1e9 mm³。計算定数をテストから引用せず、
受入契約の数値と単位から期待値を与えた。体積のモデルも断面1e6 mm²・長さ1000 mmで指定する。

| 入力・観測契約 | 独立期待値 | 試験 |
|---|---|---|
| 標準ρ=7.85e-9、1m³ | 物理質量7.85 t、物理重量76.9822025 kN、設計78.5 kN | core `design_density_guard_uses_unrounded_boundary_and_separate_invalid_diagnostics`、load `one_cubic_metre_steel_keeps_independent_design_weight_and_physical_mass` |
| 物理85 kN/m³相当ρ | 質量8.66758781031239 t、差6.5 kN、設計不可 | 上記とjob `high_density_rejects_real_preparation_and_old_dl_seismic_then_recovers` |
| 境界ρ*=78.5e-6/9806.65、ρ*(1±1e-8) | 等号/下側は許可、上側は拒否 | core上記、job `real_preparation_boundary_and_invalid_density_keep_separate_diagnostics` |
| α=1.1 | 本体の密度が85なら拒否（86.35へ割増しても拒否） | job上記 |
| 未使用/共有材料・鉄筋 | 未使用/鉄筋は停止せず、共有参照鋼は対象ID付き拒否 | job `unused_high_density_and_rebar_do_not_block_common_preparation`と6部材共有の`steel_frame` |
| Beam/Fiber/MultiSpring/Brace・CFT箱/円の鋼管/充填材 | 鋼管だけ対象、独立物理質量は成功 | load `high_density_primary_kinds_and_cft_steel_reference_reject_design_only` |
| SRC内蔵鋼/総断面 | 鋼の境界をSRC総断面重量へ適用しない | load `src_embedded_steel_high_density_does_not_apply_steel_threshold_to_total_section` |
| Shell | 要素ID・シェルの計算目的付き拒否 | load `steel_shell_design_self_weight_rejects_high_density_with_element_id` |
| 二次Beam/Post、CFT箱/円 | Designは拒否、MassEquivは成功、充填材は誤検出しない | load `secondary_high_density_design_guard_does_not_block_physical_cascade` |
| 囲み/取付き鋼壁（4000×3000×200 mm） | 物理204000 N、設計経路は壁ID付き拒否 | job `high_density_steel_wall_rejects_all_design_routes_but_preserves_physical_weight` |
| 負・NaN/∞ | 「負」/「非有限」、過小評価とは別診断 | core境界試験、job実準備の境界試験 |
| 正常→高密度変更→失敗→訂正 | 旧Auto DL/EX/EY除去、旧階重量の鮮度無効化、Manual保持、再準備で回復 | jobの正常/失敗/回復試験 |
| GUI準備/同期→編集Undo→再同期、単独DL同期 | 共通診断、旧Auto不可、元密度で再準備可能 | app `high_density_steel_gui_preparation_sync_rejects_and_undo_recovers` |
| 公開MCP `analysis_run`→失敗→密度訂正→再実行 | 保存済みEXを最新として利用せず、理由付き失敗、再実行成功 | server `public_mcp_high_density_steel_rejects_existing_design_load_case_and_recovers` |

数値許容差は重量1e-8 N、質量1e-10〜1e-12 t。可否・材料/部材ID・入力ρ・ρg・78.5・
目的は文字列の契約で確認する。原子更新とUndoは#439/#506の既存経路を再利用した。
`compute_linear_static`単独は前処理済みモデルを渡す公開前提を維持し、ManualだけのDL解析まで
新しく禁止しない。GUI/MCPは共通設計準備の失敗により解析を進めない。

## 出典の確認範囲

78.5は既確認の参考資料 §2.1（本文p.8／PDF p.11）の単位重量表を採用する。
高密度遮断は資料に直接記載された操作ではなく、accepted ADR-0033とIssue #501で
確定したSEPIKAの安全性契約である。学会規準・技術基準解説書・原本全式の再閲覧は行っていない。

2026-10-10に[NIST SP811公式HTML Appendix B.8](https://www.nist.gov/pml/special-publication-811/nist-guide-si-appendix-b-conversion-factors/nist-guide-si-appendix-b8)の
standard acceleration of free fallの表（9.80665 m/s²）を直接閲覧した。
PDF本体の取得は403で未保存。HTMLの該当表の確認と、PDF全頁の確認を区別する。
このSI換算資料を任意鋼の設計重量78.5や拒否判断の原典として扱わない。

## 残る制限・未検証

- 二次CFTの設計自重は既存の主材料設計単位重量×断面積であり、鋼管/充填材の設計重量分離は
  未対応。physical側は既に材料領域分離されている。本件は鋼管密度の可否検査を追加し、
  既存重量式の再実装を混ぜない。
- 高密度カスタム鋼の実験Validation、一般建物での質量分布・応答精度は未検証。
  この入力防護のVerificationは材料物性や全構造応答の妥当性保証ではない。
- 直接設計単位重量入力、固定値変更、自動ρ比例設計値、SRC全断面への鋼密度適用は対象外。
- 未閲覧規準原本の適用条件の完全照合と、NIST PDF全頁照合は未実施。
