# CFT中柱・長柱の許容曲げの原典照合（#1124）

状態は🔶。日本建築学会の2008年第2版の体系について、純圧縮での材料別許容耐力の累加と中柱補間、および角形中長柱の許容曲げに短柱の上限を適用する公表例を確認した。許容全式の採用は保留する。利用条件は[製品文書](../../docs/calc_basis/06_一次設計/04_SRC_CFT_断面検定.md#cftの許容耐力と材料割当)、角部の幾何と終局はそれぞれ[角形の確認記録](角形CFT曲げ_Issue1104_確認記録.md)と[終局の照合](CFT柱終局NM_Issue955_原典照合.md)を参照。

## 原典で確認できた範囲

- 『2025年版 建築物の構造関係技術基準解説書』§3.10.11 p.237は告示464号の位置付けと構造・施工条件を示し、p.241の文献20・21は協会の2012年版・2024年版を示す。両頁に中長柱の許容N–M式は掲載されていない。 [先行材料調査](CFT適用材料許容耐力_Issue887_原典照合.md#原典と有限重点)
- SRC規準第6版の解説43条 p.261は純充填型を対象から除き、学会CFT指針第2版を参照する。44条5項 p.46の充填部を無視する規定は充填被覆型、付F p.58のF1・F2は終局耐力のため、純充填型の中長柱許容式はこれらから確定できない。 [適用範囲の先行照合](SRC_CFT材料弾性係数_Issue954_原典照合.md#照合した原典と適用条件)・[付Fの先行照合](CFT柱終局NM_Issue955_原典照合.md#原典で確認した範囲)

- 城戸ほか（2017）p.754、§2.2・表1・図2は、日本建築学会『コンクリート充填鋼管構造設計施工指針』2008年版による純圧縮を説明する。座屈長さ比で短柱 l_k/D≤4、中柱 4<l_k/D≤12、長柱 12<l_k/D に区分する。短柱は材料別の許容軸耐力を累加し、円形にも拘束効果を採らない。長柱は鋼管柱・コンクリート柱それぞれの許容圧縮耐力を累加し、中柱は短柱域の値と l_k/D=12 の長柱側の値を線形補間する。§2.2の式(2)以降に掲載された軸耐力・座屈応力度は終局式。§4.2(b)の長期3.0／短期1.5は著者の提案した純圧縮評価の安全率。 [論文](https://www.jstage.jst.go.jp/article/aijs/82/735/82_753/_pdf)
- 津田（2014）p.67、§4.1の1-1・表3も同じ学会指針の純圧縮許容の構成を示す。1-2は軸力と曲げを受ける中柱の低軸力域を長柱式、高軸力域を低軸力域の最大軸力点と純圧縮耐力点を結ぶ直線と説明する。この説明は許容・終局の別を明示していない。許容式にも同じ構成が適用されるかと、適用される場合の接続軸力・接続曲げ値は学会指針本文の照合が残る。 [論文](https://www.jstage.jst.go.jp/article/coj/52/1/52_65/_pdf/-char/en)
- 城戸・藤永・津田（2023）p.1592、§2.2.2の式(11)(12)は角形CFTの短柱断面累加を示し、材料別許容耐力の算定先を学会CFT指針第2編2.8節と特定する。pp.1594–1597、§3.3・§4.2・図7–9では、座屈長さを材長とした角形比較例で、材端モーメント比 κ=1, 0.5, 0 の低圧縮側に学会指針値が短柱許容曲げを超える範囲があり、その場合に短柱値を上限とすると記す。比較は材長・断面せい比12・18・24・30、幅厚比21・31、鋼管降伏応力度325・440、コンクリート圧縮強度60・90 N/mm²の組合せ例。§3.3で著者らは、学会指針の適用上限を材長・断面せい比30、鋼管降伏応力度440 N/mm²、コンクリート圧縮強度90 N/mm²と記す。これらの上限と付帯条件は指針本文での照合が残る。式(20)–(24)は著者らの提案式。 [論文](https://www.jstage.jst.go.jp/article/aijs/88/813/88_1590/_pdf/-char/ja)
- 新都市ハウジング協会の2024年第10版第1・2刷の正誤表（2025-02-28）は、第2章p.2-11表3.3-4第3行の応力度を min(2 cFc/3, Fc) に、p.2-13の円形の角度を逆余弦に訂正し、p.2-15の内法高さ比6と座屈長さ比12の条件を明確化する。正誤表には応力度表の対象全体、p.2-15の条件が掛かる本文、許容N–Mの分枝式が掲載されていない。 [公式正誤表](https://anuht.or.jp/relays/download/22/2268/2755/0/?file=%2Ffiles%2Flibs%2F10811%2F202502281300067445.pdf)
- 学会関東支部の『合成構造の設計』第2版第1刷正誤表（2023-04-26）は、p.212式(7.3.9)の cNc を cN に訂正する。式全体・適用先・荷重期間は掲載されていない。[#418](https://github.com/hrntsm/SEPIKA/issues/418)で公開実装資料から確認した低軸力側の鋼管純曲げ項の低減係数 (1−cν·cN/Nk) と、長柱コア曲げの下限0は、学会指針第2編2.8節の本文による照合が残る。 [公式正誤表](https://kanto.aij.or.jp/images/pdf/book/20230426-composite-errata.pdf)

## 6項目と採否

Nは圧縮正、fcはコアの許容圧縮応力度、cNcはコアの許容軸力、sNは鋼管分担軸力を表す。

| 項目 | 確認した範囲と不足 | 現行との差と影響 |
| --- | --- | --- |
| ① 荷重期間別 cν | 実分担 cN の訂正を確認。長期・短期それぞれの cν、上限・適用範囲、Nk の定義と組合せは本文待ち。 | 現行は fc=Fc/3, 2Fc/3 を切り替える。材料応力度の倍率である。例えば 0<cν·cN/Nk<1 でこの低減を鋼管曲げ項に適用するとその項は減る。合成耐力全体の向きは他項も含めて確認を要する。 |
| ② コア許容軸耐力 cNc | 学会体系の純圧縮は長柱の材料別許容耐力を累加する。長柱コアの座屈曲線、分岐・期間別係数と上限、曲げ併用時の分担限界との関係は本文待ち。 | 現行はコア面積と fc の積を全柱長で使う。長柱の純圧縮耐力で公表例を上回る条件を下記で確認した。 |
| ③ 長柱のコア許容曲げ cM(cN) | 公開訂正の下限0は[#418](https://github.com/hrntsm/SEPIKA/issues/418)の範囲。学会系の角形比較で合成曲げの上限に短柱値を使う場合を確認した。コア曲線の全分枝・境界・下限が掛かる範囲は本文待ち。 | 現行は断面の弾性応力積分を直接使う。短柱による合成曲げの上限からコア曲線の形や全域の安全側は決められない。 |
| ④ 分担の境界と残余軸力 | 城戸ほか（2023）p.1592の角形短柱参照式(11)(12)は 0≤N≤cNc で cN=N、N>cNc で sN=N−cNc。中長柱許容の分担境界・低減時のコア限界と鋼管側境界は本文待ち。 | 現行の圧縮軸力の分担は全柱長で短柱参照式と同じ規則を使う。鋼管の許容圧縮応力度には座屈長さを反映する。コア限界が下がる場合、より低い軸力から鋼管に残余軸力が生じ得る。 |
| ⑤ 高圧縮の鋼管許容N–Mと低減順序 | 低軸力側の鋼管項への低減は[#418](https://github.com/hrntsm/SEPIKA/issues/418)の範囲。高圧縮の鋼管許容N–M、軸力・モーメント係数の配置、短柱上限との適用順序は本文待ち。 | 現行は残余軸応力度を鋼管の許容圧縮応力度から引く直線を使う。角形では N=cNc で sZ·sft、圧縮側から境界に近づく右極限は sZ·sfc となり、sfc<sft なら下方に段差が出る。公表例の純圧縮範囲を超える軸力でも正の現行曲げ耐力を返す例がある。 |
| ⑥ 中柱の端点・高圧縮直線 | 学会系の純圧縮は短柱値と l_k/D=12 の長柱側を線形補間する。津田（2014）が説明する低軸力域の長柱式と高軸力直線が許容式にも適用されるかは本文待ち。許容用の接続軸力・曲げ値、長柱式に入れる長さ、上限の適用順も本文照合が残る。 | 現行は柱長比で許容曲線を区分せず、中柱の軸耐力も端点補間しない。軸耐力と高圧縮側の曲げ耐力の差の向きは全域で未確定。 |

学会指針2008年第2版の第2編2.8節と関連する適用条件・材料節、新都市ハウジング協会『CFT造技術基準・同解説』2012年第3版と『コンクリート充填鋼管(CFT)造技術基準・同解説の運用及び計算例等』2024年第10版の該当本文が未閲覧。式・端点を一つの版で確認し、断面形状、材種・強度、柱長比、幅厚比・径厚比、端モーメント、荷重期間を照合した後に方式を選定する。 [学会指針の書誌](https://ndlsearch.ndl.go.jp/books/R100000002-I000009763306)・[新都市の案内](https://anuht.or.jp/pages/22/)

## 独立有限例と公開入口

城戸ほか（2023）p.1596図8(d)の学会指針の許容曲線を照合した。§3.3の断面寸法どおり□250×250×12 mm、鋼管325、コンクリート60 N/mm²、材長・座屈長さ7500 mm、κ=1の例。図の縦軸は n=N/N0 で、N0は鋼管面積と降伏応力度の積にコア面積と圧縮強度の積を加えた値。現行指針の許容曲線の純圧縮切片は図読取りで約0.45。論文p.1593 §2.3.2の短期参照に合わせて下記では短期を用いた。図8(d)の凡例に荷重期間の明記はなく、読取りは指針式・期間係数の確定には使えない。座屈長さ比30は告示第464号第七の通常の範囲を超える。 [論文](https://www.jstage.jst.go.jp/article/aijs/88/813/88_1590/_pdf/-char/ja)・[告示](https://www.mlit.go.jp/notice/noticedata/pdf/201703/00006524.pdf)

SEPIKA側は直角・等厚、SN490B（板厚12 mm、F=325 N/mm²）、鋼管E=205000 N/mm²、Fc=60 N/mm²、短期、両軸座屈長さ7500 mm、せん断0とした。コア面積51076 mm²、鋼管面積11424 mm²、鋼管の断面二次モーメント108124352 mm⁴を外内の矩形差で求めた。これらから N0=6777360 N、現行の純圧縮上限4324396.436 N（n=0.638065）、n=0.55の残余圧縮を受ける鋼管の許容曲げ45191771.983 N·mmを独立に求めた。

同じ角形断面の独立算術では、境界 N=cNc=2043040 N の許容曲げは281.123315 kN·m、境界より大きい圧縮側からの右極限は172.738226 kN·mとなる。段差に対する規準上の評価と是正判断は指針本文の照合後に行う。

| 圧縮力・曲げ需要 | 公開入口の観測 |
| --- | --- |
| N=3727548 N（n=0.55）、M=0 | 軸曲げ検定比0で適合。図の純圧縮上限の読取範囲を超える。 |
| 同じ軸力、M=30 kN·m | 許容曲げ45.191772 kN·m、軸曲げ検定比0.663838で適合。 |

公開入口は `CftDesign::check`。部材端内力の入力に対し、軸曲げ成分の検定比・詳細量を確認した。有限比較は長柱の純圧縮側で耐力が大きく出るリスクを示す。中長柱全域の差、円形への適用や実験Validationは未確認。

### 円形コアの全断面圧縮

外径400、板厚16 mm、F=325、E=205000、Fc=30 N/mm²、短期、両軸座屈長さ4000 mm、強軸曲げ需要579.9 kN·mとした。現行の線形応力仮定から、全断面圧縮で cM=2Ic(cNc−N)/(Ac dc) を得る。城戸・津田（2021）p.1016 §2.1.3(b)(ii)式(8)も同じコア曲げ式を示す。N=0.995 cNc と 0.9999 cNc の合成許容曲げはそれぞれ579.624830、579.145351 kN·m。現行の中立軸探索上限はコア径の50倍で、両点とも580.114245 kN·m、比0.999631となり、同じ断面モデルの解析解に対して合否が逆転する。外径400、板厚12 mm、Fc24、F235、座屈長さ1000 mmの短柱でも同じ現象を確認した。数値算定の是正は[#1456](https://github.com/hrntsm/SEPIKA/issues/1456)で追跡する。 [城戸・津田の論文](https://www.jstage.jst.go.jp/article/aijs/86/784/86_1014/_pdf/-char/ja)

既存回帰は `cargo test -p sepika-design-jp --locked cft`。独立有限例は上表の入力と需要で、圧縮を負として `MemberForcesAt.n` に、強軸曲げを `mz` に与える。円形の中柱例は cNc=2127235.217599 N とし、同じ入口から確認する。
