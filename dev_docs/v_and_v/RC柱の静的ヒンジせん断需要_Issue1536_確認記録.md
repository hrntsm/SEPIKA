# RC柱の静的ヒンジせん断需要の数値範囲

[Issue #1536](https://github.com/hrntsm/SEPIKA/issues/1536) の公開 Rust API `collect_rc_ultimate_checks` で、静的・両端ヒンジ略算の比較需要と判定を照合した。

## 独立算術

断面 600 × 600 mm、内法 3,000 mm、Fc 24 N/mm²、圧縮軸力 150 kN、引張側主筋は数値径 25 mm の4本、降伏強度 345 N/mm²とした。円断面積から求めた引張主筋断面積は 1,963.495408 mm²、曲げ終局耐力は 369,373,589.6465 N·mm、倍率1での比較需要は 246,249.0597644 Nとなる。かぶり40 mm、帯筋は数値径10 mm・両方向2肢・間隔100 mm、ヒンジ回転角0 radとして、塑性理論式によるせん断耐力 725,654.5709 N、付着割裂耐力 1,614,106.7299 Nを独立に求めた。

| ---: | ---: | ---: | ---: | ---: | ---: |
| 1.1 | 12,000 | 270,873.9657408 | 2.634636994293 | 5.914583653322 | 適用外 |
| 1e302 | 0 | 2.462490597644e307 | 2.946831844255e−302 | 6.554773169187e−302 | 2.083724780089e−302 |
| 7e302 | 0 | 1.723743418351e308 | 4.209759777507e−303 | 9.363961670268e−303 | 2.976749685842e−303 |

二軸せん断を照査した場合、弱軸の長期せん断力は 0 N。上表の対称配筋では両軸の需要と耐力が等しく、二軸せん断余裕度は強軸せん断余裕度を √2 で除した値となる。

## 公開検定の照合

- 上表の需要と余裕度を相対誤差 1e−12 未満で照合した。修正前の公開入口では、倍率 1e302 の需要が `inf` となった。
- 対称配筋で倍率 1e303 のときは、両軸とも約 2.46249e308 Nとなる。両軸の表現上限超過を診断し、該当需要を用いる余裕度を未算定とした。長期せん断力 2 MN による単独の不適合も確認した。
- 強軸引張側を2本、弱軸を6本とした場合、倍率 7e302 では強軸約 9.65049e307 N、弱軸約 2.48244e308 Nとなる。弱軸の診断を、表現できた強軸需要による NG と併記した。配筋本数を逆にした場合は、強軸需要の診断を弱軸せん断の NG と併記した。
- 圧縮軸力 20 MNで曲げ終局耐力がゼロの場合、倍率を倍精度の最大有限値としても需要は 0 N となった。修正前は `NaN` だった。長期せん断力と耐力の等号、および耐力を超えた場合の判定を照合した。
- 倍率を倍精度で最小の正値とした場合、内法 3,000 mmでの需要は最小正値の 246,249 倍に丸められ、比較に使える。内法を 1e12 mmとすると、その需要は最小正値の半分未満で 0 N に丸められるため、表現下限の診断と未算定を確認した。この内法は数値境界を検証するための人工条件である。

### 上下限における丸め

上表と同じ対称配筋および軸力で、算定済みの倍精度の曲げ終局耐力 369,373,589.646543622 N·mm を有理数へ正確に変換し、倍率と内法も同様に変換して、Python の `fractions.Fraction` で式の値を求めた。両軸の長期せん断力は 0 N とした。

- 内法 2,996 mm、倍率 `7.290570824515764e302` では、需要が上側の丸め境界を約 0.114 ULP 下回り、倍精度の最大有限値に丸まる。倍率を次の倍精度値にすると、需要が境界を約 1.768 ULP 上回り、無限大に丸まる。ULP は最大有限値の一つ下の倍精度値との間隔を用いた。
- 内法 13,297,449,227.27557 mm、倍率を倍精度の最小正値の9倍とした場合は、需要が最小正値の半分を約 1.79e−17 倍分上回り、最小正値に丸まる。倍率を最小正値の8倍とすると、需要は最小正値の約 0.4444 倍となり、0 N に丸まる。この内法は数値境界の試験用である。

仮数の積と商を倍精度で丸める経路では、範囲内に丸まる上側・下側の両例を未算定と誤判定した。上下端に接する正規数の指数帯まで有理数で再評価する修正後は、最初の倍率で有限の需要を比較に使い、隣接する倍率で両軸が未算定になることを公開検定で確認した。

試験入口は [rc_ultimate_strength_factor.rs](../../crates/sepika-design-jp/tests/rc_ultimate_strength_factor.rs)。今回の照合範囲は、算定済み曲げ終局耐力から比較需要と余裕度を求める数値処理および判定である。耐力式の全適用範囲と実験 Validation は含まない。
