# RC柱の静的ヒンジせん断需要の数値範囲

[Issue #1536](https://github.com/hrntsm/SEPIKA/issues/1536) の公開 Rust API `collect_rc_ultimate_checks` で、静的・両端ヒンジ略算の比較需要と判定を照合した。

## 独立算術

断面 600 × 600 mm、内法 3,000 mm、Fc 24 N/mm²、圧縮軸力 150 kN、引張側主筋は数値径 25 mm の4本、降伏強度 345 N/mm²とした。円断面積から求めた引張主筋断面積は 1,963.495408 mm²、曲げ終局耐力は 369,373,589.6465 N·mm、倍率1での比較需要は 246,249.0597644 Nとなる。かぶり40 mm、帯筋は数値径10 mm・両方向2肢・間隔100 mm、ヒンジ回転角0 radとして、塑性理論式によるせん断耐力 725,654.5709 N、付着割裂耐力 1,614,106.7299 Nを独立に求めた。

| 上限強度倍率 | 強軸の長期せん断力 [N] | 強軸ヒンジせん断需要 [N] | 強軸せん断余裕度 | 付着余裕度 | 二軸せん断余裕度 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 1.1 | 12,000 | 270,873.9657408 | 2.634636994293 | 5.914583653322 | 適用外 |
| 1e302 | 0 | 2.462490597644e307 | 2.946831844255e−302 | 6.554773169187e−302 | 2.083724780089e−302 |
| 7e302 | 0 | 1.723743418351e308 | 4.209759777507e−303 | 9.363961670268e−303 | 2.976749685842e−303 |

二軸せん断を照査した場合、弱軸の長期せん断力は 0 N。上表の対称配筋では両軸の需要と耐力が等しく、二軸せん断余裕度は強軸せん断余裕度を √2 で除した値となる。

## 公開検定の照合

- 上表の需要と余裕度を相対誤差 1e−12 未満で照合した。修正前の公開入口では、倍率 1e302 の需要が `inf` となった。
- 対称配筋で倍率 1e303 のときは、両軸とも約 2.46249e308 Nとなる。両軸の表現上限超過を診断し、該当需要を用いる余裕度を未算定とした。長期せん断力 2 MN による単独の不適合も確認した。
- 強軸引張側を2本、弱軸を6本とした場合、倍率 7e302 では強軸約 9.65049e307 N、弱軸約 2.48244e308 Nとなる。弱軸の診断を、表現できた強軸需要による NG と併記した。配筋本数を逆にした場合は、強軸需要の診断を弱軸せん断の NG と併記した。
- 圧縮軸力 20 MNで曲げ終局耐力がゼロの場合、倍率を倍精度の最大有限値としても需要は 0 N となった。修正前は `NaN` だった。長期せん断力と耐力の等号、および耐力を超えた場合の判定を照合した。
- 倍率を倍精度で最小の正値とした場合、内法 3,000 mmでの需要は最小正値の 246,249 倍に丸められ、比較に使える。内法を 1e12 mmとすると、その需要は最小正値の半分未満で 0 N に丸められるため、表現下限の診断と未算定を確認した。この内法は数値境界を検証するための人工条件である。

### 上下限における丸め

上表と同じ対称配筋および軸力で、算定済みの倍精度の曲げ終局耐力 369,373,589.646543622 N·mm を有理数へ正確に変換し、倍率と内法も同様に変換して、Python の `fractions.Fraction` で式の値を求めた。両軸の長期せん断力は 0 N とした。

- 内法 2,996 mm、倍率 `7.290570824515764e302` では、需要が上側の丸め境界を約 0.114 ULP 下回り、倍精度の最大有限値に丸まる。倍率を次の倍精度値にすると、需要が境界を約 1.768 ULP 上回り、無限大に丸まる。ULP は最大有限値の一つ下の倍精度値との間隔を用いた。
- 内法 13,297,449,227.27557 mm、倍率を倍精度の最小正値の9倍とした場合は、需要が最小正値の半分を約 1.79e−17 倍分上回り、最小正値に丸まる。倍率を最小正値の8倍とすると、需要は最小正値の約 0.4444 倍となり、0 N に丸まる。この内法は数値境界の試験用である。

仮数の積と商を倍精度で丸める経路では、範囲内に丸まる上側・下側の両例を未算定と誤判定した。上下端に接する正規数の指数帯まで有理数で再評価する修正後は、最初の倍率で有限の需要を比較に使い、隣接する倍率で両軸が未算定になることを公開検定で確認した。

試験入口は [rc_ultimate_strength_factor.rs](../../crates/sepika-design-jp/tests/rc_ultimate_strength_factor.rs)。今回の照合範囲は、算定済み曲げ終局耐力から比較需要と余裕度を求める数値処理および判定である。耐力式の全適用範囲と実験 Validation は含まない。

## 二軸せん断余裕度の上限

[Issue #1825](https://github.com/hrntsm/SEPIKA/issues/1825) では、上記の 600 mm 角の柱で、両軸の長期せん断力を 0 N とし、引張側主筋の本数と上限強度倍率を変えた。Python の `decimal.Decimal` の精度を72桁として、各軸の引張主筋断面積、曲げ終局耐力、ヒンジせん断需要を求めた。塑性理論式のせん断耐力は両軸とも 725,654.5709314911 N であり、この共通耐力を両軸の需要の二乗和の平方根で除して、二軸せん断余裕度を独立に求めた。

| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 4／4 | 1.5e−308 | 3.693735896465436e−303 | 3.693735896465436e−303 | 1.964554562836708e308 | 1.964554562836708e308 | 1.389149853392810e308 |
| 4／6 | 1.5e−308 | 3.693735896465436e−303 | 5.319510094698154e−303 | 1.964554562836708e308 | 1.364137971379613e308 | 1.120498307036174e308 |
| 2／6 | 1.2e−308 | 1.654369358586174e−303 | 4.255608075758523e−303 | 4.386291169897127e308 | 1.705172464224516e308 | 1.589303039218801e308 |
| 4／4 | 1 | 246249.0597643624 | 246249.0597643624 | 2.946831844255062 | 2.946831844255062 | 2.083724780089215 |
| 4／4 | 1e−308 | 2.462490597643624e−303 | 2.462490597643624e−303 | 2.946831844255062e308 | 2.946831844255062e308 | 2.083724780089215e308 |

- 修正前の公開検定では、倍率 1.5e−308 の 4／4 本で二軸せん断余裕度が `inf` になり、有限値を期待する回帰テストが失敗した。
- 修正後の公開検定では、二軸せん断余裕度が倍精度の範囲に収まる上表のケースと、4／6 本の強弱軸を交換したケースが、相対誤差 1e−12 未満で独立値に一致した。倍率 1e−308 の 4／4 本では正の需要を算定し、二軸せん断余裕度は `inf` となった。圧縮軸力 20 MN、倍率を倍精度の最大有限値とした 4／4 本でも、正のせん断耐力と真のゼロ需要に対して二軸せん断余裕度 `inf` を確認した。
- 同じ[強度倍率の公開テスト](../../crates/sepika-design-jp/tests/rc_ultimate_strength_factor.rs)の14件が通過した。上側・下側の需要の丸め、大きな有限需要、強弱軸いずれかの需要が範囲外となる場合の理由と別照査の NG の保持も確認した。

### 最大有限値と無限大の丸め境界

対称配筋の 4／4 本、圧縮軸力 150 kN、両軸の長期せん断力 0 N、内法 2,900.42 mm とした。両軸のせん断耐力は 732,916.03998272121 N。算定した倍精度の需要と耐力を `decimal.Decimal` に正確に変換し、精度80桁で共通耐力を √2 と片軸需要の積で除した。ULP には最大有限値とその一つ下の倍精度値との差を用いた。

| 上限強度倍率のビット列 | 両軸共通のヒンジせん断需要 [N] | 二軸せん断余裕度と最大有限値の差 | 最近接偶数丸めの結果 |
| --- | ---: | ---: | --- |
| `0x0008_238d_2f77_b89a` | 2.88286077229674368e−303 | −0.051606 ULP | 最大有限値 |
| `0x0008_238d_2f77_b899` | 2.88286077229674239e−303 | +3.994998 ULP | `inf` |

無限大に丸まる境界は最大有限値に半 ULP を加えた値。正規化した比とノルムを倍精度だけで求めた場合、上表の一行目は `inf` になり、公開検定の回帰テストが失敗した。合成余裕度を境界で有理数により比較する修正後は、隣接する二つの倍率で上表の丸め先を確認した。両例とも正の需要を算定し、単軸余裕度は `inf` となった。

照合範囲は静的・両端ヒンジ略算の数値処理と公開判定である。零耐力かつ零需要の扱いは [#1815](https://github.com/hrntsm/SEPIKA/issues/1815) で追跡する。耐力式の全適用範囲、実験 Validation、他の需要モードは今回の照合範囲外である。
