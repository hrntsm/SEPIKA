# ねじれで柱の層間変位が相殺される場合の偏心率（Issue #1595）

[Issue #1595](https://github.com/hrntsm/SEPIKA/issues/1595) の調査。状態🔶。1層の弾性剛床モデルで、ねじれによって鉛直柱の層間変位が相殺されても負担水平力が残り、偏心率が独立値と異なることを再現した。修正前の数値は照合時点の観測値とし、製品の現行動作は [#1680 の修正後の照合](#1680-の修正後の照合)に記録する。

## 原典の適用条件

『2025年版 建築物の構造関係技術基準解説書』第2版第1刷の6.2.3 pp.359–362を原画像で確認した。p.361掲載の平成19年国土交通省告示第594号第5と、同頁 (4)・p.362 (5) の解説では、各階がねじれず、構面の水平変形がそろう並進架構による評価を原則とする。立体解析等では剛床仮定の成否を問わず、一次設計用地震力作用時の応力から水平剛性を評価できる。ただし、ねじれ回転で鉛直部材の層間変位が0に近づくことを確認した場合は、剛性の過大評価を避けるため並進架構等で評価する。近零を判定する数値は指定されていない。[刊行元の書誌](https://www2.icba.or.jp/products/detail.php?product_id=606)

剛心は層せん断力を作用させると回転せず一様な水平変位を生じる点。ねじり剛性は剛心回りに単位回転を生じさせるためのモーメント。pp.359–360の式(6.2–3)・(6.2–6)は直交グリッドの構面を前提とし、式(6.2–7)・(6.2–8)は弾力半径と偏心率を示す。重心には地震時の層せん断力の合力位置を用いる。本比較では重心加力の合力位置を、すべての偏心率評価で共通に用いる。

## モデルと独立値

階高3,000 mmの鉛直柱4本を A (0, 0)、B (2000, 0)、C (1000, −4000)、D (1000, 4000) mm に置く。柱脚を固定し、柱頭のUz・Rx・Ryを拘束する。剛床を介して柱頭は水平並進と鉛直軸回り回転を共有する。Aの柱頭を剛床の代表節点とする。全柱のE＝200,000、G＝80,000 N/mm²、A＝2,000、両方向のせん断有効断面積＝1,600 mm²、強軸・弱軸の断面二次モーメント＝12,000,000・8,000,000、ねじり定数J＝4,000,000 mm⁴。剛域、端部偏心、壁、部材荷重はない。平面内の強い変位方向を A・B は全体X、CはXから−45°、Dは＋45°とする。

両端の曲げ回転を拘束した一様梁では、固定端からの距離を s とすると横力Qによる曲げモーメントは Q(L/2−s) と書ける。曲げと一定せん断のひずみエネルギーから、横変位の柔度は L³/(12EI)＋L/(GAs)。これを逆にした主軸の剛性を `k_s`＝1,040.650407、`k_w`＝699.453552 N/mm とする。A・Bの水平剛性行列は対角に `k_s`, `k_w` を持つ。C・Dの水平剛性行列は、対角成分がともに `k_d`＝(`k_s`＋`k_w`)/2＝870.051979 N/mm、非対角成分がそれぞれ −t, ＋t、t＝(`k_s`−`k_w`)/2＝170.598427 N/mm。柱個別にX/Yが連成していても、層全体の並進剛性ではこの非対角成分が相殺される。

原点の剛床応答を (u, v, θ) と置く。平面位置 (xᵢ,yᵢ) の柱頭変位は (u−yᵢθ, v＋xᵢθ)。柱水平剛性行列をその変位に掛けて、柱頭力 Qᵢ を求める。層の外力と釣り合う原点回りのモーメントは Σ(xᵢQᵢy−yᵢQᵢx)＋Σ(GJ/L)θ。第2項は柱頭Rzが材軸ねじりを生むことによる。これは柱の水平せん断に含まれない。柱1本当たり GJ/L＝106,666,666.667 N·mm/rad、4柱の和は426,666,666.667 N·mm/rad。

純並進の合力から Hxx＝2(`k_s`＋`k_d`)、Hyy＝2(`k_w`＋`k_d`)、Hxy＝0。原点で並進・回転を結ぶ剛性を (bₓ,bᵧ)、原点を動かさない回転剛性を c とすると、柱頭位置と上の釣合いより bₓ＝0、bᵧ＝1,000Hyy−8,000t、c＝4,000,000`k_w`＋2(17,000,000`k_d`−8,000,000t)＋4GJ/L（長さは mm）。剛心を通る合力は並進のみを生じるため、その座標は (bᵧ/Hyy, 0)。純ねじりでは水平合力が0なので、原点変位は (0, −bᵧθ/Hyy)。この応答から剛心回りのねじり剛性 KR＝c−bᵧ²/Hyy を得る。

| 独立値 | 値 |
| --- | ---: |
| Hxx, Hxy, Hyy [N/mm] | 3,821.404771, 0, 3,139.011062 |
| 剛心 X, Y [mm] | 565.217391, 0 |
| 原点回りの回転剛性 c [N·mm/rad] | 30,076,673,330.668 |
| 剛心回りのねじり剛性 KR [N·mm/rad] | 29,073,851,271.086 |

公開線形解析では剛心を通る各1,000 NのX/Y力と1,000,000 N·mmの純ねじりから、この並進剛性・剛心・ねじり剛性を照合した。全載荷で層せん断力を比較し、柱頭力と柱頭ねじりモーメントによる原点回りの釣合いも確認した。

## ねじれ相殺と荷重の比例縮小

X力PをY座標 e に作用させると u＝P/Hxx、θ＝−Pe/KR。CではX方向変位差が u＋4000θ になる。e を KR/(4000Hxx) の0.999倍とし、X変位を純並進の1/1000にした。この倍率はモデル入力を定める数である。加力位置 (565.217391, 1900.137460) mm を質量節点のある重心とし、X・Y方向へ各1,000 Nを作用させる。公開解析では床代表節点に合力と等価な力・モーメントを与える。Y力の作用線は剛心を通るので、重心Y加力は純並進となる。偏心率の計算には長期結果を渡さず質量重心を使う。

重心X加力では u＝＋0.261683872768 mm、θ＝−6.53555472238×10⁻⁵ rad。Cの回転によるX変位は −0.261422188895 mm、全X変位差は ＋0.000261683873 mm。比較用にX力の作用線を剛心へ移して純並進を与え、さらにX・Y双方の純並進荷重を1/1000にした。符号付き柱力の正は、柱が床から受ける全体座標の正方向とする。

| X載荷・柱 | X, Y層間変位差 [mm] | Qx, Qy [N] |
| --- | ---: | ---: |
| 重心・A | ＋0.261683873, ＋0.036940092 | ＋272.321429, ＋25.837878 |
| 重心・B | ＋0.261683873, −0.093771003 | ＋272.321429, −65.588461 |
| 重心・C | ＋0.000261684, −0.028415455 | ＋5.075311, −24.767566 |
| 重心・D | ＋0.523106062, −0.028415455 | ＋450.281832, ＋64.518148 |
| 純並進・C | ＋0.261683873, 0 | ＋227.678571, −44.642857 |
| 純並進を1/1000に縮小・C | ＋0.000261684, 0 | ＋0.227679, −0.044643 |

Cの重心加力時の Qx＝`k_d`δx−tδy は、X変位による ＋0.227679 N と、ねじれで生じたY変位による ＋4.847632 N の和。δx を0へ近づけても第2項が約4.85 N残るため、加力方向の絶対値比が増大する。対象Cの公開X剛性は重心加力で19,394.816 N/mm、純並進とその縮小でともに870.052 N/mm。方向ごとに独立な柱で Qx＝kxδx が成り立つ場合は、ねじれで同じX変位の相殺が起きてもQxも同比例で減り、この発散は生じない。また、同一条件の線形荷重を全体に比例縮小すれば力・変位とも同じ倍率で縮小する。この二つの例のように変位差の絶対値だけでは原因を区別できない。

## 公開偏心率と比較条件

重心はすべて (565.217391, 1900.137460) mm に固定した。純並進の行で変更するのは、柱剛性の評価に用いる載荷条件。独立値の分子は加力方向に直交する座標差の絶対値。重心を `(x_G, y_G)`、純ねじりから得た剛心を `(x_R, y_R)` とすると、ReXの分子は `|y_G − y_R|`、ReYの分子は `|x_G − x_R|` になる。それぞれをX・Y方向の弾力半径 `√(KR/Hxx)`、`√(KR/Hyy)` で除した。層のHxyが0のため、直交方向の変位を拘束する純並進と、直交方向の外力を0とする純並進で同じ並進剛性となる。

| 評価 | 剛心 X, Y [mm] | KR [N·mm/rad] | Re X, Y |
| --- | ---: | ---: | ---: |
| 重心加力の公開結果 | 1,000.000, −3,318.998 | 79,430,901,893.400 | 2.767676, 0.086432 |
| 純並進を用いた公開結果 | 1,000.000, 0 | 29,240,570,438.491 | 0.686916, 0.142454 |
| 純並進を1/1000に縮小した公開結果 | 1,000.000, 0 | 29,240,570,438.491 | 0.686916, 0.142454 |
| 剛心・ねじり剛性の定義による独立値 | 565.217, 0 | 29,073,851,271.086 | 0.688883, 0 |

重心加力ではCの比が過大となり、公開の剛心YがC側に移動してX偏心率が独立値の約4倍になった。局所の剛性の過大評価は剛心と弾力半径の両方に影響し、偏心率や形状係数の差が常に安全側になるとは限らない。一方、純並進による柱の比からも、位置ごとの直交方向の力によるモーメントと、柱個別の材軸ねじりは組み立てられない。X偏心率が独立値に近づいたこの例でも、剛心XとY偏心率には差が残る。層のHxyだけを確認しても、位置ごとの連成によるねじりへの寄与を判定できない。

各位置の方向別水平力を方向ごとの独立な剛性と変位の積で表せ、剛心回りのねじりモーメントをその水平力と腕で表せる架構は、方向別剛性を集計する式の前提に合う。床のねじれによる局所相殺と、加力方向の変位に比例しない水平力がある場合は、加力時の商を採用する前に、並進架構等による剛性と剛心回りのねじりモーメントを別途評価する必要がある。柱の材軸ねじり等が無視できない場合は、その寄与も独立評価に含める。現行は変位差が有限で0より大きく、商も有限なら比を採用するため、この相殺を自動で判別・診断できない。変位差が厳密に0なら算定不能になる。

## 再現と残る範囲

[統合試験](../../crates/sepika-design-jp/tests/torsional_cancellation_eccentricity.rs) は、独立剛性・剛心・ねじり剛性、符号付き柱頭力、同じ微小変位でも異なるせん断力、比例縮小時の柱剛性とReの不変性を検証する。公開線形解析が記録する上端の符号付き水平力は、部材荷重のない本例の柱頭節点力と照合する。相殺時の公開Reは観測値を出力する。

```bash
cargo test --locked -p sepika-design-jp --test torsional_cancellation_eccentricity -- --nocapture
```

基点 `cc5efe73` に本変更を適用し、WindowsのRust 1.100.0で上記試験、sepika-design-jpの全924試験、同クレートの全ターゲットClippy、`xtask check-docs`、`mdbook build docs` の成功を確認した。Cargoに未使用の既存ワークスペース依存宣言 `schemars` の警告が出た。

柱の負担水平力の修正を含む基点 `167a2b0d` で再検証した。ねじれ相殺と斜め柱の公開統合試験は計5件成功した。対象柱Cの重心X加力と小荷重のXせん断力（＋5.075311 N、＋0.227679 N）、純並進・純ねじりの独立値、公開のReは上表の精度で一致した。斜め柱については、部材荷重・剛域・端部偏心付きの上端の切断面力と、分割材の途中に載荷した場合の上端力を含め、先行の4試験を再確認した。同じRust 1.100.0でsepika-design-jpの全926試験、全ターゲットClippy、`xtask check-docs`、`mdbook build docs` も成功した。[修正PR #1679](https://github.com/hrntsm/SEPIKA/pull/1679)

- 本例では鉛直柱の軸力に水平成分がなく、部材荷重・剛域・端部偏心もない。負担水平力の算定を扱う [#1674](https://github.com/hrntsm/SEPIKA/issues/1674) の修正適用後も、上端で観測した水平力は柱頭節点力と一致した。層のHxyを0としたため、層全体の並進連成があるときの評価 [#1675](https://github.com/hrntsm/SEPIKA/issues/1675) と独立に再現できる。
- 相殺を判断する条件、適用外の診断や並進架構等を使う評価は [#1680](https://github.com/hrntsm/SEPIKA/issues/1680) で追跡する。非剛床、複数層、壁・付加ばね、部材荷重・剛域・偏心付き部材、長期軸力による重心と地震時合力位置の整合は本例では検証していない。
- 同じ柱剛性を使う自立壁n倍法の付加剛性・剛性率、柱剛性を入力とする質点系の生成・応答、形状係数から求める必要保有水平耐力および判定への数値影響は確認していない。実架構への適用、実験Validation、手動GUI・CSV確認も対象外とした。
- [形状係数Fes](../../docs/calc_basis/07_二次設計/04_形状係数_Fes.md#偏心率-re-と係数-fe) に、有限な算定値を設計で採用する際の条件を記載する。

## #1680 の修正後の照合

[統合試験](../../crates/sepika-design-jp/tests/torsional_cancellation_eccentricity.rs)では、重心X加力とその1/1000の比例縮小、および等価な剛床で代表節点をCに替えた場合に、階1・X方向・柱2（C）の層間変位の相殺を理由として算定が保留されることを照合する。純並進とその比例縮小については、従来どおり柱剛性・ねじり剛性・偏心率が同じになることを照合する。独立値は上記の釣合いの数値を維持する。

[層指標](../../crates/sepika-app/src/summary.rs)では、一方向の相殺理由が層の両方向のReとFesに伝わることを確認する。[Rs評価用再解析](../../crates/sepika-job/src/stiffness_ratio.rs)では、付加剛性に用いる柱の相殺で理由が伝わり、一次解析の変位を保持することを確認する。[質点系](../../crates/sepika-job/src/lumped_mass.rs)では、上下階の共通回転では生成でき、上層に相対回転で相殺があると、3次元せん断型と柱剛性を使う2次元せん断型の生成を対象層と柱の理由付きで停止することを確認する。これらは合成した変位・応力を使う経路の検証であり、実建物や動的応答のValidationは実施していない。

非剛床・複数剛床での相殺と評価は [#1683](https://github.com/hrntsm/SEPIKA/issues/1683) で追跡する。並進架構等による再評価と独立値との一致は今回の検証範囲外とする。
