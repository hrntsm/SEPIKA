# RC柱の短期Fc/3警告の調査（Issue #1008）

## 判定と未完了事項

AIJ RC規準2024年刊行版14条3項で、短期平均圧縮軸応力度の条件付き推奨上限と例外を確認した。短期圧縮の小・境界・大を含む公開柱検定120結果では、現行の低圧縮側警告と推奨上限の方向が異なる。[製品文書の短期平均圧縮軸応力度](../../docs/calc_basis/06_一次設計/02_RC_断面検定.md#短期平均圧縮軸応力度)に結果の読み方を記載した。

**参照する2010年刊行版は本文・関連解説が未照合で、採用版の判断とともに[#1008](https://github.com/hrntsm/SEPIKA/issues/1008)で継続する。適用条件の入力と警告表示の是正は[#1392](https://github.com/hrntsm/SEPIKA/issues/1392)で追跡する。**

### 2024年版で確認した適用条件

- 1条は3・4条の材料によるRC造建築物を対象とする。特別な調査研究で同等の構造性能を確認した場合は規準の一部を適用除外にできる。7条1項は荷重・外力の組合せを施行令・関連告示または規準に挙げた学会指針に委ねる。14条1項は長期荷重下の使用性、短期荷重下の損傷制御を扱う。短期には積雪・暴風・地震などの組合せがあり、14条3項の対象は地震時に曲げが特に増大するおそれのある柱という設計上の条件で決まる。
- 14条3項の比較量は短期の圧縮軸力をコンクリート全断面積で除した平均値で、Fc/3は等号を含む推奨上限である。解説pp.150–151では、設計用地震力より大きな水平力を受けうることを背景に、塑性域で必要な靱性と建物・部材の動的特性を設計者が判断する。余力の少ない純ラーメンは靱性への依存が大きい例。構造壁が多く、十分な耐震強度があり、柱の靱性を期待する必要のない建物では非適用とし得る。溶接帯筋・スパイラル筋などを採用し、大きな靱性を実験で確認できた柱では上限を引き上げ得る。壁の数や配筋形式だけを条件に自動除外する根拠は得られない。
- 解説図14.6～14.8とpp.151–153の説明では、圧縮軸力が大きくなるにつれて変形能力が低下する例を示している。p.153は、内法高さ／せいが5程度の柱について、Fc/3で変形限界部材角約0.01 rad・塑性率2程度以上を期待する目安を示す。これを個別の柱の靱性保証値とは扱わない。
- 14条2項の許容曲げはコンクリートの圧縮縁、圧縮鉄筋、引張鉄筋のそれぞれの材料許容値で決まる。6条表6.1および[建築基準法施行令第91条](https://laws.e-gov.go.jp/law/325CO0000000338)の材料の許容圧縮応力度は長期F/3・短期2F/3。第91条の長期F/3と14条3項の短期Fc/3には異なる目的・比較量がある。告示第1792号第4のFA種別で用いる0.35も、崩壊形到達時の軸方向応力度を用いる別の指標である。

## 公開柱検定の追加Verification（2026-11-18）

対象は `3c1083a2`。共通製品入口 `run_member_design_checks` に、3位置（始端・中央・終端）の純軸力を与えた。既存の `tests/fixtures/rc_column_axial_boundary_model.rs` のモデルを使い、矩形だけ観測用ソース内で500×500 mmへ変更した。共有fixtureと製品計算は変更していない。円形はD600 mmで、面積は90,000π mm²。Fc24 N/mm²、SD345・径19 mmの主筋8本、帯筋径10 mm・間隔100 mm、長さ3,000 mmである。

独立算術は、矩形の面積250,000 mm²、Fc/3=8 N/mm²から、平均圧縮応力度4・8・12 N/mm²を軸力1,000・2,000・3,000 kNへ換算した。円形では同じ応力度に対して360π・720π・1,080π kNとなる。これらはコンクリート全断面平均であり、鉄筋を換算した断面応力度や許容軸耐力ではない。

| 観測条件（両断面） | 現行の当該警告 | 2024年版14条3項の標準上限を適用する場合の期待・限界 |
| --- | --- | --- |
| 短期圧縮4 N/mm² | 中央だけに表示 | 上限内。低圧縮を警告する根拠は確認できていない |
| 短期圧縮8 N/mm² | 全位置でなし | 等号を含めて上限内 |
| 短期圧縮12 N/mm² | 全位置でなし | 推奨上限を超過。現行の警告なしを靱性の確認に使えない |
| 短期圧縮8−2×10⁻⁹ N/mm² | 中央だけに表示 | 数学上は上限内。現行の比較許容差の低側で外側を観測 |
| 短期圧縮8−0.5×10⁻⁹・8+2×10⁻⁹ N/mm² | 全位置でなし | 数学上は順に上限内・超過。是正時の数値許容差は未決定 |
| 長期圧縮（上記6値）、長短の軸力0・引張4／8／12 N/mm² | 全位置でなし | 当該短期圧縮上限の警告対象外。別の許容応力度検定の適合を示さない |

2断面×2荷重区分×10軸力値×3位置、計120結果がすべて `Checked` であり、当該警告の有無が上表と一致した。同一応力の3位置で検定比は一致し、`Provision`成分はなかった。短期500角の圧縮4／8／12の比は約0.221824／0.443648／0.665471で、低側警告ありでも高側警告なしでも `ok=true` となった。長期の同じ軸力では比約0.443648／0.887295／1.330943となり、3,000 kNは `ok=false` だが当該短期警告はない。この比の観測はN–M耐力全域の正解の保証ではない。

観測用ソースは [axial_warning_observation.rs](data/issue1008/axial_warning_observation.rs) に保存した。誤りが疑われる既存出力の証拠であり、望ましい規準適合の回帰契約ではない。再実行時は対象コミットの `crates/sepika-design-jp/tests/issue1008_probe.rs` へ一時複写し、`cargo +stable test -p sepika-design-jp --test issue1008_probe --locked -- --nocapture` を実行して複写先を削除する。2026-11-18の実行は1試験成功・120結果。stable 1.100.0、dev/testのdebug=0で実行し、raw出力は非追跡の `target/tmp/issue1008/product-boundary-20261118.log` に保存した。

刊行版の追加照合時に、同じ観測ソースを `3c3c3f02` で再実行した。1試験・120結果で警告の有無と圧縮側の検定比・合否が一致した。例えば500角の短期圧縮3,000 kNは警告なし・検定比約0.665471で数値上適合、同じ長期圧縮では警告なし・約1.330943でNGだった。短期圧縮4 N/mm²の中央で警告が出ても検定比約0.221824で数値上適合した。このモデルは純軸力の比較境界を確認する入力で、建物の動的特性から14条3項の適用を判定する試験ではない。

## 是正仕様への接続と残る判定

[#1392](https://github.com/hrntsm/SEPIKA/issues/1392)では、採用版と以下の入力・判定契約を確定した上で、`rc/provisions.rs::column_provisions_info`、円形・矩形の呼出元 `rc/column/mod.rs::column_check`、公開柱検定の試験、製品文書を是正する。

- 低圧縮側の警告を改める。対象の短期圧縮で標準上限以下は上限内、超過は靱性のための確認事項とする。許容応力度による検定の不適合とは別に利用者へ伝える。
- 地震時に特に曲げが増大しうるか、建物・部材に必要な靱性、非適用の根拠、実証した上限を判別する入力と、その入力を利用者が指定・確認する経路を定める。対象・非対象・例外・判別不能を表示上区別し、判別不能には確認が必要であることを示す。上限を引き上げる例外では、根拠と設定上限に基づいて比較する。
- どの短期組合せの圧縮軸力をどの断面位置で評価するか、数値許容差、必要なGUI・MCPへの伝達と保存済み検定の失効要否を定める。公開入口で矩形・円形、等号・境界直近、長短・符号と対象・非対象・例外・判別不能を検証し、構造規定の警告と検定比・NGの区別を確認する。

#1008では第8版の刷を特定して14条本文p.16と解説p.134以降、総則・材料・設計荷重を照合し、刷別正誤表を適用した上で採用版と改定差を判断する。現行の低圧縮側の比較を導入した構造設計上の意図、採用刊行版への適合、実際の柱への適用、全組合せ・GUI/MCP実操作、実建物Validation、専門家サインオフは未確認である。

## 範囲外で見つかった純引張の見落とし

初回の `3c1083a2` の観測で、500角の引張1,000／2,000／3,000 kNが長短・全3位置で検定比0、`ok=true`となった。主筋8本の断面積を数値径19 mmの円面積で独立に求めると722π=2,268.22989589183 mm²である。SD345の径19 mmに対する許容引張応力度は長期215・短期345 N/mm²であり、コンクリートの引張を無視する純引張の許容軸力は主筋面積×許容応力度から487.669428／782.539314 kNとなる。引張1,000 kNでも独立比は長期2.050569389／短期1.277891068であり、比0のOKを安全側の扱いとは評価できない。ここでの面積は実装が受理する数値径の幾何面積で、標準呼び径の公称断面積との一致を主張しない。

当時の `column_check` は円形・矩形の両方で引張側の軸力比が0で、円形D600でも平均引張4／8／12 N/mm²で比0・OKを観測した。純引張の是正は[#1393](https://github.com/hrntsm/SEPIKA/issues/1393)・[#1395](https://github.com/hrntsm/SEPIKA/pull/1395)で扱った。`3c3c3f02` では500角の引張1,000 kNの検定比は長期約2.050569／短期約1.277891でどちらもNGとなり、当該短期圧縮警告は出ていない。純引張の現在の適用範囲は[純引張の確認記録](RC柱純引張_確認記録.md)を参照する。
