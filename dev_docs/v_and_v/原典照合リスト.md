# 原典照合リスト

この一覧は、**どの数値・式・適用条件について、原典確認が残っているか**を示す。
更新日：2026-10-27。数値・式の確認範囲は各照合記録、開発課題の最新状態はGitHub Issueを正とする。

| 区分 | この一覧での意味 | 次に行うこと |
| --- | --- | --- |
| [照合待ち](#照合待ち) | 根拠となる数値・式、又は現行方式へ適用できる条件を確定できていない | 表に示す原典・確認事項を調べる |
| [不一致確認済み](#不一致確認済み) | 原典との差は確認できている | 修正又は別方式の採否をIssueで判断する。単なる原典未閲覧とは扱わない |
| [採用方針確定](#採用方針確定原典との一致とは別) | 原典との差を保持した上で現行方式の採用を決定した | 決定した適用範囲を製品文書で確認する |
| [指定範囲で照合済み](#指定範囲で照合済み) | 記載した範囲で原典と数値・式が一致した | 同じ範囲の照合を繰り返さず、残る適用条件だけを確認する |
| [照合対象外](#照合対象外) | 廃止した実装、又は本一覧とは別に扱う検証 | 現行の照合待ちに数えない |

指定原典は『2025年版 建築物の構造関係技術基準解説書』第2版第1刷（2026-02-11発行、以下「2025年版」）。
ユーザー指定により、同書収録の政令・告示を原典として受理する。公布原文の再取得は今回の照合完了の条件にしない。
照合済みは指定範囲の記載確認を表し、専門家サインオフ・実験Validation・全設計条件への適合とは別である。
