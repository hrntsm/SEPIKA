# 符号付き単純梁反力（Issue #633）

## 対象と証拠境界

過去候補の直接検証は下記履歴、現行契約によるW/S統一後の直接検証は末尾を参照する。

基準main: `0186131a80c7cd35833805c79668b208283270e9`。最新の検証対象コードSHAは `7415a53126818c933d6e22abdb3b7b85ef634807`。製品仕様は[床の符号付き反力](../../docs/calc_basis/01_荷重/03_床荷重の分配.md#符号付き単純梁反力)、[部材荷重](../../docs/calc_basis/04_要素剛性/03_部材荷重.md)、[地震重量](../../docs/calc_basis/01_荷重/05_地震用重量_層データの生成.md)を正とする。

floor/storyの既存関数の小修正を選択した。floorは原分布区間でW/Sを評価し、旧重心閾値・比clampの条件付き経路を残さない。数学の独立受入保証と域外結果の物理的妥当性は区別する。coreへ新しい共通APIを加える案は、入口ごとのadapter差を残したまま依存・API差分を増やし、正しいelement経路の不要な変更も招くため採らなかった。elementの数学コードは変更せず回帰だけ追加する。

## 独立Verification

`sepika-load/tests/signed_simple_reactions.rs` は公開 `floor::{simple_reactions,simple_beam_moment_at,simple_beam_extremes}` を実行する。期待反力の固定値は自由物体のΣF=0・ΣMi=0から導出し、別途Simpson則でw(s)、s w(s)、w(s)(x−s)を直接積分する。製品閉形式やelementの式のコピーで期待値を作らない。

| L=6000 mmの入力 | 独立期待（反力N、一次モーメント／曲げN·mm） |
|---|---|
| 全長+1→−1 N/mm | W=0、S=−6000000、Ri=1000、Rj=−1000、M(0/6000)=0、M(1500/3000/4500)=562500/0/−562500 |
| [1000,4000]、+1→−1 | W=0、S=−1500000、Ri=250、Rj=−250、両端M=0 |
| 全長+1→−1+1e−10 | Ri=1000.0000001、Rj=−999.9999998、近ゼロ合力でも反力対を保持 |
| 全長+1→−0.9 | Ri=1100、Rj=−800、重心が支間外でも反力比を制限しない |
| 全長+1→+1／0→+1 | Ri/Rj=3000/3000、1000/2000 |
| 点P=1000 N、a=1500 mm | Ri/Rj=750/250。同位置−1000との合成は反力・Mとも0 |

力の絶対許容差1e−8 N、一次モーメント・独立M積分1e−5 N·mm、固定M値1e−6 N·mm。近ゼロ合力の相対誤差だけでは判定しない。
符号反転・i/j反転の比較は対称性の自己比較であり、上表の独立数値証拠と区別する。床のせん断最大1000 N、曲げ最大の範囲を照合し、EI y''=Mの独立積分から最大たわみも照合する。既存80分割近似では独立値0.0264148455 mmとの差が0.0000308585 mmであり、絶対許容差0.00004 mmを用いる。初回0.00002 mmのassert失敗ログは保存する。

story内部は `signed_static_reactions_keep_couple_and_existing_range_adapter`、element公開入口＋ `SpanLoadTransfer::StaticallyEquivalent` は `signed_static_transfer_preserves_independent_reaction_fixtures_and_adapter` で上表の反力対を確認する。GUI CMQの投影済荷重・反力集約と単純梁M両端閉合は `signed_cmq_projected_loads_close_both_simple_beam_ends` で確認する。#500の描画塗り分けは変更しない。

## adapter・重量採否

正常域反力比clamp除去と範囲処理の試験を分離する。床の点clamp／原分布区間／区間長≤1e−9の0／非負極小支間の半分配分／負支間点荷重の既存panic、storyの支間≤0／点clamp／分布切詰めと空区間、elementの長さ下限／点比clamp／逆区間無視／原区間積分を回帰する。正常域外の新しい数学保証ではない。物理的切断の端強度再評価・GUI編集範囲統一は未実施。

`signed_story_reactions_preserve_synced_negative_mass_diagnostic_and_direction_filter` は公開 `generate_stories_with_synced_self_weight` に反力対を接続する。下向きの符号付き分布は節点3の−1000 N相当の負質量診断で拒否、水平／上向きは現方向フィルタで除外される。層生成成功を反力数学の期待にしない。新重量policy／方向gateは導入しない。

## 正常区間と域外adapterの境界修正

候補コード `a606045ce6603f7973f424df67d99b2896c24640`／文書head `5fd863985581c991cb18e55b0bf3eb5c6ed02652` は域外入力の旧反力値を保持する条件分岐を追加したが、現行契約ではこの分岐を採用しない。既存adapter保持は受理・位置・原区間・極小分岐を指し、誤った旧数値互換の固定ではない。追加コミットで旧重心閾値・反力比clamp経路を撤去した。過去の `boundary-*.log` はその候補時点の実行履歴として保持し、最終head成功へ読み替えない。

固定距離荷重は `MemberLoad::validate_extent` の対象外で、GUIの新規分布入力はb>aだけを検査する。`AddMemberLoad`／`SetMemberLoad` は固定距離の支間超過を拒否せず、選択中ケースを解析前でも参照するCMQへ到達する。座標変更時の固定区間拒否とは別である。この入力受理規則は変えず、入力の是非・明示拒否・物理的切断と端強度再評価は[調査Issue #635](https://github.com/hrntsm/SEPIKA/issues/635)へ分離する。#633で新gateや重量policyを追加しない。
