# SRC 解析用弾性係数比 — Issue #434、2026-10

## 対象と出典

[SRC 等価性能の製品仕様](../../docs/calc_basis/03_断面性能/06_SRC_CFT_の等価断面性能.md)と[準備計算の表示](../../docs/preparation/09_部材剛性.md)を検証した。追跡は [#434](https://github.com/hrntsm/SEPIKA/issues/434)、親 [#524](https://github.com/hrntsm/SEPIKA/issues/524)。P1のこの範囲は実装・直接検証済みで、親全体の完了を意味しない。

公開資料の版・頁・確認範囲は製品仕様の出典節を正とする。2026-10-10に web 経由で発行者の公開PDFを取得しテキストを確認した。株式会社ストラクチャー Ver.5.1、§2.5.2 表2.5.2-1（本文p.40／PDF p.43）、§2.5.10 表2.5.10-1（本文p.63／PDF p.66）、§2.6.4(2)（本文pp.83–84／PDF pp.86–87）、日本建築学会2008年第8条公開改定案pp.2–4を対象にした。Issue本文に記録された公開ページ画像確認と合わせ、解析比と許容曲げ比の区別に使う。ローカルcurlからの取得は403で、原本をローカル保存・画像照合したとは扱わない。

AIJの2008年資料はRC公開改定案であり、SRC2014規準原本ではない。『鉄骨鉄筋コンクリート構造計算規準・同解説』（2014）原本およびRC規準（2018）12・13条原本は未閲覧。公開マニュアル自身の計算規約と、引用先規準の全文適合を区別する。

## 独立期待値

mm・N・N/mm²で、b=300,D=600、中心 H400×200×8×12。フィレット・鉄筋・スラブなし。矩形の面積と二次モーメントから独立に算出した。

- As = 2×200×12 + (400−24)×8 = 7808 mm²。
- Is = {200×400³−192×376³}/12 = 216148650.6666667 mm⁴。
- コンクリート外形のAc,gross=180000 mm²、Ic,gross=5400000000 mm⁴。
- ns=10: Ae=250272 mm²、Ie=7345337856 mm⁴、EcIe=150579426048000 Nmm²。
- ns=15の比較値: Ae=289312 mm²、Ie=8426081109.333333 mm⁴。安全側とは断定しない。

Aの許容差は厳密一致、Iは絶対1e−5 mm⁴、EIは絶対0.1 Nmm²。値は実装出力を期待値へコピーしたものではない。この例は軸・曲げの算術検証で、ねじり・せん断の新たな理論証明ではない。

## 直接検証の対応

| 試験 | 確認する契約 |
| --- | --- |
| `src_analysis_ratio_matches_independent_rectangular_h_section`（core） | ns10とns15のA/I/EIを独立期待値と識別、実面積180000 |
| `src_material_errors_are_distinct_from_non_src`（core） | Ecの0/負/NaN/±∞・極端有限値、νの境界/非有限値、非SRC対象外、必要性能の非有限値 |
| `src_loaded_and_edited_materials_never_use_provisional_analysis_properties`（app） | 正常→編集→OVIKA保存/実読込み→App読込み→準備計算の各入口。Ec/Fc/ν不正、Fc欠落、主材料未割当で解析構築・剛性内訳・準備が停止。編集undoで復帰。正常時は梁のA/I/EIとa_mass、準備表が一致 |
| `src_invalid_ec_and_poisson_are_analysis_errors`（solver） | 材料不正は理由付きError、precheck_modelで停止 |
| `allowable_bending_ratio_boundaries_are_separate_from_analysis_ratio`（design-jp） | Fc=27/36/48/60と直上の15/13/11/9を別試験し、解析ns10との混同を防止 |
| 既存SRC/CFT要素・準備の試験 | CFTの既存算定を保持、正常SRCの解析配線の回帰 |

- GUI実画面の手動操作・目視は未実施。GUI featureのコンパイル検証とApp実入口の自動試験を区別する。
