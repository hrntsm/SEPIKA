# フィレット・角Rの断面整合：Issue #413 の検証

作成日: 2026-10-05
更新日: 2026-10-07
状態: ✅ 合意範囲の Verification。規準設計の正の角R対応は #418 の暫定ゲート

## 対象と検証方法

本記録は、Issue #413 の合意した形状と算定元の契約に対する、再現可能な検証結果を残します。
実製品・実験との Validation や、#418 の規準設計仕様の策定完了を示すものではありません。

H のフィレットと角形 CFT の角Rについて、閉形式の A・Iy・Iz・強軸 Zp を独立した幅積分で照合しました。
幅積分では円と水平線の交点から断面幅を求め、端点の平方根特異性を避けるため正弦変換を用いて 262,144 区間を積分しています。
本体の円弧部分の面積・一次・二次モーメントの公式は、参照積分には用いていません。

ファイバーは矩形、四分円環、フィレットの四分正方形から四分円を除いた領域へ分解しています。
各セルの面積と一次モーメントから面積と図心を求め、総面積の事後スケーリングは行っていません。
曲げ剛性や非線形応力の積分は図心の点評価であるため、面積保存だけで精度を保証することはできません。

対象は次の 13 ケースです。

- 角形 CFT：400×400×10、500×300×10。角R は 0、5、10、30、短辺の半分
- H：400×200×9×12。フィレット半径は 0、13、95.5

角形 CFT の鋼管とコアは材料別に照合しています。
鋼管は角丸外形から角丸内形を除いた領域とし、内角Rは `max(角R − 板厚, 0)` です。

## 数値結果

### 閉形式の断面性能

H-400×200×9×12、フィレット半径 13 mm の結果は次のとおりです。

| 項目 | 閉形式 | 独立積分との相対差 |
|---|---:|---:|
| A [mm²] | 8,329.070841543 | 9.45×10⁻¹² |
| Iy [mm⁴] | 225,549,509.4320 | 1.24×10⁻¹¹ |
| Iz [mm⁴] | 16,031,656.18828 | 5.02×10⁻¹³ |
| Zp [mm³] | 1,276,148.063937 | 1.46×10⁻¹¹ |

角形 CFT-500×300×10、角R 30 mm の鋼管面積は 15,170.79632679 mm²、コア面積は 134,056.6370614 mm² です。
鋼管とコアの A・Iy・Iz の和が角丸外形の値に戻ることも、相対差 1×10⁻¹⁴ 未満で確認しています。
未知、負値、NaN、無限大、上限超過のフィレット半径・角Rは、検証付き API でエラーとなります。

### 共通ファイバー配置

目標寸法を最大寸法の 1/4、1/40、1/160、1/640、1/2560 として段階的に細分化しました。
全ケース・全段階で、鋼材とコアの総面積の相対誤差が 1×10⁻¹⁰ 以下となることを assert しています。

代表応力分布は、方向 0°、90°、45°、−60°と、偏心した中立軸、全圧縮、全引張です。
参照値は水平線上の材料区間と中立軸の交点を求めて応力を区間積分し、高さ方向に独立高精度積分して求めています。
ゼロ近傍の断面力は、材料別面積×限界応力から定めた代表断面力で正規化しました。

| 配置 | 材料別 Iy・Iz の最大相対差 | 代表応力分布の断面力の符号付き相対差 |
|---|---:|---:|
| 通常の細分割目安 1/40 | 0.5096411% | −4.347706%〜+4.804286% |
| 検証用細分割 1/2560 | 0.000137020% | −0.0977663%〜+0.0289907% |

1/2560 の配置では、両軸 I と代表応力分布の断面力が 0.1% の照合条件を満たしました。
通常配置には過大評価と過小評価の両方があり、安全側とは認定していません。
断面力の誤差は単調に小さくなるとは限らず、1/640 の一部には 0.1% を超える値が残りました。

このテストは `plastic_fibers_at` と公開 `plastic_point` を直接呼びます。
前回の +41.34897% は、独自検証がゼロひずみを引張としていた一方、公開 `plastic_point` はゼロ応力を返すことによる差を含んでいました。
その独自検証値を公開応答の精度として採用せず、公開関数へ置換して再測定しました。

公開 `plastic_moment_at_n` では、独立積分の軸力を指定して、両主方向と斜め方向の曲げ耐力を照合しました。
フィレット半径・角Rが 0 の場合は、変更前の板分割・矩形コア配置を別に生成して同じ公開関数で比較しています。

| 断面 | 1/40 の曲げ耐力最大相対差 | 1/2560 の最大相対差 |
|---|---:|---:|
| H-400×200×9×12、フィレット半径 0 | 3.074777%（変更前と一致） | 0.000209986% |
| 同、フィレット半径 13 | 3.061502% | 0.000176130% |
| CFT-400×400×10、角R 30 | 0.0342076% | 0.000773165% |
| CFT-500×300×10、角R 30 | 0.0337737% | 0.00152757% |

角R=0 の配置は変更前の配置を保持しました。
H の通常分割の約 3% の差は既存の分割でも再現し、今回のフィレット追加で新たに導入した差ではありません。
細分化による照合条件は満たしますが、通常設定の一般的な誤差を安全側・0.1% 以下と認定していません。

### 実要素・フェース・重量・質量

`rounded_material_intervals_match_area_and_both_inertias` は、フェース用の材料区間を独立に積分し、鋼管・コア・フィレットの A・両軸 I を照合します。
四分円の境界、内側直角モデル、上限の円形外形を含めて相対差 1×10⁻⁶ 以下です。

`rounded_material_mass_and_rotary_inertias_match_independent_geometry` と `rounded_design_weight_and_physical_mass_use_independent_areas` は、独立積分値から設計重量・物理質量・質量二次モーメントを照合します。
鋼材の設計重量 78.5 kN/m³、物理密度 7.85 t/m³、コアの 23 kN/m³ を分け、相対差 1×10⁻¹⁰ 以下を確認しました。

`rounded_beam_fiber_mass_and_default_fiber_geometry_follow_independent_properties` は、実際の Beam/Fiber コンストラクター・Gauss 配置・材料応答・Lumped/Consistent 質量を通します。
CFT の Lumped は材料別質量の和を合計面積で除した等価密度を用い、両モードの総質量が独立値に一致します。
Consistent の全 12×12 成分も、相対許容差 1×10⁻¹²、ゼロ近傍の絶対許容差 1×10⁻¹¹ で一致します。
非正方形の実経路で見つかった Fiber の φ 軸順序を質量関数の契約へ合わせ、人工的に断面軸を上書きしていた既存テストも実コンストラクター同士の照合に直しました。

要素既定分割（1/16）での実材料の弾性応答の差は、H のフィレット半径 13 で強軸 −0.0947735%、弱軸 −1.704557% です。
フィレット半径 0 では −0.0967159%、−1.702831% です。
Box-500×300×10 の角R 30 は −0.135730%、−0.195992%、角R 0 は −0.141409%、−0.214644% です。
この通常分割の測定と、検証用細分化の結果は区別しています。

### 独立受入レビュー P2：実ブレースの質量源

受入レビューで、Truss が保存 A を質量源にも用い、形状由来の共通質量算定と一致しない経路を検出しました。
`TrussElement::try_new` で `Model::element_mass_properties` の単位長さ質量を保持し、両質量モードの総質量をこの共通値から算定するよう修正しました。
保護された入力 A は軸剛性に引き続き用い、質量の修正で入力性能を上書きしていません。

再現条件は H-400×200×9×12、直接入力 A=8,184 mm²、フィレット半径 0 から 13 mm、密度 7.85×10⁻⁹ t/mm³、長さ 3,000 mm です。
旧質量源は 0.192733200000000 t、独立なフィレット面積を加えた形状 A=8,329.070841543 mm² による質量は 0.196149618318345 t です。
一時的に旧質量源の density×入力 A を復元した回帰テストが失敗することを確認し、共通算定へ戻した同じテストが成功しています。
軸剛性用 A=8,184 は維持され、EA/L=559,240 N/mm であることも独立に照合しました。

`supplied_area_stays_in_stiffness_while_rounded_brace_mass_uses_common_geometry` は H と Box、直線配置と斜め配置、両質量モードを実コンストラクターから照合します。
Box-500×300×10 の直接入力 A=15,600 を維持して角Rを 30 mm に変更すると、物理質量は独立面積による 0.357272253496020 t に一致します。
線形 factory の軸剛性係数変更と非線形 factory でも、物理質量が変わらないことを確認しました。

実カタログの H・Box では、フィレット半径・角Rの編集後も表値 A・Iy・Iz・J が完全に保持され、質量は編集後の形状領域に従います。
未知の形状算定は `try_new` の理由付きエラーとなり、未知でも表値のみで成立する共通算定は維持します。
負値・NaN・無限大・過大角Rの拒否と、形状なし直接値の質量 0.047100000000000 t の回帰も確認しました。
公開 `Analysis::prepare` では、未知ブレースを factory 構築前にエラーとして返し、未算定項目とフィレット半径の理由が失われないことを確認しました。

### 実モデルのスナップショット変更の根拠

`rounded_fixture_properties_and_weight_are_independently_integrated` は、実 ST-Bridge モデルの H・Box 22 断面を円との交点から独立積分しています。
保存 A・Iy・Iz の最大相対差は 1.712686881206×10⁻⁹ でした。
対象線材の DL は 635,795.561231 N、直角モデルの独立面積では 643,146.669200 N となり、差 −7,351.107969 N を照合しました。
小梁・床荷重を含む総地震用重量は 3,192,072.126178 N、独立直角面積の比較モデルは 3,194,861.563878 N で、差は −2,789.437700 N です。
旧・新の重量スナップショットの丸め値に一致することを確認したうえで、面積・両軸 I・質量・Zp の更新に伴う解析結果を更新しました。

壁モデルは `wall_fixture_weight_change_is_the_independent_fillet_area_increment` で照合しています。
フィレットの追加面積 (4−π)r² と、既存の基礎節点除外・端部配分から独立に求めた差 148.044793795 N が、総重量 52,313.062540 N から 52,461.107334 N への変化に一致します。
この確認前にはスナップショットを承認せず、`.snap.new` を残して差を確認しました。

## 合意した設計ゲートと公開結果

`sepika-design-jp/src/cft/mod.rs` の `cft_box_check` は、コアの許容曲げ耐力を `cft_rect_ma` で算定します。
この式は内法矩形を前提とし、コア面積だけを角丸値へ置換しても角丸領域の曲げ耐力にはなりません。
終局側の `ultimate/cft_nm.rs` にも、角形断面の矩形用無次元相互作用式があります。
ユーザー回答 Q11 A により、これらを領域積分へ置換する仕様策定は #418 に分離しました。

独立ファイバー積分の結果を、既存規準式の無条件な代替として採用していません。
矩形コアを使い続けることも、角丸コアに対して安全側とは認定していません。
内角Rが正の許容曲げ、角Rが正の終局 N–M と依存する QD1/min は、理由付き未算定を公開結果まで保持します。
軸終局は形状 A・I で継続し、Mu の未算定と区別します。
`rounded_cft_gate_distinguishes_core_steel_and_qd_methods` は角R=0、0<角R≤t、角R>t、両断面形、QD1/QD2/min を照合します。
App と MCP の専用テストでは、Mu の理由・null、Skipped の位置・理由、軸判定と全適合でないことを確認しました。

CFT の設計入口は元の形状を引き継ぎ、SRC の内蔵 H の既存直角モデルは組立 H の内部表現を用います。
ST-Bridge は未知寸法を保持し、必要な形状算定だけを未算定・エラーとして扱います。
MCP の断面照会・数量積算、GUI・CSV に未算定を 0 として公開しない専用テストも追加しました。
J と鋼材せん断面積の算定方法は変更していません。
これらの式の見直しは #416・#417 に分離されたままです。

## 実行コマンドと結果

### 階・二次部材の物理質量 source 再指摘への対応

階自重の `analysis_mass_per_length` は共通質量算定のエラーを伝播するよう変更しました。
鋼管質量を保存 A から再生成せず、共通の全質量から形状コア質量を引いて割増対象を求めます。
二次部材も `SectionMassProperties::try_from_section` に主材料・主筋・せん断補強筋・鋼管材料を渡します。
job の重力荷重生成では、二次部材の物理自重を既存 cascade で検証してから生成結果を返します。
これにより、二次部材の設計 A だけが算定可能な場合にも、App が DL を先に適用してから階質量で失敗する部分適用を防ぎます。
設計 DL の算定経路、対象要素種別、自重長、被覆、反力伝達方式は変更していません。

追加した直接検証は次のとおりです。

- `rounded_partial_supplied_mass_errors_are_not_zero_filled`：正常要素の後に未知 H を置き、A だけ Supplied の共通質量・自重・階生成がフィレットの理由で失敗。DL・階・節点への変更なし。GravityCasesOnly と A・Iy・Iz 全表値の既存経路は成功
- `rounded_h_box_supplied_area_uses_shape_mass_but_saved_design_area`：既知 H・Box とフィレット半径 0 の保存 A 保護、形状の物理質量、形状なしの直接入力回帰、不正寸法のエラー
- `rounded_cft_supplied_area_preserves_dl_and_all_story_mass_modes`：非正方形 CFT-500×300×10、角R 30、Supplied A=15600。独立式 `(15600−(4−π)(30²−20²))×7.85e−9×3000` の鋼管質量 0.357272253496 t に一致。割増 1/1.3、付加線重量 0.2 N/mm、Density/同期済み DL、LumpedOnly/CorrectedLumped の全量・補正・DL を照合
- Beam の既存 composite テスト：同じ非正方形 CFT と保存 A について、Lumped/Consistent の各並進方向の質量行列総和を鋼管＋コアの独立式に照合。Consistent は要素の MassOption であり、階の MassMethod は上記 2 種
- `rounded_secondary_supplied_area_mass_reaches_stories_and_unknown_is_error`：H・Box・CFT の保存 A を保護し、二次自重の反力総和と階の動的質量増分を照合。CFT コアは割増なし。未知 H/Box の A だけ Supplied は質量反力・階生成で失敗
- job の `rounded_partial_supplied_gravity_returns_reason_without_partial_cases`、App の `rounded_partial_supplied_story_action_does_not_apply_dl_mass_or_success`、MCP の `pending_geometry_queries_and_quantity_are_not_reported_as_zero`：正常要素後の未知 H から理由付き失敗を公開し、DL・階・節点の部分適用と成功結果公開なし。job/App は二次部材だけが未知のケースも確認。App から通常 Beam の `Analysis::prepare` もエラー

共通 core と Truss の実カタログ、未知、形状なし、Lumped/Consistent 回帰も全テストで再実行しました。
エラー伝播により露呈したテスト入力の鋼材形状＋コンクリート材料は実際の RC 形状・材料へ合わせました。

`cascade::SelfWeightBasis::MassEquiv`、壁・二次部材集計の通常版／resolved 版は二次質量へ到達し、job の層質点系は生成済み `StoryDynamicMass` を消費します。
