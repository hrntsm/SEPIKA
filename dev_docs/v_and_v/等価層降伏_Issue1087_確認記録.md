# 固定弾性初期剛性と等価層降伏の確認（#1087）

## 対象と結論の境界

対象はIssue #1087の2026-11-02合意と[ADR0098](../adr/0098-fixed-elastic-story-yield.md)。現在仕様・式・数値条件は[製品の計算根拠](../../docs/calc_basis/05_構造解析/09_質点系解析.md)を正本とする。
本記録は独立な折れ線例と、solverで静的・固有値・増分・時刻歴を解いた限定骨組のVerificationである。実建物・実験によるValidation、全構造種別・全地震波の応答精度や一律の安全側性を示すものではない。

## 独立骨格

`crates/sepika-solver/src/dynamic/lumped_mass/identification.rs`の試験で、K0=100 N/mm、α=0.75、元曲線(1,100),(3,140),(6,155),(10,175)を用いる。

| 確認対象 | 独立期待値・結果 |
| --- | --- |
| 第1折点 | 割線交点の荷重1200/11 Nを初期直線へ投影し、dc=12/11 mm |
| 面積上限6 mm、手動区間4〜10 mm | dy=173/47 mm、Kp=5 N/mm、面積732.5 N·mm |
| 面積上限3 mm、手動区間5〜10 mm | 面積290 N·mm、3 mmより後のdyを一意に識別。dy<=Dareaを誤って必須にしない |
| 面積上限0.5 mm | 初期直線上の面積条件の退化として未同定 |
| 完全弾性、同定上限未到達 | 架空の第2折点を作らず、それぞれの理由で失敗 |
| 同じ折れ線への点追加、同定上限後の耐力低下点追加 | dyと採用区間は不変。後者の点を同定に使わない |
| 長さ・荷重の単位倍率変更 | 無次元選定とdy/長さ倍率は不変 |

近似不良の固定例はd=1〜10 mmにQ=[100,116,120,174,228,255,262,284,285,312] N、競合降伏不安定の固定例はQ=[100,123,153,205,206,241,248,297,305,328] N。両者がそれぞれPoorApproximation/UnstableYieldへ到達することを確認する。単にエラー型を作る試験とは区別する。
数値条件はこの限定例と後述の骨組感度に対するSEPIKA独自の選別条件であり、文献で汎用に検証済みの値として扱わない。

## 元終了目標の補間と全層せん断

`sepika-job/src/lumped_mass/identification.rs`で、頂部変位と各層の角度閾値への先着、両条件無効時のλ=1、未到達・条件未記録を確認する。層ごとの閾値交差を調べ、全層最大角の支配層が変わる区間を単一の最大値の補間で置き換えない。

静的結果の全層せん断は、増分性能曲線と同じ物理節点力・支持反力の回収を使う。`wall_system_linear::physical_story_shear_includes_wall_brace_and_support_conditions`で、壁にブレースを加える/加えない条件と上部支持ばねの有無でQ=100000 Nを確認し、全水平自由度固定では層Q=0とする。既存増分の部材荷重・偏心・支持反力回帰にも静的Qの14000 Nの照合を追加する。柱せん断のみの集計へフォールバックせず、全層Qの記録がない成果には再静的解析を要求する。

## solver由来の骨組

入口は`sepika-job/src/lumped_mass/bending.rs`の`solved_frame_static_modes_and_plastic_response_comparison`。
平面寸法2000×4000 mm、階高3000 mm、2層四柱と各階四周梁、E=205000 N/mm²、柱/梁の指定断面諸量A=40000 mm²、Iy=Iz=1e9 mm⁴、J=5e8 mm⁴を用いる。実物断面の校正例ではなく、指定諸量の数値骨組である。層物理質量20/10 t、各階四隅へ等分した節点質量、集中質量方式、基部固定、剛床、P–Δなし。既存Beam端部集中ばねを使い、対象外の明示Fiber要素へ範囲を拡張していない。下部材fy=50 N/mm²、上部と上階梁fy=20 N/mm²の人工的な降伏条件を明示する。

### 弾性静的応答とモード

実Ai EXのQ=[58839.900000,24454.499783] N、全層間変位=[0.497314263,0.407994449] mm。
せん断型はQ/K0で、曲げせん断型は公開要素剛性の4自由度全体行列を組み立てて前進求解し、同じ全層間変位を相対1e-9以内で再現する。3DのX/Yについても同じ基準平面点の全層間変位を確認する。

周期順位だけで対応付けない。全体架構2次は有効X質量27.016638 tでX並進、1次は有効Y質量26.860151 tでY並進である。

| 対応するX並進 | 全体架構 | せん断2D | 曲げせん断2D |
| --- | --- | --- | --- |
| 低次周期 [s] | 0.086212304 | 0.115278238 | 0.115287120 |
| 下階/頂部のモード比 | 0.523296028 | 0.504366617 | 0.510212808 |
| 次のX並進周期 [s] | 0.031477642 | 0.057511492 | 0.054315750 |
| 次のX並進の下階/頂部 | -0.962752353 | -0.991342374 | -0.982075033 |

低次周期差は約34%、高次の差はさらに大きい。基準分布への静的変位一致だけで質量行列・回転自由度を縮約した固有値や高次応答を保存できるとはしない。モード形状の比較は各方向の頂部を同じ1で正規化する。

2層骨組の実増分は全層最大角1/75へ到達しても上層の割線比0.75に未到達となり、等価降伏未同定としてモデル生成を拒否する。この結果を成功例へ読み替えない。

上記から上層を除き、1層四柱＋四周梁とした別モデルを使う。静的初期せん断剛性138025.999208 N/mm、第1折点1.260347 mm、第2折点13.825747 mm・826322.471770 N、降伏後剛性9494.780288 N/mm、面積上限14.683360 mm、同定上限39.589261 mm、採用区間[13.830230,39.589261] mm、規格化RMSE0.008287666となった。

## 表示・保存

本番`lumped_fit_interval_editor`にeguiのポインタ・文字入力・Enterイベントを与え、特定の層/Xだけの手動化・数値変更・解除と、別層/Yの不変を確認する。ネイティブWindowsの手操作と区別する。
階編集の本番コマンドで、下階挿入後のID繰上げ、階レベル変更、下階削除後のID繰下げ、設定対象階削除と各Undo/Redoによる区間復元を確認する。元の階の設定が別の階へ適用されないことを保証する。
公開App保存/再読込で未同定理由・元終了目標・R・割線比・手動区間を往復し、旧成功モデル・応答が最新として復活しないことを確認した。成功時の同定メタデータと主/比較用塑性率の保存も同じ公開入口で検証する。

## 未検証範囲

実建物・実験・多数の入力地震波、各構造種別と大きな偏心・ねじり連成、高次モード優勢、壁を含む実骨組の塑性骨格精度、曲げ塑性・P–Δ・基礎ロッキングは本記録のValidation対象外。Windows実機の手操作と全DPI/画面幅の操作性も未確認。壁/ブレースの物理層Q回帰を、これらの動的Validationへ拡張しない。

### 上下階の重心が異なる3次元変換と未同定理由

下階Gy=0、上階Gy=1000 mm、両層の共通評価位置y=500 mmとする独立例で、両階θz=0.001 rad・下階Ux=0・上階Ux=-1 mmの剛体回転に対して上層変形が0になることを確認した。層せん断100 Nの節点力は上下Fx=-100/+100 N、重心回りモーメントは上下とも+50000 Nmmで、剛体回転への仕事も0になる。

上下剛性100/200 N/mm、共通位置へ各階100 Nを加力したせん断型では層間変形2/0.5 mmを再現した。曲げせん断型では各層高さ3000 mm・EI=10^12 Nmm²で、同じせん断変形と独立に積分した弾性曲げ変形の和を再現した。異なる重心をもつ曲げせん断型の時刻歴について、保存した各階重心変位・回転から共通位置へ変換した最大変形と結果の方向別最大変形が一致することを確認した。

独立骨格[(1,100),(3,140),(6,155),(10,175)]、K0=100、割線比0.75、Dfit=10について、Darea=6・手動[9.5,10]は区間不足、Darea=1.5・手動[4,10]は等面積解なしに分かれる。面積が降伏点によらない水平骨格でも、元面積との一致は非一意、不一致は解なしになる。自動探索の全候補不成立も原因別候補数を保持する。

未同定結果の公開保存・再読込後、現在の編集値を[99,100] mmへ変更しても、本番egui結果画面は保存元の層0・Y方向[12,25] mmを表示する。

3次元で選択方向Y・元Xだけ終了目標未到達と、その逆を本番生成経路で検証し、失敗の構造化方向と全層の理由が不足元方向を保持する。公開保存・再読込・本番egui描画でも加振選択と独立に対象方向が保持される。
