# 終局検定の実装・検証記録

> 注記: 高強度せん断補強筋の製品別対応は ADR 0031 で撤回済みです。以下の記述は当時の検証記録です。

本書は終局検定の実装・独立した手計算照合テストと残課題の記録である。
テストで採用式の再現を確認した範囲と、規準本文への適合性確認は区別する。
一次資料で未確認の係数・簡略化の根拠は[Issue #697](https://github.com/hrntsm/SEPIKA/issues/697)で追跡する。

## 背景

これまで RC 部材の終局せん断強度は、部材ランク自動判定・プッシュオーバーのせん断降伏
判定に用いる**荒川mean式系の略算式**（`squid_n_core::rc_capacity::rc_qsu_simple`）
しか実装されておらず、「終局強度型設計指針」の
**塑性理論式**（トラス機構＋アーチ機構）による終局せん断強度・付着割裂耐力・柱の
軸終局耐力は未実装だった。新規モジュール `squid-n-design-jp/src/ultimate/` を
追加し、部材別の終局検定余裕度を算定・表示できるようにした。

## 実装した項目

### 1. 塑性理論式による終局せん断強度 Qsu

**対象:** `squid-n-design-jp/src/ultimate/rc_shear.rs`（新規）。

| 諸元 | 式 | 備考 |
|---|---|---|
| 終局せん断強度 Qsu | `b·jt·pw·σwy·cotφ + k1·(1−k2)·b·D·ν·Fc` | 第1項＝トラス、第2項＝アーチ |
| アーチ係数 k1 | `(√((L/D)²+1) − (L/D))/2` | L=内法、D=部材せい |
| トラス寄与率 k2 | `2·pw·σwy/(ν·Fc)`（上限 1.0） | `pw·σwy ≤ ν·Fc/2` を反映 |
| 有効係数 ν | `(1.0−15·Rp)·ν0`（0<Rp≤0.05）/ `0.25·ν0`（0.05<Rp） | Rp=0 で ν=ν0 |
| ν0 | `0.7 − Fc/200` | |
| cotφ | `2.0−50·Rp`（0<Rp≤0.02）/ `1.0`（0.02<Rp） | Rp=0 で cotφ=2.0 |

- 制約 `pw·σwy ≤ ν·Fc/2` を、トラス項と k2 の双方で反映（k2≤1.0 と整合し、アーチ項が負にならない）。
- 軽量コンクリートは共通事項に従い 0.9 倍に低減（`lightweight` フラグ）。

### 2. 付着割裂による終局せん断耐力 Qbu

**対象:** `squid-n-design-jp/src/ultimate/rc_shear.rs`（新規）。

| 諸元 | 式 |
|---|---|
| 付着割裂耐力 Qbu | `jt·τbu·Σφ + k1·(1−k3)·b·D·ν·Fc` |
| k3 | `2·τbu·Σφ/(b·ν·Fc)`（上限 1.0） |
| 付着信頼強度 τbu（異径鉄筋） | `αt·((0.085·b1+0.10)·√Fc + kst)` |
| 割裂線長さ比 b1 | `min(bvi, bci, bsi)`、`bvi=√3·(2·Cmin/db1+1)`, `bci=√2·((Cs+Cb)/db1−1)`, `bsi=b/(N·db1)−1` |
| 付着強度低減係数 αt | `0.75−Fc/400`（梁の上端主筋）/ `1.0`（上記以外） |
| 横補強筋効果 kst | `140·aw/(db1·x)`（代表式） |

- kst の候補となる 2 分岐（`(54+45·Nw/N1)(bsi+1)·pw` と `140·Aw/(db·s)`）のうち、
  Nw（中子筋本数）・N1（外側鉄筋本数）がモデルに保持されないため後者を代表式として採用（簡略化）。

### 2-b. 靭性指針式による終局せん断信頼強度 Vu

**対象:** `squid-n-design-jp/src/ultimate/rc_shear_ductility.rs`（新規）。

「終局耐力条件」で「靭性保証型設計指針」を選択した場合、終局せん断強度を塑性理論式
（§1）に代えて AIJ「鉄筋コンクリート造建物の靭性保証型耐震設計指針・同解説」(1997) の
Vu で算定する（原典 P.142-162）。[`ShearMethod`] で塑性理論式と切り替える。

| 諸元 | 式 | 出典 |
|---|---|---|
| せん断信頼強度 Vu | `min(Vu1, Vu2, Vu3)` | |
| Vu1（トラス＋アーチ） | `μ·pwe·σwy·be·je + (ν·σB − 5·pwe·σwy/λ)·(b·D/2)·tanθ` | (6.4.1) |
| Vu2 | `(λ·ν·σB + pwe·σwy)/3 · be·je` | (6.4.2) |
| Vu3 | `(λ·ν·σB/2)·be·je` | (6.4.3) |
| μ（トラス角度係数） | `2 − 20·Rp`（下限 1.0、Rp≤0 で 2.0） | |
| ν | `(1 − 20·Rp)·ν0`, `ν0 = 0.7 − σB/200` | |
| λ（トラス有効係数） | `1 − s/(2·je) − bs/(4·je)`, `bs = be/(Ns+1)` | (6.4.8/6.4.9) |
| tanθ（アーチ角） | 引張軸力柱=0 / `0.9·D/(2L)`（L/D≥1.5）/ `(√(L²+D²)−L)/D`（L/D<1.5） | (6.4.10/6.4.11) |

- **独立した幾何・境界確認（tanθ の符号）:** `(√(L²−D²)−L)/D` では
  `√(L²−D²)<L` で tanθ<0 となり破綻する。境界 `L/D=1.5` で
  (6.4.10)=`0.9/(2·1.5)=0.300`、(6.4.11) を `+` で評価すると `(√(1.5²+1²)−1.5)=0.303` となる
  （テスト `test_arch_tan_theta_continuity`）。採用式は `L²+D²` とし、幾何的にも
  `tanθ=√((L/D)²+1)−(L/D)` に一致する。規準本文との照合完了とは区別する。
- (6.4.1) 第 2 項（アーチ機構）の応力 `ν·σB − 5·pwe·σwy/λ` は負にならないよう下限 0 で
  クランプする（塑性理論式で `k2≤1` によりアーチ項を 0 以上に保つのと同型）。
- **配線・簡略化:** `be`（トラス機構有効幅＝外側横補強筋の芯々間隔）・`Ns`（中子筋本数）は
  モデルに直接保持されないため、`be = 幅 − 2·(かぶり+補強筋径/2)`、`pwe = aw/(be·s)`、
  `Ns = legs/2 − 1` で近似する。引張軸力（`n_axial<0`）の柱は `tanθ=0`。設計タブ「終局検定」
  ビューの「終局せん断強度」トグルで塑性理論式と切り替え、ON 時は Qsu 列見出しを `Vu` に変更する。

### 2-c. 靭性指針式の付着考慮せん断信頼強度 Vbu

**対象:** `squid-n-design-jp/src/ultimate/rc_shear_ductility.rs`。

靭性指針式選択時、付着割裂の影響を考慮したせん断信頼強度 Vbu を Qbu（塑性理論式）に代えて
算定する（AIJ 靭性指針 6.8）。トラス機構をせん断補強筋ではなく付着力 `Tx` で置き換えた式。

| 諸元 | 式 | 出典 |
|---|---|---|
| 付着考慮せん断信頼強度 Vbu | `min(Vbu1, Vbu2)` | |
| Vbu1 | `Tx·je + (ν·σB − 2.5·Tx/(λ·be))·(b·D/2)·tanθ` | (6.8.14) |
| Vbu2 | `(λ·ν·σB/2)·be·je` | (6.8.15、Vu3 と同型) |
| 付着力 Tx | `τbu·Σφ1 + τbu2·Σφ2`（降伏ヒンジ無）/ `(1−10·Rp)·(…)`（降伏ヒンジ有） | (6.8.16a/b) |

- `τbu` は §2 の付着信頼強度（[`bond_reliable_strength_deformed`]）、`Σφ1` は 1 段目主筋の周長合計。
  モデルは 1 段配筋を仮定するため 2 段目（`τbu2`・`Σφ2`）は 0。
- 降伏ヒンジ計画の区別（6.8.16a/b）は `Rp>0`（ヒンジ回転を指定）を降伏ヒンジ計画部材とみなす。
- 靭性指針式選択時は「終局検定」ビューの Qbu 列見出しを `Vbu` に変更する。

### 3-b. 柱の曲げ終局強度 Mu（ACI 規準・平面保持）— **2026-08 に削除**

**現状:** 柱の Mu は構造規定式（at 式、軸力考慮の `rc_column_mu_simple`）に一本化している。
ACI 規準の平面保持解析（等価応力度ブロック法）による選択肢は削除した。

**削除の経緯:**

柱の Mu の算定選択肢を増やす目的で `ultimate/rc_column_aci.rs` を追加していた
（`MuMethod` による切替、GUI の「柱 Mu 算定」トグル）。しかし:

- **ACI318 の原典を入手できないまま暫定実装した**もので、`dev_docs/v_and_v/原典照合リスト.md`
  にも登録されていなかった。一方で利用者向けドキュメント（`docs/calc_basis/08`）は
  「ACI318-95 に基づき算定します」と 1 次資料に基づく旨を断言していた。
  本ディレクトリの方針（計算根拠は 1 次資料で示す）に反する状態だった。
- 既定 OFF の選択肢だったため検証が後回しになり、実際に不具合を抱えていた
  （`column_axis_shear` が `opts.mu_method` を参照せず、`MuMethod::Aci` を選ぶと
  2 軸せん断の強軸だけ ACI・弱軸は at 式という非対称が生じていた）。

**再実装の条件:** ACI318 の原典を入手して照合できること。加えて、高強度コンクリート
（Fc > 60 程度）など at 式の適用範囲外の物件を扱う必要が生じたとき。
再実装する場合は、`column_mu`（強軸）と `column_axis_shear`（弱軸）の**双方**へ
算定方法を伝播させること（上記の不具合の再発防止）。

### 3-c. 柱の 2 軸せん断余裕度（採用応力）

**対象:** `squid-n-design-jp/src/ultimate/mod.rs`（`biaxial_margin`・`column_axis_shear`）。

RC 柱のせん断を指定により 2 軸せん断として検定する。

```text
余裕度 = 1 / ((Qmx/Qux)^αx + (Qmy/Quy)^αy)^(1/α)   （RC は αx=αy=α=2.0）
```

- 強軸（main_x）・弱軸（main_y、b↔D 入替）それぞれで塑性理論式 Qsu と両端ヒンジ Qmu を
  算定し、需要/耐力比 `Qmu/Qsu` を相互作用式で合成する。相互作用が単位（rx²+ry²=1）に
  達すると余裕度=1.0 になることをテストで確認。
- `UltimateShearOptions.biaxial_shear=true` で有効化し、判定（ok）は 2 軸余裕度で行う。

**配線:** 設計タブ「終局検定」ビューの「柱を2軸せん断で検定」チェックで切替。ON 時は
Qsu/Qmu 列に 2 軸合成余裕度を表示する（弱軸のせん断補強筋本数は強軸と同一と仮定）。

### 3-d. 柱の 2 軸曲げ余裕度（採用応力）

**対象:** `squid-n-design-jp/src/ultimate/mod.rs`（`biaxial_margin`・`column_mu`・`check_member`）。

RC 柱の曲げを指定により 2 軸曲げとして検定する。

```text
余裕度 = 1 / ((Mmx/Mux)^αx + (Mmy/Muy)^αy)^(1/α)   （RC は αx=αy=α=2.0）
```

- 強軸（`mz`）・弱軸（`my`、b↔D 入替）それぞれで柱の曲げ終局強度 Mu を `column_mu`
  （at 式／ACI 平面保持の切替は `MuMethod` を踏襲）で算定し、需要曲げ Mmx/Mmy との
  比 rx=Mmx/Mux, ry=Mmy/Muy を相互作用式で合成する。rx²+ry²=1 で余裕度=1.0 になることを
  `test_ultimate_check_biaxial_bending` で確認。
- 需要曲げ Mmx/Mmy は部材内力の `MemberDemand{mz, my}`（最終静的解析の応答値、`mz` を
  強軸まわり・`my` を弱軸まわりとして採用）を用いる。
- `UltimateShearOptions.biaxial_bending=true` で有効化し、ON 時は判定（ok）に曲げ余裕度
  ≥1.0 を加える。`UltimateCheck.biaxial_bending_margin` に合成余裕度を格納する。

**配線:** 設計タブ「終局検定」ビューの「柱を2軸曲げで検定」チェックで切替。需要曲げは
最後に実行した静的解析（線形静的・組合せ）の部材応答モーメントを用いる（プッシュオーバーは
部材別内力を保持しないため）。

### 4. 終局検定ドライバと余裕度

**対象:** `squid-n-design-jp/src/ultimate/mod.rs`（新規、`collect_rc_ultimate_checks`）。

モデルの RC 矩形部材（`RcRect`）を走査し、部材ごとに:

- 曲げ終局強度 Mu（既存の `rc_capacity`：梁 `rc_mu_simple`、柱は軸力考慮の `rc_column_mu_simple`）
- 両端ヒンジ時せん断力 `Qmu = 上限強度倍率·2·Mu/内法`
- 終局せん断強度 Qsu（塑性理論式）・付着割裂耐力 Qbu
- せん断余裕度 `Qsu/Qmu`・付着余裕度 `Qbu/Qmu`（≥1.0 で OK）
- 柱の軸終局耐力 Nuc/Nut

を算定する。設計軸力は長期（G+P 相当）静的解析の軸力（圧縮正）を用いる。

**配線:** アプリ設計タブに「終局検定」サブビュー（`squid-n-app/src/ultimate_view.rs`）を追加。
`App::compute_ultimate_checks` が部材内力（軸力）を収集して本ドライバを呼び、部材別の
Mu/Qmu/Qsu/Qsu·Qmu/Qbu/Qbu·Qmu/判定 を一覧表示する。算定条件（Rp・上限強度倍率・
軽量コンクリート・付着検定の有無）を UI から変更できる。

### 5. RC 柱梁接合部の終局耐力 Vju/Qdu

**対象:** `squid-n-design-jp/src/ultimate/joint.rs`（新規）。

| 諸元 | 式 |
|---|---|
| 終局せん断耐力 Vju | `κ·φ·Fj·bj·Dj` |
| 設計用接合部せん断力 Qdu | `α·(T + T′ − Qcu)`（α=1.0） |
| 接合部せん断終局強度 Fj | `0.8·Fc^0.7`（靭性指針） |
| 形状係数 κ | 十字形=1.0 / ト形・T形=0.7 / L形=0.4 |
| 補正係数 φ | 両側直交梁付き=1.0 / 上記外=0.85 |
| 余裕率 | `Vju/Qdu`（≥1.0 で OK） |

**配線:** `joint_wiring::collect_joint_checks(_with_long)` が RC 十字/ト/T/L 形接合部で
Vju/Qdu を算定し、「接合部終局(RC)」ラベルの検定結果（`ratio=Qdu/Vju`）として追加する。
これによりアプリ設計タブ「接合部・耐震壁の検定」表と MCP の DesignCheck ジョブに自動的に
反映される。有効幅 bj は許容応力度検定と同じ算定、T・T′ は梁 main_x の上下対称配筋を仮定した
降伏引張力（スラブ筋は未加算＝Qdu を安全側に過小評価しうる）、Qcu は上下柱せん断力の平均、
φ は節点に取り付く水平梁が 4 本以上のとき両側直交梁付きとみなす簡略判定とする。

### 6. CFT 柱の軸終局耐力（CFT 指針）

**対象:** `squid-n-design-jp/src/ultimate/cft.rs`（新規）。

「コンクリート充填鋼管構造設計指針（CFT 指針）」に基づく軸圧縮終局耐力 Ncu・軸引張終局耐力 Ntu。

| 諸元 | 式 |
|---|---|
| 柱分類 | `lk≤4D`=短柱 / `4D<lk≤12D`=中柱 / `lk>12D`=長柱 |
| 短柱 Ncu1 | `cNc + (1+ξ)·sNc`（ξ=0.27円形/0角型、cNc=cA·Fc、sNc=sA·Fy） |
| 長柱 Ncu3 | `cNcr + sNcr` |
| コンクリート座屈応力 cσcr | `{ 2/(1+√(cλ1⁴+1))·Fc (cλ1≤1.0); 2(√2−1)exp(Cc(1−cλ1))·Fc (cλ1≥1.0) }`（cλ1=1 で連続） |
| 〃 補助 | `Cc=0.568+0.00612Fc`、`εu=0.93·Fc^(1/4)·10⁻³`、`cλ1=cλ/π·√εu` |
| 鋼管座屈 sNcr | `{ sNy (sλ1<0.3); (1−0.545(sλ1−0.3))sNy (0.3≤sλ1<1.3); sNE/1.3 (sλ1≥1.3) }` |
| 中柱 Ncu2 | `Ncu1 − 0.125·(Ncu1−Ncu3\|lk/D=12)·(lk/D−4)` |
| 引張 Ntu | `sA·Fy`（β2 は原典照合中のため 1.0） |

- cσcr の 2 分岐は `cλ1=1.0` で連続（いずれも `2/(1+√2)·Fc`）することをテストで確認。
- sNcr の分岐条件は公開資料では `cλ1` と記載されるが、城戸ほか2017の§2.2、式(12)–(16)の実画像で鋼管細長比 `sλ1`、降伏軸力 `sNy`、オイラー荷重 `sNE` を確認した（2026-10-15）。現行規準本文の照合とは区別する。

### 6-b. CFT 短柱の N-M 相互作用（曲げを伴う終局耐力）

**対象:** `squid-n-design-jp/src/ultimate/cft_nm.rs`（新規）。

軸方向力と曲げを同時に受ける **短柱** の終局曲げ耐力 Mu(N)。

| 断面 | 諸元 |
|---|---|
| 円形 | `cNu=r1²(θ−sinθcosθ)cσcB`, `cMu=(2/3)r1³sin³θ·cσcB`, `sNu=2r2t(β1θ−β2(θ−π))Fy`, `sMu=2r2²t(β1−β2)sinθ·Fy` |
| 〃 補助 | `cσcB=Fc+0.78·2t/(D−2t)·Fy`, `r1=cD/2`, `r2=(D−t)/2`, `θ=cos⁻¹(1−2xn/cD)`, β1=0.89, β2=−1.08 |
| 角形 | `cNu=xn·cB·Fc`, `cMu=(1/2)xn·cB(cD−xn)Fc`, `sNu=2t(2xn−cD)Fy`, `sMu=B·t(D−t)Fy+2t·xn(cD−xn)Fy` |

- `Nu(p)=N`（p は円形 θ／角形 xn）を二分法で解き Mu=cMu+sMu を算定。中立軸がコンクリート
  断面外（N が曲線範囲外）の場合は端点と (Ncu1, 0)・(−Ntu, 0) を直線補間する。N=Ncu1 で
  Mu→0、N=−Ntu で Mu→0、中央付近で最大となる山型をテストで確認。
- **角形 sMu の第 2 項**は、ウェブ 2 枚の全塑性モーメント
  `2t·xn·(cD−xn)·Fy`（中立軸まわりのモーメント積分と一致）として `Fy` を採用した。
  第 1 項 `B·t·(D−t)·Fy` はフランジの全塑性モーメント。
  公開計算資料の末尾 `Fc` との相違は積分から判断したもので、規準本文の誤植とは断定しない。
- 中柱・長柱の N-M 相互作用は 6-c を参照。

### 7. プッシュオーバー応答からの部材別 Rp・設計用せん断力の直接反映

**対象:** `squid-n-solver/src/nonlinear/pushover/mod.rs`（`PushoverMemberResponse`）、
`squid-n-design-jp/src/ultimate/mod.rs`（`MemberDemand::from_pushover`・`check_member`）、
`squid-n-app`（`ultimate_demand_from_pushover`・UI トグル）。

従来は Rp を UI 一律指定、Qmu を両端ヒンジ略算（`2·Mu/内法`）、需要曲げ・軸力を静的解析応答で
代替していた（プッシュオーバー結果が部材別内力を保持しなかったため）。本項でプッシュオーバー
最終確定ステップの**部材別応答**を保存し、終局検定へ直接反映できるようにした。

| 反映量 | 算定 |
|---|---|
| 設計用せん断 Qmu（強軸） | プッシュオーバー終局時の強軸せん断 Vy（`Qmu=上限強度倍率·|Vy|`。従来の `2·Mu/内法` を置換） |
| 設計用せん断 Qmuy（弱軸） | 終局時の弱軸せん断 Vz（`Qmuy=上限強度倍率·|Vz|`。2 軸せん断の弱軸需要、従来の `2·Muy/内法` を置換） |
| 需要曲げ Mmx/Mmy | 終局時の材端曲げ（局所 z まわり Mz＝強軸・局所 y まわり My＝弱軸、両端最大絶対値） |
| 軸力 N | 終局時の部材軸力（圧縮正、[`axial_compression`] と同規約） |
| 部材別 Rp | 終局時の部材変形角（弦回転角＝層間変形角相当。ν・cotφ・μ・tanθ の一律 Rp を置換） |

- `PushoverResult.member_response` に最終ステップの部材端内力（`internal_force` のグローバル
  成分）を局所座標系（`LocalFrame`）へ射影して保存する（強軸=局所 z、弱軸=局所 y）。
- `MemberDemand` に `shear`・`shear_weak`・`rp`（いずれも `Option<f64>`）を追加。`Some` のとき
  強軸 Qmu・弱軸 Qmuy・Rp を応答値で置き換え、`None`（既定）は従来経路（両端ヒンジ略算・
  UI 一律 Rp）を維持する。弱軸 Qmuy は 2 軸せん断余裕度の弱軸需要にのみ用いる。
- **簡略化（doc 兼申し送り）:** 部材別 Rp は弦回転角（弾性成分を含む）を塑性回転角の近似
  として用いる（終局時は塑性成分が支配的。弦回転角は Rp を過大評価するため安全側）。強軸/
  弱軸せん断は同一プッシュオーバー（単一載荷方向）の部材別応答であり、これは 1 つの荷重
  ケースの採用応力に相当する（両方向プッシュオーバーの包絡は別途の設計課題）。反映点は
  最終確定ステップ（最大変位側）で、崩壊機構形成後の最も変形が進んだ状態にあたる。
- **配線:** 設計タブ「終局検定」ビューの「設計用応力・Rp をプッシュオーバー応答から反映」
  チェックで切替。プッシュオーバー未実行時は静的応答＋UI 一律 Rp へ自動フォールバックし、
  反映状態をラベル表示する。
