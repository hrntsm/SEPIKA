# 材料強度・基準強度の採用値と実装記録（2026-07）

- **対象**: 材料定数（E・G・ν・単位体積重量）、鋼材の基準強度 F（板厚区分・大臣認定品）、
  鋼材の許容応力度（ft/fs/fc/fb）、コンクリートの許容応力度、鉄筋の基準強度・許容応力度
- **確認範囲**: 採用値・式と実装位置の記録。下表全体について規準原本との一致を確認した記録ではない。

## SM520の現行契約（2026-10-12）

[Issue629の告示優先・非外挿の検証](SM520告示基準強度と範囲外拒否_Issue629_2026-10.md)を現在のSM520照合結果とする。以下の#337の2区分記録は当時の承認済み契約を実装した履歴で、当時の契約違反を示すものではない。現在は355/335/325、有効厚100 mm以下、範囲外は理由付き未算定へ是正している。

## 記録範囲

材料定数、鋼材の基準強度・許容応力度、コンクリート、鉄筋を対象とする。
対応する法令の確認対象はH12建告第2464号・第2466号、H13国交告第1024号、令90・91・96〜98条であり、列挙は原本照合の完了を意味しない。
幅厚比種別・溶接継目・高力ボルトは対象外
（幅厚比は `secondary/width_thickness` に実装済みだが別途の照合とする）。

## 標準材料物性の独立回帰値（Issue1059、2026-10）

`sepika_core::standard_material::tests` に、I/Oのprivateな標準材料aliasにあった固有試験を移した。鉄筋SD345/SR235のfy=345/235 N/mm²と密度7.85e-9 ton/mm³、数字を含む未知名`UNKNOWN999`の未解決を保持する。空名の未解決は既存 `material_grade::tests::unsupported_steel_names_do_not_restore_stock_properties_or_f_values` の表に残し、同一入力・同一公開関数の重複検証を除いた。鋼SN490等の強度・密度は既存 `material_grade::tests::supported_steel_names_restore_stock_properties_and_f_values` の独立全名称表で検証する。

コンクリート試験 `concrete_standard_properties_follow_fc_dependent_unit_weight` は、旧試験のFc36/40/50/60とFc24の強度確認を一つの表に集約する。Ecと密度の期待値を本番helperの再呼出から独立した十進固定値へ変更した。Fc別の気乾重量23/23.5/24 kN/m³から、上記Ec式とRC重量を重力加速度9806.65 mm/s²で除す換算を独立に評価した回帰値であり、規準原本や実験とのValidationを追加したものではない。

| Fc [N/mm²] | Ec [N/mm²] | 密度 [ton/mm³] |
|---|---|---|
| 24 | 22668.94590387348 | 2.447318911147028e-9 |
| 36 | 25949.46523983498 | 2.447318911147028e-9 |
| 40 | 28058.27463593021 | 2.498304721795924e-9 |
| 50 | 31524.70696751446 | 2.54929053244482e-9 |
| 60 | 33500 | 2.54929053244482e-9 |

旧試験は本番と同じhelperの再計算値への完全一致だったため、helper自身の誤変更を見逃し得た。新試験では `powf` 等の環境別最終桁の丸め差を許容して、Ec・密度のみ相対1e-14（絶対epsilon=0）で独立値と比較する。表内最大値に対する許容絶対差の上限はEcで約3.35e-10 N/mm²、密度で約2.55e-23 ton/mm³。Fc/fy・鋼/鉄筋の密度は完全一致を維持する。この変更は試験の独立参照との比較方法であり、製品の数式・材料標準値・計算公差は変更しない。ローカル実行結果と独立レビューの状態は当該PRの検証欄へ記録する。

## 実装上の相違と対応の履歴

| # | 相違 | 対応 |
|---|------|------|
| 1 | TMCP 鋼材（325/355/385/440）・低降伏点鋼（LY100=80、LY225=205）が未実装 | `material_grade` に追加（TMCP は板厚 40mm 超でも F 低減なし） |
| 2 | ST-Bridge 取込（`material_std.rs`）で接尾辞なし `SN490` が F=355（520N 級扱い）に誤分類。検定側（F=325）と不整合 | 対応表を `squid_n_core::material_grade` に一本化して解消（F=325） |
| 3 | 名称→F 値の対応表が 3 箇所（design-jp／io／app）に独立実装され不整合の温床 | `squid_n_core::material_grade` に一本化。3 箇所とも同表を参照 |
| 4 | 鋼材検定で名称から F を解決できない材料が無警告で F=235 にフォールバックし、直接入力材料の Fy が反映されない | 名称で解決できない場合は `Material.fy` を基準強度に用いるフォールバックを追加（それもなければ従来どおり 235） |

## 既知の相違・残課題（未対応）

- **G の慣用値との差**: G=79000 N/mm² の丸め値に対し、実装は G=E/(2(1+ν))=78846 N/mm² を
  都度算出する（相対差0.2%）。これはE・νからの算術比較であり、規準原本照合ではない。
- **材料強度の割増**（追記: 実装済み）: 材料強度は基準強度の 1.1 倍以下
  （590N 級の SA440・TMCP440 等は 1.05 倍以下）とする採用方式を、
  プッシュオーバー（保有水平耐力計算）の部材耐力算定に実装した。
  鋼材は 1.1 倍（590N 級 1.05 倍）、RC 主筋は 1.1 倍（fy 未設定の既定値 345 にも適用）、
  せん断補強筋は割増対象外。材料ごとの割増係数の直接入力
  （`Material::strength_factor`。直接入力材料向け）が自動判定より優先される。
  実装は部材組み立ての強度基準区分
  （`squid_n_element::factory::StrengthBasis::MaterialStrength`）と
  プッシュオーバー専用のヒンジ・せん断降伏閾値への係数適用
  （`material_grade::{material_strength_factor_steel, material_strength_factor_rebar}`）による。
  当初のモデル複製方式（fy を割増した複製モデル）は、RC 主筋の fy 未設定既定値
  （345）に係数を掛けられない・fy の Some/None がせん断降伏の分岐に使われている、
  という理由で廃止し、組み立て時の係数配線方式へ変更した。
  時刻歴応答解析・許容応力度計算には適用しない。
  当初の指示は「SA440以外は1.1倍」だったが、採用実装ではTMCP440も590N級として1.05倍とした。
  HBL®440/G440 と本実装の TMCP440 の対応を含め、この適用区分の規準原本・認定条件の照合は別途必要である。
- `concrete_allowable_bond` は異形鉄筋向けの公開 API とし、丸鋼を含む方式内部の付着許容応力度は `concrete_allowable_bond_for_rebar` で算定する。
- **板厚100mm超**へ最終区分値を流用していた履歴があり、非保守的になり得る。SM520はIssue629で範囲外を拒否する現在契約へ是正済み。他の材種の適用上限・認定条件は別途確認を要する。
- 溶接継目（令98条）・高力ボルト（令96条・H12 建告第2466号）の許容応力度は本照合の対象外。
- JBCR385・BSH325・P-325 等の円形鋼管系大臣認定品、SM520 の490N級 P-SM520 板厚特例にはグレード表の未収載がある。製品ごとの認定条件を確認せず、一般材種へ外挿しない（追加時の実装位置は `material_grade`）。
