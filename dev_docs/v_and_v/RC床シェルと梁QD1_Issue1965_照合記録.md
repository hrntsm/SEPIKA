# RC床シェルと単一RC大梁の地震時せん断需要（#1965）

[Issue #1965](https://github.com/hrntsm/SEPIKA/issues/1965) · [梁のせん断検定の計算根拠](../../docs/calc_basis/06_一次設計/02_02_RC梁のせん断検定.md#床板の上端筋を考慮する場合)

床板割当なしで同一RC床シェルの境界辺を大梁と共有しても、梁自身のQD1は床なしと同じ梁本体の値になり、床板筋の寄与が未確認という警告は出なかった。通常検定と時刻歴簡易検定の両方で観測した。梁本体だけの数値は、有効な床板筋が実際には存在すると需要を過小評価し得る。床シェルの接続から分かる範囲と、既決の警告付き算定を適用する場合の境界を以下に記録する。本調査で計算・製品仕様は変更していない。

## 原典で確認できる範囲

日本建築学会『鉄筋コンクリート構造計算規準・同解説』第10版（2024年）第15条2項(3) ii) と解説pp.174–175を照合した。公表正誤表に当該頁の訂正はない。 [公刊書誌](https://ndlsearch.ndl.go.jp/books/R100000002-I033900480) · [学会正誤表](https://news-sv.aij.or.jp/kouzou/s48/2024/seigo2024.pdf)

- 解説p.174の大地震時の梁のせん断需要は、せん断力が最大となる両端降伏曲げの絶対値の和を内法で除し、単純梁として求めた長期荷重時せん断力を加えた値と、水平荷重時せん断力を1.5倍以上として長期荷重時せん断力を加えた値のうち、小さい方を採る。梁端の降伏曲げには、引張鉄筋断面積・降伏点・有効せいを使う略算式(解15.7)がある。
- 解説p.175冒頭は、厳密に求めるなら鉄筋の実際の降伏点、必要量を超えて入れた主筋、スラブ筋の効果を考慮する必要を示す。節点共有から一体打ち・有効筋を判定する方法や、情報のない床シェルを一律に算入・除外・未算定にする条件は示さない。確認済みの床板実配筋に対する別条文の適用照合は [#1882の検証](RC梁QD1の床板筋_Issue1882_検証.md) を参照。

## 独立期待値と実入口

材軸長・内法はともに4000 mm。直接支持のため両端のフェース距離は0 mm。梁は350 × 600 mm、上端2-D19・下端4-D19、SD345、有効せいはどちらも550 mm。式(解15.7)にD19の公称断面積286.5 mm²を代入すると、上端引張時は97.854075 kN·m、下端引張時は195.708150 kN·m。梁端ごとに上・下の引張面が反対となるので、梁主筋だけでの両端曲げの和293.562225 kN·mを内法4 mで除した73.39055625 kNが、Q0 = 0でのQD1になる。単一要素で両端剛接、直接支持により局所強軸回転と局所Qy方向の反力を受ける。床シェルに支持の成立を仮定していない。

独立のQD2は、両端の鉛直変位と強軸回転を拘束した対称梁の鉛直等分布荷重から求める。材長4000 mmに30 N/mmを与えたとき、釣合いと対称性により鉛直反力は60.0 kNずつ。したがって材端に一致する両フェースのせん断力の絶対値は60.0 kN。重力参照のQL = 0、割増係数1.5ならQD2は90.0 kN。したがって両フェースではQD1の方が小さく、minはQD1で決まる。中央では等分布荷重によるせん断力が0なので、この支配関係を中央に一般化しない。鉛直等分布荷重は検定に渡すQyを独立に定めるため、対照用の地震ケースに与えたもので、水平地震力のモデル化を意味しない。

### 観測値

両フェースにおけるQD［kN］。QD1の詳細表示はN単位で小数第1位に丸められる。両入口の3条件・3方式・2材端の計36件で、詳細のQD表示は丸めを含め独立期待値と一致し、検定比に表示QAを乗じた値との差は0.1 N未満。どの行もせん断を算定でき、未算定理由・床板筋未確認警告はなかった。

| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 床シェルなし | 73.3906 | 73.3906 | 90.0000 | 73.3906 | 73.3906 | 90.0000 |
| i端だけ節点を共有 | 73.3906 | 73.3906 | 90.0000 | 73.3906 | 73.3906 | 90.0000 |
| 同一シェルの境界辺と両端を共有 | 73.3906 | 73.3906 | 90.0000 | 73.3906 | 73.3906 | 90.0000 |

QD1を使う両経路では、内法・支持条件と重力参照を満たす一方、床板割当・張出し床板がないため、シェルの有無にかかわらず床板筋の寄与が両端0と扱われた。寄与を確認できないときの警告はこの0と区別されるため、今回のシェルだけの入力は警告につながらない。QD2単独は床板筋の算定や梁の両端降伏、Q0に依存せず、同じ位置の解析Qyと重力参照から決まる。一般にシェルの追加で解析応力が変わる場合、QD2の数値まで不変という意味ではない。 [通常検定](../../crates/sepika-design-jp/src/member_design_check.rs) · [時刻歴簡易検定](../../crates/sepika-app/src/viewer/th_detail.rs) · [床板筋の算入判定](../../crates/sepika-design-jp/src/rc/beam_slab_qd1.rs)

### 一時プローブの再現手順

基点は `661da235a`。以下は [時刻歴簡易検定試験モジュール](../../crates/sepika-app/src/viewer/signed_q0_acceptance_tests.rs) に一時テスト `issue_1965_shell_only_beam_shear_probe` を追加したときの手順。床シェルが認識されない観測結果は恒久テストに固定しない。

1. `fixture::model()`（[荷重・組合せの入力モデル](../../crates/sepika-design-jp/tests/fixtures/signed_beam_gravity_model.rs)）を起点とし、j端の全体X座標を4000 mmとする。梁の断面0は [梁QD1の入力モデル](../../crates/sepika-design-jp/tests/fixtures/rc_beam_qd1_model.rs) の `model().sections[0]` に置き換える。両フェース距離は0 mm（解析準備後も直接支持の材端）。局所軸参照、材料と支持の設定は起点のまま。i端は全固定、j端はUz・Rx・Ry・Rzを固定する。梁は `ElemId(0)`、両端に偏心・解放はない。
2. シェルありの2条件では `SectionShape::RcSlab { thickness: 150.0 }` を梁と同じFc24で断面1に登録する。梁と同じ高さZ = 0 mmに、平面座標 `(0,0), (4000,0), (4000,2000), (0,2000)` mmの四節点 `ElementKind::Shell` を1要素だけ追加する。新規節点は全固定とする。一端共有では最初の節点だけ梁i端のID 0を使い、二番目は梁j端と同座標だがIDが異なる。幾何上は辺が重なるが、解析モデル上は一点しか共有しない。両端共有では最初の2節点に梁のID 0・1を使うので、同じ水平RCシェルの隣接する境界辺を梁と共有する。床板登録・割当、一本部材指定は全条件で置かない。
3. 固定・積載荷重ケース0・1の部材荷重を削除する。組合せ0は固定＋積載＋地震、組合せ1は固定＋積載のままとする。地震ケース2に、梁の全長0–4000 mmへ全体方向 `[0,0,-1]`、30 N/mmの等分布荷重を追加する。起点のj端節点荷重は維持する。j端の鉛直自由度を拘束しているので、この節点荷重は上の梁部材荷重の釣合いとは別に支持で受ける。有効な無荷重のQ0が `Some(0.0)` となることを `sepika_job::design_q0::rc_beam_q0_for_gravity_cases` で確かめる。
4. 各モデルを `App::load_model` で読み込み、損傷制御を無効にし、スレッド数1で `App::run_combination(0)` を3方式ごとに実行する。保存した通常検定 `current_design_results()` の梁の両フェース（`ξ = 0` と `1`）からせん断成分の `detail`、検定比、未算定理由を確認する。通常の選択組合せには準備で追加される自動自重ケースを含めない。
5. 時刻歴簡易検定では、同じ梁の線形静的な `current_static().member_forces` を `ThRecording::peak_member_forces` に渡す。時刻歴側のQ0経路は固定荷重・架構用積載ケースから算定するため、通常検定の準備直後のモデルをそのまま使うと組合せ0に入れなかった自動自重もQ0に入り、三条件とも9.8851032 kNとなった。そこで時刻歴照合の間だけ固定・積載・積雪ケースの部材荷重を除き、`rc_beam_q0_for_gravity_cases` でQ0 = 0を確認する。応答と同じ位置の重力参照を6成分0として `set_gravity_forces` に設定する。 `labels(&app, &recording, true)` で非線形・長期初期載荷を前提とした実描画を確認し、`draw_labeled_outcome_row` の `Checked` 分岐からせん断成分を一時的に取り出す。両材端の詳細表示のQDと、QAに検定比を乗じて復元した需要を通常検定と同じ独立期待値に照合する。照合後は荷重ケースを元に戻す。この試験は静的重力参照を与えた簡易検定への入力を扱う。地震動からの時刻歴応答の生成や、初期載荷と保存重力組合せを照合する入口の検証ではない。
6. `cargo test --locked -p sepika-app --features gui --lib issue_1965_shell_only_beam_shear_probe -- --nocapture` で対象1件を実行する。調査後は一時テストと出力行を除去する。

`cargo test --locked -p sepika-design-jp --test rc_beam_qd1 --test rc_column_mechanism` では既存の梁23件・柱46件が成功した。既存試験だけで表の床シェル対照を再現できるわけではない。

## 採用境界と残る課題

- **取付きの候補と配筋の確認は別。** 両端が同じRC床シェルの隣接する境界辺を共有するモデルでは、解析モデル上でその境界辺に対応する節点接続を確認でき、寄与未確認を検討すべき候補になる。一端だけの共有からは連続する境界辺の結合までは確認できない。ただし、床筋の寄与が0である証明にもならない。両端共有でも、梁床一体打ち、梁方向筋が引張側にあること、位置・断面積・降伏点、定着・連続性を節点IDから確認できない。交差や対角の共有、複数シェルに分割された辺、偏心・拘束等による間接接続へこの候補を一般化していない。
- **梁本体の計算は安全側とは限らない。** 独立の感度例として、支配する端部降伏モーメント和に、実際に有効な床板筋から40 kN·mが加わる場合を仮定すると、同じ内法4 mのQD1は83.39055625 kNとなる。QD2を90 kNに固定するとminも同じ値となり、比較用の許容せん断力QAを80 kNに固定した場合に限れば、梁本体の値では適合、寄与を加えた値では不適合になる。これは需要と合否の変化を示す独立算術であり、表の試験梁のQAやシェルの実寄与を求めた値ではない。QD2が梁本体のQD1以下なら、QD2を固定した比較でminは増えない。
- **今回の未確認だけを理由に一律に未算定へは変えない。** [ADR 0162](../adr/0162-rc-beam-qd1-slab-reinforcement-source.md) と [PR #1979](https://github.com/hrntsm/SEPIKA/pull/1979) は、寄与を確認できる床板筋は算入し、確認できなければ梁本体で断面検定を行い、過小評価の可能性を明示する。この決定に照らすと、床シェル側で未確認を認識しないことは見直しが必要だが、認識しただけで筋の寄与を自動算入したり、理由付き未算定に切り替えたりする根拠にはならない。既存の曲げ伝達・内法・重力参照その他の必須条件が欠ける場合に理由付き未算定となること、QD2単独が独立していることとは別の問題である。認識と警告の補完は [#2025](https://github.com/hrntsm/SEPIKA/issues/2025) で扱う。
- **検証範囲。** 単一・ハンチなしRC矩形梁の安全確保用の強軸せん断検定を対象とした。柱自身の機構候補 [#1936](https://github.com/hrntsm/SEPIKA/issues/1936)、分割梁の許容曲げ・終局せん断 [#1942](https://github.com/hrntsm/SEPIKA/issues/1942)、ハンチ [#1883](https://github.com/hrntsm/SEPIKA/issues/1883)、実配筋からの算定範囲の拡張 [#1882](https://github.com/hrntsm/SEPIKA/issues/1882) は扱わない。一本部材指定の分割梁も別の適用条件を持つ。実架構での梁床の一体性、床筋の実寄与、時刻歴求解、実験Validationは未確認。状態🔶。
