# 時刻歴簡易検定のRC梁Q0（#1646）

## 再現条件

`crates/sepika-app/src/viewer/signed_q0_acceptance_tests.rs` から、長期荷重を初期状態に含む非線形時刻歴の条件で簡易検定の描画を呼び出す。RC梁2本の例は、正常なモデルで静的組合せから内力包絡に渡す値と重力参照内力を用意し、一方の梁の断面参照方向を非有限にする。鋼柱の例は、強軸曲げを与えると NG となる柱と、断面参照方向が非有限のRC梁を含む。いずれの例でも、全体のQ0集計は局所軸に関するエラーを返す。

```bash
cargo test --locked -p sepika-app --features gui --lib signed_q0_th_detail_
```

## 修正前の結果

基点 `7fa6e691` に回帰テストのみを追加して実行し、2件失敗、1件成功。長期荷重あり・QD1で、鋼柱の `検定比 1.132 (NG)` と健全なRC梁の `検定比 0.424 (OK)` が消え、どちらの描画でも別の梁（部材ID 1）の局所軸エラーが表示された。

## 修正後の結果

上記コマンドで描画テスト3件が成功した。

| 対象 | 描画テストで確認した結果 |
| --- | --- |
| 局所軸を解決できないRC梁、QD1・min(QD1,QD2) | Q0の検定不能と部材ID・断面参照方向の理由を表示 |
| 同じRC梁、QD2 | 正常な断面参照方向で描画した検定結果と一致 |
| 健全な別のRC梁、3方式すべて | 別梁のエラーの有無で検定結果が一致 |
| 鋼柱、QD1選択時 | 別節点のRC梁の追加と、その梁のエラーの有無にかかわらず `検定比 1.132 (NG)` を表示 |

修正後の初回は鋼柱と追加RC梁が同じ節点を使い、柱の横座屈に用いる支持条件も変わった。鋼柱の回帰は節点を分け、正常なRC梁を加えた段階で柱の表示が一致することも確認した。

## 確認範囲

描画テストは選択部材の簡易検定を確認する。非線形時刻歴解析自体は実行せず、内力記録と長期初期状態の条件を描画に渡す。通常の画面操作や保存済みの時刻歴結果から、不正な局所軸があるモデルでこの描画に到達するかは未確認。
