# 弾性ティモシェンコ梁の部材荷重（#1878）

## 検証対象

[部材荷重の計算根拠](../../docs/calc_basis/04_要素剛性/03_部材荷重.md#算定式)に示す弾性梁の横荷重換算と、同じ荷重応答を使う CMQ を照合する。単位は mm、N、rad とする。線形弾性・等断面の梁についての計算検証で、非線形モデルの計算式や実験に対する適用性を検証するものではない。

## 集中荷重と節点載荷の照合

全長 4000、i 端から 1000 の位置に集中荷重 5000 を与える。E = 10000、G = 666.67、Iy = 138240000、Iz = 34560000、A = 28800、せん断断面積は両方向 24000 とする。集中荷重を持つ単一要素と、荷重点で二分し中間節点に同じ節点荷重を与えたモデルを比較する。後者は部材荷重の積分を経由しない。

- 両端固定は支持反力と支持モーメントを比較し、節点変位ゼロの CMQ の端力とも照合する。
- 単純支持は両支持点の非ゼロ回転を比較する。
- いずれも曲げ二方向で剛域なしと非対称剛域（i 端 250、j 端 400）を比較する。両端固定の許容差は参照値の絶対値と 1 の大きい方の 1e-6 倍、回転は相対差 1e-6 とする。

## 非対称の区間線形分布

同じ梁の 350〜2600 の区間に強度 2〜5 の同符号分布荷重を載せる。両端固定の独立期待値は、断面の曲げモーメントとせん断力の釣合い式を補エネルギーへ代入し、二つの不静定力について停留条件を解いて得た。Euler–Bernoulli の期待値ではせん断の補エネルギーを除き、実装側ではせん断断面積を 1e15 とする。

| 参照条件 | i 端せん断 [N] | i 端曲げ [N·mm] | j 端せん断 [N] | j 端曲げ [N·mm] |
| --- | ---: | ---: | ---: | ---: |
| ティモシェンコ | −4863.367955 | 3834372.628727 | 3011.632045 | 2999650.808773 |
| Euler–Bernoulli | −4876.890381 | 3861417.480469 | 2998.109619 | 2972605.957031 |

回帰試験は [sepika-solver の線形静的解析テスト](../../crates/sepika-solver/src/statics/linear/tests.rs)の `timoshenko_point_load_matches_split_beam_reactions_and_support_rotations` と `timoshenko_partial_trapezoid_matches_complementary_energy_and_euler_limit`。実行入口は `cargo test -p sepika-solver --lib timoshenko_`。

## ローカル検証結果

2026-11-25 の Windows で、上記 2 件を含む `sepika-core`・`sepika-element`・`sepika-solver` の全テストが通過した（既定の無視テストは除く）。既存の剛域・材端条件付き CMQ の釣合い試験と、非線形梁の荷重応答試験も通過した。解析式の変更に伴い解析成果の契約版は 112 から 113 に更新し、モデル保存のスキーマ版は変更していない。

GUI の CMQ では、符号が変わる区間内のゼロ交差が浮動小数点で端点と同じ座標に丸められた場合も、幅のある側を塗ることを確認した。2026-11-25 の Windows で `cargo test -p sepika-app --features gui --locked --lib viewer::` の 333 件が通過した。

## レビューで追加した照合

- 集中荷重は上記と同じ寸法・材料・載荷位置で、両方向のせん断断面積を 1e15 mm² として Euler–Bernoulli 極限も確認する。両端固定梁の i/j 端断面モーメントの独立期待値はそれぞれ 2812500 / 937500 N·mm。試験は `timoshenko_point_load_fixed_end_moments_match_euler_limit`。
- [実建物モデルの代表値試験](../../crates/sepika-app/tests/full_model.rs)では、同じ入力・剛性・解析契約版のまま、弾性梁の部材荷重換算に渡すせん断変形係数だけを一時的にゼロにすると、旧スナップショットが全項目で一致した。現行の方向別係数で再計算すると、固定荷重ケースの最小鉛直変位 `static.DL.min_uz` が表示精度で −0.9969 mm から −0.9973 mm に変わるため、この項目だけを更新した。差は約 −0.0004 mm で、弾性剛性の変更ではなく等価節点力の変更による。
