# SRC材端集中ばねの適用範囲（#1987）

矩形SRC梁・柱の材端集中ばねは、曲げ降伏点とひび割れ後から最大点までの復元力を一貫して定められないため、理由付き適用外とした。対象部材の識別、解析入口からの拒否、別方式を巻き込まない境界を検証する。新しい曲げ降伏点や骨格の数値Verification・実験Validationではない。 [Issue #1987](https://github.com/hrntsm/SEPIKA/issues/1987)・[ADR 0170](../adr/0170-src-concentrated-spring-flexural-backbone-hold.md)

## 原典から読み取れる候補と未確認範囲

日本建築学会『鉄骨鉄筋コンクリート構造計算規準・同解説 ―許容応力度設計と保有水平耐力―』第6版第3刷を参照した。印刷ページと先行照合の条件・独立算術は [#1950の照合記録](SRC材端集中ばねの曲げ降伏_Issue1950_照合記録.md#原典から採用できる範囲) に示す。

| 確認範囲 | 今回の採用判断 |
| --- | --- |
| 40・41条 本文pp.42–43、41条解説pp.242–251 | 曲げ卓越と終局せん断先行なしは条件であって、剛床による自動選択や一軸曲げせん断の指定はその証明ではない。作用軸力の変動を無視する根拠もない。 |
| 41条(2)と16・17条 | 短期許容曲げは条件付きの降伏点のモーメント候補。梁の無軸力例を柱へ転用しない。候補値のみではひび割れ後の剛性・降伏変形は定まらない。 |
| 41条(3)と30–32条 本文pp.34–37 | 32条の終局曲げは最大点のモーメント候補に限る。最大点の変形や限界変形、降伏点を置換する根拠にはしない。 |
| 41条解説の表41.1–41.4（pp.243–245）と式(解41.1・解41.2・解41.5)（p.244、pp.250–251） | 梁と柱では断面・軸力条件が異なる。梁の評価に床スラブ効果は含まれない（p.248）。解説には断面曲率から単曲率部材角への関係と短期許容曲げに対応する部材角の求め方があるが、弾性梁と直列のばねの相対回転は定めない。製造区分・実板厚別の材料強度、変動軸力、部材角からばね回転への接続を一体で扱う適用条件は未確認。 |

先行の小範囲の手計算は短期許容候補と終局最大点を区別する比較であり、実部材の規範降伏値ではない。先行のファイバー照合で確認した組立材の板厚別材料強度をもって、材端集中ばねの適用成立とはしない。

## 公開入口の検証条件

| 入口・入力 | 確認する契約 |
| --- | --- |
| 増分・非線形時刻歴。剛床上の矩形SRC梁の自動選択、矩形SRC梁・柱の一軸曲げせん断明示 | 正規組立（ウェブ45 mm・フランジ13 mm）、製造不明、圧延、主材料Fyの未入力と120 N/mm²の比較で、対象部材と曲げ降伏点・ひび割れ後から最大点までの復元力の適用外理由を返す。 |
| 同じ種類の解析で軸曲げ連成、非剛床の梁の自動選択、剛床上の柱の自動選択、ファイバー、マルチスプリング | 組立SN400B（ウェブ45 mm・フランジ13 mm）で載荷し、増分の断面せん断力と加振時の節点応答を得る。剛床上の明示連成で製造不明なら既存の材料診断を返す。 |
| 直接の非線形要素生成・ヒンジビュー | 同じ部材の入力診断と同じ理由を返す。直接生成はpanic、ヒンジビューは材端集中ばねの種別を保持し、骨格・N–M相関・N–M曲面なし。 |
| 線形静解析 | 一軸曲げせん断を明示した矩形SRC柱でも、横荷重に対する弾性変位と断面力を得る。 |

公開入口の回帰は [solverの統合試験](../../crates/sepika-solver/tests/src_pushover_shear.rs) と [要素生成とヒンジビューの試験](../../crates/sepika-element/src/factory/input_check/tests.rs) で再現できる。以前の解析成果を再使用しないよう解析契約版を115に更新した。検定契約版126、一次検定の計算経路、壁上下の弾性剛梁、壁側柱の診断は変更していない。

## 検証結果

新規ターゲットに作業ツリーのソースをコンパイルし、solverの統合試験 `src_pushover_shear` の16件と、要素生成とヒンジビューの適用外理由の一致を調べる単体試験1件が成功したことを確認した。増分・時刻歴の拒否、既存ファイバー系の受理、線形静解析、適用外時のビューを確認した。新規復元力の数値比較と実験Validationは実施していない。

## 対象外

SRCのせん断復元力 [#1946](https://github.com/hrntsm/SEPIKA/issues/1946)、独立した断面参考図 [#1949](https://github.com/hrntsm/SEPIKA/issues/1949) とその説明 [#1986](https://github.com/hrntsm/SEPIKA/issues/1986)、解析前の「モデル化」ビューの着色と理由表示 [#1992](https://github.com/hrntsm/SEPIKA/issues/1992) は対象外。曲げが先行する実部材の同定、循環・軸力変動を受ける部材の変形・破壊順序、実験Validationは未確認。
