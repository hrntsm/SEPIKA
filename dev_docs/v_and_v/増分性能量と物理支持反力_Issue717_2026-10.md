# 増分性能量と物理支持反力のVerification（Issue #717）

## 対象と独立期待値

対象はmain `82b6d1eb`の増分性能曲線・層切断面記録と、今回の最小修正。
保存候補は`preserve/496-before-scope-split-20261021`の`7b84feec`・`692218e4`。
候補の古い成功記録を現在mainの再現証拠には使っていない。

| ケース | 独立根拠 | 修正前 | 修正後 |
| --- | --- | --- | --- |
| 3 mの全固定Fiberに水平2 N/mm | 合力6000 N、左右反力各3000 N、中央切断面0 N | 性能曲線0 Nで失敗 | 全支持抵抗6000 N、中央切断面0 N |
| 外力16000 N、同剛性の柱と地盤支持ばね | 並列ばねの同変位・力分担各8000 N | 公開増分解析で成功 | 全支持抵抗16000 N、骨組切断面8000 Nを維持 |
| 剛床代表節点載荷と直接slave載荷 | 同一並進の力と仕事16000 N×頂部変位 | 公開増分解析のX/Yで成功 | 値と正常終了を維持 |
| 壁上梁8000 N＋側柱6000 N | 元荷重の合力14000 N | 性能曲線UDL11000 N、集中13062.5 N | 両方14000 N。切断面は上側実荷重に応じ11000 N/14000 N |

混在例の旧集中値は、側柱集中荷重位置0.75LのHermite上端等価力
6000×(3×0.75²−2×0.75³)=5062.5 Nを壁上梁8000 Nへ足した値。
上端物理反力4500 Nとも全支持反力6000 Nとも一致せず、元荷重の合力の代用にはならない。
全支持抵抗を物理反力から回復し、目的別の骨組切断面の負担は別に保持する。

## 境界検証

- 部材端点ちょうどの集中荷重と同じ節点への荷重で支持反力・性能量が一致する。
  端点から1e-7 mm離れた荷重は部材内部として保持する。正負載荷・上下端反転を確認する。
- 性能曲線の部材荷重は、下端SLを除き最上端SLを含む区間で積分する。
  下端直下・下端・中間階・最上端・最上端外、階なしで、基部と層別の集計範囲を確認する。
- 中央切断面の集中荷重はi端側極限と対応させ、1499/1500/1501 mmと上下端反転で
  上側外力の1000 Nの跳びを確認する。階帯の半開区間に置き換えない。
- 部分台形分布[500,2500] mm・1→3 N/mmは合力4000 N、1500 mmより上は2500 N。
  荷重分布とHermite形状関数の独立積分による固定端反力45800/27 N・62200/27 Nへ照合した。
- 固定masterへRigidLinkで拘束し、DofMapではactive・Reducerでは独立0となる上端について、
  初回の抽出実装は上端反力0 N（期待−3000 N）で失敗した。
  Reducerの厳密な空行だけを固定と同様に扱い、両支持各−3000 Nへ修正した。
  従属固定点への節点荷重と端点集中荷重の同一反力・控除も確認した。
- 物理支持反力は全自由度写像から回復し、仕口パネルの一般化回転を節点力に扱わない。
  既存の壁接続・通常材・非所有部材の混在回帰を維持する。

## 採否と確認限界

`7b84feec`の物理反力回復・荷重積分を抽出して現在の荷重受渡しへ接続した。
`692218e4`の新runtime照合と代表節点特例は、現在mainで元の誤拒否を再現しなかったため導入しない。
一般MPC・階跨ぎ・部分slaveの近似拡張、新しい性能指標、GUI追加は行っていない。

公開増分解析で確認したものと、確定step記録/物理回復を直接確認したものを区別する。
全固定Fiberの再現はStepRecorderの直接試験であり、独立自由度0を拒否する公開増分入口の対応追加ではない。
材料則・収束性・全組合せや実験によるValidationを保証するものではない。
独立レビュー・CI・マージの将来の成功はこの記録に含めない。
