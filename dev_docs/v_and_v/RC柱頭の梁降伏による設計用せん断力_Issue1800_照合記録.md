# RC柱頭の梁降伏による設計用せん断力（Issue #1800）

照合した規準の箇所は[RC柱のせん断検定の根拠](../../docs/calc_basis/06_一次設計/02_04_RC柱のせん断検定.md#柱頭柱脚の崩壊メカニズム)を参照。本文(15.8)式の最上階条件を、解説図15.9(b)の上階柱の有無と照合した。旧検定版99では、梁降伏を採る柱頭が終端でも梁の寄与を半減していた。

## 独立計算

RC矩形柱400×600 mm、柱内法高さ1,500 mm、Fc24、設計軸力100 kN（圧縮）、強・弱軸とも引張側の主筋は数値径19 mmの3本で、主筋・帯筋はSD345。帯筋は直径10 mm、間隔100 mm、各方向2脚。梁は柱頭にX方向・Y方向それぞれ1本を置き、せい600 mm、上下とも数値径19 mmの主筋2本、かぶり40 mmとした。梁・柱とも引張側のかぶり40 mm、横補強筋径10 mmなので、主筋重心から縁までの距離は59.5 mm。

強軸の柱端は解15.15式から \\( 0.8(3\pi 19^2/4)(345)(600) + 0.5(100000)(600)\{1-100000/(400\cdot600\cdot24)\} \\) となり、170.336243 kN·m。梁端は解15.14式から \\( 0.9(2\pi19^2/4)(345)(600-59.5) \\) となり、95.166562 kN·m。強軸の短期許容せん断力は拘束の各ケースで同じで、\\( 400(7/8)(600-59.5)[1.095+0.5(345)\{2(\pi 10^2/4)/(400\cdot100)-0.002\}] \\) から270.029514 kNとなる。

| 架構の条件 | 強軸QD1（kN） | 強軸検定比 | 弱軸検定比 |
| --- | ---: | ---: | ---: |
| 柱頭に上階柱がない | 177.001870 | 0.655490830018 | 0.647803791369 |
| 同じ柱頭節点から上階柱が続く | 145.279683 | 0.538014088466 | 0.500122540485 |
| 別節点との連結拘束があり、共有節点で上階柱を確認できない | 227.114991 | 0.841074693830 | 0.704882579202 |

弱軸は同じ手順で柱幅を600 mm、せいを400 mmとし、柱の降伏モーメントを113.557495 kN·m、許容せん断力を214.801725 kNとした。すべての比較で強軸の検定比が結果を決める。通常検定のせん断検定比は絶対差 \\(10^{-12}\\) 未満、時刻歴簡易検定は表示の小数第2位（0.66、0.54）で比較した。

## 要素と検証

| 経路 | 照合した条件 |
| --- | --- |
| [通常の公開検定](../../crates/sepika-design-jp/tests/rc_column_mechanism.rs) | 終端と連続、柱の節点順反転、階名RF・B1F、別の柱が上にあるセットバック、剛床。上階柱はBeam（鉄骨）、Fiber・MultiSpring（RC）を使い、端別XYZ偏心を付与。高い節点につながるFiber大梁は柱の連続条件と梁降伏モーメントの集計の両方から外れる。 |
| [通常の公開検定](../../crates/sepika-design-jp/tests/rc_column_mechanism.rs) | 柱頭と近傍の上階柱脚を全自由度または回転1自由度の剛体リンク、多点拘束で結び、柱頭は柱降伏となることを照合。柱脚にも梁候補を置き、両端梁候補を選んだ後に柱頭の低減を省いたときは、両端柱降伏の需要となる。剛体リンクの拘束指定なし、または剛体リンク・多点拘束の唯一の指定成分を柱頭のみ・上階柱脚のみ・両節点で支点固定した場合は、連結拘束なしと同じ最上階の検定比になる。 |
| [時刻歴簡易検定](../../crates/sepika-app/src/viewer/th_detail.rs) | 同一の内法・軸力・配筋を与えたピーク記録からの描画で、終端と上階Fiber柱ありの表示検定比を確認。 |
| [OVIKA保存経路](../../crates/sepika-app/src/app/result_contract_tests.rs) | 検定版99は読込で失効し、解析契約版が一致する部材内力を保持したまま明示的に再検定すると現行版100が付く。 |

対象は与えた断面力による有限例。時刻歴の全時刻の応答、実験Validation、規準の全適用範囲は確認していない。ヒンジ候補の比較と柱脚機構は[#1817](https://github.com/hrntsm/SEPIKA/issues/1817)、梁降伏モーメントを集計する解析要素の範囲は[#1820](https://github.com/hrntsm/SEPIKA/issues/1820)で追跡する。
