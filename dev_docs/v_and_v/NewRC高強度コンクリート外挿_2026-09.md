# NewRC 高強度コンクリート外挿の検証記録（Issue #385）

作成日: 2026-09-27

## 対象

設計基準強度 `Fc > 60 N/mm²` のコンクリートについて、現行仕様が NewRC の応力–ひずみ曲線を変更せず外挿して使用することを検証対象とする。高強度コンクリート用の別構成則は採用しない。対象経路は、単軸材料の NewRC 構成則、ファイバー材料の生成、および NewRC 式から算定する初期接線である。

## 現行仕様

現行仕様の正本は次の計算根拠である。

- [NewRC コンクリート構成則（ファイバー柱の既定）](../../docs/calc_basis/02_材料/01_一軸材料構成則.md#newrc-コンクリート構成則ファイバー柱の既定)
- [コンクリートのヤング係数 Ec](../../docs/calc_basis/03_断面性能/04_コンクリートのヤング係数_Ec.md)
- [非線形梁要素のモデル化](../../docs/calc_basis/04_要素剛性/09_非線形梁要素のモデル化.md)

`Fc ≤ 60` では既存どおり材料から解決した `Material.young` を NewRC の初期接線へ反映する。`Fc > 60` では NewRC 固有の Ec を用いて外挿する。いずれも3履歴則の構成則は維持し、`Fc > 60` の適用だけが NewRC 原典の適用範囲外への暫定的な外挿である。実験または商用ソフトとの妥当性確認を完了したことを意味しない。

## 参照解と判定条件

参照解は、計算根拠に記載した NewRC の定義式とする。次の境界・代表値をコードテストで照合する。

| 項目 | 判定条件 |
|---|---|
| 適用範囲の境界 | `Fc = 60` と `Fc > 60` で構成則の選択が変わらない |
| 初期接線 | `Fc≤60` は材料から解決した E、`Fc>60` は NewRC 式の `Ec` と一致する |
| 圧縮包絡線 | `Fc > 60` でも NewRC の係数式から有限な応答を返す |
| ファイバー生成 | 高強度 Fc のファイバーが NewRC 材料として生成される |
| 明示ヤング係数 | `Fc≤60` は `Material.young` の変更を初期接線・圧縮代表点・引張ひび割れ・Karsan–Jirsa の `Ets` に反映し、`Fc>60` は変更しない |

厳密式の数値照合は倍精度の許容差 `1e-9` を基本とし、履歴応答の代表点は実装するテストの参照値に基づいて判定する。入力値が NewRC の原典上の範囲外であること自体は、検証済みの妥当性を示すものではない。

## 実装追跡とコード検証

現行実装の追跡先は `squid-n-material::newrc::ConcreteNewRc`、`ConcreteCyclic::newrc`、およびファイバー生成経路である。次の回帰テストを実装し、実行した。

- `fc_60_and_fc_80_are_both_newrc_materials`: `Fc = 60` と `Fc = 80` の NewRC 境界・圧縮ピークを確認（成功）
- `test_all_fiber_materials_return_initial_tangent_at_zero_strain`: `Fc = 21, 60` は材料 E、`Fc = 80` は NewRC Ec と3履歴則の原点接線を確認（成功）
- `fc_at_or_below_60_uses_material_young_in_concrete_materials`: `Fc = 21, 60` の材料 E依存（原点接線、圧縮代表点、引張ひび割れ、Karsan–Jirsa の `Ets`）を確認（成功）
- `fiber_surface_uses_analysis_material_young_moduli`: 解析用材料の初期接線を表示用コンクリートファイバーと一致させることを確認（成功）
- `fc_over_60_fiber_materials_use_newrc_envelope_and_history`: Fc=80 の Retrograde、OriginOriented、KarsanJirsa について、独立に算定した包絡線・除荷応答・原点接線・再載荷応答または残留ひずみ到達点を確認（成功）
- `cargo test -p squid-n-element`: 成功

これらは NewRC の定義式と履歴則の Verification であり、Fc>60 に対する実験、実測、商用ソフト、または原典適用範囲外への外挿の妥当性確認（Validation）は未実施である。
