# 集中ばね梁の部材荷重（Issue #802）

## 対象と独立期待値

[Issue #802](https://github.com/hrntsm/SEPIKA/issues/802) の軸方向・横方向の部材荷重を対象とする。
荷重と端力の釣合い、弾性梁と材端ばねの直列柔性、バイリニア材料の独立算術を照合するVerificationであり、実験Validationではない。

公開時刻歴は `general_member_loads.rs` の `concentrated_axial_cantilever_public_time_history_records_equilibrium_and_reaction` と
`concentrated_transverse_public_time_history_records_udl_and_point_equilibrium` を使う。
地動0・質量正・dt=0.001 s・Newmark β=0.25/γ=0.5・減衰0・長期荷重あり・4時点を記録する。
軸方向はNewton許容1e-9、横方向は1e-6とし、独立値照合は1e-7×max(|期待値|,1)。
横方向はゼロ動的外力を基準とする絶対残差に、曲げモーメントの丸めが作用するため、軸方向と分ける。

| 試験 | 入力と独立期待値 |
| --- | --- |
| 軸片持ち | L=1000 mm、E=205000 N/mm²、A=80000 mm²、w=2 N/mm。u=wL²/(2EA)=0.00006097560975609757 mm、N(0),N(L/2),N(L)=2000,1000,0 N、反力−2000 N |
| 横片持ち | L=6000 mm、w=1 N/mm又は中央P=6000 N。固定端V=−6000 N、M=18e6 N·mm、自由端V/M=0。UDL中央M=4.5e6 N·mm、中央集中荷重の中央M=0 |
| 全固定端ばね | L=3000 mm、w=1 N/mm、ks=1e10 N·mm/rad。kb=2EI/L、固定端Mの絶対値=(wL²/12)/(1+kb/ks)。半剛接kcでは分母へkb/kcを加え、ピンではM=0 |
| 塑性中央集中荷重 | L=3000 mm、E=205000 N/mm²、I=1e8 mm⁴、P=1e5 N、ks=1e12、My=1e7、kh=1e10。端ばね角の絶対値=(PL/8−My+kh·My/ks)/(kb+kh)、M=PL/8−kbθ |

公開時刻歴の初期・後続記録と全評価位置の包絡を照合する。反力は記録断面力の符号反転だけで作らず、
公開結果変位を同じ元荷重とともに要素へ渡し、組立に用いる `internal_force` から固定端・自由端残差を独立照合する。
これは公開時刻歴結果に反力列が保存されることを保証する試験ではない。

## 材料・接続・復元と利用側

`frame::concentrated::tests` では、上表の固定/ピン/半剛接、塑性材料モーメント、接線の変位差分、
荷重だけの1→0.5→1→0更新、失敗後の完全復元、壊れた材料checkpointの原子的拒否、保存再開と除荷、
各端の荷重込み軸力による別々のN-M限界を照合する。正常試行からのrevertでも、確定荷重・変位に対応する材料降伏値へ戻ることを確認する。
非対称剛域200/400 mmとRC総角基準について、合力・一次モーメントと材料端モーメントの一致を確認する。
総角基準では専用の弾性剛性を使う。材料構成則そのものの一般的Validationではない。

`mixed_time_history_member_rhs_keeps_axial_displacement_and_physical_records` は通常Fiber/MSと集中ばね梁を同時に解く。
集中ばねを含めた元部材荷重を要素で受け取り、右辺での重複計上がないことと、各部材の記録・包絡を照合する。
`mixed_gravity_and_confirmed_pushover_keep_all_member_load_paths_consistent` は既存増分kernelの載荷・確定記録と
利用側の軸力を照合する。壁の耐力は元荷重なしfixtureから与え、荷重付き公開壁解析への機能拡張を意味しない。

解析計算契約を51→52とする。`persist::tests::manifest_contract_versions_and_missing_metadata_reopen_without_restamping` に
旧版51の実ファイル保存・再読込を追加し、結果を現在有効へ再刻印せず拒否する。現行版は同じ経路で利用できる。

## 変更前の知見と訂正

[Issue716の検証記録](一般部材荷重_Issue716_2026-10.md) の混在試験は、集中ばねの記録軸力1000 N一様を旧挙動として保持していた。
本Issueでは物理軸力2000→0 Nへ期待値を是正する。過去の試験件数・成功記録を、今回の正しい断面力の証拠へ読み替えない。

局所Newtonは従来、反復上限に達しても成功扱いしていた。荷重込み釣合いの失敗を原子的に拒否するため、
通常端ばねでは残差が減る線探索を加え、未収束をエラーにする。既存mathには再利用できる線探索がなかった。
旧 `test_spring_yield` の加力角0.0001 radでは、直列の梁柔性を含む弾性釣合いM≈2.6e6 N·mmがMy=1e7を下回る。
旧試験は未収束状態に依存していたため、0.001 radの試行接線を確認する試験へ是正した。

続くsolver検証では、RC総角基準の自動ねじり解放の二重適用と、増分記録の旧軸力期待値の2件が失敗した。
RC基準剛性をrawと端条件適用後に分けて接続を一度だけ適用し、増分記録の固定端軸力期待値を−1000から−2000 Nへ是正した。
最終953件はこれらの是正後である。Clippy初回は試験のcloneによるslice生成2件を指摘し、from_refへ置換後に成功した。
横荷重の専用公開試験は初回Newton許容1e-9でstep1未収束となった。前述の1e-6へ分けた後に10件成功し、独立値の照合許容は緩和していない。

範囲外の観察として、Bilinear(e=1e12,fy=1e7,hardening=0.01)へtrial(0.001)→commit→probe(0.001)を実Rustで実行すると、
応力19899999.999999996は同じで、接線は1e10から1e12へ変わる。strain=0.0001では同操作後も接線1e10となる。
降伏面での同一点接線と丸めの扱いは[調査Issue #808](https://github.com/hrntsm/SEPIKA/issues/808)で追跡し、本修正では構成則を変更しない。新規差分検証はcommit前の試行接線を対象とする。
