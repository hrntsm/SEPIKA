# 時刻歴簡易検定の横座屈修正係数

[#1667](https://github.com/hrntsm/SEPIKA/issues/1667) の調査。対象は `342380f6a`、状態🔶。
偏心ゼロで同じ強軸曲げを与えた対称H形鋼柱は、Cを空欄にすると通常検定・時刻歴簡易検定ともに適合した。Cに試験値0.8を入力すると通常検定だけが不適合となり、時刻歴簡易検定は値を採用せず適合のままだった。

## 原典と適用条件

日本建築学会『鋼構造許容応力度設計規準』2019年制定、第1版第3刷（2024年6月15日）、5.1(4)a、pp.10–11、式(5.7)～(5.16)を原典で確認した。短期倍率は5.6、p.14。 [書誌](https://ndlsearch.ndl.go.jp/books/R100000002-I030037737)

式(5.11)のCは弾性横座屈モーメントの補正係数であり、材全体ではなく横補剛区間ごとの曲げ分布に対応する。区間内で符号付きの強軸曲げモーメントが単調に変化する場合、同一区間の両端の強軸曲げモーメントを絶対値が大きい順に `M1`、`M2` とし、複曲率で正、単曲率で負とする比 `r = M2/M1` から、塑性限界細長比 `pλb = 0.6 + 0.3r`、`C = min(1.75 + 1.05r + 0.3r², 2.3)` を得る。曲げモーメントの絶対値の最大が区間内部にある場合は `pλb = 0.3`、`C = 1` とする。一定曲げは `r = −1` の極限であり、ここでも `pλb = 0.3`、`C = 1` となる。

同一補剛区間・同一荷重状態の曲げ分布を扱うため、時刻歴にこの式を適用する場合は両端と内部の曲げを同じ確定時刻で確認する必要がある。両端の極値が偶然同時でも、区間内部の分布が未確認なら単調とみなせない。原典の当該箇所は、通常検定用の任意の直接入力を別の分布や時刻に流用できるとはしていない。

## 独立計算と製品入口の観測

[#1651の偏心なしモデル](材端偏心のあるH形鋼柱の横座屈長さ_Issue1651_確認記録.md#同一入力と独立算術)と同じ、H-400×200×8×13（隅角半径0 mm、無欠損）、F = 235 N/mm²、E = 205000 N/mm²、ポアソン比0.3を使用した。基準節点と実材端は一致し、実材端の支点間隔は3000 mm。中間横補剛はなく、短期の局所 `Mz = +215 kN·m` を `ξ = 0, 0.5, 1` に与え、その他の断面力は0とした。

矩形板の断面積・断面二次モーメントと平行軸の定理から強軸 `Z = 1148243.413333 mm³`、弱軸 `Iweak = 17349290.666667 mm⁴` を得た。比較では薄肉近似 `J = 356762.666667 mm⁴`、製品採用の断面式 `Iw = Iweak × 387²/4 = 649596478464 mm⁶`、`G = E/2.6` を使用した。式(5.11)の平方根内を `a × (π² E Iw/lb² + GJ)`、`a = π² E Iweak/lb²` としてCごとの `Me` を求め、`λb = √(FZ/Me)` と式(5.8)の中間域を用いた。短期許容値は長期の1.5倍、検定比は曲げ応力度 `M/Z = 187.24252846 N/mm²` をこれで除した値とした。

| C | Me [kN·m] | λb | 現行式の短期 fb [N/mm²] | 現行式の比・適否 | Issue起票時の fb [N/mm²]・比 |
| ---: | ---: | ---: | ---: | --- | --- |
| 1.0 | 824.185821 | 0.57218747 | 192.38542 | 0.97326778・適合 | 192.33775・0.97350901 |
| 0.8 | 659.348656 | 0.63972504 | 182.82359 | 1.02417050・不適合 | 182.76667・1.02448947 |

起票時の値は弾性限界細長比を1.29とした再計算で一致する。現行値と原典の式(5.12)は `1/√0.6`。この差は [#1666](https://github.com/hrntsm/SEPIKA/issues/1666) で是正され、今回の適否には影響しない。C = 0.8 は入力の影響を切り分ける感度試験値であり、規準上の選択値ではない。

通常検定は公開入口 `run_member_design_checks`、時刻歴は同じ内力を2フレームと内力包絡に与え、部材詳細の描画入口から確認した。両経路で横座屈長さ表示は3000 mm。通常検定の許容曲げ応力度は結果詳細の小数4桁、時刻歴の検定比は画面の小数3桁を観測した。時刻歴画面には許容曲げ応力度とCの採用値は表示されない。

## 同時性を欠く包絡と後続対応

[包絡の作成処理](../../crates/sepika-solver/src/dynamic/timehistory/recording.rs)は評価位置・成分ごとの絶対最大値を符号付きで保持する。[時刻歴部材詳細](../../crates/sepika-app/src/viewer/th_detail.rs)は入力Cを除外したうえで、対称H形鋼柱の包絡行でこの端部曲げを自動算定に使う。[柱の自動算定](../../crates/sepika-design-jp/src/steel/section.rs)が参照する区間内の曲げは中央1点だけであり、同時刻の断面力を使っても単調性や中央以外の内部最大は確認できない。軸力極値行では確定ステップの断面力を使うが、その行だけで全確定時刻の強軸曲げを覆うわけではない。単一補剛区間の対称H形鋼梁の包絡行は、分布未確認の強軸曲げ・組合せを未算定とするため、柱と同じ挙動ではない。

[鋼梁の曲げ・横座屈検定](../../docs/calc_basis/06_一次設計/03_02_鋼梁の曲げ_横座屈検定.md)では、通常検定の直接値を使っても単一区間の曲げ分布の確認を省けないとしている。非単調で絶対値の最大が端部にある場合や、端部と内部の最大値が同値で大小を区別できない場合には端部比による割増しをしない。この境界の扱いは現行製品の判断であり、原典の二つの場合の記述とは区別する。[鋼柱・ブレースの軸力・曲げ検定](../../docs/calc_basis/06_一次設計/03_05_鋼柱_ブレースの軸力_曲げ検定.md)が両経路で共通とするのは横座屈長さの選定であり、Cの扱いは記載していない。柱の通常検定では [S造検定属性の入力画面](../../crates/sepika-app/src/tables/steel_attrs.rs)の案内どおり有効な直接値が自動算定より優先されるが、[時刻歴マニュアル](../../docs/result_view/10_時刻歴アニメーションの表示.md)に直接値の非適用や時刻歴の採用Cの説明はない。

反例として、同じ3000 mm区間で時刻aの端部曲げを `(+259, 0)`、時刻bを `(0, −259)` kN·m とする。各時刻の分布は直線であり、対応するせん断力の絶対値は `259/3 kN`、軸力・弱軸曲げ・ねじりは0とする。ここでは強軸曲げの許容値と比だけを比較する。各時刻は `r = 0` で `C = 1.75`、`pλb = 0.6` だが、成分別包絡は両端 `(+259, −259)`、中央 `+129.5` kN·m となる（絶対値が等しい中央では先に現れる時刻aを保持）。現行の柱経路がその両端を用いると `r = +1` から `C = 2.3`、`pλb = 0.9` となる。独立代入では真の各時刻の許容値223.83312 N/mm²・比1.00772に対し、包絡の仮想組合せは226.40581 N/mm²・比0.99627となる。これは実在しない分布で許容値を過大評価する算術反例で、上記GUI試験とは分ける。

後続の [#1953](https://github.com/hrntsm/SEPIKA/issues/1953) では、次の扱いを検証する。今回の調査では製品挙動を変えない。

- 自動算定で曲げ勾配による有利な補正を採用するには、対象区間・同時刻の曲げ分布と支点条件を確認する。強軸曲げとCが最大となる時刻は同じとは限らないため、比較対象は需要と同時刻の許容値による検定比とする。曲げ分布・補剛区間・必要な同時応答を確認できなければ適合を確定せず、不足する根拠を示す。適用条件を満たす範囲で安全側の代表値（規準式で `C = 1`、`pλb = 0.3`）による参考値を計算できても、それだけで適合とはしない。独立に確定した不適合は残す。
- 通常検定用の直接値を一律には反映しない。直接入力を許す場合、同じ補剛区間・支持条件・曲げ分布で対象時刻に適用できる値、または対象全時刻を覆う安全側の値と独立に確認できる条件を定める。Cの指定だけでは塑性限界細長比や曲げ分布の確認を省けない。
- 入力画面と時刻歴結果で直接値の適用・非適用、採用Cとその根拠（採用区間・同時刻の分布・代表値・未算定理由）を開示する。[時刻歴マニュアル](../../docs/result_view/10_時刻歴アニメーションの表示.md)と通常検定の計算根拠もそろえ、適用条件を満たさない場合に簡易検定の「OK」を通常検定の代替と誤読できないようにする。

## 再現と検証範囲

[自動試験](../../crates/sepika-app/src/viewer/steel_time_history_c_tests.rs)は既存の柱フィクスチャを使い、公開通常検定の許容値・比・適否と、時刻歴部材詳細の表示を照合する。基準節点・材端の偏心ゼロ、理想支持、対称H形鋼柱、無欠損の一定強軸曲げが確認範囲である。実動的解析での座屈現象、他断面や複数補剛区間への一般化、手動GUI確認は対象外。

```powershell
cargo test -p sepika-app --features gui --lib --locked viewer::th_detail::steel_time_history_c_tests::h_column_direct_c_changes_static_but_not_time_history_check -- --exact
```

Windows x86_64-pc-windows-msvc、Rust 1.100.0。`cargo test -p sepika-app --features gui --lib --locked --no-run` のログで本作業ツリーからの `sepika-app` のコンパイルを確認し、出力された試験バイナリに上記の完全名と `--exact` を渡して1件成功（失敗0件）。同じバイナリの `viewer::th_detail::` フィルタでは当該試験を含む49件成功（失敗0件）。
