## 利用入口と非対象

| 入口 | 判定・復旧 |
|---|---|
| OVIKA読込／保存 | 読込で対象カテゴリを除外。保存は版を認証し直さない。モデル・設定は保持 |
| 静的ケース／組合せ選択・直接検定 | 剛域反映後に実選択keyの版＋生成入力を照合。旧検定の表示選択では自動再検定しない |
| 固有値・増分・時刻歴・質点系・部分解析採用 | 旧解析カテゴリを採用前に除外し、新しく成功した計算にだけ版を付与 |
| 保有水平耐力・目的別採用run | 既存依存key・目的別生成入力の照合へ解析版を接続 |
| RC/CFT終局検定 | 既存の実需要source選択を維持して、採用する応力の版と入力を照合 |
| GUI検定比・部材／接合部／壁／小梁／床板表示、CSV | 除外した旧合否や全適合を出さず、計算契約の理由を表示。明示再検定ボタンで回復 |
| MCP DesignCheck | 毎回新解析。OVIKA保存応力の再利用入口ではない |
| MCP Parquet/FsResultStore `result_get` | #589（#483後）の別保存契約。本件の対応済みに含めない |
