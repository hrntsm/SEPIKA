# 仕口パネルの方向別接合面距離（Issue #759）

対象は[Issue #759](https://github.com/hrntsm/SEPIKA/issues/759)。2026-10-25、Windowsのローカル実行を記録する。対象実装コミットは `a765e74d`。面の定義と適用条件の正本は[計算根拠](../../docs/calc_basis/04_要素剛性/06_パネルゾーン.md#部材端の接合面とオフセット)、判断は[ADR 0073](../adr/0073-panel-connection-face-distance.md)。

## 修正前の公開入口による再現

base main `6ed74717` で `sepika_job::prepare_model_for_analysis` の後に `Analysis::prepare` を呼び、両者が成功する安定モデルで測定した。接合部0に上下の箱柱400×200×12（角R=0、せい方向X）、X方向とY方向のH梁を各1本配置し、柱の遠端と梁の遠端を固定した。柱は下側ID0を採用し、X梁はID2、Y梁はID3。

`cargo test -p sepika-job panel_759_public_preparation_uses_directional_column_faces --locked -- --nocapture` で、修正前の梁i端距離は `[200, 200] mm` だった。実接合面の独立期待値は `[200, 100] mm` で、公開解析準備が成功した後の期待値assertが失敗した。同じ恒久回帰で修正後は `[200, 100] mm` となり成功した。

最初の試行は梁の遠端を自由にしたモデルで剛性非正定値となり、距離 `[200,200]` は測定できたが解析準備成功の証拠にはしなかった。遠端を固定した対照で上記の再現を取り直した。

## 元分布荷重の公開MS反例と是正

追加した `panel_759_public_solver_preserves_original_span_loads_reactions_and_shear_work` の初回実行では、幅側へ接合する箱柱400×200とX梁（接合面100 mm）で、柱脚N=−19000 N・My=60049999.99999952 Nmmは独立値と一致した一方、公開MSYは−55825414.930555634 Nmmだった。元荷重の独立MSYは−60050000 Nmmであり、差4224585.069444 Nmmを確認した。

通常弾性梁が荷重を要素内で所有しない経路では、等価節点荷重を物理節点の12成分だけへ散布し、仕口パネル追加自由度へのCᵀqを欠いていた。剛性と部材端回転に用いる既存の結合係数を共有してTᵀqを求め、線形の物理荷重台帳、全体荷重組立、増分の非所有重力荷重経路へ接続した。要素が部材荷重応答を所有する線形/増分経路には重ねて加算せず、元物理節点荷重・反力控除の12成分は維持する。

是正後、同じ公開静的・Analysis入口でMSY=−60050000 Nmm、柱脚反力、元荷重による追加せん断変位/仕事が独立値と一致し、直接回帰が成功した。全体荷重組立からの直接求解とも節点応答を比較する。追加荷重変換には、柱/梁の両係数・両γ同時・全体回転・柱傾斜・部材端反転の独立投影による仕事回帰を設けた。

all-targets初回では、未知Rの面距離回帰を全準備へ通したところ、面解決後に既存の断面性能算定が角R未知で停止した。この試験は公開 `apply_rigid_zones_and_panels` による面準備へ限定し、未知Rでも全準備・解析が成功するという主張はしない。既存支持試験のH弱側・明示0距離fixtureと、縮尺時刻歴試験が仕口パネル距離だけ未縮尺だった点も、目的と独立期待値を保持して是正した。all-targets初回の4失敗（3target）を最終成功で取り消さない。

荷重是正後のall-targets2では、非所有重力経路の自由度検査を空荷重の非線材にも適用したため、既存の壁を含む増分3件とパネル公開入口1件が失敗した。空荷重は散布対象から外す最小修正を行い、仕口パネル＋節点ばねを持つ公開pushoverで重力なし/ありを直接実行して成功した。追加回帰の最初の2試行は、重力組合せの種別・明示P=0を揃えていない試験入力で停止し、正規のG+P=0へ修正してから受理を確認した。
