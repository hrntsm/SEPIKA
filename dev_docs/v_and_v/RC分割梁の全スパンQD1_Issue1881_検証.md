# RC分割梁の全スパンQD1（#1881）

[Issue #1881](https://github.com/hrntsm/SEPIKA/issues/1881)・[製品の算定条件](../../docs/calc_basis/06_一次設計/02_02_RC梁のせん断検定.md#一本部材に指定した分割梁)

## 原典と独立計算

日本建築学会『鉄筋コンクリート構造計算規準・同解説』2024年版、第15条p.22の式(15.7)、解説pp.174–175を照合した。梁両端の降伏曲げによるせん断と、単純梁として算定した長期荷重によるせん断を組み合わせる。解説の降伏曲げ略算は0.9Atσydで、実降伏点・余剰主筋・スラブ筋による梁端耐力の上昇は別途考慮が必要である。本件は入力から確認できる矩形断面・主筋と部材荷重に限る。

- 全長4 mの梁に等分布10 kN/mを載せる。対称性から合力40 kNの半分ずつが各外端に作用する。2 mの二分割でも同じ20 kNである。右区間中央に8 kNの逆向き集中荷重を重ねると、左端では18 kN、右端では14 kNとなる。左区間中央に置き換えると反力が対応して入れ替わり、どちらも18 kNが支配する。
- 実材長4.5 m、両外端フェース各250 mm、内法4 mのモデルでは、同じ上端2-D19・下端4-D19、SD345、有効せい550 mmを両外端に使うと、98 kN·mと196 kN·mの和を内法で除した73.391 kNにQ0を加える。右外端を6-D19／3-D19に変えると、降伏曲げ和はD19の10本分と5本分であり、大きい側を使う場合は20 kNを加えて142.318 kNとなる。

- 分割梁の両外端が直接支持される場合と、0.5 m角の鉛直柱を介して支持される場合について、局所Qyに当たる鉛直並進の拘束を一端で外す。曲げ伝達が確認できても鉛直反力の伝達先がない場合はQD1・minが未算定になること、拘束の代わりに正の鉛直ばねを与える場合は算定できることを照合する。

## 再現手順

- `cargo test -p sepika-job --test signed_q0 --locked` で全スパンのQ0と中間節点荷重、荷重位置、局所軸の適用境界を確認する。
- `cargo test -p sepika-design-jp --test rc_beam_qd1 --locked` で分割前後のQD1、危険断面位置、外端の異配筋、反力伝達条件、未算定の理由を確認する。
- `cargo test -p sepika-app --features gui --lib grouped_rc_qd1 --locked` で通常検定の選択組合せと時刻歴簡易検定の適用範囲を確認する。

内法に実柱面を使う条件は単一要素の梁と同じ。単一要素梁の反力支持の確認は [#1966](https://github.com/hrntsm/SEPIKA/issues/1966) で扱う。分割した架構の実建物比較、架構全体の降伏機構、中間支点・節点荷重やスラブ筋を特定できないモデル、終局検定は本検証に含めない。
