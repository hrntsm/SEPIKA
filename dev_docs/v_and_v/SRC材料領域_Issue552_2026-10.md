## 独立期待値と面積・剛性

b300、D600、H400×200×8×12、主筋なし、単位mm。Hを上下flange2枚とweb1枚として長方形の厳密積分から求める。期待値は製品のメッシュ計算をコピーしない定数oracleで照合し、進行側Decimalの独立算術とも一致。

| 量 | 期待値 |
| --- | ---: |
| Ag / As / Ac [mm²] | 180000 / 7808 / 172192 |
| 強軸Is / Ic [mm⁴] | 216148650.6666667 / 5183851349.333333 |
| 弱軸Is / Ic [mm⁴] | 16016042.6666667 / 1333983957.3333333 |
| EA（Ec20500、Es205000）[N] | 5130576000 |
| 強軸EI [N·mm²] | 150579426048000 |
| ε=1e−4の弾性fixture N [N] | 513057.6 |
| 旧重複の軸力過剰 [N] | 16006.4 |
| 材料別一定圧縮応力24/235のN [N] | −5967488 |

最後の一定応力は独立に指定する積分fixtureであり、同時到達ひずみ・終局耐力のValidationではない。微小一様弾性fixtureも製造解としてEc/Esを指定し、解析材料の非線形応答と区別する。

`src552_independent_area_centroid_inertia_and_elastic_oracle`は材料別Aと一次モーメント、EA、軸力を相対1e−10以内で照合する。ゼロ一次モーメントは面積×断面最大寸法で正規化する。ΣAfは180000で保存され、主筋追加の別試験はΣAf=Ag+4×one_bar_area(20)、実座標(±100,±250)を確認する。

## 段階細分化と通常配置の誤差

誤差は厳密Iに対する絶対相対差の百分率。表のIはセル中心の点積分で、各セル自身の局所Iを加算していない。

各誤差はこの系列で単調減少し、最終材料別I/EIは0.1%以内。A・図心の保存はこの収束と独立に検証する。通常分割の応答・耐力を一律安全側としない。要素は既存の90°断面回転を行うため、直接試験では強軸EIは断面接線d[2][2]で照合する。
