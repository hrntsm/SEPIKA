# RC梁の曲げ終局耐力略算（#1501）

[#1501](https://github.com/hrntsm/SEPIKA/issues/1501) の調査では main の 96bbd465 を基点に公開検定の挙動を初回照合した。main の更新を取り込んだ 94c51fbc を基点に、追加した公開検定の試験と文書を最終検証した。無軸力・矩形RC梁の強軸曲げについて、解説書の適用記述と実験集計、圧壊時の独立断面計算、公開終局検定を照合した。略算値を必要せん断力へ転用すると、断面・材料により余裕度を過大にも過小にも評価し得る。理由付き未検定と参考値の扱いは [#1711](https://github.com/hrntsm/SEPIKA/issues/1711) で是正する。

## 原典の適用条件と試験範囲

- 『2025年版 建築物の構造関係技術基準解説書』第2版第1刷 pp.698–699、付録1-3.1(1)⑥a)、式(付1.3-5)。矩形梁で引張鉄筋の降伏が圧縮コンクリートの破壊に先行する釣合鉄筋比以下の略算。式の入力は引張鉄筋の断面積・降伏強度と、圧縮縁から引張鉄筋重心までの有効せい。鉄筋比が過大、コンクリート圧縮強度が過小、圧縮幅が有効せいに比べて著しく小さい場合は適否を検討する。圧縮強度18 N/mm²以上かつSD390級以下では通常の引張鉄筋比2%未満に適用でき、SD490も2%未満で適用できると記載する。p.698にある引張鉄筋比0.4–2.8%は降伏点剛性低下率の別式。スラブ参加の扱いは有効幅、変形、拘束、定着を別途確認する。
- 引用文献(6)の日本建築学会『建築耐震設計における保有耐力と変形性能』1990年版、pp.158–159、§3.2.1 式(3.1)にも引張降伏先行と通常の鉄筋比2%未満の記述がある。2025年版解説書と同書の曲げ略算の該当段落には鉄筋比の分母が明記されていない。本調査の断面比較では、引用文献(1)の日本建築学会『鉄筋コンクリート構造計算規準・同解説』2024年版、第13条解説2、pp.132–133の矩形梁での定義に沿い、p_t＝a_t/(bd) と置く。同条に掲載された許容曲げの釣合鉄筋比は許容応力度で決まる。終局時の圧壊・降伏判定には以下のひずみと応力の釣合いを用いた。2%付近の比較はこの分母を置いたときの感度であり、判定の実装に先立つ分母の確認は [#1711](https://github.com/hrntsm/SEPIKA/issues/1711) に残る。
- 解説書p.699は圧縮強度60 N/mm²未満・曲げ降伏先行の297体として平均1.09、変動係数0.11、±30%内96.6%を記す。引用元の建築研究資料No.175（2016年）第3章 §3.5.5 pp.3-52–3-55、表3.5.5では297体は曲げ降伏先行の両強度群の合計。実験値／計算値は全体で平均1.09・変動係数11.1%・最小0.81・最大1.88・±30%内96.6%。実験圧縮強度60 N/mm²未満は211体で平均1.08・変動係数11.8%・±30%内96.2%、同60 N/mm²以上は86体で1.13・7.8%・97.7%。集計には同報告の表を採る。報告が図で区分したSD490相当（実験降伏強度490–570 N/mm²）も、SD490級の公称入力や適用条件とは区別する。60 N/mm²は試験の層別であり、曲げ式の適用上限を意味しない。試験比が1をまたぐため、耐力の下限やせん断需要の上限としての保証も得られない。[建築研究資料No.175、第3章](https://www.kenken.go.jp/japanese/contents/publications/data/175/4.pdf#page=52)

## 独立した断面計算

矩形断面で軸力ゼロ・平面保持とし、圧縮縁を深さ y＝0、中立軸を y＝c とする。圧縮正のひずみは ε(y)＝εcu(1−y/c)。無拘束コンクリートは引張応力を負担せず、圧縮側は f_c(ε)＝Fc(2r−r²)、r は ε/0.002 を [0, 1] に制限した値とした。圧縮縁の終局ひずみ εcu＝0.003 とした。鉄筋は Es＝205,000 N/mm²、引張・圧縮ともに同じ降伏強度 σy の弾完全塑性とし、各段の中心で応力を評価する。コンクリート合力を全幅で積分したため、鉄筋の位置ではその面積が置換したコンクリートの応力を控除する。これらは感度比較の仮定であり、拘束・スラブ・ひずみ硬化・鉄筋破断や高強度材の個別応力–ひずみ特性はモデル化していない。

圧縮側コンクリートと上下の鉄筋の合力の和が0となる c を二分法で求め、引張側鉄筋位置 y＝d まわりのモーメントを求めた。釣合い時の中立軸は c_bal＝d εcu/(εcu＋σy/Es)。圧縮縁が εcu に達したとき c＜c_bal なら引張主筋は降伏済み、等しければ同時、c＞c_bal なら未降伏。釣合時の圧縮側合力を σy で割ると釣合いの引張鉄筋量が得られる。反対側の配筋と圧縮側幅がこの合力に入るため、同じ引張鉄筋比でも降伏順序は変わり得る。

主筋は1段ずつ、かぶり40 mm、あばら筋は数値径10 mm・2脚@100、主筋中心の縁距離は40＋10＋呼び名の数値/2 mm。D29は公称断面積642.4 mm²/本、D19は286.5 mm²/本。上下の材料は共通で、上端引張時は断面を反転して上端主筋を引張側に移す。主筋強度の実験値・上限強度倍率は加えていない。

次のPythonで表の値を再現できる。入力は mm・N/mm²、出力は p_t と p_bal が%、c と c_bal が mm、ひずみが‰、曲げが kN·m。

~~~python
def section(b, depth, fc, fy, nt, nc, area=642.4, diameter=29):
    dp = 40 + 10 + diameter / 2
    d = depth - dp
    at, ac = nt * area, nc * area
    es, e0, eu = 205_000, 0.002, 0.003
    k = e0 / eu
    # i0、i1 は中立軸から圧縮縁までの無次元応力分布とその一次モーメントの積分。
    i0, i1 = 1 - k / 3, 0.5 - k**2 / 12

    def force_and_moment(c):
        concrete = b * c * fc * i0
        center = c * (1 - i1 / i0)

        def steel_stress(y):
            strain = eu * (1 - y / c)
            r = min(1, max(0, strain / e0))
            return min(fy, max(-fy, es * strain)) - fc * (2 * r - r**2)

        opposite = ac * steel_stress(dp)
        axial = concrete + opposite + at * steel_stress(d)
        moment = concrete * (d - center) + opposite * (d - dp)
        return axial, moment / 1e6

    c_bal = d * eu / (eu + fy / es)
    p_bal = 100 * (at + force_and_moment(c_bal)[0] / fy) / (b * d)
    low, high = d / 1000, d
    for _ in range(70):
        c = (low + high) / 2
        if force_and_moment(c)[0] > 0:
            high = c
        else:
            low = c
    c = (low + high) / 2
    return (100 * at / (b * d), p_bal, c, c_bal, 1000 * eu * (d / c - 1),
            force_and_moment(c)[1], 0.9 * at * fy * d / 1e6)


cases = [
    *((480, 202, fc, 490, 2, 2) for fc in (17, 18, 19, 60, 72)),
    (480, 202, 18, 685, 2, 2),
    *((b, 210, 18, 490, 2, 2) for b in (440, 2 * 642.4 / (0.02 * 145.5), 450)),
    (650, 214, 18, 490, 3, 2),
    (650, 214, 18, 490, 2, 3),
    (350, 610, 24, 345, 2, 2, 286.5, 19),
]
for case in cases:
    print(case, tuple(round(x, 6) for x in section(*case)))
~~~

### 上下非対称配筋

幅650×せい214 mm、上3-D29・下2-D29、有効せい149.5 mm、Fc18・SD490。上端引張では p_t＝1.9832%、p_bal＝1.9360%、c＝83.7487 mm、引張ひずみ2.3553‰で未降伏。下端引張は p_t＝1.3222%、p_bal＝2.1089%、c＝66.1727 mm、引張ひずみ3.7777‰で降伏済み。c_bal＝83.2059 mmは両方向で共通。独立 M は上102.4165・下76.2233 kN·m、公開の参考 Mu は上127.0593・下84.7062 kN·m。

独立断面の両端終局モーメントを逆符号で仮置きしたせん断成分の大きさは (102.4165＋76.2233)/4.000＝44.6600 kN。略算の上下 Mu を同様に仮置きすると52.9414 kN。上端引張が圧壊先行したこの例では、いずれも両端の引張降伏機構に基づくせん断需要として採用できない。公開静的検定は上下で主筋配置の異なる梁を従来どおり理由付き未検定とし、比較需要と余裕度はNaN。確定総応答でも上下の参考 Mu を返した。比較需要には別途与えた総せん断力30 kNを使い、両方向で理由なしOKだった。

### 需要の過小評価でせん断の判定が分かれる例

幅350×せい610 mm、上下各2-D19、有効せい550.5 mm、Fc24・SD345、p_t＝0.2974%。独立断面は引張主筋の降伏先行で M＝109.3545 kN·m、Q＝54.6772 kN。公開 Mu＝97.9430 kN·m、Qmu＝48.9715 kNで、独立 Qを10.4%下回る。塑性理論式の Qsu＝609.6686 kN、比較上の長期せん断 QL＝558.0000 kNのとき、控除後は51.6686 kNとなった。付着照査を外した公開検定は余裕度1.0551でOK。同じ耐力・重力条件のまま独立 Qに置き換えると余裕度0.9450。この入力は比較の境界を観測するための直接需要であり、実架構の荷重・崩壊機構やせん断耐力式そのものの妥当性は検証していない。曲げ耐力を小さめに見積もることは、同じ値から保証設計の要求せん断を求める場合には危険側となり得る。

## 公開入口と再現

公開の collect_rc_ultimate_checks を [rc_ultimate_beam_hinge.rs](../../crates/sepika-design-jp/tests/rc_ultimate_beam_hinge.rs) に追加した4試験で照合した。両端に回転拘束のある4,000 mm梁を用い、フェイス距離0、強軸曲げ、上限強度倍率1.0、Rp＝0、塑性理論式を選んだ。需要過小評価例を除き静的 QL＝0、付着照査有効。入力として i端上端引張・j端下端引張の機構を指定した。非対称例では逆向きも指定し、長期 Mz は上端引張で−10 kN·m、下端引張で＋10 kN·m。機構指定は分岐確認用で、独立計算で圧壊先行とした例を含む。現行のGUIの静的参照では機構を指定できず、RC矩形梁は未検定となる。APIで観測した有限OKは、機構を直接指定した場合の動作に限る。

## 適用外と後続対応

- 方向別に長方形断面・材料・鉄筋比の原典条件と圧壊に対する引張降伏の先行を確認する。鉄筋比2%以上、Fc18未満、SD490を超える材種、圧縮幅が著しく狭い断面、釣合い近傍は個別の断面計算を求める。
- 現行は略算の適用条件を診断しない。静的需要で適用範囲外や判別不能を理由付きで保留し、確定総応答のせん断判定と参考曲げ耐力の扱いを分ける是正は [#1711](https://github.com/hrntsm/SEPIKA/issues/1711)。安全な静的需要の扱いには、耐力の下限と需要の上限を分けて根拠を定める必要がある。独立計算は是正に用いる共通の材料モデルや倍率を確定していない。
- 付着割裂・定着の条件は [#1500](https://github.com/hrntsm/SEPIKA/issues/1500)・[#1502](https://github.com/hrntsm/SEPIKA/issues/1502)、方向別両端ヒンジの需要は [#1582](https://github.com/hrntsm/SEPIKA/issues/1582)、増分解析の曲げヒンジ表示への影響は [#1712](https://github.com/hrntsm/SEPIKA/issues/1712) を参照。今回は限定的な計算と公開検定のVerificationで、実験試験体の独立再計算・実架構の載荷解析・手動GUI／MCP実通信・実験Validationは未実施。

利用者向けの適用条件は [RC梁の曲げ終局耐力と曲げ終局時せん断力](../../docs/calc_basis/08_部材終局耐力/01_01_RC梁の曲げ終局耐力と曲げ終局時せん断力.md) と [静的・両端ヒンジ略算による終局検定](../../docs/calc_basis/08_部材終局耐力/07_01_静的_両端ヒンジ略算による終局検定.md) に記載した。
