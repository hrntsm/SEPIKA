# 壁有無の固有周期比較（Issue #1161）

[Issue #1161](https://github.com/hrntsm/SEPIKA/issues/1161) の比較では、単層立体架構から
開口付き耐震壁版 0 を除いた対照を作る。壁版の参照を除いた入力を照合し、節点・階・柱梁・
断面・材料・拘束・荷重が等しいことを確認する。屋上パラペットと、その階帯に用いる
z = 6000 mm の節点・第三階は両ケースに含めない。パラペット・壁自重の階所属は
[壁自重の用途別配分の試験](壁自重の独立用途配分_Issue444_2026-10.md)で確認する。

## 解析質量と独立期待値

屋上の節点 4 を剛床代表節点として直接指定し、屋上 4 節点の X・Y 並進を共通にする。
他の節点自由度は拘束し、仕口パネルの追加回転を用いない。準備・壁展開後の独立自由度が
この 2 方向であることを確認する。

両モデルの X 並進に 2.0 t（2.0 N·s²/mm）の節点質量を直接与え、質点のみ方式
（`LumpedOnly`）を用いる。床代表節点を直接指定すると、準備はその節点の入力質量を保持する。
部材密度と壁重量は部材・荷重入力に保持する。入力から得た縮約質量行列の期待値は
X–X が 2.0 t、X–Y・Y–X・Y–Y が 0 である。両モデルの組立後の質量行列をこの期待値に
照合し、App の固有値結果でも唯一の振動モードの X 有効質量 2.0 t、Y・Z の有効質量 0 を
確認する。

屋上の +X 方向に 1000 N を載荷する。無質量で水平外力を受けない Y 並進の釣合いは
`K_yx u_x + K_yy u_y = 0` である。これを X の式へ代入すると、X 並進の剛性は
`K = K_xx - K_xy K_yx / K_yy` となる。線形静的解析の節点 4 の変位 `u_x` [mm] から、
この剛性を `K = 1000/u_x` [N/mm] として求める。両解析は壁を展開し、同じ線形基準剛性を
用いる。1 自由度の運動方程式 `m ü_x + K u_x = 0` から `T = 2π √(m/K)` [s] を得る。
質点質量と静的変位から求めた周期を固有値解析の周期と照合し、壁ありで `K` が増加し、
同じ質量で `T` が短くなることを確認する。相対許容差 1e-6 は有効質量と周期の数値照合に
用いる。周期の大小には差の率を設けない。

| 対照 | X 解析質量 [t] | 静的変位から求めた剛性 [N/mm] | 静的変位と質量から求めた周期 [s] | App の固有周期 [s] |
| --- | ---: | ---: | ---: | ---: |
| 壁あり | 2.0 | 1,030,826.535 | 0.00875189 | 0.00875189 |
| 壁なし | 2.0 | 39,911.053 | 0.04447831 | 0.04447831 |

## 確認範囲

[App の wall_model 統合試験](../../crates/sepika-app/tests/wall_model.rs)の
`enclosed_wall_shortens_period_with_equal_x_mass` は、上記の拘束と質量で
耐震壁版の有無が線形架構の X 方向剛性と周期に及ぼす効果を確認する。壁側柱との接続や
準備計算で生じる剛性の変化を含む。静的解析と固有値解析は剛性の組立を共有するため、
この照合は壁剛性の絶対値の独立検証までを含まない。

`snapshot_wall_bay_scalars` は立体架構を通常の自由度・補正質点方式で解析した
壁ありの代表周期・応答を回帰確認する。立体架構では固有値順や X 有効質量の大小が
モード選択を変えうる。壁を除くと質量分布も変わりうるため、この比較で確認した
周期の順序を任意の立体架構・質量方式に適用できる範囲は未確認である。

実在の RC 壁の剛性・周期、ひび割れ、規準適合と安全性は別の検証を要する。
線形軸・面内曲げは [#652 の記録](RC壁線形軸曲げ剛性_Issue652_調査記録.md)と
[PR #1433](https://github.com/hrntsm/SEPIKA/pull/1433)、開口評価は
[#821 の記録](RC開口壁_Issue821_モデル監査.md)と
[PR #1406](https://github.com/hrntsm/SEPIKA/pull/1406)を参照する。これらはそれぞれ
無開口の有限例と側柱のない開口板の監査を含む。現行方式の全適用条件や実験 Validation は
各調査の範囲に残る。設計用周期の適用条件は
[固有値解析の計算根拠](../../docs/calc_basis/05_構造解析/03_固有値解析.md)を参照する。
