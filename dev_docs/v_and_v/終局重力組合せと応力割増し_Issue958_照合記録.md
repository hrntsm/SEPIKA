## 独立有限例と安全性

- **積雪の適用状態。** ある断面の同符号応力を G=100、架構用 P=20、S=40、水平力 K=±30 kN とすると、長期常時 120、多雪長期 148、短期積雪 160、多雪地震 164／104 kN。限界耐力計算の極めて稀な積雪は 176 kN で、別の荷重状態になる。例えば長期積雪で比較耐力 140 kN に対して S を落とすと需要比が 148/140≒1.057 から 120/140≒0.857 へ下がり、合否が反転する。0.7 で低減済みの 28 kN を S に入力して長期組合せでも 0.7 を掛ける場合は、120+0.7×28=139.6 kN、需要比 139.6/140≒0.997 となり、同じ耐力に対して合否が反転する。これは同じ断面・同符号での照合例であり、反対符号や他断面での増減は別に確認する。
- **地震成分の割増し。** RC 梁の両端ヒンジを確認した仮想断面で Q0=12、QM=80、比較耐力 95 kN とする。割増し前の同符号総せん断力は 92 kN、告示ハの最低値 1.1 を地震成分に適用した設計用せん断力は 100 kN。需要比 0.9684 では通る例が 1.0526 で不成立となる。総応答の 1.1 倍は 101.2 kN で、Q0 にも倍率が掛かる。逆向き QM=−80 kN の符号付き成分比較では絶対値が 76 kN と 74.8 kN になり、総応答一律倍で包絡できるとは限らない。後者は誤った倍率の掛け方を示す力学上の点比較で、告示表の包絡や非線形応答分離の一般式を定める例ではない。
- **評価点と非線形性。** ある確定ステップの総応答だけから、法規が求める地震成分・ヒンジ状態・別外力分布での応答は確定しない。他ケースの線形重力結果を確定総応答から引いて割増しし再加算する操作を、新たな非線形履歴の解として採用しない。

Windows で `cargo test -p sepika-job --locked --offline --lib ultimate_demand -- --nocapture` を実行し 10 件成功した。一時プローブは公開静的需要入口に符号付き内力を与え、0.7S の合成後圧縮軸力 148,000 N と、0.35・1.0・1.4・1.5 の長期重力での拒否を確認した。既存試験では G/P と地震用積載の区別、符号付き合成後の QL=12,000 N、圧縮・引張の解析内力、位置・応答欠落の拒否も確認した。積雪のプローブはケース内力の合成までを対象とし、屋根荷重への変換や局所積雪量は別途確認する。

Windows の `cargo test -p sepika-design-jp --locked --offline --lib gravity_demand_contract_tests -- --nocapture` は 8 件成功した。既存試験では局所の総せん断力 +92,000 N／−68,000 N を与え、絶対値を一度だけ比較すること、倍率 1.1 と追加 QL を拒否することを確認した。この試験の負符号は部材の局所軸に対するせん断力の向きを表し、試験範囲は与えた局所応答の処理に限る。一時プローブ 1 件は次節の二軸の反転を再現した。

## 使用中の経路で確認した不一致

### MCP の CFT 軸終局

保存した G+P を評価する共通静的入口と、単独ケースを評価する MCP ジョブの差を [#1411](https://github.com/hrntsm/SEPIKA/issues/1411) で追跡する。調査基準 `d3d19494`、角形 400×400×12 mm、Fc=30 N/mm²、鋼材降伏強度 235 N/mm²、柱長および両軸座屈長 7,200 mm、柱頭の圧縮 G と P は各 4,000 kN。保存長期組合せの係数は各 1。

| 入口 | 独立釣合いと比較 | 実測 |
| --- | --- | --- |
| 公開共通静的需要と CFT collector | 柱頭鉛直力の和より N=8,000 kN。Ncu=7,468.425 kN に対し余裕 0.93355 で NG | N=8,000 kN、余裕 0.93355、軸 NG、Mu 未算定 |
| 公開 `sepika_mcp::compute_job`、ケース省略および G を明示 | 正しい重力条件では、いずれも単独 G から全合格を返せない | どちらも N=4,000 kN、余裕 1.86711、`all_checks_calculated_and_ok=true` |

Windows で独立プローブを `cargo test -p sepika-mcp --locked --offline --test issue958_temporary_probe -- --nocapture` により 1 件実行した。Ncu はこの条件の製品比較耐力として固定し、地盤・座屈耐力式の妥当性の検証は含めない。

### RC 柱の静的二軸せん断

強軸に長期せん断がある場合に、二軸指定で強軸単独の NG が合格へ変わる不一致を [#1412](https://github.com/hrntsm/SEPIKA/issues/1412) で追跡する。調査基準 `d3d19494`。既存の直達検定モデルの矩形柱 600×600 mm、Fc=24 N/mm²、内法 3,000 mm に、圧縮軸力 150 kN、QL=500 kN を与えた。上限強度倍率は 1、付着と二軸曲げは無効。公開 `collect_rc_ultimate_checks` を呼び二軸せん断指定だけを切り替えた。

| 項目 | 値 |
| --- | --- |
| 製品算定の比較耐力とヒンジ略算需要 | Qsu=725.654571 kN、Qmu=246.249060 kN |
| 強軸で必要な比較 | QL+Qmu=746.249060 kN > Qsu。強軸の需要が耐力を超えるため NG |
| 強軸単独の実測 | 余裕度 0.916367、NG |
| 二軸せん断指定時の実測 | 二軸余裕度 2.083725、OK |

二軸指定が採用する相互作用余裕度には QL の控除が入らず、強軸単独の余裕度も最終せん断判定に使わない。二軸指定でこの強軸不成立が合格に変わらない扱いが必要である。再現は公開検定の需要契約を対象とし、新しい二軸合成式の適用範囲や耐力式全体の妥当性は検証していない。

## 残る条件と修正判断

長期重力の明示選択、符号付き合成、総応答への重力の二重算入防止は先行契約の範囲で評価する。文献で確認した鋼構造の塑性荷重、限界耐力計算、RCの保証設計とSEPIKAの終局検定の間には適用条件と比較耐力の差がある。既定倍率や組合せ係数の置換を根拠づける一般則は確認できなかった。保証設計の実装に進む場合には、採用する設計経路、作用分離、ヒンジの確認、Q0 の算定法、Ds／保有耐力の評価点と各比較耐力を先に定める。

地域指定と実況の自動判定、新しい法規ルート、風の生成は今回の採用判断の対象外。日本建築学会『鉄筋コンクリート構造保有水平耐力計算規準・同解説』2021年版と『鉄筋コンクリート造建物の靱性保証型耐震設計指針・同解説』1999年版の保証設計式本文を照合範囲に含めておらず、静的略算の倍率に一般的な規準適用を与えない。一般建物での適用成立と実験 Validation は未確認。
