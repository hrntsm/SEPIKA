# RC梁の非有限なあばら筋間隔（#1853）

通常の強軸曲げを算定できるRC矩形梁を対象に、あばら筋間隔がNaNまたは正負の無限大の場合と、有限な対照の検定結果を照合した。 [Issue #1853](https://github.com/hrntsm/SEPIKA/issues/1853)・[現行の検定条件](../../docs/calc_basis/06_一次設計/02_02_RC梁のせん断検定.md#あばら筋間隔が非有限の場合)

## 原典の確認範囲

日本建築学会『鉄筋コンクリート構造計算規準・同解説』2024年版のうち、第15条 式(15.2)〜(15.5)（pp.20–21）におけるせん断補強筋比と、第15条2項(4) iii（p.22）のあばら筋間隔上限を確認した。第16条（p.25）の式(16.1)・(16.3)はせん断力と主筋の周長総和を用い、式(16.2)・(16.4)は鉄筋応力度・鉄筋径・有効付着長さを用いる。同条の式(16.9)〜(16.11)（p.27）では、2024年版の大地震時の安全性の照査で横補強筋効果に用いる間隔を確認した。2024年版との照合範囲は各照査に必要な入力の確認である。製品が採用する短期1999方式の適用条件と式・係数の照合範囲は製品文書に記載する。 [2024年版の書誌](https://ndlsearch.ndl.go.jp/books/R100000001-I25115036270)・[付着の採用式](../../docs/calc_basis/06_一次設計/02_07_RC梁の付着_定着検定.md)

## 独立算術と通常の公開検定

材長3000 mm、幅250 mm、せい350 mm、Fc24、SD345、上下各3本の数値径19 mm、かぶり40 mmとした。あばら筋は数値径10 mmで、脚数は2または0とした。梁中央の正曲げを照査した。有効せい290.5 mm、応力中心距離254.1875 mm。中立軸は軸力の釣合いから113.593904 mm、短期許容曲げは引張鉄筋で決まり74.591892 kN·mとなる。

2脚、M=45 kN·m、Qy=200 kNの短期損傷制御では、α=2、コンクリートの許容せん断応力度1.095 N/mm²となる。100 mm間隔のせん断補強筋比は0.006283185307、許容せん断力は139.730012 kN。間隔0 mmでは補強筋比を0とし、許容せん断力は92.778438 kNとなる。1999方式の短期付着では、下端筋の許容付着応力度1.5 N/mm²、比較長さ1500 mmを用いた。

| 条件 | 独立値と公開検定の結果 |
| --- | --- |
| 2脚、100 mm、M=45 kN·m、Qy=200 kN | 曲げ比0.603282727、せん断比1.431331730、短期1999付着比0.338108100 |
| 2脚、0 mm、M=45 kN·m、Qy=200 kN | 曲げ比0.603282727、せん断比2.155673294、短期1999付着比0.387398027 |
| 2脚、NaN・正負の無限大、短期1999 | 各間隔で未算定理由を返した。M=45 kN·m、Qy=200 kNでは未算定行のみ。M=300 kN·m、Qy=300 kNでは曲げNGの比4.021884847を併記 |
| 2脚、NaN・正負の無限大、短期1991 | M=45 kN·m、Qy=200 kNで、付着NGの比1.268083462を併記。地震時QD1ではQ0=150 kNと両端の曲げ降伏による51.148726 kNから需要201.148726 kNとなり、付着NGの比1.275366864を併記 |
| 2脚、NaN・正負の無限大、長期1999 | M=300 kN·m、Qy=300 kNで、曲げNGの比7.657483127と付着NGの比3.873980265を併記 |
| 0脚、100 mm・NaN・正負の無限大、短期1999 | M=300 kN·m、Qy=300 kNで、せん断の補強筋項と付着の横補強筋効果をともにゼロとした独立値はせん断比6.467019883、付着比2.582653510。各間隔で両NGと曲げNGを確認し、非有限の間隔では未算定理由も確認 |

比は独立値との差が1e-8未満で一致した。非有限の間隔では、間隔に依存するせん断・短期1999付着・構造規定の適否が返らないことを確認した。修正前の版106では2脚かつ間隔NaNの例でせん断比は表示されず、短期1999付着比0.387398027が表示された。0脚かつ間隔NaNの例では、補強筋項がゼロで求まるせん断比も欠落した。 [公開検定試験](../../crates/sepika-design-jp/tests/rc_beam_asymmetric.rs)

## 保存検定

同じ断面の2脚、間隔+∞の片持ち梁に、先端の静的モーメント300 kN·mを与えた。両端と中央で曲げ・長期1999付着のNGと、間隔の未算定理由が得られた。この解析成果と検定版106を持つOVIKAを読み込むと、間隔+∞と解析内力を保持し、旧検定成果を失効させた。保存内力を使った再検定で、検定版107の結果が新規検定と一致した。 [GUIの保存契約の試験](../../crates/sepika-app/src/app/rc_beam_asymmetric_tests.rs)

確認範囲は通常検定の強軸方向と上記の配筋・荷重条件である。終局検定や増分解析に用いるせん断補強筋比の取り扱いは対象範囲外とした。
