# RC壁の線形軸・面内曲げ剛性の調査（Issue652）

2026-10-25初回調査、2026-10-26に2025年版解説書、2026-11-18にRC規準2024・入力経路・独立応答比較を照合。[Issue #652](https://github.com/hrntsm/SEPIKA/issues/652)の調査記録。状態は🔶。現行仕様の正本は[壁エレメントモデル](../../docs/calc_basis/04_要素剛性/05_壁エレメントモデル.md)とする。

## 調査結論

コンクリート総断面のEA=Ec・A、EI=Ec・Iを無開口の矩形壁板で比較した。RC規準8条3項・9条5項(2)と2025年版解説書はモデルの役割と目的・応力に応じた剛性評価を示す。現行ps換算と総断面候補の適用条件は未確定。側柱と外部架構を含む有限例では、候補で壁板の曲げモーメントとせん断力が減り、変位と側柱・外部架構の負担が増えた。採否はOPENとする。2026-10-25の公開資料確認と文書訂正は[PR #822](https://github.com/hrntsm/SEPIKA/pull/822)の成果として区別する。

[ADR0013](../adr/0013-adopt-wall-element-model.md)は壁エレメント置換モデルの選択であり、個別の鉄筋換算式を承認する根拠ではない。[ADR0044](../adr/0044-wall-horizontal-ratio-and-component-validation.md)の出力別入力不足の判断は参照できるが、線形総断面の採用決定へ読み替えない。未決定の候補をaccepted ADRにしない。

### 採否判断に残る具体的な限定条件

候補を比較する最小の断面条件は、無開口・矩形の壁板に同じ幾何からAとIを定め、側柱の軸抵抗を別に保持する三本柱の役割である。これは**検討条件案であって採用済みの適用範囲ではない**。壁板長を内法又は中心間のどちらに採るか、側柱との重複をどう避けるかも、RC規準8条3項等の実記載と同じ幾何へ対応付ける必要がある。一本柱の側柱込み断面と混ぜない。

外部判断を求める際は次を一組として提示する。

1. RC規準(2024)8条3項と9条5項(2)に従い、壁板と側柱を分担するモデルで鉄筋影響を無視できる条件を個別に検証する。同条2項の柱・梁での省略慣行には相対剛性の仮定がある。
2. 対象の長期・短期荷重、応力解析／層間変形／偏心率・剛性率等の目的、ひび割れ前か、ひび割れ後のどの状態かを限定する。荷重名だけでひび割れの有無は決めず、ひび割れ判定と、対象外時の拒否又は別評価の契約を明示する。708頁の技術的検証条件も併せて判断する。
3. 同一壁板A/Iの評価範囲と側柱との重複、上下梁の剛性・外部梁の接続、均一連層／突き出し／基礎回転を明示する。現行の壁板断面と一律100倍梁をそのまま規準適合としない。
4. 無開口での採否と開口壁への拡張を分ける。開口の位置情報・A/I・せん断・耐震壁不成立時の条件は#821の未決事項を参照し、対象外の開口を無開口へ補完しない。
5. 独立した壁板EA/EIの数値に加え、側柱軸の偶力と上下梁を含む応答を照合する。鉄筋情報不変・Ec/幾何依存の実入口試験は候補を実装した後の受入条件であり、現行試験の成功で置き換えない。

線形ps換算も総断面候補も本書だけで正当化できないという限定結果を、[Issue #883](https://github.com/hrntsm/SEPIKA/issues/883)のRC部材横断調査へ還元する。#883の全節調査や終局式検証を本件で完了扱いにせず、同一修正Issueを新規起票しない。採用判断を行っていないため新たなaccepted ADRも作成しない。

## RC規準2024と2025年版解説書の対応

日本建築学会『鉄筋コンクリート構造計算規準・同解説』（2024年12月10日、第10版第1刷、ISBN 978-4-8189-0682-2）の本文と解説を照合した。2025年版解説書の付録1-3.1(3)②、708–710頁、⑤、713–714頁も再照合した。公開元で[AIJ正誤表（2025-11-19掲載分まで）](https://news-sv.aij.or.jp/kouzou/s48/2024/seigo2024.pdf)と[刊行元Q&A](https://news-sv.aij.or.jp/kouzou/s48/2024/answer.htm)を確認し、今回参照した5・8・9条の剛性評価に直接対応する訂正または回答は見つからなかった。

Issue本文の「psを数量/質量の正本として維持」は、現行の方向別数量をpsへ戻す意味に解釈しない。今回の調査はそれぞれの既存契約を変更しない。入力表現と用途が異なるため、線形の筋比不要を理由に数量・非線形・質量の検査まで解除してはならない。

### 共通筋比の入力経路

調査起点 `2f70390c` の解析結果契約は72、OVIKAの保存スキーマは1。ネイティブ断面の `SectionShape::RcWall` は `ps` を直交する各方向の補強筋比の小さい方と定義する。縦筋比は軸方向の縦筋面積を実壁厚×壁長で除した値、横筋比は実壁厚に対する横筋比であり、両方向の入力は未知も保持する。断面編集の「直交最小筋比 ps」は独立入力（新規画面の初期値0.0025）。編集・保存された値を使い、解析時に明示した縦筋比・横筋比から再計算しない。横筋が少ない壁ではpsが縦筋比を表さず、同じ縦筋比でも鉄筋位置が違えば換算Iは異なる。数量について断面編集の旧案内と現行算定が食い違う点は [#1431](https://github.com/hrntsm/SEPIKA/issues/1431)。

ST-Bridge採用版は入出力とも2.0.2。[公開仕様書 Revision 2](https://www.building-smart.or.jp/wp-content/uploads/2021/03/ST-Bridge_XML%E4%BB%95%E6%A7%98%E8%AA%AC%E6%98%8E%E6%9B%B8%EF%BC%88ver.2.0.2%EF%BC%89.pdf) 本文262、264、266–267頁（PDF274、276、278–279頁）は、RC壁配筋を縦・横それぞれの径・ピッチで示し、内外不同では面と位置も分ける。SEPIKAの現行取り込みは `StbSecWall_RC_Straight` の厚さを `build_walls` で保持し、標準強度指定を別経路で解決する。壁配筋の要素から `RcWall` を作成したり、方向比やpsを算出したりする写像はない。厚さだけの形状データを保持する壁断面では、線形軸・面内曲げのRcWall専用換算係数は1。書き出しも壁配筋要素を生成しない。壁厚属性の書き出しと再取り込みの不整合は [#1432](https://github.com/hrntsm/SEPIKA/issues/1432)。

### 採用経緯と未照合部分

履歴`b3ad5ecb`はpsを縦横共通とみなす近似として導入し、原典照合リストへ未照合登録している。既存実装の由来を確認した証拠であり、公開原典の妥当性確認ではない。[剛性計算照合§1.8.1](剛性計算_参照実装照合.md#181-壁エレメントモデル本体の実装)と[原典照合リスト](原典照合リスト.md)の未照合状態を維持する。

現行A/Izは矩形全体であり、開口rはせん断断面にのみ適用する。公開資料のA/I開口差引との相違を、総断面候補の採用だけで解消したことにしない。側柱の軸抵抗を別要素で保持し、壁柱の軸・面内曲げへ側柱自身のA/Iをそのまま加算する方式でもない。面外Iy・ねじり・せん断・開口再設計・非線形・数量・質量・#617のQu前処理は今回変更していない。

この開口A/Iの相違について、入力・実入口の再現と資料のモデル適用範囲を独立に監査する課題は[Issue #821](https://github.com/hrntsm/SEPIKA/issues/821)で追跡する。相違だけから不具合や危険側とは判定しない。

## 候補採用後に必要となる入力契約

以下は採用決定前の契約案であり、現在の入力要件を置き換えない。

- 対象は線形壁柱の軸・面内曲げだけ。Ec [N/mm²]、同一評価断面のA [mm²]・I [mm⁴]からEA [N]・EI [N・mm²]を得る。Ec・幾何は有限正値とし、欠落・参照不能・不正は壁ID・断面ID・役割・理由を示して拒否する。
- この二成分の算定自体にps・pwh_ratio・pwv_ratio・鉄筋Es・fy・強度倍率を要求しない。「不要」を0・別方向比・psによる欠落補完として実装しない。入力値を勝手に書き換えない。
- せん断・Qu・非線形・数量・質量が必要とする材料や配筋の検査はその用途で維持する。モデル全体が不要入力を持てることと、他用途の入力不足を受理することは別である。
- 「総断面」の評価対象に側柱を含むか、開口をどの断面評価へ反映するか、ひび割れ前の弾性仮定をどの荷重・解析目的へ認めるかを採用前に明示する。対象外の開口を黙って埋めたり無開口へ切り替えたりしない。

## 安全性と判断が必要な点

通常のEc<205000、ps>0という条件では、係数を除去すると壁柱単体のEA/EIは小さくなる。しかし、単体の定荷重下の変形増加だけで建物全体の安全側を主張できない。並列架構では壁の負担減と他部材の負担増が同時に生じ、剛性比の変化は偏心・周期・応答にも影響する。ひび割れ後にはコンクリート総断面が実剛性を上回り、変形を過小評価する可能性もある。

採用前に、対象とする解析目的・応力範囲、ひび割れ・クリープの扱い、壁柱と側柱の分担、上下梁・開口条件を定める。その条件で規準の適用性と応答を検証し、AGENTS.mdに従ってユーザーが採否を判断する。

## 無開口壁板の独立応答比較

### 条件と再計算式

未ひび割れの線形弾性、初期応力なし。壁板は厚さ200 mm、長さ4000 mm、高さ3000 mm、Ec=30000 N/mm²。幾何からA=800000 mm²、I=1.0666666667×10¹² mm⁴を算定する（矩形IはRC規準2024の付4、506頁）。現行方式の比較値は軸用・曲げ用ともEc+(205000−Ec)×0.0025=30437.5 N/mm²を総断面に掛ける。候補は同じA/IにEcを掛ける。無開口で幾何・材料・せん断・周辺架構を同じ条件とし、中央のEA/EIだけを置き換える。

側柱を左右の軸ばね（各 (EA_c/h=1.6×10^6) N/mm、壁中央からの腕 (d=2000) mm）とし、上下を剛梁とする。下辺固定。上辺へ中央鉛直力P=100 kNを与える軸ケースは、対称性で上辺の回転が0となる。鉛直変位は (v=P/(EA/h+2EA_c/h)) であり、壁板の軸力 (N_w=(EA/h)v) と側柱各軸力 (N_c=(EA_c/h)v) の和がPになる。

水平ケースでは、回転自由の上辺へ水平力P=100 kNを与える。比較用の壁のせん断剛性は両方式でGA=9.0×10⁹ Nとする。側柱の軸変形から上辺の回転ばねを (k_θ=2(EA_c/h)d^2) とする。壁下端から高さzでの曲げモーメント (M(z)=Q_w(h-z)-C) を曲率として積分すると、回転角は (θ=(Q_wh^2/2-Ch)/EI)、側柱偶力は (C=k_θθ)。壁系の水平変位は次式で得られる。

```text
C / Qw = kθ h² / [2 (EI + kθ h)]
u / Qw = h/(GA) + h³/(3 EI) − (C/Qw) h²/(2 EI)
P = Qw + kf u
各側柱の軸力絶対値 = C/(2d)
壁脚曲げモーメント = Qw h − C
```

水平ケースは外部架構なし（kf=0）と、同じ上辺並進に接続する外部架構（kf=1.0×10⁶ N/mm）の2条件とする。仮想壁柱を通るせん断力 (Q_w) は壁系への負担であり、側柱が独立軸材であるこの例では側柱はせん断力を負担しない。

### 安全性の判定範囲

候補では、壁板の軸力・脚部曲げと、外部架構がある場合の壁系せん断力が減る。逆に、側柱の軸力絶対値、外部架構のせん断力、荷重制御下の変位は増える。同じ物理断面を使う後段検定で応力度を断面力から算定する場合、どの部材・断面を照査するかで応力度の増減も分かれる。力を直接入力する系では当該方向の総反力が等しくても分担は変化する。変位制御では逆に、同じ変位を生じるための反力が剛性とともに変わる。

この例の上下梁は剛体拘束であり、実梁100倍、外部梁の接続と回転拘束、多層・偏心・基礎回転、開口の幾何は再現していない。理想化した同一境界での置換差だけが確認範囲である。鉄筋による弾性剛性割増を外しても、実RCのひび割れ後剛性より大きく変形を過小評価する場合があり、ひび割れ後の安全性の根拠にはならない。長期荷重でクリープを考慮する場合も、この例の一定Ecに含めていない。
