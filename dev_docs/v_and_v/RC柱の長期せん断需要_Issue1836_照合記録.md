# RC柱の長期せん断需要（#1836）

状態🔶。長期荷重時の最大せん断力が既定の検定位置から外れると、矩形・円形ともに、せん断が不適合となる部材の全検定行が適合になり得る。部材の最大値を判定に反映する変更が必要であり、[#1843](https://github.com/hrntsm/SEPIKA/issues/1843) で追跡する。

## 原典の確認と最大値を求める区間

日本建築学会『鉄筋コンクリート構造計算規準・同解説』2024年版（ISBN 978-4-8189-0682-2）を照合した。2026年11月22日に確認した公開Q&Aと正誤表には、以下の長期設計用せん断力の記述に対する訂正はない。 [刊行版の書誌](https://ndlsearch.ndl.go.jp/books/R100000001-I25115036270)・[日本建築学会Q&A](https://news-sv.aij.or.jp/kouzou/s48/2024/answer.htm)・[正誤表](https://news-sv.aij.or.jp/kouzou/s48/2024/seigo2024.pdf)

| 参照箇所 | 確認した内容 |
| --- | --- |
| 第15条1項、2項(1) i)・ii)（pp.19–20） | 長方形断面等に適用し、円形等のその他の断面形には準用する。実験等で補強効果を確認した許容値には別扱いがある。許容値は式(15.1)の b j α f_s、長期設計用せん断力は部材に生じる長期せん断力の最大値。式(15.1)の記号欄では、許容値を求めるための M、Q もそれぞれ長期荷重による最大曲げモーメント、最大せん断力と記される。 |

第15条2項(1) ii) は部材の最大値を要求し、材端フェース・節点芯・剛体アーム端のどこを最大値の探索境界とするかは明記していない。本照合では、付2の設計例に沿って、通常の柱の両材端フェースを含む柱区間で長期せん断力の絶対値の最大を求める。節点芯は解析モデルの参照位置であり、フェースと一致する場合は区間の境界に含む。剛体アームの境界は剛性の設定によって決まり、柱区間の境界には材端フェースを用いる。この適用には、柱と接合部の境界を幾何で定められることを前提とする。

## 現行の需要と許容値の入力

- **需要**。解析は節点芯・材端フェース・部材中央・部材詳細の追加位置で内力を回収する。通常検定は材端フェース・部材中央・追加位置に一致する内力だけを部材検定行に渡す。矩形・円形とも、長期はその行の局所 |Qy| と |Qz| を各方向の許容値で除し、大きい比をせん断内訳とする。フェース間にある分布荷重の切替点は、自動では評価断面に加わらない。 [解析の評価断面](../../crates/sepika-element/src/frame/beam/construct.rs)・[検定位置](../../crates/sepika-design-jp/src/design_position.rs)・[柱の検定式](../../crates/sepika-design-jp/src/rc/column/mod.rs)
- **許容値**。通常検定は、検定行の抽出前に解析の全評価断面から最大 |Mz| の位置の (|Mz|, |Qy|) と、最大 |My| の位置の (|My|, |Qz|) を別々に選び、それぞれの方向の α を求める。選定には節点芯を含み得る。部材最大 |Q| を求める需要の照合とは独立した入力である。本文の M・Q の定義、p.177の柱脚・柱頭の小さい α と現行の採り方の関係は別途確認する。 [共通の部材検定](../../crates/sepika-design-jp/src/member_design_check.rs)・[αと許容値](../../crates/sepika-design-jp/src/rc/shear_capacity.rs)・[#1841](https://github.com/hrntsm/SEPIKA/issues/1841)

## 公開解析と独立釣合い

幅400×せい600 mmの矩形と径600 mmの円形、普通コンクリートFc24、SD345、材軸長3000 mmの片持柱を用いた。柱の両端接合は剛接合、柱脚節点は全自由度固定、柱頭は自由。柱脚節点につながる幅300×せい600 mmのRC梁は両端節点を固定する。柱の節点芯間を x=0〜3000 mm とすると、準備後の柱脚フェースは x=300 mm、剛体アーム端は x=150 mm。柱頭フェースは柱頭節点芯と一致する。既定の解析評価断面は x=0、300、1500、3000 mm、柱の検定行は x=300、1500、3000 mm。材軸偏心・仕口パネル・壁は設定していない。

保存荷重組合せは `DL + LL`（各係数1、架構用積載は空のケースで明示）。自重は鉛直方向の軸力に含まれる。局所 y（全体 X）方向に柱頭集中力12 kNと全長一様荷重1 N/mmをDLとして与える。内点最大の例では、さらに同じ方向の符号付き分布荷重を x=1050〜1100 mm に −6000 N/mm、x=1100〜1150 mm に +6000 N/mm 与える。これらの合力は0、偶力は15 kN·mで、既定の検定位置のせん断力を変えずに連続なピークを生じさせる。両例はせん断需要の回収を分離して比較するための理想化入力である。

独立値は、切断面より上側の自由体について、柱頭荷重と分布荷重の合力を合計してせん断力を、切断面まわりのモーメントを合計して曲げを求めた。対照例で |Qy| は `12000 + (3000 − x)` Nで、フェース間の最大は柱脚フェースにある。内点最大の例では局所分布荷重が切断面の下側にあるか、上側で合力が相殺される範囲で対照例と同じ値を取る。x=1050〜1100 mmで傾き +5999 N/mm、x=1100〜1150 mmで −6001 N/mmとなり、x=1100 mmで正方向の50 mm分300 kNが加わる。両例で Qz と My は0。次表は独立値である。公開解析では、両例の既定評価断面4か所と、内点最大の例で追加した x=1100 mm を照合した。解析での符号は Qy が負、Mz が正（柱頭では丸め誤差範囲でゼロ）。

| ---: | --- | ---: | ---: |
| 0 | 柱脚節点芯 | 15.000 kN、40.500 kN·m | 15.000 kN、55.500 kN·m |
| 300 | 柱脚フェース | **14.700 kN**、36.045 kN·m | 14.700 kN、51.045 kN·m |
| 1100 | 既定検定位置の間 | 13.900 kN、24.605 kN·m | **313.900 kN**、32.105 kN·m |

## 検定結果と判定の差

共通の解析準備 `prepare_model_for_analysis`、モデルに登録した長期組合せの線形静的解析 `Analysis::linear_combination`、通常の断面検定 `run_member_design_checks` を順に実行した。内点最大の例では、同じモデルで柱の付帯情報に継手位置 x=1100 mm を一時的に加え、解析と検定を再実行した。追加位置は最大値を検定に渡すと生じる判定差を観測するために使った。

| 矩形 | 対照 | 0.106446 / 0.097757 / 0.086895 | 0.353302 / 0.187457 / 0.086895、全行OK | ― |
| 矩形 | 内点最大 | 0.106446 / 0.097757 / 0.086895 | 0.500327 / 0.187457 / 0.086895、全行OK | せん断比2.273028でNG、軸＋曲げ比0.314683 |
| 円形 | 対照 | 0.091650 / 0.084168 / 0.074816 | 0.426258 / 0.120001 / 0.074816、全行OK | ― |
| 円形 | 内点最大 | 0.091650 / 0.084168 / 0.074816 | 0.854847 / 0.120001 / 0.074816、全行OK | せん断比1.957064でNG、軸＋曲げ比0.338164 |

両例・全行で αy=αz=1.000 と表示された。最大 |Mz| はどちらの例も柱脚節点芯にあり、同位置の |Qy| は15.0 kNである。内点最大の例で x=1100 mm を追加しても |Mz| の最大位置は移動せず、既定の3行と両方向の許容値は変わらない。長期許容せん断力（QAy、QAz、kN）の表示は矩形（138.098、130.497）、円形（160.393、160.393）。|Qy| をせん断比で除して得た観測値も表示と一致する。

式(15.1)で普通コンクリートFc24の長期 f_s=0.73 N/mm²（第6条 表6.1）、有効せい d を最大600 mm（j=7d/8≤525 mm）、αを最大1.5とすると、検討方向の許容せん断力には矩形229.950 kN、円形（現行の等積正方形幅531.736 mm）305.682 kNの上限がある。313.900 kNはこの上限も超えるため、この例の不適合は α の選び方に依存しない。既定の行で最大値を捉えられる対照例では通常検定で足りるが、内点最大の例では両形状とも部材の不適合を見逃す。是正では通常の長期検定で方向別の最大せん断力を算定し、部材の判定と結果表示に反映する必要がある。 [是正 Issue #1843](https://github.com/hrntsm/SEPIKA/issues/1843)・[現行の適用条件](../../docs/calc_basis/06_一次設計/02_04_RC柱のせん断検定.md#長期せん断の検定位置)

## 再現手順

基点は `1fa4e090d7ddc4f3f5951beb1e2dfc4369d42bca`。検証環境は Windows x86_64-pc-windows-msvc、Rust stable 1.100.0。モデルの配筋等は既存の[柱入力](../../crates/sepika-design-jp/tests/fixtures/rc_column_axial_boundary_model.rs)と[梁断面入力](../../crates/sepika-design-jp/tests/fixtures/rc_beam_asymmetric_model.rs)を使う。プローブに荷重条件、追加位置、独立釣合い、許容差（位置10⁻⁸ mm、せん断10⁻⁵ N、曲げ10⁻² N·mm）、対象柱全行の適否確認を保持した。 [再現プローブ](data/rc-column-long-term-shear/public_probe.rs)

PowerShellでリポジトリルートから実行する。検証時はデバッグ情報を生成しない設定（`CARGO_PROFILE_DEV_DEBUG=0`、`CARGO_PROFILE_TEST_DEBUG=0`）を使った。

```powershell
$root = (Get-Location).Path
$manifest = Join-Path $root 'Cargo.toml'
$target = Join-Path $root 'target/rc-column-long-term-shear'
$probe = Join-Path $root 'crates/sepika-job/tests/rc_column_long_term_shear_probe.rs'
if (Test-Path -LiteralPath $probe) { throw '既存のプローブ用ファイルがあります' }
Copy-Item -LiteralPath 'dev_docs/v_and_v/data/rc-column-long-term-shear/public_probe.rs' -Destination $probe
try {
    cargo +stable test --locked -p sepika-job --manifest-path $manifest --target-dir $target --test rc_column_long_term_shear_probe -- --nocapture
    if ($LASTEXITCODE -ne 0) { throw '再現プローブの実行に失敗しました' }
} finally {
    Remove-Item -LiteralPath $probe
}
```
