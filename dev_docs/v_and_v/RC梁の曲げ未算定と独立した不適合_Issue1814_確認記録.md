# RC梁の曲げ未算定と独立した不適合（#1814）

強軸曲げの適用条件を外れるRC矩形梁で、未算定理由と、既存の式で独立に確定する強軸せん断・付着・構造規定の不適合を同位置に保持することを確認した。 [Issue #1814](https://github.com/hrntsm/SEPIKA/issues/1814)

## 原典の確認範囲

日本建築学会『鉄筋コンクリート構造計算規準・同解説』2024年版の次の箇所を照合した。 [刊行版の書誌](https://ndlsearch.ndl.go.jp/books/R100000001-I25115036270)

| 参照箇所 | 確認した内容 |
| --- | --- |
| 第13条（pp.17–18） | 梁の許容曲げの検討。断面の条件と応力中心距離の略算が使える条件がある。 |
| 第15条 式(15.1)〜(15.9)（pp.19–22） | 許容せん断力のせん断スパン比を求める曲げモーメントは荷重による解析需要。式(15.7)の曲げ降伏に基づく需要は両端の曲げ降伏モーメントの和を用いる。式(15.9)は重力時と地震時のせん断力を用いる。 |
| 第16条 式(16.1)〜(16.4)（pp.25–26） | せん断力を引張筋の周長総和と応力中心距離で除す照査と、鉄筋の存在引張応力度を需要とする照査がある。 |
| 第15条2項(4) iii（p.22） | 梁のあばら筋間隔の上限は、梁せいの1/2と250 mmの小さいほう。 |

SEPIKAの既存の構造規定チェックは、min(D/2, 250 mm) の超過を警告とし、min(3D/4, 300 mm) の超過をNGとする。以下の構造規定NGは製品の判定を検証する。規準の間隔上限は前者に対応する。 [RC梁の構造規定](../../docs/calc_basis/06_一次設計/02_08_RC梁の構造規定.md)

2024年版の照合は各照査に必要な内力・断面量の確認に用いた。採用済みの1991／1999方式の係数・範囲を旧版原典と完全照合したものではない。既存のせん断・付着・構造規定の式を使用し、曲げの適用条件外で新たな有効せい・応力中心距離の仮定を置かない。QD1の両端の曲げ由来需要の計算方法そのものは別課題とする。 [せん断の採用式](../../docs/calc_basis/06_一次設計/02_02_RC梁のせん断検定.md)・[付着の採用式](../../docs/calc_basis/06_一次設計/02_07_RC梁の付着_定着検定.md)・[Issue #1851](https://github.com/hrntsm/SEPIKA/issues/1851)

## 独立計算と共通検定の照合

材長3000 mm、矩形250×350 mm、Fc24、SD345、上下のかぶり40 mm、数値径19 mmで上端3本×2段・下端3本×1段とした。上下の縁からの重心距離は上83.25 mm、下59.5 mm。通常検定で各位置に正曲げ45 kN·m、Qy 150 kNを与えると、重心距離の不一致で曲げは未算定になる。

数値径10 mmの2脚あばら筋を350 mm間隔とすると、正曲げ側の有効せい290.5 mm、応力中心距離254.1875 mm、せん断補強筋比0.001795196、せん断スパンによる割増係数1.967823878となる。長期許容せん断応力度0.73 N/mm²を使うと、補強筋項は0で、250 × 254.1875 × 1.967823878 × 0.73 = 91.285812 kN。短期・損傷制御は短期の許容せん断応力度1.095 N/mm²と補正2/3を使うため、この入力では同じ許容せん断力となる。付着1991の周長総和は3 × π × 19 = 179.070781 mmで、許容付着応力度は長期2.31 N/mm²、短期3.465 N/mm²である。

| 条件 | 独立に算定した需要と検定比 | 共通検定の観測結果 |
| --- | --- | --- |
| 長期 | Qy 150 kN。せん断 1.643190723、1991付着 1.426593895 | 両端・中央に2内訳のNGと曲げ未算定。各比は独立値との差1e-8未満 |
| 短期・地震時需要の指定なし | Qy 150 kN。せん断 1.643190723、1991付着 0.951062596 | せん断NGと曲げ未算定。付着の適合内訳は表示しない |
| 短期・QD2・QL = −20 kN | QD2 = 20 + 1.5 × abs(150 − (−20)) = 275 kN。せん断 3.012516326、1991付着 1.743614760 | 両端・中央に2内訳のNGと曲げ未算定。各比は独立値との差1e-8未満 |
| QD1またはminで有効な重力参照・Q0あり | 曲げ由来の需要が未確定 | 強軸せん断と1991付着を保留 |
| QD2で重力参照が別部材または別位置にのみ存在、またはQD1・minでQ0が欠落 | 需要の算定に必要な参照が不足 | 強軸せん断と1991付着を保留。曲げと参照欠落の理由を併記 |
| 構造規定 | あばら間隔350 mmが min(3D/4, 300 mm) = 262.5 mmを超過 | 上の各条件で部材中央に構造規定NG。エラー1件を表す表示用検定比1.01 |

対照は同じ断面にあばら間隔100 mm、正曲げ45 kN·m、Qy 20 kNを与えた。確定した項目にNGがなく、曲げ未算定の位置には未算定行のみ返る。曲げ需要0の端部に既存せん断の算定が残ることも確認した。 [通常の公開検定試験](../../crates/sepika-design-jp/tests/rc_beam_asymmetric.rs)

簡易検定では、あばら間隔100 mm、短期、中央、正曲げ300 kN·mを用いた。下端筋の引張応力度は1387.550272 N/mm²、横補強筋の換算長さは10.471976 mm、係数Kは1.299558、必要付着長さ3381.080997 mm、比較長さ1500 mm。1999付着の比2.254053998を、重力参照やQ0の欠落による未算定理由およびねじり診断と併記した。非有限の解析Mzまたは部材長から1999付着のNGを出さず、引張側主筋がない方向からせん断・付着NGを出さないことを確認した。単一結果の入口は未算定を返す。 [簡易検定試験](../../crates/sepika-design-jp/tests/rc_beam_asymmetric.rs)

## GUIと保存

片持ち梁モデルの実静的解析と通常検定から、同位置のせん断NG・未算定理由、検定比図の「未検定あり」と「NG 1件」、ホバー内訳にせん断が出ることを確認した。別の実静的解析から得た中央の構造規定NGおよび曲げ未算定理由をOVIKAに保存し、再読込した。検定版104では同じ解析成果を読み込み、再検定で版105の結果を復元することを確認した。 [検定比図の試験](../../crates/sepika-app/src/viewer/check_ratio.rs)・[OVIKAの試験](../../crates/sepika-app/src/app/rc_beam_asymmetric_tests.rs)

検証範囲は既存の危険断面位置、強軸方向と入力した荷重・配筋条件である。弱軸、全断面での包絡、曲げ適用条件の拡張および設計規準への全面的な適合は検証範囲外である。
