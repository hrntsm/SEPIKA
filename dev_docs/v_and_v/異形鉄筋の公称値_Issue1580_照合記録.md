# 異形鉄筋の公称値と公開検定の照合（#1580）

## 判定と対象

標準呼び名の異形鉄筋について、鉄筋の断面積・周長を呼び名の数値から円として計算すると、設計用の表値に対して大小どちらにもずれる。公開終局検定では、D19主筋による静的ヒンジせん断需要の過小評価と、D10あばら筋によるせん断耐力の過大評価を、それぞれ適否の境界をまたぐ条件で確認した。設計用の面積・周長を用途別に扱う是正は [#1584](https://github.com/hrntsm/SEPIKA/issues/1584) で追跡する。状態は🔶（有限Verification）。

調査は2026-11-20、初回調査基点 `9aae5acce393f2de06b4de60b1382f8ecfa45c30`、両端固定での最終実行基点 `5531605cc43afd905c758d4bb7bf4b4db0bc5f41`。発端の [#1580](https://github.com/hrntsm/SEPIKA/issues/1580) は `f91f398a` の [#1497の確認例](RC梁両端曲げ降伏時せん断力_Issue1497_確認記録.md) を参照する。本調査の基点には [#1507](https://github.com/hrntsm/SEPIKA/issues/1507) の反対側照査が入っている。現行の入力・計算・保存を変更せず、許容引張応力度の径区分 [#961](https://github.com/hrntsm/SEPIKA/issues/961) とST-Bridgeの呼び名保持 [#507](https://github.com/hrntsm/SEPIKA/issues/507) を別契約として扱う。

### 終局検定での差と適否

略算式は `M_u=0.9 a_t σ_y d`、有効せいと倍率1を固定した静的両端ヒンジは `Q_μ=2M_u/L`。D19の円面積283.528736986 mm²と公称286.5 mm²から、以下を得る。曲げ耐力は kN·m、せん断力は kN。確定総応答へのせん断入力は解析応答相当の固定値を与えた。

| 入力 | 公開観測のMu | 公称面積の独立Mu | 公開観測のQμ | 独立Qμ（他を固定） |
| --- | ---: | ---: | --- | ---: |
| 上2本・下4本、上端引張、QL=0 | 96.839240 | 97.854075 | 反対側の曲げ耐力が大きいため未算定 | 比較適用外 |
| 上2本・下4本、下端引張、QL=0 | 193.678480 | 195.708150 | 96.839240 | 97.854075 |
| 上下2本、静的ヒンジ、QL=560.400 | 96.839240 | 97.854075 | 48.419620 | 48.927038 |
| 上下2本、確定総応答 | 96.839240 | 97.854075 | 580.000000 | 580.000000 |

上端引張のMuが1.037%小さいことは単独の曲げ抵抗に対して安全側だが、対称梁のQμも同率で小さくなる。このケースでは現行のQsuを固定すると、(609.051678−560.400)/Qμ は現行 **1.004793（OK）**、D19面積のみ補正した比較 **0.994372（不足）** となる。付着は比較で無効とした。QL値は境界を分離するための入力で、当該断面の長期検定適合を示す値ではない。

D10あばら筋の方は、1脚の円面積78.539816340 mm²と公称71.33 mm²で `p_w` がそれぞれ0.00448799と0.00407600になる。上表の対称梁と同じ幾何で、製品の塑性理論式のトラス＋アーチを、`j=7d/8`、`νF_c=0.58×24`、`k=[2(√((L/D)²+1)+L/D)]⁻¹`、`t=min(p_w σ_wy, νF_c/2)` と置いて `2 b j t + k b D (νF_c−2t)` で独立計算した。`σ_wy=345`、`R_p=0`、普通コンクリートである。円面積の計算は公開Qsu **609.051678 kN** と一致し、公称面積では **563.466330 kN**（現行が8.090%過大）。確定総応答580 kNでは現行余裕 **1.050089（OK）**、独立比較 **0.971494（不足）**。上下のD19面積も変えてもこの固定Qμと同一幾何の塑性理論式Qsu自体は変わらない。両反転は同じ算定式・条件で単独の入力差を置き換えた比較であり、採用式の全条件の妥当性や別のせん断・付着方式の適否は未検証。 [塑性理論式の算定根拠](../../docs/calc_basis/08_部材終局耐力/02_01_RC梁_柱の終局せん断耐力_塑性理論式.md)

### 許容曲げ・応力・付着と剛性

同じ上下2本の断面に長期負曲げ30 kN·m、強軸せん断20 kNを与え、公開 `RcDesign.check` を実行した。`j=7d/8=481.25 mm`、`f_t=215`、`f_c=8`、`n=15`。引張側の曲げ比較は `a_t f_t j`。圧縮側は圧縮コンクリートの三角形応力分布と、圧縮鉄筋の重複分を控除した14倍・引張鉄筋15倍の換算力を釣り合わせる。中立軸 x を圧縮縁からの距離とし、`350 x²/2+14 a_c(x−59.5)+15 a_t(x−550)=0` を二分して得た x と断面二次モーメント `I_cr=350 x³/3+14 a_c(x−59.5)²+15 a_t(550−x)²` から `f_c I_cr/x` を得る。比較用引張応力度は `M/(a_t j)`、1991式の周長項は `τ=Q/(j Σφ)`、両長期付着検定比の分母は観測の `f_a=1.54 N/mm²`。

## 是正の優先順と確認を残す範囲

1. [#1584](https://github.com/hrntsm/SEPIKA/issues/1584) では、標準呼び名の識別を保持して計算へ渡す方針を先に確定し、RC梁の主筋面積、D10等を含む横補強筋面積、周長を一つの呼び名に対して用途ごとに解決する。終局の曲げ抵抗だけを補正すると静的ヒンジのせん断需要が残るため、同一断面で耐力・需要を追う。上記2例と過大側・過小側の呼び名、任意径、丸鋼、未解決の径、反対側未算定理由も回帰対象とする。
2. 面積差が伝播するRC柱・SRCのRC部分・面積比による細則・接合部・付着を追い、許容曲げ・軸、せん断、付着応力、降伏時剛性を各式の支配枝で確認する。数表を持たない任意径を使う条件、径の法令区分、ST-Bridgeの元表記、既存保存データの解釈は計算側の公称値と混同せずに決める。どの径が規準で呼び名の数値か、実際の幾何寸法が要る箇所かを確認し、先に一括変換しない。
3. 初期の外形性能やSRCの内蔵鉄骨寄与、数量の表による単位質量を、今回の面積・周長差だけで再定義する根拠は確認していない。標準呼び名の近傍にある任意径へ単位質量表を適用する扱いは、構造計算の是正と切り分けて [#1585](https://github.com/hrntsm/SEPIKA/issues/1585) で調査する。壁の比率入力による推定本数とRC/SRC初期剛性における鉄筋寄与の要否は各機能の前提から判断する。
