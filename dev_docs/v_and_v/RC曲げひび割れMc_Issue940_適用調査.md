# RC部材の曲げひび割れMcの適用調査（Issue #940）

## 結論と証拠の範囲

2026-10-27、基点 `7154b41d` の計算を変更せず、[#940](https://github.com/hrntsm/SEPIKA/issues/940)の対象を調査した。
**原典と異なることは確認したが、現行の省略を正当化する条件と設計上の採否は未確定であり、追加原典・外部判断を要する。**
原典式への全面置換、軸力条件の一律拒否、全曲げ耐力式の変更を必要とする証拠は今回確定していない。
現行動作を維持することを、設計への採用承認・安全側認定としない。状態は🔶。

- 原典の係数・根号・鉄筋考慮の定義・軸力項・数値適用域と、梁から柱への参照を原画像で確認した。
- 現行core、集中ばね、増分解析の記録閾値、ファイバーの役割をソースで追跡した。新しい製品関数の実行試験ではない。
- 追加した数値は独立算術による項別・単材骨格感度である。実要素、全体求解、GUI/MCP、時刻歴の実行結果ではない。
- 既存[#883の公開core試験](RC部材力学モデル_Issue883_原典照合.md#独立数値境界と要素証拠索引)はN=0・供給Ze同一に限る一致であり、鉄筋考慮・軸力依存や構造物Validationを確認したものではない。

現在の利用者向け式・制約は[非線形復元力特性](../../docs/calc_basis/08_部材終局耐力/04_RC_部材_非線形復元力特性.md#せん断スパンと総部材角)を正本とする。
梁αyの採用係数・適用域は#941の対象で、本調査では再判定しない。

## 原画像で確認した内容と残る原典

資料は『2025年版 建築物の構造関係技術基準解説書』第2版第1刷、付録1-3.1。
版の確認・公式正誤/Q&Aの照合は[#883の記録](RC部材力学モデル_Issue883_原典照合.md#対象と証拠の区別)を引き継ぎ、今回はp695・697・701の全頁画像を再確認した。
原画像・抽出本文はリポジトリへ転載しない。

| 頁・位置 | 確認した内容 | 未確認・解釈の限界 |
| --- | --- | --- |
| p695、冒頭 | 部材モデル化の一例。式の適用範囲・構造規定・導出背景を理解して用いる | 掲載式と違うという理由だけで現行を不具合とは確定できない |
| p697、(1)④a)、付1.3-1 | `Mc=0.56√σB Ze+ND/6` [N·mm]。σB [N/mm²]、Zeは鉄筋を考慮した断面係数 [mm³]、N [N]、D [mm]。適用域σB=18〜60、N/(bD)=0〜10 N/mm² | 当該頁に換算比、鉄筋領域の控除、非対称配筋の正負曲げ別Zeの具体算定は記されない。コンクリート幾何Zeへの置換やN項省略の許容条件も確認できない |
| 同p697、根拠・精度記述 | RC規準(2024)8条の解説を参照。1975〜2013年データによる、Fc<60・曲げ降伏先行はり494体で実験/計算平均1.18、変動係数0.36と記載 | 集計の平均・変動から個別の省略が安全側とは言えない。全試験の配筋・軸力別条件、現行解析との対応は未照合 |
| p701、(2)④a) | 柱のMcを梁と同様に算定してよい。前回の柱255体で実験/計算平均1.13、変動係数0.31、近年のFc18〜60の243体で平均1.16、変動係数0.33と記載 | 柱だからN項を省いてよいとの意味ではない。集計は実装Validationではない |

原典のσBと入力Fcを同値に置く条件も、実測強度・設計基準強度の使い分けを含めて残る。
N=0でも一致には**供給Zeが同一**であることが必要で、幾何Zeが鉄筋考慮Zeと等しいとは証明していない。
無筋との数学的一致を配筋のあるRCへの省略根拠にせず、鉄筋寄与を無視できるという判断には別の根拠が要る。
引張N<0は上記数値適用域外であり、符号付きND/6を形式的に追加することを解決策としない。

## 現行の実利用経路（ソース確認）

| 入口・部材/役割 | Mcへの入力と調整 | 下流と解釈 |
| --- | --- | --- |
| core `rc_capacity::rc_crack_moment` | `0.56√Fc×供給Ze`。N・配筋入力なし、ここでのclampなし | 呼出側が同じZeを渡す場合に限ってN=0項と一致。関数の存在は鉄筋換算の実施を意味しない |
| element `factory/springs.rs::rc_reference_crack_moment`、矩形RC梁の基準骨格 | 形状b・DからbD²/6。N項なし、Mcのclampなし。`rc_reference_issue`はMc<My、Rc<Ry等を診断 | `build_flexural_springs`が武田型・逆行型・最大点指向型のひび割れ点へ渡す。`factory/mod.rs::build_nonlinear_behavior`で実集中ばねを生成。ここでのMc変更は折れ点・第2勾配と追加端ばね接続へ及ぶ |
| 同`crack_moment`、上記矩形梁基準以外のRC系集中ばね（柱を含む） | 保存断面のmax(Iz,Iy)/(max(depth,width)/2)、N項なし。0.1My〜0.9Myへclamp。入力が使えない場合はMy/3 | 同じraw Mcでも矩形梁基準とは採用値が異なり得る。柱の判定は`is_column_member`、矩形梁基準の判定は`uses_rc_alpha_reference`。断面名だけでは経路を特定できない |
| `build_flexural_springs`の二折線等 | 二折線・辻山田型・鋼座屈の分岐はMc算定前にreturn。原点指向型の折れ点にもMcはない | 関数を呼ぶ全履歴則が同じMc折れ点を使うとはしない。M–N相関付きの降伏耐力調整をMcのND/6考慮と混同しない |
| solver `nonlinear/pushover/hinge.rs::member_moment_thresholds`、梁・矩形/円形柱等の記録用 | `section_elastic_modulus`は保存断面のmax(Iz,Iy)/(max(depth,width)/2)。Mc=min(raw Mc,My)。N項なし | `step_record`が準備時に閾値を作り、確定ステップの端部曲げを`track_hinges`で判定する。イベント分類用であり、その値を要素の接線剛性へ設定する経路ではない |
| element `frame/fiber`、ファイバー系の実応答 | 当該Mc helperによる明示折れ点は設定しない。断面の材料応力を積分する経路 | 曲げ・軸変形連成とコンクリート引張構成則の応答と、上記記録用Crackイベントは別。イベントの式だけの変更をファイバーの剛性是正としない |

増分`nonlinear/pushover/driver.rs`と非線形時刻歴`dynamic/timehistory/nonlinear.rs`は共に`build_nonlinear_behavior`を呼ぶ。
したがって集中ばね骨格の変更は両解析への接続を持つが、今回その影響量を実求解していない。
自動選択は`factory/regime.rs::resolve_force_regime`で剛床所属の非柱を集中ばね、それ以外をファイバーにする。
柱は断面用途`FrameSectionUse::Column`で判定し、明示した応力評価方式による上書きもあるため、柱の実応答すべてが上記clampを通るわけではない。
ファイバー側は`frame/fiber/mod.rs::concrete_fiber_material`で引張強度2.0 N/mm²を渡し、材料実装は`sepika-material/src/uniaxial/concrete_cyclic.rs::tension_envelope`等に別途存在する。
その引張強度・離散化・履歴の妥当性をp697のMc一致で保証しない。
保存断面性能への補正がある場合も、上記max選択を鉄筋考慮Zeの生成とみなさない。

## 独立算術と結果影響の限界

[Decimal60スクリプト](data/issue940/independent_decimal.py)・[出力](data/issue940/independent_decimal.log)はPython標準ライブラリのみを用いる。
再現コマンドは `python dev_docs/v_and_v/data/issue940/independent_decimal.py`。
生産関数や既存テストの出力を期待値生成に呼ばず、原典項と固定した三折線を計算する。

Fc=25 N/mm²、b=300、D=600 mmとし、幾何Ze=18,000,000 mm³ならN=0項は50,400,000 N·mm。
N=600,000 NのND/6は60,000,000 N·mm、軸応力は3.333… N/mm²で、上記原典の数値域内にある。
供給Ze=21,600,000 mm³は**20%感度用の仮定入力**で、特定配筋から換算した値ではなく、原典に適合する断面を立証しない。

固定条件My=300,000,000 N·mm、K0=30,000,000,000 N·mm/rad、αy=0.3、
Ry=My/(αyK0)、Rc=Mc/K0、K2=(My−Mc)/(Ry−Rc)の単材骨格を比較する。
このαyは感度計算の指定値であり、現行αy式の根拠・適用域を評価していない。

| 比較条件 | Mc [10⁶ N·mm] | Rc [rad] | K2 [10⁹ N·mm/rad] | R=.005のM [10⁶ N·mm] | M=80×10⁶ N·mmのR [rad] |
| --- | ---: | ---: | ---: | ---: | ---: |
| 幾何Ze、N=0 | 50.40 | .001680 | 7.885425 | 76.579612 | .005433761 |
| 仮定供給Ze、N=0 | 60.48 | .002016 | 7.648161 | 83.302112 | .004568248 |
| 幾何Ze固定、圧縮N=600 kN | 110.40 | .003680 | 6.393885 | 118.839928 | .002666667 |
| 仮定供給Ze、圧縮N=600 kN | 120.48 | .004016 | 6.123340 | 126.505367 | .002666667 |

同じ初期剛性・降伏点を固定しても、Mc変更はひび割れ角だけでなく区間勾配・指定角の抵抗・指定Mの角を変える。
後2条件のM=80×10⁶はひび割れ前なので同じ弾性角となる。
幾何Ze固定・圧縮時にND/6を省くと比較式よりMcは小さいが、それだけから架構の応力再分配・層間変形・Qu・Dsが安全側とは判定できない。
鉄筋考慮Zeと幾何Zeの大小も、非対称配筋・曲げ方向を確定せず一律には断定しない。

別途clampの算術は、raw Mc=50.4×10⁶ N·mmに対して一般集中ばねはMy=40×10⁶なら36×10⁶、
My=600×10⁶なら60×10⁶となり、記録閾値はMy=40×10⁶なら40×10⁶となる。
これは上記コードの式を独立代入した値であり、実要素へその入力を通した観測ではない。
実際の剛性・変形・部材応力の差の量、非線形履歴、全体耐力、正負曲げ・二軸・変動軸力への一般化は未確認。

## 採否判断と再判定に必要なもの

調査としては原典との相違・実利用・安全性の未確定を記録した。**計算是正の要否は保留**し、別式の存在だけで後続修正Issueを作らない。
原典式を設計へ採用する判断、又は現行省略を正当化する判断には次の証拠が必要である。

1. RC規準(2024)8条の関連解説本文で、鉄筋考慮Zeの具体算定、軸力の符号と扱う時点、梁・柱・正負曲げの条件を確認する。
2. 現行のコンクリート幾何Ze・軸力項なし・用途別clampを支持する資料又は設計者の適用判断を得る。指定版の当該頁だけからその根拠は得られない。
3. 対象を決めた上で、実配筋・実材料・軸力条件・初期剛性とMcの整合を確認し、集中ばねの折れ点/受動接続と記録閾値を区別して実要素・実解析で影響を評価する。

この過程で具体的な危険側結果又は採用条件への不適合が確定した場合だけ、その経路・入力・期待結果を限定した是正又は適用制限を後続Issueにする。
追加原典や外部判断がない現状では、省略を全域承認することも、根拠未確定の軸力項・換算断面を新たに導入することもしない。
