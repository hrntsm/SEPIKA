# 複数剛床とシェル床の二次元質点系層剛性（Issue #1701）

[Issue #1701](https://github.com/hrntsm/SEPIKA/issues/1701) の照合。状態🔶。複数剛床とシェル床の四柱例で、ねじれにより加力方向の層間変位が相殺された柱の比を足し合わせると、二次元線形せん断型の層剛性は独立な一様並進の剛性を大きく上回った。公開入口は両床条件で診断を出さずに質点系を生成した。

## 入力と独立対照

[#1683 の四柱架構](複数剛床と床面内変形による柱の層間変位相殺_Issue1683_照合記録.md#架構と拘束)を共用した。3,000 mmの1層に柱A・B・C・Dを配置し、柱脚を全固定、柱頭を鉛直方向と水平軸回りで拘束する。柱頭の床は独立なA–C・B–Dの2剛床、又は全柱を結ぶ四節点シェル1枚とした。解析方向はXで、水平の局所軸が全体軸と異なるC・DのX柱頭力には、X変位とY変位の両方が寄与する。

比較用の階動的質量は、同じ柱頭座標の四柱架構の別コピーに、地震用積載荷重として各柱頭へ鉛直下向き9,806.65 Nを与え、公開の準備計算で求めた。材料密度は0で、比較用の質量は四点の各1 t、計4 t。静的解析の床条件を保つため、準備で新設された剛床・代表節点や荷重ケースは移さず、上階の動的質量だけを試験モデルの明示入力として渡した。元の静的モデルの各柱頭の節点質量は1 tで、比較用質点の質量はその合計と一致する。標準のAi地震荷重を用いた検証は含まない。

[独立一様変位反力](複数剛床と床面内変形による柱の層間変位相殺_Issue1683_照合記録.md#一様変位の独立解析と荷重対照)は、全柱頭が共通にX方向に0.25 mm動き、Y方向の変位と柱頭の回転が0となる境界で求めた。この状態ではシェルにひずみが生じず、2剛床の拘束とも両立する。各主軸方向の柱頭水平柔度を曲げ・せん断のひずみエネルギーから求め、力を全体座標へ回す。合計反力955.351193 Nを0.25 mmで除した層の並進剛性は3,821.404771 N/mm。反力と剛性の算出に製品の力・変位・柱剛性を用いていない。4 tを同じ並進自由度に集約した周期は `2π√(4/K)` で求めた。一様並進を拘束条件とする1自由度の比較値であり、各床の空間運動やシェルの面内変形を許す立体架構の固有周期は含まない。

手入力の地震荷重ケースを、公開の線形静的解析に渡した。無ねじれのX対照は、上記の独立反力の水平成分を各柱頭に与える。ねじれ時はX対照へAの＋XとCの−Xの偶力を加え、層のX・Y合力を保つ。各床条件で単位偶力を別に解き、CのX層間変位が無ねじれ対照の1/1,000となるように偶力を決めた。対照とねじれの各荷重の全成分を1/1,000とする比例縮小も別々に解いた。ねじれを起こす偶力の調整には解析応答を使い、上記の独立剛性・周期の算出には使わない。

同じ重量を配置して元の各床モデルを通常の準備計算に渡す補助試行では、シェル床に上階の剛床が自動で1組付加された。複数剛床の例では柱頭A・Bが剛床の代表節点を兼ねており、重量と物理質量を各剛床へ一意に帰属できないという注意が出て、上階の動的質量は未算定となった。この重量準備の条件は [#1706](https://github.com/hrntsm/SEPIKA/issues/1706) で追跡する。

独立並進対照の1自由度周期は0.203281728 sで、両床の無ねじれ対照と比例小荷重の生成値が一致した。ねじれ時は、無ねじれ対照に比べて層ばねが2剛床で約5.85倍、シェル床で約16.60倍となり、質点系の周期はそれぞれ約41%・25%となった。全ケースで層Yせん断力は丸め誤差内の0だった。

ねじれでは、CのX層間変位が比例小荷重と同じでも、CのY変位によるX力が残る。剛性差の大部分は、CのX負担力を相殺後の小さなX変位で除した柱比が増えたことによる。絶対値を使うため、この大きな柱比が他柱の比と符号で相殺されることもない。純並進と相殺を含む載荷は、ともに全荷重を比例縮小しても剛性がほぼ同じだった。小変位の絶対値や同一の荷重分布の比例縮小だけでは区別できない。

コード上、二次元線形せん断型は方向別の柱比を合計する。三次元質点系の方向間連成の適用確認はこの経路にかからない。単一剛床の回転から変位相殺を診断する既存の [#1680 の修正](ねじれで柱の層間変位が相殺される場合の偏心率_Issue1595_照合記録.md#1680-の修正後の照合)と、連成候補と床条件から偏心率を保留した [#1683 の結果](複数剛床と床面内変形による柱の層間変位相殺_Issue1683_照合記録.md#公開評価と設計採用条件)は、今回の公開生成結果と別の経路である。

## 適用判断と後続条件

- この四柱例では、同方向の柱の変位と負担力が対応する無ねじれ対照に限り、「柱 ki」の層ばねが並進剛性と一致した。本例の一致を一般の無ねじれ架構に広げるには、壁・ブレース等を含む全抵抗要素と縮約に採る運動の整合を確認する必要がある。
- ねじれ時の層ばねは、同じ架構・合力でX方向の共通並進を表す層剛性として採用できない。周期が短くなったことから地震時の応答量の増減や安全側・危険側は決まらない。波形、減衰、立体モード、加力の分布による影響を別途評価する。
- 適用判断には、対象層・方向・柱、符号付きの両方向変位差と柱の負担力、剛床ごとの回転又は床の面内変形、他の自由度から力への寄与を照合する。対応を確認できない場合は、数値を採用せず、評価したい並進に対応する拘束と反力を明示した再解析、又は床ごとの運動・面内変形を保持する立体解析で必要な応答を求める。層せん断力と代表変位の比へ切り替える場合も、代表変位・荷重分布・抵抗要素が評価目的と対応することを確かめる。
- この反例で診断付きの生成保留を自動化するには製品変更が必要。少なくとも、床条件と柱の方向間連成を考慮し、比例小荷重を区別して適用条件が確認できないケースを階・方向・柱と理由付きで保留する条件を検証する。絶対変位や試験で使った1/1,000を判定閾値に転用する根拠はない。製品での診断付き保留は [#1705](https://github.com/hrntsm/SEPIKA/issues/1705) で追跡する。

## 再現

[質点系の統合試験](../../crates/sepika-job/tests/planar_column_ki_torsional_cancellation.rs)は、[四柱模型](../../crates/sepika-design-jp/tests/fixtures/multi_floor_torsional_cancellation_model.rs)と[独立反力](../../crates/sepika-design-jp/tests/fixtures/multi_floor_torsional_cancellation_reference.rs)を [#1683 の統合試験](../../crates/sepika-design-jp/tests/multi_floor_torsional_cancellation.rs)と共用する。試験で使う数値誤差と観測差の下限は、この入力に対する再現条件である。

```bash
cargo test --locked -p sepika-job --test planar_column_ki_torsional_cancellation -- --nocapture
cargo test --locked -p sepika-design-jp --test multi_floor_torsional_cancellation -- --nocapture --test-threads=1
```

基点 `4ebf5992` に本差分を適用し、WindowsのRust 1.100.0で `cargo test --locked -p sepika-job` の246件、`cargo test --locked -p sepika-design-jp` の950件が成功した。stable更新確認後の両クレートの全ターゲットClippy（`--locked -- -D warnings`）、`cargo fmt --all -- --check`、`cargo run --locked -p xtask -- check-docs`、`mdbook build docs`、変更文書のローカルリンク・見出し、`git diff --check` も成功した。Cargoは既存のワークスペース依存宣言 `schemars` の未使用警告を出した。

[#1705](https://github.com/hrntsm/SEPIKA/issues/1705) の修正後は、質点系の統合試験を表と同じ荷重で実行し、無ねじれ対照とその比例小荷重の層ばね・周期は独立値と一致し、ねじれ荷重とその比例小荷重は対象層・方向・柱を示して保留することを確認した。X・Yの一様並進を重ねた荷重も、X方向の層間変位が全柱で一致する一方、直交方向に層間変位があることを示して保留した。上表のねじれ時の層ばね・周期は #1701 の照合時の記録である。

## 未確認の範囲

各床1例、1層、X方向の線形せん断型と手入力地震荷重に限る。立体の固有値・モード・有効質量、地震波を使った時刻歴応答、実建物のAi地震荷重、GUIの準備から解析までの操作、複数層・複数床構成、床物性やメッシュの感度、壁・ブレースその他の抵抗要素、非線形、実験Validationは未確認。これらの検証は、[未検証一覧](未検証一覧.md#ねじれで柱の層間変位が相殺される場合の偏心率1595)を参照する。
