## 対象と記録時点

対象Issueは[#618](https://github.com/hrntsm/SEPIKA/issues/618)。基点はmain `ed0e7124`、実装対象SHAは `705c215704a9e82169454051dd27b58ea2d6bc68`。
2026-10-25、Windows・stable Rust 1.99.1 / Clippy 0.1.99で実行した有限例のVerificationである。
採用式・適用条件の正本は[梁の剛性計算上の付加](../../docs/calc_basis/04_要素剛性/01_ティモシェンコ梁要素.md#剛性計算上の付加協力幅壁エレメント上下梁雑壁)。

## 公開入口と不変条件

結合fixtureはFL=0、ΔSL=-300 mm、梁偏心0、D600 mm、梁節点Z=-300 mm、床偏心0で、
左右床板上面0、下面-150/-200 mmを公開配置解決で照合する。
中心線間距離1300/2300 mm、梁幅はいずれも300 mm、元構造スパン10000 mmである。
床板割当領域の支持部材に全長を割り当て、`stiffness_breakdown` と `BeamElement::try_new` を通す。
床領域の床板参照と割当領域の同一床板を二重算入しない。

公開算定前後のモデル全体をbincodeで比較し、ID・支持・元断面・厚さ・配置・重量/数量設定を含む入力が変化しないことを確認する。
同じ実断面で床板協力だけを除いた梁との比較で、EA用面積・弱軸I・GAs用面積・J・材長・質量特性・節点・端条件の完全一致を確認する。
供給強軸Iを2倍した場合も供給値へ同じ倍率が乗る契約を確認する。
設計自重・数量モジュールは変更していない。初回の要素検証では重量・数量入口の独立再実行は行っておらず、
同一入力の完全一致と梁質量等の不変性による確認に限定する。厚さを変更した別モデルの重量・数量不変性は要求しない。

旧RC床fixtureは実配置・支持割当を持たず、床領域外周から最大厚を拾う期待だった。
本変更では実支持と全長条件を証明するfixtureへ置き換え、集中ばねfixtureにも明示配置・支持割当を与えた。
部分区間や未解決支持を外周の代表厚で補完する契約は維持しない。
解析契約版を52から53へ更新したため、52以前の保存解析成果は再解析を必要とする。

## App feature CIで判明した既存fixtureの追随

PR #813の初回CI（run `40171675588`）はApp GUI構成で927成功/4失敗、workspace構成ではApp412成功/1失敗だった。
追加の失敗は、重量・荷重・表示の既存fixtureが、今回明示した矩形RC梁の床板協力剛性の配置/支持条件を満たしていなかったことによる。
剛性実装の診断を緩和せず、次のように観測契約を整理した。

| 試験 | 維持する観測と追随理由 |
| --- | --- |
| `girder_overlap_independent_values_reach_preparation_dl_and_seismic_weight` | 全ケースで直接の大梁重量・DL自己重量・階生成重量の独立期待を維持。上端一致ケースは準備成功後の床込みDL合計/地震重量/CSVも維持。段差・床偏心ケースは床板IDと梁ID付きの上端不一致診断を期待し、準備成功後の集計は検証しない。左右異厚・上端一致で大梁重量30240 Nの独立fixtureも追加。 |
| `girder_overlap_edits_undo_redo_and_save_reload_update_weights_and_invalidate_results` | 偏心・厚さ・密度・版なし・節点編集後の重量期待、Undo/Redo、保存再読込、入力/成果失効を維持。段差と一定幅にならない節点変更では準備の配置診断を期待。上端一致/版なしのケースは準備重量行も検証。 |
| `test_secondary_beam_subdivided_slab_dl_cmq_and_rc_scope_diagnostic` | 小梁で細分された床板のDL保存、大梁中間集中荷重の位置4000 mm、正の反力、非接続支持節点へ荷重を残さない契約を維持。床板が矩形RC大梁の一部だけに取り付くため、線形解析入口では対象梁・床板・全長取付き条件の診断と成功成果を公開しないことを検証。 |
| `rc_reference_cache_tracks_property_basis_and_slab_diagnostics_while_stale` | 支持部材で閉じた割当領域とFL350/ΔSL-350 mm、梁/床偏心0を与え、上端一致の実床板から既存のスラブ引張筋/骨格未対応診断へ進める。未解決支持の診断で元のキャッシュ観測を代用しない。 |

線形静的解析の成功・成果保存は既存の `test_run_linear_static_applies_auto_rigid_zones` と
`test_async_linear_static_job_flow` に引き続き対応付ける。部分取付きRC床板fixtureの解析成功を保証したとは扱わない。
これはIssue本文の段差・部分span対象外条件への追随であり、診断回避のための材種変更・断面種変更・荷重削除はしていない。
本追補は重量・荷重入口の既存独立期待を再実行するが、数量入口の独立実行を追加したものではない。

追加した重量の独立期待は、梁幅400/せい700 mm、材長6000 mm、左右床厚150/200 mm、
単位体積重量24e-6 N/mm³について、左右半幅の重複断面積70000 mm²を梁断面積280000 mm²から控除し、
`(280000 - 70000) × 6000 × 24e-6 = 30240 N` とした。
