# RC柱QD1で用いる大梁の曲げ軸（Issue #1907）

従来の梁降伏候補では、柱の検討曲げ軸と梁の実強軸が一致しない場合も、同じ強軸降伏曲げを柱端に代入する例を確認した。新たに需要の低減を認めた [PR #1908](https://github.com/hrntsm/SEPIKA/pull/1908) の候補とは適用条件が異なる。従来候補にも検討曲げ軸と力の伝達の確認が必要である。本件では製品算定を変更しない。

## 原典照合

日本建築学会『鉄筋コンクリート構造計算規準・同解説』2024年版、本文p.22の(15.8)式、解説pp.179–181を確認した。曲げ降伏時の柱せん断力は柱頭・柱脚の降伏曲げの絶対値の和を柱内法高さで除すのが原則で、本文では一般階で柱頭に接続する梁の降伏曲げ和の1/2、最上階でその全量が柱頭自身より小さければ置換できる。長期荷重によるせん断力が無視できない場合は別に加える。

解説図15.9(a)は両端柱降伏、(b)は柱脚の柱降伏と柱頭の左右梁端降伏を一つの構面内で示す。図(b)に示す左右梁の上端引張・下端引張を逆にした二組のうち、大きい方のせん断を採る。図(b)を上下反転した候補は小さい場合に採用できる。図中の \\(Q_{D1}\\) と \\(Q_{D2}\\) は(a)(b)の区別で、製品の算定選択「QD1」「QD2」の区別ではない。解15.14式の梁の降伏曲げは、検討する曲げに対する引張主筋量と有効せいに依存する。p.180では、降伏曲げをラーメン節点でなく部材端部で算定し、その間を内法とする。

同解説の二軸せん断（pp.180–181）は、水平力の方向と構面・柱断面の方向が異なる場合に曲げとせん断の二軸相関が必要であるとする。(解15.17)式は柱せん断の二軸相関であり、斜交梁の強軸曲げ和を柱の一方向に割り当てる式ではない。図15.9を立体架構に拡張して単純投影で梁降伏を算定する根拠は、照合した条文・解説にはない。

## 検討曲げと節点に伝わるモーメント

鉛直柱の全体X方向せん断に対応する曲げは全体Y回りである。梁の局所xを実材軸、局所yを断面参照方向の直交成分、局所zを右手系で定める。以下の矩形梁では局所z回りを強軸曲げ、局所y回りを弱軸曲げとする。[解析の局所系](../../crates/sepika-element/src/transform.rs)

| 対照の梁 | Y回り成分の係数の絶対値（ねじり、弱軸曲げ、強軸曲げ） | 検討曲げとの関係 |
| --- | --- | --- |
| 水平X・標準断面 | (0, 0, 1) | 強軸曲げがそのまま対応する。 |
| 水平X・断面を90°回転 | (0, 1, 0) | 強軸曲げは全体Z回りになり、Y回りの抵抗は弱軸曲げに依存する。強軸Myでは決まらない。 |
| 水平・XYで4:3に斜交 | (0.6, 0, 0.8) | 強軸曲げだけでなく、梁の材軸ねじりもY回り成分を持ち得る。 |
| XZ内で4:3に傾斜・標準断面 | (0, 0, 1) | 同一鉛直面内なら傾斜だけでは強軸の対応は失われない。接合・支持等の確認は別に必要。 |

係数は節点差を標準、回転、斜交、傾斜の順に \\((4,0,0),(4,0,0),(4,3,0),(4,0,3)\\) m とし、強軸ベクトルを外積から求めたもの。例えば平面斜交では局所xが \\((4,3,0)/5\\)、局所yが全体Z、局所zは \\((3,-4,0)/5\\) となる。一般の立体配置では3成分がいずれも寄与し得る。係数は既知の断面力を変換するものであり、各成分の同時降伏・到達可能な力や上下柱分担を表さない。

梁フェースの断面力を節点に移す際、回転させた断面モーメントに加えて、節点からフェースへの位置差 \\(\mathbf r\\) と全体座標の力 \\(\mathbf F\\) による \\(\mathbf r\times\mathbf F\\) が作用する。剛域による腕と材端偏心を単なる断面軸の回転と混同しない。例えばピンでフェースの曲げが解放されていても、長さ100 mmの剛域が約6.176 kNのせん断を伝えると節点回りに約0.618 kN·mを生じる。軸力10.350 kNと鉛直偏心200 mmの例は、フェース曲げ0でも節点のY回りに2.070 kN·mを生じる。[弾性要素応答の既存試験](../../crates/sepika-design-jp/tests/rc_column_mechanism.rs)

## 現行需要の対照

一般階の対照は[既存の独立断面計算](RC柱QD1の崩壊メカニズム_Issue1817_検証.md#独立計算)と同じ400×600 mmのRC柱、内法1,500 mm、Fc24、SD345、両端圧縮100 kN、参照せん断0の条件。柱端の強軸Myは3本配筋で170.336243 kN·m、4本で217.288602 kN·m。柱頭梁は左右2本で、各梁の上下主筋は各2本。梁和は190.333125 kN·m、柱脚梁の和の1/2は190.333125 kN·mとなるが、この比較では最小候補にならない。実強軸と柱曲げ軸がそろう側の柱頭大梁は変更せず、もう一方だけを表のように変更した。

| 柱頭梁の対照 | 4本配筋・未係数梁和でも置換できる従来候補のQD1 (kN) | 3本配筋・1/2を掛けた後にだけ置換できる #1908 の候補のQD1 (kN) |
| --- | ---: | ---: |
| 水平X・標準断面 | 208.303443 | 177.001870 |
| 水平X・断面90°回転 | 208.303443 | 227.114991 |
| 水平X・退化参照方向に対する解析基底の代替で強軸不一致 | 208.303443 | 227.114991 |
| 水平・XYで4:3に斜交 | 208.303443 | 227.114991 |
| XZ内で4:3に傾斜・標準断面 | 208.303443 | 177.001870 |
| 節点間は水平X、遠端偏心で実材軸のみXYで4:3に斜交 | 289.718136 | 227.114991 |

標準断面の従来候補は \\((217.288602+190.333125/2)/1.5=208.303443\\) kN、新候補は \\((170.336243+190.333125/2)/1.5=177.001870\\) kN。両端柱降伏の対照は4本で289.718136 kN、3本で227.114991 kN。遠端偏心では接続梁の不確かさを処理する既存条件で両端柱降伏となる。これと、偏心なしでも断面参照方向から解析の実強軸が不一致になるケースを区別する。平面斜交の4:3はXへ割り当てられ、斜交した梁の強軸降伏曲げの全量が比較に残る。

最上階の柱頭にX方向梁1本（95.166562 kN·m）が接続する別の対照では、柱端170.336243 kN·mとの和から177.001870 kNとなり、梁を90°回転しても変わらない。上階柱が柱頭節点に直接続かず、柱頭梁の和が柱Myより大きい柱脚候補の対照では、柱脚梁の和95.166562 kN·mの1/2と柱頭Myから145.279683 kNとなり、片方の柱脚梁の90°回転で変わらない。一般階の上下反転候補は別で、水平共線・支持・断面軸等を確かめる [#1908 の適用範囲](../adr/0151-rc-column-qd1-mechanism-comparison.md) があり、回転断面を除く対照も確認した。

Issueの300 kN·m、4 m、梁和200 kN·mの例は、常時せん断が無視できるとき \\((300+200/2)/4=100\\) kN と \\((300+300)/4=150\\) kN の式の比較である。上の208.303443 kNと289.718136 kNの差も候補選択の差で、いずれも立体架構で実際に伝達する曲げの推定値、適否の反転または安全側・危険側の判定ではない。

## 通常検定と時刻歴簡易検定

| 経路 | 必要条件と照合範囲 |
| --- | --- |
| 短期地震時の通常検定 | 通常の短期組合せと対応する重力参照の両柱端軸力、検定位置のせん断力の参照および内法が必要。検討曲げ軸・配筋・相手端の支持等を同じモデルの力の伝達と照合する。上表と最上階柱頭のQyは公開検定のせん断比を独立許容値270.029514 kNで比較。連続なしの柱脚のQyは通常検定の方向別の機構算定入口で確認した。 |
| 時刻歴簡易検定 | 同じ機構算定に、重力参照と検定対象スナップショットの両端軸力を同じ端順で渡す。一般の立体架構で別時刻の方向別ピークを集めて同時の降伏や釣合いとみなせない。上表と最上階・連続なしの対照はアプリが呼ぶ方向別の共通入口で両端の軸力を与えて比較。応答全履歴の解析やGUIの通し検証はしていない。 |

[検証コード](../../crates/sepika-design-jp/tests/rc_column_mechanism.rs) と [時刻歴簡易検定の呼出箇所](../../crates/sepika-app/src/viewer/th_detail.rs) を参照。両経路の判定前には計算対象の方向に対する確認が必要であり、直交材のねじりや偏心力を含む伝達を「梁端強軸の降伏曲げ和」と置き換えることはできない。

## 修正の要否と未確認範囲

修正が必要なのは、一般階の従来柱頭・最上階柱頭・上階の連続を確認できない場合に残る従来柱脚等で、片端梁降伏に使う耐力が柱の検討曲げに対応することを確認せず、需要低減を採る点である。まず従来候補にも軸・伝達の適用判定を置き、確認できない候補を無条件に採用しない方針を検討する。両端柱降伏を照合可能な候補として使うか、理由を伴って未算定とするかは、立体の条件と検定経路を区別して決める。単純投影の導入も、両端柱降伏を一般の立体条件の上限とみなすことも、今回の証拠からは決めない。

従来候補の適用条件と是正は [#1970](https://github.com/hrntsm/SEPIKA/issues/1970) で追跡する。上階連続区分と従来脚自体の根拠は [#1904](https://github.com/hrntsm/SEPIKA/issues/1904)、常時せん断の算入は [#1905](https://github.com/hrntsm/SEPIKA/issues/1905)、床板筋の寄与は [#1906](https://github.com/hrntsm/SEPIKA/issues/1906)、柱側梁端の接合条件は [#1839](https://github.com/hrntsm/SEPIKA/issues/1839) の範囲と区別する。曲げ・ねじりの降伏相関、実際の立体架構の応答、判定の反転、実験による妥当性確認は未検証。
