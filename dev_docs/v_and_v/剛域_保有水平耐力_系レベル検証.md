# 剛域が曲げヒンジの形成荷重・崩壊機構に与える影響の検証

作成日: 2026-07-25

## 対象

`FiberBeam`（ファイバー要素・MS 要素）への[剛域導入](../../docs/nonlinear/04_非線形梁要素のモデル化.md)が、
門形架構の曲げヒンジ形成荷重、機構判定、層弾性剛性に与える影響を確認する。
理想化した柱端集中ばねの別模型で、4柱端が降伏したときのせん断力の絶対値も確認する。
Ds に関する当初の検証経緯と現在の扱いは [#871 の確認記録](Ds条件不足の保留_Issue871_確認記録.md) を参照する。

## 参照解の出典

日本建築学会『鋼構造塑性設計指針』第4版（2026年）§2.2–2.3 pp.12–13 は、
塑性崩壊に釣合条件・機構条件・塑性条件が必要で、仮想仕事による機構候補の荷重は上界になることを示す。
§2.5.1 pp.18–20 の図C2.5.1(c)、式(C2.5.1.b) では、柱4材端に等しい全塑性モーメントを置いた
層機構の水平荷重を導いている。原典の例題の層機構候補は、梁中央の鉛直荷重により梁中央断面が塑性条件を満たさない。
以下の模型は鉛直荷重を与えず、梁を強くした条件でこの層機構を用いる。
日本建築学会『建築耐震設計における保有耐力と変形性能』（1981年）鋼構造 §2.4.3 pp.86–87 も、
仮想仕事法では実際と異なる機構を選ぶと耐力を過大評価しうるため、成立しうる機構のうち最小荷重を採ると説明する。

剛域を持つ比較模型では、柱の可撓長 \(L'=H-\lambda_i-\lambda_j\) に対し、
両柱が逆曲率で曲がり、4柱端の曲げモーメントの絶対値がすべて \(M\) に等しいとき、水平せん断力の和は \(4M/L'\) となる。
剛域の有無で同じ閾値に達する荷重の比は \(H/L'\) である。
柱の弾性層せん断剛性の参照は \(12EI/L'^3\)（節点変位基準）。

## 許容差

- 柱4材端が降伏したときのせん断力の比（剛域あり／なし）は、理論値 \(H/L' = 1.25\) に対し **±5%**
  （荷重ステップの量子化で数 % のばらつきが出る。ファイバー断面の離散化誤差は比を取ることで相殺される）
- 層弾性剛性の比: 理論値 \((H/L')^3 = 1.953\) に対し **±5%**
  （せん断変形・はりの弾性変形の寄与ぶん）

## 柱4材端の形成荷重を独立に照合する模型

#1160 の `test_portal_frame_collapse_load` は剛域なしの強梁模型を用い、柱を幅・せい各100 mmの中実矩形、
降伏応力度50 N/mm²（材料強度係数1.0）、曲げ一成分の材端集中ばねとする。
柱脚は固定、柱の高さは3,000 mm、梁のスパンは5,000 mm。
鉛直荷重は与えず、X方向に荷重制御で載荷してから頂部変位100 mmを目標に変位制御する（80ステップ設定）。

参照解では変形前の形状で釣り合わせ、柱端に軸力とせん断力から独立した完全弾塑性の
回転ヒンジを置く。中実矩形の純曲げ全塑性モーメント \(M_p = \sigma_y b d^2/4 = 12.5\) kN·m
（[全塑性モーメントの根拠](../../docs/calc_basis/08_部材終局耐力/10_線材のヒンジ判定用耐力.md)）
に4柱端が達すると、柱が回転し梁が水平移動する機構が成立する。仮想回転 \(\theta\) に対し、
外力仕事 \(QH\theta\) と内力仕事 \(4M_p\theta\) が等しいので \(Q=4M_p/H=16.667\) kN となる。
各柱は \(2M_p/H\) の水平せん断力を負担し、梁のせん断力に対応する柱軸力は左右で釣り合う。
部材内に分布荷重がないため曲げモーメントは直線分布となり、各柱と梁の曲げモーメントの絶対値は \(M_p\) 以下に収まる。
梁の曲げ閾値は \(M_p\) より大きく、梁は弾性のまま力を伝える。
これは理想化した回転ばねの解析検証であり、実断面の局部座屈や軸力との耐力相関を対象とする規準適合性の検証は含まない。

公開のヒンジ履歴から部材IDと材端位置で識別し、`Yield` または `Ultimate` が初めて出たステップを各材端について求める。
最後の柱端が初回降伏した確定ステップで4柱端がすべて降伏状態にあることを確認し、そのステップのベースシアを採る。
ヒンジ履歴の表示閾値は軸力ゼロでの \(M_p\) である。解析の回転ばねには曲げ・軸力相関と降伏後の硬化がある。
理想参照の梁せん断力から見積もる柱軸力の絶対値は \(2M_p/5{,}000\simeq5\) kN で、柱の軸耐力500 kNの約1%に当たる。
実測では4柱端がそろったステップ27のせん断力は16.683 kNで、形成荷重の指標と理想参照の差は0.10%だった。
最終の機構判定は `Overall` だった。絶対値比較の許容差は旧試験の30%を維持する。
硬化により、100 mmまでの曲線上の最大ベースシア `qu` は17.664 kNとなった。

旧試験の等断面ファイバー模型（柱・梁とも100×100、形状未指定）は
`test_portal_frame_column_bases_yield_before_roof_ends` に保持した。
実測では柱脚2材端がステップ28（43.5 kN）に、残る柱頭2材端と梁2材端がステップ43（66.0 kN）に初回降伏し、
最終機構は `Overall`、最大ベースシアは120.0 kNだった。旧抽出は異なる時刻の4番目である
ステップ31（48.0 kN）を採っていたが、この時点では柱脚2材端の反復記録だけがあった。
旧参照値52.22 kNは弾性断面係数を使ったため、等断面ファイバー模型の全塑性崩壊荷重との照合は保留する。
回帰試験では確定ステップの量子化による違いを許容し、両柱脚の先行、上部4材端の降伏、`Overall`、正の `qu` を確認する。
同時刻の複数材端、同一材端の後続記録、ひび割れと降伏の識別は
`first_yield_steps_keep_simultaneous_ends_and_ignore_repeated_yield_and_cracks` で個別に確認する。

## 検証で判明した不整合と是正

系レベルで測って初めて表面化した経路上の不整合を 3 件是正した。いずれも
**剛域を要素に実装しただけでは崩壊機構・Ds まで正しく伝わらない**類のものである。

### 1. 曲げヒンジ判定が節点位置のモーメントを使っていた

**症状**: 剛域を与えても観測崩壊荷重が全く変わらなかった（比 = 1.0000）。

**原因**: `pushover/hinge.rs::track_hinges` が `ElementBehavior::internal_force`
（グローバル系・**節点位置**の材端力）のモーメント成分をそのまま断面耐力 My と
比較していた。節点位置のモーメントは剛体アームぶん（せん断 × アーム長）だけ
大きいため、断面が実際に降伏するより早くヒンジが検出される。両端固定柱では
節点モーメント \(M_{node} = Q \cdot H/2\) なので、判定条件 \(M_{node} = M_y\) は
\(Q = 2M_y/H\) となり**剛域長に依存しない**。これが比 1.0 の正体。

**是正**: 材端力を局所座標へ回し、剛体アームのモーメントを差し引いた
**危険断面＝剛域フェイス**の材端力で判定する（`geom.rs::member_end_forces_at_face`、
`rigid_arm::to_flex_force`）。局所成分を用いることで、材軸まわりのねじりを
曲げと取り違える従来の丸め（グローバル My/Mz の最大値を取っていた）も解消した。
終局時の設計用曲げ（`member_response.rs`）も同じ危険断面基準へ揃えた
（せん断・軸力は剛体アームで変化しないため従来どおり）。

### 2. 崩壊機構の運動学的ゲートが部材あたり 1 ヒンジしか数えていなかった

**症状**: 柱両端が降伏していても崩壊機構が `Partial` と判定された。

**原因**: `track_hinges` は 1 部材につきモーメント最大側の 1 端しか
`HingeEvent` を記録していなかった。`determine_mechanism` は (部材, 材端) の
重複を除いて降伏ヒンジ数を数えるため、両端降伏した柱も 1 個としか数えられず、
運動学的ゲート「形成降伏ヒンジ数 ≧ r+1」（本モデルは r=3 で 4 個必要）に届かない。

**是正**: 材端ごとに `HingeEvent` を記録する。崩壊機構種別は
`squid_n_design_jp::secondary::member_rank::story_ds` の機構補正（層崩壊・部分崩壊は
代表ランクを 1 段階不利側へ）に直結するため、Ds への影響が大きい。

### 3. 段階的耐力喪失解析でファイバー部材のピン化が効いていなかった

**症状**: `staged_strength_loss` の耐力喪失部材除去が、ファイバー要素では
実質的に機能していなかった（除去したはずの部材が曲げ剛性を保っていた）。

**原因**: 耐力喪失部材は「両端ピン＋断面の実質ゼロ化」（`detach_element`）で除去するが、
`FiberBeam` が `end_cond` を考慮していなかったため、ピン化が無視され断面 1e-6 倍の
**両端固定**部材として残っていた。

**是正**: `FiberBeam` に材端解放（ピン・半剛）を実装した
（要素端回転を内部自由度へ分離し、回転ばねを挟んで静縮約。内部釣合いは
要素内 Newton で解くため降伏後もモーメント解放が保たれる）。

副作用として、除去が正しく効くようになった結果、対称フレームでは 2 本の柱が同時に
耐力喪失して残存構造が機構化し、再載荷パスの剛性行列が分解できなくなる。
これは物理的に正しい終了条件なので、`staged_strength_loss` は
**2 パス目以降の分解失敗を解析の正常終了として扱う**よう改めた
（1 パス目の失敗は元モデル自体の問題としてエラーを返す）。

## 検証の限界・残課題

- 本検証は**単一層・単一スパン**の門形フレームによる。多層モデルでの層崩壊
  （`MechanismType::StoryCollapse`）判定に剛域が与える影響は未検証。
- 形成荷重は「柱の4材端の降伏がそろった確定ステップのベースシア」で、
  ステップの量子化誤差を含む（剛域比較の当初実測では理論比との差が約1.3%）。
  集中ばね模型は変位制御で4材端の降伏を確認する。完全弾塑性の耐力一定区間の直接同定は未実施。
- Ds のもう一方の入口である**部材ランク**（せん断余裕度 Qsu/Qmu）は、剛域控除後の
  内法スパンを既に用いており（`shear_yield::compute_shear_yield_thresholds` と
  `RigidZone::flexible_length_from`、既存テスト
  `test_compute_shear_yield_thresholds_rc_rect_uses_rigid_zone_reduced_clear_span`）、
  本改修の対象外。ランク → Ds の系レベル通し検証は未実施。
- `FiberBeam` の軸剛性は剛域を軸方向にも剛として扱う（EA/L'）ため、弾性梁
  （EA/L）と一致しない（[calc_basis 4.9.5](../../docs/nonlinear/04_非線形梁要素のモデル化.md)）。
  柱の軸変形が支配的な高層・細長架構での影響は未評価。
