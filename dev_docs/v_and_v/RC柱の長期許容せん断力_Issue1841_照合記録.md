# RC柱の長期許容せん断力の割増係数（#1841）

状態🔶。矩形・円形の通常の長期保存組合せについて、長期設計用せん断力を187 kNに固定し、許容値の割増係数αの選び方を照合した。両形状とも、現行の検定では全3行が適合し、RC規準の解説の手順を適用した独立計算では全3行がせん断で不適合になる。許容値を是正する必要がある。 [調査 #1841](https://github.com/hrntsm/SEPIKA/issues/1841)・[是正 #1854](https://github.com/hrntsm/SEPIKA/issues/1854)・[現行の適用限界](../../docs/calc_basis/06_一次設計/02_04_RC柱のせん断検定.md#長期許容せん断力の割増係数)

## 原典と検定の対応

出典は日本建築学会『鉄筋コンクリート構造計算規準・同解説』2024年版。

- 第15条2項(1) i) pp.19–20の式(15.1)は、長期許容せん断力を `QA = b j α fs` とし、αを `4/(M/(Q d)+1)` から柱では1〜1.5に制限する。M・Qの記号説明は長期荷重による最大曲げモーメント・最大せん断力を指す。ii)は別に、長期設計用せん断力を部材の長期荷重による最大せん断力とする。
- 第15条解説2項(3) ii) p.177の式(解15.11)は、柱の使用性検討で軸圧縮と帯筋の寄与を見込まない。まずα=1で長期設計用せん断力を満たすか確認し、不足する場合は柱脚部・柱頭部それぞれのαの小さい方で再照査する。この手順では二つの材端で別々にせん断スパン比を求めるため、部材内の最大M・最大Qを別々の位置から拾って割増に用いると、判定が異なる場合がある。
- 解説の【計算例2】pp.204–205は、3階CB3柱頭のY方向で同じ断面のM=153 kN·m、Q=75 kNを組にしてα=1.07、長期許容せん断力661 kNを算定している。記載の断面諸量でα=1としても約618 kNで設計用75 kNを上回るため、両端の比較が必要な条件の例は得られない。付2の構造設計例 p.438の断面設計(1)は、長期荷重時・水平荷重時の断面算定用内力にフェース位置を用いる。以上から、本照合では方向ごとに各材端フェースの同じ断面のM・Qを組にした。第15条本文は式と記号を定め、フェース位置は付2の設計例が採用した条件である。
- 第15条1項は矩形・T形以外を準用とする。この照合の円形柱には、SEPIKAが用いる等積正方形近似の断面諸量を共通に用いた。本文・解説・例題から、二方向同時作用時の相関式、材端近傍に不連続がある場合のα用断面の詳細、任意の分布荷重下の内点でαを追加評価する条件までは確定できない。

現行の共通検定は、解析で評価した全断面から `(|Mz|, |Qy|)` と `(|My|, |Qz|)` を別々に選ぶ。各組の選定基準は曲げの絶対値で、対応するせん断力は同じ断面の値を使う。検定行を抽出する前の選定なので節点芯も対象になる。矩形柱は方向別の断面諸量を使い、円形柱は両方向に共通の等価幅と有効せいを使う。長期の保存組合せでは、これと独立に、両材端フェース間で求めた方向別の最大せん断力を許容値に対して照査し、大きい方のせん断検定比を各行に表示する。 [共通検定](../../crates/sepika-design-jp/src/member_design_check.rs)・[柱の検定](../../crates/sepika-design-jp/src/rc/column/mod.rs)・[αと許容値](../../crates/sepika-design-jp/src/rc/shear_capacity.rs)・[#1843の最大需要の検証](RC柱の長期せん断需要_Issue1843_検証.md)

## 独立計算

### 片持ち柱の釣合い

長さ3,000 mmの鉛直片持ち柱の脚を固定し、脚節点にはせい600 mmの矩形大梁を接続する。柱脚フェースは脚芯から300 mm、柱頭フェースは柱頭芯と一致する。柱の局所y方向に柱頭横力25 kNと全長の等分布荷重60 N/mmを加え、柱頭にはそれらの曲げを打ち消す向きに145 kN·mの偶力を与える。固定荷重ケースに入力し、既定の長期保存組合せで解析する。柱の自重は軸力にのみ寄与する。

脚芯から断面までの距離をx（m）とし、切断面から柱頭までの長さを `s = 3 − x`（m）とする。柱頭側の力とモーメントの釣合いから、検定入口の符号で `Qy = −(25 + 60s)` kN、`Mz = −145 + 25s + 30s²` kN·m。両材端フェース間ではQyに符号反転がなく、Mzは単調減少する。したがって最大の `|Qy|` は脚フェースの187 kN、最大の `|Mz|` は頭フェースの145 kN·mである。Qz・Myは0。最大せん断力の位置は既定の検定行と一致し、係数ごとの比較で需要と位置を固定できる。 [#1836の需要の照合](RC柱の長期せん断需要_Issue1836_照合記録.md)

| 位置 | x (mm) | Mz (kN·m) | Qy (kN) |
| --- | ---: | ---: | ---: |
| 柱脚の節点芯 | 0 | 200.0 | −205.0 |
| 柱脚の材端フェース | 300 | 141.2 | −187.0 |
| 材中央 | 1,500 | −40.0 | −115.0 |
| 柱頭の材端フェースと節点芯 | 3,000 | −145.0 | −25.0 |

### 断面諸量と許容値

材料は普通コンクリートFc24、主筋・帯筋はSD345。矩形は幅400 mm・せい600 mm、四辺に各3本（隅筋を共用し合計8本）。円形は直径600 mm、等間隔で16本。両形状とも数値径29 mmの主筋、かぶり40 mm、数値径10 mmの帯筋、間隔100 mmとした。円形の本数は、せん断の合否差を軸力・曲げの不適合が覆わないように選んだ。配筋条件はせん断の係数差を比較するためのモデル入力である。

検討方向の矩形幅は400 mm。円形には断面積 `π × 600²/4` mm²に等しい正方形を仮定するので、辺長および等価幅は531.736155 mm。引張縁から主筋重心までの距離は両形状とも `40 + 10 + 29/2 = 64.5` mmとし、矩形のせいと円形の等価せいから引いて有効せいdを求めた。第15条の `j = 7d/8` と第6条 表6.1（p.9）の普通コンクリートの長期許容せん断応力度 `fs = min(24/30, 0.49 + 24/100) = 0.73 N/mm²` を用いる。SEPIKAの計算関数を呼び出さずに以下を算出した。 [円形柱の等価幅・有効せい](../../crates/sepika-core/src/rc_rebar_geom.rs)

| 断面 | b (mm) | d (mm) | j (mm) | fs (N/mm²) | α=1のQA (kN) |
| --- | ---: | ---: | ---: | ---: | ---: |
| 矩形 | 400.000000 | 535.500000 | 468.562500 | 0.73 | 136.820250 |
| 円形 | 531.736155 | 467.236155 | 408.831636 | 0.73 | 158.695110 |

各組の `|M|/(|Q|d)` を同一単位で求め、規準式の範囲内に収めたαでQAを算定する。

| αに用いる断面または組 | 曲げの絶対値 (kN·m) | せん断の絶対値 (kN) | 矩形のスパン比 | 矩形のα | 矩形のQA (kN) | 円形のスパン比 | 円形のα | 円形のQA (kN) |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 柱脚の節点芯（現行） | 200.0 | 205.0 | 1.821867 | 1.417501 | 193.942878 | 2.088044 | 1.295318 | 205.560671 |
| 柱脚の材端フェース | 141.2 | 187.0 | 1.410047 | 1.500000 | 205.230375 | 1.616057 | 1.500000 | 238.042666 |
| 柱頭の材端フェース | 145.0 | 25.0 | 10.830999 | 1.000000 | 136.820250 | 12.413423 | 1.000000 | 158.695110 |
| フェース間の成分別最大（Mは頭、Qは脚） | 145.0 | 187.0 | 1.447995 | 1.500000 | 205.230375 | 1.659549 | 1.500000 | 238.042666 |

矩形・円形ともに、α=1のQAを187 kNが超える。解説の二段階手順では、次に小さい方の柱頭のα=1を採り、せん断検定比は矩形1.366757、円形1.178360となる。成分別最大を別々の断面から代入した場合は、上限に達して偶然に脚フェースと同じαになり、せん断検定比は矩形0.911171、円形0.785573となる。この例で最大曲げの探索をフェース間に限ると柱頭を選ぶが、最大曲げの位置が小さい方のαを与える一般則は原典から得られない。

## 公開入口との照合と是正範囲

通常の公開入口である `prepare_model_for_analysis`、`Analysis::linear_combination`、`run_member_design_checks` を順に呼び、検定には `RcColumnLongTermShearInput::SavedCombination` を指定した。解析の評価4断面で独立釣合いのMz・Qyと直交方向のゼロを確認した。通常検定の3行（柱脚フェース、材中央、柱頭フェース）では全行で局所Qy最大187 kNと位置300 mm、直交方向の需要0を確認した。

| 断面 | 現行の長期QA表示 (kN) | 現行のせん断比 | 軸力・曲げ比の最大 | 現行の全体適否 | 解説のαに置き換えた全体適否（独立計算） |
| --- | ---: | ---: | ---: | --- | --- |
| 矩形 | 193.9429 | 0.964201 | 0.723046 | 全3行OK | 全3行NG |
| 円形 | 205.5607 | 0.909707 | 0.468055 | 全3行OK | 全3行NG |

現行の許容値表示とせん断比は節点芯のM・Qによる独立計算と一致した。解説の係数による計算では、現行の軸力・曲げ比と需要を保持してせん断の許容値だけを置き換えた。これにより不適合を見逃す条件が存在するため、材端フェースの方向別M・Qを用いて係数を選ぶ是正が必要となる。必要な材端内力を確認できない場合の扱いは是正時の検証対象とする。 [是正 #1854](https://github.com/hrntsm/SEPIKA/issues/1854)

## 再現手順

基点は `571796605a2daf6815274070bac48ba9b1072533`。Windows x86_64-pc-windows-msvc、Rust stable 1.100.0で [再現プローブ](data/rc-column-long-term-shear-alpha/public_probe.rs) を実行し、1件通過。独立値との許容差は正規化位置10⁻⁹、せん断10⁻⁵ N、曲げ10⁻² N·mm、せん断検定比10⁻⁸とした。表示されたQAとαはそれぞれの表示桁で比較した。

リポジトリルートで実行する。検証時は共有ターゲットを指定し、下記と同じプロファイル設定を使用した。

```powershell
$root = (Get-Location).Path
$manifest = Join-Path $root 'Cargo.toml'
$target = Join-Path $root 'target/rc-column-long-term-shear-alpha'
$probe = Join-Path $root 'crates/sepika-job/tests/rc_column_long_term_shear_alpha_probe.rs'
$env:CARGO_PROFILE_DEV_DEBUG = '0'
$env:CARGO_PROFILE_TEST_DEBUG = '0'
if (Test-Path -LiteralPath $probe) { throw '既存のプローブ用ファイルがあります' }
Copy-Item -LiteralPath 'dev_docs/v_and_v/data/rc-column-long-term-shear-alpha/public_probe.rs' -Destination $probe
try {
    cargo +stable test --locked -p sepika-job --manifest-path $manifest --target-dir $target --test rc_column_long_term_shear_alpha_probe -- --nocapture
    if ($LASTEXITCODE -ne 0) { throw '再現プローブの実行に失敗しました' }
} finally {
    Remove-Item -LiteralPath $probe
}
```

既存の `cargo test --locked -p sepika-job --test rc_column_long_term_shear` は19件通過。製品文書は `cargo run --locked -p xtask -- check-docs` と `mdbook build docs` が通過した。
