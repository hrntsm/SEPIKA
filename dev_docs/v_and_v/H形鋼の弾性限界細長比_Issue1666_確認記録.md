# H形鋼強軸曲げの弾性限界細長比（#1666）

日本建築学会『鋼構造許容応力度設計規準』2019年制定、第1版第3刷の5.1(4)a pp.10–11と5.6 p.14を照合した。式(5.12)の弾性限界細長比は `1/√0.6`。境界の等号は式(5.8)に入り、直上は係数2.17の式(5.9)に入る。短期の許容値は長期の1.5倍。入力の選定を含む採用方式は[製品文書](../../docs/calc_basis/06_一次設計/03_02_鋼梁の曲げ_横座屈検定.md#許容曲げ応力度と横座屈)を参照。 [規準の書誌](https://ndlsearch.ndl.go.jp/books/R100000002-I030037737)

## 独立期待値

目標とする基準化細長比 λb を先に選び、規準の式(5.10)から弾性横座屈モーメント Me = FZ/λb² を求める。式(5.11)を横座屈長さの二乗 x = lb² について解くと、x = (B + √(B² + 4Ak))/(2k)、A = π⁴E²IzIw、B = π²EIzGJ、k = (Me/C)² となる。長期は目標 λb に該当する式(5.7)〜(5.9)、短期は5.6を適用する。計算には十進55桁を使い、入力と期待値を丸めて回帰に固定した。

個別算定の試験入力は F = 235 N/mm²、E = 205 000 N/mm²、G = 79 000 N/mm²、Iz = 10⁷ mm⁴、Iw = 10¹² mm⁶、J = 10⁵ mm⁴、Z = 10⁶ mm³、C = 1、塑性限界細長比 = 0.3。

| 目標 λb | lb [mm] | 長期 fb [N/mm²] | 短期 fb [N/mm²] |
|---:|---:|---:|---:|
| 0.29 | 1 516.566835334 | 153.230223521 | 229.845335281 |
| 1.2905 | 7 037.978070644 | 65.113913326 | 97.670869989 |
| 1.2911 | 7 041.539016985 | 64.966334840 | 97.449502261 |

等号の試験は数値照査専用の入力とする。lb = π mm、Iw = 0、E・G・Iz・J・C の数値を1として Me = 1 N·mm とし、F = 235 N/mm²、Z = 1/141 mm³より λb² = 1/0.6。式(5.8)の端点では長期65.076923077 N/mm²、短期97.615384615 N/mm²となる。 [個別算定の回帰](../../crates/sepika-design-jp/src/steel/section.rs)

通常検定の共通入口では、SN400BのH-400×200×8×13の鋼柱に、断面欠損なし、フィレット半径0 mm、全長で一定の強軸曲げを与える。F・E・Gは個別算定と同じとする。矩形3枚の断面から求めた Iz = 17 349 290.666667 mm⁴、Iw = 649 596 478 464 mm⁶、J = 356 762.666667 mm⁴、Z = 1 148 243.413333 mm³と、等曲げの C = 1、塑性限界細長比0.3から上記と同じ方法で lb を求める。短期曲げ応力度97.6 N/mm²に相当するモーメント112 068 557.141333 N·mmを与えると、横座屈長さに用いる節点間距離が8 050.059931 mm（λb = 1.2905）で検定比0.999274400・適合、8 055.338211 mm（λb = 1.2911）で1.001544366・不適合となる。境界を1.29に固定した場合、前者にも式(5.9)が適用され、許容値97.540138903 N/mm²、検定比1.000613707・不適合となる。 [通常検定の回帰](../../crates/sepika-design-jp/tests/steel_column_lateral_buckling.rs)

## 保存と確認範囲

[#1877](https://github.com/hrntsm/SEPIKA/pull/1877) の `e11f1e5c6` で式(5.12)の修正と同時に検定契約版が110から111に更新された。読み込みでは現行版と完全一致する検定結果だけを利用するため、修正前の結果は再検定が必要となる。#1666では計算本体・保存契約を変更しない。確認範囲は上記の式・境界と有限の通常検定で、任意の曲げモーメント分布や補剛条件への適合、実験Validationは含めない。区間内の最大曲げの判定は別途追跡する。 [#1886](https://github.com/hrntsm/SEPIKA/issues/1886)
