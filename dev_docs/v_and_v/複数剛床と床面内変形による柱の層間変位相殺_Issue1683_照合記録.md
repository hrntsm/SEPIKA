# 複数剛床と床面内変形による柱の層間変位相殺（Issue #1683）

> シェル床の照合は廃止前の記録です。[#2033](https://github.com/hrntsm/SEPIKA/issues/2033) により現行版ではシェル床は対応外です。現在の恒久回帰は複数剛床を対象とします。

[Issue #1683](https://github.com/hrntsm/SEPIKA/issues/1683) の照合。状態🔶。複数剛床と面内変形する床の両方で、柱の加力方向の層間変位が小さくても、直交方向の変形によって加力方向の柱頭力が残った。製品の柱剛性入口は大きな比を返し、偏心率入口はこの二例では方向間連成候補と床の適用条件を理由に保留した。

## 原典と照合範囲

『2025年版 建築物の構造関係技術基準解説書』第2版第1刷 6.2.3 p.362 (5) の原画像を確認した。各階にねじれが生じず、構面の水平変形がそろう並進架構での評価が原則である。立体解析等では剛床仮定の成否によらず一次設計用地震力による応力から水平剛性を求められるが、ねじれで鉛直部材の層間変位が0に近づく場合は、並進架構等により評価する。近零を判定する数値は示されていない。非剛床でもルート2の適用には各階の偏心率が0.15以下であることの確認が必要になる。[刊行元の書誌](https://www2.icba.or.jp/products/detail.php?product_id=606)、[建築基準法施行令第82条の6](https://laws.e-gov.go.jp/law/325CO0000000338#Mp-At_82_6)

剛心は、層せん断力によってねじれず一様な水平変位が生じる点であり、ねじり剛性は剛心回りの単位回転を生じさせるモーメントである。同書p.360の式 (6.2–6) は、平成19年国土交通省告示第594号第5のねじり剛性の式を直交グリッド上の構面に適用する。直交グリッドの前提が成り立たない場合も、求める剛心とねじり剛性が上の定義に適合することを確認する。この定義を使える場合は、偏心方向と直交する並進剛性とねじり剛性から弾力半径を求め、偏心距離を弾力半径で除す。関連する単一剛床の数値は [#1595 の照合記録](ねじれで柱の層間変位が相殺される場合の偏心率_Issue1595_照合記録.md) を参照する。本照合は単一剛床での設計採用 [#1685](https://github.com/hrntsm/SEPIKA/issues/1685)・[#1698](https://github.com/hrntsm/SEPIKA/issues/1698) の条件を扱わない。

## 架構と拘束

階高3,000 mmの1層に鉛直柱A、B、C、Dを置く。平面座標は順に (0, 0)、(2000, 0)、(0, 4000)、(2000, 4000) mm。要素IDは0～3、柱頭節点IDは1、3、5、7。柱脚は全固定、柱頭はUz・Rx・Ryを拘束する。柱頭Rzは自由とし、材軸ねじりを保持する設定を用いる。剛域、材端偏心、壁、支持ばねと部材荷重はない。線形弾性・微小変形で、軸力による幾何剛性は考慮しない。柱頭に同じ質量を置き、質量重心は (1,000, 2,000) mm。応答の載荷による合力の作用位置は別に記す。

柱はE＝200,000、G＝80,000 N/mm²、A＝2,000 mm²、両方向のせん断有効断面積＝1,600 mm²、強軸・弱軸の断面二次モーメント＝12,000,000・8,000,000 mm⁴、J＝4,000,000 mm⁴。平面内の強い変位方向はA・Bが全体X、CはXから−45°、Dは＋45°。

| 床条件 | モデル化 |
| --- | --- |
| 複数剛床 | A–CとB–Dの2組。AとBを各床の代表節点とし、各組の柱頭は水平並進・Rzを共有する。2組の間をつなぐ梁や床要素は置かない。 |
| 面内変形する床 | A–B–D–Cを結ぶ四節点シェル1枚。剛床拘束なし。E＝2,000 N/mm²、ポアソン比0.25、厚さ2 mm。面内変形を観測しやすくする検証用の床特性であり、実床の諸元への当てはめは行っていない。 |

材軸ねじり保持を明示したのは、シェル床で既定のi端ねじり解放を用いると全柱でねじりが解放され、シェルの全節点で等しいRzに抵抗する剛性がなくなるためである。X対照の線形解析は非正定値の診断で停止した。既定設定の扱いは [#1700](https://github.com/hrntsm/SEPIKA/issues/1700) で追跡する。

## 一様変位の独立解析と荷重対照

全柱頭にXまたはY方向へ＋0.25 mmを同時に与える。直交方向とUz、Rx、Ry、Rzを0とし、柱脚は元のまま固定する。変位を規定した独立解は床全体の剛体並進なので、両剛床の拘束と両立し、シェルの膜ひずみ・曲げ変形・ドリリング変形は0。柱頭に必要な力は各柱の反力から求まる。柱頭反力の正は境界から部材に作用する全体座標の正方向とする。柱脚水平反力は柱頭の逆符号。柱頭の曲げ回転拘束には全体座標で Mx＝QyL/2、My＝−QxL/2 の曲げモーメントを要する。Rzに対する反力モーメントは0。

両端の曲げ回転を拘束した一様梁の曲げ・せん断柔度は、主軸ごとに `L³/(12EI) + L/(GAs)`。これを逆にして強軸の剛性 `ks = 1,040.650407`、弱軸の剛性 `kw = 699.453552` N/mmを得る。C・Dの水平剛性行列の対角項は `kd = (ks + kw)/2 = 870.051979` N/mm、非対角項はCが `−t`、Dが `+t`、`t = (ks − kw)/2 = 170.598427` N/mm。対角項から得る同方向の力と、非対角項から得る直交方向の力を、ベクトルとして比較する。

| 柱 | 一様Xの反力 (Qx, Qy) [N] | 一様Yの反力 (Qx, Qy) [N] |
| --- | ---: | ---: |
| A、B（各柱） | ＋260.162602, 0 | 0, ＋174.863388 |
| C | ＋217.512995, −42.649607 | −42.649607, ＋217.512995 |
| D | ＋217.512995, ＋42.649607 | ＋42.649607, ＋217.512995 |
| 全柱合計 | ＋955.351193, 0 | 0, ＋784.752766 |

この変位条件での層の並進剛性はXが3,821.404771、Yが3,139.011062 N/mm。全柱の直交方向の力は相殺される。独立反力の水平成分だけを荷重として与えた公開線形解析をX・Y対照とする。曲げモーメントはモデルのRx・Ry拘束が負担する。Rzを拘束しない公開解析でも、両床で全柱頭に規定した並進が再現され、柱頭回転は丸め誤差内の0となった。公開解析の変位や応力は独立値の算出に使用していない。

複数剛床のねじれケースで、A–Cの回転は＋1.13526773×10⁻⁴ rad、B–Dの回転は0。Aを基準にすると、CのX変位差は並進＋0.454357092 mmと回転成分−0.454107092 mmの和になる。二床の回転が異なるため、階全体を一つの並進・回転で表せない。

シェル床のねじれケースでは、全柱頭Rzは0である一方、A–CのX変位の差は−0.451625198 mm、A–Bの同方向の変位差は−0.089946841 mm。後者は同じY座標の2点間で生じるため、剛体回転と並進だけでは説明できない。床中央での変位勾配の反対称成分 `(∂uy/∂x − ∂ux/∂y)/2` は＋8.336588×10⁻⁵ rad。双一次補間の床中央の並進から、CのX変位差は並進＋0.226690976 mm、反対称成分による−0.166731752 mm、残りの面内変形成分−0.059709224 mmの和となる。この分解はシェル床の変形を説明するもので、層の代表回転や設計用ねじり剛性は定義していない。

両床のX対照・Xねじれとそれぞれの比例縮小、Y対照で、符号付き柱頭水平力を要素の節点残差と照合した。層せん断力と柱頭水平力合計は外力合計に一致し、柱頭力の腕によるモーメントと柱の材軸ねじりモーメントを足した値は原点回りの外力モーメントに一致した。Xねじれ時の4柱の等質量平均のX層間変位は複数剛床が＋0.238651773 mm、シェル床が＋0.226690976 mm。X対照は両床で＋0.25 mm。これらの平均値は局所相殺を表れにくくする。

Cでは `Qx = kd δx − t δy`。同じ＋0.000250 mmに対するX変位の分担は＋0.217513 N、Y変位による分担は複数剛床で＋4.631191 N、シェル床で＋14.868957 Nである。δxが0に近づき、−tδyが残ると `|Qx|/|δx|` は大きくなる。X対照とXねじれのそれぞれを全成分比例縮小した場合は、全柱の力・変位・層の合力・モーメントが比例して小さくなり、柱比は元の各ケースと同じ値を保つ。比の尺度不変性だけでは相殺を除外できない。方向別に力と変位が比例する場合は、δxが小さくなるとQxも同じ比で小さくなる。相殺診断には変位の絶対値に加え、床ごとの回転・面内変形と、直交方向の変位や他要素からの力の寄与の確認が必要である。

## 公開評価と設計採用条件

[柱剛性・偏心率の公開入口](../../crates/sepika-design-jp/src/secondary/eccentricity_analysis.rs) の柱比は、上端に単一剛床の共通回転を見いだせない両例で、相殺を理由とする停止を行わず上表の有限値を返した。一方、同じモデルの公開Reは全ケースで、部材2（C）の方向別断面剛性の軸が全体の直交軸と一致せず、層上端に剛床が複数ある、または層上端に単一剛床がないことを理由として算定不能となった。これは [剛心・ねじり剛性の同定経路](../../crates/sepika-design-jp/src/secondary/story_rigidity.rs) が連成候補を検出した結果であり、相殺そのものを検出した結果とは区別する。現行では連成候補を検出しない場合に柱比へ進む経路もある。

再現試験では公開APIで算定したRsは1であり、公開ReがErrのため [Fes算定](../../crates/sepika-design-jp/src/secondary/holding_capacity.rs) へ進めなかった。[Appの層指標](../../crates/sepika-app/src/summary.rs) でも、RsとReがそろった場合にFesを算定し、Reの理由をFesへ伝えることをコードで照合した。試験でAppや標準Ai経路を起動した結果ではない。有限なReであっても、例えば柱比の過大評価は剛心と弾力半径の双方に影響する。偏心率やFesへの影響の向きは、本例の柱比からは定まらない。

| 設計時の確認結果 | 追加計算・保留・利用者に示す根拠 |
| --- | --- |
| 一次設計用地震力で方向別の変位と負担水平力が対応し、剛心・ねじりモーメントの算定条件も確認できる | 反映する抵抗要素、方向ごとの力と変位の対応、ねじりへの全寄与、対象とする地震時層せん断力の合力位置と重心の対応を確認した上で、算定したReと確認済みのRsからFesを評価する。 |
| ねじれで鉛直部材の層間変位が0に近づく | 原典に従い、一次載荷の柱比によるRe・Fesの採用を保留し、並進架構等で水平剛性とねじり抵抗を別途評価する。 |
| 相殺時に同方向の変位に比例しない力が残る | 柱比が過大になる理由を確認するため、階・方向・柱、符号付きの両方向変位差と柱頭力、剛床ごとの回転や床の面内変形、対照時の反力と境界条件を提示する。直交方向の変位や他要素の力が、同方向の負担水平力へ寄与したかを調べる。 |
| 床の代表運動、床間の加力・モーメント配分、剛心の一意性やねじり剛性の評価条件が定まらない | 全層Re・Fesを保留する。複数剛床では同一の層合力・モーメントでも各床への配分で応答が変わり、非剛床では載荷分布と拘束で変形が変わる。一様変位の反力は、その境界条件での並進剛性を与える。設計用Reには、剛心の定義に対応する無ねじれの一様変位を生む加力と、剛心回りの単位回転の条件も必要になる。 |
| 床のモデル化や分離した床ごとの扱い、代表回転・近似方法を選ぶ必要があり、その安全性が未確認 | 利用者に実際の床間の接続と力の伝達、一次設計用載荷、抵抗要素、評価単位と境界条件、採用方法の根拠を確認する。必要なReが保留ならルート2のRe条件も未確認とし、Re又はRsが保留ならFesおよびそれを用いる必要保有水平耐力の採用を保留する。 |

本Issueの再現に製品計算の変更は不要。現行の単一剛床を前提にした相殺診断から外れる層で、自動検出や安全性を確認した算定保留を製品に追加するには、一次載荷に対する診断条件、量の尺度、回転・床変形と他成分の力の寄与を確かめられる応答や追加計算を設計する必要がある。並進架構等による設計値の自動算定には、床群の評価単位・加力と拘束、回転・抵抗要素の寄与、合力位置、Re・Fesへの接続の根拠と利用者による適用確認が別途必要になる。
