# SRC柱のルート2-1設計用せん断の確認（#1612）

[Issue #1612](https://github.com/hrntsm/SEPIKA/issues/1612)。『2025年版 建築物の構造関係技術基準解説書』第2版第1刷（2026年2月11日）付録1-4.1 pp.758–759の付1.4-1・付1.4-2・付1.4-3・付1.4-6と、RCの終局曲げの付録1-3.1 pp.703–704の付1.3-10〜15を照合した。付1.4-2はRC部分だけの代替式であり、鉄骨の要求値は付1.4-1に従う。付1.4-6は鉄骨部・RC部それぞれで要求値と許容値を比較する。

## 独立値と共通部材検定の比較

矩形600 mm角・Fc24・H400×200×8×13（F235）、異形主筋D25（強軸の引張・圧縮側各4本、弱軸の引張・圧縮側はそれぞれ中間主筋を含む）、帯筋D10@100・各方向2脚（SD295）、確認済み内法高さ4,000 mm。[#953のPython計算](data/issue953/independent_values.py)に基づく端部の鉄骨短期許容曲げとRC終局曲げを、単独検定ではなく公開共通部材検定に渡した。比較例の組合せ応力と入力は有限Verification用で、支持条件や崩壊機構を示す実架構モデルではない。軸力は圧縮正で記載する。

入力値の付1.4-3による圧縮側上限、全主筋の純引張下限での曲げ耐力0は、[#1416の直接検定](SRC柱短期地震時の曲げ方式_Issue1416_確認記録.md)にも独立例がある。今回の表示では採用式、材軸に対応する方向、加力の向き、根拠参照および材料別検定比を確認した。組合せ全せん断の値を変えてもQd2の結果は変わらない。

## 不足・適用外・回帰の確認

- ルート2-1として検定を要求したとき、部材・方向・根拠参照・有限で正の内法高さ・対象柱の解析断面力が不足していても、通常短期の許容せん断に切り替えない。
- 一次設計用地震せん断Qが非有限、RC需要の演算結果が非有限、またはQが鉄骨部の設計用せん断未満で、当該方向のRCは理由付き未算定。独立に確定した鉄骨部の不適合は保持する。
- 鉄骨の両端耐力がそろわないときも、RCが両端降伏で鉄骨耐力に依存しない場合、または接続梁による柱頭上限に必要な柱頭鉄骨耐力が有効な場合は、独立に確定したRC部の不適合を保持する。
- 強軸の一次設計用地震せん断400 kNの例では、主筋材料が未割当、材種が未対応または材料区分が不適合でも、有効な配筋形状・帯筋と代替式から求まるRCせん断の不適合を主筋の未算定理由と併記する。
- 同じ検定位置に解析断面力が二つある場合（許容誤差内で位置がわずかに異なる場合を含む）、その位置は理由付き未算定とし、別の位置の確定した軸力・曲げの不適合を保持する。
- 評価位置の軸力が非有限でも、確認済み入力に基づくせん断の不適合を併記する。入力を欠く場合の独立した軸力不適合、長期柱・短期SRC梁にこの設定が適用されないことも確認する。

公開入口の再現は `cargo test -p sepika-design-jp --locked --test src_column_route21_shear`。

## 限界

この比較は確認済み入力を共通部材検定で照査できることのVerificationであり、耐力や加力・崩壊機構の自動特定は行っていない。GUI・保存モデルへの入力は [#1928](https://github.com/hrntsm/SEPIKA/issues/1928) の範囲。付1.4-1における設計留意事項の全体、他ルート、梁・壁・接合部・柱脚、実架構の機構と実験Validationは対象外。
