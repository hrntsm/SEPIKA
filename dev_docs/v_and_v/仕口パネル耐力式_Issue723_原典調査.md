# 仕口パネル耐力式の原典調査（Issue #723）

## 結論と適用判断

2026-11-18、照合開始時の基点 `db97d9d7` で日本建築学会『鋼構造接合部設計指針』第5章を照合した。**状態は🔶。#723は継続**。標準形のS造の降伏式の形、軸力比と応力評価位置、全塑性との区別を確認した。照合時点の実装には、軸力の取り方と正方形等厚鋼管の形状係数に差があった。形状係数の差は[公開入口の追加照合](#正方形等厚鋼管の形状係数の追加照合issue-1428)を参照。

- **採用根拠を確認した範囲**は、適切に補剛された標準形式の H 形強軸・円形鋼管・正方形等厚箱形断面における降伏式の形と、H 形強軸・円形鋼管の実効体積・形状係数。短期荷重時の検定に降伏点を使う位置づけも一致する。現行製品の N・A・F を含む全式の適合判定は保留する。
- **有限条件で不一致を確認した範囲**は、上下柱平均に対する片側軸力の使用と、`db97d9d7` 時点の正方形等厚の形状係数。当時の形状係数では、同一 N・A・F と実効体積の場合に指針の降伏耐力を過大評価した。強度差・補強・H弱軸等の扱いは下の適用範囲に従う。
- **全塑性式を降伏式の代用として採用しない**。保有水平耐力・崩壊型を指針の手法で検討するときに使う全塑性耐力と、静的検定・非線形ばねの降伏点を区別する。冷間成形柱の柱梁耐力比に用いる最大曲げモーメントは別の評価量。
- **残る採否**は CFT 固有の N・A・F、角形異厚・矩形、パネル補強・接合詳細、引張時、非線形の状態・履歴と剛性。CFT 専用原典本文の確認と適用条件の特定が必要。採用柱・方向別材料の選択は #585・#601 の既合意に従う。SRC #949 と変動軸力接線 #752 は別課題。

対象は静的なS/CFT仕口パネル検定と、非線形S仕口パネル要素の耐力。#893 の2025解説書の確認、#1293 の強弱軸・幾何・需要の図解、#936（#892）の静的検定で実断面積を使う修正を起点とする。

## 降伏式と N・A・F の照合

指針 §5.2 式(5.1)の降伏耐力は、パネルの最大せん断応力度がミーゼスの降伏条件に達するときのモーメント `pMy = (Ve/κ) (Fy/√3) √(1−n²)` である。式(5.2)–(5.4)の有効体積 `Ve = Ae db`、形状係数 `κ` および式(C5.4)のせん断抵抗面積 `Ae` は、断面に応じて定まる。式(C5.1)・図C5.2・p.240では、短期荷重時の柱梁フェースにおける応力から、梁端モーメントの和と上下柱端せん断力による補正で設計用パネルモーメントを算定する。現行静的検定には、釣合い式による需要と、解析が返す仕口パネルモーメントを用いる入口がある。S/CFTのパネル算定は荷重の長期・短期区分で式を切り替えないため、指針の短期検定との対応は対象の荷重状態をそろえて評価する。各方向の軸力は需要の取得経路を変えても下表の扱いになる。

### 全塑性相関式と適用範囲

指針の標準形式の全塑性耐力は `pMp = αn Ve Fy/√3`（式(5.5)）。弾性せん断応力分布の最大値で決まる降伏点に対し、全塑性はパネル全体の塑性化を表す指標で、`1/κ` を掛けない。実験値は構面方向で0.35%オフセット、箱形45°載荷で0.5%オフセット（pp.241–242、図C5.6）。§5.2 は全塑性の本文式(5.5)–(5.10)について `db/dc ≤ 1.8`、さらに正方形等厚の箱形は `Dc/tp ≤ 40`、円形は `Dc/tp ≤ 50` を示す。次表の実験範囲は表C5.1の記録であり、式の全条件や製品の自動判定範囲を表すものではない。

| 断面・形式 | 指針の根拠・比較条件・採否 |
| --- | --- |
| H形強軸 | 適切な補剛がある標準形では、式(5.2)のウェブ1枚の `Ve` と `κ` は現行と一致。全塑性時はフランジが軸力を先に負担し、`n ≤ 1−Ap/A` で `αn=1`。超過分に対し `αn=√(1−{(n−1) A/Ap+1}²)`（式(5.6)–(5.7)）。表の実験範囲は `Dc/tp=11–50`、`tp/tf=0.6–1.8`、`db/Dc=0.7–1.7`、`n=0–0.7` |

| CFT角・円 | 中空鋼管の標準式と表C5.1をCFTへ適用する根拠は確認できなかった。現行静的は採用柱の部材全体の軸力と鋼管A・Fを使い、鋼管の降伏式を評価する。非線形要素の対象外。軸力分担とコンクリート耐力寄与は下節 |

指針式(5.11)の弾性剛性に用いる体積は、H形強軸で `dc db tp`、円形・正方形等厚箱形は `db A/2`。箱形では調査時の `G Ve` と一般には同値にならない。指針 §5.1 の保有水平耐力・崩壊型に向けた弾塑性解析は全塑性耐力と弾性剛性の入力を述べる。現行モデルの降伏点・移動硬化・方向別独立ばね・推定軸力の更新を組み合わせた応答に対して、同節を包括的な妥当性の根拠にはできない。初期剛性の差は耐力差と別の論点であり、架構応力・変形の安全側は判定できない。

### CFT専用原典と一次論文

新都市ハウジング協会は2012年8月の『コンクリート充填鋼管(CFT)造技術基準・同解説』第3版と2024年1月の『同解説の運用及び計算例等』第10版の書誌・販売情報等を掲載する。手元の指定資料と公開先で専用本文を確認できていない。CFT柱終局N–Mの [#888](https://github.com/hrntsm/SEPIKA/issues/888) と区別し、CFTパネルの採否は #723 で継続する。 [新都市ハウジング協会の書籍情報](https://anuht.or.jp/pages/22/)

福元の復元力提案では、降伏点のパネルせん断耐力は鋼管と充填部の和。鋼管の軸応力度は、全体軸力を鋼管・充填部の各軸耐力の比で分担させ、鋼管分を鋼管全断面積で除して評価する。式(5)は全体軸耐力を `As σsy + Ac σB` とし、鋼管応力度は全体軸力比 `n` に鋼管降伏応力度 `σsy` を掛けた値。鋼管のせん断抵抗面積はウェブ面積で、円形では `As/2` とする。ひび割れ点では剛性比、終局点では別のせん断耐力累加が用いられる。これらは実験に基づく研究提案であり、論文の材料強度と製品の基準強度を同一視せず、専用設計規準の採用は保留する。 [角形CFT（2014）、§2.1、p.2014、式(1)–(7)](https://www.jstage.jst.go.jp/article/aijs/79/706/79_2013/_article/-char/ja)・[円形CFT（2015）、§2.1、pp.1206–1207、式(1)–(8)](https://www.jstage.jst.go.jp/article/aijs/80/713/80_1205/_article/-char/ja)

例題1の p.249 最上段には軸力比の分母を `295×237×10³` とする表記がある。独立計算では、掲載軸力比0.186、同じページ下方の上柱の算定式の分母 `295×237×10²`、同じ箱形断面を用いた p.260 の軸力比算定式の分母 `295×237×10²` と整合する `A=237×10² mm²` を用いた。

- **正方形等厚の形状係数**。外寸400×400、板厚16、db=500、F=235、N=0、Ve=6144000で比較する。式(5.4)の `κ=1.125` による降伏耐力740.979に対し、直交外寸400・dc=384による照合時点の実装の `κ=1.121212…` は743.482。指針に対して0.338%の過大評価で、同一の需要742なら指針値を超えるが照合時点の実装値以下となる。

- **引張除外**。引張の絶対軸力比0.6で式(5.1)を符号対称に適用する数式上の比較では耐力係数0.8、現行は1.0。現行は同式をそのまま評価した値を25%上回る。指針の引張時の採否は圧縮例から確定できず、実接合部に対する安全側は判定できない。
- **H形弱軸**。H-400×300×12×18、db=420、Fy=325、N=0とする。Bc/tf=16.67、db/Bc=1.4は表C5.1の範囲内。現行のフランジ2枚モデルは `2 Bc db tf Fy/(1.5√3)=567.420`、同表・式(C5.5)の曲げを考慮した全塑性耐力は507.150。現行の初期降伏値が比較対象の全塑性耐力を約11.9%上回る条件があり、純せん断近似を安全側とみなせない。異なる耐力指標の比較であり、指針の全塑性式を降伏値に採用する根拠にはならない。
- **円形の弾性剛性**。鋼管に `A=π dc tp` を用いると、同じG・dbで調査時の `G Ve` は指針の式(5.11)の `G db A/2` の `4/π=1.27324` 倍。この剛性差から架構での応力・変形の安全側は判定できない。適切に補剛され、板厚が一様な標準形式の円形鋼管は、[#1429](https://github.com/hrntsm/SEPIKA/issues/1429) の [初期剛性の原典対応](../../docs/calc_basis/04_要素剛性/06_パネルゾーン.md#仕口パネル要素の剛性)を参照。
- **CFTの軸力分担の感度**。例として鋼管負担軸耐力と充填部負担軸耐力がそれぞれ3000 kN、全体の圧縮軸力が1800 kNの場合、製品と研究式で同じ強度を仮置きして軸力比だけを比較すると、鋼管断面に全軸力を負担させる現行は0.6、福元の耐力比分担は0.3。ミーゼスの係数はそれぞれ0.8000と0.9539。CFTパネル全体ではせん断抵抗面積・充填部の力・条件も変わるため、耐力式全体の採否や安全側は判定できない。

### 正方形等厚鋼管の形状係数の追加照合（Issue 1428）

[#1428](https://github.com/hrntsm/SEPIKA/issues/1428) では、指針p.238の式(5.1)(5.4)とp.241の図C5.4(c)により、適切に補剛した標準形式のS造正方形等厚鋼管が両主軸とも `κ=9/8` となることを確認した。外寸400×400 mm、実板厚16 mmの上下柱、梁フランジ中心間距離500 mm、F=235 N/mm²、N=0、パネル板厚未指定の接合部では、両方向の板厚中心間距離が384 mm、実効体積が6,144,000 mm³となる。

静的検定の公開入口 `collect_joint_checks_with_long` の検定比、および公開仕口パネル要素 `PanelZone::new_nonlinear` の `yield_moment` を両軸で照合した。修正前はいずれも743,482,341.0271007 N·mm、修正後は式(5.1)(5.4)の固定期待値740,979,033.481555 N·mmと一致した。要素に739 kN·mおよび742 kN·mに相当するせん断変形を各軸に個別に与え、せん断モーメントと接線剛性で弾性と降伏後の応答を確認した。軸力の評価・非線形履歴の物理的妥当性は引き続き別途確認が必要である。

### 正方形等厚鋼管の初期せん断剛性の追加照合（Issue 1504）

[#1504](https://github.com/hrntsm/SEPIKA/issues/1504) では、指針p.239の式(5.11)に、例題1（pp.248–249）のBCR295柱 □-400×400×16の全断面積23,700 mm²とH-600×200×11×17梁の `db=583 mm` を用い、`G=78,500 N/mm²` として独立計算した。p.249上段の面積の指数は同頁下段の上柱の算定式・記載の軸力比0.186と整合しないため、下段の算定式と軸力比に整合する23,700 mm²を用いた。`78,500×583×23,700/2=542,321,175,000 N·mm/rad`（542,321.175 kN·m/rad）となる。自動生成した剛性と、公開仕口パネル要素の線形・非線形の初期接線および弾性範囲のモーメントを両軸で照合した。
