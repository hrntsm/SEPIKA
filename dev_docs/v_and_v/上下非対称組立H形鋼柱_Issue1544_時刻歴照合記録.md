# 上下非対称組立H形鋼柱の時刻歴簡易検定（#1544・#1570）

[#1544](https://github.com/hrntsm/SEPIKA/issues/1544) の再現断面は、全せい400 mm、上フランジ80×12 mm、下フランジ180×20 mm、ウェブ厚8 mm、基準強度235 N/mm²。短期の断面照査の原典は日本建築学会『鋼構造許容応力度設計規準』（2019年）本文6.1節（p.15）および11.9節(1)(4)（p.27）。11.9節は10.1(1)および6.1・6.2を参照する。有限長の照査の適用条件は[計算根拠](../../docs/calc_basis/06_一次設計/03_05_鋼柱_ブレースの軸力_曲げ検定.md#上下非対称組立h形鋼柱の圧縮と強軸曲げ)を正とする。

## 独立期待値

[断面照合](上下非対称組立H形鋼柱_Issue1528_照合記録.md#再現断面と独立期待値)と同じ3矩形から、断面積7,504 mm²、強軸二次モーメント168,019,265.000711 mm⁴、上下の断面係数634,601.730518 mm³と1,242,409.032342 mm³を得た。曲げの圧縮側は軸圧縮応力度と曲げ圧縮応力度との和、引張側は曲げ引張応力度から軸圧縮応力度を控除した値とし、それぞれを235 N/mm²で除した。軸力・曲げ以外の成分は全て0。

| 時刻 | N [kN、引張正] | Mz [kN·m] | 断面単独の支配比 | 支配 |
|---|---:|---:|---:|---|
| A | −78 | 0 | 0.04423173 | 軸圧縮 |
| B | −77 | +150 | 1.04948900 | 上縁の圧縮 |
| C | −77 | −155 | 0.99568717 | 上縁の引張 |
| 成分別の絶対値包絡 | −78 | −155 | 0.99512010 | 上縁の引張 |

Bは軸力の極値にも強軸曲げの絶対値最大にも該当しない。正側の強軸曲げ極値として保持される。有限材長の簡易検定ではBの下限比が1を超えて不適合になる。Cは座屈が未算定で、比が1以下というだけでは適合を確定できない。

抽出の限界は A=(−800, 0)、B=(−400, +125)、C=(−1, +130)、D=(−1, −145) [kN, kN·m] とした別例で確認する。Bの上縁圧縮比は約1.06502だが、A・C・Dだけが抽出される。当時の画面には抽出条件と全時刻の適否が未判定である旨が表示された。

## 要素と検証

GUIと再開の試験は、柱梁接合部のない片持ち柱を用いる。

| 照合した項目 | 検証 |
|---|---|
| 符号・同断面6成分・途中確定ステップ | `signed_bending_peaks_keep_the_whole_section_force_at_non_displayed_steps`。間引いたフレームに含まれない時刻と材中央を保持し、継続時の同値は最初の時刻を採用 |
| 断面単独で確定する不適合と残る条件 | `asymmetric_built_h_history_shows_reverse_bending_failure_after_save_and_reopen`。実解析の詳細記録を再現条件の断面力へ差し替え、通常のプロジェクトとして再読込。BはNG、Aの数値は抽出時刻、Cは座屈の未算定と表示 |
| 抽出範囲・曲げ極値の欠落 | `asymmetric_built_h_legacy_history_discloses_missing_section_checks_and_peaks`。表示に使う時刻だけでは不適合が確定しない場合と曲げ極値を欠く場合の表示 |
| 途中状態の保存と再開 | `非対称組立h柱の全確定時刻の照査と個別極値は再開しても一致する`。試験入力波で実解析し、連続実行との同一性と対象柱の曲げ極値がない前半記録の拒否を確認 |

#1570以前は抽出された確定点のVerificationを行った。

## #1570での全確定時刻の照合

同じ独立断面諸量を使うと、A〜Dの上縁圧縮または引張の支配比は次のとおり。

| 時刻 | N [kN、引張正] | Mz [kN·m] | 上下縁の支配比 |
|---|---:|---:|---:|
| A | −800 | 0 | 0.45365876 |
| B | −400 | +125 | 1.06501634 |
| C | −1 | +130 | 0.87228151 |
| D | −1 | −145 | 0.97172980 |

公開時刻歴解析の線形例では、柱脚を固定し、柱頭は二方向の並進だけを許した斜柱を用いる。目標断面力と節点変位を線形部材剛性で対応付け、平均加速度法の時刻ごとの釣合いから地動を求めた。まず全フレーム記録で柱脚N・Mzが例の値に一致することを確認した。斜柱の応答には弱軸曲げ・せん断も生じるため、断面の検定比は下限として評価した。

| 照合した項目 | 検証 |
|---|---|
| 実解析の全確定点と評価位置 | [公開時刻歴解析の試験](../../crates/sepika-job/tests/asymmetric_column_time_history.rs)。間引き3でBが表示フレームと柱脚の成分別極値から外れても、柱脚のBで下限1.06501634を確認。中央はAで0.45365876、反対側は曲げの符号が反転するDで0.97286394。全フレーム記録と集計が一致 |
| 断面力欠落・有限範囲外・継続時の理由保持 | [解析ジョブの集計試験](../../crates/sepika-job/src/time_history_check.rs)。通常の集計入口へ入力したA〜DでBの不適合を確認し、別時刻でのねじり、引張と曲げ、非有限断面力、断面力欠落、欠損、材料強度欠落を照合。前半と後半の理由と支配値を保持 |
| 再開と旧途中状態 | 公開時刻歴解析の試験でBでの途中保存・読込・再開が連続解析と一致。アプリの再開試験で全応答・全ピークのバイト比較と、新しい集計または正負曲げ極値を持たない対象柱の旧途中状態の拒否を照合 |
| GUI表示とプロジェクト保存 | [ヘッドレスGUI試験](../../crates/sepika-app/src/viewer/th_detail.rs)。線形・非線形の実解析から簡易検定と座屈の未算定理由を表示し、保存前と再読込後の表示を比較。旧詳細記録の利用可能な検定行と再解析案内を確認 |

有限材長の座屈耐力は [#1541](https://github.com/hrntsm/SEPIKA/issues/1541)、引張と曲げの適用条件は [#1484](https://github.com/hrntsm/SEPIKA/issues/1484) の範囲。部材全体の適否と実験によるValidationは未確認。
