# 鉄骨のせん断面積と合成の採用範囲（Issue #951）

## 平鋼の是正後の検証（Issue #1396）

下記の採用範囲照合は調査時点の記録である。平鋼の検定方針は[ADR 0112](../adr/0112-flat-bar-shear-unresolved.md)、現在の適用条件は[鋼構造の断面検定](../../docs/calc_basis/06_一次設計/03_鋼構造_断面検定.md#せん断の検定)を参照する。

[公開入口の回帰テスト](../../crates/sepika-design-jp/tests/steel_flat_bar_shear.rs)は、100×10 mm・直接F235 N/mm²・短期・座屈長さ0の平鋼について、柱・大梁それぞれの純Qy・純Qz=100000 Nの4条件で理由付き未算定を要求する。直線で一様な弾性梁の中立軸で、せん断力方向に応じてbとhを交換してVQ/(Ib)を評価すると、最大応力度は両方向とも150 N/mm²。短期許容せん断応力度135.677313259562 N/mm²との比は1.105564345256730となる。一方、調査時点の流用面積833.3333333333334 mm²で求めた比は0.884451476205384で、4条件すべてで適合だった。この独立値は弾性梁の局所照査との比較に用い、平鋼の許容応力度設計式の確定には用いない。

同じ公開入口で、剛性用の正の供給値および非正値を設定した平鋼、微小値・負値・非有限値の各方向入力、せん断力0の平鋼の軸力・曲げ、ブレースの軸力および法定細長比の不適合を検証する。丸鋼・溝形鋼・T形鋼・山形鋼と、名称だけが平鋼を示す一般断面の供給値・全断面積代替も、方向別に独立した期待値で照合する。

[GUIの回帰テスト](../../crates/sepika-app/src/app/shear_area_acceptance_tests.rs)は、片持ちの平鋼大梁の静的解析で得た応力を用い、全3位置の検定不能と理由を検定表・CSV・OVIKA保存再読・再検定で確認する。保存検定の旧版57・58を失効させた場合も、現行の解析成果から再検定できることを確認する。これらは計算と結果伝達のVerificationである。

## 結論と証拠の境界

2026-11-18、基点`8e0989427fac0165f92ce1242fa277a418dbade7`のH形・一様厚BOX・Otherについて、剛性As、検定Ad、二方向比とvon Misesへの接続を調べた。
[#417の用途分離・方向対応・二方向加算](用途別せん断面積と二方向検定_Issue417_2026-10.md)は維持し、本件では計算式・適用ガード・保存契約を変更しない。
**数値応答の維持と、設計での採用継続の承認は別である。** 規準の版・式・形状・適用条件との対応が未確定の箇所は採否を保留する。
平鋼では局所最大せん断応力に対する需要過小の有限例を公開APIで観測したため、具体是正を[#1396](https://github.com/hrntsm/SEPIKA/issues/1396)へ分ける。

以下は、公開元の方式説明、独立した弾性理論、現行コード・実行結果を区別した記録である。方式説明を規準本体の代替にせず、式の一致だけで適用範囲を承認しない。
本記録は実験・実建物によるValidationではない。CFT換算、角丸断面の幾何、異厚BOXの適用拡大は対象外。

## 二方向加算と同一点応力の境界

同じ断面点の直交せん断成分τ1、τ2と材軸方向法線応力σだけが非零の応力状態なら、von Mises相当応力は次式である。

```text
σeq² = σ² + 3(τ1² + τ2²)
```

非負の代表値a、bについて`a+b ≥ sqrt(a²+b²)`なので、**a、bが各点の成分絶対値の上界であり、σも同じ点で正しく評価されている場合**には、和を二乗する評価は二乗和以上になる。
これは代数の確認であり、現行の`abs(Q)/Ad`が各点の上界である証明ではない。剛性Asの流用、開/閉断面のせん断流、ねじれ、応力集中、評価点が異なるσの省略はこの不等式では補えない。
したがって「和なので任意断面で安全側」「二方向合成を採ったので平鋼の一方向需要も十分」とはしない。

| 現行の部材・形状 | VM用法線応力（σN=abs(N)/A、σs=abs(Mz)/Zstrong、σw=abs(My)/Zweak） | 結果への接続 |
| --- | --- | --- |
| H梁 | σN+σs max(H−2tf,0)/HとσN+σs+σwの2候補、共に同じτsum | Bendingへ両VM比と独立軸曲げ/単独曲げ比の最大。ShearはRy+Rz |
| H柱 | σN+σs max(H−2tf,0)/H。弱軸曲げσwはVMへ含めない | ShearへVM比とRy+Rzの最大、別のAxialBendingと全体最大 |
| BOX/Other梁 | σN+σs+σw | BendingへVM比と独立軸曲げ/単独曲げ比の最大。ShearはRy+Rz |
| BOX/Other柱 | σN+σs+σw | ShearへVM比とRy+Rzの最大、別のAxialBendingと全体最大 |

VM比は`sqrt(σ²+3τsum²)/ft`。N/Mを含む各方向のVM比全体を足す計算は行わない。
[#692](https://github.com/hrntsm/SEPIKA/issues/692)や[#743](https://github.com/hrntsm/SEPIKA/issues/743)の状態から共通化完了を推定せず、現ソースで柱梁の分岐と上記の差を確認した。
当時の#417の試験成功は、同一点の物理的成立の証明ではない。弱軸曲げをH柱VMへ追加する是正も、同一点応力分布・合否への影響を確認せず本件へ混ぜない。

## 平鋼の公開入口と独立した局所応力

直線・一様・無欠損の矩形平鋼、均質線形弾性、局所荷重点/材端から離れた初等梁のせん断分布を対象にする。
高さh、幅b、断面積A=bhに対し、曲げ応力の釣合いから`τ(y)=VQ(y)/(Ib)`、中立軸で`Q(0)=bh²/8`、`I=bh³/12`。
したがって最大値は`τmax=3V/(2A)`、最大応力に対応する面積は`2A/3`である。一方、二乗分布の面積積分による剛性用エネルギー等価面積は`5A/6`であり、両者を区別する。
これは規準の平均応力・塑性再分配の許容条件を同定するものではない。

`SectionShape::SteelFlatBar { width:100, thick:10 }.to_section`から公開`SteelDesign.check`を呼ぶ一時integration testで、次の4条件を実測した。
材料は直接入力F235 N/mm²、短期、座屈長さ0、N=My=Mz=0、断面積1000 mm²。短期fs=235/√3=135.677313259562 N/mm²。

| 用途・せん断 [N] | 現行As=Ad [mm²] | 現行τ [N/mm²] | 全体検定比・判定 | 独立τmax/fs |
| --- | ---: | ---: | --- | ---: |
| 梁・Qy=100000/Qz=0 | 833.3333333333334 | 120 | 0.884451476205384・適合 | 1.105564345256730 |
| 梁・Qy=0/Qz=100000 | 同上 | 120 | 同上 | 同上 |
| 柱・Qy=100000/Qz=0 | 同上 | 120 | 同上 | 同上 |
| 柱・Qy=0/Qz=100000 | 同上 | 120 | 同上 | 同上 |

線形弾性の局所最大応力150 N/mm²に対して現行需要は20%小さく、同じfsで最大応力を照査する条件では合否が反転する。梁のBendingに含まれるVMも0.884451476205384であり、独立曲げ・軸力検定はこの有限例の不足を捕捉しない。
これは全平鋼の規準違反・実建物の破壊、又は全Other形状の一律20%過小を認定するものではない。

[#1396](https://github.com/hrntsm/SEPIKA/issues/1396)では、平鋼の最大/平均応力と許容値の採用条件を確定し、検定Adを剛性Asから分離するか、確定できない条件を理由付き未算定にする必要がある。
丸鋼の形状算定As=0.9A、その他の板組形状、直接供給As、非正As時のfallback Aは別々に評価する。全Otherを一律1.5係数へ置換しない。

| 初期せん断剛性 | core `section_shape/builder.rs`で形状Asを作成、element `frame/beam/construct.rs`で断面表(as_z,as_y)を局所方向へ対応させてGAに用いる。供給断面性能のAsは別入力。AdやRy+Rzを解析Asへ戻す処理はない |

| ブレース・未対応形状 | ブレースは軸力検定で、今回のτsum検定を適用しない。単一リップ溝形、異厚BOX、不成立BOX、圧縮山形等の既存の理由付き未算定を解除しない |

H/BOXの現行数値応答と#417の既完了は維持する。規準と対象条件が確定するまで、設計での採用継続の承認は保留する。
Otherは平鋼の具体是正を別に追跡し、それ以外の形状も現行比だけで局所せん断の安全確認を完了しない。
必要な制限を今後コードに導入するか、どの条件でAdを採るかは是正課題で決める。本件の文書上の注意を、未算定ガード実装済みと読み替えない。

## 残る照合と再判定条件

- H/BOXの剛性As：剛性を目的とした規準本文の式・記号・係数と形状域を、1973/2005/2019等の版ごとに対応させる。検定面積との寸法一致では代替しない。
- H/BOXの検定Ad：ウェブせい、フランジの最大/平均、フィレット、冷間成形/溶接、矩形と角Rの範囲を規準・鋼管資料の式と確認する。現行とは別のQ/(ht)の定義が得られても、同じ許容値・断面条件で比較してから採否を決める。
- 二方向合成：規準の応力成分と同一点の断面応力を照合し、代表せん断が点応力の上界になる条件、曲げ/軸力の同時作用を確認する。単一τのVM式からτsumの規定を推定しない。
- Other：形状ごとの応力分布と許容値、直接供給Asの用途、fallback Aの成立範囲を確認する。平鋼の上記有限例は具体是正に分離し、未確認全体を解消済みにしない。

同じ未確認事項の調査Issueを重複作成しない。新たな具体不一致が対象条件・独立期待値とともに確定した時だけ最小の是正課題に分ける。[#697](https://github.com/hrntsm/SEPIKA/issues/697)の原典・Validation残項目と#417の完了状態を混同しない。
