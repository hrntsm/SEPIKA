### 断面検定の有限比較

全例でF=235 N/mm²を直接入力し、E=205000 N/mm²、ν=0.3、短期とした。短期の比較値は `ft=235 N/mm²`、`fs=135.677313259562 N/mm²`。公開 `SteelDesign::check` に材長3000 mm、評価位置0.5、2019年版選択、梁横補剛間隔1000 mmを与えた。表の `N` は引張正、`Qy` がせい方向に作用する強軸せん断、`Qz` が幅方向に作用する弱軸せん断、`Mz` が強軸曲げ。表にない断面力は0。

| 断面・用途・断面力 | 現行の全体検定比 | 独立比較の比 |
| --- | ---: | ---: |
| 直角H 400×200×8×13 mm、大梁、Qy=420 kN | 1.034619 | 0.967369（規準解説 式(10.1.2)の単独せん断） |
| 同H、柱、N=77 kN、Mz=167 kN·m、Qz=365 kN | 0.992447（軸曲げ比0.796165） | 1.003062以上（同一フランジの局所von Mises） |
| 同H・同断面力、大梁 | 1.018010 | 同上 |
| 直角・一様厚BOX 300×200×12 mm、柱／大梁、Qy=850 kN | 0.945783 | 1.058095以上（局所せん断） |
| 丸鋼D40 mm、柱／大梁、QyまたはQz=140 kN | 0.912365 | 1.136947（円中心の局所せん断） |
| 同丸鋼、柱／大梁、Qy=140 kN、Qz=−10 kN | 0.977534 | 1.139843（円中心の局所せん断） |

- **H梁の規準比較。** 同じ `fs` に対し、規準解説の `Htw=3200 mm²` で `τ=131.25 N/mm²`、現行の `(H−2tf)tw=2992 mm²` で `τ=140.374332 N/mm²`。他の断面力がないこの梁では、現行の代表せん断応力度が同解説式より大きい。梁全せいの式への変更や、柱・弱軸・他形状への援用には、それぞれの採用判断を要する。
- **H柱の局所比較。** 一様・無欠損の均質線形弾性材のうち、載荷点・拘束位置から離れ、ねじりがない断面を想定した。断面積8192 mm²、強軸の断面二次モーメント229648682.667 mm⁴、弱軸の断面二次モーメント17349290.667 mm⁴。幅方向座標5 mm（ウェブ端4 mmの外）で上フランジの端側だけを切る。切断厚さ13 mm、切り出し部分の弱軸についての断面一次モーメントは `13(100²−5²)/2 mm³`。材軸方向釣合いから平均せん断成分は104.928641 N/mm²、同じ切断線の平均法線応力度は `N/A+Mz(200−13/2)/Istrong=150.112174 N/mm²`。その平均成分のノルム `sqrt(σ̄²+3τ̄²)` は同じ線上の局所相当応力の最大値以下なので、分布一定を仮定せず下限を比較できる。この例の `My` は0であり、弱軸曲げの加算だけでは柱のフランジでの不足を解消できない。
- **BOXの局所比較。** 同じ弾性・載荷条件で、断面二次モーメントは `(200·300³−176·276³)/12=141639552 mm⁴`、中立軸より上の部分の断面一次モーメントは `(200·300²−176·276²)/8=574128 mm³`。中立軸で対向ウェブを横切るせん断成分の平均は、材軸方向釣合いから `Qy·574128/(141639552·24)=143.559477 N/mm²`。少なくとも一点のせん断応力度の絶対値はこの平均以上となる。現行の直角BOXの検定面積6624 mm²では128.321256 N/mm²。正の角R、冷間成形、他方向と同時に力を受ける状態への適用は未確認。
- **丸鋼の局所比較。** 一様な等方弾性の中実円について、円中心でのせん断応力度の大きさは `(3+2ν)/(2(1+ν))·hypot(Qy,Qz)/A`（Steinboeckほか 2013、著者版 式(3)、式(5d)、§4.4の均質中実で `B(r)=−R²`）。一方向で154.257868 N/mm²、二方向で154.650882 N/mm²。現行の0.9Aを使う代表値はそれぞれ123.787178、132.629119 N/mm²であり、後者では方向別の和でも円中心の応力に達しない。短期許容値は直接Fのもとでの共通比較値で、丸鋼柱・大梁への設計上の適用根拠は確認していない。[著者公開版](https://www.acin.tuwien.ac.at/fileadmin/cds/pre_post_print/steinboeck13b.pdf)

局所比較の判定の反転は、同一許容値で局所弾性応力を照査する条件で確認した。具体是正は、[中実丸鋼の検定面積 #1452](https://github.com/hrntsm/SEPIKA/issues/1452)、[直角・一様厚BOXの純強軸せん断 #1453](https://github.com/hrntsm/SEPIKA/issues/1453)、[H柱の弱軸せん断と軸力・強軸曲げ #1454](https://github.com/hrntsm/SEPIKA/issues/1454)で追跡する。これらの例は部材の応力全長分布、実建物、試験体の挙動、規準の全検定項目に対する適合性を評価していない。丸鋼以外のOther（溝形・T形・山形・形状なし）の局所応力、供給Asや全断面積代替の適用条件は引き続き照合する。

### 剛性Asの有限比較

せん断ひずみエネルギーから定義する面積を `A_E=Q²/∫(τ₁²+τ₂²)dA` とする。せん断の代表応力度を評価する検定面積と目的が異なる。[エネルギーから断面係数を求める定式化](https://www.ibs.kit.edu/download/Mit_2001-06.pdf)

- 上記直角Hの弱軸せん断のみを考える。幅方向 `4<|z|<100 mm` の上下フランジで、厚さ平均せん断は同じ端側の釣合いより `Qz(100²−z²)/(2Iweak)`。厚さ方向について平均の二乗は二乗の平均以下なので、その二乗をこの外側フランジ領域だけで積分しても `A_E ≤ 4692.909 mm²` となる。SEPIKAの剛性用 `2Btf=5200 mm²` はこの上限を約10.8%上回る。これは同じGでの断面せん断剛性の比較であり、部材の全変形や骨組の荷重分担は算定していない。
- 丸鋼D40で、同じ仮定とν=0.3のエネルギー等価係数はSteinboeckほかの式(18)で `κ=6(1+ν)²/(7+14ν+8ν²)=0.850671`。現行の剛性用0.9、局所応力に対応する面積係数 `2(1+ν)/(3+2ν)` とはそれぞれ異なる。[著者公開版](https://www.acin.tuwien.ac.at/fileadmin/cds/pre_post_print/steinboeck13b.pdf)

Hの強軸、BOXの両軸を含む剛性式の採用条件、1973年版・2005年版の該当条文と版間のつながりは未確定。2019年版 §10.1 の検定式との寸法の一致は、剛性式の採用根拠にならない。冷間成形角形鋼管は[2018年版設計・施工マニュアル](https://www.bcj.or.jp/publication/detail/3/)を書誌で確認し、本文の寸法定義と適用条件は照合待ち。二方向の加算規約の適用域、軸力・曲げとの同時作用についても、同一点の成分上界が成立する範囲と規準の照合を継続する。

公開APIの一時integration test `cargo test -p sepika-design-jp --test issue951_original_source_probe --locked -- --nocapture` は1件・内部11条件で成功した。独立比較の値は断面幾何、材軸方向釣合いまたは弾性解から別に求め、実行では公開結果を独立した定数と許容差 `1e-12` で比較した。

## H形鋼柱の是正後の検証（Issue #1454）

2019年規準の5.1(2)解説 p.49・図5.1.1は、通常のH形断面でウェブ面内に作用するせん断のウェブ平均と、細長い長方形断面のみで負担する場合の最大値を対比する。5.5 式(5.24)（p.14、解説 pp.59–60）は同一箇所の平面応力を扱い、5.6の短期許容引張応力度は長期値の1.5倍となる。11.9(4)（p.27、解説 p.97）は充腹柱の軸力と曲げを6.1・6.2へ委ねる。6.2 式(6.3)・(6.4)（p.15、解説 p.61）の評価は引張側フランジと部材の横座屈である。6.3はボルト類を対象とする。これらからH形鋼柱の弱軸せん断に対するフランジ内の公称応力度分布、フィレット半径の取扱い、組合せ応力度が最大となる点は確定できない。[規準の書誌](https://ndlsearch.ndl.go.jp/books/R100000002-I030037737)

[公開計算方式説明 Ver.5.1](https://www.structure.jp/manual/be513.pdf) §2.5.7(3)、本文 pp.57–58は、弱軸のフランジに対して図2.5.7-1に係数1.5を示し、曲げの各方向の断面係数から得た法線応力度と単一の代表せん断応力度を組み合わせる。上下フランジの面積を1.5で除した値を使い、#1454の寸法・短期荷重で外縁の法線応力度を組み合わせると比は1.0180097018となる。この方式説明には断面内の弱軸せん断分布や、フィレットの評価位置が示されていない。

同例でウェブの負担を省いた同寸の2枚の矩形フランジにQzを等分すると、薄肉モデルの幅方向の放物線分布は各フランジの幅中央で105.28846154 N/mm²となる。引張側フランジ中心線（せい方向193.5 mm、幅方向0 mm）で組み合わせた比は1.0051082318。ウェブの弱軸断面二次モーメントも含む切断線の釣合いでは、幅方向5 mmでの同一切断線の平均成分のノルムを許容引張応力度で除した値が1.0030620773となる。後者は切断線内の局所弾性応力の最大に対する下限であり、公称値や最大点の座標は与えない。前者は薄肉近似の比較であり、規準が指定する公称値としては採用しない。適用制限の判断は[ADR 0115](../adr/0115-h-column-weak-axis-combined-stress.md)を参照する。

[断面検定の公開入口](../../crates/sepika-design-jp/tests/steel_h_column_combined.rs)では、上記の直角H 400×200×8×13 mm・F235 N/mm²・材長3000 mmに N=77 kN、Mz=167 kN·m、Qz=365 kN が作用する短期の再現入力で、理由付き未算定を確認する。Qz=0の対照では、独立算術の断面諸量 A=8192 mm²・Z=1148243.413333333 mm³、横座屈の弾性限界モーメント824185820.619118 N·mm（C=1、G=E/2.6）、短期 fb=192.337746536794 N/mm²から、従来の軸曲げ比 0.7961649672 と一致する。これは既存式の維持を確認する比較で、規準6.2の式(6.3)・(6.4)は同じ応力と許容値でもそれぞれ0.6588891890・0.7072981448となる。軸曲げ式自体の規準への適合確認とは区別する。

[通常GUIの回帰](../../crates/sepika-app/src/app/shear_area_acceptance_tests.rs)と[MCPジョブの回帰](https://github.com/hrntsm/SEPIKA/blob/8ae832fa7b87dc61dfd03198a1a4bdbbb2eca0cf/crates/sepika-mcp/src/job/design_check.rs)では、同じ断面・材長に柱頭荷重を与えた片持ち柱の実解析から未算定理由を確認する。GUIは検定表、CSV、現行OVIKAの保存再読、および旧検定契約の失効と現行内力からの再検定を対象とする。実験・実建物を用いた妥当性確認は行っていない。

### 直角H形断面の局所弾性解

上記の直角H形、均質等方線形弾性、ポアソン比0.3、無ねじり、弱軸せん断のみがせん断成分を生むSaint-Venantモデルでは、ウェブとフランジの取り合いで局所せん断応力度に有限の上限がない。これは規準の設計用公称応力とは別のモデルである。[断面内せん断の境界値問題](https://www.ibs.kit.edu/download/Mit_1998-01%281%29.pdf)・[角部の固有モード](https://dauge.pages.math.cnrs.fr/publis/CoDa_comp.pdf)

せい方向を y、幅方向を z とし、半断面 y ≥ 0 でウェブ内法の半せい h=187 mm、全半せい H=200 mm、ウェブ半厚 a=4 mm、半幅 b=100 mm とする。断面の応力関数を Qz/Iweak で正規化し a²y/2 を加えた u は、ポアソン比を ν、κ=ν/(1+ν)、k=(b²−a²)/2 として Δu=−κy を満たす。境界値は y=0（|z| ≤ a）、ウェブの両側面 |z|=a（0 ≤ y ≤ h）、フランジ内側 y=h（a ≤ |z| ≤ b）で0、フランジの両端面 |z|=b（h ≤ y ≤ H）と外側面 y=H（|z| ≤ b）で −k(y−h) となる。同じポアソン方程式を満たす p=κy(h²−y²)/6 を使うと、p−u は調和となる。境界で p−u ≥ 0 が成り立つための条件 k ≥ κH(H+h)/6 はこの断面で成立し、p−u は内部で正、取り合いの頂点で0になる。

取り合いの内角3π/2を囲む十分小さい扇形で、円弧上の正の値を下から押さえる非負・非零の境界値を与え、半径辺では0となる調和関数と比較する。その第一固有モードの係数は正であり、頂点への二等分線上では p−u が距離の2/3乗の正の定数倍以上となる。p は頂点で0かつ滑らかなので、u の勾配は有界であり得ない。せん断応力度はこの勾配と有界な項からなり、軸力・強軸曲げの法線応力は有界。フィレット半径を正とする実断面の有限値や、規準の設計用公称応力の分布は、この証明からは決まらない。

## H形鋼柱の圧縮・軸力なしの是正後の検証（Issue #1483）

2019年規準の11.9(4)（p.27、解説 p.97）は、充腹柱に圧縮力と曲げが働く場合を6.1 式(6.1)・(6.2)へ委ねる。6.1（p.15、解説 p.61）は圧縮側の座屈を考慮した圧縮・曲げおよび引張側の曲げ・平均圧縮を扱い、弱軸せん断を受けるフランジの公称応力度分布を与えない。5.5 式(5.24)（p.14、解説 pp.59–60）は同一点の垂直応力度とせん断応力度を対象とし、許容引張応力度は5.1・5.6によって長期 F/1.5、短期 F となる。5.1(2)解説 p.49のウェブ平均は通常のH形断面のウェブ面内せん断に対する記述であり、弱軸のフランジ内分布、フィレット評価、組合せの最大位置を決められない。既存のせん断比は弱軸の代表値を含むため、同一点の評価と独立した規準上の不適合としても採用しない。[規準の書誌](https://ndlsearch.ndl.go.jp/books/R100000002-I030037737)

独立算術では、直角H-400×200×8×13 mm、材長3000 mm、F235 N/mm²、短期、位置0.5、Qz=365 kNとする。断面積8192 mm²、強軸断面係数1148243.413333333 mm³、弱軸断面二次モーメント17349290.666666664 mm⁴を用いる。ウェブ端のせい方向距離は187 mmで、旧合成に用いた弱軸の代表せん断は105.2884615385 N/mm²となる。局所弾性比較では、幅方向5 mmのフランジ切断線で厚さ平均のせん断応力度成分 Qz(100²−5²)/(2Iz)=104.9286414630 N/mm²を得る。同じ切断線で圧縮側の平均法線応力度は、軸力成分の絶対値にせい方向193.5 mmに対応する曲げ成分を加える。

| N [kN] | Mz [kN·m] | 旧合成比 | 同一切断線の厚さ平均成分による局所弾性比の下限 | 既存の軸曲げ比 |
| ---: | ---: | ---: | ---: | ---: |
| −77 | 167 | 0.9924467273 | 1.0030620773 | 0.8075119088 |
| 0 | 177 | 0.9891224156 | 1.0004290927 | 0.8014469492 |

右端の比較では短期 fc=183.0658305530 N/mm²（圧縮時）、短期 fb=192.3377465368 N/mm²を使う。厚さ平均の成分から得た比は局所弾性応力の最大の下限であり、規準判定には用いない。フィレットのある断面の最大値や公称応力度への換算も扱わない。

[公開断面検定の回帰](../../crates/sepika-design-jp/tests/steel_h_column_combined.rs)は両例の理由付き未算定と Qz=0 の対照での軸曲げ比を照合する。軸曲げと法定細長比が独立に不適合となる別入力では、各比と組合せ未算定理由の併存を検証する。軸曲げの比較は既存式のVerificationであり、規準6.1への全面適合を確認するものではない。[GUI回帰](../../crates/sepika-app/src/app/shear_area_acceptance_tests.rs)は片持ち柱を実解析し、検定表、CSV、保存再読と旧検定失効後の再検定を対象とする。[MCP回帰](https://github.com/hrntsm/SEPIKA/blob/8ae832fa7b87dc61dfd03198a1a4bdbbb2eca0cf/crates/sepika-mcp/src/job/design_check.rs)は未算定の位置・理由と独立不適合の集計を確認する。

2026-11-18、基点`8e0989427fac0165f92ce1242fa277a418dbade7`のH形・一様厚BOX・Otherについて、剛性As、検定Ad、二方向比とvon Misesへの接続を調べた。

平鋼では局所最大せん断応力に対する需要過小の有限例を公開APIで観測したため、具体是正を[#1396](https://github.com/hrntsm/SEPIKA/issues/1396)へ分ける。

## 二方向加算と同一点応力の境界

同じ断面点の直交せん断成分τ1、τ2と材軸方向法線応力σだけが非零の応力状態なら、von Mises相当応力は次式である。

```text
σeq² = σ² + 3(τ1² + τ2²)
```

非負の代表値a、bについて`a+b ≥ sqrt(a²+b²)`なので、**a、bが各点の成分絶対値の上界であり、σも同じ点で正しく評価されている場合**には、和を二乗する評価は二乗和以上になる。
これは代数の確認であり、現行の`abs(Q)/Ad`が各点の上界である証明ではない。剛性Asの流用、開/閉断面のせん断流、ねじれ、応力集中、評価点が異なるσの省略はこの不等式では補えない。
したがって「和なので任意断面で安全側」「二方向合成を採ったので平鋼の一方向需要も十分」とはしない。

| 現行の部材・形状 | VM用法線応力（σN=abs(N)/A、σs=abs(Mz)/Zstrong、σw=abs(My)/Zweak） | 結果への接続 |
| --- | --- | --- |
| H梁 | σN+σs max(H−2tf,0)/HとσN+σs+σwの2候補、共に同じτsum | Bendingへ両VM比と独立軸曲げ/単独曲げ比の最大。ShearはRy+Rz |
| H柱 | σN+σs max(H−2tf,0)/H。弱軸曲げσwはVMへ含めない | ShearへVM比とRy+Rzの最大、別のAxialBendingと全体最大 |
| BOX/Other梁 | σN+σs+σw | BendingへVM比と独立軸曲げ/単独曲げ比の最大。ShearはRy+Rz |
| BOX/Other柱 | σN+σs+σw | ShearへVM比とRy+Rzの最大、別のAxialBendingと全体最大 |

VM比は`sqrt(σ²+3τsum²)/ft`。N/Mを含む各方向のVM比全体を足す計算は行わない。
[#692](https://github.com/hrntsm/SEPIKA/issues/692)や[#743](https://github.com/hrntsm/SEPIKA/issues/743)の状態から共通化完了を推定せず、現ソースで柱梁の分岐と上記の差を確認した。
当時の#417の試験成功は、同一点の物理的成立の証明ではない。弱軸曲げをH柱VMへ追加する是正も、同一点応力分布・合否への影響を確認せず本件へ混ぜない。

## 平鋼の公開入口と独立した局所応力

直線・一様・無欠損の矩形平鋼、均質線形弾性、局所荷重点/材端から離れた初等梁のせん断分布を対象にする。
高さh、幅b、断面積A=bhに対し、曲げ応力の釣合いから`τ(y)=VQ(y)/(Ib)`、中立軸で`Q(0)=bh²/8`、`I=bh³/12`。
したがって最大値は`τmax=3V/(2A)`、最大応力に対応する面積は`2A/3`である。一方、二乗分布の面積積分による剛性用エネルギー等価面積は`5A/6`であり、両者を区別する。
これは規準の平均応力・塑性再分配の許容条件を同定するものではない。

`SectionShape::SteelFlatBar { width:100, thick:10 }.to_section`から公開`SteelDesign.check`を呼ぶ一時integration testで、次の4条件を実測した。
材料は直接入力F235 N/mm²、短期、座屈長さ0、N=My=Mz=0、断面積1000 mm²。短期fs=235/√3=135.677313259562 N/mm²。

| 用途・せん断 [N] | 現行As=Ad [mm²] | 現行τ [N/mm²] | 全体検定比・判定 | 独立τmax/fs |
| --- | ---: | ---: | --- | ---: |
| 梁・Qy=100000/Qz=0 | 833.3333333333334 | 120 | 0.884451476205384・適合 | 1.105564345256730 |
| 梁・Qy=0/Qz=100000 | 同上 | 120 | 同上 | 同上 |
| 柱・Qy=100000/Qz=0 | 同上 | 120 | 同上 | 同上 |
| 柱・Qy=0/Qz=100000 | 同上 | 120 | 同上 | 同上 |

線形弾性の局所最大応力150 N/mm²に対して現行需要は20%小さく、同じfsで最大応力を照査する条件では合否が反転する。梁のBendingに含まれるVMも0.884451476205384であり、独立曲げ・軸力検定はこの有限例の不足を捕捉しない。
これは全平鋼の規準違反・実建物の破壊、又は全Other形状の一律20%過小を認定するものではない。

[#1396](https://github.com/hrntsm/SEPIKA/issues/1396)では、平鋼の最大/平均応力と許容値の採用条件を確定し、検定Adを剛性Asから分離するか、確定できない条件を理由付き未算定にする必要がある。
丸鋼の形状算定As=0.9A、その他の板組形状、直接供給As、非正As時のfallback Aは別々に評価する。全Otherを一律1.5係数へ置換しない。

## 残る照合と再判定条件

- H/BOXの剛性As：剛性を目的とした規準本文の式・記号・係数と形状域を、1973/2005/2019等の版ごとに対応させる。検定面積との寸法一致では代替しない。
- H/BOXの検定Ad：ウェブせい、フランジの最大/平均、フィレット、冷間成形/溶接、矩形と角Rの範囲を規準・鋼管資料の式と確認する。現行とは別のQ/(ht)の定義が得られても、同じ許容値・断面条件で比較してから採否を決める。
- 二方向合成：規準の応力成分と同一点の断面応力を照合し、代表せん断が点応力の上界になる条件、曲げ/軸力の同時作用を確認する。単一τのVM式からτsumの規定を推定しない。
- Other：形状ごとの応力分布と許容値、直接供給Asの用途、fallback Aの成立範囲を確認する。平鋼の上記有限例は具体是正に分離し、未確認全体を解消済みにしない。
