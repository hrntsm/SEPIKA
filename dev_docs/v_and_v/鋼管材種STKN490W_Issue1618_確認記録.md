# STKN490Wの標準材種としての取扱いと基準強度（#1618）

## 原典照合

| 資料 | 確認結果 |
| --- | --- |
| 『2025年版 建築物の構造関係技術基準解説書』9.2、平成12年建設省告示第2464号第1の表（pp.569–570）と表の注記（p.572） | JIS G 3475-1996の材種として STKN400W・STKN400B・STKN490B を掲載する。STKN490B の基準強度 \(F\) は厚さ40 mm以下で325 N/mm²、40 mm超100 mm以下で295 N/mm²。STKN490W の種類記号または基準強度の記載はない。 |
| 日本建築学会『鋼構造許容応力度設計規準』第1版、4.1解説（p.47）、5.1表5.1（p.9） | 種類記号を挙げる4.1解説は上記3種を掲載する。表5.1の STKN400・STKN490 は系列名で、STKN490 の \(F\) は告示の上記板厚区分と一致する。系列名は追加の種類記号を認める根拠にはならない。 |
| 日本建築学会『鋼構造接合部設計指針』第4版、付録1の1.2 表A1.2（p.378） | JIS G 3475 の抜粋は上記3種を掲載する。STKN490B の掲載厚さは2–100 mm。降伏点または耐力の下限は40 mm以下325 N/mm²、40 mm超100 mm以下295 N/mm²であり、上記告示の \(F\) と一致する。 |

指定箇所から STKN490W を標準材種とする根拠は確認できない。照合範囲は上の掲載箇所に限り、他版のJIS原文や個別の国土交通大臣認定の有無は調べていない。存在しないとは断定しない。個別認定品などを入力する場合は、採用する製品の形状と実板厚、基準強度の適用条件を設計者が認定資料などで別途確認する。数値を直接入力して計算できることは、規格適合や認定の確認を意味しない。

## 材料入力と検定

[#1877](https://github.com/hrntsm/SEPIKA/pull/1877)（`e11f1e5c6`）で、共通鋼材表の STKN490 系列から W の種類記号を除外済みである。本件で標準材種の選択ロジックは変更しない。

- **材種名からの標準物性の復元** — `standard_material_properties` は STKN490B に標準物性（`fy=325 N/mm²`、40 mm以下の値）を返す。STKN490W には標準物性を返さない。これはGUIのプリセット一覧とは別の入口で、材料テーブルの鋼材プリセット一覧には STKN490B、STKN490W のいずれもない。
- **直接入力** — 材料テーブルは「直接入力」で指定した名称・区分・E・ν・ρ・Fyを `AddMaterial` に渡し、その値がモデルに保持されることをコードで確認した。検定が採用する \(F\) はモデルの `fy` 欄への書き戻しではない。STKN490B は登録材種なので実板厚で表を引き直し、STKN490W は未登録の名称として正の有限値で明示された `fy` を用いる。どちらも名称による材種の書換えは行わない。
- **検定の試験条件** — 外径400 mm、実板厚40 mmまたは41 mm、柱長3,000 mmの円形片持ち柱。柱頭の純引張需要は20,000 kN。CFTはFc24と強軸・弱軸の座屈長さ各6,000 mmを指定する。直接入力例の `fy=277 N/mm²` は挙動確認用で、STKN490W に採用すべき値ではない。

鋼管断面積は \(A_s = \pi t(D-t)\)。長期許容引張応力度は鋼構造許容応力度設計規準5.1の式(5.1)による。長期許容引張力は鋼管のみの \(A_s F/1.5\)、CFT終局引張耐力は \(N_{tu}=A_s F\)。下表は独立に算出した比・耐力と公開検定結果を照合した値である。いずれもこの需要に対して不適合となる。

| 材料入力 | 厚さ [mm] | 採用 \(F\) [N/mm²] | 通常鋼管・CFTの長期許容検定比 | CFT終局 \(N_{tu}\) [kN] |
| --- | ---: | ---: | ---: | ---: |
| STKN490B（標準物性の復元、または直接入力 `fy=277`） | 40 | 325 | 2.040448 | 14,702.654 |
| 同上 | 41 | 295 | 2.199232 | 13,641.125 |
| STKN490W（直接入力 `fy=277`） | 40 | 277 | 2.394027 | 12,531.185 |
| 同上 | 41 | 277 | 2.342142 | 12,808.785 |

STKN490W でE・ν・ρを入力し、`fy` を空欄にすると、通常鋼管は鋼材の基準強度を決定できず、許容応力度検定の入口で部材と材種名を含む `fy` の入力エラーになる。CFTは通常の解析準備で部材IDと鋼管材料の診断を返す。許容応力度検定に内力を別途渡すと各位置が鋼管材料の理由付き未算定となり、終局検定の入口では鋼管のF値が未設定または不正とのエラーになる。いずれも STKN490B の値では補完しない。

## 検証範囲と残課題

円形鋼管の公開入口で、解析準備と線形静的解析（`Analysis::prepare`・`linear_static`）、許容応力度検定（`run_member_design_checks`）、CFT終局検定（`collect_cft_ultimate_checks`）を対象とした。CFTの未入力ケースで許容応力度検定の診断を確認するため、同一形状で明示 `fy` を持つ対照ケースから得た内力を使った。OVIKAの保存・読込は、材料名から物性を再構成せずモデルをそのままシリアライズ・デシリアライズすることをコードで確認した。GUI操作とOVIKAの保存・読込は実行していない。ST-Bridgeは対応終了のため対象外。100 mm超の板厚でのCFT検定は実行していない。CFTファイバー非線形解析における板厚上限の扱いは [#1694](https://github.com/hrntsm/SEPIKA/issues/1694) の対象で、本検証とは区別する。

## 再現手順

Windowsのstable 1.100.0で、専用のCargoターゲットディレクトリを使って実行した。

```powershell
cargo test --locked --offline -p sepika-core --lib steel_names_
cargo test --locked --offline -p sepika-design-jp --test stkn490w_material
```

共通材種表は `supported_steel_names_restore_stock_properties_and_f_values` と `unsupported_steel_names_do_not_restore_stock_properties_or_f_values` の2件が成功した。公開入口は `stkn490w_requires_explicit_strength_in_steel_and_cft_column_checks` の1件が成功し、鋼管・CFT各2板厚で4種の材料入力を照合した。
