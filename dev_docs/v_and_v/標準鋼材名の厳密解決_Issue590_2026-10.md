# 標準鋼材名の厳密解決（Issue #590）

## 対象と参照

標準物性復元と板厚付きF値の名称認識を検証する。
現在仕様は[鋼材名の対応範囲](../../docs/calc_basis/02_材料/04_標準材料一覧.md#鋼材名の対応範囲)を正とする。
SM400A/B/CとSM490A/B/C/YA/YBの区別の参照は、日本製鉄の
[2025年9月改訂 建設用資材ハンドブック・平鋼 PDF1頁](https://www.nipponsteel.com/product/construction/handbook/pdf/3-52.pdf)と
[日鉄スチールの製造規格表](https://www.shapes.nipponsteel.com/product/spec-manufacturing/)である。
委任前調査ではPDF本文抽出と製造規格表を照合した。PDFスクリーンショット取得は失敗し、原画像照合は未実施。
単一メーカーの製造範囲を全JIS種類の網羅性の証明としない。

## 独立期待値と実入口

許可・拒否表は本番resolverやSTEEL_GRADESから生成せず、テストにliteralで記述する。
許可表は全既存bare分類名、SM400A/B/C、SM490A/B/C/YA/YB、SN/STKN/SNR/SM520の既存suffixを含む。
前後空白を付けた入力にも同じ標準E=205000、ν=0.3、密度7.85e-9、fyを期待する。
拒否表はSM400YA/YB/XYZ、SN400XYZ、他の未対応suffix、余分文字、内部空白、小文字、空文字を含み、
標準物性とF値の両入口でNoneを期待する。
厚40/40.001mmのSM400=235/215、SM490=325/295等は既存数値表の回帰期待である。
全JIS種類・全厚みの基準強度表を原典から再証明した試験ではなく、特にSM490YA/YBの種類別強度表を保証しない。

| 試験 | 観測する契約 |
|---|---|
| `material_grade::tests::supported_steel_names_restore_stock_properties_and_f_values` | 独立許可表・前後空白・既存物性・板厚境界 |
| `material_grade::tests::unsupported_steel_names_do_not_restore_stock_properties_or_f_values` | 独立拒否表・両復元入口のNone |
| `stbridge::strength_tests::unknown_src_steel_grades_keep_metadata_without_stock_strength_or_mapping` | grade-only未知名・元metadata・report/強度診断・stock強度/密度/対応の合成なし |
| `stbridge::strength_tests::explicit_unknown_src_steel_keeps_all_properties_and_native_override` | 同名明示材料の物性/参照保持・重複なし・F入口None/CFT明示177・native採用の区別 |

STB試験は既存`sepika-io/tests/fixtures/strength_src.stb`のSN490Bを置換し、
公開`import_stbridge_with_report`で読み込む。grade-only試験のSM400YA/YB/XYZ、SN400XYZは
原gradeを残し未解決診断を返す。内蔵鋼材placeholderのfy=None、generic E205000、密度0を
標準物性復元と区別して確認する。`prepare_stb_strength_materials`を再実行しても認定しない。
明示SM400YA材料はE123456、ν0.27、密度6.1e-9、G45678、fy177をすべて保持する。
元grade-onlyの拒否は維持し、`native_material`を明示選択した場合だけnative_override=trueの177を確認する。

## 制限・未検証

これは名称認識と明示物性保持のVerificationであり、材料の実験Validationではない。
Fの数値表・厚み方針、#488の独立allowlist、未知時の一般235 fallback、別prefixによる強度割増係数、
材料区分推定は変更しない。OVIKAには新たな復元入口を追加しない。
全計算のfail-closed達成とは扱わない。種類別F表の原典完全照合、全厚み、実験Validationは未検証。
局所環境の容量制限により、以下は未実行とし最終headのCIで確認する。

| CI workflowの確認 | ローカル未実行理由 |
|---|---|
| ci.yml: workspace/default全試験、GUI/MCP/Parquet feature試験、io defaultのdoctest等、GUI単体check | 新たな多数の実行ファイル・feature依存のビルドが必要。容量制限のため直接変更したcore/io lib-testに限定 |
| ci.yml: workspace/feature clippy | 多数の構成のビルドは容量制限。core/io default all-targetsのみ実行 |
| ci.yml: audit・dependency-check | 依存変更なし。全適用CIで確認 |
| docs.yml: workspace全API文書、公開/deploy | 全クレート文書ビルドは容量制限。mdBook/check-docsまでローカル実行、公開は本件のローカル作業対象外 |

`cargo fmt`はCIと同じコマンドをローカル実行済み。新規依存は追加していない。
