# RC柱の曲げ降伏時における常時せん断力の算入（#1905）

[Issue #1905](https://github.com/hrntsm/SEPIKA/issues/1905) の照合記録。対象は短期地震時の安全確保用のRC柱QD1とQD1・QD2の小さい方を採る照査。製品の算定は変更していない。

## 原典の規定と適用境界

日本建築学会『鉄筋コンクリート構造計算規準・同解説』2024年版、第15条2項(3) ii) の本文 p.22 と、解説2項(3) iii) pp.178–179・解説図15.9を照合した。

- 本文(15.8)は、柱頭・柱脚の降伏曲げモーメントの絶対値の和を柱の内法高さで除す。柱頭では、接続梁端の降伏曲げモーメントの絶対値の和の1/2が柱頭の値より小さければ代用できる。最上階では1/2を掛けない。本文(15.8)自体には長期せん断の明示項がない。
- 本文(15.9)は長期荷重によるせん断力 QL と水平荷重によるせん断力 QE の割増し n·QE の和で、n ≥ 1.5 なら (15.8) によらなくてよい。解説は曲げ降伏による値とこの代替値の小さい方を採る考え方を示す。この記録では、図15.9(b)の中の記号と区別し、製品の名称どおり **QD1** を曲げ降伏側、**QD2** を(15.9)側と呼ぶ。
- 解説 pp.178–179の段落で QL が明示される式は(15.9)側であり、p.179冒頭は、通常の場合に QL を0とみなしてよい一方、特殊な荷重条件等で比較的大きなせん断力が常時作用する場合には設計用せん断力へ算入するよう求める。この記述から、(15.8)の候補に解析から得た QL を別項として直接加算することまでは断定できない。本文と解説の該当範囲には「比較的大きい」の数値閾値、そのときの柱QD1の加算式、作用位置・符号・包絡順序は示されていない。図15.9は降伏曲げの釣合いを示し、常時横荷重の分布を明記した図ではない。(15.7)の梁に認められる単純梁の QL を柱にそのまま流用する根拠にもならない。
- 図15.9(b)では左右の梁端で引張側が逆となる組合せを正負で比較する。上下反転候補の条件と候補値の比較は別件（[#1908](https://github.com/hrntsm/SEPIKA/pull/1908)）。損傷制御用の割増しのない解析せん断力も別件（[#1955](https://github.com/hrntsm/SEPIKA/pull/1955)）。

同書 pp.204–205 の計算例2（CB3柱、3階柱頭、Y方向）は、長期せん断力75 kNと地震時せん断力203 kNを使い、(15.9)の安全確保用需要を 75 + 1.5 × 203 = 379.5 kN（原典表示380 kN）とする。地震成分を同じにして QL だけを省くと304.5 kNで、丸め前の差は75 kNとなる。この例は(15.9)への算入を具体的に示すが、75 kNが適用閾値であることも、(15.8)の処理も示さない。

## 独立した断面の釣合い

同じ材端フェース間の、同一位置・同じ切断側・同じ局所方向の符号付きせん断力を比較する。例えば、常時荷重負担を含まない増分せん断が +100 kN、常時せん断が +30 kN なら、その状態の総せん断は +130 kN。増分が −100 kN で常時分が同じなら −70 kN。両方向の機構が同じ絶対値で成立するこの対称例の包絡は 130 kN であり、相殺する片方向の 70 kN だけでは不足する。方向別の終局曲げや機構が非対称なら、符号と絶対値を先に落として同じ扱いにはできない。Qy（Mzに対応）とQz（Myに対応）は、異なる局所軸の需要として照合する。

一方、両端の降伏曲げを**総曲げ**として釣り合わせたときは、同じ端部曲げを負担する常時成分をせん断にもう一度加えない。一定の符号対応で dM/dx = Q と置くと、内法区間 h′ のせん断の平均は両端の総曲げ差 ΔM/h′。区間に横荷重がなく QL が一定の場合、QL による曲げ差はこの平均に既に含まれる。ΔM/h′ に一定の QL を再加算する方法はこの前提では釣り合わない。増分として評価するなら、増分側の端曲げにも常時の端曲げを除いた値を使う。

独立例では、内法3.0 m、i材端フェースを x=0 とし、一方向の総曲げを −150 kN·m と +150 kN·m、逆方向ではその符号を反転した値に固定する。分布荷重なしとし、特殊な荷重条件の例として内法中央に常時横荷重60 kNを加える。切断の釣合いから左半のせん断は右半より60 kN大きく、曲げの釣合いから両半の平均は ±100 kN になる。したがって左・右の値は以下のとおり。荷重点では両側を区別する。荷重なしで断面需要の絶対値が一定の対照と比べ、この常時荷重を省くと最大需要を30 kN過小評価する。

| 常時横荷重 | 正加力の左／右（kN） | 負加力の左／右（kN） | 絶対値の包絡（kN） |
| --- | ---: | ---: | ---: |
| 0 kN（無視して差がない対照） | +100 / +100 | −100 / −100 | 100 |
| 60 kN（内法中央） | +130 / +70 | −70 / −130 | 130 |

例えば同じ許容値を仮に120 kNと置けば、100/120=0.833… から130/120=1.083… に変わる。さらに同じ支配位置で独立に求めた有効なQD2が135 kNなら、小さい方の選択でも100→130 kN。QD2が115 kNなら100→115 kNとなり、QD2側に切り替わる。この115、135 kNは需要選択を説明する仮定値で、同じ解析を実施した結果ではない。これは端部の総曲げと中間荷重が既知の自由体での力学検証であり、具体的な建物で両方向の機構が成立することや、許容値120 kNを示したものではない。60 kN、30 kN、30%のいずれも規準の閾値ではない。

## 現行の通常検定と時刻歴簡易検定

- **通常検定**（分岐元 fce6148b1）では、地震組合せの固定・積載・積雪荷重のうち有効係数がゼロでない項から設計用の静的重力参照を組み立てる。RC柱のQD1は、柱端の設計軸力が降伏曲げに影響することとは別に、同位置の長期せん断力を直接加算しない。QD2は同位置・同方向の重力参照 QL と総応答 Q から製品の式 `|QL| + n·|Q−QL|` を求める。Minは通常の有限な候補ではQD1とQD2の小さい方を採るため、QD2に長期せん断を入れていてもQD1が支配する場合の不足は解消しない。通常画面で重力参照の組立て自体に失敗した場合は、ルート2-1の入力を組み立てず、部材検定の呼出し後、安全確保時の報告を組立て失敗理由付きの未算定に置き換える（`skip_for_load_state`）。
- **通常の公開部材検定で参照表を渡した場合**でも、有効な配筋で軸力・曲げを算定できるRC柱の従来経路では、参照表に対象柱の行がなければQDを組み立てず、柱の行に検定位置の参照断面がなければ従来の需要関数が、いずれも解析総せん断の絶対値 `|Q|` を使う。参照断面があって必要方向の成分が非有限の場合は、断面が見つからない場合の `|Q|` 代替とは別である。床板付き梁候補に対する専用処理や軸力・曲げの境界条件にこの代替挙動を一般化しない。通常検定の重力参照不足の診断は [#1804](https://github.com/hrntsm/SEPIKA/issues/1804) で追跡する。
- **時刻歴簡易検定**では、長期荷重を初期状態に含めた非線形時刻歴の該当経路で安全確保用QDを用いる。QD1とMinの柱機構は柱端の応答軸力と重力参照軸力を使うものの、せん断需要は通常検定と同じく常時せん断を直接加算しない。QD2に必要な同位置・同方向の重力参照せん断力や柱機構に必要な柱端重力参照軸力を確認できなければ、依存する照査は未算定となる。線形、長期未載荷、別方式の照査をこのQD1の適用範囲に含めない。
- 分岐元では時刻歴で保存済み常時組合せを名称・種別で選ぶ。別件の [#1961](https://github.com/hrntsm/SEPIKA/pull/1961)（#1830の解決）では、実際の初期載荷と保存組合せの荷重ケース・有効係数を照合する。これは初期載荷の荷重条件の対応を確かめるもので、線形静的参照と非線形初期内力の一致を保証せず、柱QD1への算入も行わない。同じ初期荷重に対する両者の差は [#1958](https://github.com/hrntsm/SEPIKA/issues/1958) の対象。

根拠となる経路は、[通常検定の組立て](../../crates/sepika-app/src/app/actions/design/check.rs)、[公開部材検定](../../crates/sepika-design-jp/src/member_design_check.rs)、[時刻歴の最大応力に対する検定](../../crates/sepika-app/src/viewer/th_detail.rs)、[RC柱の検定](../../crates/sepika-design-jp/src/rc/column/mod.rs)、[共通の設計用せん断力](../../crates/sepika-design-jp/src/rc/design_shear.rs)。利用上の制限は[RC柱のせん断検定](../../docs/calc_basis/06_一次設計/02_04_RC柱のせん断検定.md)に記載済み。

## 公開部材検定での観測

分岐元 fce6148b1 の [既存RC柱機構テスト](../../crates/sepika-design-jp/tests/rc_column_mechanism.rs) の最上階柱モデル（`yielding_head_model()`）を用い、`run_member_design_checks` に次の断面力を渡した。力の入力単位はN、曲げとねじりはすべて0。位置は 0、0.5、1。どの位置でも重力参照と短期応答の軸力は −100,000 N（圧縮）、Qzは0。Qyだけを表の QL と QL + 200 kN にそれぞれ設定した。長さ・配筋・軸力・降伏候補は共通で、安全確保の短期検定を選択した。中央断面のせん断検定比に独立に得た許容せん断力270.029514 kNを乗じて、採用需要を確認した。

| 重力参照 Qy（kN） | 応答 Qy（kN） | QD1（kN） | Min（kN） | QD2（kN） |
| ---: | ---: | ---: | ---: | ---: |
| 0 | 200 | 177.001870 | 177.001870 | 300 |
| +30 | 230 | 177.001870 | 177.001870 | 330 |
| −30 | 170 | 177.001870 | 177.001870 | 330 |
| +100 | 300 | 177.001870 | 177.001870 | 400 |

一時プローブ `issue1905_probe` を同じテストファイルに追加し、`cargo test -p sepika-design-jp --test rc_column_mechanism --locked issue1905_probe -- --exact --nocapture` で対象1件・表の12組の一致を確認した。プローブは現行の未対応を恒久仕様に固定しないため製品のテストに残していない。断面力を直接与える公開検定の観測で、上記自由体を解析した結果でも、実モデルで適否が反転することの確認でもない。時刻歴についてはこの入力による再実行はせず、上記の共通需要算定と時刻歴の入力経路をコードで確認した。

同じモデル・位置で、重力参照の欠落も別の一時プローブで確認した。短期応答 Qy=230 kN、重力参照の有限な位置の Qy=30 kNとし、QD2を指定。重力参照の表が完全なら、中央断面の採用需要は330 kN。重力参照から中央断面だけを除くか、重力参照の表を空にして対象柱を除くと、いずれも中央断面の採用需要は解析総せん断の230 kNだった。`cargo test -p sepika-design-jp --test rc_column_mechanism --locked issue1905_missing_gravity_probe -- --exact --nocapture` で対象1件・3組を照合し、プローブはテストファイルに残していない。通常画面の組立て失敗時の処理と、参照成分に非有限値がある場合の分岐はコードを確認した。

## 後続で決めること

常時せん断の算入が必要な柱は、現行のQD1またはMinの適合表示だけで適否を確定しない。自動閾値を新設する根拠は確認できなかった。設計者が作用位置・方向・切断側、重力参照の荷重条件と取得可否を確認し、算入が必要か判断できる提示をまず検討する。評価が必要と分かった方向で、常時せん断または降伏機構との対応を確認できなければ、ゼロ補完やQD1の適合確定をせず、理由付きの未算定または別途照査を明示する案とし、成立が独立の他方向・他項目の不適合を消さない。

算入を実装するときは、端曲げの総量と増分、部材内の常時横荷重の分布、同一断面の符号、正負別に成立する候補、QD2の代替条件と包絡順序を確定してから、通常検定と時刻歴で個別に照合する。[#1962](https://github.com/hrntsm/SEPIKA/issues/1962) で追跡する。今回の範囲は規準と独立釣合いの限定Verificationであり、建物全体の機構同定、実験Validation、時刻歴全時刻の適否判定は行っていない。
