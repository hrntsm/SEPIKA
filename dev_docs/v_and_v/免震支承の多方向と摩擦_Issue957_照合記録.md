# 免震支承の水平二方向と摩擦用鉛直荷重の照合

[Issue #957](https://github.com/hrntsm/SEPIKA/issues/957)の限定照合。利用者向けの入力は[免震アイソレータ](../../docs/calc_basis/09_免震制振/01_免震アイソレータ.md)、復元力の式は[免震・制振ばねの復元力](../../docs/nonlinear/08_免震制振ばねの復元力.md)を正とする。

## 実利用範囲

| 入口 | 使用する値と処理 |
| --- | --- |
| GUIの「境界条件」・「部材」 | `isolator_props_fields` で共通入力。支点配置は `PlaceSupportIsolator` が固定接地節点との零長要素を生成し、部材追加は `AddIsolator` が指定2節点間に配置する。どちらも `ElementKind::Isolator` と `IsolatorAttr` に諸元を保持し、GUIのkN系をN系で保存する。 |
| GUIの「部材」の免震支承一覧 | `isolators_table` と `SetIsolatorPropsLocal` が保存諸元を変更する。種別・K1・K2・Qd・Kv・μを変更できる。Nの入力は新規配置フォームにある。 |
| GUIの設計表示 | `design_view` が `sepika_design_jp::isolator` から本数別低減率を読み、全4種に表示する。摩擦限界も同モジュールで表示する。解析要素は同じ非負の摩擦限界を諸元から別に算定する。 |
| 骨組の線形解析 | 線形組立が `build_behavior_with_axial_factor` から `IsolatorElement` を生成し、初期接線を使う。滑りや降伏による接線更新の検証入口は非線形解析側。 |
| 骨組の増分・非線形時刻歴 | 各ドライバが `build_nonlinear_behavior` から共通の `IsolatorElement` を使う。零長では局所部材軸を鉛直として構成し、非零長では節点を結ぶ方向を局所部材軸にする。以下の二方向とはその直交面の局所二軸を指す。 |
| 曲げせん断型質点系 | [PR #838](https://github.com/hrntsm/SEPIKA/pull/838)の別経路。 `sepika-job/src/lumped_mass/bending.rs` の入力検査は立体モデルの免震部材を対象外とする。 |
| ST-Bridge | `sepika-io/src/stbridge` で免震階を識別するパーサー処理を確認した。今回の摩擦諸元・低減率の入口はGUIと要素生成で追跡した。 |

天然ゴム・LRB・HDRは同じ局所二軸のバイリニアを使い、各軸の入力を本数で割らない。共通のひずみ係数を使う分岐でも、塑性履歴は各軸で保持する。弾性すべり支承は水平力ベクトルの合力で滑りを判定する。解析で `n_springs` を読んで剛性・耐力を選ぶ処理は確認されなかった。

[PR #1046](https://github.com/hrntsm/SEPIKA/pull/1046)の利用マニュアルの整理を引き継ぐ。[Issue #858](https://github.com/hrntsm/SEPIKA/issues/858)・[PR #870](https://github.com/hrntsm/SEPIKA/pull/870)で削除した未使用の柱梁材端ばね分岐とMSの重複データは、この免震要素の生成経路に含まれない。製品別HDR、転がり専用、球面すべり専用の削除済み分岐と、GUIに接続していないLRB区分冪乗・温度補正も今回の適用判定から外す。

## 剛性・耐力配分の独立計算

各一軸ばねが正負を負担するMSSを仮定し、水平面に角度 θᵢ = iπ/n（i = 0,…,n−1）で等角度配置する。単位ベクトル eᵢ に各ばね軸を取り、変位 u の射影 eᵢ・u を各ばねに与える。復元力ベクトルは各ばね軸力 fᵢ をその方向に戻した Σ fᵢeᵢ となる。加力方向 θ の初期剛性の投影和は同じ一軸剛性 k に対して k Σ cos²(θᵢ−θ) となり、n≥2では和がn/2となるため k/K=2/n が成立する。Kは目標の初期水平剛性 [N/mm]。

完全弾塑性の一軸ばねのうち加力方向と直交するものを除き、変位を十分に増やしてすべて降伏させると、加力方向の力は各軸降伏耐力 q [N] と Σ|cos(θᵢ−θ)| の積になる。これは最初のばねが降伏する時点の力とは異なる。θ=0かつnが偶数なら、軸を90度離れた組に分けた投影和が実装の Σ(cos+sin) に一致する。有限のnでは加力方向でこの降伏後の投影和が変わる。

| n | 初期剛性比 k/K | ばね方向 θ=0 の投影和 | 同方向の耐力比 q/Q | θ=π/(2n) の耐力投影和 |
| --- | --- | --- | --- | --- |
| 2 | 1 | 1 | 1 | 1.414214 |
| 4 | 0.5 | 2.414214 | 0.414214 | 2.613126 |
| 6 | 0.333333 | 3.732051 | 0.267949 | 3.863703 |
| 8 | 0.25 | 5.027339 | 0.198912 | 5.125831 |
| 16 | 0.125 | 10.153170 | 0.098491 | 10.202297 |

再現には、上のθᵢに対し各軸の `cos(θᵢ−θ)` を平方または絶対値にして合計する。方位角0と隣接軸の中間角の有限比較で、荷重履歴一般の等価性は確認していない。例えばn=8で軸方向に合わせたqを用いると、中間角の降伏後投影は目標Qの約1.01959倍になる。n=1では直交剛性が0で、表示剛性比2には二方向の等価性が成立しない。n=3を同じ等角度配置で扱うとθ=0の絶対値和は2だが、表示関数は `n/2` の整数切捨てによって耐力比1を返す。偶数本の式をそのまま奇数本の適用根拠にはできない。

## 解析要素の独立有限例

既存の `crates/sepika-element/src/springs/isolator/tests.rs` の `iso_model`、`laminated`、`friction` を利用した一時試験 `issue957_public_factories_direction_and_fixed_axial_load` で観測した。全ケースで要素を新規生成し、鉛直に配置した2節点のj端に下表のグローバル変位を1回与えた。 `build_behavior` の初期接線でX方向対角値がK1に一致し、 `build_nonlinear_behavior` の `Incremental`・`TimeHistory` でそれぞれ `update_state` と `internal_force` によりj端の3成分を取得した。n=2, 3, 8, 16の4通りで同じ入力を反復した。初期接線24点・非線形応答48組に対し、下表の独立期待値と各成分10⁻⁶ N以内で一致した（剛性は10⁻⁶ N/mm以内）。

| 支承・入力 | j端の変位 (X, Y, Z) [mm] | j端の力 (X, Y, Z) [kN] |
| --- | --- | --- |
| ゴム、K1=2 kN/mm、K2=0.2 kN/mm、Qd=100 kN | (100, 0, 0) | (110, 0, 0) |
| 同上、変位の大きさは同じ | (60, 80, 0) | (102, 106, 0) |
| すべり、K1=10 kN/mm、Kv=5000 kN/mm、μ=0.1、長期N=1000 kN | (9, 12, −0.1) | (60, 80, −500) |
| 同上 | (9, 12, +0.1) | (60, 80, +500) |
| 同上で長期N=0 kN | (9, 12, +0.1) | (0, 0, +500) |
| 同上で長期N=−1000 kNを要素に直接入力 | (9, 12, +0.1) | (0, 0, +500) |

ゴムでは各軸の降伏変位50 mmまでの力が100 kNであり、その後は超過変位に0.2 kN/mmを掛けて加える。等しい100 mmの変位に対し斜め方向の合力は約147.11 kN、軸方向は110 kNである。この有限例では軸別の履歴から斜め方向のせん断力が大きく出るが、建物によっては変位を過小評価する可能性もあり、二方向応答一般の安全側は判定できない。

すべりでは (90, 120) kN の弾性予測の大きさが150 kNなので、固定限界100 kNの円への射影から (60, 80) kN となる。鉛直荷重が独立に500 kNまたは1500 kNへ変わる仮想の圧縮接触で、同じμを仮定すると限界は50 kNまたは150 kNであり、固定100 kNは前者を上回り後者を下回る。これらの変動値は鉛直ばね試験の変位から接触反力を同定した値ではなく、固定モデルの力の上・下振れを示す算術例。入力Nを0以下にする処理で水平力が0になっても、Kvの引張側は作用する。

再現する場合は既存fixtureで表の諸元をセットし、 `LocalVec` のj端並進3成分（添字6〜8）に表の値を入れる。初期接線と出力の観測は上記のfactory呼び出しの順で行う。荷重制御の求解・水平回転を伴う履歴・収束・動的応答の検証はこの有限試験に含まない。製品別の実験Validationは未実施。

## 適用判断と再判定条件

- **現行要素を使用する条件。** ゴム系の独立二軸モデルは入力諸元または試験により、その方向特性で対象応答を評価できる範囲に用いる。連成降伏・等方の非線形応答が必要な場合は対象外。表示上の低減率を入力のK1・K2・Qdへ掛ける必要はない。
- **固定長期軸力を使用する条件。** 個々のすべり支承について圧縮接触が維持され、鉛直荷重の変動や面圧・速度等によるμの変化を省けることを、対象製品の認定・試験条件と荷重ケースから判断する。変動の一律許容率は確定できていない。引張・浮上り・再接触や有意な荷重依存を要する応答は現行モデルの適用範囲外。固定長期Nが応答の全指標を一律に安全側へ動かす根拠はない。
- **表示の是正。** ゴム系新規フォームがn=1および奇数を受理し、設計表示は解析上未使用の係数を「マルチシア」として弾性すべりを含め表示する。再現はゴム系をn=3で配置して設計表示を確認するか、既定諸元の弾性すべりを配置して同じ欄を確認する。実際の採用モデルを示す表示に改め、参考計算を残す場合は対象種別と偶数本の条件および解析非適用を明示する。 [#1438](https://github.com/hrntsm/SEPIKA/issues/1438)
- **長期軸力入力の是正。** 既定のゴム系を配置して「部材」の免震支承一覧の種別を弾性すべりへ変更すると、保存諸元のN=0が引き継がれ、μを入力してもQmax=0を保つ。同一覧にNの編集欄がない。境界条件の設置済み支承も諸元表示と撤去が入口となる。既定の `IsolatorProps` の種別だけを変更し、実際の `SetIsolatorPropsLocal::apply` に渡す一時試験でN=0とQmax=0を観測した。配置済みの弾性すべり支承でNを確認・変更できることを別途検証する。 [#1437](https://github.com/hrntsm/SEPIKA/issues/1437)
- **残る規準・認定資料。** 日本建築学会『免震構造設計指針』第4版（2013年）の復元力モデルおよび引張・鉛直荷重の条件、日本免震構造協会『時刻歴応答解析による免震建築物の設計基準・同マニュアル及び設計例』（2018年）の3.1・5.2〜5.4、告示の計算例が必要なら日本建築センターの『免震建築物の技術基準解説及び計算例とその解説』も該当本文を未確認。実建物への適用には、個々の免震材料認定番号と認定別添、長期・地震時の軸力範囲と支持接触、対象温度・面圧・速度での水平一方向／二方向の試験履歴を揃えて再判定する。 [日本建築学会の書誌](https://ndlsearch.ndl.go.jp/books/R100000002-I024938472)・[協会の目次](https://www.jssi.or.jp/bussiness/shuppan_detail/doc/12_mokuji.pdf)・[告示解説の書誌](https://www.bcj.or.jp/publication/detail/49/)
