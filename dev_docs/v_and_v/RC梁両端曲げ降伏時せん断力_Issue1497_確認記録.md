# RC梁の両端曲げ降伏時せん断力と静的終局検定

[Issue #1497](https://github.com/hrntsm/SEPIKA/issues/1497)の調査。対象は main `f91f398a` のRC矩形梁の静的・両端ヒンジ略算。状態🔶。部材荷重のない自由体の釣合いと、公開検定の結果を照合した。長期曲げの符号を終局時の降伏方向に用いることはできず、現行の反対側比較を通過する片持ち梁も確認した。

## 原典で確認した範囲

『2025年版 建築物の構造関係技術基準解説書』第2版第1刷（2026年2月11日、ISBN 978-4-86458-358-9）の奥付と下記の印刷ページをPDFから画像化し、式、記号、適用条件を確認した。[出版案内](https://kenbokyo.jp/book/item.html?bid=88)、[第2版の書誌](https://ndlsearch.ndl.go.jp/books/R100000136-I1970868940118834340)

- **pp.414–417、6.4.3 (1) 2) i)**。ルート2-1では、柱・梁の設計用せん断力に QL＋nQE と Q0＋Qy の小さい方を採用する。n の割増対象は一次設計用地震力による QE。Qy は両端に曲げ降伏が生じたときのせん断力で、Q0 は単純支持としたときの常時荷重によるせん断力。Q0 の算定上の単純支持と、Qy に必要な両端での曲げ伝達は別条件。RC規準（2024）の安全性確保のための許容せん断力と比較し、設計用せん断力に対する付着割裂も確認する。通し筋では同頁の許容せん断力の照査で付着照査を代替できる場合がある。p.417ではルート2-2の靭性確保にルート2-1の検討を参照している。
- **pp.698–699、付録1-3.1 (1) ⑥ a)、式(付1.3-5)**。矩形梁で引張鉄筋の降伏が圧縮コンクリートの破壊に先行する場合、曲げ耐力は 0.9×引張鉄筋断面積×降伏強度×有効せいで略算できる。引張側とその重心から圧縮縁までの距離を梁端ごとに用いる。過大な鉄筋比、過小なコンクリート圧縮強度、圧縮幅が有効せいに比べて著しく小さい場合は適否の検討が必要。Fc 18 N/mm²以上・SD390級以下では通常の引張鉄筋比2%未満が適用範囲で、SD490についても2%未満の記載がある。スラブ筋を上端引張の耐力に見込む場合は定着と有効幅を確認する。
- **pp.707–708、付録1-3.1 (2) ⑥ d)、式(付1.3-20)～(付1.3-22)**。一・二段目の付着信頼強度は上端筋の低減を反映し、二段目はさらに段による低減を受ける。設計用付着応力度は d_b×Δσ/[4(L−d)]。d_b は主筋径、Δσ は終局限界状態における両端での主筋応力度の差、L は内法長さ、d は有効せい。両端にヒンジが形成された後の付着割裂が部材種別や保有水平耐力に無視できない影響を与える場合は、RC規準（2024）16条の大地震動に対する検討が必要。例に短スパン梁のシアスパン比2未満や平均せん断応力度とFcの比が0.20超の場合が挙げられる。カットオフ筋を有する部材の付着割裂には付録の付着式を使えるが、同頁に挙げるせん断終局強度推定式による代用は適用外。
- **pp.422–426、6.4.4 (2) 1)～2)**。RC梁のせん断破壊と付着割裂破壊を脆性破壊として扱う。全体崩壊形、部分崩壊形、局部崩壊形、および崩壊形が形成されていない階に別途求める応力を区別している。柱・接合部・梁中央などの降伏や別の脆性破壊が先行する場合は、当該梁の両端が想定した方向で曲げ降伏するかを別に確かめる必要がある。

製品の静的検定は終局耐力から長期架構用組合せの最大絶対せん断力を控除する比較で、ルート2の QD の算定、Q0 と Qy の組合せ、RC規準での付着・定着の照査は別途必要。該当ページから、長期の曲げ符号を使って梁端の地震時の降伏方向を特定する条件や、製品の上下比較だけで適用できる一般条件は得られなかった。

## 独立した梁端の釣合い

内法長さ4.000 mの梁で、同じ断面符号の左・右梁端の曲げモーメントを M_i、M_j とする。梁区間内に横荷重と集中モーメントがないとき、せん断力は一定で、その絶対値は |M_j−M_i|/4.000。部材荷重があれば、端部曲げに対応する成分に加え、荷重分布に応じた位置別のせん断が生じる。

上端2-D19、下端4-D19、公称断面積286.5 mm²/本、SD345、有効せい550 mmの例では、引張鉄筋面積は上573、下1,146 mm²。式(付1.3-5)から上端引張の曲げ耐力は0.9×573×345×550＝97.854075 kN·m、下端引張は195.708150 kN·mとなる。左上端・右下端が引張降伏する場合、M_i＝−97.854075 kN·m、M_j＝＋195.708150 kN·m。せん断の絶対値は73.390556 kNで、地震作用を逆にして左右の引張側が入れ替わる場合もこの一様断面の例では同値となる。反曲点は左端から約1.333 m、逆向きでは約2.667 m。上端耐力を2倍すると48.927038 kNで釣合い値を約33%過小評価し、下端耐力を2倍すると97.854075 kNで約33%上回る。部材荷重と上限強度倍率はこの比較に加えていない。

逆符号で両端が曲げ降伏する場合、代表耐力が左右の降伏耐力の平均に等しいときに2倍式は釣り合う。両端が等耐力であれば、その耐力を使って表せる。代表耐力が左右の両方を下回らなければ、倍率を掛ける前の2倍式はこの端部曲げ成分の上界となる。これは仮定した端モーメントについての釣合いに限る。両端が実際にその耐力へ達するか、荷重によるせん断の分布、付着や定着の妥当性は、それぞれ確認を要する。

偏心や直接載荷による端モーメントのない自由端や、曲げを解放した端部では、支持・接続先への曲げ伝達を期待できない。接合部で曲げを伝達できても、接合部の耐力・定着、架構の拘束、部材荷重、地震方向ごとの崩壊形により、片端や支間内が支配する場合や、端部曲げが同符号になる場合がある。同符号の端モーメントに対応するせん断成分の大きさは、左右の端モーメントの絶対値の差の絶対値を内法長さで割った値となる。強度を伝達できる接合と、両端が逆符号で降伏する機構の成立は別の条件。

## 公開入口の観測

`sepika_job::complete_ultimate_static_demand` で固定荷重Gと架構用積載P（係数ともに1）の強軸曲げ・QLを合成し、`sepika_design_jp::ultimate::collect_rc_ultimate_checks` で比較した。モデルは `crates/sepika-design-jp/tests/fixtures/rc_beam_asymmetric_model.rs` の `model(false)` を基に、端部座標、フェイス距離、断面、境界条件を設定した。断面はFc24、主筋・あばら筋SD345、梁幅350 mm、梁せい609.5 mm、かぶり40 mm、あばら筋径10 mm・2脚@100、両端のフェイス距離0 mm、内法長さ4,000 mm。標準D19の入力値19.0 mmでは、主筋断面積は1本当たりπ×9.5²＝283.528737 mm²、有効せいは上下550 mm。独立釣合いの上・下耐力は96.839240・193.678480 kN·m、要求せん断力は72.629430 kN。呼び径入力と公称断面積の差は [#1580](https://github.com/hrntsm/SEPIKA/issues/1580) で追跡する。

相当径のケースでは、公称断面積を円面積として再現する数値径（4×286.5/πの平方根）を使い、梁せいを径の増分の半分だけ調整して有効せいを550 mmに維持した。これは面積をそろえた照合用の入力。既定の倍率1.0、Rp＝0、付着照査有効で実施した。次表の5ケースでは、左右両節点の全自由度を拘束し、梁の両端接合を固定とした。Gの保存内力としてi端・中央・j端とも一定の強軸曲げ−10または＋10 kN·m、せん断0を与え、Pは全成分0とした。これらは公開需要組立てに与えた釣合いの取れる内力であり、終局時の載荷や崩壊解析を表さない。

| --- | ---: | --- |
| 標準D19、上2／下4、負曲げ | 96.839240 | 未算定。反対側の曲げ耐力が大きく未検定 |
| 標準D19、上2／下4、正曲げ | 193.678480 | 96.839240、OK |
| 相当径、上2／下4、負曲げ | 97.854075 | 未算定。反対側の曲げ耐力が大きく未検定 |

| 標準D19、上下各2、負曲げ | 96.839240 | 48.419620、OK。等耐力・逆符号で降伏すると仮定した独立値と一致 |

塑性理論式と靭性指針式で上表の判定は共通。負曲げで未検定となった行では比較需要と余裕度がNaNで返り、Mu・選定側Qsu・Qbuが参考値として残った。48.927038 kNは公称面積・上端耐力での独立した2倍式の値で、公開入口が返した比較需要ではない。

追加の感度確認では両節点を固定とし、梁幅・配筋を下表のとおり変更した。梁せい609.5 mm、内法長さ4,000 mm、径19.0 mm、材料・かぶり・あばら筋は標準D19の比較と同じとした。Gの保存内力は正の局所せん断力を各点で同じ QL とし、強軸曲げを `Mz(x) = Mz_i + QL × 4000 × x` とした。QLはN、Mz_i と Mz はN·mm、xは i 端からの距離を内法長さで割った無次元位置で、0・0.5・1を与えた。正曲げは下端引張、負曲げは上端引張。Gの他成分とPの全成分は0とした。これらは公開需要組立てに保存内力を直接与えて分岐を確認する入力である。

| 確認項目 | 梁幅（mm）・上下配筋 | Gの Mz_i（kN·m） | Gの QL（kN） | 付着照査 |

| 反対側のせん断 | 350、上1本×2段／下2本×1段 | +5,000 | 555 | 無効 |
| 反対側の付着 | 200、上下各2本×1段 | +10 | 512.1 | 有効／無効 |

塑性理論式では、反対側のせん断不足を示す未検定を確認した。幅200 mmの例では、同断面に QL＝0、Mz_i＝±10 kN·m を与えた比較で上下の耐力を確認した。要求値48.419620 kNに対し、せん断耐力は上下とも560.850381 kNで、QL＝512.1 kNを控除した値は48.750381 kN。上端側の付着耐力は560.254845 kNで控除後は48.154845 kN、下端側は795.100760 kN。付着を含めると反対側の付着耐力の比較で未検定、付着を省くとOKとなった。この幅200 mmの例では靭性指針式の選定側せん断照査でNGになった。選定側NGのケースでは、反対側の曲げ耐力が大きくても有限の比較需要とNGを保持した。反対側の主筋不足では、選定側の余裕があっても理由付き未検定となった。

### 片持ち梁の線形解析からの観測

幅350 mm・上下各2-D19の同断面で、左節点を固定、右節点を自由とし、右端に固定荷重として強軸曲げを生じる下向きの先端力2.5 kNを与えた。先端モーメント・荷重偏心はゼロとした。両方の部材端接合を固定の設定としても、右節点は自由で他の部材が取り付かない。独立した静力学解は左から−10、−5、0 kN·m、せん断力の大きさ2.5 kN。`sepika_job::compute::compute_linear_static` が同じ長期内力を返し、上記の公開需要組立てと検定を通すと両せん断方式とも Qmu＝48.419620 kN、理由なしでOKとなった。

この支持条件で先端力を増加させる場合、固定端が96.839240 kN·mに達する荷重は24.209810 kN（96.839240/4.000）で、自由端は0 kN·mのまま。製品の48.419620 kNは指定した片持ち機構の釣合いとは異なる。支持条件によって両端に曲げ降伏が成立しない梁を、反対側の耐力比較で判別できないことを確認した。この例で24.209810 kNより大きい値を使った事実から、他の支持条件・機構・付着の照査まで安全側とは判断できない。

### 再現手順

1. `crates/sepika-job/tests/issue1497_probe.rs` に一時の統合試験を作る。上記のフィクスチャを読み込み、i、j節点の座標を (0, 0, 0)、(4000, 0, 0) mm、両端のフェイス距離を0 mm、長期組合せの選択を0番（G＋P）とする。断面はフィクスチャの `section` で作り直し、梁せいは600 mm＋主筋径の半分とする。
2. 主要5ケースと感度確認では j 節点を固定に変更し、i 節点の拘束と両端の固定接合は保持する。`complete_ultimate_static_demand` の荷重ケース別の取得関数から、表に従う `MemberForces` を部材ID 0に返す。成分順は N、Qy、Qz、Mx、My、Mzで、位置はi端・中央・j端とする。片持ちだけは j 節点を自由とし、Gの節点荷重を j 節点の全体Y方向に−2,500 Nの力へ置き換える。GとPのそれぞれについて、`compute_linear_static` が返す `member_forces` を需要組立てに渡す。
3. 合成した需要を `collect_rc_ultimate_checks` に渡す。塑性理論式と靭性指針式について、採用した曲げ耐力、比較需要、せん断・付着耐力、余裕度、判定と未検定理由を確認する。リポジトリルートで次のコマンドを実行する。

```bash
cargo test --offline --locked -p sepika-job --test issue1497_probe -- --nocapture
```

## 製品での対応と残る検証

- 現行ガードの「反対側」は同一断面のもう一方の引張側。長期曲げが選んだ側の照査が成立したとき、その側が上下の最大曲げ耐力で、もう一方の側のせん断・有効にした付着も同じ比較需要を満たすか確認する。単一断面・逆符号の両端曲げを仮定した曲げせん断成分について上下の最大値は上界になる。実際の左右配筋・曲げ伝達・地震方向・崩壊形・主筋応力度差は判定の対象に含まれない。
- 適用外の支持状態や両端降伏の成立を確認できない梁に理由付き未検定を返すため、支持・接続状態、他部材・ばねの拘束と実際の曲げ伝達の判定条件を整理する。[#1581](https://github.com/hrntsm/SEPIKA/issues/1581)
- 上下・左右が異なる梁の曲げ需要を検定するには、地震作用方向ごとの左右の評価断面と降伏方向、左右の曲げ耐力、部材荷重のせん断、付着の応力度差と定着条件を組にして扱う必要がある。両端ヒンジ以外の機構や、両端で降伏しても同符号の場合を区別する。[#1582](https://github.com/hrntsm/SEPIKA/issues/1582)
- 付着の短スパン・カットオフ筋・段別配筋等の具体的な判定、実架構での全崩壊形、規準適合および実験Validationは未確認。手動GUIとMCP実通信は実施していない。
