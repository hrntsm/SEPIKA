# RC梁・柱の丸鋼主筋の終局付着（Issue #1730）

## 資料照合

| 資料 | 確認内容 |
| --- | --- |
| 『2025年版 建築物の構造関係技術基準解説書』第2版第1刷 p.586、9.3節。平成13年国土交通省告示第1024号 第1第十五号・第2第十四号 | 丸鋼の長期許容付着応力度は梁上端で `min(0.04 Fc, 0.90)`、ほかの位置で `min(0.06 Fc, 1.35)`（N/mm²）。短期値は表の長期値の2倍、付着の材料強度は表の長期値の3倍。引抜実験で確認した強度の1/3を長期許容値とできるただし書もある。 |
| 同書 pp.707–708、付録1-3.1 (2) ⑥ d)、式(付1.3-20)～(付1.3-22) | 終局限界状態では主筋の付着信頼強度と部材両端の主筋応力度差から求めた設計用付着応力度を比較する。適用の詳細を靭性指針の6.8節に委ねており、丸鋼への適用条件や告示の材料強度による代用は確認できない。 |
| 日本建築学会『鉄筋コンクリート構造計算規準・同解説』2024年版、第10版第1刷、6条解説 pp.60–64、16条解説 pp.217–221 | 丸鋼を用いる場合の端部フックと長期・短期付着の準用は、16条 (16.2)・(16.4) に関する。付着割裂強度式の解説は異形鉄筋の節による割裂機構と引抜試験を扱い、靭性指針の付着強度式の基に異形鉄筋の付着応力伝達の研究を挙げている。 |
| 荒木秀夫・伊木勇人「主筋に丸鋼を用いた低強度コンクリート部材の耐震性能評価」日本建築学会技術報告集 17巻35号、2011年、pp.167–170 | 丸鋼の付着滑脱を扱う、低強度コンクリートの既存部材の耐震診断に向けた評価法。現行の梁・柱の終局検定で使用する両方式の付着信頼強度への適用は確認できない。 [公開論文](https://doi.org/10.3130/aijt.17.167) |

例えば Fc=24 N/mm² では、告示の表から丸鋼の付着の材料強度は梁上端2.70 N/mm²、ほかの位置4.05 N/mm²となる。終局付着割裂式の付着信頼強度にはこの値を代入できる根拠を確認できないため、丸鋼に対する付着割裂の判定を未算定とする。1999年の靭性指針本文と、丸鋼を用いた任意の実部材に対する妥当性は未確認。

一次設計の1999方式で丸鋼に適用する式は [#1802](https://github.com/hrntsm/SEPIKA/issues/1802)、異形鉄筋1段の付着信頼強度と建築研究資料No.197の係数・寸法定義との差は [#1805](https://github.com/hrntsm/SEPIKA/issues/1805) で追跡する。

## 公開検定の確認

修正前の `feba8f46` で `collect_rc_ultimate_checks` を実行した。Fc=24 N/mm²、内法3,000 mm、丸鋼の主筋径19 mm、強軸曲げ−10 kN·m、軸力0、弱軸せん断0、塑性回転角0 radの確定総応答を入力した。付着を有効にした場合、強軸せん断30 kNでは3部材とも両方式で適合となった。

| 部材 | 主筋材種 | 塑性理論式の付着割裂耐力 [kN] | 靭性指針式の付着破壊考慮せん断信頼強度 [kN] |
| --- | --- | ---: | ---: |
| 幅250 mm×せい350 mmの梁 | SR235 | 424.713 | 182.839 |
| 幅400 mm×せい600 mmの矩形柱 | SR295 | 1,198.765 | 745.316 |
| 直径600 mmの円形柱 | SR235 | 783.530 | 688.377 |

これらは修正前の実装が出力した数値である。丸鋼の付着耐力の参照値として採用できる根拠は確認していない。

修正後の同じ入力では、3部材とも両方式で付着耐力と余裕度が未算定となり、部材IDと丸鋼の材種を示す理由を返した。強軸せん断を2,000 kNに増やすと、両方式でせん断の不適合を返し、付着を未算定とした理由を詳細に保持した。両せん断力で、せん断耐力とせん断余裕度は修正前の値と一致した。

恒久回帰 `crates/sepika-design-jp/tests/rc_ultimate_round_bar_bond.rs` は、静的需要と確定総応答、塑性理論式と靭性指針式、梁・矩形柱・円形柱でこの契約を確認する。付着を無効にした場合と数値径の異形鉄筋での既存挙動、独立したせん断・曲げの不適合と柱の軸終局耐力を確認する。
