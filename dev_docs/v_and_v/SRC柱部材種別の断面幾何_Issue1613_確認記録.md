# SRC 柱の部材種別候補に用いる断面幾何（#1613）

[Issue #1613](https://github.com/hrntsm/SEPIKA/issues/1613) の二つの断面を公開候補 API で再現し、矩形 SRC の共通幾何検証を候補計算にも適用した。規準上の扱いと利用時の制約は [SRC 柱の種別](../../docs/calc_basis/07_二次設計/03_部材ランク.md#src-柱の種別) を参照。

『2025年版 建築物の構造関係技術基準解説書』第2版第1刷 6.5.4(2) pp.442、444 で、崩壊形の圧縮力、柱の圧縮耐力、鉄骨部分と柱全体の曲げ耐力で SRC 柱を区分する条件を参照した。日本建築学会『鉄骨鉄筋コンクリート構造計算規準・同解説』第6版（2014年）第7条 pp.5、7 の鉄骨かぶりと主筋・鉄骨間のあきは、断面内への収まりや重なりの有無だけでは確認できない。以下は候補式と入力拒否の Verification で、かぶり・あき・幅厚比、耐力定義の妥当性、Ds の採用条件と実験 Validation は対象外。

## 独立値と断面境界

鋼材を上下のフランジと、水平中心線で分けた上下のウェブの四つの長方形に分けた。各長方形の面積を合計し、中心から水平中心線までの距離を各面積に乗じて合計した値を全塑性断面係数とした。RC部分の曲げ項は 0.9×4×π×12.5²×345×537.5 N·mm とした。候補式の材料強度と断面積に関する前提は [#1417の独立数値](SRC柱部材種別材料_Issue1417_確認記録.md#独立数値) を参照。

| --- | ---: | ---: | ---: | ---: | ---: |
| 400×200×8×13 | 235 | 8,192 | 1,285,952 | 0.292370604915024 | 0.479761357753610 |
| 600×100×8×13 | 235 | 7,192 | 1,422,052 | 0.297773458894517 | 0.504900536592460 |
| 400×600×8×13 | 235 | 18,592 | 3,298,352 | 0.245958396220166 | 0.702853840557948 |
| 300×90×90×13 | 215 | 27,000 | 2,025,000 | 0.225800135280932 | 0.570557008130156 |

主筋の中心は幅方向に ±237.5 mm と ±79.1667… mm、せい方向に ±237.5 mm で、半径は12.5 mm。例えば H600×100×8×13 のフランジはすべての主筋の外側にあり、H400×600×8×13 はフランジから同じ側の主筋中心まで37.5 mm離れる。等号の三例は他の幾何条件も満たすため、公開 API で両比を絶対誤差 10⁻¹² で照合する。

それぞれの等号から鋼材せい・幅・ウェブ厚だけを0.001 mm増やした三例では、公開 API が超過理由と両寸法を返すことを確認する。H200×200×8×100 ではウェブ内法せいが0 mmのため拒否する。H500×200×8×13 のフランジは、せい方向の絶対値237～250 mm、幅方向の絶対値100 mm以下の領域を占め、内側の主筋中心を含む。公開 API は主筋径と内蔵鉄骨寸法を含む干渉理由を返す。

せい0 mmと幅NaNの内蔵鉄骨、および SRC 外形90×300 mmに H300×90×90×13 を入れてコンクリート領域の面積が0となる場合は、幾何の不成立理由と入力寸法を返す。ウェブ・フランジそれぞれの実板厚が0、負、NaN、無限大または材種表の上限を超える場合も、既存の板厚理由と両板厚を確認する。

## 通常の製品入口

App の `invalid_src_column_geometry_prevents_automatic_holding_capacity` では、不正な二断面を使う架構のモデル読込みに成功した後、準備計算の大梁の端部柱フェース解決で最初に停止する。準備のエラーと対象部材の診断に寸法と理由が現れ、X/Y 地震静的解析と増分解析も同じ寸法理由で停止する。自動の保有水平耐力判定は増分解析結果がないため判定結果と採用元を返さない。

`src_column_auto_rank_reports_inapplicable_steel_from_a_saved_run` では、正常な SN400B の FA 候補と Ds の採用保留、および材種・実板厚の未評価理由も確認する。
