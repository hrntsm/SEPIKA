
## 代表モデルと入力データ

対象は現行の[実モデル統合テスト](../../crates/sepika-app/tests/full_model.rs)で使う[model.stb](../../crates/sepika-app/tests/fixtures/model.stb)を明示入力で準備した派生モデル一つとする。元データは4層+PHの混構造、主架構115部材（柱40・大梁75）で、初回検討対象だけを鉄骨大梁に限定する。小さい独自モデルを新設して既存の床・二次部材・共有断面の影響を省略しない。

データの基点は`1b057e81`、原本SHA-256は`1909407d49574fe563ca21aac9c6c7ab04d267dccb9e9e73119582732be79215`。[抽出スクリプト](data/issue973/model-input.ps1)で原本の対象/断面/節点を確認した。ここでのSTB IDは取込時の照合用であり、GUIやAIへ渡す複合参照を内部ID番号から推定しない。取込後に元ID対応と端点/断面用途を照合して#974の参照へ解決し、検討に固定する。

| 入力 | 固定値/作成方法 |
| --- | --- |
| 基準の鉄骨大梁 | STB G43（id=43）、節点13→14、座標(1000,1000,4700)→(5000,1000,4700) mm、長さ4000 mm |
| 基準断面 | STB section10 GY1（floor=2）、H-500×250×9×16、SN400B |
| 比較案A | G43だけを既存section11 GY2（floor=2）、H-700×250×12×19、SN400Bへ割当 |
| 比較案B | G43だけを既存section23 b6、H-450×200×9×14、SS400へ割当 |
| 比較対象の注意 | Bは材種も異なる既存断面であり、純粋な寸法だけの感度試験ではない。材料/形状/性能/算定元を変更一覧に表示する |
| 検討開始前の入力完成 | `full_model.rs`の`analysis_fixture_path`と`imported`で明示する解析用派生に揃える。RC梁4断面の配筋中心65.5mm（FB1のみ51mm）と位置適用を明示、原本を上書きしない |
| 階/配置 | 同テストの`declare_analysis_story_levels`でFL=[200,4700,8700,12700,16500]mm、ΔSL=0を明示。`declare_analysis_beam_placements`でRC梁-D/2、他梁/小梁0mm。`declare_analysis_slab_placements`で原本境界高さとFLから各床の基準階/偏心を明示 |

| ユーザー入力荷重 | 取込の標準ケースDL/LL架構/LL地震/EX/EYと手入力荷重の内容を基準で保存。案作成後の入力追加/係数変更なし |
| 計算設定 | `App::default`から入力完成した時点の解析・検定・数量設定を全保存。threads=1、全案で同じ設定。将来の既定値からの補完は不可 |
| 荷重状態 | `tests/support/frame_gravity.rs::select_frame_gravity`と同じ保存組合せ「保存長期架構G+P」を検討開始前に作成。Dead/Live種別ケースを各係数1で明示保存。各案で構成ID・係数・longの一致を確認し、表示選択から暗黙決定しない |

準備前に入力の欠落・不正や未設定領域を診断し、初回検証の対象/荷重を落とす不備を解消する。現行テストで明示している入力完成を、安全側の近似・実建物の設計条件の推定と呼ばない。派生モデルの条件をすべて記録し、このモデルでの検討操作のVerificationに限定する。初回検証で既存有効断面として参照解決/材料/用途検証を通らなければ、その理由を記録して停止し、似た名前の断面へ自動置換しない。

## 一連操作と観測欄（#985で実測する）

以下の計算値・GUI操作は今回**未実行**。数値欄に仮の合格値を入れない。各案の実行ID/結果参照・観測値・単位・状態・入力/契約版を一緒に記録する。

| 順序 | 観測対象/判定 |
| --- | --- |
| 1 基準作成 | 原本ハッシュ、入力完成後OVIKA、支点・入力荷重・計算/数量設定、共有断面の参照部材一覧、固定G43の複合参照を記録 |
| 2 A/B作成 | 基準本案は不変、差分は固定G43の断面割当だけ。共有元/割当先断面の定義と他の参照部材は不変。部材/節点/支点数と入力荷重を照合 |
| 3 準備 | 基準/A/Bそれぞれ`run_preparation`と同じ経路。自動算定自重・地震用重量・自動荷重を再生成し、入力荷重固定と派生値変化を別欄に保存。警告/失敗を保存 |
| 4 静的 | 保存G+P組合せを明示して`run_combination`相当の既存経路を実行。指定STB node14の全体Z変位[mm]を符号付きで取得し、値0と未取得を区別 |
| 5 検定 | 同じG+P・longで`run_design_check`相当を実行。G43の同じ評価部位（i端フェイス・中央・j端フェイスの各行）/検定成分の比[無次元]と需要/耐力・単位・適用状態を記録。同じ最大値だけで別評価部位を比較しない |
| 6 数量 | `try_compute_quantity_takeoff`相当でG43の鋼材体積[m³]、数量状態、断面積の算定元と材長を取得。建物総量は補足、鉄筋/コンクリートや重量を対象鋼材体積へ代用しない |
| 7 比較 | 基準/A/Bの断面割当、対象鋼材体積、node14 Z変位、G43の同じ部位/成分の検定比を図表で確認。基準との差を符号付きで表示。条件が違う行は比較不可理由を残す |
| 8 採用 | 人がA/Bのいずれかを理由と未確認事項を確認して選ぶ（どちらが優れるかは事前決定しない）。一括割当を採用し、本案要再計算/比較結果非移植、一度のUndo、採用履歴を確認 |
| 9 保存再読込 | 基準/比較/結果/未算定理由/採否/条件がAI未接続で閲覧可。未完了計算は中断、接続権は失効。変更前ファイルを壊さない保存失敗も確認 |

検定比の比較キーは`案の対応対象 + 荷重状態種別/実効構成/継続時間 + 評価位置/方向/成分 + 計算契約版`とする。需要と耐力は案ごとに計算し、荷重の自動派生値が異なること自体を条件不一致としない。単独ケースと組合せ、自動G+Pと保存G+P、長期と短期、別評価位置、未対応と算定済は取り違えない。対象鋼材体積は実断面積×材長の単位換算を独立照合し、フィレット等のある実断面を単純な矩形差に置換しない。変位/検定比の増減方向を一般的な安全性の保証に使わず、強度/剛性/荷重・周辺応答を既存計算で評価する。
