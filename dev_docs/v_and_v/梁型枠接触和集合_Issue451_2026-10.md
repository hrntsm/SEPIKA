# 梁型枠接触和集合 — Issue #451

対象は水平一定矩形RC・SRC梁の底面・両側面の床接続控除。数量全体系への適合確認ではない。
製品の入力・単位・適用条件の正本は[数量算定式](../../docs/calc_basis/10_数量積算/01_数量積算の算定式.md#梁と床の接続面の控除)。

## 一次資料と採用判断

国土交通省大臣官房官庁営繕部『公共建築数量積算基準（令和5年改定）』、
最終改定令和5年3月29日、[原本PDF](https://www.mlit.go.jp/common/001178206.pdf)を直接閲覧。
第4編第2章第2節1(2)1・2（本文p.12／PDF p.17）は側面・底面から梁と床板の接続面を差し引く。
同2(3)2（本文p.13／PDF p.18）は梁の側面・底面とハンチ面積の伸びの取扱いを示す。
梁・床板の接続に、その他の接続部の1 m²以下の非控除例外は適用しない。

左右別接触集合の積分は本アプリの幾何数量契約であり、原本に直接記載された数式や例題と装わない。
参考資料の梁スラブ剛性節は型枠控除の根拠には使用しない。
他部位・上面型枠・施工条件・ハンチ全面の基準適合性は今回検証していない。

## 独立期待値

B=0.3 m、D=0.6 m、L=6 m、端部フェイス控除なし、床と梁の数量上端同高。
基準面積は底面0.3×6＋両側面2×0.6×6=9.0 m²。
矩形fixtureの絶対誤差を1e-9 m²以内で確認する。

| ケース | 独立計算 [m²] | テスト |
| --- | --- | --- |
| 床なし | 9.0 | `beam_contact_union_independent_rectangles_and_invariances` |
| 左150・右100 mm全長 | 9−(0.15+0.10)×6=7.5 | 同上 |
| 片側150 mm全長 | 9−0.15×6=8.1 | 同上 |
| 同側100/150 mm重複 | 9−0.15×6=8.1 | 同上 |
| 前半3000 mmのみ左150 | 9−0.15×3=8.55 | 同上 |
| 前半の同位置100 mm重複 | 8.55 | 同上 |
| 床上面+100 mm、実厚150 mm | 9−0.05×6=8.7 | `beam_contact_height_intersection_opening_gap_and_clear_span` |
| 梁下面以下・梁上端より高い非接触床 | 9.0 | 同上 |
| 実厚900 mm、側面高さ600 mmにclip | 9−0.6×6=5.4 | 同上 |
| 左床0–2000及び4000–6000 mm、間は開口非接触 | 9−0.15×4=8.4 | 同上 |
| 内法500–5000 mm、床0–3000 mm | 1.5×4.5−0.15×2.5=6.375 | 同上 |
| 同側の上下で離れた100 mm床2枚 | 9−0.2×6=7.8 | `beam_contact_direct_support_span_secondary_and_vertical_union` |
| 支持材IDとspan=[0,0.5]の直接接続 | 8.55 | 同上 |
| 二次小梁への前半150 mm接続 | 8.55 | 同上 |

左右交換、入力順、材端反転を確認。内法距離は材端反転時にi/j距離も交換する。
床fixtureは梁と別節点IDで生成し、材軸部分区間・高さずれを幾何照合する。
剛性用厚0でも実在床の接触値を保持する。現モデルに`stiffness: bool`はなく、
将来の#450入力や剛性・荷重代表厚の実装を検証済みとは扱わない。

## 拒否・未確定と公開入口

`beam_contact_rejects_unknown_invalid_and_unsupported_inputs`はNoPlateで接触なし、
Unset・床板参照不明・断面参照不明・支持材参照不明・負/ゼロ/NaN/無限厚・自己交差境界、
傾斜梁・非矩形の診断を検証する。
`beam_contact_direct_support_span_secondary_and_vertical_union`は接触基礎梁の対象側面未確定と
ハンチ付き接触未対応を検証する。床なしのハンチ・基礎梁は既存数量回帰試験を保持する。
旧両側床fixtureの一面が自己交差していたため、頂点順を修正し独立期待値を保持した。

| 入口 | 実入口検証 | 期待値・観測 |
| --- | --- | --- |
| GUI | `beam_contact_quantity_gui_renders_union_and_unavailable_reason` | 実egui描画の明細にG451/7.50、不正厚時は未算定理由のみ |
| CSV | `beam_contact_quantity_csv_preserves_union_and_diagnostics` | G451明細7.50、不正厚時は未算定理由、通常明細なし |
| MCP | `beam_contact_quantity_mcp_preserves_union_and_diagnostics`及び`beam_contact_quantity_mcp_tool_returns_verified_rows_and_unavailable_reasons` | JSONと実SepikaServerツール処理のdetail明細7.5、未確定時unavailable、totalsなし |

GUIとCSVは`sepika-app/tests/beam_contact_quantity.rs`、MCPは`sepika-mcp/src/tests.rs`。
幾何期待値は出力を正解にせず、上記の独立面積から算定した。
実入口ではNoPlate（残る片側100 mmから8.4 m²）、Unset、参照不明、不正厚、
自己交差、非矩形も確認する。材軸mm許容差は9 mm/11 mmの境界比較、無関係の非接触傾斜床は
`beam_contact_uses_shared_mm_tolerance_and_ignores_unrelated_slope`で確認する。
`beam_contact_non_nodal_secondary_is_unavailable_materialized_is_counted_once`は、
接触を持つ非節点端部二次小梁が未算定になり、実部材化された同軸小梁は実梁側8.55 m²のみを
数えることを確認する。
`beam_contact_uses_shape_dimensions_and_rejects_nonfinite_formwork`は、補助depth/widthを10000 mmへ変えても
形状300×600 mmによる片側600 mm接触の5.4 m²が保たれること、形状の幅・せいの負/ゼロ/NaN/無限、
有限幅の面積オーバーフロー、不正内法距離を未算定として拒否することを確認する。

`beam_contact_sloped_beam_contact_is_direction_independent`は、幅300/せい600 mm、
端点(0,0,0)–(6000,0,3000) mm、別節点の水平床上面3000/厚150 mmで、
全長及び終端5700–6000 mmの床接触が両材端方向とも傾斜梁未対応になることを確認する。
前半0–3000 mmだけの床は梁上端最大1500 mmで非接触、控除なしの既存梁数量
1.5×√(6²+3²)=10.062305898749054 m²を両方向で保持する。
全長床でも剛域が終端側の半長3354.1019662496847 mmを除外すると、残る内法区間は
非接触で5.031152949374527 m²を保持する。材端反転時は剛域i/jも交換する。
既存の無関係な非接触傾斜床の試験も保持する。これらの非接触値は既存数量の回帰であり、
傾斜梁の実接触面積や一般数量の適合を検証済みとするものではない。
MCPの既存異常入力行列に別節点水平床と傾斜梁の両方向を加え、JSON及び実ツール入口で
未算定理由「傾斜梁」、totalsなしを確認する。

## 残る制限・連携

数量の上端標高は梁材軸・床境界の標高を基準とする現機能の契約。
独立上端・偏心入力は存在せず、解析断面中心を上端と同一視する一般保証はしない。
傾斜・非矩形・ハンチ接触、基礎梁の対象片面、床内孔の面積だけによる接触差引きは未対応。
2節点以外の主架構梁の接触型枠は未対応。多節点梁の数量全体の算定は今回変更していない。
矩形以外の一般幾何誤差、実施工・実測Validation、数量全基準適合は未検証。
断面未割当線（section=None）は床境界用に自動生成される主架構線も存在し、
数量対象の断面未割当実梁と現モデルで識別できないため、従来の数量除外を保持する。
これは断面未割当実梁の数量を確定したという保証ではない。
明示された断面IDの不明参照（Some(SectionId(999))）は支持材ID付きで拒否する。

親[#524](https://github.com/hrntsm/SEPIKA/issues/524)には、本件の限定Verification完了と制限を報告する。
[#450](https://github.com/hrntsm/SEPIKA/issues/450)とは支持材・有向区間・床実厚の入力境界を共有し、
本件は剛性用有効厚・荷重厚の再実装を行わない。既存数量修正[#448](https://github.com/hrntsm/SEPIKA/issues/448)は回帰で保持する。
非節点端部の床なし小梁・間柱が既存数量から除外される制限は[#557](https://github.com/hrntsm/SEPIKA/issues/557)で別途追跡し、今回の修正は接触を持つ二次小梁の未確定診断に限定する。
最終headの全CI、独立Reviewer、親追加レビュー及びmergeの完了はローカル検証と区別して別途確認する。
