# RC梁・柱の異形鉄筋1段の終局付着（#1805）

基点は `5ce4a3f0`。普通コンクリートの矩形RC梁・柱に、1段の異形鉄筋を通し筋として配筋した。梁上端・下端と柱の強軸について、塑性理論式と靭性指針式の公開検定、および公開資料の付着信頼強度との数値差を確認した。

建築研究資料 No.197 の付着信頼強度だけを現行算定に代入すると、梁上端で両方式、梁下端で靭性指針式の付着余裕度が1を下回った。柱の付着余裕度は両方式で1以上を保ち、独立したせん断検定で不適合となった。状態🔶。この差は有限例での感度であり、両指針の刊行版に対する規準適合と実験Validationは未確認。追跡元は [#1805](https://github.com/hrntsm/SEPIKA/issues/1805)。

### 1段目の付着信頼強度

双方とも τbu = αt{(0.085 bi + 0.10)√強度 + kst} の形。以下の寸法は mm、強度・応力度は N/mm²。b は部材幅、db は主筋径、N1 は対象1段の主筋本数、s は横補強筋間隔。Aw は横補強筋1脚の面積、nleg は現行入力の検討方向の脚数とする。

| 項目 | 現行の公開検定（両方式共通） | No.197 の参照算術 |
| --- | --- | --- |
| コンクリート強度 | 設計基準強度 Fc | 圧縮強度 σB |
| αt | 梁上端 0.75 − Fc/400（下限0）、梁下端・柱 1 | 梁上端 0.75 + σB/400、梁下端・柱 1 |
| 側面割裂 bsi | b/(N1 db) − 1 | 同左 |
| 隅角割裂 bci | √2{(Cs + Cb)/db − 1}。公開入口は横補強筋外面までの入力かぶり C を Cs と Cb の両方に使う | √2(dcs + dct)/db − 1。dcs・dct は主筋芯から側面・上下面までの距離 |
| 割裂線長さ比 bi | min(bsi, bci, bvi)（下限0）。bvi = √3{2 min(Cs, Cb)/db + 1} | min(bsi, bci) |
| 横補強筋効果 kst | 140 nleg Aw/(db s)。割裂形に共通 | 側面割裂（bsi ≤ bci）では (54 + 45 Nw/N1)(bsi + 1) pw。隅角割裂（bci < bsi）では 140 Aw/(db s)。Nw = Ns + 2、Ns は中子筋本数、pw は検討方向の横補強筋比（小数） |

公開入口が同じ非負の C を渡す条件では、現行 bvi − bci = 2(√3 − √2)C/db + √3 + √2 > 0 となり、Vノッチは単独で支配しない。今回も現行は全例で隅角の値を採用し、参照式は梁で側面、柱で隅角の値を採用した。梁上端の係数を単独で変えると付着信頼強度は増えるが、今回の3例では横補強筋効果と割裂線長さ比の変更も含めると付着信頼強度は下がった。

`collect_rc_ultimate_checks` に部材IDと需要を渡し、`UltimateShearOptions` は検定方式、`include_bond=true/false`、`biaxial_bending=true` を指定し、残りは既定とした。上限強度倍率1.0、二軸せん断なし。基点で一時の統合試験 `rc_bond_issue1805_probe` を `cargo +stable test --locked --offline -p sepika-design-jp --test rc_bond_issue1805_probe -- --nocapture` で実行した（1試験、3条件×2方式×付着有無の12呼出し）。再実行時は上記の条件で一時の統合試験を作成する。

## 独立算術と公開検定

先に No.197 の式(3.5.21)から τbu を算出し、柱は同じ係数の式(4.7.2)～(4.7.7)を照合した。上端の αt は現行0.690、No.197では0.810。ほかは1。梁の pw は142.66/(350×100)=0.004076、隅角割裂となる柱の pw は142.66/(500×100)=0.0028532。梁の参照 kst は (54+45×2/4)×3.5×0.004076=1.091349、柱では 140×71.33/(25×100)=3.994480。現行の kst は両断面で140×142.66/(25×100)=7.988960。

| 梁・下端 | 2.500000 | 1.979899 → 4.939697 | 9.303314 → 2.622280 | 2,922.722 → 823.814 |

下流の比較では τbu のみを差し替えた。現行の共通幾何は jt=je=7d/8=522.8125 mm、Σφ=N1 πdb=314.1593 mm（梁）または235.6194 mm（柱）。Rp=0 で νFc=13.92 N/mm²、k1=(√{1+(L/D)²}−L/D)/2=0.05354546。単位長さ当たり付着力を T=τbu Σφ と置くと、塑性理論式の現行下流は Qbu=jt T+k1(1−k3)bD νFc、k3=min(1, 2T/(b νFc))。

靭性指針式の現行下流は、be=280 mm（梁）、430 mm（柱）、中子筋 Ns=0。λ=1−s/(2je)−be/(4je) はそれぞれ0.770472と0.698745、tanθ=0.9D/(2L)=0.0975。Rp=0 のため Tx=T とし、次の二式の小さい値を Vbu とした。

    Vbu1 = Tx je + max(0, νFc − 2.5Tx/(λ be)) (bD/2) tanθ
    Vbu2 = (λ νFc/2) be je

Vbu1 は現行 τbu で梁上端1,054.345 kN、梁下端1,528.036 kN、柱1,146.027 kN、Vbu2 は梁785.001 kN、柱1,093.307 kN。現行は3例とも Vbu2 の上限が支配する。No.197 の τbu を代入すると3例とも Vbu1 が支配する。塑性理論式では k3 が梁上端0.827865→0.273928、梁下端1.000000→0.338183、柱0.629897→0.442892と変わる。

強軸せん断耐力は付着式と独立して算定した。塑性理論式では x=pw σwy として Qsu=2b jt x+k1(νFc−2x)bD（全例 x<νFc/2）。靭性指針式では xe=2Aw σwy/(be s) として、2xe be je+max(0, νFc−5xe/λ)(bD/2) tanθ、(λ νFc+xe)be je/3、(λ νFc/2)be je の最小値が Vu。Vu は3例とも第1項が支配した。独立算術による現行付着耐力・せん断耐力は、公開検定と表の精度で一致した。

## 刊行版の入手後に確認する事項

- 1999年第2版6.8節で、1段目の係数・上端筋の定義・かぶりの測り方・側面と隅角の分岐・Aw と Nw の数え方、主筋径と周長の定義、材料の強度・適用域を確認する。中子つきの脚配置と pw への反映、柱で検討する辺や方向、Vbu の be・je・λ とアーチ項の下限も対象とする。今回の横補強筋入力は2脚のみ。
- 1990年制定指針で、藤井・森田系の割裂形・かぶり・補強筋の定義、上端筋とコンクリート強度の扱い、付着から Qbu への接続を確認する。1999系の τbu をそのまま塑性理論式に接続する妥当性は未確定。
- 刊行版から各方式の独立した耐力と適用条件を求め、公開検定を再照合する。差が残る入力と安全側・危険側となる条件を特定し、式の変更や理由付き保留は [#1827](https://github.com/hrntsm/SEPIKA/issues/1827) で判断する。

多段配筋、丸鋼、設計用付着応力度・カットオフ筋等の追加照査、地震方向ごとの梁端・崩壊機構、円形柱への一般化は今回の対象外。 [#1500](https://github.com/hrntsm/SEPIKA/issues/1500)・[#1730](https://github.com/hrntsm/SEPIKA/issues/1730)・[#1502](https://github.com/hrntsm/SEPIKA/issues/1502)・[#1582](https://github.com/hrntsm/SEPIKA/issues/1582)
