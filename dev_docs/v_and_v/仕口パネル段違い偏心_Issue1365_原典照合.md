# 段違い・偏心接合の仕口パネル適用範囲（Issue #1365）

## 適用判断

2026-11-19、基点 `3aa6c665` で原典、独立算術、公開入口を照合した。**状態は🔶。#1365 は継続する。** 最初の実装候補は、同一構面内に相対する水平H梁があり、各フランジ位置を適切に補剛した鉛直・等厚正方形中空鋼管の通しダイアフラム形式。指針で片側・両側段違いの設計例がある。現時点で解除できる拒否はない。中央領域と全体で需要・耐力の定義が異なり、現行の解析結果の一方向一つのモーメントだけでは中央領域の降伏検定を復元できない。

標準形式の判定と現行の処理は [#505](フランジ位置の標準形式ゲート_Issue505_2026-10.md)、標準式の適用限界・軸力と強度の定義は [#723](仕口パネル耐力式_Issue723_原典調査.md) と [PR #1430](https://github.com/hrntsm/SEPIKA/pull/1430) を起点とする。[#1428](https://github.com/hrntsm/SEPIKA/issues/1428) の形状係数、[#1429](https://github.com/hrntsm/SEPIKA/issues/1429) の円形弾性剛性、[#764](https://github.com/hrntsm/SEPIKA/issues/764) の傾斜柱の需要、[#752](https://github.com/hrntsm/SEPIKA/issues/752) の変動軸力の連成接線はそれぞれ既存の課題である。

## 形状と接合形式の対応

形状は対象とする面に投影した左右梁の実材軸端と上下フランジの**板厚中心**で定める。左右は同一構面内で相対する梁。左右ラベルを交換しても形状と算定結果を変えず、上・下の領域にはそれぞれ実際の位置と柱側応力を対応させる。梁せい中心、梁外縁、階・接合部節点、ダイアフラム外縁は別の基準。上下板厚が異なる場合、外縁を揃えても板厚中心は一致しない。

### 箱形テーパー管の剛性と柱心差

接合部設計指針 p.256 の式(C5.10)は、パネルモーメント `M` と式(C5.9)の等価せん断変形角 `γ` の関係を次の式で表す。

`M = 2G × [AU AL/(AU + AL)] × [cos θ1 cos θ2/(cos θ1 + cos θ2)] × db γ`

`AU, AL` は上・下階側の断面積、`θ1, θ2` はパネル両面の柱材軸に対する傾斜角（図C5.18）、`db` は梁の上下フランジ板厚中心間距離。パネルアスペクト比が2以下かつ `θ1 + θ2 < 10°` の場合、本文式(5.13)の `V0 = db(AU + AL)/4` を用いる平均断面積による剛性の近似は、式(C5.10)に対する誤差が5%未満とされる。この誤差条件を柱絞りと梁段違いの組合せへは広げない。

p.255 の式(C5.6)は、検討構面内で上下柱図心がずれた3面テーパー管（図C5.19(b)・図C5.21）に軸力が作用する場合の近似 `Me = (NU + NL)e/2`。`NU, NL` は図の上・下柱圧縮軸力、`e` は上下柱の図心間の構面内偏心距離。図心が一致する本文式の条件や上柱軸力比による耐力評価とは別で、図C5.22と式(C5.7)では曲げ方向に応じて見かけの全塑性耐力が増減する。

## 段違いの式と荷重状態

フランジ中心の鉛直区間を左右で `[zL-, zL+]`、`[zR-, zR+]` とする。全高さ `db0 = max(zL+, zR+) − min(zL-, zR-)`、中央高さ `dbM = min(zL+, zR+) − max(zL-, zR-) = dbL + dbR − db0`（正の重なりあり）。パネル1は両梁が付く中央、パネル2・3は上・下の周縁。上周縁・下周縁は高さが正の場合に存在し、異せい中心揃えでは同じ大梁が上下に現れる。図5.1は左が上周縁、右が下周縁に接続する配置を例示している。

- **降伏検定**。図5.1の符号で、パネル面における梁端曲げ `ML, MR` を各フランジ距離で除した偶力 `FL, FR` と、柱の上・下フェースせん断 `QU, QL` を用いる。`Q1 = FL + FR − (QU + QL)/2`。`Q2 = 上周縁を含む梁の偶力 − QU`、`Q3 = 下周縁を含む梁の偶力 − QL`（解説(C5.11)–(C5.13)に対応する図の荷重方向）。中心の需要 `M1 = Q1 dbM`（(C5.14)）。本文(5.14)の耐力は `My = (VeM/κ)(Fy/√3)√(1−n²)`。面積 `Ae` をH強軸で `dc tp`、円形・等厚正方形で `2 dc tp` として `VeM = Ae dbM`、`κ` は断面に従う。指針は水平荷重時に一般に中央のせん断が大きいとして降伏を中央で検定する。これを任意の独立荷重・符号・直交載荷でも常に成り立つとは扱えない。
- **全体モーメントと全塑性**。`M = ML + MR − (QU + QL) db0/2`（(C5.15)）。`Mp = min(MpA, MpB)`。Aは全領域塑性化で `MpA = αn Ae db0 Fy/√3`。Bは中央と左右梁のフランジ・ウェブの部分塑性化。各梁の中央外高さ `Δj = dbj − dbM` と外側フランジ幅・板厚 `Bj, tfj`、ウェブ厚 `twj`、梁の降伏強さ `Fyj` を用いて `MpB1 = αn VeM Fy/√3 + Σ Fyj (Bj tfj Δj + twj Δj²/2)`、`MpB = MpB1 (HL − dc H − db0 L)/(HL − dc H − dbM L)`。添字 `j` は左右梁、`H, L` は上下階高・左右スパンの平均。異せい中心揃えでは同一梁が上下両周縁にまたがる。図5.1と異なるこの形状で梁ごとの `Δj²` をそのまま使えるかは、周縁ごとの仮想仕事とフランジ・ウェブの塑性域の確認が必要。厚さや幅が上下異なる組立Hについても、本文の単一 `B, tf` での評価は保留する。荷重状態と機構で耐力の意味と評価面が変わる。標準形の `αn` の定義と実験範囲は #723 を参照する。指針は標準の等厚正方形箱形断面で軸力比 `n ≤ 0.5` のとき `αn=1` とする。一方、桑原ら（2000）p.181結論4は同じ軸力比の範囲でも、異せいの場合にせん断耐力の低下を報告している。全塑性式の係数と0.35%オフセットの実験耐力は評価量が異なり、段違い全般で軸力の影響を無視できる範囲は確定していない。本文全塑性式には適用限界（標準では `db/dc ≤ 1.8`、正方形 `Dc/tp ≤ 40`、円形 `Dc/tp ≤ 50`）がある一方、§5.3は外包高さ・中央高さのどちらに同じ境界を用いるかを明示していない。図C5.32の `db0/dc = 733/384 ≈ 1.91` からも、標準の数値を機械的に外包高さへ移せない。
- **軸力**。通常形・段違い例のパネル圧縮軸力は上下柱端の平均で、`n = N/(Fy A)`。柱それぞれの全塑性モーメントは各柱自身の軸力を使う。例えば段違い設計例は上1223・下1373 kNからパネル1298 kNを求める。テーパー管本文の上柱軸力比、柱心差の解説式の上下平均による付加曲げ、現行参照柱（下側優先）の静的材端圧縮値／非線形試行時の推定値は、それぞれ異なる量である。引張・軸力分担・変動時接線・上下異材の採否は保留する。
- **弾性剛性**。`K = G V0` は全体モーメント `M` と高さ重み付き平均せん断変形角 `γ` を結ぶ（(5.19)、図C5.30）。`V0` はH形強軸で `dc tp db0`、等厚正方形箱形・円形鋼管で `db0 A/2`。降伏の `VeM` や全塑性Aの `Ae db0` と異なる。中央・上下それぞれの変形角・変位の写し方とその転置による力の回収を、全体の関係式だけで決めない。

## 独立値と釣合い

### 標準への極限と五つの高さ配置

等厚正方形中空柱400×400×16、`dc=384 mm`、`A=23,700 mm²`、パネル `Fy=295 N/mm²`、`G=78,500 N/mm²`、`n=0`。H梁はフランジ厚20 mm、左D600でフランジ中心 −290/+290 mm。右だけ中心位置・Dを変更する。共通の比較用応力は `ML=MR=200 kN·m`、`QU=QL=50 kN`。梁鉛直せん断・軸力を0、上・下柱のパネルに作用する水平力を逆符号とし、柱曲げの和を全体モーメント `M` に相当する釣合い側に取れる。列のモーメントは kN·m、剛性は kN·m/rad、せん断は kN。高さ0の領域は「—」。

| --- | --- | --- | --- | --- | --- | --- | --- |
| D600、同位置 | −290 / +290 | 580 / 580 | 0 / 0 | 639.655 / — / — | 371.000 / 371.000 | 1,078.992 | 539,530.500 |
| D600、右100 mm低い | −390 / +190 | 480 / 680 | 100 / 100 | 639.655 / 294.828 / 294.828 | 307.034 / 366.000 | 892.959 | 632,553.000 |

同位置の極限で中央高さ・全高さは標準 `db` に収束する。同せい段差の場合、小さい方の `db=580` を中央480に代用すれば同条件の `My` を約20.8%過大にし、全体680の代用なら剛性を約14.7%過小にする。骨組の応力再分配と検定比の安全側はこの剛性差から決まらない。異せい例で `ML/MR=−100/300 kN·m` とすると、各梁のフランジ偶力による中央需要は193.241 kN·m。小さい方の480 mmを左右共通とした標準式では176.000 kN·mとなり、中央断面の同一耐力に対する検定比を約8.9%過小評価する。異せいの三例はこの等せん断条件で同じスカラー量を得るが、周縁領域の位置と荷重経路は異なる。上端揃えで高さ0の上周縁に実在するせん断需要はない。上下せん断を各50 kNのまま、異せい例の `ML/MR` を200/200から300/100 kN·mへ変えると、全体 `M` は371.000 kN·mのまま、中央 `M1` は341.517から324.276 kN·mへ変わる。全体モーメントだけから中央需要を一意に求められない。図5.1と同じ両側段違いで `FL=500 kN, FR=−450 kN`、`QU=QL=50 kN` の符号例では、中央は0 kN、上は450 kN、下は −500 kNとなる。柱水平力は逆向きの対とし、柱曲げで全体の釣合いを取れる。中央のせん断が支配する条件を任意の符号の荷重へ一般化できない。

各領域の高さを `h2, dbM, h3` として `Q1 dbM + Q2 h2 + Q3 h3` を取ると、上表のように上下柱せん断が等しい場合は (C5.15) の `M` と一致する。不同の場合、図5.1の力の約束のもとで、領域式をそのまま高さ積分した値から (C5.15) を引くと `(QU−QL)(h3−h2)/2` となる。上端揃えの原典例1では差は −3.675 kN·m。桑原ら(2000)の片側段違い式(1)–(4)は中央だけでなく片側領域にも平均柱せん断を使っている。各資料の需要の定義をそのまま取り合わせず、採用するフェース応力・変形・荷重仮定で再度釣合いを確認する。

線形純せん断の比較として `γi = Qi/[G(A/2)]` で各領域を独立に評価すると、`γ = Σ hi γi/db0` から同せい段差例の `γ≈0.000579 rad` を得る。領域の弾性ひずみエネルギー `Σ Qi hi γi/2 = 0.114908 kN·m` に対し、平均の積 `Mγ/2 = 0.105885 kN·m`。平均の荷重–変形関係が同じでも、平均変数だけでは異なる領域せん断に対する仕事全体を再現しない。この比較は平均関係を否定するものではなく、解析要素としてどの変形と仕事を保持するかの条件になる。

### 水平寄りと柱心差の付加作用

標準例に `+Y=80 mm` の横寄りを加える。上フランジへ作用する合計フランジ力を `+X` の `400/0.580=689.655 kN` と取れば、`r×F` の `Mz` は −55.172 kN·m、反対向きの下フランジ力では +55.172 kN·m。偏心率は `80/400=0.20`。上下の合計が0でもその間で受け渡されるねじりは残り得る。左右パネル板への配分は鋼管とダイアフラムの剛性、柱端のねじり拘束で変わる。仮に一つの正方形薄肉閉断面が全ねじりを負担するとし、板厚中心間384 mmの囲み面積から `τt=T/(2×384²×16)≈11.693 N/mm²`。平均せん断 `Q1/(2×384×16)≈52.055 N/mm²` に加減すると 63.748 と40.363 N/mm²。この値は配分を固定した釣合い例で、指針の降伏耐力やねじり拘束を再現する評価式ではない。省略により局部需要を過小評価し得る。

別の例として上下柱の圧縮荷重1298 kNが互いに平行で柱心が50 mmずれた場合、対となる軸力の作用線の差から65 kN·m（正確には64.9）の曲げが生じる。載荷方向と偏心の符号でパネル曲げの加算側・減算側が入れ替わる。梁の横寄りが生む鉛直軸回りのねじりとは別成分である。

## 残る採否

1. **実装候補を採用できる入力の確定**。等厚正方形の中空鋼管、同一構面の水平H梁、実際のフランジ高さと補剛、通しダイアフラムおよび溶接、均一なパネル板厚、パネル全断面積・左右梁諸元・上下柱と各階高・各スパンを特定する。断面や接合詳細が非対称、板が極薄、上・下・中央の領域が消失する条件と、既往実験の範囲を整理し、対象外の理由を確定する。
2. **解析と検定が受け渡す力・変形の合意**。中央降伏検定の需要、機構A/Bで比較する全体需要、および全体・領域別の剛性と変形の定義を確定する。独立した上・下せん断や荷重反転で釣合い・仕事・耐力が整合することを確認する。方向別の適用・未算定、解析の応力出力、準備・検定表示、保存結果の互換契約を同じ物理位置・高さと結びつける。単一の標準パネルモーメントから全状態を復元できることは前提にしない。
3. **水平寄り・複合形状の別評価**。箱形の許容省略も厳密な下限保証がなく、局部ねじりの省略や安全側が確定しない近似には採用前のユーザー判断を要する。柱ねじりとせん断・局部耐力の分担、柱絞りの偏心付加曲げ、斜交・傾斜と同時載荷の適用条件を原典・独立検証で詰める。CFTやH弱軸へ中空鋼管の式を広げない。

先行設計判断は [ADR 0024](../adr/0024-separate-panel-element-and-joint-check.md) と [ADR 0106](../adr/0106-beam-end-offsets.md) に従う。新しい解析モデルや適用範囲に関する設計判断は未確定。実装課題の切り出し・関連付けは採否確定後とし、上記を [#1365](https://github.com/hrntsm/SEPIKA/issues/1365) で追跡する。製品の現行適用範囲は[仕口パネル要素](../../docs/calc_basis/04_要素剛性/06_パネルゾーン.md#適用拡張に必要な確認)と[鋼構造の柱梁接合部](../../docs/calc_basis/06_一次設計/07_鋼構造の柱梁接合部.md#s-造柱梁接合部)に記載する。
