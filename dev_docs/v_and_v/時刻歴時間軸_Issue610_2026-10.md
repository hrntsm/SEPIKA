## 採用時間範囲の照合対象

時間範囲は [公開時間範囲 probe](https://github.com/hrntsm/SEPIKA/issues/610#issuecomment-6184185055) と Issue 本文の採用表を踏まえて固定した。以下は検証対象の識別であり、製品仕様の正本は上記製品 docs とする。

| 入口・境界 | 修正後に assert する時間・状態 |
| --- | --- |
| 有限正 duration/dt | S=ceil(duration/dt)≥1、N=S+1、S 積分、解析／記録終時刻 Sdt |
| 0<duration<dt | S=1、N=2、終 dt |
| duration=0／負／非有限、dt≤0／非有限 | 生成・巨大確保前の拒否、既存入口への失敗伝播 |
| 外部 0 点 | 正常採用なし。既存 Err／empty、N−1 の underflow なし |
| 低位外部 1 点 | 初期 1 点・0 積分・終 0、ag[0] の初期釣合い |
| GUI CSV | 既存 2 点下限を維持 |
| 外部 N≥2 | T=N−1、終 Tdt、入力 s+1、末端後の自動自由振動なし |
| checkpoint 0≤s≤T | 残 T−s、時刻 sdt..Tdt、u/v/a 保持、s=T は無更新 |
| checkpoint s>T | 拒否。panic／underflow や旧誤 checkpoint 救済なし |
| 詳細記録 | 開始 anchor s、以降絶対 step の間引き格子、末端 T。再開で格子 reset なし |

入力点数と積分数を区別し、MCP サマリの n_steps／n_points／end_time と照合する。
初期を含む応答の相対加速度と、同時刻の地動を加えた絶対加速度・慣性力を別々に照合する。

## 独立 fixture と参照値

共通条件：1 自由度、m=1 N·s²/mm、k=40 N/mm、c=0、dt=0.1 s、Newmark β=1/4・γ=1/2、静止初期変位・速度。
参照は [製品 docs の Newmark 有効荷重・初期釣合い](../../docs/calc_basis/05_構造解析/05_時刻歴応答解析.md#線形時刻歴newmark-β) の手計算である。
有効剛性は 40+4/0.1²=440 N/mm。応答から逆算・コピーした期待値ではない。

| 入力 ag [mm/s²] | 期待時刻 [s]・積分回数 | 独立期待値 |
| --- | --- | --- |
| [0,100,0] | [0,0.1,0.2]、2 回 | u0=0、u1=−100/440 mm、u2=−0.8264462809917356 mm |
| [100,0] | [0,0.1]、1 回 | u0=v0=0、a0=−100 mm/s²、u1=−100/440 mm |

最初の例では 440u1=−100、2 回目は前時刻の u/v/a による有効荷重が −4000/11 N となる。
後者は先頭の a0=−100 を含めた有効荷重 −100 N によって u1 を得る。
変位の絶対許容差 10⁻⁹ mm はこの小 fixture のみに適用し、一般の構造解析の収束許容差に読み替えない。
4 solver の時刻・点数・初期釣合いを別々に assert し、先頭が零の例だけで初期処理を合格にしない。

### 独立広域検証での入力接続漏れと限定修正
