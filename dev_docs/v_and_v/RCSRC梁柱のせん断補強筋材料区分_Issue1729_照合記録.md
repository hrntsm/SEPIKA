# RC・SRC梁柱のせん断補強筋の材料区分（Issue #1729）

[Issue #1729](https://github.com/hrntsm/SEPIKA/issues/1729) では、せん断補強筋に「鉄筋」以外の区分の材料を割り当てた場合の検定結果を確認した。修正元の検定版は98（`6ce2dbcc`）。算定式の根拠と適用範囲は[RCの許容せん断式](../../docs/calc_basis/06_一次設計/02_05_RC梁_柱の許容せん断の共通式.md)、[RC梁の付着・定着](../../docs/calc_basis/06_一次設計/02_07_RC梁の付着_定着検定.md)、[SRCの許容せん断式](../../docs/calc_basis/06_一次設計/04_03_SRC梁_柱の許容せん断検定.md)、[RC終局せん断](../../docs/calc_basis/08_部材終局耐力/02_RC_終局せん断.md)を参照する。

## 検定の比較

使用した断面はRC梁250×350 mm、RC矩形柱400×600 mm、RC円形柱直径600 mm、SRC梁・柱600×600 mm。コンクリート強度は24 N/mm²、せん断補強筋はSD345、Fyは345 N/mm²とした。材料名、Fy、配筋、荷重をそろえ、断面に割り当てるせん断補強筋の材料区分だけを変更した。通常の検定は部材IDと正規化位置0.5で照合した。終局の静的需要は左右支持のRC梁で両端降伏の入力を与え、確定総応答は追加の長期せん断力なし・上限強度倍率1とした。

| 確認対象 | 比較内容 |
| --- | --- |
| RC・SRCの許容応力度検定 | 正しい材料区分と、鋼材・コンクリート区分への変更、鉄筋区分への修正を比較。診断に部材・断面・材料名・現在区分・修正方法が残り、修正後に同じ結果へ戻ることを確認した。 |
| RCの独立不適合 | 大きい曲げ・せん断需要と20 mmのかぶりで、曲げ・軸力と構造規定の不適合、長期柱の許容せん断、1991方式の付着を比較した。1999方式は、長期と短期でかつ補強筋間隔0または脚数0の場合に付着不適合を保持し、横補強効果を用いる短期は未算定とした。補強筋項が0となる梁・柱のせん断と長期たわみの不適合も照合した。短期柱ではQD1、Min、QD2で同じ位置の重力参照が欠けると代替需要で判定せず、QD2で一方向だけ参照が有限ならその方向のせん断不適合を保持した。 |
| SRCの独立不適合 | 長期柱の一体式と、梁・短期柱の鉄骨部のせん断、曲げ・軸力を比較した。鉄骨部と分担する場合は、材料区分の不一致でRC部の補強筋強度を用いる耐力を保留した。短期地震時のQd1では、帯筋脚数0の方向でRC柱脚曲げ参照が非有限でも、鉄骨部の確定した不適合を保持した。 |
| RCの終局検定 | 3断面それぞれで塑性理論式と靭性指針式を選択し、静的需要と確定総応答の両方で材料区分を変更した。せん断・付着の未算定と、曲げ終局耐力、柱の曲げ不適合と参考軸終局耐力の保持を確認した。補強筋間隔0および矩形柱弱軸の補強筋脚数0で、強度を使わずに確定したせん断不適合を保持した。間隔0の塑性理論式の付着不適合を保持し、靭性指針式の付着は未算定とした。 |
| 終局せん断・付着の上限が厳密に0となる条件 | 矩形柱の確定総応答で、靭性指針式の Rp=0.05 rad または間隔2,000 mm、塑性理論式の Fc=140 N/mm² を入力。既存式による0のせん断耐力を正しい材料と区分不適合の双方で確認した。靭性指針式では異形主筋の付着耐力・余裕度がともに0で、区分不適合時の付着信頼強度が未算定であることを確認した。主筋が丸鋼または棒種不明の場合は付着の保留を維持した。 |
| 主筋とせん断補強筋の両方が区分不適合 | RC梁で主筋を鋼材区分、せん断補強筋をコンクリート区分に割り当て、両方の修正方法を確認した。1991方式の付着・短期せん断と、塑性理論式の終局付着・せん断の独立した不適合を保持した。SRC梁とSRC柱でも両割り当てに対する診断を確認し、短期の鉄骨部のせん断不適合を保持した。 |
| 時刻歴簡易検定 | RC梁とSRC梁の部材中央の確認で、重力参照を用意できない場合の材料診断と確定した曲げ不適合を比較した。 |
| 保存結果 | 検定版98で保存された検定を失効させ、現行解析版の保存内力を保持したまま再検定し、検定版99を記録する契約を確認した。 |

公開検定の回帰は [材料区分の試験](../../crates/sepika-design-jp/tests/shear_rebar_category.rs)、[長期たわみの試験](../../crates/sepika-design-jp/tests/girder_deflection.rs)、[SRC柱の曲げ方式の試験](../../crates/sepika-design-jp/tests/src_column_seismic_bending.rs)、時刻歴は [簡易検定の試験](../../crates/sepika-app/src/viewer/signed_q0_acceptance_tests.rs)、保存は [保存契約の試験](../../crates/sepika-app/src/app/result_contract_tests.rs) を参照。

## 確認範囲

検証したのは採用済みの式に対する材料の適用条件と、未算定と独立した不適合を伝える結果契約。規準の任意の配筋・軸力・荷重範囲での妥当性や、実験値との一致は確認していない。非線形解析のせん断補強筋の材料区分は [#1809](https://github.com/hrntsm/SEPIKA/issues/1809) で追跡する。
