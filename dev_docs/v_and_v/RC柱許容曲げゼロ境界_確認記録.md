# RC柱の許容曲げゼロ境界（#1285・#1374・#1803・#1813）

## 結論と検証範囲

#1375で確認した危険側の誤合格を修正し、正常断面でも許容曲げが非正かつその方向の需要が非零なら理由付き未検定とする。有限Verificationであり、円形等価近似の精度、全軸力域・配筋・材料、実験Validation、短期軸応力度の警告方向（#1008）は確認範囲外である。製品仕様は[RC断面検定](../../docs/calc_basis/06_一次設計/02_RC_断面検定.md#柱の二軸曲げの合成)を正とする。

## 再現入力と独立期待

単柱の下端固定、上端自由、節点は(0,0,0)と(0,0,3000) mm。柱用途、普通コンクリートFc24、主筋・帯筋SD345、主筋径19 mm、帯筋径10 mm・間隔100 mm、かぶり40 mmとする。矩形は400×600 mm、両方向の最外段各3本で角筋の重複を除いた8本、帯筋は両方向2脚。円形は直径600 mm、等間隔8本。D19はGUIの径選択肢の保存値19.0を使う。解析用材料はコンクリートE=23000、鉄筋E=205000 N/mm²、密度はそれぞれ2.4e−9、7.85e−9 t/mm³。

長期fc=8 N/mm²、n=15、ft=215 N/mm²である。一様圧縮でコンクリート8、鉄筋120 N/mm²となり、コンクリートが支配する。8本の主筋面積はπ×9.5²×8=2268.229896 mm²。コンクリートと鉄筋の重複を除く換算面積は、総面積に主筋面積の14倍を加える。一様圧縮合力の独立値は次のとおり。

| 断面 | 総面積 mm² | 換算面積 mm² | 軸力単独上限NA N | NAでの許容曲げ N·mm |
| --- | ---: | ---: | ---: | ---: |
| 矩形400×600 | 240000 | 271755.218542 | 2174041.748340 | 0（両方向） |
| 円形600 | 282743.338823 | 314498.557366 | 2515988.458925 | 0（両方向共通） |

表は小数6桁へ丸めた説明値であり、境界再現の入力には `rc_column_axial_boundary_reference.rs::axial_limit_n` の途中丸めなしのf64値を用いる。丸めたNAを再入力すると0分岐への到達・合否が変わり得る。

上限では全断面が許容圧縮応力に達する一様な線形ひずみとなる。埋め込まれた鉄筋の応力も同じひずみに対応する。平面保持で非零の曲率を加えれば圧縮側の応力が上限を超えるか、上限内に保つために軸合力を下げる必要がある。したがってNAと非零曲げの同時作用を適合とすることはできない。これは走査・補間実装を再計算した期待値ではなく、一様圧縮と断面の釣合いから得た境界条件である。円形の全主筋を使う一様圧縮上限と、曲げ時の等価正方形・筋集約の精度は区別する。

## 修正後の検証

`sepika-design-jp/tests/rc_column_zero_moment_capacity.rs` は共有入力と独立NAを用い、矩形・円形の位置0・0.5・1を共通製品入口から検証する。

| 圧縮軸力 | 曲げ需要 | 期待結果 |
| --- | --- | --- |
| 0.99NA | 両方向1 N·mm | 正容量の対照、比約0.99で適合 |
| NA | 両方向0 | 比1で適合 |
| NA | 各方向単独・二軸の非零 | 理由付き未検定 |
| 1.01NA | 各方向単独・二軸の非零 | 理由付き未検定。現行の軸力判定は[#1813の検証](#曲げ未検定の位置での軸力超過1813)を参照 |
| 1.01NA | 両方向0 | 比1.01で不適合 |

正常な圧縮境界モデルでは、矩形の両方向の曲線は共通NAの曲げ0の終端を持つ。片方向だけ0容量の方向交換契約はprivate `column_moment_ratio` の試験で、(0,20)/(20,0) N·mmを与えて検証する。0容量方向の需要0・他方向需要30では比1.5を保持し、0容量方向に−1を加えると理由に両容量・両需要・N/NAを保持する。

`linear_static_once` の実解析では有限節点荷重と有限断面力を確認し、矩形は未検定になる。円形は浮動小数点の丸めでNA直下・微小正容量となる場合があるため、有限の不適合または未検定を要求する。0とみなす新しい閾値は導入しない。`sepika-job/tests/rc_column_axial_boundary.rs` は共通準備と自重を含め、上端が独立NAになる節点荷重を与える。

MCP廃止前に実施した `rc_column_boundary_mcp_case_and_combination_are_unchecked_in_json` では、単独長期ケースと保存長期組合せを実ジョブへ通し、せん断の不適合がないときの未検定3・不適合0・全件適合falseと理由のJSON保持を確認した。

## 軸力・曲げの未検定とせん断の併記（#1803）

日本建築学会『鉄筋コンクリート構造計算規準・同解説』2024年版14条2項（p.19）は軸力に応じた許容曲げを扱い、15条2項(1)(i)の式(15.1)（pp.19–20）のαは曲げとせん断の需要を参照する。15条2項(1)(ii)（p.20）は長期せん断の需要を最大せん断力とする。許容曲げが0でも、その値は長期せん断の需要・許容値の算定に必要な入力ではないことを確認した。照合範囲は軸力・曲げの状態とせん断を別に判定できることに限り、円形等価矩形の精度や短期せん断の全適用条件は対象外とした。

公開 `run_member_design_checks` に両形状の圧縮NAと非零の二軸曲げを与え、1,000 kNのせん断を与える位置で軸力・曲げ未検定とせん断NGを返すことを確認する。長期Fc24でα上限1.5、幅・応力中心距離をそれぞれ外径または断面の最大寸法600 mm以下としても、許容せん断力の上限は600×600×1.5×0.73 = 394,200 Nであり、1,000 kNはこれを超える。0、10 kNの位置では軸力・曲げの未検定だけを返す。短期地震時は参照の部材欠損・位置欠損・成分非有限、他方向の独立NG、柱端軸力で確定するQD1と同位置せん断も必要とするmin方式を区別する。柱端の重力参照軸力・応答軸力の欠損と非有限、有限な両入力から算出した設計軸力の非有限は、それぞれ理由を返す。QD2単独では検定位置の重力参照せん断力で判定できる。時刻歴の簡易検定入口には、設計用せん断力を使わない荷重状態の両形状を与え、軸力・曲げが未検定の位置にせん断NGを追加しないことを確認する。

QD1・min方式の柱端条件は、矩形・円形の梁要素、ファイバー要素、マルチスプリング要素を公開入口に与えて確認する。両柱端の条件が揃う場合はせん断NGと軸力・曲げの未検定を同位置に返す。検定位置に重力せん断が存在しても、柱端の条件が不足するmin方式は未検定理由を返す。

#1803のGUI検証は、両形状の1.01NA・水平荷重1,000 kNを共通準備と静的解析へ通し、3位置のせん断NGと未検定、保存・再読込、検定版100の結果失効と明示再検定を確認した。水平荷重10 kNと1,000 kNを対照にした描画検証では、位置ごとのツールチップ、理由、部材の凡例に出るNG件数と未検定表示を確認した。これらの試験は[#1813の軸力超過の検証](#曲げ未検定の位置での軸力超過1813)でも使用する。

検証コマンドと完了結果は修正PRに記録する。独立NAの根拠は上記の一様圧縮釣合いとし、走査・補間の実装を期待値として複製しない。

## 曲げ未検定の位置での軸力超過（#1813）

状態🔶。通常の長期・短期断面検定について、曲げ未検定の位置で独立に確定した軸力超過が結果に残ることを検証した。判定と表示は[製品の計算根拠](../../docs/calc_basis/06_一次設計/02_03_RC柱の軸力_二軸曲げ検定.md#曲げが未検定の位置での軸力判定)を参照。

### 原典と独立期待値

日本建築学会『鉄筋コンクリート構造計算規準・同解説』2024年版の12条（p.17）、14条(1)(2)（p.19）、14条解説の断面釣合い（pp.144–146、式(解14.1)）、解説図14.3・14.4（pp.148–149）を照合した。コンクリートの引張を無視し、長期・短期に同じヤング係数比を用いて、コンクリート圧縮側の応力を積分し、全鉄筋の応力を総和する。Fc24・SD345の対照値は長期でfc=8・ft=215 N/mm²、短期でfc=16・ft=345 N/mm²。

一様圧縮ではn=15の換算断面にコンクリート許容圧縮応力度を掛ける。対応する鉄筋応力度は長期120、短期240 N/mm²であり、各期間ともコンクリートが支配する。一様引張では鉄筋だけが引張を負担し、径19 mmの全主筋8本の断面積2268.229896 mm²にftを掛ける。圧縮には上記400×600 mmとD600 mmの断面を使い、引張は矩形500×500 mmとD600 mmを使った。表は小数6桁に丸めた値で、試験入力に途中丸めはない。

| 荷重期間 | 矩形のNA (N) | 円形のNA (N) | 矩形・円形のNT (N) |
| --- | ---: | ---: | ---: |
| 長期 | 2174041.748340 | 2515988.458925 | 487669.427617 |
| 短期 | 4348083.496680 | 5031976.917849 | 782539.314083 |

圧縮・引張とも対応する上限の1.01倍で、独立期待比は上限に対する需要の比1.01。曲げ需要を0、Myのみ1 MN·mm、Mzのみ2 MN·mm、両方向の4通りとする。期待は、上限一致・曲げ0で比1の軸力・曲げ検定、上限一致・非零曲げで理由付き未検定、1.01倍・曲げ0で比1.01の軸力・曲げ不適合、1.01倍・非零曲げで比1.01の「軸」の不適合と理由付き未検定。全ての入力を柱脚・中央・柱頭の各位置で照合した。

### 公開検定・GUI・保存

- [公開通常検定](../../crates/sepika-design-jp/tests/rc_column_zero_moment_capacity.rs)では、独立値による需要を与え、比は絶対誤差10⁻¹²以内、検定種類・詳細の値と単位・曲げ未検定理由は同じ位置で確認した。時刻歴の簡易検定では従来の理由付き未検定を確認した。単一結果APIの理由付き未検定はコード経路を確認した。独立せん断の回帰は許容軸力一致を入力として確認した。
- 公開通常検定に、有限の軸力（倍精度の最大有限値）と、1 N未満の正の引張上限になる矩形モデル（主筋径0.01 mm）を与えた。比を倍精度の有限値で表せない場合の境界試験であり、最大有限値を下限として出し、詳細に下限である旨と上限・需要を表示して軸力超過を保持することを確認した。
- [実解析とGUI描画](../../crates/sepika-app/src/viewer/check_ratio.rs)では、矩形と円形の圧縮柱に水平荷重10 kNまたは1,000 kNを与えた。確定表示は前者で軸、後者で軸・せん断。それぞれ「軸」の内訳、3位置のNGと未検定理由の併記、凡例のNG部材1件を照合した。引張柱も純引張および非零曲げを伴う超過の描画を確認した。
- [実解析・OVIKA保存と再検定](../../crates/sepika-app/src/app/rc_column_boundary_tests.rs)では、検定版108の保存と読込でNGと未検定の全明細を照合した。検定版107は読込時に検定を失効させ、解析内力を保持したまま再検定によって版108の同じ結果を得た。

## 短期の解析内力が非有限の場合（#1850）

状態🔶。既存の断面諸元と算定式を使い、適否判定に必要な断面力と公開入口の結果を照合した。製品での読み方は[軸力・二軸曲げ](../../docs/calc_basis/06_一次設計/02_03_RC柱の軸力_二軸曲げ検定.md#短期の解析内力が非有限の場合)と[せん断検定](../../docs/calc_basis/06_一次設計/02_04_RC柱のせん断検定.md#短期の解析内力が非有限の場合)を参照。

[#1850の修正前の報告](https://github.com/hrntsm/SEPIKA/issues/1850)では、矩形・円形柱に通常短期の断面力 `[NaN, 0, 0, 0, 0, 0]`（N、Qy、Qz、Mx、My、Mz）を与えると、各形状の3位置がすべて適合だった。[修正後の公開入口試験](../../crates/sepika-design-jp/tests/rc_column_nonfinite_forces.rs)には、矩形400×600 mm・円形D600 mm、Fc24、SD345の数値径19 mm主筋8本、長さ3,000 mmの片持ち柱を用いた。

| 条件 | 確認結果 |
| --- | --- |
| 全3位置のN、My、MzのいずれかをNaN、正負の無限大、有限0とする | 非有限は該当成分名を含む理由付きの未検定、有限0は軸力・曲げ検定比0 |
| 曲げ片側をNaN、他方を1,000 kN·mとする。別の入力で引張1,000 kNまたは安全確保のせん断1,000 kNを与える | 有限な方向の曲げによる不適合、純引張上限超過による「軸」の不適合、αを使わない安全確保のせん断不適合を、それぞれ未検定と併記 |
| 損傷制御で0、0.25、1のいずれかの曲げ試料がNaN。中央は有限で、片方向にせん断1,000 kN | 中央のQy側はMz、Qz側はMyの全試料に依存。曲げが欠けた側は未算定となり、反対側の不適合を保持 |
| 柱長500 mm。重力参照断面力は各位置で有限0。柱端または中央のNをNaNにし、Qyは1,000 kN | QD2単独はN非有限の位置でも必要なせん断力があれば不適合。柱端Nが非有限の場合、QD1と小さい方の方式は中央でも未算定。柱端Nが揃う場合は中央Nが非有限でも、柱端に基づくせん断の不適合を保持 |
| 時刻歴用の公開 `RcDesign.check_outcomes` に中央NがNaN、Qyが1,000 kN、同位置の重力参照は有限0、柱端のメカニズム情報なし | QD2で確認したせん断不適合と未検定を併記。局所Nを要するQD1の代替算定を保留し、QD1単独と小さい方の方式は未検定。単一結果の `RcDesign.check` は各方式で理由付き未検定を返す |

軸力・曲げについて有限な方向の下限から不適合を出せる根拠は、矩形の比の和と円形の比の二乗和がともに非負項の和であること。損傷制御のせん断については、有限な試料だけで最大曲げを決めると、割増係数αを過大評価しうる。QD1とQD2の小さい方の採用は、必要な枝の不明時にはその方向を確定できない。

[アプリのOVIKA試験](../../crates/sepika-app/src/app/rc_column_boundary_tests.rs)で、解析版108の保存内力を維持し、直前の検定版108の検定結果を失効させる。明示再検定後の検定版109の全明細を新規検定と照合する。[#1843](RC柱の長期せん断需要_Issue1843_検証.md)・[#1854](RC柱の長期許容せん断力_Issue1854_検証.md)の保存長期は、材端フェースを使うせん断と位置ごとの軸力・曲げの回帰試験で確認する。

### 確認の範囲

- 現行の[線形・非線形時刻歴の記録処理](../../crates/sepika-solver/src/dynamic/timehistory/recording.rs)は、非有限の断面力を含む試料をエラーとする。非有限軸力に対する簡易検定の確認は公開APIへの直接入力で行った。[時刻歴の表示](../../crates/sepika-app/src/viewer/th_detail.rs)には別のせん断スパンの試料選択があり、投入試料が非有限となるGUI操作は確認していない。
- 矩形・円形の長期単独ケース `SingleCase` では、長さ3,000 mmの上記モデルの全3位置に `[NaN, 0, 0, 0, 0, 0]` を与え、全3行が検定比0となる現象を一時試験で確認した。長期の単一結果 `RcDesign.check` に同じ入力を中央で与えても検定比0となった。[#1864](https://github.com/hrntsm/SEPIKA/issues/1864)
- CFT柱の同種の課題は別途追跡する。[#1863](https://github.com/hrntsm/SEPIKA/issues/1863)
