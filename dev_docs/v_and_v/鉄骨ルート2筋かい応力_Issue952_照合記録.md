# 鉄骨造ルート2の筋かい地震時応力割増し（#952）

確認日 2026-11-18。製品コードの確認基点は `d90f0112`。[Issue #952](https://github.com/hrntsm/SEPIKA/issues/952)、[先行するルート照合（#880）](鉄骨耐震ルート_Issue880_原典照合.md)。

通常の部材検定ではルート2用の筋かい水平力分担率βを算定せず、一次地震時応力の割増しと周辺部材への伝達を行わない。未割増しの応力で検定比が1.0以下でも、ルート2用の応力ではNGとなり得ることを、固定入力で共通の公開検定入口から確認した。

## 割増しの条件と応力の伝達

| 原典箇所 | 確認結果 |
| --- | --- |
| 図6.3-1、pp.375–376、p.389 | 一次設計に続く鉄骨造ルート2の要件の一つ。本文は高さ31 m以下、地上部分の塔状比4以下、層間変形角1/200以下（著しい損傷のおそれがない場合1/120以下）、剛性率0.6以上、偏心率0.15以下を列挙する。筋かい端部・接合部の破断防止、局部座屈等の防止、柱脚の安全性、冷間成形角形鋼管柱の条件等も別に存在する。 |
| p.387、告示昭55建告第1791号第2第一号 | 鉄骨造または鉄骨造と他構造の併用建築物で、水平力を負担する筋かいのある階（地階を除く）が対象。令第82条第1号により得た構造耐力上主要な部分の、令第88条第1項の地震力による応力に、β≤5/7なら1+0.7β以上、β>5/7なら1.5以上を乗じる。得た地震時応力を用いて令第82条第2号・第3号の構造計算を行う。βは同一階・地震方向の一次地震時に、筋かいが負担する水平力をその階の全地震層せん断力で除した無次元量。 |
| pp.390–391、6.3.3(1)、図6.3-3・6.3-4 | 筋かい構面とラーメン構面の復元力特性・エネルギー吸収差を背景に、筋かいの強度増加に伴う周辺の柱・梁・柱脚への作用増を記載。本文ではβ=5/7を1.5倍側で説明している。掲示された告示の表では等号は1+0.7β側であり、境界の下限値はどちらも1.5。 |
| pp.387–389、p.391の6.3.3(2) | 筋かいの端部・接合部は軸部降伏時に破断しないことを別に確認する。冷間成形角形鋼管の柱梁耐力比や該当する1階柱脚への係数は別の条項である。p.391は、特定のSN鋼材で幅厚比を別式によって評価する場合や、梁等について局部座屈が生じないことを確認した場合に幅厚比規定のただし書を適用できる例を扱う。これらの条件は第一号の応力割増しを免除する根拠にならない。 |
| p.650、付録①・付図1.2-8 | 原則として対象階全材の一次設計用地震力による応力を割り増す。図の上・中・下階の係数は1.3、1.5、1.0で、異なる階の割増率を平均できる境界梁の例は1.4、1.25。図は長期荷重を省略している。例で下階の未割増し柱軸力が上階の割増し柱軸力を下回る場合、少なくとも下階が上階を下回らないよう設定する。実際の柱軸力増分の伝達は適切に評価する。 |
| p.650、付録②・付図1.2-9 | ①による軸力の割増しが過大になり得るときの方法。筋かい以外の曲げ・せん断と筋かい軸力を割り増し、筋かい軸力・梁せん断力等の増分から節点の力の釣合いで柱・梁の軸力増分を求め、元の軸力に加える。図の柱軸力増分は上階から下階へ累積し、筋かいのない下階でも上階の増分と直上梁のせん断力による増分を受ける。得た地震応力と長期荷重による応力を加えて検討する。 |
| p.651、付録③ | 一次設計用地震力で各層のβを求め、層せん断力に各層の係数を乗じる。割増し後の層せん断力の差から各階の水平力を逆算し、その荷重で再解析して設計用地震応力を求める方法。 |

付録③の手計算例として、上階から順に層せん断力100、200、400 kNを1.3、1.5、1.0倍すると、割増し層せん断力は130、300、400 kN。差分から得る各階の水平力は130、170、100 kNとなる。当初の各階水平力に個別に同倍率を掛けると130、150、200 kNとなり、結果が異なる。

割増しは一次地震成分にかかる。符号を保った設計用地震応力に、長期応力や多雪区域の地震時に必要な積雪応力を該当する組合せで加える。対象階の割増しと、その影響の下階・柱脚への伝達を確認する。付録の三つの方法は個別の検討例であり、任意の架構で同じ断面力になることは未確認。終局評価点のβuや、作用方向の異なる地震ケースの分担率を代用しない。地階の除外は割増しを発動する階の条件であり、上階からの影響を無視する根拠にはならない。

## 現行入口と有限Verification

| 入口 | コードで確認した動作 |
| --- | --- |
| GUIの設計タブ・部材検定 | `App::run_design_check`（`crates/sepika-app/src/app/actions/design/check.rs`）が選択中の解析断面力を共通検定へ渡す。検定比表示は得られた有効な比に基づく（`crates/sepika-app/src/viewer/check_ratio.rs`）。ルート2を指定して地震成分を割り増す入力や、自動でルート2を認定する処理はない。 |
| MCPのDesignCheck | `compute_design_check_job`（`crates/sepika-mcp/src/job/design_check.rs`）で保存組合せの各ケースを解析・合成して共通検定に渡す。積雪ケースのないモデルで地震ケースを指定した場合は検定用G+Pを自動合成し、積雪ケースがあれば保存組合せの指定を求める。NGの判定は `CheckResult::ok()` による。応答の `load_target.legal_conditions_verified` は一律に `false` で、ルート2に特化したフィールドはない。`n_ng` や `all_members_checked_and_ok`・`all_checked_and_ok` は共通検定で得た結果を集計する。 |
| 公開の共通検定 | `run_member_design_checks`（`crates/sepika-design-jp/src/member_design_check.rs`）が入力断面力を `SteelDesign::check` へ渡し、通常の筋かいは `steel::brace::check_brace` で引張・圧縮の軸力を検定する。引張では総断面積と許容応力度を用いる。 |
| 荷重組合せの制約 | `combination_design_state`（`crates/sepika-core/src/load_combo.rs`）は地震ケース係数の絶対値1を標準組合せとして受理する。任意の係数で地震ケースを増やした保存組合せを、通常の短期検定にそのまま使えるとは限らない。引張専用反復を用いる筋かいがある場合の別ケース合成はGUI・MCPとも理由付き未検定となる。 |

有限試験は、総断面積750 mm²の平鋼75×10 mm、基準強度235 N/mm²の引張筋かいに、同一断面・短期条件で以下の組合せ軸力を一つずつ入力する。短期許容引張力は750×235=176.25 kN。50 kNの長期成分と100 kNの一次地震成分、β=0.5を仮定すると、地震成分の下限倍率は1.35となる。

| 共通検定への軸力入力 | 独立期待値 | 観測判定 |
| --- | --- | --- |
| 未割増し 50 + 100 = 150 kN | 150/176.25 = 40/47 ≈ 0.851064 | OK |
| 地震成分だけ割増し 50 + 135 = 185 kN | 185/176.25 = 148/141 ≈ 1.049645 | NG |

テストは [`steel_route_2_brace.rs`](../../crates/sepika-design-jp/tests/steel_route_2_brace.rs) の `unamplified_route_2_brace_demand_can_pass_when_amplified_demand_fails`。公開入口の観測値を独立期待値と絶対誤差1×10⁻¹²で比較する。軸力は外部で与えた固定断面力で、βの算定や荷重組合せの生成、架構全体の釣合い、下階伝達・柱脚、他の条項の適合はこの試験の対象外。GUI・MCPの表示については共通検定への接続と結果の扱いをコードで追跡した。手動GUI・MCP実通信・実建物や実験によるValidation・専門家サインオフは未確認で、V&V状態は🔶。

ローカルでは対象試験1件、`cargo test -p sepika-design-jp --locked`（対象試験を含む761件）、`cargo clippy -p sepika-design-jp --all-targets --locked -- -D warnings` が成功した。初回の対象試験では単体テスト専用の補助メソッドを統合テストから参照してコンパイルに失敗し、公開の列挙型の判定へ置き換えた。

## 利用条件と残る課題

[鋼構造の断面検定](../../docs/calc_basis/06_一次設計/03_鋼構造_断面検定.md#計算ルートに応じた応力の確認)に、通常結果の範囲と設計者が別途確認する条件を記載した。対象建物では一次地震方向ごとの分担率、設計に利用する柱・梁・筋かい・柱脚の応力、上階の軸力増分の下階への伝達を外部計算または別途検討で確認し、その応力に対する短期許容応力度等と接合部・柱脚を照査する。付録①の脚注が挙げる『建築士事務所』1991年6月号、付録③の引用文献本文、特殊架構での適用範囲、告示と通達の全改正履歴は未確認。

鉄骨筋かいを含む地震時の検定結果で、ルート2を適用する場合の割増しと伝達が未確認であることを示す表示の是正は、[#1407](https://github.com/hrntsm/SEPIKA/issues/1407)で追跡する。個別建物の適用資格、割増しの対象階・方向、採用する計算方法とその適用範囲は別途判断する。
