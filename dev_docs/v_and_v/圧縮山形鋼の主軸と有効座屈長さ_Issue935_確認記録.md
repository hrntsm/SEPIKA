### 片脚接合を中心圧縮材として扱える範囲

許容応力度設計規準 §11.4(2) は、トラスのウェブ材が単一山形鋼で、片脚を弦材またはガセットプレートへ接合する場合、節点間距離と最小断面二次半径で細長比を求め、中心圧縮材として算定してよいとする。軽微な組立材でウェブ材を高力ボルト1本で接合する場合は、材の許容応力度を1/2に低減する。細長比や法定上限を半減する規定ではない。

解説図11.4.9（p.89）・p.90は、ガセットによる図のξ軸まわりの支持がピンに近く、η軸まわりが固定に近いと説明する。この材端拘束と偏心を持つウェブ材について、曲げねじれ座屈解析とトラス実験を根拠に、図の最小主軸まわりの両端ピン中心圧縮材としての評価を安全側とする。ボルト1本では材端拘束が小さく偏心で耐力が下がる。§11.4(2) が対象とするのは部材の圧縮検定であり、片側ガセット接合部自体には §14.3(2) の偏心検討が別途必要になる。

## 断面主軸と支持条件の対応

- 図心を通る脚と平行な局所 y、z 軸に対し、Iy = ∫z²dA、Iz = ∫y²dA、Iyz = ∫yz dA と定義する。主軸は対称行列 [[Iy, −Iyz], [−Iyz, Iz]] の固有方向で、固有値が主軸の二次モーメント。断面輪郭・図心を特定できる場合は断面積分から両方を導出する。直接与える場合は面積、図心基準、局所座標に対する主軸方向、主軸の大小と二次モーメントの対応を一組として検証する。断面の回転や反転に応じて方向と符号も変わるため、二次モーメントの大小だけで向きは復元できない。脚軸に対する部材の向きと、接合した脚と力の作用線を保持する。
- 支持・補剛を主軸表現へ移しても、各主軸の曲げが互いに独立で、ねじれ等の座屈が別途扱われている条件では、主軸ごとの境界条件で有効座屈長さを決め、同じ軸まわりの二次半径 i = √(I/A) と対応させる。両方向が同じ理想ピン支持のように、軸を回しても支持条件が等しい場合は、共通の材長と最小主軸二次半径が支配する。両方向の長さの数値が同じことだけでは支持条件の等価性を示せない。
- 拘束方向が断面主軸と異なれば、各端の横移動・曲げ回転や中間補剛条件が主軸表現で連成し得る。有効長さは支持を解いた結果であり、方向ベクトルのように回転・射影できない。座屈解析で、実際の端部および途中の移動、回転、ねじれ・反りに対する拘束、軸力分布と接続を評価する。連成固有値を令65条の主軸別細長比や許容圧縮応力度に用いるための一般的な対応規定は、今回の原典範囲では確認できなかった。
- 偏心がある場合は荷重作用線と断面図心の距離から生じる曲げ、横荷重とせん断中心の位置関係によるねじれ、二次変形や反り・ねじれ拘束、曲げねじれ座屈を検討する。開断面のねじり性状は主軸の断面二次モーメントだけで定まらない。接合部の断面欠損、幅厚比・局部座屈、架構の安定、圧縮と曲げの組合せも、それぞれ適用する根拠が要る。

幾何軸の既存性能は [断面諸量](../../docs/calc_basis/03_断面性能/02_断面諸量.md#塑性断面係数-zp-の算定範囲) を参照。
[ST-Bridgeの独立断面積分](STB単材形鋼の正値半径_Issue1386_確認記録.md)で確認した輪郭と軸の区別は、今後の断面入力・積分の照合に再利用できる。ST-Bridgeから形鋼形状を読めても、主軸別の座屈長さや接合偏心の評価条件は別途確認する。

## 独立計算

### 断面と理想両端ピン

角なしの等辺L100×100×10 mmを、脚方向の座標で二つの非重複矩形 [0,100] × [0,10]、[0,10] × [10,100] に分け、矩形重心まわりの二次モーメントに平行軸項を足した。Python標準の有理数で積分した結果、A = 1900 mm²、図心は両座標とも28.684210526 mm、Iy = Iz = 1800043.859649 mm⁴、Iyz = −1065789.473684 mm⁴。弱主軸は (e_y − e_z)/√2、強主軸は (e_y + e_z)/√2 で、I_w = 734254.385965 mm⁴、I_s = 2865833.333333 mm⁴、i_w = 19.658323347 mm、i_s = 38.837267326 mm。幾何軸の二次半径は両方向とも30.779725552 mm。

SS400、F = 235 N/mm²、E = 205000 N/mm²とし、断面図心に一定圧縮を作用させ、両端で横移動を両方向拘束し曲げ回転を両方向自由とした。ねじれ・反り、局部座屈、初期不整、偏心の自由度を含まない理想弾性曲げの比較であり、両主軸の l_k は材長 L。各行は l_k/i で細長比を求め、学会規準 §5.1(3) 式(5.4)(5.5) の Λ = 119.789085、長期 f_c = 0.277F/(λ/Λ)²、短期1.5倍を独立算術に用いた。

L6000では弱主軸の応力度比も1未満だが、構造規定比は柱1.526071・柱以外1.220857で双方が上限超過する。表の上限超過行に示した応力度比はこの差の比較用で、製品による検定出力ではない。L4500の柱以外は上限内でも長期の純圧縮許容応力度を超える。告示1024号の炭素鋼表1で同じ細長比を代入すると、L6000・L4500・L3000の弱主軸の長期値は順に10.03283・17.83614・40.13131 N/mm²。告示の Λ = 1500/√(F/1.5) と係数18/65を用いた値であり、ここでの上限・純圧縮の判定関係は同じ。式を採用する既存の経緯と材料Eの範囲は [#879の独立比較](鉄骨材料と許容応力度_Issue879_原典照合.md) と [ADR 0084](../adr/0084-steel-compression-material-e.md) を参照。

L3000の例で、図心から弱主軸に直角な方向に20 mm偏心し、脚の交点側が圧縮になる一次曲げを与えると、曲げモーメントは0.800 kN·m。角までの距離40.566 mmと I_w から一次曲げ応力度44.198 N/mm²、平均圧縮21.053 N/mm²を足した角の圧縮は65.251 N/mm²となる。純圧縮比だけではこの曲げを評価できない。この例は符号・作用位置・断面係数を明示した一次応力度の比較であり、偏心を受ける実材の支持条件、二次効果や許容曲げ耐力は算定していない。

### 幾何軸の回転拘束により主軸が連成する場合

同じL6000の断面に、両端とも y、z 方向の横移動を拘束し、幾何軸 y まわりの曲げ回転を拘束、z まわりを自由とした。材軸 x まわりのねじり自由度は含まない。各主軸の変位 w_j は、その軸まわりに正の曲げ回転を与える横方向 e_j × e_x を正とし、傾き w_j′ が曲げ回転、EI_j w_j″ が符号を揃えた曲げモーメントとなる。

材中央を x = 0 とすると、材中央に対称な弾性座屈モードは w_j = B_j[cos(k_j x) − cos(q_j)]、k_j = √[P/(EI_j)]、q_j = k_j L/2 と書ける。両端の変位はこの形で0になり、拘束回転 (w_w′ + w_s′)/√2 = 0 と自由軸まわりの曲げモーメント (−EI_w w_w″ + EI_s w_s″)/√2 = 0 が残る。二条件の行列式から次を得る。
q_w sin(q_w) cos(q_s) + q_s sin(q_s) cos(q_w) = 0
両端ピンの弱主軸Euler荷重 P_w = 41.26650182 kN と、自由な幾何軸まわりだけのピン曲げによる上界 P_w Iy/I_w を区間端として二分した。区間内では両主軸の q_j tan(q_j) が増加し根は一つ。材中央に反対称なモードの下限は、同じ断面の両端ピン条件での 4P_w であり、この根より大きい。

結果は最小弾性固有荷重 P = 87.36663446 kN、B_s/B_w = −1.62968767。回転拘束のある幾何軸の 0.5L を弱主軸、自由な幾何軸の L を強主軸と取り違えると、単独軸の最小Euler荷重を161.06531840 kN、支配細長比を154.490787と見積もる。この荷重は連成解より約84%大きく、危険側である。比較のため連成解の荷重を π√(EA/P) で換算すると209.763925。この換算値は理想弾性荷重を一つの数値で比較するためのものであり、令65条の判定値や実材の許容耐力には採用しない。

## 公開入口の確認と制限解除に必要な条件

基準 main `8c6e63fb`（#1448を取り込んだ調査ブランチ `a3d6b2e7`）で再実行した。`cargo test -p sepika-design-jp --test steel_slenderness --locked` は11件成功。既存の `issue901_compressed_angles_require_principal_axis_effective_lengths` は `SteelDesign::check` で #901 の反例と長短期・用途の制限を再現した。公開一括入口 `run_member_design_checks` は、同じ2節点の単一要素モデルを使った一時ハーネスで確認した。入力は SS400、`SteelAngle` のL100×100×10、L3000/4500/6000、柱/大梁/筋かい、長期/短期、両軸既定/各軸に材長を直接指定の36通り。偏心・材端フェース・横補剛の追加指定はなく、i端に +1 kN、中央に −1 kN、j端に 0 N の軸力を与え、他の断面力は0。36通りすべての圧縮位置が主軸と有効座屈長さの理由付き `Skipped` で、引張・軸力0の位置は `Checked`。公開入口の観測は検定結果の契約を対象とし、供給した断面力は支持条件からの求解結果ではない。形状を持たない直接性能の一般断面に、名称だけで山形鋼の制限が適用される保証はない。

既存のGUI回帰 `cargo test -p sepika-app --lib --features gui issue901 --locked` は6件成功。うち山形鋼の2件では、未検定を含む部材のグレー表示と各位置の理由、荷重組合せの切替を検証した。OVIKAの保存・失効・再検定は通常鋼の法定上限NGを用いた既存回帰で確認した。

- 限定した後続の実装候補は、§11.4(2)のトラスの圧縮ウェブ材だけを識別し、片脚の接合先・接合方法、両端条件、節点間距離、最小主軸半径の出所を確認する方式である。軽微な組立材の1本高力ボルト条件と半減、接合部検定との境界、令65条と部材許容応力度の独立判定、曲げ等が作用する場合や条件不足の保留を [#1449](https://github.com/hrntsm/SEPIKA/issues/1449) で扱う。通常の「筋かい」分類や、通常Sに直接長を入れたという事実だけではこの方式を選べない。
- 一般の柱・大梁・筋かいは未検定を維持する。解除には、同じ実断面・主軸方向・配置と端部境界が検定及び応力解析で対応すること、主軸ごとの有効長の根拠、連成や偏心・ねじれを扱う方法、圧縮と曲げを組み合わせる場合の断面応力度と許容値の適用条件が要る。主軸別の既定長の採用、一般の曲げねじれ耐力、有効長への換算の安全性は未確認。
- 将来の解除時は共通検定入口の用途・組合せごとの結果を起点に、GUIの検定表・検定比図、該当する帳票とMCPの結果で、採用根拠・構造規定NG・応力度NG・理由付き未検定の意味を保持する。入力と結果の保存・再読込、入力変更や旧検定結果の失効、再検定後の表示を確認する。現行の混在位置・組合せ切替と旧成果の扱いは [#901の確認範囲](鋼圧縮材有効細長比_Issue901_確認記録.md) を参照。

一般の山形鋼・接合形状での実験Validation、専門家サインオフ、手動GUI、今回の供給断面力モデル固有のOVIKA保存・再検定は未実施。
