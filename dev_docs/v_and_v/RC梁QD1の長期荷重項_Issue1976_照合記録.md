# RC梁QD1の長期荷重項の支点と作用腕（#1976）

[Issue #1976](https://github.com/hrntsm/SEPIKA/issues/1976)・[現行のQ0算定](../../docs/calc_basis/06_一次設計/02_02_RC梁のせん断検定.md#rc梁の単純梁せん断q0)

単一RC矩形梁について照合した。実材軸端と実柱面では、同じ荷重でもQ0が異なり得る。照合した原典から式(15.7)の長期荷重項の支点・作用腕を一意に定められないため、比較モデルへの置換は保留し、現行の式・適用条件は変更していない。

## 原典から確認できる範囲

日本建築学会『鉄筋コンクリート構造計算規準・同解説』第10版（2024年）を照合した。 [書誌](https://ndlsearch.ndl.go.jp/books/R100000001-I25115036270)

| 照合箇所 | 支点位置の判断に使える範囲 |
| --- | --- |
| 第15条 p.22、解説 pp.174–175 | 式(15.7)の長期荷重によるせん断力は単純梁として算定できる。内法スパン長さは両端降伏曲げの和をせん断力に換算する項の分母。解説p.174は式(15.9)で使う長期荷重時せん断と区別する。単純梁の支点を柱芯・実柱面・剛域端のどこに置くか、支点外に荷重がある場合の伝達先や評価断面、支点反力をそのまま使えるかは示さない。p.175の梁端での応力評価はせん断スパン比による割増係数の説明であり、単純梁支点の定義ではない。 |
| 第15条解説 pp.202–203、4階BA3梁 | 架構応力図の長期せん断力214 kNと地震時せん断力144 kNから、式(15.9)で430 kNを求めている。式(15.7)の単純梁の作り方は同定できない。 |
| 付2「構造設計例」 pp.438、454–456、470 | p.438のフェイス値は長期・水平荷重時の断面算定用応力。梁の大地震時の安全性は終局強度に基づいて確認し、3階GA2梁の例は長期・損傷制御のせん断を示すが大地震時の安全性算定は省略する。p.454の単純梁は片端にモーメントを加える回転変形モデルであり、式(15.7)の長期荷重項の算定例ではない。 |

2026年11月26日時点で公開の正誤表・質疑回答に、式(15.7)の単純梁支点・作用腕に関する追記は確認されなかった。 [正誤表](https://news-sv.aij.or.jp/kouzou/s48/2024/seigo2024.pdf)・[Q&A](https://news-sv.aij.or.jp/kouzou/s48/2024/answer.htm)

## 独立した静力学比較

偏心のない水平梁の実材軸端を x = 0、5 m、両実柱面を x = 0.5、4.5 m とする。各ケースの下向き荷重の合力を W、その作用点（分布荷重は重心）を xG とする。i支点まわりのモーメント釣合いから j反力は W × (xG − i支点位置) ÷ 支点間距離、上向きを正とした i反力は W から j反力を引く。i・j反力の絶対値の大きい方を比較する。

| 梁に載せる荷重 | 実材軸端の反力 i / j → 最大絶対値 [kN] | 実柱面支持・内法内だけの反力 i / j → 最大絶対値 [kN] |
| --- | ---: | ---: |
| x = 0.75 m の集中荷重 P = 16 kN | 13.6 / 2.4 → 13.6 | 15 / 1 → 15 |
| 全長の8 kN/m、合力40 kN | 20 / 20 → 20 | 16 / 16 → 16（内法外を切り落とし、合力32 kN） |
| 内法内のみの8 kN/m、合力32 kN | 16 / 16 → 16 | 16 / 16 → 16 |
| x = 2.5 m の集中荷重 P = 16 kN | 8 / 8 → 8 | 8 / 8 → 8 |
| x = 0.25 m の集中荷重 P = 16 kN | 15.2 / 0.8 → 15.2 | 0 / 0 → 0（内法外を除外） |

x = 0.75 m の荷重に対する i反力の比は、実材軸端支持では (5 − 0.75)/5 = 0.85、実柱面支持では (4.5 − 0.75)/4 = 0.9375。支点間距離だけでなく荷重の作用腕も変わる。左右の後退距離が等しく、両案で同じ単方向荷重をすべて支点間に保持する場合は、重心が支点間の中央なら同値、中央から偏ると支点間距離が短い方が大きい。後退が左右で異なる場合は中央も移るため、この大小関係は一般化できない。全長等分布を内法で切る場合の差には、支点位置だけでなく荷重総量の減少が含まれる。

支点を実柱面へ移しても、内法外の荷重を張出し部に残すことはできる。両側0.5 mの張出しにも8 kN/mを残すと、支点反力は20 / 20 kNのままだが、内法側の支点直近の断面せん断力の絶対値は両端とも16 kNとなる。x = 0.25 m の集中荷重を残すと反力は17 / −1 kN、内法側の断面せん断力の絶対値は両端とも1 kN。これは鉛直の双方向拘束を仮定した比較で、実際に反力を引張側へ伝達できることや、内法外の荷重を柱へ直接割り付けてよいことを示さない。いずれもFEMの長期参照内力QLではない。

## 公開検定と通常検定の照合

### 一時プローブの再現手順

1. [通常検定試験モジュール](../../crates/sepika-app/src/app/signed_q0_acceptance_tests.rs)の `fixture::model()`（[荷重・組合せの入力モデル](../../crates/sepika-design-jp/tests/fixtures/signed_beam_gravity_model.rs)）を起点にする。梁は `ElemId(0)` とし、j節点の全体X座標だけを6000から5000 mmに変更する。断面0だけを [両端降伏の入力モデル](../../crates/sepika-design-jp/tests/fixtures/rc_beam_qd1_model.rs)の `model().sections[0]` に置き換える。このfixtureが参照する [配筋モデル](../../crates/sepika-design-jp/tests/fixtures/rc_beam_asymmetric_model.rs)は同じ試験モジュールに `asymmetric` として読み込む。梁は350 × 600 mm、上端2-D19、下端4-D19、有効せい550 mm。材料表は起点のまま（Fc24とSD345。Fc24の `density` は `2.4e-9` のまま）。梁の局所軸参照は `[0, 0, 1]`、材端偏心は0のまま。
2. 同じ両端降伏fixtureの `add_columns_at_outer_nodes` を参照方向 `[0, 1, 0]` で呼び、柱 `ElemId(1), ElemId(2)` を追加する。柱形状の幅とせいを1000 mmに変え、配筋を維持して `to_section` で断面1を再生成する。断面用途は柱とし、主材料・主筋・せん断補強筋の材料IDは梁断面から引き継ぐ。全節点を全体Zへ3000 mm上げる。梁節点0・1は `(0, 0, 3000)`、`(5000, 0, 3000)` [mm] で節点拘束なし、柱脚節点2・3は対応するX座標でZ = 0の全固定。梁・柱の部材端接合は剛接。梁の両端にフェース距離500 mm、手動剛域長350 mmを設定する。`model.stories` に `Story::new` で1F（ID 0）と2F（ID 1）を追加する。床レベルを `Some(0.0)`・`Some(3000.0)` [mm]、構造レベル差を両階とも `Some(0.0)` [mm] とし、`weight_override` を両階とも `Some(100_000.0)` [N] にする。
3. 各行で同じモデルを複製し、静力学比較表の順に固定荷重ケース0の部材荷重をその行の1件だけに置き換え、積載ケース1の部材荷重を空にする。荷重方向はすべて全体 `[0, 0, -1]`。集中荷重は `fixture::point` に位置をmm、力を16000 Nで与える。分布荷重は梁の0–5000 mmまたは500–4500 mmに、両端の強度8 N/mmで与える。組合せは起点のまま、0番「独立選択」は固定0＋積載1＋地震2、1番「独立重力」は固定0＋積載1で、係数はすべて1。地震ケース2のj節点の荷重（全体Z方向 −10 kN）は短期検定を通すための入力で、Q0には入れない。
4. 準備前の各モデルを `sepika_job::simple_beam_q0_by_terms` に渡し、項 `[(LoadCaseId(0), 1.0), (LoadCaseId(1), 1.0)]` に対する梁のQ0を実材軸端支持の独立値と比較する（絶対誤差が `1e-8 N` 未満）。`sepika_design_jp::run_member_design_checks` に同じモデルと梁 `ElemId(0)` の応答を渡す。正規化位置 `0.1, 0.5, 0.9` の各応答は `[0, 30000, 0, 0, 0, 1e7]` [N, N·mm]、パネル応答は空。検定オプションは短期・QD1単独とし、`long_member_forces` に同じ3位置の `[0, -7300, 0, 0, 0, 0]`、`q_simple_by_elem` にjobの結果を指定し、残りは既定値とする。
5. 同じ荷重行のモデルを新しい `App::default()` に読み込む。損傷制御を無効、QD1単独、スレッド数1とし、`run_preparation` の後に `run_combination(0)` を呼ぶ。自動生成された自重荷重ケースはこの組合せに加えない。`current_design_results()` から梁の正規化位置 `0.1, 0.5, 0.9` の検定結果を選ぶ。次に `run_combination(1)` を呼び、`current_static()` の `girder_column_face_forces` から梁のi・j実柱面（500・4500 mm）の断面力を取り出す。配列の要素 `[1]` の局所Qy [N] を符号を変えずにFEM QLとして記録する。

### 期待値と観測結果

降伏曲げによる項の独立期待値は、D19の公称断面積286.5 mm²から求めた両端の降伏曲げの和293.562225 kN·mを内法4 mで除した73.39055625 kN。これに実材軸全長5 mで求めた独立反力の最大絶対値を加える。両検定経路の各位置で、せん断の検定比に、詳細表示の `QA=` に続く許容せん断力 [N] を乗じて需要を復元した。表示丸めを含め、全5荷重・3位置で独立期待値に0.1 N以内で一致した。

| 荷重（前表と同順） | jobのQ0 [kN] | 公開・通常検定のQD1 [kN] | 通常解析でのFEM QL（i / j実柱面）[kN] |
| --- | ---: | ---: | ---: |
| 内法内偏心集中 | 13.6 | 86.99 | +14.969 / −1.031 |
| 全長等分布 | 20 | 93.39 | +16 / −16 |
| 内法内等分布 | 16 | 89.39 | +16 / −16 |
| 内法内対称集中 | 8 | 81.39 | +8 / −8 |
| 片側剛域内集中 | 15.2 | 88.59 | −0.258 / −0.258 |

検定位置は実柱面と中央でも、QD1に足したQ0は実材軸端で求めた値だった。偏心集中荷重では、降伏曲げの項を固定して実柱面支持の比較値を足すと88.39 kNで、観測した現行需要より1.4 kN大きい。全長等分布荷重と内法内等分布荷重のFEM QLはこの例では同値だが、梁に載せた全荷重が異なるためQ0には4 kNの差が出た。FEM QLでQ0を置き換えた結果ではない。

当時はプローブを追加した状態で下記のモジュール全体を実行し、一時プローブ1件と既存の通常検定試験6件が成功した。一時プローブは比較条件を回帰仕様として固定しないため、リポジトリには残していない。

- 現在のチェックアウトで既存6件を実行するには、`cargo test --locked -p sepika-app --lib app::signed_q0_acceptance_tests -- --nocapture` を使う。この6件だけでは上の観測を再現しない。
- 上の観測を再現するには、再現手順を同じ試験モジュールの一時テスト `issue_1976_qd1_arm_probe` として追加し、`cargo test --locked -p sepika-app --lib issue_1976_qd1_arm_probe -- --nocapture` でその1件を実行する。表の値はそのテストで観測する対象であり、実柱面支持案を実装して検定したものではない。

## 残る判断

状態🔶。現行Q0は同じ偏心荷重に対する実柱面支持の比較値より小さくなる例があり、実柱面への単純な置換や内法外荷重の一律除外にも安全側の保証はない。置換の要否と適用条件を決めるには、支持位置、柱芯側・剛域上の荷重をどこで負担するか、支点反力と内法側の断面せん断力のどちらを比較するかを合わせて定め、その候補を独立に検証する必要がある。実架構に対する適用性・実験Validationは未確認。 [製品方式の追跡 #2003](https://github.com/hrntsm/SEPIKA/issues/2003)
