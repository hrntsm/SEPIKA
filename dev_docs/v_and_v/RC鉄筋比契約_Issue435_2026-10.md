## 呼出し・生成契約の追跡表

寸法は mm、筋面積は mm²、Es/Ec は N/mm²、各比率は無次元。`RcCapacityInput.d` は**全せい D**、`d_eff` は**有効せい d**。
公開フィールドの一括改名は行わず、内部の用途名とRustdocで識別する。

| 入口・生成経路 | αy用pt | せん断用pt/pw | d/D、a/D、材料 |
| --- | --- | --- | --- |
| core `rc_alpha_y_sugano` | 引数 `pt_alpha_ratio` は小数。矩形 at/(bD)、T形は明示した引張方向の仮想断面 | 受け取らない | 引数d/D・a/D・n=Es/Ec。係数・分岐の是正は#523 |
| core `rc_qsu_simple` | 受け取らない | **pt外部引数なし**。100at/(b d_eff)を内部生成。pwは小数 | Dは`d`、有効せいは`d_eff`。M/(Qd)=clear_span/(2d_eff)。Es/Ecを使わない |
| core `rc_rebar_ratios` | b,D,d,at と `RcAlphaSection` から生成。T下はat/(BD)、T上は(at+slab)/(bD) | 100at/(bd)を別生成。T形でもせん断側はbと梁主筋atを保持 | 非有限・非正・d>D・B<b・不正スラブ筋をResult診断。T形は型で方向・B・上端スラブ面積を必須にする。I0/ITを乗じない |
| design `RcBeamBendingInput` → `rc_beam_bending` / `rc_beam_bending_checked` | `pt` は生成済みの小数を受け取る。せん断百分率を受け取らない | 用いない | at/d_eff/d_full、Es・Ec・aを直接指定。checkedは不正at・d・D・Es・Ec・a・ptをResult診断。未検査版のEc≤0→n15、D≤0→a/D3・d/D.9の既存フォールバックは入力診断の代用にしない |
| element `factory/springs::flexural_alpha_y` | 梁の上下 `bending_steel(D, false/true)` を各々比率生成。既存の共通骨格は主筋面積が少ない側を採用 | 用いない | dは段別面積重心、Dは断面全せい。a=剛域控除可撓長さ/2。Esは主筋材料young、Ecはコンクリートyoung。主筋未割当の低レベル既定Es205000、Ecなしの既定n15は解析入力チェックを回避する根拠にしない |
| element `factory/input_check` → `ensure_nonlinear_input` | 正負両引張側のat・dと幅・全せい・Es/Ecを確認。上下未入力・片側欠落も診断し、未入力として検査を省略しない | モデル入力診断をせん断生成前にも適用 | スラブ協力付き集中ばねはスラブ筋入力と正負骨格が無いため解析前に停止。矩形/既定αyへ代用しない |
| solver `pushover/shear_yield::real_rebar_capacity_input` | 用いない | 梁上下の候補ごとにat,dを生成しQsu最小側を採用。pw=検討方向Aw/(b pitch)、小数 | 梁は全せいD、矩形柱は検討方向b,D、円形柱は等価正方形。σyは材料強度割増、σwyは指定/既定材料強度。軸力項は呼出時に更新、比率単位に影響しない |
| core `rc_capacity_input_from_rect` | 用いない | 矩形柱X方向主筋の半量と上辺の有効せい、Aw_x/(b pitch)から幾何入力 | 全せいDは引数d。材料強度割増は呼出側。既存の総面積半量と最外辺面積の用途差を本件で変えない |
| app `holding::rank_new_rc_beam_side`、矩形/円形RC・SRCのランク経路 | 用いない | 梁は上端/下端別、矩形柱は強/弱方向別、円形は等価正方形からRcCapacityInputを生成。ptはcoreで内部生成、pwは小数 | 全せい/有効せいを分離。配筋・材料の入力診断を行う。既存ランク用百分率も100at/(bd_eff) |
| core `flexural_strength`、design `rc/beam`・`column`・`column_mechanism`・`joint_wiring`・`ultimate/rc_strength`・`rc_check`・`srrc` | 用いない | RcCapacityInputはMu/柱Muのため。pt/pwをαyへ流用する呼出しなし | `d`は全せい、`d_eff`は有効せい。曲げだけの仮b=1やpw=0を鉄筋比生成入力とみなさない |
| design `secondary/rc_capacity` | coreを再エクスポート | 同一契約 | 別の百分率変換や係数を実装しない |

`rc_qsu_simple_checked` はRcCapacityInputの幾何診断後に既存せん断式を実行し、不正幾何を耐力0へ置換しない。
従来のscalar `rc_qsu_simple` に残る非正入力の0返しは、診断済み入力を前提とする低レベル挙動であり、入力を妥当と判定したことにはならない。
本件では荒川係数・pw上限・σ0・M/Q範囲処理を変更していない。
