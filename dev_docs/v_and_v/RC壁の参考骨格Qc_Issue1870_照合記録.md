# RC壁の参考骨格のせん断ひび割れ点（#1870）

[#1876](https://github.com/hrntsm/SEPIKA/pull/1876)で採用した式の入力条件と、参考骨格での荷重・変形の表示を照合した。式と採用範囲を変更せず、適用外・入力不足時の診断を確認した。現在の計算根拠と制約は[製品文書](../../docs/nonlinear/05_RC_部材_非線形復元力特性.md#耐力骨格点単位)を参照。

## 原画像との照合

| 資料と位置 | 確認結果と限界 |
| --- | --- |
| 『2025年版 建築物の構造関係技術基準解説書』第2版第1刷、付録1-3.1(3)④b)、pp.712–713、式(付1.3-26)・(付1.3-27) | 採用式(27)は実壁厚と側柱中心間距離の積を用い、圧縮強度の上限は360 kgf/cm²。式に軸力項はない。式(26)が用いる鉛直荷重による壁板の圧縮応力度は、選択した荷重状態からQuに用いる壁全断面の平均圧縮応力度とは異なる。式(26)の形状係数には壁板の柱内法長さと側柱寸法が必要。式(27)の実験値／計算値は2資料で平均1.60、1.56、変動係数はいずれも0.46。下限に近い傾向であり、個別の下限保証や上限を超える強度への外挿の根拠にはならない。 |
| 日本建築学会『鉄筋コンクリート構造計算規準・同解説』第10版第1刷（2024年）、8条解説3(2)、pp.87–88、19条解説3(1)・(2)、pp.308–309 | 8条解説は層間水平変位のせん断・曲げ・基礎回転を分ける。19条解説図19.4は無開口壁の実験値と式(27)の応力度と同形の折線を示すが、折線を下回る点もある。Q1はひび割れ防止を意図し現行規準は全せいを使用する。Q2はひび割れ後の抵抗。どちらも参考骨格のQcを置き換える式ではない。 |

式(27)に荷重や側柱主筋量が現れないことは、無軸力を仮定することや、異なる壁形式へ適用を広げられることを意味しない。無開口・鉛直・同質コンクリート・対称な両側柱、明示配筋、壁脚の荷重状態、終局点・剛性比の成立は参考骨格全体の条件であり、すべてを式(27)の原研究から導いたものではない。有開口のQcに適用できる低減率や、対象壁に対する実験的妥当性は確認していない。

## 独立値と境界

| 条件 | 期待値・比較 |
| --- | --- |
| Fc24 N/mm²、壁厚200 mm、柱心間4200 mm、上下梁心間3000 mm | 旧単位で圧縮強度を24/0.0980665 kgf/cm²、面積を20×420 cm²として算定すると、上側強度区間の式が支配し、SI換算Qcは920218.95 N。独立に与えた純せん断初期剛性1000000 N/mmに対するひび割れ変位は0.92021895 mm、せん断角は0.00030673965 rad。共通検定とGUIの保持値、断面検定の表示920.2 kN・0.9202 mmおよび両横軸を照合する。 |
| Fc17 N/mm²、壁厚180 mm、柱心間4000 mm | 低強度側の式が支配し、0.85 N/mm²×720000 mm²からQcは612000 N。独立のケースで純せん断ひび割れ変位0.23442677013644364 mmと照合する。 |
| Fc360 kgf/cm²（35.30394 N/mm²）、壁厚200 mm、柱心間4200 mm | 12.9 kgf/cm²×20 cm×420 cm＝108360 kgf（1062648.594 N）。Qc単体は強度上限を含むが、参考骨格全体は剛性低下率の強度範囲外。上限の次に大きい浮動小数点値はQcも理由付きで未算定。 |
| 有開口・側柱なし・壁脚の軸応力度超過 | それぞれQc用開口低減率未確定、参考骨格に必要な両側柱なし、壁全断面の平均圧縮応力度が上限超過と区別する。有開口時はGUIに未検定理由を表示し、参考グラフを生成しない。 |

荷重・変形の照合は検定の参考骨格に限る。実解析の履歴則・終局時剛性低下率・終局耐力の変更や、実解析の応答差・実験Validationの確認を含まない。
