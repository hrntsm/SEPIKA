# RC柱の短期圧縮靱性推奨の確認（Issue #1392）

## 原典と確認範囲

| 出典 | 照合した内容 |
| --- | --- |
| 日本建築学会『鉄筋コンクリート構造計算規準・同解説』第10版（2024年）、14条3項 p.19 | 地震時に特に曲げが増大するおそれのある柱の短期圧縮軸力と全断面積を用い、平均値を設計基準強度の1/3以下に抑える推奨。上限は等号を含む。 |
| 同書14条解説3 pp.150–153 | 余力の少ない純ラーメンや耐震壁の多い建物は柱の靱性を期待する程度の例であり、自動判別式ではない。非適用には柱の靱性を期待する必要がないとの判断を要する。大きな靱性を実験で確認した場合には上限を引き上げ得るが、拘束補強の形だけで例外を適用できない。 |
| 『2025年版 建築物の構造関係技術基準解説書』第2版第1刷 pp.337、420、424、584 | 許容応力度の照合、材料許容値、崩壊形到達時の部材種別と、短期の全断面平均圧縮による靱性の確認を区別する。 |

2024年版の確認箇所は規準本文と解説の原画像で照合した。最初の照合、2010年版の限定的な調査、当時の低圧縮側警告の記録は [#1008 の調査記録](RC柱短期軸応力_Issue1008_調査記録.md)を参照する。低圧縮側警告は [#1876](https://github.com/hrntsm/SEPIKA/issues/1876) で削除され、今回も追加しない。[採用判断](../adr/0153-rc-column-ductility-advisory.md)・[製品の計算根拠](../../docs/calc_basis/06_一次設計/02_09_RC柱の構造規定.md#短期平均圧縮軸応力度)

## Verification

| 保証対象 | 独立期待値・確認経路 |
| --- | --- |
| 矩形・円形、標準値の上限方向 | Fc24で標準値は8 N/mm²。500角の面積は250,000 mm²なので、1,000／2,000／3,000 kNの圧縮は4／8／12 N/mm²。D600の面積は90,000π mm²なので、360π／720π／1,080π kNで同じ応力度。始端・中央・終端のうち12だけが標準値を超える。 |
| 浮動小数点境界 | 500角の2,000,000 Nの次の表現可能な値を閾値と区別しない。軸力を±0.0001 Nとしたときは下側を超過とせず、上側の超過を検出する。 |
| 結果の意味と範囲 | 明示の対象・非対象・例外と未指定を区別し、同じ断面力の許容応力度検定結果は一致する。長期は付記なし、短期はゼロ・引張・非有限と不足を区別する。材端フェースと節点芯が無次元座標で5×10⁻⁷しか離れていなくても、フェース内力の欠落を節点芯で補わない。片端ハンチは増寸範囲内の比較を保留し、内側の境界、中央、反対端では基準断面で比較する。中央を越える実寸のハンチは検定位置のクランプで短くならず、ハンチの範囲が不明な場合は比較を保留する。 |
| 通常GUIと保存 | 矩形400×600 mmで終端3,000 kNは12.5 N/mm²、別位置の始端が許容応力度検定比を支配し、中央は軸力非有限。検定画面の参考表示は終端の数値超過と一部の比較不可を伝える。現行の通常検定は再読込で一致し、旧検定版では保存内力を保持して再検定できる。 |

公開入口の試験は `crates/sepika-design-jp/tests/rc_column_ductility.rs`、通常検定・画面の描画テキスト・保存の試験は `crates/sepika-app/src/app/rc_column_ductility_tests.rs` に置く。保存試験で用いる異なる位置の内力は組合せの結果へ与えた既知値であり、実建物を解析した軸力分布の検証ではない。

## 確認していない範囲

個別建物での適用判断、例外の実験結果・個別上限の妥当性、全短期組合せの包絡・検定位置間の最大値、寸法変化区間の実断面積、実建物Validation、手動GUIと専門家サインオフは確認していない。終局、時刻歴の専用検定と2010年版の適用は今回の対象外。
