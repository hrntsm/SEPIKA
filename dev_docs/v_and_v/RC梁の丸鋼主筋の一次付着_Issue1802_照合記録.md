# RC梁の丸鋼主筋の一次付着（Issue #1802）

## 照合結果

「1999方式」で丸鋼の付着割裂を検定できる根拠は確認できなかった。2024年版RC規準が丸鋼について示すのは、端部フックを条件とする長期・短期の平均付着応力度の照査であり、付着割裂強度の式の準用ではない。現行の「1991方式」のせん断力による計算も、この丸鋼の照査には代用できない。

| 資料 | 確認事項 |
| --- | --- |
| 日本建築学会『鉄筋コンクリート構造計算規準・同解説』1999年版 | [国立国会図書館の書誌](https://ndlsearch.ndl.go.jp/books/R100000002-I000002914675)は確認できたが、デジタル資料の閲覧は館内限定で、この調査では本文を入手できなかった。丸鋼に対する強度式、横補強筋効果と上限、長期・短期・フック・定着の条項は直接照合できない。2024年版の6条解説(6) i)（p.65）は、1999年版の修正係数を乗じる許容値を異形鉄筋の付着強度に関する値として説明しているが、これは旧版本文の確認に代わらない。 |
| 同 2024年版、第10版第1刷、16条1項(2)・(3)（pp.24–26）、解説1(3) i) c)（pp.216–217） | 16条は異形鉄筋を対象とするが、やむを得ず丸鋼を用いる場合は端部フックを必須とし、長期に式(16.2)、短期に式(16.4)を準用する。フックは原則として標準フックとし、標準フックが確認できれば鉄筋の存在応力度を2/3倍にできる。丸鋼は表面状態によって付着抵抗がばらつくため、解説は許容耐力に十分な余裕を取るよう勧めている。 |

## 必要入力と現行の扱い

2024年版の平均付着応力度は、標準フックによる低減前の引張鉄筋の存在応力度を σt として、τa2 = (h σt) db / [4(ld − d)]。長期・短期それぞれの 0.8 fa と比較する。h は標準フックの確認により2/3としてよい。長さは mm、応力度は N/mm²とし、作用する荷重でせん断ひび割れが生じないと確認できた場合だけ、分母の ld − d を ld に置き換えられる。

| 準用に必要な条件・入力 | 現行の入力・判定 |
| --- | --- |
| 丸鋼の識別、径 db、有効せい d、Fc、長期・短期、上端筋の区分 | 材料・配筋情報、荷重区分および有効せいは使える。現行の上端筋は梁上側で引張となる鉄筋を指すので、下に300 mm以上打ち込むという表6.3の区分は別に確認する。 |
| やむを得ず丸鋼を使用する判断、端部フックの有無・標準詳細、通し筋の圧縮端側仕口での定着と、損傷制御時にも鉄筋の塑性化がほとんど進行していないこと（p.217） | 一次付着の入力・計算では確認しない。フックの不明・不備を応力低減なしの計算で代用して適合にはできない。 |
| スパン内で曲げモーメントが最大となる付着検定断面と、そこでの鉄筋の存在応力度 σt | 現行1999方式には解析位置の強軸曲げから応力度を略算する経路があるが、検定位置が規準所定の断面であることと、対象筋ごとの応力度を確認していない。 |
| 通し筋はスパン内法長さ、カットオフ筋は付着検定断面から鉄筋端までの ld（標準フックを設ける場合は折曲げ開始点まで） | 内法長さを別途供給できる設計経路でも、1999方式は節点間などの部材長と有効せいから比較長さを仮定する。通し筋とカットオフ筋を区別する入力や折曲げ開始点は一次付着に渡らない。1991方式は長さを使わない。 |
| 有効付着長さ ld − d が正、または当該荷重でせん断ひび割れなしを確認できる場合の ld | 現行はこの条件を検定しない。ひび割れが未確認なら ld − d を使う。長期の通し筋で両端応力の状態により照査が不要となる場合（p.217）も、荷重・配筋・応力の確認なしに省略しない。 |

## 独立計算と現行出力の比較

実部材の設計全体ではなく、丸鋼の一次付着成分を単独で比較する例。普通コンクリート Fc=24 N/mm²、幅400 mm・せい600 mm、かぶり40 mm、数値径10 mmの2脚あばら筋を100 mm間隔、上下各1段4本のSR235丸鋼（径20 mm）とする。節点間長さは1,500 mm、内法は1,000 mm、付着検定断面はスパン端の正曲げ最大断面とし、下端の通し筋が引張となる。比較元では標準フックと圧縮端の定着を確認できたと仮定し、長期も両端で曲げの符号が異なり照査が必要な場合とする。短期の損傷制御時にも鉄筋の塑性化がほとんど進行していないと仮定する。この例では短期の鉄筋応力度の略算値229 N/mm²はSR235の公称降伏点235 N/mm²未満だが、これは現行製品が塑性化の程度を確認したことを意味しない。長期・短期ともせん断ひび割れが生じないことは確認していない。いずれも独立照査の仮定であり、現行入力で確認できた条件ではない。

- d = 600 − (40 + 10 + 20/2) = 540 mm、j = 7d/8 = 472.5 mm、下端引張筋面積 = 400π mm²。有効付着長さは 1,000 − 540 = 460 mm。長期は M = 90 kN·m、短期は M = 136 kN·m とし、σt = M/(400π × 472.5) で略算する。
- 長期の上限は 0.8 × min(0.06 × 24, 1.35) = 1.080 N/mm²、短期はその1.5倍の1.620 N/mm²。標準フックの効果を採って τa2 = (2σt/3) × 20/(4 × 460) とする。1999方式との比較では同じ断面・曲げを与える。参考の1991方式には両荷重ともせん断力240 kNを与える（設計用せん断力への割増なし）。

| 荷重 | σt（N/mm²） | 2024年版準用 τa2（N/mm²） | 2024年版準用比 | 現行1999方式の付着比 | 現行1991方式の付着比 |
| --- | ---: | ---: | --- | --- | --- |
| 長期 | 151.576 | 1.09838 | 1.01702（NG） | 0.41279（OK） | 1.49705（NG） |
| 短期 | 229.048 | 1.65977 | 1.02455（NG） | 0.38556（OK） | 0.99803（OK） |

現行値は main の `727bb2f94` で、公開入口 `RcDesign::check` が返す `CheckKind::Bond` を一時テストで観測した。部材種別は大梁、スラブなし、あばら筋材はSD295A（降伏点295 N/mm²）、位置は `pos=0`。強軸曲げ・せん断以外の断面力は0、`DesignCtx.length=1500` mm、`seismic_qd=None`、`rc_damage_control=true`。各荷重で `Rc1999` と `Rc1991` を切り替え、他の入力を固定した。1999方式では長期・短期とも付着長さは1,020 mm、必要付着長さは長期421.0 mm、短期393.3 mmだった。表のOKは付着成分だけの比較であり、曲げ・せん断など部材全体の判定ではない。2024年版準用の結果との差は、材料表だけでなく、応力度と付着長さの取り方および補正係数が異なることによる。Fc=24 N/mm²でその他の鉄筋・長期・1段の現行1999方式の基準値は丸鋼1.20 N/mm²、異形鉄筋1.00 N/mm²だが、基準値だけでは2024年版との差や1999年版に対する過大評価を判定できない。

## 採用範囲と残作業

現行1999方式を丸鋼の付着割裂の適合判定として維持できる条件は確認できなかった。2024年版の荷重別準用式は上記の適用条件が確認できる場合に限り別途照査に使える。付着の計算根拠や適用条件を確認できない場合は理由付き未算定とし、独立して確定した曲げやせん断等のNGを失わない製品挙動が必要になる。両方式の結果の扱いは [#1956](https://github.com/hrntsm/SEPIKA/issues/1956) で是正する。準用式を実装する場合の入力と適用範囲は別途定める。本調査では[製品文書](../../docs/calc_basis/06_一次設計/02_07_RC梁の付着_定着検定.md#丸鋼を引張主筋に用いる場合)に利用上の制約を明記し、計算挙動は変更しない。終局の丸鋼付着は [#1730](https://github.com/hrntsm/SEPIKA/issues/1730)・[#1808](https://github.com/hrntsm/SEPIKA/pull/1808) の範囲であり、今回の比較に含めない。

## #1956の是正後の確認

通常の公開入口 `run_member_design_checks` では、上記の例と同じFc、矩形断面、主筋径・本数、部材長1,500 mm・内法長1,000 mm、および長期・短期の曲げ・せん断力を使った。あばら筋材はSD295AでなくSD345とし、部材中央や節点端ではなくi端の柱フェース（材軸位置比250/1,500）に内力を与えた。短期は損傷制御とし、入力の合算せん断力を使う。SR235・SR295のどちらでも、両方式・長期・短期とも付着比が出ず、理由が出ることを確認した。数値径20 mmを維持して主筋材をSD345に変更した場合は、付着比を数値で返した。

通常検定と時刻歴簡易検定の公開入口 `RcDesign::check_time_history` に同じ断面・材軸位置で小さい内力（1 kN·m・1 kN）を与えると、両方式で付着未算定の理由だけを返した。大きい内力（400 kN·m・600 kN）では、付着未算定の理由とともに、検定比が1を超えた曲げ・せん断の不適合が残った。時刻歴は確定ステップを想定し、短期は長期・水平合算値として断面力を直接渡した。

この回帰は一次の付着を保留する条件と判定の伝達を確認するもので、丸鋼の2024年版準用式の実装・承認、端部の定着詳細の確認、終局付着の検証は含まない。
