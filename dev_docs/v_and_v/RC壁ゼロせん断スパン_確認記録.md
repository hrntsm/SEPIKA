## 反曲点を壁脚フェイスへ置く独立釣合い

既存の `rc_wall_side_column_model.rs` の矩形1層壁を用いる。柱心間幅4000 mm、高さ \(h=3000\) mm、壁厚180 mm、側柱600 mm角、壁脚face \(f=300\) mm。下側2節点は水平・回転を拘束し、鉛直だけ自由として各節点へ \(k\) の鉛直支持ばねを置く。下梁は両端ピン、上側は鉛直・回転を拘束し水平を自由とする。solver試験は壁面外水平も拘束し、job試験は生成剛床の水平拘束診断を満たすため壁面外水平も自由とする。側柱そのものの元端条件は両端固定を維持する。

この試験は既存の壁置換モデルの弾性釣合いを検証するものであり、剛性モデルの妥当性を新たに承認するものではない。下辺の回転を \(\theta\)、半幅を \(a=2000\) mm、側柱面積を \(A_c=360000\) mm²とする。中央壁柱の曲げ剛性は、既存の縦筋換算を含めて独立に次となる。

\[
EI_w=\{23000+(205000-23000)\times0.002\}
\frac{180\times4000^3}{12}=2.242944\times10^{16}\ \mathrm{N\,mm^2}
\]

上辺の回転を0とし、曲率を高さ方向に積分すると中央壁柱の下辺曲げは \(Qh/2-EI_w\theta/h\)。両側柱の軸伸縮による偶力を加え、壁全体の下辺曲げ \(M_0\) と支持ばね偶力を釣り合わせる。

\[
M_0=\frac{Qh}{2}-C\theta=2ka^2\theta,\qquad
C=\frac{EI_w+2EA_ca^2}{h}=2.955648\times10^{13}\ \mathrm{N\,mm}
\]

フェイス曲げ0の条件 \(M_0-Qf=0\) から、支持ばね定数を決める。

\[
k=\frac{fC}{2a^2(h/2-f)}=923640\ \mathrm{N/mm}
\]

支持ばねと上側鉛直拘束が壁周辺の偶力を受けるため、水平参照力だけでも壁脚faceの曲げは0へ近づきうる。基部固定・自由上辺の片持ち壁だけの \(M=Q(h-f)\) を、任意の支持条件へ一般化できない。

恒久試験は独立値923640を用い、浮動小数点の微小残差を0へ丸めない。Windows/stable 1.100の一時観測では、同じsolver試験の支持ばねだけを923639.9999999986 N/mmとしたとき、生成Aiの正負でそれぞれ \(Q=\mp199999.9999999948\) N、\(M_{face}=0\) N·mm、\(N=0\) Nとなり、初期Qu参照が成功した。これはその入力・環境での厳密0到達の観測で、全プラットフォームで同じ浮動小数点値が出る保証ではない。この微調整値の探索や厳密0のassertは恒久試験に置かない。

jobの初回試行は上側の壁面外水平まで拘束したため、自動生成剛床の水平拘束診断で止まった。上側の両水平を自由とした入力で準備・実求解・増分を再実行した。生成済みモデルを直接solverへ渡す成功と、通常の準備を通る成功は区別する。

## ゼロでの側柱と軸力の選択

共通フェイス `StaticWallFace::new` は両側柱の正方形形状・配筋・材料が一致することを要求する。初期Quの水平参照は、壁全体の \(M\) の絶対値で比を取り、上辺伝達力の符号で正負の引張側柱・圧縮側柱を対応付ける。静的参考骨格は側柱寸法・主筋の各最大値を式に渡すが、共通フェイスが成立した対象では左右の値は同じである。\(M=0\) で水平力の符号から枝を割り当てられることと、断面内の引張・圧縮の分布を定められることは別の判断である。\(N=0\) の場合も壁全体の \(N,M\) の相殺から個々の側柱軸力が0とは言えない。\(N>0\) の場合も、全断面の圧縮正 \(N/A\) だけでは局所の応力伝達や端部圧壊の条件を特定できない。

断面・配筋選択が出力に現れる条件を、成分が既知の下位APIで検証した。既存の矩形壁フィクスチャから右柱だけ600 mm角・主筋径22 mmから800 mm角・主筋径25 mmへ変更した。主筋本数は各10本、柱心間4000 mm、壁厚180 mm、\(F_c=24\) N/mm²、横筋 \(P_{wh}=0.004,\ \sigma_{wh}=295\) N/mm²、縦筋 \(P_{wv}=0.002\)。壁板と柱の和集合から \(A=1594000\) mm²、\(D=4700\) mm、上限付き \(t_e=270\) mmとなる。左柱を引張側と入力した枝では \(a_t=3801.3271\) mm²、\(d=4300\) mm、右柱を引張側と入力した枝では \(a_t=4908.7385\) mm²、\(d=4400\) mm。主筋面積には入力径の円面積を使った。

異なる有効せいに対する \(t_ej\) は順に1015875、1039500 mm²となる。軸応力度1 N/mm²を加えると、他の成分を固定した増分はそれぞれ101.5875、103.9500 kNとなる。独立の十進計算で求めた次の値に対し、`WallElement::directional_shear_capacity_at_reference` のQuの一致を確認した。

| 入力圧縮軸力 | 左柱を引張側とする枝（min / mean、kN） | 右柱を引張側とする枝（min / mean、kN） |
| --- | ---: | ---: |
| 0 N | 2327.654 / 2886.491 | 2469.639 / 3072.908 |
| 1594000 N（\(\sigma_0=1\) N/mm²） | 2429.241 / 2988.078 | 2573.589 / 3176.858 |

両方式とも各枝の比0と1は同値で、負の圧縮軸力 −1594000 N は拒否された。同じ非対称壁は製品2経路が共有するフェイスの解決で拒否された。したがって、算定された枝の差約6%は下位APIにおける \(a_t,d\) の選択の感度である。非対称壁の製品受理、壁脚での \(M=0\) の実求解、どちらの枝を採るべきか、破壊耐力の大小はこの例から確定しない。

初期Quは長期参照Gの軸力を使い、静的参考骨格は選択したケース・組合せの全軸力を使う。たとえば、長期参照の正の軸力に対して選択組合せの合成軸力が引張なら、比が両方0でも、初期Quの軸力条件は満たせる一方、参考骨格は軸力条件で未算定となる。これは入口の判定条件からの帰結で、この組合せを実求解した観測ではない。

## 採用判断と残る確認

本調査の結果、現行の算定・診断を維持し、設計採用判断を保留する。次の条件を確認するまで[#1288](https://github.com/hrntsm/SEPIKA/issues/1288)は未完了とする。

- 壁脚に反曲点があるI形無開口壁について、壁全体の危険断面を選ぶ根拠、せん断力と曲げの分布、上下端反力・端部拘束の条件。危険断面の比が下限1より小さい範囲で、比0を含めた採用を評価できるか。
- 反曲点断面で \(a_t,D_c\) を選ぶ根拠。左右対称で算術上同値となる範囲でも、側柱・壁板への応力伝達と圧縮領域の拘束を確認する。
- 同じ評価断面・載荷境界で、軸力の符号・大きさ、縦横筋と柱主筋・帯筋、柱幅とせい・壁厚・高さに対応する破壊形式と実測耐力。特に、無軸力および圧縮域で、反曲点が壁脚にある入力に対する実験Validationと両計算経路の設計利用条件が残る。

開口壁、線形換算剛性、Qc、別骨格、軸力上限、側柱なしの適用は本件で再判定しない。GUI手入力と全プラットフォームでの厳密0到達は先行調査に引き続き未確認。
