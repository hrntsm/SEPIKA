# 曲げせん断型の層曲げ剛性と分割柱（#1645）

[Issue #1645](https://github.com/hrntsm/SEPIKA/issues/1645) の再現条件について、公開生成入口 `sepika_job::build_lumped_mass` で合成応答を照合した。修正前の基点は `4fb30f3a566bdb3982eca35a89f8412a2527e126`（[#1640](https://github.com/hrntsm/SEPIKA/issues/1640) 適用済み）。

## 入力と独立算術

SL 間の高さが各 3000 mm の 2 層骨組とし、X 座標 ±1000 mm、Y 座標 ±2000 mm の四隅に通常柱を置いた。柱脚は固定とし、第1層の X 方向加力を模した柱軸力を左右それぞれ引張 1500 N、圧縮 1500 N、柱上端の鉛直変位をそれぞれ +0.15 mm、−0.15 mm、柱脚の鉛直変位を 0 mm とした。左側の柱1本の分割節点を表の位置に変え、他の柱の分割節点は各層の中央に置いた。

4本を一度ずつ数えると、平均 X 座標は 0 mm、上下端の平均曲げモーメントは 6.0×10⁶ N·mm、柱軸仕事は 900 N·mm となる。層曲げ剛性は 3000 × (6.0×10⁶)² / 900 = 1.2×10¹⁴ N·mm² となる。

上階付近の分割で左柱を二重に数える場合、平均 X 座標は −200 mm となる。引張側3件の腕長は 800 mm、圧縮側2件は 1200 mm となるため、曲げモーメントは 7.2×10⁶ N·mm、柱軸仕事は 1125 N·mm となる。曲げ剛性は 3000 × (7.2×10⁶)² / 1125 = 1.3824×10¹⁴ N·mm² で、4本を数えた場合より 15.2% 大きい。

| ---: | ---: | ---: | --- |
| 1500 | 0.075 | 1.200000000000×10¹⁴ | 1.2×10¹⁴ と一致 |
| 2999.5 | 0.15 | 1.382400000000×10¹⁴ | 層 1F・上階 SL・柱材 ID 1 を示して生成を停止 |
| 0.5 | 0 | 1.200000000000×10¹⁴ | 層 1F・下階 SL・柱材 ID 0 を示して生成を停止 |

修正前の下階付近の分割では、柱脚の代わりに分割節点を下端として短い柱材を評価区間から外しても、両節点へ同じ鉛直変位を与えたこの入力では EI_y が同値になった。修正後は分割節点を Z=2998 mm、2 mm にした場合も、評価区間が一意に定まり EI_y = 1.2×10¹⁴ N·mm² と一致する。

## 既存の解析との関係

3次元の曲げせん断型は、修正前も上階・下階ともに剛心を求める処理で区間の曖昧さを診断し、生成を停止した。修正後は共通の曲げ剛性算定で先に診断し、対象層名 1F を併記する。区間を定められる柱は、[#834](https://github.com/hrntsm/SEPIKA/issues/834) の軸伸縮による層曲げ剛性と [#1087](https://github.com/hrntsm/SEPIKA/issues/1087) の曲げ変形を除いたせん断骨格の算定へ引き継ぐ。SL 候補の判定と区間の曖昧さの扱いは、[SEPIKA の曲げせん断型の適用条件](../../docs/calc_basis/05_構造解析/09_質点系解析.md#柱軸伸縮から曲げ剛性を求める)に記載する。

修正後の統合テストは `cargo test --locked -p sepika-job --test bending_shear_column_intervals` で実行できる。確認範囲は合成応答による生成入口・剛性・診断であり、SL 近接分割を持つ実ソルバー応答、GUI 操作、保存成果、周期および時刻歴応答への影響、一般架構での影響の方向は未確認である。
