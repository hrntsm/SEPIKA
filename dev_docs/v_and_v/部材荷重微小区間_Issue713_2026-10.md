# 部材荷重の微小区間（Issue #713）

## 対象と根拠

対象は [Issue #713](https://github.com/hrntsm/SEPIKA/issues/713)。整理親は [#524](https://github.com/hrntsm/SEPIKA/issues/524)、調査基準は main `e059628edbc6f2c420bd8774df11a314ec95db19`。2026-10-21 に両 Issue の本文全体を GitHub connector で取得した。参照解は線形分布を矩形と三角形へ分けた面積・図心と、切断片の力・モーメントの釣合いによる独立計算である。実装の積分手順を期待値側へ複写しない。

製品の式・制約は[部材荷重](../../docs/calc_basis/04_要素剛性/03_部材荷重.md)を正とする。本記録は人工入力による限定 Verification であり、実構造の発生頻度・影響や実験 Validation を示さない。

## 利用経路と処理の役割

`crates/sepika-solver/src/common/linear_load.rs`・`common/assemble.rs`・`statics/linear/mod.rs` と、`crates/sepika-element/src/frame/member_load.rs` を照合した。

線形の `factory::build_behavior_with_axial_factor` は Beam / Fiber / MultiSpring をいずれも弾性 `BeamElement` として構築する。入力の種別名だけで実行要素を判定しない。非線形 Fiber の `owns_frame_member_loads` は `wall_connection` がある場合だけ真で、他の非線形 Fiber は `nonlinear/pushover/loads.rs` から `legacy_member_force` を用いる。これらを荷重所有応答へ一律に移行済みとは扱わない。

| 経路 | 必要な役割と本件の対象 |
| --- | --- |
| ブレースの `legacy_member_force` / `assemble_global_f` → `consistent_load_local(StaticallyEquivalent)` → `add_bending_static` | 材軸直交荷重を、材端モーメントなしで合力・一次モーメントを保つ両端並進力へ配分する。残っていた `integ2` の実利用経路 |
| ブレースの断面回復 → `superpose_member_loads` → `fixed_internal_local` → `comp_resultant` / `comp_moment` | 固定端内力の重畳。ブレースへ返すのは軸力だけであり、曲げ・せん断を新たに負担させない |
| `LoadedFrameSection::applied_force_above_elevation` → `comp_resultant` | #496 の荷重込み応答でも、水平切断面の上側へ作用する実荷重合力の集計には同じ問題の積分が残る |
| Beam / Fiber / MultiSpring の可撓部荷重写像 | 軸・曲げの整合節点荷重は既存の `gauss_dist` を用いる。Hermite 形状関数による曲げの整合節点荷重とブレースの静定分配は役割が違うため維持する |
| `LoadedFrameSection::at` | 荷重込み断面の Q・M の回復。端部近傍の微小区間では `gauss_dist` の腕長座標の丸めが独立モーメント期待値との差として現れたため、荷重合力・モーメントを同じ解析積分へ接続する |
| `FrameDeadLoadMap` → `add_rigid_load` | 剛域内の荷重を、その合力と節点まわり一次モーメントへ移す。同じ腕長座標の丸めが残るため、分布荷重を解析積分へ接続する |

`integ2` を廃止し、合力・一次モーメントの積分を `comp_resultant` / `comp_moment` にまとめた。これらは切断区間両端の線形補間強度から解析的に積分する。微小幅の強度固定を除き、端部近傍で積分点の座標が丸まることによる強度の変化も避ける。荷重補間方式・塑性機能は追加しない。
静定分配の両端反力は、それぞれの端からの腕長によるモーメントから直接求める。合力から他端反力を差し引くと、端部近傍の小反力で有効桁が失われるためである。
`comp_moment` は参照位置に近い切断端へ合力のモーメントを移す形で同じ解析式を評価する。切断端からの一次モーメントの項は幅を段階的に乗じ、幅の二乗を先に作ることによるアンダーフローを避ける。相殺合力ゼロの回帰でも許容差を変更しない。

| 長さ 1 mm のブレース、両端の材軸直交方向に各 1 N/mm の支持ばね、他自由度は拘束。元人工例と強度入替・負・符号相殺の4条件 | `short_brace_distribution_public_static_paths_preserve_force_and_first_moment` で `linear_static_once` と `Analysis::linear_static` の両公開経路を対象とする。ばね反力相当の変位から合力・一次モーメントを照合し、ブレース断面力は全成分ゼロを要求 |

上記の非ゼロ期待値の許容差は期待値絶対値の `2e-14` 倍。ゼロ期待値には厳密一致を用いる。端部近傍の位置には二進数で表現できる幅を用い、丸め済みの異なる区間を同じ入力と扱わない。
solver の合力許容差は絶対値 `1e-10 N`、一次モーメントの比の許容差は `2e-14`、断面力は厳密ゼロである。
