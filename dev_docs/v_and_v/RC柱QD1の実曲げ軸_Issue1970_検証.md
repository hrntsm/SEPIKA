# RC柱QD1の実曲げ軸と候補除外の検証（#1970）

## 原典と期待値

日本建築学会『鉄筋コンクリート構造計算規準・同解説』2024年版、第15条(15.8)式（本文p.22）、解説図15.9、部材端の算定位置と二軸せん断の説明（解説pp.179–181）を照合した。両端柱降伏と同一構面の片端梁降伏を区別した。強軸の投影係数だけで立体架構の降伏や曲げ・ねじりの相関を表せない。[是正前の軸変換と計算結果](RC柱QD1の大梁曲げ軸_Issue1907_照合記録.md)・[採用判断](../adr/0165-rc-column-qd1-girder-bending-axis.md)

対照は400×600 mmのRC柱、内法1,500 mm、Fc24、SD345、両端圧縮100 kN、参照せん断0とした。柱端の強軸Myは3本配筋で170.336243 kN·m、4本で217.288602 kN·m。一般階の対向する柱頭梁の和は190.333125 kN·m。主な対照では、是正前の照合で4本だった柱脚梁を幅400 mm・主筋5本とし、両端柱降伏と柱頭候補を独立に比較できるよう柱脚の梁和で置換できない条件とした。標準の候補は、4本配筋の従来柱頭を例にとると (217.288602 + 190.333125/2)/1.5 = 208.303443 kN。軸不一致で別端の候補がないときは両端の柱Myを使うため 2×217.288602/1.5 = 289.718136 kN。公開検定ではこれらを独立した強軸許容せん断力270.029514 kNで除した検定比と照合する。[独立断面計算](RC柱QD1の崩壊メカニズム_Issue1817_検証.md#独立計算)・[テスト](../../crates/sepika-design-jp/tests/rc_column_mechanism.rs)

## 照合結果

| 対照 | 4本配筋の一般階・従来柱頭のQD1（kN） | 3本配筋の一般階・係数後のQD1（kN） |
| --- | ---: | ---: |
| 水平X・標準断面 | 208.303443 | 177.001870 |
| 断面90°回転 | 289.718136 | 227.114991 |
| 退化参照方向から代替した解析基底で断面の強軸が不一致 | 289.718136 | 227.114991 |
| 平面斜交（X:Y = 4:3） | 289.718136 | 227.114991 |
| 同一構面内の傾斜 | 208.303443 | 177.001870 |
| 芯は水平X、遠端偏心で実材軸が斜交 | 289.718136 | 227.114991 |

X:Y = 3:4の梁は、以前の方位割当ではY側だけに属したが、X側の残りの梁だけで需要を低減しない。強・弱軸の両端柱降伏の対照は227.114991、151.409994 kNとなる。同一構面内の傾斜は強軸QD1を変えないが、弱軸側では斜め梁の材軸と柱の曲げ軸が平行でなく、弱軸側で両端柱降伏が支配する。通常の直交架構、およびその構面全体を全体座標軸から回転した例も対照とした。傾斜柱は実曲げ軸が梁の強軸曲げに対応する場合を確認した。

最上階柱頭の梁を回転すると、標準の (170.336243 + 95.166562)/1.5 = 177.001870 kN から両端柱降伏の227.114991 kNへ移る。上階柱が柱頭の節点に続かず柱脚を置換できる場合は、標準の (170.336243 + 95.166562/2)/1.5 = 145.279683 kN から同じ両端柱降伏へ移る。一般階の独立した柱脚候補、最上階の独立した柱頭候補は、反対端の軸不一致だけでは失わない。元の対照で柱端Myが217.288602 kN·mで柱脚梁の主筋が4本の場合は、断面を回転した場合は独立した柱脚梁和の1/2が190.333125 kN·mとなり、271.747818 kNを採用する。同じ入力で断面は標準向きのまま、節点間の向きは変更せず遠端偏心で梁の実材軸を斜交させると、軸不一致に加えて接合条件も満たさず、両端柱降伏の289.718136 kNとなる。

通常検定は公開APIで、時刻歴簡易検定は共通入口に加えてGUIの検定表示で照合する。接続梁の回転と柱端軸力欠落を重ねた対照で、当該方向を未算定とし、独立した軸力・曲げの不適合を保持する。重力参照の一覧が空又は検定柱を含まない場合も、軸不一致の方向に応答せん断力を代用せず、他方向を保持する。また節点間長が正でも、内法が未算定、ゼロまたは非有限となる入力では未算定とする。QD2単独では回転の前後で結果を変えない。保存検定は解析契約114を維持したまま、検定契約125を失効させる。[時刻歴簡易検定](../../crates/sepika-app/src/viewer/th_detail.rs)・[保存の再検定](../../crates/sepika-app/src/app/result_contract_tests.rs)

照合したのは式の候補選択と検定結果の伝達まで。両端柱降伏は立体架構で実際に伝達する曲げの上限ではない。立体の降伏相関、地震応答全履歴、実験による妥当性、立体の適否は未検証。
梁上下の非対称配筋による曲げの包絡は [#1980](https://github.com/hrntsm/SEPIKA/issues/1980)、軸除外を行わない短期QD1の内法の確認は [#1982](https://github.com/hrntsm/SEPIKA/issues/1982) で別に追跡する。
