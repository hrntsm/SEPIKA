## 既存の通常計算の照合準備

`crates/sepika-design-jp/src/secondary/holding_capacity.rs` の `fs`・`fe`・`fes` と製品文書の式を読み、下記の数値・境界が一致することを確認した。
折線の形状と代表点は上記の建築研究所図5とも一致するが、告示原文への適合確認ではない。

| 対象 | 確認した境界と数値 |
| --- | --- |
| Fs | Rs≧0.6で1、0≦Rs＜0.6で2−Rs/0.6。Rs=0.6で1、0.3で1.5、0.15で1.75。1.5上限なし |
| Fe | Re≦0.15で1、0.15＜Re＜0.30で直線補間、Re≧0.30で1.5。Re=0.15で1、0.225で1.25、0.30で1.5 |
| Fes | FsとFeの積。Rs=0.15、Re=0.225で2.1875 |

通常計算が使う非負・有限入力と、建築物の法規上の適用条件は区別する。
Rs/Reの値だけから、ただし書適用の必要性・許可・適否を判断しない。
ただし書の文言及び個別評価に要求される条件の公的公布原文としての確認は未完了とする。
技術資料上の確認範囲は下記の追補と区別する。
計算変更を必要とする原典との差異は、現時点で確定していない。
