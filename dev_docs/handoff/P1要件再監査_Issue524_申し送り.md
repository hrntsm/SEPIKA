## RCの単位と骨格

#435はαy用pt=at/(bD)の小数と、せん断用百分率を区別し、分母の違いも対象にした。
#523の現在の採用式は次のとおり。

```text
基本式（a/D≤2.0）: αy=(0.043+1.64 n pt+0.043 a/D)(d/D)²
a/D>2.0: αy=(−0.0336−0.1935 n pt+0.1270 a/D)(d/D)²
pt=at/(bD), n=Es/Ec
```

2026-10-18に[rc_alpha_y_sugano / rc_alpha_y_sugano_checked](../../crates/sepika-core/src/rc_capacity.rs)で係数・分岐と既存の境界値試験を静的確認した。
n=10、pt=.01、d/D=.9ならa/D=2の基本式は.23733、第2式の右極限は.1628505となる。
この不連続を数値上隠すために分岐を逆転しない。
入力診断は正の有限比率とd/D≤1を要求し、式の非正値を自動補正しない。
コードの確認・式の独立評価は、原研究の適用条件の照合や試験の実行を意味しない。
現行の採用条件は[RC非線形復元力特性](../../docs/nonlinear/05_RC_部材_非線形復元力特性.md)を正とする。
原典での入力範囲・不連続・非正値の扱い、T形梁の引張側別の協力幅・スラブ筋・I0/IT補正は別の確認対象。

#434は解析剛性のEs/Ecと許容曲げ用n=15/13/11/9を区別する要求。
監査時点のSRCは標準Es=205000N/mm²と入力Ecから比を作り、カスタム鋼材youngを参照する実装ではなかった。
#436はM/(GA)のmmを回転角へ加える問題と、抜出しモデルの腕長・適用条件の原典確認を分けた。

## 壁の応答・断面・Ds

#443の監査時点には四節点分岐とwall_shear_signedがあり、全て二節点として処理するという前提を撤回した。
節点並べ替え、符号、切断面、未提供の回転等の出力を残る対象とした。

#441の是正要件は `τu=1.2Q/ΣA`、ΣAは付帯柱・袖壁を含む全断面積。
剛性As・終局耐力te・ランク用ΣAを分離し、Qu用開口低減をτuの分母へ流用しない。
2026-10-18時点の[rc_wall_tau_over_fc](../../crates/sepika-design-jp/src/secondary/ds_group.rs)は絶対値Qを壁厚×側柱心間距離×Fcで除しており、この是正要件の採用完了とは扱わない。
共有側柱の断面積配分は原典で確認する。軸力配分をそのまま断面積配分の根拠にしない。

#442は層別ピークstory_quと最終member_responseの混在を対象とし、同じ確定ステップの層切断面でβuを集計する要求。
#489はD部材の既定処理、耐力加重のA/B/C群判定、RC/S/SRCの別表、保有耐力接合条件を対象とする。
D部材の群判定からの除外を全体Quの無条件除外へ拡張しない。
非せん断破壊条件Qu≥1.25Qという是正要件と、コードのQ≥0.99Quによる脆性判定は別に記録し、原典の適用条件を照合する。
Qu=1000kNでは前者の境界がQ=800kNとなるという算術確認は、WD判定の規準適合性の証明ではない。

#440はSRCの両側柱・上梁の構成条件と壁板・側柱・内蔵鋼材の別項を要求し、CFT/S側柱の適用は別原典調査とした。
#496はBeam/FiberMultiSpring表現を跨ぐRC/SRC側柱の物理的役割を維持し、純鋼板の一律解放は #518 で別検討とした。

## 荷重・数量・再生成

#437/#438は最大100mmの比較格子、凹形の支持候補、台形の比較精度を分け、独立積分と誤差評価を要求した。
約2%の既存差や100mmという設定だけで許容精度・安全側を保証しない。
#444はDL支持先、階高中央での地震用重量、小梁上の壁のDL全量下側伝達を区別する要求。
#450は単純倍率と精算の選択を保持し、精算だけに左右異厚の断面幾何を適用する要求で、合成倍率はφ1+φ2−1。
#451の型枠控除は剛性式ではなく実接触領域の独立幾何で確認する。

#445の自立壁には支持床直上層への帰属処理があったため、再実装より検証を先行し、指定基準柱と層平均剛性の差を別に扱った。
#506の割当領域の境界キー照合も既存で、名前の重心/面積推定と区別した。
残る同一性・分割/統合・衝突・undo/redoを検証対象とする。
#501/#504/#505は高密度鋼の設計荷重過小評価、dbの0.9D、根拠が未確定の段差150mmを対象とし、不足/対象外を合格として継続しない契約を要求した。
