## 代表4画面と移動

下図の`[固定]`は継続参照パネルのピン、`[拡大]`は表を主領域の単独表示へ移す操作を表す。上部の工程入口、コマンド検索、左右の入口アイコン、下部の状態入口は残し、閉じたパネルは同じ入口または検索で再表示する。工程の前後関係で移動を禁止しない。

### モデルを作成・確認

```text
┌ プロジェクト / 本案 / 編集世代    工程入口   コマンド検索 ┐
│探す[固定] │ 2F伏図 [視点/階/通り] │ 選択属性[固定]       │
│モデル/条件│ 部材を選択             │ 名称/断面/影響部材数 │
│結果/検討  │ 短時間の割当設定のみ重畳│ 根拠を開く           │
│           │ [図/表/グラフ/二分割]  │ 検討を作成           │
├ ログ/診断/依頼状況（開閉）   未保存 / 結果有効性          ┤
└─────────────────────────────────────────────────────────┘
```

図・ナビゲータ・表の選択連動を維持する。階/通りの変更で選択を捨てず、見えない対象は「選択3件、表示中1件」と示す。依頼作成前に隠れた選択を一覧で確認できる。配置/割当の重畳設定は完了/取消で閉じ、背後へのクリック・スクロールを消費する。

### 条件・数値を編集

```text
┌ プロジェクト / 本案 / 編集世代    工程入口   コマンド検索 ┐
│条件[固定] │ 部材/断面/荷重の入力表 [単独・拡大] │属性/根拠│
│対象を探す │ ID/名称/階/断面/単位付き数値       │[固定]   │
│検討へ戻る │ [共有断面編集] [選択部材へ割当]     │影響一覧 │
├ ログ/診断/依頼状況（開閉）   編集確定/エラー/Undo          ┤
└─────────────────────────────────────────────────────────┘
```

入力確定・不正値・Undoは既存編集経路へ渡す。編集中にパネル位置を自動変更しない。「共有断面編集」は参照する全部材へ波及し、「選択部材へ割当」は列挙した部材だけが既存断面を参照する変更で、元断面を改変しない。既存の「複製してこの部材だけ別断面に」は存続するが、初回AI検討では使わない。

### 結果を検証

```text
┌ プロジェクト / 案名・版    工程入口   コマンド検索         ┐
│結果を探す │ 左:変位図                     │条件/根拠[固定]│
│run/状態   │ 案・run・荷重状態・階/通り      │開始入力/単位 │
│検討一覧   │ 右:結果表/グラフ [単独へ]      │算定/未算定理由│
│           │ 同じ対象行 → 図を強調          │入力へたどる   │
├ 依頼/計算進行・診断・ログ   最新/要再計算/未対応           ┤
└─────────────────────────────────────────────────────────┘
```

数値行から部材・評価位置/方向・荷重状態・算定式の根拠・入力へたどる。AIの説明は「AI説明」と表示し、SEPIKAの結果値の欄と混ぜない。古い結果は生成当時の案の図へだけ結び付ける。現在案へ重ねる場合は「過去結果」と明示し、最新の比較・採用判断値に使わない。

### 案を比較・採用

```text
┌ プロジェクト / 検討ID / 目的     工程入口  コマンド検索     ┐
│検討[固定] │ 基準案:図/表    | 比較案A/B:図/表 │根拠[固定]│
│目的/対象  │ 固定対象の強調  | 断面・数量・変位 │条件/未確認│
│案/採否    │ 条件一致/差分  | 検定比と状態     │採用理由   │
│           │ [変更一覧] [却下] [採用確認へ]     │依頼文     │
├ 依頼状況（コピー済/受理/計算中/成功/失敗/切断）            ┤
└─────────────────────────────────────────────────────────┘
```

「検討を作成」→目的と固定対象・固定条件を確認→基準案固定→比較案作成→既存断面割当→準備→静的→検定/数量→比較→採用確認（全差分・影響範囲・未確認事項・理由）→人が採用、または理由付き却下。各段階から図・入力・結果・検討へ往復できる。AIなしでも同じ操作をボタン/検索から実行できる。依頼文と検討IDのコピーは「コピー済」であり受理/実行中ではない。接続先選択とGUI許可を経て要求を受理して初めて進行を表示する。

## レイアウトの共通契約

主領域は単独または左右二分割とし、自由多窓配置を導入しない。表/グラフも図と同じ大きさの主領域を占有できる。各ビューの見出しに内容名と識別、単独/二分割/左右入替を置く。狭い画面は基準/比較を切替表示し、選択・スクロール・視点を保持する。ログ等を閉じても下部に件数/進行/直近エラーと入口を残す。エラー詳細への到達・既存のログ自動表示を失わない。

工程を初めて開いた時は既存プリセットを初期候補とし、以後は工程ごとのユーザー配置/固定状態を復元する。AIの進行・結果到着・工程往復で主領域種別、カメラ、選択、入力フォーカスを切り替えない。明示した「対象へ移動」の時だけフレーミングする。各パネルの入口名・選択した操作は日本語検索からも到達できる。キーボードでビュー切替、表編集、パネル開閉、採用確認/取消へ移動でき、フォーカスを見える形にする。数値は桁揃え・単位・日本語ラベルを保持し、状態は文字と記号を併記する。色だけで採否・警告を表さない。

## 参照、画面選択、依頼の固定対象

| 識別 | 契約/表示位置 |
| --- | --- |
| プロジェクト | 永続プロジェクトID。上部に名称、詳細からID。同じファイルの再読込は維持、新規/別プロジェクトとして複製は新ID |
| GUIインスタンス | 起動/読込セッションID。接続案内と詳細に表示。再起動/別GUIを区別し権限は引継がない |
| 本案 | プロジェクトID + 単調増加の編集世代。Undoでも世代を再使用しない。上部に本案/世代/未保存 |
| 検討/案 | 永続検討ID・基準案ID・比較案ID + 案編集版。検討見出し/案見出しに表示。名前は変更可能、参照に使わない |
| 対象 | 所属プロジェクト・基準/案ID・対象種別・保存ID。表の識別列/属性/固定対象一覧に名称と共に表示 |
| 階/通り | 保存IDとラベル、ビュー見出しに表示。節点Zや名称だけで推定しない |
| 荷重状態 | 単独ケース/保存組合せ/自動合成の区別・ID/実効構成・継続時間。結果見出しと根拠に表示 |
| 結果 | 案ID/入力識別・run ID・計算契約版・種別・荷重状態・対象・評価位置/方向/成分。結果見出し/行詳細から全項目へ到達 |

内部ID番号だけを外部参照として渡さない。既存の削除/再配置によるID remapを通す場合も、古い外部参照は別対象へ読み替えず拒否する。#974で対象の存続を識別する世代/不変トークンを持ち、削除後に同じ番号を持つ新対象は別物とする。表示名が重複しても列挙で選べる。基準から比較へは複製時の対象対応を保持し、欠落/曖昧時に名前で救済しない。

画面の選択は既存の双方向連動を使う一時状態で、依頼の固定対象は作成確認時の明示ID列・基準世代の保存値とする。依頼後に選択が変わっても対象は変えない。依頼中は「画面選択」と「検討の固定対象」を別の文字ラベル/強調で示し、固定一覧から再選択できる。固定対象の追加/除去は既存依頼を書換えず、新しい検討を作る。

二分割ではプロジェクト・検討・固定対象と画面選択を共通にする。比較ビューの左右には別々の案ID/結果IDを持つ。カメラ、階/通りフィルタ、表示種別、変形倍率、カラースケール、表の並び/スクロールは各ビューに保持し、明示した「表示を同期」でコピーする。同期はモデル変更ではない。荷重状態・評価成分/位置・単位の一致は比較値の条件として照合し、左右の表示が異なる時は差分欄を「比較不可: 条件相違」とする。表示が隠れた対象も固定対象から除外しない。

## 保存、計算、採否の境界

検討はOVIKA内のプロジェクト所有の保存対象とする（スキーマ互換方針は[ADR 0014](../adr/0014-schema-compatibility.md)）。目的、作成時刻、固定対象と対応表、基準の本案世代、基準/比較のモデル全体・入力/解析/検定/数量設定、案の版、差分、実行要求/ジョブと状態、開始入力・実効条件・契約版付きの結果、未確認事項、採否・理由・採用時本案世代を保存する。外部AIの会話や接続権、APIキーを保存の前提としない。ビュー配置はUI状態として保存してよいが、計算入力識別に混ぜない。

既存ResultsBundleと保存成果の生成入力/契約照合を再利用し、検討の各案から生成時の結果を参照する。結果IDは一意で不変とし、別案/後続runへ付替えない。基準作成時の本案結果は生成入力・設定・契約が完全に一致するものだけ、元の生成元を保持して基準へ参照できる。別案への自動流用はしない。保存は結果データもOVIKAの既存保存機構へ含め、プロセス中の一時パス・MCPサマリだけに依存しない。保存失敗では従前ファイルを有効として未保存表示を残し、部分保存を成功と表示しない。

| 状況 | 操作と表示 |
| --- | --- |
| 本案編集中 | 比較案は固定基準から独立して編集できる。本案の編集確定で世代相違を表示。採用確認は入力確定/取消後に行う |
| 比較計算中 | 開始時の案版/入力を固定。同じ案の編集を拒否し、別案/本案/閲覧は可。結果を現在の選択へ付替えない |
| 基準が古い | 本案編集/Undoを含め世代相違なら採用拒否。旧検討を保持し、現在本案から新検討を作り固定対象を再確認。旧比較の変更候補は確認して割当し直し、再計算 |
| 案の断面割当を変更 | 準備/静的/検定/数量の依存結果を要再計算。支点・入力荷重・設定は不変でも自重等の自動算定値は再生成 |
| 選択/視点/フィルタ/工程/表並替 | 計算入力を変更せず結果を失効させない。解析非依存編集の既存判定を維持 |
| 結果を表示 | 成功/有効を生成入力/実効条件/契約版で照合。「未計算」「要再計算」「失敗」「未検定」「未対応」「契約不一致」を0/合格で埋めない |
| 未対応の結果 | 理由と対象を残して比較値を空欄（理由付き）にする。既存MCPサマリでGUI詳細結果を得たことにしない |
| 結果条件が片側だけ異なる | 数値差・優劣を出さず条件差と比較不可理由を表示。同じ入力荷重構成/継続時間/評価位置・方向で再実行する |
| 採用確認 | 変更一覧・対象・影響範囲・計算状態/未確認事項・理由を表示。未計算/失敗/未検定を含む場合は確認記録を明示して人が判断。採用を安全性保証や検定OKと表示しない |
| 採用/却下 | GUIの人だけが実施し理由を保存。却下は本案無変更。採用は固定対象への割当を一つのUndo単位で適用し、本案要再計算。後から検討を見ても採用時の判断を改変しない |
| 採用のUndo | 直後なら一度で割当を復元。検討の採用履歴は削除せず「採用をUndo」と追記。本案の結果有効性は既存入力照合に従う |
| 保存/再読込 | AIなしで目的・基準/案・差分・結果と採否を閲覧可。ジョブ/許可を復活させず、未完了は中断。契約不一致結果は理由を残して利用不可 |

権限拒否・競合・接続切断時の操作は[ADRの境界](../adr/0087-gui-owned-study-and-local-ai.md#切断と並行操作)に従う。固定条件と計算結果の変化を混同せず、安全側/危険側が未確認の近似計算を追加しない。
