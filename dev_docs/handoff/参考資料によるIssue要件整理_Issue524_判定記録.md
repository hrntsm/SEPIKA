## 主な判断

- #441: 平均せん断応力度のΣAは付帯柱・袖壁を含む定義。剛性Asと終局耐力teから分離する。
- #444: DL重力支持と地震用の階重量配分を分離。開口が非対称なら総重量の単純半分と一致しない。
- #345 / #450 / #451: 梁自重は階標準厚、剛性は取付き実厚、型枠は実接触面。用途を統合しない。
- #450 / #451: 現行コードには隣接床厚の参照が既にある。初回移行の未実装前提を訂正し、左右異厚・重複・参加可否を残作業として具体化した。
- #434: RC/SRC許容曲げ計算のn表は、解析剛性の材料欠落フォールバックの根拠にならない。
- #503: 明示した材種の295と材料欠落を区別する。欠落を検定済みにしない。
- #493–#495 / #518–#519: SRC内蔵鋼板の式を純鋼板壁へ流用しない。未考慮事項・未検定理由を開示する。
- #523: αyの係数・適用区間に現行式と参考資料の差を発見。PDF p.90–91の画像でも確認した。一次資料p.17で照合する独立Issueを追加し、未照合のまま式を置換しない。
