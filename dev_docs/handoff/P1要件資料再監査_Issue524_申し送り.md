## 監査で是正した要点

### RCの単位と骨格

#435はαy用pt=at/(bD)の小数と、せん断用百分率を区別し、分母の違いも記録した。
#523では「一次資料を比較して採用式を決める」という旧方針を撤回した。参考資料の画像確認済みの式を採用する。

```text
基本式: αy=(0.043+1.64 n pt+0.043 a/D)(d/D)²
a/D>2.0: αy=(−0.0336−0.1935 n pt+0.1270 a/D)(d/D)²
pt=at/(bD), n=Es/Ec
```

原画像はPDF p.90–91（本文p.87–88）を確認済み。
係数・不等号の差は文字抽出の誤りではない。
n=10、pt=.01、d/D=.9でa/D=2の基本式は.23733、第2式の右側極限は.1628505。
この境界差を記録し、分岐を逆にして現在の式へ近づけない。
資料にない入力範囲・不連続の扱い・非正値への対応は、
日本建築学会『鉄筋コンクリート終局強度設計に関する資料 1987』p.17で補足する（原典未閲覧）。
T形梁の上下引張での協力幅・スラブ筋・I0/IT補正も範囲に含めた。

#434は解析剛性のEs/Ecと許容曲げ計算用n=15/13/11/9を分けた。
現行SRCは標準Es=205000と入力Ecから比を作る実装であり、
カスタム鋼材youngを参照する実装だと誤記しない。
#436はM/(GA)のmmを回転角へ加える問題と、資料外の抜出しモデルの腕長の確認を分けた。

### 壁の応答・断面・Ds

#443には四節点分岐とwall_shear_signedが既存である。全て二節点として処理するという前提を撤回した。
残る節点並べ替え、符号、切断面での力、未提供の回転等の出力を対象とする。

#441は参考資料§2.6.6(1)（本文p.108–109／PDF p.111–112）にある
`τu=1.2Q/ΣA`を採用した。ΣAは付帯柱・袖壁を含む耐震壁の全断面積。
現行の`Q/(t lw r2)`との係数・面積の差を追跡し、
Qu用の開口低減を根拠なくτuの分母へ流用しない。
図2.6.5-11（本文p.96／PDF p.99）のN2/2は軸力配分であり、
共有側柱の断面積を半分とする根拠ではない。共有断面の配分は一次資料で補足する。

#442は層別ピークstory_quと最終member_responseの混在を対象にし、
同じ確定ステップの層切断面でβuを集計する。
#489では資料のD部材の既定処理、耐力加重のA/B/C群判定、RC/S/SRCの別表、
鉄骨接合部/継手の保有耐力接合条件を明記した。
D部材の群判定からの除外を全体Quの無条件除外へ拡張しない。
また壁の非せん断破壊条件Qu≥1.25Qを採用し、現行Q≥0.99Quの判定との差を追跡する。
Qu=1000kNならQ=800kNが境界で、800kN超はWD側となる。

#440はSRCの両側柱・上部梁の構成条件と、壁板・側柱・内蔵鋼材の別項を明記した。
CFT/S側柱への適用は別の原典調査とする。
#496はBeam/FiberMultiSpring表現を跨いでRC/SRC側柱の物理的役割を維持する契約とし、
純鋼板への一律解放は#518で別に検討する。

### 荷重・数量・再生成

#437/#438は資料の最大格子100mmを採用し、凹形の支持候補と台形の比較精度を分けた。
約2%の既存差を許容値や安全側としない。誤差評価・独立積分の成果物を要求する。
#444はDL支持先、階高中央での地震用重量集計、小梁上の壁のDL全量下側伝達を分けた。
#450は単純倍率と精算の選択を保持し、精算だけに左右異厚の断面幾何を適用する。
合成倍率はφ1+φ2−1。#451の型枠控除は剛性式ではなく接触領域の独立幾何計算とする。

#445の自立壁には支持床直上層へ帰属する現行処理がある。
この点は検証を先行し、資料の指定基準柱と現行層平均剛性の差を別に扱う。
#506も割当領域の境界キー照合が既存であり、名前の重心/面積推定と区別した。
既対応部分の再実装を要求せず、残る同一性・分割/統合・衝突・undo/redoを検証する。

#501/#504/#505は高密度鋼の設計荷重過小評価、dbの0.9D、
原典にない段差150mmの適用条件を対象とした。
不足/対象外の計算を合格として継続しない契約を具体化した。
