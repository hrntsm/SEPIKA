## 移行後の文書の役割

- GitHub Issues: 未完了の開発作業。IssueのScope/Doneと実際の進捗を更新する。
- handoff: 過去の実装経緯・判断の履歴。本書と元の「残課題」節は監査スナップショットで、現役の残課題台帳として更新しない。
- docs: GUIで使う構造設計者向けの理論・計算根拠・現行仕様・適用条件。実装位置は補助参照。
- v_and_v: 検証状態・原典照合・未検証・結果の証跡。具体的な実装/修正が必要ならIssueへ結び付ける。
- ADR: 確定した設計判断の根拠と適用範囲。
