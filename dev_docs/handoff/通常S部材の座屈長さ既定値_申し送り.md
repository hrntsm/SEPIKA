# 通常S部材の座屈長さ既定値の申し送り

作成日: 2026-11-18

[#1443](https://github.com/hrntsm/SEPIKA/issues/1443)の既定値を通常・時刻歴簡易検定へ共通化した。過去の設計判断のうち、通常S柱と偏心一般ブレースの直接指定必須、および通常S柱の0指定を置き換えた。CFT、SRC、横座屈、BRBの検定条件は別契約を維持した。[ADR 0114](../adr/0114-steel-buckling-length-defaults.md)

危険側となる条件がある。理想ピン柱脚・水平移動非拘束の有限例では、実効長が既定値を上回り、通常・時刻歴簡易検定とも実効長を直接指定した結果との間で適否が逆転した。実効長が既定値を超える方向は条件に応じた直接指定が必要となる。[原典条件・有限例・保証範囲](../v_and_v/通常S部材の座屈長さと時刻歴簡易検定_確認記録.md)

検定契約60以前の保存成果は再検定を要する。時刻歴簡易検定は表示時に保存解析の内力から算定するため、採用長さは表示時の現行契約で決まる。

軸力包絡で絶対値の大きい引張が圧縮ピークを置き換える制限は[#1445](https://github.com/hrntsm/SEPIKA/issues/1445)で追跡する。
