# RC床板平均厚の申し送り

作成日: 2026-10-25

## 判断の経緯

Issue618の初期実装は左右異厚を矩形分解したが、個別床板の全長取付きへ限定していた。
App lib試験の追随後、実建物ST-Bridgeのfull_model統合で、RC基礎梁に複数の部分床板が接するため準備計算が停止した。
取り込み自体は梁偏心を未入力としており、解析用fixtureが0を明示した結果、D1800のRC梁上端と床上面にも900 mmの不一致があった。
床板群と小梁を削除する、材種を変える、統合試験を停止期待にする変更は採らなかった。

利用者は床板厚の長さ加重平均を指定し、危険側可能性の説明後に明示承認した。
現在の採用条件と式は[製品計算根拠](../../docs/calc_basis/04_要素剛性/01_ティモシェンコ梁要素.md#剛性計算上の付加協力幅壁エレメント上下梁雑壁)、判断は[ADR0075](../adr/0075-rc-beam-length-weighted-slab-thickness.md)を正とする。

## 危険側の申し送り

厚さの長さ加重平均は、区間別の曲げ変形を精算する方式ではなく、剛性過大・変形過小となり得る。
この採用は利用者の明示指示による。一般的な安全側近似や誤差上限を確立したものとして扱わない。
重量・数量・物理質量へ平均厚を流用せず、幅変化や全長欠落を平均へ吸収しない。

## 実モデルfixtureと検証の所在

解析fixtureではRC梁上端を床上面へ揃えるため、元節点材軸から-D/2 mmの偏心を明示する。
既存の小梁・支持区間・床板群と統合試験の観測契約を維持する。
独立期待値、対象SHA、実行結果、未実施範囲は[V&V](../v_and_v/RC梁左右床板厚_Issue618_2026-10.md)へ記録する。
最終レビュー・CI・mergeの最新状態は[PR813](https://github.com/hrntsm/SEPIKA/pull/813)と[#618](https://github.com/hrntsm/SEPIKA/issues/618)で確認する。

## 維持した幅探索の範囲

対向梁幅の探索は、既存のPrimary Beamと未検出時の自梁幅を用いる規約を保持した。
SecondaryやFiber/MS等の断面幅を新しく探索する対応は追加していない。
床板群の幅一定判定は、この既存探索が採用する内法距離・協力幅を照合する。
これらの探索範囲外に対する実幅との一致は本作業で検証したと扱わず、元Issue本文の関連調査範囲と区別する。
