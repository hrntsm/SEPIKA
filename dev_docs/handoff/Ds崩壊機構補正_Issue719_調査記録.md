## 結論と判断の範囲

**指定された2025年版第2版の原画像により、原典未閲覧という保留を対象範囲について解除した。** 一律の群1ランク悪化は確認した条件別取扱いを実現しないため、規準上の補正として維持しない方向で修正する。コードの単純削除だけでは不足するため、本調査ではコードを変更せず、条件別評価と情報不足時の扱いを後続実装へ分離する。

通常RCは部材・接合部ごとの種別と採用応力状態、S露出柱脚は伸び能力・保有耐力接合・群Dの例外を分ける。S造RC基礎梁の限定換算は、最下層のRC基礎梁ヒンジをRC種別から一段階下のS種別へ換算し、ヒンジ位置に応じ柱種別を修正する大阪府の限定取扱いとして区別する。RCのFDには対応するS種別がなくFD回避の保証が必要であり、層全体の一律補正とは異なる。2025年版の一般規定とは確定せず、現在の機構・ヒンジ情報だけでは自動適用不可と結論する。採用条件と現在の制約の正本は[構造特性係数Ds](../../docs/calc_basis/07_二次設計/02_構造特性係数_Ds.md#崩壊機構に関する適用条件と確認範囲)及び[DsとQuの採用状態](../../docs/calc_basis/07_二次設計/01_保有水平耐力の判定.md#dsとquを採用する状態の条件)とする。

一律補正によってDsが増えても、機構・破壊形式・評価状態を誤った結果全体の安全側保証にはならない。今回、新しい近似・補正の製品採用や安全性判断はしていない。

### 今回の原画像確認で解消しない範囲

2020年版・2015年版そのものとの版間差分、AIJ規準本体、現行統合告示全文は未照合である。これらの未確認を、今回確認した2025年版の該当条件まで未閲覧であるかのように扱わない。S造RC基礎梁の限定換算を一般化する場合は、適用地域・条件・RCのFD及び混在時の扱いを所管等へ確認する必要がある。

## 後続実装への申し送り

調査目的に対して条件と残判断を整理した。実装完了ではない。条件別補正は [#871](https://github.com/hrntsm/SEPIKA/issues/871)、Ds/Quの採用状態と不足情報は [#872](https://github.com/hrntsm/SEPIKA/issues/872) で管理し、#489は再開しない。

1. 一律補正を規準適合の根拠から外し、通常RCの非ヒンジ柱・接続部材・脆性破壊と採用状態を条件別に扱う。情報不足をランク補正や未補正で埋めず、判定を保留する契約を後続で確定する。
2. S露出柱脚の形式・伸び能力・保有耐力接合・群D例外を設計情報と対応させる。RC基礎梁の換算は一般規定とせず、適用条件が未確定なら別途確認として残す。
3. #442の目的別識別は維持し、非崩壊部分、脆性部材除外の整合、壁せん断破壊時のβu等の状態条件を補う。現在の単一run/step構造で、非崩壊階や別途仮定した応力をどう保持するかは未決定であり、新規解析を本件では実装しない。
4. 未使用`story_ds`と、それを使うV&Vを実際の採用経路へ整理する。互換性のためには残さない。終了理由表示は再照合基準で是正済みのため、重複した後続課題を作らない。数値的特異を物理的機構の証明に使わない条件は維持する。
