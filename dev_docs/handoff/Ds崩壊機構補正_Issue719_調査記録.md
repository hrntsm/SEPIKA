## 結論と判断の範囲

**原典不足により採用条件の確定は未完了。** 層柱梁群の一律 1 ランク悪化を法令由来として説明する根拠は、今回確認した範囲では得られなかった。根拠が存在しないと証明したものではない。
製品本文の断定を訂正し、現在の制約を明示した。計算コードは変更していない。

| 対象 | 判断できること | 保留すること |
| --- | --- | --- |
| 通常 RC の層崩壊 | 下記告示改正本文は崩壊時応力・ヒンジ位置・隣接梁種別を使う。機構ラベルから群全体を一律悪化する根拠として使えない | 一律補正の恒久維持・削除、条件別方式への置換。削除だけでは必要な部材種別・破壊確認を補えない |
| S 柱脚 | RC 基礎梁の限定換算と別条件で調べる必要がある | 柱脚形式・保有耐力接合・アンカーボルト等の条件別補正と例外。今回の原典確認では確定できない |
| S 造 RC 基礎梁ヒンジ | 大阪府の限定した取扱いは確認。層崩壊層の柱梁群を一律悪化する現処理とは異なる | 当該取扱いの製品採用、適用地域・設計条件、RC の FD を含む適用外の扱い |
| Ds/Qu 評価点分離 | #442 の状態識別・混合拒否は維持できる。指定点が法令の採用条件を満たすこととは別 | 各条件の採用点、非崩壊部分、局部破壊時の採用、柱脚等の保証条件を自動判定する方式 |
| 未使用の `story_ds` | App と異なる補正を持ち、互換性維持を理由に残す必要はない | 公開 API と V&V の整理・削除を伴うコード変更は独立の後続作業 |

一律補正が Ds を増やす場合でも、機構・破壊形式・評価状態を誤った結果全体の安全側保証にはならない。今回は安全性不明の新しい採用判断をしていない。
