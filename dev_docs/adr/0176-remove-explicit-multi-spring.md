# 非線形線材のマルチスプリング指定を廃止する

Status: accepted

非線形線材のマルチスプリング（MS）は明示指定でのみ使い、通常の梁・柱の自動選択には含まれていなかった。今後の対応範囲にも不要なため、専用の要素種別・解析処理と専用の表示を廃止する（[#2032](https://github.com/hrntsm/SEPIKA/issues/2032)）。材端集中ばねとファイバーの選択・計算、支持や節点のばねは対象外とする。

旧指定は、別のモデルへ置換すると利用者が意図した応答と異なり得るため受け付けない。[ADR 0014](0014-schema-compatibility.md)に従い、構造スキーマ版は変えず移行処理を設けない。計算の適用範囲が変わるため、保存成果の解析・通常検定の契約版を更新する。

過去のADRにあるMS対応の判断と当時の照合結果は履歴として残す。現在の利用条件は製品文書を正とする。
