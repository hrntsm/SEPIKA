# 矩形SRCの内蔵Hを材料領域から控除し、離散主筋近似と質量を分離する

Status: accepted

Issue [#552](https://github.com/hrntsm/SEPIKA/issues/552) の限定対象である中心直角H付き矩形SRCについて、既存の共通ファイバー生成元でHの3板をコンクリートから除く。残存領域をH境界に沿う矩形へ分解し、正面積セルへメッシュ化する。セル中心だけでの削除は境界面積を保存せず、総面積比だけの縮小は曲げの腕とIを是正しないため採らない。消費側に個別の幾何を増やさない。

離散主筋は実座標・1本面積の既存近似を残す。円形控除を全RCへ拡張する変更は今回の契約外で、近似の増分と安全側と認定できない限界を製品文書へ明示する。実主筋とHの円対矩形干渉は既存の配筋検証へ統合し、静的準備・直接解析・表示の生成でも同じ拒否を用いる。

質量は#594の独立幾何resolverを維持する。材料ファイバーの是正で質量が変わることを成功条件としない。

解析契約版は3→4へ更新する。非線形内力・接線と幾何の適用条件が変わるため旧解析成果は失効させる。検定の式・適用条件は変わらず版2を維持する。`sepika-design-jp`はこのM–Nファイバー生成元を消費せず、解析成果が失効した際には`sepika-app::app::result_validity`の既存経路がそれに依存する検定成果も消去する。

現在仕様は[ファイバー断面](../../docs/calc_basis/03_断面性能/07_ファイバー断面.md)、証拠は[Issue552 V&V](../v_and_v/SRC材料領域_Issue552_2026-10.md)を参照。SRC2014規準原本と全履歴則の実験Validationは未閲覧・未実施であり、検証済みと扱わない。
