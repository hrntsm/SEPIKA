# 通常S柱は両軸の座屈長さ直接指定を必要とする

Status: accepted

[Issue #1398](https://github.com/hrntsm/SEPIKA/issues/1398)では、理想ピン柱脚をG=10へ置換すると独立釣合いの有効長を過小評価し、採用圧縮式でNGの柱をOKとする有限反例が得られた。ピン端だけを除外しても、層内軸力分布・同時座屈を含む設計適用条件を現APIの節点剛度集計から立証できない。

通常S主架構柱の共通検定入口では自動Kを採用せず、有限・非負の両軸座屈長さ直接指定を必要とする。不足は対象柱・軸と理由付き未検定とし、材長への補完も認めない。0は当該軸の座屈を無視する既存指定として保持する。独立解を一般化した万能Kや根拠不明の倍率は追加しない。

RC・SRC・CFTへの既存係数供給と数値APIは変更しない。CFTは実検定で係数を消費するため、下位API削除による材長への後退を避ける。この保持は他材種の適用域を承認する判断ではない。CFTの適用域は[#1400](https://github.com/hrntsm/SEPIKA/issues/1400)で追跡する。圧縮許容式・法定細長比・BRB等も変更しない。現在仕様は[鋼構造の断面検定](../../docs/calc_basis/06_一次設計/03_鋼構造_断面検定.md#柱の座屈長さ係数-k)を正とする。
