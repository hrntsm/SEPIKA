# 参考用スケルトン計算を廃止し製品計算の責務を維持する

Status: accepted

## 背景

参考用M–φ→M–θ計算は製品の要素生成から利用されず、外部利用はRC略算耐力との開発時比較だけだった。
材料則・変形近似が製品計算と異なり、参考用の骨格生成一式を移管すると独立した保守対象が残る。

## 判断

[#849](https://github.com/hrntsm/SEPIKA/issues/849)の決定に従い、参考クレートと専用APIを廃止し、移管は行わない。
製品の材端骨格はelement、履歴則・材料状態はmaterial、断面のM–φ/N–Mはsection、略算耐力はcoreを正本として維持する。
旧参考M–φのConcrete/Bilinearによる履歴状態と、sectionの弾完全塑性評価は同等な計算として置換しない。

| 旧処理 | 判断と理由 | 維持する保証 |
| --- | --- | --- |
| builder / types | 削除。汎用・RC参考骨格と専用型は製品から未使用 | elementのfactory試験で製品の要素選択・材端骨格・武田履歴を確認 |
| fiber_model | 削除。参考用の配筋・M–φイベント検出・軸力探索で、製品と材料条件が異なる | sectionの断面応答・M–φ初期剛性/終局域・軸力依存の既存試験を維持 |
| deformation | 削除。参考用の三角形曲率・ヒンジ集約・せん断/抜出し角を製品は呼ばない | 製品の材端ばね・ファイバー要素の既存試験を維持。旧近似の保証を代替したとは扱わない |
| tests | 削除。参考骨格の形状・軸力依存・手計算比較と#436の単位/拒否契約は廃止対象を検査する | 現行core/section/elementの独立期待値と回帰試験を維持 |
| design-jpの±30%比較と専用fixture | 削除。同じ代表断面の略算耐力はcoreの独立手計算がより狭い許容差で検査する | `test_rc_mu_simple_matches_handcalc`、Qmu手計算、柱耐力分岐等を維持 |

±30%比較は参考側の材料則・イベント検出の変化だけでも失敗しうる。
略算式の係数・単位の退行はcoreの手計算照合が検出し、比較に固有の製品故障検出根拠は確認できない。
この整理は略算式の適用範囲全体の物理Validation完了を意味しない。

## 結果

旧APIの互換実装を作らず、現行計算の式・既定値・履歴状態は変更しない。
#436等の過去の実施記録は保持し、V&V/handoff索引で廃止済みの対象と区別する。
