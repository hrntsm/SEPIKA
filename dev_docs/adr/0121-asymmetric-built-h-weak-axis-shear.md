# 上下非対称組立H形鋼の弱軸せん断を未算定とする

Status: accepted

上下非対称組立H形鋼に共通の仮想フランジ幅・厚さを用いると、弱軸せん断の合否が実断面と対応しない評価で決まる。実フランジ面積への置換だけでは、フランジとウェブでのせん断力の分担や公称応力度の評価方法を定められない。規準の材料許容値に対応する評価を確定できるまで、上下のフランジの幅または厚さが異なる組立H形鋼の柱・大梁では、弱軸せん断力が非零または非有限の位置を理由付きで未算定とする。

法定細長比、軸力の材料上限、上下非対称組立H形鋼柱の圧縮と強軸曲げについて、既存の手順で独立に確定した不適合は表示する。強軸せん断や同一点組合せの既存条件にも該当する場合は、それぞれの理由を併記する。旧検定結果の再利用を防ぐため、解析契約と独立して検定契約版を更新する。 [適用条件と比較例](../../docs/calc_basis/06_一次設計/03_03_鋼梁_柱のせん断検定.md#上下非対称組立h形鋼の弱軸せん断)・[Issue #1546](https://github.com/hrntsm/SEPIKA/issues/1546)
