# 固定したS造部材の鋼材数量と全体数量の算定状態を分離する

Status: accepted

## 判断

検討の固定対象である主架構S造部材の鋼材数量を、他部材の型枠・コンクリート・鉄筋の算定状態から分離する。既存の実断面積・節点間材長・数量用単位重量による鋼材明細生成を共用し、近似式や入力モデルの切除を設けない。対象そのものの断面・材料・用途・節点・面積・材長が不正なら拒否する。

全体の数量計算と接触型枠の拒否は維持する。全体数量を実際に取得し、取得不能ならその理由を固定鋼材の値と併記する。他の未算定数量を0で持つ部分的なQuantityTakeoffを作らない。既存のQuantityEvidenceReference.takeoffの意味も変更せず、鋼材専用結果を明示する別経路とする。

比較GUI・MCP・共通根拠は同じ固定入力の鋼材専用経路を使い、断面積の算定元・節点間材長・鋼材体積と全体未算定理由を示す。数量根拠の計算契約を2へ更新し、保存入力・範囲・契約の識別と併せて再取得する。旧契約を現在の全体数量成功や鋼材専用成功へ読み替えない。開発中の互換性は[ADR0014](0014-schema-compatibility.md)による。

## 理由

床と接触する基礎梁の型枠対象側面は現入力で特定できず、全体数量が取得不能になる。一方、別階にある鉄骨大梁の鋼材体積はこの型枠条件へ依存しない。全体数量を先に計算してから対象を絞るだけでは、算定可能な鋼材まで取得不能になる。全体の拒否を緩める方法は、型枠未定を確定値へ読み替える危険があるため採らない。

新しい型枠入力や全材料の部分集計基盤は設けず、現在の鉄骨断面比較に必要な非依存成分の分離に限定する。
