# 壁上下の剛梁を連続した壁板の弾性高剛性部材として扱う

- Status: accepted
- Date: 2026-10-19
- Related: [#496](https://github.com/hrntsm/SEPIKA/issues/496)、[ADR 0013](0013-adopt-wall-element-model.md)、[ADR 0063](0063-wall-side-column-foundations.md)

## 背景と判断理由

壁上下辺の大梁を実梁自身の材料降伏を評価する部材と解釈すると、壁板を表すための高剛性化と材料非線形との関係が曖昧になる。
ユーザーは、これらが壁と連続した一枚の板を梁でモデル化する都合で設ける弾性梁であり、梁自身の降伏評価を必要としないことを明示した。
この物理的役割を明示して採用し、通常の材料非線形部材と区別する。

実梁の降伏を再現する案には、剛性倍率と材料構成、周辺壁との応力分担を別途定式化する必要がある。
それは今回確定した役割と異なるため採用しない。剛性倍率を緩和して材料求解を成立させる案も、意図した壁置換モデルを変えるため採用しない。
この判断は壁全体系の剛性・応力分担・表示と受入条件に及ぶため、要素表現から暗黙に推定する仕様にしない。

## 決定

壁上下の剛梁は、連続した壁板を表す弾性高剛性部材とし、既存の剛性倍率 100 を維持する。
この役割では梁自身の Fiber／MultiSpring 材料降伏を解析しない。
要素の入力表現名だけで役割を変えたり、Fiber／MultiSpring という名称だけで一律に拒否したりしない。
要素生成、モデル化表示、診断、製品ドキュメントは、この弾性の物理的役割を共通に示す。

通常の Fiber／MultiSpring 部材と壁側柱は の軸・二軸曲げの材料応答と履歴を保持する。
壁上下の剛梁に対する弾性の採用は、非線形側柱の特異・不収束を弾性に置換して成功とする根拠にはならない。
側柱の回転解放と材料構成の分離は [ADR 0063](0063-wall-side-column-foundations.md) に従う。

## 適用限界と確認状態

この弾性モデルは実梁自身の耐力・降伏・損傷を評価する用途には使えず、解析で梁が降伏しないことから実梁の無損傷を保証しない。
高剛性の弾性境界を実梁の材料非線形まで表すモデルとして用いると、耐力の過大評価や変形の過小評価につながり得る。
壁全体系に対する安全側の保証や、独立した物理 Validation の完了を意味しない。

`accepted` はモデルの採用判断を表す。
検証結果は対象のコードと固定時点に対応付け、分離前の成果をそのまま現在の計算経路の成功根拠にしない。
剛性・反力・変位・壁せん断・耐力・重量／質量と、側柱の局所釣合い・接線・履歴仕事を含む受入条件を、この判断だけで成立したと扱わない。
[#496](https://github.com/hrntsm/SEPIKA/issues/496) の全七完了条件と最終 CI の完了も示さない。
製品仕様・計算根拠・利用上の制限の正本は[壁上下の剛梁の役割](../../docs/calc_basis/04_要素剛性/05_壁エレメントモデル.md#壁上下の剛梁の役割)とし、本ADRは採用判断とその理由を記録する。
