# 曲げせん断型を弾性曲げと履歴せん断の直列要素で扱う

Status: accepted

## 背景

せん断型の全層間変位に曲げ要素を追加すると、柱軸伸縮による曲げ柔性を二重計上する。
曲げを層回転ばねだけに置換すると、層内モーメントの勾配に対応する曲げ並進変位を満たせない。

## 判断

既存のせん断型の計算経路と既定値を維持し、曲げせん断型だけ別の生成・求解経路へ接続する。
EX/EYの水平力による柱軸仕事から弾性EIを求め、静的・各確定増分ステップの全層間変位から弾性曲げ変位を控除する。
曲げはEuler–Bernoulli要素、非線形性は既存の最大点指向型せん断履歴とし、内部直列接続点を同じ試行状態で釣り合わせる。

各階の曲げ回転を外部自由度として残し、並進と同じ物理質量源から水平軸慣性・積慣性を生成する。
回転を無質量として消去する方式やZ軸慣性の流用は、要求する回転動力学を変更するため採用しない。
曲げ回転は既存の表示用[Ux,Uy,θz]と分けて保存する。
増分の確定ステップには各階代表節点の水平変位・Z軸回転も記録し、3次元骨格は初期載荷点と各ステップを同じ剛心位置へ写してから生成する。代表節点の選択でせん断骨格を変えないためである。

傾斜柱は鉛直変位差が軸伸縮だけを表さず、柱軸仕事を保証できないため対象外として診断する。
算定不能を剛扱いや正値補正で通過させない。
