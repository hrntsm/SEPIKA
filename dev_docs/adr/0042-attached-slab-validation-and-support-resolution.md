# ADR-0042: 取り付く床板の幾何と支持先を入力境界で共通検査する

- Status: accepted
- Date: 2026-10-10
- Issue: #458

## 判断

Attached 床板の幾何と荷重支持先の検査を core に置き、入力経路と荷重計算が同じ診断と支持対応を使う。Line の幾何参照が節点対であるため、分割された梁を一つの先頭候補で代表させず、取付き区間を覆う梁区間を解決する。Point/Columns は既存の指定節点への伝達を維持し、未接続の幾何節点は既存の梁スパン変換に対応する一意性を検査する。一般の二次部材・壁版の支持解決にはこの変更を適用しない。

面荷重と先端荷重の公開計算経路は、境界座標へのアクセス前に同じ core 支持解決を使う。先端荷重側に独立した最小被覆長・被覆許容差・重複判定を持たせず、支持区間の割合で全荷重を分け、実梁区間の実長で等分布へ換算する。

編集は候補モデルへ適用して Attached の契約のみを検査し、成功した候補と逆操作だけを採用する。複合コマンドで拒否診断を受けた場合は全体を拒否する。通常の Noop と理由付き拒否を区別し、GUI/MCP へ診断を返す。モデル全体の validate を全編集へ強制して途中作成を禁止する案は採らない。

## 理由とトレードオフ

以前の参照・span 検査だけでは有限な extent でも自己交差や荷重支持先の欠落が残り、下流の先頭候補や節点反力への代替で不正入力が見えなくなる。入力経路ごとの検査を増やすと、GUI・MCP・保存済みファイル・解析で受理される形状が異なる。core を共通契約とすることで load への逆依存を避け、実梁支持の計算にも同じ区間を渡す。

候補モデルの複製は編集時のメモリと計算量を増やすが、逐次適用後の逆操作による巻戻しは途中の拒否や再構築で完全性を保証しにくい。元モデルと履歴を直接保持する方式を採用する。

片端ゼロの三角形を拒否する案は Issue の許可契約を満たさないため、連続重複頂点を正規化する。荷重計算は頂点数4を前提にせず面積から等分布強度を求める。傾斜取付き線を新たに禁止せず、既存の XY 面積による面荷重合力を保つ。長方形以外の等分布は本アプリの既存伝達モデルの範囲であり、荷重の分布形を安全側として新規に保証する判断ではない。
