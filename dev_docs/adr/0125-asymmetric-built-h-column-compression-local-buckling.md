# 上下非対称組立H形鋼柱の圧縮と強軸曲げに局部座屈を省く条件を適用する

Status: accepted

材長・座屈長さがすべてゼロの断面照査でも、圧縮を受ける板の局部座屈は生じ得る。軸力と強軸曲げを合わせた応力度から圧縮を受けるフランジとウェブを判定し、2019年版の本文が定める幅厚比を照査する。解説によるウェブ制限の緩和や、無効部控除後の応力度が確定しない場合は理由付きの未算定とする。

幅厚比の条件から外れる断面では、無効部の控除により断面積と図心がともに変化する。各縁の応力度が全断面の値より常に大きくなることを保証できないため、全断面による不適合の表示にも幅厚比の確認を要する。独立に確定した法定細長比の不適合は表示する。

旧検定では局部座屈の条件外で適合が表示され得るため、検定契約版を更新する。 [計算根拠と適用条件](../../docs/calc_basis/06_一次設計/03_05_鋼柱_ブレースの軸力_曲げ検定.md#上下非対称組立h形鋼柱の圧縮と強軸曲げ)・[Issue #1605](https://github.com/hrntsm/SEPIKA/issues/1605)
