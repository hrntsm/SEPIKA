# 部材の両端で異なるXYZ方向の並進偏心に段階的に対応する

Status: accepted

SEPIKAの偏心設定を、部材の両端で異なるX・Y・Z方向の並進偏心を扱える方向へ拡張する。構造解析の仕様を先に定め、部材種別ごとに可視化と力学計算への適用範囲を定める。2026-11-06のユーザー決定による。

対象は柱・大梁・小梁・間柱・ブレースとする。まず大梁・小梁へ対応し、その後に他部材へ拡張する。全体を一つの実装Issueにまとめず、独立して完了を判断できる段階ごとにIssueを分ける。

偏心は建物全体のX・Y・Z方向の符号付き移動量として指定する。単位はmmとし、部材の局所座標方向として解釈しない。

偏心の基準となる中心線は、偏心の編集では動かさない。小梁・間柱の支持アンカーも基準となる中心線上の位置として扱い、支持部材自身の偏心を加算しない。各部材の実配置は、その基準位置と自身の偏心から決める。

主架構の各端は元の接続先を保ち、接続位置と偏心した実部材端を剛体で結ぶ。偏心後の交差・接触だけから接合を推定せず、取付き位置に応じた他部材の自動分割・接続先の変更は行わない。別の取付き位置で他部材の途中に力が入るモデルは、この剛体接続によって表現したものとは扱わない。

小梁・間柱の偏心は可視化だけに反映し、力学計算には使わない。荷重伝達・反力・重量・質量・検定は偏心前の基準位置で扱い、偏心によるモーメントを加えない。小梁・間柱を全体架構の剛性へ算入する範囲を広げる変更は行わない。

小梁・間柱のこの扱いは2026-11-06のユーザー明示指示によるモデル化であり、ピン・ねじり解放から偏心モーメントが常に零になるという力学的結論ではない。実配置の偏心によって支持先に生じる曲げ・ねじりを過小評価し得るため、安全側の近似とは扱わない。実装時には製品docsの計算根拠にも、この適用範囲と制約を記載する。

仕口パネルの計算式の適用範囲は維持する。偏心後の接合部が適用外となる場合は、対象と理由を示して計算を停止する。適用範囲の拡張に必要な調査・開発は別Issueで追跡し、今回の偏心対応の完了条件に混在させない。

今回のST-Bridge対応は両端の偏心を対象とする。部材途中の節点とそのオフセットを持つ入力は、黙って省略せず対象と理由付きで拒否する。中間節点への正式対応は後続Issueで追跡する。

先にSEPIKA本体でこの並進偏心を扱う設計を確立し、その後にST-Bridgeの基準位置とオフセットを変換する入出力を設計する。各段階の適用範囲と完了条件を[親Issue #1361](https://github.com/hrntsm/SEPIKA/issues/1361)と子Issueで管理する。

ADR 0076で一般XYZ偏心入力を対象外とした判断を、この並進偏心の範囲で撤回する。各方向の偏心は有限な数値を必須とし、偏心なしは0とする。
