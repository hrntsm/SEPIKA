# 床板の実配置を支持座標から分離する

Status: accepted

床板は指定階のFLと上面偏心を個別入力として保持し、実厚を割当断面から解決する。
支持材から解決する境界座標は荷重伝達と接続のために維持し、床上面・下面は共通の実配置解決で返す。
変形表示は未変形の上面へ支持材の基準節点変位を加える。

支持座標へ床偏心を直接加えると、荷重伝達と解析節点の接続まで移動し、
梁の高さ変更で床高さが変わる。階FLと独立した床入力を保ち、後続の重量重複控除と嵩上げ重量が
同じ実位置を使えるよう、支持位置と床表面を別契約とする。
既存床領域の支持節点が上下へ移動した場合も、明示した支持境界のXYを再走査して接続を保持する。
未入力や参照切れを近傍節点Zと既定偏心0で補完する案は、入力不足を有効な配置へ読み替えるため採らない。
