# RC梁の方向別両端降伏による要求せん断力は独立した直接入力で求める

- Status: accepted
- Date: 2026-11-25
- Related: [#1582](https://github.com/hrntsm/SEPIKA/issues/1582)、[ADR 0120](0120-rc-beam-static-hinge-applicability.md)、[ADR 0139](0139-rc-beam-ultimate-shear-demand.md)、[ADR 0150](0150-rc-beam-directional-bond-stress.md)

## Context

設計上確認した両端曲げ降伏から要求せん断力を求めるには、当該方向の支持伝達、実柱面の内法、端ごとの曲げ耐力、同じ区間の常時せん断が必要である。長期曲げの代表符号、支持形式、均一断面の公称曲げ略算や架構解析の長期せん断力では、これらを置き換えられない。曲げ耐力上限をそのまま代入しても、常時せん断との相殺で合成絶対需要の過小評価が起こり得る。

## Decision

公開検定に確認済みの方向別入力を追加し、既存の実柱面の幾何を当該需要の検証に使う。設計者が支持・耐力・機構を確認し、モデルと矛盾する端部条件を排除する。両端に、梁接合節点の直接の強軸回転支持、または実柱面を与える柱の反対端でその曲げに抵抗できる方向の直接支持を求める。接続数だけでは拘束の方向や力の伝達を確認できないため、多層架構の連鎖や剛リンク等の支持経路は探索せず未算定とする。実柱面を与える柱がない場合も対象外とする。入力の両端位置はモデルの実柱面と一致し、正の内法となるものに限定し、極端に短い内法でも別区間の常時せん断を組み合わせない。端別曲げ耐力上限を用いた符号付きの端別値は、機構せん断をゼロから上限まで変えた絶対需要上限と分ける。表示丸めが上限値の過小評価とならないよう、設計に用いる数値は安全側に丸め、丸めた詳細表示は参考と明示する。常時せん断は符号付き端値で内法区間全体を挟める場合に限る。

算定するのは、ルート2の両端降伏枝とその上限に限る。最終需要やルート3の割増しには荷重段階その他の設計条件が別途必要であり、両端で降伏することだけを根拠に算定できない。新結果は従来の静的比較・確定総応答のいずれとも独立させ、同じ方向の非降伏付着との明示的な矛盾だけを検出する。

## Consequences

端別耐力・正負方向の違いを保持し、相殺が生じても方向別の絶対需要上限を過小評価しない。従来のせん断・付着の耐力式、静的用の内法の適用範囲および保存形式は変えない。一般の支持経路の扱いの検討、自動入力・GUI対応は [#1914](https://github.com/hrntsm/SEPIKA/issues/1914) で追跡する。[製品の計算根拠](../../docs/calc_basis/08_部材終局耐力/07_01_静的_両端ヒンジ略算による終局検定.md#方向別の両端降伏枝)・[検証](../v_and_v/RC梁の方向別両端降伏せん断_Issue1582_検証.md)
