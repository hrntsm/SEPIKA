# SRC柱の短期地震時せん断に適用確認済みの曲げ耐力を用いる

Status: accepted

評価位置の軸力で略算した曲げ耐力を柱の両端に使うと、方向別の配筋、端部別の軸力、接続梁による柱頭制限で決まる要求値が過小になる場合がある。曲げ耐力0から別の需要式に切り替えると、適用条件を満たして確定した需要0と入力不足の区別も失われる。

短期地震時の曲げ方式は、付1.4-1の適用を確認した両端・両方向の材料別曲げ耐力と柱頭条件をRustの検定入口で受け取る。既定の製品入力で根拠が不足する場合は未算定理由を表示し、独立に確定した軸力・曲げの不適合を保持する。代替式に必要な一次設計用地震力の柱せん断は、当該組合せの全せん断力と別に解決する必要がある。製品モデルからの自動算定と代替式は後続課題で扱う。
