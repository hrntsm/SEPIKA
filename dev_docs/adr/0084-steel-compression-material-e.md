# 鋼材の許容圧縮式を登録材料のEで共通適用する

Status: accepted

## 背景

原典照合#924で、告示1024号の炭素鋼表と現行のE依存式の数値差を確認した。
標準的な建築用鋼材のEは205000 N/mm²だが、材料には異なるEを登録できる。
この入力を一律に標準値へ置き換えるか、特別な認定鋼材にも現行式を適用するかを判断する必要があった。

## 判断

2026-10-27のユーザー指示により、材料種別が鋼材であれば、大臣認定による特別な鋼材を含めて現行の許容圧縮応力度式を共通適用する。
登録材料のEと既存のF解決規則を使い、標準Eへの固定・告示表の値による上限制限を追加しない。
採用式・標準値・認定材料の使用条件は[製品仕様](../../docs/calc_basis/06_一次設計/01_材料の許容応力度.md#鋼材f-値許容応力度座屈)を正本とする。
CFT鋼管も[専用材料の規則](../../docs/calc_basis/06_一次設計/04_SRC_CFT_断面検定.md#cft鋼管のヤング係数と許容圧縮)に従う。

## 結果と安全性

今回の決定は現行式の採用範囲を明記するもので、計算コード・材料入力範囲を変更しない。
E210000、F235、λ150では現行42.527028741583対告示41.538461538462 N/mm²となる既存の数値差を保持する。
告示表との比較では約2.38%大きい許容値となり、同じ作用に対する検定比が小さくなる危険側の可能性がある。
ユーザーは特別な認定材料も含めて同式を適用する方針を明示承認した。この注意を製品の計算根拠にも記載する。

採用承認を、任意の材料に対する認定取得の確認、告示表との完全一致又は実験Validationの完了とは扱わない。
