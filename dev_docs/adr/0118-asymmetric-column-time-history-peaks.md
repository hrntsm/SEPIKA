# 上下非対称組立H形鋼柱の時刻歴簡易検定は全確定時刻の断面を照査する

Status: accepted

[#1544](https://github.com/hrntsm/SEPIKA/issues/1544) の再現例では、成分別の絶対値包絡と引張・圧縮軸力極値だけでは、強軸曲げの符号が反転した時刻に断面で確定する不適合が落ちた。正負の強軸曲げ極値を加えても、[#1570](https://github.com/hrntsm/SEPIKA/issues/1570) の例では軸力と曲げがともに極値を取らない時刻が支配する。異なる時刻の成分を組み合わせると、許容比の過大評価と過小評価が生じ得る。

解析の確定断面力を詳細フレームの間引き前に解析ジョブへ渡す。設計側と共用する上下縁の照査で、対象柱の評価位置ごとに支配比と同時刻の軸力・強軸曲げ、未算定理由を集計する。全断面力履歴の保存はメモリと保存容量が確定ステップ数にも比例するため採用しない。集計済みの軸力極値と正負の強軸曲げ極値は、それらの時刻で独立に確定できる不適合を引き続き表示するために保持する。対象外の組合せ、欠落と有限材長の座屈は未算定とし、全体の適合は確定しない。

線形途中状態には前半の集計を保存し、再開点の次の時刻から同じ集計を続ける。集計のない対象柱を含む旧途中状態は、前半を現行条件で照査できないため再解析を求める。旧プロジェクトの応答結果では利用できる極値を表示し、全確定時刻の断面照査の不足を案内する。計算・通常検定の式と解析結果の数値は変わらないため、解析と通常検定の契約版を維持する。操作と適用条件は[時刻歴簡易検定](../../docs/result_view/10_時刻歴アニメーションの表示.md#上下非対称組立h形鋼柱)を正本とする。

[#2044](https://github.com/hrntsm/SEPIKA/issues/2044) の確定照査の公開入口は、解析時の要素順で記録を引く。呼出側からモデルを受け取ると、別のモデルで同じ部材 ID を別の集計に結び付けられるため、解析ジョブの結果と解析モデルを実行内で一体にする。保存時は既存の要素添字と生成入力の照合を引き続き使う。
