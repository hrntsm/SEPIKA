# 上下非対称組立H形鋼柱の時刻歴簡易検定は正負の曲げ極値を個別に抽出する

Status: accepted

[#1544](https://github.com/hrntsm/SEPIKA/issues/1544) の再現例では、成分別の絶対値包絡と引張・圧縮軸力極値だけでは、強軸曲げの符号が反転した時刻に断面で確定する不適合が落ちる。異なる時刻に生じた成分を組み合わせると過小評価も見かけの不適合も生じ得る。

上下非対称組立H形鋼のS柱では、各位置の引張・圧縮軸力極値と正・負の強軸曲げ極値を取る時刻の断面力で照査する。解析時に全確定ステップから抽出する。すべての断面力履歴を保持すると保存容量とメモリ使用量が解析ステップ数にも比例するため、既存の軸力極値に加える時刻数は各位置につき最大2件とする。抽出の対象外により厳しい組合せがあり得るため、照査で確定した不適合を表示し、全時刻の適否は未判定とする。

旧プロジェクトの応答結果は表示でき、当該極値の不足は簡易検定画面で案内する。対象柱の極値が不足する途中状態を再開すると前半と後半を同じ条件で集計できないため、その途中状態は拒否する。計算・検定の式や解析結果の数値に変更はないため、解析と通常検定の契約版は維持する。操作と適用条件は[時刻歴簡易検定](../../docs/result_view/10_時刻歴アニメーションの表示.md#上下非対称組立h形鋼柱)を正本とする。
