# 壁解析モデル生成をモデル層へ、梁CMQを実荷重応答へ集約する

Status: accepted

## 背景

壁版から解析要素への変換は荷重の有無に依存せず各消費者が利用する。荷重クレートに置くとモデル派生を利用するだけの設計・表示も荷重クレートへ依存する。一方、独立した剛域CMQは実解析の部材荷重積分と符号・荷重の所属を二重管理していた。

## 判断

壁展開は演算・ID・対応表・報告を保持してcoreへ移す。梁CMQの公開入口はelementへ移し、ゼロ節点変位の既存実荷重応答を利用する。loadからelementへの上向き依存と新クレートは導入しない。床荷重形状用の独立積分・荷重無視モード・旧互換入口を残さない。

通常弾性梁も既存の実荷重応答を所有し、公開の全体荷重組立を含めて零変位残差から等価節点力を一度だけ組む。非所有要素の既存分配契約は維持する。

建物共通の剛域考慮は保存される解析条件とする。解析用の剛域だけを派生させ、OFFでも入力剛域長・フェース・仕口パネルの偏心を保持する。準備計算で手動入力を書き換える案は、ON復帰時に値を復元できなくなるため採らない。
