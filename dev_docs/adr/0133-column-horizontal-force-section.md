# 通常柱の負担水平力を上階SL接続節点の層側で求める

Status: accepted

通常柱は、上階SL接続節点の高さと最上部材の実材軸端の高さが一致し、その直下を横切る柱の区間が特定できるときに評価する。柱頭側から層内に作用する符号付きの全体水平力を使う。端点の集中荷重があれば柱頭側切片に含める。地震静的結果に両端直内側の力を保持し、荷重ケースを係数倍して合成する場合にも同じ量を伝える。

局所軸力とせん断力の符号を直しても、i端だけを使うと部材荷重の位置によってi/j反転時に異なる力を採る。汎用の断面力は部材集中荷重の位置でi側極限を返す契約があり、上端がi端のときに必要な層側の力と一致しない。端の別に応じた物理力を持たせると、汎用断面力の位置指定と長期軸力による重心の契約を維持できる。上端の実材軸端と節点の高さが異なる場合は、一方の位置を黙示的に採用するとその間に作用する荷重を過不足なく扱える保証がないため保留する。保存した旧解析成果は解析契約版91で失効させる。
