# H形鋼柱の弱軸せん断と軸曲げの同一点評価を適用制限する

Status: accepted

軸引張・強軸曲げ・弱軸せん断を受けるH形鋼柱では、弱軸せん断を負担するフランジで法線応力とせん断応力を組み合わせる必要がある。ウェブ端の法線応力度と、せん断有効断面積で除した代表値を組み合わせた検定比では、同一切断線の局所弾性応力の下限に対して合否が反転する有限例がある。[独立比較](../v_and_v/鉄骨せん断面積と合成_Issue951_採用範囲照合.md#断面検定の有限比較)

同一点の設計用公称応力を評価して組合せ応力度が最大となる点を使うには、公称応力分布とウェブとフランジの取り合いにあるフィレット半径の取扱いが必要になる。確認した規準からこれらを確定できないため、該当する検定位置は理由付きで未算定とする。せん断有効断面積を使う代表値には断面内の座標がなく、切断線における厚さ平均から得たノルムは局所応力の下限なので、いずれも設計用公称応力の最大点の代わりに用いることはできない。直角断面の局所弾性解にはウェブとフランジの取り合いで発散する条件があり、規準の公称応力評価に転用できない。[直角H形断面の局所弾性解](../v_and_v/鉄骨せん断面積と合成_Issue951_採用範囲照合.md#直角h形断面の局所弾性解)

適用条件の変更以前の保存検定は、再利用すると旧適合判定を表示しうる。検定契約版を更新し、解析成果から独立して失効させる。[現在の適用条件](../../docs/calc_basis/06_一次設計/03_鋼構造_断面検定.md#h形鋼柱で引張強軸曲げ弱軸せん断が同時に作用する場合)・[Issue #1454](https://github.com/hrntsm/SEPIKA/issues/1454)
