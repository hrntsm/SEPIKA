# 軸力による幾何剛性を削除し、材料非線形と軸力を維持する

- Status: accepted
- Date: 2026-11-04
- Related: [Issue #1332](https://github.com/hrntsm/SEPIKA/issues/1332)

## Context

通常のGUI解析では幾何剛性を無効にしていた一方、内部には要素の算定、接続変換、全体加算、切替引数、専用診断と試験が残っていた。2026-11-04のユーザー指示で、現在の製品に軸力による幾何剛性を持たせない方針が確定した。

## Decision

P–Δおよび同じ機能に属する部材内P–δの幾何剛性を、内部インターフェースと解析設定を含めて削除する。無効な選択肢、無視する引数、ゼロ行列の互換実装は残さない。ADR 0076の幾何剛性転送とADR 0086の幾何剛性を有効にする低位入口に関する判断を撤回する。

長期荷重の初期載荷、軸力・軸変形・軸剛性、N–M相関、ファイバー断面の軸・二軸曲げ連成、軸力依存の復元力を維持する。微小変位の接続変換、剛域・偏心・パネル、荷重・質量・減衰、材料接線とNewton反復、既存座屈検定と履歴則も維持する。代替の幾何非線形モデルは追加しない。

## Consequences

通常GUI経路の結果を維持し、未利用の算定・切替・専用検証の保守を終了する。再導入には要素、接続変換、解析入口と検証を通した設計が必要になる。

P–Δの無視は常に安全側ではなく、圧縮軸力による変形・応力の増大や安定性低下を評価する用途を対象外とする。この適用限界を承知した明示指示による削除であり、安全側の簡略化として採用したものではない。現在の適用範囲は[梁要素](../../docs/calc_basis/04_要素剛性/01_ティモシェンコ梁要素.md)、[増分解析](../../docs/calc_basis/05_構造解析/07_プッシュオーバー解析.md)、[時刻歴](../../docs/calc_basis/05_構造解析/05_時刻歴応答解析.md)を正本とする。過去のV&V・実行ログは実行時点の履歴として保持する。
