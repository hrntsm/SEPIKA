# 小梁の必要入力が不正な場合は検定全体をエラーにする

Status: accepted

## 決定と理由

小梁の曲げ・たわみ略算の公開APIは `Result<BeamDesignResult, String>` を返し、必要な性能・許容値の不正や数値表現不能を理由付きエラーにする。GUIは部材IDを付けて既存の検定全体停止経路へ伝える。

項目ごとの未検定状態と理由を追加する案は、正常な他項目を残せる一方、集計・保存・表示にも部分成立の契約を追加する必要がある。既存の鋼小梁の材料不備は検定全体を停止するため、同じ契約に統一し、不足値を0や適合に置き換えない。

断面せいと断面二次モーメントはGUIの部材力算定前にも検査する。たわみ算定側の補完で不正な性能が0たわみとなる可能性を公開APIの部材力検査だけでは排除できないためである。

## 保存成果への影響

検定契約版を48とし、契約版47以前の成果は入力一致でも再検定まで利用しない。解析契約とモデルスキーマは変更しない。旧成果の検定比0・合否から必要入力の妥当性を復元する移行は行わない。
