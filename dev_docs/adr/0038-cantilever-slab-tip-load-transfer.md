# 片持ちスラブの先端荷重は取付き梁へ力のみ等分布伝達する

Status: accepted

本判断は ADR-0037 の面荷重 `q*d` 伝達を維持したまま、片持ちスラブの先端荷重のみに追加適用する。先端荷重の対象は線取付きかつ取付き線分布の片持ちスラブに限り、先端辺の実長あたりの線荷重を、既存の荷重ケース ID ごとに独立した強度と全体座標の ±X/±Y/±Z 方向で与える。EX を含む任意の既存ケースを対象とし、形状・入力変更に合わせて自動同期するが、手入力荷重は残す。先端荷重は取付き線の支持梁へ力のみ等分布で伝達し、取付き区間を支持梁で覆えない場合はエラーとする。面荷重の既存フォールバックは変更しない。

先端荷重を取付き線だけへ伝達するのは、先端・側辺の支持状況で荷重の行き先を変えず、手入力の荷重と併存させながらケース別の作用を追跡するためである。先端荷重について、側辺・先端辺への分配や、覆えない区間を節点集中荷重で代替する案は採らない。後者は梁の応力を過小評価し得る。

先端荷重による取付き部のモーメントはこのモデルでは伝達しない。利用者が各方向について連続するスラブ等の負担条件を確認することを適用前提とし、条件が成り立たなければ応力を過小評価し得るため、常に安全な伝達規則とはみなさない。点取付きと囲まれた床板は対象外とする。
