# 偏心で実柱面を取れないRC梁端は実材端で検定する

Status: accepted

Related: [#1882](https://github.com/hrntsm/SEPIKA/issues/1882)、[ADR 0162](0162-rc-beam-qd1-slab-reinforcement-source.md)、[ADR 0163](0163-rc-beam-qd1-support-path.md)

## Context

梁の偏心を解析に取り込むと、接続節点を共有していても、偏心後の梁実材軸が接続柱の実側面を横切らない端がある。形状や接合そのものが不明な場合と、偏心による非交差を確認できる場合は異なる。

## Decision

短期地震時の安全確保でQD1を使う単一RC矩形梁は、接続柱への強軸曲げ伝達を確認でき、梁の偏心による非交差を立証できる端に限り、その端の検定位置とQD1の内法の境界を解析部材の実材端にする。この扱いは原典にある明文の置換規定ではなく、#1882でユーザーが明示承認した。

反対端に実柱面を確定できる場合は、そちらを変えない。形状不明、柱の候補間の位置不一致、非有限な形状、偏心前から非交差、梁端の曲げ解放ではこの扱いをしない。保存された実材端の断面力を使い、節点力への置換、最近傍サンプルによる代替、外挿はしない。反対側の実柱面に通常の保存断面行がない場合、同じ位置の実柱面専用の応答と重力参照があれば用いる。時刻歴で実柱面に有効な記録がなければ、その位置は未算定とし、解析の保存内容は変更しない。Q0は荷重の座標を定める実材軸全長と端別反力を引き続き用いる。

## Consequences

短期地震時の通常検定と時刻歴簡易検定に適用する。分割梁、RC柱、終局検定、QD2単独には広げない。実際の有効な内法より長く評価すると、QD1の曲げモーメント由来のせん断力を過小評価する。この条件と結果の解釈を製品文書に記載する。
