# 上下対称H形鋼柱の通常検定は同じ補剛区間全体で照査する

Status: accepted

Related: [#1981](https://github.com/hrntsm/SEPIKA/issues/1981)、[ADR 0132](0132-steel-column-lateral-buckling-end-supports.md)、[ADR 0148](0148-steel-calculation-sources.md)、[ADR 0166](0166-symmetric-column-time-history-lateral-buckling.md)

## 背景

両端と中央の断面力が分かっても、材間荷重による内部最大を捉えられず、許容値も需要も危険側になり得る。逆に、強軸曲げの最大断面だけで軸曲げ検定を済ませると、軸力が変わる柱で組合せの最大を取り違える。

## 判断

通常検定の上下対称H形鋼主架構柱は、確認した一つの補剛区間全体で、同じ線形静的荷重状態の分布と同じ切断面の断面力を照合する。横座屈長さの選択順は変えない。節点間距離を既定値とする場合も、節点位置と実材端の対応がなければ、その長さだけでは曲げ分布を照合する区間を特定できない。既存の実材端支持確認を優先し、中間補剛の自動推定はしない。

式(5.13)〜(5.16)の利用条件は区間の曲げ分布で確認する。非零の絶対値最大が内部で成立すれば、端と同値の内部最大・平坦部も含めて内部最大と扱う。内部が最大でなく符号付き曲げが単調なら符号付き端部比を使う。直接入力のCや既定測点で不足を補わない。非単調で絶対値最大が端にしかない分布には、端部比を使用できる根拠がない。

同じ物理断面・切断側で確認できる不適合と、区間全体に対する適否は分ける。単調分布で、釣合いを確認した保存値と厳密な回復値の端部比が異なる場合には、両方の許容値で同じ断面力を照査する。軸曲げの適否が分かれれば未算定とし、端部比に依存せず確定する不適合は残す。確認できない組合せの全区間適合は表示しない。軸力と強軸曲げを成分別に包絡して組み合わせることもしない。通常の幅厚比、座屈長さと独立の照査は維持し、対象外の断面・分割柱・中間補剛・時刻歴・鋼梁にはこの判断を拡張しない。

## 影響

通常検定の結果契約版を更新する。計算済みの静的解析内力とプロジェクト形式の意味は変更しない。同じ解析入力とケース・組合せに対応する保存内力は通常検定の再実行に使用できる。確認根拠、独立数値例、適用限界は[確認記録](../v_and_v/H形鋼柱の通常補剛区間_Issue1981_検証.md)に示す。
