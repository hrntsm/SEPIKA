# 確認済み断面割当を既存Undoで採用し、判断根拠を固定する

Status: accepted

## 判断

Issue #981の採否は、比較画面が保持した計算と開始時入力・準備後入力・条件・結果を所有する判断記録として検討に保存する。確認時の変位対象・ケース指定・検定集計指定と固定対象も保存する。新しい計算や比較案の再編集で過去の判断を差し替えない。採否・任意理由・適用状態と、現在の本案入力との一致は別々に表示する。

本案一致は編集世代を除き、STB節点の未採番を既存処理で採番し、質量方式を解析設定へ揃え、派生自動荷重だけを除いたモデル全体・検討の全計算設定・受理波形識別を比較する。比較条件一致の許可された断面差の除外は、本案一致へ持ち込まない。長短期の表示区分は、選択中のケース・組合せから既存検定が更新する派生状態なので入力条件の一致照合から除外し、計算時根拠には保持する。荷重ケース・組合せの実定義、その他の解析・検定設定は照合に残す。入力参照の重量入力キーは動的ケース等を除外するため、完全な本案一致の代用にしない。Undoで全入力が戻る場合は採用できる。

断面割当は既存SetElementSectionのCompositeCommandを既存UndoStackの候補検証へ渡す。採用コマンドは全割当の前後一致を照合し、一部のNoopを成功にしない。構造計算の検証規則は追加しない。Undo上の一操作へ確定通知を付け、採用記録に共有した適用状態だけを更新する。候補計算中には通知しない。別の編集履歴は作らず、Undo/Redoの順序と再適用内容は既存スタックが所有する。通知先の適用状態は保存時に値へ固定し、過去セッションのUndoは保存しない。

本案の検定設定も既存のanalysis_settings.msgpackへ保持し、結果の失効判定より前に復元する。検討の基準案だけに非既定設定を保存すると、保存再読込で本案だけ既定へ戻り基準相違になるためである。

結果を除外した保存でも、検討を持つ本案の立体・質点系の動的ケース定義は保持し、読込後の孤立ケース除去を行わない。ケース定義を除去すると、保存だけで基準との入力一致が失われるためである。結果の復元と有効性は既存規則のままとし、定義保持を計算成功と扱わない。検討を持たない保存の孤立ケース整理は本Issueの採用条件に関係しないため変更しない。

本案結果は既存の編集後失効規則を使い、比較計算の結果を移植しない。採用はNG・未検定・未対応の解消を意味しない。

## 理由と代替案

世代だけで本案一致を判定するとUndo後の完全復帰を拒否する。許可断面差を除外すると、本案ですでに変更された割当を基準一致と誤認する。モデル同値だけで採用の取消を推定すると、通常編集による同値復帰とUndo取消を区別できない。全モデル置換と第二履歴は、通常編集・検証・Undoから分岐するため採らない。
