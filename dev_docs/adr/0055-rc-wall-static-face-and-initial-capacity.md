# ADR 0055: RC壁の同一face内力とrun初期耐力を分離する

## Status

accepted

## Context

仮想壁柱の軸・曲げ断面は中央壁板だけを表す一方、面内せん断性能は側柱込みである。側柱の全成分を一律加算したり、別位置の最大Nと最大Mを選んだりすると、同じ切断面の壁全体内力にならない。

解析後の参考骨格に用いる同一静的状態と、非線形要素を生成する前の初期耐力には異なる入力が必要である。保存静的結果の選択やrun中の履歴再構築に依存させると、解析開始条件と採用耐力の生成元が曖昧になる。

## Decision

解析後の参考骨格には、既存の入力一致検査を通したcase/comboの全結果バッチと同じ展開済みModelを渡す。内部の限定読取りで成分所有・局所符号・端順を正規化し、形状から一意に解決した共通壁脚faceに中央と左右側柱を揃える。中央Q、中央Mと側柱軸力腕長、中央と側柱Nをそれぞれ合成し、物理断面積と解析軸断面積を区別する。公開状態APIや汎用registryは追加しない。

初期Quは同じrunの展開済み入力から、既存長期集合Gと壁方向の正負Ai荷重を求解前に合成して直接静的求解する。active-set応答の事後重ね合わせと負号反転による代用を採らない。必要な全壁・全局所分岐の有限正Quを解決してから非線形要素へ渡す。未解決値の弾性fallbackを設けない。

参照結果はrun内のパラメータ計算だけに使い、静的結果台帳・非線形状態・履歴へ移植しない。既存長期載荷を一回行い、Quはrun中固定する。既存run結果に採用Quを保持し、Dsとモデル化表示は入力一致を確認したその値を使う。表示のために求解しない。計算契約版を更新し、旧結果を互換補完しない。

## Consequences

同一平面・単独無開口・対称同質の既存対応Beam側柱・成立した面内解放・共通faceを確認できる限定域でのみ成功する。#496の側柱役割・解放拡張と#572の方式選択は本判断へ取り込まない。参照荷重の規約は[製品の計算根拠](../../docs/calc_basis/08_部材終局耐力/08_RC壁の壁脚内力と初期耐力.md)を正本とする。

壁方向ごとの正負直接求解には追加計算が必要となる。初期耐力の参照状態は実動的状態や非線形長期載荷後Nとの完全一致を保証せず、実験Validationは別途必要である。限定域外や入力不足は対象ID・理由を伴う未算定または開始拒否となる。
