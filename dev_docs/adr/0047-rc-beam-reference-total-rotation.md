# RC梁の基準骨格と追加端回転を分離する

- Status: accepted
- Issue: #523

## 判断

採用αy式の総部材角は、一定せん断・三角形モーメントの基準分布を用いる。
実factoryへの接続は、部材属性で逆対称・同一半部材の基準を明示した矩形RC梁に限定する。
未指定を既定とし、保存済みモデルへ暗黙に適用しない。基準の選択は実応力分布の適合確認ではない。
実行する解析種別の履歴則と有効な部材荷重で適否を診断する。

初期強軸剛性はコンクリート幾何Iによる S=6EcI/L とし、この基準では独立せん断柔性を加算しない。
一般BeamElementのせん断剛性、弱軸、軸、他の骨格の仕様は維持する。
Takeda、Retrograde、MaxPointOrientedの総角履歴へ θtotal=θadditional+M/S を課し、弾性梁と接続する。
初期追加柔性0、αy=1、零tangentのplateauを有限な行列で扱い、penaltyや無限大へ置換しない。

## 理由と帰結

M/Qを持たない入力からL/2を自動推定すると、一般分布を同じ基準へ誤適用する。
総角をそのまま弾性梁へ直列接続すると、弾性回転を二重加算する。
永続する明示基準と総角からの厳密控除は、この二つを分離するため必要である。
OriginOrientedは初期基準剛性と一致しないため理由付き未対応とする。
任意分布、非同一半部材、T形の正負骨格接続、実験Validationは対象外とする。
