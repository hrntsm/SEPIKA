# 標準配筋の元入力と解析用配筋を分離する

Status: proposed

ST-Bridge 2.0.2の梁・柱配筋コンテナ、posごとの子要素、Apply条件は、属性の明示と省略を保持する。副主筋を主筋の2段目へ変換せず、腹筋・巾止筋・軸筋とそれぞれのD/strengthを区別する。強度はADR-0051のresolverを再利用する。

既存Rc*形状は解析の消費型であり、元入力の正本として使わない。標準から写像できないpos、寄せ配置、適用された追加役割、位置・間隔は元入力を保存したまま理由付きで計算を拒否する。未使用断面の未対応配筋は架構解析ゲートに含めず、部材検定はその部材の断面だけを検査する。架構配筋を消費しない直接床板設計へゲートを広げない。RC/SRC接合部・PCa水平接合面・耐震壁側柱も、実消費する断面に限って同じ診断を検査し、理由付き検定不能を返す。

形状編集は旧元配筋と役割別強度指定を解除し、native入力へ移す。Undoは形状と元入力を一緒に復元する。コマンドを経由しない変更は元入力から作った形状の記録との不一致を出力・計算境界で検出する。

native配筋は現幾何が使う主筋中心を標準center属性で出す。Apply条件を明示し、省略されていた同系列の原位置属性を新たに有効化する混在は出力を拒否する。必須値の0補完や標準段数を超えた切捨ては行わない。

最新正本は原標準構造を正本とし、解決できる範囲だけを座標・段・役割・材質の鉄筋集合へ写像する。標準Xは左右の垂直列、Yは上下の水平列として既存Rc配筋へ対応させる。総本数の矛盾検査は確認済み共有位相に限定し、未証明の一般式で別の有効標準入力を拒否しない。位置・位相未解決なら保存して計算を拒否する。一般RC幾何エンジンやXML未記録の軸筋座標は本件の必須実装ではなく、未解決位置を0座標やNONE配置で埋めない。
