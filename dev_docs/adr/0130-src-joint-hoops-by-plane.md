# SRC接合部帯筋を節点と構面ごとに登録する

Status: accepted

SRC接合部帯筋は、節点、検討構面の正向き水平軸、全接続柱IDの集合、構面内の梁IDの集合を照合して採用する。短期せん断検定が接続部材全体を対象とするため、柱集合にはSRC柱と同じ節点に接続する他の構造種別の主架構柱も含める。部材に設定した帯筋を接合部に適用すると、接合部の実際と異なる配筋・材料が検定に渡る。節点だけを識別子にすると直交構面間の違いを保持できず、軸だけを追加しても接続梁が入れ替わった後に同じ方向で自動的に適用される。登録後に対象梁または接続柱が削除された場合は、同じ位置に再び部材を接続しても再登録を要する。現在の構面軸と柱・梁の集合が登録時と異なる間は準備値を返さず、現構面での再登録を求める。登録部材を残したまま登録時と同じ構面へ戻したときは登録が対応する。節点・部材IDの再採番には編集の参照更新を使う。

短期検定に必要な値は、有効脚本数・標準呼び径・間隔・対象幅・材種を設計者が確定した場合に限り準備する。材種は異形棒鋼の規準表値を特定するために直接登録し、任意の材料名や降伏点による置換を避ける。接合部の実配筋と規準の適用条件は入力値だけで確定しないため、帯筋入力の準備と耐力検定を分離する。

[仕口パネル解析要素と柱梁接合部の断面算定](0024-separate-panel-element-and-joint-check.md)の区別を維持する。帯筋入力の構面は既存の接合部構面分類に従う。

GUIで編集中またはMCPで参照した構面は、編集が挟まると同じ節点ID・軸でも接続する柱・梁が別になることがある。GUIでは編集開始時のリビジョンを照合する。MCPではサーバ起動を識別するUUIDと照会時のリビジョンを一つの照会証跡で照合する。数値のリビジョンは再起動後に再利用されるため、起動の識別を含めて古い構面の指定を拒否する。MCPの登録・更新・解除では照合と適用を同じロック内で行い、証跡が不一致なら構面の再確認を求める。

## 短期検定への接続

#1426 の短期分岐で、接合部節点・既存の主架構隣接関係・検討中の構面軸を共通入力入口 `resolve_src_short_term_joint_hoops(model, adjacency, node, plane.axis)` に渡す。失敗理由はその構面の未算定理由へ引き継ぐ。成功値の帯筋比・許容引張応力度は、短期耐力式の適用条件を確認した上で受け渡す。短期検定を有効にする変更では、生成元の検定入力照合に帯筋指定も含める。
