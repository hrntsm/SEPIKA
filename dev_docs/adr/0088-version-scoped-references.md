# 対象参照を入力版内で照合し、計算開始時の案版を保存する

Status: accepted

## 判断

[#974](https://github.com/hrntsm/SEPIKA/issues/974)では、[ADR0087](0087-gui-owned-study-and-local-ai.md)の所有・保存境界を変更せず、対象参照の解決範囲を同一プロジェクト・案・入力版内に限定する。整数IDに入力版内の存続トークンを添え、版をまたぐ存続の推定や固定対象へのID再配置を行わない。現在選択の既存ID再配置は維持する。

編集版には保存世代を基点とする既存UndoStackの単調revisionを用いる。個々のGUI編集入口へカウンタ更新を追加すると、表等の直接Undo経路で更新漏れが生じるためである。直接変更も入力識別で検出する。入力識別では既存の重量依存入力正規化を再利用し、その正規化が除外する案入力（通り・数量・組合せ・名称等）を補う。派生重量・自動荷重の再生成を人の編集世代へ加算しない。 準備計算が既存Undo履歴へ積んだrunのうち、正規化した明示入力が前後で同じものだけ、実際のrevision増分を参照世代から控除する。UndoStack本体のrevisionは変えず、人がUndo/Redoした増分は控除しない。解析設定のGUI編集はブロックごとのdraftから共通commit入口へ確定し、変更時に保存世代を進める。同フレームの計算要求より先に確定し、設定A→B→Aでも旧版を再使用しない。

補完対象は通り・数量・組合せ・取込節点識別と、断面・材料・階・原階・床領域・壁領域・所属および未割当の二次部材の名称とする。階の重量手入力等は正規化元に含まれ、生成所属・自動剛域・自動荷重・派生質量は含めない。全解析設定と、案が現在受理している立体・質点系の元波形識別も入力版へ含める。元波形識別は受理前の実波形列と時間刻みから得る。立体は全方向成分を含め、実効条件で不使用になる成分も省かない。質点系は解析へ渡す前の入力列と入力時間刻みを含める。異波形・異設定なら一般部材や節点の参照も一致させない。振動ケースの保存レコードは成功時に生成される成果でもあるため入力版とは分離し、対象トークンへ当該レコード自体の識別を加える。

波形識別は既存の前提・起動拒否検査を通った受理時に確定し、変わる場合だけ保存世代を進める。A→B→Aでも旧版を再使用せず、同じ波形の再実行は入力版を維持してrunだけ更新する。受理前拒否では識別を変更せず、受理後の計算失敗では受理した入力を保持する。非同期の開始版は受理確定後に固定する。成功時のケースupsertでは識別を変更しない。受理済み元波形の小識別は結果を除外して保存する場合も残し、設定・質量方式・識別を復元してから保存入力との一致を照合する。未準備の質量方式は保存候補モデルだけへ同期して保存し、読込時のモデル正本同期で設定を巻き戻さない。旧質量設定の派生成果は同梱せず、編集中モデルとUndoは変更しない。

荷重ケースには、明示・自動作成・明示ケースへの種別自動適用（元種別付き）の小さい保存属性を持たせる。名前や手入力荷重の有無だけでは明示の空ケースと自動ケースを区別できないためである。参照キーでは自動ケースを除き、元の明示種別へ戻したモデルを重量入力正規化と定義補完の両方へ渡す。利用者の定義編集・手入力荷重追加で明示入力へ昇格し、最後の荷重を削除しても昇格を保持する。Undoでは由来も復元する。自動属性と手入力荷重が矛盾する場合も、手入力を参照識別から除去しない。

仕口パネルは既存生成器が全要素・全接続offsetを再生成する派生情報として、参照用cloneで既存の除去処理を使う。手入力剛域とモデル化設定は保持する。未採番STB節点IDも既存採番処理で正規化し、明示非既定ID/GUIDは保持する。質量方式は準備時にモデルへ反映される解析設定へ揃える。物理部材の保存ID列は別に含め、パネル除去に伴う実ID再配置を同一入力版に読み替えない。これらの参照正規化は実モデル・Undo・計算式を変更しない。

結果の実行IDと開始時の案・入力版を既存生成入力記録に併置する。非同期ジョブでは開始時に案版を固定し、完了時の案版で補完しない。解析非依存編集で計算上有効な結果も、生成時の案版は変えない。計算式・有効性照合は既存経路を使う。

## 代替案と影響

全対象へ永続GUIDを追加して編集間の同一性を追跡する方式は採らない。現在の要件は古い入力版の明示拒否であり、削除のUndoを含む対象の完全履歴を導入する必要がないためである。案間の対応や検討本体の保存は[#979](https://github.com/hrntsm/SEPIKA/issues/979)で明示対応を接続する。

参照の最小保存情報は既存の解析設定保存ラッパーへ含める。保存対象の入力が変わった場合は同じ版として復元しない。接続・実行許可は参照保存情報に含めない。旧成果に案版・開始入力がなければ取得不能とし、現在入力を代用品にしない。
