# 梁の実配置を基準材軸・解析接続から分離する

Status: accepted

## Context

梁と床板の上下関係には実材軸と実断面が必要だが、既存の支持探索と解析は共有節点・支持アンカーを基準にする。共有節点の移動や支持先の再探索は、接続先・自由度・荷重伝達を変えてしまう。SL は階の代表節点を生成する基準であり、既存梁の基準位置と一致するとは限らない。

## Decision

大梁と小梁に一つの任意値として一律鉛直偏心を保存し、未指定と明示0を区別する。STB取込みで偏心を補完せず、旧形式の移行を行わない。新規GUI作成は明示0を設定する。

既存の節点・支持アンカー解決を基準位置Nとして維持し、実配置Pを別の共通APIで導出する。実配置はキャッシュせず、断面・基準位置・偏心から都度解決する。後続の偏心接続は部材識別・各端のN/P対応を参照できる。

上下端と水平幅には既存SectionGeometryの優先順位付き材料領域を有限長に押し出した実形状との交点を使う。局所断面上端の鉛直投影や幅・せいの半分への置換は採らない。表示の形状モードは実配置、解析結果の図は解析配置を使う。

## Consequences

実配置の不足・不正は配置を消費する経路で対象と理由付きのエラーとなる。入力編集は既存の計算入力識別・陳腐化経路へ含めるが、本変更だけでは解析剛性変換を適用しない。
重量算定と偏心接続解析は同じ配置情報を利用でき、階レベルや偏心を独自に再解釈する必要がない。

後続[ADR 0076](0076-beam-eccentric-connection.md)で、実配置と共有解析節点の分離を維持したまま偏心接続解析を追加した。本ADR時点の「解析剛性変換を適用しない」は追加前の責務境界を表す。
