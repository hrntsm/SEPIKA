# 長期軸力重心には柱頭の層側断面の材軸圧縮力を使う

Status: accepted

柱頭のSL接続節点の平面位置を、同じ高さで対象層に入った直後の最上部材の材軸圧縮力で重み付けする。[ADR 0133](0133-column-horizontal-force-section.md) と同じ切断位置と端点荷重の帰属を使う。荷重ケース・組合せに両端直内側の材軸力を保持し、必要な応答又は切断位置が不明な柱を含む場合は偏心率を保留する。保存した旧解析成果は解析契約版95で失効させる。

『2025年版 建築物の構造関係技術基準解説書』第2版第1刷 6.2.3(3) p.359 式(6.2-2)は、地震層せん断力の合力点に対して、長期荷重による鉛直支持部材の軸力と部材位置を用いる略算を示す。材端の指定や傾斜柱の鉛直投影は規定していない。柱頭座標を使う既存の略算に対して、端の宣言順で軸力の位置を変えると同じ架構の偏心率が変わる。柱頭位置に対応する層側の力を使い、傾斜柱も既存略算と同じ材軸成分を用いる。せん断力を含む全体鉛直負担への変更では重みの定義が変わり、偏心率への影響は荷重と剛心の配置に依存する。

汎用の断面力には集中荷重位置でi側の極限を採る契約がある。上端がi端に指定された場合も層側の力を得られるよう、荷重込みの端直内側の応答を用いる。長期軸力の応答を水平力と独立に保持し、軸力だけで重心を求める際に水平応答の有無に依存させない。
