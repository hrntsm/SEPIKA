# 方向間連成層の剛心とねじり剛性を剛床応答から求める

Status: accepted

単層の上端が一つの剛床を持ち、下端の面内移動・回転が拘束され、地震静的解析と同じ線形弾性系の独立した3成分の荷重応答を求められる場合は、剛床の純ねじり時に変位が0となる点と、モーメントを回転角で除した値を剛心・ねじり剛性とする。X・Yの応答と純ねじり応答を重ね合わせて回転を除き、剛心での並進剛性の両対角項と非対角項を求める。

地震静的と同じ壁展開済みモデルで構成した線形剛性の因子分解を共有し、層の評価結果を地震静的結果とともに保存する。地震荷重によって剛床が回転する応答や、柱1本ずつの同方向の水平力と変位の比からは剛心・ねじり剛性に寄与する力とモーメントを分離できない。X・Yの荷重をそれぞれ別の活動状態で解くと同じ柔性行列の列にならない。外付けの自立壁の付加剛性を含む系と独立な3自由度を確定できない連成候補も算定を保留する。

方向間連成がある場合、直交変位を拘束して求める弾力半径と、直交外力を0にして求める弾力半径は異なる。『2025年版 建築物の構造関係技術基準解説書』第2版第1刷 6.2.3 pp.359–362 に剛心・ねじり剛性の定義を照合した。p.362 (5) は斜め構面を含む架構について直交方向の応力への留意を求める一方、弾力半径の採用条件は指定していない。ここでは一般の連成層のRe・Fes・必要保有水平耐力の数値化を保留する。3次元質点系のX/Y独立ばねも連成を表せないため、等価せん断型・等価曲げせん断型の生成を保留する。[設計用評価条件の調査 #1685](https://github.com/hrntsm/SEPIKA/issues/1685)

層の非対角項が相殺されても、部材の位置によって回転モーメントが残り得る。この場合も剛床応答による剛心・ねじり剛性を用いる。材料非線形化後に相殺を維持できる根拠がないため、3次元非線形質点系の生成を保留する。各位置の方向別剛性が独立で、回転時のねじりモーメントを水平力と腕の積で集計できる直交構面には既存の方向別評価を用いる。その経路におけるねじれによる層間変位の相殺は [ADR 0135](0135-torsional-cancellation-holds-column-stiffness.md) に従う。

剛床の層応答は架構全体の応答であり、柱に分離した方向別剛性を与えない。これを用いる線形等価せん断型は層せん断力と層間変位を用いる方式に限り、柱 ki を指定した場合は生成を保留する。

片方向に傾く部材では、層のX/Y並進剛性が対角でも、剛床の回転が部材の曲げ回転となり得る。対象層の応答を同定できる場合は剛床の定義による結果を採用する。

地震静的結果の収録内容と3次元質点系の適用条件が変わるため、解析契約版を94に更新する。
