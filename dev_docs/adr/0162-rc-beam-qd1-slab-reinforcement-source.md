# RC梁のQD1に用いるスラブ筋は床版の実配筋から判定する

Status: accepted

Related: [#1882](https://github.com/hrntsm/SEPIKA/issues/1882)

## Context

床版の取付きだけでは、RC梁端の降伏曲げに寄与するスラブ筋を特定できない。寄与を確認できないままゼロと扱うと、梁の設計用せん断力QD1を過小評価しうる。

## Decision

梁端ごとに設計者が有効筋を選別した結果や降伏曲げモーメントを入力する方式ではなく、床版の実配筋・定着・連続性をモデル上の根拠とし、SEPIKAが梁端・曲げ方向ごとにスラブ筋の有効性を判定する方式を採用する。

自動判定の初回適用は、ハンチのないRC矩形梁と、梁に平行な上端筋を持つ一体打ち床版に限定する。梁端で筋の位置・定着・連続性を確認できない場合や、開口・分割の影響を確認できない場合は、スラブ筋の寄与を算入せず、梁本体の配筋からQD1を算定する。これは有効なスラブ筋が存在しないことを確認した場合とは区別する。

スラブ筋の有効性の判定と、それを算入する梁端の降伏曲げの算定は、指定原典からRC梁のQD1への適用根拠を確認できる方法・条件に限る。別の目的で示された協力幅や断面算定式を、適用根拠を確認せず転用しない。有効筋を特定できても算定式の適用根拠を確認できない場合は、その式による自動算入を行わない。

梁本体だけで算定したQD1でもRC梁のせん断に対する断面検定を行い、検定条件を満たす場合はOKと判定する。結果にはスラブ筋の寄与が未確認で算入していないことと、設計用せん断力を過小評価しうることを示す。設計後に現場で開口が設けられて配筋の連続性が変わる場合があり、設計実務ではスラブ筋を見込まない前提で設計する場合もある、という判断に基づく。

## Consequences

端部ごとの確認値を入力する方式よりもモデルで保持する情報は増えるが、同じ配筋・定着条件を端部ごとに重複して入力せず、どの入力を根拠に筋を採用したか追跡できる。寄与を確認できない場合はQD1を未算定とする現行方式から変更する。実際に有効なスラブ筋が梁端の降伏曲げを増やす場合は、スラブ筋を算入しないQD1が設計用せん断力を過小評価し、断面検定にNGとなる条件をOKと判定しうる。この条件を了承した上で梁本体だけの断面検定を認める。実装時は、製品文書にこの条件と利用上の注意を明記し、検証結果と適用限界をV&Vに記録する。
