# S造・SRC造の算定根拠を指定の5資料にそろえる

- Status: accepted
- Date: 2026-11-23

S造・SRC造の算定式と適用条件を確認できる資料にそろえるため、技術的根拠は『2025年版 建築物の構造関係技術基準解説書』と、日本建築学会の『鋼構造許容応力度設計規準』『鋼構造塑性設計指針』『鋼構造接合部設計指針』『鉄骨鉄筋コンクリート構造計算規準・同解説 許容応力度設計と保有水平耐力』に限る。『鋼構造設計規準』1973年版を含む他資料を根拠とする現行方式は、指定資料で式と適用条件を確認できる方式に置き換える。指定資料で根拠を確認できない機能は廃止対象とする。

従来は異なる版に基づく許容応力度や適用条件が同じ検定に混在しており、旧版を選択できる公開APIもあった。算定結果を指定資料から追跡できるよう、機能の維持や旧版の選択肢より、採用方式と構造種別ごとの適用条件を原典で確認できることを優先する。

CFT固有の算定方式は、詳細な検定を照合できる原典がそろうまで今回の見直し対象から外す。S造・SRC造の変更が鋼材、仕口パネルなどの共通処理を通じてCFTに及ぼす影響は確認し、結果・適用条件・診断が変わる場合は変更に含めて検証する。

共通の解析要素・数値解法・履歴則は維持する。断面検定、終局耐力、部材種別、鋼材強度に加え、共通モデルに渡すS造・SRC造固有の耐力や剛性補正は指定原典と照合する。設計用の耐力や係数の根拠をそろえながら、非線形解析で利用できる共通モデルを維持するためである。

指定原典の範囲を超える方式は、計算経路、選択肢、専用の結果表示を廃止する。廃止した検定を未算定項目として残すと、SEPIKAが引き続きその検定に対応しているか判別しにくくなる。旧データの扱いは[スキーマ互換方針](0014-schema-compatibility.md)に従う。

鋼大梁とRC床板の合成剛性を求める旧平均法は廃止する。指定原典で現行の平均係数や協力幅の適用を裏付けられず、合成を明示確認する方式でもその計算上の根拠は補えない。この判断は[ADR 0116](0116-steel-girder-slab-composite-applicability.md)を置き換える。

純鋼板を耐震要素として扱う機能は、先に廃止した非線形解析に加え、線形解析からも廃止する。線形解析だけを残しても、指定原典で適用条件を確認できない壁の剛性が架構の応答に入るためである。外装などの鋼板の重量は既存の荷重入力で扱う。旧モデル向けの移行や互換処理は設けない。

SRC規準第6版第3刷の25条（pp.28–33）と38条2項（p.41）は、鋼板を内蔵するSRC壁部材の許容耐力と終局せん断耐力を扱う。式(38.2)は内蔵鋼板と鉄筋コンクリートの負担分を評価するため、純鋼板壁への適用根拠には用いない。SRC壁の内蔵鋼板は廃止の対象外とし、実装の対象範囲は [ADR 0149](0149-src-shear-wall-scope.md) に定める。

S造仕口パネルの弾塑性解析は対象に含める。『鋼構造接合部設計指針』5.1・5.2が示す弾性剛性と全塑性耐力を用いる。短期検定に用いる降伏耐力は別に求める。骨格曲線の既定はユーザー指定のバイリニアで、全塑性耐力に達した後の勾配は初期剛性の1/100とする。二次勾配はSEPIKAが採用するモデル化の仮定で、原典の耐力・剛性とは根拠を区別する。軸力比の評価には上下柱のパネル側軸力を用い、柱1本の変位から推定して補わない。

S造線材のせん断降伏は、設計上の判断に使えるよう増分解析で到達を記録する。増分解析で用いるせん断力とせん断変形の関係は、ユーザーの選択により、降伏後の勾配を初期せん断剛性の1/100とする。この値は降伏後の変形と応力の再配分に影響するSEPIKAのモデル化の仮定である。今回の変更は増分解析に限る。

角形鋼管では、二方向のせん断力による応力を板ごとに断面の釣合いから評価し、断面内で最初にせん断降伏応力度に達した点を、設計用の記録と勾配の切替に共用する。『鋼構造塑性設計指針』第4版3.6の式(3.6.1)は、せん断力による全塑性モーメントへの影響を省略できる限界を示す。薄肉・等厚の正方形鋼管を一方向に加力した比較では、初降伏はその公称限界の8/9に当たる。勾配の低下は降伏した箇所の応力を増やす方向に適用し、その箇所の応力を変えない方向の剛性を保つ。局部の初降伏を線材モデルの切替点とするため、切替後の変形と応力の再配分はこの仮定に依存する。

S造の増分解析では、せん断ばねの降伏条件と塑性状態を軸曲げ側から独立させる。角形鋼管の二方向せん断は、せん断ばねの内部で各板への重なりを評価する。垂直応力とせん断応力の組合せについては、同指針3.6解説の式(C3.6.2)が材料点の降伏条件を示す。この条件で生じる塑性化を解析応答に反映するには軸曲げとせん断を連成する構成則が必要であり、今回採用する独立ばねの適用範囲を定める理由となる。

線材のせん断復元力はファイバーと材端集中ばねの双方で使い、S造・RC造で解析への組み込み方を共通にする。耐力、降伏後の勾配、履歴は構造種別の根拠に従って定める。RC造の原典の範囲は[ADR 0147](0147-rc-calculation-sources.md)による。

RC梁・柱は、RC規準第10版（2024年）の付2「構造設計例」p.437に従い、せん断ばねの骨格にバイリニアを採用する。終局せん断耐力に達した後の勾配は、ユーザーの選択により初期せん断剛性の1/100とする。二次勾配は解析上の仮定である。設計上は終局せん断耐力への到達を記録し、二次勾配によって増加するせん断力を耐力に算入しない。

RC柱の終局せん断耐力は、増分解析の各試行状態における軸力で更新する。軸力は耐力式に使い、せん断ばねの塑性履歴は軸曲げと独立に保持する。到達は確定ステップの耐力とせん断力に基づいて記録し、引張域など耐力式の適用条件を外れたときは対象部材とステップを診断する。

RC梁・柱の終局せん断耐力に到達した系の増分解析では、到達後の応答を参考表示に使う。保有水平耐力の評価には、到達直前までの確定ステップを採用し、到達点そのものを確定した場合はその点まで採用できる。二次勾配による部材せん断力の増分を、架構全体の保有水平耐力に含めないためである。

ユーザーの明示指示により、S造・SRC造の対象部材の座屈長さは両端節点間距離を基準とし、柱は1.2倍、梁・ブレースは1.0倍を既定値とする。軸別の指定値を優先する。既定係数は入力省略時の近似であり、支持条件による座屈長さが既定値を超える場合は許容圧縮応力度を過大評価し得る。[独立釣合いの確認例](../v_and_v/鉄骨柱K_独立釣合いと適用条件の確認記録.md)では、理想ピン柱脚を持つ1層1スパン架構で係数2.327877を得ている。利用上の条件は[座屈長さの製品文書](../../docs/calc_basis/06_一次設計/03_06_鋼部材の座屈長さ_有効細長比.md)に示す。

ユーザーの明示指示により、横座屈長さにも入力省略時の既定値を設け、両端節点間距離の1.0倍とする。各部材で利用できる直接入力、明示横補剛、確認済みの実材端支持を優先する。圧縮フランジの有効支点間距離が節点間距離より長い場合、既定値は許容曲げ応力度を過大評価し得る。設定がない場合に未算定としていた[ADR 0132](0132-steel-column-lateral-buckling-end-supports.md)の判断を置き換える。
