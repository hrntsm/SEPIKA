# RCの算定根拠を技術基準解説書とRC規準にそろえる

- Status: accepted
- Date: 2026-11-22

RCの実装には旧版規準、公開改定案、個別の指針・研究資料を参照した方式が混在していた。算定式と適用条件を同じ版から追跡できるよう、RCの技術的根拠は『2025年版 建築物の構造関係技術基準解説書』第2版第1刷と、日本建築学会『鉄筋コンクリート構造計算規準・同解説』第10版（2024）にそろえる。法令・告示は条項を特定し、同解説書の掲載箇所を併記する。

指定原典から裏付けられない算定方式は、適用範囲の是正・代替・廃止の対象とする。方式の変更は検定の可否、解析応答、既定値、保存データに影響し得るため、先に参照を棚卸しし、依存先を確認してから実装と製品文書をそろえて更新する。安全性に関する未確認事項と従来の検証記録は保持する。

ファイバー要素、既存の履歴則、材料に依存しない数値解法は維持する。それらと組み合わせるRC固有の耐力式・骨格曲線・単調載荷の材料包絡線はそれぞれ照合する。RC壁の終局時せん断剛性低下率では、RC規準の引用元を設計判断時に確認した結果に基づき、壁筋比に実壁厚基準の横筋比を用いる。確認状態と追跡先は[RC計算根拠の棚卸し](../v_and_v/RC計算根拠の棚卸し.md)に記録する。

RC梁・柱の終局検定のせん断耐力は、技術基準解説書の荒川mean式を採用する。矩形の普通コンクリート部材の確定内力と配筋が必要で、引張を受ける柱や断面力範囲を確認できない場合は未算定とする。大地震時の付着はRC規準16条の設計用付着応力度を許容値と比較する独立の照査とし、配筋区分や付着長さなどが確認できる場合に限り算定する。従来方式の結果は再利用せず、計算契約版を更新する。

終局せん断検定のためだけに、採用した確定ステップの危険断面フェース間で確認した内力を記録する。判定用のフェース位置と剛域の可撓端は一致するとは限らず、曲げの最大値が変わるため、既存の可撓端応答を流用しない。柱では軸別に照査し、原典で根拠を特定できない二軸せん断の相互作用式を採用しない。終局せん断は再表示時に計算するため、既存保存応答の他用途と通常検定の結果は失効させない。必要な内力の記録がない場合は終局せん断だけを未算定とする。

大地震時の付着では、割裂の基準強度をモデルのコンクリート強度・種別と打込み時の鉄筋区分から、補強効果を想定割裂面で確認した配筋寸法から求める。主筋の規格値は材種の照合に用い、応力度照査には実降伏強度または強度上昇を考慮した確認済みの降伏応力度を用いる。部材の曲げやせん断を算定できない場合でも、確認できた付着応力度と必要延長の判定を保持する。

RC梁の集中ばねに用いる降伏時剛性低下率の式は、技術基準解説書の短スパン式を a/D が1.0以上2.0未満、基本式を2.0以上5.0以下で選ぶ。境界の2.0は同書の梁試験体の検証区分に従う。

RC梁の集中ばねでは「逆対称・同一半部材（軸力なし）」を明示指定し、骨格の軸力比を0とする。現行の固定骨格に、長期軸力を地震時の軸力として代入する近似や、軸力に応じて履歴中に骨格を更新する方式は採用しない。矩形梁の降伏モーメントにはRC規準8条解説(解8.20)を軸力ゼロで適用し、引張・圧縮鉄筋の重心間距離を用いる。両方のスパン区分で同じ引張鉄筋比の適用条件を確認する。USD685系など、原典から当該略算の適用を確認できない主筋強度は未算定とする。降伏時の剛性と同じ骨格を成立させるため、ひび割れ点の断面係数には鉄筋を考慮する。旧基準には軸力の明示がないため、再指定を求める。
