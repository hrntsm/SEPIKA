# 小梁のボルト条件を断面符号名で共有し、部分検定と総合判定を分ける

Status: accepted

## 判断

Issue #1048の2026-11-02合意に基づき、小梁端部の高力ボルト接合条件をモデル内の断面符号名に対応する一つの設定として保存する。同じ符号でも階別の断面が別IDで存在するため、断面IDへ条件を持たせる案では「同符号の全小梁に同じ本数」を保証できない。断面寸法で共有すると、異符号を別設定にする要求を満たせない。部材や端部の上書きは設けず、検定時に採用断面の符号から参照する。

本数倍の摩擦接合許容値を使える条件を利用者が確認する。確認不足を既定の適用可へ読み替えない。片持ち支持端はせん断成分を参考値として保持し、対象外の曲げ伝達を含む総合適合へ引き上げない。未設定・非対応・条件不足も曲げとたわみの算定済み結果を残して、理由付き未検定とする。

F10Tは法令の軸断面に対する長期許容式、溶融亜鉛めっきF8Tは対応する公開長期表を採る。すべり係数や丸めが異なるため、両者を同じ強度比だけで換算しない。採用式・条件と入力の正本は[製品文書](../../docs/calc_basis/06_一次設計/05_小梁・床の断面検定.md#小梁端部の高力ボルトによるせん断伝達)。

## 保存成果

せん断を含まなかった検定成果を再利用しないよう検定計算契約版を47へ更新し、解析67は維持する。版間移行はADR0014に従う。独立照合と操作経路の確認範囲は[検証記録](../v_and_v/小梁高力ボルト_Issue1048_確認記録.md)に残す。
