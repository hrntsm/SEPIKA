# 仕口パネルの梁端接合面を既存入力から一意に解決する

Status: accepted

## 判断

仕口パネルの梁端オフセットは、下側優先で採用した柱の実断面・向きと梁材軸から求める実接合面までの材軸上距離とする。入力から採用面が一意に決まる接合だけを扱い、接合詳細の新入力は追加しない。H形柱の外フランジ広面の内部へ交わる梁、角形鋼管の真の外周、円形鋼管の外円筒面を解決する。角R未知の角形鋼管は全許容Rで交点距離が不変の場合だけ解決する。

H形柱の弱軸側、フランジ端の境界・端面やウェブ側の採用面は既存の入力から特定できない。対象柱・梁・接合部と理由を示して、当該面距離に依存する準備計算・解析を停止する。H弱軸の抵抗板モデルを持つことから、梁の接合位置まで自動確定できるとは解釈しない。

製品の具体的な寸法・式・適用条件は[部材端の接合面とオフセット](../../docs/calc_basis/04_要素剛性/06_パネルゾーン.md#部材端の接合面とオフセット)を正とする。

## 理由と選ばない方式

方向を無視した柱最大せいは非正方柱や断面回転に対応せず、有効材長・剛性・内力・荷重・反力を変える。外接矩形・最小距離・平均・0による推測は安全側と判断できない。H形の空隙側では、単なる材軸と鋼領域の交点をパネルの採用面と同一視すると、ウェブ接合など入力のない接合詳細を仮定してしまう。

斜交でも実面と距離が一意な対象があるため、一律に斜交を拒否しない。既存の断面実領域の交点算定を再利用し、丸角を直角の矩形へ置き換えない。柱が傾斜する場合も射影方向を単位化せず、元の梁材軸上の距離を保持する。パネル式の物理的な適用範囲の拡張とは分ける。

## 部材荷重の仕事共役

剛性と部材端回転の結合係数を荷重変換にも共有し、等価部材節点荷重を同じ変換の転置で追加せん断自由度へ写す。通常弾性梁の非所有荷重経路と、要素自身が荷重残差を返す所有経路を区別し、後者へ再加算しない。反力を回収するときの元の物理節点荷重12成分は保持する。

物理節点の反力が釣り合うだけでは、追加自由度の荷重項と仕事の整合を保証しない。#759の公開分布荷重回帰で、柱脚反力が正しくても仕口モーメントが異なる反例を実測したため、同じ剛体接続を用いる全ての必要荷重入口へ転置変換を接続する。

## 独立する量と既存成果

手動剛域長・危険断面位置・仕口パネル面距離を別々に保持する。柱端に用いる梁最大半せいは今回拡張しない。正当なモデル化解除・既存対象外の距離消去と、必要面未解決の0補完を区別する。

明示・保存仕口パネルの距離が現入力と不整合なら公開解析で停止し、再準備で更新する。解析計算契約を更新して旧成功成果を失効させる。検定の式自体は変更しない。

関連課題は[Issue #759](https://github.com/hrntsm/SEPIKA/issues/759)、座標変換とH弱軸の抵抗板モデルは[ADR 0069](0069-panel-column-axes-and-h-weak-shear.md)。
