# 仕口パネルの参照柱を物理的な下側優先で統一する

- Status: accepted
- Date: 2026-10-21
- Related: [#585](https://github.com/hrntsm/SEPIKA/issues/585)、[ADR 0024](0024-separate-panel-element-and-joint-check.md)

## 背景と判断理由

柱を最小の実効体積から選んでも、材料・形状係数・軸力比が異なれば剛性や耐力の最小値は保証されない。同体積での入力順依存も、モデルの合法な並替えで結果を変えうる。
ユーザーは物理的な下側柱を優先する規則を決定した。解析剛性・非線形柱情報・断面検定のすべてへ及ぶため変更の影響が大きく、体積最小や上下平均との選択を明示する。

## 決定

参照柱の採用規則は[製品仕様](../../docs/calc_basis/04_要素剛性/06_パネルゾーン.md)を正本とし、共通解決・生成・解析・検定で同じ柱へ接続する。下側柱の物理的な不在と、存在する柱の諸元不備を分け、採用側の不備はエラーにする。

旧成果の採用柱を再認証できないため解析契約を28から29へ、検定契約を19から20へ更新する。保存モデルスキーマとマイグレーションは変更しない。

## 責務と確認限界

ADR 0024が定める解析要素と断面算定の分離、既存の材種・標準形式ゲート、釣合い用の両側応力組立は維持する。本判断はそれらを置き換えない。
材料・実板厚からの強度決定全般は[#601](https://github.com/hrntsm/SEPIKA/issues/601)、耐力式の原典とN/Aの定義は[#723](https://github.com/hrntsm/SEPIKA/issues/723)、軸力更新・接線・履歴は[#724](https://github.com/hrntsm/SEPIKA/issues/724)で扱う。下側優先の採用は、耐力式のValidationや安全側の保証を意味しない。
