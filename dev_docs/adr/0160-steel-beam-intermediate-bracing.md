# 等間隔の中間横補剛を指定したH形鋼梁は区間ごとに最大曲げを照査する

- Status: accepted
- Date: 2026-11-26
- Related: [#1897](https://github.com/hrntsm/SEPIKA/issues/1897)、[ADR 0158](0158-grouped-steel-girder-lateral-buckling.md)

## Context

H形鋼梁の等間隔横補剛本数は横座屈長さを与えるが、材端フェースと中央の検定だけでは各区間の最大曲げをつかめない。短い横座屈長さの直接指定だけからは支点間の距離を得られても、支点の位置を定められない。また、一本部材の解析要素の分割位置は補剛端とは限らない。

## Decision

単独解析要素の正の等間隔補剛本数を採用したとき、実材軸上の両端と中間点で補剛区間を確定する。荷重と断面力から再構成した曲げ分布で、同じ区間の許容値と、材端フェース内の両端・絶対値最大の需要を照合する。共通補剛端では区間両側に結果を残す。短い直接指定や一本部材の要素別本数からは補剛端を推定しない。従来は既知の短い長さから既定断面の部分区間照査を行えたが、通常検定では補剛端や最大需要が確認できない場合にその照査を適合とせず、断面の許容応力度上限などから独立に立証できた不適合を表示する。明示した横座屈長さ0による断面照査、および実材軸全長と一致する単一補剛区間の確認は維持する。

## Consequences

通常検定の適用範囲と照査位置が変わるため検定契約版を122へ更新する。解析契約版114と保存形式は変更しない。旧契約の保存検定は利用せず、現行契約の静的解析結果で再検定する。時刻歴、補剛材自体の強度・剛性検定、不等間隔の補剛端入力は対象外とする。
