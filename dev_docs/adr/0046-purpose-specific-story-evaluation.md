# 目的別確定評価点と層切断面力を保持する

- Status: accepted
- Date: 2026-10-10

## 判断

Ds 判定と保有耐力比較を別目的の EvaluationPoint とし、入力世代・WallRunIdentity・方向・確定 step・選定理由を一致検証する。両目的の条件差を許容するため、XY×2目的の採用runとAnalysisSettingsをResultsBundleに保持する。採用履歴は対象stepへ絞り、任意run全履歴の無制限保存はしない。GUI採用・OVIKA保存・帳票を同じ保持状態へ接続する。

各目的は保存条件を使って入力世代を照合する。自動地震荷重はLoadSource::Autoの部分のみ再生成し、標準名であっても手入力荷重を保持する。現在モデル・材料・手入力荷重の変更や、関連固有周期の変更は旧runを無効にする。解析停止条件の変更だけで別目的のrunを拒否しない。

確定時の実ElementBehaviorから符号付き切断面力を記録し、上側自由体の外力累積と支持ばね作用との残差を検証する。PanelOffsetMemberの追加DOFを含むglobal_dofs対応を使い、節点数×6による力ベクトル長の推測をしない。PanelZoneの柱節点参照は独立伝達力ではない。壁面内側柱は壁系全体へ一度だけ含め、共有側柱の個別壁配分はしない。

## 理由と帰結

層ピーク分母と別step壁力の混合はβuを変える。最終変位から過去非線形応力を再計算しても確定応答には戻らない。欠損・異常値・不釣合いは理由付きで停止し、clampやランクAで隠さない。

群耐力重みは同時点の実負担力から分離した正の明示入力とする。既存の群判定表・機構補正・τu式を法的に再定義しない。法定停止点の既定値、現行法の網羅的原典確認、実験Validationは別課題である。
