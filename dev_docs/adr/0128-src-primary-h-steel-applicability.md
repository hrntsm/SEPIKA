# SRC梁・柱の一次検定で内蔵H形鋼の材種と実板厚を確認する

Status: accepted

鋼管用のSTK400とH形鋼用のSN400Bは、板厚によっては同じF値になる。基準強度表の数値だけで一次検定を進めると、同じ形状・需要に同じ耐力が返り、入力した製品にその耐力を適用できるかが結果から判別できない。

第4条の材質・形状の規格から、矩形SRC梁・柱の内蔵H形鋼に適用を確認できるJISの種類記号と実板厚に限り、基準強度表を使用する。溶接条件を確認できないSS490や、鋼管の材種は理由付き未算定とする。個別認定に基づく製品を扱うには、製品の認定範囲と採用強度を照合できる入力が必要である。材料名と降伏応力だけで、その認定を確認できない。

[ADR 0126](0126-src-column-rank-steel-material.md)と共通のJISの種類記号・板厚・溶接条件を使用する。直接入力強度に関する診断はそれぞれの検定の契約に従う。旧版の検定は適用根拠が不足する材種にも結果を保持するため検定契約版を更新する。保存済み解析結果の利用条件は解析契約版と生成入力で判定する。 [製品の適用条件](../../docs/calc_basis/06_一次設計/04_01_SRCの部材検定.md#内蔵h形鋼の材種と実板厚)・[Issue #1610](https://github.com/hrntsm/SEPIKA/issues/1610)
