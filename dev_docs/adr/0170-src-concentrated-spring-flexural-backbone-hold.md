# 矩形SRC梁・柱の材端集中ばねは曲げ復元力の適用条件を確認できるまで使わない

Status: accepted

Related: [Issue #1987](https://github.com/hrntsm/SEPIKA/issues/1987)、[ADR 0156](0156-src-h-manufacture-plate-strength.md)

## Context

矩形SRC梁・柱の材端集中ばねは、主材料の降伏強度または既定の235 N/mm²と弾性断面係数で曲げ降伏を決めていた。前提を限定した照合ではSRC規準の短期許容曲げ候補より遅く降伏した。既定の一般骨格がSRC部材の剛性低下と耐力を表せる根拠はない。

SRC規準40・41条は作用軸力と材料強度を考慮し、曲げひび割れ点・降伏点・最大点・限界変形点を区別する。41条(2)が許容する16・17条の短期許容曲げは降伏点のモーメントの候補であり、41条(3)が参照する32条の終局曲げは最大点用である。これらの値だけで、曲げ卓越と終局せん断先行なし、作用軸力（変動を含む）、内蔵鉄骨の製造区分と各板厚、ひび割れ後の剛性と最大点の変形、部材角から直列ばね回転への対応を一貫して決められない。条件付きの無軸力梁の候補も、現行モデルを許容する根拠にはならない。

## Decision

矩形SRC梁・柱で材端集中ばねが選ばれる場合は、剛床上での自動選択と一軸曲げせん断の明示指定のいずれも、増分・非線形時刻歴で理由付き適用外とする。内蔵鉄骨の製造区分や主材料の降伏強度入力による例外は設けない。対象部材と適用外理由を返し、解析に連動するヒンジの表示にも骨格・相関・曲面を渡さない。

従来の一般骨格、降伏点の値だけの置換、短期許容値と終局値の入れ替えには根拠がない。ファイバーへの暗黙置換は、指定した塑性化の表現と軸力・曲げの連成を変えるため行わない。

## Consequences

線形解析と一次検定、壁上下剛梁の弾性扱い、壁側柱の診断は変更しない。元からファイバーに解決される自動選択、明示軸曲げ連成、ファイバーとマルチスプリングには、組立H形断面の既存条件を適用する。既存の解析結果を再利用しないよう解析契約版を115に更新し、検定契約版は変更しない。SRCのせん断復元力と独立した断面参考図は本判断の対象外とする。
