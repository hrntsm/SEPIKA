# 数量設定を保存モデルに持ち、方向別壁筋の不足を小計へ伝播する

Status: accepted

## Context

壁の直交最小筋比を両方向へ代入すると、方向別配筋が異なる壁で数量を過小評価しうる。
方向入力の欠落を重量0として集計すると、未算定と明示0を出力先から区別できない。
また数量側だけの一時設定では、GUI・CSV・MCP・保存再読込で概算の前提が揃わない。

## Decision

RC壁の方向入力は既存の共有断面入力を正本とし、数量専用の方向入力は追加しない。
部材の算定済み鉄筋と未算定理由を別に保持し、部位・階・構造種別・全体へ同じ理由を集約する。
出力先で欠落方向を0へ補完せず、不完全小計の状態と対象ID・方向を伝える。
未実装の壁版鉄筋にも同じ状態を使い、詳細積算の新経路は追加しない。

数量設定をcoreの保存モデルへ置き、共通編集コマンドとUndo／Redoを使用する。
数量計算は各出力入口で保存モデルとその設定から実行し、別の数量キャッシュ・失効体系を作らない。
数量設定は解析・検定の計算入力照合と重量準備の入力照合から除外する。
数量設定だけの編集・Undo／Redoは既存の正常な解析成果を失効させない。
積算鉄筋重量を物理質量へ加えると、包括RC密度との二重計上になるため接続しない。

## Consequences

不完全小計は数値だけでは読めないため、GUI・CSV・MCPは状態と理由を併記する。
保存形式の扱いは[ADR 0014](0014-schema-compatibility.md)に従い、初回リリース前の互換移行は追加しない。
現行仕様・概算仮定・未考慮項目は[数量積算](../../docs/calc_basis/10_数量積算/01_数量積算の算定式.md)を正とする。
