# 鋼製間柱の独立検定条件を鉛直荷重伝達と分離する

Status: accepted

Issue #1097 の鋼製間柱は全体解析の剛性へ追加せず、壁領域の二次部材として独立検定する。鉛直荷重はケース別の既存cascadeを使い、検定用局部横荷重は主架構へ自動転送しない。横支持・断面向き・軸座屈長さ・横補剛・たわみ限界・対象組合せと長短期をModelの部材ID別条件へ保存する。鉛直端部負担率から横支持を推定しない。

荷重応答は荷重端点で分割した多項式を閉形式積分する。H形・等厚角形の検定比の符号分割と導関数の根を求め、同一組合せ・同一位置のN/M/Qで既存鋼柱検定へ接続する。固定分点の最大値や別位置の成分最大の合成は、支配位置を過小評価し得るため採らない。許容値の準備を既存柱検定から共用し、既存適用条件の検査を通してから使用する。

全必要項目の完了と総合合否を区別し、未対応形状・設計条件不足は理由付きで残す。たわみ限界未設定時も合成変位は保持する。入力照合と検定計算契約版45・解析計算契約版66で保存成果の有効性を管理する。

ユーザー追加指示により、SteelBox/CftBoxの角R未設定は断面設定の共通入口で拒否する。H形のフィレット半径は別条件として維持し、Noneを明示0へ変換しない。既存ファイルの半径不足への計算時防御は残す。

明示した断面方向は、二次部材自重と壁版の支持面にも使う。独立検定の局部横荷重とは異なり、支持面変更は既存主架構自重にも影響するため、Modelを用いる解析・自動荷重・重量入力識別にも保持する。二次部材が間柱に支持される場合は未指定の方向を補完せずエラーとし、従来の壁支持面だけの未指定時参照は維持する。
