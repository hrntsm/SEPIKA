# 長期初期状態を全量1回の静的求解で確定する

- Status: accepted
- Date: 2026-10-26
- Related: [Issue #859](https://github.com/hrntsm/SEPIKA/issues/859)

## Context

増分解析と非線形時刻歴の長期初期載荷には、5分割と未収束時の半減再試行があった。長期応力は柱軸力・N–M相関・以後の材料履歴の基準となるため、載荷方式の変更は非線形の確定経路と再現される解析結果に影響する。ユーザーは段階載荷を当面不要と決定したが、長期荷重自体と有効・無効の設定は必要である。

## Decision

両解析とも、全長期節点荷重・部材荷重を既存の静的Newton求解で1回だけ載荷する。収束成功時に限り要素状態を確定する。失敗は全要素のsnapshotを復元して原因付きで停止し、半減再試行や長期荷重なしへの切替えを行わない。

## Consequences

段階載荷なら収束したモデルでも、全量の単一求解では開始できない可能性がある。単一求解が成立しない場合は、長期状態が未確定のまま解析を続行せず停止する。初期状態の成立を確認できない結果を終局判定や動的応答へ渡さない。

材料の確定経路が変わるため旧5段階との数値同一性は保証しない。安全側・危険側が一意に定まる近似として扱わず、同じ外力を釣り合わせる求解契約の変更として独立な釣合い・状態復元の回帰で確認する。解析契約版を更新して旧契約の保存成果を再利用しない。

水平増分の荷重制御・変位制御と通常の刻み調整、時刻歴のNewmark積分・各時刻のNewton反復は変更しない。分割載荷管理の共通化や代替の刻み調整器は導入しない。
