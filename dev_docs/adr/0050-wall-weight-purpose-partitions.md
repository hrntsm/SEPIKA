# 壁版の物理総量からDL支持と地震用階帯を独立生成する

Status: accepted

物理壁版IDごとに実領域・内法・板厚・位置付き開口の和集合・一様仕上げから共通総量を算定する。設計重量、物理質量相当重量、解析Wallの行列負担はADR0033/0035の用途差を保持する。生成Wallと荷重のみの壁で量を重ねない。

DLは下梁全量・上梁全量・壁実高さ中央切断、またはDL専用任意辺率で実支持材へ伝える。支持条件と方式は別で、左右下完全スリット・上接続は先に上梁全量とする。小梁上では下小梁全量の後、既存反力伝達を使う。

階重量は階レベル中間の水平帯で実領域を切り、DL比・反力を使わない。位置不足の成分総量と配分未算定を区別し、必要な地震用計算を壁ID付きで停止する。同期DLも自動壁成分を識別して同じ階帯から一度生成し、手入力ケースのみの入口は再解釈しない。

ADR0018の地震用重量への壁支持比共通適用を置換する。DL辺率・二次部材端部率・支持不足診断は保持する。実領域の不足を既存の最小幅近似で補わない。壁分割・新力学モデルは導入しない。

現在仕様は[壁の断面と自重](../../docs/calc_basis/01_荷重/09_壁の断面と自重.md)、[V&V](../v_and_v/壁自重の独立用途配分_Issue444_2026-10.md)を参照。
