# SRC耐震壁は両側SRC柱付きの壁を対象にする

- Status: accepted
- Date: 2026-11-23

SRC規準第6版第3刷25条1項(a)（p.28）の両側柱付き壁を初回の対象とする。SRC骨組に組み込む通常のRC壁板と鋼板内蔵RC壁板を扱い、同じ境界条件で鋼板の有無による耐力と応答の違いを検証できるようにする。筋かい入り壁板、袖壁付き柱、腰壁・垂れ壁付き梁は、壁の入力形状や応力の取り方が異なるため今回の対象から外す。

初回の適用範囲を無開口壁とする。開口付き壁の許容せん断耐力に25条4項の低減を用いるには、同条5項の開口補強の確認が必要である（pp.30–33）。開口付き壁に対応するときは、補強の入力と検定をそろえる。

増分解析を対象に含め、壁の履歴則にはユーザー指定によりSEPIKAの既存の武田型を使う。SRC規準40条解説（pp.240–241）は壁部材の復元力モデルや評価法を示していないため、武田型の採用はSEPIKAのモデル化の仮定とする。規準に基づく耐力式と、解析に用いる履歴則の根拠は区別する。

面内せん断の骨格曲線は、既存の壁モデルと同じ弾完全塑性とする。初期弾性剛性で終局せん断耐力まで進み、以降は水平とする。武田型が使うひび割れ点は既存モデルと同じく弾性線上に置き、その点で骨格の剛性は低下させない。終局せん断耐力はSRC規準38条2項（p.41）に従い、通常のRC壁板には式(38.1)、鋼板内蔵RC壁板には式(38.2)を使う。

増分解析のせん断ばねでは、静的一次参照で決めた正負の終局せん断耐力を固定する。設計採用時には同じ確定ステップの軸力・曲げ・せん断から38条2項の耐力を再照査する。耐力を超えた最初のステップとそれ以降の解析応答は参考扱いとする。最初の到達点では設計採用を認め、以降は主せん断ばねが応力を保持しても採用しない。軸力やせん断スパン比が変化する間も、脆性的な破壊後の架構耐力を過大評価しないためである（技術基準解説書6.2.4 p.369）。

38条2項のせん断耐力式は、実応力から求めたせん断スパン比 M/(Ql) が1以上3以下のときに使う（p.41）。範囲外の値を上下限へ置き換えて耐力を補完せず、理由を示して設計への採用を保留する。

内蔵鋼板は、壁板の内法範囲を覆い、壁厚の中央に配置する等厚の鋼板1枚とする。板厚と材種を明示し、周辺のSRC柱・梁の内部鉄骨へ設計せん断力を伝達できる接合が確認されていることを適用条件とする（SRC規準25条6項 p.33、25条解説 p.196、38条2項 p.41）。軸・曲げ剛性と終局曲げ耐力に鋼板を算入する場合は、軸・曲げに必要な応力伝達と、コンクリートおよび周辺鉄骨との一体性も確認する（同11条 p.9、25条2項 pp.28–29、38条1項 pp.40–41）。部分配置・複数枚・偏心配置には、内法全長を使う鋼板負担分の式を適用しない。

壁単体の検定と増分解析に加え、SRC架構各階・各計算方向の構造特性係数 Ds、必要保有水平耐力 Qun と保有水平耐力 Qu の比較を対象とする。『2025年版 建築物の構造関係技術基準解説書』6.5.4（pp.441–444）に示すSRC用の部材種別・部材群とDsの規定を使う。S造・RC造用の表で代用すると必要保有水平耐力を過小評価し得るため、SRC表の適用条件が成立した場合に採用する。

初回の建物全体の合否判定は、全評価階・両方向でSRC用の規定の適用を確認できる建物を対象とする。RC造やS造の規定を適用する階・方向を含む建物では、建物全体の合否を保留する。方向・高さによって構造種別が異なる場合は、同解説書6.9（pp.482–484）に沿った方向別・階別の規定と異種構造間の接合の確認が別途必要である。

架構全体の合否は、直交する両水平方向の正・負加力をそれぞれ照合する（同解説書6.2.4 p.369）。片側の解析応答を反転して他の加力の根拠には用いない。

崩壊形、対応する確定ステップ、および柱・壁の破壊形式は設計者が確認して入力する。プログラムは同じ解析実行・計算方向・確定ステップの応力と規定の耐力を照合し、崩壊形を根拠付ける部材の耐力到達を確認する。保有水平耐力として比較する層力は、同じ計算方向に他に成立する崩壊形が確認されている場合、その層の最小値を超えないことも確認する。部材種別、部材群、Ds、必要保有水平耐力と合否は必要な確認がそろった階・方向について算定する（技術基準解説書6.2.4 pp.365–369、6.5.4 pp.442–444、SRC規準39条 p.42）。
