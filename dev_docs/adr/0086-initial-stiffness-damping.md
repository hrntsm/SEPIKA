# 非線形時刻歴の既定減衰を未載荷の初期剛性比例とする

- Status: accepted
- Date: 2026-10-27
- Related: [Issue #808](https://github.com/hrntsm/SEPIKA/issues/808)

## Context

塑性確定点の同一点接線は、方向を指定しない微分として一意に定まらない。接線比例減衰では材料履歴からの再評価分岐が減衰力へ直接伝播する。ユーザーは初期剛性比例を採用し、ゼロ増分だけでなく解析開始から一貫した基準を求めた。

既定設定はすでに初期剛性比例へ接続していたが、非線形solverでは長期静的載荷後に基準行列を取得していた。このため先行塑性化や軸力によって基準が変わり得た。

## Decision

未載荷の非線形要素群から、長期載荷・動的初期条件の適用前に基準剛性を一度取得する。初期加速度と全時刻の初期剛性比例減衰へ同じ行列を用いる。幾何剛性を有効にした低位入口でも、長期軸力導入前の状態が基準となる。

材料構成則と履歴、復元力、Newton釣合い用接線は変更しない。既定選択と保存enum識別子を維持し、GUIでは「初期剛性比例」と明示する。明示選択できる既存のRayleigh・モード別・接線方式を残す。設定移行を追加せず、解析契約版を65へ更新して旧結果の再利用を防ぐ。共通の初期基準を用いるRayleighとh1一定型の基準も未載荷に揃う。

## Consequences

塑性化後も初期剛性に応じた減衰が働くため、接線比例より大きな減衰力となり得る。応答過小評価の可能性があり、全建物・全応答に対する安全側保証ではない。採用方式・適用注意の正本は[減衰の計算根拠](../../docs/calc_basis/05_構造解析/04_減衰.md)とする。

材料の方向別接線の調査結果と、この減衰の採用判断を分離する。限定した独立Verificationで初期基準固定を確認し、実測Validation・一般入力の収束性や安全性を確認済みとしない。2025年版技術基準解説書との照合は本Issueの対象外であり、ユーザー決定を原典適合確認へ読み替えない。
