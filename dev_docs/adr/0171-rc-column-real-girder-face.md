# RC柱の通常検定では接続大梁が定める実材端面の静的応答を採る

Status: accepted

Related: [#1846](https://github.com/hrntsm/SEPIKA/issues/1846)、[ADR 0145](0145-rc-column-long-term-shear-span.md)、[ADR 0146](0146-rc-column-long-term-shear-alpha.md)

## Context

解析準備の公称フェースは梁せいを使い、柱軸に沿う実境界と一致しない場合がある。公称フェースを修正すると剛域・重量・終局検定など別の構造モデルにも影響する。既存の汎用断面力に新しい測点を挿入する方法も、測点の最大値を採る別の機構判定・表示に波及する。

## Decision

実材軸に直交し、有限な接触が確認できる大梁の面を、通常の長期・短期RC柱検定の対象とする。部材荷重を含む同一静的解析で柱区間側の断面力を回収し、既存の汎用測点とは別に保存する。短期地震時に重力参照を要する式には、同位置のケース応答を合成した値を使う。

一面に定まらない接合、形状不足、実面に対応する応答不足では該当検定を保留する。どの面を選んでも安全側になるとはいえず、軸力・曲げやその合成比は位置によって増減するため、公称フェース・近傍断面・材中央での切り詰めを代用しない。柱の正の区間外と判明した中央や追加位置の断面力は検定しないが、独立して確認した不適合と、中央の内力を要しない構造規定の判定は残す。

## Consequences

解析と検定の計算契約を改版する。長期せん断の区間最大とαは既存の採用条件を維持する。接続大梁の実材端面を、準備・剛域・重量、短期せん断の機構算定、時間応答の簡易検定、終局検定の条件に広げない。
