# 偏心率は上下階SL間の区間が定まる柱をすべて集計する

Status: accepted

柱の水平剛性の算定では、各上階SL節点から出る柱材ごとに上下階SL間の区間をたどる。上階SLと下階SLは経路の端とする。両境界につながる連なりの層内分岐や、下階SLへの経路上に高さが順に下がらない区間がある場合は、層と部材・節点を示して算定を保留する。同じSLの別節点どうしを柱材で結ぶ境界には既存の診断を適用する。

共有するSL節点だけを理由に柱を除くと、実際に負担した水平力が集計から落ちる。中間節点の分岐を上階SLの接続と同じように数えると、共有部材と層間変位の組合せが一意に決まらず、一部の柱の負担を脱落または重複させる。分岐点での剛性の配分や変位の補間には追加の評価条件が要る。長期軸力による重心、自立壁のn倍法および柱剛性を使う質点系は、偏心率と同じ経路判定を用いる。共有する上階SL節点を持つ柱のD値略算法は、傾斜柱の軸力の寄与を含めた適用性を確認するまで保留する。

旧結果に保存された自立壁の剛性率評価用変位や質点系の結果を再利用しないよう、解析契約版を92に更新する。
