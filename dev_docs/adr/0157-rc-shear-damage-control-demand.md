# RC梁・柱の損傷制御では長期・水平の合算応答を用いる

- Status: accepted
- Date: 2026-11-25
- Related: [#1880](https://github.com/hrntsm/SEPIKA/issues/1880)

## Context

RC規準第10版（2024）の(15.4)式では、損傷制御用需要は長期荷重と水平荷重による同じ断面のせん断力の和である。安全確保用の(15.7)～(15.9)式を混ぜると、水平荷重の割増しだけでなく、曲げ降伏に基づく需要への置換によって損傷制御の需要を過小評価する場合がある。

## Decision

通常検定は適用可能な保存荷重組合せの合算断面力を採用し、別途の重力解析で合成し直さない。時刻歴簡易検定は生成入力が現モデルと一致し、固定・架構用積載荷重だけを初期載荷した非線形時刻歴の確定ステップに限る。積雪や種別未指定を初期載荷した場合は、地震組合せ相当の重力条件とみなさない。異なる時刻の内力包絡では同時刻の曲げとせん断を確定できないため、損傷制御のせん断を未算定とする。水平成分のみの記録に静的長期を後から加える代替は採らない。損傷制御時にはQD1・QD2・minを参照しない。

## Consequences

損傷制御では通常検定の保存結果を再検定する。設計契約を119に更新し、解析結果の契約は変更しない。時刻歴は既存の軸力極値の確定ステップだけを使うため、全時刻の最大検定比・適否を判定しない。安全確保の時刻歴重力参照の扱いは変更せず、長期初期載荷と同一と確認できない場合の扱いは [#1830](https://github.com/hrntsm/SEPIKA/issues/1830) で追跡する。
