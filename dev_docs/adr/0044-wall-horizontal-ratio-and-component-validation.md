# 壁横筋比は最小筋比から推定せず出力成分ごとに入力不足を扱う

Status: accepted

Issue #503の採用済み参考資料式ではβsに横筋比が必要だが、既存RcWall.psは直交最小比しか保持しない。方向不明のps代入は剛性と終局変形を別の値にするため、未知を許容する明示横筋比を追加する。psの用途・契約は保持する。

全材料の欠落を一括拒否すると縦筋強度を使わないβs/Quまで消えるため、出力ごとに不足を判定する。対応材種と有限正fyは必須とし、未入力から295・材名推定を使わない。初回リリース前の保存形式はADR0014に従いスキーマ版を1に保ち、マイグレーションを追加しない。

骨格の不成立点をクランプして成功にせず原因付きエラーにする。公開研究の定義が確認できた無開口・純せん断の割線接続に限定する。異材料や方向未解決の断面を同質断面に代用しない。製品仕様・適用条件・出典は[製品ドキュメント](../../docs/calc_basis/08_部材終局耐力/04_RC_部材_非線形復元力特性.md)を正とする。
参考断面は部材内力候補ではなくモデルの実在側柱から解決する。主材不明の柱を断面から除外すると別の壁を算定するため、不足を診断する。作用方向の未確認な非対称側柱に強側の寸法・配筋を代用せず、左右の断面・配筋が対称でコンクリート種別・弾性特性が同質な鉛直壁へ適用を限定する。
