# RC柱の短期地震時せん断の柱頭係数を接続節点から決める

- Status: accepted
- Date: 2026-11-22
- Related: [#1800](https://github.com/hrntsm/SEPIKA/issues/1800)

## Context

柱頭の梁降伏を用いて柱の設計用せん断力を低減できる範囲は、その接合部より上に柱が続くかどうかで変わる。セットバックや段差床では、階名や建物全体の最高標高を使うと、柱が途中で終わる架構の柱頭の需要を過小評価する。

## Decision

上階に続く柱は、柱頭と接続節点を共有する上向きの主架構柱で確認する。端別XYZ偏心があっても元の接続節点で判定する。剛床拘束は床の面内運動の条件なので、離れた柱を同じ柱頭の連続材に数える根拠にならない。

剛体リンクや多点拘束を介した連結では、離れた節点間の力の伝達条件から柱の連続性を一意に決められない。共有節点で連続を確認できず、このような拘束が柱頭に取り付く場合は、規準(15.8)式の原則である柱自身の降伏モーメントを柱頭に用いる。[RC柱のせん断検定の根拠](../../docs/calc_basis/06_一次設計/02_04_RC柱のせん断検定.md#柱頭柱脚の崩壊メカニズム)

## Consequences

柱頭の寄与に係数を使う段階と、梁の降伏モーメントの算定・ヒンジ候補の選定を分ける。この修正によって既存の候補が入れ替わり、需要が下がることを避ける。一般階で比較に使う寄与と柱脚候補の見直しは [#1817](https://github.com/hrntsm/SEPIKA/issues/1817)、梁降伏モーメントを集計する解析要素の範囲は [#1820](https://github.com/hrntsm/SEPIKA/issues/1820) で扱う。
