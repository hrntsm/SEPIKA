# 平衡化した求解行列の推定逆条件数で正定値求解の数値条件を診断する

Status: accepted

## Context

Issue #818では、ねじり解放したRC柱と片持ち梁の独立零エネルギー機構を直接静解析が受理した。単位の異なる並進・回転を含む剛性を未平衡のまま分解し、浮動小数点で正になった微小pivotだけから正定値と判定していた。荷重残差が小さいことや非ゼロ変位を得ることでは、未励起の機構を拒否できない。

因子内部のpivotを絶対値で切ると単位・剛性規模に依存する。全自由度数や局所fill数から独自にpivot床を作る案には、既算定因子の誤差伝播や超節点計算まで含む根拠がない。密行列への変換や別の数値分解を一律に追加する方式も、既存の大規模な疎直接法へ課す費用が大きい。

## Decision

共通Choleskyソルバで正対角の平方根による合同平衡化を行い、faerの高水準疎LLᵀ分解をそのまま使う。faerが読む下三角を対称行列として扱い、非対角は対応する両列の絶対値和に一度ずつ加える。対角を1とし、反復推定の求解には平衡化済み行列の因子だけを使う。元単位への右辺・解の変換は通常の公開求解に限る。

推定逆条件数の定義にはLAPACK DPOCON、作業精度で特異とみなす水準にはDPOSVXを採用する。faer 0.24.0には対応する逆ノルム推定APIがないため、DLACN2を対称行列の関数適用へ限定して最小移植する。初期定数ベクトル、符号の反復、推定値の停滞、最大5反復、最大成分の変化、最終交互符号ベクトルを保持する。対称なので通常・転置の両作用は同じ因子による求解で実現し、逆行列・追加の因数分解・因子内部の参照を要しない。著作権と利用条件は `crates/sepika-math/LICENSE-LAPACK` に保持し、バイナリ再配布時の同梱要件をREADMEへ記す。

LAPACK DPOSVXは警告後も解を返すが、本件ではその水準を満たさない結果を公開しない。推定逆条件数がDLAMCHの丸め単位未満、または推定に非有限値が生じた場合は、正定値求解を数値的に確認できないものとして分解を拒否する。架空剛性・拘束・ねじり条件・物理近似を追加しない。

分解試行の最初に前回の数値因子を無効化し、失敗後の公開求解を拒否する。疎構造の記号解析キャッシュは維持する。共有する静的・固有値・増分接線・時刻歴の実求解行列に適用し、初期加速度の既存LU切替や動的有効剛性の物理的適用条件を一律に静的機構判定へ置き換えない。

## Consequences

単位や独立対角剛性の規模による見かけの悪条件を抑えてから、荷重によらず診断できる。追加費用は疎成分の走査・ベクトル記憶と最大11回の因子による求解であり、各公開右辺の求解では再診断しない。有限でも作業精度で識別不能な正定値行列は拒否される。

DLACN2の逆ノルム推定は下界であり、推定逆条件数は上方推定になり得る。したがって全機構の検出・所要変位精度・安全性の数学的保証とはしない。入力の丸め・並べ替え・因子計算の丸めにより判定境界付近で採否が変わり得る。独自のpivot床を加えてこの限界を隠さない。

現行の式・精度水準と一次資料は[線形代数ソルバ](../../docs/calc_basis/05_構造解析/01_線形代数ソルバ.md#数値条件の確認と逆1ノルム推定)、独立入力と実測は[Issue #818の検証記録](../v_and_v/正定値求解の数値条件_Issue818_確認記録.md)を正とする。
