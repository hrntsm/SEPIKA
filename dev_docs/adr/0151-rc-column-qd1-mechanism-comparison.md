# 一般階のRC柱のQD1は適用条件を満たす片側梁降伏を係数適用後に比較する

- Status: partially superseded by [ADR 0155](0155-rc-column-qd1-floor-girder-hold.md)（床板付き候補の扱い）、[ADR 0165](0165-rc-column-qd1-girder-bending-axis.md)（曲げ軸の適用判定）
- Date: 2026-11-25
- Related: [#1817](https://github.com/hrntsm/SEPIKA/issues/1817)

## Context

RC規準2024年版第15条(15.8)式は両端柱降伏を原則とし、柱頭に上階柱が続くときは、接続梁の降伏モーメント和の1/2が柱頭の柱自身の降伏モーメントより小さければ置換を認める。解説図15.9(b)の前の説明は、図を上下反転した柱脚梁降伏の候補が小さい場合も採用できるとしている。梁和の全量を先に柱自身の値と比較すると、係数適用後に成り立つ候補を落とす。また、柱頭を常に優先すると、条件を満たす柱脚梁降伏の方が小さい場合を扱えない。

## Decision

[ADR 0143](0143-rc-column-head-shear-factor.md)に従い、上階柱が柱頭の同じ節点から続く場合を一般階とする。一般階における各候補の小ささは、係数適用後の寄与で比較する。両端で柱降伏する候補を原則とし、比較に用いる梁降伏は片端のみに限る。

柱脚の梁和の1/2は、図(b)の反転と照合できる幾何・支持に限る。検定柱と上下の連続RC柱が同一鉛直芯で剛接・無偏心、柱頭・柱脚に支持や連結による別の力の伝達経路がなく、柱脚では左右2本の水平共線の大梁が曲げを伝達でき、その遠端の支持まで確認できることを要する。梁遠端が追随する自由端や、柱脚に独立柱脚支点がある場合は図の仮定を確かめられないため採用しない。上下柱で曲げを等分する規準の略算であり、上下柱の剛性を同一とする制約の追加や、曲げの実分担を解析結果から推定することはしない。既存の柱頭側の適用条件と梁の降伏耐力式は変更しない。

別方向の大梁の斜交曲げ・ねじりは、梁の加力方向の割当だけでは除外できない。このため柱脚に左右2本以外の大梁があれば反転候補を採らない。反転時の柱頭は柱自身のMyを用い、柱頭に梁が取り付くこと自体を除外条件にはしない。柱頭・柱脚で剛体リンク・多点拘束に関わる節点は、縮約後の別節点参照の有無を問わず反転候補から除外する。固定節点の変位や回転を参照した拘束は、縮約後に別節点参照がなくても接合節点を実質的に固定し得る。

断面形状に加え、検定柱・上下の連続柱・柱脚両側の大梁がコンクリートを主材料とすることを確認する。RC断面形状だけで、主材料が異なる部材の曲げ伝達・耐力をRC規準の図と同等には扱わない。

壁の境界は解析要素への展開前後を区別せず反転候補から除外する。接合節点側にXYZ偏心を持つブレースも、軸力を節点へ移すときに曲げが生じ得るため除外する。

RC規準p.180は梁の降伏曲げに対するスラブ筋の寄与を挙げている。床板を支持する梁について、この寄与を求めずに新たに需要を低減することはしない。床板を支持する柱脚梁は新たな反転候補には使わない。柱頭梁は床板の支持に加え、同じ床シェル要素と両端の節点を共有する場合も、係数適用前から梁和が柱Myより小さいときだけ従来の置換を維持する。既存の梁Myの評価へのスラブ筋の反映は[#1906](https://github.com/hrntsm/SEPIKA/issues/1906)で追跡する。

梁の強軸曲げ耐力を検討柱の曲げ方向へ移すには、両者の回転軸が合う必要がある。柱脚の左右水平梁は断面の局所y軸が鉛直であることを要する。柱頭も係数適用後に限って小さくなる場合は、検定柱が鉛直で梁の主材料区分がコンクリートであることを確かめ、実材軸から強軸曲げの回転方向を求めて検定柱の曲げ軸との平行を確認する。同一鉛直面内の傾斜梁は対象に含める。正規化前の幾何と解析に使う軸の両方から、平面の向きや参照方向の材軸成分に依存せず、また軸の代替が検討方向を変えていないことを確認する。従来の梁候補全体の対応は[#1907](https://github.com/hrntsm/SEPIKA/issues/1907)で追跡する。

## Consequences

柱脚側の幾何や支持を確認できない一般階では、両端柱降伏と適用できる柱頭梁降伏だけを比較する。図15.9(b)の反転の検証範囲外である最上階・上階連続不明時の柱脚の扱いは維持し、[#1904](https://github.com/hrntsm/SEPIKA/issues/1904)で追跡する。常時せん断が無視できない条件での需要は [#1905](https://github.com/hrntsm/SEPIKA/issues/1905)で追跡する。通常検定と時刻歴簡易検定は同一の候補を使い、旧契約の保存検定は失効する。解析結果の契約は変更しない。[製品の計算根拠](../../docs/calc_basis/06_一次設計/02_04_RC柱のせん断検定.md#柱頭柱脚の崩壊メカニズム)・[照合記録](../v_and_v/RC柱QD1の崩壊メカニズム_Issue1817_検証.md)
