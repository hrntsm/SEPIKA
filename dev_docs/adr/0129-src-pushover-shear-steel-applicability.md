# SRC矩形梁・柱の増分解析でせん断降伏に用いる内蔵H形鋼の基準強度を確認する

Status: accepted

鋼管用の材種名や適用根拠を特定できない直接入力材でも、解析がせん断降伏イベントを記録し、部材の破壊状況として後続の評価へ伝えることがあった。根拠の不足をイベントなしとして返すと、後続の部材評価がせん断降伏なしと解釈し得るため、部材ID・材料の理由付きで増分解析を停止する。

[ADR 0126](0126-src-column-rank-steel-material.md)・[ADR 0128](0128-src-primary-h-steel-applicability.md)と内蔵H形鋼の用途条件を共有する。ウェブ・フランジは両方の適用範囲を確認し、せん断降伏閾値に使うFは従来どおり方向に対応する板の実厚から得る。用途条件を他の材料利用にも一律に課すと、その経路の入力契約を変更するため、増分解析のせん断降伏の準備に適用する。

旧版には根拠を確認できないせん断降伏が保存され得るため、解析契約版を更新する。 [製品の適用条件](../../docs/calc_basis/08_部材終局耐力/10_02_線材のせん断降伏判定用耐力.md#内蔵h形鋼の材種と実板厚)・[Issue #1614](https://github.com/hrntsm/SEPIKA/issues/1614)
