# ねじれで柱の層間変位が相殺される層の水平剛性を保留する

Status: accepted

上階の全評価柱が単一の剛床と加力方向に一体で動き、下階も同様に単一の剛床と一体で動くか全柱下端が加力方向に固定され当該変位が0の層を対象とする。上階の評価柱上端の平面図心を上下階共通の基準にすると、剛床代表節点の選択によらず柱位置の変位を並進成分と回転成分に分けられる。両成分が逆符号で、層間変位の絶対値が両成分の絶対値それぞれより小さければ、層・方向・柱の理由を用いて水平剛性の算定を保留する。この判定は相殺を検出する適用条件であり、外力を比例縮小した場合も変わらない。法令・解説書の数値基準や比を採用できる範囲の保証には用いない。

単一の加力応答から得る柱の方向別の比だけでは、各柱の直交方向の力がつくるモーメントや柱材軸のねじりを再構成できない。[原典と独立照合](../v_and_v/ねじれで柱の層間変位が相殺される場合の偏心率_Issue1595_照合記録.md)では、並進架構の柱剛性を用いても剛心とねじり剛性に差が残った。解析で得た変位から回転成分を除く操作は、並進架構への再載荷に相当しない。このため、剛性を別値で補わず、層の偏心率・形状係数と、同じ柱剛性に依存する壁の付加剛性・Rs用再解析・質点系を保留する。複数剛床・非剛床では層を共通の並進・回転に分けられず、この判定の対象外とする。

固定下端を持ち、加力直交方向に同じ座標の上端しかない層では、平面図心まわりの当該方向の腕が全柱で0になる。この配置では一様な加力方向変位からねじれの寄与を分離できず、この相殺判定では検出できない。

柱剛性を用いる保存解析結果の適用条件が変わるため、解析契約版を93に更新する。部材検定の計算契約とモデル保存スキーマは維持する。
