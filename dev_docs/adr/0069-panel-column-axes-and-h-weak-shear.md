# 仕口パネルを柱2主軸へ接続し、H形弱軸はフランジ2枚の純せん断モデルとする

Status: accepted

## 判断

仕口パネル解析要素は、採用柱の強軸・弱軸に対応する2方向を持つ。柱の既存の断面方向を用い、梁方向ごとの仮想パネルや新たな設置角入力を設けない。せん断変形・内力・接線と部材端回転は同じ柱主軸の基底を用い、傾斜柱でも3次元の物理回転を部材へ渡す。

H形柱の弱軸側は、ユーザーが2026-10-23に指定したフランジ2枚の純せん断モデルを採用する。強軸側のウェブ1枚との違いを実諸元に反映する。解析側の梁高さは既存の共通最大値を維持し、明示パネル厚は抵抗板1枚あたりの有効厚として扱う。Fを決める製品板厚は、その有効厚と分ける。

具体的な算定式・寸法・係数・適用条件の正本は[仕口パネル要素](../../docs/calc_basis/04_要素剛性/06_パネルゾーン.md)とする。

## 検定への適用

[Issue758](https://github.com/hrntsm/SEPIKA/issues/758)のS/CFT接合部検定も、同じ柱2主軸で需要を符号付き集約する。元の梁構面の標準形式を保持し、同一主軸へ幾何的に寄与する構面間で上下フランジ位置の一致を要求する。瞬間の零応力によって参加条件を変えず、独立する整列直交構面は方向別の高さで扱う。

公開MSは仕事共役な逆変換で復元するが、解析の共通梁高さと当該軸の高さが一致しない場合は、容量の実幾何との対応を確認できないため未算定とする。最大値・平均値・任意の梁対による容量の補完を加えない。MSのない材端力経路は鉛直柱に限定し、非鉛直柱の既存面内式は[#764](https://github.com/hrntsm/SEPIKA/issues/764)で別途扱う。新しい腕長・補正式を根拠なく導入しない。

通常の検定結果は強軸・弱軸で保持する。複数の元構面に入力不備がある場合は、保存成果の適用条件を確認できるよう、共通幾何の理由を補足の入力診断として保持する。この診断は追加の物理パネルの検定ではない。具体的な式・適用条件は[S造柱梁接合部](../../docs/calc_basis/06_一次設計/07_鋼構造の柱梁接合部.md#s-造柱梁接合部)、実行証拠は[Issue758のV&V](../v_and_v/仕口パネル検定2軸集約_Issue758_2026-10.md)を参照する。

## 理由と選ばない方式

同一のせん断ばねを2本設けるだけでは、強軸のウェブと弱軸のフランジの抵抗部位を表せない。柱断面が梁方向に対して回転しても、物理的な抵抗部位は柱の2主軸に定まるため、柱主軸への仕事共役な接続を採る。

弱軸側について、接合詳細に応じたフランジ曲げや曲げ・せん断相互作用を含む新しい容量式を、この変更で独自に一般化しない。今回の採用根拠はユーザーの明示した2枚板の純せん断モデルであり、特定の原典式や規準の全条件への適合を確認した結果ではない。

## 結果と未確認範囲

弱軸側でフランジ曲げ等による耐力低下が支配する場合、純せん断モデルは耐力を過大評価し得る。この危険側になり得る近似を、製品の計算根拠とV&Vへ明記する。座標変換・釣合い・仕事・履歴のVerificationと、採用近似のValidationを区別する。

既存式へ各方向のFを用いる軸力比の機械的な接続は、軸力分配や断面全体の軸耐力モデルの妥当性確認ではない。N/A・Fと耐力式の原典確認は[#723](https://github.com/hrntsm/SEPIKA/issues/723)、軸力連成接線は[#752](https://github.com/hrntsm/SEPIKA/issues/752)、検定需要の柱2軸への集約は[#758](https://github.com/hrntsm/SEPIKA/issues/758)、実柱フェースに対応する方向別オフセットは[#759](https://github.com/hrntsm/SEPIKA/issues/759)で区別する。

柱長さ・基準軸耐力の既存数値下限による軸力比の過小評価は[#761](https://github.com/hrntsm/SEPIKA/issues/761)で追跡する。本判断によってその下限を物理モデルとして正当化しない。
