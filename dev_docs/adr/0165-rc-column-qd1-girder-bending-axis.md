# RC柱QD1の片端梁降伏は検討曲げ軸に対応する場合に採用する

- Status: accepted
- Date: 2026-11-26
- Related: [#1970](https://github.com/hrntsm/SEPIKA/issues/1970)、[#1907](https://github.com/hrntsm/SEPIKA/issues/1907)

## Context

RC規準2024年版第15条(15.8)式は両端柱降伏を原則とし、解説図15.9の梁降伏は同じ構面で降伏曲げの伝達が確認できる場合の候補である。水平方位で梁を柱の強軸・弱軸へ振り分けても、その梁の曲げの回転軸やねじりとの区別を確認したことにはならない。[ADR 0151](0151-rc-column-qd1-mechanism-comparison.md)では新たに追加する低減の軸対応を確認したが、従来の置換や方位割当から外れた梁の影響も同じ判断が必要である。

## Decision

柱の検討曲げ軸と梁の強軸曲げの対応を、実材軸と解析の断面基底で確認する。確認できない梁だけを落とすとその端の耐力を小さく見積もるため、梁降伏候補を端単位で除外する。検討曲げ軸が梁の材軸と平行なら、その梁の断面曲げは当該軸に寄与しないため、標準的な直交架構の梁をその方向の梁和に含めない。これは平面の片端梁降伏式を使うための判定であり、立体のねじり抵抗や曲げ・せん断の二軸相関を評価するものではない。

軸の不一致だけを理由に候補を外した方向では、両端柱降伏と独立に成立した候補を比較する。遠端偏心による実材軸の斜交は、軸の不一致に加えて [ADR 0144](0144-rc-column-qd1-girder-end-conditions.md) の接合条件を満たさないため、別端の候補までを比較できる構面とみなさない。曲げを伝え得ることが実軸から分かる方向では、平面上の方位割当にかかわらず接合条件も確認する。軸対応の理由で候補を除外した方向の需要が確定しなければ、[ADR 0155](0155-rc-column-qd1-floor-girder-hold.md)と同様に理由を表示し、その方向を代替算定しない。重力参照の一覧に柱が含まれない場合にも、その方向へ応答せん断力を代用しない。係数、柱の連続条件、柱側梁端の接合・有効剛域の判断、床板筋の取り扱いは変更しない。
