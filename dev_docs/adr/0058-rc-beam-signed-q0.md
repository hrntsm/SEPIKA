# RC梁Q0を符号付きlocal Qy端反力の合成から求める

- Status: accepted
- Date: 2026-10-15
- Related: [#600](https://github.com/hrntsm/SEPIKA/issues/600)、[#633](https://github.com/hrntsm/SEPIKA/issues/633)、[ADR 0014](0014-schema-compatibility.md)

## Context

RC梁の検定需要はlocal Qyを使う。荷重の材軸直交成分の大きさやケース別最大端反力を先に足すQ0では、検定方向の異なる荷重も加算され、同じ選択荷重のケース分割だけで結果が変わる。

両端支持時せん断の評価では、任意3Dの評価方向とケース合成順序を明示する必要がある。既存RC検定が扱うlocal Qyに方向を揃え、ケース分割に依存しない合成を採用する。

## Decision

既存RC梁のQ0は、正規化した全体荷重方向を既存局所y軸へ射影し、符号付き合力と一次モーメントから両端支持反力を求める。選択重力termsの係数を両端別に合成した後、最大絶対値を部材Q0とする。これは既存RC検定との整合に基づくSEPIKAの採用判断である。

定義済み直交方向・無荷重・相殺による0を有効値とし、不足を0・部分値・QL・過去成果で補完しない。既存の有限域外clampと空区間無寄与を維持する。SRC等の非RCの数値・結果キー存在条件・既存不足ゲートは維持し、CFT・重量採否・終局需要へ広げない。

## Consequences

同じ物理荷重のケース分割・統合に依存しないQ0となる。local Qzや3D合成せん断、符号反転分布の全断面極値の評価にはならず、全断面最大に対する安全側は保証しない。鉛直限定・斜材禁止の新しい方向ゲートは設けない。

検定結果の意味が変わるため検定契約版を11から12へ更新する。解析契約版21は維持する。旧検定は鮮度更新・再保存で復活させず、現行契約での再検定を必要とする。
