# 終局需要を静的ヒンジ略算と初期重力を含む確定総応答に分ける

- Status: accepted
- Date: 2026-10-18
- Related: [#565](https://github.com/hrntsm/SEPIKA/issues/565)、[ADR 0041](0041-holding-result-input-validity.md)

## Context

架構応力用と地震重量用では積載用途が異なる。需要側が現在の地震重量集合から重力を選び直すと、静的需要と増分解析の初期状態を同じ条件として扱えない。また、初期重力を含む確定総応答へ静的略算の QL 控除と上限強度倍率をそのまま適用すると、重力の二重算入や増幅が生じる。

総応答から重力を除いた増分だけを別に増幅する方法は、符号付き成分の由来と採用式の根拠が必要になる。現時点でそれを仮定して既存倍率を正当化することはできない。

## Decision

需要モードを静的・両端ヒンジ略算と増分・確定総応答に分ける。架構用長期重力は既存の保存組合せを明示選択して共通解決し、別の組合せ台帳は導入しない。静的需要では完全な符号付き重力内力から抽出する。増分では同じ実行に載荷した重力条件と確定総応答を結び付ける。

総応答モードでは QL を追加せず、上限強度倍率 1 の範囲に限る。QL の未設定だけでモードを暗黙推定せず、静的の不足と総応答の追加なしを区別する。必要ケース・対象・位置・入力識別の不足は、ゼロ需要や静的への代用に変換しない。

## Consequences

略算の結果と実際の確定総応答を区別でき、初期重力の用途・係数と需要の由来を保持できる。一方、全位置探索・補間や総応答の過強度需要は含まれず、特別な終局重力条件は別途根拠を揃える必要がある。

これは SEPIKA の先行対応範囲に関する採用判断であり、一般の全終局荷重条件の規準適合を立証するものではない。製品仕様・式・出典は[終局検定の統括](../../docs/calc_basis/08_部材終局耐力/07_終局検定の統括.md)を正本とする。
