# 終局需要を静的ヒンジ略算と初期重力を含む確定総応答に分ける

- Status: accepted
- Date: 2026-10-18
- Related: [#565](https://github.com/hrntsm/SEPIKA/issues/565)、[#1412](https://github.com/hrntsm/SEPIKA/issues/1412)、[#1476](https://github.com/hrntsm/SEPIKA/issues/1476)、[#1497](https://github.com/hrntsm/SEPIKA/issues/1497)、[#1498](https://github.com/hrntsm/SEPIKA/issues/1498)、[ADR 0041](0041-holding-result-input-validity.md)

## Context

架構応力用と地震重量用では積載用途が異なる。需要側が現在の地震重量集合から重力を選び直すと、静的需要と増分解析の初期状態を同じ条件として扱えない。また、初期重力を含む確定総応答へ静的略算の QL 控除と上限強度倍率をそのまま適用すると、重力の二重算入や増幅が生じる。

総応答から重力を除いた増分だけを別に増幅する方法は、符号付き成分の由来と採用式の根拠が必要になる。現時点でそれを仮定して既存倍率を正当化することはできない。

## Decision

需要モードを静的・両端ヒンジ略算と増分・確定総応答に分ける。架構用長期重力は既存の保存組合せを明示選択して共通解決し、別の組合せ台帳は導入しない。静的需要では完全な符号付き重力内力から抽出する。増分では同じ実行に載荷した重力条件と確定総応答を結び付ける。

総応答モードでは QL を追加せず、上限強度倍率 1 の範囲に限る。QL の未設定だけでモードを暗黙推定せず、静的の不足と総応答の追加なしを区別する。必要ケース・対象・位置・入力識別の不足は、ゼロ需要や静的への代用に変換しない。

### RC 柱の静的二軸せん断

両端ヒンジ略算の二軸余裕度を使うのは、強軸・弱軸の長期せん断力が明示的にゼロの場合に限る。長期せん断力のある静的二軸をどう合成するかは、既存の略算にそのまま適用できる根拠が揃っていない。両軸の長期せん断力は符号付き合成の後に軸別に抽出し、弱軸が欠ける需要をゼロに読み替えない。

二軸の適用条件を満たさない場合も、長期せん断を考慮した強軸せん断、または独立した照査で確定した NG は保持する。それ以外は部材別の未検定理由を返し、他部材の結果とともに表示する。増分・確定総応答の二軸せん断では、初期重力を含む両軸の総せん断力を一度だけ用いる。[原典照合と不一致の記録](../v_and_v/終局重力組合せと応力割増し_Issue958_照合記録.md#rc-柱の静的二軸せん断)

### RC矩形梁の静的曲げ方向

長期架構用組合せを合成した後に、強軸曲げが一方向の評価結果だけを静的略算に採用する。最大絶対値をとる位置の符号で、曲げ終局耐力と付着条件に使う引張側を揃える。正負が混在する場合、全評価位置でゼロの場合、符号を確認できない需要は、梁単位で理由付き未検定とする。対称配筋でも上端筋の付着条件は異なる。選んだ引張側に主筋がない場合も、曲げ終局耐力と比較需要を決められないため未検定とする。

『2025年版 建築物の構造関係技術基準解説書』第2版第1刷の式(付1.3-5)（p.698）は引張側の断面積と有効せいを使う。同書の付着照査（pp.700、707–708）は上端筋の条件や両端間の主筋応力度差を扱う。両端曲げ降伏時せん断力の定義（p.416）からは、長期曲げの代表位置で選んだ一つの耐力を異なる引張側の両端に適用する根拠は得られない。この略算から実際の降伏方向やヒンジ成立を判断しない。選んだ側の曲げ終局耐力が反対側より小さいとき、両端が異なる引張側で降伏する場合の要求せん断力を過小評価し得る。反対側の有効せいや配筋、上端筋の付着低減によって、せん断・付着の耐力も低下し得る。選んだ側のせん断・付着の照査で余裕度が1未満の場合は、静的略算の NG として保持する。選んだ側で照査を満たす場合は反対側の引張主筋の諸元、曲げ終局耐力、および同じ比較需要に対するせん断と付着（有効時）の条件を確認する。条件が成立しない場合は選んだ側の断面耐力を残し、要求せん断力とその余裕度を未算定として梁を理由付き未検定とする。

## Consequences

略算の結果と実際の確定総応答を区別でき、初期重力の用途・係数と需要の由来を保持できる。一方、全位置探索・補間や総応答の過強度需要は含まれず、特別な終局重力条件は別途根拠を揃える必要がある。

これは SEPIKA の先行対応範囲に関する採用判断であり、一般の全終局荷重条件の規準適合を立証するものではない。製品仕様・式・出典は[終局検定の統括](../../docs/calc_basis/08_部材終局耐力/07_終局検定の統括.md)を正本とする。
