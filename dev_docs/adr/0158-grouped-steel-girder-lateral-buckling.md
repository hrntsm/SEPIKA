# 一本部材の鋼梁横座屈は明示した単一補剛区間全体で照合する

- Status: accepted
- Date: 2026-11-25
- Related: [#1898](https://github.com/hrntsm/SEPIKA/issues/1898)

## Context

解析要素の分割位置は圧縮フランジの有効支点とは限らない。一本部材の合成された代表曲げだけでは規準の分布条件と最大需要が確認できない。短い要素長を横座屈長さとして採ると許容値を過大評価し、最大曲げを代表断面に限ると需要を過小評価し得る。

## Decision

一本部材の全長を各要素で共通の横座屈長さとして直接指定した場合のみ、その長さを一つの補剛区間の候補とする。分割した各要素の断面、軸、荷重と保存断面力、および接続境界を照合する。独立に確認できた不適合は保持するが、確認できない一本部材からは要素長や部分区間を使った横座屈の許容値を推定しない。全要素が明示的に横座屈長さ0を指定している断面照査と、連続する実材軸全長に対して正の部分補剛区間を指定した照査は維持する。

## Consequences

通常検定の許容値・結果の適用範囲が変わるため、検定契約版を120に更新する。解析契約は変えず、旧検定を保存していた場合は応力から再検定する。複数補剛区間の最大需要は [#1897](https://github.com/hrntsm/SEPIKA/issues/1897) で扱う。
