# SRC柱のルート2-1設計用せん断力には組合せと方向に対応する確認済み入力を用いる

Status: accepted

共通部材検定にある短期組合せの全断面力では、付1.4-2の一次設計用地震力だけによる柱せん断力を特定できない。モデルの部材接続だけでも、方向別の端部耐力、柱頭を制限する梁の材料別耐力、または柱両端の曲げ降伏は確定できない。節点間距離への置換や、重力参照を引いた値を用いると、設計用せん断力を過小評価することがある。

[ADR 0127](0127-src-column-seismic-bending-demand.md)の確認済み曲げ耐力を用いる方針に沿い、共通部材検定に、検定する地震荷重組合せの柱・局所方向・加力の向きに対応する確認済み入力と根拠参照を渡す。確認済みの内法高さと両端の鉄骨短期許容曲げ耐力は両方式で共通とし、RC部は検討方向ごとに必要条件を確認した方式を明示する。他部材の地震時せん断方式の設定は転用せず、根拠不足で別の方式にも切り替えない。原典に負値の扱いが明記されない代替式の負のRC要求値は未算定とし、絶対値や0を採用しない。

共通部材検定の追加時点では、GUIは新しい入力を保存せず、従来の未算定と独立不適合を維持した。

[#1928](https://github.com/hrntsm/SEPIKA/issues/1928) では、GUIで確定した登録を組合せ名だけでなく、解析の実行記録と生成入力・設計条件に結び付ける。同名の組合せを再解析した場合でも、根拠を前回の解析から無確認で流用できないようにする。登録はモデルそのものではなく特定の解析を参照する検定入力なので、プロジェクトの解析設定に保存し、照合できない登録は現行検定に渡さない。通常の検定入力の照合でも、参照組合せに登録があるときだけ採用された登録を含める。未登録の組合せでは従来の入力契約と結果が変わらないため、検定契約版を更新しない。
