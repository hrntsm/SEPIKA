# ADR 0045: 凹形床は全周支持の有限線分モデルで分配する

- Status: accepted
- Date: 2026-10-10

## Context

公開資料は格子重心から最短の垂線と同距離等分を示すが、凹角の辺延長・頂点負担を確定しない。
幾何モデルの違いは格子を細かくしても消えない。境界面積欠落と辺帰属の積分誤差も区別する必要がある。

## Decision

[Issue #437](https://github.com/hrntsm/SEPIKA/issues/437)の確定契約に従い、
無開口・全周支持の単純多角形について有限線分最近接と全同距離等分を採用する。
共有端点への等距離群を片全域で認証し、候補群変更が可能な真面積から辺別誤差上界を算定する。
最大セル寸法、局所原点、丸めεと要求精度の扱いは[製品仕様](../../docs/calc_basis/01_荷重/03_床荷重の分配.md#多角形床の幾何分配)を正本とする。

## Consequences

延長直線や二等分線の方式とのモデル差を、格子許容差で吸収しない。
床剛性・実応力の厳密解、一律安全側、他者の内部仕様との一致を保証しない。
境界の実面積保存を優先し、支持欠落・参照不明・資源不足・要求精度未達をゼロ荷重成功へ変換しない。
開口輪郭のモデル入力、自由辺への適用、別方式の台形精度（#438）へ範囲を拡張しない。
