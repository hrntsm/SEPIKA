# 梁の鉛直偏心を必須の数値として保持する

Status: accepted

梁の一律鉛直偏心は有限な数値を必須とし、偏心なしは0 mmで表す。未指定を認めるADR 0071の判断と、未指定偏心を入力状態として扱うADR 0076の判断を撤回する。2026-11-06のユーザー決定による。

未指定を導入して取り込み不備を利用者の追加入力へ転嫁すると、表示・計算・編集の各経路で不完全なモデルを扱う必要が生じる。必須数値によってこの状態を排除し、形式変換の責務を取り込み側へ戻す。保存形式の互換・移行はADR 0014に従う。
