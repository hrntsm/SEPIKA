# 鋼柱・鋼梁の二方向せん断は方向別検定比の和を採用する

- Status: accepted
- Date: 2026-10-18
- Related: [#417](https://github.com/hrntsm/SEPIKA/issues/417)、[#692](https://github.com/hrntsm/SEPIKA/issues/692)

H形鋼・角形鋼管・Otherの柱／梁の二方向せん断は、方向別の面積と軸対応を保って各方向の検定比を求め、その和をせん断の検定比とする。
純せん断は `Ry = abs(Qy)/(Ay fs)`、`Rz = abs(Qz)/(Az fs)`、`Rshear = Ry + Rz` とする。
二方向が同時に作用する場合も検定するため、同時二方向を理由付き未検定にする案は採らず、2026-10-18のユーザー指示「それぞれの方向で検定してその和が検定比としてください」を採用理由とする。

von Misesとの接続は、方向別のせん断応力度の和 `tau_sum = abs(Qy)/Ay + abs(Qz)/Az` を既存の式のτへ入れ、既存の軸力・曲げによる法線応力と独立検定を保持する。
各方向のvon Mises比全体を加算すると同じ軸力・曲げ成分を二重算入するため、この方法は採らない。
ユーザーは同日の確認に「Aでよいですが、ドキュメントにこの式で計算されているということを忘れずに明記してください。」と回答し、この接続と明式化を選択した。
参照マニュアルBE513は単一のτによる式を示しており、二方向の和はSEPIKAの追加採用規約として区別する。

H梁の二つの法線応力ケースとその最大値、H柱のウェブ端の法線応力、Box/Otherの法線応力は保持し、H柱とH梁の法線応力の評価差を統一する判断は含めない。
実際の式と適用範囲は[鋼構造断面検定](../../docs/calc_basis/06_一次設計/03_鋼構造_断面検定.md)を正とし、Pipeの既存合成とCFTの初期弾性は対象外とする。
