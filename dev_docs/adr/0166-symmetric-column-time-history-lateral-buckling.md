# 上下対称H形鋼柱の時刻歴横座屈を同時刻・補剛区間で照査する

Status: accepted

Related: [#1953](https://github.com/hrntsm/SEPIKA/issues/1953)、[ADR 0148](0148-steel-calculation-sources.md)、[ADR 0118](0118-asymmetric-column-time-history-peaks.md)

## Context

成分別包絡の端部曲げを組み合わせると、どの確定時刻にも生じない有利な曲げ勾配となり、横座屈を考慮する強軸曲げを危険側に判定し得る。同時刻の両端・中央を選ぶだけでも、支持位置と区間内の単調性や内部最大は確定しない。最大曲げ需要の時刻が、曲げ勾配による補正を含めた最大比の時刻とも限らない。

## Decision

上下対称H形鋼柱の時刻歴簡易検定では、確認済みの両実材端と一致する解析全長の単一補剛区間を扱う。節点間距離の既定値を変更する判断ではなく、通常検定とは異なり、係数算定に必要な区間の位置を確認できない場合は未算定とする。曲げの符号が反転する場合は、圧縮側となる各フランジに対して支点の確認を要する。

各確定時刻で解析が表す部材荷重とその時刻の断面応答から分布を取得し、規準の単調変化または内部最大の条件を確認する。同一区間の最大曲げと短期許容応力度を比較し、比で支配時刻を選ぶ。直接Cや部材端・中央の代表点を分布の確認に代用しない。規準分岐が未確認の場合は係数の代表値を仮定しない。最大値が平坦な範囲では端部の軸力・弱軸曲げだけから適用条件を外挿しない。強軸曲げの確定NGと部材組合せの未算定を分け、同じ解析区間で独立に確認できた材料許容上限の超過は横座屈の適用条件が不成立でも残す。引張軸力と強軸曲げが同時に作用する断面の横座屈を曲げ単独の判定で代用しない。

強軸方向の合算分布荷重が各荷重境界間で一定となる分布を照査する。強度が境界間で変化する分布は、丸めた極値座標で同時断面力を誤認し得るため、別の式分岐にフォールバックせず未算定とする。確認済み断面だけで材料許容上限の超過が分かる場合は、その不適合を残す。強度が変化する分布への適用拡張は [#1991](https://github.com/hrntsm/SEPIKA/issues/1991) で扱う。

## Consequences

全確定時刻の支配値と未算定理由は間引きと独立に保存し、線形途中保存は前半の照査を引き継ぐ。旧保存結果は照査なしとして再実行を案内し、当該記録を欠く途中状態は先頭から計算し直す。別ケースを再計算して現在の結果がある場合も、対象の結果を作成した入力と現在のモデルが一致しないときは照査を表示しない。静的解析・通常検定・モデル入力の契約版は変更しない。梁・上下非対称H形鋼柱の検定挙動と、時刻歴の引張軸力と強軸曲げの全時刻の同時性全般は対象外とする。
