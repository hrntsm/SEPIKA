# 平鋼の柱・大梁のせん断に検定不能を適用する

Status: accepted

平鋼の弾性せん断分布では、剛性と局所応力に対応する面積が異なる。剛性用面積を検定へ流用すると、同じ許容値を用いた局所応力の照査で合否が反転する有限例がある。[独立計算と公開検定入口の検証](../v_and_v/鉄骨せん断面積と合成_Issue951_採用範囲照合.md#平鋼の公開入口と独立した局所応力)

形状として平鋼を指定した柱・大梁では、どちらかにせん断力がある検定位置を理由付きで未算定とする。ウェブ用式の転用や、弾性局所応力に合わせる面積の置換を見送る理由は、平鋼に対する評価位置・応力と許容値の対応が確定していないためである。断面性能の供給方法はこの判断の根拠にならない。

適用条件の変更以前の保存検定は再利用すると旧適合判定を表示しうる。検定契約版を更新し、解析成果の契約から独立して失効させる。現在の適用条件と規準の参照箇所は[鋼構造の断面検定](../../docs/calc_basis/06_一次設計/03_鋼構造_断面検定.md#せん断の検定)を正とする。[Issue #1396](https://github.com/hrntsm/SEPIKA/issues/1396)
