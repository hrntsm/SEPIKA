# シェル要素による解析を廃止する

Status: accepted

[Issue #2033](https://github.com/hrntsm/SEPIKA/issues/2033) と追加の指示に従い、床だけでなく用途を問わずシェル要素の入力・解析・結果を廃止する。通常の床領域・床板・剛床、および壁版・耐震壁は別のモデルであり、入力・計算を維持する。シェルの用途による区別や、代替の床・壁解析モデルは導入しない。

旧プロジェクトのシェルを取り除いたり、剛床や壁エレメントに置き換えたりすると、利用者が指定した抵抗・荷重・質量の経路が変わる。[ADR 0014](0014-schema-compatibility.md) に従い、構造スキーマ版を維持する。旧入力の復元・変換やシェル専用の読込処理は設けず、通常の復号と計算契約の判定を用いる。解析・検定の適用対象が変わったため、結果の契約版を更新する。
