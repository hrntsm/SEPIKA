# SRC柱の部材種別の候補計算を内蔵H形鋼の材種表と実板厚で制限する

Status: accepted

内蔵鉄骨の基準強度を一律235 N/mm²で補うと、柱の圧縮耐力と鉄骨曲げ耐力をともに過大評価し、有利な部材種別を算出し得る。明示した降伏応力だけでは、指定建築材料の規格や個別認定の適用条件を確認できない。矩形SRC柱の内蔵H形鋼では、SS・SM・SN材のJISの種類記号を確定して基準強度を選ぶ。種類記号の不足や適用根拠が不足した柱は理由付きで未評価とし、自動判定を停止する。

現行のSRC柱の断面入力からは圧延H形鋼と鋼板組立H形鋼を識別できない。JIS G 3136の厚さ条件は圧延H形鋼のフランジと組立用の各鋼板で参照先が異なるため、両形態で条件が成立するようにSN材では両板の下限を確認する。種類記号と厚さによる選定は候補値の基準強度の数値を対象とし、塑性を期待する用途や溶接への適合、JISの全要求は個々の製品と設計条件で別途確認する。

SRC規準第6版の表4.1・注では、SS490の使用は溶接を用いない部分に限られる。現行入力から溶接の使用箇所を確認できないため、SS490を内蔵鉄骨に割り当てた柱の部材種別候補は理由付きで保留する。

一次検定と共通の材料解決でウェブ・フランジの実板厚を検証し、厚い方の区分から候補式に渡す共通の基準強度を選ぶ。対象の表値は板厚に対して同値または減少する。この選択で圧縮力比は同値または増加し、鉄骨曲げ耐力比は同値または減少する。したがって、候補式のままフランジ厚だけを使う場合と比べて有利な種別には移らない。

保有水平耐力の部材種別候補は、保存済み増分解析の応答と現在の材料情報から評価時に求める。候補値を保存せず、一次検定の結果も変わらないため、解析・検定結果の契約版を維持する。検討方向による評価の制限と、候補耐力・破壊状況の採用判断は別に追跡する。 [製品の適用条件](../../docs/calc_basis/07_二次設計/03_部材ランク.md#src-柱の種別)・[Issue #1417](https://github.com/hrntsm/SEPIKA/issues/1417)・[Issue #1418](https://github.com/hrntsm/SEPIKA/issues/1418)・[Issue #1419](https://github.com/hrntsm/SEPIKA/issues/1419)
