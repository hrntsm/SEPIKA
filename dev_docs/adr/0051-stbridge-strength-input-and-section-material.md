# ST-Bridgeの元強度指定と断面材料を分離する

Status: accepted

ST-Bridge 2.0.2の部材・断面・指定節点の原階・共通によるFcと、径別・位置別の鉄筋・鋼材gradeを、元の省略状態のまま保存する。強度採用結果を断面の属性へ補完しない。

nativeの材料割当は断面が持つ。ST-Bridgeからの実効強度は元指定から部材ごとに解決し、既存の部材材料消費口へ渡す。同じ断面でも部材明示Fcが異なる合法入力を、断面複製や最後の値の上書きで表現しないためである。採用grade・採用元と物性既定復元を分け、明示native割当の数値は標準grade解決と区別する。

SRC内蔵鋼の明示割当も鉄筋と同様に採用材料参照を保持する。標準gradeを表す名前と編集済Fyの数値が一致しない場合は、標準出力で数値が戻るのを防ぐため出力を拒否する。

材料の表示名変更は元標準gradeを変更しない。元指定の編集、明示物性の編集、ID参照の変更は編集コマンドで行い、同じ保存・undo/redo境界に置く。

領域へ分割した床へは元第1節点の供給を保持する。元省略の指定節点依存を標準出力の境界で表現できない場合は出力を拒否する。元床幾何の再結合・配筋全写像を強度対応に混ぜない。

材料をすべて断面の解決値へ置き換える案は、元省略と上位部材指定を失うため採用しない。元属性だけを保存して既存解析へ接続しない案は、画面・診断と実材料が食い違うため採用しない。
