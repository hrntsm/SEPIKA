# 線形時刻歴の再開状態に前半結果と生成条件を保持する

Status: accepted

## 決定と理由

途中の確定状態、先頭からの結果、全入力波形、準備済みモデルの計算入力、解析設定、自由度変換、解決済み減衰、解析計算契約版を専用ファイルへ一緒に保持する。既存のMessagePackとSHA-256を用い、形式識別子・形式版と破損検査値を付ける。旧形式・契約版からの移行は行わない。

変位・速度・加速度だけを保存する案では、再開区間のピークを全区間の結果と取り違えることを防げない。結果と状態を同じ保存単位にし、再開成功時だけ通常の全区間結果へ反映する。途中状態はプロジェクトとは別ファイルとし、現在のプロジェクト入力・設定の一致を要求する。振動ケース等、既存の計算入力照合から除外される付随情報は一致条件に加えない。

停止指定によって入力波形を切り詰めない。代表記録方向、自動間引き、絶対ステップ格子を全波形から決定し、停止点を詳細記録へ強制追加しない。再開開始点の重複又は格子外フレームを除き、全ステップ履歴と全ピークを合成する。これにより通常の連続実行と同じ記録列を保つ。

## 保存成果への影響

既存の積分式・減衰算定・通常結果の形式は変更しない。再開状態には現在の解析計算契約版の完全一致を要求する。任意時刻の補間、非線形履歴の再開、停止点以後からの別条件による継続は扱わない。
