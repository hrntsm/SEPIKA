# PCa 部材への対応を廃止する

Status: accepted

[Issue #1790](https://github.com/hrntsm/SEPIKA/issues/1790) の方針に従い、部材種別を問わず PCa 部材を対応対象から外す。RC 矩形梁・柱断面を受け付けていた水平接合面の使用限界・終局限界の検定と、そのための属性の入力・編集・保存を廃止する。部材共通の解析・検定、S 造合成梁の床板合成は現行の入力と計算で扱う。

開発中の OViKA 保存スキーマは [ADR 0014](0014-schema-compatibility.md) に従う。旧 PCa 属性が記録されたモデルは読込エラーとする。属性を黙って捨てたり、通常の部材の属性に読み替えたりすると、水平接合面を考慮したモデルとして誤って扱われるためである。旧版の部材検定に含まれる水平接合面の判定を現行結果として引き継がないよう、検定の計算契約版を更新する。
