# 梁の実材軸への偏心接続を既存要素の外側で合成する

Status: accepted

## Context

共有節点を梁の実材軸へ移すと、他部材の接続と自由度を変更する。既存の材軸方向剛域・端解放・仕口パネル適合はそれぞれ異なる責務を持つ。変位だけ、あるいは反力だけを個別に補正すると仕事共役が崩れる。実配置の既存APIは実断面形状も要求するが、形状を持たない保存断面性能による既存の解析経路は維持する必要がある。

## Decision

固定初期幾何の微小剛体写像を、元要素の全体座標12自由度の外側、既存の仕口パネル適合の内側へ被せる。全要素種別で同一の写像を使い、変位・接線・幾何剛性・内力・荷重・既存質量に適用する。部材内力は実材軸側に保ち、接続節点力と支持反力だけを転置写像で移送する。内部状態・確定・復元は変換後の内側状態のみを保持し、外側で変位状態を重ねて保存しない。

実断面形状を必要としない主架構梁の端位置解決を設け、実配置APIと同じ一律鉛直移動の計算を共用する。梁用途以外、二次小梁の新しい剛性算入、一般XYZ偏心入力、パネル中心偏心や新しい段違い適用は追加しない。

地動慣性入力は拘束自由度を含む全質量と既存の剛体影響ベクトルを乗じてから自由自由度へ抽出する。自由自由度へ先に射影した質量へ地動影響を掛ける順序は採らない。拘束並進と自由回転の偏心質量連成が消失するためである。偏心0の整合質量も同じ欠落を持つので、偏心の有無で分岐せず共通処理を是正する。

層切断の対象梁はN_i→P_i→P_j→N_jの物理経路で通過を判定する。上側自由体のN端力とP実軸の上側荷重から全交点合力を回復し、単一の実軸断面だけで腕の伝達を代用しない。上側はZ>切断面とし、対象梁の境界通過は>と<=の半開区間へ統一する。性能曲線の荷重帯分類も実P軸へ揃え、P=Nのときだけ端点部材荷重を直接節点荷重と同一視する。

## Consequences

形状なし解析断面の契約を維持しつつ、未指定偏心・参照欠落・不正座標を部材と端の診断付きで拒否する。全質量による地動影響の準備に追加の一回の組立を要する。既存整合質量を用いた地動応答は、偏心0でも拘束端側の寄与により変わり得る。節点対角集中質量の入力、既存の減衰則・積分法は変わらない。計算契約版を更新して古い解析成果の再利用を拒否する。
