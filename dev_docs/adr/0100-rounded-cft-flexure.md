# 角形CFTの許容・終局曲げで同じ角部材料領域を積分する

Status: accepted

## 判断

Issue #1104の角R連続化では、既存の外角Rと内角r=max(R−t,0)の材料領域を共通入力とする。角丸矩形の切断面積・図心一次／二次モーメントを円弧の解析積分で供給し、カタログ・直接入力の解析性能を置換しない。

許容は現行のコア線形圧縮応力と鋼管弾性断面係数による累加を維持する。終局の汎用共通ひずみモデルや安全率除算へ変更しない。#418の未確定な中長柱許容の全分枝は今回採用しない。

角形短柱の終局は、コアの一様圧縮Fcと鋼管の±Fyを全領域で積分し、軸力釣合いから中立軸を求める。コア外の中立軸も同じ応力モデルで評価できるため、端点の根拠のない直線補間を用いない。R=0の旧端点補間値は保存対象とせず、矩形独立積分との整合を保証する。円形の既存方式は変更しない。

中長柱終局は、同一検討軸・同一座屈長さのA/I/Zpを既採用の柱曲線へ接続する。鋼管基準曲げをFy Zps、コア基準曲げをFc Zpc/2とし、長方形でも幅を反映する。正Rの中長柱は既確定のFc≤58.8399・lk/D≤30に限定する。柱分類の代表せいと柱長境界は維持し、角Rの連続性を別の境界の平滑化へ拡張しない。

## 理由と限界

藤本ほか2009の印刷式は同心等厚円弧と指定中立軸域を扱う。同じ応力ブロックの領域積分を使うことで、印刷式を適用域外へ外挿せず角部内・コア外の中立軸を扱える。0<R<tの内側直角と長方形の中長柱は、実輪郭と既採用曲線の明示的な準用として区別する。

形状の連続性と数値Verificationは規準全体への適合・経験曲線の安全側・実験Validationを認定しない。Muを用いるQD1/minの要求せん断も変わるため、曲げ耐力の低下だけを安全側としない。採用仕様・適用範囲は製品docs、実行証拠はV&Vを正とする。
