# CFT柱は両軸の座屈長さ直接指定を必要とする

Status: accepted

[#1400](https://github.com/hrntsm/SEPIKA/issues/1400)では、接続部材の剛度比から求める自動KのCFTへの一般適用条件を確認できなかった。柱脚・梁遠端・半剛接の回転拘束、周辺架構の水平拘束、荷重状態に応じた軸力分布と座屈モードを決める根拠が必要である。固定自由柱の独立例では、自動Kは許容圧縮耐力を過小評価し、部材長で補完した終局検定は軸圧縮終局耐力を過大評価して合否が逆転した。[原典と有限例](../v_and_v/CFT柱の座屈長さ_Issue1400_2026-11.md)

共通の許容応力度検定、GUIの時刻歴詳細、およびGUI・MCPのCFT軸終局検定は、強軸・弱軸の有限な正の直接座屈長さを必要とする。片軸でも不足または不正なら対象と軸を示す。許容検定は対象柱を未検定とし、軸終局は既存の一括エラーの契約に従う。K=1や一律の係数、通常S柱の「0＝座屈無視」を代用しない。式単体に長さを渡す数値APIは維持する。

単独の軸終局検定は既存の代表断面を用い、両軸の入力長さでそれぞれ軸圧縮耐力を評価して小さい値とその分類を採る。座屈曲線の分枝境界に僅かな段差があり、長さの大小だけで耐力を選ぶと最小値を取りこぼし得る。曲げの表示は強軸を対象とし、強軸の直接長さで分類・算定する。検定契約60で旧検定成果を失効させる。

現行仕様は[CFT柱の座屈長さ](../../docs/calc_basis/06_一次設計/04_SRC_CFT_断面検定.md#cft柱の座屈長さ)と[CFT柱の軸終局耐力](../../docs/calc_basis/08_部材終局耐力/06_CFT_柱_終局耐力.md)を正とする。
