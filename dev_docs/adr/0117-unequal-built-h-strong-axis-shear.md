# 上下のフランジ厚が異なる組立H形鋼の強軸せん断を未算定とする

Status: accepted

薄い方のフランジ厚を上下に用いるとウェブ内法面積を過大に見積もり、せん断の不適合を見逃しうる。実ウェブ面積による平均と初等梁の局所応力度は異なる比較値になり、通常のH形断面に関する規準の記載では、上下のフランジ厚が異なる断面に対する評価方法と許容値の対応が確定しない。

該当する柱・大梁に強軸せん断力がある位置の強軸せん断検定を理由付きで未算定とする。法定細長比と独立に確定した軸曲げの不適合を保持する。軸力と強軸せん断だけが作用する無欠損断面では、形状と材料から確定できる軸応力度の材料上限超過も保持する。旧適合判定の再利用を防ぐために検定契約版を更新する。[適用条件と独立比較値](../../docs/calc_basis/06_一次設計/03_03_鋼梁_柱のせん断検定.md#上下のフランジ厚が異なる組立h形鋼の強軸せん断)・[Issue #1542](https://github.com/hrntsm/SEPIKA/issues/1542)
