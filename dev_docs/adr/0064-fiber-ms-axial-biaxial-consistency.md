# Fiber と MS の軸・二軸曲げを同じ材料応答へ整合させる

- Status: accepted
- Date: 2026-10-19
- Related: [#496](https://github.com/hrntsm/SEPIKA/issues/496)、[#715](https://github.com/hrntsm/SEPIKA/issues/715)、[ADR 0063](0063-wall-side-column-foundations.md)

## 判断と理由

通常の塑性化域 Fiber／MultiSpring と壁側柱に、軸・二軸曲げを同じ材料試行状態から求める共通の構成則を採用する。
曲げだけを材料応答へ接続し、軸力を弾性のまま残す案は、軸降伏後の再配分・変形・履歴仕事を整合させず、安全側とも判断できない。
側柱だけを修正する案も、壁との接続によって同じ材料断面の意味が変わるため採用しない。

全可撓長の弾性梁へ、両端断面の軸・二軸曲げの塑性増分を組み合わせる。
追加変形からは完全な初期断面剛性に対応する弾性分を控除する。
断面全ひずみを直列追加すると弾性変形を二重計上し、対角成分だけを控除すると非対称断面の初期連成を失うためである。
この初期弾性分は履歴中に再定義しない。

材料の実断面座標と右手系の局所軸を保ち、断面力と部材端力・追加変形を仕事共役に結ぶ。
両端の軸・二軸曲げを同時に釣り合わせ、収束した同じ試行状態の内力と整合接線を返す。
接線と変位の積や、両端軸力の平均で非線形内力を代用しない。
元の端部条件と壁側柱の回転解放は材料構成と分離し、回転解放を理由に軸塑性を無効にしない。

材料履歴・局所未知数・内力と接線のキャッシュは一体で確定・復元する。
局所収束だけでは確定せず、特異・非有限・不収束を弾性への代替や微小剛性の追加で隠さない。
この判断は要素の応答と保存状態へまたがるため、一部の成分だけを旧方式へ戻す変更では成立しない。

## 記録の範囲

本書は保存ブランチ `preserve/496-before-scope-split-20261021` の同番号の判断を、現在の実装と製品文書へ照合して復元したものである。
旧版の試験成功や未検証範囲を、現在の実装の検証結果へ読み替えない。
全長分布塑性化、新しい材料則、動的な側柱解放、P–Δ、非平行共有柱の対応を追加する判断ではない。

現在の算定式・単位・適用範囲は[非線形梁要素のモデル化](../../docs/calc_basis/04_要素剛性/09_非線形梁要素のモデル化.md#ファイバーモデル)、接続の分離は[ADR 0063](0063-wall-side-column-foundations.md)を正とする。
