# 自立壁の基準剛性は二方式を選択可能とし、Rsは付加剛性を反映して再解析する

Status: accepted

2026-10-27のユーザー指示により、自立壁の付加剛性の基準には代表内柱方式と層内柱合算方式を用意する。異なる算定方法の選択を認め、両式の統一や数値の一致を実装の前提にしない。方式は建物全体で共通とし、初期選択は既存の層内柱合算方式とする。

代表内柱方式では各層で利用者が1本指定し、同じ柱のX・Y方向の一次解析結果から求めた剛性と断面積を使う。これは解説書のD値式との同一性を主張する判断ではない。柱の指定と方向別の扱いを明示し、将来の方式変更で評価条件が曖昧になることを避ける。

Rsは壁の付加剛性と配置を反映した評価用再解析で求める。剛性比だけで変位を補正する代替案は、並進・回転の連成により誤差方向が変わり、一律に安全側とはいえない。さらに確認した補正式は2025年版解説書の指定式ではなく、別の公開計算資料の採用例であり、ユーザーはその選択機能を不要と判断した。再解析に必要な処理・計算量を受け入れ、近似補正は設けない。

斜め壁は壁面内方向の単一ばねとし、方向別基準剛性を壁方向へ投影した剛性に壁方向ベクトルの外積を乗じる。Rs再解析はXY連成と壁位置による回転連成を保持し、Reも同じばねの方向別成分を使う。既存の方向別対角成分を保持して連成項だけを加える代替案は、異方性のある柱で抵抗方向が壁方向からずれるため採用しない。既存斜め壁のReも変わり、一律に安全側とはいえないことを提示した上で、ユーザーはQ8でこの方式を明示選択した。

[ADR 0083](0083-misc-wall-coefficient-lower-bound.md)のnの下限に関する判断は維持する。同ADRで扱わなかった代表柱指定とRs接続を今回の対象に加える。判断の背景と独立した連成例は[Issue #740の調査記録](../v_and_v/自立壁Rs接続_Issue740_調査記録.md)を参照する。このADRは採用方針の記録であり、実装・検証の完了を示すものではない。
