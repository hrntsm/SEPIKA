# ADR 0056: RC壁の終局せん断耐力方式を建物共通の二択にする

## Status

accepted

## Context

公開計算資料には、コンクリート項の係数だけでなく分母も異なる荒川min／meanの二式がある。Qu全体の倍率変更や小さい値の自動採用では、設計者が選んだ算定方式を再現できない。参考骨格と実解析の初期耐力へ異なる方式を使うと、結果表示・Ds評価と解析骨格の対応も失われる。

## Decision

建物共通のStressAnalysisCfgにRcWallShearMethodの二択を一項目だけ置き、新規Defaultをmeanとする。部材・断面・階別の上書き、汎用registry、二方式同時計算・比較を追加しない。採用式と適用限界は[製品計算根拠](../../docs/calc_basis/04_要素剛性/10_RC壁の壁脚内力と初期耐力.md#終局せん断耐力の方式と入力)を正本とする。

#535の材料・方向配筋と、[ADR 0055](0055-rc-wall-static-face-and-initial-capacity.md)の同一face入力・run初期静的前処理を再利用する。参考骨格と解析前正負Quへ同じ選択を明示的に渡す。初期Quは開始時Modelから固定し、モデル化表示とDsは既存runの採用値を読む。重複する前処理や旧仮定による再計算を作らない。

成功・未算定とも方式を識別可能にする。既存GUI編集・Undo・入力一致判定とModel保存を使い、切替前成果と開始後編集されたjob結果を拒否する。解析・検定の計算契約版を更新し、旧結果の互換変換を行わない。

## Consequences

設計者は建物全体の選択と結果の方式を追跡できる。方式切替は両consumerの数値を変えるため再解析・再検定が必要になる。選択によるQuの大小は対象壁での安全側判定や実験Validationの代用にならない。

材料・応答不足や限定域外では他方式・0耐力へのfallbackを採らない。#496の側柱・部材荷重・Fiber/MS・共有柱などの拡張と、求解中の耐力更新・履歴再構築・自動step探索は対象外とする。
