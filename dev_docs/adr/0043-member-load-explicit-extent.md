# 部材荷重の全長追従は強度を保持する明示属性とする

Status: accepted

等分布の形状と全長へ追従する意図は別であり、現在の材長と区間が一致しても固定距離の入力である場合がある。数値比較で意図を推定すると、保存・編集・階コピーで利用者の固定区間を変えてしまうため、`MemberLoadExtent` として固定距離と全長等分布追従を保存する。

全長追従は利用者入力の等分布だけに指定でき、強度と全体座標の方向を保持する。総荷重一定の再配分は部材の長さ当たり荷重という入力を変えるため採用しない。固定距離区間を保持できない座標変更は切り詰め・消去せず全体を拒否する。複合編集は中間形状でなく最終候補を判断し、逆操作は座標と変更対象荷重のスナップショットで復元する。

属性がない入力には固定距離の既定値を与えるが、全長一致による追従推定やスキーマ版間マイグレーションは作らない。[ADR-0014](0014-schema-compatibility.md) に従い初回リリース前はスキーマ版1を維持する。

参考資料 §2.2.2(6) は用途・形状を示す資料であり、節点編集仕様の根拠ではない。利用者向けの現在仕様は [荷重の入力](../../docs/calc_basis/01_荷重/07_荷重の入力.md) を正本とする。
