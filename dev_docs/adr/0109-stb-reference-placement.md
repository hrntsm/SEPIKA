# STBの配置基準を材軸偏心へ変換し未確定の幾何を拒否する

Status: accepted

ST-Bridge 2.0.2の部材基準点・回転・端オフセットをSTB全体座標で解決し、SEPIKAの図心材軸偏心へ変換する。省略成分は0として確定し、利用者の追加入力へ転嫁しない。共通global変換は部材配置の解決後に一度だけ適用し、書き出しは変換済みの全体座標を用いる。点とベクトルを区別し、節点荷重も同じ回転で変換する。

原節点・支持アンカーを移動せず、実配置から接合や分割を推定しない。小梁・間柱は可視化専用の姿勢を持ち、片持ちの端正規化では偏心・負担率と幅向きを同じ物理端へ再対応する。力学基底や数量、計算照合モデルには姿勢を適用しない。原入力と根拠digestでは姿勢を保持する。未リリースの保存スキーマは[ADR 0014](0014-schema-compatibility.md)に従い版1を維持する。

形状のない梁・小梁・ブレースはSTB基準点と材軸との差を確定できないため、正常な部材出力としてRawへ退避しない。図心基準の柱・間柱と未使用断面の既存Raw出力、内部任意断面の編集・OVIKA保存は維持する。この範囲で[ADR 0036](0036-stbridge-section-use-explicit-mapping.md)のRaw出力判断を補足する。

端オフセットの差が基準材軸に沿い、実材軸が元の向きを保つ場合は、基準線の断面姿勢を本体の実材軸基底でも表せる。断面基準点から図心までの移動は両端で共通なので、端点間の差を変えない。この条件に限り異値を入出力する。丸めで軸方向以外の差・方向変化を見落とさないよう、方向判定に角度許容を導入しない。共通座標変換後にもこの条件を確認し、直角の回転は厳密な符号変更と座標交換で扱う。異値を持つ二次部材は支持アンカー化や節点照合による位置のずれを拒否する。出力時は逆変換したオフセットの再変換で両方の実材軸端が保持されることを確認する。

両端の座標に同じ丸め誤差が生じる場合は端点間の差だけでは見つからない。異値でのSTB基準点と図心のオフセット換算、各偏心を節点へ加えた端位置、共通座標変換の位置演算は、各端の全成分で保持を確認する。配置の逆算に使った内部断面が標準XMLから復元できるとは限らない。異値部材を含む場合に出力するXMLを一度読み直し、該当する主架構・二次部材の基準端・実材軸端・断面基底・断面形状を照合する。二次部材は支持の有無にかかわらず、STBに書き出す端順序で表示幾何を照合する。

支持アンカーの基準端が節点と一致しても、読み直した結果の親支持が元と一致するとは限らない。異値二次部材は、二次部材を介する間接支持をたどり、各支持先と取付き位置を同じ再読込結果で照合する。

共通回転の積が丸められてから差し引かれると、両端の差を保ったまま回転後の座標成分が失われることがある。異値の場合は、回転角から得た正弦・余弦で各端の基準点・実材軸端・偏心を変換する積と加減算も検査する。

軸直交差を受けるには、STB基準線の断面姿勢と偏心後の材軸を独立に保持する本体表現・双方向変換と独立した幾何検証が必要となる。[Issue #1367](https://github.com/hrntsm/SEPIKA/issues/1367)の全完了条件にはこの対応が残る。

公式XSDは圧延C/L/Tの半径に正値を必須とする。現在の内部形状はこの半径を保持できず、非対称断面の図心と基準点差を正確に変換できない。0半径への置換、XSD制約の緩和、無通知の属性損失を避け、標準入出力を理由付きで拒否する。正確な表現拡張は[前提Issue #1386](https://github.com/hrntsm/SEPIKA/issues/1386)で追跡し、本Issueの非対称標準往復の未達条件を消さない。

採用仕様と出典は[製品仕様](../../docs/model_io/02_ST-Bridge_形式.md#部材の基準位置と回転)、実行証拠と残条件は[V&V](../v_and_v/STB配置変換_Issue1367_2026-11.md)を参照する。

公式にない属性・要素を用いた正常出力も、正確な配置の意味保証から除外する。組立Hは上下幅・上下厚がそれぞれ等しい場合だけ公式A/B/t1/t2で出力し、非対称native断面は両出力入口から理由付き拒否する。平鋼・中実丸鋼・リップ溝形の正式タグ接続は[Issue #1387](https://github.com/hrntsm/SEPIKA/issues/1387)へ分離し、既存の方言タグを標準成功として返さない。内部の断面性能と姿勢はOVIKAで保持する。

SRC内蔵Hの実半径・Roll/Build保持は[旧Issue #414](https://github.com/hrntsm/SEPIKA/issues/414)で未実装のまま見送られた既知の制約であり、この変更で新規対応・全SRC禁止を追加しない。一般SRCの正確な物理形状往復は本Issueの未達条件に残す。C/L実半径等の[旧調査 #613](https://github.com/hrntsm/SEPIKA/issues/613)と、新前提#1386の実装責務を区別する。
