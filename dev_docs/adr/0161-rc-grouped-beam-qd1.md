# 一本部材のRC矩形梁は物理スパン全体の釣合いでQD1を求める

- Status: accepted
- Date: 2026-11-26
- Related: [#1881](https://github.com/hrntsm/SEPIKA/issues/1881), [#1851](https://github.com/hrntsm/SEPIKA/issues/1851), [#1885](https://github.com/hrntsm/SEPIKA/issues/1885)

## Context

一本のRC梁を解析上分割しただけで設計用せん断力が変わると、検定が解析モデルの分割に依存する。端部の降伏曲げと長期荷重から求める成分には、同じ物理梁の外端と荷重範囲を用いる必要がある。線材の接続だけでは中間支点の有無、曲げ伝達、断面の向き、その他の荷重伝達を保証しない。

## Decision

通常検定では、同一の物理スパンを確認した一本部材に限り、外端断面の降伏曲げの組合せと全区間の部材荷重からQD1を求める。強軸曲げの伝達条件は単一要素の梁に準じる。分割梁では全スパンの外端反力を算定する前提として両外端の局所Qy方向の反力伝達も確認する。直に拘束または支点ばねを与える外端と、実柱面を与える平行な柱を軸方向に介してその反対端の支持へ伝える外端に限る。独立に確認できない荷重、局所軸、曲げ伝達・外端断面は理由付き未算定とする。区間の降伏曲げや反力、別の崩壊機構、時刻歴の応力包絡から代用しない。時刻歴簡易検定では分割梁のQD1を扱わない。根拠と適用範囲は[RC梁のせん断検定](../../docs/calc_basis/06_一次設計/02_02_RC梁のせん断検定.md#一本部材に指定した分割梁)に記載する。

## Consequences

通常検定の保存結果を更新するため設計契約を123にする。解析契約、終局検定、分担支持の検定、QD2単独の適用条件は変更しない。単一要素の梁に対する反力伝達の確認は [#1966](https://github.com/hrntsm/SEPIKA/issues/1966) とする。[独立検証記録](../v_and_v/RC分割梁の全スパンQD1_Issue1881_検証.md)を参照。
