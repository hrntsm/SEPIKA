# 床板筋の寄与を確認できないRC大梁による柱のせん断需要低減は保留する

- Status: accepted
- Date: 2026-11-25
- Related: [#1936](https://github.com/hrntsm/SEPIKA/issues/1936)、[#1906](https://github.com/hrntsm/SEPIKA/issues/1906)

## Context

日本建築学会『鉄筋コンクリート構造計算規準・同解説』2024年版の第15条(15.8)式は両端柱降伏を原則とする。柱頭の梁が曲げ降伏する場合は梁端の降伏曲げで置換できるが、解説 pp.179–180 は床板筋の寄与に触れている。既存モデルから有効な配筋・定着を確認できず、床板の影響を無視した梁の降伏曲げを使うと柱の設計用せん断力を過小評価し得る。

## Decision

最上階・一般階とも、床板筋を含む梁端の降伏曲げを確認できない候補は比較から外す。[ADR 0151](0151-rc-column-qd1-mechanism-comparison.md)の該当する床板付き候補の扱いをこの判断で置き換える。実板厚のある床板の取付き線を複数の梁で支持する場合は、既存の支持区間の解決結果から各梁を特定する。荷重のみの取付きは床板の曲げ寄与とみなさない。両端柱降伏と独立に確認できた候補は保持する。未確認の候補を最小値の比較から外すことで、確認できない低減を適用しない。柱端の値を得られない場合に検定位置の値で代替せず、当該方向を未算定にする。梁の床板筋算定は [#1882](https://github.com/hrntsm/SEPIKA/issues/1882) で扱う。

## Consequences

通常検定と時刻歴簡易検定で候補除外の理由が分かる。地震時応力に基づくQD2単独と独立の照査結果を変えない。保存したことのある検定結果は再計算する。解析結果の契約は変更しない。
