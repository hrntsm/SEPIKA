# H形鋼大梁の床板合成剛性は設計者の明示確認を要する

Status: superseded by ADR-0148

床板の隣接と厚さだけでは、鋼とコンクリートの間でせん断力を伝えられるかが分からない。床板を考慮した剛性から鋼梁単独の剛性へ切り替えると応力分配も変わり、安全側かどうかは評価量と架構に依存する。接合条件の欠落をそのいずれかの剛性で補う案は採らない。

大梁単位で、現行近似の適用確認または非合成の判断を保持する。床板材種は既存の主材料解決を共有し、鋼床板をコンクリートの換算式から除外する。コンクリート床板が接して適用が確認できない場合は、採用剛性を未算定とし、解析を保留する。準備計算には判断理由を残し、利用者が入力を修正できるようにする。

大梁が直接支持するRC床板を協力剛性の候補にする。床領域全体の幅と同領域の全RC床板の最大厚は現行近似の組であり、どちらもこの判断で変更しない。鋼床板が混在する領域は全幅をRCの協力幅とする根拠がないため、合成剛性を保留する。

床板側・材軸方向ごとの接合を保存する案もあるが、現行近似は一本の大梁に一つの強軸曲げ剛性を用いるため、入力粒度と計算で表現できる範囲を揃える。接合の力学モデルや、協力幅・平均法の根拠の検討は [#1306](https://github.com/hrntsm/SEPIKA/issues/1306) で扱う。
