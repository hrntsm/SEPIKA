# RC梁の床板厚を各側の取付長で加重平均する

- Status: accepted
- Date: 2026-10-25
- Related: [#618](https://github.com/hrntsm/SEPIKA/issues/618)、[#450](https://github.com/hrntsm/SEPIKA/issues/450)

## 背景

全長1床板へ限定した初期修正では、小梁で床板が細分される実モデルの剛性を算定できなかった。
床板群を削除したfixtureや停止期待へ置き換えると、本来の統合保証を失う。
利用者は床板厚の長さ加重平均を指定し、剛性過大・変形過小となり得る説明を受けた上で明示承認した。

## 決定

各側に同じ内法距離・協力幅の矩形区間があり、実厚と上端一致を個別に検証でき、重複・隙間なく元構造スパン全長を覆う場合に限り、実厚を支持取付長で加重平均する。
平均厚を左右フランジ矩形へ用い、梁1本の強軸倍率を算定する。左右の分割点は一致させない。
I・倍率・柔性の平均、幅変化の吸収、区間柔性積分は採用しない。
版なし混在、幅変化、段差、Attached、未設定・未解決、不正な個別厚を平均で補わない。
重量・数量・質量とS/SRC梁にはこの平均を流用しない。
採用式・条件と危険側例は[製品計算根拠](../../docs/calc_basis/04_要素剛性/01_ティモシェンコ梁要素.md#剛性計算上の付加協力幅壁エレメント上下梁雑壁)を正本とする。

## 安全性と採らなかった案

この近似は安全側を保証しない。一定曲げ・一定Eで、平均厚の剛性が区間別回転を一致させる等価剛性を上回る有限例を独立検証した。
厚さ平均以外の近似や、既存荷重・重量の適用条件拡大は承認されていない。
区間別柔性積分は別課題#517であり、今回導入しない。

## 承認と確認

2026-10-25の利用者発言「長さで重みづけされた平均値としその使用をドキュメントに記載してください」「対象は床板厚です」を受けた判断である。
危険側可能性の説明後、「それはそれでよいです。結局一本の梁で一つの剛性増大を考慮する以上をなにかの妥協が生まれます」と承認された。
