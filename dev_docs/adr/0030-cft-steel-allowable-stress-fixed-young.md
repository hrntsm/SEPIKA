# CFT の鋼管材料を専用参照で保持する

Status: accepted

## 決定

CFT の `Section.material` は充填コンクリート、`Section.steel_material` は鋼管材料として保持する。鋼管部分の物性は鋼管材料から、充填コンクリートの Fc・コンクリート種類は主材料から解決する。

## 背景と理由

CFT はコンクリートと鋼管の複合断面であり、単一の主材料では両領域の物性を表せない。ST-Bridge 取り込みでは `strength_concrete` を主材料、`StbSecSteelColumn_CFT_Same` の `strength` を鋼管材料へ分離して解決する。

## 影響

- `strength` がない入力は取り込みを継続するが、鋼管材料未設定のまま質量特性・自重の解決時にエラーとする。
- 質量特性は鋼管領域へ鋼管材料の密度、充填部へ主材料の Fc・コンクリート種類から求めた無筋コンクリート密度を適用する。

## 許容圧縮応力度に用いる E（#767、2026-10-25）

ユーザーは「正の有限な材料Eを許容し、式へそのまま使う」と明示した。
CFT鋼管の許容圧縮応力度にも鋼管専用材料のEを用い、非標準値を入力範囲として許す。
0以下・非有限のE、または算定中のoverflow/underflow等で必要な正値を表現できない場合は理由付き未算定とし、固定205000へ補完しない。

旧固定Eの理由だった専用材料参照の不在は#367で解消済みである。
固定値は低Eの具体例で圧縮耐力を過大評価するため、材料参照が可能な現在も無条件に安全側として維持することはできない。
非標準Eを拒否する案と原典確認まで保留する案に対して、今回はユーザーが既存一般式への直接入力を選択した。
これは原典本文で任意EのCFT適用を確認した判断ではない。取得HTTP403と本文未閲覧は[調査記録](../handoff/CFT鋼管E_Issue767_調査記録.md#url取得の失敗記録)に残す。

等価断面ns・充填材E・F・密度・仕口パネルの契約をこの判断で変更しない。
検定契約版を更新し、解析成果を生成元に持たない直接設計成果を含む旧検定成果を再検定まで利用しない。
