# 自立壁n倍法の下限を原典とそろえ、方式全体の適合判断と分ける

Status: accepted

## 背景と判断

[Issue #889](https://github.com/hrntsm/SEPIKA/issues/889)で2025年版第2版第1刷の付録1-3.1(9)④、p740–741を直接確認した。原典の代表内柱D値式にはnの下限1がある一方、確認した層内合算の公開採用例に1未満を認める直接根拠は見つからない。入力可能であることだけを根拠に1未満の受理を続けない。

既存の層内合算式は変更せず、係数の下限を原典にそろえる。これは入力範囲を制限する判断であり、代表内柱D値式と層内合算K式の同値性や方式全体の適合性の証明ではない。新しい近似・代表値への置換は導入しない。Rs接続・代表柱指定・Ke直接入力・開口スリット拡張は扱わず、[#740の接続保留](../v_and_v/自立壁Rs接続_Issue740_調査記録.md)を維持する。

不正な係数を1又は未指定へ補完すると、利用者が指定した評価条件を黙って変えるため拒否する。保存時にも拒否し、失敗時は既存ファイルを保持する。範囲外の旧ファイルの自動修復・移行は行わず、[ADR 0014](0014-schema-compatibility.md)に従ってモデルスキーマ版は1を維持する。GUIには係数編集欄が存在しないため、この判断で新設しない。

Re/Fesの適用条件と3D質点系生成の適用条件が変わるため、解析契約61→62、検定契約32→33に更新する。保存成果を新しい適用条件で再認定しない。結果の構造を変えないので結果スキーマ版は据え置く。係数を増やした場合のRe/Fesの方向は壁位置と重心に依存し、一律に安全側とは判断しない。

## 証拠と仕様の正本

[限定原典照合・独立値・製品試験](../v_and_v/自立壁n下限_Issue889_確認記録.md)に確認範囲と未確認を記録する。採用式・係数・制約の正本は[形状係数Fes](../../docs/calc_basis/07_二次設計/04_形状係数_Fes.md)とする。
