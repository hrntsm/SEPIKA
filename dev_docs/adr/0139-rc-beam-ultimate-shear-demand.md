# RC矩形梁の要求せん断力の上側評価を静的終局検定の条件とする

- Status: accepted
- Date: 2026-11-21
- Related: [#1711](https://github.com/hrntsm/SEPIKA/issues/1711)、[ADR 0120](0120-rc-beam-static-hinge-applicability.md)

## Context

部材の曲げ強度を略算できる条件と、その曲げ強度から保証設計の要求せん断力を過小評価せずに求められる条件は異なる。通常域の材料・配筋で引張降伏が先行する独立例でも、曲げ略算を用いた要求せん断力が比較値を下回り、せん断判定が逆転した。[RC梁の曲げ終局耐力略算の根拠](../../docs/calc_basis/08_部材終局耐力/01_01_RC梁の曲げ終局耐力と曲げ終局時せん断力.md)

## Decision

支持と対象方向の機構を照合した上で、曲げ略算の適用と、要求せん断力に用いる曲げ強度の上側評価を個別に求める。現行入力の材料・断面からどちらも確認できないため、静的比較需要の計算は保留する。参考曲げ略算と既存の診断情報は保持する。十分な根拠を持つ確定総応答の比較需要と、曲げ略算による比較需要は別扱いとする。

## Consequences

静的検定は理由付き未検定となる。根拠を確認できた耐力について長期せん断力だけで超過が確定する場合は、不適合を示す。解析の確定総応答によるせん断・付着の比較には参考曲げ略算の適用可否が影響しない。[静的検定の適用条件と表示](../../docs/calc_basis/08_部材終局耐力/07_01_静的_両端ヒンジ略算による終局検定.md#rc矩形梁の引張側と評価範囲)
