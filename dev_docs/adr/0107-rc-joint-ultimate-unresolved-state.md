# ADR 0107: RC終局接合部の設計状態が未確定ならモデル候補を未算定で保持する

- Status: accepted
- Date: 2026-11-18

## 背景

#1377で、応力列を候補列に使う入力組立が、柱の欠落で接合部を消し、列順や直交成分で耐力・需要を変えることを確認した。対称モデルの算術一致だけでは、設計状態・方向・材料配筋定着の成立を証明できない。

## 判断

RC終局接合部の候補をモデルのRC柱・RC矩形梁の端部接続から抽出し、現在の公開入口では理由付きSkippedにする。明示パラメータの低レベル耐力計算は維持する。応力や材料の欠落を0で補完せず、方向や降伏状態を本数・先頭部材・応力最大値から推定しない。共通の部材収集とRC許容・S/CFTの入力組立は変更しない。

## 理由と影響

現APIには検討目的・設計状態・定着等の成立を一組で証明する入力がなく、正常ケースだけを算定できる境界を確定できないため、終局自動算定全体を保留する。下柱優先や方向の幾何分類だけで数値を残す案は、残りの成立条件を解決しないため採らない。新しい近似・閾値・式は追加しない。

検定成果の計算契約版を更新する。将来自動算定を再開する場合は、同じ検討面・作用状態の力と幾何、材料・配筋・定着の成立、独立した釣合い期待を合わせて確認する。
