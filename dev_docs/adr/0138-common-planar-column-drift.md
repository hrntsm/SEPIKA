# 二次元線形せん断型の柱剛性に加力方向の共通層間変位を求める

Status: accepted

複数剛床や面内変形する床では、層を一つの並進と回転で表せることを前提とする [ADR 0135](0135-torsional-cancellation-holds-column-stiffness.md) の相殺判定を適用できない。柱の負担水平力が残ったまま局所の層間変位が小さくなると、柱の力と変位の比を使う二次元線形せん断型の層ばねは、独立した一様並進の対照より過大になる。[公開生成と独立対照の照合 #1701](https://github.com/hrntsm/SEPIKA/issues/1701)

対象柱が加力方向に共通の層間変位を示すかを照合し、直交方向の層間変位がある場合も採用を保留する。判定は層間変位の相対量に基づく。絶対変位を基準にすると、変位が相殺される応答と、それと同程度まで荷重を縮小した一様並進の応答を区別できない。選択した応答に対する水平変位の整合確認であり、他の自由度の力への寄与や別の加力状態での独立性はこの照合では分離できない。

採用を保留した層では代替ばねを同定するための独立応答がないため、対象柱と理由を示して質点系の生成を止める。既存の保存質点系が新しい採用条件を経ず利用されることを防ぐため、解析契約版を更新する。
