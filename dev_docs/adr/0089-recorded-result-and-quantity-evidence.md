# 結果と数量の根拠を固定入力の参照から開く

Status: accepted

## 判断

[#978](https://github.com/hrntsm/SEPIKA/issues/978)の根拠閲覧は、[ADR0088](0088-version-scoped-references.md)の結果参照と、数量用の固定入力参照を一つの入口に受け入れる。
静的結果の参照は記録された実行・入力版・計算契約を検査してから、保存入力の節点座標と対応する変位・荷重状態を開く。
主架構検定では既存の式名・数値詳細と採用応力源を使い、未検定の支配ケースを確定しない。
閲覧中の数値と入力は固定し、現行入力との有効性と保持中の実行との一致は既存判定で随時照合する。

数量は既存の随時計算であり、結果の実行スロットや保存履歴を増やさない。
数量の根拠参照は、生成時の入力参照、モデル全体という集計対象範囲、完全な固定モデル、数量集計契約版を含む。
参照は公開された共通入口から開き、固定モデルに既存の数量集計を適用して数値・対象・不完全状態を再構成する。
数量集計契約は整数版1から開始し、再構成する数量・対象範囲の意味を変える変更では更新する。
通常のプロジェクト保存への追加は行わず、後続の検討保存がこの参照を保持できるよう直列化可能とする。

数量参照の生成は所有するAppの現在入力版とモデルを同時に固定する入口に限定する。
参照内の案版・モデル・範囲・契約の組にダイジェストを持たせ、直列化後の不整合と別プロジェクト、異なる契約を拒否する。
不足値を現行入力から補わない。入力版が異なる図からは現在選択を過去の対象へ読み替えず、保存入力の対象を明示選択する。

## 代替案と影響

数量を通常の解析結果スキーマへ追加する方式は、随時計算を実行結果や履歴保存に変更して後続の検討保存と責務を重ねるため採らない。
現在モデルだけを持つ参照では再編集後に同じ根拠を再表示できず、計算時モデルだけの参照では案版と集計契約を区別できない。
固定モデルを参照内に含めることで容量は増えるが、保持する根拠を直接再構成でき、全編集履歴の保存は不要になる。

保存・読込時の既存の結果失効・除外規則は変更しない。既に除外された結果の履歴や記録のない詳細を復元しない。
現在の入力表への移動は保存済み工程配置を読み込んだ後に表を主領域へ表示し、戻る際に元工程・配置を復帰する。
