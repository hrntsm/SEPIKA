# RC梁の終局せん断は採用ステップの一本部材全体の内力から求める

- Status: accepted
- Date: 2026-11-26
- Related: [#1889](https://github.com/hrntsm/SEPIKA/issues/1889), [ADR 0147](0147-rc-calculation-sources.md)

## Context

分割したRC梁で区間別にせん断スパン比を求めると、別々の区間に現れる曲げとせん断の最大値の比を失う。区間ごとの耐力または余裕度を集約してもこの比は復元できない。区間ごとの最大値だけを後から合成する方法も、評価区間の外端実フェースや荷重位置で左右の断面力を含むか判別できなければ、最大値の過小評価を防げない。

## Decision

増分解析の確定ステップで、荷重込みの断面力を回復できる時点に、一本部材の実フェース間の軸力範囲と、軸別の最大絶対曲げと最大絶対せん断を集約する。集中荷重境界を含む各区間の端と、区間内の多項式の極値を評価する。等間隔の採取点や位置不明の保存端力は使わない。一本部材全体を確認した結果とその不成立理由は、従来の個別区間用内力とは別の記録とする。根拠と適用範囲は[RC梁・柱の終局せん断耐力](../../docs/calc_basis/08_部材終局耐力/02_01_RC梁_柱の終局せん断耐力_荒川mean式.md#採用ステップの内力)に置く。

通常検定のQD1と異なり、外端の両端曲げ降伏・反力の伝達条件は適用条件にしない。曲げと付着の需要、およびRC柱の終局せん断の需要は変更しない。

軸力と弱軸作用の有無は、小さい応答値を一律に切り捨てて判定しない。軸力は材軸方向が自由な端からの切片に作用する外力と反力、弱軸は断面の対称性・荷重面と節点拘束でゼロを独立に確認できる場合だけ、有限精度で得た値に代えてゼロを採用する。条件が成立しても応力値が解析の収束許容値と整合しなければ証拠を発行しない。

荷重の通常加算で成分を失うと、回復値と実際の釣合いが一致しない。回復値がゼロなら、実フェースで荷重を切り捨てず、全長の個々の荷重に軸方向作用がないか確認する。部材荷重は各区間の軸、節点荷重とその点に一致する部材端の集中荷重は接する各区間の軸を用いる。荷重の該当自由度を同じ点で明示的に拘束している場合だけ、直接反力として扱う。柱やばねが負担する力の配分は推定しない。この照合は局所軸が許容範囲で一致する全区間で実施し、有限精度の応答を物理的なゼロと置き換えられる条件は広げない。最終部材応答は最後の確定履歴と同じ記録を使い、荷重の確認を通らない別経路から証拠を発行しない。

内法外にある荷重も、節点力を通じて内法の応答に寄与し得る。全区間で非零の局所荷重成分が失われていないことを確認できる場合だけ確定総応答を採用する。一般の荷重射影方式はこの判断では変更しない。

## Consequences

同じ採用ステップの分割区間の記録がすべて揃って一致した場合にだけ、検定の各行で梁全体のせん断を計算する。結果に新しい記録がないことだけで同じ解析応答の他用途は無効にしない。旧保存結果や区間別の直接指定を供給しても、一本部材の検定を代用できない。検証条件は[独立検証記録](../v_and_v/RC一本部材の終局せん断_Issue1889_検証.md)を参照。

既存の計算結果・応答は変えず、この照査の任意記録だけを追加する。保存結果の共通解析版・通常検定版は、[OVIKAの計算契約](../../docs/model_io/01_プロジェクト形式_ovika.md#保存結果の計算契約と再実行)と[ADR 0118](0118-asymmetric-column-time-history-peaks.md)に従って維持する。[ADR 0014](0014-schema-compatibility.md)の保存スキーマ方針を変えず、記録のない旧結果への補完・変換は行わない。
