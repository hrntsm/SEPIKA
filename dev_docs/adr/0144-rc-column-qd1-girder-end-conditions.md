# RC柱の短期地震時QD1では柱側梁端の曲げ伝達条件を確認する

- Status: accepted
- Date: 2026-11-22
- Related: [#1839](https://github.com/hrntsm/SEPIKA/issues/1839)

## Context

両端柱降伏の設計用せん断力を、柱頭で接続梁が曲げ降伏する機構によって低減できる。共有節点へ曲げを伝えないピン端を梁降伏として数えると、成立しない機構で需要を低減する。半剛接の回転ばねは剛性のみを指定する。端別XYZ偏心がある場合や、ピン・半剛接の端に有効な剛域がある場合、軸力やせん断力を節点へ移送する際に付加曲げが生じ、可撓端の曲げ伝達だけでは節点の降伏機構を確定できない。

## Decision

柱と節点を共有する側の梁端で曲げ伝達を確認し、計算根拠に示す剛接の大梁だけを梁降伏の候補とする。ピン・回転ばねの端では共有節点側の剛体アームを確認する。柱側にXYZ偏心があれば、平面上の梁の方向だけでは曲げを伝える方向を確定できない。これらの端に材軸剛域があれば、柱の曲げ軸が剛体アームと平行な方向に限って、付加曲げがゼロと判断できる。遠端だけの偏心は、共有節点側に回転解放以外の伝達経路がないピンの判定に影響しない。曲げを伝え得るが機構を確定できない接続がある方向は、残りの大梁の部分和による低減を避け、RC規準(15.8)式の両端柱降伏を用いる。[RC柱のせん断検定の根拠](../../docs/calc_basis/06_一次設計/02_04_RC柱のせん断検定.md#梁降伏を採用できる接続条件)

## Consequences

通常検定と時刻歴簡易検定は、同じ接続判定を使う。入力した剛域長と解析で採用する剛体アームが異なる場合は実際の解析条件を参照する。柱頭係数の判断は[ADR 0143](0143-rc-column-head-shear-factor.md)による。ヒンジ候補の比較順と柱脚機構は[#1817](https://github.com/hrntsm/SEPIKA/issues/1817)で扱う。
