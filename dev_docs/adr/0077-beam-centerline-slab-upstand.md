# 梁の床板嵩上げを中心線上端と水平投影幅で算定する

Status: accepted

梁の床板嵩上げは、実材軸のXY位置を通る鉛直線と有限な梁実形状の最上交点を梁上端とし、水平面内の梁直交方向への実断面外側投影幅を掛けて算定する。2026-10-25のユーザー合意による。高さは中心線上で解決し、幅方向への高さ積分は定義に含めない。

床板の対象は既存の支持・割当から保ち、物理的な上下接触を候補抽出条件としない。床板材料の採用元を保持して、設計重量と物理質量を同じ区間体積から別々に導出する。既存自重算定区間との交差を用いるため、材種ごとに既存の算定区間が異なる場合はその差を維持する。

回転断面・円管・中空断面にも同じ算定位置を適用する。中心線を通る鉛直方向は局所断面の固定方向となるため、既存の実材料・空洞の区間と有限端面の交差から上端の切替位置を求める。不連続点をまたぐ一つの線形荷重を作らず、各区間内からの端点極限を用いる。

この定義を重量・質量の共通契約とすることで、荷重の列挙、二次支持反力、動的質量と表示内訳が別々の幾何を採用することを避ける。嵩上げを構造断面・剛性・耐力へ加える判断は含まない。

荷重・動的質量を使う解析に加え、解析成果を参照しない直接小梁検定の需要も変わる。両者をそれぞれの計算契約で失効させ、解析版の不一致だけに直接検定の再計算を依存させない。
