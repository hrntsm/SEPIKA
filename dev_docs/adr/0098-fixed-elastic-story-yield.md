# 共通弾性静的応答を固定した層骨格と未同定診断を分離する

Status: accepted

## 判断

Issue #1087の2026-11-02合意に基づき、非線形質点系の初期剛性を、増分曲線の最初の記録からではなく、同じ水平力分布の弾性静的応答から固定する。曲げせん断型は既存の弾性曲げを分離し、等面積は非線形せん断成分へ適用する。主塑性率と履歴則は同じ等価降伏第2折点を使う。

降伏後枝の同定は変形座標に均等な連続最小二乗とする。入力点番号で候補や重みを決めると、同じ折れ線への点追加で降伏基準が変わるため、無次元変形区間上で比較する。初期剛性・等面積だけでは降伏点は一般に一意でないため、共通範囲の適合誤差と競合候補の降伏変位安定性も要求する。製品仕様と数値条件の正本は[質点系解析](../../docs/calc_basis/05_構造解析/09_質点系解析.md)。

## 成立しない結果の保存

未同定・近似不成立をモデルの仮折点や弾性置換で表さず、モデルと応答を持たない診断専用結果として保存する。成功APIのモデル・固有値・時刻歴の構成は維持し、失敗時のjobエラーから構造化診断を受け取るGUI経路を追加する。前の成功モデルを最新の成立結果として表示しない。

単なるエラー文字列は再読込後に元条件を失い、空又は弾性のモデルを返す案は成立と未同定を混同するため採らない。解析成果がstaleの保存でも診断は独立して保持する。計算契約版は解析67へ更新し、先行#1097の検定45を維持する。OVIKAの版間移行はADR0014に従う。

手動区間は編集コマンドを通してUndo/Redo可能にする。変更・Undo/Redo時は質点系の表示窓口だけを無効化する。固有値専用結果にも開始時の入力識別を保持し、非同期完了・表示・保存時に照合する。階ID参照の走査と階snapshotに手動区間を含め、挿入・削除・復元で元の階との対応を維持する。元静的・増分成果の入力識別からこの区間だけを除き、同じ元曲線での再同定を可能にする。一方、質点系時刻歴の開始時モデル識別には区間を含め、変更後に以前の骨格の応答を現在入力の成果と誤認しない。
