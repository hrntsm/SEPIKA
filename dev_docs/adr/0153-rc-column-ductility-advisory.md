# RC柱の短期圧縮靱性推奨は設計者の適用判断と独立した付記で扱う

- Status: accepted
- Date: 2026-11-25
- Related: [#1392](https://github.com/hrntsm/SEPIKA/issues/1392)、[ADR 0147](0147-rc-calculation-sources.md)

## Context

2024年版RC規準14条3項の短期平均圧縮軸応力度の制限は、柱の靱性のための条件付き推奨であり、材料の許容圧縮応力度とは別である。柱の地震時の曲げ増大のおそれ、架構全体が柱に求める靱性、特別な補強の実験的な裏付けは既存入力から確定できない。壁の数や配筋形式、荷重の名称・種別などで自動判別すれば、対象柱を見落としたり、標準値との比較結果が柱の適否と誤読されたりする。

## Decision

公開の共通部材検定では、設計者の部材別判断を対象・非対象・実験根拠による例外として受け取り、指定がなければ適用判別不能とする。標準値は、対象には推奨値との比較、判別不能には数値上の参考比較にだけ使う。例外時は個別上限も適否も算定しない。長期・終局・時刻歴の検定には追加しない。

通常GUIには判断を保存する入力を追加しない。選択中の短期荷重組合せについて、確認できた検定位置の最大と位置、比較できない位置を、許容応力度の判定とは独立して表示する。比較が検定比を支配する位置に埋もれないよう、比較結果を別に保持し、通常の検定結果とともに保存する。

## Consequences

推奨値以下であっても、対象柱への適用、実験結果の妥当性、実際の柱の靱性を保証しない。設計結果の計算契約を更新し、旧保存検定は失効させる。入力・プロジェクト形式・解析の計算契約は変えず、適合する保存内力は再検定に使える。[製品の計算根拠](../../docs/calc_basis/06_一次設計/02_09_RC柱の構造規定.md#短期平均圧縮軸応力度)・[確認記録](../v_and_v/RC柱短期圧縮靱性推奨_Issue1392_確認記録.md)
