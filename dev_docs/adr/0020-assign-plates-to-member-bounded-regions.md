# 囲まれた床板・壁版は支持部材で分割された領域へ割り当てる

Status: accepted

囲まれた床板・壁版は、任意の節点境界から作成せず、支持部材から導出した床板割当領域・壁版割当領域へ 1 枚ずつ割り当てる。床板割当領域は大梁と小梁、壁版割当領域は柱・梁・間柱で分割し、複数の割当領域をまたぐ版を許可しない。これにより、支持関係と版境界の不一致や重複版による荷重の二重計上を防ぐ。

各割当領域は未設定・版あり・版なしの状態を持つ。支持部材の変更で境界が変わった割当領域は版の割当を解除し、新しい領域を未設定とする。未設定は荷重・剛性を過小評価し得るが、入力途中でも計算できることを優先して解析を禁止しない。代わりに計算前の確認を必須とし、結果画面と出力帳票へ未設定件数と対象を常時記載する。

任意境界を許可する案は入力経路によってモデルの不変条件が変わるため採用しない。変更後の領域へ版仕様を自動継承する案も、利用者が意図しない荷重・剛性の変更を生むため採用しない。

小梁・間柱には安定した ID を与え、端部はモデル節点ではなく二次部材の取付き位置として保持する。取付き位置は支持部材 ID と材軸上の位置を持ち、二次部材の接続、荷重伝達、版割当領域の生成で共用する。二次部材の接続だけを表す節点を主架構へ追加すると、解析要素の接続と誤認しやすく、幾何判定による支持関係の再推定も必要になるため採用しない。

床板割当領域・壁版割当領域は安定した ID を持つモデル要素として保存する。支持部材の変更後も境界が同じ領域は ID と状態を維持し、境界が変わった領域だけを新しい ID の未設定領域へ置き換える。片持ち二次部材の自由端は、支持端を基準とした親領域の構面内ベクトルで保持する。

床板・壁版と割当領域は別のモデル要素とし、割当領域が版 ID を保持する。囲まれた版は割当領域 ID から形状を取得して境界を重複保存せず、取り付く版だけが取付き先と張り出し量または高さを保持する。これにより、支持部材から決まる幾何と版の物理仕様を分離しながら、囲まれた版と取り付く版を同じ版 ID で参照できる。


同一性の照合は支持種別・支持 ID と区間の f64 ビット列で行い、境界辺の巡回・逆順を正規化し、
±0 だけを同一化する。近接した区間値・重心・面積・親の表示名による版割当の転用は認めない。
親の床領域・壁領域は名前と所属を幾何から再整理するため、その ID の不変を割当領域の安定 ID 契約に含めない。

再構築は確定前に既存領域と候補の ID・境界キー・版割当の重複を検査する。不正な既存領域を正常な面走査の
重複除去で修復したことにせず、領域・次 ID・版・入力荷重・Undo/Redo 履歴を保持して全体を拒否する。
一般再構築で孤立版が生じる場合は候補段階で診断し、床・壁とも未更新にする。

明示した主架構の追加・削除、節点座標変更、二次部材の配置・削除・端部編集では、境界変更で孤立した旧版を取り除き、新領域を未設定にする。
確認には旧版 ID・件数・入力荷重と復元可能性を示す。領域・次 ID・版・版内の面荷重を 1 つの Undo 単位で保存し、
1 Undo で元の入力へ戻す。Redo は同じ ID で編集を再適用し、ID 払い出しの水位も復元する。
GUI は確認待ちのコマンドを保留する。確認を提供できない節点グリッドでは旧版を失う編集を診断して拒否する。
MCP が公開する二次部材編集は `confirm_plate_loss=true` の確認後に同じ編集を確定する。
これを一般再構築の予期しない孤立版破棄を許可する経路として用いない。
