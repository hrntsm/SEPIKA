# 上下非対称組立H形鋼大梁の強軸曲げは上下縁と横座屈長さの直接指定で照査する

Status: accepted

全せいの半分を使うと図心から遠い縁の応力度が過小になり、許容値を超える位置で適合と判定し得る。強軸曲げには図心から各縁までの距離を用い、曲げの符号で各縁の引張・圧縮を区別する。

正の横座屈長さに対する上下非対称断面の許容曲げ応力度は、圧縮側のフランジを区別して適用できる条件の確認を要する。横座屈長さ0の理想化は設計者が該当位置に直接入力した場合に限り採用する。未指定の既定値や自動算定値が0でも横座屈低減を不要とする根拠にならないため、断面照査によって適合を確定する用途には使わない。適用可能な断面で材料の許容上限を超える場合は、横座屈の算定条件が未確定でも独立した曲げの不適合を保持する。

旧結果では過小な応力度により適合が表示され得るため、検定契約版を更新する。 [曲げ照査の適用条件](../../docs/calc_basis/06_一次設計/03_02_鋼梁の曲げ_横座屈検定.md#上下非対称組立h形鋼大梁の強軸曲げ)・[Issue #1545](https://github.com/hrntsm/SEPIKA/issues/1545)・[横座屈の調査 #1598](https://github.com/hrntsm/SEPIKA/issues/1598)
