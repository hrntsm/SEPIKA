# 比較用のケース別検定根拠を原本から分け、数量の固定対象を保持する

Status: accepted

## 判断

Issue #980では、各保持計算の準備後入力と静的結果を独立した作業状態へ渡し、既存の結果選択・検定経路でケース別の検定根拠を作る。元の計算結果の検定欄は表示中の1ケースであるため、これを全ケースの最大とは解釈しない。ケース別根拠は検討の保持計算へ保存し、共通の実行・入力・契約・静的応力源を持つ根拠参照で開く。通常の契約・生成入力・未対応パネルの失効判定を経由し、古い成果を再認証しない。

比較図は読取専用の固定入力と既存ビューアを利用する。構築・ケース切替時に表示用状態を作り、通常描画で全モデルの複製や検定を繰り返さない。表示構築時に選んだrunのケース別根拠を表示状態自身に固定保持し、ケース切替でownerの最新runを探索しない。通常結果への移動も構築時のrunに限定する。明示した再表示だけが全指標と図を同時に新runへ更新する。図内の結果ケース選択は上部共通指定に固定し、操作直後だけ別ケースを表示して翌フレームで戻る状態を作らない。指標差は左右図の選択から独立し、案−基準案に固定する。変形図の共通倍率は自動倍率への係数ではなく絶対表示倍率とする。案ごとの自動倍率に同じ係数を掛けても、同じ変位量の表示倍率にはならないためである。

条件照合は開始時入力の許可された固定部材の断面割当だけを基準へ戻し、設定とモデルの実データを照合する。編集経路が採番する未採番STB節点識別は、両方に既存の採番処理を適用して比較する。番号・名前だけによる対応の推定や、支点・手入力荷重の差を許す近似は行わない。準備後の自動荷重・質量は条件不一致と分離する。

数量根拠の範囲に固定部材集合を追加する。モデル全体の既存意味と集計契約1は変更せず、追加範囲はその同じ数量明細を固定集合で抽出する。対象なし・欠落は取得不能とし、現在入力で補完しない。範囲・集合は既存ダイジェストに含め、保存・再読込・根拠閲覧でも同一範囲を保持する。ADR0089の全体範囲の再解釈は行わないため、既存契約版を据え置く。

位置別の対応はxiと検定項目集合の完全一致に限る。フェイス移動やハンチ・継手との順序交替があり得るため、昇順の配列番号から意味上の同一位置を推定しない。位置集合差は未比較範囲として示す。変更外部材は部材×ケースの全算定位置最大も独立に集計し、各案の実支配位置・項目と未検定数を保持する。この包絡は位置変更自体を条件不一致とせず、既存全位置の厳密な最大として比較する。ただし検定項目集合の不一致と、未検定により比較可能な算定範囲を確認できない場合は、差・悪化を計算しない。項目差を位置差に混ぜない。固定対象集合の検定比は全主架構とは別の集計として常時表示し、対象外部材が全体を支配しても隠さない。固定対象・全体最大の差も実算定範囲を照合し、未検定件数の一致だけでは認定しない。部材ケースが両案で全位置算定済みならxi移動を許し、一部未検定なら位置・項目・算定済み／未検定の対応を厳格に照合する。比較から到達する共通根拠・通常検定比図・通常検定表でも空・非有限・負の検定成分を共通ガードで未評価とし、既存ratioの空入力0を合否へ使用しない。表示用の壁集計で不正成分を未検定として扱う際も保存結果を書き換えない。部材・節点の未評価判定はSkippedと不正なCheckedを共通関数で扱い、比フィルタだけが不正成分を除外して正常位置の合格色へ集約する状態を作らない。未検定のマーカーと確認済みNGの存在を同時に残す。未評価を含む節点の適合値を凡例の最大へ残さず、確認済みNGのみ保持する。壁は表示用の不正成分処理を通常表と凡例で共有し、rawな結果を合格件数へ戻さない。新規NGは基準側の最大1以下を比較可能な位置・項目集合で確認できた場合だけ確定し、基準未評価や集合差がある場合の案側NGを分ける。

生成時に既存検定APIの出力から、実行・ケース、部材IDとxi列、接合部・壁の対象、各位置のChecked項目multiset／Skippedの期待構造を独立して保存する。数値や式は複製しない。比較時の欠落判定はこの固定構造と照合し、現在モデルから対象や位置を生成し直さない。部材単位・空位置列・部分的なcomponentsの削除も検出し、両案で同じ欠落があっても範囲一致とはしない。期待構造そのものの欠落も未評価とする。元runの通常結果と追加の共通根拠も生成時構造を保持し、表示用コピーだけを失効させる。計算原本と期待構造を表示判定で書き換えない。

生成時構造・入力・実行の共通確認が有効な根拠について、同じCheckedの中でも、完全算定状態と有限・非負の成分で確認済みのNGを共通評価で分ける。不正成分が一つでもあれば完全評価の最大・差・新規NGは確定しないが、残る有効成分のNG値は図・通常表・根拠・壁集計に残す。有効成分がない場合に0を補完しない。生成時の対象・位置・項目構造や生成情報の欠落により根拠全体が利用不可の場合は、既存の共通失効ゲートを維持し、残存数値を再認証しない。集計不可・欠落理由・範囲未確認を表示する。NG件数と未評価件数は同じ集計行に併存し、相互排他的な内訳とはしない。表示用の壁のNG行と未評価行は原本の同一検定を示し、検定件数は原本の対象内（seismic_target=true）行数を保ち、対象外を分母へ含めない。表と凡例の表示用集計を共通化する。

## 代替案

比較画面へ独自の数量式・変位解析・検定式を実装する方式は、通常結果と計算根拠を分岐させるため採らない。表示中の1ケースだけを全実行検定の代表とする方式は、支配ケース交替と変更外への影響を欠落させるため採らない。全編集履歴は保存せず、保持する計算根拠の範囲を維持する。
