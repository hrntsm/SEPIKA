# RC柱の長期設計用せん断力を両材端フェース間で求める

- Status: accepted
- Date: 2026-11-22
- Related: [#1836](https://github.com/hrntsm/SEPIKA/issues/1836)、[#1843](https://github.com/hrntsm/SEPIKA/issues/1843)

## Context

指定した断面だけのせん断検定では、荷重の切替点や集中荷重の直前・直後で生じる最大値を見逃す。RC規準2024年版の第15条2項(1) ii) は、柱の長期設計用せん断力にその部材の最大値を求める。探索区間の端は条文で特定されていない。付2の構造設計例では、長期荷重の断面算定用応力にフェース位置を採用している。 [原典と独立釣合いの照合](../v_and_v/RC柱の長期せん断需要_Issue1836_照合記録.md)

## Decision

柱と接合部の境界が確定する場合、両材端フェースの柱区間側を端として、部材座標の各方向で長期設計用せん断力を求める。接合部も含む節点芯間を一律に採ると、柱断面の許容せん断力を接合部の断面力と比較することになる。剛体アーム端を採る方法では、剛域の設定が変わると柱断面を検定する範囲まで変わる。断面方向にかかわらず接続梁のせいの半分を控除すると、実際の柱区間の一部を除外する場合があるため、接続梁の実配置で境界を確認する。 [製品の計算根拠](../../docs/calc_basis/06_一次設計/02_04_RC柱のせん断検定.md#長期せん断の検定位置)

保存組合せの解析と同じ荷重・断面力の釣合いを使い、区間内の極値と集中荷重の両側を評価する。荷重と解析結果の対応や柱区間を確認できない場合は、最大値を理由付きで未算定とする。接続梁の候補フェースが異なる接合で最大の控除長を機械的に採ると、別の候補フェースまでの柱区間を落として最大せん断力を過小評価し得る。測点を追加する方法では、荷重による不連続と測点間の極値をともに保証できない。

## Consequences

最大せん断力の位置は、軸力・曲げを検定する位置と一致するとは限らない。結果のせん断内訳に方向と採用位置を記録する。軸力・曲げの判定は既存の断面位置で行う。

通常検定に必要な断面内力が欠ける場合でも、照合できた最大需要が方向別の長期許容せん断力の上限を超えれば、不適合を確定できる。長期許容せん断力はαに比例するため、上限で除した比は検定比の下限になる。欠落または非有限の参照値からαを推定すると、許容値を過小評価して不適合を誤って確定し得る。αの参照条件は [#1841](https://github.com/hrntsm/SEPIKA/issues/1841) で扱う。
