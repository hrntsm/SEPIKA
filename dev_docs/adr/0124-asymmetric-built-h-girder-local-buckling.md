# 上下非対称組立H形鋼大梁の全断面照査に幅厚比の条件を設ける

Status: accepted

[ADR 0122](0122-asymmetric-built-h-girder-bending.md) の横座屈長さを0と指定した位置でも、圧縮側フランジやウェブが局部座屈すると、全断面を用いた適合判定は耐力を過大評価し得る。2019年版規準の幅厚比の限度で、局部座屈の影響を省ける断面に適合判定を限定する。圧縮フランジは曲げの符号ごとに選び、軸圧縮力ゼロの溶接組立大梁には梁ウェブの限度を用いる。

無効部分を控除すると図心が移るため、全断面の曲げ比の最大値が1を超えても、不適合を確定できるとは限らない。全断面と有効断面の断面二次モーメントの大小関係および上下外縁の間隔を用い、各フランジの板厚別の材料上限に対して少なくとも一縁の超過を立証できる場合に限って不適合を保持する。この下限で不適合を確認できない場合は、有効断面の算定が必要な理由を示す。

幅厚比を確認する前の保存検定で適合と表示され得るため、検定契約版を更新する。 [曲げ照査の適用条件](../../docs/calc_basis/06_一次設計/03_02_鋼梁の曲げ_横座屈検定.md#上下非対称組立h形鋼大梁の強軸曲げ)・[Issue #1604](https://github.com/hrntsm/SEPIKA/issues/1604)
