# 上下非対称組立H形鋼柱の軸力ゼロの強軸曲げは実縁で照査する

Status: accepted

軸力がゼロでも、図心がせいの中央からずれる組立H形鋼柱では、圧縮・引張縁で応力度が異なる。各縁の断面係数を実形状から求め、曲げの符号で許容曲げ応力度を用いる縁と許容引張応力度を用いる縁を選ぶ。

適合判定には、材長と各座屈長さがゼロの断面単独照査に加え、充腹柱の幅厚比の制限を満たす条件を採る。局部座屈により無効部が生じると断面二次モーメントと図心が変わるため、有効断面による照査が必要になる。全断面を用いる条件が成立する場合、横座屈や他の力との組合せが未確定でも、縁応力度が材料の許容上限を超える不適合は保持する。弱軸曲げが加わると、強軸曲げでは引張となるフランジの幅端にも圧縮が生じ得るため、全断面を用いるには両フランジで幅厚比の制限を満たすことを要する。
