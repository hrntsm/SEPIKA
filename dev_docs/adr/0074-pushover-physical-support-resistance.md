# 増分性能曲線を物理支持反力から回復し、層切断面力と区別する

- Status: accepted
- Date: 2026-10-25
- Related: [#717](https://github.com/hrntsm/SEPIKA/issues/717)、[ADR 0049](0049-purpose-specific-story-evaluation.md)

## 背景と判断理由

active自由度の内力和は、部材荷重から拘束端へ直接伝わる作用を含まない。
全固定部材に水平分布荷重を載せた有限例では、部材力が存在しても性能曲線が0となる。
壁接続材だけの等価節点力を戻す補正も、一般材との混在や荷重位置に依存する。
同じ確定状態の物理材端力と元荷重から固定支持反力を回復し、支持ばねの反力を加える。

## 決定

- 性能曲線のベースシアは、全固定支持と地盤支持ばねの反力の符号を反転した合計とする。
  固定自由度に直接載る節点荷重は除く。
  既存Reducerの行が厳密に空となり変位0へ消去される従属自由度も固定と同じように回復・控除する。部材端点ちょうどの集中荷重は同じ節点荷重と同一に扱う。
- 部材荷重を要素が所有する場合は確定済みの物理材端力を使い、それ以外は既存の等価節点荷重を差し引く。
  仕口パネルの一般化回転を物理支持反力へ混ぜず、全自由度写像から物理節点だけを回復する。
- 性能曲線の層別値は既存の上端階所属節点集合を上層から累積する。
  その物理材端力と地盤支持作用に、層下端SLより上・最上端SL以下の部材内部荷重を厳密積分して加える。
  節点所属を高さだけから再定義しない。
- 目的別層力は層内水平切断面で回復する。上側の実外力と、固定支持・支持ばねの作用を使う。
  固定端の荷重や拘束点反力をactive自由度の欠落で失わせない。
- 層切断面ちょうどの集中荷重は、既存の部材断面力のi端側極限に合わせる。
  上下端反転で左極限が選ぶ物理側は変わるため、性能曲線の階帯の半開区間とは分けて検証する。

## 候補の採否

保存ブランチ`preserve/496-before-scope-split-20261021`の`7b84feec`から、物理支持反力回復と部材荷重積分を現在mainへ適合させて採用する。
大規模な荷重所有方式の変更と保存検証成果物の一括移植はしない。

`692218e4`が対処する剛床代表節点荷重の照合漏れは、現在mainの公開増分解析で再現しなかった。
X/Y方向の代表節点載荷と直接slave載荷で、力・仕事・目的別層力の一致を確認した。
候補の新しいruntime照合と代表節点の特例を導入しない。
一般MPC・階跨ぎ・部分slaveを同一並進へ近似して適用範囲を広げない。

## 安全性と確認限界

全支持抵抗と骨組負担せん断力を混同すると、建物耐力・層負担の解釈が変わる。
固定端に伝わる実荷重の欠落を安全側とは扱わない。既存材料応答・収束条件・幾何モデルの近似は変更しない。
解析契約版を49へ更新し、旧性能曲線を現行結果として再利用させない。
有限のVerificationを[検証記録](../v_and_v/増分性能量と物理支持反力_Issue717_2026-10.md)へ残し、一般MPCやすべての塑性状態の保証、物理Validationとは区別する。
