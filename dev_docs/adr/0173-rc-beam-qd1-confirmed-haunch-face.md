# RC梁のハンチ付き材端のQD1は確認済みの実フェース・有効主筋を使う

Status: accepted

Related: [#1883](https://github.com/hrntsm/SEPIKA/issues/1883)、[ADR 0162](0162-rc-beam-qd1-slab-reinforcement-source.md)、[ADR 0163](0163-rc-beam-qd1-support-path.md)、[ADR 0164](0164-rc-beam-qd1-eccentric-material-end.md)

## Context

ハンチの増寸はコンクリートの外形を表し、ひずみが生じる面や、折上げ・定着された有効引張主筋を定義しない。
一般部から材端へ配筋をそのまま延長すると、反対符号の両端降伏曲げの和を過小評価し得る。
逆に、ハンチの存在だけを理由にすべて保留すると、設計者が実断面と配筋を確認した場合にも需要を算定できない。
降伏曲げから求めるせん断需要と、ハンチ区間そのものの許容耐力は別の照査を必要とする。

## Decision

ハンチ付き材端の断面・主筋を自動で推定せず、材端ごとに設計者が確認した矩形実フェースと上下引張の有効主筋を任意入力として保持する。
梁軸に平行な全有効引張主筋、群内の共通実降伏点、必要な付着・定着および軸力影響を無視できることが前提であり、斜行する筋の投影や力の移送を仮定しない。
実フェースが既存のQD1境界かつハンチ長の起点であることを照合する。床板寄与を一般部のルールや未確認警告で代用すると危険側になり得るため、ハンチ付きで床板を支持する梁は保留する。偏心によりハンチ側で実柱面に交差しない場合も実材端には置換しない。

通常および時刻歴簡易検定でこの材端情報をQD1の需要にだけ使う。ハンチ区間や実フェース外で一般部の曲げ・せん断・付着を代用しない。
一般部で独立に確認された不適合は保持する。接合部の伝達、ハンチ区間そのものの適合、全架構の崩壊機構を保証しない。

## Consequences

旧入力へ推定値を補わず、入力がない場合はハンチ付き梁のQD1を未算定とする。
入力は解析の剛性、荷重、断面評価位置を変えないため、変更は検定の鮮度判定に反映し、解析入力には含めない。
長期、QD2単独、終局、RC柱、床板筋の既存評価方式は変更しない。
長期・QD2単独における変断面位置での一般部耐力の扱いは [#2009](https://github.com/hrntsm/SEPIKA/issues/2009) に切り分ける。
