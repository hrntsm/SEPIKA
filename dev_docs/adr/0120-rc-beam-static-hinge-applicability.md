# RC矩形梁の静的略算に両端の曲げ降伏機構の確認を求める

- Status: accepted
- Date: 2026-11-20
- Related: [#1581](https://github.com/hrntsm/SEPIKA/issues/1581)、[ADR 0061](0061-ultimate-gravity-demand-modes.md)

## Context

両端曲げ降伏時のせん断力を比較需要に使うには、梁の両端が曲げを伝達し、想定する載荷方向で必要な向きに降伏することを確認する必要がある。長期重力の曲げ符号が一方向であることや、採用側と反対側の断面耐力を比べることでは、この条件を確認できない。端部が解析上の固定接合でも、支持先が存在しなければ架構へ曲げを伝達できない。支持先を持つ梁でも、架構や接合部の他の部位が先に降伏・破壊する場合がある。[原典と独立梁端釣合いの確認](../v_and_v/RC梁両端曲げ降伏時せん断力_Issue1497_確認記録.md)

## Decision

曲げ伝達と両端の曲げ降伏機構を別の適用条件とする。静的入力に終局機構の証拠がないため、確認済みの機構は共通検定へ明示入力する。確認の対象とした載荷方向で互いに逆向きの曲げ降伏が生じることを、梁の端順序と各端の引張側で特定する。回転剛性が正であること、線形重力の応力、増分解析の強弱軸を区別しない表示用ヒンジ事象からは補完しない。

曲げ伝達を確認できる範囲を、梁端が剛接で、接続する節点の3方向の回転が直接固定された場合に限定する。並進を許す支点も曲げ反力を伝えられる。向きにかかわらず両端で同じ曲げ終局耐力を使えるよう、上下対称配筋を適用条件とする。架構内の接合や非対称配筋まで広げるには、終局時の力の伝達経路と両端別の曲げ・せん断・付着条件の根拠が要る。支持や機構を確認できない梁には、この略算の需要と合否を提示しない。

## Consequences

曲げ略算の適用と要求せん断力の追加条件は [ADR 0139](0139-rc-beam-ultimate-shear-demand.md) を参照する。

現行の設計タブでは両端の曲げ降伏機構を指定できないため、静的RC矩形梁は未検定となる。支持の適用外と未確認を理由で区別できる。外部連携の静的終局検定はCFT柱が対象。適用条件と結果の表示は[静的・両端ヒンジ略算による終局検定](../../docs/calc_basis/08_部材終局耐力/07_01_静的_両端ヒンジ略算による終局検定.md)を正本とする。
