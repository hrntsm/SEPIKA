# 断面性能の算定元を項目別に区別し、フィレット半径・角Rの編集時の更新を分ける

Status: accepted

## 判断と理由

[Issue #413](https://github.com/hrntsm/SEPIKA/issues/413) の dig-with-docs で確定したユーザー回答 Q8 B・Q10 A に基づく判断です。
断面性能の算定元を性能項目ごとに保持し、形状算定値とカタログ・直接入力値で明示的に区別します。
フィレット半径・角Rの編集では形状算定の断面性能を再計算し、カタログ・直接入力値は維持します。
既存の個別編集を保ち、直接入力の保護と形状への追従を両立するためです。

たとえば形状生成後に A だけを直接入力した場合、A は維持し、形状算定の Iy・Iz はフィレット半径・角Rの編集に追従させます。
undo/redo と OVIKA の保存・読込でも、この項目別の算定元区分を保持します。

フィレット半径・角Rが未知で必要な形状算定ができない場合はエラーとし、表値からそれらの寸法を推定しません。
表値の維持と形状寸法の確定は別の判断であり、表値を未知の寸法の代替根拠にはしません。

## 代替案

- 全値維持：フィレット半径・角Rの編集後も形状算定値が残り、形状と断面性能が不整合になるため採用しない。
- 全値再計算：カタログ表値や直接入力値を形状算定値で上書きするため採用しない。

## 記録の範囲

本 ADR は受け入れ済みの設計判断であり、実装完了や現在の製品挙動を示すものではありません。
フィールド名・enum・既存データの扱いなどの実装詳細は決めません。
製品仕様の `docs/` への反映は実装後に行います。

ねじり定数 J の算定方法自体の見直しは [#416](https://github.com/hrntsm/SEPIKA/issues/416)、鋼材せん断面積の算定方法自体の見直しは [#417](https://github.com/hrntsm/SEPIKA/issues/417) に分離します。
本 ADR では、これらの算定方法や適用範囲を拡大しません。

## 角丸 CFT の規準設計の分離

ユーザー回答 Q11 A により、正の角Rの規準設計仕様を [#418](https://github.com/hrntsm/SEPIKA/issues/418) へ分離します。
許容曲げは内角Rが正、終局 N–M は角Rが正の場合に未対応とし、理由付きの算定不能を公開結果まで保持します。
規準の矩形モデルを角丸の領域積分へ無条件に置換しないための暫定ゲートです。
具体的な適用条件・依存する設計用せん断・軸終局との区別は、`docs/` の一次設計・CFT 終局耐力を正本とします。
