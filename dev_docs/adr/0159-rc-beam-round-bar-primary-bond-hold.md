# 丸鋼主筋を使うRC梁の一次付着は未算定とする

- Status: accepted
- Date: 2026-11-25
- Related: [#1956](https://github.com/hrntsm/SEPIKA/issues/1956), [#1802](https://github.com/hrntsm/SEPIKA/issues/1802)

## Context

[照合記録](../v_and_v/RC梁の丸鋼主筋の一次付着_Issue1802_照合記録.md)では、現行の1999方式の付着割裂式を丸鋼に適用できる根拠を確認できなかった。1991方式が用いるせん断力も、丸鋼に対する2024年版RC規準の平均付着応力度の検定に代用できない。準用には、現行の入力で確認しない端部フックと実際の付着区間などの条件が必要となる。

## Decision

丸鋼を主筋に使ったRC梁の一次付着は、両方式で長期・短期とも検定比を算定しない。通常検定と時刻歴簡易検定では理由を返し、独立して確定した不適合は併記する。端部フックや付着区間を仮定せず、異形鉄筋式も代用しない。

## Consequences

旧契約の保存検定結果を現行結果として使わないよう、設計契約を121に更新する。解析契約と終局付着は変更しない。丸鋼の2024年版準用を実装する場合は、照合記録の未確認事項を踏まえて必要入力と適用範囲を別途定める。
