# RC梁の矩形許容曲げを上下同重心かつ各段が中立軸の想定側にある配筋に制限する

Status: accepted

[Issue #1266・#1388の独立確認](../v_and_v/RC梁非対称多段配筋_圧縮筋位置の確認記録.md)で、圧縮筋の重心位置を引張筋の縁距離で代用すると、実際の配筋位置によるコンクリート圧縮制限を超える許容値を出す例が確認された。正負で過大・過小の向きが異なり、引張支配で差が隠れる断面もある。

矩形の非零曲げは、上下の面に主筋がある場合に各面の縁からの主筋重心距離が一致し、各段が中立軸の想定側にある場合に限り、従来の重心集約式を使う。圧縮側主筋のない断面では引張側の条件だけを評価する。適用外の位置は共通の理由付き検定不能とし、合格へ集約しない。

実圧縮筋重心を使う方式は位置の代用を解消できるが、中立軸をまたぐ配置では段ごとの換算係数の判別が必要になる。段ごとの許容応力度やjも含めて方式の適用範囲を検証するまで既存式の適用を制限する。この判断により、既存の非対称断面の一部は検定比が得られなくなる。

中央・スラブ付き正曲げには既存の引張側略算を適用する。零曲げの位置では、曲げ許容値を求めずに対応するせん断・付着を検討する。現在の利用条件と規準の確認範囲は[梁の許容曲げと中立軸](../../docs/calc_basis/06_一次設計/02_RC_断面検定.md#梁の許容曲げと中立軸)を正とする。
