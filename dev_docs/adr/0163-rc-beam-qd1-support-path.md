# RC梁のQD1の算定条件に接続先の支持経路を含めない

Status: accepted

Related: [#1884](https://github.com/hrntsm/SEPIKA/issues/1884)

## Context

現行の通常断面検定は、梁端に直接の回転拘束がない場合、実柱面を与える接続柱の反対端に対象方向の直接支持を求める。同じ梁断面・配筋・内法・検定入力の比較では、接続柱の反対端を直接固定するとQD1は77.398 kNとなり、柱をもう一段延ばして固定すると未算定となった。日本建築学会『鉄筋コンクリート構造計算規準・同解説』2024年版、第15条 p.22の式(15.7)と解説 pp.174–175には、この直接支持の確認を算定条件とする記載はない。

## Decision

単一のRC矩形梁の梁端が別の部材に接続されている場合、その接続先の反対端に直接支持があることや、それより先に支持点へ至る経路があることをQD1の算定条件にしない。梁端自体に明示された強軸曲げ解放の扱い、および実端面・内法・端部断面・配筋・長期荷重の確認は変更しない。一本部材に指定した分割梁の反力伝達条件と静的終局検定は、この判断の対象外とする。

## Consequences

接続先の支持を探索する方式に比べ、モデルの分割や支持点までの部材数だけでQD1が未算定になることを避けられる。一方、この算定は接続先が支持されていること、接合部の伝達耐力、実際の降伏順序を保証しない。接続先が自由な枝であることだけを理由にQD1を除外する従来の完了条件は、この判断と両立しない。
