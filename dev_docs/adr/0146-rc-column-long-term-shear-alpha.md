# RC柱の長期せん断で必要な方向に両材端フェースの小さい割増係数を使う

- Status: accepted
- Date: 2026-11-22
- Related: [#1841](https://github.com/hrntsm/SEPIKA/issues/1841)、[#1854](https://github.com/hrntsm/SEPIKA/issues/1854)、[ADR 0145](0145-rc-column-long-term-shear-span.md)

## Context

最大曲げを生じる断面から割増係数αを決めると、他方の材端でより小さい係数となる場合に許容値を過大評価する。RC規準2024年版の第15条2項(1)の式(15.1)は長期許容せん断力を定め、解説2項(3) ii)（p.177）はα=1から始め、必要な場合に柱脚・柱頭の小さい方を用いる。付2の断面設計(1)（p.438）は長期の断面算定用内力にフェース位置を採る。 [独立計算と従来の判定の照合](../v_and_v/RC柱の長期許容せん断力_Issue1841_照合記録.md)

## Decision

矩形・円形RC柱の通常の長期保存組合せに二段階照査を採用する。αを調べる方向では、ADR 0145で決めた物理フェースと柱区間内側の切断面を使う。節点芯や部材の曲げ最大位置による代替は、せん断スパン比を過小にして許容値を過大にする場合がある。別断面から抽出したMとQの組にも同じ問題がある。材端の保存断面力と実部材荷重の釣合いを照合し、実フェースの測点がないときは釣合いから復元する。位置の補間には、分布荷重による曲げの非線形分布や集中荷重でのせん断の跳びを保証できない。

## Consequences

部材のせん断判定に使う内力と軸力・曲げの検定行が別々に成立する。2段階目の必要な内力を確認できない方向でも、需要がαの許容上限を超える不適合と、他方向の独立した不適合を保持する。検定契約版を更新し、同じ解析契約と生成入力の保存内力から再検定できる。 [製品の計算根拠](../../docs/calc_basis/06_一次設計/02_04_RC柱のせん断検定.md#長期許容せん断力の割増係数)・[検証](../v_and_v/RC柱の長期許容せん断力_Issue1854_検証.md)
