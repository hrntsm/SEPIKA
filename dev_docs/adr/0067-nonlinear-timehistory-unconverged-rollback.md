# 骨組の非線形時刻歴の全体未収束は時刻開始状態へ復元して停止する

- Status: accepted
- Date: 2026-10-21
- Related: [#714](https://github.com/hrntsm/SEPIKA/issues/714)、[#496](https://github.com/hrntsm/SEPIKA/issues/496)、[ADR 0063](0063-wall-side-column-foundations.md)

## 背景と判断理由

有限な試行応答でも全体釣合いが成立したとは限らない。未収束状態を確定すると、その材料履歴を起点に後続応答が計算され、当該時刻の警告だけでは影響を切り離せない。
ユーザーは全体未収束時の完全な復元とエラー終了を明示的に選択した。

## 決定

骨組の非線形時刻歴では、反復上限までに全体釣合いが収束しないステップを確定せず、時刻ステップ開始時のsnapshotへ復元してエラー終了する。
材料履歴だけのrevertでは試行時の部材荷重・内部変形・応答を復元できないため、全要素のtrialと確定状態を含むsnapshotを使用する。
非有限応答や反復中の求解・要素更新の失敗も同じ復元と診断を適用する。応答変数・記録・ピーク値・塑性率履歴の確定は収束判定後に限る。

警告付きで有限な未収束状態を確定する案は、途中の参考値を得られる利点がある。しかし後続応答の信頼性を保証できず、安全側とも判断できないため採用しない。
時間刻みの自動細分、収束許容差・材料則の変更、部分結果形式は導入しない。質点系のsolverは対象外とする。

旧契約で確定された未収束応答を再利用しないため解析契約を27から28へ更新する。検定契約19と保存スキーマは維持する。
製品仕様の正本は[時刻歴応答解析](../../docs/calc_basis/05_構造解析/05_時刻歴応答解析.md#非線形時刻歴newmark-β--newton-raphson)とする。

## 確認限界

本判断は全体未収束時の確定を禁止するもので、物理的精度のValidationや[#496](https://github.com/hrntsm/SEPIKA/issues/496)全体の完了を示さない。
既存のV&Vにある警告付き続行の実行記録を、この停止方針の受入証拠へ読み替えない。
