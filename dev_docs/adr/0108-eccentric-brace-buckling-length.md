# 偏心ブレースの軸力接続と圧縮座屈長さを分離する

Status: accepted

[Issue #1364](https://github.com/hrntsm/SEPIKA/issues/1364)では、実材軸を既存の弾性トラスに渡し、梁・柱と同じ微小剛体接続を適用する。偏心に由来する節点モーメントをブレースの曲げ耐力として評価するモデルは採らない。非線形解析内のトラスにも同じ初期幾何を使い、新しい材料履歴や幾何剛性は追加しない。

実材軸長は軸剛性・軸力・質量を定めるが、接合部の支持条件と座屈長さは同一ではない。剛体腕を座屈長さへ加える、または実軸長を無条件に採用する方式の安全性を一般に確定できないため、非0偏心の一般圧縮ブレースは両主軸の座屈長さ直接指定を必要とする。未指定の方向があれば理由付きで未検定とし、引張検定・偏心0の既存条件・座屈拘束ブレースの既存専用検定は維持する。

支持・元の節点と部材所属は移動させず、接触からの接合推定や支持部材の自動分割は行わない。回転の不安定性を微小剛性で補正せず、解析入口の診断を返す。現在の仕様は[端別XYZ偏心](../../docs/model_edit/09_梁の鉛直偏心.md)と[座標変換](../../docs/calc_basis/04_要素剛性/08_座標変換.md)を正本とする。
