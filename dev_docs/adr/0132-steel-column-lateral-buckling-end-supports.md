# 一般H形鋼柱の横座屈長さに実材端支持の確認を求める

Status: accepted

一般H形鋼柱の強軸曲げでは、両実材端で横移動とねじれの有効な拘束が成立し、中間横補剛がないと設計者が確認した場合に、実材軸長を横座屈長さとして採用する。確認は検定する荷重状態で圧縮側となる各フランジについて行う。通常検定と時刻歴簡易検定に共通の条件を適用する。

節点の拘束条件だけでは、接合や偏心部を介して圧縮フランジを拘束できる位置を確定できない。実材端より外に有効な支点がある場合に実材軸長を採ると横座屈長さを過小評価し得る。梁用の等間隔横補剛本数には端部と中間補剛の有効性が含まれず、始端・中央・終端の直接入力には支点位置や補剛区間の端部モーメントとの対応がない。支持条件が確定しない場合、または別の位置で横補剛する場合の横座屈照査は未算定とし、独立に確定する不適合と未算定理由を保持する。
