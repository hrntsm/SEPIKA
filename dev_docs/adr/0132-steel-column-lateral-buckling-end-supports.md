# 一般H形鋼柱の横座屈長さに実材端支持の確認を求める

Status: superseded by ADR-0148

一般H形鋼柱の強軸曲げでは、両実材端で横移動とねじれの有効な拘束が成立し、中間横補剛がないと設計者が確認した場合に、実材軸長を横座屈長さとして採用する。確認は検定する荷重状態で圧縮側となる各フランジについて行う。通常検定と時刻歴簡易検定に共通の条件を適用する。

節点の拘束条件だけでは、接合や偏心部を介して圧縮フランジを拘束できる位置を確定できない。実材端より外に有効な支点がある場合に実材軸長を採ると横座屈長さを過小評価し得る。梁用の等間隔横補剛本数には端部と中間補剛の有効性が含まれず、始端・中央・終端の直接入力には支点位置や補剛区間の端部モーメントとの対応がない。支持条件が確定しない場合、または別の位置で横補剛する場合の横座屈照査は未算定とし、独立に確定する不適合と未算定理由を保持する。

確認を適用するのは、照合対象の端条件が確認時と一致する間に限る。両端節点の座標・拘束・ばね、柱の断面形状・偏心・端条件・局所軸・手動剛域に加え、両端に直接接続する入力要素の断面寸法、軸・せん断・曲げ・ねじり剛性の主要入力、ダンパーの特性、柱端を含む拘束と相手節点の状態、梁端のねじり解放設定を照合する。接続の削除や設定変更で過去の確認を流用しないためである。確認は入力条件を参照し、解析で生成するパネル・壁要素、自動剛域、剛床重量を照合対象に含めない。接続壁の開口・スリット、接続梁と床板の合成条件、モデル外の接合詳細、二次部材の補剛性能、離れた位置の拘束が実材端に伝わるかどうかは設計者が再確認する。モデルを確認時の入力に戻した場合は記録を再び採用できる。

[ADR 0148](0148-steel-calculation-sources.md)により、設定がない場合は節点間距離を既定値として採用する。[製品の適用条件](../../docs/calc_basis/06_一次設計/03_05_鋼柱_ブレースの軸力_曲げ検定.md#一般h形鋼柱の横座屈長さ)を参照。
