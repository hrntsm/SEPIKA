# 壁単体の確定step応答を線材応答から分離する

- Status: accepted
- Date: 2026-10-10

## 判断

4節点壁を線材専用の `PushoverMemberResponse` 集合から除外し、各確定stepに `WallStepResponse` を保存する。壁単体の全体座標合力・基準点付きモーメント、局所Qw、加力方向Qdir、弦変形、既存の仮想壁柱断面力を保持する。未提供値には `None` と理由を使い、線材応答の0を壁の測定値へ読み替えない。

節点対応・面内軸は `wall_element_geometry` と要素の正規化自由度順を再利用する。下辺a/bの順から独立した新しい絶対正方向は導入しない。仮想壁柱の位置・局所断面力規約をそのまま保持し、付帯柱との自動合算や側柱識別は行わない。

入力世代はGUIの既存結果入力照合データ、MCPでは入力モデル・解析設定の直列化データで識別する。runの識別と確定step番号を結果に保持し、壁版への対応は既存の壁展開インデックスを使う。低水準のソルバ結果には入力識別未提供の理由を保持する。旧保存結果の壁専用履歴がない場合は未記録として扱う。

## 理由と帰結

同じ壁でも局所QwとQdirは斜めの構面で異なる。節点モーメントの和だけでは基準点までの腕によるモーメントが欠落する。弦変形角は剛体回転・曲げを含むため、材料せん断ひずみとして提供できない。壁内部の塑性状態を線材イベントの不在から判定することもできない。

既存の壁ランク分岐は対象kindからWallが除外されて到達しなかったため、Wallを対象に含め、専用結果のQw符号を正負別Qu選択へ、|Qw|を局所頭打ち・τu/Fc判定へ、|Qdir|を層の正の水平負担割合へ接続する。壁応答が未記録・不正なら明示的に拒否する。平均せん断応力度、層集計、同step選択、側柱を含む系全体の評価は別の課題であり、その式や集計基準は変更しない。

矩形鉛直壁以外の壁専用応答は未検証理由を記録する。既存解析要素の生成可否をこの結果制限によって変更しない。現在仕様と単位・適用条件は [壁エレメントモデル](../../docs/calc_basis/04_要素剛性/05_壁エレメントモデル.md#壁単体の確定ステップ応答) を正とする。
