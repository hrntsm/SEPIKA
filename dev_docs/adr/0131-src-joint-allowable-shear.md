# ADR 0131: SRC柱梁接合部の許容せん断を構面別に評価する

- Status: accepted
- Date: 2026-11-20

## 背景

原典照合で、接続本数と梁端曲げの絶対値和だけから形状・応力を組み立てると、直交梁や応力行の有無で同じ構面の許容値が変わることを確認した。特に部材の応力レコードが欠けると、構面が消えるか、検定比0として扱われる場合があった。

## 判断

節点の部材接続から構面を選び、その構面の実柱面曲げが全てある場合に限り需要を組み立てる。通常の検定は線形静的解析の実柱面専用断面力を受け取る。SRC梁・S梁の短期は構面別に登録された接合部帯筋を用いる。RC梁の短期は、梁鉄骨のない接合部のウェブ有効高さと応力伝達を確定できるまで未算定とする。必要な応力や諸元を確認できない場合はその理由を残す。応力伝達の省略条件は確認済みの部分曲げ耐力和から評価し、架構モデルで耐力和を確定できない場合はパネルの許容せん断と独立に別途確認を残す。

## 理由と影響

応力が得られない構面を結果から除外すると、接合部がないモデルと、接合部に必要な応力がないモデルを区別できず、全適合の集計に影響する。モデル側から候補を特定することで、入力欠落と需要ゼロを区別できる。帯筋の有効な脚・間隔・幅は接合詳細に依存する。近接する応力位置からの置換も、部材荷重の不連続や剛域の影響で需要の過小評価を防げない。

共通の接合部検定結果を使い、GUIとMCPの双方で構面・未算定理由・伝達の別途確認を保持する。保存検定の計算契約版を更新する。
