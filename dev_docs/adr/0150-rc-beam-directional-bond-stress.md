# 非降伏RC梁の大地震時付着照査は確認済みの方向別応力度から行う

- Status: accepted
- Date: 2026-11-25
- Related: [#1872](https://github.com/hrntsm/SEPIKA/issues/1872)、[#1894](https://github.com/hrntsm/SEPIKA/issues/1894)

## Context

RC規準2024年版16条1項(3)3)は、付着検定断面で同じ鉄筋の長期荷重時と水平荷重時の存在応力度を要求する。終局検定で使用する長期需要の集約値と増分解析の確定総応答では、この荷重別・主筋別の値を復元できない。また、最大曲げ断面が分かっても、非対称配筋では別断面の異なる主筋が支配しないことまでは確認できない。

## Decision

正負地震荷重ごとに、曲げ非降伏と断面位置、採用主筋、同じ断面・主筋の荷重別存在応力度を確認済みの直接入力として受ける。必要な付着照査をその断面で代表できるかは別に確認する。二つの荷重成分を別断面や逆側の引張筋から寄せ集める方法、総応答差による推定、応力中心距離の一律近似では応力度の過小評価を避けられると確認できないため採用しない。採用主筋がいずれかの荷重で圧縮側となる場合も、同じ鉄筋の圧縮成分をどう扱うかの根拠を確認できないため未算定とする。

## Consequences

既存の付着耐力式や降伏梁・柱の入力方式を変えず、方向ごとに確認した主筋と設計用引張応力度を追跡できる。代表性未確認や一方向の入力欠落があっても、確認済みの応力度・必要延長の不適合は失わない。直接入力は保存しないため、解析・保存検定の契約版は変更しない。通常の設計タブは情報不足を表示し、方向別の需要取得は別途扱う。[製品の計算根拠](../../docs/calc_basis/08_部材終局耐力/02_02_RC梁_柱の大地震時の付着照査.md)・[検証](../v_and_v/RC梁の方向別終局付着_Issue1872_検証.md)
