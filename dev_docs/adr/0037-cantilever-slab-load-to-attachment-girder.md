# 線アンカーの取り付く床板は取付き大梁だけへ等分布伝達する

Status: accepted

線アンカーの取り付く床板（片持ち・バルコニー）は、荷重伝達方向、側辺・先端辺の支持部材の有無によらず、取付き線の取付き大梁だけへ全荷重を等分布で伝達する。面荷重 `q`、出し長さ `d` に対する線荷重は `w_line = q*d` とし、部分取付き区間でも総荷重 `q×面積` を保存する。

旧方式の側辺・先端支持辺への最近接負担面積分配は採らない。片持ち床板の特殊な支持条件では、基準資料に基づく取付き線への伝達規則とならず、側辺・先端辺の実部材や小梁の存在によって伝達先が変わるためである。

点アンカー（出隅）と囲まれた床板は対象外とする。
