# SRC内蔵H形断面の軸力・曲げの材料強度は製造区分と各母材の実板厚から選ぶ

Status: accepted

矩形SRC梁・柱の断面形状に内蔵H形断面の製造区分を保持する。材料割当は一つなのでウェブと上下フランジで材種が同じ組立材だけを算定対象とする。圧延品のフランジ厚による製品規格の区分では、ウェブの降伏強度を決められない。製造区分を断面寸法から推定せず、圧延と不明は理由付きでファイバー材料を確定しない。根拠を持たない直接入力の強度で補完すると母材の適用判断ができなくなるため、既知の適用条件を満たす組立材に限定する。

組立材は各母材の実板厚を告示の強度表に照らす。ウェブとフランジを一律に扱うと、板厚区分の組合せによって軸力・曲げ耐力を過大評価する。材料強度基準の割増を各板に一度だけ適用し、告示第2464号第3第1号の上限を超える入力は算定しない。以前の解析結果を再採用しないよう解析契約版を114に更新する。未記録の製造区分はOVIKA読込時も不明とする。

ST-Bridge入出力は廃止されたため復活させない。現行のSRC梁・柱の方向別せん断降伏は非対応であり、本判断はその復元力や判定式を追加するものではない。
