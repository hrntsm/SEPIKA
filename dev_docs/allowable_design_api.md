# 許容応力度検定のGUI非提供API

通常のGUIで採用する式・入力条件の正本は[許容応力度・部材検定](../docs/calc_basis/06_一次設計/README.md)とする。本書はGUIから選べないライブラリ専用方式を扱う。現在のGUIの選択肢として案内しない。

許容曲げ応力度の公開API `SteelFbBasis` は `Standard1973` と `Asd2019` を持ち、既定は `Asd2019`。GUIはこの既定を採用する。1973年版の選択はAPI呼出側で明示する。

## 1973年版の許容曲げ応力度

\\[ f\_b = \max(f\_{b1}, f\_{b2}) \le f\_t \\]

\\[ f\_{b1} = F(2/3 - (4/15)(l\_b/i)^2/(C \cdot \Lambda^2)) \\]

\\[ f\_{b2} = 89000/(l\_b \cdot h/A\_f) \\]

断面二次半径 \\( i \\) は、圧縮フランジと、せいが部材せいの 1/6 のウェブからなる T 形断面で算定します（ウェブ部の高さは \\( \max(h/6 - t\_f,\ 0) \\)）。上下フランジの形状が異なる組立 H 形（BH）は、どちらが圧縮側か特定できないため、上下フランジそれぞれで求めた T 形断面のうち \\( i \\) が小さい側を安全側として採用します。

短期は長期の1.5倍、上限はF。横座屈修正係数C、横座屈長さ、記号・単位は[鋼構造の現行採用式](../docs/calc_basis/06_一次設計/03_鋼構造_断面検定.md#許容曲げ応力度と横座屈)を参照する。F・fbはN/mm²、lb・h・iはmm、Afは圧縮フランジ面積mm²、C・Λは無次元。

実装入口: `sepika_design_jp::steel::{steel_fb_h, steel_fb_h_asd2019}`（[section.rs](../crates/sepika-design-jp/src/steel/section.rs)）。

## 方向を区別しない柱座屈長さのAPI

`steel_column_k` / `steel_column_k_with_index` は方向を区別しない簡略版で、全部材に強軸の断面二次モーメントを用いる。梁の結合状態（ピン接合を含む）を考慮せず、剛域による材長補正も行わない。支点境界条件・梁遠端の結合状態も考慮しない。GUIの軸別算定で方向の水平投影が縮退した場合にも、この簡略版と同じ剛度比を用いる。

実装入口: [buckling.rs](../crates/sepika-design-jp/src/steel/buckling.rs)。
