## 概要

SEPIKA（セピカ）は、Rust で開発する日本の建築構造計算一貫プログラムです。
モデル作成から荷重計算・構造解析・検定・設計・レポートまでを一つの流れで扱い、
計算根拠を確認しながら構造設計を進められるオープンソースのソフトウェアを目指しています。

## 開発状況・はじめ方

現在は開発中です。機能の実装・検証と GUI の整備を進めており、
一般利用向けの完成した正式リリースとして案内する段階ではありません。
